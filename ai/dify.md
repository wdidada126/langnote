# dify

什么是Dify？
Dify（Do It For You）是一个开源的 LLMOps 平台，专注于缩短 AI 原型与生产应用之间的距离。它通过「可视化 + API 优先」的方式，帮助开发者快速构建、测试、监控并上线基于大型语言模型（LLM）的解决方案，支持从聊天机器人、检索增强生成（RAG），再到代理 Agent 的全功能覆盖。
