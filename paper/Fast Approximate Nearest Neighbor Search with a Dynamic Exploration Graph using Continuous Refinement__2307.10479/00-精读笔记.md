## 一句话总结

图类 ANN（如 HNSW）通常「先建一个静态分层图、之后增量插入会逐渐劣化」。DEG 反其道而行：只维护一张**无向偶正则图**（每个点度数固定、且保证连通），插入新点时通过「部分替换旧边」同时完成新点接入和老邻域更新，并用边优化算法**持续打磨**图的质量——于是搜索更快、索引大小可预测、连通性有保证，还天然支持动态增删。

## 0. 给新手的阅读前置（背景知识地图）

**子方向解决什么大问题**：同 Falconn++ 笔记的背景——ANN 是向量检索基石。图类方法目前是 recall-speed 权衡最强的一类，也是主流向量数据库的默认索引。

**为什么难（图方法的痛点）**：
- 图质量决定搜索效率：好图 = 短路径 + 少绕路 + 强连通；
- 经典方案（NSG/HNSW）构建成本高或结构复杂（分层、剪枝启发式多）；
- 动态插入会劣化图质量：老图的边是按「当时的数据分布」连的，新点进来后旧邻域不再最优；
- 删除/更新支持普遍较弱。

**几类主流解法（图类内部）**：

| 方案 | 结构特点 | 短板 |
|------|---------|------|
| HNSW | 分层跳表式图，贪婪搜索 | 层级结构复杂、内存开销、理论保证弱 |
| NSG/Vamana | 单图 + 裁边（α 剪枝） | 构建慢，动态性差 |
| **DEG（本文）** | 单张无向偶正则图 + 边替换 + 持续优化 | 🔧（论文讨论的取舍见原文） |

**关键名词直觉解释**：
- **偶正则图（even regular graph）**：每个顶点度数都相同（偶数）的图——好处是索引大小完全可预测（度数 × 点数），且容易维护出度不超标。
- **贪婪搜索（greedy search）**：从入口点出发，每步跳向邻居中离查询最近者，直到没有更近的邻居为止——图 ANN 的标准搜索方式。
- **探索式查询（indexed query / exploration）**：以图中某个已有顶点为查询起点（查询点本身在图里），做邻域探索型任务；论文发现 ANNS 强的图做这种探索并不一定好。

## 1. 问题背景与动机

- 前人工作：HNSW（分层图 + 启发式裁边）、NSG（单调搜索图 + 裁边）、Vamana（DiskANN 用的 α-图）等在静态场景表现优异。
- 前人缺陷/未解决问题（据论文动机）：
  1. 大多数图的边在构建时一次定型，增量插入新点后，老顶点的邻域不会更新，图质量随时间劣化；
  2. 结构复杂（分层、复杂裁边规则）导致构建慢、实现难、索引大小不易预测；
  3. 连通性缺乏保证——某些剪枝策略可能让部分顶点不可达，搜索会漏掉它们；
  4. 「以图中已有顶点为起点的探索式查询」这一场景几乎没人专门评估——ANNS 效率高 ≠ 探索效率高。

## 2. 核心方法

**最直观类比**：传统建图像「先画好一整张城市地图，之后新开的路只能粗糙地接上去」；DEG 像一个「永远在施工的养护队」——每接入一条新路，就顺手重铺几段旧路，地图随时都保持在良好状态。

**具体做法（输入 → 关键操作 → 输出）**：
1. **图形态**：只维护**一张无向偶正则图**（度数统一，如 2k），搜索与构建共用同一张图；
2. **增量插入 + 边替换**：新顶点到来时，不是简单追加边，而是「部分替换」图中已有边——新点接入的同时，老顶点的邻域也被更新（一次操作两件事）；
3. **持续边优化（continuous refinement / edge optimization）**：一个边优化算法在构建过程中不断改进边的选择，让图在任意时刻都是「组织良好的」，而非只在建完时最好；
4. **搜索**：标准贪婪遍历（搜索过程细节与参数见原文 🔧）。

**理论性质 / 保证**（论文明确列出的四点）：
1. 搜索效率更高；
2. 索引大小可预测（正则度数决定）；
3. **连通性有保证**，因而所有顶点可达；
4. 天然是动态图结构（支持持续插入）。

## 4. 实验结论（概览）

- **对比基线**：HNSW、NSG 等现有图 ANN 算法（完整清单 🔧 查原文）。
- **数据集**：多个标准 ANN 数据集（名称/维度/规模 🔧 查原文）。
- **指标**：recall vs 查询时间；构建/插入效率；探索式查询性能。
- **结论方向**：
  1. DEG 在 indexed（探索式）与 unindexed（普通）两类查询上都显著优于现有算法；

## 7. 2026 视角（🔧）

- 动态/流式 ANN 是 2024–2026 的活跃议题：RAG 知识库频繁增删向量，静态图的「插入劣化」问题被放大，DEG 的「边替换 + 持续精化」思想与 FreshDiskANN 等一同构成动态图 ANN 的代表作。
- 工业主力仍是 HNSW（FAISS、Milvus、pgvector 等）与 DiskANN 系；DEG 属于「结构更简单、保证更强」的学术挑战者，尚未见大厂内置 🔧。
- 索引大小可预测 + 连通性保证这两点，对多租户向量数据库的资源规划有实际意义。

## 8. 新手学习路线

- **10 分钟**：读本笔记 + 摘要，抓住「偶正则图 + 边替换 + 持续精化」三个词。
