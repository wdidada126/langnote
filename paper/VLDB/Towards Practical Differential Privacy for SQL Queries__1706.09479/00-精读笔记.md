## 一句话总结
差分隐私（DP）号称能「分析数据又不泄露个人」，但已有机制扛不住真实世界里五花八门的 SQL 特性（尤其是 join）；本文先用 810 万条真实查询做实证研究，摸清实用 DP 到底需要什么，接着提出 elastic sensitivity（弹性敏感度）——一种能对含一般 equijoin 的查询近似 local sensitivity 的方法，证明了它是 local sensitivity 的上界，因此可安全地接到任意基于 local sensitivity 的机制上；最后做成端到端系统 FLEX，能挂在任何现有数据库上，开销只有 0.03%。

## 0. 给新手的阅读前置（背景知识地图）
- 子方向解决什么大问题：让分析师在敏感数据上跑 SQL 聚合（如「某病种的平均住院天数」），同时给出可证明的隐私保证——即差分隐私（DP）。
- 为什么难：DP 要加噪声，噪声大小取决于查询的敏感度（sensitivity）：加/删一个人的记录，查询结果最多变多少。真实 SQL 有 join、子查询、各种函数，且 join 会让一条记录影响多行、敏感度可能爆炸；而已有机制往往只支持很窄的查询子集。
- 几类主流解法：

| 方法 | 代表 | 思路 | 优缺点 |
|------|------|------|--------|
| global sensitivity + 拉普拉斯/高斯机制 | 经典 DP | 用最坏情况敏感度加噪 | 简单有保证，但噪声大（尤其 join） |
| local sensitivity / smooth sensitivity | 经典改进 | 用「当前数据库」下的敏感度 | 噪声小，但计算难、还需平滑 |
| 专用查询类机制（如只支持 count/sum 无 join） | 早期系统 | 限定查询语言 | 安全但覆盖面窄、不实用 |
| elastic sensitivity + FLEX（本文） | 本文 | 静态分析 SQL join 结构，近似 local sensitivity 的上界 | 覆盖面广、开销极低；是上界故保守 |

- 本文属于哪一类：local sensitivity 的可证明上界近似 + 端到端系统路线。
- 必懂关键名词：
  - differential privacy（差分隐私）：相邻数据库（相差一个人的记录）上，查询结果分布几乎不可区分；用 ε（有时 δ）量化。
  - global vs local sensitivity：前者是对所有数据库的最坏变化量；后者是针对当前这个数据库的最大变化量，通常更小所以噪声更少。
  - equijoin：等值连接（`ON a.id = b.id`），是真实查询里最常见也最容易放大敏感度的操作。
  - mechanism（机制）：给查询结果加噪的具体算法（如 Laplace 机制）。

## 1. 问题背景与动机
- 前人工作简述：DP 理论成熟，已有不少机制与一些原型系统，但大多只支持有限的查询特性（尤其难以处理 join 与真实 SQL 方言）。
- 前人缺陷/未解决问题（逐条）：
  1. 特性覆盖不足：真实 SQL 用到的众多特性（join、嵌套、各种表达式）在已有机制中没有支持。
  2. 数据库兼容性差：已有方案常要求特定存储/引擎，难以接进现有数据库。
  3. 敏感度难算：join 的存在使 local sensitivity 难以精确计算，粗暴用 global sensitivity 又导致噪声过大、结果不可用。
  4. 需求不明：缺少基于真实查询负载的实证研究来界定「实用」到底意味着什么。

## 2. 核心方法
- 最直观类比：给查询结果加多少噪声，取决于「改一个人最多能让结果变多少」。精确算这个值很贵；elastic sensitivity 的做法是算一个一定不小于真实值的估计——宁可多加点噪声（保守），也绝不低估（那会破隐私）。
- 具体做法（输入 → 关键操作 → 输出）：
  1. 实证研究：收集 8.1 million 条真实 SQL 查询，归纳出实用 DP 的需求，并据此分析前人方法的局限。
  2. elastic sensitivity：对含一般 equijoin 的查询，通过静态分析（沿 join 链传播每表的敏感度上界）近似 local sensitivity。
  3. 理论保证：证明 elastic sensitivity 是 local sensitivity 的上界，因此可以被任何 local sensitivity-based 机制（如 smooth sensitivity 机制）安全使用。
  4. 系统 FLEX：端到端系统，在查询执行前分析 SQL → 计算 elastic sensitivity → 选机制加噪 → 返回结果；可兼容任意现有数据库。
  5. 输出：满足 DP 的查询结果。
- 形式化要点：关键性质是 `elastic_sensitivity(q, D) ≥ local_sensitivity(q, D)`（上界/可靠 over-approximation）；摘要未给出 ε 取值等超参数 🔧。
- 理论性质/保证：有——elastic sensitivity 是 local sensitivity 的上界（这是正确性/隐私安全性的关键定理）。

- 10 分钟：读摘要 + 第 0、2 节，记住一句话：elastic sensitivity = local sensitivity 的安全上界。
