## 一句话总结
指出主流 NL-to-SQL 基准（如 Spider）用的数据库太简单、领域训练数据几乎没有，导致现有系统在真实复杂科学库上很差；ScienceBenchmark 用三个真实、高度领域专用的科学数据库（科研政策、天体物理、癌症研究），由 SQL 专家+领域专家手工造高质量 NL/SQL 对，再用 GPT-3 合成数据扩充，证明 Spider 上 SOTA 系统在它上面成绩很低，"NL-to-SQL 远未解决"。

## 0. 给新手的阅读前置（背景知识地图）
- 子方向解决什么大问题：Text-to-SQL / NL-to-SQL 评测——衡量"把自然语言问题翻成 SQL"的系统有多准。好的基准应反映真实难度；但 Spider 等老基准库小、表少、领域简单，系统刷到 80%+ 却一碰到真实复杂库就崩。
- 为什么难：真实科学库表多、列多、领域术语强、几乎没有现成 NL/SQL 训练对；手工标注贵，系统容易过拟合简单库。
- 几类主流解法（基准分类）：

| 路线 | 代表 | 直觉 |
|------|------|------|
| 简单单域基准 | Spider、WikiSQL | 库小、表少，易刷分但不真实 |
| 复杂真实基准 | ScienceBenchmark、BIRD | 真实大库/领域库，更贴近落地 |
| 数据增强 | GPT-3 合成 NL/SQL | 用 LLM 扩充稀缺训练对 |

- 本文属哪类：评测基准论文，提出复杂真实领域的 NL-to-SQL 基准。
- 关键名词直觉：
  - NL-to-SQL / Text-to-SQL：自然语言 → SQL 的翻译任务。
  - Spider：最流行的跨库 Text-to-SQL 基准，但库偏简单。
  - execution accuracy（执行准确率）：跑生成的 SQL 看结果是否与标准一致，本文采用的主要指标。

## 1. 问题背景与动机
- 前人工作简述：Transformer 语言模型 + Spider 把 NL-to-SQL 准确率推到 80%+，但 Spider 库简单、领域训练数据稀缺。
- 前人缺陷/未解决问题（逐条）：
  1. 基准不真实：Spider 库表少、列少、条目少，不能反映真实设置。
  2. 领域数据稀缺：复杂真实库几乎没有 NL/SQL 训练对，现有系统表现差。
  3. 缺领域专家校验：老基准缺乏领域专家把关的训练/测试数据质量。

## 2. 核心方法
- 最直观类比：Spider 像"小学应用题"，ScienceBenchmark 像"带专业术语的博士考题"——不是题量更多，而是每道题更真、更专。
- 具体做法（输入 → 关键操作 → 输出）：
  1. 选三个真实科学库：科研政策（CORDIS）、天体物理（SDSS）、癌症研究（OncoMX），表多、列多、数据量大。
  2. 手工造数据：SQL 专家 + 领域专家为每个领域造高质量 NL/SQL 对。
  3. 合成扩充：用 GPT-3 生成合成数据补充稀缺的手工数据。
  4. 评估：在 dev/test 上测各 SOTA 系统的 execution accuracy（测试集不公开，需提交评测）。
  - 输出：一个高挑战、领域专家校验的 NL-to-SQL 基准 + 排行榜。
- 形式化要点：核心是"真实复杂领域库 + 专家校验 + LLM 增强"的基准构建范式；指标用 execution accuracy。
- 理论性质/保证：无；属实证评测论文。

## 4. 实验结论（概览）
- 对比基线：Spider 上表现最好的系统（T5-Large、SmBoP+GraPPa、ValueNet 等）。
- 数据集：CORDIS、SDSS、OncoMX 三个科学库。
- 指标：execution accuracy（dev/test）。
- 结论方向（官网排行榜已核实数字，2023 年提交）：
  - 这些系统在 ScienceBenchmark 上 execution accuracy 很低：例如 CORDIS test 仅 14%（T5-Large），SDSS test 最高 30%，OncoMX test 最高 24%。
  - 证明 Spider-trained SOTA 在复杂真实领域上大幅下降，NL-to-SQL "远未解决"。
  - 🔧 最新排行榜数字请查 ScienceBenchmark 官网后补入。

## 7. 2026 视角（🔧）
- LLM（如 GPT-4）时代 NL-to-SQL 准确率在 Spider 上已很高，但"复杂真实大库 + 领域术语"仍是难点；ScienceBenchmark、BIRD 这类真实基准成为衡量 LLM-based 系统的主要标尺，且衍生出大量数据合成（OmniSQL、SQL-Factory 等）工作。
- 本节为趋势判断（🔧 具体生态以当年为准）。
