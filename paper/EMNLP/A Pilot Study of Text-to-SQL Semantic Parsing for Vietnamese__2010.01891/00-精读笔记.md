## 一句话总结

越南语在该任务上也是低资源语言。本文**发布首个公开的越南语大规模 Text-to-SQL 语义解析数据集**，并在其上扩展、评测两大强基线 EditSQL 与 IRNet，得出关键经验：自动越南语分词能提升两个基线；**NPMI 分数有助于 schema linking（模式链接）**；越南语依存句法特征也有帮助；单语模型 **PhoBERT 优于多语模型 XLM-R**。

## 0. 给新手的阅读前置（背景知识地图）

### 0.1 Text-to-SQL 与「低资源语言」
- 同中文那篇：把自然语言问题转成 SQL。英文标杆是 Spider。
- **低资源语言**：缺少大规模标注数据、预训练模型也少（如越南语）。本文目标就是补越南语的空白。

### 0.2 两个关键子任务名词
- **Schema Linking（模式链接）**：把问题里的词对应到数据库的具体表/列。例如「员工」→ 表 `Employee`，「工资」→ 列 `salary`。这一步错了 SQL 必错。
- **分词（word segmentation）**：越南语虽用空格，但语义词常由多词构成，仍需分词以得到更好单元。

### 0.3 关键模型/技术名词
- **EditSQL**：基于「编辑」思想的 text-to-SQL 模型（Zhang et al., 2019）。
- **IRNet**：把自然语言先转成半抽象的中间表示再生成 SQL（Guo et al., 2019）。
- **NPMI（归一化点互信息）**：衡量两个词共现强度的统计量，本文用它辅助 schema linking。
- **PhoBERT / XLM-R**：越南语单语 / 跨语言预训练语言模型。

## 2. 核心方法

### 2.1 直觉类比
像为中文翻译官准备「越南语版考题 + 参考答案」：本文先造出一套越南语的「自然语言问句 → SQL」考题（数据集），再让两名优等生（EditSQL、IRNet）去考，并逐一调整他们的「备考方式」（分词、schema 链接方法、句法特征、语言模型）看谁分高。

### 2.2 步骤
1. **构建越南语数据集**：发布首个公开的大规模越南语 Text-to-SQL 数据集（ViText2SQL）。
2. **扩展并评测两大基线**：在越南语数据上跑 EditSQL 与 IRNet，做关键配置对比。
3. **逐项实验关键配置**，提炼经验。

### 2.3 核心发现（本文的硬货）
- **自动越南语分词**提升两个基线的解析结果；
- **NPMI 分数**对 schema linking 有用；
- 越南语神经依存句法 parser 抽出的**潜语句法特征**也有帮助；
- 单语模型 **PhoBERT 表现优于近期最佳多语模型 XLM-R**。

## 7. 2026 视角（🔧 给今天的读者）

- **多语言 Text-to-SQL 已成独立方向**：大模型时代，跨语言、低资源语种 text-to-SQL 有更多工作；本文的「单语模型优于多语」经验在如今仍具参考价值。
- **预训练范式变化**：如今多数直接用多语/单语 LLM + 提示（ICL），传统「分词 + 句法特征」工程被大幅简化，但 schema linking 仍是核心难点。
- **新趋势补充**：顺读本仓库 XiYan-SQL、综述，以及 ICL 错误分析（2501.09310）。
