## 0. 给新手的阅读前置（背景知识地图）
- 子方向解决什么大问题：Text-to-SQL（也叫语义解析 semantic parsing）是把人话「这张表里工资最高的人是谁」翻译成可执行 SQL 的任务。它是打通「自然语言界面」与「关系数据库」的关键一环。
- 为什么难：一句话可能对应很长的 SQL（嵌套、多表 JOIN、聚合）；同一个意思可以有很多种表达；训练数据稀缺且标注昂贵。
- 几类主流解法：

| 方法 | 代表 | 思路 | 优缺点 |
|------|------|------|--------|
| 序列到序列（seq2seq） | 早期神经语义解析 | 把 SQL 当字符串直接生成 | 简单，但对结构不敏感、易语法错 |
| 基于骨架/草图 | RAT-SQL、RYANSQL | 先定 SQL 结构再填槽位 | 结构更可靠，但仍缺细粒度监督 |
| 对齐增强 | 本文 Squall | 显式标注词-逻辑片段对齐 | 监督更丰富，迁移到翻译式训练 |

- 本文属哪类：在 encoder-decoder（序列到序列）范式下，额外引入「词法-逻辑对齐（lexico-logical alignments）」这一细粒度监督，并借用机器翻译里的技术（监督注意力、辅助消歧目标）。
- 2-3 个必懂关键名词（直觉解释）：
  - semantic parsing（语义解析）：把自然语言映射成机器可执行的「逻辑形式」（这里是 SQL）。
  - alignment（对齐）：把问句里的某个词（如「工资」）和 SQL 里的某个片段（如 `salary`）一一对应起来，像翻译里的「词对齐」。
  - execution accuracy（执行准确率）：生成的 SQL 在数据库上跑出来的结果，是否和正确答案完全一致——这是 Text-to-SQL 最看重的指标。

## 1. 问题背景与动机
- 前人工作简述：大规模带逻辑形式标注的语义解析数据集（如 WikiTableQuestions、Spider）出现后，纯监督的 seq2seq 模型取得了很大进展。
- 前人缺陷/未解决问题（逐条）：
  1. 监督信号太粗：此前大多只给「整句 → 整条 SQL」的配对，模型不知道句子里哪一块对应 SQL 里哪一块。
  2. 机器翻译里成熟的技巧用不上：翻译领域靠「对齐」做监督注意力、做短语对齐，但语义解析没有对齐标注，这类方法被挡在门外。
  3. 细粒度监督的潜力未被验证：究竟「词-逻辑对齐」能带来多大提升，缺乏一个带对齐标注的数据集来系统回答。

## 2. 核心方法
- 最直观类比：教小孩把中文句子翻成英文时，光给「整句↔整句」不够，最好用荧光笔把「苹果↔apple」标出来。Squall 就是给 SQL 任务发的「荧光笔标注」。
- 具体做法（输入 → 关键操作 → 输出）：
  1. 输入：WikiTableQuestions 里的英文问句 + 对应表格。
  2. 标注构建：人工为 11,276 条问句写出 SQL 等价物，并额外标注「问句片段 ↔ SQL 片段」的对齐关系，构成 Squall 数据集。
  3. 训练新可能：基于这份对齐，提出两种利用方式——
     - (1) supervised attention（监督注意力）：直接用对齐作为注意力的监督信号，让模型「看」问句时聚焦到对应的表列/值。
     - (2) 辅助消歧目标（auxiliary disambiguation objective）：训练模型把输入里的指代（哪个「他」、哪张表）正确消解到具体表列。
  4. 输出：更准确的 SQL 生成模型；并给出 oracle（上限）实验评估对齐信息的天花板。
- 形式化要点：核心是把「对齐」作为额外的监督信号注入 encoder-decoder；超参主要是对齐标注的利用方式与辅助任务权重（具体数值🔧查原论文）。
- 理论性质/保证：无形式化理论保证；贡献在数据集与经验性方法验证。

## 3. 变体 / 工程版（如有）
- Squall 数据集本身是该方向的公共资产；其「对齐」思想后续被多种 schema linking / 对齐增强的 Text-to-SQL 模型沿用（见 §6 互链）。代码仓 `tzshi/squall` 提供数据集与基线实现 🔧。

## 4. 实验结论（概览）
- 对比基线：强 seq2seq 基线（具体名称🔧查原论文）。
- 数据集：WikiTableQuestions 经 Squall 增强后的 11,276 条。
- 指标：execution accuracy（执行准确率）。
- 结论方向（摘要给出的已核实数字）：
  - 5 折交叉验证下，两种策略相比强基线提升 4.4% 执行准确率。
  - Oracle（若对齐信息完全可用）实验显示，对齐还能再带来最高 23.9% 的潜在提升。
  - 🔧 各数据集/基线的精确数字查原论文 Table 后补。
