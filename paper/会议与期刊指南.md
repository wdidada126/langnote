# 会议与期刊指南：计算机 / 软件 / AI 各专业及子方向

> 整理日期：2026-09-27
> 定位：按学科 / 子方向系统列出**顶级会议（以 CCF-A 为主）与代表期刊**，供选题、投稿、读论文时快速定位。
> 互链：AI 领域完整列表见 [`notes/ai.md`](../notes/ai.md)；CCF 奖励与系统领域委员会名单见 [`notes/CCF.md`](../notes/CCF.md)。
> 说明：级别标注依据 CCF 推荐目录（2022 版）与 CSRankings 共识；会议时间 / 地点逐年变化，投稿前请以官方 `aideadlines.com` / `ccfddl.top` 与各官网为准。

## 〇、怎么读这份清单

- **CCF-A**：国内认可度最高的「顶会 / 顶刊」门槛，投稿首选；CCF-B/C 为次选，部分方向 B 类也很强。
- **会议 vs 期刊**：AI / 系统 / 网络 / 安全等方向以**会议**为权威（录用率 10–25%，周期快）；数据库、理论、软件工程方向**期刊**同样重要。
- **CSRankings**：按方向给院校 / 会议排名，选会、选导师、看趋势都很实用（csrankings.org）。
- **录用率**：顶会普遍 15–25%，NeurIPS/ICML 等常 <25%；期刊周期长但含金量高。

## 🔧 2026 视角与缺口

- **跨方向收敛**：具身智能（VLA）、Agentic AI 正在模糊 CV / NLP / 机器人 / 系统的边界，投稿时可同时看 AI 与系统 / 机器人会议。
- **本仓库缺口**：尚无「人机交互」「理论」「图形学」「实时系统」方向的具体论文笔记；各方向我仅列了主干会议，未收 CCF-B/C 与区域会议（如 AAAI 之外的 IJCAI  workshop、APSys 等），可按需补。
- **勿杜撰**：以上级别/定位为公认共识；具体某年会某年的录用率、截稿日、h5-index 数值请以官方为准，本文件不编造数字。
