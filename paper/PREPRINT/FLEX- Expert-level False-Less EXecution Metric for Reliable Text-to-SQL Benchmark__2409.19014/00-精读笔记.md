## 一句话总结

Text-to-SQL 评测长期靠「跑一遍 SQL 看结果对不对」（EX 指标），但这个指标既会冤枉好模型也会放过坏模型。FLEX 请大语言模型当「人类专家裁判」，把与人类判卷的一致性从 Cohen's kappa 62 提到 87.04，并顺带揭出老指标系统性低估/高估模型的三类问题。

## 0. 给新手的阅读前置（背景知识地图）

- 子方向解决什么大问题：Text-to-SQL（自然语言转 SQL）模型迭代极快，但「怎么打分」一直没跟上。分错了分数，排行榜就会误导整个领域的研究方向。
- 为什么难：一条自然语言问题往往有多种正确 SQL 写法（等价重写）；而 EX 指标只执行模型 SQL 与金标 SQL，比结果集——碰上「结果碰巧一样但语义不同」或「金标标注本身有错」就失真。
- 几类主流解法：

| 路线 | 思路 | 优缺点 |
|------|------|--------|
| 精确匹配（ACC/EM） | SQL 串/成分逐一比对 | 等价重写全判错（高假阴） |
| 执行准确率（EX） | 执行两条 SQL 比结果集 | 主流标准，但对空结果集、标注噪声极敏感 |
| 测试套件（Test Suite） | 多组数据库实例反复执行 | 更严但工程重、仍有盲区 |
| LLM 裁判（本文 FLEX） | LLM 模拟专家综合判定 | 与人一致性最高，裁判模型自身偏差需警惕 |

- 本文属哪类：第四类——LLM-as-a-judge 式评测指标。
- 关键名词直觉解释：
  - EX（Execution Accuracy）：模型 SQL 与金标 SQL 在测试库上执行，结果一致则得分；
  - 假阳性/假阴性：模型错了却判对（放水）/模型对了却判错（冤枉）——EX 两头都有；
  - Cohen's kappa：衡量「评分者之间一致性」的统计量，剔除了「碰巧一致」的成分，越高越一致。

## 1. 问题背景与动机

- 前人工作简述：Spider、BIRD 两大基准都以 EX 为主指标；Test Suite（精准执行比对）等工作试图减少假阳/假阴；近年大量 LLM 方法的成绩也建立在 EX 上。
- 前人缺陷/未解决的问题（逐条，据摘要）：
  1. EX 存在大量假阳性与假阴性，且随系统复杂化日益突出；
  2. 与人类专家判断不一致：人认为对/错的，EX 常给出相反结论；
  3. 标注质量问题被系统性忽视：金标 SQL/问题本身有错时，模型「代标注背锅」；
  4. 困难问题上的高估：EX 对特别难的题目反而倾向给模型放水，掩盖了真实短板。

## 2. 核心方法

- 最直观类比：以前判卷是「对着标准答案抄一遍跑一遍」，FLEX 是请一位细心的老教授：他会看题目语境、数据库 schema、金标 SQL、候选 SQL，再按一套明确的评分细则裁定——包括发现「标准答案本身就写错了」。
- 具体做法（输入→关键操作→输出）：
  - 输入：自然语言问题 + 数据库 schema/内容上下文 + 金标 SQL + 待评模型 SQL；
  - 关键操作：用 LLM 构造「专家级评审提示」——提供全面的上下文（问题、库结构、数据）并施加精细的评判标准（等价性、语义符合度、金标可靠性 🔧 提示词细节查原文），让 LLM 输出判定；
  - 输出：每条样本的判定（对/错，含对金标质量的质疑 🔧 输出粒度查原文），汇总为 FLEX 分数。
- 形式化要点：以与人类专家的 Cohen's kappa 为核心校准指标；从 62 提升到 87.04。
- 理论性质/保证：无形式化保证；其有效性由「与人类一致性 + 大规模实验」支撑。

## 4. 实验结论（概览）

- 对比基线：传统 EX 指标；基准：Spider 与 BIRD；校准参照：人类专家判定。
- 结论方向（数字均据摘要，已核实）：
  1. 与人类专家一致性从 kappa 62 提升到 87.04；
  2. 用 FLEX 重评后，各模型性能平均提升超过 2.6 个百分点，并实质性改变 Spider/BIRD 排行榜名次；
  3. EX 低估模型的假阴性主要源于标注质量问题；
  4. 模型在特别困难的问题上反而容易被高估。

## 7. 2026 视角（🔧）

- LLM-as-a-judge 已是 NL2SQL/Text-to-SQL 工业评测的常见组件，但「裁判偏差、可复现性、成本」仍是公开争论点；FLEX 是最早系统量化「EX 假阳/假阴对排行榜的扭曲」的工作之一 🔧（通说）；
- 2026 年主流榜单（Spider/BIRD 及其后续）开始引入人工复核与多裁判集成 🔧（待证）；BIRD 后续版本对标注质量的清理与本文发现互相印证；
- 趋势：执行类指标与 LLM 判分正在融合（执行证据 + 语义审查），同时针对裁判模型的对抗鲁棒性研究兴起 🔧。
