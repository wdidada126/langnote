## 一句话总结

现有概率数据清洗要么假设太天真（比如全按高斯分布）经常欠拟合，要么要专家手写复杂先验太烧钱。BClean **自动构建贝叶斯网络**并允许用户交互式修改，把清洗变成贝叶斯推断：清洗 F 值最高 0.9，比其他贝叶斯方法高 2%，比其他清洗方法高 15%。

## 0. 给新手的阅读前置（背景知识地图）

- **大问题**：脏数据（错值、不一致、冲突）会让下游分析全错。数据清洗要"发现错误 + 修复错误"，而修复本质是猜"这条记录最可能本来是什么"。
- **为什么难**：属性之间相互依赖（城市↔邮编↔气温），改一处牵动全行；依赖关系（约束）很难人工写全；真实数据分布复杂不规则。
- **主流做法对比**：

| 方法 | 代表 | 思路 | 优缺点 |
|------|------|------|--------|
| 规则/约束式 | HoloClean 类 | 函数依赖+代价最小修复 | 可解释；约束要人工给 |
| 概率/贝叶斯 | 早期 BN 清洗 | 概率图模型推断 | 建模自然；分布假设简单易欠拟合 |
| 学习式 | RNN/ML 清洗器 | 数据驱动修复 | 需要标注；可迁移性弱 |

- **本文属于哪类**：第二类的系统化升级——自动学 BN + 用户可改 + 高效推断。
- **必须先懂的名词**：
  - **贝叶斯网络（BN）**：刻画属性间条件依赖的有向无环图概率模型。
  - **函数依赖（FD）**：`邮编 → 城市` 这类"定了 A 就定了 B"的约束。
  - **结构学习**：从数据自动学出 BN 的图结构。

## 1. 问题背景与动机

- 前人工作：概率清洗方法（含贝叶斯）要么假设简单分布频繁欠拟合，要么要求专家用编程语言写复杂先验分布。
- 未解决的问题：
  1. 自动且**不天真**的依赖发现（朴素假设不够）；
  2. 用户如何低成本注入领域先验、纠错自动生成的模型；
  3. 贝叶斯推断在大表上的效率。

## 2. 核心方法

- 类比：请一位会"自动画病历图谱"的医生——系统先自动画出属性之间的依赖图谱（BN），你若懂业务可以拿笔改两笔（加先验/纠错），之后所有修复都按这张图做概率推断，而不是瞎猜。
- 具体做法（输入 → 操作 → 输出）：
  1. **自动 BN 构建**：把基于结构学习的**函数依赖发现**与**相似度函数**结合，捕捉属性关系（比朴素独立假设更真实）；
  2. **用户交互**：允许用户修改生成的 BN——指定先验或纠正自动生成中的错误；
  3. **评分模型**：为贝叶斯推断设计补偿性评分模型（打分决定最优修复 🔧 细节见原文）；
  4. **效率三件套**：图划分、域剪枝、预检测等近似策略提速。
- 输出：修复后的数据集（带概率依据）。

## 3. 变体 / 工程版

- 系统本身就是面向真实应用的工程版；近似策略（图划分/域剪枝/预检测）分别对应"分而治之 / 缩小候选 / 提前拦截"。

## 4. 实验结论（概览）

- 对比基线：其他贝叶斯清洗方法 + 其他数据清洗方法；数据：真实与合成数据集。
- 结论方向（摘要明确给出）：清洗 F 值最高 **0.9**；比现有贝叶斯方法高 **2%**，比其他清洗方法高 **15%**。
