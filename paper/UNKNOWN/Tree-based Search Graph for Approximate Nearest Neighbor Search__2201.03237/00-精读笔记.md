## 一句话总结
图基 ANNS 里最强的一支是**单调搜索网络（MSNET）**（NSG、NSSG 等）：搜索时距离单调下降、不回头，因此出度小、效率高。但现有 MSNET 设计**没有优化「单调搜索成功」的概率**，其概率下界只有 **50%**；一旦单调搜索失败，就要付出巨大的**回溯（backtracking）**代价才能保住精度。本文先提出 **(r,p)-MSNET**，给出**有保证的单调搜索概率**；因其严格构建复杂度太高，又提出低复杂度的近似实现 **TBSG**；在**四个百万级数据集**上，TBSG 的搜索效率超过了现有的 SOTA 图基算法。

## 0. 给新手的阅读前置（背景知识地图）
- **子方向解决什么大问题**：在高维向量（embedding）里快速找到与查询最近的 K 个。精确搜索太贵，于是用**近似最近邻搜索（ANNS）**。
- **为什么难**：数据量大、维度高、还要在 recall 与延迟之间可调；图基方法还要额外付出**建图**成本，且搜索路径是否「走回头路」直接决定延迟。
- **几类主流解法**：

| 方法 | 代表 | 思路 | 优缺点 |
|------|------|------|--------|
| 倒排/聚类（IVF） | Faiss IVF-PQ | 聚类分桶，只扫最近几桶 | 构建快，但高 recall 时成本高 |
| 哈希 | LSH 系 | 用局部敏感哈希分桶 | 理论清晰，高维下精度/效率权衡较差 |
| 图索引（非单调） | HNSW、KGraph | 建近邻图后贪心游走 | 通用强，可能需要较多跳数 |
| 图索引（单调搜索网络） | NSG、NSSG、本文 TBSG | 建图时约束使搜索单调下降、少回溯 | 出度小、效率高；建图更复杂 |

- **本文属于哪一类**：**图索引 + 单调搜索网络（MSNET）**，专注于提高单调搜索的成功概率。
- **必懂关键名词**：
  - **Monotonic Search Network（MSNET，单调搜索网络）**：一种图结构性质，保证从入口点出发沿图游走时到查询的距离**单调下降**，从而不必回溯；NSG/NSSG 属此类。
  - **out-degree（出度）**：每个节点连出去的边数；出度小意味着每跳的距离计算少、内存占用低。
  - **backtracking（回溯）**：搜索走进「死路」后退回并尝试其它分支，代价高昂。
  - **recall@K**：返回的 K 个结果中真实近邻的比例，是 ANNS 的核心精度指标。

## 1. 问题背景与动机
- 前人工作简述：ANNS 领域中图基算法是最重要的分支之一；Fu 等人的研究表明基于 **MSNET** 的算法（如 **NSG**、**NSSG**）在搜索效率上达到 SOTA。MSNET 的设计目标是：**用最小的节点出度实现单调搜索**，从而追求高效率。
- 前人缺陷/未解决问题（逐条）：
  1. **未优化单调搜索概率**：现有 MSNET 设计只追求「最小出度下可单调搜索」，但没有刻意提高**单调搜索实际发生**的概率。
  2. **概率下界过低**：单调搜索概率的**下界只有 50%**——相当比例的查询会失败。
  3. **失败代价高昂**：一旦单调搜索阶段失败，为了达到所需精度，必须付出**巨大的回溯代价**。
  4. **由此产生性能问题**：上述回溯直接伤害搜索效率（延迟/吞吐）。

## 2. 核心方法
- **最直观类比**：把搜索想象成下山。MSNET 保证「地图上存在一条一路向下的路」，但没保证你站的位置一定能走上这条路；一半左右的情况你得往回爬（回溯）。本文的思路是：**在地图上多修一些「一定向下」的坡道**，让「一路向下」的概率可被保证。
- **具体做法（输入 → 关键操作 → 输出）**：
  1. **输入**：向量数据集。
  2. **理论目标 (r,p)-MSNET**：提出 **(r,p)-MSNET**，使单调搜索具有**有保证的概率（guaranteed probability）**——即把单调搜索的成功概率作为显式设计目标并给出保证。
  3. **降低构建复杂度**：严格的 (r,p)-MSNET **构建复杂度过高**，因此提出 **TBSG（Tree-Based Search Graph）** 作为其**低复杂度近似**。
  4. **搜索**：在 TBSG 上执行图搜索（沿用「跳到更近的点」的贪心游走），以更少的回溯达到目标召回。
  5. **输出**：查询的近似 K 近邻。
- **形式化要点**：关键参数是 **(r, p)**（r 与 p 的具体含义 🔧 以论文定义为准，可理解为与半径/概率相关的约束）；TBSG 以树结构组织来近似严格 (r,p)-MSNET 的性质。
- **理论性质/保证**：**有**——(r,p)-MSNET 提供**可保证的单调搜索概率**（这是本文的主要理论贡献）；TBSG 作为近似，其保证以工程近似方式达成。

## 3. 变体 / 工程版（如有）

## 7. 2026 视角（🔧）
- 图基 ANNS 已是向量数据库的默认索引（HNSW 在 CPU 侧、CAGRA 类在 GPU 侧占主导）；「减少回溯、让搜索路径更接近单调」仍是索引结构研究的核心命题。
- 近年趋势：图结构与量化（PQ/RaBitQ）融合以降低距离计算成本、磁盘/分布式图索引、以及带过滤（filtered ANNS）的搜索。本文的「概率保证」视角在今天更多以「beam search + 自适应预算」的形式出现。
- 本节为趋势性判断；具体 SOTA 与基准数字 🔧 查当年 ANN-Benchmarks 类评测。
