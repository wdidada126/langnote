## 一句话总结
大规模视觉定位（「这张照片是在哪儿拍的？」）长期依赖 SfM 建出来的 3D 点云。近年流行做法是两级走：先用「整图级别的全局描述子」召回少量候选图像，再在候选图像内部比对局部特征。但这意味着每张查询图都要算两种特征，代价不小，而「必须有全局描述子」几乎成了共识。本文退一步问：真的需要吗？ 提出 CANN（Constrained Approximate Nearest Neighbors），只用局部特征就能同时在几何空间和外观空间上联合求解 $k$ 近邻。实验显示它在公开定位基准上显著优于基于全局特征的 SOTA 检索方法与局部特征聚合方案，且建索引与查询都快一个数量级。

- 子方向解决什么大问题：视觉定位（visual localization）——给定一张查询图，确定它在 3D 世界中的拍摄位置与姿态。它是 AR、机器人、自动驾驶定位的核心能力。
- 为什么难：
  - 规模：3D 点云里可能有几百万到几千万个 3D 点，直接用查询图的局部特征去匹配，等于做一次超大规模的近邻搜索。
  - 两级方案的代价：先全局召回、再局部匹配的混合方案，要求对每张查询图同时计算两种特征（global + local），成本翻倍。

- 三个必懂的关键名词：
  1. 局部特征（local feature）：图像上关键点（角点等）的描述子，一张图有成百上千个。它比整图描述子更细粒度，是精确定位的关键。
  2. 外观空间（appearance space）：描述子向量所构成的空间——「看起来像不像」。
  3. 几何空间（geometry space）：3D 点的空间位置所构成的空间——「位置对不对得上」。CANN 的关键就是同时在这两个空间上求近邻，而不是分开做。

## 1. 问题背景与动机
- 前人工作简述：大规模视觉定位系统持续依赖由图像集合经 SfM（structure-from-motion）构建的 3D 点云。3D 点用局部图像特征表示。由于直接把查询图的局部特征与整个点云匹配，近邻搜索规模太大，近年大量工作转向混合方案：先用整图嵌入（global embedding）检索出少量数据库图像，再只在这些图像上做局部特征匹配。
- 前人缺陷 / 未解决问题（逐条）：
  1. 必须计算两种特征：混合方案要求对每张查询图像同时算全局与局部两类特征，这是一个显著的额外开销（significant downside）。
  2. 「全局描述子必不可少」是未经检验的共识：论文指出，这似乎已成为一种 common belief，但并没有被认真质疑过。
  3. 局部特征聚合方案慢：使用局部特征聚合（feature aggregation schemes）的路线，在建索引与查询上都很昂贵。
  4. 多度量检索缺乏理论基础：在多个度量（multiple metrics）上做 $k$ 近邻检索，此前缺少成体系的理论推导。
  5. 直接局部匹配规模过大：不做任何加速时，局部特征与点云的匹配代价不可接受。

## 2. 核心方法
- 最直观类比：找人有两种办法：一是先在全市的「户籍照片库」里按脸找出一批相似的人（全局召回），再逐个核对指纹（局部匹配）——但这意味着你既要拍脸又要采指纹。CANN 相当于只用指纹，并且同时核对「指纹纹路像不像」（外观空间）和「这人当时在不在现场」（几何空间）两条线索，一次查询把两件事一起办了。既然少采一种信息，自然更快。
- 具体做法（输入 → 关键操作 → 输出）：
  1. 输入：查询图像的局部特征（不使用任何全局/整图嵌入）+ 由 SfM 构建的 3D 点云（其 3D 点带有局部特征与几何位置）。
  2. 关键操作一：理论基础。作者首先推导了在多个度量（across multiple metrics）下进行 $k$ 近邻检索的理论基础——这是 CANN 能「同时跨几何与外观空间」求解的依据。
  3. 关键操作二：CANN 求解。基于上述理论，提出 Constrained Approximate Nearest Neighbors（CANN），作为跨几何空间与外观空间的联合（joint）$k$ 近邻求解方案，且只使用局部特征。
  4. 应用：把 CANN 用于视觉定位，替代原来的「全局召回」步骤。
  5. 输出：查询图在点云中的候选匹配（进而得到相机位姿）。
- 形式化要点：
  - 关键设计变量：两个空间（几何 / 外观）上的度量如何组合、约束如何施加、$k$ 的取值；🔧 具体算法与参数见原论文（含 ICCV camera-ready 与 appendix）。
  - 核心取舍是「去掉全局特征」——省掉一整类特征提取的开销。
- 理论性质 / 保证：论文明确先derive the theoretical foundation（推导理论基础）再给出方法，说明它有理论支撑；🔧 具体的近似比/复杂度结论需精读补充。

## 7. 2026 视角（🔧）
- 「全局召回 + 局部匹配」至今仍是视觉定位与图像检索的主流两级架构，但本文证明至少在定位任务上，这一步可以被更聪明的联合检索取代——这类「质疑共识组件是否必需」的工作在工程上价值很高。
- 更广义地看，本文属于「把多模态/多度量的约束直接编码进 ANNS」这一脉络；今天随着多模态检索（图文互检、视频检索）普及，这类跨空间联合检索的需求只会更多。
- 近年趋势：把几何先验与学习到的描述子更紧地结合、面向端侧的实时检索、以及用学习式索引替代传统 ANN 结构。本节含趋势判断，最新格局 🔧 需查当年文献。
