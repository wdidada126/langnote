## 一句话总结

近似最近邻搜索（AKNN）里最烧时间的不是建索引，而是「算距离」——此前最优的 ADSampling 用随机投影近似算距离，但精度有损失、且不够通用。本文改用基于数据分布的正交投影来估距离，再把「距离修正」拆成独立的数据驱动环节，在真实数据集上比 ADSampling 快 1.6～2.1 倍且精度更高。

## 0. 给新手的阅读前置（背景知识地图）

子方向解决什么大问题：在亿级高维向量里找 K 近邻（搜图、RAG、推荐都靠它），逐对精确算距离太慢，于是 ANN 索引（HNSW、IVF 等）只对少量候选算距离——但候选集内的距离计算仍是运行时大头。本文正攻这一环：怎么把「算一次距离」变便宜。

为什么难：
- 高维向量距离计算是 O(d) 的内存带宽密集操作，d 常见 128～960；
- 压缩向量（量化）能省带宽但引入精度损失；
- 「近似算距离」必须配「修正机制」才能保证最终结果仍接近精确 KNN。

几类主流解法（候选距离计算层面）：

| 路线 | 代表 | 直觉 |
|------|------|------|
| 量化压缩 | PQ/SQ 系列 | 把向量压成短码，用码本近似距离 |
| 提前终止 | FINGER 等 | 用部分维度算出「保真下界」，够了就停 |
| 随机投影近似 | ADSampling（SOTA） | 随机正交投影到低维逐维累积，用统计界判定何时可提前终止 |
| 数据分布感知投影 | 本文 | 不随机投影，改用贴合数据分布的正交投影 + 独立的数据驱动修正 |

本文属哪类：第 4 类——ADSampling 的直系改进，保持「逐维累积 + 提前终止」框架，换掉「随机」这一不适配数据的部件。

关键名词直觉解释：
- AKNN：Approximate K Nearest Neighbor，允许少量误差换大幅加速的 KNN 搜索；
- ADSampling：ICDE'24 的 SOTA 距离近似方法——随机正交投影把向量转到低维，逐维累加估计距离，一旦「下界已超过当前阈值」即可提前终止；
- 正交投影（orthogonal projection）：旋转变换保持距离不变，投影只丢维度不扭空间；「随机」的正交基对所有数据一视同仁，而数据的主成分方向却是有偏的——这是本文改进的物理直觉。

## 1. 问题背景与动机

- 前人工作：ANN 系统普遍用近似距离（量化/采样）降低距离计算开销；ADSampling（ICDE 2024）用随机投影 + 距离修正做到「近似但不牺牲太多精度」，成为候选距离计算的 SOTA。
- 前人的缺陷/未解决问题（本文逐条给出动机，摘要原文明示）：
  1. 有效性受限（effectiveness）：随机投影不利用数据分布，同样的维度预算下丢掉了本可保留的信息，近似精度打了折扣；
  2. 通用性受限（generality）：距离修正过程与「随机投影」这一近似机制耦合在一起，换成别的距离/别的近似手段时修正难以移植；
  3. 因此需要一个既更准、又与近似机制解耦的距离计算框架。

---

## 2. 核心方法

- 最直观类比：ADSampling 像是「随机抽 64 道题估学生总分」——抽题均匀但浪费；本文改成「按考试大纲（数据分布）抽最有区分度的 64 道题」，估计更准；而且把「估分怎么修正」从「怎么抽题」里拆出来，换一套抽题法也照样能修。
- 具体做法（输入 → 关键操作 → 输出）：
  - 输入：查询向量、候选向量（高维）、当前最远邻阈值；
  - 关键操作 1（正交投影近似）：对数据集做基于数据分布的投影变换（而非随机正交矩阵），使投影后低维子空间承载尽可能多的距离信息；查询与候选同样变换，逐维累积估计距离；
  - 关键操作 2（数据驱动的距离修正）：把修正过程从近似过程中解耦——修正参数/模型从数据中学得（离线数据驱动），独立于投影方式；这同时带来通用性：修正环节可适配不同近似机制与距离度量（🔧 学习的具体形式与所支持的距离类型查原文）；
  - 输出：近似但高保真的距离（供 AKNN 框架内候选排序/终止判定使用）。
- 形式化要点：与 ADSampling 共享「逐维累积 + 统计界提前终止」的骨架（🔧 精确的不等式与判定条件查原文），差异在投影矩阵的选取准则与修正项的来源。
- 理论性质：保留了提前终止的精度保证框架（🔧 保证的严格表述与条件查原文后补）。

## 4. 实验结论（概览）

- 对比基线：ADSampling（主基线，无 SIMD 情形）、FINGER（SIMD 情形对照）等候选距离计算方法。
- 数据集：真实世界高维数据集（README 指明 GIST、DEEP 等，源自 CUHK 提供的标准 ANN 数据集页）。
- 指标：给定精度要求下的查询吞吐/时间（QPS）、距离计算次数、召回率。
- 结论方向（摘要已明示）：相对 ADSampling，在真实数据集上获得 1.6～2.1 倍加速，同时精度更高——同时改善「快」与「准」，验证了分布感知投影 + 解耦修正两个改进点的有效性。
- 🔧 各数据集精确 QPS-召回曲线、距离计算节省比例查原论文实验章后补。

## 5. 开源代码与动手实践

- 仓库：https://github.com/mingyu-hkustgz/res-infer ，语言 C++（Eigen、Boost、OpenMP 依赖）+ Python 实验脚本（numpy、faiss、scikit-learn 等）。
- 典型流程（教学示意，以 README 为准 🔧）：
  1. 准备数据集（GIST/DEEP 有自带学习数据；其他数据集用 `data/data_split.py` 从 base 切分学习集）；
  2. `python data/compute_gt.py` 计算学习查询的 ground truth；
  3. 在 `set.sh` 中设置存储路径与数据集名，`bash run.sh` 跑实验；
  4. CMakeLists 中选择编译开关：SIMD 版用 `-march=core-avx2 -mavx512f` 等，无 SIMD 版用 `-std=c++17 -O3`（分别对应 `search_ivf_512`/`search_hnsw_512` 与普通目标）。
- 许可与资源提醒：FINGER 基线在仓库内为参考实现（作者注明应以 FINGER 原仓库为准）；数据集从 CUHK GQR 页面下载，体积较大；许可证 🔧 待确认；仓库主分支为 `nolearn`（即无需在线学习数据的推理版），内有 technical_report.pdf 可直接参考。

## 7. 2026 视角（🔧）

- 距离计算加速是向量数据库（Milvus、Faiss、Weaviate 等）内核层的军备竞赛：量化（PQ/SQ/RaBitQ 系）与提前终止两条线持续融合，本文代表的「分布感知 + 数据驱动修正」是 2024-2025 年该轴上的代表作之一；
- ADSampling 及其后继这类方法的价值在于可插拔——不换索引、不动架构，只在距离计算层替换即可白拿加速，因此落地阻力小；
- 趋势上，「学习型/数据驱动的运行时优化」（learned index、learned filtering、数据驱动修正）正在从查询优化器蔓延到向量检索的每一层，本文是这一趋势在距离计算层的例证。
