## 一句话总结

数据湖里躺着成千上万张没人管表，某张"源表"丢了或不完整时，Gen-T 能从湖里自动找出一组表、拼起来尽可能"还原"它——并告诉你还原失败是因为"值不一样"还是"数据本来就缺"。

## 0. 给新手的阅读前置（背景知识地图）

**子方向解决什么大问题？** 数据湖 = 企事业单位里堆满未经治理的表（文件）的存储层。 Tables 会丢失、被删、或只留下残片；而湖里往往散落着同一实体的多份拷贝。**表回收（table reclamation）** 问的是：给定一张源表（Source Table），能否从湖里找到一组表，整合后尽可能还原它。

**为什么难？**
- 湖里没有 schema 约束：同列不同名、同值不同写法、类型混乱。
- 候选表可能"部分对部分错"：有些列能对上、有些行缺失。
- 搜索空间巨大：不只是"找相似表"，还要决定"怎么组合"（union? join? outer join?）。

**与相近问题的区别（摘要明确强调）：**

| 问题 | 目标 | 与本文区别 |
|------|------|-----------|
| Query-by-Example / Query-by-Target | 找一个查询来"解释"目标 | 关注查询可表达性，不强调还原真实数据 |
| Table Union Search | 判断哪些表可以 union | 只做"找表"，不做整合还原 |
| **Table Reclamation（本文）** | 用可能不完整/不一致的真实表尽可能完整地**回收数据** | 新问题定义 |

**本文属于哪一类？** 数据发现 + 数据集成的端到端系统，核心新度量是 **error-aware instance similarity**（错误感知的实例相似性，基础是数据交换领域的 instance similarity）。

**关键名词直觉解释：**
- **Source Table（源表）**：要被还原的目标表——可能是历史快照、丢失表的部分残片。
- **origin tables（起源表）**：候选中真正"贡献内容"的表；Gen-T 先过滤出它们再整合。
- **SPJ / UNION / OUTERJOIN / 包含与补**：搜索空间覆盖的算子族——选择-投影-连接、并、外连接，以及"列包含/补集"这类一元算子（摘要核实）。

## 1. 问题背景与动机

- **前人工作简述**：数据湖表发现（dataset discovery）、表 union 搜索（本仓库 `Dataset Discovery in Data Lakes__2011.10427`、`Pylon- Semantic Table Union Search in Data Lakes__2301.04901` 等）已能"找相似表"；QBE/QBT 类查询发现问题已有大量工作。
- **前人缺陷 / 未解决问题（逐条）**：
  1. **只找表、不整合**：union 搜索类工作停在"找到候选"，没有把候选表真正整合回一张可用表。
  2. **假设数据干净完整**：既有集成方法难以处理"候选表本身不完整或不一致"的真实湖况（摘要明述这是与 QBE/QBT 的关键区别）。
  3. **算子覆盖不足**：此前搜索空间多限于 SPJ 或简单 union，缺 UNION、OUTERJOIN、一元"包含与补"算子的组合。
  4. **失败原因不可解释**：还原不出来时，说不清是"值冲突"还是"数据缺失"。

## 2. 核心方法

**最直观类比**：考古复原。一块陶罐碎片（源表）丢了，你在仓库（数据湖）里翻箱倒柜，找出各家博物馆的同类碎片（候选表），先鉴定哪些碎片真的出自这个罐（过滤出 origin tables），再拼装成尽可能完整的罐子（整合还原）；拼不上的地方还能判断：是碎片磨损了（值不一致）还是当年就没挖到（数据不完整）。

**具体做法（输入 → 关键操作 → 输出）**（摘要核实）：
- **输入**：一张 Source Table + 一个大型表仓库（数据湖）。
- **关键操作（三段式流水线）**：
  1. **表发现（table discovery）**：扫描湖，用 error-aware instance similarity（基于数据交换的 instance similarity，能容忍错误）找候选表；
  2. **过滤起源表**：从候选中甄别真正贡献内容的 origin tables；
  3. **整合还原**：用覆盖 UNION、OUTERJOIN、包含/补等算子的集成查询把起源表拼起来，最大化对源表的还原。
- **输出**：还原出的表 + 对还原失败原因的区分（值差异 vs 数据不完整）。

**形式化要点 / 理论性质**：新问题形式化 + 新相似性度量定义（🔧 度量公式与复杂度查原论文后补）。
