## 一句话总结
图索引（HNSW/DiskANN/NSG）检索时「搜到什么时候停」通常靠固定的束宽（beam width）拍脑袋决定；这篇论文提出**基于距离的终止条件**（Adaptive Beam Search），并证明：只要图是「可导航的（navigable）」，该算法**保证**近似解出最近邻问题——理论保证 + 实测全面更优，还能直接套用到现有流行图索引上。

## 0. 给新手的阅读前置（背景知识地图）
- **大问题**：高维数据上精确最近邻代价爆炸，工业界主流用**图索引**：把数据点连成一张有向邻居图，查询时从某入口出发贪心走向越来越近的节点。HNSW（内存）、DiskANN/Vamana（磁盘）、NSG 是三大代表。
- **为什么难**：图搜索本质是启发式——搜太久慢，搜太早停就漏掉真邻居；传统束搜索用「候选队列大小 = beam width」控制停止，这个参数与数据、图结构、目标召回全无理论关联，调参靠经验。
- **主流解法分类（直觉）**：
  | 类别 | 思路 | 代表 |
  |------|------|------|
  | 实用工程改进 | 更好的图构建、剪枝、量化 | NSG、HNSW、DiskANN |
  | 理论刻画 | 对特定图类证明搜索可达性/复杂度 | degeneracy order 等理论工作 🔧 |
  | **本文** | 换终止条件：距离自适应束搜索 + 可导航性下的正确性证明 | 本文 |
- **关键名词直觉**：
  - *束搜索（beam search）*：维护 top-beam 个候选，逐轮扩展邻居；beam 越大越准越慢。
  - *终止条件*：决定「何时不再扩展」的规则——本文用「当前最好距离不再被显著改进」替代「队列满了就停」。
  - *可导航图（navigable graph）*：图上存在「每一步都能局部变近」的路径性质；本文证明它是准确搜索的关键充分条件。

## 1. 问题背景与动机
- **前人工作**：HNSW、DiskANN、NSG 等图方法凭经验准确率与效率成为高维检索主流；理论侧已有不少对图方法的理解性工作（摘要称 significant work focused on practical refinements and theoretical understanding），但摘要明言——**many questions remain**。
- **前人缺陷（逐条）**：
  1. 束搜索终止条件基于**束宽**，是纯经验参数，与「是否已接近真邻居」无因果关系；
  2. 实用图方法（HNSW/Vamana）**缺乏搜索准确性的理论保证**；
  3. 理论结论与实际使用的图结构之间长期缺乏桥梁（本文补上「可导航性 ↔ 搜索性能」这一连接）。

## 2. 核心方法
- **最直观类比**：黑夜里找山顶。传统办法是「带固定人数的搜索队，人数用完就收工」；本文改成「连续走了若干步都没有人比当前位置更高，就收工」——离山顶越近，越容易判断「再走也白走」，所以终止时机是**距离自适应**的。
- **输入→关键操作→输出**：
  - 输入：图索引 G、查询点 q、近似参数；
  - 关键操作：把束搜索的终止判据从「beam width 满」改为**基于当前查询-节点距离的改进幅度**（distance-based termination condition）；每轮从候选中扩展，当最优距离不再被充分改进时停止；
  - 输出：q 的（近似）最近邻。
- **形式化要点**：
  - **定理（经摘要核实）**：只要搜索图是 navigable 的，Adaptive Beam Search **保证近似求解**最近邻问题；
  - 由此建立「可导航性 ↔ 图搜索性能」的理论联系。
- **理论性质/保证**：如上——可导航图上的近似正确性保证；对实际非严格可导航图（HNSW、Vamana 的近似版本）给实证支持。

## 3. 变体 / 工程版（如有）
- 方法本身是一个**即插即用的终止条件**，可直接替换 HNSW / Vamana 等系统中的标准束搜索（摘要称 simple and practical way to improve popular methods）；工程集成细节 🔧 查原论文。

## 4. 实验结论（概览）
- **设置**：在 navigable 图与实践中近似 navigable 的图（**HNSW、Vamana**）上，跨多个数据集、多种图构建、多个目标 k（target number of nearest neighbors）做大量实验（摘要核实）。
- **指标**：recall 意义下的搜索质量/效率权衡 🔧（精确 QPS-recall 数字查原论文后补）。
- **结论方向**：Adaptive Beam Search 在**一系列 recall 值、数据集、图构建与 k** 上都优于标准束搜索。
