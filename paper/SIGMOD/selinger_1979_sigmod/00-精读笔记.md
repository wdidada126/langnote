# Access Path Selection in a Relational Database Management System (Selinger) — 精读笔记

> SIGMOD 1979 · Selinger, Astrahan, Chamberlin, Lorie, Price（IBM Research，System R 血统）
> 三态标注：✅ 论文硬写事实 / ⚠️ 记忆或二手归纳 / 🔧 本地可复演实验

## 一、基本信息

| 项 | 内容 |
|---|---|
| 会议 | SIGMOD 1979（Proceedings of 1979 ACM SIGMOD international conference） |
| 定位 | **Cost-based 查询优化**的奠基文：动态规划枚举连接序 + 统计信息驱动的选择率/代价模型 |
| 血统 | System R / RSX→SEQUEL 时代产物；"Selinger 优化器"成为 PostgreSQL 至今的代称（✅） |

## 二、问题史：规则优化为什么不够

- 1970s 早期：查询处理路径靠**规则**（heuristic，如"先做选择"）与人工指定（QUEL/HQUEUE 的存留集思想）；多连接查询的物理计划随索引/数据量变化，规则排不定（✅ 动机）。
- 前情：Selinger 本人的 A System R 论文（1981 ⚠️ 未建）与 Chamberlin 1974 SEQUEL/HQUEUE 提供原型；本文专注"路径选择"一题（⚠️ 谱系）。
- 关键立问：**能否用价格（代价）在指数级计划空间中自动择优？**——答案是分层 DP+interest 列表剪枝（✅）。

## 三、优化框架

### 3.1 三层代价输入

1. **目录统计**：每（关系×存取路径）一个目录条目：页数、元组数、键值分布（直方图/区间）、索引层级与键宽度（✅ 论文 §3 清单）。
2. **选择率估计**：谓词按等值/区间两类公式估基数；组合谓词假设独立性（✅ 论文自承该假设 ⚠️ 原罪）。
3. **代价模型**：以"页访问次数+CPU 常数"为单位；排序计 pass 数公式；连接分 nested-loop（按页）、索引连接、归并连接三类比价（✅）。

### 3.2 动态规划枚举（interest list）

- 自底向上：先为单关系选最优存取路径；逐步扩展"子集→超集"，每个子集只保留**有序 interest 列表**（对排序/分布等"期望输出属性"各留最优，默认只留"任意序"一条 ⚠️ 细节）——指数空间剪成可控（✅ 招牌）。
- 关键约束：只处理**左深树**（默认序），交换律/结合律按 DP 序展开；右深/十字形不探索（✅——这条边界是后来 Genki/COO 诸攻击点）。

### 3.3 查询树改写

- 谓词下推、选择合并、投影消除等启发式在 DP 前统一完成（✅ 预处理）。

## 四、评测（✅ 定性）

- 论文以真实库存/订单库为例：计划枚举耗时秒级、统计采集开销与查询收益可平衡；作者强调统计过期是主要误差源（✅ 结论方向）。
- 无现代基准（TPC 尚不存在），对比对象是手工指定路径的工程师（✅ 时代注脚）。

## 五、批判读法

- **独立性假设**是六十年之债：相关性数据上选择率指数级错估，导致错误连接序——直方图、采样、多列统计、学习估基数全在还它（⚠️）。
- 左深树偏置：星型查询里"先大事实×维"的 bushy 更优时代被 System R 错过，DPx/Impromptu 系 1990s 才补（⚠️）。
- 统计模型与优化器耦合：每加一种算子都要手写选择率公式——可扩展性差，Calcite/Cascades 规则化是反面答案（⚠️ 对照 [[orca_1994_sigmod]]）。
- 代价公式为 1979 磁盘机调参（1 页 ≈ 数万次 CPU 指令的假设早已翻转）；内存/列存/SSD 时代常数项全部重排（✅ 判断）。

## 六、🔧 本地微实验（非本书引擎行为）

1. **手搓 DP 枚举**：4 表连接，写"子集→最优左深计划"动态规划（代价=行数×系数），对比枚举全排列的节点数。
2. **独立性之罪**：造 10 万行相关列数据（city↔zip），用独立假设估 `A∧B` 选择率，量化偏差并观察 DP 选错连接序。
3. **直方图选择率**：等高 vs 等宽直方图估区间谓词，对比真值。
4. **左深 vs 十字**：星型查询手工比价两种树形的中间结果总量。
5. **排序代价公式**：实现论文多趟外排 pass 数公式，用 DuckDB/SQLite 实测排序时间粗标定。

## 九、最新演进与工业实践

- PostgreSQL planner 仍是活的 Selinger 直系（统计=MCV+直方图，DP=interest 序）；MySQL 长期"贪心+代价简化"成为对比教材（✅）。
- 学习式优化（Bao/Lero/Neo，库内多篇已建档 ⚠️ 检索 Lero/Balsa 目录）不改 DP 骨架、只换"引导/打分"——Selinger 框架 45 年后仍是底座（✅ 判断）。
- 湖仓优化器（Iceberg 统计+N2L）把选择率问题升维到"开放格式元数据可信度"，独立性假设之债依旧（⚠️）。
- 2024–2026：LLM 辅助统计解释/调参兴起，但代价模型核心公式仍出自本文谱系（⚠️ 判断）。
