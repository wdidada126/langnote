## 一句话总结
把「集合相似搜索」重新形式化为一个已知集合大小、可在查询集与存储集之间「非对称」利用信息的问题，并用「布尔超多数函数（supermajority）+ 多份 polylog 拷贝」给出哈希方案，在时间和空间上相对 MinHash/SimHash 等前辈拿到 n^0.14 倍提升，且在随机设定下被证明是最优的（还顺带给出新的超收缩界）。

## 0. 给新手的阅读前置（背景知识地图）
- **子方向解决什么大问题**：集合相似搜索（Set Similarity Search）要判断「两个集合有多像」，典型度量有 Jaccard、Containment、重叠度等，广泛用于去重、Near-Duplicate 检测、推荐。本文把它推广成一个更一般的问题，并追求**理论最优**。
- **为什么难**：
  - 集合巨大且高维稀疏，暴力两两比较不可行；
  - 不同相似度量（Jaccard / 子集 / MIPS / 部分匹配）各有难处；
  - 想同时压低「查询时间」与「空间占用」很难，且需要可证明的下界。
- **几类主流解法**：

| 方法 | 代表 | 思路 | 优缺点 |
|------|------|------|--------|
| 局部敏感哈希 (LSH) | MinHash（Jaccard）、SimHash | 用哈希把相似集合映射到同桶 | 成熟，但本文证明其非最优 |
| 球面 LSF / Chosen Path | Spherical LSF、Chosen Path | 几何化后做空间划分 | 前辈方案，本文在随机设定下超越 |
| 本文：超多数哈希 | Supermajorities | 利用集合与其补集的非对称信息 | 随机设定下时间/空间双优 |

- **本文属于哪一类**：哈希（LSH 族）路线，但是**带最优性证明**的理论突破。
- **2-3 个必懂关键名词**：
  - **Jaccard / Set Similarity**：两集合交集/并集，衡量相似度。
  - **LSH（局部敏感哈希）**：相似的输入大概率落入同一哈希桶，用于近似检索。
  - **supermajority（超多数函数）**：一种布尔函数，用来把「集合本身」与「补集」的信息都利用起来做判定。

## 1. 问题背景与动机
- **前人工作简述**：集合与欧氏相似搜索已有 MinHash、SimHash、Spherical LSF、Chosen Path 等哈希方案，各自在某些设定下较优。
- **前人缺陷/未解决问题（逐条）**：
  1. **未充分利用集合信息**：前人没有同时最优地利用「集合本身」与「补集（complements）」的信息，且在查询集与存储集之间对称处理，浪费了可做非对称优化的空间。
  2. **缺最优性保证**：现有方案多为启发式/亚优，缺在随机设定下的严格下界。
  3. **统一框架缺失**：子集搜索、MIPS、Jaccard、部分匹配等被当作不同问题，缺统一最优解。

## 2. 核心方法
- **最直观类比**：查「相似集合」像在两个大篮子里找重合多的。前人只看「篮子里有什么」；本文同时看「篮子里有什么」和「没装什么（补集）」，并且让「查询篮」和「库存篮」用不同方式配合，从而更省地锁定目标。
- **具体做法（输入 → 关键操作 → 输出）**：
  1. **输入**：已知大小的数据库集合与查询集合（假设大小预先可知，这是广义问题的前提）。
  2. **关键操作一：广义问题建模**。把近似集合相似搜索统一成一个对称问题，涵盖近似子集搜索、MIPS、Jaccard、部分匹配。
  3. **关键操作二：polylog 拷贝**。通过对数据结构做 polylog 份拷贝，最优地求解上述任意对称问题。
  4. **关键操作三：非对称利用信息**。概念上不同于前人，最优地利用集合与其补集的信息，并在查询集与存储集之间**非对称（asymmetric）**处理。
  5. **关键操作四：把几何概念落地为算法**。将基于布尔超多数函数的几何概念，转化为实际算法，需要用到 **Z² 上的分支随机游走（branching random walks）**，论文给出首个非渐近（non-asymptotic）近紧分析。
  6. **输出**：在随机设定下时间/空间最优的集合相似搜索方案；并附**新的超收缩（hypercontractive）下界**论证最优性（通过对有向噪声算子 T 的新界）。
- **形式化要点**：核心是「已知集合大小 + 非对称利用补集 + 超多数函数 + polylog 拷贝」；超参含拷贝份数等（🔧 具体参数请查正文）。
- **理论性质/保证**：本文的**核心卖点就是理论最优性**——在随机设定下对所有基于哈希的结构最优，并通过归约对 1-cell / 2-cell probe 结构也成立。🔧 定理精确陈述与常数因子以论文原文为准。

## 4. 实验结论（概览）
- 注意：本文以**理论贡献（算法 + 下界）**为主，实验部分体现为与 MinHash/SimHash/Spherical LSF/Chosen Path 的**复杂度对比**而非传统基准跑分。
- **对比基线**：MinHash [J. Discrete Algorithms 1998]、SimHash [STOC 2002]、Spherical LSF [SODA 2016/2017]、Chosen Path [STOC 2017]。
- **评价指标**：查询时间 (time) 与空间占用 (space) 的渐近/近紧界。
- **结论方向（摘要给出的已核实结论，可直接引用）**：
  - 相比前述最佳工作，在时间**与**空间上均提升 **n^0.14 倍**；
  - 或在近常数时间 regime 下，于空间上获得**任意大的多项式倍**提升；
  - 给出的**下界**证明该最优性（随机设定下的哈希结构，及 1/2-cell probe 归约）。
- 🔧 具体常数、不同相似度量下的逐项对比，请查原论文。
