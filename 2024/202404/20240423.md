下面是一个简单的 ioctl 使用示例，这个示例用于读取 Linux 系统中终端设备的属性。请注意，这个示例不需要 sudo 权限，因为它只是读取设备的属性，而不是修改它们。

c
#include <stdio.h>  
#include <stdlib.h>  
#include <unistd.h>  
#include <fcntl.h>  
#include <termios.h>  
#include <linux/kd.h>  
#include <sys/ioctl.h>  
  
int main() {  
    int fd;  
    struct termios tty;  
  
    // 打开终端文件描述符  
    fd = open("/dev/tty", O_RDWR | O_NOCTTY);  
    if (fd == -1) {  
        perror("open");  
        exit(EXIT_FAILURE);  
    }  
  
    // 获取当前终端属性  
    if (tcgetattr(fd, &tty) != 0) {  
        perror("tcgetattr");  
        exit(EXIT_FAILURE);  
    }  
  
    // 使用 ioctl 读取终端的键盘模式  
    int kmode;  
    if (ioctl(fd, KDGKBMODE, &kmode) == -1) {  
        perror("ioctl KDGKBMODE");  
        exit(EXIT_FAILURE);  
    }  
  
    printf("Current keyboard mode: %d\n", kmode);  
  
    // 关闭文件描述符  
    close(fd);  
  
    return 0;  
}
在这个例子中，我们打开了 /dev/tty 设备（这通常指的是当前进程的控制终端），然后使用 tcgetattr 函数获取了终端的属性。接着，我们使用 ioctl 调用和 KDGKBMODE 命令来获取键盘模式。最后，我们打印出获取到的键盘模式并关闭文件描述符。

请注意，这个示例中的 ioctl 调用是用于读取信息的，因此不需要 sudo 权限。如果你尝试执行需要写权限的 ioctl 操作（例如更改设备配置），则可能需要 sudo 权限，具体取决于设备的权限设置和系统的安全策略。

在编译和运行这个程序时，确保你有足够的权限来打开 /dev/tty 设备。通常，普通用户就可以打开和控制自己的终端。如果你尝试打开其他用户的终端或系统级设备，则可能需要 sudo 权限。


在 C/C++ 中，ioctl 系统调用通常需要 sudo 权限的情况通常出现在你需要对系统级设备或者需要更高权限才能访问的设备进行操作时。例如，修改网络接口配置、访问某些硬件资源等。

下面是一个简单的 C 语言示例，它使用 ioctl 来获取网络接口的状态，并需要 sudo 权限来执行，因为直接访问网络接口通常需要管理员权限。

c
#include <stdio.h>  
#include <stdlib.h>  
#include <string.h>  
#include <unistd.h>  
#include <sys/socket.h>  
#include <sys/ioctl.h>  
#include <net/if.h>  
#include <arpa/inet.h>  
  
int main() {  
    int fd;  
    struct ifreq ifr;  
    char *iface = "eth0"; // 假设我们想要查询的是 eth0 接口  
  
    // 创建一个 socket 文件描述符  
    fd = socket(AF_INET, SOCK_DGRAM, 0);  
    if (fd < 0) {  
        perror("socket");  
        exit(EXIT_FAILURE);  
    }  
  
    // 清除 ifreq 结构体  
    memset(&ifr, 0, sizeof(ifr));  
  
    // 设置 ifreq 结构体中的 ifname 字段为我们想要查询的接口名  
    strncpy(ifr.ifr_name, iface, IFNAMSIZ-1);  
  
    // 使用 ioctl 调用 SIOCGIFADDR 来获取接口的地址  
    if (ioctl(fd, SIOCGIFADDR, &ifr) < 0) {  
        perror("ioctl SIOCGIFADDR");  
        close(fd);  
        exit(EXIT_FAILURE);  
    }  
  
    // 输出接口的地址  
    struct sockaddr_in *addr = (struct sockaddr_in *)&ifr.ifr_addr;  
    char ip[INET_ADDRSTRLEN];  
    inet_ntop(AF_INET, &addr->sin_addr, ip, INET_ADDRSTRLEN);  
    printf("Interface %s has IP address: %s\n", iface, ip);  
  
    // 关闭 socket 文件描述符  
    close(fd);  
  
    return 0;  
}

在这个例子中，我们首先创建了一个 socket 文件描述符，然后设置了一个 ifreq 结构体来包含我们想要查询的接口名称。我们使用 ioctl 调用和 SIOCGIFADDR 命令来获取接口的地址，并将其转换为人类可读的格式。

由于这个操作涉及到直接访问网络接口，因此通常需要 sudo 权限。如果你没有这些权限，ioctl 调用将失败，并返回 Permission denied 错误。

请注意，eth0 只是一个示例接口名，你的系统上可能没有这个接口，或者它可能叫其他名字（如 wlan0 对于无线接口）。你需要替换为你系统上实际存在的接口名。

ssize_t writev(int fd, const struct iovec *iov, int iovcnt); 是 Unix 和类 Unix 系统（如 Linux）中的一个系统调用，用于从多个不连续的内存缓冲区中写入数据到一个文件描述符（fd）。

这个函数的参数解释如下：
int fd：这是你想要写入的文件描述符。它可以是一个普通的文件、套接字、管道等。
const struct iovec *iov：这是一个指向 iovec 结构体数组的指针，每个 iovec 结构体都描述了一个内存缓冲区。
int iovcnt：这是 iov 指向的 iovec 结构体数组中的元素数量。
iovec 结构体通常定义如下：

```c
struct iovec {  
    void  *iov_base;    /* 缓冲区的起始地址 */  
    size_t iov_len;     /* 缓冲区的大小 */  
};
```
writev()函数会尝试将iov指向的每个iovec结构体描述的缓冲区中的数据写入到fd` 指定的文件描述符中。返回的值是实际写入的字节数，如果出现错误则返回 -1。
使用 writev() 的一个主要优点是它可以减少系统调用的次数，从而提高性能。当你需要从多个不连续的缓冲区中写入数据时，你可以使用 writev() 而不是多次调用 write()。这样可以减少系统调用的开销，因为每次系统调用都涉及到从用户空间到内核空间的上下文切换。
需要注意的是，writev() 不保证原子性，也就是说，在写入过程中可能会被其他进程或线程打断。因此，如果你需要原子性的写入操作，你可能需要使用其他机制（如文件锁）来确保数据的完整性。
