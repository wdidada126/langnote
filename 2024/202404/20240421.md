# 一、这是什么项目？
SYsU-lang = 中山大学编译原理课的大实验
- 一个精简版 C 语言编译器（类似 SysY）
- 基于 LLVM + Flex/Bison 实现
- 分 3～4 个实验：词法分析 → 语法分析 → 生成 AST/ASG → 输出 LLVM IR

# 二、核心知识点（面试/实验必背）
## 1. 语法树 vs AST vs ASG
- 语法解析树 Parse Tree：保留所有文法符号，非常臃肿
- 抽象语法树 AST：去掉无用符号，结构简洁
- 抽象语义图 ASG：加入语义信息、符号引用、指针关联，编译器真正使用的结构

结论：AST 远简单于语法树，ASG 更适合做语义分析与代码生成。

---

## 2. 实验架构（官方标准）
```
源代码 → 词法分析(Flex) → 语法分析(Bison) → 生成 ASG → 输出 JSON → 生成 LLVM IR
```

核心设计：
- ASG（抽象语义图） 是整个实验的灵魂
- 使用 Visitor 模式 遍历 ASG（输出 JSON / 生成 IR）
- 统一内存管理：`Mgr` 管理器管理所有对象，避免内存泄漏

## 3. Flex + Bison 用法（实验必考）
- `.l` 文件：词法规则
- `.y` 文件：语法规则
- `%union`：定义语义值类型（存放 int、指针等）
- `yyparse()`：入口
- `yylex()`：词法分析供给词法单元

# 四、你提到的 Boost.Spirit 是什么？
一个C++ 模板元编程实现的递归下降解析器，不用生成代码，直接在 C++ 里写文法。
- 优点：极强、极灵活
- 缺点：模板错误极难读、编译极慢  
所以中山大学实验不用它，而用更友好的 Flex/Bison。
