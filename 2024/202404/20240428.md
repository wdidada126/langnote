# MAT（Eclipse Memory Analyzer）完整功能列表
严格对照你提供的《JVM内存分析工具MAT的深度讲解与实践——进阶篇》原文整理，可直接用于面试、文档、学习。

## 一、全局概览与内存分布
1. Heap Dump Overview（堆概览）
   - 显示堆总大小、对象数、类数量、类加载器数量、GC Root 数量
   - 显示线程概况、环境、VM 信息
   - 用于快速判断：类加载器泄漏、类数量暴涨、线程异常

2. Dominator Tree（支配树）⭐⭐⭐⭐⭐
   - 按 Retained Heap 从大到小排序
   - 展示对象支配关系：谁回收就能释放一大片内存
   - 支持按 class/package/classloader 分组
   - 定位：大对象、线程持有的内存、泄漏根对象

3. Histogram（直方图）⭐⭐⭐⭐⭐
   - 按类统计：对象个数、Shallow Heap、Retained Heap
   - 支持正则过滤、分组、排序
   - 用于：哪类对象太多、哪类占用内存最大
   - 可计算精确 Retained Heap

4. Leak Suspects（泄漏嫌疑人）⭐⭐⭐⭐
   - 自动分析内存泄漏，给出可疑点与占用比例
   - 显示引用链、堆栈、问题描述
   - 开箱即用，快速定位明显泄漏

5. Top Consumers（最大消耗者）
   - 展示占用内存最高的类、包、类加载器
   - 按占比饼图/表格呈现

## 二、对象间依赖分析
6. Outgoing References（外出引用）
   - 查看对象引用了谁
   - 用于：大对象内部到底持有什么

7. Incoming References（被谁引用）
   - 查看对象被谁引用
   - 用于：谁在引用它导致无法 GC

8. Path to GC Roots（到 GC 根的路径）⭐⭐⭐⭐⭐
   - 列出对象到 GC Root 的最短强引用链
   - 可排除软/弱/虚引用，只看强引用
   - 定位：为什么这个对象无法被回收

9. Merge Shortest Paths to GC Roots
   - 合并多个对象到 GC Root 的公共路径
   - 批量分析泄漏点

10. Thread Overview（线程概览）⭐⭐⭐⭐
   - 显示所有线程、栈帧、堆栈信息
   - 显示线程的 Retained Heap、是否守护线程
   - 可直接看线程栈，定位：线程阻塞、线程泄漏、线程持大内存

11. Immediate Dominators（直接支配者）
   - 查看对象的直接上级支配者
   - 快速定位谁“控制”该对象

## 三、对象状态详情
12. Inspector（对象检查器）⭐⭐⭐
   - 查看对象所有字段值、类型、地址、继承结构
   - 查看静态变量、ClassLoader、GC Root 信息
   - 用于业务分析：集合大小、内容是否异常

13. Java Collections 集合分析工具⭐⭐⭐⭐
    - Collection Fill Ratio：集合填充率（空 List/Map 浪费内存）
    - Array Fill Ratio：数组填充率
    - Map Collision Ratio：HashMap 冲突率
    - Extract Hash Set/List Values：抽取集合内容
    - 定位：空集合、低填充率、Hash 冲突导致内存暴涨

14. Show Retained Set（显示被支配集合）
    - 展示该对象回收能释放的所有对象集合

## 四、按条件检索与高级功能
15. OQL（对象查询语言）⭐⭐⭐⭐
    - 类 SQL 查询堆内对象
    - 例：查找空 ArrayList
      ```sql
      SELECT * FROM java.util.ArrayList WHERE size=0 AND modCount=0
      ```
    - 支持正则、where 条件、统计

16. Class Loader Explorer（类加载器分析）
    - 查看所有类加载器实例、加载的类
    - 定位：类加载器泄漏、反复创建 ClassLoader

17. Duplicated Classes（重复类检测）
    - 查找被重复加载的类
    - 解决：版本冲突、NoClassDefFoundError、类重复装载

18. Find Strings（字符串搜索）
    - 搜索堆内所有字符串，用于定位业务关键词、缓存内容

19. 按地址查找对象
    - 输入内存地址直接定位对象

## 五、导出与工具
20. 导出为 CSV、HTML、TXT
21. 对比多个堆 Dump
22. 自动报表生成
