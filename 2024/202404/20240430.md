# 结论先行
**MAT 完全可以查询某个类的所有实例对象**，而且有 **3 种常用方式**，从简单到高级，直接能用。

## 方式一：Histogram 直方图（最常用、最快）
1. 打开 Heap Dump → 进入 **Histogram**
2. 在顶部搜索框输入**完整类名/简单类名**
3. 找到目标类，右键：
   - **List objects → With incoming references**
4. 直接列出**该类所有实例**，每个实例都能点开看字段、引用、内存地址。

适用：快速看某类到底创建了多少个实例、每个实例详情。

## 方式二：OQL 对象查询语言（精准筛选，最强）
MAT 顶部菜单栏 → **Query → Object Query Language**

### 查某个类全部实例
```oql
SELECT * FROM com.xxx.User
```

### 加条件过滤
```oql
SELECT * FROM com.xxx.User WHERE id > 1000
```
执行后直接列出所有实例，可逐个查看对象结构、字段值、引用链。

## 方式三：通过 Class 实体直接展开
1. 在 Histogram 找到目标类
2. 点开类前面小三角，直接展开**所有实例对象**
3. 选中任意实例，可看：
   - Shallow/Retained 大小
   - 所有成员变量值
   - 被谁引用（Path to GC Roots）

---

# 额外实用能力
1. 可以统计**实例总个数、总占用内存**
2. 可以筛选**活着的实例**（排除已可回收）
3. 可以导出所有实例为文本/CSV
4. 可以看每个实例**引用了哪些其他对象**、**被谁引用**

---

# 一句话总结
MAT 原生支持**按类查全部实例**，日常排查优先用：
**Histogram 搜索类 → List objects 列出所有实例**
复杂条件筛选用 **OQL**。
