要在CLion中调试带有.so库依赖的C++代码，并关联.so库的源代码，你可以按照以下步骤操作：
配置CMake项目：
确保你的项目是使用CMake构建的。CLion能够很好地支持CMake项目，并且可以自动配置调试。
设置调试配置：
在CLion中，转到Run -> Edit Configurations。
选择你的目标配置。
在Debugger部分，确保Use Clang++ debugger选项被选中。
配置符号路径：
在调试配置中，你需要确保符号（也就是.so库和可执行文件的调试信息）的路径被正确设置。
在Debugger部分，查找Symbol file (.dll/.so) paths设置。
添加你的.so库和任何其他相关依赖的路径。
源代码路径：
如果你的.so库的源代码不在默认的源代码路径中，你需要添加这些路径。
在调试配置中，转到Debugger -> GDB -> Search directories。
添加你的源代码路径。
在.so库的源代码上设置断点：
一旦你设置了符号和源代码路径，你可以在CLion中直接在.so库的源代码上设置断点。打开相应的文件并点击行号旁边的空白区域来设置断点。
开始调试：
现在，你可以像平常一样开始调试你的程序。当程序执行到你在.so库中设置的断点时，它应该会停下来，允许你在那里检查和步进代码。
注意事项：
确保你的.so库是使用与你的应用程序相同的编译器和版本构建的，以便调试器能够正确解析符号信息。
如果你使用的是动态链接库（例如在Linux上的.so文件），请确保它们在运行时与调试版本匹配。这通常意味着你需要使用与调试版本相同的构建配置重新构建这些库。
如果你的项目很大或使用了复杂的构建系统，可能需要更多的配置和调整。
