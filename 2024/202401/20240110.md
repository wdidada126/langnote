# 一、谷歌 C++ 规范 最核心必守点（你面试/开发都用得到）
## 1. 头文件保护（你问的这个）
- 必须用 #include 守卫宏，格式：
  ```
  <PROJECT>_<PATH>_<FILE>_H_
  ```
- 禁止用 `#pragma once`（谷歌规范明确不推荐）
- 示例：
  ```cpp
  #ifndef MY_PROJECT_SRC_UTILS_LOG_H_
  #define MY_PROJECT_SRC_UTILS_LOG_H_
  ...
  #endif // MY_PROJECT_SRC_UTILS_LOG_H_
  ```

## 2. 命名规范（谷歌最严、最标志性）
### ① 文件名：全部小写 + 下划线
`user_manager.h` `database_client.cc`

### ② 类名 / 结构体：大驼峰
`UserManager` `DatabaseConfig`

### ③ 函数名：大驼峰
`GetUserId()` `SetName()`

### ④ 变量：
- 局部变量：小驼峰 `userName`
- 成员变量：小驼峰 + 下划线结尾 `user_name_`
- 全局变量：`g_` 开头 `g_config`

### ⑤ 常量：`k` 开头 + 大驼峰
`const int kMaxConnection = 10;`

### ⑥ 宏 / 枚举：全大写 + 下划线
`MAX_RETRY_COUNT` `ENUM_SUCCESS`

---

## 3. 格式规范
- 缩进 2 空格（禁止 Tab）
- 行宽 80 列
- 大括号不换行（K&R 风格）
- 指针 `*`、引用 `&` 紧贴类型
  ```cpp
  User* user;
  const User& GetUser();
  ```

## 4. 函数设计
- 函数尽量 短小
- 函数参数 输入在前，输出在后
- 禁止使用缺省参数（谷歌规范强烈不推荐）

## 5. 类设计
- 成员变量 必须私有
- 优先使用组合，而非继承
- 禁止隐式转换，构造函数必须加 explicit
  ```cpp
  explicit User(int id);
  ```

## 6. 其他高频强制规范
- 禁止使用 using namespace std
- 头文件中 尽量不使用 using
- 智能指针必须用 std::unique_ptr / std::shared_ptr
- 禁止使用 C 风格强制转换
  ```cpp
  // 禁止
  (int)value;

  // 必须
  static_cast<int>(value);
  ```
- 所有 临时/局部变量 尽可能最小化作用域
- 优先使用 `nullptr`，不用 `NULL`

# 二、CLion 中 如何自动遵守谷歌规范？（最关键！）
## 1. 一键开启 CLion 谷歌 C++ 规范
### 步骤：
```
File → Settings → Editor → Code Style → C/C++
→ Scheme → 点击下拉 → Import Scheme → Google C++
```

开启后：
- 格式化自动按谷歌风格
- 不符合规范会波浪线警告

## 2. 一键格式化整个文件（遵守谷歌）
快捷键：
```
Ctrl + Alt + L
```

## 3. 开启 clang-format（谷歌官方格式化工具）
CLion 内置，最强校验。

开启方法：
```
Settings → Editor → Code Style → C/C++
勾选：Enable Clang-Format
选择：Google
```

之后：
- 粘贴代码自动格式化
- 保存自动格式化
- 完全强制谷歌规范

## 4. 使用 cpplint（谷歌官方 C++ 规范检查器）
可以直接在 CLion 里装插件：

### 插件名：
Cpplint

### 作用：
逐行扫描是否违反谷歌规范，包括：
- 头文件保护宏
- 命名
- 格式
- 函数长度
- 包含顺序
- 变量作用域
- 指针/引用格式
- 宏规范
- 等等 全部谷歌规则

违规直接标黄/标红，告诉你违反哪一条。

## 5. 使用 clang-tidy（高级静态检查）
谷歌规范 + 现代 C++ 最佳实践

CLion 内置开启：
```
Settings → Inspections → C/C++ → Clang-Tidy
选择：google
```

能检查：
- 未使用的 using namespace std
- 隐式转换
- 内存泄漏风险
- 线程不安全
- 代码异味

- clang-format
- cpplint
- clang-tidy

违规直接不让提交。
