MySQL: 使用 CONCAT() 函数。

```sql
SELECT CONCAT('Hello', ' ', 'World');
```
SQL Server: 使用 + 运算符。

```sql
SELECT 'Hello' + ' ' + 'World';
```
Oracle: 使用 || 运算符或 CONCAT() 函数。

```sql
SELECT 'Hello' || ' ' || 'World' FROM DUAL;
```

PostgreSQL: 使用 || 运算符。

```sql
SELECT 'Hello' || ' ' || 'World';
```
SQLite: 使用 || 运算符。

```sql
SELECT 'Hello' || ' ' || 'World';
```

mac clang也支持#pragma once

#pragma once 是一个在 C++ 中常用的预处理指令，用于确保头文件的内容在一个编译单元中只被包含（include）一次。这有助于防止因重复包含同一个头文件而导致的符号重定义错误。

具体来说，当你在一个头文件中使用 #pragma once 时，编译器会记住这个头文件已经被包含过了。如果在同一个编译单元中再次尝试包含这个头文件，编译器就会忽略它，从而避免重复包含。

举个例子，假设你有两个头文件 A.h 和 B.h，它们相互包含：

cpp
// A.h  
#pragma once  
#include "B.h"  
// ... 其他代码 ...  
  
// B.h  
#pragma once  
#include "A.h"  
// ... 其他代码 ...
在这个例子中，由于 #pragma once 的存在，A.h 和 B.h 之间的循环包含不会导致问题。当 A.h 第一次被包含时，它会包含 B.h。但由于 B.h 也使用了 #pragma once，所以它在被包含一次后就不会再次被包含，从而避免了无限循环和重复定义的问题。

需要注意的是，#pragma once 是一个非标准的预处理指令，尽管它在许多现代编译器中都被支持。为了编写更加可移植的代码，一些开发者更喜欢使用标准的 #ifndef、#define 和 #endif 预处理指令来实现类似的功能，这种方法通常被称为“包含卫士”（include guards）。

例如：

cpp
// A.h  
#ifndef A_H  
#define A_H  
#include "B.h"  
// ... 其他代码 ...  
#endif // A_H  
  
// B.h  
#ifndef B_H  
#define B_H  
#include "A.h"  
// ... 其他代码 ...  
#endif // B_H
这种方法在所有支持 C++ 的编译器中都是有效的，但可能会稍微增加一些编写和维护的工作量。

在C++中，static关键字修饰类的成员函数时，它有特定的含义和用途。当一个类的成员函数被声明为static时，它就成为了一个静态成员函数。

作用：
独立于对象调用：静态成员函数不需要类的对象就可以被调用。
不能访问非静态成员变量：静态成员函数只能直接访问静态成员变量或其他静态成员函数。
常用于函数功能不依赖于对象状态的情况：静态成员函数通常用于执行与类实例无关的任务，如查找、统计等。
与普通函数的区别：
调用方式：普通成员函数需要一个类的对象来调用，而静态成员函数可以通过类名直接调用，不需要对象。
访问权限：普通成员函数可以访问非静态成员变量和非静态成员函数，而静态成员函数只能访问静态成员变量和其他静态成员函数。
生命周期：普通成员函数的生命周期与类的对象绑定，而静态成员函数的生命周期与类绑定，不依赖于任何对象。
内存分配：普通成员函数在每个对象中都有其拷贝，而静态成员函数在所有对象中共享同一个拷贝。
目的：静态成员函数主要用于执行与对象实例无关的任务，而普通成员函数主要用于操作对象的状态。
示例：
cpp
class MyClass {  
public:  
    static void staticFunc() {  
        // 静态成员函数的实现  
    }  
    void nonStaticFunc() {  
        // 普通成员函数的实现  
    }  
};
在这个例子中，staticFunc是一个静态成员函数，可以直接通过类名调用，如MyClass::staticFunc()，而nonStaticFunc是一个普通成员函数，需要一个MyClass的对象来调用，如myObject.nonStaticFunc()。

在C++中，处理异常主要通过try-catch语句块实现。try语句块包含可能会抛出异常的代码，而catch语句块则包含处理这些异常的代码。

下面是一个简单的例子：

cpp
#include <iostream>  
#include <stdexcept>  // 包含异常类  
  
int main() {  
    try {  
        // 可能会抛出异常的代码  
        throw std::runtime_error("This is a runtime error");  
    } catch (const std::exception& e) {  // 捕获所有继承自std::exception的异常  
        std::cerr << "Caught an exception: " << e.what() << std::endl;  
    } catch (...) {  // 捕获所有其他类型的异常  
        std::cerr << "Caught an unknown exception" << std::endl;  
    }  
    return 0;  
}
在上述代码中，throw关键字用于抛出一个异常。catch关键字用于捕获异常，它后面的括号中可以是一个具体的异常类型，也可以是...，表示捕获所有类型的异常。在catch块中，可以通过e.what()来获取异常的描述信息。

此外，C++还有许多内置的异常类，例如std::runtime_error，std::logic_error等，这些类都继承自std::exception。你可以根据需要选择使用。
