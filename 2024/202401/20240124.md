在SQL中，不同的数据库系统有不同的函数来拼接字符串。以下是一些常见数据库系统的拼接字符串函数：

MySQL: 使用 CONCAT() 函数。

```sql
SELECT CONCAT('Hello', ' ', 'World');
```
SQL Server: 使用 + 运算符。

```sql
SELECT 'Hello' + ' ' + 'World';
```
Oracle: 使用 || 运算符或 CONCAT() 函数。

```sql
SELECT 'Hello' || ' ' || 'World' FROM DUAL;
```
或者

```sql
SELECT CONCAT('Hello', ' ', 'World') FROM DUAL;
```
PostgreSQL: 使用 || 运算符。

```sql
SELECT 'Hello' || ' ' || 'World';
```
SQLite: 使用 || 运算符。

```sql
SELECT 'Hello' || ' ' || 'World';
```
当使用字符串拼接时，请注意数据类型，确保您正在连接的数据是字符串类型。如果不是，您可能需要使用函数将其转换为字符串，例如在MySQL中使用 CAST() 或 CONVERT()。

import random
import string

def generate_password(length):
    characters = string.ascii_letters + string.digits + string.punctuation
    password = ''.join(random.choice(characters) for _ in range(length))
    return password

# 生成长度为 10 的随机密码
password = generate_password(10)
print(password)
