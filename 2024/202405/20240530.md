在Java中，获取CPU使用率、内存使用率、连接数（如数据库连接数或网络连接数）通常涉及不同的方法和库。对于执行shell命令来获取这些信息，你可以使用java.lang.Runtime类中的exec()方法。但请注意，执行shell命令可能依赖于操作系统，并且可能不是跨平台的解决方案。

以下是一些方法来实现这些功能：
获取CPU使用率：
Java本身没有直接获取CPU使用率的API。但你可以通过读取/proc/stat（Linux）或类似的系统文件，或者通过JMX（Java Management Extensions）和第三方库（如OSHI）来间接获取。
使用第三方库如OSHI（Operating System and Hardware Information）可以跨平台地获取CPU信息。
获取内存使用率：
你可以使用java.lang.Runtime类中的totalMemory(), freeMemory(), 和maxMemory()方法来获取Java进程的内存使用情况。但这只适用于JVM的内存使用，而不是整个系统的内存使用。
对于整个系统的内存使用，你可以使用OSHI或类似的库。
获取连接数：
对于数据库连接数，你需要查看特定数据库的JDBC驱动程序或连接池（如HikariCP, C3P0等）的API。
对于网络连接数，你可能需要读取系统文件（如/proc/net/tcp在Linux上）或使用特定的网络库。
执行shell命令：
使用java.lang.Runtime.getRuntime().exec()方法可以执行shell命令。例如，在Linux上，你可以执行top, free, 或其他命令来获取系统信息。
但请注意，这种方法可能不是跨平台的，并且可能需要处理命令输出和错误。
以下是一个简单的示例，展示如何使用Runtime.exec()执行shell命令：

```java
public class ShellCommandExample {  
    public static void main(String[] args) {  
        try {  
            Process process = Runtime.getRuntime().exec("free -m"); // Linux命令获取内存使用情况  
            BufferedReader reader = new BufferedReader(new InputStreamReader(process.getInputStream()));  
            String line;  
            while ((line = reader.readLine()) != null) {  
                System.out.println(line);  
            }  
            int exitCode = process.waitFor();  
            System.out.println("\nExited with error code : " + exitCode);  
        } catch (IOException | InterruptedException e) {  
            e.printStackTrace();  
        }  
    }  
}
```

但请记住，对于跨平台解决方案和更详细的信息，使用像OSHI这样的库通常是更好的选择。
