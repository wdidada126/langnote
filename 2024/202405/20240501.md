在Ubuntu 20上安装dos2unix，你可以通过以下步骤进行：

安装tofrodos：
tofrodos实际上安装了两个工具：todos（相当于unix2dos）和fromdos（相当于dos2unix）。你可以使用以下命令来安装它：

```bash
sudo apt-get install tofrodos -y
```
安装完成后，你就可以使用todos和fromdos命令来进行文本格式的转换了。

优化命令：
由于你可能更习惯于使用unix2dos和dos2unix这两个命令，你可以通过创建符号链接或别名的方式来实现。

创建符号链接的方法如下：

```bash
sudo ln -s /usr/bin/todos /usr/bin/unix2dos  
sudo ln -s /usr/bin/fromdos /usr/bin/dos2unix
```
或者，你可以在~/.bashrc文件中添加别名，以便在每次登录时自动设置它们。打开~/.bashrc文件并添加以下行：

```bash
alias unix2dos='todos'  
alias dos2unix='fromdos'
```
然后保存文件并运行source ~/.bashrc来使更改生效。

现在，你就可以使用dos2unix和unix2dos这两个命令来转换文本文件的格式了。例如，要将一个名为Hello.txt的文件从Windows格式转换为Linux格式，你可以运行：

```bash
dos2unix Hello.txt
```
同样地，要将一个Linux格式的文件转换为Windows格式，你可以运行：

```bash
unix2dos Hello.txt
```
