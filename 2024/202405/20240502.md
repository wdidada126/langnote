TCP（Transmission Control Protocol）具有以下11个状态：
1. CLOSED（关闭）：初始状态，表示没有打开的连接或已终止的连接。
2. LISTEN（监听）：服务器等待接受连接时的状态。服务器正在侦听来自客户端的连接请求。
3. SYN_SENT（同步已发送）：客户端发送连接请求后的状态。客户端已发送SYN（同步）包，等待服务器的确认。
4. SYN_RECEIVED（同步已接收）：服务器在收到客户端的连接请求后的状态。服务器已收到客户端的SYN包，并发送了自己的SYN和确认ACK包。
5. ESTABLISHED（已建立）：连接已成功建立并且数据可以传输的状态。双方可以开始进行数据传输。
6. FIN_WAIT_1（等待对方结束第一阶段）：表示连接关闭中的一方（一般为客户端）已发送连接终止请求，等待对方（一般为服务器）的确认。
7. FIN_WAIT_2（等待对方结束第二阶段）：表示连接关闭中的一方（一般为客户端）已收到对方的确认，等待对方发送连接终止请求。
8. CLOSE_WAIT（等待关闭）：表示连接关闭中的一方（一般为服务器）已收到关闭请求，正在等待自己的应用程序关闭连接。
9. CLOSING（关闭中）：表示连接关闭中的一方（一般为客户端）同时也发送了关闭请求，等待对方的确认。
10. LAST_ACK（最后确认）：表示连接关闭中的一方（一般为服务器）已发送关闭请求并收到对方的确认，等待最后的确认。
11. TIME_WAIT（时间等待）：表示连接已关闭，但仍保持在活动状态一段时间。在此状态下，连接仍可接收延迟的数据包，以防止在网络中存在尚未接收的数据包。

这些状态反映了TCP连接在建立、数据传输和关闭过程中的不同阶段和状态变化。

如何查看你的 Java HTTP Server 当前的 TCP 连接状态 + 命令 + 代码 + 工具全套

# 一、一句话结论
HTTP 是基于 TCP 的，所以看 HTTP 请求的 TCP 状态 = 直接看 TCP 连接状态
你只需要在 mac 上用 2 条命令 就能实时看到。

# 二、mac 上查看 TCP 状态的 2 条万能命令
## 命令 1：查看所有 TCP 连接（最常用）
```bash
netstat -an | grep tcp
```

## 命令 2：只看你的 Java HTTP Server 端口（推荐！）
假设你的 Java Server 端口是 8080
```bash
lsof -i :8080
```
或者
```bash
netstat -an | grep 8080
```

## 命令 3：实时动态刷新（像监控一样）
```bash
watch -n 0.1 netstat -an | grep 8080
```

# 三、你能看到哪些 TCP 状态？（对应 HTTP 请求阶段）
这些就是你要的 TCP 状态，直接对应 HTTP 的建立/传输/关闭：

| TCP 状态 | 含义（HTTP 请求在干嘛） |
|---|---|
| LISTEN | Java HTTP Server 正在监听端口，等待请求 |
| SYN_SENT | 客户端正在发起连接（握手第一步） |
| SYN_RCVD | 服务器收到握手请求 |
| ESTABLISHED | HTTP 请求正在处理 / 数据传输中 |
| FIN_WAIT1 | 发起关闭（一端发了 FIN） |
| FIN_WAIT2 | 等待对方关闭 |
| TIME_WAIT | 请求结束后，等待 2MSL 自动关闭 |
| CLOSE_WAIT | 服务器等待关闭（被动关闭） |
| CLOSED | 连接已完全关闭 |

# 四、你用 Reqable 发请求时，状态变化顺序
```
LISTEN
→ SYN_SENT / SYN_RCVD
→ ESTABLISHED  <-- HTTP 正在通信
→ FIN_WAIT1 / FIN_WAIT2
→ TIME_WAIT    <-- 请求结束后短暂存在
→ CLOSED
```

# 五、Java HTTP Server 如何在代码里获取 TCP 状态？
Java 本身不能直接获取 TCP 状态，但可以：

## 方案 A：通过 Socket 拿到连接信息（最接近）
```java
ServerSocket serverSocket = new ServerSocket(8080);
Socket socket = serverSocket.accept();

// 可以看到：
socket.isConnected()    // 是否已连接
socket.isClosed()       // 是否关闭
```

## 方案 B：调用系统命令获取 TCP 状态（mac 可用）
Java 执行 `netstat` 解析结果，能拿到真实 TCP 状态。

```java
Process process = Runtime.getRuntime().exec("netstat -an | grep 8080");
```

# 六、我给你一个 可直接运行的 Java HTTP Server 示例
你运行它，用 Reqable 访问，就能用上面命令看 TCP 状态：

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;

public class SimpleHttpServer {
    public static void main(String[] args) throws IOException {
        // 监听 8080
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/", new MyHandler());
        server.setExecutor(null);
        server.start();
        System.out.println("Java HTTP Server 启动，端口 8080");
    }

    static class MyHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            String response = "Hello from Java HTTP Server";
            exchange.sendResponseHeaders(200, response.length());
            OutputStream os = exchange.getResponseBody();
            os.write(response.getBytes());
            os.close();
        }
    }
}
```

运行后，用 Reqable 访问：
```
http://localhost:8080
```

然后开终端执行：
```bash
lsof -i :8080
```
你就能看到 ESTABLISHED 状态！
