Spring Boot 提供了用于 MQTT 消息传递的 `spring-boot-starter-mqtt` 起步依赖。通过使用这个起步依赖，您可以很容易地在 Spring Boot 应用程序中集成 MQTT 客户端功能。

首先，在您的 Spring Boot 项目的 `pom.xml` 文件中添加 `spring-boot-starter-mqtt` 依赖：

```xml
<dependency>
    <groupId>org.springframework.integration</groupId>
    <artifactId>spring-integration-mqtt</artifactId>
    <version>6.3.3</version>
</dependency>
```

接下来，您可以创建一个 MQTT 客户端的配置类，并在其中配置 MQTT 连接信息和相关的 bean。以下是一个简单的示例：

```java
import org.eclipse.paho.client.mqttv3.MqttConnectOptions;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.integration.annotation.ServiceActivator;
import org.springframework.integration.mqtt.core.MqttPahoClientFactory;
import org.springframework.integration.mqtt.core.MqttPahoMessageDrivenChannelAdapter;
import org.springframework.messaging.MessageHandler;

@Configuration
public class MqttConfig {

    private static final String MQTT_BROKER = "tcp://localhost:1883";
    private static final String CLIENT_ID = "spring-boot-client";

    @Bean
    public MqttConnectOptions mqttConnectOptions() {
        MqttConnectOptions options = new MqttConnectOptions();
        options.setServerURIs(new String[]{MQTT_BROKER});
        options.setAutomaticReconnect(true);
        // 设置其他连接选项
        return options;
    }

    @Bean
    public MqttPahoClientFactory mqttClientFactory() {
        DefaultMqttPahoClientFactory factory = new DefaultMqttPahoClientFactory();
        factory.setConnectionOptions(mqttConnectOptions());
        return factory;
    }

    @Bean
    @ServiceActivator(inputChannel = "mqttInputChannel")
    public MessageHandler mqttInputHandler() {
        MqttPahoMessageDrivenChannelAdapter adapter = new MqttPahoMessageDrivenChannelAdapter(CLIENT_ID, mqttClientFactory(), "your-topic");
        adapter.setCompletionTimeout(5000);
        adapter.setConverter(new DefaultPahoMessageConverter());
        adapter.setQos(1);
        return adapter;
    }
}
```

在这个配置类中，我们定义了 MQTT 连接选项以及 MQTT 客户端工厂。然后，通过 `MqttPahoMessageDrivenChannelAdapter` 创建了一个消息驱动的通道适配器，用于订阅指定的主题并处理接收到的消息。

请注意，您需要根据您的实际情况修改 MQTT 代理的地址、客户端 ID 以及订阅的主题等信息。

这样，您就可以使用 `spring-boot-starter-mqtt` 起步依赖在 Spring Boot 应用程序中实现 MQTT 客户端功能。
