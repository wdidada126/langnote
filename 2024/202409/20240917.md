在 C++11 标准中引入了多线程支持，包括了 `std::thread` 类和相关的头文件。在 Mac 平台上，你可以使用 Clang 或者 GCC 编译器来编译支持 C++11 的代码。

在 C++11 标准之前，进行多线程编程可能需要依赖于操作系统提供的线程库，比如 POSIX 线程库。在 Mac 平台上，它支持 POSIX 线程，你可以使用 `<pthread.h>` 头文件来开启多线程编程。

以下是一个简单的示例代码，展示了如何在 C++11 之前使用 POSIX 线程库在 Mac 平台上开启多线程编程：

```cpp
#include <iostream>
#include <pthread.h>

void* threadFunction(void* arg) {
    int* thread_id = static_cast<int*>(arg);
    std::cout << "Thread " << *thread_id << " is running." << std::endl;
    return nullptr;
}

int main() {
    pthread_t thread1, thread2;
    int id1 = 1, id2 = 2;

    pthread_create(&thread1, nullptr, threadFunction, &id1);
    pthread_create(&thread2, nullptr, threadFunction, &id2);

    pthread_join(thread1, nullptr);
    pthread_join(thread2, nullptr);

    return 0;
}
```

在这个示例中，`pthread_create` 函数创建了两个线程并启动它们，每个线程运行 `threadFunction` 函数。`pthread_join` 函数用于等待线程的结束。

请注意使用 POSIX 线程库可能会使代码在不同平台上的可移植性受限。因此，如果你可以使用 C++11 标准的 `std::thread` 类，推荐使用 C++11 的多线程支持，因为它提供了更加方便和可移植的多线程编程接口。

在 Windows 平台上，如果你想在没有 C++11 标准支持的情况下开启多线程编程，你可以使用 Windows API 提供的线程相关函数来实现。Windows 平台上的多线程编程通常会使用 `CreateThread` 函数来创建新线程。

下面是一个简单的示例代码，展示了如何在没有 C++11 标准支持的情况下使用 Windows API 在 Win 平台上开启多线程编程：

```cpp
#include <iostream>
#include <windows.h>

DWORD WINAPI ThreadFunc(LPVOID lpParam) {
    int threadId = *(int*)lpParam;
    std::cout << "Thread " << threadId << " is running." << std::endl;
    return 0;
}

int main() {
    HANDLE hThread1, hThread2;
    DWORD threadId1, threadId2;

    int id1 = 1, id2 = 2;

    hThread1 = CreateThread(NULL, 0, ThreadFunc, &id1, 0, &threadId1);
    hThread2 = CreateThread(NULL, 0, ThreadFunc, &id2, 0, &threadId2);

    // 等待线程结束
    WaitForSingleObject(hThread1, INFINITE);
    WaitForSingleObject(hThread2, INFINITE);

    CloseHandle(hThread1);
    CloseHandle(hThread2);

    return 0;
}
```

在这个示例中，`CreateThread` 函数创建了两个线程并启动它们，每个线程运行 `ThreadFunc` 函数。`WaitForSingleObject` 函数用于等待线程的结束。

请注意，使用 Windows API 提供的函数可能会限制代码在其他操作系统上的可移植性，因此如果可能的话，推荐使用 C++11 标准的 `std::thread` 类，因为它提供了更加方便和可移植的多线程编程接口。

在 C++11 中，标准库并没有提供直接支持多进程编程的类，但你可以使用操作系统提供的函数来实现多进程编程。在 Unix/Linux 系统上，可以使用 `fork()` 系统调用来创建子进程，而在 Windows 系统上，可以使用 `CreateProcess()` 函数来创建新进程。

下面是一个简单的示例代码，展示了在 C++11 中如何在 Unix/Linux 系统上使用 `fork()` 创建子进程：

```cpp
#include <iostream>
#include <unistd.h>
#include <sys/wait.h>

int main() {
    pid_t pid = fork();

    if (pid == -1) {
        std::cerr << "Failed to fork a new process." << std::endl;
        return 1;
    } else if (pid == 0) {
        // 子进程
        std::cout << "Child process is running." << std::endl;
    } else {
        // 父进程
        std::cout << "Parent process is running." << std::endl;
        wait(NULL); // 等待子进程结束
    }

    return 0;
}
```

在这个示例中，`fork()` 调用会创建一个新的子进程，子进程会复制父进程的地址空间，然后在子进程中返回 `0`，在父进程中返回新创建的子进程的 PID。使用 `wait(NULL)` 可以等待子进程结束。

需要注意的是，跨平台性是多进程编程的一个挑战，因为不同的操作系统对进程管理有不同的实现。如果你需要编写跨平台的多进程应用程序，可能需要使用一些跨平台的库或者框架来实现。
