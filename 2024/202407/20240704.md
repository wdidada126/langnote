## c++ default delete关键字

在C++11及其之后的版本中，关键字 `default` 和 `delete` 可以用于方法的声明，以显式地定义特殊成员函数（如构造函数、析构函数、拷贝构造函数、拷贝赋值运算符、移动构造函数和移动赋值运算符）的行为。它们提供了对类的默认行为的控制，以满足不同的设计需求。

### `default`

关键字 `default` 用于告诉编译器为类生成一个默认的实现。例如，如果你不需要自定义的构造函数、析构函数或拷贝/移动操作，可以使用 `default` 来让编译器自动生成这些方法的默认实现。

#### 用法示例：

```cpp
class MyClass {
public:
    MyClass() = default;               // 默认构造函数
    ~MyClass() = default;              // 默认析构函数
    MyClass(const MyClass&) = default; // 默认拷贝构造函数
    MyClass& operator=(const MyClass&) = default; // 默认拷贝赋值运算符
    MyClass(MyClass&&) = default;      // 默认移动构造函数
    MyClass& operator=(MyClass&&) = default; // 默认移动赋值运算符
};
```

### `delete`

关键字 `delete` 用于禁止特定的函数实现。这在禁止类的某些拷贝或移动操作时非常有用。例如，如果你希望一个类是不可拷贝的，可以将拷贝构造函数和拷贝赋值运算符声明为 `delete`。

#### 用法示例：

```cpp
class NonCopyable {
public:
    NonCopyable() = default;
    ~NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete; // 禁止拷贝构造函数
    NonCopyable& operator=(const NonCopyable&) = delete; // 禁止拷贝赋值运算符
    NonCopyable(NonCopyable&&) = default; // 默认移动构造函数
    NonCopyable& operator=(NonCopyable&&) = default; // 默认移动赋值运算符
};
```

### 区别和作用

1. `default`：
   - 生成编译器默认的实现。
   - 用于不需要自定义行为但仍需要显式声明的情况。
   - 保留类的默认特性，减少代码重复。

2. `delete`：
   - 禁止特定函数的实现。
   - 用于明确指出某些操作是不允许的，增强类的安全性和正确性。
   - 常用于禁止拷贝构造、拷贝赋值，以实现不可拷贝的类。

### 实际应用

- `default`：当你希望类使用编译器生成的默认行为时使用。例如，一个简单的 `struct`，其成员的默认构造、拷贝、移动等操作都不需要特别处理。
- `delete`：当你希望类的某些操作不被允许时使用。例如，单例模式中，禁止拷贝构造和拷贝赋值以确保类只有一个实例。

### 示例代码

```cpp
#include <iostream>

class DefaultExample {
public:
    DefaultExample() = default;
    ~DefaultExample() = default;
    DefaultExample(const DefaultExample&) = default;
    DefaultExample& operator=(const DefaultExample&) = default;
    DefaultExample(DefaultExample&&) = default;
    DefaultExample& operator=(DefaultExample&&) = default;
};

class DeleteExample {
public:
    DeleteExample() = default;
    ~DeleteExample() = default;
    DeleteExample(const DeleteExample&) = delete; // 禁止拷贝
    DeleteExample& operator=(const DeleteExample&) = delete; // 禁止赋值
    DeleteExample(DeleteExample&&) = default; // 允许移动
    DeleteExample& operator=(DeleteExample&&) = default; // 允许移动赋值
};

int main() {
    DefaultExample de1;
    DefaultExample de2 = de1; // 允许拷贝

    DeleteExample de3;
    // DeleteExample de4 = de3; // 编译错误：拷贝构造函数被删除

    return 0;
}
```

通过使用 `default` 和 `delete`，可以更好地控制类的行为，增强代码的可读性和安全性。
