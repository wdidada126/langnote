TiDB 是一个分布式关系型数据库，它支持分页查询，但是不使用 `ROWNUM` 来实现分页，而是通过 `LIMIT` 语句来实现。在 TiDB 中，你可以使用 `LIMIT` 语句来限制查询结果的数量，并且可以通过 `OFFSET` 来跳过一定数量的行，从而实现分页的效果。

例如，如果你想要获取第 2 页的数据，每页显示 10 条记录，你可以使用如下的 SQL 语句：

```sql
SELECT * FROM your_table ORDER BY some_column LIMIT 10 OFFSET 10;
```

这里的 `10` 是每页显示的记录数，`OFFSET 10` 表示跳过前 10 条记录，也就是第一页的数据。

TiDB 也支持 `LIMIT row_count OFFSET offset` 语法，这与 Oracle 中的 `FETCH NEXT n ROWS ONLY` 和 `OFFSET m` 类似，但是 TiDB 使用 `LIMIT` 和 `OFFSET` 来实现分页查询。需要注意的是，使用分页查询时，应该通过 `ORDER BY` 语句指定查询结果的排序方式，以确保数据的顺序一致性。

此外，TiDB 还提供了一些高级的分页批处理方案，例如使用窗口函数 `row_number()` 来为每一行数据生成行号，然后根据行号进行分页处理。这种方法可以避免对大量数据进行排序，从而提高分页查询的效率，尤其适用于处理大量数据的场景。
