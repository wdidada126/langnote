Oracle SQL中的`INSERT ALL`语句允许你在一个单一的操作中插入多行数据。这种语句特别有用，当你需要从多个不同的查询中插入数据到同一个表中时。以下是`INSERT ALL`语句的基本语法：

```sql
INSERT ALL
    INTO table_name1 (column1, column2, ...)
    SELECT column1, column2, ...
    FROM table_or_view_or_query1
    WHERE condition1
    INTO table_name2 (column1, column2, ...)
    SELECT column1, column2, ...
    FROM table_or_view_or_query2
    WHERE condition2
    ...
SELECT 1 FROM dual
```

这里是`INSERT ALL`语句的组成部分：
- `INSERT ALL`：开始一个`INSERT ALL`语句。
- `INTO table_name (column1, column2, ...)`：指定要插入数据的目标表和列。
- `SELECT column1, column2, ... FROM table_or_view_or_query`：指定从哪个表、视图或子查询中选择数据。
- `WHERE condition`：（可选）指定选择数据的条件。
- `SELECT 1 FROM dual`：结束`INSERT ALL`语句。`dual`是Oracle特有的虚拟表，可以用于这种类型的操作。

每个`INTO ... SELECT`对可以独立地从不同的源选择数据，并且可以有自己的`WHERE`子句。`SELECT 1 FROM dual`部分是必须的，它标志着`INSERT ALL`语句的结束。

下面是一个具体的例子，演示如何使用`INSERT ALL`语句：

```sql
INSERT ALL
    INTO employees (id, name) VALUES (1, 'John Doe')
    INTO employees (id, name) VALUES (2, 'Jane Smith')
SELECT 1 FROM dual;
```
在这个例子中，我们向`employees`表中插入了两行数据。每行数据都是通过`INTO ... VALUES`语句插入的，最后以`SELECT 1 FROM dual`结束。

请注意，`INSERT ALL`语句中的每个`SELECT`语句都可以是从不同的表或视图中选择数据，也可以是更复杂的子查询。这使得`INSERT ALL`语句非常灵活，可以用于多种数据插入场景。
