微软出的安卓子系统

微软推出的安卓子系统，官方名称为“适用于 Android 的 Windows 子系统”（Windows Subsystem for Android），通常被称为 Windows 11 安卓子系统或简称 WSA 。这个子系统允许用户在 Windows 11 操作系统上直接运行 Android 应用程序，提供了一个集成的体验  。

该子系统包括 Linux 内核和基于 Android 开源项目（AOSP）版本的 Android 操作系统 。它在 Hyper-V 虚拟机中运行，能够将 AOSP 环境中应用程序的运行时和 API 映射到 Windows 11 操作系统的图形层、内存缓冲区、输入模式和传感器  。

用户可以将 Android 应用程序固定到 Windows 11 的“开始”菜单或任务栏，并通过鼠标、触摸或触控笔与其交互  。Android 应用还可以集成到 Alt + Tab 和任务视图中，帮助用户在应用之间快速切换  。

最近的更新中，微软改进了子系统输入的兼容性、滚动平滑度、启动性能，并修复了复制和粘贴超大内容时崩溃的问题 。此外，还优化了网络连接、图形、使用游戏手柄的操控体验，并提升了卸载应用程序的性能 。子系统还更新到了 Chromium WebView 104，并进行了内核安全更新 。

这个子系统为 Windows 11 用户提供了在电脑上运行 Android 应用的便利，使得用户能够在一个统一的环境中使用多种应用  。


在Oracle 19c数据库中，如果您想要根据`etp_id`分组，并查询每个`etp_id`分组中`create_time`最早的数据信息，您可以使用子查询或者窗口函数来实现。以下是两种可能的查询方法：

### 方法1：使用子查询

```sql
SELECT *
FROM (
    SELECT 
        id, 
        etp_Id, 
        create_time, 
        a_id, 
        b_id,
        ROW_NUMBER() OVER(PARTITION BY etp_Id ORDER BY create_time ASC) AS rn
    FROM 
        your_table_name
) WHERE rn = 1;
```

在这个查询中，`ROW_NUMBER()`窗口函数为每个`etp_Id`分组内的记录分配一个序号，按照`create_time`升序排列。外层查询选择了每个分组中序号为1的记录，即每个`etp_Id`最早的`create_time`对应的记录。

### 方法2：使用子查询和MIN函数

```sql
SELECT 
    t1.id, 
    t1.etp_Id, 
    t1.create_time, 
    t1.a_id, 
    t1.b_id
FROM 
    your_table_name t1
JOIN (
    SELECT 
        etp_Id, 
        MIN(create_time) AS min_create_time
    FROM 
        your_table_name
    GROUP BY 
        etp_Id
) t2 ON t1.etp_Id = t2.etp_Id AND t1.create_time = t2.min_create_time;
```

在这个查询中，子查询首先找出每个`etp_Id`的最早`create_time`，然后外层查询通过`JOIN`操作将原表与子查询结果连接起来，选择了每个`etp_Id`最早`create_time`对应的记录。

请将`your_table_name`替换为您实际的表名。这两种方法都可以有效地查询出每个`etp_id`分组中`create_time`最早的数据信息。
