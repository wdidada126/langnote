# 先给你直白翻译：啥是 828、啥是 OSTEP
## 1. OSTEP 是什么
OSTEP = Operating Systems: Three Easy Pieces
中文常叫：操作系统三大件/操作系统三本轻松读物
- 免费开源操作系统经典教科书，全网可下载 PDF
- 作者：Remzi H. Arpaci-Dusseau
- 地位：自学操作系统天花板、MIT/伯克利很多课都用它当教材
- 内容：进程、线程、并发、调度、虚拟内存、文件系统、磁盘、一致性协议，全覆盖
- 特点：大白话、不讲晦涩公式、极其好懂，你能半个月通关 Lab，就是因为这本书讲得太通俗

## 2. 啥是 828？
828 = 清华 828 操作系统实验
全称：清华大学 828 Operating System Lab
- 清华本科生操作系统必修课实验
- 全网公开、开源、所有人都能自学做
- 实验栈基于 OSTEP 教材配套设计
- 难度特点：
  相比 MIT 6.S081、伯克利 CS162、南大 PA
  清华828 是公开系统 Lab 里最简单、最友好、最适合入门的
  所以你才会有感觉：
  > 看完OSTEP，半个月就通关全部828 Lab

# 3. 828 实验包含哪些（全套）
1. Lab1：Shell 实现 手写简易命令行解释器
2. Lab2：进程调度 实现时间片轮转、优先级调度
3. Lab3：内存管理 虚拟内存、页表、缺页异常
4. Lab4：线程与锁 用户态线程、互斥锁、条件变量
5. Lab5：文件系统 简易文件系统 inode/目录/读写

整套基于 xv6 精简内核，代码量不大、步骤引导极详细，比 MIT 6.S081 简单太多。

# 4. 为什么你觉得 828 特别简单？
1. 教材匹配度拉满：828 完全照着 OSTEP 章节出题
2. 实验文档中文、步骤极细，手把手引导
3. 基于 xv6 教学内核，代码量小、架构极简
4. 没有 6.S081 那种硬核大坑、不用啃复杂硬件细节
5. 并发、内存、文件系统概念 OSTEP 都讲透了，做题直接套

# 5 一句话总结
- OSTEP：操作系统神级免费教材，通俗易懂，入门必看。
- 828：清华操作系统公开课实验，基于 xv6、配套 OSTEP，公开系统 Lab 里难度最低、最适合新手刷通关。
