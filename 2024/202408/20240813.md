内存块太小导致malloc和new返回空指针，该怎么处理？

对于malloc来说，需要判断其是否返回空指针，如果是则马上用return语句终止该函数或者exit终止该程序；
对于new来说，默认抛出异常，所以可以使用try...catch...代码块的方式：
```
try {
  int *ptr = new int[10000000];
} catch(bad_alloc &memExp) {
  cerr << memExp.what() << endl;
}
C++
还可以使用set_new_handler函数的方式：

void no_more_memory() {
  cerr << "Unable to satisfy request for memory" << endl;
  abort();
}
int main() {
  set_new_handler(no_more_memory);
  int *ptr = new int[10000000];
}
```
C++
在这种方式里，如果new不能满足内存分配请求，no_more_memory会被反复调用，所以new_handler函数必须完成以下事情：

让更多内存可被使用：可以在程序一开始执行就分配一大块内存，之后当new_handler第一次被调用，就将这些内存释放还给程序使用；
使用另一个new_handler；
卸除new_handler：返回空指针，这样new就会抛出异常；
直接抛出bad_alloc异常；
调用abort或exit。

bad_alloc 是 C++ 标准库中的一个异常类，它定义在头文件 <new> 中。这个异常类型专门用于在内存分配请求失败时由 new 操作符抛出。当 new 操作符无法为对象分配足够的内存空间时，它会抛出一个 std::bad_alloc 类型的异常。
基本用法
在 C++ 中，处理 bad_alloc 异常通常涉及到 try-catch 语句块。你可以尝试分配内存，并在捕获到 bad_alloc 异常时执行一些错误处理代码，比如释放已分配的资源、记录错误日志、或者向用户报告错误。

```cpp
#include <iostream>  
#include <new> // 包含 bad_alloc 的定义  
  
int main() {  
    try {  
        // 尝试分配一个非常大的数组，可能会失败  
        int* largeArray = new int[1000000000000];  
    } catch (const std::bad_alloc& e) {  
        // 捕获到 bad_alloc 异常  
        std::cerr << "内存分配失败: " << e.what() << '\n';  
        // 在这里处理错误，比如释放资源、记录日志等  
    }  
  
    return 0;  
}
```
std::bad_alloc 成员函数
what()：这是一个从 std::exception 类继承而来的成员函数。它返回一个指向以 null 结尾的字符数组的指针，该数组包含了描述异常的字符串。对于 std::bad_alloc，这个字符串通常是 "std::bad_alloc"，但具体实现可能有所不同。
注意事项
当你的程序抛出 std::bad_alloc 异常时，它意味着你的程序已经处于内存不足的状态。因此，在捕获到这个异常后，你应该谨慎地处理它，因为此时程序可能没有足够的内存来执行复杂的错误处理代码。
在某些情况下，如果程序无法从堆上分配内存，它可能也无法从栈上分配足够的空间来执行错误处理代码。因此，设计错误处理策略时应该考虑到这一点。
考虑到性能和资源使用，尽量避免在性能敏感的代码路径中频繁地尝试分配大量内存，因为这可能会增加抛出 std::bad_alloc 异常的风险。
总之，std::bad_alloc 是 C++ 中处理内存分配失败的一种机制，通过合理使用 try-catch 语句块和异常处理代码，你可以使你的程序更加健壮和可靠。

std::apply 是 C++17 中引入的一个函数模板，位于 <tuple> 头文件中。它允许以元组的方式将参数传递给一个可调用对象（函数、函数指针、成员函数指针、函数对象等）。
在C++中，模板的使用非常灵活，但是直接要求模板参数必须是某个类的子类，或者必须拥有某个特定的成员变量或成员函数，并不像在一些其他语言中那样直接支持。不过，你可以通过一些间接的方法来实现这种需求。
方法一：使用静态断言（C++11及以上）
你可以使用std::is_base_of来检查模板参数是否是某个类的子类，或者使用std::is_member_function_pointer、std::experimental::is_detected（C++17之前需要自行实现或使用库）来检查是否存在某个成员函数或成员变量。
示例：检查模板参数是否为某类的子类
```cpp
#include <type_traits>  
#include <iostream>  
  
class Base {};  
class Derived : public Base {};  
class NotDerived {};  
  
template<typename T>  
typename std::enable_if<std::is_base_of<Base, T>::value, void>::type  
func(T* obj) {  
    static_assert(std::is_base_of<Base, T>::value, "T must be derived from Base");  
    // 使用obj  
    std::cout << "T is derived from Base" << std::endl;  
}  
  
int main() {  
    Derived d;  
    func(&d); // 正确  
  
    // NotDerived nd;  
    // func(&nd); // 编译错误  
}
```
方法二：使用SFINAE（Substitution Failure Is Not An Error）
SFINAE是模板元编程中常用的一种技术，可以在编译时根据模板参数的类型选择性地启用或禁用模板特化。
示例：检查模板参数是否拥有特定成员函数
```cpp
#include <iostream>  
#include <type_traits>  
  
class A {  
public:  
    void foo() {}  
};  
  
class B {};  
  
template<typename T, typename = void>  
struct has_foo : std::false_type {};  
  
template<typename T>  
struct has_foo<T, decltype(void(std::declval<T>().foo()), void())> : std::true_type {};  
  
template<typename T>  
typename std::enable_if<has_foo<T>::value, void>::type  
func(T* obj) {  
    // 使用obj.foo()  
    obj->foo();  
    std::cout << "T has foo()" << std::endl;  
}  
  
int main() {  
    A a;  
    func(&a); // 正确  
  
    // B b;  
    // func(&b); // 编译错误  
}
```
注意
静态断言（static_assert）是在编译时进行检查，如果条件不满足，则编译失败。
SFINAE和enable_if允许在编译时根据模板参数的不同特性选择性地启用或禁用模板特化，这可以用来在编译时检查模板参数是否满足某些条件。
在实际应用中，你可能需要根据你的具体需求选择最合适的方法。

默认初始化 值初始化
默认初始化和值初始化是C++中两种不同的初始化方式。默认初始化是指在没有提供初始值的情况下，使用变量类型的默认构造函数进行初始化。值初始化是指使用指定的初始值对变量进行初始化。
下面是一个代码例子，展示了默认初始化和值初始化的区别：
```cpp
#include <iostream>

int main() {
    // 默认初始化
    int a; // 使用int类型的默认构造函数进行初始化，a的值为0
    double b; // 使用double类型的默认构造函数进行初始化，b的值为0.0
    char c; // 使用char类型的默认构造函数进行初始化，c的值为'\0'

    // 值初始化
    int x = 10; // 使用指定的初始值10对x进行初始化
    double y = 3.14; // 使用指定的初始值3.14对y进行初始化
    char z = 'A'; // 使用指定的初始值'A'对z进行初始化

    std::cout << "a: " << a << std::endl; // 输出：a: 0
    std::cout << "b: " << b << std::endl; // 输出：b: 0
    std::cout << "c: " << static_cast<int>(c) << std::endl; // 输出：c: 0 (字符'\0'转换为整数时为0)
    std::cout << "x: " << x << std::endl; // 输出：x: 10
    std::cout << "y: " << y << std::endl; // 输出：y: 3.14
    std::cout << "z: " << z << std::endl; // 输出：z: A

    return 0;
}
```
