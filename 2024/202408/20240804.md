mutable c++关键字

mutable 是 C++ 中的一个关键字，它用于修饰类的非静态数据成员。当你在类的成员变量前加上 mutable 关键字时，这个成员即使在类的 const 成员函数中也可以被修改。mutable 的主要作用是允许在 const 成员函数内部修改类的某些特定成员，而无需将整个函数声明为非 const。

这在某些情况下非常有用，比如你需要在一个 const 成员函数内更新一个用于缓存或记录状态的成员变量，但又不想破坏类的 const 正确性。

下面是一个简单的例子来说明 mutable 的用法：

```cpp
#include <iostream>  
#include <string>  
  
class MyClass {  
public:  
    MyClass(std::string value) : value_(value), accessCount_(0) {}  
  
    void setValue(const std::string& newValue) const {  
        // 这里尝试修改value_会编译错误，因为value_不是mutable的  
        // value_ = newValue; // 错误  
  
        // 但我们可以修改mutable成员  
        ++accessCount_; // 正确  
    }  
  
    // 假设这个函数用于获取value_的副本，但同时记录它被访问了多少次  
    std::string getValue() const {  
        ++accessCount_; // 允许在const函数中修改mutable成员  
        return value_;  
    }  
  
    // 一个非const成员函数，用于展示如何修改所有成员  
    void changeValue(const std::string& newValue) {  
        value_ = newValue;  
        ++accessCount_;  
    }  
  
private:  
    std::string value_; // 非mutable成员  
    mutable int accessCount_; // mutable成员  
};  
  
int main() {  
    MyClass obj("Initial");  
    obj.getValue(); // 访问并更新accessCount_  
    obj.getValue(); // 再次访问并更新accessCount_  
  
    // 尝试修改value_，需要非const成员函数  
    obj.changeValue("Changed");  
  
    std::cout << "Value: " << obj.value_ << ", Accessed " << obj.accessCount_ << " times." << std::endl;  
  
    return 0;  
}
```

在这个例子中，accessCount_ 是一个 mutable 成员，它可以在 const 成员函数中被修改。而 value_ 则不是 mutable 的，因此它不能在 const 成员函数中被修改。注意，mutable 成员通常用于缓存、计数器等场景，它们不直接影响对象的状态（即不影响对象在逻辑上是否相等），但可能需要根据访问情况更新。

#include <utility> 是 C++ 标准库中的一个头文件，它主要定义了一对实用的工具：std::pair 和 std::tuple 的相关支持函数，以及 std::swap 函数（尽管在 C++11 及以后的版本中，std::swap 也可以在 <algorithm> 头文件中找到）。然而，需要注意的是，std::tuple 的完整定义实际上位于 <tuple> 头文件中，而 <utility> 主要关注于 std::pair 和一些与实用程序相关的功能。

std::pair
std::pair 是一个模板结构体，用于将两个值组合成一个单一的实体。这对于需要同时存储和操作两个相关值的情况特别有用。std::pair 提供了两个成员变量：first 和 second，分别用于访问其两个元素。

std::swap
std::swap 是一个通用的函数模板，用于交换两个对象的值。它通常用于算法中，以优化性能或满足某些接口要求。在 C++11 及更高版本中，std::swap 被设计为可高度定制的，允许用户为自定义类型提供专门的交换函数，以优化性能。

示例
以下是使用 <utility> 头文件中 std::pair 的一个简单示例：

cpp
#include <iostream>  
#include <utility> // 包含 std::pair  
  
int main() {  
    std::pair<int, std::string> myPair = {1, "Hello, World!"};  
    std::cout << "The first element is " << myPair.first << " and the second is " << myPair.second << std::endl;  
  
    // 假设我们想要交换 pair 中的元素  
    // 注意：在真实场景中，直接交换 pair 的元素可能不是很有用，但这里只是为了演示  
    std::swap(myPair.first, myPair.second);  
    std::cout << "After swap, the first element is " << myPair.first << " and the second is " << myPair.second << std::endl;  
  
    return 0;  
}
注意，在这个例子中，虽然我们用到了 std::swap 来交换 pair 的两个元素，但这并不是 std::swap 的典型用法。更常见的用法是交换两个 pair 对象，或者用于其他支持 std::swap 的类型。

总的来说，<utility> 头文件在 C++ 标准库中扮演着提供基础实用程序的角色，特别是通过 std::pair 和 std::swap，为开发者提供了强大的工具来处理成对的数据和对象交换。

std::variant 和 std::monostate 都是在 C++17 标准中引入的，它们一起提供了一种类型安全的联合体（union）的替代方案，允许存储多种类型之一的值，并且比传统的联合体更加安全和灵活。

std::monostate 的含义
std::monostate 是一个空的结构体，它作为 std::variant 的一种特殊类型存在，用于表示“无值”或“空”状态。当 std::variant 的所有其他可能类型都不适用时，可以使用 std::monostate 作为备选。这在你需要一个能够表示多种类型但也可能不表示任何特定类型的场景下非常有用。

语法
std::monostate 是在 <variant> 头文件中定义的，使用它不需要包含额外的头文件。它是一个空的结构体，所以它的实例不占用额外的空间（除了可能的对齐填充）。

例子
下面是一个使用 std::variant<std::monostate, int, std::string> 的例子，这个 variant 可以存储一个整数、一个字符串或者表示“无值”状态：

```cpp
#include <variant>  
#include <iostream>  
#include <string>  
  
int main() {  
    std::variant<std::monostate, int, std::string> var;  
  
    // 初始化为无值状态  
    var = std::monostate{};  
  
    // 检查是否为monostate  
    if (std::holds_alternative<std::monostate>(var)) {  
        std::cout << "var is in monostate" << std::endl;  
    }  
  
    // 赋值为整数  
    var = 42;  
    if (std::holds_alternative<int>(var)) {  
        std::cout << "var is now an int with value " << std::get<int>(var) << std::endl;  
    }  
  
    // 赋值为字符串  
    var = "Hello, World!";  
    if (std::holds_alternative<std::string>(var)) {  
        std::cout << "var is now a string with value " << std::get<std::string>(var) << std::endl;  
    }  
  
    return 0;  
}
```
这个例子展示了如何初始化 std::variant 为 std::monostate，以及如何在后续操作中检查和修改其存储的类型和值。

注意事项
使用 std::get<T>(var) 访问 std::variant 中的值时，需要确保 var 当前确实持有类型 T 的值，否则会导致 std::bad_variant_access 异常。
std::holds_alternative<T>(var) 可以用来检查 var 是否当前持有类型 T 的值，从而安全地访问 var。
std::visit 是另一个强大的工具，它可以安全地遍历 std::variant 中的所有可能类型，并执行相应的操作，而无需担心类型不匹配的问题。
