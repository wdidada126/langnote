1. libgda
简介: libgda 是一个 C 语言数据库访问库，提供了对多种数据库的支持，包括 MySQL、PostgreSQL 和 SQLite。
支持多线程: libgda 支持多线程操作。
维护状态: libgda 是 GNOME 项目的一部分，依然在维护中。
链接: https://gitlab.gnome.org/GNOME/libgda
2. libdbi
   简介: libdbi 是一个 C 语言数据库接口库，提供了统一的 API 来操作多种数据库。
   支持多线程: libdbi 支持多线程操作。
   维护状态: 虽然 libdbi 的活跃度可能不如一些更现代的项目，但仍在维护中。
   链接: https://libdbi.sourceforge.net/
