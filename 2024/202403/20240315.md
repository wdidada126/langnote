领导力，你跳槽手下会跟随你吗？
很多人以为，挖人给高薪就行了，只要砸钱，有什么人是挖不过来的？刚毕业的小朋友通常会这么思考~
但是，多想一步：这么容易的话，HR和猎头其实都不需要了，一个实习生足以完成所有招聘工作：直接往各大招聘网站上投放JD：比原薪酬高30%以上。哗啦哗啦，人就蜂拥而至~
对于中低级别员工，有可能是这样的——有人给个高0~30%薪水就去了，但对于很多工作年限稍长的人而言，跟谁干活，前途咋样，这些才是需要重点考虑的，至于薪水——跟对人了还愁无法发展，还愁薪水涨不上去？
因此，对于撬人一方而言，如何让中高级别人员感受到，公司领导对你的殷殷期盼和信赖，对你未来发展的支持，对你职业生涯的帮助，这才是挖人的重点。而中高级别人员一旦搞定，中低级别人员就好多了——中高级别人员一般来说都不是一个人在战斗，他都有一支属于自己的团队，有忠心耿耿的、专业能力强的下属，会跟着他去任何地方——哪怕薪水差不多~
所以挖人，最重要的其实不是挖中低级员工，而是挖中高级别领导——一个团队一个团队的挖，这样子效率更高，忠诚度高，素质更高。至于散养、散招的中低级别员工，那就随缘看看咯~
前两天，一位10多年前带过的实习生，现在是四大的一位高级经理，请我喝咖啡，聊了聊他想升总监的事情：说他老板现在有些不信任他，觉得他过于焦虑且领悟不到老板的想法，认为他还不够成熟~
我问的第一个问题是：假设你今天想跳槽到另一家四大，你有几个铁杆会跟着你一起走？他想了想，说可能有一个~我问的第二个问题是：假设没有你老板，你一年能为公司挣多少钱？他说，可能很少，甚至没有~我问的第三个问题是：你会为自己的前途焦虑和迷茫么？他说，当然啦，每天焦虑得睡不着~
我说，那你确实不够成熟，还没有为升总监准备好~对于四大的合伙人而言，要推人升总监/合伙人，上面三个问题非常重要。第一个问题代表你是否有人，第二个问题代表你能否挣钱，第三个问题代表你能否抗压~
事实上，对于公司招聘中高级别员工而言，这三个问题也同样重要：
有人：只要你有团队有人，那么对公司而言，即便挣不了钱也可以当资源池使用；
有钱：只要你能替公司带来足够的增量，即便你没有人，你也可以当销售使用；
抗压：只要你心态足够好，心理足够健康，哪怕一年半载没有收入，你也能够宠辱不惊~
理解了这些，你应该就能理解大公司怎么挖人的，也能理解为什么字节能够挖走这么多百度的人：
找到郁郁不得志、但又有一帮铁杆的中高级别员工，晓之以理动之以情，最重要的是发展、前途，搞定他——哪怕是许诺股票期权都可以；
然后给他们空间和要求，让他们自己主动去把自己那一帮人拉过来；
有人说，如果挖错中高级别人员了呢？想办法让他们主动离职就好啦——放心，中高级人员更在乎他们羽毛的~

为何下面的代码在C++11中无法运行？错误提示为：constexpr 变量必须具有文本类型或引用类型C/C++(2402)。如何修改才能正确？我知道改成const可以正确，但是如何在这个例子中正确使用constexpr呢？

using namespace std;
constexpr array<string, 2> arrstr{"abc", "xyz"};

string得在C++20后才能constexpr构造了，考虑到C++11，你应该使用const char*。

using namespace std;
constexpr array<const char*, 2> arrstr{"abc", "xyz"};
