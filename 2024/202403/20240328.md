# 一、Java 中 a.foreach() 空指针异常 + 正确判空写法
你出现 NPE 只有一个原因：
**集合 a 本身是 null，然后你调用 a.forEach() → 空指针**

## 错误写法（会抛空指针）
```java
List<User> list = null;
list.forEach(System.out::println); // 空指针！
```

## 正确写法（通用、安全、不会空指针）
```java
// 判空 + 遍历
if (list != null && !list.isEmpty()) {
    list.forEach(item -> {
        // 业务逻辑
    });
}
```

## Java 8+ 优雅写法（Optional）
```java
Optional.ofNullable(list)
       .ifPresent(items -> items.forEach(item -> {
           // 业务逻辑
       }));
```
