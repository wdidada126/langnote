最近社区的管奎同学帮助把yalantinglibs 集成到vcpkg中了，现在可以通过vcpkg来安装雅兰亭库了。如何安装安装 vcpkg执行 ./vcpkg install yalantinglibs如果使用cmake, 添加下列脚本:

find_package(yalantinglibs CONFIG REQUIRED)target_link_libraries(main PRIVATE yalantinglibs::yalantinglibs)

yalantinglibs（雅兰亭库）是阿里开源的一套现代C++20高性能基础库合集，主打协程、序列化、RPC、HTTP、日志等核心能力，全头文件/轻量依赖，易用且性能极强。

### 一、核心定位
- 开源地址：https://github.com/alibaba/yalantinglibs
- 核心作者：purecpp社区负责人祁宇（chufeng）
- 核心目标：用极简API+极致性能，帮C++开发者快速构建高性能服务端应用。

### 二、包含的核心子库（常用）
#### 1. struct_pack（序列化，王牌）
- 编译期反射，一行代码完成序列化/反序列化
- 性能：比Protobuf快2–20倍
- 头文件库，无依赖，支持C++17/20

#### 2. coro_rpc（协程RPC，高性能）
- C++20协程实现，易用+超高吞吐
- 回声场景可达2000万+ QPS
- 支持同步/异步、SSL、自定义协议

#### 3. coro_http（协程HTTP）
- C++20协程HTTP服务端/客户端（HTTPS）
- 支持GET/POST、WebSocket、文件上传、断点续传

#### 4. struct_json/struct_xml/struct_yaml
- 基于编译期反射，结构体↔JSON/XML/YAML互转
- 零配置、高性能，比 RapidJSON/JSONcpp 更易用

#### 5. easylog（高性能日志）
- C++17日志库，极简API，支持fmt/std::format流式输出

#### 6. async_simple（协程基础库）
- 阿里自研C++20协程框架，提供Future/Promise、协程调度等基础能力

### 三、关键特性
1. C++20为核心：全面使用协程、模块、编译期反射等新特性。
2. 高性能：序列化/RPC/HTTP均为行业顶尖水平。
3. 易用极简：API设计极简，几乎零学习成本。
4. 跨平台：支持Linux/macOS/Windows。
5. 头文件为主：大部分库为header-only，集成简单。

### 四、vcpkg安装（你提到的）
管奎同学已将其集成到vcpkg，安装命令：
```bash
./vcpkg install yalantinglibs
```

CMake集成：
```cmake
find_package(yalantinglibs CONFIG REQUIRED)
target_link_libraries(main PRIVATE yalantinglibs::yalantinglibs)
```
