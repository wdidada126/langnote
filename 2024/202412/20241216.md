upstream_show 指令是 Nginx 的第三方模块 nginx-upstream-fair 提供的，用于显示当前 Nginx 中 upstream 的状态信息。

要配置 upstream_show 指令，你需要首先确保安装了 nginx-upstream-fair 模块。然后，在 Nginx 配置文件中的 http 块中添加 upstream_show 指令。

以下是一个基本的配置示例：

http {
    # ...
 
    upstream backend {
        server backend1.example.com;
        server backend2.example.com;
    }
 
    server {
        listen 80;
 
        location /upstream_show {
            upstream_show;
        }
    }
}

在上述配置中，我们定义了一个名为 backend 的 upstream 块，并在 server 块中定义了一个 location 块，用于响应对 /upstream_show 的请求。upstream_show; 指令告诉 Nginx 显示关于 backend upstream 的状态信息。

请注意，nginx-upstream-fair 模块可能不在所有系统上可用，你可能需要从源代码编译 Nginx 或从第三方仓库获取该模块。

确保在使用 upstream_show 指令之前已经安装并启用了 nginx-upstream-fair 模块。如果你是从源代码编译 Nginx 并安装了该模块，确保在编译 Nginx 时包含了这个模块。如果你是通过包管理器安装的，确保安装了相应的包。
