在使用 `cmake --build .` 命令构建项目之后，通常会有一个安装步骤来将构建的可执行文件、库和其他资源安装到系统的适当位置。安装步骤的具体方式取决于项目的配置和您的系统环境。

一般来说，大多数 CMake 项目会在其根目录下提供一个 `install` 目标，您可以使用 `cmake --build . --target install` 命令来执行安装。这个命令会告诉 CMake 使用之前生成的构建系统来执行 `install` 目标，从而完成安装过程。

例如，如果您的项目使用 Unix Makefiles 生成器（这是默认情况），那么安装命令可能是这样的：
```bash
cmake --build . --target install
```
如果您的项目使用其他生成器，例如 NMake 或 MSVC，您可能需要相应地调整命令。

请注意，安装步骤可能需要管理员权限，因此您可能需要在命令前加上 `sudo`（在 Unix-like 系统上）或以管理员身份运行命令提示符（在 Windows 上）。

此外，一些项目可能还有其他的安装选项或步骤，例如设置环境变量、创建符号链接等。因此，最好查阅项目的文档或安装说明，以了解适用于您的项目的具体安装步骤。
我给你**一次性讲透、彻底搞懂**：
**`cmake --build . --target install` 到底是什么？和 `make install` 有什么关系、区别？**

你会发现它们**本质是同一个东西**，只是**跨平台包装层**不一样。

---

# 一、先给你终极结论（最关键）
## **`cmake --build . --target install`
## = 跨平台版本的 `make install`**

### 关系：
- **`make install`** = **只适用于 Linux/Mac 的 Makefile 构建系统**
- **`cmake --build . --target install`** = **CMake 统一命令，自动调用底层构建工具（make/ninja/msbuild）去执行 install 目标**

### 作用完全一样：
**把编译好的程序、库、头文件 复制到系统指定安装目录（/usr/local、C:\Program Files 等）**

---

# 二、`--target install` 中的 target 不是可执行程序吗？
## **不是！这里的 `install` 是一个【特殊目标】**

CMake 会**自动生成 3 类 target**：

1. **可执行程序**（你写的）
   `add_executable(main ...)` → target: `main`

2. **库**
   `add_library(mylib ...)` → target: `mylib`

3. **系统内置特殊目标**（CMake 自动生成）
   - `all`（默认，编译所有）
   - `install`（**安装目标**）
   - `clean`（清理）
   - `test`
   - `package`

所以：
## **`install` 是 CMake 自动给你生成的“安装脚本”，不是你的程序！**

---

# 三、`make install` 做什么？
```bash
make install
```
作用：
- 执行 Makefile 里的 `install` 目标
- 把 `make` 编译好的文件**拷贝到系统路径**
- 只适用于 Make 环境

---

# 四、`cmake --build . --target install` 做什么？
```bash
cmake --build . --target install
```
作用：
1. 找到当前目录的构建系统（Makefile / .sln / build.ninja）
2. 自动调用底层工具：
   - Makefile → 调用 `make install`
   - Ninja → 调用 `ninja install`
   - Visual Studio → 调用 `msbuild INSTALL.vcxproj`
3. **统一跨平台安装命令**

---

# 五、最清晰对比（一看就懂）
| 命令 | 作用 | 平台 | 底层调用 |
|---|---|---|---|
| `make install` | 安装编译产物 | Linux/Mac | Make |
| `cmake --build . --target install` | 安装编译产物 | **全平台** | 自动识别 make/ninja/msbuild |

## 一句话：
**`cmake --build` 是跨平台外壳，`make install` 是它在 Linux 下的具体实现。**

---

# 六、`install` 目标靠什么工作？
靠你 CMakeLists.txt 里写的：
```cmake
install(TARGETS myapp
    RUNTIME DESTINATION bin
)

install(FILES mylib.h
    DESTINATION include
)
```
CMake 根据这些指令**自动生成 `install` 目标**。

---

# 七、最常用等价命令（你以后随便用）
## Linux / Mac Makefile
```bash
make install
=
cmake --build . --target install
```

## Linux Ninja
```bash
ninja install
=
cmake --build . --target install
```

## Windows Visual Studio
```bash
msbuild INSTALL.vcxproj
=
cmake --build . --target install
```

2. **`install` 是 CMake 自动生成的系统目标，不是可执行文件**
3. **`cmake --build . --target install` = 跨平台版 `make install`**
4. **功能完全一样：复制编译产物到系统目录**
5. **CMake 命令更强大、全平台通用**
