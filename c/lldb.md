# lldb

`lldb` 是一个由 Clang 项目提供的高性能调试器，它是 LLVM 项目的一部分。`lldb` 是 "LLVM Debugger" 的缩写，它是 GNU `gdb` 调试器的替代品，旨在提供更好的性能、可扩展性和易用性。

`lldb` 提供了以下功能：

1. **表达式求值**：可以在运行时计算和查看变量的值。
2. **断点**：可以在代码中的特定位置设置断点，以便在程序执行到该位置时暂停。
3. **步进/步出/继续**：可以控制程序的执行流程，如单步执行、跳出函数或继续执行。
4. **查看和修改变量**：可以查看和修改程序运行时的变量值。
5. **调用函数**：可以在调试期间调用函数。
6. **堆栈跟踪**：可以查看程序的调用堆栈，了解当前执行的函数和它们的参数。
7. **线程查看和控制**：可以查看和管理多线程程序的线程。
8. **脚本和插件支持**：`lldb` 支持使用 Python 脚本进行扩展，还允许用户编写自己的插件来增强调试器的功能。

与 `gdb` 相比，`lldb` 有以下优势：

* **更好的性能**：`lldb` 在许多情况下都比 `gdb` 更快。
* **更好的 C++ 支持**：由于 `lldb` 是与 Clang 编译器一起开发的，因此它对 C++ 的支持更好。
* **更现代的界面和更好的易用性**：`lldb` 的命令行界面更加现代和直观，使其更易于使用。
* **更强大的脚本和插件支持**：`lldb` 的 Python 脚本和插件支持使其更易于扩展。

要使用 `lldb` 进行调试，通常需要在编译程序时使用 `-g`（或 `-ggdb`）标志来生成调试信息。然后，你可以使用 `lldb` 命令启动调试器，并加载你的程序。一旦程序加载，你就可以设置断点、查看变量、步进代码等。
