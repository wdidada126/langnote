musl是专门为Linux内核设计的C库

wget http://musl.libc.org/releases/musl-latest.tar.gz
tar -xzf musl-latest.tar.gz
cd musl-*
./configure --prefix=/usr/local/musl
make
sudo make install
echo 'export PATH=/usr/local/musl/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

musl中的汇编代码主要用于实现与硬件架构密切相关的底层功能优化，其核心作用包括：

关键性能优化
通过汇编实现字符串操作（如strlen、memcpy）、数学运算等高频调用的基础函数，利用处理器特定指令集（如SIMD）提升执行效率。例如musl的strlen实现通过汇编优化了字节对齐检查和零字节检测逻辑。
系统调用封装
在不同CPU架构（x86/ARM等）中，汇编代码用于直接触发系统调用指令（如x86的syscall或ARM的svc），建立用户态与内核态的桥梁。
线程局部存储(TLS)支持
通过汇编访问架构相关的线程寄存器（如x86的fs/gs段寄存器），实现高效的线程本地变量存取。
启动代码与上下文切换
系统启动阶段的栈初始化、函数调用约定维护（如参数传递规则）以及协程上下文保存/恢复均需汇编实现。
硬件特性适配
针对不同CPU的缓存一致性模型、原子操作指令等特性，汇编代码确保内存屏障和原子变量操作的正确性。

musl的汇编代码通常位于arch/目录下，按架构分类（如x86_64、arm等），其设计强调精简性和可移植性，相比glibc减少了汇编代码量以降低维护成本。
