# c17

https://en.cppreference.com/w/c/17

C17引入了新的库函数和特性，比如带参数的宏指针、泛型以及C11中未包含的一些数学函数。

**C17引入的新特性包括带参数的宏指针、泛型以及C11中未包含的一些数学函数等**。这些特性大大增强了C语言的功能和灵活性，使得程序设计更加高效和易于维护。下面将详细解释这些新特性：

1. **带参数的宏指针**
   - **定义**：带参数的宏指针是一种可以在预处理阶段定义和使用的新型宏，它可以接受参数并在编译时生成对应的代码。
   - **应用**：这种宏常用于生成简单函数的替代实现，例如单行的条件判断或者简单的算术运算。通过这种方式可以优化代码，减少函数调用开销。
2. **泛型选择表达式**
   - **定义**：C11首次引入了_Generic选择表达式，C17在此基础上进行了改进。这个关键字允许在编译时根据类型选择不同的表达式进行求值。
   - **使用场景**：例如，你可以根据传入参数的类型来选择执行不同的代码块。这样，同一个函数或宏能够处理不同类型的数据，提高了代码的复用性和可读性。
3. **数学函数**
   - **新增函数**：C17增加了一些新的数学函数，如立方圆分布函数、扩展幂函数等，这些函数在统计学和工程学计算中有广泛的应用。
   - **实用性**：这些新增的数学函数提供了更精确的计算结果和更广的适用范围，使得科学计算和金融分析等领域的编程更加方便和精确。
4. **改进的Unicode支持**
   - **新增字符类型**：C17引入了char16_t和char32_t这两种新的字符类型，提供了对Unicode的支持。
   - **应用场景**：这使得C语言程序能够更好地处理国际化文本，尤其是在处理多语言环境和文本处理应用中非常有用。
5. **线程局部存储**
   - **定义**：_Thread_local存储类说明符用于声明线程局部变量，这些变量在每个线程中都有一个独立的副本。
   - **用途**：这解决了多线程程序中的并发访问问题，每个线程独立地拥有自己的变量副本，避免了数据竞争和同步的问题。
6. **头文件和标准库函数的改进**
   - **新增函数**：C17增加了一些安全且具有边界意识的字符串和内存操作函数，如strncpy_s、memcpy_s等，这些函数帮助防止缓冲区溢出。
   - **安全性提升**：这些函数替换了传统的不安全函数，使得编写低风险代码变得更加容易和安全。

总的来说，C17标准不仅在语言的核心功能上进行了增强，还通过引入带参数的宏指针、泛型选择表达式以及多种新的数学函数和字符类型，显著提升了C语言的编程能力和应用领域。这些新特性使得开发者能够编写出更安全、更高效、更符合现代编程需求的代码。
