# toad（Python）

Toad 是 Python 生态中最主流、专为金融风控（信用评分卡）打造的一站式开源工具库，核心价值是自动化、标准化、可解释的评分卡全流程开发。

### 一、基本定位
- 全称：TOAD (Tools for One-stop Analytics and Decision)
- 背景：由国内金融风控团队开源（GitHub: amphibian-dev/toad）
- 核心场景：信用评分卡（A/B/C/F卡）、反欺诈、授信审批、贷后监控
- 优势：高度贴合风控业务逻辑、WOE/IV/PSI 原生支持、分箱强、可解释、工业级稳定

### 二、核心功能点（纯文字，可直接给AI IDE）
#### 1. 数据探索与质量检测（EDA）
- 缺失值、唯一值、异常值、数据类型一键检测
- 特征分布、统计量、相关性、共线性分析
- 自动生成数据质量报告

#### 2. 特征分箱（Binning）—— 风控核心
- 支持：决策树分箱、卡方分箱、等频/等距、k-means、自定义分箱
- 自动保证：单调性、坏样本率趋势、业务可解释
- 缺失单独分箱、特殊值合并
- 分箱结果可视化（箱占比 + 坏件率）

#### 3. 特征转换与编码
- WOE 编码（证据权重）：自动计算并转换
- IV 值（信息价值）：一键评估特征预测力
- 标准化、归一化、类别编码

#### 4. 特征筛选
- 按 IV、缺失率、共线性、稳定性 自动过滤
- 逐步回归（Stepwise） 选变量（AIC/BIC）
- 支持正向/反向/双向选择

#### 5. 模型评估与稳定性
- PSI（群体稳定性指数）：特征/模型跨时间稳定性
- KS、AUC、ROC、召回率、精确率、F1
- 混淆矩阵、Lift 曲线、分数分布

#### 6. 评分卡生成与输出
- 逻辑回归 → 标准分数映射（如 300–850 分）
- 自动计算：基准分、刻度、每张卡分数
- 评分卡表导出（变量+分箱+对应分数）
- 支持 PMML 部署

#### 7. 风控专用指标
- 坏样本率（Bad Rate）
- 累计坏样本占比
- 拒绝推断、滚动率、迁徙率分析

### 三、典型风控建模流程（文字流程图）
1. 数据导入 → 数据探查（detect）
2. 清洗：去重/缺失/异常 → 初步特征筛选（quality/select）
3. 分箱（Combiner）→ 调优 → WOE转换
4. 逐步回归选特征 → 逻辑回归建模
5. 模型评估（KS/AUC/PSI）→ 分数校准
6. 生成标准评分卡 → 导出/部署

### 四、与其他库对比（要点）
- vs scorecardpy：toad 分箱更强、逐步回归优化、PSI 更全、更工业级
- vs sklearn：sklearn 通用；toad 原生风控指标（WOE/IV/PSI）+ 分箱 + 评分卡

### 五、一句话总结
Toad = 风控评分卡全生命周期工具箱：从数据清洗 → 分箱 → WOE/IV → 特征筛选 → 建模 → 评估 → 评分卡输出，一行代码覆盖风控核心环节。
