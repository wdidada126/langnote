关于Velocity模板引擎的一些思考总结
https://zhuanlan.zhihu.com/p/151813814
Java Web开发的开源模板引擎很多，很多开源项目在做了集成比如：Velocity, Freemarker等。
模板引擎是为了使用户界面与业务数据（内容）分离而产生的，它可以生成特定格式的文档，用于网站的模板引擎就会生成一个标准的HTML文档。模板引擎不属于特定技术领域，它是跨领域跨平台的概念，在Asp下有模板引擎，在PHP下也有模板引擎，在C#下也有，甚至JavaScript、WinForm开发都会用到模板引擎技术。
简单来说，模板的诞生是为了将显示与数据分离，模板技术多种多样，但其本质是将模板文件和数据通过模板引擎生成最终的HTML代码。模板引擎就是利用正则表达式识别模板标识，并利用数据替换其中的标识符。比如：Hello,<%=name%>数据是{name: '模板引擎'}，那么通过模板引擎解析后，我们希望得到Hello,模板引擎。模板的前半部分是普通字符串，后半部分是模板标识，我们需要将其中的标识符替换为表达式。

模板引擎和流程引擎的主要区别在于它们的设计目标和处理内容不同。

模板引擎的主要应用场景是网页设计。在Web开发的上下文中，模板引擎用于将特定的数据（如动态内容、变量等）嵌入到静态模板中，以生成最终的HTML网页。模板引擎可以预先定义HTML模板，并在模板中预留特定位置以供动态内容填充，从而使得网页设计者和开发者能够更方便地管理和维护网站的前端界面。

流程引擎则是一种更广泛的概念，它可以被用于各种需要自动化处理的工作流程中，不限于Web开发。流程引擎的主要目标是“业务过程的部分或整体在计算机应用环境下的自动化”。它主要解决的是如何自动进行在多个参与者之间的按照预定义规则传递文档、信息或任务的过程，从而实现某个预期的业务目标。

总结来说，模板引擎主要侧重于网页设计和前端界面的自动化生成，而流程引擎则更注重于整个业务过程的自动化执行。这两者在应用领域和使用场景上有明显的区别。

mybatis中set标签没有智能去除sql修改语句的逗号
https://blog.csdn.net/java2min/article/details/103332844
在MyBatis中，<set>标签用于动态生成SQL的UPDATE语句，它可以根据条件选择性地更新字段。然而，<set>标签并不会智能地去除SQL修改语句的逗号，这是因为它是根据条件动态生成SQL语句的，每个字段之间使用逗号分隔。

如果你希望在最后一个字段之后不添加逗号，你可以考虑使用<trim>标签来替代<set>标签。<trim>标签可以去除SQL语句开头和结尾的指定字符，例如逗号。

下面是一个使用<trim>标签的例子：

xml
<update id="updateUser" parameterType="User">  
  UPDATE user  
  <trim prefix="SET" suffixOverrides=",">  
    <if test="name != null">name = #{name},</if>  
    <if test="age != null">age = #{age},</if>  
    <if test="email != null">email = #{email},</if>  
  </trim>  
  WHERE id = #{id}  
</update>
在这个例子中，<trim>标签的suffixOverrides属性设置为逗号，表示要去除SQL语句结尾的逗号。当某个字段满足条件时，它的更新语句会被添加到<trim>标签的内容中，并在最后一个字段之后自动去除逗号。

注意：使用<trim>标签时，要确保至少有一个字段满足条件，否则生成的SQL语句可能会缺少"SET"关键字。
