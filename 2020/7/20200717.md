= 房价跟踪预测系统设计 =

以 Service-oriented 架构 SOA 为核心，以 Full Stack 技术为特点，并融入了当前炙手可热的机器学习 TensorFlow 在实际工程中的运用。系统实现了动态房屋数据采集，房屋信息检索，与最重要的房屋价值预测。 以Service-oriented 架构搭建一个高 Scalability 与 Availability 的全栈系统。在实际构造系统中会使用大量当下流行的技术工具与解决方案，技术栈涉及 Node.js / Express，RPC / REST, RabbitMQ, Web Scraper, Web API, MongoDB, TensorFlow。



整体可以分为4个部份：



\1. 网页前端：主要采用Node.js实现一个动态网站让用户进行搜索，并返回搜索结果与价值预测。前端不处理任何业务逻辑，而是通过 RPC 调用后端服务器 API。

\2. 后端服务器：它是一个用 Python 实现的 API 层，接受来自前端的请求，实时采集数据，读写数据库与消息队列，调用 TensorFlow Serving。

\3. 数据采集器：本质上是一个连续运行的网络爬虫，不断抓取房屋信息并更新数据库。

\4. 机器学习: 包含一个线上预测系统和一个线下训练系统。

Scalability:

\1. load balancing => traffic dispatch

\2. Cache (cache the high-level class objects, instead of db query results), use it as heavily as possible, define your clever keys.

\3. Vertical & horizontal scaling

\4. Master-slave: db replication (“denormalization” and “SQL tuning" index, denormalize right from the beginning and include no more Joins in any database query; Joins will now need to be done in your application code. -> feel like a NoSQL)

\5. Sharding + partitioning

\6. NoSQL database

\7. Async (message queue)  - modern design

  \- Dynamic content => static content: 秒杀系统，大型促销，CDN, Apache traffic server

  \- Async message queue: RabbitMQ, ActiveMQ, Redis list (low-pri, time-consuming tasks -> async queue)

= Miscellaneous =

\1. Pragmatism: use commodity, open source software, not re-invent the rolls

\2. Rest API design

\3. Loose coupling: RPC, service oriented architecture(SOA), queue & async processing (message queue)

\4. Shadow release, dark launch (% progressive user open up)
