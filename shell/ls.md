# ls

先直接回答你当前问题：`ls -la` 与 `ls -lh` 的唯一区别是：

- `ls -la`：  
  - `-l`：长格式（权限、所有者、大小、时间、文件名）  
  - `-a`：显示所有文件（含 `.` 开头的隐藏文件）  
  - 大小默认用字节（bytes）显示（你截图里的 `1.3K`、`41M` 是你的终端/别名美化过的，原生 `ls -la` 只显示纯数字，如 `1331`、`42991616`）

- `ls -lh`：  
  - `-l`：长格式  
  - `-h`：human-readable，自动换算成 K/M/G/T  
  - 大小显示为易读单位（K/M/G），不再是纯字节数

### 一句话总结
- `ls -la` = 长格式 + 显示隐藏文件 + 字节大小（原生纯数字）
- `ls -lh` = 长格式 + 显示隐藏文件 + 自动 K/M/G 单位

你截图里看到 `1.3K`、`41M`，是因为你的 shell（zsh/bash）里有类似：
```bash
alias ls='ls -h'
```
所以你敲 `ls -la` 实际是 `ls -la -h`，已经带了人类可读单位。

`ls -lrt` 是 Linux 和类 Unix 系统中 `ls` 命令的一个常用组合选项，下面分别解释 `l`、`r`、`t` 这三个选项的作用：

### `-l` 选项
- 作用：以长格式显示文件和目录的详细信息。使用该选项后，`ls` 命令会输出每一个文件或目录的权限、硬链接数、所有者、所属组、文件大小、最后修改时间以及文件名等信息。
- 示例：执行 `ls -l` 命令后，输出可能如下：
```plaintext
total 24
-rw-r--r-- 1 user user  4096 Mar 30 10:00 file1.txt
drwxr-xr-x 2 user user  4096 Mar 30 10:30 directory1
-rwxr-xr-x 1 user user  8192 Mar 30 11:00 script.sh
```
这里的每一行代表一个文件或目录，各列信息依次为：文件权限、硬链接数、所有者、所属组、文件大小、最后修改时间、文件名。

### `-r` 选项
- 作用：以逆序（反向）显示文件和目录列表。通常情况下，`ls` 命令会按照字母顺序或其他排序规则（如按时间排序）正序显示结果，而使用 `-r` 选项后，显示顺序会反转。
- 示例：假设目录中有文件 `a.txt`、`b.txt`、`c.txt`，正常执行 `ls` 会按字母顺序显示为 `a.txt b.txt c.txt`，而执行 `ls -r` 则会显示为 `c.txt b.txt a.txt`。

### `-t` 选项
- 作用：根据文件和目录的最后修改时间进行排序，最新修改的文件或目录会排在前面。如果不使用 `-t` 选项，`ls` 命令默认按字母顺序排序。
- 示例：假设有三个文件，`file1.txt` 是昨天修改的，`file2.txt` 是今天上午修改的，`file3.txt` 是今天下午修改的，执行 `ls -t` 命令后，显示顺序会是 `file3.txt file2.txt file1.txt`。

### `-lrt` 组合选项
- 作用：将这三个选项组合使用时，`ls -lrt` 会以长格式显示文件和目录的详细信息，并根据最后修改时间进行排序，不过是按照逆序排列，即最旧的文件或目录会排在最前面。
- 示例：执行 `ls -lrt` 命令后，会看到按时间从旧到新排列的文件和目录详细信息列表。

综上所述，`ls -lrt` 是一个非常实用的命令组合，尤其在需要查看文件历史修改情况时很有帮助。 

ls -lt 和 ls -lr 的主要区别在于排序方式：
ls -lt 按修改时间倒序排列，最新修改的文件显示在最前面。
ls -lr 按文件名倒序排列，从Z到A、从9到0的顺序显示文件。
两者的共同点是都使用 -l 参数显示详细信息，区别仅在于排序方式。-t 按时间排序，-r 表示反向排序。如果需要按时间倒序查看文件，ls -lt 是最常用的组合。
