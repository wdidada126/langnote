# cum

如软件开发者或软件最终用户希望通过更直观、更快捷的方式使用CodeMeter通用支持工具（cmu）,则可选择基于命令行的 CodeMeter 通用支持工具 (cmu)。
常用cmu命令行工具：
Windows:调用目录 %\Program Files%\CodeMeter\Runtime\bin，使用命令 cmu[32].exe 。
Linux：调用目录usr/bin， 使用命令 cmu。
Mac OS：调用目录usr/bin， 使用命令 cmu。

1. 查询当前Runtime 版本、本地许可信息、网络许可等信息
2. 添加、删除、清除许可服务器IP
3. 执行认证时间更新
4. 导入许可证请求和更新文件（环境文件和更新文件，*.WibuRaC 和 *.WibuRaU）
5. 转换加密锁驱动模式
6. 创建日志文件
更多cmu命令可通过cmu32.exe /? 命令查询。
