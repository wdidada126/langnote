Podman
定位：Podman 是一个基于 libpod 库的容器引擎，用于管理容器和容器镜像。
功能：Podman 提供了类似 Docker 的容器化解决方案，允许用户创建、运行和管理容器。
优势：与 Docker 类似的命令行接口、无需守护进程、Rootless 模式支持、可与 Kubernetes 集成等。
应用场景：适用于需要容器化的应用程序部署和管理，特别是在无需 Root 权限的场景下使用。
