# rjvm

https://github.com/andreabergia/rjvm

This project is an attempt to write a minimal JVM 7 using Rust.
this is a hobby project, built for fun and for learning purposes.


git clone https://github.com/andreabergia/rjvm.git
cd rjvm
rustup set auto-self-update disable
rustup toolchain install stable --profile minimal
just build test
just lint
