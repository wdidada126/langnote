# jsr166

并发
JSR 166: Concurrency Utilities

https://jcp.org/en/jsr/detail?id=166

https://jcp.org/aboutJava/communityprocess/final/jsr166/index.html

第二部分：规范提案
2.1 规范描述
本JSR目标与JDK1.2集合包类似：
标准化一个简单可扩展的框架，将常用工具组织成易于用户学习和开发者维护的精简包
提供高质量实现
该包将包含适用于多种编程风格和应用场景的接口与类，包括：
原子变量
特殊用途的锁、屏障、信号量和条件变量
为多线程设计的队列及相关集合
线程池和定制化执行框架
我们还将研究核心语言和库中的相关支持。
（注：这与J2EE中使用的事务性并发控制框架完全不同，但可用于构建此类框架）
2.2 目标Java平台
J2SE
2.3 解决的需求
基础的线程原语（如同步块、Object.wait/notify）无法满足许多编程需求，导致开发者不得不自行实现高层并发工具，造成大量重复劳动。这些工具往往存在正确性或性能问题。标准化并发工具将简化多线程应用开发并提升质量。
2.4 现有规范的不足
当前开发者只能使用Java语言自带的并发控制结构，这些结构对某些应用过于底层，对另一些应用则功能不足。
2.5 技术基础
大部分实现将基于Java底层构造，但需要关键的JVM/语言增强来保证原子性和监视器语义的正确高效。
2.6 建议API包名
java.util.concurrent
2.7 平台依赖性
仅间接相关：不同平台的JVM可能对某些结构有差异化优化能力。
