# String

String a = "abc";
String s1 = "a";
String s2 = "b";
String s3 = "c";
System.out.println(a == "a" + "b" + "c"); // true
System.out.println(a == s1 + s2 + s3); // false
System.out.println(a == "ab" + "c"); // true

在这个示例中，我们首先定义了一个字符串常量 a = "abc"，然后分别使用字符串常量和变量进行拼接，并使用 == 运算符进行比较。第一个比较表达式中的所有操作数都是常量，因此编译器会在编译期间进行拼接，生成一个新的字符串常量，可以使用 == 运算符进行比较。第二个比较表达式中包含了变量，因此无法在编译期间确定结果，需要在运行时进行拼接，生成一个新的字符串对象，不能使用 == 运算符进行比较。第三个比较表达式中的所有操作数都是常量，因此编译器会在编译期间进行拼接，生成一个新的字符串常量，可以使用 == 运算符进行比较。

需要注意的是，为了避免这种不确定性，应该尽量使用 equals() 方法进行字符串比较，而不是 == 运算符。equals() 方法比较的是字符串内容是否相等，而 == 运算符比较的是两个字符串对象的引用是否相等。
