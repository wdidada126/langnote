# automaton

https://github.com/cs-au-dk/dk.brics.automaton

该库是一个 Java 实现的 有限状态自动机（DFA/NFA）库，支持 Unicode 字符集和正则表达式操作（包括交集、补集等非标准操作）。它的特点是速度快、体积小，并且实现了真正的无限制正则操作。

git clone https://github.com/cs-au-dk/dk.brics.automaton.git automaton
cd automaton
mvn clean package
ls target/
