Source Insight常用快捷键
1.Ctrl + 鼠标单击 进入定义.
2.Alt + F12可以切换，让字符宽度变得一致，或者是大小不同地显示。
3.Shift + F8 标亮文本中光标所在的单词。
4.Ctrl + G (或者F5) 跳转到某一行。
5.Ctrl + O 搜索文件，找到回车打开，找不到ESC退出
6.Alt + G (或者F7) 打开Symbol Window.
7.Alt +, 后退；Alt+.前进.
8.Ctrl + F 查找关键字。

Source Insight不仅是一个强大的代码查看工具，它同样支持对代码的编辑功能。具体来说，Source Insight是一个面向项目开发的程序编辑器和代码浏览器，它拥有内置的对多种编程语言（如C/C++、C#、Java等）的分析能力，能在工作的同时动态维护它自己的符号数据库，并自动显示有用的上下文信息。这些功能使得Source Insight在软件开发领域得到了广泛应用。

以下是Source Insight在编辑代码方面的几个关键特点：

代码编辑：用户可以直接在Source Insight中打开、查看和编辑代码文件。它提供了基本的文本编辑功能，如查找和替换、拼写检查、撤销和重做等。
代码分析：Source Insight能分析源代码，并在用户需要时提供代码的上下文信息，如变量声明、函数定义等。这有助于用户更好地理解代码结构和逻辑。
项目支持：Source Insight支持项目管理，用户可以创建项目来组织和管理相关的代码文件。这使得在大型项目中查找和编辑代码变得更加容易。
快捷键和自定义：Source Insight支持多种快捷键自定义，用户可以根据自己的习惯来设置快捷键，提高编辑效率。
代码审查和格式化：Source Insight还支持代码审查和代码格式化功能，有助于保持代码风格的一致性和提高代码质量。
综上所述，Source Insight不仅可以查看代码，还具备强大的代码编辑功能。它是一款非常适合软件开发人员使用的代码编辑器和浏览器。
