# CSE365 学习要点提纲（骨架）

> 按模块/讲整理 3–5 条要点；不记录具体 challenge 题解，只沉淀概念与通用方法。

## L1 Linux 命令行与程序滥用
- shell 是程序组合的攻击面：管道、重定向、通配符皆可被滥用。
- 掌握 strace/ltrace、ps、文件描述符视角观察程序行为。
- 「程序误用」是第一课：不挖 bug，先用设计行为达成非预期目标。
- 养成最小环境习惯：专用用户、临时容器内实验。

## L2 权限提升与 setuid
- setuid 位使程序以属主运行：错误实现 = 任意提权入口。
- effective/real uid 差异与 `seteuid/geteuid` 检查遗漏的经典事故。
- 环境变量、当前目录会进入特权程序的信任链。
- 通用方法：先枚举攻击面（suid 二进制、sudo -l、计划任务）。

## L3 劫持类攻击（路径/库/环境变量）
- `PATH` 劫持、相对路径调用漏洞程序的风险。
- `LD_PRELOAD`/LD_LIBRARY_PATH 注入共享库（非 suid 场景）。
- shellcode 之前奏：让别人的程序执行你的代码的多种通道。
- 防御面：secure_execution_mode、绝对路径、最小权限。

## L4 Web 基础：HTTP
- 请求/响应/头部/状态机的语义，是 Web 安全一切讨论的地基。
- Cookie 与无状态 HTTP 的会话绑定；认证头（Basic/Bearer）形态。
- HTTPS = HTTP + TLS：证书、SNI、代理可见性差异。
- 工具：curl/telnet 手搓报文理解抽象。

## L5 服务器与拦截代理
- 用代理（Burp/ZAP）看见并篡改「浏览器行为」。
- 服务端校验 vs 客户端校验：信任边界第一原则。
- HTTP 方法、隐藏参数、目录枚举等信息收集流程。
- 实验环境：本地起多服务 + mitm 拓扑。

## L6 汇编：寄存器与数据
- x86-64 通用寄存器、栈指针、指令集最小闭环（mov/add/call/jmp）。
- 用 gdb/pwndbg 单步验证「C 代码 → 机器行为」映射。
- 系统调用是用户态到内核的 ABI 边界。
- 反汇编视角读 ELF：section/symbol 与安全相关段。

## L7 汇编：内存与控制流
- 栈帧、调用约定、返回地址：为 CSE466 溢出模块埋点。
- 条件跳转与整数比较标志位；控制流即攻击目标。
- shellcode 的语言学：可注入字节序列的约束。
- 读别人 shellcode 练「汇编直觉」的最佳材料（通用方法层面）。

## L8 密码学 I：对称与哈希
- 混淆 ≠ 加密；ECB 模式的数据模式泄露。
- 哈希的三性质与「可加盐性」；口令哈希需慢函数。
- 随机数源（CSPRNG）错误是现实高频漏洞。
- 用 Python 复现加密误用模式而非攻击特定站点。

## L9 密码学 II：非对称与信任
- 公钥体系解决分发问题；签名保证来源。
- 中间人攻击为何依赖「信任」而非「算法缺陷」。
- PGP/TLS 信任模型对比；密钥指纹与 TOFU。
- 现实翻车案例：弱随机、重用 nonce（概念级）。

## L10 Web 安全 I：命令注入与 XSS
- 注入本质：数据被当作代码解释——跨 SQL/命令/HTML 统一视角。
- 命令注入：拼接 shell 字符串的代价；参数化调用防御。
- XSS 载荷的上下文差异（属性/JS/URL）与编码策略。
- 防御层：输出编码、CSP、HttpOnly 的组合拳。

## L11 Web 安全 II：SQL 注入
- 联合/布尔盲注/报错注（方法概念层面）；登录框万能 payload 的原理。
- 参数化查询 + ORM 正确用法是根治手段。
- 注入链组合：从读数据到文件读写/命令执行的权限跳板。
- 合法实验：本地 DVWA/Juice Shop 靶场练习。

## L12 综合与期末（CTF 式）
- 多知识域串联：枚举 → 初探 → 链式利用 → 后渗透最小动作。
- 方法论沉淀：信息收集占七成工作量。
- 时间管理与卡关策略：30 分钟无进展即查资料/换题。
- 与 CSE466 衔接：从「误用与注入」进入「内存破坏与逆向」。
