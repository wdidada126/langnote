# MIT 6.858 讲义要点提纲（骨架）

> 每讲 3–5 条要点级提纲，正文笔记后续按讲填充。

## L1 导入：原则与威胁模型
- 端到端安全观：机制（mechanism）与策略（policy）分离。
- 混淆式安全（security by obscurity）为何不成立；攻击者全知假设。
- Zoobar 靶系统结构预览：Lab 地图与评分规则。

## L2 Web 攻击 I
- XSS 三类（反射/存储/DOM）在 Zoobar 上的真实演练。
- CSRF：浏览器以凭证为中心的自动行为即攻击面。
- 会话固定与 cookie 属性；HTTPOnly/SameSite 的边界。
- 攻击链思维：把低危原语串成账户接管。

## L3 Web 防御与同源策略
- 同源策略是数据级隔离承重墙；CORS 的受控放行。
- 输出编码 vs CSP：从「转义一切」到「声明可执行源」。
- SQL 注入与参数化；最小权限 DB 账号。
- Lab4 预告：浏览器端防线（内容嗅探、帧选项）。

## L4 浏览器安全
- 站点隔离（site isolation）与渲染进程沙箱演进。
- 扩展与混合内容的信任漏洞；DOM clobbering 等怪技。
- 浏览器作为 TCB：攻击面从服务器转移到客户端。

## L5 缓冲区溢出与 shellcode
- x86-64 栈帧、参数传递与 shellcode 编写约束（无 \x00、位置无关）。
- 从注入代码到面向已有代码（ret2libc）的范式转变。
- 信息泄露原语（格式化字符串/越界读）是溢出的前菜。
- Lab1 主线：在 Zoobar 服务上完整走通利用链。

## L6 利用与缓解的军备竞赛
- ROP：gadget 搜索、调用约定适配、pivot 技巧。
- ASLR/canary/DEP/CFI 逐层抬高利用成本及各自绕过。
- 现代靶场趋势：类型混淆与堆元数据攻击替代线性溢出。
- 阅读要点：攻击论文如何构造「不可能」的泄露。

## L7 语言防护与沙箱
- SFI 思想：指令级二分箱 + 每次内存访问的掩码检查（Wahbe 1993）。
- NaCl：软件沙箱跑原生码，PNaCl/受限模块的工程化。
- 对比硬件方案（seccomp、沙箱进程、虚拟化）的性能-隔离曲线。
- 设计题：给浏览器插件/解释器选沙箱时的判据。

## L8 密钥管理与 TLS
- 密钥生命周期：生成、存储（KMS/HSM）、轮换、吊销。
- TLS 中「密码学正确 ≠ 协议安全」：降级与延展案例。
- PKI 信任锚的现实脆弱史（错误签发的 CA）。
- 本课视角：把 6.1600 的概念落到系统设计检查单。

## L9 认证与 SSO
- Kerberos 票据流复盘；时间戳与重放的攻防。
- SSO/OAuth 场景中的令牌混淆与受众（audience）缺失问题。
- 「谁信任谁」的图：把认证协议画成主体-密钥矩阵。

## L10 特权分离
- 把大单体拆成最小权限组件：前端解析器不持密钥、后端不碰网络。
- 组件间通信的鉴权与降级故障域设计。
- Lab2 主线：Zoobar 拆分加固，溢出组件拿不到全局权限。
- 反思：分离引入的复杂度 vs 攻破半径的缩小。

## L11 访问控制与信息流
- ACL/能力表对比；最小公共化在共享系统中的应用。
- 非干扰（noninterference）：低安全级用户观察不到高安全级活动。
- Bell-LaPadulla（机密性）与 Biba（完整性）双模型。
- 静态信息流标签传播的直觉（为 L13 铺垫）。

## L12 能力系统与标签系统
- 能力（capability）作为可传播的引用权限：KeyKOS/Capsicum 脉络。
- SELinux/Flask 标签强制访问控制：策略与机制彻底分离的样本。
- 现实系统采用率低的原因：可用性与迁移成本。

## L13 动态污点追踪
- 污点语义：source（不可信输入）、sink（危险操作）、传播规则。
- PolyBike 式指令粒度追踪与过度污点（over-tainting）问题。
- 用污点找真实漏洞的模式：注入类、越权类。
- 工具地图：Archer/BitBlaze、Dynamic Taint 在现代 fuzzer 中的角色。

## L14 符号执行
- 把输入变成符号值：路径条件 + SMT 求解遍历分支。
- 路径爆炸与混合执行（concolic）：具体值引导 + 符号探索。
- EXE/KLEE 到 angr/SymCC 的谱系；对 Python 动态语言的新难题。
- Lab3 主线：为 Zoobar 写符号执行式 bug 查找器。

## L15 Fuzzing
- 随机 → 覆盖引导（遗传算法式语料库调度）。
- AFL++ 三路：fork server、共享内存、插桩反馈。
- 结构化协议 fuzzing（HFuzz/AFL++ dictionary）与 grammar。
- 内核 fuzzing：Syzkaller 的 syzlang 描述系统调用接口。

## L16 推测执行攻击
- 侧信道 + 投机乱序 = 跨特权读取（Meltdown）/ 跨分支预测（Spectre）。
- 屏障式缓解（retpoline、LFENCE、STIBP）的性能代价。
- 「时间即信道」：安全边界必须覆盖微结构状态。

## L17 安全文件系统（SecFS 主题）
- 威胁模型：完全不可信的远端存储服务器。
- SUNDR 方案：版本化 + 客户端校验，检测分叉（fork）攻击；单调性约束。
- 机密性与完整性之外：可用性（拒绝服务）为何难防。
- Final Project 主线：SecFS 设计-实现-报告。

## L18 侧信道与 enclave
- 缓存 Flush+Reload/Prime+Probe 家族；密钥提取实例。
- SGX enclave：隔离谁、attestation 证明什么、又不证明什么。
- enclave 内部仍泄露：页表与微架构面。

## L19 软件验证
- 形式化规格 → 证明实现满足性质：seL4/CertiKOS 路线。
- 验证成本与可信度收益的边界：验证到哪一层为止。
- 与符号执行/fuzzing 的互补关系（测试是部分证明）。

## L20 隐私与总结
- DP 再次出现：数据收集即攻击面的统一视角。
- 全课主线收束：利用（破）→ 分析（找）→ 构造（防）三段式。
- 攻击论文阅读法：威胁模型、原语组合、评估诚实度。
