# MIT 6.1600 讲义要点提纲（骨架）

> 每讲 3–5 条要点级提纲，正文笔记后续按讲填充。

## L1 导入：安全目标与威胁模型
- 安全性 = 在明确攻击者模型下可陈述、可验证的性质，而非感觉。
- CIA 三元组 + 真实性；攻击者能力分级（被动窃听到主动注入）。
- Kerckhoffs 原则：系统安全只依赖密钥，不依赖算法保密。
- 全课方法：为每个目标定义「安全游戏」式攻防交互。

## L2 认证基础：口令
- 口令空间熵决定离线破解成本；撞库与彩虹表实践。
- 服务端存储：加盐慢哈希（bcrypt/Argon2）取代直接哈希。
- 单因素认证的天花板 → 引出多因素与协议认证。

## L3 消息完整性与哈希
- 完整性目标的两种实现：对称 MAC vs 哈希+密钥的正确姿势。
- 哈希安全三性质：原像、第二原像、抗碰撞；MD5/SHA-1 的现状。
- Merkle-Damgård 长度扩展攻击 → HMAC 的构造动机。

## L4 认证协议
- 挑战-应答防重放；nonces 与时钟的作用。
- Needham-Schroeder _public-key 协议被 Lowe 中间人攻破：细节即魔鬼。
- 协议分析需要形式化模型：假设、消息组件、主体信念。
- 与 L2 呼应：实体认证 vs 消息认证的区别。

## L5 语义安全与对称加密
- 确定性加密泄露等值关系：IND-CPA 游戏定义「安全」。
- ECB/CBC/CTR 模式与误用案例；IV 唯一性 vs 秘密性。
- 流密码与两一次一密（GGM）构造视角（概念级）。

## L6 Diffie-Hellman 密钥交换
- 单向函数与离散对数直觉；乘法群上的 DH。
- 被动安全易得，主动（MITM）安全需认证公钥 → 引出演习题「MITM 攻击 DH」。
- 临时 DH 提供前向安全（DHE）的工程意义。

## L7 公钥加密
- 公钥加密定义与 IND-CPA；教科书 RSA 的确定性缺陷。
- OAEP 填充、混合加密范式（KEM/DEM）。
- RSA 数学回顾与椭圆曲线密钥尺寸对比。

## L8 数字签名
- 签名 = 私钥验签方向的加密类比；EUF-CMA 安全目标。
- hash-then-sign 范式与其局限（多消息攻击、可延展性）。
- 与 MAC 的信任差异：签名支持不可否认。

## L9 TLS 与 PKI
- TLS 握手组件：密钥协商、认证、记录层 AEAD。
- TLS 1.2 vs 1.3：回合数、降级保护、前向安全默认化。
- PKI：CA 层级、证书验证、CT 日志与「信任锚的脆弱性」。
- 真实事故复盘：DigiNotar、错误签发。

## L10 OS 与平台安全基础
- 隔离、特权级、最小特权、完全中介在 OS 层的落地。
- TOCTOU 与权限检查时机问题。
- 从 TCB（可信计算基）视角重新划分系统边界。

## L11 硬件信任与 enclave
- 信任根：TPM、安全启动链。
- SGX enclave 模型：谁隔离谁、attestation 的作用。
- enclave 侧信道（页表/缓存类攻击）说明「无银弹」。

## L12 访问控制与文件系统
- DAC/MAC/RBAC/能力表机制对照（与 CS161 L3 对齐但更模型化）。
- 文件系统作为安全机制：所有权、ACL、setuid 的危险。
- 完整性模型：Biba 与 Take-Grant 图直觉。

## L13 内存错误与利用
- 越界/UAF/类型混淆的攻击分类学。
- 一条完整利用链解剖：泄露 → 覆写 → 控制流劫持。
- 为什么「内存安全」是可证明的语言级性质。

## L14 漏洞挖掘
- Fuzzing：生成-反馈循环，覆盖率引导（AFL 思路）。
- 程序分析：污点追踪与符号执行的角色。
- 漏洞库（CVE）与根因归类的统计直觉。

## L15 缓解与防御
- DEP/CFI：把控制流劫持从「容易」推回「昂贵」。
- 编译器加固与内存安全语言迁移策略。
- 防御 vs 攻击的成本不对称分析。

## L16 人与终端用户
- 可用性失败即安全失败：错误默认值与警告疲劳。
- 钓鱼/水坑攻击的社会工程机制；红队实验案例。
- 浏览器作为人机信任边界的 UI 安全性。

## L17 隐私
- 匿名通信：洋葱路由信任模型（Chaum 混币网络直觉）。
- 差分隐私：把「从聚合数据推断个体」量化为 ε。
- 元数据即泄露：威胁模型的又一次扩张。

## L18 群体与课程总结
- 系统级视角：安全是生态问题（供应链、激励、标准）。
- 五模块串讲：认证 → 传输 → 平台 → 软件 → 人。
- 后续路径：6.858（系统攻防）、6.875/理论密码深潜、SEED Labs 实验。
