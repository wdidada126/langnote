# L18 无监督学习 III：PCA/ICA、谱聚类、异常检测

> Notes Ch.8 + Lecture Notes（PCA/ICA/Anomaly Detection 老讲义）· 前置：L08, L16-L17 · 对应项目：projects/p07_pca（含 ICA/谱聚类扩展）

## 1. 数学推导要点

### 1.1 PCA 复习：第三种推导——最大似然
- 概率 PCA（Tipping & Bishop）：`x = Wz + ε, z~N(0,I), ε~N(0,σ²I)` → `Cov(x) = WW^T + σ²I`。
- 极大似然解：`W 的列 = 前 k 大特征向量 × √(λ_j − σ²)`，噪声 `σ² = 平均(λ_{k+1..n})`——
  **特征分解从"几何最优"升级为"模型 MLE"**，与 L17 因子分析同一族谱（Φ 退化为各向同性）。
- 判 k：特征值缺口（`λ_k ≫ λ_{k+1}`，Mardia 检验式直觉）或解释方差曲线拐点。

### 1.2 ICA：从去相关到独立
- 动机：PCA 只给不相关（二阶），独立需要所有阶矩。盲源分离"鸡尾酒会"：`x = As`，求 W≈A⁻¹。
- 目标：最大化各源的非高斯性——峰度（`E[u⁴]−3` 易受离群点支配）→ 换成**负熵近似**：
  `J(u) ≈ H(u_gauss) − H(u)`，用非线性的对数似然型泛函（`log cosh`、`−exp(−u²/2)`）。
- FastICA 不动点迭代：`w ← E[x g(w^T x)] − E[g'(w^T x)] w` 后正交化（对称/逐列两版）。
- 与 PCA 的关系：先白化（PCA 的副作用，L08 §1.3）；对高斯源 ICA 无解——
  **独立 + 高斯 ⟹ 任何旋转都独立，方向不可辨识**（这是讲义反复强调的 negentropy 论证）。

### 1.3 谱聚类：图拉普拉斯的代数
- 步骤：相似度图 `W_ij = exp(−‖x_i−x_j‖²/(2σ²))` → 度 `D = diag(W·1)` → 归一化拉普拉斯
  `L_sym = I − D^{-1/2} W D^{-1/2}` → 取前 k 小特征向量按行组成 Y → 行归一化 → k-means。
- 理论：最小化归一化割（Ncut）是 `min Σ cut(A,B)/vol` 的松弛，而
  `x^T L x = ½ Σ_ij W_ij (u_i−u_j)²`、约束 `y^T D y = 1, y ⊥ D1` 的最优解恰是 Fiedler 向量——
  组合优化 → 连续特征问题的标准松弛（Rayleigh-Ritz 再出场，L08）。
- σ 与 k 的选择：σ 控制图的粒连度（连通分量测试），k 同 k-means 难题。
- 为什么比 k-means 强：能沿流形"走窄桥"切开非凸簇——代价是 O(m³) 特征分解与 σ 的脆弱性。

### 1.4 异常检测（高斯模型 + 阈值）
- 逐维拟合 `N(μ_j, σ_j²)`，密度 `p(x) = Π_j N(x_j; μ_j, σ_j²)`（独立性假设，朴素贝叶斯的无监督镜像），
  `p(x) < ε` 判异常；ε 由验证集（含标注异常）按所需 Precision/Recall 选。
- 多元高斯版：马氏距离 `(x−μ)^T Σ⁻¹ (x−μ) > r²` 更准但协方差估计易崩（L05 陷阱 4 的熟人）。
- 与监督法的分野：异常极少（0.1%）→ 评估不能用准确率（L03 陷阱 2 同款），用 P-R/F1@top-k；
  特征工程在此决定生死："异常应让某单维密度变得极低"的设计准则。

## 2. 直觉与常见陷阱
- 直觉四连：PCA 找方向（二阶），ICA 找源头（高阶），谱聚类找桥（图割），异常检测找尾部（密度）。
- 陷阱 1：ICA 的排序与符号不可辨识：输出源没有"第 1 个"，正负号随机——比较算法性能要先匹配（p07 用相关矩阵对齐）。
- 陷阱 2：谱聚类在 σ 过小/过大时分别退化为"图碎成沙"与"完全图 = k-means"；写邻接矩阵时用稀疏存储防内存爆炸。
- 陷阱 3：异常检测用高维联合密度：维度灾难下所有点都"边缘"，逐维乘积 + 人工特征筛选才是可操作方案。
- 陷阱 4：把 PCA 降维后的距离当原空间语义：丢掉的小特征值方向可能正是异常所在（异常检测反而常在残差空间做，MLOps 里的 MSPC 传统）。
