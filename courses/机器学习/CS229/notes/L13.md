# L13 神经网络基础：前馈、反向传播、激活与损失

> Notes Ch.7 §7.1-7.3 · 前置：L02-L04（MLE/优化），L12（函数空间优化视角）· 对应项目：projects/p05 之外的 NN 迷你实验并入 p01 框架（可选扩展）/ 推荐配合 CS231n 作业

## 1. 数学推导要点

### 1.1 前馈与记号
- 逐层：`z^(l) = W^(l) a^(l−1) + b^(l)`，`a^(l) = f(z^(l))`；`a^(0)=x`，输出 `h_θ(x)=a^(L)`。
- 参数 θ = 所有 W, b；损失 `J(θ) = (1/m) Σ_i L(h(x_i), y_i)`。
- 激活函数谱系：sigmoid（饱和、梯度≈0）、tanh（零心）、ReLU `max(0,z)`（非饱和、便宜、死神经元风险）、
  leaky ReLU/GELU（现代默认）。
- 万能逼近定理：单隐层 + 有限神经元可在紧集上逼近任意连续函数——**存在性 ≠ 可学性 ≠ 高效**，
  这是 L10 陷阱 4 的神经网络版。

### 1.2 反向传播 = 链式法则的动态规划
- 目标：`δ_j^(l) = ∂J/∂z_j^(l)`。输出层 δ 由损失决定，例如 softmax+交叉熵：`δ^(L) = a^(L) − y`（L04 结论原样复用）。
- 反向递推：`δ^(l) = ((W^(l+1))^T δ^(l+1)) ⊙ f'(z^(l))`；
  `∂J/∂W^(l) = δ^(l) (a^(l−1))^T`，`∂J/∂b^(l) = δ^(l)`。
- 计算图视角：反向模式 AD 在"输出少、输入多"时优于前向模式（Jacobian 链的乘法结合顺序）——
  这正是"损失是标量、参数是百万维"的 regime。
- 手推练习金标准：两层 tanh + MSE 全尺寸推一遍，与 p01 框架的数值梯度检查（中心差分，`‖g_num−g_ana‖/‖g‖ < 1e-7`）对照。

### 1.3 训练配方（承 L02 优化家族）
- 初始化：sigmoid/tanh 用 Xavier `Var = 2/(n_in+n_out)`；ReLU 用 He `Var = 2/n_in`——
  动机：前向激活方差与反向梯度方差逐层守恒（推导只需两层方差传播等式）。
- 优化器：mini-batch SGD + momentum `v := βv + g; θ := θ − αv`；
  RMSProp `s := βs + g²; Δθ = α g/√(s+ε)`；Adam = momentum + RMSProp + 偏差修正。
- 归一化家族：BatchNorm（mini-batch 内按特征归一 + γ/β 仿射，训练/推断两套统计量）；
  LayerNorm（样本内跨特征，序列模型标配——为 L15 Transformer 埋线）。
- 正则化：权重衰减（L2，接 L09 结构风险）、dropout（训练时 Bernoulli 掩码 + 推断期缩放/平均，
  解释为隐式 bagging——L12 方差语言的回响）。

## 2. 直觉与常见陷阱
- 直觉：网络 = 可微的流水线特征工程；反向传播 = "谁对错误负责多少"的信用分配记账法。
- 陷阱 1：梯度消失/爆炸：sigmoid×深度的乘积 `∏ f' W` 指数衰减/膨胀——解法是其历史主线
  （残差、归一化、ReLU、初始化、梯度裁剪）。
- 陷阱 2：BN 忘记 `eval` 模式切换 → 推断结果随 batch 抖动；dropout 推断期忘关 → 输出系统性偏小/方差虚高。
- 陷阱 3：学习率与批量大小联动：大 batch 要升 lr（线性缩放经验律），Adam 换 SGD 时 lr 差 2-3 个数量级。
- 陷阱 4：loss 不降先看梯度：先确认 `‖∇‖≈0`（优化到位）还是 `‖∇‖` 有限但走不动（lr/条件数）或是数据 bug（标签错位）。
- 陷阱 5：只监控 loss 不监控指标：交叉熵与准确率在类不平衡下可以各说各话。
