# L15 CNN 与序列模型：卷积、RNN/LSTM、Transformer 概览

> Notes Ch.7 + CS231n/CS224n 延伸 · 前置：L13-L14 · 对应项目：无（numpy 复现建议做 CS231n A1/A2；本讲以概念对照为主）

## 1. 数学/结构要点

### 1.1 卷积：局部性 + 权重共享 + 平移等变
- 单层：输出通道 c 在位置 (i,j) 的打分 `Σ_{k,l} W_c[k,l] · x[i+k−P, j+l−P]`（padding P），
  参数量与图像尺寸无关，仅 `k²·C_in·C_out`（对比全连接的灾难）。
- 反向：卷积的反向 = 相关运算（滤波器旋转 180°）对误差图 δ 做"全卷积反传"；
  对步幅/分组只需调整索引——CS231n A2 的 `conv_backward` 是最佳习题。
- 感受野（receptive field）逐层乘积增长：深层小卷积堆叠（VGG）用更少参数换更大非线性。
- 骨干演进一句话史：LeNet→AlexNet（ReLU+Dropout+GPU）→VGG（堆 3×3）→ResNet（恒等旁路 `F(x)+x`，
  反向时梯度有 `∂/∂x` 直通项，根治 L13 陷阱 1）→ViT/ConvNeXt（把 Transformer 先验搬回视觉）。

### 1.2 RNN：时间权重共享
- `h_t = f(W_h h_{t−1} + W_x x_t + b)`；展开 = 深度为 T 的网络，反向即 BPTT。
- 梯度 `∂h_T/∂h_0 = Π_t W_h^T diag(f')`：谱半径决定消失/爆炸（18.06 特征值语言直接适用）。
- LSTM：门控 `i,f,o,c̃` + cell state 加法路径 `c_t = f_t⊙c_{t−1} + i_t⊙c̃_t`——
  **f_t≈1 时梯度沿加法支路不衰减**，是对消失问题的工程解（对照残差：同一思想，不同轴）。
- GRU：两门简化版，小模型上常与 LSTM 打平。
- seq2seq/注意力：编码器-解码器 + Bahdanau 注意力 = "对齐"的软版本，通向 §1.3。

### 1.3 Transformer 概览（2024 后必讲的半讲）
- 缩放点积注意力：`Attention(Q,K,V) = softmax(QK^T/√d)V`；√d 防止内积方差随维度增长把 softmax 推进饱和区（与 L13 BN 的方差守恒哲学同源）。
- 多头 = 并行学不同子空间的"对齐方式"；自注意力 = 序列内部 `Q=K=V=X`。
- 结构配方：残差 + LayerNorm（Pre-LN 更稳）、FFN（每位置 MLP）、正弦/学习位置编码补顺序信息。
- 与 RNN 的本质交易：O(n²) 内存/并行全开 vs O(n) 状态/串行——**并行性赢下了算力时代**。
- 训练细节（L14 清单复用）：warmup + Adam、标签平滑、dropout；推理 KV-cache 是 L15 的"系统课彩蛋"。

## 2. 直觉与常见陷阱
- 直觉：架构 = 你假设数据对称性的清单。CNN 信平移等变，RNN 信时序递归，Transformer 信"内容决定关注对象"。
- 陷阱 1：小数据硬上 ViT（缺 CNN 局部先验 → 样本效率差）；数据增强/蒸馏/混合架构是补救。
- 陷阱 2：padding 与 batch 长度不齐：RNN 忘记 `pack_padded_sequence` → 短样本的零位污染状态与损失。
- 陷阱 3：注意力当解释：权重高 ≠ 因果证据（ Jain & Wallace 2019 的经典泼冷水）。
- 陷阱 4：把 Transformer 训练崩了怪模型：多半是没 warmup/lr 太猛/缺 Pre-LN——工程先于理论排查。
- 陷阱 5：因果任务里用双向注意力（BERT 式）预测下一 token = 信息泄漏（causal mask 不可省）。
