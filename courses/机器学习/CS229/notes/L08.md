# L08 判别学习 III：感知机、排序学习；特征降维 PCA

> Notes Ch.4 §4.6-4.7 + Lecture Notes (PCA) · 前置：L06-L07 · 对应项目：projects/p07_pca（PCA 部分）

## 1. 数学推导要点

### 1.1 感知机：在线的对偶性
- 更新规则：误分 (x, y) 时 `w := w + η y x` → 展开：**`w` 永远是训练样本的整系数线性组合**
  `w = Σ_i k_i η y_i x_i`（k_i 为第 i 个样本被纠错的次数）——与 SVM 对偶 `w = Σ α_i y_i x_i` 同构，
  核化感知机因此理所当然：`f(x) = Σ_i β_i K(x_i, x)`。
- Novikoff 收敛定理（存在间隔 γ、数据在半径 R 球内时）：误分类总次数 ≤ (R/γ)²，
  与迭代步数无关——**在线学习的第一块石头**，为 L10 的间隔界埋线。
- 感知机最小化的是 0-1 损失的贪心替代（hinge 无惩罚、无正则）：能分就停，分不开就永远不停。

### 1.2 排序学习（Learning to Rank）
- 输出从 {±1} 变为实值打分 `f(w) = Σ_i w_i Q(w; x_i)`（L2 网页分、推荐分）。
- 损失改为 pairwise hinge：对每一对"应排在前"的 `(x_i, x_j)` 要求
  `f(x_i) − f(x_j) ≥ γ`，违例惩罚 `Σ_{(i,j)∈P} max(0, γ − (f_i − f_j))`。
- 优化仍是次梯度；结构上就是"差向量版本的 SVM"——间隔思想从分类推广到序结构。

### 1.3 PCA：最大方差 = 最小投影误差
- 目标一（重构）：找 k 维子空间 U（正交基）最小化 `Σ_i ‖x_i − UU^T x_i‖²`。
- 目标二（方差）：最大化投影方差 `Σ_i ‖U^T x_i‖²`。约束 `U^T U = I` 下两目标互补（总能量恒定）。
- 拉格朗日推导：`max tr(U^T Σ̂ U) s.t. U^T U=I` → `Σ̂ u_j = λ_j u_j` → **解是样本协方差矩阵前 k 大特征向量**（Rayleigh-Ritz 定理）。
- 计算：协方差特征分解 O(n³)；数据多特征少用 `X^T X`（18.06 的 SVD：`X = UΣV^T`，右奇异向量即主成分）。
- 白化（whitening）：再除以 `√λ_j`，各主成分方差归一——L16 ICA 的前置步骤。
- 解释方差比例 `Σ_{j≤k} λ_j / Σ λ_j` 是选 k 的默认曲线（scree plot）。

## 2. 直觉与常见陷阱
- 直觉：PCA 是"把数据躺平到惯性最小的轴上看"；它只是旋转+截断，**不做任何监督信息利用**（与 LDA 判别投影对照，L05）。
- 陷阱 1：PCA 前不减均值 = 第一主成分被均值方向绑架；不缩放则量纲大者称王。
- 陷阱 2：把主成分当"因果特征"解释——载荷矩阵可正可负、符号任意（特征向量符号不定），解读看相关性不看符号方向。
- 陷阱 3：k 的选择只看解释方差阈值：下游任务（如聚类 L16）需要的是"对任务有用的 k"。
- 陷阱 4：非线性流形上硬用线性 PCA → 核 PCA（L18 谱聚类视角）或自编码器（L17）。
- 陷阱 5：测试集参与 PCA 拟合 = 数据泄漏；sklearn 必须 fit on train / transform both。

## 3. 与前后讲次的联系
- 感知机是 L06 间隔的"在线孪生"；排序学习是 hinge 家族换差空间，收束判别式三部曲。
- PCA 的拉格朗日特征值问题与 L07 对偶共用工具；为 L16 k-means（欧氏几何预处理）、
  L18（PCA 正式复习 + ICA/谱聚类）、L17 自编码器（PCA 的非线性推广，且逐层线性 AE 的最优解就是 PCA 子空间）铺路。
- 重构误差公式在 L17 因子分析中几乎原样复现（加一个各向异性噪声）。
- p07 项目同时充当 L16 聚类的预处理实验台：PCA 降维后再跑 k-means，观察边界变化。
