# L14 深度学习实践：PyTorch/TensorFlow、架构设计、调参

> Notes Ch.7 §7.4-7.5 · 前置：L13 · 对应项目：无新增 numpy 项目（本讲为工程讲，建议跟 CS231n A1/A2 或官方教程练手）

## 1. 方法论要点

### 1.1 一个训练管线的解剖
1. 数据：加载 → 预处理/增广 → DataLoader（打乱、pin memory、多 worker）；
2. 模型：`nn.Module` 定义（层容器 + forward）；
3. 损失与优化器：`CrossEntropyLoss`（内部含 log-softmax 数值稳定版，勿再手写 `log(softmax)`——L03 陷阱 1 的官方回答）+ `AdamW`；
4. 循环：`zero_grad → forward → backward → (clip) → step`，调度器 `scheduler.step()`；
5. 评估：`eval()` + `no_grad()` + 固定增广/校准指标；
6. 记账：MLflow/W&B 记录超参、曲线、工件（checkpoint 含 optimizer/scheduler 状态）。

### 1.2 架构设计 = 选择归纳偏置
- 深度 vs 宽度：深而窄表达"层级组合先验"，宽而浅更接近传统逼近论——先按数据形态选。
- 参数预算：CNN 每层参数 `k²·C_in·C_out`，Transformer 注意力 `O(n²d)` 内存墙；先手算一遍再训练。
- 经典积木（L15 细讲）：残差连接（梯度旁路）、归一化位置（Pre-LN vs Post-LN 训练稳定性）、
  下采样策略（步幅卷积 vs 池化 vs 像素洗牌）。
- 迁移学习：从大数据集（ImageNet/LM）微调，冻结比例/分层 lr/头重训是三板斧；小数据下的默认正确答案。

### 1.3 调参科学
- 顺序哲学：先过拟合小样本（1 batch 记住 → 确认无 bug），再谈正则与规模。
- 学习率是一等公民：范围测试（1e-5→1 扫一遍画 loss 曲线）→ 取最陡段起点；其余超参围绕 lr 调。
- 搜索方法对照（L09 交叉验证思想的 DL 版）：网格（维度低）→ 随机（同等预算覆盖更大空间，统计上更优）→
  贝叶斯/早停接力（Hyperband/ASHA：算力换评估次数）。
- 可复现性四件套：种子、确定性算法开关、数据版本（DVC）、环境锁定（conda/uv lock）。

## 2. 直觉与常见陷阱
- 直觉：深度学习 80% 的失败是数据问题，15% 是训练动力学，5% 才是模型容量（与 CS229 前半程的理论分布恰好相反——这就是"实践"讲存在的意义）。
- 陷阱 1：train loss 降 val loss 升 ≠ 立刻加正则：先查数据泄漏/分布漂移/评估口径。
- 陷阱 2：验证集只有一份却做 500 次超参搜索 = 悄悄把验证集训练进了模型（多重假设检验视角：每次选择都是一次 L10 意义下的复杂度）。
- 陷阱 3：梯度裁剪掩盖发散：clip 阈值应只兜底偶发尖峰；天天被 clip 说明 lr/初始化有真问题。
- 陷阱 4：混合精度直接开：BN/loss 的 fp16 动态范围问题需要 GradScaler（接 L13 陷阱）。
- 陷阱 5：用 GPU 利用率找瓶颈：数据加载常是真正瓶颈（`num_workers`、磁盘、增广 CPU 成本）。

## 5. 开源项目中的对应
- **PyTorch**（`Lightning` 封装训练循环）、**TensorFlow/Keras**（`fit` + callbacks）、**JAX/Flax**（函数式训练循环）：三种管线风格各配一份官方 tutorial。
- **Hugging Face** `Trainer` + `datasets`：把 §1.1 六步固化成配置；`transformers` 的模型卡是"归纳偏置选择"的活百科。
- **Weights & Biases / MLflow**：实验追踪双雄；MLflow 与 sklearn 的 `search_cv` 集成把 L09-L14 的调参串成一条日志流。
- **DVC**：数据版本化——可复现性四件套的第四件。
- **MLX**：本地 MacBook 上做 §1.3 的小规模搜索实验零成本。
