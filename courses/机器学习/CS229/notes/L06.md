# L06 判别学习 I：最大间隔分类器、函数间隔与几何间隔

> Notes Ch.4 §4.1-4.3 · 前置：L03, L05 · 对应项目：projects/p04_svm

## 1. 数学推导要点

### 1.1 支持向量的动机：从"分对"到"分得自信"
- 感知机只要求分对，无穷多条边界都可以；我们要**边际（间隔）最大**的那条。
- 函数间隔：`γ̂ = min_i ŷ^(i)(w^T x^(i) + b)`，其中 `ŷ ∈ {−1,+1}`。
  缺陷：`(w,b) → (kw, kb)` 不改变分类面却放大 γ̂ → 任意缩放。
- 几何间隔：点到超平面的欧氏距离 `γ_i = (y_i(w^T x_i + b))/‖w‖`（需 y_i∈{±1} 约定）。
  规范化 `‖w‖ = 1` 后函数间隔 = 几何间隔。

### 1.2 最优间隔分类器（OHC）原始形式
```
max_{w,b}  γ̂
s.t.  ŷ^(i)(w^T x^(i) + b) ≥ γ̂,  i=1..m
      ‖w‖ ≤ 1
```
- 技巧：固定 `γ̂ = 1`（利用缩放自由度），把 ‖w‖≤1 扔进目标：
```
min_w  (1/2)‖w‖²
s.t.   y^(i)(w^T x^(i) + b) ≥ 1
```
- 这是一个**二次目标 + 线性约束 = 凸 QP**（Slater 条件成立 → 强对偶，L07 用）。
- 解的性质：最优 w 必是支持向量的线性组合 `w* = Σ_i α_i y_i x_i`（Lagrangian 驻点条件）——
  测试时 `f(x) = Σ_i α_i y_i x_i^T x + b` 只需支持向量参与（核方法的大门，L07）。

### 1.3 间隔为何是好的归纳偏置（预告 L10）
- 间隔 ≥ γ 的数据被 ‖w‖≤B 的球分开时，VC 维 ≤ min(n, R²B²/γ²)：
  大间隔 → 有效假设空间小 → 泛化界紧。SVM 的成功 = 凸优化 + 统计理论罕见地同向。
- 鲁棒性直觉：测试点的特征扰动 δ（‖δ‖ < γ）不改变预测——"训练时多要的间隔，测试时是安全垫"。

## 2. 直觉与常见陷阱
- 直觉：`y = sign(w^T x + b)` 里只有方向重要；间隔最大化 = 在"分对"解集里挑最不急转弯的。
- 陷阱 1：线性不可分时 OHC 无解——必须加松弛变量（软间隔，L07），而不是回家。
- 陷阱 2：不标准化特征做 SVM：`‖w‖²` 惩罚在原始尺度上偏袒量纲大的特征，间隔全乱。
- 陷阱 3：把函数间隔当距离汇报给同事；b 的符号约定、y∈{0,1} 还是 {±1} 混用是笔记推导事故高发区。
- 陷阱 4：用训练集间隔调 C——间隔是训练集性质，超参数必须看验证集。
