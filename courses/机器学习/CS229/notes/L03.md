# L03 分类与逻辑回归：假设函数、交叉熵损失、Newton/IRLS

> Notes Ch.2 · 前置：L02 · 对应项目：projects/p01_linear_logistic（实验 B）

## 1. 数学推导要点

### 1.1 为什么不能直接套用线性回归
- 分类标签 `y ∈ {0,1}`，用 LMS 拟合会得到超出 [0,1] 的预测，且离群点把直线拉歪。
- 修补思路：把 `θ^T x` 压进 (0,1) → 选 sigmoid `g(z) = 1/(1+e^{-z})`，
  性质：`g'(z) = g(z)(1−g(z))`，`g^{-1}(p) = log(p/(1−p))`（logit）。
- 令 `h_θ(x) = g(θ^T x) = P(y=1|x;θ)` → 伯努利分布的参数化。

### 1.2 交叉熵损失（从 MLE 出发，不是拍脑袋）
- 似然：`p(y|x;θ) = h^y (1−h)^{1−y}` → `ℓ(θ) = Σ_i [y^(i) log h^(i) + (1−y^(i)) log(1−h^(i))]`。
- 取负平均 = 交叉熵代价：`J(θ) = −(1/m) Σ_i ...`。
- 信息论读法：真实分布（经验伯努利）与预测分布的 KL 散度（去掉与 θ 无关的熵项）。
- **关键**：逻辑回归 + 交叉熵是凸的；逻辑回归 + 平方损失非凸。梯度巧合般干净：
  `∂J/∂θ_j = (1/m) Σ_i (h^(i) − y^(i)) x_j^(i)` ——形式与 LMS 一样，只是 h 换成了 g(θ^T x)。
  推导链：`−(y/h)(∂h/∂θ) + ((1−y)/(1−h))(∂h/∂θ)`，再用 sigmoid 导数即消成 `(h−y)x_j`。

### 1.3 Newton 法与 IRLS
- 二阶泰勒最小化：`θ := θ − H^{-1} g`，`H = ∇²J`。逻辑回归的 Hessian：
  `H = (1/m) X^T diag(w) X`，`w_i = h_i(1−h_i) ∈ (0, 1/4]` → 半正定 → 凸性另一证。
- IRLS 解读：每步牛顿迭代 = 用权重 `w_i = h_i(1−h_i)` 再做一次**加权最小二乘**——
  "逻辑回归没有闭式解"与"逻辑回归是迭代加权线性回归"两句话同时成立。
- 实践：牛顿法 O(n³)/步但迭代次数个位数；大数据用（迷你批）GD/SGD 或 L-BFGS。

### 1.4 决策边界与多类
- `h ≥ 0.5 ⟺ θ^T x ≥ 0`：决策边界是超平面，逻辑回归本质是**线性分类器**，输出是"带概率的符号"。
- 多类：one-vs-rest（K 个二分类器，概率不归一）与 softmax/多项逻辑回归（L04 GLM 统一处理）。

## 2. 直觉与常见陷阱
- 直觉：sigmoid 把"证据"（log-odds 线性打分）翻译成"信念"（概率）；交叉熵只惩罚"自信且错"的预测。
- 陷阱 1：`log(h)` 在 h→0 时下溢。永远写 `log sigmoid(z) = −log(1+e^{−z})` 的数值稳定版（`np.logaddexp(0, -z)`；sklearn 的 `log_loss`/`LogisticRegression` 内部均如此）——CSAPP/浮点表示的直接教训。
- 陷阱 2：类别不平衡（1:1000）时下采样负类后再用 0.5 阈值判类——先验变了，阈值/概率要按 `p/(p+(1−p)·r)` 校正（r 为采样比）。
- 陷阱 3：不标准化特征就跑带正则的 logistic 回归，λ 对各特征强度不公平（sklearn 文档明言此坑）。
- 陷阱 4：把牛顿法步长当成固定 1——对数似然非二次时会 overshoot，需线搜索/backtracking。
