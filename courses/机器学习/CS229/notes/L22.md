# L22 进阶专题：核密度估计、高斯过程、Boosting 理论（历年选读）

> 附录 KDE / Gaussian Processes + Ch.6 理论延伸 · 前置：L05-L07（贝叶斯/核）、L12、L16-L18 · 对应项目：p06 扩展（KDE 与 GMM 边界对照）

## 1. 数学推导要点

### 1.1 核密度估计（KDE）：非参数的 MoG
- 估计：`p̂_h(x) = (1/m) Σ_i (1/h) K((x−x_i)/h)`（高斯核取 `N(x_i, h²I)`）——
  **把 GMM 的 μ_j 换成全部训练点、权重均匀 1/m**：MoG 的"k=m"极限，生成式假设归零。
- 偏差-方差显式化（本讲是 L09 的活体解剖）：
  `Bias ≈ (h²/2)μ₂(K) p''(x)`（核二阶矩 × 曲率），`Var ≈ p(x)/(mh·R(K))`；
  MSE 最优 `h* ∝ m^{−1/5}`（d 维 `m^{−1/(d+4)}`）——**维度灾难以指数形式出现在收敛率里**。
- 带宽选择：交叉验证（伪样本法）/ Scott & Silverman 法则（高斯参考规则）。
- 应用：`p̂` 低的点即异常（L18 的 KDE 升级版）、 Mean-Shift 聚类（对 `∇p̂` 爬山——EM 之外的第二条无监督路径）。

### 1.2 高斯过程回归（GP）：无限维贝叶斯线性回归
- 先验：任意有限点集 `f(x_1..x_m) ~ N(0, K)`，K_ij = k(x_i,x_j)——核函数从"技巧"（L07）升格为"先验本体"。
- 后验（高斯条件公式一遍代数，务必亲手推）：
  `mean* = k^T (K+σ²I)^{-1} y`，`cov* = k** − k^T(K+σ²I)^{-1}k`。
- 与核岭回归：GP 均值 = KRR 预测（L07 的对偶同解），GP 额外白送**预测不确定度** → 贝叶斯优化（采集函数 EI/UCB，调参的 L14 科学化终极形态）。
- 复杂度：精确 GP O(m³)（求逆）与 L02 正规方程同命；稀疏近似（INDucing points）、随机特征（L07 陷阱 4 的解药）构成现代 GP 工程。
- 与神经网络的桥：单层无穷宽随机初始化网络的高斯过程极限（Neal 1996）——L13 与 GP 在"宽度→∞"处重逢（NNGP/NTK 是研究前沿，点到）。

### 1.3 Boosting 理论（L12 的定理化）
- 提升定理（Schapire）：弱学习（err ≤ ½−γ）经多项式轮 boosting → 任意强 err ≤ δ。
- 间隔视角（Schapire-Singer）：AdaBoost 的训练间隔随轮数增大，泛化界 `O((n_d·log² m)/m)` 与基函数个数无关——
  对"零训练误差仍不过拟合"的首次理论解释（L09-L10 悬念的兑现之一；L12 §1.2 的正式版）。
- 与 L09 结构风险的统一：所有 boosting 损失都是某个凸上界损失的前向分步最小化（Bregman 距离推广到 Crammer-Singer 多类，研究向）。

## 2. 直觉与常见陷阱
- 直觉：KDE="每个样本都当一次簇中心"；GP="把权重先验搬到函数空间"；boosting="错题本的理论证书"。
- 陷阱 1：KDE 在高维退化（`m^{−1/(d+4)}`）：d>4 时先想想 L18 降维或改用参数模型；边界偏（boundary bias）在密度支撑集边缘爆炸——反射/变带宽修。
- 陷阱 2：GP 核选择 = 模型假设：RBF 隐含无限可微（对阶梯函数不友好），Matérn 调光滑度，周期核处理季节性——与 L01 归纳偏置同一课时的不同教材。
- 陷阱 3：GP 的 σ²（观测噪声）与长度尺度/幅度超参联合学习时似然面多峰：多次初始化，或固定物理已知噪声。
- 陷阱 4：把 boosting 理论界的"与轮数无关"读成"永不过拟合"：界松 + 数值上过拟合真实存在（L12 陷阱 1 的回应）。
- 陷阱 5：用 KDE 做似然比检验时忘记归一化常数/交叉验证泄漏：伪样本 CV 必须留出。
