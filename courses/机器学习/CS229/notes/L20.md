# L20 强化学习 I：MDP、值迭代与策略迭代、策略搜索

> Notes Ch.9 §9.1-9.4 · 前置：L19（链式动态规划语言）· 对应项目：projects/p08_rl_gridworld（值迭代部分）

## 1. 数学推导要点

### 1.1 MDP 五元组与目标
- `(S, A, P_{sa}, γ, R)`：马尔可夫性 `P(s_{t+1}|s_t,a_t,历史) = P(s'|s,a)`（HMM 状态转移的行动版，L19）。
- 策略 `π: S→A`（或随机 π(a|s)）；回报 `R_t = Σ_{i=0}^∞ γ^i r_{t+i}`，γ<1 保证几何级数收敛并表达"时间贴现"。
- 值函数：`V^π(s) = E_π[R_t | s_t=s]`，`Q^π(s,a) = E[r + γV^π(s')]`——
  Bellman 期望方程：`V^π(s) = Σ_a π(a|s)[Σ_{s'} P_{ss'}^a (R + γV^π(s'))]`：**值 = 一步奖励 + 折现后继值**，对 V 线性。

### 1.2 最优性与 Bellman 算子
- 最优 Bellman 方程：`V*(s) = max_a Σ_{s'} P^a_{ss'}(R + γV*(s'))`；`π*(s) = argmax_a Q^{V*}(s,a)`。
- Bellman 算子 `T` 在 sup 范数是 γ 压缩：`‖TV₁−TV₂‖_∞ ≤ γ‖V₁−V₂‖_∞` →
  Banach 不动点 ⟹ 值迭代 `V ← TV` 几何收敛 `O(γ^k)`——**"迭代必有解且唯一"的存在性证明**（EE364A 里没教的不动点课）。

### 1.3 两大算法
- **值迭代**：`V_{k+1}(s) = max_a Σ P(R+γV_k)`；策略提取 `π = argmax Q^V`。
- **策略迭代**：交替 ①策略评估（解线性方程组 `V^π = r^π + γP^π V^π`，或迭代到收敛）②策略改进（贪心）。
  改进步保证 `V^{π'} ≥ V^π` 逐点；有限 MDP 策略数有限 → 有限步收敛（通常几轮，但状态空间指数大）。
- 对比：值迭代 = "每次只做一步评估"的策略迭代；广义策略迭代（GPI，Sutton 语）是统一视角，为 L21 的 Q-learning（"采样的 GPI"）铺路。

### 1.4 连续状态与策略搜索（LQR 前奏 + 现代 RL 预告）
- 无限/连续状态：V 用函数逼近 `V̂(s;θ)`（线性基函数 → 拟合值迭代 FVI；神经网络 → DQN 家族，指向 CS285）。
- 直接策略搜索：把 `J(θ) = E_{π_θ}[Σγ^t r]` 对 θ 求导，REINFORCE：
  `∇_θ J = E[∇_θ log π_θ(a|s) · (回报到目标项)]`——似然比技巧：
  对期望里的分布求导 = 乘 score function（与 L13 反向传播是两种"穿过随机性"的路）。
- 线性二次型调节器（附录，工程控制版）：`J = Σ x^T Q x + u^T R u`，值函数二次型 `x^T P x`，
  Riccati 递推解最优控制 `u = −Kx`——连续状态版的"值迭代"，下一讲讲透。

## 2. 直觉与常见陷阱
- 直觉：值迭代 = 把 Bellman 备份当扩散方程迭代；策略改进 = 在当前地图上的贪心爬山；二者轮流 = GPI。
- 陷阱 1：γ 的角色误解：γ→0 近视（只吃即时奖励），γ→1 远视但收敛慢、方差大（L21 的 TD 方差）。
- 陷阱 2：奖励黑客：目标对了世界就对了？值迭代忠实地优化你写错的 R——"设计奖励"是应用 RL 的第一工程难题（接 L23 项目伦理）。
- 陷阱 3：策略迭代评估不彻底：评估截断误差允许存在但仍收敛（乐观策略迭代），"精确解方程组"是教学理想化。
- 陷阱 4：把贝尔曼 max 写进期望方程（V^π 不该有 max）：策略评估与策略优化的混淆是作业挂科第一原因。
- 陷阱 5：连续状态直接用表格法：维度灾难，函数逼近的稳定性问题（ deadly triad：bootstrapping+逼近+自数据，Sutton 书第 11 章警告，L21 再见）。
