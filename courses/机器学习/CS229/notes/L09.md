# L09 学习理论 I：偏差-方差、经验风险最小化 ERM、一致性

> Notes Ch.5 §5.1-5.4 · 前置：L01-L08 全部 · 对应项目：projects/p02_regularization

## 1. 数学推导要点

### 1.1 泛化误差与学习曲线
- 真实误差 `γ(h) = E_{(x,y)~P}[(h(x)−y)²]`（平方损失），训练误差 `ε̂(h)`。
- 假设均匀收敛（Hoeffding + union bound，有限 H）：
  `P(∃h: |γ(h) − ε̂(h)| > ε) ≤ 2|H| e^{−2mε²}` → 样本复杂度
  `m ≥ (1/(2ε²)) log(2|H|/δ)` 即可保证 ERM 输出 h 满足 `γ(h) ≤ γ(h*) + 2ε`。
- 解读三板斧：ε（容忍度）、δ（置信）、|H|（模型复杂度）——"学习 = 用样本换掉对未知的恐惧"。

### 1.2 偏差-方差分解（期望意义下的精确恒等式）
对固定 x，在训练集随机性上取期望（`E_D` 记 h_D 为在数据集 D 上的 ERM 输出）：
```
E_D[(h_D(x) − y)²] = σ²_y            (噪声，不可约)
                   + (E_D h_D(x) − f(x))²   (Bias²)
                   + E_D[(h_D(x) − E_D h_D(x))²]  (Variance)
```
- 推导要诀：加减 `E h_D(x)` 与 `f(x)`，交叉项因独立性（训练集 ⊥ 新样本）为零。
- 含义：Bias 来自 H 太小（欠拟合：线性模型拟合抛物线），Variance 来自 H 太大 + 样本有限（高次多项式逐数据集乱抖）。
- **权衡是假设空间的属性，不是某一次训练的结果**——这是它和"过拟合诊断"的区别。

### 1.3 一致性与正则化
- 强一致：`m→∞` 时 `ε̂(h_mERM) → γ(h*)`。上面 union bound 对有限 H 立即给出一致性。
- 无限 H（如实函数）时 log|H| 爆炸——L10 的 VC 维接管。
- ERM 的病：H 足够大时训练误差可以为 0，泛化却无保证 → **结构风险最小化**：
  `min γ̂(h) + λP(h)`（正则项 = 给假设空间加权先验）。L07 的 `‖w‖²`、L11 的树深度限制都是它的化身。
- 交叉验证（附录/k-fold）：用 `E_{D'}[γ_{D'}(h_D)]` 的可计算代理选 λ——训练/验证/测试三分法在此获得理论身份。

## 2. 直觉与常见陷阱
- 直觉：画两条曲线（训练误差、验证误差）随 m 增长，间隙是否收敛到 0 就是 bias-variance 诊断图。
- 陷阱 1：把 B-V 与 train/test gap 混为一谈：gap 大是 variance 症状，但欠拟合时 gap 也可以小而误差大（bias）。
- 陷阱 2：正则强度只按训练误差调——λ 是超参数，必须留出验证集；否则等于用测试集调参。
- 陷阱 3：样本多时还在调模型：偏差主导时再正则也无济于事——看学习曲线决定"加数据还是加容量"。
- 陷阱 4：对时间序列/分组数据随机 k-fold 泄漏（同组样本同时出现在训练与验证）→ GroupKFold/TimeSplit。
