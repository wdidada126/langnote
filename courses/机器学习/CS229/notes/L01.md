# L01 监督学习问题设定、假设空间与代价

> Notes Ch.1 导言部分 · 无先修讲次 · 对应项目：projects/p01_linear_logistic

## 1. 数学框架要点

### 1.1 监督学习的形式化
- 训练集 `S = {(x^(i), y^(i))}_{i=1..m}`，`x^(i) ∈ R^n` 为特征向量，`y^(i)` 为标签。
- 分类：`y ∈ {0, 1}`（或多类）；回归：`y ∈ R`。
- 学习算法 `A` 输出一个**假设** `h: X → Y`。`h(x)` 对未标注样本的预测即推断（inference）。
- 关键区分：**假设空间 H** 是算法"能表达"的所有函数的集合；
  可学性 = 在 H 中找得到好假设 + 有efficient算法找到它。

### 1.2 代价函数与经验风险
- 平方代价：`J(h) = (1/m) Σ_i (1/2)(h(x^(i)) − y^(i))²`（1/2 是为求导干净）。
- 训练目标：`min_{h∈H} J_train(h)`——这叫**经验风险最小化（ERM）**。
- 真正的目标是泛化误差 `E_{(x,y)~P}[(h(x)−y)²]`：训练误差小 ≠ 测试误差小，
  这一裂缝由 L09-L10 的学习理论处理。

### 1.3 参数化 vs 非参数化
- 参数化：先固定 H（如线性函数族），只学有限维参数 θ。可外推、压缩数据。
- 非参数化：H 随数据增长（kNN、决策树不剪枝）。灵活但需要更多数据。
- 选择 H 本质是**归纳偏置**：你愿意相信世界的哪类规律。

### 1.4 记号约定（全课程统一）
- `x^(i)` 第 i 个样本，上标括号非幂；`x_j` 第 j 个特征；下标矩阵元素 `A_{ij}`。
- 设计矩阵 `X ∈ R^{m×n}`（第 i 行是 `(x^(i))^T`），标签向量 `y ∈ R^m`。
- 期望 `E_{(x,y)~P}`、经验平均 `(1/m)Σ_i` 分别对应"世界"与"数据集"两个层面——
  学习理论就是研究后者何时逼近前者。

## 2. 直觉与常见陷阱
- 直觉：整套 CS229 可以看成同一个问题的反复变奏——"给定 H、损失 L、约束，如何求 θ，以及这样求出来的 θ 靠不靠谱"。
- 陷阱 1：把 `J` 的 1/2 系数当玄学。它纯为排版：`∂/∂θ (1/2)r² = r·∂r/∂θ`。
- 陷阱 2：特征未归一化直接跑梯度下降，等高线呈病态椭圆，收敛极慢（L02 会数值演示）。
- 陷阱 3：用测试集调超参数——测试集只能用一次，否则报告的泛化误差是假的。
- 陷阱 4：混淆"模型复杂度"与"假设空间大小"：H 大而过拟合是偏差-方差权衡问题，不是 bug。

- **scikit-learn**：`sklearn.base.BaseEstimator` 的 fit/predict 协议就是本讲 `A → h → h(x)` 的工程化封装；
