# L17 无监督学习 II：因子分析与变分自编码器（导论级）

> Notes Ch.8 §8.4-8.5 + 附录 · 前置：L16（EM/Jensen）、L13（网络训练）· 对应项目：并入 p06 的扩展讨论（因子分析 EM 可选做；VAE 超出 numpy-only 范围，指向 CS231n/教程）

## 1. 数学推导要点

### 1.1 因子分析模型
- 生成假设：`z ~ N(0, I_k)`（k < n 的隐因子），`x = μ + Λz + ε`，`ε ~ N(0, Φ)`（对角噪声）。
- 边缘分布：`x ~ N(μ, ΛΛ^T + Φ)`。协方差结构 = 低秩（k 维共享变异）+ 对角（私有噪声）。
- 性质练习（讲义核心）：`Cov(x_i, x_j) = λ_i^T λ_j`（i≠j，完全由共享因子解释）；
  `Var(x_i) = λ_i^T λ_i + Φ_ii`（私有方差 = 唯一性 uniqueness，心理学词源）。
- 与 PCA 的分界（必考对比）：
  - PCA：最小化重构误差，无生成模型，噪声各向同性（Φ=σ²I 特例）；
  - FA：最大化边际似然，各维度噪声不同 → 对"哪些特征更可信"建模；潜空间无"主方向"排序含义（k 小即可）。
  - 关系：FA 的 `Φ→σ²I` 且 k→n 时与 PCA 的极大似然解重合（子空间相同，载荷旋转/缩放）。

### 1.2 因子分析的 EM
- 完全数据 `(x, z)` 是高斯联合 → E 步需要 `E[z|x]` 与 `E[zz^T|x]`（条件高斯一阶二阶矩，配方法可得）。
- M 步：`Λ = (Σ_i E[z_i x_i^T])(Σ_i E[z_i z_i^T])^{-1}`，`Φ_ii = (1/m) Σ_j Var(x_ij − Λ_j z_i 的残差)`，
  即"对角取残差方差"——形式上与线性回归正规方程同构（把不可见的 z 换成它的后验矩），L02 的投影故事在隐变量下重演。
- 不可辨识性：`Λ R`（R 为正交阵）给出同一分布 → 后旋转（varimax）做解释性工程。

### 1.3 变分自编码器（导论级，Ng 2024 后新版 Ch.8 正式收录）
- 动机：FA 的线性/高斯局限 → 用神经网络当生成模型，隐变量仍是简单先验 `p_θ(z) = N(0, I)`。
- 直接最大化 `log p_θ(x)` 不可解（对 z 积分高维）→ 用网络 `q_φ(z|x)`（编码器）近似后验，
  **ELBO 分解**（与 EM 的 Jensen 分解同一恒等式换元）：
  `log p_θ(x) = ELBO(φ,θ) + KL(q_φ(z|x) ‖ p_θ(z|x)) ≥ ELBO`，
  `ELBO = E_q[log p_θ(x|z)] − KL(q_φ(z|x) ‖ N(0,I))`。
- 重参数化技巧：`z = μ_φ(x) + σ_φ(x) ⊙ η, η~N(0,I)` → 梯度可穿过采样反传（期望的参数化随机变量）。
- 训练即"重构损失 + KL 正则"：与 L13 自编码器的差别只在 KL 项与采样；
  两项权重退火 = β-VAE 的 disentangling 讨论（研究前沿，本讲点到为止）。
- 与 EM 的谱系：E 步 ≈ 优化 φ，M 步 ≈ 优化 θ；VAE 把两者都换成梯度步——" amortized EM"。

## 2. 直觉与常见陷阱
- 直觉：FA 说"高维数据其实躺在一张低维弹性薄膜上，每个方向有自己的抖动幅度"；VAE 说"给这张薄膜配一个神经网格并学会来回投影"。
- 陷阱 1：FA 的 k 与旋转不可辨识：因子解释（"哪个因子是什么"）是统计学最软的部分，varimax 不是真值而是习俗。
- 陷阱 2：VAE 样本模糊：解码器用高斯/像素伯努利 + MSE 式重构 → 回归到均值；把重构损失换 GAN/扩散是另一个故事（L17 不展开，指向深度生成模型课）。
- 陷阱 3：后验崩塌（posterior collapse）：强大的条件解码器学会忽略 z → KL→0，先验成了摆设；小 β 退火/词级 KL 权重是标准解法。
- 陷阱 4：VAE 的 ELBO 与"真对数似然"的差是 KL，**不能用 ELBO 当证据做贝叶斯模型比较**。
- 陷阱 5：把 FA 当 PCA 的别名写进报告：两者协方差假设不同，下游（缺失值填补、噪声加权）行为不同。
