# L21 强化学习 II：Q-learning、线性规划方法、LQR 概览

> Notes Ch.9 §9.5-9.7 + 附录 LQR · 前置：L20 · 对应项目：projects/p08_rl_gridworld（Q-learning 部分）

## 1. 数学推导要点

### 1.1 Q-learning：不知道 P 也能值迭代
- 最优 Q 的 Bellman 方程：`Q*(s,a) = Σ_{s'} P^a_{ss'}[R + γ max_{a'} Q*(s',a')]`。
- 采样版（Watkins）：每经历 `(s,a,r,s')` 做一次随机近似更新
  `Q(s,a) ← Q(s,a) + α[r + γ max_{a'} Q(s',a') − Q(s,a)]`，括号 = **TD 误差**。
- 收敛定理（Robbins-Monro 条件）：`Σα=∞, Σα²<∞`，所有 (s,a) 无限次访问 → Q→Q* a.s.
  ——"离策略（off-policy）"：学习目标是贪心的 max，行为可以是探索性的 ε-greedy。
- 与值迭代的关系：期望备份换成单样本备份 = L02 的 GD→SGD 翻译（随机逼近谱系；L16 EM 的确定期望也同族）。

### 1.2 探索与离线策略
- ε-greedy/softmax（玻尔兹曼探索）/乐观初始化（把未知当已知的奖励诱导出访）。
- SARSA：把 max 换成当前策略的期望——on-policy，收敛到 Q^π；"悬崖行走"对照实验是理解 off/on 差异的最佳 5 分钟。
- 经验回放（DQN 关键件）：打破样本时序相关 + 复用——把 SGD 的 i.i.d. 假设补回来（L02 陷阱的 RL 版）。

### 1.3 LP 方法：把动态规划写成优化问题
- 原始（求 V）：`min_v Σ_s c_s v_s  s.t.  v_s ≥ Σ_a π[r + γPv], ∀s,a 形式化后取线性化`——
  标准形（Puterman）：`min Σ_s η₀(s) v_s s.t. v_s ≥ R(s,a) + γ Σ P^a_{ss'} v_{s'}, ∀(s,a)`。
- 约束恰是 Bellman 不等式；**对偶变量 = 各(状态,动作)被选的概率** → 对偶问题即占优策略 LP。
- 与 L07 同一套拉格朗日机器（第三次出场）：Slater 由 γ<1 保证，强对偶成立。
- 现代回声：批量 RL/正则化 DP（如 TD3+BC 的"行为约束"）可读作带正则项的 LP 松弛——理论讲次里的预言家。

### 1.4 LQR 概览（连续线性二次控制）
- 系统 `x_{t+1} = Ax_t + Bu_t`，代价 `Σ x^T Q x + u^T R u`（Q⪰0, R≻0）。
- 值函数二次型 `V(x) = x^T P x` 代入 Bellman → **Riccati 递推**
  `P_k = Q + A^T P_{k+1}A − A^T P_{k+1}B(R + B^T P_{k+1}B)^{-1}B^T P_{k+1}A`，最优 `u = −Kx`，`K = (R+B^TPB)^{-1}B^TPA`。
- 解读：LQR = "值迭代在连续线性二次世界"的闭式兄弟；`K` 是增益矩阵（倒立摆/无人机姿态控制的发动机）。
- iLQR/DDP（非线性推广：局部二次近似逐次迭代）通向机器人控制（斯坦福无人直升机项目的底层，L23 彩蛋）。

## 2. 直觉与常见陷阱
- 直觉：Q-learning 把"算期望"外包给"多走几遍"；TD 误差是"意外程度"，也是多巴胺模型的数学核心（神经科学彩蛋）。
- 陷阱 1：`max_{a'} Q(s',a')` 的过估计偏差（采样噪声下 max 期望 ≠ 期望 max）→ Double Q/DQN 解法；这是统计偏差（L09 语言）在 RL 的具体显形。
- 陷阱 2：不可达状态/动作饿死：off-policy 收敛前提"无限次访问"不满足时 Q 停留在垃圾初值——探索预算是算法的一部分。
- 陷阱 3：Q-learning 配非线性逼近可能发散（deadly triad，L20 陷阱 5）；表格版收敛是教学安全区，工程上 bootstrap 双刃剑。
- 陷阱 4：把 LQR 的 R 调小当"更省力"：R→0 增益爆炸、鲁度（稳定裕度）崩塌；LQR 的回路整形性质（GM≥6dB 等）才是选型依据（EE363 语）。
- 陷阱 5：LP 建模中 γ=1 且不可达稳态：LP 无界 = 值无界，先检查吸收/正常性条件。
