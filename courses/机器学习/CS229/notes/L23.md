# L23 课程项目：从选题到论文式报告（自主直升机传统）

> 课程项目要求 · 前置：全部 · 对应项目：langnote 侧 projects/ 全套 + 本讲给"如何把课内项目写成一页报告"的模板

## 1. 传统与范围

### 1.1 斯坦福自主直升机（Copter）为什么是招牌
- 任务：为直升机建模（数据驱动学习动力学）→ 控制器（LQR/iLQR，L20-21）→ 飞行表演。
- 方法论拆解（每个环节都是前 22 讲的一次回访）：
  1. 数据：机载传感器时序，噪声/缺失/分布漂移（L09 理论、L18 异常检测）；
  2. 建模：残差学习——物理先验（牛顿/旋翼方程）+ ML 修正项，即"结构 + 黑盒"混合；
  3. 控制：学到的模型喂给 LQR/MPC（L21 附录）；
  4. 评估：仿真 vs 实机差距 = sim-to-real，报告必须诚实讨论。
- 现代同款精神：无人机 RL 控制、机器人操作（CS285/EE106 项目线）、自动驾驶预测（原 Argo 传统）。

### 1.2 自选课题的合格线
- 一句话可检验性："在 X 数据上比较/改进 Y 方法，用 Z 指标证明 W 结论"。
- 三种安全选题姿势：
  1. 复现 + 对照（如 L05 GDA vs L03 LR 的样本效率曲线——生成式 vs 判别式的课堂实验放大版）；
  2. 换领域应用（表格 GBDT vs DL 在某公开集，呼应 L12 §1.3 的"表格默认答案"）；
  3. 小改进 + 消融（正则化项/采样策略/核选择的一阶差分实验）。
- 失败也是结论：报告里"为什么没成"比"调参成功"更受好评——Ng 的评分重心在科学方法不在 SOTA。

## 2. 论文式报告的结构模板（8 页双栏 = 学术写作的肌肉记忆）
- Abstract：一句问题 + 一句方法 + 一句最强数字。
- Introduction：动机 → 与已有工作（Related Work 嵌在 §1 或独立）的差异声明。
- Methods：形式化（损失/模型图，直接用 L01-L21 的记号体系），可复现细节列表（数据划分、超参、算力）。
- Experiments：主表 + 消融表 + 曲线；每图必有"读法一句"（caption 自明）。
- Conclusion：结论、局限、下一步——局限段是新手与老手的分水岭。
- 工具链：LaTeX（必学工具线已覆盖）、MLflow/W&B 管实验（L14）、SHAP/特征重要性做解释（L12）。

## 3. 常见陷阱与评审视角
- 陷阱 1：没有 baseline：与"未调参的随机森林/logreg"比都赢不了时，报告越复杂越可疑。
- 陷阱 2：一个种子出全家：给 ±std 或多种子（与 L09 方差概念同款语言）。
- 陷阱 3：数据泄漏在应用课题里最隐蔽：时序切分、分组切分（L09 陷阱 4）、增强只在训练折。
- 陷阱 4：把"模型新颖"凌驾于"评估严谨"：评审用一句话概括你的贡献，若只是"我们换了个损失"，实验必须因此加倍扎实。
- 陷阱 5：图表无误差棒、无超参表：复现性 = 报告质量的同义词。
