# L02 线性回归：LMS、批量/随机梯度下降、正规方程与概率解释

> Notes Ch.1 · 前置：L01 · 对应项目：projects/p01_linear_logistic（实验 A）

## 1. 数学推导要点

### 1.1 模型与损失
- 假设 `h_θ(x) = θ^T x`（含截距技巧：令 `x_0 = 1`）。
- LMS 损失：`J(θ) = (1/2) Σ_i (h_θ(x^(i)) − y^(i))²`。
- 梯度：`∂J/∂θ_j = Σ_i (h_θ(x^(i)) − y^(i)) x_j^(i)`，向量形式 `∇J = X^T(Xθ − y)`。
- `J` 是 θ 的二次函数且 Hessian `X^T X ⪰ 0` → 凸函数 → 任何局部最优即全局最优。

### 1.2 批量梯度下降（batch GD）
`θ := θ − α ∇J(θ)`，每步遍历全部 m 条样本。
- α 太小收敛慢；α 太大震荡发散。经验：先画 J 随迭代曲线再调 α。
- 线性模型下收敛速率依赖 `X^T X` 条件数 κ：误差按 `((κ−1)/(κ+1))^t` 衰减（与最速下降法理论一致）。

### 1.3 随机与小批量梯度下降
- SGD：每次只用一条样本 `θ := θ − α(h_θ(x)−y)x`；在 J 不为零处**不收敛**，围绕最优值抖动。
- 关键技巧：**递减学习率** `α(i) = a/(b+i)`，或样本随机洗牌（lms 与 lms 打乱版本表现差异巨大）。
- 在线学习视角：数据流式到来时 SGD 是天然选择。

### 1.4 正规方程（闭式解）
- 令 `∇J = 0` → `X^T X θ = X^T y` → `θ = (X^T X)^{-1} X^T y`（若可逆）。
- 18.06 视角：`Xθ = y` 无解时，最优解是 **y 在 col(X) 上正交投影**：`X^T(y − Xθ) = 0`。
- `X^T X` 奇异的情形（特征线性相关、n > m）：用伪逆 `θ = X^+ y`（SVD 实现），工程上永远加小对角项 `+λI`（岭回归萌芽，L04/L09 见）。
- 复杂度：GD 每步 O(mn)，正规方程 O(n³ + mn²)。n 上万时 GD/共轭梯度占优。

### 1.5 概率解释（为什么偏偏是平方损失）
- 假设 `y^(i) = θ^T x^(i) + ε^(i)`，`ε^(i) ~ N(0, σ²)` i.i.d. → `p(y|x;θ) = N(θ^T x, σ²)`。
- 似然 `L(θ) = Π_i p(y^(i)|x^(i);θ)`，取 log 得
  `ℓ(θ) = −(1/σ²)·J(θ) + const` → **最大化似然 = 最小化 J**：高斯噪声假设是平方损失的全部来源。
- 这条"损失函数 = 某分布假设下的 MLE"逻辑在 L03（伯努利→交叉熵）、L04（指数族统一）重复使用。

## 2. 直觉与常见陷阱
- 直觉：GD 沿等高线走之字形，正规方程一步登天——二者是"迭代 vs 代数"的永恒对照。
- 陷阱 1：忘记特征缩放就谈"GD 收敛慢"。标准化后 J 等高线接近圆，α 可以放大。
- 陷阱 2：SGD 抖动误判为 bug。J 在 α 固定时收敛到 O(α) 邻域而非零点。
- 陷阱 3：对每批数据用伪逆硬解正规方程——数值上 `cond(X^T X) = cond(X)²`，平方条件数会吞掉精度（CSAPP 浮点专题的教训），优先 QR/Cholesky/CG。
- 陷阱 4：截距 θ_0 参与正则化惩罚（下一讲引入 λ 时）——惯例是不惩罚偏置。
