# L11 树与集成 I：决策树、特征选择、剪枝

> Notes Ch.6 §6.1-6.3 · 前置：L09-L10（复杂度语言）· 对应项目：projects/p05_trees_forest

## 1. 数学推导要点

### 1.1 模型与训练问题
- 决策树 = 对特征空间的递归轴对齐划分；根到叶路径是合取规则，叶给出多数类/均值。
- 完美拟合训练集的树总是存在（每样本一叶）——典型高方差假设类，L10 视角：
  轴对齐矩形并的 VC 维随叶子数线性增长。
- 最优树问题是组合爆炸的（NP-hard 类结论），因此一切实现都是**贪心启发式**。

### 1.2 不纯度与分裂准则
- 三兄弟（节点 t 上）：
  - 误分类率 `1 − max_k p_k`；
  - 基尼 `Σ_k p_k(1−p_k)`；
  - 熵/信息增益 `−Σ_k p_k log p_k`，增益 `Δ = H(parent) − Σ_v (n_v/n) H(v)`。
- 关系：误分类率在最坏情况下也单调、但梯度平台多（不敏感）；熵与基尼在 p∈(0,1) 上曲率良好，实践中首选。
- 连续特征：先排序（O(n log n)），对相邻值中点扫描最优切点——信息增益是单变量分段常数，增量式统计即可 O(n log n) 完成。
- 缺失值：代理分裂（C4.5）或按分布分流（XGBoost/LightGBM 默认 learned default direction）。

### 1.3 生长与剪枝
- 生长停止准则：节点样本数/增益阈值/最大深度（预剪枝）。
- **代价复杂度剪枝（CART）**：`R_α(T) = R̂(T) + α|leaves(T)|`，
  自底向上可解出 α 的临界值序列，得到嵌套树序列 → 验证集选一棵（结构风险最小化的树版，呼应 L09）。
- C4.5 的悲观剪枝用二项置信区间估计子树误差，思路同为"用统计不确定性惩罚深度"。

### 1.4 特征选择准则（附录）
- 增益比（C4.5）：`Δ / H(split)`，修正"高基数特征占便宜"（按身份证号分裂增益最大却最蠢）。
- 互信息视角：增益就是 `I(Y; X_j)`——与 L05 朴素贝叶斯的对数似然差是近亲（本讲 §1.2 预告过）。

## 2. 直觉与常见陷阱
- 直觉：树是"if-else 的可微性替代物"——用分段常数逼近；轴对齐 → 决策边界是阶梯，斜线需要很多级。
- 陷阱 1：单棵树极不稳定（bagging 的全部理由，L12）：换 10% 数据树形面目全非。
- 陷阱 2：拿测试集当验证集选剪枝 α——嵌套树序列的选择必须有独立验证数据。
- 陷阱 3：类别特征高基数时 one-hot 让树每层只切一列（退化成链表）；有序编码或 target encoding + OOF（LightGBM 原生类别支持是卖点）。
- 陷阱 4：用不纯度增益比较不同分裂的"大小"时忽略样本量权重 `n_v/n`——实现里必须带上。
- 陷阱 5：树模型输出概率在叶上退化为 {0,1} 附近 → 校准差；需要 L12 的 bagging/boosting 或 Platt 校准（接回 L03 交叉熵）。
