# L16 无监督学习 I：k-means、Mixture of Gaussians 与 EM

> Notes Ch.8 §8.1-8.3 · 前置：L08 PCA（几何），L04（MLE/指数族）· 对应项目：projects/p06_clustering_em

## 1. 数学推导要点

### 1.1 k-means：优化目标与坐标下降
- 目标（失真度）：`J(c, μ) = Σ_i ‖x^(i) − μ_{c(i)}‖²`，同时优化分配 c 与中心 μ。
- 坐标下降两步：
  - E 步：`c(i) = argmin_j ‖x_i − μ_j‖²`（最近中心）；
  - M 步：固定 c，对 μ 求导 → `μ_j = mean{x_i : c(i)=j}`（均值是平方损失的最优点，L02 结论）。
- 每步 J 单调不增且有下界 → 收敛到局部最优；k-means++ 初始化（按 D² 采样中心）把期望近似比抬到 O(log k)。
- 隐含假设：各簇是**等方差球形高斯、体积相近**——k-means 是非对称硬分配（每点只属一簇）+ 圆球假设的 MoG 特例（§1.3 见）。

### 1.2 高斯混合模型（MoG）
- `p(x) = Σ_{j=1}^k Q(j) N(x; μ_j, Σ_j)`；参数 `{Q(j), μ_j, Σ_j}`。
- 完全数据对数似然 `Σ_i log Σ_j Q(j)N(x_i;μ_j,Σ_j)` **不可分解**（log 内求和）→ 无法逐簇 MLE——EM 登场的理由。

### 1.3 EM：隐变量的期望最大化
- 引入责任度 `z^(i) ∈ {0,1}^k`（点 i 来自哪簇，观测不到）。
- E 步：`w^(i)_j := P(z_j=1|x_i;θ) = Q(j)N(x_i;μ_j,Σ_j) / Σ_l ...`；
- M 步（加权 MLE）：`μ_j = Σ_i w^i_j x_i / Σ_i w^i_j`，`Σ_j = 加权协方差`，`Q(j) = 平均责任度`。
- **收敛证明骨架**（Jensen 凹性）：定义 `F(θ, Q分布) = E_z[log p(x,z;θ)]`（Q 为自由变分分布）。
  `ℓ(θ) = F(θ,Q) + KL(q ‖ p(z|x,θ)) ≥ F(θ,Q)`；
  取 `q* = p(z|x,θ_old)` 使 `F(θ_old, q*) = ℓ(θ_old)`；则
  `ℓ(θ_new) − ℓ(θ_old) = [F(θ_new,q*) − F(θ_old,q*)] + [两项 KL 差] ≥ 0`（第一项 M 步非负，第二项 KL 不等式非负）。
- k-means 是 EM 的硬分配极限（Σ→σ²I, σ→0 时 `w_j ∈ {0,1}` 退化为最近中心）。

### 1.4 EM 的一般形式与家族
- 通用两步：E 步算后验 `Q(z) = p(z|x;θ^t)`；M 步 `θ^{t+1} = argmax E_{Q}[log p(x,z;θ)]`。
- 家族树：高斯混合、因子分析（L17）、HMM 的 Baum-Welch（L19）、缺失数据填补、k-means——
  "有隐变量/缺失就想到 EM"是本讲要形成的条件反射。

## 2. 直觉与常见陷阱
- 直觉：EM = "先猜归属，再用归属重估参数"的鸡生蛋循环；每次循环似然只涨不跌。
- 陷阱 1：局部最优敏感：MoG 对初始化比 k-means 更敏感（奇异协方差崩溃 = 一个分量抱住单点，Σ→0 似然→∞）→ 正则 `Σ+εI`、多重启、合并近邻分量。
- 陷阱 2：k 的选择：BIC = `−2ℓ + (参数数)·log m` 或 gap statistics；与 L09 结构风险同一逻辑。
- 陷阱 3：用 k-means 做各向异性/长条簇数据：模型假设违约，结果必错——先看 PCA 投影（L08 的用途！）。
- 陷阱 4：EM 收敛速度：平坦似然峡谷中爬得极慢；"收敛"判据 `Δℓ` 太小常是假收敛。
- 陷阱 5：把责任度 w 当硬标签下游使用：模糊归属是 MoG 的信息量所在，硬切就丢了协方差估计。
