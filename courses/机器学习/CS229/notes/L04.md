# L04 广义线性模型：指数族、Poisson 回归、GLM 拟合算法

> Notes Ch.2 §2.4-2.5 · 前置：L02-L03 · 对应项目：projects/p02_regularization（损失/正则实验共用 GLM 骨架）

## 1. 数学推导要点

### 1.1 指数族
- 定义：`p(y;η) = b(y) exp(η^T T(y) − a(η))`。η 自然参数，T(y) 充分统计量，a(η) 对数配分函数。
- 归一性 ⟹ `E[T(Y)] = a'(η)`，`Var(T(Y)) = a''(η)`：**a 的两阶导生成败矩，指数族的一切矩计算都是一次求导**。
- 成员表（都改写为该形式，练习必做）：伯努利（η=log φ/(1−φ)，a=log(1+e^η)）、
  高斯（固定 σ：η=μ，a=η²/2σ²）、泊松（η=log λ，a=e^η）、指数、gamma、beta。
- Bernoulli(φ) 写成指数族时 T(y)=y，η 是 logit——这正是 L03 sigmoid 的出处。

### 1.2 GLM 三假设（对条件分布而非边缘分布）
1. `Y|X=x ~ ExponentialFamily(η(x))`；
2. 预测目标 `h(x) = E[T(Y)|x]`（常取 `= E[Y|x]`）；
3. `η = θ^T x`（自然参数线性——**链接函数选择的核心**）。
- 导出各模型：高斯→线性回归（恒等链接）；伯努利→逻辑回归（logit 链接）；泊松→Poisson 回归（log 链接，`E[Y|x] = e^{θ^T x} > 0` 天然满足计数约束）。
- 一般拟合算法：给定数据求 `ℓ(θ) = Σ log p(y^(i); η^(i))` 最大。
  对指数族逐样本梯度和 Hessian：
  `∇ = Σ (y − h(x)) x`，`H = −Σ b(η) a''(η) x x^T`（广义 IRLS）→ 对数似然是凹的（凸优化意义下良态）。

### 1.3 Poisson 回归推导示范（考试/面试级）
- `p(y;η) = (1/y!) exp(yη − e^η)`，`E[Y]=e^η` → `h(x)=e^{θ^T x}`。
- `ℓ(θ) = Σ [y^(i) θ^T x^(i) − e^{θ^T x^(i)} − log y! ]`，
  `∇ℓ = Σ (y^(i) − e^{θ^T x^(i)}) x^(i)` ——与 LMS 梯度同形（残差×特征），残差换成了计数残差。
- 应用原型：网页点击数、放射学粒子计数、保险索赔次数（GLM 在精算/流行病学的日常工作马）。

### 1.4 Softmax 回归（多项响应，注意它不是严格 GLM）
- `p(y=j|x) = e^{θ_j^T x} / Σ_l e^{θ_l^T x}`，K 个参数向量。
- 梯度：`∇_{θ_j} ℓ = x (1{y=j} − p_j)`；Hessian 块状、**奇异**（θ 整体平移不变，可固定 θ_K=0）。
- 是逻辑回归的多类推广，也是神经网络输出层的原型（L13/L15 复用）。

## 2. 直觉与常见陷阱
- 直觉：GLM 是"一条直线 + 一个概率假设"的全部组合空间；换损失函数 ≈ 换指数族成员。
- 陷阱 1：**链接函数作用在自然参数 η 上**，不是均值上。说"logistic 链接"其实默认了"自然参数 = logit 均值"这一巧合；log 链接泊松同理。非自然链接会破坏凹性。
- 陷阱 2：对连续目标用 Poisson 回归（或反之）：先问"数据的噪声分布是什么"，再选族——L02 §1.5 的教训反过来用。
- 陷阱 3：softmax 所有 θ_j 初始化相同 → 梯度对称 → 永远学不出类间差别（打破对称性，L13 再讲）。
- 陷阱 4：过离散（overdispersion）：真实计数方差 > 泊松假设的均值，标准误全错；负二项回归是补丁。

- **scikit-learn**：`PoissonRegressor` / `TweedieRegressor(power=...)`（GLM 家族旋钮：power=0 高斯、1 泊松、2 gamma）、`LogisticRegression`/`Softmax 回归 = LogisticRegression(multi_class='multinomial')`。
