# L19 概率图模型：有向/无向图、HMM、前向-后向、Viterbi 与 Gibbs 采样

> 讲义 Graphical Models & HMM（附录/经典 Lecture Notes 2008 系列）· 前置：L05（贝叶斯）、L16（EM）、L04（指数族）· 对应项目：projects/p09_gibbs（Gibbs/HMM 采样实验）

## 1. 数学推导要点

### 1.1 图 = 因式分解 + 条件独立的账本
- 有向图（贝叶斯网）：`P(x_1..x_n) = Π_i P(x_i | Pa(x_i))`；局部 Markov：节点 ⊥ 非后代 | 父。
  d-分离（含对撞 collider 规则：`A→C←B` 时 C 未观测反而让 A、B 相关——直觉杀手，必做烟雾报警器例）。
- 无向图（马尔可夫网/CRF）：`P(x) = (1/Z) Π_C ψ_C(x_C)`，势函数定义在极小团上；
  Z（配分函数）通常不可解——统计物理的硬度正式进入 ML。
- 表达力：任何正概率分布都可写成图模型（Hammersley-Clifford），但**稀疏图 = 稀疏依赖假设 = 可学可推**，回到 L01 归纳偏置。
- 与 GLM 的接口（L04）：因子势取指数族对数线性形式 `ψ = exp(θ^T f)` 即最大熵模型/CRF 家族。

### 1.2 HMM：链式图上的动态规划
- 模型：`π, A（转移）, B（发射）`；平稳分布等性质（附录）一句话带过。
- **前向算法**：`α_t(i) = P(o_1..o_t, q_t=i)`，递推 `α_{t+1} = (α_t A) ⊙ b_{o_{t+1}}`，
  复杂度 O(T·N²) vs 暴力 O(T·N^T)——变量消元的图论版本。
- **后向算法** `β_t(i)`：平滑 `γ_t(i)=αβ/Σαβ = P(q_t=i | 全部观测)`、
  转移对 `ξ_t(i,j)`——Baum-Welch（EM）的 E 步就是求 γ, ξ，M 步重数频数（L16 EM 的序列实例）。
- **Viterbi**：把 Σ 换 max 的半环（max-product），同样 O(TN²)，回溯最优路径——
  与 CS188 搜索/Dijkstra、动态规划课程（6.006）同一定理的不同皮肤。
- 数值：α 连乘下溢 → 缩放（scaling，每步除 Σ）或 log 域（logsumexp，L03 老朋友）；缩放系数之积的倒数 = 似然 1/P(O)。

### 1.3 推断的复杂度地图与采样
- 精确推断：树上 DP 线性；一般图 #P-hard → 变分（L17 mean-field/L17 §1.3 的 q 推广）或采样。
- **Gibbs 采样**：从 `p(x_i | x_{−i})` 逐坐标更新，马尔可夫链平稳分布 = 目标分布（细致平衡易证）。
  在贝叶斯网里条件分布就是"该节点的 CPT × 子节点消息"——图结构自动给出采样器。
- 收敛诊断：burn-in、有效样本数（自相关）、多链（Gelman-Rubin）；与 L02 SGD 的"收敛但抖动"意象互文。
- 对比 SGLD/汉密尔顿蒙特卡洛一句话：Gibbs 是坐标系的 Metropolis-Hastings 特例。

## 2. 常见陷阱与直觉
- 直觉：图模型的语言是"消息"——前向=沿时间传信念，Gibbs=沿坐标传采样，BP=沿边传话；掌握消息传递就掌握一半。
- 陷阱 1：对撞偏置：选择"被劫持者"做样本研究"劫持↔暴雨"必然发现假相关——图论给因果直觉打预防针（通向 Pearl/Judea 因果课）。
- 陷阱 2：HMM 参数初始化随机 → 局部最优；用 k-means 状态预分簇（L16 工具）再初始化发射分布。
- 陷阱 3：前向缩放后忘记似然换算，或 log 域里对 0 取 log；γ 不归一（先 Σ 再除）是作业常见错误。
- 陷阱 4：Gibbs 处理强相关坐标时"随机游走慢"：块 Gibbs/翻转采样是补丁——采样也讲条件数（L02 的幽灵）。
- 陷阱 5：把 CRF 当"HMM 的判别版"随便用：无标注预训练 + 标注微调（远程监督）才是它的生态位。
