# L07 判别学习 II：SVM 对偶形式、KKT 条件、核方法

> Notes Ch.4 §4.4-4.5 + 附录 Convex Optimization & Duality · 前置：L06 · 对应项目：projects/p04_svm

## 1. 数学推导要点（对偶三步走）

### 1.1 软间隔与 Lagrangian
```
min_{w,b,ξ} (1/2)‖w‖² + C Σ_i ξ_i
s.t. y^(i)(w^T x^(i)+b) ≥ 1−ξ_i,  ξ_i ≥ 0
```
- C 越大越不允许违例（hinge 损失的正则化视角：`min (1/2)‖w‖² + C·Σ hinge`）。
- 引入 α_i, β_i ≥ 0：
  `L = (1/2)‖w‖² + CΣξ_i − Σ α_i[y_i(w^T x_i+b)−1+ξ_i] − Σ β_i ξ_i`。

### 1.2 对偶问题
- 驻点条件：`∂L/∂w = 0 → w = Σ α_i y_i x_i`；`∂L/∂b = 0 → Σ α_i y_i = 0`；
  `∂L/∂ξ_i = 0 → C = α_i + β_i`（消去 β：`0 ≤ α_i ≤ C`）。
- 代回得对偶 QP（只依赖 α）：
```
max_α  Σ_i α_i − (1/2) Σ_{i,j} α_i α_j y_i y_j x_i^T x_j
s.t.   0 ≤ α_i ≤ C,  Σ_i α_i y_i = 0
```
- **核技巧入口**：对偶只含内积 `x_i^T x_j` → 替换 `K(x,z) = φ(x)^T φ(z)`，
  永远不必显式计算 φ。`w = Σ α_i y_i φ(x_i)` 仍成立于高维空间。

### 1.3 KKT 与稀疏性（SVM 为何"支持向量机"）
- 互补松弛：`α_i = 0` 或约束紧；`β_i = 0` 或 `ξ_i = 0`。
- 三种角色：α=0 非支持向量；0<α<C 在边界上无违例（决定 b）；α=C 违例者。
- 测试函数：`f(x) = Σ_{i∈SV} α_i y_i K(x_i, x) + b`——稀疏性来自对偶 + KKT，而非任何启发式。
- b 的求法：任取 0<α_j<C 的支持向量，`b = y_j − Σ α_i y_i K(x_i, x_j)`（数值上取平均更稳）。

### 1.4 常用核与超参数
- 线性核（文本高维稀疏首选）、多项式 `(x^T z + c)^d`、RBF `exp(−γ‖x−z‖²)`。
- 合法性：Gram 矩阵半正定（Mercer 条件）。RBF 的 γ→0 退化为线性可分硬间隔世界，γ→∞ 退化为"只记得训练点"的最近邻。
- 复杂度：训练 O(m²·n + m³)（QP 求解，SMO 摊薄常数），测试 O(#SV × 核评估)。

## 2. 直觉与常见陷阱
- 直觉：对偶 = "从约束的反面看问题"——变量从 n 维 w 变成 m 个 α，数据维度消失，只剩内积。
- 陷阱 1：核与 C/γ 联合网格搜索时把训练误差当指标：γ 很大的 RBF 几乎能背下任意标签（一致性？L09 会正式讨论——记住万能逼近不等于泛化）。
- 陷阱 2：用非 PSD 的"核"（如 `cos` 距离矩阵随意拼接）→ QP 非凸，求解器崩。
- 陷阱 3：类别不平衡时 C 对两类一视同仁：用 `class_weight` 或 `C_{y=1}=C/π_1` 式再平衡，否则支持向量全在多数侧。
- 陷阱 4：m > 10⁴ 还上核 SVM：随机特征（Rahimi & Recht）或线性近似是现代默认方案。
- 陷阱 5：忘记核机器同样需要标准化/中心化（RBF 对尺度敏感；多项式对 b 项符号敏感）。
