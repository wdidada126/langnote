# L10 学习理论 II：VC 维、有限假设类界

> Notes Ch.5 + 附录 VC Dimension · 前置：L09 · 对应项目：无直接项目（理论讲次，p02 讨论区延伸）

## 1. 数学推导要点

### 1.1 从 |H| 到"有效假设数"
- L09 的界含 `log|H|`；实参数假设类 |H| 不可数，界为空话。
- 关键观察：对固定 m 个点，h∈H 只能产生至多 `2^m` 种标注模式（dichotomies）。
  定义增长函数 `Π_H(m) = max_{x_1..x_m} |H 在这 m 点上诱导的标注集|`。
- Sauer-Shelah 引理：若 Π_H(k) < 2^k（不能打碎某个 k 点集），则
  `Π_H(m) ≤ Σ_{i=0}^{k−1} C(m,i) = O(m^{k−1})` ——指数坍缩成多项式。

### 1.2 VC 维
- 定义：H 的 VC 维 = 能被 H 打碎（shatter，实现全部 2^d 种标注）的最大点数 d。
- 算例（背下来）：
  - 直线上的区间分类 {x: a≤x≤b}：VC=2；实轴射线 `{x≥a}`：VC=1。
  - R² 中直线分类：VC=3（三点可打碎；四点凸/凹位置论证不可，用 Radon 定理一句话）。
  - 半空间 R^n：VC = n+1。
  - k 个 R² 矩形的并：VC = 4k；n 个布尔变量的合取范式：O(n log n) 级。
- 泛化界（无限 H 版）：以概率 ≥ 1−δ，对所有 h∈H：
  `γ(h) ≤ ε̂(h) + O(√((d log(m/d) + log(1/δ))/m))`，d = VC(H)。
- 与 L09 的界同构，只是 `|H| → (m/d)^d`：**复杂度从基数变成打碎能力**。

### 1.3 间隔维与 SVM 的联系
- 对 ‖w‖≤B、球半径 R 的线性分类器，间隔维 ≤ min(n, R²B²/γ²)——把 L06 §1.3 的承诺变成定理。
- SVM 最大化 γ ⟺ 最小化有效 VC 维 ⟺ 结构风险最小的具体化：理论与算法在此握手。

### 1.4 No Free Lunch（附录常配）
- 对一切分布上的学习算法配对定理：任何算法的期望误差与随机猜测算法相同——
  **可学习性来自对 H（即世界）的先验限制**，"无假设的学习"在数学上不存在。
  这是 L01 "归纳偏置"论述的定理化。

## 2. 直觉与常见陷阱
- 直觉：VC 维问的是"你的模型最多能把多少个点任意指鹿为马"；能瞎标 30 个点方向的模型，就需要 30 个量级的样本去说服。
- 陷阱 1：用 VC 维界算实际样本数：界中的常数松到不可用，它给的是**阶**与**直觉**，不是预算表。
- 陷阱 2：把参数个数当 VC 维： sine 模型 `sin(ωx)` 一个参数可打碎无限多点（VC=∞）——"参数量=复杂度"是错觉。
- 陷阱 3：对 SVM 说"VC 维=支持向量数"：正确的是间隔界用 #SV/间隔半径表述；网络传言失真。
- 陷阱 4：深度学习时代 VC 界与"过参数化仍泛化"的表面矛盾：需要隐式正则/谱范数界等现代理论（CS229M/研究前沿，本科阶段不必恐慌）。
