# L05 生成式学习算法：GDA、朴素贝叶斯、LDA/QDA

> Notes Ch.3 · 前置：L02-L04 · 对应项目：projects/p03_lda_naive_bayes

## 1. 数学推导要点

### 1.1 生成式路线总纲
- 建模 `P(x|y=k)` 与 `P(y)`（联合分布），推断时贝叶斯反推：
  `P(y=k|x) = P(x|y=k)P(y=k) / Σ_j P(x|y=j)P(y=j)`。
- 好处：小样本可用（每类各自估计，不需全空间覆盖）、可采样生成新样本、天然处理缺失特征。

### 1.2 高斯判别分析 GDA
- 假设 `x|y=k ~ N(μ_k, Σ)`（共享协方差！），`y ~ Bernoulli(φ)`。
- MLE：`φ = (1/m)Σ 1{y^(i)=1}`，`μ_k = 类内均值`，`Σ = 类内离差加权平均`。
- 判别：`log P(y=1|x)/P(y=0|x) = θ^T x + θ_0`，**二次项全部消掉**（因 Σ 相同）→
  GDA 决策边界是线性的，且**逻辑回归的系数可由 GDA 参数显式表达**。
- 深刻结论（Ng 强调）：GDA 的"强假设 + 精确解"与逻辑回归的"弱假设 + 数值优化"在
  假设成立时殊途同归；假设不成立时逻辑回归更稳。这是**生成式 vs 判别式**的第一次正面交锋。

### 1.3 朴素贝叶斯
- 关键假设：特征条件独立于标签，`P(x|y) = Π_j P(x_j|y)`（特征为词袋计数/二值时多项/伯努利 NB）。
- 文本分类：`P(w_j|c)` 用计数 + **拉普拉斯平滑** `(count+α)/(N+αV)`，`log P` 累加防下溢。
- 为什么"朴素"还work：分类只需要 argmax，条件独立的错误在对数几率里大量抵消；
  但**概率值本身 calibration 很差**（趋向 0/1）。
- 词袋 vs 语言顺序：NB 对词序不敏感，是 bag-of-words 假设的代价。

### 1.4 LDA 与 QDA
- LDA = GDA 的多类版（共享 Σ）；QDA 允许 `Σ_k` 不同 → 决策边界退化为二次。
- 参数量：Σ_k 各自估计需 O(Kn²) 参数 → 小样本高方差。**LDA 是"低方差高偏差"选项，QDA 反之**——偏差-方差权衡在本讲以协方差共享的方式具体化。

## 2. 直觉与常见陷阱
- 直觉：NB 是"每个特征各自投票"的贝叶斯版；GDA 是"每类一团高斯，边界落在两团中间"。
- 陷阱 1：零概率杀死整条链：一个未见过的词频=0 → 整类后验=0。拉普拉斯平滑 α 是超参数，验证集调。
- 陷阱 2：朴素假设与特征复制：把同一特征抄两遍，"意见"被加权两次——NB 对共线特征极敏感（与逻辑回归恰好相反）。
- 陷阱 3：GDA 里用总协方差而不是**类内合并**协方差；LDA 的 Σ 不含类间散度，这是与 Fisher 判别（L08 延伸）的分水岭。
- 陷阱 4：高维直接估 Σ 病态 → 对角协方差（= 朴素贝叶斯高斯版）或 shrinkage（Ledoit-Wolf）是工程标准答案。
