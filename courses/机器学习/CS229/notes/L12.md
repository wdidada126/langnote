# L12 树与集成 II：随机森林与 boosting、bagging、AdaBoost、XGBoost/GBDT

> Notes Ch.6 §6.4-6.6 · 前置：L11 · 对应项目：projects/p05_trees_forest

## 1. 数学推导要点

### 1.1 Bagging 与随机森林：方差的集体治疗
- Bootstrap：有放回抽 m 个训练集，各自建树，平均输出。
- 方差计算核心（等相关模型平均）：`Var((1/B)Σ f_b) = σ̄²/B + (1−1/B)·ρ̄σ̄²` →
  B→∞ 时方差收敛到 `ρ̄σ̄²`：**bagging 只能消独立部分，消不掉树之间的相关性**。
- 随机森林的关键补丁：每次分裂在随机 m_feat 个特征子集里选最优 → 去相关 →
  `ρ̄` 下降，才让 B→∞ 有意义。`m_feat` 回归≈n/3、分类≈√n 是经验默认。
- OOB 误差：bootstrap 每样本约 63.2% 概率被抽中 → 36.8% 天然做验证集，免费 CV。
- bagging 几乎不降偏差（每棵树期望函数 ≈ 同一目标）——集成理论的第一半句。

### 1.2 Boosting 与 AdaBoost：偏差的逐个击破
- 框架：`F_m(x) = Σ_{t=1}^m α_t h_t(x)`，每轮拟合**当前残差/加权错误**。
- AdaBoost（二分类，h_t ∈ {±1}）：
  - 加权错误 `err_t = Σ_i w_i^{(t)} 1{h_t(x_i)≠y_i}`，`α_t = ½ log((1−err_t)/err_t)`，
    权重更新 `w_i^{(t+1)} ∝ w_i^{(t)} exp(−α_t y_i h_t(x_i))`（分类正确则指数衰减）。
  - 定理（推导要点）：训练误差被指数界 `Π_t 2√(err_t(1−err_t)) = exp(−2 Σ γ_t²)` 控制，
    γ_t = ½ − err_t 为弱学习优势 —— "弱可学"能放大成"强可学"（PAC 提升定理）。
  - 等价的损失视角：AdaBoost = 前向分步最小化**指数损失** `Σ exp(−y_i F(x_i))`，
    与 L03 交叉熵同族 → 对标签噪声敏感（对异常点疯狂加权），这是它的阿喀琉斯之踵。
- 间隔理论（Schapire-Singer）：boosting 泛化界只依赖间隔分布与 #基函数，**不依赖基学习器个数** ——对"训练误差为 0 后仍继续提升"现象的理论回答（呼应 L09-L10）。

### 1.3 GBDT / XGBoost：把 boosting 搬进二阶梯度世界
- Gradient Boosting：每轮用新树拟合负梯度（pseudo-residual）`r_i = −∂ℓ(y_i, F(x_i))/∂F`；
  函数空间视角 = 对 `Σ ℓ(y_i, F(x_i))` 做"树形状的梯度下降"（与 L02-L03 的欧氏梯度下降完全同构）。
- XGBoost 目标（第 t 轮，二阶泰勒）：
  `Σ_i [g_i f_t(x_i) + ½ h_i f_t²(x_i)] + γ·叶子数 + ½λ‖w‖²`，
  最优叶值 `w_j* = −Σ_{i∈j} g_i / (Σ_{i∈j} h_i + λ)`，分裂增益 `½ Σ_j (G_j²/(H_j+λ)) − parent 项 − γ`。
  **g、h 是任二阶可微损失的通用接口**（logistic: g=p−y, h=p(1−p)）。
- 工程三件套：直方图分箱（LightGBM GOSS/EFB）、列采样（随机森林思想回归）、正则项 γ/λ 显式控制复杂度。
- HistGradientBoosting（sklearn 1.x 默认强基线）证明：GBDT 是"结构化数据默认答案"（TabPFN/表格 Transformer 挑战者尚年轻）。

## 2. 直觉与常见陷阱
- 直觉口诀：**bagging 降方差、boosting 降偏差**；森林=民主投票，boosting=错题本接力。
- 陷阱 1：boosting 轮数不是超参上限而是过拟合旋钮：early stopping（验证损失回升即停）标配；lr=0.05~0.1 时树要更多。
- 陷阱 2：AdaBoost/GBDT 在标签噪声大的任务上崩：换 `loss='linear'`（Huber）或 MAE 型损失、加大 min_child_weight。
- 陷阱 3：树集成概率输出未校准 / 类别不平衡下 AUC 好看 PR 难看——校准 + PR 曲线（L03 陷阱 2 家族）。
- 陷阱 4：把 OOB 与 CV 混用：OOB 只对 bootstrap 森林成立；换模型就失效。
- 陷阱 5：特征泄漏给 GBDT（时间戳、ID 列、未来信息）：树对单列分裂不设防，SVM/LR 早被你气死了它还能用。
