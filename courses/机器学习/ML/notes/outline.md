# Coursera ML（2022）提纲

> 骨架级要点，正文笔记待逐讲展开。

## C1M1 机器学习简介
- 监督学习（有标签：回归/分类）vs 无监督学习（无标签：聚类/关联）。
- 数据驱动范式：模型 + 损失 + 优化三要素。
- 应用案例贯穿全程：房价预测、猫狗识别、推荐。

## C1M2 线性回归与成本
- 模型 f(x)=wx+b；平方误差成本 J(w,b)。
- 成本函数凸性 ⇒ 梯度下降可达全局最优的直觉。
- 多特征向量化的好处（并行计算）。

## C1M3 梯度下降
- 更新规则：参数沿负梯度方向、学习率 α 决定步长。
- 同时更新所有参数；特征缩放让等高线变圆加速收敛。
- 批量/随机/小批量的区别与取舍。

## C1M4 线性回归实践
- Python/NumPy 向量化实现；广播机制。
- normal equation 闭式解与其 O(n³) 代价。
- 作业：预测房价（多特征 + 缩放）。

## C1M5 逻辑回归
- 假设函数 g(z)=sigmoid；分类输出概率化。
- 决策边界由 wx+b=0 决定；非线性靠特征构造。
- 交叉熵损失（凹性保证可优化）+ L2 正则化防过拟合。

## C2M6-7 神经网络
- 从逻辑回归堆叠到多层网络；激活函数非线性。
- 前向传播矩阵形式；反向传播 = 计算图 + 链式法则。
- 作业：手写数字识别；PyTorch 实现与训练循环。

## C2M8 应用 ML 建议
- train/dev/test 划分；评估指标按任务定制（1:100 代价不对称）。
- 偏差/方差诊断 + 学习曲线；误差分析驱动迭代。
- 迁移学习：先复用预训练模型再自训。

## C2M9 决策树与树集成
- 信息增益（熵）选择分裂特征；剪枝防过拟合。
- 随机森林：bootstrap + 特征随机；XGBoost：梯度提升工程化。
- 树模型 vs 神经网络的选择依据（数据量/特征类型）。

## C3M10 无监督学习
- k-means：分配-更新迭代、随机初始化、肘部法选 k。
- 异常检测：高斯密度 + ε 阈值；vs 类别不平衡分类。
- 降维与可视化（ PCA 思想）；作业：数据集异常检测。

## C3M11 推荐与强化学习
- 协同过滤/矩阵分解：u·v + 偏差项，梯度下降学参数；内容推荐。
- 强化学习：状态/动作/奖励、马尔可夫决策链、价值函数。
- Q-learning 与策略梯度入门（直升机/月球着陆器作业）。
