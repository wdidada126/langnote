## 二、为什么学

1. **"信息"是 CS 的最底层量纲**：比特、冗余、熵、信道容量决定了压缩、传输、存储、加密、机器学习的理论天花板。
2. MIT 面向大一新生的入门课，**门槛低但视野高**：一门课同时打通香农信息论与热力学熵（Maxwell 妖、Landauer 原理）。
3. 为后续 MacKay 信息论、CS229/统计学习（KL 散度、互信息、信息瓶颈）、网络与存储（纠错码、纠删码）、系统（磁盘/内存 ECC）提供共同语言。
4. Penfield 的教材刻意避免测度论与高深数学，是**自学信息论的最佳第一站**。
