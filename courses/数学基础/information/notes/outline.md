# notes/outline.md — MIT 6.050J 信息论与熵（骨架）

## L1 信息过载
- 信息的三种朴素含义：数据 / 意义 / 价值；本课只量化"消除的不确定性"
- 香农理论的革命性：把语义搁置，只关心符号与概率
- 现代背景：视频、模型权重、日志爆炸，带宽与存储都是硬的

## L2 概率与意外程度
- 越不可能的消息携带越多信息：I = log(1/p)
- 对数为何是唯一合理选择：独立消息的信息可加性
- 均匀分布信息量最大，确定事件信息量为 0

## L3 比特与编码
- 比特 = 二元选择的单位；字母表大小与所需比特数 log2 M
- 定长码的浪费：不等概率信源用定长码达不到熵
- 编码三要素：信源、码表、可解码性（唯一/前缀）

## L4 熵的定义与性质
- H(p) = −Σ p_i log2 p_i = 平均信息量 = 定长码最短长度下界
- 凹性、对称性、极值 H ≤ log M（均匀时取等）
- 微分熵可为负；离散/连续熵的区别要提前讲清

## L5 条件熵与互信息
- H(X|Y) = H(X) − I(X;Y)；互信息度量"共享的不确定性"
- 链式法则与数据处理不等式（DPI）的直觉
- KL 散度：非对称、恒非负、Gibbs 不等式

## L6 信源编码定理
- 无失真压缩的平均码长下界 = 熵；块编码可任意逼近
- 典型序列思想：绝大多数长序列概率集中在 2^{nH}
- 与大数定律的联系（CS126 的先修接口）

## L7 Huffman 与 Kraft 不等式
- 前缀码 ⟺ Σ 2^{-l_i} ≤ 1
- Huffman 反复合并最小两节点，最优异前缀码
- 手算一例 + 与熵比较冗余；Fano 不等式与失败案例

## L8 实际压缩
- 字典法（LZW）、上下文建模、算术编码：逼近熵的工程手段
- 相关性与冗余：图像/音频/文本中可压缩度的来源
- 有损压缩：率失真理论的入口（D(R) 折中）

## L9 信道模型
- 信道三要素：输入字母表、转移概率、输出字母表
- BSC(p)、BEC(p)、AWGN 的基本参数与容量
- 信道与信源分离：编码定理成立的前提

## L10 噪声与误码
- 为什么"重复传输"效率极低：1/3 重复只能勉强降错
- 硬判决与软判决；误码率与 SNR 的关系
- 错误检测 vs 错误纠正 vs 错误避免（ARQ/FEC）

## L11 香农信道容量定理
- C = max_{p(x)} I(X;Y)：只要 R < C 就能以任意小错误传输
- 随机编码论证的直觉：存在性证明而非构造
- 工程含义：把"纠错"与"压缩"变成两个独立可优化的模块

## L12 带宽与香农公式
- C = B log2(1 + S/N)：功率换成带宽，带宽换成功率
- 为什么"信息不能无限快传"：物理层天花板
- 与 EE120/6.007 的频域分析、采样定理衔接

## L13 线性纠错码与汉明码
- 生成矩阵 G、校验矩阵 H、码空间作为向量空间（18.06 应用）
- 最小距离 d 与纠错能力 t = ⌊(d−1)/2⌋
- 汉明码 (7,4)：一次纠错、 syndrome 译码

## L14 从汉明到现代码
- 奇偶校验、RS 码（有限域多项式）、卷积码与维特比译码概览
- 逼近容量的码：Turbo 码与 LDPC 的核心思想（迭代 + 稀疏图）
- 纠删码在分布式存储中的使用（15-418/6.824 呼应）

## L15 密码学与信息量
- 一次性便笺：|密钥| ≥ |明文| 才能完美保密
- 香农保密定理：H(K|C)=H(K), H(P|C)=H(P)
- 唯一解距离、冗余度与破解难度；现代密码为何转向计算安全

## L16 热力学熵
- 玻尔兹曼 S = k ln W：微观状态数与宏观无序
- 吉布斯熵与香农熵形式一致（差一个常数与单位）
- 温度的信息学定义：1/T = ∂S/∂E

## L17 Maxwell 妖与 Szilárd 引擎
- 妖"用信息换熵"，看似违反热二定律
- 关键在于妖必须测量、存储、最终擦除信息
- 信息与物理量的可互换性：这是本课最深刻的部分

## L18 Landauer 原理
- 擦除 1 bit 至少耗散 kT ln2 热量（约 3×10⁻²¹ J @ 室温）
- 可逆计算（Toffoli/CCNOT）如何绕过该下界
- 对 CPU 功耗墙、量子计算与超低功耗架构的现实意义

## L19 生物中的信息
- DNA：4 字母表、冗余密码子、纠错机制
- 感官通道的带宽测量（视觉/听觉比特率数量级）
- 神经编码中的信息量估计（互信息方法）

## L20 计算的极限与总结
- 能量-比特-时钟三条墙：物理定律给出的下限
- 复盘：熵（信源）→ 容量（信道）→ 编码（工程）→ 物理（代价）
- 通往 MacKay 与统计学习的路线图
