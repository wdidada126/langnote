## 二、为什么学

1. **CS 的连续数学底座**：梯度、链式法则、多元偏导、拉格朗日乘子直接支撑机器学习优化（CS229、EE364A）、图形学（GAMES101/15-462 的光照与几何）、物理仿真。
2. **18.02 是多门课的先修**：数值分析（18.330 的数值微积分与微分方程）、信号与系统（积分变换、复指数）、概率论（多元密度函数的重积分）。
3. **建立"极限—逼近"思维**：泰勒展开、线性近似是理解误差分析、复杂度中连续近似、数值稳定性的直觉来源。
4. MIT Notes 的特点是**抓住本质少刷题**，适合自学，性价比高。
