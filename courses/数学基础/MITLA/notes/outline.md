# notes/outline.md — MIT 18.06 线性代数（骨架）

## L1 几何视角与列向量观点
- 方程组的两种图像：行 = 超平面交点；列 = 向量 b 能否由 A 的列线性表出
- 线性组合 / 张成（span）是全书基本语言
- 矩阵-向量乘法 = 列的线性组合，行点乘只是记号

## L2 消元法与矩阵乘法
- 高斯消元 → 上三角 U；主元为 0 需行交换（PA=LU）
- 五种乘法观点（行×列、列组合、行组合、分块、秩一和之和）
- A=LU 的意义：把"复杂变换"分解成"下三角回代 + 上三角消元"

## L3 逆矩阵与矩阵作为变换
- 可逆 ⟺ 只有零解 ⟺ 满秩 ⟺ 行列式非零（一一对应）
- 逆 = 反向变换；(AB)⁻¹ = B⁻¹A⁻¹ 的顺序性
- 转置、对称、置换矩阵等基础矩阵族

## L4 向量空间与子空间
- 子空间判定：含零向量、对加法和数乘封闭
- 关键例子：N(A)（解空间）、C(A)（值域）、R^n、零空间
- 3B1B 视角：空间 → 子空间 → 基 → 坐标

## L5 求解 Ax=0
- 行化简到 R，主变量/自由变量分离
- 特解个数 = 自由变量个数 = n − r；零空间维数
- 简化行阶梯形 R 是 A 的"最干净替身"

## L6 求解 Ax=b
- 可解 ⟺ b ∈ C(A) ⟺ [R d] 中零行对应 d 分量为 0
- 通解 = 特解 + 零空间任意向量（仿射空间）
- 方阵情形：满秩 ⟹ 唯一解；秩亏 ⟹ 无解或无穷解

## L7 线性无关、基与维数
- 无关 ⟺ 唯一零线性组合；列的秩 = 行的秩（关键定理）
- 基 = 无关 + 张成；维数定理 r + (n−r) = n
- 行空间维数 = 列空间维数 = 秩

## L8 四个基本子空间
- R^n：行空间 C(Aᵀ) ⊕ 零空间 N(A)；R^m：列空间 C(A) ⊕ N(Aᵀ)
- 左零空间 = "约束方程"的来源：yᵀA=0 ⟹ yᵀb=0
- 这张图是理解最小二乘与对偶的地图

## L9 正交性与 QR
- 正交补的定义与维数互补；投影矩阵 P = A(AᵀA)⁻¹Aᵀ
- Gram-Schmidt 正交化 → Q 正交矩阵、R 上三角
- QR 是数值稳定的最小二乘基础（与 L2 的 LU 对照）

## L10 最小二乘
- 无解时求"最好"解：min ‖Ax−b‖²
- 正规方程 AᵀA â = Aᵀb；b̂ = Aâ 是 b 在 C(A) 上的投影
- 多项式拟合/线性回归 = 第一个 ML 模型；协方差矩阵出现 (AᵀA)

## L11 行列式
- 四条公理（线性、交换变号、det I=1）→ 全部性质
- 展开式、余子式、det(AB)=detA·detB
- 几何：体积缩放因子；|det|=0 ⟺ 降维 ⟺ 奇异

## L12 特征值与特征向量
- Ax=λx；特征方程 det(A−λI)=0
- 特征向量给出"变换不变方向"，特征值给出该方向缩放
- 迹 = 特征值之和，det = 特征值之积

## L13 对角化与矩阵幂
- A = SΛS⁻¹ ⟺ 有 n 个无关特征向量
- A^k = SΛ^k S⁻¹ → 差分方程 x_{k+1}=Ax_k 的解析解
- 幂法（power iteration）求主特征向量的算法雏形

## L14 矩阵指数与微分方程
- e^{At} = Σ (At)^k/k!；解 dx/dt = Ax 为 x = e^{At}x(0)
- 对角化使 e^{At} 逐特征值计算 e^{λt}
- 稳定性由 Re(λ) 的符号决定（控制与物理的联系）

## L15 对称矩阵与谱定理
- 实对称 ⟹ 特征值全实、特征向量可正交归一：A = QΛQᵀ
- 正交对角化 = 旋转到主轴坐标系
- 谱定理是 PCA、二次型、振动模态的共同底座

## L16 正定矩阵
- 定义 xᵀSx > 0（所有非零 x）；等价：λ>0 ⟺ 主元>0 ⟺ 左上子式>0
- Cholesky 分解 S = LLᵀ（对称正定专用，省一半算力）
- 正定 ⟺ f(x)=xᵀSx 是碗形 → EE364A 的凸性判据

## L17 半正定与协方差矩阵
- 数据矩阵中心化后 C = AᵀA/n 半正定；特征值 = 各方向方差
- PCA 即对角化协方差矩阵；主成分 = 特征向量
- 相关性、白化、马氏距离都从这里来

## L18 奇异值分解 SVD
- A = UΣVᵀ，U、V 正交，σ_i ≥ 0；不必方阵、不必对称
- V 是行空间基、U 是列空间基、σ 是两者的缩放比
- 特征值 ⊂ 奇异值的特例（对称半正定时重合）

## L19 SVD 的应用：低秩与伪逆
- Eckart–Young：最优秩 k 近似由前 k 个奇异值给出
- 伪逆 A⁺ = VΣ⁺Uᵀ → 最小范数最小二乘解
- 应用：图像压缩、推荐系统（矩阵分解）、去噪、潜在语义分析

## L20 范数、条件数与稳定性
- 向量范数诱导矩阵范数 ‖A‖ = max ‖Ax‖/‖x‖
- 条件数 κ = σ_max/σ_min：误差放大上界
- 为何数值课上要避免正规方程、改用 QR/SVD（18.330 接口）

## L21 线性代数的工程与数据应用
- PageRank：随机矩阵主特征向量 + 幂迭代
- 图拉普拉斯 L = D−A：Fiedler 向量与谱聚类
- 神经网络一层 = 线性映射 + 激活；反向传播 = 雅可比链式乘积

## L22 复盘：一张图看懂线性代数
- 秩与可解性 → 子空间分解 → 正交投影 → 最优解
- 特征值/奇异值 = 在不同对称性假设下"找到最简单坐标"
- Strang 的核心心法：**每次变换都问"哪个空间、哪个基"**
