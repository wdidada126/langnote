## 二、为什么学

1. **CS 中使用频率最高的一门数学**：图形学变换、检索与推荐（矩阵分解）、深度学习（一层线性变换 + 非线性）、PageRank（幂迭代求特征向量）、编译器数值分析、量子计算全部建立在 18.06 之上。
2. **四个基本子空间是"看问题的坐标系"**：秩、零度、可解性、最小二乘、对偶性一次性打通，后续学凸优化与机器学习会省掉大量认知成本。
3. **SVD / 特征分解 = 数据科学的显微镜**：PCA、低秩近似、数值稳定性、矩阵条件数都直接来自这里。
4. Strang 的教学风格强调"先几何后形式"，非常适合自学，也是把线性代数"用活"的最佳入门。

## 三、先修与知识联系

```
高中代数（行列式、方程组）
        │
        ▼
   18.06 线性代数  ── 向量空间 / 子空间 / 特征值 / SVD / 正定性
        │
        ├──► 18.02 多元微积分：梯度与 Hessian 是线性化矩阵；二次型判定极值
        ├──► 18.330 数值分析：LU/QR/幂迭代/正交性 → 数值算法主体
        ├──► EE364A 凸优化：Hessian 正定 ⟹ 凸；对偶 = 子空间正交分解
        ├──► CS126 / CS70 / 6.042J：马尔可夫链、PageRank、纠错码（有限域上的线性代数）
        ├──► CS229 / CS231n：反向传播 = 雅可比乘积；PCA / 注意力矩阵
        └──► 6.050J / MacKay 信息论：协方差矩阵、维纳滤波、信源子空间
```
