# Algorithms I & II 讲义要点（骨架）

> 对应 README 的 L1–L12（Part I 六周 + Part II 六周）。每条为骨架级要点，正文待填充。

## L1 算法分析
- 三种成本测定手段：操作计数、增长阶（~cN^b）、经验拟合；Big-O/Big-Θ 的语义差别。
- 空间与时间同为约束：随机访问模型（uniform cost）与其局限。
- 摊还分析的入门例子：动态数组几何扩容 → 均摊 O(1)。
- 记号与"最坏/平均/摊销"三个维度不要混用。

## L2 基础排序
- 选择排序、插入排序：O(N²) 但插入排序对近乎有序数据与短数组极快。
- 希尔排序：递减增量序列打破"逆序对"瓶颈，经验 O(N^1.5) 量级。
- 排序的网络可视化与"为什么先写朴素版"的教学意图。
- 稳定性与 in-place 的最初定义。

## L3 归并与快排
- 归并排序：分治 + 辅助数组，O(N log N) 最坏保证，代价是空间。
- 快排：切分不变式、随机化避免最坏、递归深度与栈开销。
- 三路切分（Dutch national flag）处理大量重复键。
- 工程细节：小数组切换插入排序、尾递归优化、median-of-three。

## L4 优先队列与堆
- 完全二叉树的数组表示：parent/child 下标关系与缓存友好性。
- swim/sink 的不变式：堆序 + 完全性；insert/delMax 都是 O(log N)。
- heapify 自底向上 O(N)（与 6.006 一致）。
- 应用：事件驱动模拟、Top-K、多路归并、Huffman。

## L5 无序符号表（BST）
- BST 的查找/插入/删除（删除用后继替换）与中序有序遍历。
- 随机插入下平均树高 ~1.39 log N，有序输入退化为链。
- 与哈希表的选型：是否有序遍历、是否范围查询。
- 递归在树算法里的"信任递归"写法。

## L6 平衡树（2-3 树 → 红黑树）
- 2-3 树用"允许 3-节点"保证对数高，旋转保持中序不变。
- 红黑树是 2-3 树的二叉表示；LLRB 用左倾红链接简化实现。
- 三条性质 → 树高上界 2 log N 的论证路径。
- 与 Java TreeMap、Linux CFS 的对应关系；跳表作为随机化替代。

## L7 无向图与 DFS
- 图的数据结构选型：邻接表 vs 邻接矩阵 vs 隐式图。
- DFS 解决连通分量、单路径、环检测；递归栈=显式栈。
- BFS 解决无权最短路；两者代价 O(V+E)。
- 双连通分量/桥的概念（延伸）。

## L8 有向图
- 有向图的可达性、强连通分量（Kosaraju：反向图 + 完成时间序）。
- DAG 与拓扑排序：调度、编译依赖、数据流分析的基石。
- 环检测与"拓扑排序存在 ⇔ 无环"。
- 应用：课程作业顺序、Gradle/Maven 依赖、Spark DAG。

## L9 最小生成树
- Cut 定理是所有贪心 MST 算法的正确性来源。
- Kruskal：排序 + 并查集，稀疏图友好；Prim(lazy)：PQ + 延迟删除。
- Prim(eager)：索引优先队列做到 O(E log V)。
- 并查集带权/加权快速合并 + 路径压缩（近线性）。

## L10 最短路径
- 松弛（relaxation）是统一视角：DAG、Dijkstra、Bellman-Ford 都是不同顺序的松弛。
- Dijkstra 需要非负权；贪心正确性依赖"未定集合中最小者已定"。
- Bellman-Ford 处理负权并检测负环；SPFA 的工程实践与风险。
- 归约技巧：把非图问题建模为最短路（ Seam carving、A* 的启发式）。

## L11 字符串
- 键索引计数 → LSD/MSD 基数排序：定长字符串线性排序。
- 三向字符串快排：通用且实践快，避免 MSD 的递归小数组开销。
- Trie/RST 与前缀检索：自动补全、路由表；空间优化（压缩 Trie）。
- 与符号表的统一视角：字符串即 char 数组的有序键。

## L12 子串搜索、正则与压缩
- KMP：前缀函数/DFA 实现 O(M+N)，"永不回退文本指针"。
- Boyer-Moore：坏字符 + 好后缀，实践次线性；Rabin-Karp：滚动哈希，适合多模式。
- 正则的 NFA 模拟（Thompson 构造）与 DFA 预编译的取舍。
- 压缩：Huffman（变长最优前缀码）、LZ 系列与 Unicode 编码基础。
