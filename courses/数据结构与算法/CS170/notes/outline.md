# CS170 讲义要点（骨架，按 cs170.org Notes 主题）

> 每条为骨架级要点；CS170 作业以 LaTeX 写证明，笔记正文应留"定理—证明—反例"三件套位置。

## L1 导论与增长阶
- 算法 = 有限步骤的机械过程；效率比较必须在增长阶层面而非秒表层面。
- O/Ω/Θ/o 的精确定义与"常数隐藏"带来的误导（大常数算法不实用）。
- 递归式求解三板斧：展开、递归树、主定理（含非正则情形的边界）。
- 建模习惯：先写输入规模 N 是什么，再谈复杂度。

## L2 分治 I
- 分治成本 = 子问题数 × 合并代价；用递归树看清谁主导。
- 大整数乘法：从 O(n²) 到 Karatsuba O(n^1.585)，理解"少一次乘法"的价值。
- Strassen 矩阵乘法 O(n^2.807)：算法可以靠代数技巧改进。
- 主定理使用注意：正则条件与多参数问题不适用。

## L3 分治 II 与几何
- 最近点对 O(n log n) 的关键：strip 内每点最多比较常数个后继。
- 平面扫描 + 有序结构解决区间/线段相交问题。
- 分治与递推式设计的"预处理/后处理不对称"技巧。
- 记住：几何算法的下界往往来自元素唯一性归约。

## L4 下界与决策树
- 决策树模型：排序的比较下界 Ω(n log n) 来自叶子数 ≥ n!。
- 对抗论证（adversary）：对任意算法构造坏输入。
- 不同计算模型的下界不可迁移：换模型就可能突破。
- 下界证明写法：归约到一个已知有下界的问题（如 element uniqueness）。

## L5 随机化排序与选择
- 随机快排：期望 O(n log n) 来自逆点对指示器变量的期望线性性。
- 最坏情况概率极小（Chernoff + union bound），实践中无需 pivot 花招。
- Randomized Select：每次期望砍掉 3/4，线性期望时间求中位数。
- Las Vegas（答案必对、时间随机）与 Monte Carlo（时间固定、答案可错）区分。

## L6 图模型与遍历
- 邻接表/邻接矩阵/隐式图三选型；遍历代价 O(V+E) 是"图算法基线"。
- BFS 给无权最短路；DFS 给拓扑序、连通分量、环与双连通分解。
- 递归 DFS 的栈深度风险 → 显式栈工程写法。
- 用"遍历顺序"表达规格：pre/post order 能解的问题清单。

## L7 权重图与 Dijkstra
- 贪心选择性质：未定集中最小 tentative 距离已确定（非负权必要条件）。
- 用二叉堆 O(E log V)，斐波那契堆 O(E + V log V) 只在稠密图有意义。
- A* 可采纳启发式保证最优，一致性避免重复扩展。
- 负权场景切 Bellman-Ford，并用 V-1 轮解释 tightness。

## L8 MST 与并查集
- 割性质一句话推出 Kruskal/Prim/Borůvka 全部正确性。
- Kruskal = 排序 + 并查集；瓶颈生成树即 MST。
- Union-Find：按秩合并 + 路径压缩得 Θ(α(n))，会用摊还论证解释。
- 动态 MST、次小 MST 等延伸证明题模板。

## L9 贪心方法论
- 贪心成立的两个必要构件：贪心选择性质 + 最优子结构。
- 交换论证是通用证明器：把最优解逐步改成贪心解。
- 拟阵给出"贪心必最优"的充要刻画，生成树是标准例子。
- 反例设计能力：给三个贪心准则各造一个坏输入。

## L10 动态规划 I
- DP 的正确姿势：先定义递归（含状态含义），再 memo，最后填表。
- DAG 最短路是 DP 的几何图像：拓扑序 = 无后效性。
- 状态设计的三问：决策序列、需要记住的后缀信息、转移成本。
- 空间优化：滚动数组、只保留计数、路径重建技巧。

## L11 动态规划 II
- 编辑距离/LCS：二维状态与三角不等式改进（Hirschberg 线性空间）。
- 0-1 背包：O(nW) 伪多项式 → 弱 NP 完全；FPTAS 通过缩放误差。
- 区间 DP 的"子问题嵌套"结构（矩阵链乘、最优 BST）。
- 概率 DP（期望步数、马尔可夫链吸收概率）也是同一框架。

## L12 高级 DP
- 树形 DP：在树上做"子树汇总 + 换根"两遍传播。
- 位掩码 DP：状态压缩到 2^n，解决 TSP/安排类小 n 问题。
- DP 转移写成矩阵乘法后用快速幂降到 O(log k)。
- 识别"DP 可优化"：决策单调性、凸包技巧（CHT）、Knuth 优化的使用条件。

## L13 线性规划
- 可行域是多面体，最优解在顶点 → 有限搜索空间的直觉。
- 单纯形：进基/出基与退化处理；实践快但指数最坏。
- 建模训练：把调度、路由、近似分配写成 LP。
- 内点法与椭圆法给出多项式时间：理论地位重要。

## L14 LP 对偶与博弈
- 每个 LP 有对偶；弱对偶给界，强对偶给最优性判定。
- 互补松弛条件用于验证整数解的最优性（Kőnig 证明的核心）。
- 影子价格：对偶变量的现实解释（资源稀缺度）。
- 零和博弈价值定理 ⇔ LP 对偶， minimax 由此而来。

## L15 网络流 I
- 增广路径定理：无增广路 ⇔ 最大流；最小割给出上界证书。
- Edmonds-Karp 多项式界 O(VE²)；Dinic 在单位容量网络更快。
- 整数容量 → 整数最大流，是组合优化的通用"放大器"。
- 流的分解与路径表示：把流当作随机策略。

## L16 网络流 II 与归约
- 归约三件套：源汇构造、容量编码约束、证明"解一一对应"。
- 二分图最大匹配、最小点覆盖与 König 定理（流的对偶）。
- 带下界流的可行性判定（超级源汇）与调度应用。
- 棒球淘汰：割即证明，学会用网络流写"不可能性证书"。

## L17 难解性 I
- NP = 多项式可验证；NPC = NP-hard 且属于 NP。
- 归约方向：已知难问题 → 待证问题（新手最常搞反）。
- Cook-Levin 思路：把 nondeterministic TM 计算表编码为 3-CNF。
- 证明 NPC 的两步义务： membership 与 hardness 要分别写。

## L18 难解性 II
- 经典归约链：3SAT → 独立集 → 团 → 顶点覆盖 → 哈密顿回路 → TSP。
- 数值问题：子集和/划分的伪多项式 DP 与弱 NP 完全。
- 强 NP 完全问题（3-维匹配、精确覆盖）不存在 FPTAS（除非 P=NP）。
- 面对 NP-hard 的四条出路：近似、特例、随机平均、指数但优化常数。

## L19 近似算法
- 近似比证明范式：给"任何算法都必须 ≥ f(OPT)"的下界 + 你的算法 ≤ c·f。
- 顶点覆盖 2-近似（匹配 / LP 舍入两种证明）；集合覆盖 H_n 与阈值论证。
- 度量 TSP：MST 双倍 2-近似，Christofides 3/2 近似（完美匹配的作用）。
- PTAS/FPTAS 与 gap 归约带来的不可近似性边界。

## L20 概率工具与哈希
- 期望线性性不需要独立性；指示器变量是最重要的分析工具。
- 阶梯：Markov → Chebyshev → Chernoff；"高概率（w.h.p.）"的表达方式。
- 通用哈希：2-universal ⇒ 期望冲突 O(1+α)，结合 Markov 得高概率界。
- Bloom Filter 与 LSH：用假阳率换空间/换精确比较，务必会推 FPR 公式。

## L21 数论与密码学
- 模运算、扩展欧几里得、中国剩余、费马小定理与欧拉定理。
- RSA 正确性依赖 φ(n) 与欧拉定理；安全性归约到分解难度。
- Miller-Rabin：非平凡平方根 ⇒ 错误概率 ≤ 1/4 per round。
- 离散对数与 Diffie-Hellman；"归约式安全证明"的写法范式。

## L22 量子与其他前沿
- Qubit、叠加与测量：量子算法为何只能"加速特定问题"。
- Shor 的周期查找给出多项式分解，Grover 只给平方根加速（最优）。
- 并行模型 work-span：T₁、T_∞、Brent 定理与调度上界。
- 总结地图：贪心/DP/流/线性规划/随机/近似/下界七种武器各解什么。
