# 6.046 讲义要点（骨架，Spring 2015 主题）

> 每条为骨架级要点；6.046 的作业是"设计 + 证明"，笔记正文应突出**证明结构**而非代码。

## L1 导论与设计范式
- 建模先行：把模糊需求写成"输入-约束-目标"三元组，算法好坏取决于建模质量。
- 分治与递推复习：主定理的三个情形与"猜解 + 代入验证"的严格写法。
- 三层论证义务：正确性（终止 + 最优）、复杂度、下界/tightness。
- 与 6.006 的区别：从"识别已知算法"到"构造新算法"。

## L2 贪心 I：区间调度
- 贪心三检查：贪心选择性质、最优子结构、交换论证可行性。
- 区间调度按结束时间排序的最优性证明（替换不劣）。
- 反例训练：按"最短区间""最早开始"为什么失败。
- 交换论证模板：设最优解 O，逐步把 O 改造成贪心解且不增加代价。

## L3 贪心 II：Huffman 与拟阵
- 前缀码树的最优子结构：最浅两叶可交换为兄弟。
- Huffman 的正确性与 O(n log n) 实现（频率堆 + 计数排序技巧）。
- 拟阵 (E, I) 上贪心必最优：增广性质是核心。
- 记住"哪些问题是拟阵"：生成树、区间调度不是拟阵，需单独论证。

## L4 生成树与图贪心
- 割性质（cut property）统一 Kruskal/Prim/Borůvka。
- Kruskal = 排序 + 并查集：逆 Ackermann 复杂度来源。
- Prim 的惰性 vs 急切优先队列实现与索引堆。
- 第二小生成树、最小瓶颈生成树等衍生证明题。

## L5 最短路综述与启发式
- Dijkstra 的正确性证明（归纳 + 松弛不变式）。
- Bellman-Ford 处理负权、负环检测与 V-1 轮tightness。
- A* 的可采纳性（admissible）与一致性（consistent）条件、与 Dijkstra 的关系。
- 分层/收缩启发式（contraction hierarchies）作为工程加速的算法基础。

## L6 动态规划框架
- "DP = 在依赖 DAG 上求最短路"的统一视角，避免死记公式。
- 状态设计的三问：决策序列是什么、后缀信息需要哪些、状态间如何转移。
- 最优子结构证明的标准写法：cut-and-paste（若子问题不最优则可替换更优）。
- 空间优化：滚动数组与状态压缩；重建方案（parent 指针）。

## L7 动态规划应用
- 编辑距离/LCS 的 O(mn) 转移与三角不等式改进（Hirschberg 线性空间）。
- 背包：伪多项式 O(nW) 与 FPTAS 的推导（缩放 + 误差累积控制）。
- 树形 DP 与区间 DP 的递归式差异。
- 隐马尔可夫 Viterbi：DP 在概率图模型上的直接落地。

## L8 最大流 I
- 残量网络与增广路径定理：流最大 ⇔ 无增广路径。
- 弱对偶/强对偶：任何可行割给出流的上界，达到即最优。
- 整数容量 → 整数最大流（因此可解匹配/分派）。
- 不同增广策略的复杂度：BFS（Edmonds-Karp O(VE²)）、缩放、Dinic。

## L9 最大流 II 与归约
- 归约三步：把新问题编码为网络、证明"解对应"、控制规模。
- 二分图最大匹配 = 单位容量流；König 定理与最小点覆盖等价。
- 带下界流的可行解构造（超级源汇）与项目选型问题。
- 棒球淘汰定理：用割证明"可淘汰 ⇔ 存在超容量割"。

## L10 线性规划与对偶
- 标准形/单纯形的几何直觉：顶点与可行域、退化与循环。
- LP 强对偶、互补松弛条件与"用对偶证近似比"。
- 最大流最小割 = LP 对偶的特例，学会用对偶语言复述。
- 零和博弈的价值定理 ⇔ LP 对偶。

## L11 难解性 I：归约与 NP 完全
- 多项式归约的传递性；SAT 为源头（Cook-Levin 构造）。
- NP 定义的两种等价叙述（验证机 vs 猜测）。
- 证明 NP 完全的两条路：从已知 NPC 归约 or 直接构造。
- 常见误区：归约方向搞反、忘记证明问题在 NP 内。

## L12 难解性 II：经典归约
- 团 ⇄ 独立集（补图）；顶点覆盖 ⇄ 独立集。
- 3-SAT → 独立集/顶点覆盖的 gadget 构造方法。
- 哈密顿回路 ⟶ TSP 的归约与"0/1 距离"技巧。
- 读题模板：先猜 NPC，再找 gadget，最后验证映射双向。

## L13 难解性 III：数论与空间类
- 子集和/划分的伪多项式 DP 与"强/弱 NP 完全"区分。
- 数论难题（整数分解、离散对数）不属于已知 NPC：复杂度地位说明。
- PSPACE 概览与博弈类问题（广义地理、TQBF）。
- 近似方案层级 PTAS/FPTAS 与强 NP 完全的关系。

## L14 近似算法 I
- 近似比的定义与证明范式（下界 + 构造上界匹配）。
- 装箱 Next-Fit/First-Fit 的 2-近似、Best-Fit 与下界。
- 顶点覆盖的 2-近似（极大匹配 / LP 取整双证）。
- 度量 TSP：MST 双倍 + Christofides 1.5-近似（完美匹配的作用）。

## L15 近似算法 II
- 集合覆盖的 H_n 贪心近似与"元素覆盖增益递减"证明。
- LP 松弛 + 随机舍入：MAX-3SAT 的 7/8 型结果与条件期望法。
- 不可近似性：归约保持 gap（如独立集难以 n^(1-ε) 近似）。
- 半定规划（SDP）与 MAX-CUT Goemans-Williamson 0.878 概览。

## L16 随机算法 I
- 期望线性性无需独立性：指示器变量是最强武器。
- 随机化快速排序的期望比较次数 O(n log n) 与"逆点对"分析。
- Las Vegas vs Monte Carlo 的错误概率与时间期望。
- 用概率法证存在性（下界证明入口）。

## L17 随机算法 II：集中不等式
- Markov → Chebyshev → Chernoff 的强度阶梯与适用条件。
- 抛硬币加载/ Balls-into-Bins：最大负载 O(log n / log log n) 的证明骨架。
- Union bound + 集中 → 高概率（with high probability）结论。
- Skip List：随机化替代旋转的平衡树，期望 O(log n) 且易并行。

## L18 哈希与随机结构
- 通用哈希族定义与期望冲突界 → 线性探测/分离链的 O(1+α)。
- 2-universal 与 Markov 结合即可给高概率界。
- Bloom Filter 的假阳率公式、空间下界与信息论直觉。
- 下界视角：cell-probe / 决策树模型中的不可能性论证（Lynch 风格）。

## L19 在线算法与竞争分析
- 竞争比定义：与离线最优比较，最坏情况比值。
- 分页：LRU 是 k-竞争且下界为 k（标记算法论证）。
- Ski rental / 秘书问题的 2-近似与 e/(e-1) 停止规则。
- 竞争分析作为"没有分布信息时的合理性"标准。

## L20 算法博弈论
- 纳什均衡的存在性（有限博弈、不动点直觉）。
- 自私路由的 Braess 悖论与 Price of Anarchy 上界（仿射延迟 O(4)）。
- 机制设计与激励相容（VCG 概览）。
- 与 ML 的联系：多智能体系统与资源分配。

## L21 密码学中的算法
- 数论基础：欧几里得、模逆、中国剩余、费马/欧拉定理。
- Miller-Rabin 素性测试的错误概率与 derandomization 猜想。
- RSA 的正确性与"归约式安全证明"：破译 ⇒ 分解。
- 随机预言、哈希碰撞与协议中的概率论证（衔接 6.1600/6.858）。

- work-span 模型：T₁ 与 T_∞，跨度决定下界，Brent 定理给出调度。
- 分治算法的并行化实例（归并排序、矩阵乘法、扫描前缀）。
- 量子计算概览：Shor/Grover 的算法意义与经典难度图谱位置。
