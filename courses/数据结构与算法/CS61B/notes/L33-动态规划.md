# L33 动态规划（memoization、自底向上与图视角）

> 对应 spring2024 L33：重叠子问题、自顶向下 memo、自底向上表；0-1 背包/LCS/编辑距离。阅读：CLRS 15；Lab11/HW（Teleportation 续）。

## 1. 核心概念

- **适用条件**：最优子结构 + 重叠子问题（否则用分治/贪心）。三步骤：定义状态 → 写递推 → 定边界/求序。
- **两种实现同一数学**：
  ```java
  // 自顶向下 memo（61B 偏好；递归 + HashMap/数组缓存）
  int knapsack(int i, int cap) {
      if (i == 0 || cap == 0) return 0;
      String key = i + "," + cap;
      if (memo.containsKey(key)) return memo.get(key);
      int best = knapsack(i - 1, cap);
      if (weight[i] <= cap)
          best = Math.max(best, value[i] + knapsack(i - 1, cap - weight[i]));
      memo.put(key, best); return best;
  }
  // 自底向上表：dp[i][c] = max(dp[i-1][c], v[i]+dp[i-1][c-w[i]])，i 升序、c 升序
  ```
- **经典三题状态设计**：
  | 问题 | 状态 | 转移 | 复杂度 |
  | --- | --- | --- | --- |
  | 0-1 背包 | dp[i][cap] | 选/不选第 i 件 | Θ(nW) 伪多项式 |
  | LCS | dp[i][j] 两串前缀 | 匹配则左上加一，否则 max | Θ(mn) |
  | 编辑距离 | 同上 | 插/删/替 +1 | Θ(mn)；LCS 是其特例 |
- **空间滚动优化**：只依赖上一行 ⇒ Θ(n) 数组；再配合路径回溯需保留决策表或二次扫描。
- **DP 即 DAG 上最短路**：状态=节点、转移=边，按拓扑序递推（L32 的 Θ(V+E) DAG 路径）。Teleportation HW：`dp[城市][天数]` 沿"航班边"松弛 K 轮。

## 2. 复杂度视角

- 黄金法则：**DP 时间 = 状态数 × 转移成本**。`fib` memo 后 Θ(n)（vs 指数递归树 Θ(φⁿ)，节点数=递归调用的不同参数对数）。
- 伪多项式警示：背包 Θ(nW) 中 W 是数值而非输入长度——输入按二进制编码时并非多项式（CS170 的 NP 完全入口）。

- **CSAPP**：dp 表按行主序访问 + 滚动数组 = cache 友好的遍历序；同一 DP 换遍历方向快 5×（矩阵链乘的 diagonal 遍历反例）。

## 5. 开源项目应用

- **JDK**：无通用 DP 框架，但 `java.text.BreakIterator` 分句/词边界与 `Pattern` 的 NFA 模拟（Thompson 线性时间）暗含 DP；`Arrays.mismatch` 是线性特例。
- **Git**：`diff`/blame 的 Myers O(ND) 算法 = 编辑距离格点最短路（D 即 DP 状态的界）；rename 检测的相似度矩阵同族。
- **数据库（CS186/15-445）**：查询优化器自底向上枚举连接序（System R 动态规划、Cascades 记忆化搜索）——"状态=子查询集合，转移=加一条 join"，是工业界最著名的 DP 部署。
- **生物信息**：Needleman-Wunsch/Smith-Waterman 序列比对 = LCS/编辑距离换打分函数，BLAST 用其启发式加速。
- **编译器**：寄存器分配的区间剪枝、指令选择（树模式匹配 DP）。
