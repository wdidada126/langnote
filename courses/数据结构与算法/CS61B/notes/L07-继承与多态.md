# L07 继承与多态（extends、super、重写、Object 契约）

> 对应 spring2024 L7：类继承、方法重写、super 调用、动态分派、Object 的 equals/hashCode/toString。作业：Lab2 续。

## 1. 核心概念

- **`extends`**：子类继承父类的实例变量与方法；Java 单继承（接口可多实现）。
- **重写（Override）** vs 重载（Overload）：同名同签名替换实现 vs 同名不同签名共存。重写看运行时类型，重载看编译时类型。
- **动态分派**：`p.fly()` 在运行时沿 `p` 实际类型的继承链找最近实现——多态的全部机制。
  ```java
  class Animal { void speak() { System.out.println("?"); } }
  class Dog extends Animal {
      @Override void speak() { System.out.println("woof"); }
  }
  Animal a = new Dog();
  a.speak(); // woof —— 变量静态类型 Animal，对象动态类型 Dog
  ```
- **`super`**：调用父类构造器/被覆写的方法；构造链自顶向下执行（先 Object 再子类）。
- **组合优于继承**：继承耦合内部实现（脆弱基类问题），组合只依赖接口。

## 2. Object 方法契约（本课最重要的"工程 API"之一）

- `equals`：自反/对称/传递/一致 + `x.equals(null)==false`；必须同时重写 `hashCode`：**equals 相等 ⇒ hashCode 相等**（逆否命题用于哈希表正确性，L20 的根基）。
  ```java
  @Override public boolean equals(Object o) {
      if (this == o) return true;
      if (o == null || getClass() != o.getClass()) return false;
      Term t = (Term) o;
      return coeff == t.coeff && Objects.equals(var, t.var);
  }
  @Override public int hashCode() { return Objects.hash(coeff, var); }
  ```
- `toString`：日志/调试契约；Lab 里助教 JUnit 失败信息全靠它。

## 3. 复杂度视角

| 操作 | 成本 | 说明 |
| --- | --- | --- |
| 虚方法调用 | O(1)，vtable 一次间接 | 比静态调用多一跳；JIT 去虚化后可内联 |
| `instanceof` 链式比较类型 | 最坏 O(层深) | 深继承树中热点路径应避免 |
| `equals` | 随字段 O(字段成本) | 字符串字段 ⇒ O(n) |

## 6. 开源项目应用

- **JDK java.util**：`AbstractCollection→AbstractList→ArrayList`、`AbstractMap→HashMap/TreeMap`：模板方法模式让子类只重写 `get/size` 等原语即可免费获得 `iterator/contains/toArray`。
- **RocksDB**（Java JNI 层）与 Lucene：大量 `extends Filter/Codec` 扩展点，插件式多态是存储引擎生态的基石。
- **Spring**：整个 IoC/AOP 建立在"按接口/父类注入"的多态之上；`equals/hashCode` 契约破坏是实体类放入 `HashSet` 后"消失"的经典事故。
