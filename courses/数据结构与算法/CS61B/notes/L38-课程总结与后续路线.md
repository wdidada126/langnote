> 对应 spring2024 L38：全课知识地图收官、并发简介、后续课程与工程实践路线。作业：HW10；期末复习框架。

## 1. 核心概念：一张图收编全课

```
                 ┌ 线性：数组(L16) → 动态数组(L17) → DLList(L18) → 环形 ArrayDeque(L19)
  按"序"的强弱 ──┤ 部分序：堆(L28, 只有父子序) → BST(L25) → AVL/RB(L26-27) → B 树(分页)
                 └ 散序：哈希表(L20-22) —— 放弃序换 O(1)
  键的推广：数字/对象 key(L20) → 字符串 key → Trie(L36, 逐字符寻址)
  多对多关系：图(L29) → 遍历(L30) → 生成树/连通(L31) → 最短路(L32) → DAG 递推=DP(L33)
  横切工具：接口/多态(L4-11) 规格 · 异常测试(L12-14) 质量 · Θ/摊还(L15/L17) 成本 · 排序(L34-35) 预处理 · I/O(L37) 持久化
```

- **三大母题**：
  1. **空间换时间**：倍增缓冲、哈希桶、堆数组化、Trie、索引（B 树）。
  2. **不变量决定操作集**：堆/UF/树各自"只维持一部分序"，承诺越少、操作越便宜。
  3. **摊还**：扩容、再哈希、heapify、缓冲刷新——单次尖刺、总账平摊。
- **并发概览（61B 深度即止）**：共享可变状态是 bug 之源 → `ConcurrentModificationException`（迭代中改结构）、`Collections.synchronizedList` 只保证单调用原子；真正的并行归 L28 之后的专门课（KAIST CS431/Stanford CS110/15418）。

## 4. 工程实践清单（从 CS61B 带走的习惯）

1. 先写 spec/javadoc 再写实现；不变量写成注释并配断言。
2. 测试从边界来：空、单元素、满、负索引、null 键策略。
3. 复杂度写进 API 合同（javadoc 里 "Runtime: Θ(1) amortized"）。
4. 结构组合出 API：HashMap+DLList=LRU；堆+图=Dijkstra；Trie+Map=自动补全。
5. 性能问题顺序排查：算法渐近 → 常数（装箱/指针追逐/缓冲）→ 并发/内存。
