# L28 堆与优先队列（二叉堆、heapify 线性建堆）

> 对应 spring2024 L28：complete tree 数组表示、offer/poll、线性建堆。阅读：CLRS 6；Lab8。项目对应：projects/heap。

## 1. 核心概念

- **优先队列 ADT**：只承诺 `insert` 与 `deleteMax/poll`——**不需要全序遍历**，这是比排序更弱也更快的需求。
- **二叉堆不变量**：完全二叉树（形状）+ 父 ≥ 子（序）。只保证"根最大"，兄弟间无序 ⇒ 可用数组零指针存储：
  ```java
  // 下标约定（61B/CLRS 用 1 基，JDK 用 0 基）：
  parent(i) = i/2;  left(i) = 2i;  right(i) = 2i+1;  高 = floor(log2 n)
  public void offer(T x) {
      items[++n] = x; sinkUp(n);          // 或 swim：沿 i/2 上浮
  }
  public T poll() {
      T max = items[1];
      items[1] = items[n--];
      sinkDown(1);                        // 与较大孩子交换，直到序恢复
      return max;
  }
  ```
- **sinkDown 细节**：每次与**较大**孩子交换（否则破坏不变量）；路径长 ≤ log n。
- **线性建堆 heapify**：把任意数组自底向上对每个内部节点 sinkDown ⇒ **Θ(n)** 而非 Θ(n log n)。直觉：大部分节点在底层，修复成本随高度指数衰减：Σ h/2ʰ = Θ(n)（L17 级数技巧再现）。
- **堆排序**：heapify + 反复 poll 放尾部 ⇒ 原地 Θ(n log n) 最坏，但缓存不友好、不稳定（L34–L35 详述）。

## 5. 开源项目应用

- **JDK**：`PriorityQueue`（二叉堆 + Comparator，无下界限制，`offer` O(log n)）；`DelayQueue`（堆 + 条件等待）；`Arrays.sort` 对原始类型用双轴快排，而 `PriorityQueue` 文档明写"不提供最小元素快速移除以外的保证"。
- **Lucene**：多段结果归并（`PriorityQueue` 收集每段 top doc）、`WAND`/块最大打分跳过用堆式剪枝——搜索= Top-K 的工业定义。
- **RocksDB**：compaction 优先队列按 score 排序（堆）；memtable flush 队列同构。
- **Kafka/Spark**：Kafka `TimeTaskQueue`（数组堆做延迟操作）；Spark `PriorityQueue` 调度 stage。
- **Git**：`commit-graph` 生成时对 parent 拓扑序处理使用小顶堆（Bloom 修正队列）。
