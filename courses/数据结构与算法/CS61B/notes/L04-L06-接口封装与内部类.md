# L04–L06 接口、封装、内部类与包（对象系统第一课）

> 对应 spring2024 L4–L6：对象与接口、封装、this、内部类/静态嵌套类、包与访问控制。作业：Lab2（IntLists）启动。

## 1. 核心概念

- **对象 = 数据 + 行为 + 封装**。类是模板，对象是实例；实例变量属于对象，`static` 变量属于类。
- **接口（interface）**：只声明方法签名（sp 记号规格），不规定实现。`implements` 即承诺"我支持这些方法"。
  ```java
  interface Shape { double area(); }
  class Rectangle implements Shape {
      private final double w, h;               // private：外部不可见
      Rectangle(double w, double h) { this.w = w; this.h = h; }
      public double area() { return w * h; }
  }
  ```
- **方法签名** = 名字 + 参数类型列表（不含返回类型）；调用时按签名分派。
- **`this`**：指向当前对象的隐式引用。经典陷阱：`this.x = x` 区分实例变量与参数；内部类里 `Outer.this` 区分内外两个 this。

## 2. 内部类与静态嵌套类

- **内部类（inner class）**：定义在另一个类内、能访问外围类实例成员——天然持有外围对象引用。
- **静态嵌套类**：不带外围引用，等价于"住在同一个命名空间里的独立类"。
- 后续价值：`ArrayList` 的 `Itr`、`HashMap` 的 `Node` 都是内部类/嵌套类；L10 迭代器实现是本讲最直接的下游应用。

```java
class SLList {
    private class IntNode { int item; IntNode next; } // 内部类：直接读外围 first
    private IntNode first;
}
```

## 3. 包与访问控制

| 修饰符 | 同类 | 同包 | 子类 | 任意 |
| --- | --- | --- | --- | --- |
| `private` | ✔ | | | |
| （默认包私有） | ✔ | ✔ | | |
| `protected` | ✔ | ✔ | ✔ | |
| `public` | ✔ | ✔ | ✔ | ✔ |

- `package p.u.t;` + 目录结构一致；`import` 只是编译期简称，不产生运行时依赖。
- **信息隐藏原则**：字段一律 `private`，通过方法暴露行为——这是 6.031 的 spec/representation invariant 的雏形。

## 4. 复杂度视角

| 操作 | 成本 | 说明 |
| --- | --- | --- |
| 接口方法调用 | O(1)，但多态调用有虚分派开销 | invokeinterface 指令，JIT 可内联去虚化 |
| 内部类访问外围私有字段 | O(1) | 编译器生成合成访问方法（历史；现代用 nestmates） |
