# L13 习题课与期中复习：证明技术与常见错误

> 讲次：Fall 2011 Lecture 13 ｜ 材料：PSet3 讲解 + 往年期中（OCW 公开） ｜ 定位：Part A/B 总结，为 Part C（树与摊还）开门

## 1 本讲功能

- 把 L01–L12 的知识重组为**四件证明武器**，并给出考试级答题格式：
  1. 渐近论证（L03）：增长阶排序、循环求和；
  2. 递推求解（L04）：递归树 → 代入法验证 → 主定理套用与反例；
  3. 不变式/归纳（L05/L08/L09）：循环不变式三板斧、递归断言；
  4. 贪心/交换论证（L11）：定案前缀最优性。

## 2 高频题型清单（对照 PSet1–3）

- **代码报复杂度**：三层依赖嵌套逐层求和（L03 例 2）；切片/拷贝隐藏成本（L02 `a = a + [x]` 的 Θ(n²)）。
- **设计题**：
  - 逆序对计数 = 归并时统计（L04），Θ(n log n)；
  - 双栈共享一数组（L06）；
  - DAG 最短路 = 拓扑序 DP（L08/L10）；
  - 井字棋/四子棋的 minimax + memo（L12）。
- **真假辨析**（期中最爱）：
  - "f=O(g) ⇒ g=Ω(f)" 对；"f=O(g) ⇒ f=Ω(g)" 错；
  - "平均 O(1) 的哈希查找 ⇒ 任意输入 O(1)" 错（期望≠最坏）；
  - "Dijkstra 加负权只要没有负环就对" 错（定案即错，与负环无关，L11 反例）；
  - "归并排序原地 O(1) 额外空间" 错（标准版 Θ(n)；原地版存在但复杂且常数大）。
- **递推题**：T(n)=3T(n/4)+n log n → 主定理情形 3（正则条件）Θ(n log n)；T(n)=T(n−1)+Θ(1)·log n → Θ(n log n) 展开即得。

## 3 复杂度证明的常见错误（本课"错题本"）

1. 在 O 记号内做减法/不等式方向错误：由 d[u] ≤ d[y] 推不出 d[u] = d[y]。
2. 循环不变式写得太弱（"数组部分有序"→ 无法完成保持步）或太像结论（循环论证）。
3. 递归分析忘记非整数规模：用 ⌈n/2⌉ 与归纳假设时先证 "T(n) ≤ cn log n − b" 带低阶项（CLRS 4.3 技巧）。
4. 把"存在快输入"当"算法快"：必须声明对**所有**输入或**期望**（含随机模型假设）。
5. 空间复杂度漏递归栈：BFS 队列 Θ(宽度)、DFS 栈 Θ(深度)（L09/L10 对称点）。

## 4 答题模板（以期中真题风格）

```text
题：给"部分有序数组（每个元素距最终位置 ≤ k）排序"，要求 Θ(n log k)。
   思路：维护大小为 k+1 的最小堆（L18 预告）——滑动窗口内最小值出堆即全局最小。
   答题四段：算法伪码 → 复杂度（n 次出堆, 每次 O(log k)）→ 正确性（不变式：堆内 = 未输出的最小候选集）→ 边界（k≥n 退化普通堆排）。
```
