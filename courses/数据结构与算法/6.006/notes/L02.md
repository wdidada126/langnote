## 1 问题模型

- 目标：建立"Python 内置容器的操作成本表"，之后所有算法伪码都翻译成这些原语来实现。算法分析的输入是操作序列，操作本身必须有定义良好的成本。
- 语言选择理由：Python 让实现接近伪码，把注意力留给算法；但**动态类型 + 引用语义**会让成本分析踩坑（别名、拷贝语义），本讲专门排雷。

## 2 核心内容与成本表

```text
容器        本质              关键操作成本（均摊/最坏注明）
list        动态数组（指针）   索引 O(1)；append 均摊 O(1)；insert(0,x) O(n)
tuple       不可变数组        构造后 O(1) 读，可作 dict 键
str         不可变字符序列    切片 O(k)；比较 O(n)；`s==t` 先比引用（别名词典）
dict/set    哈希表            查找/插入期望 O(1)（L07 展开）
```

- **切片 `a[i:j]` 是拷贝**，Θ(j−i)，不是视图——把"O(1 取子数组)"写进证明是常见错误。
- 别名陷阱：`b = a; b[0] = 1` 会改 a（可变对象传引用）；`a += [x]` 原地扩展，`a = a + [x]` 新建并拷贝——后者在循环里把 O(n) 累积成 O(n²)。
- 位与表示：int 定长/变长（Python 大整数逐位链表，故 `2**1000 % p` 是 Θ(位数)）、str 是不可变 unicode 序列、list 存的是**指针数组**（元素本体堆上）——这决定了浅拷贝/深拷贝语义。
- 函数传参：对象引用按值传递（call by object）；默认参数求值一次，可变默认值 `def f(x=[])` 是共享状态事故。

## 3 复杂度练习（本讲现场推导）

```python
def mystery(n):
    a = []
    for i in range(n):
        a = a + [i]     # 每次重新拷贝整个 a
    return a
```

- 第 i 轮拷贝 Θ(i)，总计 Σi = **Θ(n²)**。改成 `a.append(i)` 则均摊 Θ(n)（均摊证明在 L19）。
- `for x in sorted(a)`：Θ(n log n)；`bisect.insort(a, x)`：O(n) 定位 + O(n) 搬移。

## 4 正确性/语义论证思路

- 用"引用图"推理程序：画出对象与指针，判断两次 `==` 与 `is` 的结果。Python 小整数与短字符串驻留使 `is` 偶然为真——**语义论证永远用 `==`，不用 `is`**。
- 幂等与纯函数：优先写不原地修改输入的版本（伪码风格），避免"算法跑一遍输入被毁了"的隐性 bug。

## 7 开源项目应用
