# L05 初等排序：插入排序、循环不变式与表示选择

> 讲次：Fall 2011 Lecture 5 ｜ 教材：CLRS 2.1 ｜ 本课笔记：notes L5 ｜ 后续：L06 栈队列、L19 摊还（数组插入成本）

## 1 问题模型

- 同一排序问题，换**增量构造**策略：维持"已排前缀"，把下一个元素插入正确位置。适合在线场景（数据逐步到达）与小 n（常数小）。
- 本讲另一主角是**证明方法论**：循环不变式（loop invariant）——把 L04 的归纳法改写成循环语言。

## 2 算法伪码

```text
INSERTION-SORT(a):
  for j = 1 to len(a) - 1:
    key = a[j]; i = j - 1
    while i >= 0 and a[i] > key:
      a[i+1] = a[i]; i -= 1        # 逐个右移腾位
    a[i+1] = key
```

- 数组版插入 = 一次定位（可二分，L23 呼应）+ Θ(k) 搬移；搬移才是瓶颈。
- 链表版：定位 Θ(j) 顺序走、插入 O(1) 改指针；**没有数组的随机访问，也没有数组的搬移成本**——两种表示在最好/最坏上互补。

## 3 复杂度推导

- 第 j 轮 while 执行次数 = 元素 a[j] 前面比它大的个数（**逆序对**贡献）。总比较/搬移 = 逆序对数 I(a) + (n−1)。
- 最好（已排）：Θ(n)；最坏（逆序）：I = n(n−1)/2 → Θ(n²)；随机输入期望 I = n(n−1)/4 → Θ(n²)。
- 由此得一个漂亮的旁证：**任何只交换相邻逆序对的排序 ≥ Ω(n²)**（初始逆序数可差 Θ(n²)），呼应 L01 的下界直觉。
- 逆序数还刻画"几乎有序"：插入排序 Θ(n + I)，数据近有序时它是最佳工程选择（Timsort 的 run 内插入即此）。

## 4 正确性论证（循环不变式三板斧）

断言：进入第 j 轮前，`a[0..j-1]` 是原 `a[0..j-1]` 的有序排列。
- **初始化**：j=1 时前缀长度 1，成立。
- **保持**：每轮把 key 与有序后缀从右往左比较、大的右移，直到找到 ≤key 处插入——前缀延长一位仍有序（内层另有"已移区保持有序且空槽在正确位置"的子不变式）。
- **终止**：j = n 时全数组是原数组的有序排列；算法显然有限步终止（j 严格增）。
- 写法要求：三个时刻各一句，不变式必须**强到足以完成证明**（只写"部分有序"不够）。

## 7 开源项目应用

- **CPython `list.sort`**：`sort.c` 中 galloping 失败时退回**二元插入排序**处理小碎片；`MINRUN=64` 以下片段直接插入排。
- **GNU coreutils `sort`**：小缓冲内的插入排序作为外排首趟的"生成 run"步骤。
- **`bisect.insort`**：文档明示 O(n)——正是本讲"定位便宜、搬移贵"的 API 化。
- **Linux `slab/sort`**：内核对小块数组排序偏好 insertion/heap 混合，避免函数调用与 malloc。
