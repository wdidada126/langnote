# L26 后缀数组、基数排序与随机化算法：期末总纲

> 讲次：Fall 2011 Lecture 26 ｜ 教材：CLRS 8.3（基数排序）、33.4（后缀数组，4/E 补充材料）＋ 随机化（notes L26） ｜ 定位：结课与期末复习

## 1 问题模型

- 三块内容一条线——**"跳出比较模型"**：
  1. **基数排序**：键是 w 位/定长字符串 → 非比较排序 O(wn) 或 O(n)（w=O(log n) 时）；打破 L05/L14 的 Ω(n log n) 比较下界（前提：键有内部结构）。
  2. **后缀数组 SA**：把文本所有后缀排序（L25 后缀 trie 的省空间替身），一次 O(n log n)（倍增+基数排序，Manber-Myers）或线性（SA-IS/Skew，延伸）→ 之后任意模式查询 O(m log n)、重复/匹配统计全部落定——L24/L25 的"离线终形态"。
  3. **随机化算法**：把期望写进保证（quickselect 期望 O(n)、随机 MTF/分页 L21/L22、通用哈希 L17、min-witness 采样延伸）。
- 期末收束视角：**问题 → 模型（RAM/比较/位/流）→ 策略（分治/贪心/DP/哈希/树/随机/在线）→ 保证（最坏/期望/摊还/竞争）四层表**，全课 26 讲在一张矩阵里。

## 2 伪码

```text
RADIX-SORT(A, w 位):
  for d = 0 to w−1 或分块 r 位一组:
    STABLE-COUNTING-SORT(A, 第 d 位)     # 稳定性 = 正确性心脏

后缀数组倍增（Manber-Myers）:
  rank₁[i] = T[i]
  k = 1; while k < n:
    SA = 按 (rank[i], rank[i+k]) 基数排序下标 i   # 两遍计数排序 O(n)
    重编 rank; k *= 2                              # log n 轮 → O(n log n)

QUICKSELECT(A, k, 随机 pivot):
  p = 随机元素划分(同快排); 按 |左| 与 k 递归一侧  # 期望 O(n)
```

## 3 复杂度推导

- 基数排序：计数排序 O(n + 2^r) 每趟 × ⌈w/r⌉ 趟；r = w → O(n + 2^w)；w = O(log n) 取 r≈½lg n → O(n log n) 不划算 vs 纯比较；**定长小整数/字符串是它的主场**（w=O(1) → Θ(n)）。
  - 正确性关键引理：趟间依赖"低优先排高位在后"当且仅当每趟**稳定**。
- 后缀数组倍增：每轮基数排序 O(n)（rank 值域 < n），轮数 lg n → **O(n log n)**；LCP 数组（Kasai O(n)）支持"两后缀最长公共前缀"（RMQ 延伸）。
- quickselect 期望线性（与快排同分析，L05/L21 血脉）：E[T(n)] = (1/n)Σ[E[T(max(i−1,n−i))}] + Θ(n) → 猜 T(n) ≤ cn → 代入得 c·n/2·(均分期望) ≤ cn − Θ(n)（经典 4cn 收口）→ **E = Θ(n)**；最坏 Θ(n²)（全知对手或运气差）。
- 中位数：随机化 BFPRT? 课内只要求"quickselect 选 n/2 = 期望线性中位数"；确定性最坏线性（median-of-medians）作延伸（6.046/CS170 会证）。

## 4 正确性论证思路

- 基数排序：对"已按低 d 位有序"归纳，第 d+1 趟稳定性保证高位相同者保持低位序 → 字典序成立。
- SA 倍增：不变式 rank_k[i] 编码后缀前 2k 字符的等价类；(rank_k[i], rank_k[i+2k]) 唯一确定前 4k 类 → 归纳到 4k ≥ n 完成全序（尾字符哨兵处理边界）。
- quickselect 正确性 = 划分不变式（左 ≤ p ≤ 右）+ 目标位置落侧判断；随机版与确定版共享同一"正确性"，随机只买"期望成本"——**正确性与效率解耦**是本课的收官宣言。
