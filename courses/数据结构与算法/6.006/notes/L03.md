# L03 渐近效率：O/Ω/Θ 与增长阶

> 讲次：Fall 2011 Lecture 3 ｜ 教材：CLRS 3.1–3.2、Appendix（对数/求和） ｜ 本课笔记：notes L3 ｜ 后续：L04 主定理、此后每讲都用

## 1 问题模型

- 我们要比较函数 T(n)（算法成本）的**增长率**，忽略常数与低阶项。定义（n→∞）：
  - `T(n) = O(g(n))`：∃c>0, n₀，∀n≥n₀: T(n) ≤ c·g(n) —— 上界（"不比你慢"）。
  - `Ω(g)`：−T ∈ O(−g) 的对应下界；`Θ(g)` = O ∩ Ω —— 紧确界。
  - `o(g)`：任意 c 都最终成立（严格慢）；ω 对称。
- 注意 O 的滥用：`O(n) ≤ O(n²)` 这类写法在证明里禁止；等号只在"集合成员"意义下方便时可用。
- 对数换底只差常数 → 渐近记号下 log₂ = ln = log₁₀；而 2^{log n} = n、n^{log n} = 2^{(log n)²} 等恒等式要熟。

## 2 增长阶级联（本课常用链条）

```text
1 ≺ log n ≺ log² n ≺ √n ≺ n ≺ n log n ≺ n² ≺ n³ ≺ 2ⁿ ≺ n!
```

- 比较技巧：取对数、比 T(n+1)/T(n)、写成 2^{f(n)} 比指数。
- 循环成本规则（成本模型：字 RAM，基本操作 O(1)）：
  - 单层循环：求和每轮成本；嵌套：乘积仅当内层与外层无关；
  - 有 break/依赖时逐轮计数，如 `while n>0: n//=2` 为 Θ(log n)。

## 3 复杂度推导示例（关键步骤）

例 1：`for i in range(n): for j in range(i): ...`
Σ_{i=0}^{n-1} i = n(n−1)/2 = Θ(n²)。

例 2（本讲经典"看起来三次其实二次"）：

```text
for i = 1 to n:
  for j = i+1 to n:
    for k = 1 to j: O(1)
```

内层合计 Σ_j j，外层再 Σ_i → 逐层化成幂和 Σ i² = Θ(n³) 的一半量级？精确：
Σ_{i=1}^{n} Σ_{j=i+1}^{n} j = Σ_j j·(j−1) = Θ(n³)。反例记忆：**依赖上下界的嵌套必须逐层求和，不许直接相乘**。

例 3：递归成本 `T(n) = T(n−1) + Θ(1), T(0)=Θ(1)` → 展开（telescoping）得 Θ(n)。为 L04 递推树预热。

## 4 正确性论证思路

- 证明 Θ 要**两侧各证一次**：上界给构造（放缩链），下界给特例输入或逐项放缩。
- 常见错误清单（PSet 高频）：把"存在一个输入慢"说成"最坏复杂度"却用了最好输入的放缩；常数随 n 变（如 c=n）却仍写 O；在 O 记号里做减法。
