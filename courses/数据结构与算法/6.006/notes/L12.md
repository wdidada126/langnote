# L12 博弈搜索：Minimax 与 Alpha-Beta 剪枝

> 讲次：Fall 2011 Lecture 12 ｜ 教材：AIMA 第 5 章 + CLRS 补充（DP 视角） ｜ 本课笔记：notes L12 ｜ 联系：L08 DP、L11 最短路、L14–L15 树

## 1 问题模型

- 双人零和完全信息博弈（井字棋、四子棋、国际象棋抽象）：状态树 alternating moves，MAX 先手求最大化终局效用，MIN 反之。
- 规格：给定局面，返回（价值，最优着法）。决策树规模 b^d（分支因子 b、深度 d）——纯枚举对棋类不可行，本讲给出**不牺牲正确性的剪枝**。
- 这是 L08 DP 的变体：状态=（棋盘, 轮到谁），转移=着法，价值=子问题 max/min；与最短路的差异只是"每层换 min"（最短路 = 全 max 取 min 的特例，路径即 MAX 唯一玩家）。

## 2 伪码

```text
MINIMAX(state):
  if terminal(state): return utility(state)
  if MAX-turn: return max over moves m of MINIMAX(child(state,m))
  else:        return min over moves m of MINIMAX(child(state,m))

ALPHA-BETA(state, α, β):
  if terminal: return utility
  if MAX-turn:
    v = -∞
    for m in moves:
      v = max(v, ALPHA-BETA(child, α, β))
      α = max(α, v)
      if α >= β: break          # β 截断: MIN 祖先绝不会走到这里
    return v
  else: 对称地用 β = min(β, v), α >= β 剪枝
```

- 井字棋 3×3：9! ≈ 3.6×10⁵ 叶子（对称性前），本课现场手算"中心开局必胜/角开局"等结论——终端小，可 memo 全量（L08 V2）。
- 实用三件套（棋引擎视角）：① 迭代加深（IDS）代替固定深度；② 启发式评估函数代替终局效用；③ 着法排序（中心先走、杀手着法）决定剪枝效率。

## 3 复杂度推导

- Minimax 全量：Θ(b^d)。
- Alpha-Beta：
  - 最坏着法序：退化为 Θ(b^d)。
  - 最优着法序：只访问约 **Θ(b^{d/2}) 个节点**——有效分支因子 √b，等于"免费"把搜索深度翻倍（证明：对 d=2 归纳，每个 MAX 节点只需展到一个 β 剪枝即可确定界）。
  - 精确界（最坏/平均）是研究课题；本课要求会 d=2、d=3 的手算剪枝图。
- 记忆化：状态转置（transposition）使"树"实为 DAG，转置表（zobrist 哈希 → L07/L17）把指数树压回"状态数×平均分支"。

## 4 正确性论证思路

- Minimax 值定义良构：有限博弈树自底向上归纳即存在值（Zermelo 定理的树版）。
- Alpha-Beta 正确性：**剪掉的子树不会改变根返回值**。证明用区间不变式：α = 祖先 MAX 已保证的下界，β = 祖先 MIN 已保证的上界；α ≥ β 时当前节点的值对祖先决策无关（祖先有更优选择，无论本节点返回何值）。
- 对"评估函数 + 固定深度"的近似：不再保证真实博弈值，只保证"在深度 d 的树上是精确 minimax"——近似质量交给工程实验。
