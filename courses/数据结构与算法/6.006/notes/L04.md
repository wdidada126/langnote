# L04 分治与归并排序：递归树与主定理

> 讲次：Fall 2011 Lecture 4 ｜ 教材：CLRS 2.3、4.1–4.4 ｜ 本课笔记：notes L4 ｜ 后续：L05 插入排序对照、L18 堆排序、L26 基数排序

## 1 问题模型

- 排序实例：数组 a[0..n)，输出其排列使非降。**策略：分治（divide & conquer）**——把问题切成若干小规模子问题，递归解决，再合并。
- 归并排序：Divide 取中点；Conquer 递归排两半；Combine 线性合并两个有序序列。
- 递归的成本写成递推关系：T(n) = 2T(n/2) + Θ(n)。本讲交付两件求解工具：**递归树展开**与**主定理**。

## 2 算法伪码

```text
MERGE-SORT(a, lo, hi):               # 半开区间 [lo, hi)
  if hi - lo <= 1: return            # 空/单元素天然有序
  mid = (lo + hi) // 2
  MERGE-SORT(a, lo, mid); MERGE-SORT(a, mid, hi)
  MERGE(a, lo, mid, hi)              # 双指针 + 临时缓冲, O(hi-lo)

MERGE: i=lo; j=mid
  while i<mid and j<hi:
    取 a[i],a[j] 较小者写入 buf; 对应指针 +1
  把剩余段拷入 buf; buf 回写 a[lo:hi]
```

- 空间：缓冲 Θ(n)（非原地）；稳定性：相等时取左半 → 稳定排序。

## 3 复杂度推导（关键步骤）

**递归树**：第 i 层有 2^i 个子问题、每个规模 n/2^i，合并成本每层 Θ(n)，共 log n + 1 层 → T(n) = Θ(n log n)。叶层共 n 个规模 1 的问题。

**主定理**（形式一）：T(n) = α·T(n/β) + Θ(n^δ)，α≥1, β>1, δ≥0：
- δ > log_β α（合并主导）→ Θ(n^δ)；例 T(n)=2T(n/2)+Θ(n²) → Θ(n²)。
- δ = log_β α（平衡）→ Θ(n^δ log n)；归并即 1=log₂2 → Θ(n log n)。
- δ < log_β α（子问题主导）→ Θ(n^{log_β α})；例二叉树遍历 T(n)=2T(n/2)+1 → Θ(n)。
- 注意：α<1（如 T(n)=½T(n/2)+1）不适用，答案是 Θ(1)。

更一般主定理（CLRS Thm 4.1）要求 f(n) 正则条件（af(n/b) ≤ cf(n)）才能用情形 3。

## 4 正确性论证思路

- **递归的正确性 = 归纳法**：断言"MERGE-SORT(a,lo,hi) 使 a[lo:hi] 成为原多重集的有序排列"。
  - 基例：长度 ≤1 平凡。
  - 归纳步：两半由归纳假设有序且为原半的多重集；MERGE 引理——两个有序序列的合并输出是两者并的多重集且有序（不变式：buf 已写前缀是两输入剩余部分最小元素的有序序列）。
- 关键习惯：**先陈述归纳假设再证明**，假设用错对象（对 n/2 假设对 n 证）是 PSet 常扣分处。

## 7 开源项目应用

- **CPython `list.sort`（Timsort，`sort.c`）**：自然归并，利用已存在 run，最坏 Θ(n log n) 空间减半技巧（galloping 模式即 L23 式指数搜索+二分）。
- **Linux 内核 `lib/sort.c`**：in-place 归并变体（block merge），解决内核不能随意 malloc Θ(n) 缓冲的约束。
- **Lucene/RocksDB**：多级归并（merge levels）把"分治排序"复用到倒排链与 SSTable 合并上，k 路归并用 L18 的堆。
- **`numpy.sort(kind='mergesort')`**：显式暴露稳定归并选项，对应本讲稳定性讨论。
