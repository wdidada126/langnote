# L08 动态规划入门：重叠子问题与备忘录

> 讲次：Fall 2011 Lecture 8 ｜ 教材：CLRS 15.1 ｜ 本课笔记：notes L8 ｜ 后续：L09–L11 图上 DP、L26 字符串 DP（编辑距离类）

## 1 问题模型

- 场景：递归算法把同一子问题**重复指数级求解**。识别信号：朴素递归 + 状态可枚举且总数多项式 → 上 DP。
- 两要素：**最优子结构**（大问题最优解由子问题最优解拼装）+ **重叠子问题**（同一子问题多次出现）。对比 L04 分治：归并的子问题不重叠，分治不需要表。
- 建模模板（本课反复使用）：
  1. 定义状态（子问题是什么，用什么参数刻画）；
  2. 写转移方程（最优子结构的代数式）；
  3. 定边界与计算顺序（递归+memo 自动正确；自底向上要保证依赖先算）；
  4. 算状态数 × 转移成本 = 总复杂度。

## 2 核心例：Fibonacci 的四种写法

```text
V1 裸递归     fib(n)=fib(n-1)+fib(n-2)          Θ(φⁿ), φ≈1.618（指数）
V2 自顶向下   memo 数组, 查前先填                Θ(n) 时间 + Θ(n) 栈
V3 自底向上   for i=2..n: f[i]=f[i-1]+f[i-2]    Θ(n) 时间 + Θ(n) 空间
V4 滚动变量   只留 f[i-1], f[i-2]                Θ(n) 时间 + Θ(1) 空间
```

- V1 的调用次数满足 C(n)=C(n−1)+C(n−2)+1 → 与 fib 同阶指数。
- V2→V3 的通用等价改写：memo 递归填表顺序 = 依赖图的任一**拓扑序**（→ L09/L10：DP 表所在 DAG 的最短路问题）。
- Python 具象：`functools.lru_cache` 即 V2 的一行封装；n=10⁵ 时注意递归深度限制（改 V3）。

## 3 复杂度推导（第二例：最短路径直觉）

- 问题：给定 DAG 与边权，求 s→t 最短路。状态 d[v] = s 到 v 的最短距离；转移 d[v] = min over 入边 (d[u] + w(u,v))。
- 按拓扑序处理（L10 交付拓扑排序），每个顶点处理一次、每条边松弛一次 → Θ(V + E)。
- 对比：一般图有环则此转移不成立（依赖成环）→ 引出 Dijkstra（L11 非负权）/ Bellman-Ford（负权，6.046）。
- 空间优化通例：DP 表只依赖上一层 → 滚动数组（V4 模式），编辑距离（projects/p06）从 Θ(mn) 降到 Θ(min(m,n))。

## 4 正确性论证思路

- 模板：**引理（最优子结构）+ 归纳（计算顺序）**。
  - 引理：s→t 最短路经过 v 的那一段必是 s→v 最短路（否则替换得更短，矛盾——cut-paste / "剪切粘贴"论证，6.046 的叫法）。
  - 定理：拓扑序下逐点松弛后 d[v] = δ(s,v)。对拓扑位置归纳：d[v] 计算时其全部前驱已定，取 min 正确。
- memo 版正确性 = 递归正确性 + "同参数同答案"（纯函数前提）。

## 7 开源项目应用

- **CPython `functools.lru_cache`**：C 实现的 O(1) memo 表（哈希+双向链表，L06/L22 合体），DP 落地首选。
- **diff/git（Myers 算法）**：`xdiff` 即编辑距离 DP 的线性空间变体（V4 思想 + 中点递归）。
- **Biopython/BLAST 局部比对**：Smith-Waterman 是带 max(0,··) 转移的二维 DP。
- **LCS/语音识别解码器（Kaldi/Vosk）**：DP 图（lattice）上最短路，规模百万级仍按拓扑序——本课模型的大规模直系。
