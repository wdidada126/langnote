# L23 van Emde Boas 树：整数宇宙上的 O(log log u)

> 讲次：Fall 2011 Lecture 23 ｜ 教材：CLRS 问题 20-2（vEB 笔记在 course notes L23） ｜ 后续：L26 总结；对照 L15（平衡）与 L17（哈希）

## 1 问题模型

- 字典 + **有序操作**（min/max/successor/predecessor），键取自宇宙 U = {0..u−1}。比较模型的下界： predecessor 需 Ω(log u / log log u)（Beame-Hastad? 细胞探测）；二叉堆只给 min 的 O(1)。
- vEB 树（van Emde Boas, 1977）：利用"键是 w = lg u 位整数"的结构，每步砍掉一半**位** → 操作 O(lg w) = **O(log log u)**。
- 适用画像：u 远大于 n 时的稀疏整数键集合（路由前缀最长匹配、时间轮/定时器、位图 index）。n ≈ u 时不如位图；n 小时不如排序数组+二分。

## 2 结构伪码

```text
vEB(u):  universe 平方根分解——高 ⌈w/2⌉ 位选簇, 低 ⌊w/2⌋ 位簇内定位
  summary: vEB(⌈√u⌉)            # 记录"哪些簇非空"(按位: 簇的存在性集合)
  clusters[⌈√u⌉]: vEB(⌊√u⌋)     # 每簇内再递归
  min, max: 特判两标量（递归基: u=2 直接存 0/1）

SUCCESSOR(x):
  if x < min: return min
  c = x 的高半 (x >> 半宽); r = x 的低半
  if 簇 c 非空（查 summary 或直接判）: 先在 cluster[c] 内找 ≥r 的后继
  else: nc = summary 中 ≥c 的最小非空簇 → 返回该簇 min
```

- 插入/删除对称：维护 summary 的簇存在性（0→1 或 1→0 时同步 summary）。

## 3 复杂度推导（关键递推）

- T(u) = T(√u) + T̂(√u) + Θ(lg u)：一个簇内递归 + 一次 summary 递归 + 高/低半的位运算与常数层调度。（严格版：summary 只走一层 O(lg u)? 标准分析写 T(u) ≤ T(√u) + O(lg u)——summary 查询本身 O(lg √u) 归并进常数层。）
- 换元 S(w) = T(2^w)：S(w) = S(w/2) + Θ(w) → 主定理情形 3（f=n 主导且正则）→ S(w) = Θ(w) → **T(u) = Θ(lg u)**？标准结论：**O(lg lg u)**。
  - 关键步骤核对：S(w) = S(w/2) + Θ(1) 才是 O(log w)。分歧在"层内成本"：vEB 用 Θ(1) 次位运算 + 仅一条递归链 → 正确递推 **T(u) = T(√u) + Θ(1)**（每层常数次 summary/簇访问，另一路不递归），换元得 S(w)=S(w/2)+Θ(1) = **Θ(log w) = Θ(log log u)** ✓。——本讲最重要的"读伪码定递推"示范：先数清"一层付几笔钱、递归开几条链"。
- 空间：Θ(u) 朴素版；**动态 vEB**（结点按需分配）Θ(n)。
- 扩展：y-fast trie（Furmanets 等）把 successor/insert 做到 O(log log u) 且空间 O(n)；x-fast trie O(log log u) 期望。

## 4 正确性论证思路

- 结构不变式：summary 非空簇集合 = {c : cluster[c] ≠ ∅}；min/max 全局标量与"簇内 min"一致；递归基 u=2 显式维护。
- SUCCESSOR 分两情形（同簇 / 跨簇）穷尽，跨簇取"summary 后继簇的最小元素"——证明其确为全局最小后继（字典序 = 高半优先的序，高半同则低半同）：**位切分的序同构**是本讲正确性心脏。
- 删除后 summary 清理：仅当簇变空才同步——论证"非空 ⇒ 在 summary"双向不变式。

## 6 跨课程联系

- **网络（topdown/CS144）**：IP 路由最长前缀匹配 ≈ 前驱查询（把前缀当整数区间端点）；trie 是 L25 的另一解，vEB 系（TCAM+树混合）是硬件路由的折中。
- **OS**：内核定时器轮（timer wheel）是"位分桶"的时间版；`tcache` bins 管理、sched `dl_runtime` 的红黑前驱对照。
- **DDCA/体系结构**：优先编码器/leading-zero-count 电路 = u 固定的组合式 vEB 叶层——log log 深度与电路对数延迟同构（shift-add 乘法器的分块也是平方根分解）。
- **数据库（15-445）**：位图索引/zone map 的"簇存在性摘要"就是 summary 思想的分页版（RocksDB bloom+index block 两层摘要，L17 合体）。
- **CS170/6.046**：y-fast/x-fast 与"字典树+平衡树杂交"的设计范式课。

## 7 开源项目应用

- **RethinkDB/自研 ID 分配**：单调号段复用器的"空洞回收"（next-fit 后继查询）用 vEB/位图分块。
- **Linux `bitmap` API + 位图分配器**：ext4 块位图以 word 分块 + summary 两层，是 vEB 的"两层残件"（真实动机是页粒度 I/O，但结构同构）。
- **ClickHouse/PostgreSQL BRIN**：块范围摘要（min/max per range）= "summary 粗筛 + 簇内扫描"，与 vEB 分解同一张骨。
- **`pyvebtree`/`python-lazy-object-proxy`?** 社区有 C 版 vEB（`vEB`/`libvtree`）但工业使用罕见——诚实注脚：真实系统多用"位图两层分桶"或 y-fast 变体，完整 vEB 主要活在教学与特殊结构（如 LRU 的 O(1) 新实现 "QuickList"? 延伸）。
