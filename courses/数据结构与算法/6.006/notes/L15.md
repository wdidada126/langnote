# L15 平衡二叉树：AVL 树与旋转

> 讲次：Fall 2011 Lecture 15 ｜ 教材：CLRS 13.1 对照 + AVL 原始论文思想（本课 notes L15 独有，CLRS 只讲红黑） ｜ 后续：L16 工程实践、L21 伸展树

## 1 问题模型

- L14 的债：操作 O(h)，但 h 可 Θ(n)。目标：**最坏 O(log n)** 的字典——每次修改后以局部修复维持 h = O(log n)。
- AVL（Adelson-Velskii & Landis, 1962）：不变式升级为"任意结点两子树高度差 ∈ {−1,0,+1}"（平衡因子）。
- 设计模式：*强不变式 + 局部修复（旋转）*——同一模式将在 L20（并查集不变弱了才快）、L21（伸展树干脆放弃最坏界换摊还）反复对照；红黑树是"弱不变式+多路径补偿"的另一解。

## 2 伪码

```text
平衡因子 bf(x) = height(right) − height(left) ∈ {−1,0,1}

ROTATION（唯一局部手术，双向）:
      y               x
     / \     ⟲y      / \
    x   C   ───►    A   y
   / \                  / \
  A   B                B   C
（复杂度：改 3 个指针 + 重算 2 个高度, O(1)）

INSERT(x): 普通 BST 插入 → 沿父链上行更新高度;
  首个失衡点 z 必在插入路径上; 四种形态 LL/LR/RL/RR:
    LL/RR: 单次反向旋转;  LR/RL: 先旋子再旋己（两次）
  关键引理: 修复 z 后, z 的新子树高度与插入前相同 ⇒ 上传播停止 ⇒ 至多 2 次旋转。
DELETE(x): BST 删除 + 自删除点上行的"再平衡"（可能传播 O(log n) 层、O(log n) 次旋转）。
```

## 3 复杂度推导（高度界）

- 定理：AVL 树高 h ⇒ 结点数 n ≥ F(h)，F 满足 Fibonacci 递推（最小 AVL 树 N(h) = 1 + N(h−1) + N(h−2)）。
  - 归纳证明：高 h 的失衡容忍最小树 = 根 + 高 h−1 + 高 h−2（否则子树可再塞结点仍平衡，矛盾）。
  - N(h) = φ^{h+2}/√5 − 夹逼 → h ≤ log_φ(√5·n) ≈ **1.44 log₂ n**。
  - 常数：AVL 最坏高 ≈ 1.44 log₂ n + O(1)；红黑 ≤ 2 log₂(n+1)——AVL 更"胖瘦均衡"，查询更快。
- 操作成本：查找 O(h)=O(log n)；插入 O(log n)（2 旋转 + 上行）；删除 O(log n) 旋转最坏。
- 每个结点多存 height（或 bf）一字段——"最坏保证"的空间/维护税。

## 4 正确性论证思路

- 旋转保 BST 不变式：以中序序列论证——旋转前后 A|x|B|y|C 次序逐字不变（比"指针图"干净的证法）。
- 平衡恢复引理：四情形逐一验证旋转后 |bf| ≤ 1（LR 情形需两个中间高度子案）。
- "修复后高度复原 ⇒ 祖先不再失衡"是插入只需 O(1) 旋转的核心论证，考试爱考；删除时高度可能 −1 → 传播，对比记忆。
