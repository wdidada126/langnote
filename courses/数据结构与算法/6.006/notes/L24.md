# L24 字符串匹配：Rabin-Karp 滚动哈希与 KMP

> 讲次：Fall 2011 Lecture 24 ｜ 教材：CLRS 32.1–32.2 ｜ 本课笔记：notes L24 ｜ 后续：L25 Trie/Aho-Corasick、L26 后缀数组

## 1 问题模型

- 匹配问题：文本 T（长 n）与模式 P（长 m），报告所有出现位置（本课允许重叠；先查一个也同界）。L01 的朴素法 Θ(nm)。
- 两条提速路线：**哈希路线**（Rabin-Karp：期望 Θ(n+m)，把"比较字符串"换成"比较数值"，L07/L17 血脉）与**自动机路线**（KMP：确定 Θ(n+m)，把"回溯"换成"失败函数"）。
- 应用形态：grep/编辑器查找、DNA 比对（L01 回归）、 plagiarism 检测（Winnowing 用 RK 指纹）、入侵检测。

## 2 伪码

```text
RABIN-KARP(T, P, q 大素数):
  x = hash(P) mod q
  y₀ = hash(T[0..m−1]) mod q
  for s = 0..n−m:
    if yₛ == x and T[s..s+m−1] == P: report s   # 二次校验防假阳性
    yₛ₊₁ = (B·(yₛ − B^{m−1}·T[s]) + T[s+m]) mod q   # 滚动: O(1) 换窗

KMP:
  预计算 π[0..m−1]（P 的最长真前缀=后缀长度表）:
    π[0]=0; k=0; for q=1..m−1: while k>0 and P[k+1]≠P[q]: k=π[k]; if P[k+1]==P[q]: k++; π[q]=k
  匹配: 指针 i 扫 T 不回退, j=π 跳转:
    while j>0 and P[j+1]≠T[i]: j=π[j]; if P[j+1]==T[i]: j++; if j==m: report; j=π[m]
```

- RK 参数：B=字母表大小或随机质数、q 防溢出大素数（64 位自然回绕 = mod 2⁶⁴，随机 B 使对抗输入无利可图，L26 口径）。
- KMP 灵魂：匹配失败时已匹配前缀 P[1..j] 内部结构允许把 P 右移 j−π[j] 位——**i 永不回退**（RK 的 i 也从不回退但需要哈希，KMP 纯组合）。

## 3 复杂度推导

- RK：预计算 O(m) + 滚动 n 步 O(1) + 命中校验期望小——若 q > 宇宙大小/失败概率 ≤ m/q 级，期望 **Θ(n+m)**；最坏（全 'a' 类文本）Θ((n−m+1)m) 由"假阳性风暴"造成，随机化（选 q/B）消除。
- KMP 预计算 O(m)：`while` 每步 π 严格降、外层每步至多 +1 → 总降次 ≤ 总升次 ≤ m（摊还！L19 手法）。
- KMP 匹配 O(n)：j 的下降总量 ≤ 上升总量 ≤ n。π 表的正确性 = "最长 border 才能接上"（引理：P 移位合法当且仅当重叠部分是 border）。

## 4 正确性论证思路

- RK：模算术恒等式 yₛ ≡ hash(T[s..s+m−1]) (mod q)——对 B 进制 Horner 展开逐项归纳；"哈希相等 + 逐字验证"保证无假阴性、无假阳性（只影响速度不影响正确）。
- KMP：不变式"匹配前缀 T[i−j+1..i] = P[1..j]"；失败时新 j=π[j] 是使不变式保持的最大值 → 不漏任何合法移位（所有合法移位的重叠必为 border，border 链被 π 穷尽）。
- 考试格式：给 π 表手推匹配过程表（6.006 期中题型）。

## 7 开源项目应用

- **CPython `stringlib`（`stringlib_fastsearch.h`）**：Boyer-Moore-Horspool + Two-Way（Crochemore-Perrin）混合，`str.find` 最坏线性——读它=同时复习 RK/KMP/BM。
- **ripgrep/GNU grep**：字面量路径用 memchr/Twoway，正则路径编译为自动机（L25 呼应）。
- **Linux 内核 `lib/`**：`memmem`（Two-Way）与 `strchr` SIMD 版——内核版 KMP 故事。
- **Mongoc/Redis Search**：子串索引与 BM25 前置过滤，Rabin-Karp 指纹用于全文去重（GitHub 的 Winnowing 查重）。
- **基因比对（minimap2）**：minimizer 指纹 = 多窗口滚动哈希的极值采样——DNA 上的 RK。
