# L18 堆与优先队列：heapify 的线性时间

> 讲次：Fall 2011 Lecture 18 ｜ 教材：CLRS 6.1–6.5 ｜ 本课笔记：notes L18 ｜ 后续：L19 摊还（本讲和式的摊还味）、L20 并查集

## 1 问题模型

- 优先队列 ADT：`insert / find-min / extract-min`（+ decrease-key）。L11 Dijkstra 的引擎盖；事件驱动模拟、任务调度、Top-K。
- **二叉堆** = 数组表示的完全二叉树 + 堆不变式（父 ≤ 子，**只保证偏序**，兄弟间无序）：与 L14 BST 对照——BST 中序全序但树高不受控，堆牺牲秩序换取**形状受控（完全）⇒ h = ⌊log n⌋ 铁定**。
- 数组布局：`i 的孩子 2i+1/2i+2，父 (i−1)//2`——零指针，缓存极佳（CSAPP 视角：指针追逐消失）。

## 2 伪码

```text
SIFT-DOWN(i):              # 与较小孩子交换, 直到不变式恢复
  while True:
    c = argmin(children(i) 中存在者)
    if 无 c 或 a[i] <= a[c]: break
    swap(a[i], a[c]); i = c                      # O(log n)

SIFT-UP(i):   与父比较上冒                          # O(log n)
INSERT:  append 末尾; SIFT-UP                      O(log n)
EXTRACT-MIN: swap(0, 末尾); pop; SIFT-DOWN(0)     O(log n)
BUILD-HEAP(a): for i = n//2 − 1 downto 0: SIFT-DOWN(i)   # 自底向上
HEAPSORT(a): BUILD-HEAP; for k=n−1..1: swap(0,k); SIFT-DOWN(0, 限长 k)
```

## 3 复杂度推导（本讲高潮：建堆为什么 O(n)）

- 朴素界：n 次 SIFT-DOWN × O(log n) = O(n log n)，**错在不均匀**：底层结点 sift 距离短。
- 精确和式：高 h 的完全二叉树，"高恰为 j 的结点"有 ⌈n/2^{j+1}⌉ 个，每个代价 ≤ j：
  T(n) = Σ_{j≥0} ⌈n/2^{j+1}⌉·j = n·Σ j/2^{j+1} = **Θ(n)**（用 Σ jx^j = x/(1−x)² 在 x=½ 处 = 2）。
- 下界：建堆比较数 Ω(n)（对"叶全为极大值"构造）→ Θ(n) 紧。
- 堆排序：BUILD Θ(n) + n−1 次 extract 各 O(log n) → **Θ(n log n) 原地最坏**（对比归并 Θ(n) 空间；L04/L05 谱系补全）。
- 平均下界提示：堆排序比较数 ≈ 2n log n（归并 ≈ n log n）——同阶不同常数，工程偏好归并/快排（L26）。

## 4 正确性论证思路

- BUILD-HEAP 正确性：循环不变式"处理 i 后，i 的整棵子树是合法堆"——归纳自底向上；i+1 步 SIFT-DOWN 恰修复"新根可能违例、两子树已合法"的唯一破坏点。
- HEAPSORT：不变式"a[k+1..n) 已含最大的 n−k−1 个元素且升序放置；a[0..k] 是堆"——堆顶即剩余最大，交换入尾保持。
- extract 的"末尾补顶"为何合法形状：完全二叉树删叶只剩这一种 O(1) 做法——数组表示与形状的绑定论证。

## 7 开源项目应用

- **CPython `heapq`**：纯 Python 最小堆（`heappush/heappop/heapify/merge`）；`heapq.merge` 就是 k 路归并；`nlargest` 自动切堆/排序策略（k 小用堆、k 大排序更快）。
- **Go `container/heap`**：接口注入式堆（Swap 回调），工程教学名作；`time.Timer` 运行时内部堆即本讲数组堆。
- **Java `PriorityQueue`**：无 decrease-key（教训被 L11 预言），故 Dijkstra 场景要 `IndexedPriorityQueue` 自建。
- **RocksDB 调度 / 内核 `sched` 前身 HRTICK、KVM 中断投递**：多处最小堆变体；LLVM `PriorityWorklist`——Pass 调度用无锁化堆近似。
