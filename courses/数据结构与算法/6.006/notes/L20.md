# L20 并查集：按秩合并、路径压缩与逆 Ackermann 界

> 讲次：Fall 2011 Lecture 20 ｜ 教材：CLRS 21.1、21.3（含定理 21.1 结论） ｜ 本课笔记：notes L20 ｜ 后续：L21 摊还进阶、Kruskal（6.046）

## 1 问题模型

- 动态连通性 ADT：`MAKE-SET(x)`、`UNION(x,y)`、`FIND(x)`——"x、y 是否同一集合？"。应用：等价类归并、Kruskal 最小生成树的环检测、网格 percolation、离线最近公共祖先。
- 表示：**森林**——每棵树用一个代表元（根），`FIND` = 上行找根，`UNION` = 根挂根。朴素实现两个方向都会退化成链（FIND Θ(n)）。
- 本讲是摊还分析（L19）的巅峰应用题：两个局部小聪明——**按秩合并 + 路径压缩**——换来 m 次操作 Θ(m α(n))，α = 逆 Ackermann < 5（n < 宇宙原子数）。

## 2 伪码

```text
MAKE-SET(x): p[x]=x; rank[x]=0
FIND(x):
  if p[x] != x: p[x] = FIND(p[x])   # 路径压缩: 沿途全挂到根
  return p[x]
UNION(x,y):
  rx=FIND(x); ry=FIND(y)
  if rank[rx] < rank[ry]: p[rx]=ry          # 小秩挂大秩
  elif rank[rx] > rank[ry]: p[ry]=rx
  else: p[ry]=rx; rank[rx] += 1             # 平秩: 新根秩 +1
```

- Python：列表存 parent/rank，n 个元素两个数组——projects/p08 实现带计数版本（size 加权）与无压缩对照。
- Kruskal 预告：边按权排序后逐条试加，`FIND(u)==FIND(v)` 即成环——O(E log E) 里 DSU 摊后不再是瓶颈（6.046 主场，此处立接口）。

## 3 复杂度推导（关键骨架，完整证明 40 页 → 本课记分层论证）

- 只有按秩：树高 ≤ log n（秩 = 高度上界；秩 k 的树至少 2^k 个结点），FIND O(log n)。
- 加路径压缩后的 α(n) 界证明骨架：
  1. 把结点按秩分成 O(log n) 个**秩层**；2. 定义"慢速增长函数" lg* 与 α(m,n)=min{i≥1: lg^{(i)}(n) ≤ m/n}；
  3. 关键点：同层同"非根压缩标志"的结点，父指针秩沿路径**严格增**且该结点至多被"标记一次"→ 每结点对每层至多付一次跨越成本；
  4. 计数：每 FIND 的成本 = O(跨层大跳) + O(层内重复)，层数 log n → 合计 Σ = O(m α(m,n))。
  5. CLRS 定理 21.1 只要求引用；但"同层父秩严格增"这一引理要能当场证。
- 单操作摊还 O(α)；MAKE-SET n 次 + m≥n FIND/UNION → 总 O(m α(n)) ≈ 线性。

## 4 正确性论证思路

- 不变式：每棵树是某集合、根即代表元；UNION 后两树并一。FIND 压缩只改"父指针高度"不改"代表元归属"——证明 p 变更后 FIND 结果不变（对路径归纳）。
- 按秩的"秩是高度上界"引理：归纳于 UNION 次数；路径压缩破坏高度但从不破坏秩序（秩只增且挂接方向正确）→ 引理仍成立（关键辨析题）。
- 测试策略：对拍（n 小随机 UNION/FIND 序列 vs "集合法"朴素实现，projects/p08）。
