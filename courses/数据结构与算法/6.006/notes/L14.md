# L14 二叉搜索树：结构、操作与有序性

> 讲次：Fall 2011 Lecture 14 ｜ 教材：CLRS 12.1–12.3 ｜ 本课笔记：notes L14 ｜ 后续：L15 AVL 平衡化、L18 堆（同数组表示的另一种秩序）

## 1 问题模型

- 字典 ADT 的**有序**实现：BST 不变式——任意结点 x：`key[left(x)] < key[x] < key[right(x)]`（子树递归成立）。
- 换来哈希表给不了的能力：`min/max、successor/predecessor、range(a,b)`，全部 O(h)（h=树高）。
- 与 L07 哈希对照选型：无序等值查询 → 哈希；有序/范围/前驱 → BST。
- 代价：性能完全押在树高 h 上——插入序决定形态，有序输入退化成链表 h=n（本讲痛点，L15 解决）。

## 2 伪码

```text
SEARCH(x, k): if x=NIL or x.key=k: return x
              return SEARCH(k < x.key ? left : right, k)   # 迭代版同样简单

INSERT: 自根下行, 比较 k 与各结点, 走左/右, 到 NIL 挂新叶          O(h)
MIN: while left: left      MAX: 对称                             O(h)
SUCCESSOR(x): 有右子树 → 右子树 MIN；
              否则沿父指针上行, 直到"从左边来的那个祖先"           O(h)
DELETE(z): 0 子 → 摘除; 1 子 → 子顶替;
           2 子 → 用右子树 MIN y 顶替 z, 递归删除 y（y 至多 1 右子） O(h)
```

- 中序遍历（左-根-右）输出全局升序：Θ(n)，L04 归纳法直接证。
- Python 具象：标准库**没有**自平衡 BST；`bisect` 在有序数组上提供 predecessor/range（O(log n) 查 + O(n) 插）。

## 3 复杂度推导

- 所有动态操作 O(h)。**期望界**：随机插入序（输入是排列的均匀随机）⇒ 期望树高 Θ(log n)，证明骨架：结点 v 的深度 = 第 1 号"记录元"（左起前缀最大值）问题的Indicator 和，E[深度] = Σ 1/i = H_n ≈ ln n → E[h] = O(log n)（对高度取 union bound 需更小心，本课只给期望深度结论）。
- 最坏 Θ(n)：升序输入。由"排序下界"反推：若 BST 最坏 o(log n) 则比较排序 o(n log n)，矛盾 → **任何基于比较的平衡字典都有 Ω(log n) 操作下界**（最坏情形）。
- 与哈希的本质差别：哈希 O(1) 是期望/概率性，BST O(log n) 是**最坏确定**——工程上"可预测延迟"场景（数据库索引、定时器轮）选树。

## 4 正确性论证思路

- SEARCH 正确性：不变式"k 若存在必在以 x 为根的子树中"——比较后按 BST 不变式排除一半，断言保持。
- DELETE 两子情形：右子树 MIN y 是 z 的后继（全局下一个），用它顶替保持 BST 不变式：左(<z) < y < 右(除 y 外 >y，因 y 是右子树最小)。对"至多一子"性质的论证是细节分。
- SUCCESSOR 上行算法：第一次"从左边来"即最小祖先满足 key > x.key——画父指针链证明。
