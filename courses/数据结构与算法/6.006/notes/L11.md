# L11 单源最短路：Dijkstra 与贪心正确性

> 讲次：Fall 2011 Lecture 11 ｜ 教材：CLRS 24.3 ｜ 本课笔记：notes L11 ｜ 后续：L12 博弈搜索、L22 竞争分析；负权见 6.046 Bellman-Ford

## 1 问题模型

- SSSP：带非负权图，源 s，求 s 到一切点的最短距离与路径。BFS 的推广：边不再等价，"层"变成距离值。
- 贪心策略：在所有"未定"顶点中挑当前距离估计 d[v] 最小者**一锤定音**。d 是"经已定集合的上界"，贪心主张：最小上界即真值。
- 应用形态：路由（OSPF link-state 即跑 Dijkstra）、地图导航（L12 A* 是其启发式版）、概率图推理、游戏寻路。

## 2 伪码

```text
DIJKSTRA(G, s):
  d[v] = ∞ ∀v; d[s] = 0
  PQ = 最小堆 of (d[v], v)                 # L18 堆; L06 队列 → 优先队列
  settled = ∅
  while PQ:
    u = PQ.extract_min(); settled.add(u)   # 出堆即"定案"
    if stale(u): continue                  # 惰性删除版
    for (v, w) in G.adj[u]:
      if v in settled: continue
      if d[u] + w < d[v]:
        d[v] = d[u] + w; parent[v] = u
        PQ.insert_or_decrease(v, d[v])     # decrease-key 或重复插入
```

- 两种堆用法：支持 decrease-key（索引堆）→ O((V+E) log V)；惰性重复插入 → O(E log E)，堆里可能积压过期条目（projects/p05 用惰性版）。

## 3 复杂度推导

- 二叉堆：extract-min × V 次、decrease-key × E 次，各 O(log V) → **O((V+E) log V) = O(V log V + E log V)**。
- Fibonacci 堆（6.046 内容，本课提及）：O(V log V + E)。
- 数组朴素版（稠密图）：每轮线性找最小 → O(V²)，邻接矩阵稠密图反而是最优朴素解。
- 每轮堆操作 O(log V)，共 O(V+E) 次——把 L03 的"操作计数 × 单价"方法完整走一遍。

## 4 正确性论证思路（贪心证明范式）

- 定理：u 出堆时 d[u] = δ(s,u)。证明（contradiction + 非负权）：
  设某条 s→u 最短路 P 先离开已定集合于边 (x,y)（y 未定）。则 δ(s,y) ≤ δ(s,u)（P 前缀 + **非负权尾巴**）。归纳假设 x 已定案故 d[x]=δ(s,x)，y 的估计 d[y] ≤ δ(s,x)+w(x,y)=δ(s,y) ≤ δ(s,u)。u 是堆中最小 ⇒ d[u] ≤ d[y] ≤ δ(s,u)；又 d[u] ≥ δ(s,u)（始终是最短路上界可行解）⇒ 等号成立，矛盾。∎
- 要点：**非负权恰好在"δ(s,y) ≤ δ(s,u)"一步使用**——这就是负权让 Dijkstra 崩塌的精确位置（两跳负边反例：A→B(2), A→C(4), C→B(−6) → B 被定案成 2 而真值 −2）。
- 贪心证明通用模板 = "定案集合的前缀最优性" + 交换论证/割性质（与 L18 Prim、6.046 Kruskal 同族）。
