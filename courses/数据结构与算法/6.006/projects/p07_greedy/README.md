# p07 贪心（greedy algorithms）

- 对应讲次：L11（贪心正确性/交换论证）、L18（Huffman 用堆）、L03（期望读者自查复杂度）。
- 知识点：区间调度三策略（最早开始/最短区间/最早结束）与暴力对拍的**反例自动搜索**；Huffman 编码（堆合并、码长、Kraft 等式、熵界 H ≤ L < H+1）。
- 文件：`main.py`（300 组随机区间 + CLRS 16.1 例 + Zipf/重尾分布码长实验）。
- 运行：`run.bat` / `bash run.sh`；手动 `python -m py_compile main.py && python main.py`。
- 预期输出：最早结束策略恒等于暴力最优；两个坏策略被找到正差距反例；CLRS 频率表 L≈2.20 ∈ [H, H+1)；重尾字母表上相对定长节省 30%+。
- 延伸：把区间调度换成带权版本 → DP（加权区间调度，CLRS 习题 16.2-1）看贪心如何失效。
