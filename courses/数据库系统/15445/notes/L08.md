# L08 树形索引（Tree-Based Indexes：B/B+ 树）

> 15-445/645 Fall 2023 · Lecture 8 · 阅读：课程讲义；Project #2 关联
> B+ 树是关系库索引的事实标准：矮、胖、有序、叶相连——每个特征都对着磁盘的脾气。

## 1. 核心概念

### 1.1 为什么不是二叉树/AVL/红黑
点查 n 个键，二叉平衡树高 log2 n：n=1亿时 ≈27 层，每层一次页 I/O（根热、深层冷）→ 不可接受。
DBMS 要的是**多路搜索树（m-ary）**：一个节点塞满一页（几百个键），树高降到 log_m n ≈ 2–4 层——**用"胖节点"换"矮树"，把 I/O 次数压到常数级**。

### 1.2 B 树 vs B+ 树
- **B 树（Bayer & McCreight 1972）**：键和数据都存内部节点，查找可能中途命中。
- **B+ 树**：**内部节点只存键+子指针（作为"路由"），全部数据记录（或 TID 指针）只在叶子**。好处：
  1. 内部节点更"瘦"→ 扇出更大→树更矮；
  2. **叶子用双向链表相连**→ 范围扫描只需顺叶走，不用回到上层（L11 index nested loop / range scan 的基础）。
- **聚集 vs 非聚集**：聚簇索引叶子直接存整行（InnoDB 主键即聚簇）；二级索引叶子存 (key, 主键 TID)，需回表（二次查找）。

### 1.3 查找
从根二分定位子指针 → 逐层下降 → 叶子内二分找键 → 范围则顺叶右兄弟。
复杂度 O(log_m n) 次页访问；缓冲池让上层节点常驻→实际只有叶子层偶尔缺页。

### 1.4 插入与分裂（split）
1. 下降到合适叶子插入键值；
2. 叶子未满（< m）→ 完成；
3. 溢出（满）→ **分裂**：把该节点一分为二，中间键提升到父节点；
4. 父节点因插入新键又溢出 → 递归分裂上升；
5. 根分裂 → 树高 +1（唯一的"长高"方式）。
工程优化：**预防式分裂**（下降路上遇到"将满"节点就提前分裂，保证下行到的父一定有空间）、**Key-only split**（内部节点复制键）。

### 1.5 删除与兄弟借/合并
1. 找到叶子删键；
2. 若节点低于最小度数 ⌈m/2⌉−1 → **underflow**：
   - **borrow（借）**：从相邻兄弟借一个键（父键下移、兄弟键上移，旋转）——兄弟有富余时；
   - **merge（合并）**：兄弟也满了没法借 → 与兄弟合并，父键下沉做分隔，父节点少一个键 → 可能递归 underflow；
   - 根只剩一个子 → 树高 −1。
- 二级索引删除要处理重复键（记 count 或用 (key,pid) 复合）。

### 1.6 变体（点到，L09/工程用）
- **Blink-tree / B-link tree（Lehman-Yao）**：每内部节点也带右兄弟指针 + page-ID，支持 latch-free/concurrent 下降，避免昂贵的上锁爬树（L09 并发索引核心）。
- **BW-tree（Berchtold-Büchi-Widom / Levitin&Mohan 2014）**：无锁 CAS + mapping table + delta page，为 NVMe/持久内存/多核设计，SQL Server Hekaton 系。
- **prefix/branch compression、suffix truncation**：塞更多键进一页。
- **Skip list（跳表）**：RocksDB memtable 用；概率平衡、并发插入友好、实现简单——是"有序 + 多指针"的另一实现（L25 杂项/6.006 联系）。
- **LSM-tree**：写优化，把随机写变顺序写，与 B+ 树读优化互补（L03 写放大）；RocksDB/Cassandra/HBase。

## 4. 开源项目应用
- **InnoDB**：主键=聚簇 B+ 树（16KB 页），二级索引 B+ 树叶子存主键；change buffer、页分裂留 1/16 填充因子。
- **PostgreSQL**：默认 **B-tree（nbtree）** 支持唯一/范围/排序/前缀 like；还有 GiST/GIN/Bloom 等其他"树"。
- **RocksDB/LevelDB**：LSM 为主，但每层 SSTable 内有稀疏 index + 可配 hash；memtable 跳表。
- **sqlite**：B+ 树变体（表与索引都是 b-tree 页，叶子既存数据又存指针）。
- **MongoDB WiredTiger**：B+ 树 + LSM 双模式可配。
