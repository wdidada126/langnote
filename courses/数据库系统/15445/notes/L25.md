# L25 期末串讲与系统杂项（Final Review + Systems Potpourri）

> 15-445/645 Fall 2023 · Lecture 25 · 复习 + 前沿专题串讲
> 收官讲：把全课机制拉通成一条"数据从磁盘到查询再到副本"的主线，再快速掠过几个"数据库还能这样玩"的前沿方向。

## 1. 全课主线回顾（一条查询的生命周期）
1. 用户写 SQL（L02）→ 解析成语法树 → 语义检查（约束/模式，L01）；
2. 逻辑计划（代数，L01）→ 优化器用统计估行估代价、搜物理计划（L14）；
3. 执行引擎跑物理算子树（火山 L12 / 向量化 L13），算子调排序聚合 join（L10/L11）；
4. 算子通过索引定位数据（哈希 L07 / B+树 L08，并发下降 L09）；
5. 索引/表通过缓冲池读页（L06），页从磁盘/SSD 按块读（L03/L04），行或列布局（L05）；
6. 写操作经并发控制保隔离（2PL L16 / TO L17 / MVCC L18），改页前写 WAL（L19）；
7. 崩溃靠 ARIES redo/undo + 备份/PITR 复原（L19/L20）；
8. 规模/可用性驱动复制+分片+共识（L21），跨节点事务（L22），并行分析与云数仓存算分离（L23/L24）。
一句话：**"用有限内存、不可靠设备、并发访问下，对大数据做又快又正确的查询与更新"**——全课都在解这句话。

## 2. 易混概念速查表
| 成对概念 | 一句话区分 |
|---|---|
| latch vs lock | 闩保护内存结构(微秒/无事务语义)；锁保护数据项(事务级) |
| B+树 vs LSM | 读优化原地更新 vs 写优化顺序追加（L08/L03） |
| 行存 vs 列存 | OLTP 读整行 vs OLAP 读整列（L05） |
| redo vs undo | 前滚已提交效果 vs 回滚未提交效果（L19） |
| 2PL vs TO vs MVCC | 悲观锁 / 时间戳拒绝 / 多版本快照（L16/17/18） |
| SI vs Serializable | 快照隔离仍可能 write skew，SSI 才补上（L18） |
| 复制 vs 分片 | 同数据多副本(可用性) vs 不同数据散多机(扩展性)（L21） |
| 火山 vs 向量化 | 逐元组虚调用 vs 批+SIMD（L12/13） |
| 存算一体 vs 分离 | Redshift 早期 vs Snowflake（L23） |

## 3. 前沿专题串讲（Potpourri）

### 3.1 图数据库（Graph DB）
- 数据是顶点/边/属性，查询是**多跳遍历**（关系模型里多表 self-join 的噩梦：`朋友的朋友的朋友` 在 SQL 里指数级 join，在图里 O(跳数)）。
- 查询语言：**Gremlin**（遍历时序）、**Cypher/SPARQL/GQL(ISO 2023)**（声明式模式匹配）。
- 存储：邻接表 vs 邻接矩阵 vs 属性图（CSR 压缩邻接）；关系库用边表 + 递归 CTE 勉强模拟。
- 应用：**Neo4j**（属性图鼻祖，无索引邻接=双向链表指针直连，遍历零查表）、**TigerGraph**、**Memgraph**、**ArangoDB**、Postgres 的 `Apache AGE`。
- 与本课：遍历深度大时缓冲池局部性差，"无索引邻接"是把 L08 的"回表"彻底消除的极端设计。

### 3.2 向量数据库与相似性检索（Vector DB / ANN）
- 场景：embedding 高维向量的近似最近邻（kNN），支撑 RAG/推荐/图像检索。
- 索引：**HNSW**（分层可导航小世界图，跳表式分层导航）、**IVF-PQ**（倒排+乘积量化）、DiskANN（SSD 友好图）。
- 指标：召回率 vs 延迟 vs 内存；本质是"用概率/图结构近似欧氏/余弦最近邻"。
- 产品：**Milvus、Qdrant、Weaviate、pgvector、Faiss(库)**。
- 与本课：ANN 索引 = 新型"索引结构"（对标 L07/L08）；embedding 列压缩 = L05 量化思想。

### 3.3 机器学习与数据库（MLDB / AI4DB / DB4AI）
- **DB4AI**：SQL/ML 集成（特征存储、`CREATE MODEL`、in-database training）。
- **AI4DB（self-driving database）**：用 ML 取代调优决策——learned query optimizer、learned index、自动索引推荐、异常检测。CMU **OtterTune**、Pavlo 的 **"NoDB / Self-Driving DBMS"** 愿景、**Bao**。
- **Learned Index**（Kraska 2018）：用回归模型拟合 key→位置 CDF，替代 B+树比较——数据分布可学时更小更快，但更新/churn 难。
- 与本课 L14：统计信息/基数估计正在被"学习型"方法挑战。

### 3.4 主存与新型硬件
- 内存廉价 → 主存数据库（HyPer/SQLite 内存模式）、持久内存 PMem（字节寻址持久，冲击 WAL/fsync 模型）、NVMe CXL 内存池化。
- 存算处理近数据计算（PIM/SmartNIC）——L23 存算分离的下一站。
