# L12 查询执行 I（Volcano / 迭代器模型）

> 15-445/645 Fall 2023 · Lecture 12 · 阅读：课程讲义；Project #3 关联；Graefe Volcano 论文
> "把每个运算变成一个会吐元组的对象"——一行接口统一了扫描、过滤、连接、聚合，让任意查询树都能被同一个驱动循环跑起来。

## 1. 核心概念

### 1.1 迭代器抽象（Tuple-at-a-Time）
每个算子实现三方法：
```
Init()  -> 重置内部状态，准备新一轮
Next()  -> 返回下一个元组（或 END 表示耗尽）
```
执行引擎是一棵**算子树**（物理计划树），根调 `Next()`，每个算子按需从子算子拉元组——**pull / demand-driven / 火山模型**。

示例（SQL：`SELECT a FROM R WHERE b > 10`）：
```
Projection(a)
   └─ Filter(b>10)
         └─ SeqScan(R)
```
驱动：根 `Init()`；循环 `root.Next()` 直到 END；每次 `Filter.Next()` 会不停调 `SeqScan.Next()` 直到拿到满足 b>10 的行；`Projection.Next()` 再把该行的 b 列裁掉。

### 1.2 算子分类：pipeline vs blocking
- **Pipelined（流水线/非阻塞）**：`Next()` 可以在收到一条输入后很快产出一条输出——SeqScan、Filter、Projection、Union、（部分）join。
- **Blocking（阻塞/materializing）**：`Next()` 第一次调用前必须**消费完全部输入**——Sort、Hash Join 的 build 侧、Hash/Sort Aggregate、ORDER BY。
- 这条分界（"火山模型的接缝"）决定了：内存峰值（阻塞点要存全部数据）、能否早停（LIMIT 只需 pipelined 前缀）、并行切分点（pipeline breaker 处划分流水线段）。

### 1.3 Volcano 系统的成就
Graefe 的 Volcano（1990）+ 后续的 Cascades：
- 统一接口 → 算子正交、可任意组合、可扩展新算子；
- 把"执行"与"优化"解耦（优化器枚举物理算子组合，执行器只负责跑）；
- 支持并行（每个算子可内部并行，EXPLAIN 里 Parallel Aware）。

### 1.4 火山模型的"原罪"：函数调用开销
每条元组都跑一遍 `Init/Next` 虚函数调用链。执行一条 `a+b` 表达式 = 一次虚函数 dispatch，CPU 分支预测失败、无法向量化。
**元组"逐条"流动 → 现代 CPU 的 SIMD/流水线利用率极低。**
这就是 L13 向量化与编译执行要解决的瓶颈。

### 1.5 表达式求值（Expression Evaluation）
算子里的谓词/投影表达式如何求值：
- 朴素：解释执行表达式树（每行递归 eval）——慢；
- **编译执行**：把表达式编译成机器码/闭包（LLVM JIT 或 C 代码生成）一次，每行调用——HyPer/Spark SQL 的 Whole-Stage Codegen；
- **向量化**：一个表达式一次处理一批数据，写回数组——与 SIMD 契合（L13）。

## 3. 跨课程联系
- **CS143 编译原理**：物理算子树 ≈ 编译器 IR/中间代码；火山 `Next()` ≈ 树遍历解释器；编译执行（codegen）≈ 把 IR 编译成机器码。"解释 vs 编译"两条执行路线，两课完全同构。
- **CS61A/CS111 惰性求值**：pull 模型=生成器/协程的 `yield`，Python generator、C# LINQ、Java Stream 就是火山模型的语言级翻版。
- **CSAPP Ch.5/6**：函数调用开销、分支预测、指令级并行（ILP）——火山慢在哪，CSAPP 给微观解释。

## 4. 开源项目应用
- **PostgreSQL**：经典火山，`ExecProcNode` 逐元组，节点=算子（`nodeSeqscan.c` 的 `ExecSeqScan`）。
- **Volcano/Cascades（开源版 CosmosDB 优化器）**、**Calcite**：算子框架鼻祖。
- **DuckDB**：火山"骨架"+向量化"肌肉"——算子接口仍是 `Next()`，但每次返回一个 **DataChunk（2048 行）**。
- **Spark**：Tungsten 用 **Whole-Stage Codegen** 把火山算子树编译成一段 Java 字节码，消除虚函数与对象创建。
