# 02 — B+ Tree（插入/分裂 + 范围扫描）

- **对应讲次**：L08 Tree-Based Indexes
- **机制**：内存 B+ 树——内部节点只存分隔键+子指针（路由），数据全在叶子；**叶子用 next 兄弟指针串联**，范围/全序扫描顺链走 O(range)；插入触发叶子溢出→分裂→中间键提升到父→父再溢出则递归分裂，根分裂时树高 +1。order（最大子指针数）可配。
- **文件**：`main.cpp`。
- **测试覆盖**：顺序插入 50 键后中序有序且分层正确、随机插入保持有序与值映射、`RangeScan[7,13]` 有序且闭合、树高随规模增长。

## 构建
- Windows：`build.bat`　Linux/macOS：`bash build.sh`

## 与讲义的接缝
- `find_leaf` 的"相等即右行"对应 B+ 树处理重复键；二级索引应存 `(key, tid)` 复合键。
- 分裂用"自顶向下 DFS 找父"的教学式实现；工业 B+ 树（L08/B-link）会预分裂或用兄弟指针避免回爬（见 L09）。
- 未实现删除（借/合并），作为练习：underflow 时先向兄弟 borrow、否则 merge 并递归修父（L08 §1.5）。
