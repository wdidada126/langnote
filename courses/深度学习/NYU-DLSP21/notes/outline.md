# NYU DLSP21 提纲

> 骨架级要点；讲次据 atcold.github.io/NYU-DLSP21 公开课表。

## L1 导论与线性模型
- LeCun 视角：学习特征而非设计特征。
- 线性模型三要素：模型/损失/优化器统一框架。
- 软最大与交叉熵作为分类基线。

## L2 多层感知机
- 隐藏单元、非线性与表示层叠。
- 容量与训练：初始化、归一化输入。
- 误差反传直觉：从链式法则到"信用分配"。

## L3 自动微分
- 前向模式 vs 反向模式的复杂度来源。
- 计算图 tape 机制与框架实现。
- LeCun 的立场：BP 是工程必然而非生物学假设。

## L4 卷积神经网络
- 权重共享/局部连接 → 平移等变与参数效率。
- 从 LeNet 到现代 backbone 的设计谱系。
- 能量函数视角：CNN 作为匹配器。

## L5 无监督学习
- 嵌入 + 聚类 + 倒排索引的检索三件套。
- 自监督信号设计：对比、预测、重建。
- JEPA 与能量模型思想的伏笔。

## L6 序列模型（Cho 主讲）
- 语言建模目标与困惑度。
- RNN→LSTM→GRU 的演化与门控推导。
- Cho 的教义：序列本质是"上下文条件分布"。

## L7 注意力与 Transformer
- 加性/乘性注意力打分。
- 自注意力的排序不变性与位置补偿。
- 多头、残差流与并行化收益。

## L8 BERT 与 GPT
- 双向掩码 vs 自回归：两种预训练目标的得失。
- 微调 vs in-context learning 两条下游路线。
- 上下文相关词向量的层次分析。

## L9 强化学习
- 从监督到 RL：数据分布随策略变化。
- 值函数/策略梯度二分法速览。
- DQN 与 Atari：深度网络作为价值近似器。

## L10 新浪潮与 Build GPT-2 Mini
- 2021 视角的展望：自监督、可扩展训练。
- 期末项目拆解：tokenizer → 数据管线 → 模型 → 预训练 → 评估。
- 用 6000 万参数 GPT 续写文本的完整工程链。
