## 为什么学

- 堪称"圣经级"的深度学习入门课，学习者数以百万计，讲解深入浅出、Project 编排精细。
- 从最基础的前向传播一路覆盖到 CNN、RNN、Attention 与 Transformer，一站式建立完整知识地图。
- C3《ML 策略》独一份：教你如何在真实项目中做误差分析、设定 human-level baseline、诊断偏差/方差，是刷题课给不了的工程直觉。
- 学完可直接衔接 CS231n / CS224n / CS285 等进阶课，也适合参加 Kaggle 比赛练手。

## 先修与知识联系

- 先修：Python、线性代数与微积分基础、机器学习入门（对应 Coursera ML / CS229 前半）。
- 后续：CS231n（CV 深入）、CS224n（NLP 深入）、EECS498-007（DL for CV 实战）、LHY（进阶专题与作业）。
- 横向：与 CS229 共享监督学习框架；C5 序列模型与 CS224n 前半重合，可互为强化。
