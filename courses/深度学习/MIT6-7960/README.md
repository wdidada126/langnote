## 为什么学

- 覆盖面广：不只押注 LLM/NLP 单一主线，也系统覆盖 CV 等任务与方法，适合建立"多方向通识"。
- 理论、模型设计、应用案例三线合一，能看清"同一套 DL 思想"如何在不同任务落地。
- MIT OCW 完整公开（视频/作业/项目），自学友好，作业与项目适合进阶练手。
- 难度介于 CS230 与 CMU 11-785 之间，是从"会用"到"懂原理"的好跳板。

## 先修与知识联系

- 先修：线性代数、概率统计、机器学习基础（CS229/TinyML 课程群任意一路）。
- 纵向：可衔接 6.5940 TinyML（高效化）、6.S184 生成模型（SDE 视角）、CS231n/CS224n 深入方向。
- 横向：与 CMU 11-785 主题重叠度高，可互为讲解补充（11-785 更硬核、6.7960 更均衡）。
