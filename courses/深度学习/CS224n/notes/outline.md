# CS224n 提纲

> 骨架级要点；讲次以 2025 官网为准。

## L1 导论
- 符号派到连接派：NLP 的范式迁移时间线。
- 层次语言学：语音/形态/句法/语义/语用与深度模型对应物。
- 课程地图：从计数向量到 LLM。

## L2 词向量
- 分布假设；计数法（共现矩阵+SVD/PPMI）与预测法（word2vec）。
- 负采样的博弈解释；SGNS 目标函数。
- GloVe：全局-局部折中；向量类比与局限。

## L3 依存句法
- 图表示与投影性约束；动态规划打分。
- 早期神经网络解析器：窗口特征→递归网络。
- 结构化预测 vs 逐 token 分类的差异。

## L4 Seq2Seq 机器翻译
- encoder-decoder 框架与暴露偏差。
- BPE 子词切分如何解决 OOV。
- 束搜索与长度惩罚（A4 主线）。

## L5 注意力
- 对齐问题：固定向量瓶颈。
- 加性/乘性注意力与软对齐可视化。
- 注意力即"可微检索"。

## L6 Transformer
- QKV 缩放点积与多头并行。
- 位置编码、残差流、前馈层分工。
- 训练成本对比 RNN：并行的胜利。

## L7 Transformer 实践
- 从 0 搭 encoder-decoder 做翻译（A4/A5）。
- padding mask 与因果 mask 的区别。
- 常见坑：初始化、标签平滑、学习率 warmup。

## L8 BERT 与 GPT
- 目标决定架构：MLM vs 自回归 LM。
- 微调范式 vs prompt 范式的分野起点。
- 句子级任务的 [CLS] 与 token 级任务的表示复用。

## L9 上下文表示
- ELMo：双向 LSTM 特征提取器时代。
- 探针实验：模型内部存在何种语言学信息。
- 静态嵌入→上下文嵌入的语义升级。

## L10 神经生成与解码
- 训练（MLE）与推理（解码）目标错配。
- 重复与平淡问题；top-k/top-p 采样。
- 评估：BLEU/ROUGE 的失效与现代方法。

## L11 大语言模型
- GPT-3 与 in-context learning：提示即程序。
- 缩放定律与涌现能力。
- 数据配比、tokenizer 设计成为核心竞争力。

## L12 提示与推理
- CoT 与自洽性；提示的搜索与编译（DSPy）。
- 工具调用与检索增强。
- 推理模型的 test-time compute 视角。

## L13 对齐
- SFT→RM→PPO 的 RLHF 流水线。
- 奖励黑客与 DPO 简化。
- 对齐税与安全评估。

## L14 PEFT
- LoRA 低秩假设与合并推理。
- Adapter/Prefix/IA3 谱系。
- 全参微调 vs PEFT 的决策树。

## L15 多模态
- CLIP 对比学习与零样本迁移。
- 视觉投影进 LLM（LLaVA 式）。
- 统一 token 空间的得与失。

## L16 可解释性与评估
- 注意力可视化不是解释。
- 探针、因果中介分析入门。
- benchmark 污染与评估设计。

## L17 前沿
- 当季嘉宾讲座：智能体、长上下文、高效架构。
- Final Project（SQuAD QA）答辩精华复盘。
