### 1.2 VAE：变分自编码器
隐变量 z ~ N(0,I)，解码器 p_θ(x|z)，用编码器 q_φ(z|x) 近似后验。优化**证据下界（ELBO）**：
```
log p_θ(x) ≥ E_{q_φ(z|x)}[log p_θ(x|z)] − KL( q_φ(z|x) ‖ p(z) )
             └──── 重构项 ────┘             └──── 正则项 ────┘
```
- **重参数化技巧**：`z = μ_φ + σ_φ ⊙ ε, ε~N(0,I)` → 随机性移出计算图，L04 的反向传播照常可用。
- KL 闭式（对角高斯）：`½ Σ (μ² + σ² − log σ² − 1)`；
- σ 固定 → 重构损失退化为 MSE；ELBO 是"最大似然"的变分近似——
  生成模糊源于后验均值回归（平均脸效应），与 L03 的正则-偏差直觉同源。

### 1.3 GAN：对抗博弈
生成器 G(z) 造假，判别器 D(x) 验真，极小极大：
```
min_G max_D  E_x[log D(x)] + E_z[log(1−D(G(z)))]
```
- 理论不动点：唯一均衡 = 真实分布（Jensen-Shannon 散度）；实践中**没有收敛保证**。
- 训练病理与解法（A3 核心经验）：
  模式崩溃（只学会一类）→ 标签条件化/mini-batch discrimination；
  震荡/不收敛 → D、G 交替比例与学习率平衡；
  梯度消失（D 太强）→ **WGAN/WGAN-GP**：
  `min_G max_D E[D(x)] − E[D(G(z))] s.t. |∇D|_2 ≤ 1（梯度惩罚）`—— Wasserstein 距离替代 KL。
- **DCGAN** 卷积配方（L06 积木）：stride 卷积代替池化、BN（G 内）、LeakyReLU。
- 条件生成（cGAN/StyleGAN）：标签/文本嵌入注入（concat/adaIN）→ L14 扩散之前的 SOTA。

### 1.4 VAE vs GAN 光谱
似然可算（VAE/自回归）↔ 样本锐利（GAN）：重构-多样性-锐利的"不可能三角"，
L14（扩散）用 Langevin 采样把两者兼得——本讲是理解那条路线的必经台阶。
