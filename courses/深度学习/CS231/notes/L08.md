# L08 注意力与 Transformer（Attention and Transformers）

> Spring 2025 · Lecture 8 · 作业 **A2 截止**、A3 铺垫（本讲是 ViT/P3 项目的理论基础）。
> 参考阅读：原论文 Vaswani et al. 2017；课程 supplementary "The Illustrated Transformer"。

## 1. 核心概念

### 1.1 注意力：可微查表
查询 Q、键 K、值 V 的软检索。缩放点积注意力：
```
Attention(Q,K,V) = softmax(QKᵀ/√d_k) · V
```
- `√d_k` 防点积随维度方差过大 → softmax 饱和（梯度消失）；
- softmax 行归一 → 每步输出是 V 的**凸组合**：对 token 集合置换等变（permutation equivariant）、无位置概念；
- 与 L07 对比：RNN 沿时间递推 O(T) 串行，注意力**任意两点一步直连**（长程路径长度 O(1)）且全并行，
  代价是 O(T²) 存储——L11 的 FlashAttention/稀疏化全在救这个 T²。

### 1.2 多头与 Transformer 块
```
MultiHead(Q,K,V) = Concat(h_1..h_P)·W_O ,  h_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
块 = MHA → Add&Norm → FFN(Linear→GELU→Linear) → Add&Norm
```
多头 = "多个子空间各自查表"（语法头/指代头/纹理头…）；残差与 LN 让深层堆叠可训（L06 残差 + L06 BN 思想的逐样本版 LayerNorm）。
**前向公式的梯度全部由 L04 链式法则推出**——P3 项目手写了一遍。

### 1.3 位置信息
注意力自身"词袋"，需注入位置：
- 学习式嵌入（NLP 原版）；
- 正弦编码（频率基，外推性好）；
- 相对位置偏置 / RoPE（旋转嵌入，LLaMA 系标配）；
- ViT：class token + 学习式 patch 位置嵌入。

### 1.4 ViT（Vision Transformer, 2020/21）
图像切 patch：`224×224×3 → 196 个 16×16×3 → 线性投影成 196 个 token`，后接标准 Transformer。
- 卷积 = 局部先验+平移等变：小数据友好；ViT = 无先验+大数据驱动：JFT-300M 规模反超 CNN。
- **归纳偏置换可扩展性**：本课反复出现的对偶（也解释了 L12 自监督为何偏爱 ViT——大模型吃大数据）。
- 后续：Swin（层级+窗口注意力，把 O(T²) 拉回线性）、DeiT（纯 ImageNet 蒸馏可行）、ViT-22B。

### 1.5 注意力在视觉各任务（A2 检测/分割的伏笔）
- DETR：检测=集合预测，目标查询注意力替代 NMS（L09）；
- 分割/视频：SAM 图像编码器（L09/L10）；多模态：cross-attention 把视觉接进 LLM（L13/P3 玩具版）。
