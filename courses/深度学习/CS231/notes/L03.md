# L03 正则化与优化（Regularization and Optimization）

> Spring 2025 · Lecture 3 · A1 进行中（本讲内容直接对应 A1 的 SVM/softmax 调参部分）。
> 参考阅读：课程 Notes "Regularization"、"Optimization I"。

## 1. 核心概念

### 1.1 为什么需要正则化：偏差-方差
训练误差低不代表测试误差低。欠拟合=高偏差，过拟合=高方差；模型容量与数据量之间的张力
由**正则化**调节。经验风险 + 结构风险：
```
L_total(θ) = (1/N) Σ_i L_i(f(x_i;θ), y_i) + λ R(θ)
```

### 1.2 参数范数惩罚
- L2：`R(W) = ||W||_F²`，对所有权重收缩，偏好"小而分散"的权重；梯度 `2λW` 与数据梯度**相加**，
  故 λ 必须相对**损失**（而非正则项）取小值——A1 的 learning rate/λ 扫描必踩点。
- L1：`R(W) = ||W||_1`，产生稀疏解（等高线菱角效应），特征选择意义。
- Elastic Net：两者混合；`max(0, |w|-ρ)` 软阈值是其解析近端算子。
- 其他：数据增强（对分类任务是最强"免费"正则）、早停（implicit L2）、Dropout（AlexNet 配方，见 L06）。

### 1.3 优化问题设定
损失面对参数一般是**非凸**的，但小批量 SGD 在实践中收敛良好。优化即：
```
θ_{t+1} = θ_t - α · ĝ_t ,   ĝ_t ≈ ∇_θ L  （mini-batch 近似梯度，E[ĝ] = ∇L）
```
batch / mini-batch / stochastic 是方差与算力的折中：batch 小→梯度噪声大但更新便宜、
泛化往往更好（噪声即隐式正则）。

### 1.4 梯度下降家族
- **Momentum**：`v = μv - αg; θ += v`，抑制锯齿震荡，等效把病态曲率条件数缩小。
- **Nesterov**：先按惯性走一步再回头修正梯度，理论收敛率略优。
- **AdaGrad / RMSProp / Adam**：按坐标缩放步长，
  `Adam: m=β₁m+(1-β₁)g, v=β₂v+(1-β₂)g², θ -= α m̂/(√v̂+ε)`，
  自适应但 CV 大模型上纯 Adam 泛化常逊于 momentum SGD（ViT 训练用 AdamW：解耦权重衰减，
  `θ -= α( m̂/(√v̂+ε) + λθ )`）。
- **学习率调度**：step decay / cosine / warmup（Transformer 与 BN 时代标配，L06/L08 用到）。

### 1.5 二阶视角与梯度检查
牛顿法 `θ -= H⁻¹g` 不可行（H 为 D×D）；LBFGS 在小模型偶用。工程上本课只信一阶导，
但**必须验证梯度推导**：中心差商
```
g_num = (L(θ+h)-L(θ-h)) / 2h ,   h=1e-6 ，  要求相对误差 < 1e-6
```
A1 的 gradient check 即此——"make it right" 的纪律。

## 4. 知识点在开源项目中的应用
- PyTorch `optim.SGD(momentum=, weight_decay=)`、`optim.AdamW`：本讲全部公式的工业实现；
  AdamW 论文指出 `weight_decay` 塞进 SGD 式 Adam 不等价于解耦衰减，PyTorch 已修正。
- `torch.optim.lr_scheduler.CosineAnnealingLR` / timm 的调度表（cosine + warmup + EMA）是 L03 经验参数的固化。
- HF `accelerate`/DeepSpeed 的 gradient accumulation：等效放大小批量以模拟大 batch（1.3 的算力-方差权衡）。
