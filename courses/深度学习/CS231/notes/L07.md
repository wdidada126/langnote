# L07 循环神经网络（Recurrent Neural Networks）

> Spring 2025 · Lecture 7 · 承 L04 反传技术，时间展开版。
> 参考阅读：课程 Notes "RNN"；Karpathy "The Unreasonable Effectiveness of RNNs"。

## 1. 核心概念

### 1.1 序列模型与权重共享
图像用空间共享（卷积），序列用**时间共享**：
```
h_t = σ_h(W_hh h_{t-1} + W_xh x_t + b)      （隐状态：压缩的历史）
ŷ_t = W_hy h_t + b_y                         （每步输出）
loss = Σ_t L_t(ŷ_t, y_t)                     （对齐/错位监督均可）
```
参数跨 t 共享 → 任意长度输入、few-shot 泛化结构先验。三种模式：
one-to-many（图像描述生成）、many-to-one（情感分类）、many-to-many（视频动作识别、翻译）。

### 1.2 词嵌入
图像是像素网格，文本首先进入**查表**：`x_t = E[w_t] ∈ R^D`，E 随网络端到端学习。
`word2vec` 式的分布假设（"观其伴知其义"）使语义=向量几何：`king - man + woman ≈ queen`。

### 1.3 沿时间反向传播（BPTT）
把 RNN 按 T 步展开成 L04 的深网（共享权重！），链式法则沿展开图回传：
```
∂h_T/∂h_k = Π_{t=k+1..T} diag(σ'_t) W_hh      （雅可比连乘）
```
连乘的谱半径决定命运：特征值<1 → **梯度消失**（长程依赖学不动）；
>1 → **梯度爆炸**（loss NaN）。对策：梯度裁剪 `g ← g · min(1, c/||g||)` 治爆炸；
门控架构治消失。

### 1.4 LSTM / GRU
LSTM 引入细胞状态 c（记忆总线）与三门（遗忘/输入/输出）：
```
f_t = σ(W_f [h_{t-1}, x_t]);  i_t = σ(...);  o_t = σ(...)
g_t = tanh(W_g [h_{t-1}, x_t])
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t        ← 关键：加法+门控使梯度可"恒等"流动
h_t = o_t ⊙ tanh(c_t)
```
直觉：c 是传送带，f≈1 时梯度沿加法路径不衰减（Highway/ResNet 思想的序列版）。
GRU 两门（更新/重置）合并 c 与 h，参数少 25%，效果常相当。

### 1.5 视觉应用
- **Show and Tell**：CNN 特征作解码 RNN 的初始输入/每步条件（attention 的前夜，L08）。
- **图像描述 BLEU 评估**、两阶段 captioning；视频=时间序列（L10 的 RNN 时代方案即两流 CNN + LSTM）。
