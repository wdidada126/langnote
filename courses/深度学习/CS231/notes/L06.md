> 参考阅读：课程 Notes "CNN Architectures"、"Case Studies"。

## 1. 核心概念

### 1.1 架构演进的两条曲线
ImageNet top-5 错误率 2010–2015：30%→3.6%（超过人类标注员）。驱动力：
**更深的网络 + 更强的正则 + 更大的数据/GPU**。规律（Karpathy 风格总结）：
网络越深，浅层负责边缘/纹理，深层负责部件/对象——表示层次化。

### 1.2 经典案例速览
- **AlexNet (2012)**：8 层、ReLU、Dropout、LRN、数据增强、GPU 双卡。首次展示"大数据+深网+GPU"。
- **VGG-16 (2014)**：只用 `3×3 conv` 与 `2×2 pool` 的极简语法，16–19 层；证明深度与统一积木的威力，也是迁移学习首选 backbone。参数 138M（FC 占大头），启示：**深可以，但要省参数**。
- **GoogLeNet / Inception (2014)**：同一位置并联 1×1/3×3/5×5/pool 多分支（"该用哪种滤波器？都学"），
  1×1 卷积做**瓶颈降维**：`C→C'→C''` 的参数量 `C·1·C' + C'·3·3·C''` 远小于 `C·3·3·C''`。
- **ResNet (2015)**：残差块 `y = F(x, {W}) + x`。动机：普通 56 层网反而**不如** 20 层（优化退化而非过拟合）。
  恒等捷径保证 `∂L/∂x ≥ ∂L/∂y`，梯度有"高速公路"；152 层可训，预激活变体（BN→ReLU→Conv）成为后续标准。
- **后 resnet 简史**：ResNeXt（分组卷积）→ DenseNet（稠密连接）→ MobileNet（深度可分离：先逐通道 conv 再 1×1 混合，FLOPs 降 ~9 倍）→ EfficientNet（复合缩放）。

### 1.3 Batch Normalization (2015)
对每个 batch 内通道的激活做标准化，再接可学的 γ/β：
```
μ_B, σ_B² = batch 统计；x̂ = (x-μ_B)/√(σ_B²+ε)；out = γx̂ + β
训练用 batch 统计；推断用 running mean/var（EMA）—— train/eval 模式差异的元凶。
```
作用机制的现代理解：不只是减少 ICS（内部协变量偏移），更关键的是**平滑损失面**、
允许更大学习率、附带轻微正则。位置：Conv→BN→ReLU 或 BN→ReLU→Conv（预激活，ResNet v2）。
反传公式含 1/N 交叉项（batch 内样本不再独立）——A2/P2 手写 BN 的难点。

### 1.4 迁移学习（把课程史变成你的免费算力）
ImageNet 预训练 backbone + 自有小数据集微调：
- 冻结 backbone 只训头部（数据少、域近）→ 逐层解冻 + 小学习率微调（数据多、域远）；
- 判别规则：**数据少 → 增强+冻结；数据多 → 全网络重训或大学习率微调**。
