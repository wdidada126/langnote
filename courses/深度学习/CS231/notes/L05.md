## 1. 核心概念

### 1.1 全连接用于图像的三宗罪
对 224×224×3 输入用全连接：第一层若 1000 隐元即 `150528×1000 ≈ 1.5 亿`参数——
(1) 参数爆炸；(2) 无视空间局部性（相邻像素强相关）；(3) 平移后需重学。
卷积 = **局部感受野 + 权值共享 + 多滤波器堆通道**。

### 1.2 卷积层的结构
输入 `X ∈ R^{H×W×C}`，滤波器 `W_k ∈ R^{R×S×C}`，输出激活图：
```
o(i,j) = Σ_{r,s,c} X(i+r-1, j+s-1, c) · W_k(r,s,c) + b_k
```
P 个滤波器 → 输出 `H'×W'×P`。空间尺寸与深度公式（A1/A2 必背）：
```
H' = (H - R + 2P_pad)/stride + 1        通道数 = 滤波器个数
```
三种"相关性"：每个输出与输入**局部**相关、跨位置**平移等变**、通道间**全连接**。

### 1.3 池化与典型堆叠
max-pool 2×2 减半分辨率（L04 的 max 门梯度规则逐窗应用）。经典积木：
```
[Input → CONV → RELU → POOL] × n → FC → SOFTMAX
```
感受野随深度**乘性增长**：两层 3×3 等效 5×5，但参数更少、非线性更多（VGG 的洞见，L06）。

### 1.4 卷积的反向传播
CONV 本质是"带滑窗索引的稀疏矩阵乘"，反传两条等价路线：
- **对偶性**：对 X 的梯度 = 用同一批权重、以"翻转 180° 的滤波器"对上游梯度做卷积（corr vs conv 的历史分歧即来源于此）；对 W 的梯度 = X 与 dO 的互相关。
- 工程实现：**im2col**——把每个感受野拉平成行，滑窗卷积 → 一次大 GEMM（L05 fast 路线，P2 项目实现 naive/im2col 两版 + 梯度检查）。

### 1.5 参数量与 FLOPs 手算（面试级基本功）
- 参数量：`R·S·C·P + P`；
- 前向乘法数：`H'·W'·R·S·C·P`；
- 经验：一个 3×3 conv 层 FLOPs 常占全网络大头，FC 层参数多但现代 CNN 里 FLOPs 占比下降（1×1 瓶颈，L06）。

## 4. 知识点在开源项目中的应用
- cuDNN 的 `cudnnConvolutionForward`：背后是 Winograd/FFT/im2col-GEMM 算法族（P2 的 naive→fast 演进即其简化史）。
- [llama.cpp](https://github.com/ggml-org/llama.cpp) 的 ggml 后端把 conv/attention 统一为"带布局的 matmul 图"，1.4 的 im2col-GEMM 思路在 CPU 上同样成立（其 `im2col` 用于 whisper/clip 视觉塔）。
- torchvision `nn.Conv2d(in_channels=3, kernel_size=3, padding=1)`：尺寸公式的官方可执行版；`groups=` 即深度可分离卷积（MobileNet，L06 伏笔）。
