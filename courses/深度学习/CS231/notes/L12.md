# L12 自监督学习（Self-Supervised Learning）

> Spring 2025 · Lecture 12 · 连接 L06（预训练 backbone）与 L13（生成）的桥梁。
> 参考阅读：Chen et al. SimCLR；He et al. MAE；Oquab et al. DINOv2 节选。

## 1. 核心概念

### 1.1 免标签的学习：预文本任务（pretext task）
监督信号从"人给的标签"换成"数据自己造的问题"：
- 拼图/旋转预测（自回归式）→ 上下文预测（CPC）→ 掩码重建（MAE/BERT 视觉版）
- **实例判别**（instance discrimination，Doersch/Exemplar 一脉）→ **对比学习**
- **自蒸馏**（BYOL/DINO）→ **图文对齐**（CLIP，L13/多模态的前夜）

### 1.2 对比学习
同一图两个增强视图=正样本对，batch 内其余=负样本：
```
z_i = g(f_aug1(x)),  z_j = g(f_aug2(x))
InfoNCE: L = -log exp(sim(z_i,z_j)/τ) / Σ_k exp(sim(z_i,z_k)/τ)
```
sim 用归一化点积、τ 控制难负例权重；**增强设计即监督定义**
（SimCLR：crop+color jitter+gray；对颜色敏感的医学任务就要慎用 color jitter——增强是领域知识入口）。
均匀性/对齐（Wang & Isola）给出表示空间的几何刻画。

### 1.3 非对比：自蒸馏与掩码建模
- **BYOL/DINO**：学生-教师双网 + 停止梯度 + 原型分布正则，不需要负样本——
  分布式友好（L11），DINOv2 借此扩到 1.42 亿图、产出"通用视觉特征"。
- **MAE**：ViT 随机遮挡 75% patch、只让编码器看 25%、轻量解码器重建像素——
  极简却逼近对比法，掩码率/信息不对称是成功关键。

### 1.4 评估协议
线性探针（L09 已见：冻结 backbone 只训线性头）、微调、以及零样本迁移（CLIP 路线）。
"表示质量"没有单一指标，本课强调：**任务相关性 > 刷榜**（DINOv2 的 segmentation/depth 特征分析）。

### 1.5 图文自监督（CLIP）
4 亿图文对、对称 InfoNCE（batch=32768 是 L11 的存在理由）：
```
I_i·T_i 配对为正例，batch 内其余图文为负例 → 双塔各自得到"开放词汇"嵌入空间
```
零样本分类 = 把类别名写进模板当文本查询；开放词汇检测/分割（Grounding DINO、CLIP 进检测头）的根。
