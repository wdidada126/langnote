> 参考阅读：课程 Notes "Linear Classifiers"、"kNN"。

## 1. 核心概念

### 1.1 数据驱动决策与 kNN 基线
k-Nearest Neighbor：对测试点 x，取训练集中距离最近的 k 个样本投票。
```
d(x, x_i) = ||x - x_i||_2        （或 L1 / 马氏距离）
ŷ = mode{ y_i : i ∈ kNN(x) }
```
kNN 没有"训练"只有"记忆"，但暴露了两个贯穿全课的概念：
- **超参数 k 与距离阈值只能在验证集上调**——引出 train/val/test 三分与 k-fold 交叉验证；
- 高维图像上欧氏距离失效（维度灾难），"像素相似 ≠ 语义相似"——这正是线性分类器乃至 CNN 的出发点。

### 1.2 线性分类器：把图像映射为打分
```
s_c = w_c^T x + b_c ,  s ∈ R^K  （K 个类别各一个打分）
```
每类一个"模板向量" w_c，图像与模板点积越大越像该类。相比 kNN：训练时把代价付掉
（学 W），推断只要一次矩阵乘——O(DK) 而非 O(ND)。参数矩阵 `W ∈ R^{K×D}` 就是"类别模板库"。

### 1.3 多分类 SVM（hinge）损失
间隔损失：正确类打分至少比错误类高一个 margin Δ：
```
L_i = Σ_{j≠y_i} max(0, s_j - s_{y_i} + Δ)
```
**不可微但有次梯度**：违规类（差值 > -Δ）梯度为 ±1，满足类梯度为 0（稀疏梯度）。
关键工程点：Δ 与 W 的尺度耦合，约定 Δ=1，则正则强度 λ 才可与损失比较。

### 1.4 softmax（多类逻辑回归）损失
把打分变成概率（温度由打分尺度控制）：
```
p_c = e^{s_c} / Σ_j e^{s_j}
L_i = -log p_{y_i} = -s_{y_i} + log Σ_j e^{s_j}
∂L_i/∂s_j = p_j - 1[j = y_i]      ← 极简洁的梯度
```
- 梯度 = 预测概率分布 − one-hot 真值：**Softmax + 交叉熵 = "预测与真实的差"**。
- 输出层数值稳定技巧：先减去 max(s) 再取指数（A1 会踩这个坑）。
- SVM 只约束"排序正确"，softmax 惩罚"错误类概率质量"，通常 softmax 收敛更好。

### 1.5 数据预处理与偏置技巧
零中心化 + 归一化（每维 0 均值 1 方差）使损失面更各向同性，利于 L03 的梯度下降；
增广一列 1 把 b 并入 W（或推断时单独加），A1 采用前者。

## 4. 知识点在开源项目中的应用
- scikit-learn `LogisticRegression(multi_class='multinomial')`、`SGDClassifier(loss='hinge')`：与本讲公式一一对应；A1 就是不用这些库、手写 numpy 版。
- PyTorch `nn.CrossEntropyLoss`：内部融合了 log-softmax + NLL（数值稳定版本讲 1.4）；注意它输入是**打分不是概率**，是新手最常掉的坑。
