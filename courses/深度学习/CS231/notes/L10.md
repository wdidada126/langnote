# L10 视频理解（Video Understanding）

> Spring 2025 · Lecture 10 · A2 已截止（5/7），本讲起为课程后半段"任务扩展"。
> 参考阅读：Feichtenhofer 两流/SlowFast 讲义节选；Kinetics/AVA 数据集文档。

## 1. 核心概念

### 1.1 视频 = 第 4 个维度
`V ∈ R^{T×H×W×3}`。任务族：动作识别（Kinetics 标签）、时序定位（moment retrieval，
"什么时候开始鼓掌"）、跟踪与视频分割（DAVIS，L09 的 mask 跨帧传播）、
字幕/描述（MSR-VTT，接 L07-L08 的编解码）。
数据规模感：Kinetics-700 约 65 万段 clip、每段 10 秒——
"帧数×空间 token"使视频注意力的序列长度比图像大 1-2 个数量级（1.3 复杂度的现实压力）。
与图像分类的本质区别：**动作由"变化"定义**——单帧无法区分"准备发球"与"刚发完球"。

### 1.2 三条建模路线
- **3D 卷积 (C3D/ResNet-I3D)**：把 L05 的 `3×3` 扩成 `3×3×3`（时间×高×宽），
  或空间预训练 + 时间 1×T×1 膨胀（I3D 的 inflate 技巧，节省视频标注）。
- **两流网络 (Two-Stream)**：RGB 流管外观、**光流流**管运动，late fusion；
  共识：外观主导（识别任务中 RGB 流贡献更大）。
- **SlowFast**：快流高分辨率小通道抓运动（时间 stride=1），慢流低帧率高通道抓语义——
  用通道分配换时间分辨率的非对称设计。
- **Two-Stream → Transformer**：时间注意力（X3D/TimeSformer/VideoMAE），帧当 token。

### 1.3 预训练与长视频
视频标注贵 → 主力打法是 **图像预训练 backbone + inflate/适配 + 小学习率微调**（L06 迁移的时序版）；
长视频用分段采样（sparse clip sampling）+ 段级特征聚合（mean-pool/注意力池化/LSTM 头，L07 复活）。
自监督进入视频（L12）：帧顺序预测、掩码像素重建（VideoMAE）几乎无标注可用。

### 1.4 检索与描述（视觉-语言交汇）
CLIP 逐帧编码 + 时间聚合 → 文本查询检索（"猫跳下桌子的视频"）；
LLaVA-OneVision/Qwen2.5-VL 把均匀采样帧直接喂进多模态 LLM 做视频问答——
本课程的多模态主线（L13/L16 的前奏）在此显形。

## 2. 与前后讲次的联系
- 直接复用：L05/L06 卷积积木（inflate 自 ResNet）、L08 注意力（帧 token）、L09 检测器（逐帧检测+关联=多目标跟踪）。
- 时间轴复杂度：T 帧 × 196 token 的 O((T·N)²) 注意力是 L11 分布式/稀疏优化的真实压力源。

## 4. 知识点在开源项目中的应用
- **PyTorchVideo / torchvision `MViT`、`S3D`**：1.2 全部模型的官方参考实现。
- **MMAction2**：两流/SlowFast/时序定位工业库；Kinetics-700 checkpoint 即开即用。
- **SAM2**：视频分割+对象跟踪统一范式（L09 跳连记忆化 = 其 memory attention）。
- **X-CLIP / VideoMAE**：CLIP 的视频化与自监督预训练；llama.cpp/whisper 的音视频对齐管线同属此生态。
