# L04 神经网络与反向传播（Neural Networks and Backpropagation）

> Spring 2025 · Lecture 4 · A1 核心：两层 MLP + 手写反向传播。
> 参考阅读：课程 Notes "Backpropagation"、"Backprop Case Study"。

## 1. 核心概念

### 1.1 为什么要多层：组合与分段线性
单层线性分类器只能画一条超平面。复合多层"线性+非线性"：
```
h = σ(xW₁ + b₁) ∈ R^H        （隐层，σ 逐元素）
s = hW₂ + b₂ ∈ R^K           （打分层，接 L02 的 softmax 损失）
```
ReLU `σ(z)=max(0,z)` 使网络成为**分段线性函数**：每层把空间折叠一次，深层可表达
指数多个线性区域（Montúfar 组合论证的直觉版）。标量/向量/矩阵/张量统一为张量。

### 1.2 计算图与链式法则
把网络拆成**门（gate）**的有向无环图：`add / mul / max / sigmoid / exp …`。
每个门只需两件事：前向公式 + **局部梯度**。反向传播 = 从损失出发，按拓扑逆序把
"上游梯度（grad）"乘上局部雅可比分发回每个参数：
```
∂L/∂x = Σ_下游出口 (∂L/∂z) · (∂z/∂x)        （多元：对每条路径求和）
```

### 1.3 三个必会门的梯度（A1 推导骨架）
- add 门：梯度**原样分发**（gradient distributor）。
- mul 门：梯度**交换乘数**（`dx = gz·y, dy = gz·x`）。
- max 门：梯度只给**胜者**（与 L05 max-pooling 同构）。
- sigmoid：`g' = σ(1-σ)`——导数用**输出**表达；饱和导致梯度≤1/4，深层堆 sigmoid 会梯度消失。
- 矩阵乘 `Z=XW`：`dX = dZ·Wᵀ, dW = Xᵀ·dZ`。**形状对偶律**：dX 与 X 同形、dW 与 W 同形，
  用形状即可"看图写梯度"，不必逐元素展开——本讲最重要的元技能。

### 1.4 全连接层的组合式反传
对 batch 维求和，逐层回传（层数记 ℓ = 2..L）：
```
δ^{(ℓ)} = ((W^{(ℓ+1)})ᵀ δ^{(ℓ+1)}) ⊙ σ'(z^{(ℓ)})
∂L/∂W^{(ℓ)} = (a^{(ℓ-1)})ᵀ δ^{(ℓ)}
```
这就是 L05 卷积、L07 RNN、L08 Transformer 内部一切自动微分的原型：
**框架（PyTorch autograd）= 自动登记计算图 + 自动执行本讲手工做的事**。

### 1.5 数值与工程细节
- 损失对 batch 取平均时，梯度要除以 N（A1 常见 off-by-N）。
- 用 L03 的中心差商逐层检查；深层网络允许 1e-6 量级相对误差。
- 非线性激活全家福：ReLU（默认）、Leaky ReLU、GELU（L08 Transformer 用）、tanh（L07 RNN 用）。
