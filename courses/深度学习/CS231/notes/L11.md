# L11 大规模分布式训练（Large Scale Distributed Training）

> Spring 2025 · Lecture 11 · 把 L01-L08 的"单卡数学"升级为"集群工程"。
> 参考阅读：DeepSpeed ZeRO 论文、Megatron-LM 论文节选；课程 supplementary。

## 1. 核心概念

### 1.1 为什么要分布式：三重墙
模型参数（7B fp16 ≈ 14GB 仅权重，Adam 再 ×12）、梯度、激活值；
单卡显存、单卡算力、数据吞吐三面墙同时立起。经验数字（必背）：
```
显存 ≈ 参数·p + 优化器状态 + 激活(与 batch、层数、分辨率相关)
训练 FLOPs ≈ 6·N·D   （N=参数量, D=token/像素样本数；前向2+反向4）
```

### 1.2 数据并行与 AllReduce
每卡复制模型、切分 batch，各自反向后**梯度求平均**——等价于大 batch SGD（L03）：
```
g = (1/W) Σ_w g_w     通过 Ring-AllReduce 完成：scatter-reduce + all-gather，
                      每卡通信量 ≈ 2·(W-1)/W·|g|，与卡数几乎无关（带宽墙）
```
DDP 的桶化（bucketing）与计算-通信重叠是工程细节核心。

### 1.3 模型并行家族
- **流水线并行**（Megatron GPipe 式）：按层切卡，micro-batch 填充"气泡"；
  1F1B 调度降低激活显存。
- **张量并行**：单层内矩阵乘按列/行切（`Y=X·A·B` 拆两卡各持一半），需卡间低延迟（NVLink 域内）。
- **专家并行 MoE**、**序列并行**（激活切分）、**上下文并行**（长视频/高分辨率注意力的 T 维切分——
  L10 的时序 token 爆炸在此求解）。

### 1.4 显存技术
- **ZeRO 1/2/3**：把优化器状态/梯度/参数分片到各卡，配合 all-gather 恢复计算所需；
- **激活重计算**（checkpointing）：以算换存（反向时重算前向激活，+30% 换 -50% 显存）；
- **混合精度**（fp16/bf16 + fp32 主权重 + loss scaling）：bf16 治梯度下溢；
- **offloading**（NVMe）与 **FlashAttention**（IO 感知注意力，不存 T² 中间矩阵，属于"算子级"分布式思维）。

### 1.5 大学习率与扩有效 batch
LARS/LAMB 层自适应学习率支撑 32k batch（GPT/BERT 式 warmup，呼应 L03）；
训练稳定性问题（loss spike）与检查点/容错（弹性训练）是长作业的运维主题。

## 4. 知识点在开源项目中的应用
- **PyTorch DDP / FSDP**：1.2 与 ZeRO-3 的官方实现（`fully_shard` API）。
- **DeepSpeed**：ZeRO 全家桶 + offload + 混合精度开关；**Megatron-LM**：TP/PP 参考实现。
- **HF accelerate**：一套配置启动上述后端的"统一遥控器"；**flash-attention**（Dao-AILab）：1.4 的明星算子。
- **vLLM**：推理侧的 PagedAttention/连续批处理——训练-推理同一套系统思维。
