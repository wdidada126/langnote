# L09 目标检测、图像分割与可视化理解（Detection, Segmentation, Visualizing & Understanding）

> Spring 2025 · Lecture 9 · 作业 A2 主线（检测）；本讲合并了旧版分开的三讲。
> 参考阅读：Zou et al. "Object Detection in 20 Years" 综述节选。

## 1. 核心概念

### 1.1 检测：分类 + 定位
输出从"一个标签"变为"K 个 (类别, 框)"。度量：**IoU**（交并比）与 **mAP**（P-R 曲线下面积，
COCO 取 IoU 0.5:0.95 均值）。回归目标参数化（Faster R-CNN 式，对尺度不变且可逆）：
```
t_x = (x - x_a)/w_a ,  t_y = (y - y_a)/h_a ,  t_w = log(w/w_a) ,  t_h = log(h/h_a)
loss = cls_loss + λ · smooth_l1(t, t̂)
smooth_l1(x) = 0.5x²/β (|x|<β) else |x|-0.5β      （鲁棒、梯度有界）
```

### 1.2 两阶段 vs 单阶段
- **R-CNN 系**：候选区域（Selective Search → **RPN**：anchor + objectness）→ ROI Align → 双头。
  Faster R-CNN 把"提候选"本身学成网络，端到端。
- **单阶段**（SSD/YOLO）：多尺度特征图网格上直接预测 anchor，快；正负样本平衡（1:3）与
  多尺度 anchor 匹配是训练成败关键；focal loss 治类别不平衡。
- **免 anchor**（FCOS）与 **DETR**（L08 目标查询 + 匈牙利匹配，去掉 NMS）。
- **NMS**：按分数排序、贪心剔除 IoU>0.5 的重复框。
共同骨架 = L05/L06 的 backbone + 新头部——骨干复用是课程主线。

### 1.3 分割：逐像素分类
- 语义分割：**FCN**（全卷积+转置卷积上采样，L05 尺寸公式反着用）；
  **U-Net**：编码器-解码器 + **同尺度跳连**（小数据/医学影像标配）。
- 实例分割：**Mask R-CNN** = Faster R-CNN + 每 ROI 一个小 FCN 掩码头（多标签二值 softmax）。
- 可提示分割：**SAM/SAM2**（ViT 图像编码器 + 点/框 prompt + 掩码解码）——基础模型取代了 1.2 的整套 anchor 工程。

### 1.4 可视化与理解网络
- 特征倒置 / **DeepDream**：对激活做梯度上升 `x ← x + η·∂a/∂x`——反向传播反着用；
- **Grad-CAM**：最后一层特征图按"该类打分对特征的梯度"加权 → 定位热图；
- 线性探针（linear probe）：冻结 backbone 只训头部测"某层存了什么信息"——L12 自监督评估的标配。
结论直觉：浅层=边缘纹理、深层=对象部件语义（L06 层级假设的实证来源）。
