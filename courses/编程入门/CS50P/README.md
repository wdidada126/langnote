## 二、为什么学

- CS50 番外篇，Malan 主讲，质量与体验延续 CS50 招牌水准，但**专注 Python 单语言**，比 CS50x 更省时聚焦。
- 不只讲语法：深入 Python 特色的"Pythonic"写法——代码库使用、单元测试（pytest）、异常处理、类型注解、正则与 f-string 技巧。
- 零基础友好、作业自动评测反馈完善，是进入 CS61A / MIT 6.100L 之前最平滑的第一门编程课。

## 三、先修与知识联系

- 先修：无。可作为 CS61A 的先修替代（比 CS50x 更轻）。
- 知识联系：
  - → CS61A：本课打好 Python 语法与测试习惯，CS61A 专注抽象与解释器；
  - → MIT 6.100L：同级平行课，6.100L 深度更大（复杂度、算法）；
  - → CS50AI（Python 做 AI）：本课外番的延续课程；
  - pytest/正则/OOP 直接服务后续所有 Python 项目。
