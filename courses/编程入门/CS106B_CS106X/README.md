## 为什么学

- Stanford 的"进阶编程"课：通过 C++ 在实际作业中培养编程抽象能力，是 CS106A 与后续系统课之间的桥梁。
- 系统覆盖基础但高频的数据结构与概念：ADT、递归、回溯、排序、指针、链表、BST、哈希、OOP、栈/堆内存管理。
- 9 个 assignment 全部有详细文档与 GUI 可视化反馈，milestone 式推进成就感强；assignment8 还要靠 debugger 逃出迷宫，assignment9 用 Huffman 编码压缩真实文件。
- CS106X 比 CS106B 深一度，但主体内容一致，可按需选择。

## 先修与知识联系

- 先修：CS50/CS106A/CS61A 或同等计算机基础。
- 联系：与 CS106L 互补（B/X 讲抽象与结构，L 讲语言特性）；数据结构部分与 CS61B 重叠但更偏应用；内存管理章节是 CSAPP/CS110 的前置；AUT1400 作业可作进阶练习。
