# CS3110 讲义要点（骨架，按教材六部分）

## L1 导论与基础类型
- 为什么是函数式：不可变、无副作用、等式推理。
- utop/toplevel 工作流与 .ml 文件编译 (dune)。

## L2 列表与函数式数据处理
- 递归处理列表：map/filter/fold 三件套。
- 拒绝 for 循环：用不可变聚合表达同一算法。

## L3 高阶函数与柯里化
- 函数作一等公民；部分应用与柯里化。
- 抽象出共同模式 = 泛型行为的复用。

## L4 ADT 与模式匹配
- variant/record 构造代数数据类型；穷尽匹配。
- 与 Rust enum 的概念一一对应（预留对照笔记）。

## L5 Option/Result
- 用类型编码"可能没有/可能失败"，消灭 null 与异常滥用。

## L6 测试与调试
- 随机测试与性质测试 (QuickCheck 风格) 在 OCaml 中的实践。
- 文档、注释与整洁代码标准。

## L7 抽象数据类型
- Set/Map 接口：表示无关 (representation independence) 与表示不变量。
- 函数规格：precondition/postcondition。

## L8 效率与渐近分析
- Big-O/Ω/Θ 与"下界证明"的思维：证明没有更快算法。
- 摊还分析：queue/栈/备忘录的成本均摊。

## L9 可变状态与效果
- ref、赋值何时值得（性能/缓存）；纯函数边界。
- GC 概念初步（OCaml 的 Mark-And-Sweep）。

## L10 模块与函子
- 签名 = 类型；模块 = 值； functor = 函数 on modules。
- 用模块系统实现参数化数据结构（如 Set 复用）。

## L11 类型检查
- 类型推理 (Hindley-Milner 风格) 与健全性 (soundness) 证明直觉。

## L12 环境模型与解释器
- 从零实现微语言解释器：env、闭包、递归。

## L13 语言特性实现
- 静态检查、可变性、惰性求值、对象、并发各自的实现代价。

## L14 证明附录
- 归纳法与等式推理；为正确性论证补数学肌肉。
