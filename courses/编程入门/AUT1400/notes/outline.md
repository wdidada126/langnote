# AP1400-2 讲义要点（骨架）

## L1 Matrix 类实现
- 类的设计：成员布局、const 正确性、深拷贝语义。
- 运算符重载：`+`、`*`、`==`、`<<`、下标访问。
- 输入输出流与异常边界检查（越界、维度不匹配）。
- 配套单元测试驱动开发：先读 test 再实现。

## L2 加密货币客户端/服务端模拟
- 用类建模交易、区块、账户状态。
- 字符串解析与格式化输出。
- 模拟消息往返：客户端/服务端各自的状态机。
- 练习 vector/map 组织批量数据。

## L3 二叉搜索树 (BST)
- 递归插入/查找/删除，节点所有权与手动内存管理。
- 中序遍历与迭代器风格接口。
- 树形不变量维护与测试用例设计。

## L4 智能指针 SharedPtr / UniquePtr
- RAII：用栈对象生命周期管理堆资源。
- 引用计数线程不安全边界、控制块设计。
- UniquePtr 的 move-only 语义与删除拷贝。
- 与 std::make_shared 行为对齐，删除器扩展。

## L5 继承与多态
- 基类接口设计、虚析构函数的必要性。
- 运行时多态：vtable 机制与开销。
- 用多态替换 switch-on-type 写法。

## L6 STL 解题
- sort/find/count/copy 等算法组合使用。
- 谓词、仿函数与 lambda。
- 容器选型：vector/set/map/unordered_map。

## L7 Python 项目（选做）
- 用 Python 重写已有 C++ 逻辑，体会语言取舍。
- 动态类型与丰富标准库带来的开发速度差异。
