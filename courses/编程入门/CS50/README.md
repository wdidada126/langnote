## 二、为什么学

- 连续多年哈佛最受欢迎公选课，全球最著名的计算机入门课：一学期内从 Scratch 块编程走到 C 内存、算法、Python、SQL、Web 全栈，建立"计算机科学全景图"。
- Malan 的授课表演级（撕黄页讲二分），配套 Shorts 短视频 + 高质量 Labs/PS，作业评测反馈一流。
- 用 C 打头阵：亲手管理内存（malloc/指针），后续学任何语言都是降维。
- 完全零基础友好，也适合有经验的开发者"休闲速通"补齐体系认知。

## 三、先修与知识联系

- 先修：无。
- 知识联系：
  - → CS50P（Python 深入）、CS50AI（AI）、CS50W（Web）：官方番外系列，2025 版本课 Web/SQL 部分的纵向延伸；
  - → CS61A：本课 Python 周之后的自然进阶（抽象与解释器）；
  - → 15-213/CSAPP、CS61C：C + 内存 + 数据结构的周次是体系结构/系统课的最轻前置；
  - ← Missing Semester：建议早于或同步学习（课程 VS Code 云端环境已内置大部分工具）。
