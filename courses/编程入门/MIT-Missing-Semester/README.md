## 二、为什么学

- 补上大学课程不教、但每个 CSer 每天都在用的工具：Shell、命令行环境、Git/Vim/tmux/ssh、调试与性能分析、代码打包发布。
- 内容几乎覆盖 csdiy「必学工具」板块的绝大部分，是后续所有系统类课程（CS61B/CS162/CS149 等）的工程地基。
- IAP 2026 版新增了 Agentic Coding（AI 代理式编程）、代码质量等时代主题，比 2020 版更贴合当下工作流。
- 总学时仅约 10 小时，投入产出比极高。

## 三、先修与知识联系

- 先修：无，任意阶段均可学习；越早学收益越大。
- 后续联系：
  - 为本仓库 `必学工具`（Git、Vim、tmux/ssh、LaTeX）提供统一入口；
  - 与 `UCB DeCal`（Sysadmin）互补：Missing Semester 偏查缺补漏，DeCal 偏零基础系统讲解；
  - 为 CS61B/CS162/CS149/15-213 等课的实验环境（Linux + shell + git）扫清障碍。
