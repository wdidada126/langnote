## 二、为什么学

- MIT 2022 课程改革后 EECS、AI 与决策、EEC 三个方向的**入门必修编程课**，含金量即"MIT 第一课"。
- 覆盖 6.100A 全部内容：计算基本概念、Python 语言、简单算法与数据结构、测试与调试、算法复杂度——比一般"Python 速成"多出严谨的 CS 方法论。
- Ana Bell 讲解深入浅出、难度曲线平滑，材料免费开源、练习答案齐全，最适合计算机小白循序渐进。
- 26 讲 + 4 次 Lab 的高密度实操，学完即具备直接进入 6.100A 后续课（6.1010/6.1020）或 CS61A 的能力。

## 三、先修与知识联系

- 先修：无。
- 知识联系：
  - 与 CS50P 同级平行：6.100L 更学术、含复杂度与算法分析，二者任选其一即可；
  - → CS61A：本课的抽象/测试/复杂度为其直接先修体验；
  - → MIT 6.100A/6.1010/6.1020 及 6.0001 血统课程无缝衔接；
  - ← Missing Semester：建议同步掌握 shell/git 以管理课件与作业代码。
