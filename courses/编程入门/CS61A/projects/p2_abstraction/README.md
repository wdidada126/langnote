# P2 组合与抽象：函数式 2048 逻辑层

> 对应讲次：L03（函数抽象）、L04（合约/纯函数）、L05-L06（高阶函数）、
> L07-L08（递归与增长）。官方 Project 2 是 Penguins（数据抽象+地图绘制），
> 本迷你版以 2048 **纯逻辑层**覆盖同一批知识点：不可变表示、表示变换归约、
> 高阶选择、可复现随机。

## 内容

| 文件 | 说明 |
| --- | --- |
| `game2048.py` | 全部游戏逻辑：`merge_line`（一维规则）、`transpose/reverse` 把 4 个方向归约为 1 个（数据抽象核心手法，L10 预告）、`play` 贪心无头自对局（`max(..., key=)` 高阶，L05）。 |
| `main.py` | 演示：一维规则表、四方向棋盘、3 局可复现自对局。 |

## 运行

```bash
python main.py
python game2048.py     # 只跑自检断言
```

Windows 用 `run.bat`；语法自检：`python -m py_compile game2048.py main.py`

## 知识点对照

- **不可变棋盘**：`set_cell` 返回新元组——与 L13 可变对象的"身份/别名"问题对照；
- **方向归约**：4 个方向 = `transpose`/`reverse` 共轭出 `move_left`——函数组合与幂等性（做两遍回到原棋盘）；
- **注入随机**：`rng` 参数化使逻辑层完全可测试（域假设 L04）；
- **贪心一步**：`max(moves, key=gain)` 即 L05 的 `summation/term` 思想；
- **复杂度**：一次 move 为 Θ(16)（常数盘面），增长阶视角下"合法方向枚举"是常数级。
