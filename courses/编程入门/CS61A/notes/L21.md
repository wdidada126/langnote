## 1. 核心概念

### 1.1 Frame：L02 环境图的代码化
```python
class Frame:
    def __init__(self, parent):
        self.parent, self.mapping = parent, {}
    def lookup(self, name):
        if name in self.mapping: return self.mapping[name]
        if self.parent: return self.parent.lookup(name)
        raise SchemeError(f'{name} is not bound')
    def define(self, name, val): self.mapping[name] = val
```
全局 frame 装内建过程；每次过程调用 new Frame(闭合环境)——**parent 指向定义处**，
词法作用域由此保证（L06 闭包规则的第二次兑现）。

### 1.2 eval 的分支结构
```python
def scheme_eval(expr, env):
    if isinstance(expr, (int, float, str)): return expr      # 自求值
    if isinstance(expr, Symbol): return env.lookup(expr)      # 查名字
    head, rest = expr.first, expr.rest                        # 组合式
    if head in ('define','lambda','if','cond','let','begin','quote'):
        return eval_special_form(head, rest, env)
    proc = scheme_apply_head(head, env)
    args = eval_all(rest, env)                                # 应用序：先全部求值
    return apply(proc, args)
```
特殊形式的判定放在**求值子式之前**——顺序即语义（L19 §1.3）。

### 1.3 lambda 与过程对象
```python
class Procedure:              # 复合过程
    def __init__(self, params, body, env): ...
    def __call__(self, args):        # args 已在调用方 env 中求值（应用序）
        frame = Frame(self.env)            # 注意：self.env 是闭合环境
        for p, a in zip(self.params, args):
            frame.define(p, a)             # 只绑定值，不再求值
        return scheme_eval(self.body, frame)
```
`(lambda (x) (+ x 1))` 求值的结果就是一个带着当前 env 的 `Procedure` 对象——
Scheme 函数与 Python 函数一样是闭包（同一性：L06）。

### 1.4 递归的解法：define 先绑壳再填体
`(define (fact n) (if (= n 0) 1 (* n (fact (- n 1)))))` 求值时 `fact` 还不存在，
`lambda` 的闭合 env 却必须包含它。做法：**分两步**——先 `define fact =
Procedure(params, body, env)`，body 的求值发生在 env 已含 fact 之后。环境共享+延迟
求值天然解决（对比 Python 函数体也是调用时才查名字）。

### 1.5 让解释器说 Scheme：TailCall 信号（P4 核心）
Python 无尾调用优化，`eval → apply → eval` 相互递归在深尾递归时爆 Python 栈。
P4 的解法：`scheme_eval` 遇到尾位置调用时返回 `TailCall(proc, args)` **数据**而非
真正调用，最外层 `run_scheme` 循环蹦床（trampoline）反复续跑——尾调用变成 while
循环里的状态转移（L08 迭代过程的机器级兑现，详见 L22 与本仓库 p4 的 `eval` 主环）。
