## 1. 核心概念

### 1.1 序列三件套
| 类型 | 可变? | 同质? | 典型用途 |
| --- | --- | --- | --- |
| `list` | 是 | 任意混合 | 通用容器 |
| `tuple` | 否 | 常作结构（record） | 轻量不可变记录 |
| `range` | 否（惰性） | 整数 | 循环驱动、索引 |

```python
t = (1, 'two', [3.0])        # tuple 可含可变元素（浅不可变）
r = range(2, 20, 3)          # 不展开存内存，O(1) 空间
list(r)                       # [2, 5, 8, 11, 14, 17]
```

### 1.2 序列上的通用高阶函数
CP §2.2 的骨架是四个函数：`map / filter / accumulate(reduce) / 推导式`。

```python
from functools import reduce
xs = list(range(1, 6))
list(map(square, xs))                 # [1,4,9,16,25]
list(filter(lambda x: x % 2, xs))     # [1,3,5]
reduce(add, xs, 0)                    # 15
[x*x for x in xs if x % 2 == 0]      # 推导式= map+filter 二合一
```

思维模式：**序列变换流水线**（source → filter → map → accumulate），
即 Unix 管道 `grep | awk | sort` 的语言内形态（Missing Semester 的工具链与此同构）。

### 1.3 嵌套与打平
```python
grid = [[1,2],[3,4]]
flat = [x for row in grid for x in row]     # [1,2,3,4] 外层先写
zip(xs, ys)                                  # 并行遍历
enumerate(xs, start=1)                        # 带索引遍历
```
推导式两层 for 的阅读顺序是考试常客：从左到右对应从外到内。

### 1.4 浅拷贝 vs 深拷贝
```python
a = [[1], 2]
b = a[:]            # 切片：浅拷贝，b[0] is a[0] → True
import copy
c = copy.deepcopy(a) # c[0] is a[0] → False
```
不可变 tuple + 可变 list 的混合最容易在 Lab 里翻车（改内层元素会"隔空传染"）。
