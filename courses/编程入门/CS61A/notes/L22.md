## 1. 核心概念

### 1.1 元循环求值（metacircular evaluation）
"用 Scheme 写 Scheme 的解释器"——eval/apply 互为递归、以语言自身的数据结构
（pair/symbol）表示程序。SICP 称其为"程序设计的顶峰之一"：解释器不过是一个
**通用过程**。CP 用 Python 写 Scheme（宿主≠对象语言）教学上更稳，但"元"的味道一致：
一旦你能写 `eval`，语言就从"魔法"降格为"库"。

推论：**语言的表达力 = eval 能处理什么**。加一个特殊形式/内建/宏，就造了一门新语言。

### 1.2 尾位置与尾递归
组合式的调用表达式若处于"直接返回"位置（函数体末、`if` 分支、`begin` 末项、
`or/and` 末项）即**尾调用**。 Scheme 报告（R5RS/R6RS）规定：**尾调用必须以常数
空间执行**——即尾递归优化（TCO）：

```scheme
(define (iter n acc)
  (if (= n 0) acc
      (iter (- n 1) (* n acc))))    ; 尾调用：Scheme 中真 O(1) 空间
```

Python 没有 TCO（Guido：可读性/traceback 成本）。P4 的对策：`scheme_eval` 在尾位置
返回 `TailCall(proc, args)` 数据对象，顶层蹦床循环消化：

```python
def run_scheme(expr, env):          # trampoline
    result = scheme_eval(expr, env)
    while isinstance(result, TailCall):
        result = result.continue_eval()
    return result
```
这样 Scheme 程序的迭代过程不再消耗 Python 栈——L08"SICP 的迭代=Scheme 的
tail recursion"这一句的机器级证明。

### 1.3 宏（Macros）：用户自定义语法
`cond` 之外加 `when`？不必动 eval，写个宏（P4 语法）：

```scheme
(define-macro when (predicate body)
  (list 'if predicate (cons 'begin body)))
(when (> x 0) (display 'pos) (newline))
; 宏过程求值时收到 unevaluated 参数 → 返回新表达式 → 替换后重新 eval（macroexpand）
```
- 宏在**语法分析后、求值前**做"代码→代码"变换（hygiene/捕获问题 P4 简化处理，真实 Scheme 有 syntax-case）。
- `let` 脱糖、`loop` 构造、Rust 的 `println!`、Lisp 全家（Clojure）DSL 能力全部同源。

### 1.4 三条扩展路线总结
内建过程（apply 层）⊂ 特殊形式（eval 层，控制求值）⊂ 宏（expand 层，控制语法）。
P4 的 Part4/5 各练一条。
