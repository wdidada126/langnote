# L26 期末复习与总结：抽象的三个高度

> Week13-L2 · 范围：全学年（CP 全四部分 / SICP 精神全程）
> 历年题型：Scheme 输出预测、eval/apply 环境图、流/惰性分析、综合实现题（P4 风格）

## 1. 核心概念（知识地图）

### 1.1 一门课 = 三级抽象阶梯
```
第一级 过程抽象（L01-L09）：函数作值、递归作结构、增长阶标价
第二级 数据抽象（L10-L18）：屏障两侧各选最优表示；序列/树/字典；类与继承
第三级 语言抽象（L19-L25）：eval/apply 互递归造解释器；特殊形式/宏/流改语法；
        SQL/并发作为"另一种组合方式"
```
贯穿全部的一根线：**名字→环境的绑定规则**（L02 定义、L06 闭包、L21 Frame、
L22 宏卫生、L25 共享内存的可见性都是它的变体）。

### 1.2 期末高频自查（按新→旧）
1. **Scheme 求值**：给 P4 支持面内的程序写输出——含 `define-macro`（先 expand 再
   eval）、`cons-stream`（第二参不 eval）、尾递归蹦床步数。
2. **环境图**：`let` 脱糖为 lambda 应用；递归 define 的"先绑壳后填体"（L21 §1.4）。
3. **流三问**：严格/惰性/memo 的时空账（L23 §1.4）；`stream-ref` 第 k 项要 force 几个 thunk。
4. **SQL**：三表 join + GROUP BY/HAVING（L24）；参数化查询理由。
5. **并发**：识别 race、加锁修复、GIL 下线程池 vs 进程池选型（L25）。
6. 期中两半程的所有经典题型（L09/L17 清单）仍占期末 40% 以上。

### 1.3 三个"啊哈"时刻（写复习笔记的锚点）
- **代码即数据**（L19 同像性 → L22 宏）：解析器读什么不能改变什么；
- **迭代 = 尾递归**（L08 → L22 蹦床）：循环只是被语法糖化的 gotos，而 gotos 可以是
  常数空间的函数调用链；
- **解释器即库**（L20-L22）：`eval` 写出来那天，"语言"从神坛降到工具箱——
  这是本课与 SICP 存在的理由。

## 4. 知识点在开源项目中的应用
- **把 P4 写进简历的正确方式**：补测试、写 README、对比 Racket/Guile 的差异、加
  call/cc 或对象系统扩展（SICP 练习 4.x 级别）——"能改"比"能跑"值钱。
- **PyPy/CPython/Ruby(MRI)/Lua**：所有主流语言源码都从本讲级别的 eval 起步长成；读 `ceval.c` 时你会认出 L21 的每个分支。
- **Jupyter/REPL 工具链**：`code.interact`、IPython 的 async 化——宿主语言嵌 DSL 的日常形态（P4 的 REPL 就是玩具版 Jupyter kernel）。
- **DSL 生态**：SQLAlchemy（AST→SQL）、Hypothesis（策略组合）、Click（装饰器注册）：三级抽象阶梯在工业代码里的投影。
