## 1. 核心概念

### 1.1 迭代协议：两个方法
- 可迭代对象 iterable：实现 `__iter__()` → 返回迭代器；
- 迭代器 iterator：实现 `__next__()` → 逐个吐值，耗尽抛 `StopIteration`。

```python
class CountUp:
    def __init__(self, n): self.i = 0; self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.i >= self.n: raise StopIteration
        self.i += 1
        return self.i * self.i
list(CountUp(4))     # [1, 4, 9, 16]
```

`for x in ys` 展开即：`it = iter(ys); while True: try: x = next(it) except StopIteration: break`。

### 1.2 迭代器是一次性的
迭代器携带游标状态，耗尽即废；list 可反复 `iter()`，生成器不行。
`zip(g1, g2)` 混用"迭代器"与"序列"时注意：前者只能消费一次。

### 1.3 生成器函数：自动迭代器
`yield` 把函数变成"可暂停可恢复"的过程：每次 `next` 执行到下一个 `yield` 并冻结现场。

```python
def primes():
    n = 2
    while True:                    # 无限生成器！
        if all(n % p for p in takewhile(lambda p: p*p <= n, primes_upto(n))):
            yield n
        n += 1
# 实际工程用埃氏筛（见 p5_streams/sieve.py）
```

- 调用 `primes()` **不执行任何函数体**，只创建 generator 对象；
- `yield from sub` 委托子生成器（`chain` 的手写版）；`send/throw` 是协程雏形。

### 1.4 惰性 = 拉取模型
生成器不预计算；消费多少算多少（demand-driven）。
好处：O(1) 空间处理无限/超大数据源（日志行、传感器流）；配合 `itertools.islice`
可"取前 n 个无穷"。这是 L23 流与 SICP 3.5 章的全部机制。

```python
import itertools
first10_odd_squares = list(itertools.islice((x*x for x in itertools.count(1,2)), 10))
```
