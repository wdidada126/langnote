## 1. 核心概念

### 1.1 类 = 行为模板，实例 = 状态载体
```python
class Student:
    major = 'EECS'                 # 类属性：所有实例共享
    def __init__(self, name):
        self.name = name           # 实例属性：写进 instance dict
    def introduce(self):
        return f'{self.name}, {self.major}'

s = Student('Ada')                 # __init__ 前其实先"造空壳"再初始化
```
- `__init__` 不是"构造函数"而是**填充器**；`__new__` 才造对象（了解即可）。
- `self` 是普通位置参数，`s.introduce()` 脱糖为 `Student.introduce(s)`（绑定方法打印可见 `<bound method ...>`）。

### 1.2 属性查找：实例 dict → 类 MRO
`s.x` 的解析顺序：`s.__dict__` → `type(s).__mro__` 逐类 → `__getattr__` 兜底。
**读走链，写只写实例**——所以"写类属性"和"写实例同名属性"结果不同：

```python
s.major = 'CS'          # 在实例里新建，遮蔽类属性
Student.major           # 仍是 'EECS'
s2 = Student('Bob'); s2.major   # 'EECS'
```

### 1.3 特殊方法（dunder）= 协议的挂载点
`__init__ / __repr__ / __str__ / __eq__ / __len__ / __getitem__ / __iter__ / __add__`。
`repr` 给开发者（含类名、可调试），`str` 给用户；`__eq__` 不定义则退化为 `is`。
P3 的 Tree/Link 将实现 `__repr__` 与 `__eq__` 以通过 okpy 输出比对——CS61A 的评分器
大量依赖 repr 的"无歧义表示"（`Link(1, Link(2))` 与 `Tree(1, Link(2))` repr 不同）。

### 1.4 类也是对象
类可以当参数传（工厂函数返回类）、当属性存、动态 `type('X', (), {})` 造类。
"一切皆对象"在 Python 里字面成立：`int.__mro__` 可打印。

## 4. 知识点在开源项目中的应用
- **CPython**：`type->tp_dict`、`instance.__dict__`、描述符协议（`__get__`，property/classmethod 的底层）全部在本讲概念层之上；`dataclasses` 模块本身就是"生成 __init__/__repr__ 的元编程类工厂"。
- **attrs / pydantic**：工业级类模板——自动校验（把 L04 域假设搬进类型定义）、自动 repr/eq。
- **Django ORM**：`Model.objects.filter()` 的 Manager 描述符机制即 `__get__` 协议应用。
- **pytest**：测试类无需继承，靠命名协议发现——Python "协议优于继承"的生态风格。
