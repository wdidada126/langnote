## 1. 核心概念

### 1.1 过程 vs 函数：SICP 的关键区分
"函数"是抽象的映射（数学对象），"过程"是执行它的机器动作。同一个 `factorial`
函数可以有两种过程：

```python
# 线性递归过程：展开 5 层，收缩 5 步，空间 Θ(n)（有 n 个乘法挂起）
def fact_rec(n):
    if n == 1: return 1
    return n * fact_rec(n - 1)

# 迭代过程：状态 (counter, result) 逐步转移，无挂起运算，空间 Θ(1)
def fact_iter(n, acc=1):
    if n == 1: return acc
    return fact_iter(n - 1, n * acc)   # 尾调用
```

在 Scheme 里 `fact_iter` **真的是** O(1) 空间（尾递归优化，L22）；在 Python 里
两者都占 Θ(n) 栈——语言决定"写法"能否兑现为"运行形态"。这是全课程最精妙的一页。

### 1.2 增长阶
只看最高阶项、忽略常数：`Θ(n²)` 表示"每一步都成比例于 n²"。常用排序：

```
Θ(1) 哈希查找均摊 | Θ(log n) 二分 | Θ(n) 线性扫 | Θ(n log n) 优排序
Θ(n²) 朴素两重循环 | Θ(2ⁿ) 朴素子集枚举 | Θ(n!) 全排列
```

经验法则：**n=10⁵ 时 O(n²) 必死，O(n log n) 刚好**；n=20 时 2ⁿ 可接受。
比较操作计数法（CP 的 ` count_factors` 例）：从内层往外数乘法次数。

### 1.3 空间也是过程属性
树递归 fib：时间 Θ(φⁿ)、空间 Θ(n)（最深路径）。memoize 后：时间 Θ(n)、空间 Θ(n)。
**时间与空间可以互相购买**——动态规划（自顶向下 memo / 自底向上填表）的本质。

### 1.4 Python 的现实修正
- 大整数乘法不是 O(1)：两个 n 位数相乘朴素 O(n²)（CPython 用 Karatsuba 混合）。
- `len(s)` O(1) 但 `for c in s` 整体仍 Θ(n)；切片 `s[:]` Θ(n)——"一行代码"≠"一步"。
- 列表 `append` 均摊 O(1)（倍增扩容），`insert(0, x)` Θ(n)——预告 L13 链表动机。

## 4. 知识点在开源项目中的应用
- **CPython**：list 的 `list_resize` 用 over-allocation（`newsize += newsize>>4 + 6~8`）换来 append 均摊 O(1)；dict 同理（L16）。
- **sortedcontainers**：SortedList 用"分块 + 块内 bisect"把插入从 Θ(n) 降到 O(√n)——教科书复杂度在库设计中的再生。
- **numpy**：向量化把常数因子从"解释器字节码循环"降到 SIMD 循环，复杂度不变但实测差百倍——增长阶与运行时的关系案例。
- **Big-O  cheatsheet 生态**：bottleneck 分析工具 `scalene`（内存+CPU 采样）在真实项目里定位二次行为。
