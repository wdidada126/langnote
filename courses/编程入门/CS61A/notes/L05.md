## 1. 核心概念

### 1.1 函数是第一类对象
Python 里函数可以：赋值给名字、作参数传递、作返回值、放进容器。`def f` 与 `f = lambda`
完全等价（AST 文档字符串除外）。

```python
>>> def square(x): return x * x
>>> f = square          # 名字只是标签，f 与 square 指向同一函数对象
>>> f(3), square(3)
(9, 9)
>>> [square, abs][-1](-4)   # 放进列表再取出调用
4
```

### 1.2 通用求和：一次关键的抽象跳跃
对比两个几乎重复的函数后，把"变化部分"抽成参数：

```python
def sum_squares(n):
    return sum_term(square, 1, n)

def sum_cubes(n):
    return sum_term(cube, 1, n)

def sum_term(term, a, b):        # term 是"概念"，不只是"值"
    total, k = 0, a
    while k <= b:
        total, k = total + term(k), k + 1
    return total
```

`sum_term(term_fn, a, b)` 就是离散积分；`term` 可以任意换——
CP §1.6 由此一路导出**辛普森法则**与迭代改进（improve until converged）。

### 1.3 generalization 的代价与收益
- 收益：新需求=新参数值，不改代码（开闭原则的起点）。
- 代价：调用方心智负担↑（要理解"函数接口"）；性能：一次调用变两次。
- 判别标准：抽象是否消除了**真实的重复**（rule of three：第三次重复再抽象）。

### 1.4 lambda
只出现一次的短函数用匿名形式：

```python
summation(1, 5, lambda x: x * (x + 1))
```

`lambda` 体只能是表达式——这也是为什么 CP 强调"表达式产生值"的思维。

## 4. 知识点在开源项目中的应用
- **functools**：`reduce(function, iterable)`、`partial(f, *args)` 全以函数为参数；`cmp_to_key` 把比较函数适配给 `sorted`。
- **statistics / itertools**：`itertools.accumulate(iterable, func=operator.add)` 允许自定义归约。
- **pandas**：`df.groupby(...).agg(['mean','max'])` 以函数字符串/可调用对象作参数；`applymap` 是二维 summation。
- **pytest**：fixture 工厂、`parametrize` 本质都是把测试函数作为数据处理。
