## 1. 核心概念

### 1.1 为什么需要复合数据
程序处理的"对象"越来越复杂：复数、有理数、区间、图。语言只给原子（int/str）。
**数据抽象 = 用构造函数+选择器搭出"虚拟数据类型"，并在抽象屏障两侧隔离关注点。**

```python
# 表示 1：两个数 (real, imag) 直角坐标
def make_complex_re(r, i): return (r, i)
def real_part_re(z): return z[0]
def imag_part_re(z): return z[1]

# 表示 2：(模, 辐角) 极坐标
import math
def make_complex_po(m, a): return (m * math.cos(a), m * math.sin(a))
def real_part_po(z): return z[0]        # 存的时候已经转换
def imag_part_po(z): return z[1]

# 上层完全不知道：
def abs_complex(z):
    return math.sqrt(real_part(z)**2 + imag_part(z)**2)
```

换表示只动"屏障"处的两行绑定（`real_part = real_part_po` …），上层零改动——
这就是**表示独立性**。SICP 名言：程序应假定数据只以"要被使用的方式"被构建。

### 1.2 构造函数与选择器
- 契约：`sel(make(a,b)) == a`（有理数：`numer(make_rat(2,3))==2` 需先 `reduce` 处理 4/6）。
- 屏障两侧：上层用抽象（add_rat），底层管表示（tuple/dict/class 任选）。
- 数据抽象 vs 过程抽象（L03-L06）是同一枚硬币：过程隐藏"怎么做"，数据隐藏"长什么样"。

### 1.3 为什么 CP 在 Python 里先用 tuple 模拟
Python 已有丰富内置类型，但 CS61A 要你**亲手搭**：因为 Scheme（L15 后）与 P3/P4
里你只能靠 pair 造一切；数据抽象的肌肉记忆比语法更重要。

## 4. 知识点在开源项目中的应用
- **CPython**：复数是内置类型 `complex`（C 结构体两个 double）——内置版"屏障"；`numbers.Real/Rational` ABC（`numbers` 模块）定义协议层。
- **标准库 fractions.Fraction**：正是本讲 `make_rat/numer/denom` 的生产版（自动 gcd 约分，见 P1）。
- **attrs / dataclasses**：把"构造函数+选择器"样板一键生成（`@dataclass(frozen=True)` = 不可变值类型）。
- **numpy**：`ndarray` 的 strides/dtype 抽象——同一 buffer 多种"解释视图"，表示独立性的高维版。
