## 1. 核心概念

### 1.1 过程抽象 = 控制复杂性
函数把"怎么做"封装为"做什么"。CP §1.3 的关键例：`square` 可以由 `exp(x,2)` 定义，
而 `exp` 又可复用……层次化语言由此生长。三条设计纪律：
1. **单一职责**：一个函数一个概念；
2. **参数最少化**：能用默认值/闭包捕获的不要塞进参数表；
3. **域假设显式化**（见 L04）。

```python
def area_circle(r):        # 过程抽象
    return 3.14159 * r * r
def sum_of_areas(rs):      # 更高一层的抽象不再关心"圆"
    total = 0
    for r in rs:
        total += area_circle(r)
    return total
```

### 1.2 形参、实参与 return
- 位置参数、关键字参数、默认值、`*args/**kwargs`；默认值在 **def 时求值一次**——
  用可变默认值（`def f(a=[])`）是经典陷阱，L13 讲可变对象时会回收这个伏笔。
- 没有 `return` 语句（或 `return` 裸写）的函数返回 `None`。"打印"与"返回"的区别
  是 HW1 挂掉率最高的点：`return` 交值给调用者，`print` 只是副作用。

```python
def double(x):
    print(x * 2)   # 只有副作用
y = double(3)      # 屏幕出现 6
print(y is None)   # True —— 函数没有把值交回来
```

### 1.3 调试方法论（官网 Debugging Guide 精要）
1. **读报错**：Traceback 最后一行是异常类型，往上是你自己的最底层栈帧；
2. **print 是合法武器**：在循环里打印不变量；
3. **pdb**：`import pdb; pdb.set_trace()` 或 Python 3.7+ 的 `breakpoint()`，
   常用命令 `n/p/`/`w/q`；
4. **橡皮鸭**：向鸭子（或室友）逐行解释你的递归函数——讲不通的那行就是 bug；
5. **缩小复现**：构造最小输入。递归函数先手算 n=1、n=2 的情形。

### 1.4 递归初体验
递归三要素：基准情形（base case）、递推（recursive step）、**保证收敛**。

```python
def factorial(n):
    if n == 0:        # base
        return 1
    return n * factorial(n - 1)   # 收敛：n 严格递减
```

执行时每次调用压一个新框架（L02 环境图），返回时出栈——这是理解 L08
"迭代 vs 递归过程"与 L22"尾递归"的前置。

## 4. 知识点在开源项目中的应用
- **CPython** `frameobject.c`：帧对象布局（f_locals、f_back）就是 `tb_frame` 在 traceback 中暴露的内容——读懂 Traceback 即读懂帧链。
- **ipdb / pdb++ / debugpy**：把 `PyFrameObject` 包装成可视化面板；VS Code 断点求值即在帧的局部表上 `eval`。
- 标准库 `inspect`：`inspect.getouterframes()` 可编程遍历栈帧，pytest 的 fixture 魔法建立在其上。
