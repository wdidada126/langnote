## 1. 核心概念

### 1.1 选择排序：最简 Θ(n²)
```python
def selection_sort(xs):
    out = []
    remaining = xs[:]
    while remaining:
        m = min(remaining)            # Θ(n)
        out.append(m)
        remaining.remove(m)           # Θ(n)
    return out
```
每轮"选最小"，总比较 Θ(n²)。教学价值在于**不变量**：`out` 始终是 `xs` 的最小 k 元
且有序——循环不变量思维（L04 合约）的排序版。

### 1.2 插入排序：近乎有序时的赢家
```python
def insertion_sort(xs):
    xs = xs[:]
    for i in range(1, len(xs)):
        v, j = xs[i], i - 1
        while j >= 0 and xs[j] > v:   # 把 v 向左滑到正确位置
            xs[j + 1] = xs[j]; j -= 1
        xs[j + 1] = v
    return xs
```
- 最坏 Θ(n²)（逆序），**最好 Θ(n)**（已序）：复杂度是"输入的函数"，不只是规模。
- 稳定（相等不互换）；小 n 时常数最小——多数工业库对小区间回退到它（Timsort 的 binary insertion、IntroSort 的 cut-off≈16）。

### 1.3 归并排序：分治 + 增长阶的 Θ(n log n)
```python
def merge(a, b):
    out = []; i = j = 0
    while i < len(a) and j < len(b):
        out.append(a[i] if a[i] <= b[j] else b[j])
        i, j = (i+1, j) if a[i] <= b[j] else (i, j+1)
    return out + a[i:] + b[j:]

def merge_sort(xs):
    if len(xs) <= 1: return xs
    mid = len(xs) // 2
    return merge(merge_sort(xs[:mid]), merge_sort(xs[mid:]))
```
递推式 `T(n)=2T(n/2)+Θ(n)` → Θ(n log n)（递归树每层 Θ(n)，共 log n 层——L07 树递归
+ L08 分析工具的合体）。空间 Θ(n)（归并需要辅助）。稳定性好，链表版可 O(1) 额外空间。

### 1.4 Python 现实：Timsort
`sorted(xs, key=..., reverse=...)` 是归并+插入的混合（自然归并 run-detection），
最坏 Θ(n log n)、最好 Θ(n)、稳定、key 函数"Schwartzian transform"每元素只求值一次。
考试仍手写三种排序；工程永远用 `sorted`。
