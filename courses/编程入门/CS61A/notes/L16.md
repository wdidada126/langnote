## 1. 核心概念

### 1.1 递归树与递归处理
```python
class Tree:
    def __init__(self, root, children=()):
        self.root, self.children = root, list(children)
    def depth(self):
        if not self.children: return 1
        return 1 + max(c.depth() for c in self.children)
```
树的天然语言就是**递归**（L07 树递归的实体化）。遍历谱系：前序（根→子）、后序
（子→根）、层序（队列，生成器版见 CP）——三种都只是"访问时机"的参数化差异。

### 1.2 字典：哈希表的接口
`dict` 提供均摊 Θ(1) 查找；键必须**可哈希**（不可变 + 定义 `__hash__` 且与
`__eq__` 一致）。工程惯用法：

```python
from collections import defaultdict, Counter
counts = defaultdict(Counter)        # 嵌套默认工厂，零样板
for word in words: counts[len(word)][word] += 1
```

树→字典的换算：给节点 id 建邻接表/parent 表，可在 O(1) 查祖先与子代（P3 社交网络
的 followers 索引即倒排字典）。

### 1.3 组织策略决定效率（spring 讲义 Efficiency）
同一份数据多种组织，"为查询模式选结构"：
- 线性列表：顺序遍历 OK，点查 O(n)；
- 排序数组：点查/范围查 O(log n)（bisect），插入 O(n)；
- 哈希字典：点查 O(1)，无序；
- 树：有序 + 分支操作 O(深度)。
Lab/考试的"哪种表示支持操作 X 在 O(?) 内"题型全部由此出。

### 1.4 OrderedDict / 插入序
Python 3.7+ 普通 dict 已保证迭代按插入序，但 `OrderedDict.move_to_end/popitem` 与
"顺序参与相等比较"仍是其存在理由（LRU 缓存 = dict + 双向链表， OrderedDict 是标准件，P3 手实现）。
