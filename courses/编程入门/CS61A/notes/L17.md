## 1. 核心概念（A：数据半程知识地图）

### 1.1 一条主线：抽象屏障 + 表示独立
```
L10 屏障概念 → L11 序列（屏障上的通用操作）→ L12 迭代器（屏障的惰性兑现）
→ L13 可变对象（身份/状态进入）→ L14 类（屏障制度化）→ L15 继承（沿屏障复用）
→ L16 树/字典（屏障两侧各选最优表示）
```

### 1.2 高频题型自查
1. **链表/树输出**：`Link(1, Link(2, Link(3)))` 的 `print`、`len`、深链 `s.rest.rest.first`；
   Tree 的 repr 嵌套（P3 评分依赖）。
2. **属性/方法查找**：实例 dict → MRO；`super()` 起点是"当前类在 MRO 的下一位"。
3. **表示切换题**：给"children 为 dict 的 Tree"改写 `__init__`，保证 `depth/str` 测试不变——P3 原题型。
4. **效率配对**：list.insert(0)=Θ(n)、dict 点查均摊 Θ(1)、树 depth=Θ(节点数)、
   完全二叉树高度 Θ(log n)。
5. **可变默认值/别名**：L13 §1.4 三件套再考一遍。

### 1.3 综合例
```python
class Missing:
    def __init__(self, name): self.name = name
    def __repr__(self): return f'Missing({self.name!r})'
    def __str__(self): return f'--{self.name}--'
items = [Missing('a'), Missing('b')]
items                       # REPL 用 repr 列表：[Missing('a'), Missing('b')]
print(f'{items[0]}')        # format/print 用 str：--a--
```
考点：容器打印调**元素**的 `__repr__`；`print(obj)` 调 `__str__`（缺省回退 repr）。

## 2. 核心概念（B：语言建模选读，spring 特色周）

CS61A spring 讲义用一周介绍 LLM 直觉：token → embedding → 自回归预测
`P(next | prefix)`；attention = 对前文所有 token 的加权求和（矩阵乘法）。
关键落点有二：
1. **采样温度**即控制流（`argmax` vs `temperature>0` 抽样）——与我们 L01 的
   `or 'default'` 一样，概率也是可编程的值；
2. 模型输出 = 序列生成过程 → 与 L12 生成器同一心智模型（流式解码 stream）。
不要求数学推导，要求能解释"为什么同一 prompt 两次回答不同"。
