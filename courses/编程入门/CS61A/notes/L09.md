# L09 期中 1 复习：从函数到过程

> Week5-L1 · 范围：L01-L08（CP 第 1 章全章）
> 历年题型：环境图、输出预测、实现题（高阶/递归）、树递归效率分析

## 1. 核心概念（知识地图）

### 1.1 一张图串起前八讲
```
表达式(名字+调用+逻辑)            ← L01-L02
   ↓ 抽象
def 函数（框架、parent 指针）      ← L02-L03
   ↓ 设计
域假设 / 合约 / 声明式风格         ← L04
   ↓ 把"概念"参数化
高阶函数：作参数 → 作返回值        ← L05-L06
   ↓ 自相似
递归：线性 / 树 / 分治            ← L07
   ↓ 给过程标价
增长阶 + 迭代 vs 递归过程          ← L08
```

### 1.2 高频考点清单
1. **环境图**：函数对象的 parent 箭头指向**定义处**框架；闭包保命外层框架。
2. **输出预测**：注意"打印 vs 返回"（L03）、`print(func)` 打印 `<function ...>`、
   函数比较看对象身份（`f is g`）。
3. **实现题模板**：
   - 通用累加器 `summation/accumulate`（L05）；
   - currying 链：`f(1)(2)(3)`（L06）；
   - 树递归计数：`count_change(4)` = 4（1,2,3 硬币凑 4 元，Lab04 原题，易漏 (1,1,1,1)）。
4. **复杂度配对**：未 memo 的 fib=Θ(φⁿ)；memo=Θ(n)；迭代=Θ(n) 时间 Θ(1) 空间（Scheme 意义）。
5. **bool/int 边角**：`-7//2 == -4`、`-7%2 == 1`、`and/or` 返回操作数。

### 1.3 一个综合例（考试难度）
```python
def skip(lst, n):
    """linked-list 风格热身：跳过前 n 个元素后求和（用列表模拟）"""
    if not lst: return 0
    if n == 0:  return lst[0] + skip(lst[1:], 0)
    return skip(lst[1:], n - 1)
```
问：递归过程还是迭代过程？（递归——`+` 挂起）；`skip([1,2,3,4],1)` 输出？（9）；
切片带来什么复杂度代价？（每层 Θ(n) 拷贝 → 总 Θ(n²)——L08 的"一行≠一步"）。

重做 HW1-HW3 错题 + Lab02/Lab03 环境图填空；用 P1/P2 源码反向自问"哪个函数用到了
哪讲的概念"。做 practice midterm（官网有 spring2024/fall2022 原题限时 75 分钟）。
