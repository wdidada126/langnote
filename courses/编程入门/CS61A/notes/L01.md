## 1. 核心概念

### 1.1 这门课在问什么
CS61A 的问题意识来自 SICP 扉页："程序是思维的代表符号（representations of processes）"。
课程关注三件事：**如何把过程组织进函数**（第 1 章）、**如何把数据组织进抽象**（第 2 章）、
**解释器如何让语言自己解释自己**（第 3-4 章 / P4）。整学期你会在 Python → Scheme → SQL 三
种语言之间来回，体会"同一思想的不同外壳"。

### 1.2 求值：解释器的第一性循环
Python 交互式会话本质是一个 REPL：读入源码 → 词法/语法分析 → 求值 → 打印。
CPython 里对应 `Python/ast.c`（构造 AST）与 `Python/ceval.c`（求值 AST/字节码）。你现在是
这套流程的使用者，L19-L22 与 P4 你将亲手实现它。

### 1.3 整数：精确算术
Python 的 `int` 是**任意精度**的，不像 C/Java 溢出回绕：

```python
>>> 2 ** 100
1267650600228229401496703205376
>>> 7 / 2        # 真除法，返回 float
3.5
>>> 7 // 2       # 地板除（向负无穷取整！）
3
>>> -7 // 2      # 不是截断除法 -3，而是 -4
-4
>>> 7 % 2, -7 % 2   # 余数符号跟随除数
(1, 1)
```

`//` 与 `%` 满足恒等式 `(a//b)*b + a%b == a`，这是数论题（如模运算、日期计算）的地基。

### 1.4 布尔表达式
`bool` 是 `int` 的子类型：`True == 1`、`False == 0`，但仍可安全使用：

```python
>>> True + True
2
>>> 1 < 2 < 3          # 链式比较，等价于 (1<2) and (2<3)
True
>>> not 0              # 真值性：0、''、[]、{}、None、空对象为假
True
```

`and`/`or`/`not` 是**短路**的，而且返回**操作数本身**（不只是 True/False）：

```python
>>> '' or 'default'    # 惯用法：取第一个"真"值
'default'
>>> 1 and 2            # 都为真时返回最后一个
2
```

### 1.5 名字与赋值
`x = 3` 不是"把 3 装进盒子"，而是**给对象贴标签**（名字→对象的绑定）。这是理解后面
可变数据（L13）与 OOP（L14）的第一块基石。

## 4. 知识点在开源项目中的应用
- **CPython**：`Objects/longobject.c` 用 30-bit "digit" 数组实现 bignum；`Objects/boolobject.c` 展示 bool 只是 int 的 thin wrapper。
- **sympy**（ SymPy ）：在符号计算中复用 Python int 的精确性做有理数/多项式算术。
- 生态位对照：`numpy.int64` 故意"退化"为机器整数换取性能——语言级精确 vs 数组级近似，是 Python 数值生态的基本张力。
