## 1. 核心概念

### 1.1 身份、状态、赋值
引入可变性后，"值相等"分裂为两种：`==`（内容同）与 `is`（同一对象）。
对象 = 值 + 身份 + 可变状态。副作用让**求值顺序开始变得要紧**：

```python
a = [1, 2]; b = [1, 2]
a == b, a is b                # (True, False)
b = a
b.append(3)
a                            # [1, 2, 3] —— 同一对象，隔空联动
```

### 1.2 用类做可变对象（消息传递风格）
```python
class Wallet:
    def __init__(self, balance):
        self.balance = balance
    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            return amount
        return 0
```
CP §2.3 的精髓：对象是"带私有状态的函数分派器"。两个钱包是**不同对象**，
状态互不干扰——这就是身份。

### 1.3 链表：递归的可变序列
```python
class LinkedNode:
    def __init__(self, first, rest=None):
        self.first = first
        self.rest = rest
def link(s):                 # [1,2,3] -> LinkedNode
    if not s: return None
    return LinkedNode(s[0], link(s[1:]))
```
- prepend O(1)（vs list.insert(0,x) O(n)）、无索引 O(n) 访问——与数组互补的两端。
- 递归定义 `link(first, link(...))` 让"长度/求和/反转"全部一行递归：
  `len(s) = 0 if s is None else 1 + len(s.rest)`。
- 反转（Lab07 重点）需要**循环+三指针**（prev/cur/nxt），画链表快照防断链。

### 1.4 可变默认值回收 L03 伏笔
```python
def bad(item, box=[]):      # box 在 def 时创建一次，跨调用共享！
    box.append(item); return box
def good(item, box=None):
    if box is None: box = []
    box.append(item); return box
```
可变默认值 + 浅拷贝 + `is` 身份，是 Lab 三大惨案之源。
