## 为什么学

- 覆盖 Rust 入门所需绝大多数知识点，且有完善本地测试系统，即使无视频也能作为高质量 Rust 习题课自测。
- 部分习题可作为 CS110L 的良好补充；学完 CS110L 觉得练习不够时，本课是首选续集。
- 主讲人鼓励用 AI 辅助编程但强调核心工作自己完成——作业设计天然抗"抄答案"，且网上无公开参考答案。

## 先修与知识联系

- 先修：任一其他编程语言。
- 联系：与 CS110L 同轨道（CS110L 重系统/并发，CS220 重语言原理与练习量）；类型系统与抽象内容向 CS242/CS420 过渡；并发习题是 cs431 的前置热身；与 CS3110 (OCaml) 可对照学习代数数据类型与模式匹配。
