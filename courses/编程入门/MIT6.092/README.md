## 为什么学

- 零编程基础可上手：每节课 1 小时 Lec + 1 小时 Lab，强度低、反馈快。
- 快速建立 Java 基本功：编译原理、八大基本类型、Hello World、命名/缩进等代码风格、Debug（Eclipse warning、Assertion、Exception）。
- 作为通往 MIT 6.005/6.031（软件工程与构造）的跳板，是 Java 轨道的最短入口。

## 先修与知识联系

- 先修：无。
- 联系：与 CS61A（Python/Scheme）、CS61B（Java 数据结构）相比，6.092 是更轻的 Java 语法速成；学完 6.092 后进 CS61B 或 MIT 6.031 都顺滑；OOP 概念可与 CS106B/X 的 C++ OOP 章节横向对照。
