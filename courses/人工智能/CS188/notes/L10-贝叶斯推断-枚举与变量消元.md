# L10 贝叶斯推断：枚举、变量消元、似然加权

> 对应 AIMA Ch.15.1-15.4；Klein 讲义 "Inference in Bayes Nets"。项目 `projects/bayes` 实现本讲。

## 1. 核心概念

- **查询类型**：P(Q|E=e) —— 经联合分布边缘化：α·Σ_q Σ_hidden Π_i CPT_i。
- **简单枚举**：对每个原子求乘积再相加——O(2^n)，n=50 时宇宙热寂也跑不完。
- **变量消元 VE**：
  - 表示：网络 = **因子（factor）**集合 f_i(Pa_i ∪ {X_i})；查询 = 按消元序逐个 sum-out 变量，每次把包含该变量的因子乘起来再求和，产生新因子。
  - 复杂度：O(n·d^{w+1})，w = **诱导树宽**（消元序产生的最大团−1）——**序的选择决定生死**（例：链式序 O(nd²) vs 星形中心先消 O(nd^n)）。
  - 空间：需保留最大因子（VE 的主要弱点）。
- **溯回枚举（backward / lazy elimination）**：按需展开查询相关因子，简单实现常更快。
- **似然加权（LW）**：固定证据按 P(e) 采样隐变量，权重 = Π P(e_i|pa_i)——O(N) 样本换任意规模网络，但有偏低效当证据罕见（权重集中）。

## 2. 关键伪码

```
function VE(Q, evidence, order):
    factors ← all CPTs restricted to evidence
    for var in order:                    # 消元序
        relevant ← factors containing var
        f_new ← SUM_var( PRODUCT(relevant) )
        factors ← (factors \ relevant) ∪ {f_new}
    return NORMALIZE(PRODUCT(factors))
```

- 精确推断复杂度：Cooper 1990 证明一般 BN 推断 **NP-hard**——与 L07 "树宽决定 CSP" 完全同构（BN 推断 ⊇ 图着色计数）。

## 3. 直觉例子

- Burglary/Earthquake→Alarm→John/Calls 经典网：P(B|j,m) ≈ 0.28——推理"电话响了&Mary 也打了， burglary 概率多大"。
- 证据罕见时 LW 退化：P(所有 50 变量=特定罕见组合) 采样几乎不命中，有效样本量骤降（接 L18 粒子滤波重加权的动机）。
