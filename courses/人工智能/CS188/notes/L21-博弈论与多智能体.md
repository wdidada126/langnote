# L21 博弈论与多智能体：纳什均衡

> 对应 AIMA Ch.17（博弈论节）+ Klein 讲义 "Game Theory"。L05 去掉"完全信息回合制"假设后的一般化。

## 1. 核心概念

- **策略式博弈**：玩家集合、各自行动空间、联合效用表；同时出招无法用 L05 树。
- **占优策略**：无论对手如何都最优——** iterated deletion of dominated strategies** 是理性公共知识的推演（美人投票/竞价）。
- **纳什均衡（NE）**：策略组合 (π₁*,π₂*)，没人能 unilateral 偏离获利。存在性：有限博弈混合策略下必有（Nash 1950，角谷不动点）。
- **混合策略**：随机化使对手无 exploitable 模式——石头剪刀布唯一均衡 = 均匀随机；惩罚"预测我的预测者"。
- **零和特例**：**minimax 定理**：混合策略零和博弈的 value 唯一且 NE=α-β 搜的极限（L05 是本讲特例）。
- **囚徒困境/公地悲剧**：个体理性 ≠ 集体最优；重复博弈（tit-for-tat、folk theorem）让合作浮现——**未来折扣（γ）决定合作意愿**，回扣 L12。
- **机制设计**（逆向博弈论）：规则制定者让"说真话是均衡"（拍卖/VCG）——多智能体 RL 的激励层。

## 2. 关键公式

```
NE:  u_i(π_i*, π_-i*) ≥ u_i(π_i, π_-i*)   ∀π_i, ∀i
2x2 零和混合： p* 使对方两动作无差异（解线性方程/线性规划）
FFA: Rock-Paper-Scissors 的 1/3,1/3,1/3 即唯一对称 NE
```

## 3. 直觉例子

- 手算 matching pennies 混合均衡；点球大战数据（Palacios 2014 世界杯罚点）近似混合均衡的实证。
- 交通布拉斯悖论：每个人最优 = 集体更差（NE 非帕累托最优）。
