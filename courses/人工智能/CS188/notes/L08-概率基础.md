# L08 概率基础：条件概率、贝叶斯、随机变量与期望

> 对应 AIMA Ch.12-13；Klein 讲义 "Basics of Probability"。后半程（L9-L21）的地基课。

## 1. 核心概念

- **原子事件**：所有随机变量赋值的一个组合；P(原子) 非负、和为 1；n 个二元变量有 **2^n 个原子**（联合分布表指数爆炸——L09 贝叶斯网存在的理由）。
- **边缘化（summing out）**：P(X) = Σ_y P(X,y)；**条件化**：P(X|e) = P(X,e)/P(e)。
- **乘法规则**：P(x,y) = P(y|x)P(x)（链式法则推广）。
- **贝叶斯法则**：P(x|y) = P(y|x)P(x) / P(y)，其中 P(y) = Σ_x P(y|x)P(x)（全概率）。
- **独立与条件独立**：P(x,y)=P(x)P(y)；给定 Z 后 X⊥Y。独立是模型简化的全部来源。
- **随机变量与期望**：E[f] = Σ_x f(x)P(x)；Var、线性性 E[aX+bY]=aE[X]+bE[Y]（不要求独立）。

## 2. 关键公式

```
P(c|+) = P(+|c)P(c) / [P(+|c)P(c) + P(+|¬c)P(¬c)]      # 疾病检测
MAP-MPE: argmax_x P(x|e) vs MPE: argmax_x P(x,e)         # 最可能解释的区别
```

- **MAP ≠ MPE**：联合最优的各分量单独看不一定最优（彩票例子）。

## 3. 直觉例子

- **假阳性悖论**：患病率 1/10000、检测灵敏度 99%、假阳率 1% ⟹ 阳性后患病概率仅 ~0.1%（先验的力量）。
- 两个条件分布相加：`P(A|B) 与 P(A|¬B)` 分组平均会翻转（辛普森悖论）——提醒边缘化顺序的重要性。
