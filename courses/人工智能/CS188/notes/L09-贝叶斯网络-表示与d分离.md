# L09 贝叶斯网络：表示、条件独立、D-separation

> 对应 AIMA Ch.14；Klein 讲义 "Bayes Nets / D-separation"。概率版的"数据结构设计"。

## 1. 核心概念

- **贝叶斯网（BN）**：有向无环图 G + 每个节点的 CPT；联合分布因式分解：
  - P(x₁…x_n) = Π_i P(x_i | Parents(x_i))。
- **参数复杂度**：全连接联合表 2^n vs BN Σ_i 2^{|Pa(i)|}·|X_i|——稀疏连接即免费午餐。
- **三种局部结构与其独立性**：
  - 共同原因（fork）X←Z→Y：Z 观测后 X⊥Y；
  - 因果链 X→Z→Y：同上；
  - **共同结果（v-structure / collider）X→Z←Y：Z 未观测时 X⊥Y，观测 Z 反而使 X,Y 相关（explaining away，解释排斥）**——三结构唯一区别，考试高频。
- **D-separation**：路径被阻塞 ⟺ (a) 某非分叉节点被观测，或 (b) 分叉节点被观测。图上无 d-连接路径 ⟹ 分布级条件独立（图半单向）；反之不必然严格成立（极小完美映射假设）。
- **朴素贝叶斯**：星型 BN（类标签 → 所有特征，特征条件独立假设），L11 展开。

## 2. 关键判定流程

```
d-connected(X, Y | E)?
  存在一条无向路径，其上每个节点 v：
    - v 是分叉且 v 或其后代 ∉ E → 通过
    - v 非分叉且 v ∉ E → 通过
  全部路径都被阻塞 → d-separated → P(X|Y,E)=P(X|E)
```

## 3. 直觉例子

- **感冒/过敏 → 发烧**（fork，观测感冒不阻断？错——发烧相关由过敏解释，感冒概率下降 = 反向证据传播）。
- **电池没电 / 油没了 → 车发动不了**（v-structure）：得知"油还有"则电池嫌疑飙升——explaining away 是诊断系统（医疗/故障定位）的灵魂。
- Stormtrooper 准确率例子：条件概率颠倒（P(中|穿甲) vs P(穿甲|中)）说明贝叶斯法则必要性。
