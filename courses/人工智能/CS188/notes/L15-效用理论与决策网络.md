# L15 效用理论与决策网络

> 对应 AIMA Ch.16；Klein 讲义 "Utility / Decision Networks"。回答"R 与偏好从哪来"。

## 1. 核心概念

- **偏好公理**（理性偏好的五条）：完备/传递/连续/可替换/单调 ⟹ 存在**效用函数 U** 使偏好 = 期望效用最大化（vN-M 定理）。
- **MEU 原则**：理性 agent = argmax_a E[U | a, evidence]——L12 MDP 的 R 与 L05 评估函数的合法性来源。
- **风险态度**：U 凹=风险规避、凸=冒险、线性=中性；确定性等价、保险溢价都从曲率来（"效用弹性"即 U 曲率的经济学表达）。
- **主导性与非理性现象**：所有结果概率相等时 MEU 退化为均匀比较；Allais 悖论展示人类违反连续性公理。
- **决策网络（影响图）**：BN + **决策节点（方）** + **效用节点（菱）**；三节点链：先验 → 行动 → 效用。
  - 求解：枚举决策规则（action 的函数）取 MEU 最大；信息结构（是否可观测）改变决策规则空间——**有记忆链/无记忆链影响可解性**。

## 2. 关键公式

```
U(Lottery) = Σ_i p_i·U(outcome_i)
MEU(π) = Σ_s P(s)·U(π(s))            # 决策网络的求值
确定性等价 CE：U(CE) = E[U(X)]        # 风险溢价 = E[X] − CE
```

## 3. 直觉例子

- 彩票 vs 稳赚：100 元确定 vs 50% 得 250——期望收益 125 更大但多数人选确定（凹 U）。
- 医疗决策网：先验 P(病)、检查可观测性（信息价值见 L16）、治疗行动、效用 = 生存质量×费用——影响图是临床指南的标准数学化。

## 4. 前后讲联系

- 前承 L08-L10（概率是信念，效用是欲望，MEU=信念×欲望求和）；后接 L16（信息值 = MEU 差）、L12（R 的设计即 U 的时不变投影）、L21（多人时"我们的 U"变成机制设计问题）。
