# L18 采样与粒子滤波

> 对应 AIMA Ch.15.5 + Klein "Sampling / Particle Filters"；官方 P5 后半。精确推断太贵时的蒙特卡洛路线。

## 1. 核心概念

- **采样动机**：L10 VE 在树宽大时指数爆；采样把"分布"换成"样本云"，误差 O(1/√N) 与维度无关（温和诅咒 vs 指数灾难）。
- **直接/先验采样**：按 BN 拓扑序逐节点从 CPT 抽——得到联合分布样本，但条件查询命中率低。
- **拒绝采样**：丢弃不符合证据的样本；P(证据) 极小时全丢（罕见证据灾难）。
- **似然加权 LW**（L10 引入）：固定证据、隐变量先验采样、权重 = Π P(e_i|pa)。问题：证据在**下游**时样本与证据无关，权重方差爆炸。
- **Gibbs 采样**：逐变量按条件分布 P(x_i|x_{-i}) 重抽，马尔可夫链收敛到目标后验（遍历性条件：所有条件概率非零）。
- **粒子滤波（Bootstrap Filter）**：HMM/DBN 上的序贯蒙特卡洛——
  - 每步：传播（按转移抽粒子）→ 加权（按发射概率）→ **重采样**（消灭低权粒子）；
  - 任意大隐状态空间 O(N·T)，代价：粒子贫化、固定 N 误差有偏。
  - 推广：KLM/RPF（机器人定位，Pacman 追踪鬼的正式版）。

## 2. 关键伪码

```
function PARTICLE-FILTER(B, A, y_{1:T}, N):
  t=0: draw N particles x0 ~ π0
  for t=1..T:
      x_t^i ~ A(x_{t-1}^i, ·)                    # 传播
      w_t^i = B(y_t | x_t^i)                      # 加权
      if Σ(有效粒子数)<N_eff: resample(w)          # 重采样（系统性采样）
  估计: P(x_t|y_{1:t}) ≈ 加权经验分布
```

## 3. 直觉例子

- Pacman P5：200 粒子追一个鬼，鬼数量翻倍时表格滤波（L17）组合爆炸而粒子数只线性涨——**采样对"状态多、分布散"友好**。
- LW 失败例：Sprinkler→Rain→WetGrass，查询 P(S|wet)：证据在下游时 99% 样本权重接近 0，有效样本 N_eff = (Σw)²/Σw² 骤降。
- 重采样像"达尔文"：适者繁殖，但种群多样性丢失（Rao-Blackwellised / 移动核补救）。
