# L19 机器学习与感知机：分类与决策边界

> 对应 AIMA Ch.18-19；Klein 讲义 "Learning / Perceptron"。监督学习的最小完整标本。

## 1. 核心概念

- **学习设定**：训练集 D={(x⁽ⁱ⁾,y⁽ⁱ⁾)}；假设类 H；目标=泛化误差（测试）而非训练误差——过拟合 = 模型容量 > 数据信息量。
- **线性分类器**：打分 f(x)=w·x+b，符号定类别；决策边界是超平面（L2 范数下最近点 = 投影）。
- **感知机算法**（Rosenblatt 1958）：
  - 错分 (x,y) 时：w ← w + y·x（把权重向量朝误分样本拉）。
  - **感知机收敛定理**：数据线性可分且间隔 γ>0 时，错误次数 ≤ (R/γ)²（与维度无关！Novikoff 1962）。
  - 不可分时不收敛 → 需要损失函数+正则化（→ CS229 的 SVM/LR 才是"完整答案"）。
- **多类化**：one-vs-rest；softmax 回归 = 感知机的概率版。
- **特征工程**：异或不可用线性分 → 加 φ(x)=x₁x₂ 升维即线性可分——"难问题在好特征下变简单"是全课反复出现的主题。
- **线性可分判定**：Farkas 引理/线性规划可判定训练集是否线性可分（连接 6.006 LP）。

## 2. 关键伪码

```
w ← 0
repeat until no mistakes on D:
    for (x,y) in D:
        if sign(w·x) ≠ y: w ← w + y·x     # 只加不减，几何直觉：夹角变小
```

- 感知机 vs LR：更新规则差在"错分才动"vs"梯度永动"；LR 的概率输出让 L15 MEU 可接。

## 3. 直觉例子

- 2D 点集画图：感知机像"每次被错分就向对侧挪一点的醉汉"，几步内到任意分隔超平面。
- Iris/手写数字二分类（9 vs 其余）：加偏置项后 5 轮内准确率 >95%——但测试误差随容量增长先降后升（双 descent 是现代补充话题）。
