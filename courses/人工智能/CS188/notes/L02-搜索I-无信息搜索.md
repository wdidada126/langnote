# L02 搜索 I：无信息搜索（BFS/DFS/UCS/IDS）

> 对应 AIMA Ch.3；Klein 讲义 "Search I/II"。本项目 `projects/search` 实现本讲+L03 全部算法。

## 1. 核心概念

- **搜索问题五元组**：`SearchProblem(initial_state, successor_fn, is_goal, step_cost, [heuristic])`。
  - 状态（state）是抽象：只保留决策所需信息（"问题即状态空间"）。
- **搜索树 vs 搜索图**：tree search 可能重复扩展/死循环（有限状态空间必加 visited/closed set）；graph search 用 closed list 去重。
- **frontier 决定算法**（本课最重要的统一视角）：

| 算法 | frontier 数据结构 | 完备 | 最优 | 时间/空间 |
| --- | --- | --- | --- | --- |
| DFS | stack | 树搜索完备 | 否 | O(b^m) |
| BFS | queue | 是 | 单位代价最优 | O(b^d) |
| DLS/IDS | stack+深度限制 | 是 | 否（IDS 单位代价最优） | O(b^d)/O(d) |
| UCS | priority queue by path cost g | 是 | **是**（非负代价） | O(b^{1+⌊C*/ε⌋}) |

- **UCS 正确性直觉**：每次弹出全局 g 最小节点，任何未探索解的代价 ≥ 弹出值（frontier 单调性）。

## 2. 关键算法伪码

```
function GRAPH-SEARCH(problem):
    frontier ← WRAP-FRONTIER()        # stack/queue/PQ
    explored ← {}
    add Node(initial_state)
    while frontier not empty:
        node ← pop_frontier()          # UCS: node.state ∉ explored 才可扩展
        if problem.IS_GOAL(node.state): return PATH(node)
        add node.state to explored
        for s,a,s',c in problem.SUCCESSORS(node.state):
            if s' ∉ explored: push Node(s', g=node.g+c)
```

- 路径成本从根累计；reconstruction 沿 parent 指针回溯（DFS 空间优化：iterative deepening 只需 O(bd)）。

## 3. 直觉例子：Romania / 迷宫

-  Romania 地图：BFS 像"均匀扩圈"，DFS 像"一条道走到黑"，UCS 像 Dijkstra 从布加勒斯特向外按公里数扩展。
- Pacman 吃豆：状态=（吃豆位置, 已吃豆子集合），状态数 O(n·2^n)——**同一迷宫，状态定义不同复杂度指数级变化**（bitmask 状态空间，对应 6.006 的 state-space Dijkstra 专题）。
