# L04 局部搜索与优化：爬山、模拟退火、遗传算法

> 对应 AIMA Ch.4；Klein 讲义 "Local Search"。只关心"解在哪"，不关心"路径"。

## 1. 核心概念

- **适用场景**：状态空间巨大（n-queens 64!）、只关心最终解质量、可用廉价评价函数 f(state)。
- **爬山 HC**：从初态出发，每一步移动邻域内**更优**的邻居，直到局部最优。
  - 失败模式：局部极大/极小、高原 plateau、山脊（单步不动点，需多步邻域）。
  - 变体：随机爬山（stochastic，可跳出弱局部最优）、首选择爬山、**随机重启爬山（SIDA）**——重启次数多则"几乎必然"命中全局最优的启发。
- **模拟退火 SA**（Metropolis 1953 → Kirkpatrick 1983）：以温度 T 允许向差移动，概率 `e^{Δ/T}`；T 按调度缓慢冷却。
  - 定理：T 下降足够慢（~c/log t）则渐近收敛到全局最优（实践只用经验调度）。
- **遗传算法 GA**：种群 + 选择（适应度比例）+ 交叉 crossover + 变异 mutation；本质是带信息共享的随机重启。适合编码好、适应度平滑的问题（排程/布局）；对 AI 规划是次要工具。

## 2. 关键伪码

```
function SIMULATED-ANNEALING(problem, schedule):
    current ← random_state(); E ← VALUE(current)
    for t in 1..T_max:
        T ← schedule(t)
        next ← random_neighbor(current)
        Δ ← VALUE(next) − E
        if Δ > 0 or random() < exp(Δ / T): current, E ← next, Δ+E
    return current
```

- n-queens 邻域=同列换行；值 = −冲突对数（O(n) 增量更新，对应 6.006 的摊销/增量视角）。

## 3. 直觉例子

- 8-queens：随机重启爬山常在 <100 步解决；但更大棋盘（20-queens）退火更稳。
- 物流路径（TSP）：SA 的 2-opt/3-opt 局部搜索是 LKH 求解器核心组件。
