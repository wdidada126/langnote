# L20 神经网络与深度学习导论

> 对应 AIMA Ch.22 + 延伸；Klein 讲义 "Neural Networks"。L19 感知机堆叠 + 可微 = 本讲。

## 1. 核心概念

- **神经元**：a = σ(w·x + b)；常用 σ（logistic）、tanh、**ReLU**（max(0,x)，缓解梯度消失）。
- **前馈网络**：层堆叠；**通用近似定理**（Cybenko 1989）：单隐层足够逼近任意连续函数（宽度需指数大——"存在≠实用"）。
- **反向传播**（Rumelhart 1986）：链式法则 + 动态规划复用中间量；
  - δ^l = (W^{l+1T} δ^{l+1}) ⊙ σ'(z^l)；∂L/∂W^l = δ^l a^{l-1T}。
  - 计算图视角：前向缓存、反向传播伴随——与 AD（自动微分）等价。
- **训练配方**：损失（交叉熵）+ 优化器（SGD→**Adam**，L14 的近亲）+ 初始化 + 正则化（dropout/L2）+ 归一化。
- **架构谱系一句话**：CNN（局部性+平移等变，图像）、RNN/Transformer（序列，自注意力取代循环）、LLM 即超大 Transformer + 自回归交叉熵——对齐用 L14 的策略梯度（RLHF）。
- **与经典 AI 的接口**：网络充当 L05 eval、L03 h、L14 Q̂/π_θ、L18 的提议分布——**深度网络是前 19 讲所有"函数槽位"的万能填充物**。

## 2. 关键伪码

```
forward:  z1=W1x+b1; a1=relu(z1); z2=W2a1+b2; ŷ=softmax(z2)
backward: δ2=ŷ−y(onehot); ∇W2=δ2·a1ᵀ; δ1=(W2ᵀδ2)⊙relu'(z1); ∇W1=δ1·xᵀ
```

## 3. 直觉例子

- XOR：感知机（L19）做不到，两层 (2-2-1) 网络一次训练即会——非线性折叠空间的可视化教学。
