# L16 信息的价值：VoI、PoI 与理性感知

> 对应 AIMA Ch.16.4-16.6；Klein 讲义 "Value of Information"。把"传感器"变成可计算对象。

## 1. 核心概念

- **信息价值定义**：InfoGain(证据 E | 查询 Q) = Σ_e P(E=e)·H(P(Q|E=e)) − H(P(Q)) 的负值——**信息 = 不确定性减少的期望**（单位：比特或效用）。
- **价值 of 完美信息（VoPI）**：能观测到隐藏变量 Z 后最优策略的 MEU 提升：
  - Value(Z) = Σ_z P(z)·MEU(π*_z) − MEU(π*_∅) ≥ 0。
- **实验设计 = 买信息**：每个可选检查有成本 c，理性 agent 选 (VoI − c) 最大的检查（序贯决策时递归到 L12 的 MDP——"信息收集 MDP"，belief state 上的 POMDP 雏形）。
- **感知的价值**：什么时候值得回头看一眼？——当未来决策会被新信息改变时（信息只有决策相关时才有价值，"no value of information for irrelevant evidence"）。
- **理性 agent 的边界**：完美理性 + 无限计算才全知；有限计算下 VoI 与"元推理"（要不要继续想）trade-off（Russell & Wefald 后续）。

## 2. 关键公式

```
Value(Z) = Σ_z P(z) max_a Σ_s P(s|z)U(a,s)  −  max_a Σ_s P(s)U(a,s)
InfoGain = H[Q] − E_e[H[Q|e]]   ∈ [0, H[Q]]   # 熵形式，衔接信息论
购买判据： buy Z iff Value(Z) ≥ cost(Z)
```

## 3. 直觉例子

- 医生：CT（贵、VoI 高，改变手术决策）vs 体温（便宜、对肺癌几乎零 VoI）。
- Pacman：探头看一眼鬼的位置——若看完策略不变（鬼在另一头），这次观测 VoI=0；迷宫探索阶段 VoI 最高（不确定性最大时）。
- 买彩票前查开奖号：完美信息但**决策无关**（号码已定）→ VoI=0，经典反直觉题。
