# 17-803 讲义要点（骨架，Spring 2024 模块顺序）

> 每条为骨架级要点。这门课的产出是"研究设计 + 可复现分析"，笔记每讲应留：方法定义 / 常见误用 / 一个可复现练习。

## L1 导论：实证研究是什么
- 实证 = 用可观察证据回答研究问题，而不是靠直觉或权威。
- 三类贡献：描述现象、解释机制、评估干预；不同贡献决定不同方法。
- 软件工程实证的独特数据源：代码、仓库历史、问答网站、人（开发者）。
- 好问题的四条标准：可回答、有价值、可证伪、伦理可接受。

## L2 研究设计与效度威胁
- 内部效度：能否把结果归因于处理；历史/成熟/选择是主要威胁。
- 外部效度：结论可推广到什么人群、项目与情境。
- 构念效度：代理指标（行数/提交数）真的代表"生产力"吗。
- 结论效度：统计功效、测量误差与多重比较导致的误判。

## L3 文献与批判性阅读
- 拆解模板：研究问题 → 数据 → 方法 → 识别策略 → 结论 → 效度威胁。
- 读论文要问"如果换我个人，结论会不会翻转"。
- 引用链条分析：找源头论文，警惕被反复误引的结论。
- 写作上：区分作者声称、数据支持与你的推论。

## L4 系统综述与映射研究
- 检索式、数据库与纳入/排除标准必须可复制（PRISMA 流程图）。
- 综述类型：叙事综述、系统综述、映射研究、meta 分析，各自目的不同。
- 筛选双人 + 一致性度量，避免"读到手软"的随意化。
- 质量评估工具与数据抽取表是系统综述的核心工件。

## L5 定性研究：访谈与观察
- 访谈类型：结构化/半结构化/非正式；提纲问题要开放、非引导。
- 样本量由"信息饱和"决定，而非统计功效。
- 录音、逐字转录与备忘录（memo）是定性可信度的基础设施。
- 观察法注意霍桑效应；记录场记（field notes）要区分描述与解释。

## L6 扎根理论与定性编码
- 扎根理论：从数据中生长理论，不断比较（constant comparison）。
- 三级编码：开放 → 主轴 → 选择性；理论饱和作为停止条件。
- 代码手册（codebook）：定义、正例、反例、边界情形四要素。
- 工具：RQDA、Taguette、Atlas.ti；记录每次编码决策的修订历史。

## L7 编码一致性与信度
- 编码者间一致性：百分比一致、Cohen's κ、Krippendorff's α（有序/缺失适用性不同）。
- κ 悖论：类别分布极度不平衡时 κ 会失真，需同时报告原始一致率。
- 分歧处理机制：讨论重定义代码 > 第三方仲裁 > 多数投票。
- 内部一致性（量表信度 Cronbach's α）与编码信度不要混用。

## L8 问卷与调查设计
- 构念 → 维度 → 题项的映射；每题只问一件事（避免双重问题）。
- 量表选择：Likert 的级数、锚点与中性点；避免引导性措辞。
- 预测试与认知访谈（think-aloud）是发现歧义最便宜的手段。
- 顺序效应、社会赞许偏差与"全部选 4"的满意度自满偏差。

## L9 抽样与偏差
- 概率抽样 vs 便利抽样：软工研究常只能用后者，必须显式声明外推限制。
- 响应偏差：早期响应者差异、非响应偏差与跟进策略（Dillman 方法）。
- 自选择偏差与幸存者偏差在开源研究中尤其严重（僵尸项目/离开者）。
- 报告抽样框与招募渠道，让审稿人能评估代表性。

## L10 描述统计与数据清洗
- 先看分布与尺度：计数/比率/有序/分类，决定后续可选模型。
- 缺失机制（MCAR/MAR/MNAR）决定能否直接删除或用多重插补。
- 异常值：区分数据错误与真实极端值；不要机械删除。
- 可视化规范：箱线/密度/小倍数图；避免用双轴图制造相关错觉。

## L11 假设检验与效应量
- p 值的正确解释：在原假设为真下观察至此或更极端数据的概率。
- 必须报告效应量与置信区间（Cohen's d、比值比、IRR、AIC/伪 R²）。
- 多重比较：Bonferroni 与 FDR；预注册主要结局以控制"结果挑选"。
- 显著 ≠ 重要：实务显著性（幅度、成本、可推广）要单独讨论。

## L12 功效分析与样本量
- 功效 = 1 − β；影响因子：效应量、方差、α、样本量、模型复杂度。
- 最小可检测效应（MDE）思路：先定实务上有意义的效应，再反推样本量。
- 模拟式功效分析（sim power）适合混合模型等无解析公式情形。
- 报告计划样本量与实际样本量差异及其原因。

## L13 线性模型 I：OLS 与诊断
- 回归系数是"控制其他变量后的条件关联"，不是因果效应。
- 假设与诊断：线性、独立、同方差、正态残差；异方差用稳健标准误。
- 中心化与交互项：主效应在含交互时的解释陷阱。
- 类别编码（treatment/dummy coding）会改变系数含义与假设检验。

## L14 线性模型 II：逻辑回归与计数模型
- 广义线性模型框架：链接函数 + 分布族，理解"log-odds / log-rate"。
- 逻辑回归系数解读为比值比；边际效应更贴近直觉但依赖取值点。
- 计数结果用 Poisson/负二项；零膨胀与过离散的诊断。
- 完全分离与稀疏数据：Firth 校正或贝叶斯先验。

## L15 混合效应模型
- 数据结构决定模型：开发者嵌套在项目内、观测嵌套在开发者内。
- 随机截距/随机斜率与 ICC：组内相关越高越必须用混合模型。
- 固定效应 vs 随机效应的选择与研究问题表述相关（推广对象是谁）。
- 收敛问题、中心化与自由度近似（Kenward-Roger/Satterthwaite）。

## L16 仓库挖掘 I：数据获取
- 数据源层级：Git 本地历史、GitHub API、GH Archive 事件流、GHTorrent、BigQuery。
- 抽取的坑：限流、缺失/截断（大文件/二进制）、时间戳时区、重命名与 squash。
- 身份解析：邮箱/账号多对多（SortingHat 类工具），跨平台 ID 链接。
- 版本化数据集与可复现管线（snapshot 日期必须写进论文）。

## L17 仓库挖掘 II：构念代理
- "生产力/质量/参与度"的代理指标各有系统偏差（行数、提交数、issue 关闭率）。
- 事件窗口定义：以处理发生时刻对齐前后窗口，避免"分母随时间漂移"。
- 度量效度检查：与访谈/问卷得到的独立测量做三角验证。
- 复现性：所有度量脚本与参数入库，原始 → 派生列的 lineage 清晰。

## L18 相关 ≠ 因果
- 混杂、碰撞与选择路径：先用 DAG 把假设画清楚再选模型。
- 常见谬误：回归"控制所有变量"可能引入 collider 偏差。
- 处理效应定义（ATE/ATT）与"谁被处理"的可比性问题。
- 不可能性证明类研究：下界/不可能性也是有效结论。

## L19 因果推断方法
- 匹配与倾向得分：平衡性诊断（标准化均值差）是核心检查。
- 双重差分（DID）：平行趋势假设必须检验（安慰剂期/事件研究图）。
- 工具变量与两阶段：相关性与排他性约束；弱工具问题。
- 回归断点（RDD）：局部随机化解释与带宽敏感性分析。

## L20 实验与预注册
- 三类实验：受控实验（学生/从业者）、准实验、田野实验；现实性与控制度权衡。
- 随机化单位选择（人 vs 项目 vs 时间窗）与干扰/溢出效应。
- 处理保真度与依从性：报告"实际接受了多少处理"。
- 预注册（OSF）：主分析计划提前固定，偏离须显式说明。

## L21 社交网络分析
- 网络构造：谁和谁通过什么边相连（共同修改同一文件、回复、代码审查）。
- 中心性（度、介数、特征向量）与"结构洞"对信息/影响力传播的意义。
- 同质性 vs 影响（selection vs socialization）：需要纵向数据 + SIENA 类模型。
- 网络数据的独立性假设失效：用指数随机图模型（ERGM）或置换检验。

## L22 文本与序列分析
- 词袋 → TF-IDF → 主题模型（LDA）→ 嵌入（BERT/CodeBERT 类）：表达能力与可解释性的权衡。
- 文本预处理决策（分词、停用词、代码标识符切分）会显著改变结论。
- 序列/过程分析：n-gram、Markov 模型、过程挖掘（Petri 网/轨迹聚类）。
- LLM 辅助编码：可做初步标注，但必须人工抽检并报告一致性。

## L23 研究者伦理
- IRB 审查、知情同意、退出权与数据最小化；公开数据也可能伤人。
- 匿名化处理：作者邮箱、项目名、引文自识别信息的去标识。
- GDPR/CCPA 与合规：数据留存期限、跨境传输与被遗忘权。
- 权力关系：研究者与被研究者（学生、开源新人）之间的不对等要显式管理。

## L24 可复现、写作与传播
- 开放科学三件套：材料（材料/问卷/代码本）、数据、分析代码（含环境与 seed）。
- Artifact Evaluation 与复现徽章；ACM 复现与结果重跑政策。
- 论文结构套路：动机-方法-结果-威胁-含义；威胁一节诚实暴露弱点。
- 审稿应对：区分"事实纠正"与"偏好之争"，回复信按点编号可核查。
