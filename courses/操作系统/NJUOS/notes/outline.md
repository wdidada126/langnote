# NJUOS 讲义骨架（notes/outline.md）

> 每讲 3–5 条要点，骨架级。

## L1 引言
- OS = 硬件之上的虚拟机 + 资源管理器，核心手段是虚拟化/并发/持久化/抽象。
- 「操作系统钢琴的盖子」：应用看不见的机制才是 OS 的本体。
- 课程路线：程序（状态机）→ 对象与 API → 可持久化。
- 环境搭建：Linux、gcc、gdb、QEMU 工具链。

## L2 C 语言与系统编程回顾
- 指针与内存布局再审视；未定义行为的系统级后果。
- 可变参数、位操作、编译期/链接期/运行期三阶段。
- assert/abort 与错误处理约定。
- 为链接专题与 OSLab 做语言准备。

## L3 二进制与链接（上）
- ELF 结构：段/节、符号表、重定位条目。
- 静态链接的符号解析与地址 patch。
- 为什么 .text 不可写、.data 与 .bss 的区别。
- 用 readelf/objdump 亲手拆解 a.out。

## L4 二进制与链接（下）
- 动态链接：PIC、GOT/PLT 与延迟绑定。
- LD_PRELOAD 劫持与库版本冲突（DLL hell）。
- 蒋老师手写迷你可执行文件 + 自制二进制工具演示。
- MiniLab：链接相关实验（dlkit 风格）。

## L5 并发与内存模型
- 共享内存并发的最小模型：两线程 + 一变量。
- 交错执行的所有可能 → 状态空间爆炸的直觉。
- 顺序一致性 vs 真实内存模型差异。
- 「万恶之源」：并发 bug 的不可重现性。

## L6 程序就是状态机
- 程序 = 状态 + 初始状态 + 状态转移函数。
- 用状态机为 shell/解释器建模：事件驱动循环。
- 确定性程序、交互程序与并发程序的统一视图。
- MiniLab-1：实现一个迷你 shell/RTM 状态机。

## L7 中断、异常与系统调用
- 硬件事件→向量表→处理程序的统一控制转移机制。
- 系统调用是「受控的主动异常」。
- 上下文保存与栈切换：内核栈 vs 用户栈。
- 从 CPU 视角解释 OS 如何夺回控制权。

## L8 操作系统对象总览
- OS 面向应用提供对象：进程/线程、地址空间、文件、设备。
- 每个对象一组系统调用 API；句柄是统一引用方式。
- 「虚拟化硬件 + 提供服务」双重身份再确认。

## L9 进程与线程
- 进程 = 执行上下文 + 地址空间；线程 = 调度单元。
- 上下文切换的最小状态；协程是用户态轻量切换。
- fork 语义与写时复制。
- MiniLab-2：百行协程（co-rtm 风格），体会切换的「美妙与可怕」。

## L10 调度
- 指标：吞吐/周转/响应/公平；FIFO→SJF→MLFQ→彩票调度。
- 上下文切换开销对调度的约束。
- 实时调度 EDF 与优先级反转。

## L11 同步
- 原子性与临界区：从关中断到自旋锁/互斥锁。
- 信号量与条件变量；生产者-消费者。
- 死锁四条件与打破策略。
- 并发 bug 调试：TSan、日志与模型检查简介。

## L12 经典问题与无锁初步
- 读者-写者、哲学家进餐的形式化推理。
- 屏障与流水线同步模式。
- CAS 循环无锁队列：正确性与 ABA。
- 锁 vs 无锁的选择标准。

## L13 内存管理 I
- 地址空间抽象与重定位（编译/加载/运行三时机）。
- 分段与分页：内部/外部碎片权衡。
- 页表、TLB 与多级页表。
- 与 CS61C/CSAPP Ch.9 对齐再加深。

## L14 内存管理 II
- 虚拟内存机制：按需装页、反转页表。
- 缺页处理全流程走查（含 swap）。
- 共享内存与内存映射文件。
- OSLab 视角：内核要为每进程维护什么。

## L15 内存管理 III
- 局部性与工作集模型。
- 置换算法：OPT/FIFO/Clock/LRU 近似。
- 抖动与 OOM 处理策略。
- 案例：Linux 回收与 swap 机制速览。

## L16 存储
- 从 1-bit 器件讲起：SRAM→DRAM→Flash→磁盘。
- 磁盘调度与 SSD 的 FTL/擦除语义。
- 存储栈层次与每层接口。
- 为文件系统讲次铺垫设备抽象。

## L17 文件系统
- 统一接口与 inode/目录/链接语义。
- 分配（位图/链表/extent）与元数据一致性。
- 日志与崩溃一致性（redo/checkpoint）。
- MiniLab-5：精读微软 FAT 规范并实现迷你 myfat。

## L18 设备驱动与 I/O
- 端口/内存映射 I/O、中断与 DMA 三板斧。
- 驱动抽象：字符/块设备与统一文件视图。
- I/O 栈的缓冲与旁路（io_uring 导览）。

## L19 OS 设计与工程复盘
- OSLab 主线：从 boot 到 mini OS（内存→进程→文件逐层搭建）。
- 内核分层：异常入口/调度/内存/文件系统/驱动。
- 设计权衡记录：为什么选简单正确而非高性能。
- 对照 xv6（6.S081）与 Pintos（CS162）三种实现哲学。

## L20 总结与延伸
- 读源码、查手册：系统工作者的基本功回顾。
- 状态机 + 抽象 + 层化：贯穿全课的思维工具。
- 延伸路线：内核社区、15445、6.824、Rust for Linux。
