## 为什么学

- csdiy 收录的首门国内自主课程：蒋老师以 Hacker 风格现场写代码，「程序是状态机」「OS 是对象 + API」的讲述视角独此一家。
- 为讲透动态链接可专门手写迷你可执行文件与二进制工具链，解决大量「困扰多年」的底层疑问。
- 5 个 MiniLab + 4 个 OSLab 梯度极好：百行协程实验即可体验上下文切换之美，且大多可本地自测，无评测机也能自学。
- 中文授课 + 完整课件开源，是国内课程中理论与实践平衡度最高的 OS 课。
