# HITOS 讲义骨架（notes/outline.md）

> 每讲 3–5 条要点，骨架级。

## L1 揭开操作系统的面纱
- 从「弱弱地问，什么是操作系统」出发：OS 是覆盖硬件的虚拟机。
- 裸机启动第一步：BIOS→bootsect→setup→head 的 0.11 引导链。
- 中断是 OS 存在的物理前提：没有中断就没有多道程序。
- 实验环境：Linux 环境下配置 bochs + gcc 老工具链编译 0.11。

## L2 程序如何进入内存
- 80x86 实模式→保护模式：段基址 + 偏移的地址形成方式。
- GDT/LDT 与段选择子：0.11 的段机制极简用法。
- 分页初探：页目录/页表两级映射。
- 小实验：物理/逻辑地址换算与段页手工推演。

## L3 进程的创建
- 从 CPU 执行程序直观引出「进程」概念。
- task_struct 是进程的全部：状态/计数器/优先级/mm。
- fork 的流程：复制页表、写时复制 COW 机制。
- 大实验方向：跟踪一次 fork 的完整内核路径。

## L4 进程的调度
- 调度队列与 timer_list：时钟中断驱动的时间片消耗。
- goodness 重计算与优先级调度实现逐行读。
- schedule()：选择下一个进程并切换。
- 与 OSTEP 调度章节对照，理解策略与机制分离。

## L5 进程的切换与终止
- 上下文切换：内核栈与 switch_to 宏。
- wait/exit：孤儿、僵尸与 do_exit 清理顺序。
- 系统调用 int 0x80 在进程管理中的入口作用。

## L6 内存管理（上）
- 物理内存管理：mem_map 数组与页引用计数。
- 逻辑地址→线性→物理三级转换在 0.11 中的实现。
- _get_free_page/free_page 与内存分配路径。
- 大实验方向：内存模块阅读与打印页表实验。

## L7 内存管理（下）
- 页面置换：交换区、swap 与原 0.11 简化实现的差距。
- vmalloc vs malloc：虚拟连续与物理连续。
- memory.c 核心函数走读（find_area、unuse_memory）。
- OSTEP 虚存章节补理论：局部性与工作集。

## L8 文件系统
- 块设备与缓冲区：buffer_head、LRU 清洗队列。
- 超级块/inode/目录项三件套的 0.11 实现。
- open/read/write 全链路：从系统调用到块读写。
- 大实验方向：文件系统模块与 minix 格式剖析。

## L9 中断机制与系统调用
- IDT 与 traps.c：中断描述表初始化。
- system_call.s：参数传递、返回与错误处理。
- 一次 printf 的全旅程：库→syscall→内核→驱动。
- 小实验：跟踪中断计数与自定义系统调用。

## L10 输入输出系统
- I/O 端口与 in/out 指令；字符设备 vs 块设备。
- 键盘中断与 tty 行规程：从按键到 shell 字符。
- 终端是「文件」的抽象意义。
- 驱动框架初印象：0.11 的 chr_drv/blk_drv。

## L11 Linux 实例串讲
- 「按下回车到输出结果」贯穿全栈复盘：中断/进程/内存/FS/IO 全部到场。
- 0.11 与现代 Linux 的结构对照：哪些演化、哪些不变。
- 读内核代码的方法论：cscope/gdb/qemu 调试组合。

## L12 总复习
- 四大设计主题复述：抽象、并发、缓存、容错。
- 12 个实验核心结论汇总。
- 后续路线：NJUOS/6.S081/CS162 如何选。
