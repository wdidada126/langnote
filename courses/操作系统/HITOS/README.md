## 为什么学

- 中文 OS 公开课的口碑之王：知乎「操作系统如何自学」类问题高赞推荐常客。
- 站在学生角度循循善诱：从「弱弱地问，什么是操作系统」揭盖，从 CPU 直观引出进程，从「让程序进入内存」引出内存管理。
- 以真实工业代码 Linux 0.11（约两万行）为教材逐函数走读，理论实践结合，八小四大共 12 个实验。
- 是通往 NJUOS/6.S081/CS162 的最佳中文前置：先跟李老师把 0.11 读透，再上更强 Lab 会轻松很多。

## 最新年份讲义章节目录表（MOOC 版 8 单元骨架，对应视频分集）

| 讲次 | 标题 | 阅读材料 |
| --- | --- | --- |
| L1 | 揭开操作系统的面纱：什么是 OS、启动与中断初探 | 《Linux 内核完全注释》Ch.1–2 |
| L2 | 从程序进入内存谈起：80x86 寻址、段机制与内存布局 | 内核完全注释 Ch.3；0.11 bootsect/setup 源码 |
| L3 | 进程的创建：task_struct、fork 与写时复制 | 0.11 kernel/fork.c、sched.c |
| L4 | 进程的计划与调度：调度队列、时钟中断与优先级 | 0.11 schedule() 源码精读 |
| L5 | 进程的切换与终止：上下文切换、wait/exit | 0.11 相关源码 + OSTEP Ch.3/8 |
| L6 | 内存管理（上）：分页分段、物理内存与 Buddy 初探 | 0.11 mm/memory.c |
| L7 | 内存管理（下）：逻辑地址到物理地址、vmalloc、页面置换 | OSTEP Ch.9–12；0.11 malloc 源码 |
