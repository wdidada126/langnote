# L02 数据的机器级表示（I）：位运算与整数（补码/溢出）

> 阅读材料：CSAPP 2.1–2.3、2.10 ｜ Data Lab 发布

## 核心概念

### 1. 位运算与移位
```c
~a        // 按位取反    a & 0xFF 屏蔽高位    a | b 置位    a ^ b 翻转/比较
a << k    // 左移，低位补 0
(int)0x87654321 >> 4        // 算术右移：符号扩展 → 0xF8765432
(unsigned)0x87654321 >> 4  // 逻辑右移：补 0     → 0x08765432
```
- C 中 `>>` 对有符号数是实现定义（实践中 GCC/MSVC 均算术右移），对无符号数逻辑右移。
- 位级技巧是 Data Lab 的全部：用 `^` 做选择、用 `&` 提取域、用掩码防溢出。

### 2. 无符号数：模 2^w 算术
`b2u_w(Σ x_i 2^i)`，取值 `[0, 2^w-1]`。
- 加/减/乘结果一律 **模 2^w**：`unsigned` 下溢会回绕成巨大正数。
```c
unsigned subtractu(unsigned x, unsigned y) { return x - y; }
// 若 x < y：返回 2^w + x - y；检测借位即 "结果是否回绕"
```

### 3. 补码（two's complement）：范围不对称
`b2t_w = -x_{w-1}·2^{w-1} + Σ_{i<w-1} x_i 2^i`，范围 `[Tmin, Tmax] = [-2^(w-1), 2^(w-1)-1]`。
```
   0x80000000 = -2147483648 (INT_MIN)   0x7FFFFFFF = 2147483647 (INT_MAX)
   Tmin 没有对应的正数 → -INT_MIN == INT_MIN（溢出！）
```
- 取负：`-x = ~x + 1`；减法等价于加负：`x - y = x + (~y + 1)`。

### 4. 扩展与截断
- 零扩展 `u2u`：直接补 0；符号扩展 `t2u`/`t2t`：补符号位。
  汇编里体现为 `movzbl`/`movsbl`/`movsbq`（L4 见）。
- 截断 `t2t` 高位丢失：`int16_t x = (int16_t)333;  → 77`（333-256）。

### 5. 溢出判定（核心公式）
```
加法正溢出: x>0 && y>0 && (x+y)<=0
加法负溢出: x<0 && y<0 && (x+y)>=0
```
```c
int add_ok(int x, int y) {          // 安全加法：溢出返回 0
    long long s = (long long)x + y;
    return (s >= INT_MIN && s <= INT_MAX) ? x + y : 0;
}
```
- 补码加/减法**溢出可交换**：`(x+y)+z` 与 `x+(y+z)` 的位级结果相同（模 2^w 群）。

### 6. 表达式混合类型：无符号"黑洞"
```c
int x = -1;
unsigned u = 0;
x < u      // 真? —— 否！int 被隐式转成 unsigned，比较为 0xFFFFFFFF < 0 → 假
sizeof(x)  // size_t 即 unsigned long → 整个表达式变成无符号算术
```
2.10 的"陷阱与提示"必须精读：signed/unsigned 混用是历史上无数 CVE 的根源
（如长度检查 `len >= 0 || len < MAX` 因无符号恒真而失效）。

## 图示：位向量 → 数值
```
位向量   x7 x6 x5 x4 x3 x2 x1 x0      (w=8)
十六进制  1    0   1   1   0   0   1   0  = 0xB2
无符号    128+32+16+2                = 178
补码      178 - 256                  = -78
```

## 开源项目中的应用
- **glibc `assert.h` / `-ftrapv`**：溢出检测开关。
- **protobuf varint**：用 7 位一组 + 续位编码整数，本质是位运算流水线。
- **Linux 内核 `check_add_overflow()`**（kern.h 安全算术族）：现代内核防整数回绕。
- **xxHash/murmurhash**：`rotl/xor/mul` 位混合。
