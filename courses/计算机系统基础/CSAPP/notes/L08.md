# L08 处理器与硬件：Y86-64 HCL 模型、模拟器

> 阅读材料：CSAPP Ch.4（重点 4.1–4.5）｜ Architecture Lab 发布

## 核心概念

### 1. 从"软件视角"切换到"硬件视角"
前三讲汇编只谈 ISA；本讲回答"**一条指令的每个周期里发生了什么**"。
CSAPP 用玩具指令集 **Y86-64**（x86-64 极简子集：irmrro 六种格式、15 寄存器、
opF 双字段编码）剥离历史包袱，直达 CPU 设计本质。

### 2. 硬件描述语言 HCL：组合逻辑的"代数"
```
bool  Expr1 bool Expr2        // 与：两侧同真
bool  [ [Expr1]: (Cond1); ... ]  // 多路复用 mux（case 语义）
word  [ [Expr1]: (Cond1); ... ]
bool  Cond  ? Expr1 : Expr2   // if 三目
HW 信号即变量：先写方程，再"联立求解"出电路
```

### 3. 时钟化寄存器与硬件模型六阶段
```
CLK ┌──────────┐ 每个上升沿：i 端值 → r 端并锁存（一个周期不变）
    │ 寄存器    │
    └──────────┘
组合逻辑（ALU/mux/译码器）在两个寄存器之间"当拍算完"。
通用模型：pc ← 取指 ← 译码 → 读寄存器 → 执行(ALU) → 访存 → 写回 → 更新PC
Y86 关键信号: PC, i(指令), im/ie/ia(立即数/寄存器号), valA/valB, aluA/aluB,
             valE/valM, Stat(状态码 AOK/HLT/除零等), CC(条件码)
```

### 4. SEQ（单周期顺序实现）
- 每周期一条指令走完全部阶段；控制逻辑 = 每信号的 HCL 方程 + `Stat/Instr` 译码。
- `CC = set_cc(icode, valP, valE)`；分支条件用 `Cnd` 信号查表（呼应 L05 条件码！）。
- 缺陷：频率被最慢指令（iqle/跳转访存）拖死 → 流水线动机。

### 5. 流水线（概念层，Lab 实现）
```
IF | ID | EX | MEM | WB 五级，寄存器级间锁存（IF/ID, ID/EX...）
冒险三类:
  控制冒险: 分支未定就取错路 → 预测 + 误预测回滚（squash/气泡）
  数据冒险: 后指令要用前指令未回写的值 → 转发(forwarding/bypass)
  结构冒险: 同一硬件被争用 → 拆分端口(哈佛: 取指/访存分离)
异常: 用"信号随流水线传递 + 提交阶段(POP)"处理，避免中途改状态
```
- Architecture Lab：改 HCL 加 `iaddq`/`RRURQ` 等，跑 SSIM/OCSIM 验正确率与 CPI。

### 6. 本讲与真实世界
真实 x86：14 级+微操作、乱序发射（ROB/scheduler）、超线程——本讲只到
"顺序流水"为止，为 L09/L11"为什么指令级并行有上限"提供硬件依据。
