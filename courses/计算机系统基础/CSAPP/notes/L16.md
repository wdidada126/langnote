# L16 虚拟内存：地址空间、页表与 VM 系统调用

> 阅读材料：CSAPP 9.1–9.8 ｜ 全书压轴章，Ch.9 前半 ｜ 承 L13 装载、L10 缓存

## 核心概念

### 1. 两大角色
```
角色1: 主存的高速缓存(超大块) —— DRAM 是磁盘的缓存, TLB 是页表的缓存
角色2: 进程地址空间的抽象 —— 每进程独占、连续、可保护的假象(L01 兑现)
保护: 页表项 PTE 权限位(U/S, R/W, X)；违规 → 故障 → SIGSEGV/内核补页
共享: 多进程页表项指向同一物理页帧(代码段、mmap 共享内存、fork 的 COW)
```

### 2. 地址翻译全链路
```
CPU 生成虚拟地址 LA ──[MMU: TLB 命中?]──→ PA 物理地址 ──[缓存/内存层次 L10]
TLB miss → 页表遍历(page walk, 硬件/混合) → 仍缺 → 缺页异常(OS: 换入/分配)
多级页表: x86-64 4~5 级(PL4/PDPT/PD/PT)；稀疏地址空间 → 树压缩
```

### 3. Linux 地址空间布局（用户态，呼应 L12/L13 段）
```
0xFFFFFFFFFFFFFFFF ┌──────────┐ 内核(不可触碰)
                   │ 栈(向下)  │ 默认 8MB ulimit -s；guard page 防溢出
                   │ mmap 区   │ 共享库/匿名映射/文件映射 —— L13 装载就在这
                   │ 堆(break) │ brk 上下移；malloc 的地基(L17)
                   │ .bss/.data│ 未初始化/初始化全局
                   │ .text     │ 只读可执行
0                  └──────────┘
cat /proc/self/maps 现场观察；NULL 页故意不映射 → 空指针即 SIGSEGV
```

### 4. VM 作为缓存：缺页与抖动
```
命中(驻留位=1): 硬件翻译, 零额外开销
缺页: 类型=映射缺失(非法地址→段错误) / 换出(合法但不在内存→major fault)
替换: 工作集(working set)模型；局部性 → LRU/时钟近似;
抖动(thrash): 并发进程工作集总和 > 物理内存 → 吞吐悬崖(呼应 L10 颠簸)
```

### 5. 系统调用接口
```c
mmap(addr, len, PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
     // 建立映射: 匿名堆扩展 / 文件映射读盘 / MAP_SHARED 进程通信
munmap / mprotect(改权限, 写时保护用) / madvise(建议: 顺序读/不再用)
brk 移动堆顶(旧式, malloc 已少用)
fork → 子进程页表私有副本, 物理页只读共享 → 任一写 → COW 缺页复制
execve → 推倒重来, 新页表新映射(L13/L14 的完整图景)
```

### 6. 动态内存分配预告（malloc 与 mmap 的边界）
- 小分配走 brk 堆扩张；大块（默认 ≥128KB）直接 mmap 独立区域，free 即 munmap。

## 开源项目中的应用
- **Linux `mm/`**：`mmap.c`、缺页路径 `do_fault`、THP 透明大页。
- **jemalloc/mimalloc**：直接向 OS 要 2MB 区域（`madvise(MADV_HUGEPAGE)` 提升 TLB 命中）。
- **Redis RDB/AOF**：`mmap`? 现代 Redis 用 write+fsync；但 BGSAVE 依赖 fork+COW
  做无锁快照——fork 的 COW 成本即本讲知识。
- **数据库缓冲池/OS 页缓存**：`posix_fadvise` 提示。
