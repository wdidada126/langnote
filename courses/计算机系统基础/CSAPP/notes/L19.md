# L19 网络编程：客户端-服务器模型与 Sockets

> 阅读材料：CSAPP Ch.11 ｜ Proxy Lab 发布 ｜ 承 L18（socket 也是 fd）

## 核心概念

### 1. C/S 模型与"网络即文件"
```
客户端: 发起连接, 请求服务    服务器: 等待连接, 循环服务
一条网络连接 = 一对 Socket(套接字): 客户端端点 + 服务器端点
两端各持一个 fd → read/write 直接收发字节流(L18 全套语义适用: 短读/EINTR/EOF)
```

### 2. Internet = IP + TCP/UDP
```
IP: 尽力而为、无连接、不可靠、分段; 地址 32bit(v4)/128bit(v6), 点分十进制
端口: 16bit; 知名端口 <1024(需 root); (IP, port) = 套接字地址
TCP: 可靠、连接、全双工、字节流(粘包边界要自己管 → HTTP 用长度头/空行)
UDP: 不可靠、数据报 —— 本章不展开但 6.824/游戏服务器常用
```

### 3. 地址转换三件套（别再用已废弃的 gethostbyname）
```c
struct addrinfo hints = {.ai_family=AF_INET, .ai_socktype=SOCK_STREAM};
getaddrinfo("www.example.com", "80", &hints, &res);  // 域名+服务名 → 地址列表
getnameinfo(...);          // 反向; inet_ntop/pton: 文本↔二进制地址
sa_family: AF_INET(v4) / AF_INET6(v6) / AF_LOCAL(同机 Unix socket 也走此 API!)
```

### 4. 服务器骨架（CSAPP open_clientfd/open_listenfd 模板）
```c
/* 服务器 */
int listenfd = open_listenfd("8000");           // socket→setsockopt(SO_REUSEADDR)
for (;;) {                                       //        →bind→listen(backlog)
    int connfd = accept(listenfd, ...);          // 阻塞等连接, 返回已连接 fd
    rio_writen(connfd, "HTTP/1.0 200 OK\r\n\r\nhi\r\n", 28);  // 或直接 write
    close(connfd);                               // 不关 → fd 泄漏
}
/* 客户端 */
int fd = open_clientfd("localhost", "8000");     // socket→connect(路由可达?)
rio_readlineb(fd, buf, MAXLINE);                 // 读到 \n 为止: 协议行
close(fd);
```
- 错误文化：`connect` 可能阻塞/重试（SYN 超时）；`bind` 失败 98 = EADDRINUSE
  → 服务器都应设 `SO_REUSEADDR`。

### 5. Web 基础：一次 HTTP 事务
```
URL: scheme://host:port/path?query
浏览器 → DNS(L19 的 getaddrinfo) → TCP 连接 → 请求:
  GET /home/csapp/www/index.html HTTP/1.0\r\n\r\n
服务器响应:
  HTTP/1.0 200 OK\r\nContent-Type: text/html\r\nContent-Length: 86\r\n\r\n<正文>
Transaction = 连接+请求+响应; Proxy Lab 的 tiny server: 解析请求行/头 →
  本地文件则转发内容, http:// 前缀则再当客户端去取上游
```

### 6. 单线程服务器的致命串行（引出 L20）
- 本讲循环 accept→服务→close：一次只服务一人 → 长请求阻塞所有人。
- 解法：进程/IO 多路复用（select/poll/**epoll**）/线程 —— Proxy Lab 三种都要实现。

- **Nginx**：epoll 事件驱动 + 非阻塞 socket（`ngx_event_connect_peer`）。

- **gRPC**：HTTP/2 多路复用解决"粘包与队头阻塞"的现代答案。
