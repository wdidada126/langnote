# L10 存储器层次结构与缓存

> 阅读材料：CSAPP Ch.6 ｜ Cache Lab 发布 ｜ 本讲起进入"存储系统"篇

## 核心概念

### 1. 技术谱系
```
SRAM(6管触发器, ~几 ns, 贵)  → L1/L2/L3
DRAM(电容+行/列地址, ~几十 ns, 需刷新) → 主存；SDRAM: 与总线时钟同步
NAND Flash（页读/块擦） → SSD；摩擦来自"擦除粒度 >> 读粒度"
旋转磁盘：寻道+旋转延迟，顺序读写差距 100 倍
```

### 2. 局部性（Locality）——整个层次结构存在的理由
- 时间局部性：刚用过的还会再用（循环变量）。
- 空间局部性：邻居将很快被用（顺序扫描、行主序矩阵）。
```c
// sum 按行遍历 a[i][j]（空间局部性好）  vs 按列 a[j][i]（每次跨行→缓存颠簸）
for (i=0;i<n;i++) for (j=0;j<n;j++) sum += a[i][j];   // 快
for (j=0;j<n;j++) for (i=0;i<n;i++) sum += a[i][j];   // 慢数倍~数十倍
```

### 3. 通用缓存模型
```
缓存：S 组 × E 行/组 × B 字节/行；总容量 = S·E·B
地址切分: [ t 标记 | s 组号 | b 块内偏移 ]，s = log2(S)
命中判据: 标记匹配 && 行有效
替换: LRU / FIFO / 随机（E=1 直接映射免替换）
写策略: 写直达(write-through) vs 写回(write-back, 脏位)；
        非分配(no-allocate) vs 写分配(write-allocate, 现代默认拉行入缓)
```

### 4. 真实缓存细节
- L1 分离：I-Cache + D-Cache（L04~L07 的取指与数据正好分道）。
- 包含性：L1/L2 inclusive、L3 常 non-inclusive（影响共享一致性协议）。
- **伪共享(false sharing)**：多线程各写各的变量却落在同一 64B 行 → 缓存行来回
  弹跳；解法：`__attribute__((aligned(64)))` / padding。
- 冲突不命中：步长 = 缓存行×组数的倍数 → 颠簸；解法：数组 padding 到奇数行长、分块。

### 5. 重排遍历与分块（blocking）
```c
// 矩阵乘：ijk 顺序决定复用模式；分块(tiling)把工作集压进 L1
for (i0=0;i0<n;i0+=C) for (j0=0;j0<n;j0+=C) for (k0=0;k0<n;k0+=C)
  for (i=i0;i<i0+C;i++) for (j=j0;j<j0+C;j++) for (k=k0;k<k0+C;k++)
     c[i][j] += a[i][k]*b[k][j];
```
- Cache Lab 的两件事：写组相联模拟器（读 trace 报命中率）+ 分块矩阵转置。

### 6. 性能影响量化
```
未命中代价: L2 ~ 12 周期; L3 ~ 40; 主存 ~ 200+(数百周期) → 一次 DRAM 往返
≈ 执行数百条指令；所以"少访存" > "少算"。
硬件预取(prefetcher)顺序流式识别 → 顺序遍历比链表快 10 倍不止。
```
