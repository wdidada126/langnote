# L03 数据的机器级表示（II）：浮点数与 IEEE 754

> 阅读材料：CSAPP 2.4 ｜ 承 L02 位运算；Data Lab 浮点题

## 核心概念

### 1. IEEE 754 三域编码
单精度 32 位 = `1 符号 s | 8 阶码 exp | 23 小数 frac`；双精度 64 位 = `1 | 11 | 52`。
```
V = (-1)^s × M × 2^E
三种模式：
  规格化   exp≠全0/全1: E = exp - bias, M = 1.frac（隐含前导 1）
  非规格化 exp=0:      E = 1 - bias,   M = 0.frac（表示 0 与 ±最小数，平滑下溢）
  特殊值   exp=全1:    frac=0 → ±Inf;  frac≠0 → NaN
bias：float 127，double 1023
```
```
float 13.0 = 0x41500000:  s=0 exp=130→E=3, M=1.625, 1.625×8=13
最小规格化 float = 2^-126；最小非规格化 = 2^-149
```

### 2. 舍入（round-to-even 默认）
- 4 种舍入模式：向偶数/向 +∞/向 -∞/向零。默认"向偶数"避免长期统计偏差。
- 库函数转换：`round`(远离0)、`trunc`、`floor/ceil`；C 强转 `(int)` 是向零截断。

### 3. 浮点运算不满足结合律/分配律
```c
float f1 = (1e20f + -1e20f) + 3.0f;   // = 3.0
float f2 = 1e20f + (-1e20f + 3.0f);   // = 0.0  (3.0 被吞)
1e20f * (1e-20f + 1e-20f) != 1e20f*1e-20f + 1e20f*1e-20f  // 可能不等
// x >= 0 为假 ⇒ x < 0 未必真：x = NaN 时两个比较都为假！
```
- 编译器默认**不敢**按实数代数重排浮点表达式；`-ffast-math`(GCC)/`/fp:fast`(MSVC)
  才会，代价是 NaN/Inf 语义被破坏。

### 4. 二进制小数：很多十进制精确值不可表示
`0.1 = 0.0001100110011...₂`（无限循环）→ `0.1+0.2 != 0.3` 的经典事故。

### 5. 位级把玩浮点数（Data Lab 风格，不动 FP 单元）
```c
unsigned float_neg(unsigned uf) {         // 取负 = 翻符号位
    return uf ^ 0x80000000u;
}
unsigned float_abs(unsigned uf) {         // NaN 需保持（最高 9 位全 1 才判 NaN）
    if (uf > 0x7F800000u) return uf;      // NaN
    return uf & 0x7FFFFFFFu;
}
int float_le(unsigned x, unsigned y) {    // 无符号序比较实现 <=（含 -0==+0 处理）
    unsigned ux = x, uy = y;
    if (ux == 0x80000000u) ux = 0;        // -0 → +0
    if (uy == 0x80000000u) uy = 0;
    if ((int)(ux ^ uy) < 0) return (int)ux < (int)uy;  // 符号不同
    return ux <= uy;                       // 同号时位模式即数值序
}
```

## 图示：浮点轴
```
 -Inf  ...  最大负非规格化  -0  +0  最小正非规格化 ...  最大正规格化  +Inf
        非规格化区(间距=2^-149, 均匀)   规格化区(间距随量级指数增长)
```
数轴"近密远疏"：绝对误差随量级放大 → 数值算法用**相对误差**与 `epsilon≈2^-23`。
