# L04 机器级程序（I）：x86-64 寄存器、操作数与算术

> 阅读材料：CSAPP 3.1–3.6 ｜ Bomb Lab 发布

## 核心概念

### 1. 编译流水线与本讲视角
```
C → (cc1) → .s 汇编 → (as) → .o → (ld) → a.out
objdump -d a.out      # 反汇编；gcc -Og -S x.c -o x.s 看生成汇编
```
- 学习汇编不是为了写，而是为了**读**：调试优化代码、看懂 Crash、做安全分析。

### 2. 数据宽度与寄存器
宽度：`b(1) w(2) l(4) q(8)` 字节。
```
16 个 64 位通用寄存器：
 %rax(返回值) %rbx %rcx(第4参) %rdx(第3参) %rsi(第2参) %rdi(第1参)
 %rbp(帧基址,可选) %rsp(栈指针) %r8~%r15(第5~8参/临时)
低 32 位可独立寻址：eax...r15d；写 32 位子寄存器会将高 32 位清零。
```

### 3. 操作数（寻址）三种形式
```
立即数   $0x123 / 符号
寄存器   %rbp
内存     Imm(rb, ri, s) → 地址 = Imm + R[rb] + R[ri]×s, s∈{1,2,4,8}
  movq %rax, (%rbx)         [rbx]        数据段指针访问
  leaq 8(%rbp,%rdx,4), %rax  8+rbp+rdx*4  仅算地址，不访存（LEA 的妙用见下）
```

### 4. 数据传送
```
movb/w/l/q     源→目的（不允许内存→内存直传）
movzbl/movzwl/movzq   零扩展（对应 L02 无符号扩展）
movsbl/movsq  符号扩展（对应补码扩展）
movabsq $0x1122334455667788, %rax   # 64 位立即数专用
pushq/popq   栈顶压/弹（等价 rsp 减/增 8 + movq）
```

### 5. 算术与逻辑（重点：一条指令服务 signed/unsigned）
```
addq/subq/imulq(有符号,低位)/mulq(无符号,结果入 rdx:rax 双字)
imulq $3, %rdi, %rax   三操作数形式：src*3 → dst
incq/decq/negq/notq
andq/orq/xorq/testq(按位与，只置标志不存结果，常比较 0)/cmpq(减法，只置标志)
sal/sar/shr  左移/算术右移/逻辑右移；sar 保持符号位（L02 的算术右移）
```
- `cmpq src2, src1`（AT&T 操作数序与 Intel 相反，**前→后 = 后-前**）。
- 乘常数优化：`imulq $5` → `leaq (%rdi,%rdi,4), %rax`（1 指令 1 周期）。

### 6. 特殊 ALU：`leaq` 的"地址计算复用"
```asm
leaq (%rdi,%rsi), %rax       # rax = x + y            (rdi=x, rsi=y)
leaq 7(%rdx,%rdx,4), %rax    # rax = 5*rdx + 7        (%rdx + 4*%rdx + 7)
leaq (%rdi,%rdi,2), %rax     # rax = 3*x
leaq (%rax,%rsi,8), %rax     # rax = 3x + 8y          —— 编译器拿 leaq 当廉价三输入 ALU
```
一条 `leaq` 可同时完成「乘 1/2/4/8 + 加 + 加常数」，多数情况下只改目标寄存器、
**不置条件标志**，是编译器做强度削减（用 lea 代替 imul/add 链）的首选。

### 7. 典型读图练习（Bomb phase 0 风格）
```asm
4011e0: sub $0x28,%rsp
4011e4: mov %fs:0x28,%rax      ← 栈金丝雀 stack-guard 载入
4011ed: mov %rax,0x18(%rsp)    ← 存到帧内
...
40121c: mov 0x18(%rsp),%rcx
401221: xor %fs:0x28,%rcx      ← 退出前比对
401229: call __stack_chk_fail  ← 不匹配即炸（-fstack-protector）
```

## 与前后讲联系
- 本讲是 L05 控制流、L06 栈帧、L07 结构的词汇表；所有分支/过程建立在 mov/cmp/lea 上。
- `movsb/movzb` 对应 L02 扩展；条件标志在 L05 展开。

## 开源项目中的应用
- **Linux 内核 `arch/x86/entry/entry_64.S`**：系统调用入口就是手写汇编范本。
- **glibc `memcpy`/`strlen`**：AVX 手写汇编路径（`sysdeps/x86_64/multiarch`）。
- **V8 TurboFan / LuaJIT**：JIT 生成的正是本讲这类指令序列。
- **objdump/binutils、Ghidra**：读汇编的日常工具。
