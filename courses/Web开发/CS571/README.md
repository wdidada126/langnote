## 2. 为什么学

- React 前端 + React Native 移动端最佳实践的系统训练：完整又提纲挈领，且采用最新版本（含函数组件/Hooks 新范式）。
- 业界少见的"每学期更新"高校 UI 课：技术栈紧跟 React 18/19、Expo、Navigation 新版。
- 不手把手写代码的作业设计（对比 Udemy 式课程）：starter code 起点恰当，逼你独立查文档实现——贴近真实工程。
- 附带 Google Dialogflow 聊天机器人开发与 UX 设计原则模块，超出纯 React 的视野。
- 全学期大作业贯穿式：从单页 UI 一路做成可上线的完整 App。

## 3. 先修与知识联系

- **前置**：一门语言基础 + 基本 Web 概念；JS 语法课内有限覆盖（勤查 MDN/react.dev）。
- **对照**：fullstackopen（后端更完整）、CS142（工程视角）、mitweb（入门）。
- **衔接**：UX 模块联系交互设计；Dialogflow 联系 LLM 应用开发。
- **移动**：React Native 与原生（Android/iOS）桥接概念。
