## 2. 为什么学

- 全球最流行的免费全栈课之一：以 JavaScript 一镜到底（React 前端 + Node/Express 后端 + MongoDB/PostgreSQL）。
- 体系完整：测试（单元/集成/E2E）、CI/CD、容器、Git 工作流、TypeScript、GraphQL、React Native 全覆盖——企业开发流程的缩影。
- 练习驱动：每个 part 数十道编程练习 + 大作业（题库/博客/员工清单等），结课可产出完整作品集与证书（SUOL 学分可申请）。
- 中文翻译维护良好（/zh/ 路径），入门门槛低于 CS142。

## 3. 先修与知识联系

- **前置**：任意语言编程能力（mooc.fi Java/Python 课同级）；HTTP/网络基础；`必学工具/Git`。
- **对照**：mitweb（更快更浅的入门版）、CS142（工程严谨度更高）、CS571（React 单点纵深）。
- **衔接**：Part 14 的 PostgreSQL 可与 15445 数据库课互相印证；Part 12/13 联系容器与 DevOps。
