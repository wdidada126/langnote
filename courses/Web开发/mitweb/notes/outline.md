# MIT WebLab 逐讲要点（骨架）

## L01 Web 基础与环境
- 浏览器请求-响应模型：URL→DNS→HTTP→渲染的大图景。
- 开发环境：VS Code、本地服务器、浏览器 DevTools。
- Git/GitHub Pages 静态部署跑通"第一页"。

## L02 HTML
- 语义标签（header/nav/main/section）与文档结构。
- 表单元素：input/select/验证属性，GET/POST 差异。
- 可访问性与 SEO 基础（alt、heading 层级）。

## L03 CSS
- 选择器优先级、盒模型、定位。
- Flex/Grid 两套布局心智模型。
- 框架速览：Bootstrap 栅格 → 现代 Tailwind 思路。

## L04 JavaScript
- 类型系统与函数一等公民；ES6+（let/const、箭头、模块、解构）。
- DOM 查询与修改、事件监听与冒泡。
- 异步：回调→Promise→async/await 演进。

## L05 媒体与交互
- 图片/音视频嵌入与响应式媒体。
- Canvas 基础绘图。
- fetch 调第三方 API（当期常用：天气/视频接口）。

## L06 Node/Express 后端
- Node 运行时与 npm 生态。
- Express：路由、中间件链、静态资源、模板引擎。
- REST 初步：资源建模与状态码。

## L07 数据库
- NoSQL 文档模型：MongoDB + Mongoose schema。
- 与关系型(PostgreSQL)的建模对照与选型。
- 索引与查询性能初步。

## L08 会话与认证
- cookie/session/httpOnly 原理；登录状态管理。
- JWT 流程：签发-携带-校验。
- 安全基础：密码哈希（bcrypt）、CSRF/XSS 意识。

## L09 React 一瞥
- 组件与 JSX、props/state、受控表单。
- SPA 与路由概念。
- 与直接 DOM 操作的心智切换（声明式 UI）。

## L10 部署与运维
- 托管平台对比：Vercel/Render/传统 VPS。
- HTTPS 证书与环境变量管理。
- 性能清单：压缩、懒加载、缓存头。
