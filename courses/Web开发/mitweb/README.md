## 2. 为什么学

- 4 周从零到全栈：设计、搭建、美化、交互，覆盖 Web 前后端大部分核心技术栈。
- 以做中学：每周围绕一个可上线的小站迭代（视频/图片/表单/数据库），结课即有作品集。
- 短平快、无学分压力，适合把 Web 开发"加进技能包"的非目标专业同学。
- HTML/CSS/JS/Node/MongoDB 的第一站，之后再进 CS142/Full Stack Open 深度课程。

## 3. 先修与知识联系

- **编程**：任意语言基础（变量/函数/异步概念 helpful）；可先修 CS61A/CS50。
- **工具**：Git/GitHub（第一周即要求，对应 `必学工具/Git`）。
- **后续**：CS142（工程深度）、fullstackopen（React+Node 体系）、CS571（React 专精）。
- **横向**：计算机网络（HTTP/域名/证书）联系 `courses/计算机网络`。
