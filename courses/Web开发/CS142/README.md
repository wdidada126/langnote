## 2. 为什么学

- 斯坦福工程向 Web 应用课：HTML/CSS/JavaScript/React/Node.js/Express/Web 安全一条龙，讲"为什么这样设计"而不只是"怎么用"。
- 8 个 Project 在实战中滚动扩展同一个大应用（照片社交类站点），逼近真实产品。
- 相比 MIT WebLab 更强调工程体系：MVC、REST 设计、数据库建模、认证授权、性能与安全。
- 学完具备独立设计与实现完整 Web 系统的能力，是 fullstackopen 的" harder 模式"对照。

## 3. 先修与知识联系

- **编程**：至少一门语言扎实；异步与事件循环概念课程内补。
- **系统**：计算机网络（HTTP/TLS）、数据库（SQL/索引）可对照 `courses/计算机网络`、`courses/数据库系统/15445`。
- **对照**：fullstackopen（更细的 React/Node 教程）、CS571（React 纵深）。
- **安全**：与 `courses/系统安全/MIT6.858` Web 安全部分衔接。
