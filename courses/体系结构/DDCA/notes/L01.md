# L01 课程导论：从开关到计算机系统（Introduction）

> ETH DDCA（220.070）· Onur Mutlu · 参考阅读：Harris & Harris(H&H) Ch.1；Patt & Patel(P&P) Ch.1
> 对应 Lab：无（Lab 1 从 L02 后开始）

## 1. 核心概念

### 1.1 本课的世界观：抽象层次栈
DDCA 的主线是"每一层用下一层的构件 + 一个抽象接口解决复杂性"：

```
应用程序 / 操作系统
    ↑ ISA（指令集架构，软硬件契约）
单周期/流水线 CPU（微架构）
    ↑ 逻辑设计（FSM、datapath）
组合逻辑 + 时序逻辑（门电路）
    ↑ 开关模型（MOSFET 作为受控开关）
晶体管 → 硅与铜
```

P&P 教材从" NAND 一门走天下"切入：任何布尔函数都能用 NAND（或 NOR）复合实现，
因此"开关→逻辑门→组合/时序电路→LC-3 虚拟机"是一条可完整构造的链条。

### 1.2 二进制与信息编码
- 位（bit）是唯一可靠区分的物理状态（高/低电平，约 0 V / 约 1.8~3.3 V），这就是二进制统治数字世界的工程原因。
- n 位可编码 2^n 个状态；编码本身没有含义，含义来自约定：无符号、补码、BCD、ASCII/UTF、IEEE-754 浮点。
- H&H Ch.1 的表"同一串 11111111 在不同编码下是 255 / -1 / 0xFF"是本课第一堂"抽象课"。

### 1.3 数字系统的基本节拍
- 组合逻辑：输出只依赖当前输入（无记忆）。
- 时序逻辑：输出依赖当前输入 + 历史状态（有记忆，靠时钟推进）。
- 整个数字世界就是这两句话的排列组合，L02–L06 用五讲展开。

### 1.4 CMOS 反相器：物理层的第一性例子
两个 MOSFET（PMOS 上拉、NMOS 下拉）构成反相器：输入高→下管导通输出低；输入低→上管导通输出高。
静态时总有一管截止，故 CMOS 功耗主要来自动态翻转（P ≈ C·V²·f）——这一公式在 L11 功耗与频率墙、
L16 研究前沿中反复回响。

## 2. 与课程内外知识的衔接
- **CSAPP Ch.2/Ch.3/Ch.4**：CSAPP 从程序员视角看位级表示与机器语言；DDCA 从"这些位如何被门电路产生和存储"的硬件视角补齐下半程。本讲 P&P 的 LC-3 与 CSAPP 的 x86-64 是同一 ISA 概念的两个样本。
- **6.S081**：6.S081 Lab（如 mmap、页表）假设硬件已存在；本课 L09–L14 造出这个假设本身，之后 6.S081 的"软硬件接口"观会立体很多。
- **CS61C**：同一主题，Berkeley 风格快节奏带 C/并行/GPU；DDCA 更深更慢更电路化。
- **N2T**：N2T 从 NAND 门搭到编译器，与本讲 1.1 的栈自下而上对应；DDCA 则上下同时展开。
- **ETH CA（进阶）**：本课是官方先修，CA 假设你已能流畅读写 Verilog 并理解流水线。

## 3. 知识点在开源项目中的应用
- **RISC-V 生态总览**：ISA 契约思想 → [riscv-isa-manual](https://github.com/riscv/riscv-isa-manual)；课程用 MIPS 讲 ISA，但 2020 后工业界同型内容都在 RISC-V 上重演。
- **OpenHW Group / OpenTitan**：学习"抽象层次栈"最快的方式是看别人怎么分层开源：OpenTitan（安全 MCU）就是 规格→RTL→验证→物理 全栈开源样本。
- **XiangShan（香山）**：国产高性能 RISC-V 核，其文档的"前端/中端/后端"分层正是 1.1 栈的微架构段展开。
- **esp32 固件（ESP-IDF）**：最低门槛体验"软硬件契约"——GPIO/定时器寄存器手册就是 ISA 思想的外设版。

## 4. 本讲自查问题
1. 为什么物理层选择二值而不是十值？（噪声容限、开关可靠性）
2. 只用 NAND 能否构成带时钟的存储元件？（不能，需反馈环路→引出 L05）
3. P ≈ C·V²·f 中为什么降频节能如此显著？
