# L16 期末复习：从晶体管到完整系统的贯穿串讲 + 前沿研究导览（Review & Frontiers）

> 参考阅读：全部讲义回顾；Mutlu 研究组公开讲义/演讲
> 对应 Lab：无——检验标准：能在白板上从 CMOS 反相器讲到 MMU+cache 并自洽回答"为什么"

## 1. 核心概念：一张图收拢全课

### 1.1 贯穿串讲（每行回收一讲）
```
晶体管开关(L01) → 布尔代数/门(L02) → Mux/译码/加法器/ALU(L03)
  → Verilog/FPGA(L04) → 锁存/FF/时序约束/RF(L05) → FSM(L06)
  → RAM/ROM/补码/乘法(L07) → ISA 契约(L08) → 单周期(L09)
  → 多周期FSM控制(L10) → 流水/冒险/转发/预测(L11-12)
  → cache层次(L13) → 页表/TLB(L14) → 总线/中断/DMA/MMIO(L15) = SoC
```
三条贯穿设计哲学，考试与面试通用：
1. **抽象与契约**：ISA、总线协议、cache 对软件透明、PTE 权限位——层间只靠接口；
2. **局部性经济学**：所有层次结构（cache/TLB/DRAM 行缓冲/预取）都在赌 locality，账本是 AMAT；
3. **平行化换吞吐**：组合逻辑并行算、CLA/桶形移位器对数算、流水重叠算、超标量同时算——
   单周期→流水→乱序→多核是同一思想的四级放大。

### 1.2 高频考点自检
- 给定 lw 地址算 set/offset/TLB 命中（L13+L14 综合）；
- 5 段流水标出全部 RAW stall 与转发路径（L11+L12）；
- 画 FSM：序列检测/微操作控制表（L06+L10）；
- setup/hold 不等式求 fmax（L05）；
- RCA→CLA→流水寄存器切分点的延迟账（L03+L11 同一电路三次出场）。

### 1.3 前沿导览（Mutlu 特色：每讲留一页研究）
- **内存墙与近存计算**：DRAM 带宽增速 ≪ 算力增速（L13 账本外推）→ HBM/3D 堆叠、PIM（Samsung HBM-PIM、
  UPMEM）、预取与替换的机器学习化（SHiP/Perceptron 替换）。
- **RowHammer**（Mutlu 组代表作）：密集激活行引发电磁耦合翻转邻行位——**把"数字系统其实靠模拟物理活着"**
  写进安全议程；后续双侧 Hammer、TRR 缓解、PrimeCell——L01 噪声容限话题的惊悚回旋。
- **敏捷硬件**：Chisel/FIRRTL（Chipyard）、生成式验证（cocotb/Verilator/riscv-formal）——
  "软件人也能造芯片"的方法论，本课 Verilog 是其低配入口。
- **开源芯片现实水平**：XiangShan 南湖（RISC-V 高性能乱序，性能对标 Zen 3 级公开评测口径）、
  CVA6/PULP（中端实时）、OpenTitan（安全 MCU 量产）——开源已从玩具进入产品线。
- **异构与域专用**：GPU/NPU/脉动阵列（CS61C L19 视角）、RISC-V 向量扩展 RVV 让 SIMD 回归开源 ISA。
- **一致性/内存模型**：RVWMO 形式化、TSO↔弱序——6.S081 锁/无锁数据结构与 L12 乱序话题的理论终点（通往 CA/15-447/6.809）。

## 2. 与课程内外知识的衔接
- **CSAPP**：本课补齐 CSAPP 4/6/9 章的"下半身"；反向看，复习时应重做 CSAPP 6.6（matrix transpose）
  与 9.8 大题，体会"两门课同一份答案"。

  两课构成的"软硬件接口闭环"是自学路线里最完整的一对。
- **后续路线**：ETH CA（同教授，乱序/多核/GPU/内存系统深化）→ CMU 15-447（Patt 亲授体系结构进阶）→
  6.004/6.172；想动手：Chipyard 全栈跑通 + 给香山/RI5CY 提一个 PR。

## 3. 知识点在开源项目中的应用（导览版，逐项可深挖）
- **XiangShan 香山**：用 1.1 栈通读其文档架构章，每个方框应能叫出本课对应讲次（乱序调度≈L12 转发的一般化）。
- **Chipyard**：生成 Rocket/BOOM/SBOOM 配置对比"L09/L11/L12/L16 四级放大"在同一框架里的参数化。
- **PULP**：实时核系列（Ibex/CV32E40P）——低功耗嵌入式对 1.1 栈的裁剪答案（无 MMU、无预测器）。
- **cocotb + Verilator + riscv-formal + Spike + riscv-tests**：本课 projects/p05 之后接入的开源验证工具链五件套。
- **esp32**：以 C3（RV32IMC 量产核）为样本，把 L08 ISA、L13 cache、L15 中断/DMA 全部对上实物 datasheet。
- **OpenTitan / Caliptra**：安全芯片的"全栈开源 + 形式验证"范式——L02 形式验证种子的工业开花。
