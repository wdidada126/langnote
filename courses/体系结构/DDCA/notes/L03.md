## 1. 核心概念

### 1.1 加法器家族
- 半加器：S = A⊕B, Cout = A·B（两位一入，无低位进位）。
- 全加器：S = A⊕B·Cin 的完全展开 S = A⊕B⊕Cin，Cout = AB + Cin(A⊕B)。
- 行波进位加法器（RCA）：n 个全加器串联，**关键路径 = n×进位延迟**，O(n)。
- 超前进位加法器（CLA）：定义传播 P=A⊕B、生成 G=A·B，
  Cout[i+1] = G[i] + P[i]·Cout[i] ⇒ 进位可在 log 层级内并行算出（4 位组内全展开 + 组间级联），关键路径 O(log n)。
  RCA vs CLA 是本课第一个"面积换速度"权衡，L10 多周期、L13 cache 命中路径都会重演该权衡。

### 1.2 减法与补码预告
A − B = A + B' + 1（补码取反加一），减法器复用加法器＋mux 选择 B/B'＋Cin=1。
为什么成立？2 的补码下 −B ≡ 2^n − B，模 2^n 加法自然吸收溢出。详细证明见 L07。

### 1.3 多路选择器 Mux 与译码器
- 2^k 选 1 Mux：k 位选择 + 2^k 数据入 → 1 出；真值表即"受控开关阵列"。
- Mux 是**可编程连线**：F(A,B,C)=Σm(…) 直接接线 = LUT 思想，FPGA 的查找表(LUT4/LUT6) 就是 Mux+ROM，L04 FPGA 结构在此埋下伏笔。
- 译码器 Decoder：k 入 2^k 出，独热码；**先做使能端**(EN)再加输出缓冲三态。
- 编码器 Encoder 是逆操作；优先编码器（74148）处理多个 1 同时有效，"最高优先级胜出"——CPU 中断裁决器即此电路。

### 1.4 ALU：组合逻辑的"集大成模块"
ALU = {加/减/与/或/移位的并行阵列 + 输出 Mux 选择}，附带 Z/N/V/C 标志。
控制信号（ALUOp）位宽决定操作数，datapath 宽度决定吞吐——**同一结构，功能由选择线编码表决定**，
这是 L09 单周期 MIPS 数据通路的雏形。

### 1.5 比较器与扩展/截断
- 大小比较：逐位 CLA 式比较器（相等→高位优先）。
- 零扩展 vs 符号扩展：最高位复制——补码语义下才保持数值，预告 L07/L08。

## 2. 与课程内外知识的衔接
- **CSAPP 2.3**：CSAPP 讲 C 语言加法的溢出与无符号回绕，本质是 RCA 的模 2^n 语义；CF/OF 标志 = Cout 与"Cout⊕进位到符号位"。CSAPP Ch.4 的 Y86-64 ALU 与本讲 1.4 完全同构，可对照阅读。
- **内存层次衔接预告**：Mux 是 cache 选择线/way 选择的最小原语（L13 命中数据输出就是一个大 Mux）。
- **6.S081**：中断优先级编码 → 内核 trap 分发（picirq）的硬件侧解释。
- **CS61C/N2T/CA**：N2T 用 HDL 直接搭 16 位 ALU（Week 5）同本讲；CS61C 把它并进"数字设计周"；ETH CA 不再讲加法器本身，而讲它被流水化/被乘累加单元复用（MAC、DSP slice）。

## 3. 知识点在开源项目中的应用
- **projects/p01, p02**：本讲全部电路均有 Verilog 实现＋testbench（mux/decoder 真值表穷举；RCA vs CLA 延迟对照）。
- **PULP (pulp-platform)**：其 `apu`/MAC 单元是 1.4 ALU 的 DSP 化放大，看 RTL 可感受"mux 选择操作"模式的规模化。
- **XiangShan 香山**：`src/main/scala/xiangshan/backend/fu/ALU.scala` 用 Chisel 写加减逻辑移位——Chisel 即"可编程的 1.4"，Mux 树由 `switch/is` 生成。
- **esp32**：ESP32 的 GPIO 矩阵（GPIO Matrix）本质是巨型可编程 Mux 阵列，把外设信号任意连线——1.3 Mux 思想的片上实装，见 ESP-IDF `gpio_matrix.h`。

## 4. 常见坑
- Mux 选择信号是"地址"，数据入是"内容"——方向别画反。
- 三态总线：多个驱动同时有效 = 冲突（X），编码器/总线仲裁解决；仿真中出现 `xx` 先查多驱动。
- CLA 的 P 定义用 A⊕B 而非 A+B，两种定义进位公式不同（G/P 组协议须配套）。
