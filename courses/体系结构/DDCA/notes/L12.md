# L12 流水线（II）：控制冒险、转发与 MIPS 流水线实现（Pipelining II）

> 参考阅读：H&H Ch.7.3–7.5；课程 2023 Lecture 12–13
> 对应 Lab：Lab 9（完整流水线 CPU 上板）

## 1. 核心概念

### 1.1 转发（Forwarding / Bypassing）
EX/MEM 与 MEM/WB 寄存器输出经 Mux 接回 ALU 输入——把结果"抄近道"喂给后继指令，
消除 1.4（L11）里大部分 stall：
- ALU→ALU（add→add）：EX/MEM 转 EX，零停拍。
- Load→Use（lw→add 用其值）：数据 MEM 末才有，转回 EX 起点，后继仍必须停 1 拍——
  **load-use 冒险是 5 段流水唯一消不掉的结构性停顿**，编译器调度（提前 load）可隐藏。
转发路径本身引入关键路径：MEM/WB→EX Mux→ALU→EX/MEM，一长串组合逻辑常逼出"拆分 EX 段"。

### 1.2 控制冒险与三种对策
分支结果 EX 末才知道，而 IF/ID 已取错路指令 → 冲刷 2 条（误取代价=2 bubble）。
1. **静态不预测**：总预测不跳转，每分支罚 2 拍（课堂基线）。
2. **更早判定**：把 Zero 比较器挪到 ID 段（`beq rs,rt` 比较无需 ALU 结果）→ 罚 1 拍。
3. **分支预测**：向量法/BTB+方向/两位饱和计数器（L16 前沿）——预测错的代价 = 冲刷，
   对与错的概率决定平均 CPI。

### 1.3 冒险检测单元（Hazard Unit）
一张 4 信号真值表：{EX/MEM 写口=ID 读口 且 RegWrite 且非 R-type} 组合驱动 stall/flush。
把 L11 1.4 的每对指令分析固化成电路——设计者做表，电路查表，方法论胜利。

### 1.4 MIPS 流水线全图与 jal/jr 特例
- `jal`：PC+4 在 ID 写回 rf（目标 $31 约定）；`jr $31` 返回在 EX 冲刷。
- `j`：ID 即知目标（拼接）→ 冲刷 1 条。
- 中断/异常：流水线任何点都可能被打断 → 精确异常要求"按程序序完成旧指令、丢弃新指令、
  记录 EPC/cause"——**这是 L16 乱序核与 CA 课程的核心主题种子**。

### 1.5 性能终账
CPI_流水 = 1 + 停拍率 + 分支率×误罚——典型真实程序 1.3–1.8。
5 段流水 MIPS 周期≈单周期 1/4 ⇒ 实测加速 3–4 倍而非 5。数字诚实是体系结构第一课。

## 3. 知识点在开源项目中的应用
- **projects/p05 扩展（p05 高级实验）**：插 2 级流水 + 转发 + load-use stall，testbench 自动算 CPI 对照。
- **PicoRV32**：2 级流水、对 load-use 采用"停一拍"而非全转发——极简设计的教科书样本（其 README 的时序图即 1.3 表）。
- **Rocket/BOOM**：BOOM 的 `BypassNetwork`/`FetchPredictor`（TAGE 家族）是 1.1/1.2 的研究级放大；Chisel 源码可直读。
- **XiangShan**：其 `ifu` 模块 BTB+TAGE+ITTAGE 预测器带公开准确率统计（`perf` 计数器）——把 1.5 的 CPI 账本做成可观测性指标。
- **riscv-formal / cocotb**：对 p05 扩展版写形式断言"stall 期间 PC 不变"、"转发值等于生产者结果"——开源验证生态用法示范。

## 4. 常见坑
- 转发条件要带 `RegWrite && rd!=0`：向 $zero 转发是静默灾难。
- load-use 停拍的"冻结 ID/IF、冲刷 EX/MEM"组合动作少画一条线就会写回旧值。
- 分支在 ID 判定后，jal 的写回与分支冲刷顺序冲突：给 PC 写回 mux 排优先级表（j>br>pc+4）。
- 编译器视角：`-O` 的重排/软件流水（CSAPP 3.x）会改变冒险距离——同一段 C 在不同 `-march` 下 stall 率不同，性能建模要拿汇编。

## 6. 讲末速查
- 转发=把结果抄近路送回 ALU 入口；load-use 是唯一必须停的一拍（lw→紧跟用它）。
- 分支三板斧：不预测（罚拍）→ ID 提前判定（罚 1）→ 预测（对=白赚，错=冲刷）。
- 冒险检测四条件：EX/MEM 有写 + 目的=源 + RegWrite + 非 R 型依赖距离——全固化成电路。
- CPI_流水 = 1 + stall + 误预测罚：诚实账本上 5 段流水 ≈ 3.5× 而非 5×。
