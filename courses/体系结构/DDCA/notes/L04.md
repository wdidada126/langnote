## 1. 核心概念

### 1.1 HDL 不是编程语言：并发与两次求值语义
软件逐语句执行；`always` 块是**硬件方程的描述**，所有块并发"永远在算"。
`#10` 延迟只在仿真中存在，综合后消失。写 Verilog 前先画电路图，是避免"软件式硬件"的唯一保险。

### 1.2 可综合子集速查
```verilog
module full_adder(input a, b, cin, output s, cout);
  assign {cout, s} = a + b + cin;        // 连续赋值：组合逻辑
endmodule

module counter(input clk, rst, en, output reg [7:0] q);
  always @(posedge clk)                  // 时钟沿触发 ⇒ 推断触发器
    if (rst) q <= 8'd0;                  // 非阻塞 <=：时序逻辑规定用法
    else if (en) q <= q + 1;
endmodule
```
- `assign` / `always @(*)` ⇒ 组合逻辑；`always @(posedge clk)` ⇒ 时序逻辑。**这条二分法贯穿全课。**
- 阻塞 `=` 用在组合 `always @(*)`；非阻塞 `<=` 用在时序——混用产生仿真/综合不一致（latch 或错序）。
- 不完整 if/case 的组合 `always` 会**推断出锁存器**（latch inference 警告必须清零），L05 解释机理。
- 位宽：`[7:0]` 降序；无声明宽度的 `===`（case equality）之外慎用；`{a,b}` 拼接、`{4{a}}` 复制。

### 1.3 结构层次与 testbench
`module` 实例化连成网络表；testbench 是**不可综合**的顶层：产生时钟、激励、
`$monitor/$display` 检查，理想 TB 自带 `pass/fail` 自动判定（iverilog 下用 `$fatal` 或出错计数）。
projects/p01–p05 均按"设计 .v + tb.v + build 脚本"组织。

### 1.4 FPGA 结构：LUT 视角重看 L03
- Xilinx 7 系列 CLB 内含 4 输入 LUT（=16bit SRAM + Mux 树）、FF、进位链 CARRY4。
- 任意 ≤4 输入函数 = 1 个 LUT；更大函数由 LUT 级联 ⇒ "组合逻辑延迟按 LUT 级数计"。
- 布线资源可编程 ⇒ 同一段 RTL 在不同约束下时序不同。Vivado 流程：综合(OOC)→优化→映射→布局布线→时序报告→比特流。

### 1.5 工具链对比（课堂 Vivado vs 开源线）
| 工具 | 角色 | 备注 |
| --- | --- | --- |
| Vivado | 综合+实现+下载 | 课程官方，重、闭源 |
| iverilog | 事件驱动仿真 | 本课程 projects 编译/运行基准 |
| Verilator | 编译式仿真（C++） | 快 10–100 倍，不能 `#延迟`，工业 CI 主流 |

## 2. 与课程内外知识的衔接
- **CSAPP**：CSAPP 从不碰 HDL；本讲是"程序=数据通路的一次配置"视角的起点，到 L09 会理解 CSAPP 4.1 "%e=寄存器/内存抽象"背后的真硬件。
- **6.S081**：无直接接口，但 xv6 的设备驱动（如键盘/串口）对应 L15；本讲工具链思维（比特流、约束）有助理解固件 vs 硬件的边界（esp32：固件可编程=CPU 行为可改；FPGA 比特流=电路本身可改）。
- **CS61C/N2T/CA**：N2T 用自产 HDL（nand2tetris.hdl），语法极简无时序细节；CS61C 用 Logisim+少量 Verilog；ETH CA 直接用 SystemVerilog+Vivado 做 lab，本讲是其工具底线。

## 3. 知识点在开源项目中的应用
- **iverilog 跑通本课全部 projects**：`iverilog -o sim tb_alu.v alu.v && vvp sim`（见每个项目 build.sh/build.bat）。
- **Verilator + cocotb 验证开源核**：PicoRV32 的 CI（iverilog 回归）与 Ibex 的 CI（Verilator+cocotb+UVM 混用）代表两代开源验证路线，L09 CPU 项目可扩展接入。
- **OpenTitan / Caliptra**：大规模 FPGA 原型（`verilator` 仿真 + Vivado/Quartus 上板）流程与本讲一致，只是规模千倍。
- **esp32**：ESP32-C3/S3 是 RISC-V/Xtensa 软核 + 固定外设——若学完 FPGA，可用 TinyUSB+LiteX 在生态内自搭 SoC 对比。

## 4. 常见坑
- `initial` 块不可综合（FPGA 上电状态用复位或 GSR）。
- 忘记在敏感列表/`@(*)` 中加新信号 → 仿真错但综合对，或反之；永远写 `always @(*)`。
- `reg` 型不必然生成触发器（它只是"可保存值的变量"）；是否 FF 取决于所在 always 块。
- 位宽截断静默发生：`assign [3:0] x = a + b;` 丢进位，仿真无警告。
