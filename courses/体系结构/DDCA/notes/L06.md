# L06 有限状态机：建模、状态编码与实现（FSM）

> 参考阅读：H&H Ch.5.4–5.5；P&P Ch.7.1（以 FSM 实现简单计算机）
> 对应 Lab：Lab 4（FSM：交通灯/序列检测器，上 Basys 3）

## 1. 核心概念

### 1.1 FSM 设计五步流程（本课程方法论核心）
1. **规格**：输入/输出/时序行为的自然语言+时序图；
2. **状态图**：圆圈=状态，箭头=转移（标注输入条件/输出）；
3. **状态表**：现态×输入 → 次态/输出，即"转移函数的真值表"；
4. **编码与化简**：状态编号（二进制/独热），次态逻辑用卡诺图或 HDL 直写；
5. **实现**：次态组合逻辑 + 状态寄存器 + 输出逻辑（可再寄存器化）。
**Moore 型**：输出只依赖状态；**Mealy 型**：输出依赖状态+输入（少状态但输出有毛刺风险）。

### 1.2 经典例题
- **序列检测器**：检测 "1011" 非重叠/重叠——重叠版本需要失败回退边（KMP 的硬件化雏形），projects/p04 实现两种。
- **交通灯控制器**：红→绿→黄的计时（模 N 计数器嵌 FSM）、按钮中断请求（异步输入要同步器打拍——L05 伏笔兑现）。
- **1 的补码/边沿检测**：单 FF XOR 上一拍 = 边沿检测器——"最小 FSM 是 1 bit"。

### 1.3 状态爆炸与编码权衡
n 个 FF 可表示 2^n 状态。二进制编码省 FF 但次态逻辑复杂；独热编码一个 FF 一状态，
次态逻辑最简单（一项 OR）、面积换速度，FPGA（FF 便宜 LUT 贵）默认独热，ASIC 反之。
综合器 `(* fsm_encoding = "one_hot" *)` 可指定。

### 1.4 Verilog 三段式 FSM（工业规范）
```verilog
always @(posedge clk or posedge rst)        // 段1：状态寄存器
  if (rst) state <= S_IDLE; else state <= next;
always @(*)                                  // 段2：次态组合
  case (state) ... endcase
always @(*)                                  // 段3：输出（或并入段2）
```
一段式（时序块内直接 case）也能跑，但三段式避免组合反馈与毛刺输出，是 lint 工具认可的风格。
default 分支必回安全状态（防非法编码进入死状态，107 问题：二进制编码可能有未用状态）。

### 1.5 FSM 视角看一切控制逻辑
L08–L10 的微程序控制器、L10 多周期 CPU 的 11 状态、总线仲裁器、UART 控制器——全部是 FSM。
" datapath 干活，FSM 发号施令"是本课对 CPU 的终极分解：**CPU = FSM + datapath**。

## 4. 常见坑
- 输入未同步就进状态比较 → 亚稳态扩散（异步输入先双 FF 同步再给 FSM）。
- 输出组合直出带毛刺 → 关键控制输出要打一拍寄存（代价：响应晚一拍，规格里写明）。
- Mealy/Moore 混用导致仿真对板上错：时序图检查输出对齐沿还是输入变化。
