# L05 时序逻辑：锁存器、触发器、寄存器、计数器（Sequential Logic）

> 参考阅读：H&H Ch.5（5.1–5.3 前半）；P&P Ch.5 存储部分
> 对应 Lab：Lab 3（时序电路：计数器与分频）

## 1. 核心概念

### 1.1 为什么组合逻辑记不住东西
SR 锁存的物理本质：两个 NOR 交叉耦合形成**双稳态**正反馈环——信息存储在环路里，不在任何门里。
- SR 锁存（NOR 型）：S=1,R=0 置位；S=0,R=1 复位；S=R=0 保持；S=R=1 禁止。
- D 锁存（透明）：EN=1 期间 Q 跟随 D——**电平敏感 ⇒ 同一拍内可能穿透多处锁存 = 空窗(latch transparency)问题**，这是禁用锁存改用 FF 的核心原因。

### 1.2 D 触发器与建立/保持时间
边沿触发 FF 把"采样"收缩到时钟沿一个瞬间，两个锁存级联（主从）实现。
时序约束三件套：
```
t_su（建立）：沿前数据必须稳定的最短时间
t_h（保持）： 沿后数据必须保持的最短时间
t_cq（clk→Q）：沿后新值出现在 Q 的最长时间
```
违反 t_su/t_h ⇒ 亚稳态：输出在合法 0/1 之间震荡一段随机时间，平均无故障时间 MTBF 公式
（含 FF 的 τ、窗口 T_setup）说明**数字系统并非真的"0 或 1"，时序余量就是可靠性本身**——
这是本课第一次出现"概率性硬件"，也是 L16 讲到异步时钟域(CDC)研究的入口。

### 1.3 时序路径：fmax 怎么算
单条寄存器到寄存器路径成立条件：
`T_clk ≥ t_cq(max) + 组合逻辑路径延迟(max) + t_su + 时钟偏斜/抖动`
最大频率由**最长**路径决定；hold 违例由**最短**路径决定：`t_cq(min)+逻辑延迟 ≥ t_h`。
setup 违例可降频救，hold 违例只能插缓冲救——二者不对称是时序收敛第一课。

### 1.4 寄存器、寄存器堆与使能
- n 位寄存器 = n 个 DFF + 可选使能（DFF 带 EN 反馈 mux）。
- 寄存器堆（register file）= 2^k 个 n 位寄存器 + k 位读地址（Mux 阵列）+ k 位写地址（译码器）+ 写使能。
  **读端组合、写端时钟沿**——RF 是"组合+时序混合体"的模板，也是 L09 CPU 的 32×32 核心部件（projects/p03）。

### 1.5 计数器与分频
- 行波（异步）计数器：FF 串链，每级除 2，频率简单但 rippled 延迟累积且中间态有毛刺。
- 同步计数器：所有 FF 共用时钟，下一状态组合逻辑算出——它就是 L06 FSM 的特例（状态=计数值）。
- 分频器 = 模 N 计数器：`clk_out = cnt[某位]` 或比较翻转；消抖（debounce）电路用计数器对按键定时，Basys 3 lab 标配。

## 2. 与课程内外知识的衔接
- **CSAPP**：CSAPP 没有硬件时序；但栈指针/PC 的"每指令更新一次"在硬件里就是一个带使能的寄存器＋时钟沿——抽象与实现的接缝在此。内存层次（Ch.6）尚未到，L13 接。
- **6.S081**：xv6 时钟中断（CLINT）由计数器 FF 链产生；学完本讲再看 trap 频率的硬件来源一目了然。
- **CS61C/N2T/CA**：CS61C 的"clk2phase/寄存器"一周对应本讲+L06；N2T 把 DFF 作为存储原语直接用（不讲 setup/hold）；**ETH CA 的前置假设之一就是时序约束完全掌握**，其 CDC/时序收敛作业从这里延伸。

## 3. 知识点在开源项目中的应用
- **projects/p03**：DFF/寄存器/32×32 寄存器堆的 Verilog 行为模型与 testbench（iverilog 可编译）。
- **XiangShan / Chipyard**：Chisel `RegNext/RegEnable/SyncReadMem` 与本讲的 EN 寄存器、RF 一一对应；读 `RocketTile` 的 regfile RTL 可见"读组合写时序"仍是铁律。
- **OpenTitan `prim_flop`**：工业库统一封装带 CDC 原语的触发器——所有 FF 使用经过审计的宏，避免手搓亚稳态风险。
- **esp32 固件**：定时器/看门狗 = 片上计数器；`ets_get_time()` 背后的 RTC 计数器就是 1.5 的模 N 计数思想。

## 4. 常见坑
- `if (rst) q <= 0;` 忘记 `else` ⇒ 综合出带高电平复位 FF，功能正确但注意与仿真对齐；组合块漏 else ⇒ latch。
- 行波时钟接使能/门控时钟需专用 ICG 单元，时钟树门控是时序收敛杀手（FPGA 综合器可能给你自动转换并警告）。
- 复位异步释放同样引发亚稳态 → 异步复位同步释放（双 FF 打拍）——搜 "reset synchronizer"。
