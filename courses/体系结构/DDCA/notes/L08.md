# L08 从 C 到硬件：MIPS 指令集架构与编译执行全过程（ISA & Compilation）

> 参考阅读：H&H Ch.6.1–6.4；P&P Ch.4（机器语言/汇编）
> 对应 Lab：Lab 5（数据通路部件组装）；LC-3 汇编作业（P&P 线）

## 1. 核心概念

### 1.1 ISA 是契约不是实现
ISA 规定：程序员可见状态（32 个 GPR + PC + 标志/特殊寄存器）、指令编码、内存模型（字节寻址、对齐）、
I/O 接口。**同一 ISA 可有单周期/多周期/乱序/译码成微码等无限实现**——软硬件接口思想是 L08–L16 的脊柱。

### 1.2 MIPS 指令格式（RISC 审美）
- R 型：`opcode rs rt rd shamt funct`（6-5-5-5-5-6），add/sub/and/or/sll/slt/jr。
- I 型：`opcode rs rt imm(16)`，addi/andi/ori/sllv/lw/sw/beq，**立即数扩展：符号扩展**（addi 用）。
- J 型：`opcode addr(26)`，j/jal——26 位×4 字节寻址 256MB。
- load/store 专列：内存只能进/出寄存器（累加机→寄存器机的分水岭），对齐强制。
分支延迟槽、`$zero` 硬连线 0、`$at`/`$k0` 保留——约定体现"给软硬件留缝"。

### 1.3 从 C 到汇编：每条语句的电路代价
```c
for (i=0;i<N;i++) a[i]=b[i]+c[i];
```
→ 地址 = 基址+4×i（sll+add）、循环指针寄存器化（编译器分配）、beq 反向。
关键映射表：`if/while/for→beq/bne+j`、`函数调用→jal + 约定寄存器($a0-$v0, 保存区)`、
`数组→lui+ori 基址 + 偏移`、`&&/||→短路分支`。这一节与 CSAPP Ch.3 逐条互查效果最好。

### 1.4 指令执行语义 = 微操作序列
每条指令写成寄存器传输语言（RTL）：
`lw: MAR←R[rs]; MDR←Mem[MAR]; R[rt]←MDR`——**每个箭头都是一次带使能的寄存器写**，
L10 多周期控制器就是这些微操作的 FSM 表。汇编→机器码（译码器）与机器码→微操作（L09 控制单元）是同一张真值表的两次使用。

### 1.5 MIPS vs RISC-V（本课 projects 采用 RV32I）
| 维度 | MIPS | RISC-V RV32I |
| --- | --- | --- |
| 指令位宽 | 定长 32 | 定长 32（C 扩展压缩另说） |
| 立即数 | 分成 16 位碎片拼接 | B/J 型重排使符号位对齐（免碎步扩展） |
| 分支 | 延迟槽（历史包袱） | **无延迟槽** |
| 特殊寄存器 | 隐式 hi/lo、$31 | CSR 显式命名（mcycle 等可读写！） |
| 生态 | 教材/教学经典 | 开源 ISA：硬件可自由实现 |
RISC-V 六个基本模块（I/M/A/F/D/C…）+ 附录 ISA 手册开源可下载——这是 MIPS 没有的"ISA 即开源软件"属性，
也是本课 projects 用 RV32I 子集、后续接开源芯片生态的原因。

## 2. 与课程内外知识的衔接
- **CSAPP Ch.3**：同一件事（C→汇编）的两个视角；CSAPP 用 x86-64（CISC、变长、栈参数），本讲 MIPS/RISC-V 定长编码让"译码器电路"清晰得多。建议每学一条 MIPS 指令就在 godbolt 上对拍 x86 与 rv64 输出。
- **6.S081**：riscv 版 xv6 的 `kernel/*.vec`、trapframe 的 ra/sp 保存序、页表项位——全是本讲"约定寄存器+CSR"的直接消费者；学完 L08 再看 6.S081 lab 3（trap）会明白"内核为何能恢复用户上下文"。
- **CS61C/N2T/CA**：CS61C 后半 + N2T 下半分别用 RISC-V/LC-3；本讲 1.5 的表可当三课统一词典。ETH CA 直接以 RISC-V（BOOM/Rocket）为前提。

## 3. 知识点在开源项目中的应用
- **riscv-isa-sim (Spike)**：ISA 规范的黄金模型——写完 p05 CPU 后用 `spike --isa=rv32i` 生成 trace 对拍，开源验证标配。
- **riscv-toolchain / gcc**：`riscv64-unknown-elf-gcc -march=rv32i` 把 C 编成你 CPU 能跑的 ELF；p05 的简易汇编器/`.mem` 加载即其迷你版。
- **riscv-tests (RV32I `rv32ui-p-*`)**：官方指令级回归——p05 README 给出跑通其中 add/ld 子集的接入方法。
- **OpenHW / PULP**：PULP 扩展（倍率指令、位域指令）演示"在契约上加模块"的 ISA 扩展流程（custom-0/1 操作码段）。
- **esp32-C3**：真实量产 RISC-V 核（ESP32-C3=RV32IMC），其 TRM 手册第 6–7 章就是 1.2/1.5 的工业版。

## 4. 常见坑
- 分支目标 = PC+4+imm×4（相对 PC 基准易差一格；RISC-V 以当前指令 PC 为基）。
- lui+addi 拼 32 位立即数时低 12 位符号扩展需 +1 修正（rd 加 1）——RISC-V `li` 展开的经典细节。
- `sw` 无 rt 写回：数据通路不接写回线的指令同样要"假装写回 $zero/rd=0"对齐时序（L10 会看到）。
