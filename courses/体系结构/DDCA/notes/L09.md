# L09 单周期微架构：数据通路、控制单元、指令周期分析（Single-Cycle MIPS）

> 参考阅读：H&H Ch.6.5；课程 2023 Lecture 8–9
> 对应 Lab：Lab 5/6（datapath 组装 → 单周期 CPU）

## 1. 核心概念

### 1.1 一条指令 = 五个 datapath 动作
取指(IMem) → 译码/读寄存器(RF) → 执行/地址(ALU) → 访存(DMem，仅 ld/st) → 写回(RF, 仅非 st)。
单周期：**每指令一个时钟沿**，所有动作在组合逻辑上串联完成一次。

### 1.2 数据通路拼装（L03/L05/L07 模块首次合体）
```
PC寄存器 → IMem → ┬ instr[31:26] → 主译码器 → 控制信号
                  ├ instr[25:21]/[20:16] → RF 读口 rs/rt
                  ├ RF数据 → ALU(第二操作数 mux: imm/0) → DMem地址/结果
                  ├ imm 符号扩展/×4 → 分支加法器
                  └ instr[15:11] → RF 写口 rd；写数据 mux: ALU结果/内存/PC+4
```
新增部件：指令存储器、数据存储器（同步模型）、两个 mux、加 4 加法器、分支判定。
beq 比较结果 = ALU Zero 标志；j/jal 用拼接 + Mux 改 PC 写回源。

### 1.3 控制单元：一张 6 行真值表
主译码器输出 7 个控制信号（RegDst, ALUSrc, MemWrite, MemtoReg, Branch, Jump, ALUOp）——
**所有"程序行为"都压缩成这张表 + datapath**，图灵完备的实现不过如此。
扩展：slt 用 ALU 减法+溢出位；andi 把 ALUOp 编码为 5 种操作（多一位控制位，mux 加宽）。

### 1.4 关键路径与 CPI≡1 的代价
fmax 由 **lw 的最长路径**决定：PC→IMem→译码→RF→ALU→DMem→mux→RF 建立。
addi 明明很快，也必须等 lw 的周期——"为最慢指令买单"。定量：T_clk ≥ 8 段延迟之和（H&H 表 6.5），
RISC-V 版 projects/p05 中把 lw 换成寄存器源 add 做对照实验即可复现该结论。

### 1.5 性能方程
CPU 时间 = 指令数 × CPI × 周期时间。单周期 CPI=1 但 T_clk 巨大 → 引出 L10 多周期（CPI>1、T_clk 短）
与 L11 流水线（CPI→1 且 T_clk 短，靠并行而非压缩）。三者同一 datapath 的三次变形是本课最精彩结构。

## 2. 与课程内外知识的衔接
- **CSAPP Ch.4**：Y86-64 的 SEQ（=本讲 L10 多周期）与 PIPE（=L11 流水线）教材路线与 H&H 完全平行；CSAPP 4.5 SEQ+ 的状态机就是 1.3 控制表的微程序版——两课对照读，SEQ↔多周期一一对应。
- **内存层次衔接**：本讲把 IMem/DMem 当 O(1) 黑盒；CSAPP Ch.6 与本课 L13 揭示这个假设的代价与修补——先记此债。
- **6.S081**：单周期视角下"一条 jal 一个沿"，看 riscv 版 xv6 的 `spinlock` 时再回忆：真实多周期/流水线上 sw 并非原子——内存序话题 L16 前沿提一句。
- **CS61C/N2T/CA**：CS61C L12-14 单周期 MIPS/RISC-V 与 N2T Week 6-8 同构；ETH CA 开场即流水线及乱序，默认单/多周期已通。

## 3. 知识点在开源项目中的应用
- **projects/p05**：RV32I 子集单周期 CPU（addi/lw/sw/add/beq/jal + $zero），`$readmemh` 加载 `.mem` 程序，testbench 自动比对寄存器终态；附简易汇编器（asm→.mem）。
- **PicoRV32**：约 4k 行 Verilog 的可综合 RV32I——**最小工业级对照答案**；`picorv32.v` 通读一遍即检验本讲全部概念。
- **rv32utils (tinyriscv) / riscv-perme**：教学级单周期实现+汇编器，结构同 p05，可互相对拍。
- **cocotb 验证 p05**：用 Python 写随机指令流激励跑 Verilator 仿真——接入开源 CI 的第一步。
- **esp32-C3**：三级流水的量产 RV32IMC 控制器核，datasheet 性能段（CoreMark/MHz）用 1.5 方程分解。

## 4. 常见坑
- RF 读口时序：上升沿"同时读写"时读到旧值（edge-triggered RF 语义）——lw 后紧跟用它的指令在单周期天然正确，L11 流水线会破坏该性质。
- 分支写回源：beq 不写回，控制表 MemtoReg/RegDst 给 X 即可（don't care 复用，L02 呼应）。
- PC 更新 mux 漏跳：j/beq 同时有效时的优先级 = 控制信号 OR 关系，列表验证。
