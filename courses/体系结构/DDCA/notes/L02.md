# L02 组合逻辑 I：布尔代数、逻辑门、真值表（Combinational Logic I）

> 参考阅读：H&H Ch.2（2.1–2.5）；P&P Ch.2
> 对应 Lab：Lab 1（组合逻辑设计与 Vivado 入门）

## 1. 核心概念

### 1.1 布尔代数公理与常用定理
布尔代数 B = {0,1} 上的三元运算 (+, ·, ' )：
- 交换/结合/分配律与初等代数相同；**唯一的反直觉**：对偶原理——把 +↔·、0↔1 互换，定理仍成立。
- 关键恒等式：
  - 吸收律 A + A·B = A；A·(A+B) = A
  - 摩根定律 (A·B)' = A' + B'，(A+B)' = A'·B'（硬件意义：NAND 可替代一切）
  - 冗余项定理 A·B + A'·C + B·C = A·B + A'·C（卡诺图化简可自动发现）
- 完备集：{', ·, +} 完备；{NAND}、{NOR} 单门即完备（用 1.3 的恒等式可构造 NOT/AND/OR）。

### 1.2 真值表 → 表达式的机械路线
n 输入函数最多有 2^(2^n) 种。标准流程：
真值表 → 最小项之和（SOP，标准积之和）→ 代数化简或卡诺图 → 门级电路。
任何组合电路都对应唯一真值表 ⇒ 组合逻辑验证 = 2^n 行表的全检（小规模穷举可行，这是 L04 仿真与形式验证的起点）。

### 1.3 卡诺图与质蕴涵
- 相邻格只差 1 位 ⇒ 圈 2^k 个 1 消去 k 个变量。
- 术语：蕴涵项 / 质蕴涵(PI) / 本原质蕴涵(EPI)；多解时优先圈 EPI。
- 无关项(don't care, X)可圈可不圈，用于进一步化简——在 L08 指令译码器中大量出现。
- 5 变量以上卡诺图失效 → 工业界用 Quine-McCluskey / espresso（综合器内部做的事）。

### 1.4 标准组合模块的"代数签名"
- 缓冲/驱动：BUF（扇出修复，不改变值）
- 反相：NOT；多输入：AND/OR/XOR，且 XOR 链 = 奇偶校验器。
- 传输延迟：t_PD（最坏）、t_CD（最好）；**纯组合电路无时钟概念，其"速度"就是最长路径延迟**。

### 1.5 层次化设计方法学
模块（full_adder）→ 复用模块（ripple carry）→ 更大模块。接口三要素：输入、输出、功能规格。
这是把 Ch.2 与后续 Verilog（L04）缝起来的方法论：先图纸、后代码、再仿真。

## 4. 常见坑
- `a + b·c ≠ (a+b)·(a+c)`？在布尔代数里**成立**（分配律双向），别用实数直觉。
- 卡诺图圈必须 2^k 个且矩形；wrap-around 相邻易漏。
- XOR 三输入以上按"1 的个数的奇偶"画圈，不是两两 XOR。

## 6. 讲末速查
- 真值表 → SOP → 化简 → 门级：四步机械流程，小规模可全检验证。
- 对偶原理 + 摩根定律 = 布尔代数仅有的两条"反直觉"规则。
- 卡诺图：圈 2^k、wrap-around、无关项双向利用；>5 变量交给 espresso。
- {NAND} 完备：NOT=NAND(a,a)，AND=NOT(NAND)，OR 靠摩根——P&P 全课程的地基。
