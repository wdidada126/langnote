## 1. 核心概念

### 1.1 存储器的层次再下探一格
- 寄存器（FF）：最快、最贵（6 管/位）；SRAM 单元同样 6T，但位线共享读放大省面积。
- SRAM vs DRAM：6T vs 1T1C（电容漏电 ⇒ 必须刷新，密度换速度）——这一行表在 L13（cache 用 SRAM）、
  L14（主存用 DRAM）与 6.S081 页框回收中反复使用。
- ROM：二极管/晶体管掩膜编程 → PROM(熔丝) → EPROM/Flash（浮栅晶体管，电可擦——本质是"把电子困在绝缘层里"，
  固件 esp32 的 flash 即 NOR Flash）。

### 1.2 阵列结构：译码器 + Mux 的规模化
m×n 存储阵列：地址 k 位 → 2^k 行译码器（字线）+ 列 Mux 读出。
**SRAM cell、译码、读出放大**三件套；多 bank 交错提升带宽的伏笔在此埋下（L13 与 GPU 显存同思路）。

### 1.3 移位器（Barrel Shifter）
n 位任意量移位 = log n 级 Mux（每级移 2^i 或不移）。slli/srli/srai（L08）一拍完成全靠它；
关键路径 O(log n)，和 CLA 一样是"对数换线性"家族。

### 1.4 补码算术完全版
- 表示：−x = ~x + 1；n 位范围 [−2^(n−1), 2^(n−1)−1]（负数多一个）。
- 加/减：同一加法器（L03），**无符号与补码共用电路**，差别只在溢出判定：
  - 无符号溢出 = Cout；
  - 补码溢出 V = C_n ⊕ C_{n−1}（进位入符号位异或进位出）——"正正得负/负负得正"即溢出。
- 符号扩展 vs 零扩展：`{{4{a[3]}}, a}` 补码保值，零扩展是"无符号+移位组合"。
- 乘法：无符号数组乘 = 移位加（部分积矩阵，n² 全加器）；Booth 编码把 −1/0/+1 选择器塞进每 2 bit，
  减少部分积行数——signed 乘法的高效实现。除以 2 = 算术右移（向 −∞ 取整，CSAPP 2.4 的 C 语义由此而来）。

### 1.5 算术电路的时序含义
乘法器加法阵列是关键路径大户 → L11 流水线在"部分积树中间"插寄存器；
DSP slice/FPGA 硬核乘子就是把 1.4 阵列固化——面积/速度/功耗三角第三次出现。

## 3. 知识点在开源项目中的应用
- **projects/p02**（RCA/CLA/简单乘法思想）与 **p03 寄存器堆**（1.2 阵列的 RF 版）覆盖本讲硬件。
- **PULP (pulp-platform)**：其 `ap_cluster` 的 MAC/移位单元；`mem_lib` 仓库就是 1.1–1.2 的工业 SRAM/寄存器堆宏库，RTL 级可读。
- **XiangShan / Chipyard(Rocket)**：Rocket 的 `muldiv` 单元是 1.4 数组乘+移位除法的标准实现；香山 MDiv 使用更高 radix 算法——读一个 `MulDiv.scala` 胜过十道题。
- **esp32**：固件里的 CRC/查表运算跑在 Flash 存储上，1.1 浮栅原理决定其"读快写慢擦除贵"——OTA 分区设计知识由此来。

## 4. 常见坑
- 补码 `−2^(n−1)` 取负溢出（没有对应正数）；C 里 `INT_MIN / -1` UB 的根源。
- 数组乘部分积对齐右移方向；符号扩展每个部分积（Booth 免去此麻烦）。
- SRAM 仿真模型默认"读同拍变"，真实是同步 SRAM 下一沿才出数据——L09 访存用 1 周期模型时要说明假设。

## 6. 讲末速查
- RF(FF)→SRAM(6T)→DRAM(1T1C+刷新)→Flash(浮栅)：速度/密度/成本三角每降一层换一次。
- 存储阵列 = 行译码 + 列 Mux：L03 标准模块在 bitcell 尺度上的重复使用。
- 桶形移位器 log N 级 Mux；数组乘 n² 全加器；Booth 把部分积行数减半。
- 补码加减共用电路，分歧只在标志：CF=Cout，V=C_n⊕C_{n−1}。
