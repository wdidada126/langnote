# L11 流水线（I）：理想流水线、加速比、结构与数据冒险（Pipelining I）

> 参考阅读：H&H Ch.7.1–7.2；课程 2023 Lecture 10–11
> 对应 Lab：Lab 8（流水线寄存器与冒险观察）

## 1. 核心概念

### 1.1 流水线原理与加速比
5 段（IF/ID/EX/MEM/WB）把单周期切成等长节拍（木桶效应：T_clk = 最长段）。
理想吞吐：每拍出一条完成指令，CPI→1；加速比理想 n 段→n 倍，实际
`S = n/(1+(n−1)/p)`（Amdahl 形态：填充/排空/停顿损耗）。
**流水线不缩短任何一条指令的延迟，只提高吞吐**——一句话纠正常见误解。

### 1.2 流水线寄存器与段失衡
段间寄存器除了值还带控制位（RegWrite、MemtoReg、分支预测标记）随指令"漂"到 WB。
失衡例：MEM 段含 DMem 访问（≈450ps），ID 含 RF 读——把失衡段再切分（如 IF 拆 pc-reg/imem）
或用深度不对称段（现代核：前端 10+ 级、执行 4 级）。

### 1.3 结构冒险（Structural Hazard）
资源冲突：同一拍取指与写回都要访存 → Harvard 拆分 IMem/DMem 即消；
或统一存储 + 优先级（取指赢，写回停一拍）。分支目标缓冲、多端口 RF 的"双读一写"要求都源于此分析。

### 1.4 数据冒险（Data Hazard）与三种类型
流水线寄存器相邻，两条指令间隔 1–3 拍就要用前一条结果：
- RAW（写后读，危险真冒险）：`add r1` → `sub 用r1`；
- WAR/WAW（反/输出冒险）：**顺序发射+固定写回序的 MIPS 5 段流水线不存在**，乱序/多发射才有（10-447/CA 话题）——本课只需理解"为什么教材说 RAW 是唯一敌人"。
- 经典 5 段下：EX 段结束得结果，MEM 结束得 load 数据；后继若在更早段消费即冲突。
朴素解：stall（插入 bubble，`add` 后接 `sub` 停 2 拍）；优雅解：L12 转发。

### 1.5 停顿的可量化代价
CPI = 1 + stall_cycles/指令；给定指令混合与依赖密度算总周期——本讲核心习题类型。
CPI 公式与 1.2 失衡共同解释"为什么流水线有段数上限"：更深→单拍更短→但冒险距离拉长（转发路径更远）。

## 2. 与课程内外知识的衔接
- **CSAPP 4.6 PIPE**：CSAPP 的 PIPE 用 iF/dF/mF 等阶段命名且把 ALU 合并进 execute，与本课 5 段可互相映射；CSAPP 4.6.4 的数据冒险示例（`mrmovq`→`OPq`）与 1.4 完全一致，可做双语对照。
- **内存层次衔接**：本讲假设 MEM 段固定命中（SRAM/寄存器模型）；L13 cache miss 使 MEM 拍数不定→流水线可变长，"miss 也 stall"由此进入体系结构核心矛盾（内存墙的第一次正面遭遇）。
- **6.S081**：流水线正确性≠软件正确性：riscv 规范内存序（PMA）与单 hart 顺序无关；本讲让你明白"为什么 xv6 自旋锁需要 fence"的硬件动机（L16/6.S081 lab 4 呼应）。
- **CS61C/N2T/CA**：CS61C 流水线一周 + Hazard 一周浓缩本讲+L12；N2T 不讲流水线（止步多周期）；ETH CA Lecture 2-4 直接讲超标量/VLIW，把本讲当已知。

## 3. 知识点在开源项目中的应用
- **projects/p05 扩展**：在单周期 CPU 中插 3 段流水寄存器观察 `add→lw` RAW stall——课程作业等价实验。
- **Rocket/BOOM (Chipyard)**：Rocket 11 级流水的 stall 信号 `ireg_ready` 等命名与 1.4 分析一致；BOOM 的 scoreboard 即通用化 RAW 检测器。
- **XiangShan 香山**：`src/.../backend` 的 wakeup/select 网络就是大规模数据冒险基础设施（1024 项 ROB 的依赖追踪）。
- **esp32-C3（ESP-IDF 性能调优）**：官方性能指南解释 Flash 等待状态导致流水线停拍——把 1.5 CPI 公式套到 `irom`/`drom` 场景即得"函数放 IRAM 提速"的定量理由。
- **Verilator + riscv-formal**：对流水级做形式断言（如"写回值必等于某 EX 段值"）——冒险分析的可验证化。

## 4. 常见坑
- 把"加速比"与"频率提升"混谈：5 段流水若 T_clk 未变则无意义；先比 CPI×T_clk 乘积。
- bubble ≠ flush：stall 插入空拍（保留在飞指令）；冲刷丢弃已取错误路径指令（L12 控制冒险）。
- 忘记流水线寄存器带控制位下传：WB 段写使能应取"该指令自己"的，不是当拍译码的——经典 bug。
