# CS61C 讲义骨架（notes/outline.md）

> 每讲 3–5 条要点，骨架级。

## L1 导论：十大伟大思想
- 抽象层栈：应用→高级语言→汇编→操作系统→计算机架构→数字逻辑→电路。
- 贯穿思想：摩尔定律、抽象与层次化、性能按量化度量。
- C/汇编/机器码/hardware 描述语言如何逐级转换。
- 课程项目地图与工具链（gcc、spim/QtSpim、Logisim、gdb）。

## L2 数字逻辑与布尔电路
- 与或非构成完备集；真值表→表达式→门网表。
- 多路选择器是「硬件里的 if-else」。
- Logisim 搭建全加器并层次化封装。
- 从电路视角看 RISC-V 指令执行的物理基础。

## L3 组合/时序电路、寄存器与时钟
- 组合电路无记忆：延迟与毛刺问题。
- SR锁存→D触发器：时钟边沿捕获数据。
- 寄存器与计数器：最小存储单元。
- 时钟频率与关键路径延迟决定最大频率。

## L4 RISC-V I：指令格式与算术
- 指令即 32 位字：opcode/rd/rs1/rs2/funct 字段布局（R/I/S/B/U/J）。
- add/sub/and/or/sll/sra 等 R 型；li 为伪指令。
- 定宽指令让译码规整（RISC 哲学）。
- 十六进制与位域手工拆解练习。

## L5 RISC-V II：分支与函数
- beq/bne/blt 等 B 型 + 比较置位 slt 组合出条件跳转。
- jal/jalr 实现函数调用；ra 保存返回地址。
- 调用约定：a0–a7 参数、t/s 寄存器保存责任。
- 递归在汇编层的栈帧展开。

## L6 RISC-V III：load/store 与寻址
- lw/sw/lb/lbu 等访存指令与偏移寻址。
- 寄存器间接与立即数偏移=数组访问本质。
- 字节/半字 load 的符号/零扩展。
- 栈上局部变量与帧指针 sp 操作。

## L7 C 语言 I：指针与内存
- 指针 = 地址 + 类型信息；解引用宽度由类型决定。
- 数组退化指针；指针算术与字节偏移。
- 字符串是 char 数组 + '\0' 约定。
- 画出内存图理解 `*(p+1)` 类问题。

## L8 C 语言 II：结构体与动态内存
- 结构体成员偏移与对齐填充规则。
- malloc/realloc/free 与堆/栈区别。
- 悬垂指针、缓冲区溢出与 Valgrind 定位。
- 函数指针与回调：跳转表的 C 表达。

## L9 汇编与 C 互译
- `gcc -S` 观察 -O0/-O2 差异。
- 识别编译器惯用法（栈帧建立、循环展开模式）。
- 手写汇编↔C 对拍（Bomb Lab 式逆向思维）。
- Project 2 预备：用汇编实现神经网络推理。

## L10 数据并行：SIMD
- SIMD 寄存器一条指令处理多个数据元素。
- 手工向量化循环：load/运算/store + 掩码收尾。
- 加速比受向量化比例与余数限制。
- Project 4 预备：用 SIMD/OpenMP 加速矩阵乘。

## L11 性能度量
- 延迟（latency）vs 吞吐（throughput）；时钟周期数、CPI。
- Amdahl 定律：加速上限由不可优化部分决定。
- 基准测试方法与 profiler 使用。
- 「性能 = 指令数 × CPI × 周期时间」三因子分解。

## L12 存储器层次与 Cache
- 金字塔：寄存器→L1/L2/L3→DRAM→SSD，容量延迟互补。
- 直接映射/组相联/全相联；tag/index/offset 拆解地址。
- 命中/缺失、冷缺失/容量/冲突缺失、写策略。
- 程序局部性（时间/空间）决定缓存效果（Cache Lab 呼应）。

## L13 虚拟内存
- 页表完成地址翻译：虚拟→物理，按页粒度。
- TLB 缓存页表项；多级页表省空间。
- 缺页异常、页面置换（LRU/时钟）。
- 与 Cache 的协同：VIPT/PIPT 概念导览。

## L14 单周期与多周期数据通路
- 取指→译码→执行→访存→写回五阶段布线。
- 单周期：周期=最长路径，简单但频率低。
- 多周期：指令复用数据通路，控制 ROM/FSM 驱动。
- HCL 语言描述硬件控制逻辑（CSAPP Ch.4 同款）。

## L15 流水线与冒险
- 管道化：吞吐≈1 指令/周期，加速比受冒险限制。
- 结构/数据/控制三类冒险与气泡、转发。
- 载荷使用（load-use）冒险需停顿一拍。
- Project 3 预备：Logisim 搭两级流水线 CPU。

## L16 分支预测与异常
- 静态预测（总不跳/总是跳）→动态预测（2 位饱和计数器、 tournament）。
- 错误预测的冲刷代价与 IPC 影响。
- 中断/异常/系统调用：异步 vs 同步事件处理框架。
- RISC-V trap 寄存器与特权模式初步。

## L17 并发 I：线程与内存模型
- 共享内存并发的基本单位：线程、临界区、原子性。
- 互斥/信号量在硬件原子指令（LR/SC、AMO）上的实现。
- 数据竞争与顺序一致性的直觉。
- 死锁四条件与锁顺序。

## L18 并发 II：OpenMP/GPU
- OpenMP pragma 快速并行化循环。
- GPU=大规模 SIMD：warp、内核、内存层级。
- 并行归约、矩阵分块等模式。
- Project 4：并行迷你 Numpy 的性能调优路线。

## L19 专题：ML 芯片与加速器
- 为何通用 CPU 不够：DNN 负载的算术强度分析。
- 脉动阵列/数据流架构（TPU 思想）。
- Roofline 模型看计算/访存瓶颈。
- 体系结构研究前沿导览（与 ETH CA 衔接）。

## L20 期末复习
- 从门电路到并行程序的一条主线自述。
- 十大思想逐条对应到具体讲次例子。
- 高频考点：汇编↔C 互译、Cache 地址拆解、流水线时序图。
- 课程项目复盘：CPU 与 Numpy 两个完整闭环。
