## 2. 为什么学

- 刘老师疫情期间公开的完整中文图形学课程，资料（PPT/作业/项目）全面开放。
- 与 GAMES101 互补：101 重渲染，本课内容更全面，独有大量离散几何处理（网格、参数化、曲率）内容，且更数学化。
- 主讲人是几何处理国际一线学者（LISC 局部单参数化、SDF 字体渲染等），几何方向的中文最佳课程之一。
- 作业贴近科研：距离场字体、图像融合、曲线曲面插值、网格细分/参数化等，做完具备读 SIGGRAPH 几何论文的基础。

## 3. 先修与知识联系

- **数学**：微积分、线代为硬要求；离散微分几何（曲率/测地线）随课引入。
- **编程**：C/C++ 与数据结构；作业通常给 starter。
- **对照**：GAMES101（渲染主线互补）、GAMES102（几何处理深化）、15-462（数学视角同源，Crane 与刘老师同一学术圈）。
- **下游**：数字几何处理论文（mesh processing）、AIGC 3D 生成（几何表示是基础）。
