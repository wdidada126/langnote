# 附录讲 动画简介与课程总结（Animation & Wrap-up）

> 对应 README 讲次"附"（官方 Lecture 21–22 + 结课）。阅读：FCG4 Ch.16、Ch.17。

## 1. 为什么动画是"时间维的光栅化"

电影 24 FPS、游戏 60 FPS：动画 = 帧对连续世界的**时间采样**。
视觉暂留（persistence of vision）约 1/24–1/30 秒——低于该采样率出现频闪，
正是 L09 混叠的时间版本。

- **帧率与快门**：现实相机曝光有宽度（shutter open/close），物体在曝光期内
  移动 → 运动模糊（time exposure）。模拟方法：每条光线在曝光窗口内随机取
  一个时间 $t$（光线追踪：运动插值物体在 $t$ 时刻求交，即 motion
  primitives）；光栅化的替代：velocity buffer + 后处理（motion blur pass）。
- **频闪（strobing）**：快门全开 0 宽度 + 低帧率 → 边缘离散步进感
  （游戏高刷显示器的"sample-and-hold"模糊是另一味药）。

## 2. 摄像机动画

把相机变换写成时间的函数：$M_{view}(t)=\big(P(t),\,q(t)\big)$
（位置 + 四元数姿态）。

- 关键帧 + 插值：位置走 L11 的 Bezier/样条；姿态用 **slerp**（四元数球面插，
  等角速度、避免欧拉角万向锁跳变，L05 的债还清）。
- 经典机位语言：dolly（推轨）、pan（摇）、crane（升降）、
  虚拟景深（光圈 → 每条光线在透镜圆盘随机取点，L16 的多维采样再现）。
- 手持/抖动 = 低幅噪声叠加——程序化动画的入口。

## 3. 物体动画与模拟概览

- **关键帧/变形**：顶点 = 函数 $v_i(t)$（线性混合蒙皮：$v=\sum_j w_j\,G_jB_j^{-1}v$，
  L05 求逆复用）。
- **物理模拟**：质点弹簧、刚体（碰撞检测 + LCP）、流体/布料（SPH/FLIP/VPIM）。
  本课只点到；主线留给 GAMES103。
- 角色动画：运动捕捉 vs 程序化 vs 生成式（2023 后：视频/文本→3D 运动扩散模型）。

## 4. 课程总结：一张图收拢 16 讲

```
        表示(L10-L11) ──▶ 采样/成像(L04-L09, L12) ──▶ 感知/颜色(L13)
             ▲                    ▲
             │                    │
     光传输(L14-L16) ──────── 数学工具(L02-L03)
```

1. **数学**（L02–L03）：向量/矩阵/齐次坐标——18.06 的图形学方言。
2. **变换与投影**（L04–L06）：MVP，世界 → 裁剪空间。
3. **光栅化**（L07–L09）：采样、三角形、z-buffer、抗锯齿——实时成像主线。
4. **几何**（L10–L12）：图元、表示（显式/隐式）、纹理——"世界用什么造"。
5. **光与色**（L13–L14）：感知、局部光照、BRDF 初探——"像素为何这颜色"。
6. **光的传输**（L15–L16）：辐射度量、渲染方程、蒙特卡洛、光线/路径追踪
   ——物理正确主线。
7. **时间**（本讲）：动画与模拟——前两线沿 $t$ 轴延展。

**全课统一视角：图形学 = 在空间、频率、时间三个域里，用合适的采样换尽可能
多的物理正确性，再按人眼的预算（色域/gamma/感知敏感区）花掉它。**

## 5. 三条主线的最终对照

| | 光栅化 | 光线追踪 | 路径积分（渲染方程） |
| --- | --- | --- | --- |
| 核心算子 | 投影+半平面测试 | 射线求交+递归 | 半球 MC 积分 |
| 决定质量 | 多边形/纹理分辨率 | 递归深度 | 样本数 N |
| 硬骨头 | 反射/间接光 | 噪声/时间预算 | 方差缩减 |
| 工业位置 | 实时默认 | 实时增量(RTX) | 离线标准+实时渗透 |

## 6. 跨课程联系与进阶路线

- **GAMES202（强推续课）**：实时全局光照全景（lightmap/探针/SSGI/
  ray tracing 降噪），本课每一处"工程近似"在此展开。
- **DDCA/CSAPP/CS149**：动手理解 GPU——写 compute shader/并行光追，
  把 L07/L16 的体系结构假设变成本能。
- **CS231n / 深度生成模型** → 神经渲染谱系：NeRF（ECCV 2020，MLP 体积
  渲染，直接用上 L06 相机模型 + L15 积分）、Mip-NeRF 360、Instant-NGP、
  3D Gaussian Splatting（SIGGRAPH 2023，可微泼溅=光栅化 L07–L09 的重构！）、
  DreamerV3（世界模型在潜空间"渲染"想象帧）、扩散模型 3D 化（Zero123/
  TRELLIS）。经典成像几何 → 神经表示的映射在本课目录里处处可画。
- **GAMES103 / 刚体流体**：本讲第 3 节的正式版。
- **15-462 / CS148 / USTC-CG**：同主题不同风格的对照（见本仓库对应目录）。

## 7. 开源项目中的应用

- **Blender**：关键帧 + slerp 插值、运动模糊（per-ray time sampling）、
  MMD/刚体/FLIP 全在你学过的概念上。
- **Unreal/Unity**：Cinematic 机位轨道、Movie Render Queue（路径追踪出片）、
  Sequencer = 相机变换的时间函数编辑器。
- **raytracing-in-one-weekend**：运动模糊球（moving sphere）是
  L15–L16 采样的最佳练习题。
