# L05 变换（下）：3D 旋转、世界坐标与变换求逆

## 1. 3D 旋转的三个麻烦

1. **不可交换**：绕 x 转 90° 再绕 z 转 90° ≠ 反序。旋转群 SO(3) 非阿尔贝群。
2. **参数化有坑**：任何用 3 个数表示旋转的方案必然在某处奇异（拓扑论证：
   $SO(3)$ 不是 $\mathbb R^3$）。
3. **复合代价**：$n$ 次基本旋转 = $n$ 次矩阵乘，游戏里动画师只想要"三个角度"。

## 2. 欧拉角与万向锁（Gimbal Lock）

欧拉角约定（如 z-y-x：偏航 yaw→俯仰 pitch→滚转 roll）依次绕**动轴**旋转。
问题：当 pitch = ±90° 时，第一次与第三次的转轴重合，**失去一个自由度**，
旋转由 3 参数退化为 2 参数——万向锁。飞机姿态、机械臂、Unity 的
`Transform.rotation` 内部避开欧拉角皆因此。

- 工程对策：用**四元数** $q=(x,y,z,w)=(\hat n\sin\frac\theta2,\cos\frac\theta2)$ 表示旋转，
  $q\otimes q^{-1}$ 复数式合成，无奇异；插值用 slerp（动画平滑的关键，附录讲用到）。
- 课程视角：欧拉角仍是理解旋转复合的最佳入门；工业界默认存储是四元数。

## 3. 世界坐标系与视图变换

- **世界坐标（World）**：场景统一的"固定舞台"。每个物体有自己的
  **局部坐标（Local/Model）**，物体→世界用模型矩阵 $M$。
- **视图变换（View）**：把世界坐标搬到**相机坐标系**。相机系基向量
  $\{\vec r,\vec u,\vec{-d}\}$（右/上/视线反方向）+ 相机位置 $\vec e$：

$$M_{view}=\begin{bmatrix}r_x&u_x&-d_x&-\vec r\cdot\vec e\\ r_y&u_y&-d_y&-\vec u\cdot\vec e\\ r_z&u_z&-d_z&-\vec d\cdot\vec e\\0&0&0&1\end{bmatrix}$$

三列即基的**列观点**（L03）：每列是世界基下的相机轴方向；平移分量是相机原点的投影。
`lookAt(e, c, up)` 由 $\vec d=\widehat{c-e},\ \vec r=\vec d\times\vec{up},\ \vec u=\vec r\times\vec d$ 构造。

## 4. 变换求逆：刚体变换的捷径

一般 $4\times4$ 求逆用伴随/高斯消元。但**刚体变换**（仅旋转+平移，$R$ 正交）有捷径：

$$M=T(\vec t)R,\quad M^{-1}=\begin{bmatrix}R^T&-R^T\vec t\\0&1\end{bmatrix}=T(-\vec t')R^T$$

即"转置即逆（旋转部分）+ 反向平移"。用途：L06 把近平板 N 变回世界系求视锥、
世界↔相机往返（拾取/射线生成，L16 光线追踪的光线起点）、法线逆转置（L14）。
**正交矩阵** $R^TR=I$（18.06 复用）保证 $R^{-1}=R^T$。
