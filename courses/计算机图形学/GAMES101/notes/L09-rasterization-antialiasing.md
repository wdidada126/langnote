# L09 光栅化（二）：抗锯齿、采样理论与 MSAA

> 对应 README 讲次 L09；官方 Lecture 06–07。阅读：FCG4 Ch.8–9、Ch.11。实践：projects/p2。

## 1. 锯齿（Aliasing）从哪来

像素中心的**点采样**丢弃了像素面积信息：斜边以"半格"为单位跳变 → 阶梯。
本质：**用带限信号以外的方式采样高频信号**。频域视角：理想采样 = 频谱周期延拓；
三角形边缘的频谱高频混入低频 → 走样（moiré、锯齿、细线闪烁）。
时域同款问题：帧率低 → wagon-wheel 反转（附录的运动模糊是同一处方）。

## 2. 处方：先积分再采样（area sampling）

把"采样点"换成"采样窗"：像素颜色 = 覆盖率（coverage）加权平均。
卷积语言：$g=(f*h)\cdot s$，先低通（重建核 $h$）再点采样。
连续世界里的"像素颜色"就是**覆盖率** —— 三角形与像素方格的交面积。

## 3. 重建核（filter）家族

| 核 | 形状 | 特点 |
| --- | --- | --- |
| Box | 矩形 | 点采样/超采样平均；各向同性差 |
| Triangle/Bartlett | 帐篷 | 双线性插值的频域身份 |
| Gaussian | 高斯钟形 | 光滑、无限支、旋转不变 |
| Mitchell/ Catmull-Rom | 三次 | 锐度/平滑折中，图像处理常任 |

频域上核越"方"（理想低通 sinc），时域振荡（ringing）越重 —— 没有免费午餐。

## 4. 超采样与 MSAA

- **Supersampling**：每像素 $n\times n$ 个子样本全量跑管线，再平均。质量高、
  成本 $n^2$ 倍。
- **Multisample AA (MSAA)**：观察——**覆盖（几何）是高频问题，着色（光照/纹理）
  是低频问题**。只在三角形边缘放多个覆盖样本（4x/8x），共享一个像素级着色：
  深度/模板与覆盖逐样本，颜色逐像素。最终解析：$\bar c=\frac{1}{n}\sum_k \mathrm{cov}_k\cdot c$。
- 成本只增光栅化与内存，不增片元着色 → 游戏默认 4x/8x MSAA 的原因。
- 局限：对**纹理内部**的高频锯齿无效 → 交给 Mipmap（L12）；对着色高频无效 →
  后处理 AA（FXAA/TAA，GAMES202）。

## 5. 与前后续讲的联系

## 6. 跨课程联系

- **DDCA/CSAPP**：MSAA 的"多覆盖样本 + 单着色"是数据局部性/带宽换算力的
  典型体系结构权衡；帧缓冲压缩（移动 GPU）为 AA 样本节省带宽。
- **CS149**：解析（resolve）是一次按像素分段的归约；tile-based GPU 把
  样本放在片上 SRAM——带宽架构的活例。
- **信号处理（电子基础 EE120/信号与系统）**：采样定理、卷积、傅里叶在此
  全部兑现；若未修，建议同步看 3Blue1Brown 傅里叶篇。
- **CS231n**：图像下采样的 avg-pool vs strided-conv 的棋盘伪影，与本讲同一病因。

## 7. 开源项目中的应用

- **WebGL/Three.js**：`antialias: true` 向浏览器请求默认 MSAA 上下文。
- **Vulkan/DX12**：`VkSampleCountFlagBits`、解析阶段显式；Filament 默认 4x（桌面）。
- **Mesa**：llvmpipe 的 Gallium 状态追踪实现软件 MSAA。
- **Blender Cycles**：不用 MSAA，用随机采样的**超级采样**（路径追踪天然抗锯齿，
  见 L15–L16 的蒙特卡洛收敛）。
- **projects/p2**：可选实现 4×4 网格超采样，锯齿边缘肉眼对比。
