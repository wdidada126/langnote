# L13 颜色与外观（Color and Appearance）

> 对应 README 讲次 L13；官方 Lecture 12。阅读：FCG4 Ch.6、Ch.15（光的性质部分）。

## 1. 颜色是心理物理量

颜色不是光的属性，而是**人眼+大脑的解读**。物理量是光谱功率分布（SPD），
感知量是颜色。链路：

```
光源 SPD × 物体反射谱 → 进入眼睛的谱 → 三种视锥(L/M/S)响应 → 神经系统 → 感知
```

视锥响应是三通道 → 任何光谱都能用三基色近似匹配 → **色度图（CIE xyY）**：
马蹄形区域 = 人眼可见色域；直线边界 = 光谱 locus；内部点 = 混合色。

## 2. 色域与色彩空间

- 显示器 RGB（sRGB/Rec.709）只能覆盖色度图的**三角形子集**：
  鲜艳的青绿、饱和橙常"越界" → 无法显示。
- 印刷 CMYK 的色域三角形朝向不同 → 有些屏幕色印不出来（双向越界）。
- 色彩空间转换 = 3×3 矩阵（线性 RGB 域内）+ gamma（见下）。
  D65→ACES、sRGB→Linear 都是这类矩阵（18.06 换基，L03 观点复用）。

## 3. 加色 vs 减色

- **加色（发光：RGB 屏幕、三原色光）**：$R+G+B$ 线性叠加 → 白。
- **减色（反光：颜料、CMY 打印）**：每层颜料吸收互补波段，白光照上去
  减去一部分 → 理想 CMY 叠加吸收全部 → 黑（实际用 K 补）。
  同一束光，两条路径——本质都是 SPD 与光谱响应的积分。

## 4. 光的度量与光源外观

- 黑体辐射：温度决定颜色（1000K 红 → 6500K 日白 → 12000K 蓝）。
  色温是光源第一外观参数；影视标准 D65（约 6500K 日光）。
- 辐射度量学预告（正式在 L15 展开）：光通量/照度/亮度是同一物理量的
  人眼加权版（亮度函数 $V(\lambda)$）。

## 5. Gamma：为眼睛而做的非线性编码

人眼对暗部差异敏感（Weber-Fechner 近似对数感知），而线性量化把码字
均匀分配给亮度 → 暗部色带（banding）。**gamma 编码** $c'=c^{1/\gamma}$
（γ≈2.2）把码字向暗部倾斜；显示端解码 $(c')^{2.2}$ 还原线性光。
关键工程教训：

- 光照计算必须在**线性空间**做（能量守恒是线性的）；
  sRGB 纹理要在 shader 里 pow 2.2 回来再乘光。
- GPU 的 `GL_SRGB` 纹理格式/`backEnd sRGB` 帧缓冲由硬件自动做编解码（L07 管线细节）。

## 6. 与前后续讲的联系

- 本讲回答"像素的数值→人眼看到的颜色"，与 L09（像素数值→屏幕位置）
  合成成像闭环的两半。

## 7. 跨课程联系

- **电子基础/信号与系统（EE120）**：SPD→三通道是"感知维度的降采样"，
  混叠/匹配滤波器视角立刻理解同色异谱（metamerism）。
- **CS231n**：数据增强的色彩抖动必须在线性域或用感知均匀空间（Lab/OKLab），
  否则统计偏斜——gamma 的 ML 版教训。
- **DDCA/CSAPP**：sRGB 编解码表是 8-bit 量化经济学的硬件体现；
  HDR 链路（PQ/HLG）是位深与感知动态范围的再谈判。
- **18.06**：色彩空间转换矩阵、白点适配（von Kries）= 换基 + 对角缩放。
