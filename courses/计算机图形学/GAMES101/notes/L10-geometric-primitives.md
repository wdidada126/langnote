> 对应 README 讲次 L10；官方 Lecture 08（Geometry 1）。阅读：FCG4 Ch.3、Ch.13。
> 实践：projects/p3。

## 1. 图元（primitive）：光栅化器的词汇表

渲染管线接受的基本形状：point / line / triangle / quad / polygon。
所有复杂模型最终都分解为它们。

- **点**：零维，"针孔相机"可把任何形状变成点云（扫描数据的天然表示）。
- **线**：DDA 算法 → Bresenham（整数增量，无浮点误差）；Wu 抗锯齿线：
  按到理想线的距离加权两侧像素（覆盖率思想 L09 的首次应用）。
- **三角形**：绝对主角（L08）。
- **四边形**：4 点**不保证共面** → 包含测试/求交依赖对角线选择、结果不唯一；
  细分（quadtree）可缓解。工业偏好：细分曲面用 quad（ Catmull-Clark），
  进管线前一律三角化。

## 2. 任意多边形的问题

非凸多边形的"内外"不再由三条边决定（绕数 winding number / 奇偶规则），
且凹多边形半平面测试失效 → 一律**三角剖分（triangulation）**：
耳切法（ear clipping）、约束 Delaunay。Google logo 案例：四边形拼接处
对角线不同 → 轮廓可见差异（官方 PPT 名场面）。

## 3. 圆与球：参数 vs 隐式

两种世界通用表示法在本讲首次对照：

- **参数式**：$\vec p(t)=O+R(\cos t,\sin t)$（圆）——便于采样点/描线，
  但"内外"需要额外计算。
- **隐式**：$f(x,y,z)=\lVert p-O\rVert^2-R^2=0$（球面）；$f<0$ 为内。
  便于内外判定、**光线求交直接解一元二次方程**（L16 的第一种求交）。
  求交：$\vec o+t\vec d$ 代入，$t=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$，
  判别式/负根剔除即"命中测试"。
- 圆的**三角形近似半径误差**：$1-\cos(180°/n)$，12 边形误差 3.4% —— 
  曲面细分（L11）与 GPU tessellation 的存在理由。

## 4. 光栅化 vs 光线追踪对图元的偏好

| | 光栅化 | 光线追踪 |
| --- | --- | --- |
| 基本操作 | 像素内测试（L08 边函数） | 射线求交（解方程） |
| 三角形 | 完美 | Möller–Trumbore（也是重心坐标） |
| 球/隐式 | 困难（需参数化成网格） | 几乎免费（代回 $f=0$） |
| 复杂曲面 | 先细分成网格 | 可 raymarching SDF（L11/p3） |

可见：**表示的选择决定了可用的渲染算法**——这句话直通 L11–L16 全景。

## 6. 跨课程联系

- **数据结构与算法（6.006/CS170）**：多边形三角剖分是计算几何经典题
  （单调划分 + 双端队列 O(n log n)）；耳切是其朴素版。
- **DDCA/CSAPP**：Bresenham 的纯整数递推是早期"算法-硬件协同设计"标本。
- **18.06**：球的二次型 $(p-O)^T(p-O)-R^2$ 是"二次曲面=对称矩阵"特例；
  椭球/抛物面统一为 $p^TAq=0$，特征值给出主轴（L11 的二次曲面分类）。
- **CS149**：球体光线求交是 SIMD 友好算术（8 条射线一组解二次方程）的范例。

## 7. 开源项目中的应用

- **GPU 图元模式**：`GL_POINTS/GL_LINES/GL_TRIANGLES` 的"三角形偏好"即本讲结论；
  现代管线基本只剩三角形 + compute。
- **assimp / tinyobjloader**：把任意 .obj（含 quad/poly）三角化后进管线。
- **Blender**：编辑模式的三/四边面工作流（建模用 quad、渲染前 triangulate）。
- **raytracing-in-one-weekend / projects/p4**：只有球（隐式）就能拍出"大片"。
- **projects/p3**：手写 .obj 子集解析（v/f）+ 球/平面半空间求交。
