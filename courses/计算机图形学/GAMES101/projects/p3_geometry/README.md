# p3 — 几何表示：网格子集与 SDF/CSG（GAMES101 L10–L11；官方 Lecture 08–10）

## 覆盖讲次

- L10 几何体：三角网格（显式）与球/半空间（隐式）、扇形三角化。
- L11 表示：SDF、半空间 CSG（max 即"交/差"）、sphere tracing、
  网格拓扑（V−E+F 欧拉示性数）。

## 算法

### A. 显式路线：`data/*.obj` 子集加载 + 射线-三角形求交

- 解析器仅认 `v` 与 `f`（支持多边形扇形三角化、负索引）——"子集"即课程作业口径。
- Möller–Trumbore 求交：解 $o+td$ 与 $a+u e_1+v e_2$ 的线性方程组
  （Cramer 法则，L03），返回 $(t,u,v)$；与 L08 光栅化的重心坐标殊途同归。
- 场景：棋盘地面（y=const 半空间）+ 旋转平移的立方体、四面体；flat shading。

### B. 隐式路线：瑞士奶酪 = 球 ∩ ¬(6 个孔球)

$$d(p)=\max\big(d_{\text{大}}(p),\ -\min_i d_{\text{孔}i}(p)\big)$$

- **Sphere tracing**：沿射线步进 $t \mathrel{+}= \lambda\, d(p)$（λ=0.9 保守系数，
  CSG 后不再是严格距离场）→ 命中判 $d<\varepsilon$。
- 法线：数值梯度 $\nabla d$（有限差分）。
- 这正是 L11 "表示决定算法"的实操：同一个场景，换表示就换求交器。

### C. 拓扑自检

`main` 打印两模型的 V/E/F 与 V−E+F：
tetra=4−6+4=2（闭合流形 ✓）；cube（每面独立顶点，24V）≠2 ——
引出网格处理第一步"顶点焊接（weld vertices）"。

## 构建与运行

```sh
./build.sh && ./bin/p3        # 在 data/ 的父目录下运行
```

```bat
build.bat && bin\p3
```

输出（512×512 P6 PPM）：

| 文件 | 内容 |
| --- | --- |
| `mesh.ppm` | 立方体+四面体立于棋盘地面（显式表示，平面明暗） |
| `csg.ppm` | 瑞士奶酪立于同一地面（隐式表示，sphere tracing） |

stdout 打印网格统计（V/E/F、V−E+F）用于欧拉公式自检。

## 出图说明 / 观察点

- `mesh.ppm`：每个面是**平直着色**的三角面片（flat shading）→ 低多边形感；
  想做软着色需焊接顶点+平均法线（L11 练习）。
- `csg.ppm`：孔洞边缘有自遮挡的柔和轮廓（raymarching 天然产生软过渡）；
  把保守系数 0.9 调到 1.0 可能"穿墙"——理解距离场语义的绝佳实验。
- 场景里的网格求交是暴力 O(F)：接 p4 的 BVH 练习可迁移。
