## 算法流程

```
顶点(模型) --MVP--> 齐次裁剪空间 --6 平面裁剪--> 扇形三角化
  --透视除法--> NDC --视口变换--> 屏幕
逐三角形：包围盒 → 像素中心边函数测试（含 4×4 子样本）
  → 重心坐标 → z-buffer 测试 → correct/线性 插值(uv,n)
  → Blinn-Phong → 颜色写入（最后 gamma 2.2 编码）
```

关键点：
- 深度 `z` 在屏幕空间线性插值即可；**UV/法线**必须除以视深度 `w` 再加权归一
  （$\alpha_i/w_i$，L12 公式）——`cube_compare.ppm` 左图故意用线性插值，
  棋盘在斜面上明显"挤压"，右图为 correct 插值。
- 超采样实现为"像素内最近命中子样本"（近似 MSAA 的覆盖语义），README 已知局限。

## 构建与运行

```bat
build.bat          & bin\p2
```

```sh
./build.sh && ./bin/p2
```

无参数，直接在当前目录输出：

| 文件 | 尺寸 | 内容 |
| --- | --- | --- |
| `cube_raster.ppm` | 800×800 | 主图：Blinn-Phong + 棋盘 + z-buffer |
| `cube_compare.ppm` | 800×400 | 左=线性插值（错）右=透视 correct（对） |
| `cube_ssaa.ppm` | 800×400 | 左=1×（锯齿）右=4×4 超采样 |

## 调参实验（动手对应讲次）

- 改 `RasterOptions::perspectiveCorrect=false` 看纹理畸变（L06/L12）。
- 改 `ssSamples=1/2/4/8`：锯齿收敛与代价（L09）。
- 把 `blinnPhong` 的高光项挪到顶点插值 → 复现 Gouraud 高光丢失（L14）。
- 加阴影光线（从片元向 `lightPos` 求交）→ 得到第一个"像样"阴影（L16 预告）。

## 已知局限

- 裁剪后三角形用扇形拆分，退化/细长三角形可能有像素级缝隙。
- 背面剔除未开启（双面都画）；`area<0` 时边函数整体反号，不剔背面。
- 超采样为简化版（见上），非面积精确的 coverage 采样。
