# CS148 逐讲要点（骨架）

## L01 什么是图形学
- 图形学 = 用计算生成图像：从几何、光货到像素的完整链路。
- 应用领域：影视、游戏、CAD、可视化、AR/VR、科学计算。
- 课程路线：Blender 使用层 → 数学层 → 自建软渲染器。

## L02 Blender 与建模
- 多边形建模：顶点/边/面、挤出、细分、修改器栈。
- 修改器（mirror/subsurf）背后的几何操作。
- 渲染设置与 Cycles/EEVEE 的差异预览（为后续原理课埋点）。

## L03 3D 几何
- 三角形是基元：平面方程、重心坐标、面积与体积的叉积表达。
- 法向量：面法向与顶点法向、平滑着色的依据。
- 退化三角形与数值稳健性。

## L04 变换与场景图
- 齐次坐标下的平移/旋转/缩放与复合。
- 场景图：父子变换累积、世界/物体坐标。
- 相机变换：lookAt 与视空间。

## L05 图像与颜色
- 图像 = 采样后的辐射信号；像素与分辨率。
- 颜色是感知量：sRGB/gamma 编码、线性光计算的重要性。
- 显示（RGB 加色）与打印（CMYK 减色）两套色域。

## L06 光照与着色
- 简单着色模型：环境/漫反射（Lambert）/镜面（Phong/Blinn）。
- BRDF 概念：出射与入射方向的函数、能量守恒。
- 点/方向/聚光灯在软渲染器中的实现差异。

## L07 纹理与凹凸
- 纹理 = 以参数域存储信号；UV 映射与采样。
- 双线性/三线性采样与 Mipmap 防走样。
- 凹凸贴图/法线贴图/置换贴图：不改几何改法向。

## L08 光线追踪
- 光线-图元求交：球解析解、三角形 Möller–Trumbore。
- 递归光追：反射、折射（Snell）、阴影光线。
- 与光栅化成像顺序的对偶关系（像素→场景 vs 场景→像素）。

## L09 反走样与蒙特卡洛
- 走样 = 高频信号欠采样；抖动/超采样原理。
- 蒙特卡洛估计：在像素/半球/光源上随机采样。
- 方差与样本数的 sqrt(N) 收敛直觉。

## L10 加速结构与总结
- 均匀网格与 BVH：求交从 O(N) 到 O(log N)。
- SAH 思想简介与构建成本权衡。
- Final project 周：从建模到渲染的完整短片管线复盘。
