# Data100 逐章要点（骨架）

## Ch1 数据科学生命周期
- 提问→获取→清洗→探索→建模→沟通→部署的闭环。
- 数据系统视角：从笔记本到生产管线的差异。
- 课程地图与工具栈总览。

## Ch2 问题定义与数据范围
- 把模糊业务问题转为可测量问题；proxy 与目标错位。
- 数据来源普查：采集成本、代表性、偏差。
- 数据伦理与隐私意识（HIPAA/GDPR 初步）。

## Ch3 模拟与数据设计
- 随机实验与模拟数据生成（seed/reproducibility）。
- 抽样设计：SRS/分层/整群。
- 用模拟理解变异性与统计量分布。

## Ch4 摘要统计建模
- 中心/离散/形状：均值、方差、分位数、MAD。
- 加权平均与聚合的正确性。
- 从样本统计到总体参数估计。

## Ch5 案例：公交晚点
- 真实 CTA 数据端到端演练：问题→清洗→分组聚合→结论。
- 分组-应用-结合（GAP）范式。
- 混杂因素与辛普森悖论意识。

## Ch6 pandas DataFrame
- DataFrame/Series 模型与索引；loc/iloc 语义。
- 选择、过滤、赋值链与方法链。
- 性能意识：向量化、避免循环与 SettingWithCopy。

## Ch7 SQL
- 关系模型与代数：选择/投影/连接/分组。
- SQLite/Postgres 实操与 pandas 互转。
- 窗口函数与复杂聚合；查询即声明式计算。

## Ch8 文件摄取
- 半结构化数据：JSON/CSV/日志解析与容错。
- 模式演化与 schema-on-read 思想。
- 批量 vs 流式摄取初步。

## Ch9 数据整形与清洗
- 缺失值机制（MCAR/MAR/MNAR）与处理策略。
- reshape/melt/pivot 与 tidy data 原则。
- 异常检测与类型/逻辑一致性清洗。

## Ch10 EDA
- 分布/关系/组间对比的可视化驱动探索。
- 相关 vs 因果；变换（log/Box-Cox）稳定方差。
- 假设生成循环与记录习惯。

## Ch11 数据可视化
- 图形语法（ggplot/vega-lite 思想）：数据→标度→几何→坐标系。
- 色彩/排序/小倍图（small multiples）等设计原则。
- 叙事与误导防范（截断轴、双轴）。

## Ch12 案例：空气质量
- 传感器数据清洗与对齐（时空数据特性）。
- 测量误差建模与校准。
- 聚合粒度选择对结论的影响。

## Ch13 文本数据
- 字符串/正则摄取非结构文本。
- 词袋/TF-IDF 特征工程与情感初探。
- 主题模型（LDA）概览。

## Ch14 数据交换与 HTTP
- JSON/Parquet/protobuf 序列化对比。
- REST API 分页、限速、认证取数。
- 从公开源持续构建数据管道。

## Ch15 线性模型
- 最小二乘几何解释（投影）与矩阵解。
- 回归系数推断与残差诊断。
- 线性分类：logistic 回归与决策边界。

## Ch16 模型选择
- 过拟合/欠拟合、偏差-方差。
- 训练/验证/测试纪律与交叉验证。
- 正则化（ridge/lasso）与特征选择。

## Ch17 推断与预测理论
- 估计量的抽样分布、CLT 应用。
- 预测区间 vs 置信区间。
- 无偏/一致性/效率的基本权衡。

## Ch18 案例：称驴体重
- 多传感器融合与回归组合。
- 数据增强与验证集构造技巧。
- 模型报告写作。

## Ch19 分类
- 评估指标族：accuracy/precision/recall/ROC/PR。
- KNN/决策树/随机森林入门。
- 类别不平衡处理策略。

## Ch20 数值优化
- 梯度下降族：批量/随机/动量/Adam。
- 凸性与收敛直觉；学习率调度。
- 为什么 ML 训练 = 优化问题。

## Ch21 案例：假新闻检测
- 端到端：抓取→特征→模型→评估→部署思考。
- NLP 特征（n-gram/嵌入）与可解释性。
- 结课：生命周期复盘与大项目方法。
