# ch3_arq —— 停等 / GBN / SR 可靠传输模拟

## 对应章节

- 教材：§3.4（Principles of Reliable Data Transfer，rdt0→rdt3.0、流水线 GBN/SR）
- 笔记：`notes/ch3-02-reliable-data-transfer.md`（第 10 讲）

## 协议/模型要点

1. **三件套齐全**：CRC 检错（比特错=篡改 crc）、序号（有限空间 SEQ_MOD，N=20 未绕圈）、超时重传（timeout 以"轮"计）。
2. 停等严格按 rdt3.0：数据 CRC 错不回 ACK（等超时）、重复有效包"重发上次 ACK"（rdt2.2 技巧）。
3. GBN：接收窗=1，乱序丢弃；超时**整窗回退重发**；累积确认。
4. SR：独立确认+接收缓冲，base 只推进到首个空洞；超时只重发单个包。
5. 信道简化：RTT=2 轮、每包损伤独立、**不乱序**——README 练习：在 `to_rx` 里对同轮多包打乱到达序，观察 GBN 把"乱序当丢失"的代价。

## 运行

```
python arq_sim.py        # 或 ./run.sh（先 py_compile 自检）
```

输出对比表：轮数（≈完成时间）、发送次数、信道利用率（交付/发送）、相对停等加速比。
