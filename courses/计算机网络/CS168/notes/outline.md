# CS168 讲义骨架笔记（notes/outline.md）

> 骨架级要点，待听课后逐条展开为正式笔记。

## L01 课程导论：互联网的端到端图景与设计原则
- Internet 是由异构网络互连而成的网络的网络；理解边缘（host）与核心（router/link）的分工。
- 分层（layering）的作用：封装、模块化、互操作；各层协议与服务的关系。
- 课程主线：寻址 → 路由 → 传输 → 应用 → 端到端问题。
- 设计原则预告：端到端论据（end-to-end arguments）贯穿全课。

## L02 网络边缘与接入网、链路层：以太网
- 边缘：接入网技术（xDSL/线缆/光纤/蜂窝）与带宽分享模型。
- 链路层帧结构、MAC 地址、以太网从共享介质到交换式的演进。
- 交换机自学习（learning switch）与无环转发。

## L03 网络层寻址：IP/IPv6、NAT 与地址体系
- IP 数据报的尽力而为（best-effort）语义：不保证可靠、有序。
- 分层地址：前缀/子网、CIDR 聚合；IPv6 动机与格式差异。
- NAT 的机制与争议（地址复用 vs 破坏端到端模型）。

## L04 域内路由：距离向量 vs 链路状态
- 路由算法抽象：图上的最短路径；DV（Bellman-Ford 迭代）与 LS（Dijkstra 泛洪）。
- 收敛速度、计数到无穷问题、毒性逆转。
- OSPF 区域的工程实践。

## L05 域间路由：BGP 与商业策略
- AS 图、客户-提供商-对等关系；BGP 是策略驱动而非单纯最短路径。
- 路径属性（AS_PATH、local preference 等）与路由泄露/劫持问题。
- 路由表规模与前缀聚合的扩展性挑战。

## L06 路由实践与项目周（Project 2：路由）
- 用 Python 实现 DV/LS 路由模拟，观察收敛行为。
- 阅读真实路由数据（prefix、AS 关系图）建立直觉。

## L07 传输层：UDP 与复用/解复用
- 传输层职责：进程级（端口）复用/解复用、校验和。
- UDP 的极简语义与「为什么够用」：应用在其上自建可靠性。
- QUIC 作为「UDP 上重建传输能力」的现代案例。

## L08 TCP：连接管理与可靠传输机制
- 字节流抽象、序号/确认、超时重传、滑动窗口。
- 三次握手/四次挥手的状态机与 TIME_WAIT 的意义。
- 流量控制（接收窗口）与可靠性的关系。

## L09 TCP 拥塞控制：从 AIMD 到 CUBIC/BBR
- 拥塞崩溃与 AIMD 公平性模型；慢启动、拥塞避免、快恢复。
- 丢包信号 vs 时延信号（loss-based vs delay-based）两大流派。
- CUBIC 的高带宽行为；BBR 用带宽/时延建模替代丢包信号。

## L10 应用层：DNS 与内容分发
- DNS 层次命名空间、递归/迭代查询、记录类型与缓存。
- CDN 的 DNS 重定向与边缘缓存；Anycast 初步。

## L11 应用层：HTTP 与现代 Web 传输
- HTTP/1.1 keep-alive → HTTP/2 多路复用 → HTTP/3 over QUIC 的动机链。
- Web 性能问题本质：传输对象数量与小对象问题。

## L12 端到端论据与网络安全（TLS）
- Saltzer-Reed-Clark 端到端论据：功能应放在通信端点还是网络内部。
- TLS 握手、证书体系（信任链）、前向保密概览。
- 用端到端视角评判 NAT、中间盒、透明代理。

## L13 数据中心网络
- 胖树/Clos 架构与 ECMP；为什么数据中心不需要传统 IP 路由复杂性。
- RDMA、流量工程与拥塞控制（DCQCN）等数据中心特有问题。

## L14 无线与移动网络、Beyond Client-Server 与总结
- 802.11 CSMA/CA 与隐终端问题；移动性：IP 层 vs 链路层方案。
- P2P、命名数据网络（NDN）等超越客户端-服务器范式的尝试。
- 全课回顾：分层 + 端到端 + 策略与转发分离三条线索。
