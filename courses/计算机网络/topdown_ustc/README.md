## 为什么学

- csdiy 称其「应该是中文互联网上比较火的计算机网络课」：教材是领域最经典的神书《自顶向下方法》，授课风格偏实际而非纯理论。
- 内容与教材章节对应且**涵盖考试内容**，可放心观看；中文授课大幅降低理解门槛。
- 强烈建议先读教材预习再看课，否则上课可能懵圈（csdiy 原话）。
- 与英文原版配套课（CORE/topdown）同源，与 Stanford CS144 互补（本课讲原理，CS144 讲实现）。

## 先修与知识联系

- 先修要求：操作系统（非必需）；难度 🌟🌟🌟；预计学时 40 小时；无指定编程语言。
- 知识联系：向下衔接体系结构/OS（socket 与内核网络栈），向上支撑 Web/分布式课程（HTTP、DNS、CDN 是分布式系统的基础设施常识）。
