# USTC 计算机网络（自顶向下）骨架笔记（notes/outline.md）

> 骨架级要点；正式笔记按 B 站分集逐讲展开。

## L01 第 1 章 概述
- 网络边缘（host/access）与网络核心（router/link）；电路交换 vs 分组交换（统计复用）。
- 分组丢失与时延四分量：nodal（处理/排队/传输/传播）；带宽时延积。
- 分层模型：OSI 5 层/6 层现实；封装与服务语义。

## L02 第 2 章 应用层原理
- 进程通过 socket 与传输层通信；协议定义消息格式与动作。
- C/S：永远在线服务器、可扩展性；P2P：自组织、扩展性与激励机制。
- Web/邮件/DNS/P2P 各场景架构选择的对比。

## L03 HTTP 与 Web 性能
- HTTP 无状态；持久连接 keep-alive、管道化、HTTP/2 多路复用（课程拓展）。
- 缓存：代理缓存与条件 GET；Web 性能度量与往返时延分析。

## L04 DNS 与 CDN
- 层次名字空间：根/顶级/权威服务器；递归 vs 迭代查询；记录类型与缓存 TTL。
- CDN：把内容搬到边缘，DNS 重定向选节点；任播补充。

## L05 Socket 编程与 UDP
- UDP：无连接、不可靠、报文交付；适合实时与自建可靠性场景。
- socket API 要点：sendto/recvfrom；DNS/音视频应用示例。

## L06 第 3 章 传输层原理与可靠传输
- 复用/解复用与校验和。
- 可靠传输原理：rdt 系列（停等 → 流水线 GBN/SR）。
- 序列号回绕与窗口边界条件。

## L07 TCP：连接管理与流量控制
- 字节流 + 序号模型；三次握手/四次挥手与 TIME_WAIT。
- 接收窗口实现端到端流量控制；RTT 估计（SRTT/加权平均）。
- 超时重传的退避策略。

## L08 TCP 拥塞控制
- 拥塞窗口 cwnd：慢启动、拥塞避免、快重传、快恢复。
- 丢包三类事件（超时/冗余 ACK/快重传）的状态转移。
- TCP 公平性、与 RED 队列的联动。

## L09 第 4 章 网络层引言
- 转发（per-hop，数据平面）vs 路由（end-to-end，控制平面）。
- 数据报网络 vs VC 网络；路由器硬件（输入级/交换 fabric/输出级）。

## L10 IPv4/IPv6
- DHCP、NAT 的机制与利弊。
- 子网划分与 CIDR；最长前缀匹配转发。
- 分片重组、TTL；IPv6 主要差异。

## L11 路由算法
- 链路状态（Dijkstra）与距离向量（Bellman-Ford）对比。
- 收敛问题：计数到无穷、毒性逆转。
- OSPF 工程实践。

## L12 层次路由与 BGP
- 域内/域间划分动机（可扩展性与管理自主）。
- BGP：路径属性、策略路由、eBGP/iBGP、路由反射器概念。
- ICMP 差错与 traceroute/ping 应用；多播简介。

## L13 以太网与交换机
- MAC 地址与帧格式；从总线到交换机。
- 自学习转发表与泛洪；STP 生成树破环。

## L14 链路层差错控制与多接入
- 检错/纠错：奇偶、CRC、海明码思想。
- 多接入协议：FDMA/TDMA/CDMA、ALOHA、CSMA/CD 家族。

## L15 无线与移动：802.11
- 信道隐藏/暴露终端 → CSMA/CA + RTS/CTS + ACK。
- 802.11 帧与关联/认证；对比以太网差异。
- 蜂窝（LTE/5G 概览）与 Wi-Fi 的定位差异。

## L16 移动性与总复习
- 转交地址/隧道：移动 IP 思路；网络层 vs 链路层移动性管理。
- 全课程知识图：五层 × 四大协议（HTTP/DNS/TCP/IP）。
- 考点串讲：拥塞控制计算、子网划分、路由算法对比。
