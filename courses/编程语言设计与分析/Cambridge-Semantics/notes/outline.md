# Cambridge Semantics — 逐讲要点骨架

> 骨架级要点；填充时对照 Winskel 章节与公开录像展开，每讲附 1-2 道真题。

## L1 导论：语义是什么
- 同一程序多语言：语义=对"程序做什么"的数学回答。
- BNF 定义简单命令式语言：语法先行。
- 三大范式预告：操作/指称/公理语义。
- 为什么工程师需要语义：并发/类型 bug 的根因层。

## L2 结构归纳与规则式定义
- 归纳定义=最小封闭集；规则（premises/conclusion）读法。
- 结构归纳证明：对"推导树高度"归纳。
- 关系论基础：自反传递闭包作语义工具。
- 练习范式：证明某性质对全部推导成立。

## L3 大步操作语义
- `<c, s> ⇓ s'`：命令+状态→新状态的求值关系。
- 表达式/语句/分块规则的组装方式。
- 大步的局限：不区分发散（divergence）。
- 用 Prolog/Haskell 风格思考规则即递归函数。

## L4 小步操作语义
- 单步归约 →* 自反传递闭包；发散可见。
- 确定性证明套路（规则不相交）。
- 大/小步等价：对推导长度归纳。
- 抽象机雏形：栈式执行与语义联系。

## L5 静态语义：类型系统
- 类型规则：赋值/if/while 的类型前提。
- 良类型=可静态判定的"不会立刻出错"。
- 类型环境 Γ 的作用与弱化（weakening）引理。
- 与 ML 的 `:` 判定记法对齐。

## L6 类型安全
- Progress + Preservation 双定理结构（TAPL 范式）。
- 反证法与 inversion 引理。
- 病态案例：类型系统漏洞如何变成运行期错误。
- 本课程第一次"完整证明"练习。

## L7 λ 演算与函数式数据
- 纯 λ：αβη 与规范化；编码数据。
- 简单类型 λ 演算：强规范化直觉。
- 高阶函数与柯里化的语义。
- OCaml 小练习：手写求值器对照规则。

## L8 子类型与多态初步
- 子类型规则与替换原则（subsumption）。
- 有界/参数多态对照：TAPL ch15-16。
- 记录类型宽度子类型。
- 语义视角：类型解释为集合/偏序包含。

## L9 指称语义 I
- 从"怎么算"到"是什么"：程序=数学对象。
- 偏序集、单调与连续函数、dcpo 与最小不动点。
- flat domain、lift 处理发散。
- 状态的域方程：`State = Var → Nat` 风格。

## L10 指称语义 II
- Tarski/Kleene 不动点定理：while 的语义=算子最小不动点。
- 组合性（compositionality）的兑现：BNF 同构于域方程。
- 命令/表达式域的互递归求解直觉。
- 对比：操作语义的归纳 = 指称语义的连续。

## L11 语义等价与全抽象
- 上下文等价 ≅ 与可观测行为。
- 全抽象：指称相等 ⇔ 观察等价。
- 为何指称模型"太粗/太细"（PCF 全抽象史话）。
- 与程序验证的联系：替换性即等价。

## L12 并发语义与互模拟
- CCS/进程代数：前缀、并行、求和。
- 互模拟（bisimulation）作为行为等价：最大不动点定义。
- 弱互模拟与 τ 抽象。
- 并发 bug 的语义根源：交错非确定。

## L13 总结与路线图
- 三范式对照表：何时用哪种语义。
- 后续四门：类型理论/范畴论/霍尔逻辑/模型检测的入口。
- 课程知识在分析课中的回响：数据流=格上的不动点。
- 个人复习清单：每定理能独立复证。
