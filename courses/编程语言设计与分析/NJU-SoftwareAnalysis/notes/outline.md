# NJU 软件分析 — 逐讲要点骨架

> 骨架级要点；填充时对照讲义章节与作业实验手册展开。

## L1 程序分析导论
- 定义：不运行程序而对其性质做近似推断（静态分析）。
- 两大立场：可靠性（sound，宁可误报）vs 精度；可判定性边界（Rice 定理）。
- 应用版图：优化、缺陷检测、安全验证、程序理解。
- 课程路线图：数据流→指针→IFDS→污点。

## L2 程序表示
- AST→CFG→IR：同一程序的三层抽象。
- Java 字节码与 Jimple/Tai-e IR（三地址、弱类型）。
- 语句分类与数据依赖/控制依赖识别。
- 实验预备：Tai-e 加载类、构建 IR 的最小 API。

## L3 数据流分析框架
- 四元组 (V, L, F, ∧)：方向（前/后向）、格（BitVector 等）。
- 工作表算法与不动点迭代终止性（有限高度格）。
- MOP vs MFP：分配律决定精度差异。
- 手推一遍课后例：这是全课程基本功。

## L4 数据流应用
- 可达定义：拷贝传播与死代码判定的地基（HW1）。
- 活跃变量：后向分析，寄存器分配输入（HW2）。
- 常量传播：带 ⊓ 的平坦格；与 CSE 联动。
- 死代码检测作为可达/活跃的联合应用。

## L5 过程间分析与调用图
- 过程摘要（summary）与上下文：为什么过程内会漏。
- 调用图三件套：CHA（类层次穷举）、RTA（可达类型）、0-CFA（数据流驱动）。
- 虚方法解析是 Java 分析的核心难题。
- HW3：构建三种调用图并对比边数/精度。

## L6 指针分析 I（非上下文敏感）
- Steensgaard 合一式（等价，快而不准）vs Andersen 包含式（0-1 敏感，准而慢）。
- 约束图 + 可达闭包实现 Andersen。
- 基本算法与 on-the-fly 变体。
- HW4/HW5：实现并用于别名/可达性。

## L7 指针分析 II（上下文敏感）
- 上下文建模：调用串（C-call-site）、对象敏感 k-object、堆敏感。
- 上下文复制指针集 → 规模爆炸与剪枝（有限度敏感）。
- k 的选择：精度/开销实测（HW6 数据入笔记）。
- 与 L5 调用图互为迭代输入（ICFA 直觉）。

## L8 指针分析应用
- 别名查询服务优化与验证。
- 逃逸分析→栈分配候选；最终字段→读优化。
- 死对象/内存泄漏检测（引用可达性）。

## L9 污点分析与安全
- 污点 = 格上的后向/前向数据流：source→sink 路径可达。
- taint transfer：传播、净化（sanitizer）、别名传播。
- pTaint/TaintDroid 到 FlowDroid 的谱系。
- HW7/HW8：给定 source/sink 检出真实漏洞样例。

## L10 IFDS 与精确过程间分析
- 分布事实框架 IFDS：多项式复杂度精确过程间数据流。
- 超级图（supergraph）边与摘要传播直觉。
- 污点在 IFDS 下为什么是"金标准"。
- Reps-Horwitz-Sagiv 论文精读指引。

## L11 高级主题
- 并发程序分析：锁集/数据竞争检测。
- 动态分析对照：覆盖率引导、污点的运行时版。
- 机器学习+程序分析趋势简述。

- 版图复盘：从表达式到全程序、从精度到可扩展性。
- 工具对照表：Soot/SootUp、WALA、Tai-e、Doop、CodeQL。
