## 为什么学

- 中文程序分析最佳入门：两位老师逐算法带走流程，听课即可懂，配套 OJ 即学即练。
- 8 个作业覆盖静态分析全栈：编译优化（活跃变量/常量传播/死代码）→ 调用图 → 指针分析（非/上下文敏感）→ 污点分析（安全应用）。
- Tai-e 框架本身就是开源社区活跃的 Java 程序分析平台，作业成果直接对接科研/工业工具。
- 通向 CodeQL/Soot/WALA 等工业分析器与漏洞挖掘岗位的门票课。

## 先修与知识联系

- **先修**：数据结构（图算法/并查集/工作表算法）、Java；建议先修任意编译原理课（AST/CFG/IR 概念复用）。
- **互练**：PKU-SoftwareAnalysis（更广更难：抽象解释/SMT/合成方向）；NJU/PKU 编译课（数据流分析同源）；CS242（理论侧补充）。
- **知识映射**：L3-L6 ↔ 龙书 ch9-10；指针分析 ↔ Andersen/Steensgaard；IFDS ↔ Reps-Horwitz-Sagiv。
