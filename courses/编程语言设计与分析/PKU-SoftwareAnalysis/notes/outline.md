# PKU 软件分析技术 — 逐讲要点骨架

> 骨架级要点；填充时对照当年 syllabus 与讲义展开。

## L1 导论
- 软件分析=对程序性质的自动推断：验证/优化/测试/修复的统一底座。
- 抽象 vs 具体、sound vs precise 的核心张力。
- 课程两大项目预告：指针分析系统（Java）+ 程序合成工具。
- 与 NJU 课差异：本课程向"求解器与新应用"扩展。

## L2 数据流分析与格论
- 格/半格/高度、单调性与不动点（Tarski 直觉）。
- 前向/后向、may/must 的格对偶。
- 工作表算法实现与终止条件。

## L3 过程间分析
- 过程摘要：入口/出口关系压缩。
- 上下文无关 vs 相关；polyvariant 分析。
- IFDS：分布子格上的多项式精确解。

## L4 指针分析
- 包含式（Andersen）与合一式（Steensgaard）再复习。
- 敏感性谱系：调用串/对象/堆/完整性。
- Java 特性难点：虚调用、反射、异常边。

## L5 指针分析项目工作坊
- 架构：IR→约束生成→求解→查询 API。
- 增量与性能：位向量/可达索引（SetBag/Rely 式思路）。
- 评测：别名正确性 + 下游应用（NPE 检测等）。

## L6 抽象解释
- 具体语义→抽象域→α/γ 伴随→soundness 证明义务。
- widen/narrow 保证终止；区间/八面体等数值域。
- Astrée 案例：零误报如何达成。
- 课程视角：一切数据流分析皆抽象解释特例。

## L7 SAT 求解
- DPLL→CDCL：冲突学习、重启、启发式。
- 编码技巧：把分析问题翻译成 CNF。
- 现代求解器生态（CaDiCaL/Glucose/Kissat）。

## L8 SMT 与 Z3
- 理论组合：线性算术/位向量/数组/未解释函数。
- 量词触发器（E-matching）与不可判定性。
- Z3 API：约束式程序分析（如 Rosette/角点脚本）。

## L9 符号执行
- 路径约束累积与 fork 爆炸；状态合并。
- concolical→KLEE/angr 谱系；混合执行。
- 测试生成：覆盖率目标下的路径选择。

## L10 程序合成 I
- 规格→实现：枚举/约束求解/示例引导（PBE）。
- 可学习性与搜索空间剪枝。
- 经典系统：Excel FlashFill 一脉。

## L11 程序合成 II（SyGuS）
- 语法引导合成：在给定文法内搜索。
- CEGIS 循环：反例引导的精化。
- SyGuS-Comp 赛道与策略。

## L12 程序合成项目工作坊
- 目标：为 DSL（字符串/列表/正则）写约束版合成器。
- 架构：规格解析→候选空间→求解/枚举→反例精化。
- 评测：合成成功率与规模曲线。

## L13 缺陷定位
- 频谱统计：失败/通过执行中的语句覆盖差。
- 可疑度公式（Tarantula/Ochiai）与排序评估。
- 与 SBFL/GBFL（学习排序）的衔接。

## L14 自动程序修复与总结
- generate-and-validate 范式（Genprog）→语义修复（ACE/SemFix）。
- 补丁空间设计的演进：从随机到学习引导。
- 全课程复盘：分析（推断性质）与合成（构造程序）是一体两面。
