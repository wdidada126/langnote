## 二、为什么学

1. **"建模是艺术"的课程**：同一个问题，建模时一个小小的改动就可能让求解难度天壤之别；把问题写成"凸的"是本课核心技能。
2. **现代工程的通用求解语言**：控制（MPC）、通信（功率/波束成形）、金融（组合优化）、机器学习（SVM、逻辑回归、图模型推断）、运筹调度、芯片布线与电源完整性，全部落在 LP/QP/SOCP/SDP 的框架里。
3. **对偶与 KKT 是理解算法与系统的透镜**：影子价格、灵敏度、分布式优化（ADMM）、拉格朗基松弛学习都从这里生长。
4. **CVXPY 生态**：Boyd 团队开发的建模框架支持 Python/Julia/MATLAB，作业就是用框架解实际问题，学完即可落地项目。
