# notes/outline.md — Stanford EE364A 凸优化（骨架）

## L1 什么是凸优化
- 一般优化不可解（NP-hard），凸问题多项式时间可解且有全局最优性保证
- 三要素：目标函数、约束、可行集；凸性 = 下水平集与可行集都是凸的
- 课程地图：识别/构造凸问题 → 对偶理解结构 → 算法求解

## L2 凸集
- 凸组合、凸包、锥、仿射像与原像保持凸性
- 多面体（H-表示/V-表示）、椭球、二阶锥、半定锥
- 投影定理：闭凸集上的最近点唯一且非扩张（1-可 Lipschitz）

## L3 凸函数
- 定义 f(θx+(1−θ)y) ≤ θf(x)+(1−θ)f(y)；一阶/二阶判据
- 保持凸性操作：非负加权和、复合（单调规则）、逐点上确界、边缘化
- 重要例子：范数、log-sum-exp、负对数、幂函数、矩阵范数、Boyd–Hansen 型 trace 函数

## L4 标准凸问题族
- LP、QP（凸 QP）、SOCP、几何规划（对数变换后凸化）、SDP
- 规范形式：min f0(x) s.t. fi(x)≤0, Ax=b；局部最优 = 全局最优
- 识别练习：给一个问题，判断它属于哪一族、可用什么求解器

## L5 问题变换与等价形式
- 隐式描述（线性映射的像/原像）、分层约束、变量消去（Schur 补）
- 目标函数转换（epigraph 形式）把非凸目标变凸约束
- 多目标 → 标量化；约束 ↔ 罚函数的等价条件

## L6 对偶：动机与 LP 视角
- 下界思想：用约束的非负加权组合构造目标的下界
- LP 对偶的对称表（ primal/dual 一一对应）与弱对偶
- 例子：最大流–最小割、最小费用流、网络调度

## L7 Lagrangian 与对偶函数
- L(x,λ,ν) = f0 + Σλi fi + Σνj hj；对偶函数 g = inf_x L（点是凸函数的下确界 → 恒凸）
- 共轭函数 f* 与 Fenchel 不等式；指示函数与支撑函数
- 计算 g 的技巧：可分性、矩阵求逆引理

## L8 弱/强对偶与 Slater 条件
- 对偶间隙 = p* − d*；强对偶 d* = p* 的充分条件（Slater 相对内点版本）
- 几何证明：可行集上方图与超平面分离
- 什么时候会失败：非闭、无内点的凸问题

## L9 KKT 条件与灵敏度
- 平稳性 + 原始可行 + 对偶可行 + 互补松弛 ⟹ 最优（凸问题下充要）
- λ* 即影子价格：约束右端扰动对最优值的一阶导数
- 用 KKT 反解问题：许多"解析解"（软阈值、ridge 的对偶形式）来自这里

## L10 对偶应用
- SVM 对偶 = 核方法出现的地方（只依赖内积）
- 最大熵与逻辑回归的对偶、网络效用最大化（分布式 = 对偶分解）
- Lasso 对偶给出特征选择的一个筛选规则

## L11 几何问题
- 点集分离与最近点对 → LP/SOCP 形式
- 多面体包含/分离、最小体积包围椭球（Loewner–John 椭球）
- 分类与鲁棒性：margin 最大化的凸刻画

## L12 无约束凸优化与梯度下降
- L-光滑 + μ-强凸 ⟹ 收敛速率 O((1−μ/L)^k)，条件数决定步速
- 步长规则：常数、回溯线搜索、Nesterov 加速到 O(1/k²)
- 与深度学习优化器的联系（动量、Adam 作为自适应预条件）

## L13 等式约束与牛顿法
- 降维法（消去等式约束）、KKT 系统、扰动分析
- 阻尼牛顿法 + 线搜索的局部二次收敛；Hessian 近似的拟牛顿（BFGS）
- 实际：内点法每次迭代都要解这类线性系统

## L14 内点方法
- 障碍函数（对数障碍）、中心路径参数 t、Newton 步
- 复杂度 O(√ν log(1/ε))：ν 为障碍参数（LP: ν=m；SDP: ν=√n）
- 为什么内点法胜过单纯形（最坏情形），何时选首阶法

## L15 一阶方法与大规模优化
- 次梯度、近端梯度（ISTA/FISTA）、坐标下降
- ADMM：分解 + 对偶上升，适合分布式与大规模结构（Parikh 2014 综述）
- 现代 LLM/系统视角：通信代价 vs 迭代次数的折中

## L16 逼近与拟合
- 最小范数插值、Tikhonov 正则化与样条（Sobolev 空间视角）
- 鲁棒拟合：Huber 损失、L1 拟合（对异常值不敏感）
- 时频域应用：滤波设计与信号恢复

## L17 统计估计
- MLE 在指数族下 = 凸优化；负对数似然的凸性条件
- 稳健估计、最大散度界、EM 作为变分下界最大化
- 方差下界（CRLB）与 Fisher 信息的凸优化求解

## L18 几何拟合与选址
- 设施选址（1-median / k-center 的凸松弛）、数据拟合中的鲁棒 PCA
- 图与网络的凸刻画：电气流、PageRank 的对偶形式
- 多面体拟合、支持向量式描述集合

## L19 组合优化与凸松弛
- 整数规划非凸；LP 松弛（运输问题全单模性 ⟹ 整数最优自动成立）
- SDP 松弛 + 随机化舍入（Max-Cut Goemans–Williamson 0.878）
- 现代：矩/SOS 松弛、凸松弛在 ML 中的经验有效性

## L20 应用综述与回顾
- 控制（MPC、LQR）、电力与经济调度、金融（CVaR 优化）、机器学习
- 电源完整性/芯片布线（Boyd 组的经典应用领域）
- 全课程主线：凸性 = 可信赖计算的边界
