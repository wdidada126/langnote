## 二、为什么学

1. **CS 专业数学的分水岭**：从"会算"过渡到"会证明"，之后 6.042J/CS126/CS170/CS229 全部依赖这套语言。
2. **理论直接落到算法**：扩展欧几里得→RSA、拉格朗日插值→Reed–Solomon 纠错码、稳定匹配→Gale–Shapley、概率方法→哈希与负载均衡。
3. **算法与系统课的门票**：CS170 的正确性证明、6.824/CS149 的并发与随机算法、CS161/6.1600 的密码学基础都在这里。
4. Notes 写得深入浅出，公式推导与实际例子星罗棋布，自学体验极佳；csdiy 作者的学习资料与作业实现汇总在 `PKUFlyingPig/UCB-CS70`。
