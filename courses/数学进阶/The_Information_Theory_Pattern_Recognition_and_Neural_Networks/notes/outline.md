# notes/outline.md — MacKay 信息论、模式识别与神经网络（骨架）

## L1 范围与目标
- 四个领域（信息论、编码、推断、机器学习）是同一个数学对象的四张面孔
- 核心问题：如何在不确定性下最优地压缩、传输与决策
- 全书贯穿的"自由能分解"不等式先给预告

## L2 任务示例：概率预测打字机
- 用语言模型预测下一个字符：概率质量分配 = 压缩方案
- 交叉熵/码长与模型好坏的直接对应
- 从"猜字游戏"引出学习 = 降低惊讶度

## L3 概率论复习与图表示
- 和积规则（sum–product rule）：边缘化与条件化的统一写法
- 概率图是把和积计算"编译"成消息传递的语言
- 期望、方差、协方差与多元高斯（接 18.06 半正定）

## L4 信息熵
- H(x) = −Σ p log p：平均惊讶度、信道无关的信源度量
- 熵的凸性/凹性与极大值在均匀分布
- 联合熵、条件熵、互信息三层关系图

## L5 信源编码与 Huffman
- 唯一可译码 ⟺ 前缀码；Kraft 不等式
- Shannon–Fano–Elias 与 Huffman 的构造与最优性
- 平均码长满足 H ≤ L < H+1：熵是压缩下界

## L6 AEP 典型序列
- 长序列的自信息集中在 2^{nH}：渐近均分性
- 用典型集给信源编码定理的概率证明
- 与 CS126 大数定律的同一性

## L7 数据压缩实践
- 算术编码：把整个消息编成一个 [0,1) 区间（逼近熵）
- 上下文建模 + 自适应概率估计（PPM / 现代模型即压缩器）
- LZW 与字典法的局限；率失真前的"无损"世界

## L8 相对熵与互信息
- KL(p‖q) ≥ 0（Gibbs 不等式）与不对称性
- 互信息 I(X;Y) = 联合分布与乘积边缘的距离
- 数据处理不等式：信息只能被处理掉，不能凭空增加

## L9 信道容量
- C = max_{p(x)} I(X;Y)：信道能可靠传输的极限速率
- DMC 容量的凹优化性质与 Blahut–Arimoto 迭代算法
- 例子：BSC、BEC、Z 信道

## L10 有噪信道编码定理
- R < C ⟹ 存在码使错误率任意小；R > C ⟹ 不可能
- 随机编码论证的直觉；"坏消息"与 Shannon 的第二定理
- 工程含义：分离原理与有限码长的现实差距

## L11 线性码
- 码作为有限域上的子空间；生成矩阵 G、校验矩阵 H
- 伴随式译码 = 最小重量陪集首问题（NP-hard 的入口）
- 与 18.06 的列空间/零空间完全对应

## L12 对称信道与最佳译码
- 最大后验 = 最大似然（先验均匀时）
- 硬判决 vs 软判决：保留信道可靠性信息的收益
- 错误概率与最小距离界

## L13 编码系统的信息论极限
- 码率 R = k/n 与功率/带宽效率的折中
- Hamming 界、Gilbert–Varshamov 界与容量线的关系
- 为什么"好码必须又长又随机"的直觉

## L14 Turbo 码
- 两个短码 + 交织器 + 迭代软输入软输出（SISO）译码
- 外信息交换避免自我强化；逼近容量的现象学解释
- 历史意义：1993 年让编码理论界重新审视 Shannon

## L15 LDPC 码
- MacKay & Neal 1995/1999 的稀疏校验图与和积译码
- 度分布设计与密度进化（水填）→ 逼近容量
- 现代地位：5G 数据信道、Wi-Fi、SSD、深空通信

## L16 概率推断即解码
- 把"信道 + 编码 + 噪声"看成"先验 + 模型 + 观测"
- 译码 = MAP 推断；噪声信道是似然函数
- 这一视角让通信与 ML 共用一套算法

## L17 图模型
- 贝叶斯网（有向，表达条件独立）与马尔可夫网（无向，因子分解）
- d-分离与图的结构独立性判据
- 例：基因调控、故障诊断、语言模型

## L18 因子图与和积算法
- 因子图把任意分解都变成二部图消息传递
- 树形图上和积算法给出精确后验；复杂度随稀疏性
- 与 Viterbi/Kalman 的统一（链式因子图特例）

## L19 再访编码：译码作为推断
- LDPC 译码 = 因子图上的和积算法
- 置信传播的消息是"边缘后验"；迭代次数即收敛预算
- 短路/环对性能的影响

## L20 和积算法的局限与近似推断
- 带环图上 BP 可能不收敛/给近似结果
- 期望传播（EP）、变分近似、环路树修正
- 现代对应：GNN/图上的消息传递与摊销推断

## L21 蒙特卡洛方法
- 采样估计难以计算的期望；重要性采样与方差
- Metropolis–Hastings 与 Gibbs：构造平稳分布为目标的链（接 CS126）
- 混合蒙特卡洛（HMC）与退火；混合链思想

## L22 决策论与模型比较
- 最小期望损失、0-1 损失 → MAP，平方损失 → 后验均值
- 贝叶斯证据与奥卡姆剃刀：模型复杂度自动惩罚
- 为什么"预测概率"要用对数损失评分

## L23 机器学习框架
- 训练集 → 似然 → 交叉熵损失 = KL + 常数
- 模型容量与过拟合；泛化误差的贝叶斯视角
- 与 CS229/CS231n 术语表的对齐

## L24 神经网络与反向传播
- 多层感知机与通用逼近；损失面非凸
- 反向传播 = 计算图上的链式法则（18.02 多元链式）
- MacKay 对神经网络与推断关系的独特解读（"神经网络的贝叶斯视角"）

## L25 训练技巧与混合密度网络
- 权重衰减 = 高斯先验；早停 = 近似贝叶斯积分
- 混合密度网络（MDN）：用高斯混合表达多峰条件分布
- 现代回响：扩散模型 / 流的密度表达需求

## L26 模型选择与证据近似
- Laplace 近似、贝叶斯证据与模型后验
- 交叉验证与贝叶斯模型比较的一致与分歧
- 变分自由能作为证据下界（ELBO）

## L27 卷积与对称性先验
- 平移不变性 → 卷积核共享；这是"先验知识编程"
- 群等变性的早期表述（现代等变网络的前身）
- 感受野、参数效率与归纳偏置

## L28 主成分分析
- 最小重构误差 ⟺ 最大方差 ⟺ 协方差矩阵特征分解
- 概率 PCA 与因子分析：低秩高斯的极大似然
- 与 SVD/低秩近似（18.06、18.330）闭环

## L29 混合模型与 EM
- 隐变量模型；E 步求期望、M 步最大化下界
- EM 单调提升变分下界的证明（自由能分解的直接应用）
- 初始化敏感、局部最优、与变分法的界限

## L30 独立成分分析与盲源分离
- 非高斯性度量（峰度/负熵）+ 正交变换优化
- 信息最大化准则；FastICA 的数学内核
- 自然编码假说：视觉皮层学到类似 Gabor 的基（现代对应：字典学习/稀疏编码）

## L31 隐马尔可夫模型
- 转移 + 发射；前向滤波、后向平滑、Viterbi
- Baum–Welch 即 EM 在 HMM 上的实例
- 语音识别、行为识别、生物序列

## L32 连续信道与率失真
- 高斯信道容量 C = B log2(1+SNR)（接 6.007/EE120）
- 率失真函数 R(D)：允许失真 D 时的最小码率
- 反向水位分配（reverse water-filling）的直觉

## L33 编码与调制的联合
- 比特交织编码调制（BICM）与映射增益
- 信道可靠性 → 软信息 → 译码器充分利用
- 现代对应：LLR、QAM 解调与联合信源信道编码（DeepJSCC）

## L34 采样与量化
- 奈奎斯特采样、混叠与重建（6.007/EE120 的重复与深化）
- 量化误差的噪声建模；标量 vs 矢量量化
- 率失真视角下的比特分配

## L35 贝叶斯与频率派之争
- 两个传统对"概率"与"模型"的根本分歧
- 无免费午餐定理：没有先验就没有泛化
- 工程态度：用预测性能（对数损失）而非哲学立场裁决

## L36 计算的极限
- 图灵机、不可判定性与哥德尔式自指
- "学习"能否机械化？可计算 vs 可行 vs 最优
- MacKay 的反思：智能与推断的关系

## L37 统一视角：自由能分解
- −ln P(D) = F + KL(q‖P)，任何推断都是最小化 F
- 压缩、推断、学习、决策四件事在同一个式子上汇合

## L38 展望：MacKay 思想的现代回响
- ELBO/VAE、扩散模型、消息传递与 GNN 中的因子图
- LDPC 在存储与通信标准中的统治地位
- 稀疏编码/字典学习在表示学习中的延续
