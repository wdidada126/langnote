## 二、为什么学

1. **一条主线串起四个领域**：信息论 ↔ 统计推断 ↔ 编码 ↔ 机器学习本质上是同一件事——在不确定性下做最优压缩、最优推断与最优传输。MacKay 是极少数能把这四件事写成一本书的人。
2. **现代 ML 的理论血脉**：交叉熵损失、变分推断、EM、消息传递（BP）、蒙特卡洛、稀疏编码、神经网络容量分析——今天的深度学习与生成模型仍在用他书中整理的语言。
3. **编码理论的经典与前沿交汇点**：他在书中讲解的 LDPC 码后来成为 4G/5G/Wi-Fi 的数据信道标准码，是"理论论文 → 工业标准"最漂亮的案例之一。
4. **免费 + 高质量**：教材 PDF 官方免费、视频免费、习题解答可得，是最适合自学的研究生级课程之一。
