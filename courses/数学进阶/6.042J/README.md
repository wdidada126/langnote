## 二、为什么学

1. **MIT 版"CS 数学"总纲**：一门课覆盖证明、图论、数论、代数结构、计数与概率，是 6.006/6.046 算法课的官方前置。
2. **证明训练最扎实**：良序原理 ↔ 归纳 ↔ 强归纳等价性的讲法，直接服务于程序正确性、并发推理与形式化方法。
3. **数论到 RSA 的完整链路**：模运算 → 快速幂 → 欧拉定理 → 素性测试，学完能真正读懂密码学论文的前提假设。
4. **生成函数 + 分支过程**：递推求解与随机算法分析（例如快速失败的概率）在这套工具下变得可计算。
5. 与 CS70 高度互补：CS70 偏算法应用与伯克利风格，6.042J 偏 MIT 的结构化讲义与海量习题，两门任选一门精学、另一门查漏补缺。
