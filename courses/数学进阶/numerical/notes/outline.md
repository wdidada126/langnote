# notes/outline.md — MIT 18.330 数值分析（Julia，骨架）

## L1 课程导论与 Julia 速览
- 数值分析三问：如何建立估计 → 如何估计误差 → 如何用算法实现估计
- Julia：多重派发、类型稳定、`@benchmark`、向量化与视图（避免拷贝）
- 与 C/Python 的关系：可读性接近 Python，性能接近 C

## L2 浮点数与机器精度
- IEEE 754：符号/指数/尾数，规格化与非规格化数
- 机器精度 ε、ulp；舍入模式与"加法不满足结合律"
- 灾难性抵消：二次方程求根的数值稳定形式

## L3 条件数与稳定性
- 问题条件数（输入扰动 → 输出扰动放大倍数）与算法稳定性分离
- 后向稳定 = "精确求解了一个稍被扰动的问题"（Wilkinson 的核心概念）
- 例子：求根的多重性、矩阵求逆、插值的 Lebesgue 常数

## L4 多项式插值
- Lagrange 与 Newton 形式；误差公式含 f^{(n+1)}/(n+1)!
- Runge 现象：等距节点高次插值发散 → 切比雪夫节点
- 嵌套 Horner 求值的数值优点（求值/求导/差分通用）

## L5 分段插值与样条
- 分段线性 → 三次样条：连续性 + 最小曲率能量
- 三对角方程组求解（Thomas 算法）O(n)
- 形状保持、单调插值（PCHIP）与图形/仿真中的网格生成

## L6 数值积分（求积）
- Newton–Cotes：梯形（O(h²)）、Simpson（O(h⁴)）与误差项
- Gauss–Legendre 求积：n 个节点精确到 2n−1 次
- 自适应求积与 Richardson 外推（Romberg）

## L7 数值微分
- 前向/中心差分与截断-舍入权衡：最优步长 h ≈ ε^{1/2}(前向)/ε^{1/3}(中心)
- Richardson 外推提高阶数；五点 stencil
- 与自动微分的区别：有限差分有误差，AD 是精确导数（机器精度内）

## L8 非线性求根
- 二分（线性收敛、稳健）、Newton（二次收敛、需导数与好初值）、割线（超线性 φ）
- 收敛阶的局部分析 + 阻尼/回溯保证全局收敛
- 单变量到多变量：牛顿法的雅可比与准牛顿

## L9 方程组与同伦
- 多变量牛顿法、雅可比条件数与奇异情形
- 同伦延拓：把难问题连到易问题的根路径追踪
- 应用：电路工作点、非线性材料、多项式系统求所有根

## L10 线性方程组直接法
- Gauss 消元 → LU；部分选主元保证稳定性；O(2n³/3)  flops
- 稀疏与带状矩阵：Cholesky（正定）、banded 分解、带宽对填充的影响
- 残差迭代精化（iterative refinement）与混合精度

## L11 正交性与最小二乘
- QR 分解（Gram–Schmidt/ Householder）→ 稳定的最小二乘
- 正规方程 AᵀA 的条件数平方化：为什么数值上优先 QR/SVD
- 加权最小二乘、Tikhonov 正则化与截断 SVD

## L12 迭代法与预条件
- Jacobi / Gauss–Seidel 收敛的谱半径判据；CG 对对称正定的最优性
- Krylov 子空间思想（Arnoldi/GMRES）；预条件矩阵设计
- 大规模稀疏问题：矩阵向量乘成为唯一原语（内存层级决定性能）

## L13 特征值算法
- 幂法与反幂法、正交迭代求不变子空间
- QR 算法 + Hessenberg 约化 + 位移 → 全部特征值
- 特征值敏感性（简单 vs 重根、非正规矩阵的伪谱）

## L14 SVD 与低秩近似
- 计算 SVD 的数值路径（双对角化 + QR）
- Eckart–Young 最优低秩近似；秩揭示与数值秩判定
- 应用：PCA、图像压缩、推荐系统、去噪与病态反问题

## L15 ODE 初值问题
- 显式 Euler（O(h)）、改进 Euler/RK4（O(h⁴)）；局部 vs 全局误差
- 单步法的稳定性函数与绝对稳定区域
- 事件检测（过零）、插值稠密输出

## L16 刚性问题与自适应
- 刚性比导致的显式方法崩溃；隐式方法与 BDF/Radau
- 自适应步长控制（嵌入对、误差估计器）与容差选择
- Julia 实践：DifferentialEquations.jl 的算法族与基准

## L17 FFT 与快速多项式运算
- Cooley–Tukey 分治：O(n log n)，单位根的平方对称性
- 频域卷积、多项式乘法、大整数乘法
- 谱插值与重采样；数值微分的谱方法（Kanal 谱求导）

## L18 高维插值 / BVP / PDE
- 高维灾难：张量积网格指数增长 → 散点插值与径向基
- 两点边值问题：打靶法 vs 有限差分离散 → 稀疏线性系统
- 热/波方程：CFL 条件、能量方法与稳定性（与图形学仿真同源）

## L19 随机数与蒙特卡洛
- 线性同余/PCG/xoshiro 发生器与统计检验；周期与幂次模问题
- 逆变换、拒绝采样、Metropolis-Hastings 入门
- 蒙特卡洛积分收敛阶 O(N^{-1/2}) 与维度无关 → 高维必用；方差缩减（对偶变量、控制变量、QMC）

## L20 数据分析与复盘
- 主成分分析、低秩逼近、时间序列平滑（Savitzky–Golay）
- 精度预算表：截断误差 / 舍入误差 / 模型误差各占多少
- 可重现性：种子、BLAS 版本、并行归约顺序对结果的影响
