## 二、为什么学

1. **随机过程与统计推断是 CS 的高级必修**：排队论（系统调度）、马尔可夫链（PageRank、RL）、检测与估计（感知与通信）、随机算法分析全部要求这套语言。
2. **CS70 概率部分的正式版**：CS70 只给离散概率入门，CS126 补齐连续随机变量、多变量、极限定理与随机过程。
3. **强化学习与图模型的直接前置**：CS188（MDP/贝叶斯网络）、CS229（生成模型/EM）、10-708 PGM、CS285（策略梯度）依赖其中的条件期望、马尔可夫性与平稳分布。
4. Walrand 的书强调**"一个算法配一个定理"**，理论—实践的闭环做得比一般教材好。
