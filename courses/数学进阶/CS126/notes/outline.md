# notes/outline.md — UCB EE C126 概率论（骨架）

## L1 概率空间
- 三元组 (Ω, F, P)：样本空间、事件域（σ-代数）、概率测度
- 公理：非负、规范性、可列可加；由此推出容斥与连续性
- 建模第一步永远是"选对样本空间"（Walrand 每章的入口）

## L2 条件概率与独立性
- P(A|B) 与全概率公式；贝叶斯规则 = 逆向条件化
- 独立性 vs 互不相容：常见混淆点
- 基率谬误与"检验悖论"（医疗检测例子）

## L3 离散随机变量
- 分布律 p_X；常见族：Bernoulli、Binomial、Geometric、Poisson
- 指示器分解技巧：E[X] = Σ P(A_i)
- Lab1 用 PageRank 的链接矩阵引入"随机变量 = 函数"

## L4 期望、方差与矩
- 期望的线性性（不需独立）与凸性；Jensen 不等式
- Var(X)=E[X²]−E[X]²；协方差与相关系数
- 矩生成函数作为"分布的指纹"

## L5 多随机变量
- 联合分布、边缘化、条件分布；独立性判据 p_{XY}=p_X p_Y
- 条件期望 E[X|Y] 是"给定的最佳猜测"（L2 投影视角）
- 全期望公式（塔性质）是后续 MMSE 与 RL 的核心

## L6 独立和与卷积
- 和的分布 = 卷积；几何/泊松/高斯的可加性
- 生成函数（PGF/MGF）把卷积变乘法
- 应用：负载均衡、误差累积分析

## L7 极限定理 I
- Markov：P(X≥a) ≤ E[X]/a；Chebyshev：仅用均值方差控尾
- 弱大数定律：样本均值依概率收敛到期望
- 为什么"独立同分布"是收敛证明的必要假设

## L8 极限定理 II（CLT）
- 标准化和 → N(0,1)；误差量级 1/√n
- 用 CLT 给置信区间与近似样本量估计
- Lab3：数值验证收敛速度，对比 Chernoff 界的紧度

## L9 连续随机变量
- 通过 CDF 定义分布；PDF = 导数（几乎处处）
- P(a≤X≤b)=∫ f；点概率为 0 的含义与"条件在零测集上"
- 分位数函数与逆变换抽样（L19、蒙特卡洛接口）

## L10 常见连续分布
- Uniform、Exponential（无记忆性）、Gaussian（线性变换仍高斯）
- 指数与泊松的对偶：到达间隔 vs 计数
- Erlang、Gamma、Beta 的用途速查

## L11 联合密度与条件密度
- f_{X|Y} = f_{XY}/f_Y；边缘化 = 对另一变量积分
- 多元高斯的协方差矩阵与相关（18.06 半正定）
- 条件化 + 全概率 = 贝叶斯网的推理原子

## L12 变量变换
- Y=g(X)：单调用导数、非单调分段、多维用雅可比行列式
- 和/积/商的分布（卷积与 Mellin 视角）
- 18.02 的换元积分在此高频复用

## L13 条件期望与 MMSE 估计
- E[X|Y] 是最小均方误差意义下的最优估计
- 正交性原理：误差与 Y 的任何函数正交（投影定理）
- 线性高斯情形 → Kalman 滤波雏形

## L14 泊松过程入门
- 计数过程公理（独立增量 + 平稳增量）→ 泊松分布
- 到达间隔服从指数分布；厚尾/无记忆的取舍
- 系统性能建模的标准随机流假设

## L15 马尔可夫链
- 转移矩阵 P、Chapman–Kolmogorov：P^{n+m}=P^n P^m
- 状态分类：常返/瞬过、周期、不可约
- 与 18.06 幂迭代的直接对应（特征值 1 的结构）

## L16 平稳分布与收敛
- π = πP：左特征向量；遍历定理保证时间平均 = 空间平均
- 收敛速度由第二大特征值隙（spectral gap）决定
- 可逆性与详细平衡方程（MCMC 的正确性来源）

## L17 吸收链与首达时间
- 基本矩阵 N = (I−Q)⁻¹ 给期望访问次数
- 赌徒破产与吸收概率；一维随机行走的成败
- 应用：可靠性、算法终止时间分析

## L18 泊松过程深化
- 合并/拆分/稀释保持泊松性；非齐次泊松过程
- 均衡与残余寿命悖论（inspection paradox）
- Lab7：模拟到达过程并做排队实验

## L19 鞅与可选停止
- 鞅 = "公平赌局"；上/下鞅给集中不等式
- 可选停止定理与条件；Azuma–Hoeffding
- 随机算法分析与浓度不等式的现代入口

## L20 排队论
- M/M/1：PASTA、Little 定律 L = λW、利用率与延迟爆炸
- M/G/1 的 Pollaczek–Khinchine（结论级理解）
- 与操作系统/分布式系统性能分析的连接

## L21 参数估计
- 似然函数、MLE 与其渐近正态性；Fisher 信息与 CRLB
- 矩估计 vs MLE；充分统计量与因子化定理
- Lab8：从噪声样本反推参数并画置信区间

## L22 假设检验与检测
- N–P 引理：固定虚警率下的最优似然比检验
- ROC 曲线、AUC；贝叶斯检测（先验 + 代价）
- 应用：入侵检测、异常检测、匹配阈值

## L23 贝叶斯推断
- 后验 ∝ 似然 × 先验；共轭先验的便利
- MAP vs 后验均值；credible interval
- 与 ML 中的正则化对应（L2 = 高斯先验）

## L24 HMM 与滤波
- 隐状态 + 发射模型；前向滤波、Viterbi、后向平滑
- 语音识别（Lab9）、POS 标注、行为识别的共同结构
- 递推贝叶斯：状态空间模型的离散时间版

## L25 MDP 与随机优化展望
- 状态—动作—转移—回报；Bellman 方程 = 马尔可夫决策的核心
- 策略迭代收敛的概率论证；值函数即期望回报
- 通往 CS188 / CS285 / 10-708 的桥梁
