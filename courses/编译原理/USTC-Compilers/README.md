## 为什么学

- 理论面覆盖最全的中文编译课之一：传统前端 + 运行时管理 + 机器无关/面向机器优化全线打通。
- 实验采用**现代 LLVM 子集 LightIR** 作中间代码，并生成**龙芯（LoongArch）汇编**后端——国内少见的前瞻配置，堪称国际一流实践课。
- 6 个实验循序渐进（Flex/Bison 前端→IR 生成→后端→两级优化→寄存器分配），自动化测试脚本 + 完整教程，自学友好。
- 课件、框架代码、教程全套开源，B 站有完整授课视频。

## 先修与知识联系

- **先修**：CSAPP 级系统基础、C++；建议先了解一门 RISC ISA。
- **互练**：CS420（同为 IR 中心路线，但 LLVM IR vs LightIR、RISC-V vs LoongArch）；SJTU（虎书 + LLVM 全量）；CS143（补 LR 理论）。
- **知识映射**：Lab1-Lab6 分别对应龙书 ch3-4（前端）、ch8（翻译）、ch9（代码生成）、ch10（优化）。
