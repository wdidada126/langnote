## 为什么学

- 独特的"先用 ANTLR 4 做出小例子，再回头补理论"教学顺序，带着问题学理论，反馈快。
- ANTLR 4 是工业级 LL 解析器生成器（IDE 插件可即时可视化语法树），学的工具直接可用。
- 校外学习者待遇极好：公开 OJ、公开 Zulip、历年资料齐全——国内自学体验最佳之一的编译课。
- 10 次书面作业 + 8~10 次编程作业，逐步实现自己的编译器，理论与实践双轨。

## 先修与知识联系

- **先修**：离散数学（文法/自动图论基础）、Java（课程统一语言）。
- **互练**：CS143（同为龙书理论主线，可对照 LR vs LL 路线）；PKU-Compilers（同为增量式实现）；NJU-SoftwareAnalysis（前端产物 CFG/IR 正是分析输入）。
- **知识映射**：理论线按龙书 ch2-ch10；实践线 = mini-C 语言子集逐特性编译。
