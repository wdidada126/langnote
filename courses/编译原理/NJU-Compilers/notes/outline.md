# NJU 编译原理 — 逐讲要点骨架

> 骨架级要点，填充时对照官网讲义展开并配 ANTLR 实验代码索引。

## L1 课程导论：编译器全景与 ANTLR 入门
- 编译四阶段全景：词法→语法→语义→中端/后端；本课程用 ANTLR 4 分担模板代码。
- LL 解析器生成器 vs LR/LALR：ANTLR 支持"无限前瞻"，可处理语法范围更广。
- 第一课就动手：跑通一个四则运算小语言的解析示例。
- 课程约定：Java 实现、书面作业 + 编程作业、OJ 提交。

## L2 词法分析实践
- 用 .g4 文件写词法规则：pattern→token 的映射即 DFA 建模。
- 关键字/标识符冲突消解、最长匹配原则。
- 词法器输出 token 流的结构：位置信息对报错的重要性。
- 理论对照：正则表达式→NFA→DFA 的转换链（龙书 ch3）。

## L3 语法分析实践
- 语法规则到 AST：ANTLR visitor/listener 两种遍历风格。
- 用 AST 写小解释器：理解"语法树是语义的地基"。
- 左递归处理与文法改写直觉。
- IDE 插件即时可视化语法树的调试工作流。

## L4 文法与自动机理论回填
- 正规式、DFA/NFA 等价性——解释 L2 中 ANTLR 做了什么。
- CFG、推导与规范句型的直觉。
- 歧义文法：表达式优先级的文法化表达。
- 先实践后理论：每节都回指已做过的实验。

## L5 自顶向下解析理论
- LL(1) 条件、FIRST/FOLLOW 集构造与冲突检测。
- 递归下降 = 手写 LL(1)；predict 决策的可视化。
- 回溯与 ALL(\*) 的折中（ANTLR 的自适应预测）。
- 书面作业高频：给定文法判 LL(1)。

## L6 自底向上解析理论
- 移进-规约、句柄与活前缀；LR 项目集族构造。
- SLR/LALR/LR(1) 强度对比与典型冲突（dangling else）。
- yacc/bison 工作流一览（对照 ANTLR 路线）。
- 理解编译器前端"生成器 vs 手写"的工程取舍。

## L7 语义分析
- 符号表：作用域栈与链式结构；声明即绑定。
- 类型检查规则化：类型等价、赋值兼容、函数原型。
- 类型错误恢复策略（恐慌模式 vs 短语级恢复）。
- Java 实践：给 L3 的 AST 补上 checker。

## L8 运行时环境
- 激活记录：局部区、显示/隐式静态链、动态链。
- 块结构与嵌套过程的地址计算（display 表）。
- 参数传递方式：值/引用/值结果语义差异。
- 与 Java 虚拟机调用栈对照理解。

## L9 中间代码
- 三地址码三形态：quadruples/triples/SSA 风格。
- 为本课程 mini-C 设计 IR 的练习：够用即好。
- AST→IR 的语法制导翻译模板。
- DAG 与公共子表达式表示。

## L10 控制流与函数调用翻译
- 布尔表达式：短路翻译与回填（backpatch）。
- if/while/switch 到跳转表。
- call/return 序列与栈帧协作。
- 输出可验证：小解释器跑 IR 自检。

## L11 数据流分析
- 框架四元组：方向/格/转移函数/合流；不动点迭代。
- 可达定义、活跃变量、到达拷贝实例。
- 基本块与流图构建规范。
- MOP vs MFP、分配律与精度。

## L12 寄存器分配与指令选择
- 指令选择的树模式覆盖直觉。
- 图着色 RA：干涉图、spilling、合并。
- SSA 上的 RA（live range splitting）概览。
- Java 版玩具 RA 实验。

## L13 代码优化
- 常量传播/复制传播/归纳变量删除。
- 死代码删除与可达性。
- 循环优化：强度削弱、代码外提、展开。
- 正确性论证：优化即数据流不动点保持。

## L14 综合实验
- 全管线贯通：mini-C 子集从源码到目标码。
- OJ 测试用例组织与增量回归。
- 复盘：每阶段"为什么这么做、还能怎么做"。
- 通往后续课程：对照 LLVM（SJTU/CS420 路线）。
