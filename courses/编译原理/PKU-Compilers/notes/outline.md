# PKU 编译原理实践 — 逐讲要点骨架

> 每讲 3-5 条骨架级要点，正文填充时逐条展开并附代码索引。

## L1 走近编译器与实验环境
- 编译器 = 源语言到目标语言的翻译程序；本课程只要求输出正确的 RISC-V 汇编，内部设计完全自由。
- Koopa IR 定位：类 LLVM IR 的简化中间表示，配套运行时库负责解析/生成/输出，绕开基建细节。
- Docker 一键环境：sky 编译器骨架 + auto_test 脚本；先跑通"空编译器"再增量扩展。
- 建立心智模型：前端（词法/语法/语义）→ 中端（IR 优化）→ 后端（指令选择/寄存器分配）三段式。

## L2 最简编译器：只处理 main 函数
- 目标：编译 `int main() { return 0; }`，端到端打通"读入源码→输出汇编→链接运行"最短回路。
- 手写最小词法扫描与递归下降入口，体会"能跑通的玩具"比"完美的设计"更重要。
- 输出汇编的骨架：`.text`、全局符号 `main`、`li a0, 0` + `ret`、调用约定初识。
- 迭代式开发方法论：每次只加一个语言特性，测试驱动。

## L3 词法分析与语法分析
- 词法规则用正则描述，交给工具（flex/logos）生成 token 流；理解 DFA 驱动扫描。
- 文法用 BNF（SysY 规范），工具生成解析器或手写递归下降，产出 AST。
- 语义分析阶段自己写：遍历 AST 检查类型、作用域（本课程要求较松）。
- 关键点：工具代劳"枯燥苦力活"，AST 之后的 IR 生成与代码生成才是核心。

## L4 算术表达式
- AST→Koopa IR：每个表达式对应一条 SSA 风格的赋值指令（`%x = add %a %b`）。
- IR→RISC-V：临时变量到寄存器/栈槽的朴素映射，感受"指令选择"雏形。
- 常量折叠等局部优化可在任意一层做，体会分层设计收益。
- 测试：只含 return 表达式的程序集，逐步加深。

## L5 变量与赋值
- 局部变量生命周期：函数级栈帧内分配；理解 ldst（load/store）类 IR 指令。
- 赋值语义：名字→内存位置的绑定，符号表承担映射职责。
- 标量与内存的取舍：暂时全部下栈即可正确，性能优化留给后面。

## L6 逻辑表达式与控制流
- if/while 翻译：基本块划分 + 条件跳转 + 标签回填。
- 短路求值（&& / ||）的分支化翻译，或无分支的条件选择实现。
- Koopa IR 的 CFG：块（block）与终结指令（br/jmp）；与龙书"布尔表达式翻译"对照。
- 坑：循环内 break/continue 的多出口管理。

## L7 函数与调用
- RISC-V 调用约定：a0-a7 入参、ra/sp、保存者/调用者保存寄存器。
- 栈帧布局：局部变量区 + 保存的 ra/s0；帧指针链。
- IR 的 `call` 指令与返回值传递；递归天然支持（栈式运行时）。
- 理解"编译期决定布局、运行期动态增长"的分界。

## L8 数组
- 数组名→基地址，下标→地址计算：`addr = base + (i0*d1*d2+...+in)*4`。
- 多维数组的行主序线性化；常量下标与非常量下标的路径差异。
- IR 层的 getelementptr 风格地址计算指令（Koopa `getelem`/`bitcast`）。
- 全局数组（静态初始化数据）与局部数组（栈上）分配位置的区别。

## L9 综合实战
- 编译复杂程序：曼德布洛特绘图、浮点运算（F 扩展）、Lisp 自解释器。
- 浮点数与整数的转换、比较指令在 RISC-V 上的处理。
- 调试方法论：小测试用例二分、汇编 diff、spike/模拟器单步。
- 成果验收：通过全部官方测试即达课程目标。

## L10 挑战任务（选做）
- 实现 SysY 运行时库（`putint`/`getint` 等系统调用封装）。
- 朴素优化起步：常量传播、CSE、临时变量提升为寄存器（内存提升）。
- 参考 compiler2022-sky 的迭代版本对照自己的设计空间。
- 衔接竞赛：SysY 评测平台的性能赛规则与常用优化清单。
