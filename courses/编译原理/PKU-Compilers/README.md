## 为什么学

- 国内最友好的"零编译器基础"实战课：只输出 RISC-V 汇编、不限定内部设计，成就感直接（能编译 Mandelbrot、Lisp 解释器）。
- 2022 版引入 Koopa IR（类 LLVM IR 的简化中间表示）+ 配套运行时库，把"编译器大工程"拆成 9 个增量小步骤，反馈周期极短。
- 与 SysY 竞赛同源：完成后可直接参加全国大学生计算机系统能力大赛编译系统设计赛。
- Docker 一键环境 + 自动测试脚本，自学体验在同类课程中最好。

## 先修与知识联系

- **先修**：CSAPP/计组级别（了解 RISC-V 调用约定、栈帧）、C++ 或 Rust。
- **互练**：CS143（理论对照：本课程不细讲 LL/LR 理论，工具代劳前端）；CS420/SJTU（同走 IR→优化→后端路线）；USTC（同为 LLVM 风格 IR）。
- **知识映射**：L4-L9 增量实现 ↔ 龙书 ch7（运行时）/ch8（翻译与中间代码）/ch9（后端）。
