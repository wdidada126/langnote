# L14 机器无关优化引论：数据流分析框架

> 讲次：CS143 L14 ｜ 阅读：龙书 ch9.1-9.2, 9.4 ｜ 对应 HW5 前半；L16/L17 的活跃性、可用表达式、常量传播全部建立在本讲框架上

## 核心概念

### 数据流框架四件套
- 域 D：状态空间（如 USE/DEF 变量集、常量映射、可达定义对集）。
- 转移函数 F：每条语句 `f: D → D`（前向框架是 gen/kill 风格）。
- 交汇算子 ∧：如 ∪ / ∩——在 CFG 汇合点合并信息。
- 方向与初始化：前向（entry 已知，exit 待求）或后向（exit 已知）；乐观初始化（=∧ 单位元或 ⊤）与悲观初始化的区别。

### 格（lattice）与单调性——收敛性的数学保证
```
常量传播格的元素:  nac(非常量) ⊓ c(某常数)；⊤ = UNDEF, ⊥ = NAC
单调转移: f(x ⊓ y) ⊑ f(x) ⊓ f(y) —— 保证不动点存在且迭代收敛。
可分配(distributive)框架（如可达定义）：工作列表顺序无关收敛值。
非常量传播（CP 不满足分配律）：迭代顺序可能得到不同（仍安全）的解——龙书 9.4 例题 9.25 级考点。
```

### 统一算法：迭代工作列表
```
repeat
  for each block B:
    IN[B]  = ∧_{P ∈ pred(B)} OUT[P]     // 前向
    OUT[B] = f_B(IN[B])
until 所有 IN/OUT 不再变化
```
- 求解顺序影响步数：reverse postorder（RPO，L17 支配树给出定义）下可达定义 ≤ 轮数≈回边深度+2，实践 2-3 轮收敛。
- gen/kill 方程形式：`OUT = (IN − kill) ∪ gen`——把"语句效果"写成集合代数是 HW5 的标配。

### 经典框架速查（为 L16-L17 备料）
| 框架 | 域 | 方向 | 用途 |
| --- | --- | --- | --- |
| 可达定义 | def 对集 | 前向 ∪ | 死代码、常量的前提 |
| 活跃变量 USE/DEF | 变量集 | 后向 ∪ | L16 寄存器分配 |
| 到达表达式 | (A->e) 对 | 前向 ∪ | GVN/L17 |
| 可用表达式 | 表达式集 | 前向 ∩ | 公共子表达式消除 |
| 常量传播 | 格映射 | 前向 ∩ | L17 传播与折叠 |

- 上承 L12-L13（没有 CFG 就没有数据流）；下启 L16（活跃性=后向框架的应用）、L17（每个优化≈一个查询）。

- **6.006/CS170**：单调框架迭代 = 图上的定点算法（与 Bellman-Ford 的"松弛直到不变"同构）；Cousot 格理论把两者统一为完备格上的单调函数迭代（Tarski 定点定理）。
- **CS149/MIT6.824**：数据流分析是"信息沿依赖图异步传播直到共识"的编译器版本——与 Gossip/迭代收敛的并行化（worklist 分片、乐观并行）共享研究脉络。
- **CS242/软件分析方向**：NJU 软件分析课程（数据流/抽象解释）正是本讲框架的专题放大；Z3/CBMC 的符号执行可视为"路径敏感版数据流"。
- **CS188**：值迭代 = 状态图上后向数据流（效用沿转移传播）——AI 搜索课与优化课共用一个不动点。

## 开源项目中的应用
- **LLVM**：新 `llvm/Analysis` + `include/llvm/Analysis/*`（如 LiveVariables、SparsePropagation 的 worklist 实现）是教科书算法的直接放大；"DataStructures/UnionFind + SCC" 支撑 RPO。
- **SOOT/SootUp（Java 字节码）**：数据流框架作为一等 API（`ForwardFlowFunction`），教学实现最干净。
- **Doop/NuSMV 类**：Datalog 引擎跑程序分析——把"工作列表迭代"外包给逻辑编程引擎。
- **rustc mir_borrowck**：活跃性/可达性查询在 MIR 上跑——数据流结果直接参与语言规则（借用检查）而非仅优化。
- **CBMC**：符号执行+不变式挖掘在 SSA 上进行——本讲框架的"逐路径精化"表亲。
