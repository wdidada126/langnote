# L13 中间代码生成：表达式、控制流与回填

> 讲次：CS143 L13 ｜ 阅读：龙书 ch8.3-8.5 ｜ 配套：projects/04_ir（翻译模式 + backpatch 实现）；对应 PA4 理论部分

## 核心概念

### 布尔表达式：短路求值的翻译模式（与 L14 的衔接点）
```
B -> B1 || B2    { B truelist = B1.truelist ∪ B2.truelist
                   B.falselist = B1.falselist          ← 短路：B1 假才看 B2
                   backpatch(B1.falselist, B2.begin) }
B -> ! B1        { swap(truelist, falselist) }
B -> E1 relop E2 { t = E1 relop E2;  emit(ifz t goto _);  truelist=[qc]; falselist=[qc+1] }
真/假链（true list/false list）：待填跳转目标的多态标签（polymorphic label）。
```
- `if e1 && e2 then S` 生成的正是带短路的 CFG；e2 只有在 e1 为真后才求值——语义与 IR 的双重教学点。
- 完整控制流：`if E then S1 else S2`、`while E S` 的 SDD 见龙书 8.4——每片段末尾 emit `goto L`，回填列表 = 语法动作里的链表。

### 声明/赋值/数组
```
x = 3;            → x = 3                （直接以变量名为存储位）
A[i,j] = a*i + b*j + c  → 仿射地址：t1 = i*4; t2 = j*8; t3 = t1+t2; t4 = &A+t3; store t4
行优先：offset = ((i*n)+j)*w —— 多维下标展开成乘加链。
```

### 临时量管理
- 简单策略：无限临时名 t1,t2,...（SSA 式，L17 再复用）。
- 寄存器池策略（COOL 的 "virtual registers/栈约束" 即此类）：超过 K 个 spill 到栈，后端再折叠——IR 阶段"奢侈命名"、后端"节俭分配"是普遍分工。

### 可归约 CFG（reducible）
- 回边都满足"头支配尾" ⇒ 无 goto 面条码；C/COOL/MiniC 的控制流（if/while/return）天然可归约——L17 的区间分析、循环优化以此为前提。

## 开源项目中的应用
- **clang CodeGen**：`CodeGenFunction::Emit*` 系列是教科书 backpatch 的 C++ 复刻（`llvm::BasicBlock` 多态标签、`CreateCondBr` 先占位再 setSuccessor）。
- **CRuby/YARV、Lua VM**：字节码发射器即本讲翻译模式直译；Lua 的 jump list patch 机制连代码结构都和龙书一致。
- **rustc MIR building**：Thir→MIR 阶段生成 "基本块 + terminator"，控制流模板与 ch8.4 同型。
- **WASM（wasmCC/Binaryen）**：结构化控制流（block/loop 嵌套而非 goto）要求"回填"换成区域栈（region stack）——同一问题在受约束目标机上的变体。
- **Javac**：desugar+低阶 Gen 的 backpatch 注释直接引用龙书式术语。
