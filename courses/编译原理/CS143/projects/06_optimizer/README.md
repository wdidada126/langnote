# Stage 06 — 机器无关优化：常量折叠 / 复制传播 / 死代码删除

- **对应讲次**：`notes/L14`（数据流框架）、`notes/L17`（经典优化族与 SSA 红利）
- **对应 CS143 PA**：PA5 的"自主设计优化"加分项 + HW5 的数据流/优化部分
- **核心代码**：`opt.h`（本阶段新增），驱动 `main.cpp`

## 知识点落点（代码 ↔ 讲义）

| 讲义概念 | 实现位置（opt.h） |
| --- | --- |
| 常量传播的格（L14） | `konst` 映射：只在块内前进（Label 清空）——"块内 = 不必处理 merge" 的诚实版本，并解释为何 LLVM 要先 mem2reg |
| 常量折叠（L17） | `constFold`：算术/比较 → Const；`Jz/Jnz` 常量条件 → `Jmp`/`Nop`（分支消除） |
| CFG 化简（simplifycfg） | `pruneJumpOver`：前跳越过的直线区安全删除（带"外部跳入"检查） |
| 复制传播（L17） | `copyProp`：`Move t_a, t_b` ⇒ 后续读 a 换 b；**仅限临时量**——槽位可被重写（非 SSA），这正是"SSA 让复制传播变便宜"的现场演示 |
| 死代码删除（L17） | `deadCode`：整函数名字级"读集"反向删除；MiniC 无指针无别名，故名字分析即完备——与 L10"可判定性"呼应 |
| 不动点迭代 | `optimizeFunction`：折叠↔传播↔删除互相解锁（折叠制造复制，传播暴露死码），循环至无变化（≤10 轮保险丝） |

`x` 被折成 14、`int y = x` 与 `neverUsed` 整对指令消失、`id(1+1)` 的实参折成 2。

## 为什么这些优化"看起来弱"——以及怎么变强（练习阶梯）
1. 把 `konst` 从"块内重置"升级为**前向数据流**（L14 工作列表）：跨块常量传播 + 分支可达性（SCCP）。
2. 给 `t` 做真正的 SSA（φ 插入，L17）后，复制传播可覆盖"跨回边"情形。
3. 值编号（GVN，L17）：`(a+b)` 出现两次时让第二条复用——当前 IR 每条加法都发新临时量，正是 GVN 的靶子。
4. 强度削弱/LICM：需要循环识别（支配树 + 回边，L17）。

## 诚实声明
`copyProp` 的"重定义失效"依赖生成器的**临时量单一定义**不变式（And/Or 模板里
的 scratch 临时量有两次写——但它不是 `Move t, t'` 形式，别名表不会收录，故安全）。
若你扩展生成器产生新的双写临时量，请同步收紧此 pass。
