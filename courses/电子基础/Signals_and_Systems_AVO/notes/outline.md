# notes/outline.md — MIT 6.007 信号与系统（Oppenheim，骨架）

## 单元 I · 引言

### L1 导论与信号回顾
- 信号 = 随自变量变化的量；连续时间 x(t) 与离散时间 x[n] 是两条平行世界
- 基本信号：阶跃、冲激、复指数、正弦；周期与非周期
- 奇偶分解与能量/功率信号分类，为后面正交分解做准备

### L2 系统、框图与互连
- 系统 = 输入→输出的映射；框图是最早的"数据流图"
- 级联、并联、反馈三种连接；反馈是本课程通向控制的部分
- 记忆、因果与实际可实现性的直观

### L3 系统的性质
- 线性：叠加 + 齐次；时不变：延迟输入 ⟹ 延迟输出
- 两者合起来（LTI）才让冲激响应完全表征系统
- 判别方法：找反例比证明成立更容易，务必练几道经典题

### L4 复数与复指数复习
- 欧拉公式把正弦与指数统一：cos/sin = 复指数的线性组合
- 极坐标与乘除法 = 幅度缩放 + 相位旋转（频率响应的语言）
- 复指数的正交性是傅里叶级数收敛的代数基础

## 单元 II · 时域：冲激响应与卷积

### L5 离散时间 LTI 与卷积和
- x[n] = Σ x[k]δ[n−k]（单位分解）→ y[n] = Σ x[k]h[n−k]
- 卷积四步图解：列表、翻转、滑动、加权求和
- h[n] 是系统的"指纹"：因果 ⟺ h[n]=0 (n<0)；稳定 ⟺ Σ|h|<∞

### L6 卷积性质与差分方程
- 交换/结合/分配律对应系统的互连等效
- 单位阶跃与冲激的微分/差分关系 → 阶跃响应求导得冲激响应
- 线性常系数差分方程：经典解 = 齐次 + 特解

### L7 连续时间 LTI 与冲激函数
- δ(t) 的筛选性质；冲激是阶跃的导数（分布意义）
- y(t) = ∫x(τ)h(t−τ)dτ；面积与尺度性质
- 物理直觉：给系统一记"瞬间敲击"，听它怎么余响

### L8 微分方程与冲激/阶跃响应
- 常系数线性微分方程 ↔ 指数模态（特征根）
- 冲激响应含指数衰减/振荡；不稳定 ⟺ 右半平面极点
- 零输入/零状态分解 = 系统自由的响应 + 外力强加的响应

### L9 卷积积分的性质与判据
- 卷积的微分/积分性质（对应系统的级联/反系统）
- 无记忆 ⟺ h ∝ δ；BIBO 稳定 ⟺ ∫|h|dt < ∞
- 反例集合：不可逆系统、非因果但稳定的系统

## 单元 III · 频域：傅里叶分析

### L10 周期信号的傅里叶级数
- x(t) = Σ a_k e^{jkω₀t}；系数由内积（正交投影）给出
- 谐波结构：谱线位置与幅度、相位
- 方波/三角波的系数推导与对称性简化（奇偶、半波对称）

### L11 傅里叶级数性质
- 时移 ↔ 线性相位；频移 ↔ 调制；尺度 ↔ 谱线密度
- Parseval：时域能量 = 频域系数能量之和
- 微分性质让微分方程在频域变成乘法（关键动机）

### L12 LTI 系统与频率响应
- e^{jωt} 是 LTI 的本征函数，输出 = H(jω)·输入
- H(jω) = ∫h(t)e^{−jωt}dt：h 的傅里叶变换
- 无失真传输条件：|H| 常数、相位线性（群延迟常数）

### L13 非周期信号的傅里叶变换
- 谱密度 X(jω)：周期 → 非周期时谱线变成连续包络
- 常用变换对：矩形↔sinc、指数衰减↔洛伦兹、高斯↔高斯、δ↔常数
- 收敛条件与广义函数（Dirichlet 条件与分布意义）

### L14 傅里叶变换性质与卷积定理
- 时域卷积 ↔ 频域相乘；时域相乘 ↔ 频域卷积（对偶）
- 用频域方法解微分方程：代数化 + 有理分式反变换
- 调制与解调的数学内核就是频移性质

### L15 滤波器与失真
- 理想低通不可实现：非因果 + 无限长冲激响应
- 幅度失真 vs 相位失真；人耳/人眼对相位敏感度不同
- 实际指标：过渡带、纹波、阶数与代价的折中

### L16 采样定理（频域视角）
- 采样 = 乘以冲激串 → 频谱周期延拓，混叠的频域图像
- Nyquist 条件 fs > 2ω_m/2π；理想重建 = 乘以矩形（sinc 内插）
- 零阶保持与实用 DAC 的偏差（滚降与预补偿）

## 单元 IV · 复频域：拉普拉斯变换

### L17 拉普拉斯变换与 ROC
- X(s) = ∫x(t)e^{−st}dt，s = σ + jω：把收敛性写进变换
- ROC 的几何性质（平行于虚轴的带状区域，边界是极点）
- 同一代数表达式 + 不同 ROC = 不同信号（关键陷阱）

### L18 性质与系统函数 H(s)
- 微分/积分/时移/卷积性质 → 微分方程变代数方程
- 电路的 s 域模型（阻抗 sL、1/sC）：分析一体化
- 初值/终值定理与稳态误差的入口

### L19 极零点、稳定性与实现
- H(s) 极点位置决定响应模态与稳定性（左半平面 ⟺ 稳定）
- 因果性 ⟺ ROC 在最右极点右侧
- 直接/级联/并联实现与框图（与 L2 呼应）

### L20 频率响应与 Bode 图
- s = jω 时 H(s) 退化为频率响应；极零点在虚轴附近的几何意义
- Bode 图的分段直线近似：一阶因子 20 dB/dec、相位 90°
- 二阶因子与谐振峰、品质因数 Q

## 单元 V · 离散时间：z 变换

### L21 z 变换与 ROC
- X(z) = Σx[n]z^{−n}，z = re^{jω}：与拉普拉斯的关系 z = e^{sT}
- 单位圆 ↔ 虚轴；ROC 为环状区域
- 逆 z 变换：部分分式 + ROC 决定因果/反因果序列

### L22 系统函数 H(z) 与差分方程
- 差分方程 → 有理 H(z)；极点在单位圆内 ⟺ 稳定
- FIR（全零点）与 IIR（有极点）的结构与代价：递归实现的舍入问题
- 频率响应 = H(z) 在单位圆上取值；陷波与谐振的零点/极点设计

### L23 DTFT、DFT 与 FFT
- DTFT：x[n] 的连续频谱；非周期信号也有频域表示
- DFT：有限长序列的频域等间隔采样，隐含周期延拓
- FFT 的分治思想：旋转因子的对称性使 O(n²) → O(n log n)

## 单元 VI · 应用

### L24 幅度调制与解调
- 调制 = 频谱搬移：x(t)cos(ω_c t) ↔ 双边带
- DSB-SC 需要相干解调（本地载波相位同步）；AM 可用包络检波
- 调制指数、功率效率与噪声折中

### L25 通信系统总览
- 发送—信道—接收链路：混频、中频、滤波与判决
- 频分复用与保护带；带通信道与基带信号的映射
- 噪声与 SNR：为 6.050J 的信道容量留下接口

### L26 反馈与全课程复盘
- 反馈牺牲增益换取线性度、带宽与鲁棒性
- 闭环特征方程与稳定判据（s 平面根轨迹直觉、Bode 裕度）
