## 二、为什么学

1. **这个学科就是 Oppenheim 参与塑造的**：读他的书、看他讲课，等于直接与范式的建立者对话；他对"线性系统与傅里叶分析"的叙述组织是最经典的教材级表达。
2. **MIT 版信号与系统的正统路线**：时域 → 频域（傅里叶级数/变换）→ 复频域（拉普拉斯）→ 离散域（z 变换）→ 通信与反馈应用，逻辑链清晰、推导严谨。
3. **为一系列后续课打地基**：6.003 控制、6.341/6.342 数字信号处理、6.02  circuits、6.004 结构与计算、6.5940 高效计算中的信号/数值方法，以及图形学与音频处理。
4. **与 EE120 互补**：EE120 偏伯克利风格（lab 驱动、离散为主、工程趣味强），6.007 偏分析风格（推导完整、连续时间为轴心、习题经典）。两门对照读收益最大。
