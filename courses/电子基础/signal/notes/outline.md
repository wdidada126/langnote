# notes/outline.md — UCB EE120 信号与系统（骨架）

## L1 信号与系统分类
- 连续时间 x(t) 与离散时间 x[n]；采样把两者连接起来
- 周期（有理周期条件）、能量信号 vs 功率信号、奇偶分解
- 基本运算：时移、反转、尺度；离散域的移位最常用

## L2 系统性质
- 记忆性、因果性、稳定性（有界输入有界输出 = BIBO）
- 线性（叠加 + 齐次）与时不变性：两个假设让分析可行
- 判据练习：给系统表达式判断五性，并给出反例

## L3 离散时间 LTI 与卷积和
- 任意序列 = 移位冲激的加权和 → y[n] = Σ x[k]h[n−k]
- 卷积的图解法：翻转、滑动、相乘求和
- 单位脉冲响应 h[n] 完全表征 DT LTI 系统

## L4 连续时间 LTI 与卷积积分
- y(t) = ∫ x(τ)h(t−τ)dτ；冲激作为"筛选性质"
- 卷积的交换/结合/分配律与系统互连（级联=卷积）
- 奇异函数：δ(t)、u(t)、sgn(t)、冲激偶

## L5 方程、框图与实现
- 线性常系数微分/差分方程 ↔ 冲激响应的两种求法
- 直接 II 型、级联、并联结构；离散实现的成本差异
- 反馈连接的引入（为 L16 与 Lab6 埋伏笔）

## L6 本征函数与频率响应
- e^{jωt}/e^{jωn} 通过 LTI 只被乘一个复数：H(jω)、H(e^{jω})
- 频率响应的幅度/相位分解；线性相位与无失真传输
- 任意信号 = 本征函数叠加 → 傅里叶分析的动机

## L7 连续时间傅里叶级数
- 周期信号的谐波分解：系数是正交投影（18.06 内积）
- 性质：Parseval、对称性（实/偶/虚/奇对应）、微分积分性质
- Gibbs 现象与"有限带宽能表达多陡的边沿"

## L8 傅里叶变换
- 非周期信号的连续谱；常用配对（矩形↔sinc、高斯↔高斯）
- 时移、频移、尺度、对偶、卷积定理（时域卷积=频域相乘）
- 微分方程在频域变成代数方程：H(s) 的前身

## L9 频域卷积与理想滤波器
- 时域相乘 ↔ 频域卷积：调制与采样的统一解释
- 理想低通/高通/带通不可实现（非因果、无限长）
- 幅度失真 vs 相位失真；群延迟与色散

## L10 采样定理（连续时间）
- 周期采样 = 乘以冲激串 → 频谱周期延拓
- Nyquist 条件 fs > 2fmax；欠采样的混叠与不可逆
- 理想重建（sinc 内插）与零阶保持的实际偏差

## L11 离散时间重采样
- 抽取（decimation）需先低通、内插（interpolation）需镜像抑制
- 有理因子采样率转换、多相分解的动机
- 工程含义：音频 44.1/48 kHz 与视频帧率转换

## L12 DFT 与 FFT
- DFT 是有限长序列的频域等间隔采样；隐含周期性
- FFT 的分治推导（Cooley–Tukey）与旋转因子对称性
- 分辨率 Δf = fs/N、窗函数与频谱泄漏（Lab3 的核心）

## L13 拉普拉斯变换
- X(s) = ∫x(t)e^{−st}dt：把收敛性纳入变换本身
- 系统函数 H(s)、极零点图与冲激响应对应关系
- ROC 决定因果/稳定：右半平面 ↔ 不稳定的判据

## L14 Z 变换
- X(z) = Σx[n]z^{−n}；与拉普拉斯的关系 z = e^{sT}
- 极点在单位圆内 ⟺ 稳定；零点决定陷波频率
- IIR 与 FIR 的结构差别及有限字长效应（Lab4 数据滤波）

## L15 滤波器设计
- FIR：窗法/等纹波，线性相位与阶数代价
- IIR：Butterworth（最平）、Chebyshev（更陡但纹波）、椭圆
- 频率变换与实现选择：什么时候必须用 FIR

## L16 反馈与 Bode 图
- 开环/闭环传递函数、灵敏度函数 S 与补灵敏度 T
- 幅相裕度、Nyquist 直觉：为什么相位滞后 180° 会自激
- Lab6 倒立摆：不稳定极点 + 采样延迟 → 控制可行性

## L17 状态空间
- ẋ = Ax + Bu, y = Cx + Du；多输入多输出的自然语言
- 特征值决定模态与稳定性；可控/可观测性秩判据
- 传递函数 ↔ 状态实现的相互转换（MIMO 推广）

## L18 频域图像处理
- 二维 DFT、滤波在图像上的含义（低通=模糊、高通=锐化）
- 傅里叶切片定理（CT 与图形学/断层成像的交汇）
- Lab5：哈勃照片去噪——维纳滤波与小波/频域阈值

## L19 调制与通信
- AM/DSB-SC/SSB 的频谱搬移与包络/相干解调
- 采样与调制是同一个"乘以复指数"的两面
- 噪声、带宽与信噪比的系统级权衡（接 6.050J）

## L20 随机信号与功率谱
- 自相关、功率谱密度与 Wiener–Khinchin 定理
- 白噪声通过 LTI 系统：输出谱 = |H|²·输入谱
- 匹配滤波：最大化 SNR 的最优线性滤波器

## L21 综合复盘
- 四个域的对照表：时域 / 频域 / s 域 / z 域，同一系统的四种坐标
- 一张图：采样定理是连接连续与离散的唯一桥梁
- 通往 EE106（控制）、EE142（通信）、DSP/ML 的路标
