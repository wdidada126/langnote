## 二、为什么学

1. **工程世界的通用数学**：线性时不变系统 + 傅里叶分析是通信、控制、音频图像处理、机器学习的公共语言，也是 EE/CS 交叉最"硬核"的一门基础课。
2. **把 18.06 和 18.02 真正用起来**：频域分解 = 正交投影；卷积 = 矩阵乘法；特征值 = 系统稳定性；不变子空间 = 频率响应。
3. **算法与系统的接口**：FFT 是 CS 里少数"数学直接决定工程可行性"的算法；滤波与采样在数据系统、图形、音频、传感器管线里无处不在。
4. **理论 + 大量真实信号处理项目**（心率、图像去噪、倒立摆），学完可以直接做信号/边缘智能方向的项目。
