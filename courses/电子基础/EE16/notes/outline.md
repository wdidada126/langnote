# notes/outline.md — UCB EE16A / EE16B（骨架）

## EECS 16A

### A1 导论：信息器件与系统
- 一条链路：物理世界 → 传感器 → 电路调理 → 数字化 → 算法 → 执行器
- 抽象与建模：忽略不重要的物理细节，留下可计算的变量关系
- 全课程的组织原则：每个概念都要能用一个可测的系统来验证

### A2 系统与线性代数回顾
- 向量、矩阵、线性映射：把"多输入多输出"写成 Ax = b
- 解的存在唯一性与秩（18.06 直接复用）
- 系统视角：输入—状态—输出，为后面状态空间铺路

### A3 电路基本量
- 电荷 q、电流 i = dq/dt、电压 v = dw/dq、功率 p = vi
- 参考方向与被动符号约定：符号是模型的一部分
- 集总假设：尺寸远小于波长时电路才"成立"

### A4 KCL 与 KVL
- KCL：节点电流守恒（电荷守恒）；KVL：回路电压守恒（能量守恒）
- 图论视角：树/连支、独立方程数 = N−1 与 E−N+1
- 方程必须独立且完备，否则解不存在或不唯一

### A5 节点电压法
- 选参考节点 → 每个节点一条 KCL → 得 Ax = b
- 电导矩阵的对称性与正定性（无源网络）
- 这就是"电路求解器"（SPICE）的核心算法

### A6 元件 i–v 特性
- 电阻（线性）、电源（理想/实际）、二极管（非线性）
- 工作点：负载线与器件曲线的交点，图形化求解
- 小信号线性化：在工作点附近取切线（18.02 的梯度思想）

### A7 分压器与传感器
- 分压公式与其"被负载拉偏"的条件（输出阻抗 vs 输入阻抗）
- 光敏/热敏/应变/电容式传感器的物理量—电阻映射
- 标定：把电压反解成物理量，线性拟合与误差传播

### A8 叠加与等效
- 线性系统才能叠加；非线性元件只能工作点分析
- Thevenin/Norton 等效与最大输出功率（阻抗匹配）
- 用等效电路解释"为什么前级输出阻抗要小、后级输入阻抗要大"

### A9 储能元件与一阶系统
- 电容 i = C dv/dt、电感 v = L di/dt；能量 ½Cv²、½Li²
- RC 一阶响应：时间常数 τ、指数衰减、阶跃与自然的通解形式
- 频域初步：RC 低通 -3dB 频率 1/RC（B5 的伏笔）

### A10 二阶系统
- RLC 与特征方程：过阻尼/临界/欠阻尼三种根
- 复特征根 = 振荡 + 衰减，固有频率与品质因数 Q
- 与机械系统（质量-弹簧-阻尼）的一一对应（B13）

### A11 理想运放
- 虚短虚断（高增益 + 负反馈）→ 用 KCL 推传递函数
- 反相/同相放大、加法器、跟随器（缓冲隔离）
- 实际限制：带宽、压摆率、输入偏置、饱和

### A12 有源电路与滞回
- 积分器/微分器及其直流偏置问题
- 比较器 + 正反馈 = 施密特触发器，噪声容限与滞回窗
- 振荡的根源：延迟 + 正反馈 + 增益 > 1

### A13 数字抽象与 MOS
- MOS 管作为压控开关；CMOS 反相器的传输特性
- 逻辑电平、噪声容限、增益与级联可放大性
- 为什么数字电路能"忘掉"噪声：分层抽象的胜利

### A14 组合逻辑与硬件描述
- 门 → 模块 → 子系统；布尔代数与卡诺图化简
- Logisim 搭建半加器/多路器；Verilog 的行为级写法
- 时序预算观念（面积/速度/功耗的三角）

### A15 序列与差分方程
- 离散时间信号 x[n]；系统 → y[n] = f(y[n−1], x[n])
- 一阶递推的解：齐次 + 特解（与 A10 完全同构）
- 稳定条件：|特征根| < 1

### A16 求解差分方程与复盘
- Z 域直觉（不做严格）；单位脉冲响应 = 系统的全部记忆
- 卷积求和的雏形 → 16B/EE120 的核心
- 16A 总结：抽象 → 方程 → 解 → 反馈到器件

## EE 16B

### B1 回顾与系统视角
- 16A 的时域 + 16B 的频域 = 同一系统的两种基
- 线性时不变（LTI）是所有解析工具的前提
- 目标：能设计一个"从含噪传感数据中提取信息"的完整系统

### B2 复指数是本征函数
- 欧拉公式：e^{jωt} = cos ωt + j sin ωt
- LTI 系统对复指数的响应 = 乘以复数 H(jω)（本征函数性质）
- 相位、幅度与极坐标视角是工程师的第二语言

### B3 傅里叶级数与频谱
- 周期信号 = 谐波复指数之和；系数是正交投影（18.06 内积）
- 谱线、奇偶与对称性对频谱的约束
- 方波的吉布斯现象与带宽有限性

### B4 频域分析与系统函数
- 传递函数 H(s)：极点决定响应形式，零点决定抑制频率
- Bode 图的分段近似与相位裕度直觉
- 从微分方程到代数方程：拉普拉斯变换的动机（EE120 严格化）

### B5 滤波器设计
- 低通/高通/带通/带阻；巴特沃斯与切比雪夫的折中
- 品质因数 Q、带宽、滚降斜率与实际器件限制
- 用运放实现有源滤波器（Sallen–Key）

### B6 采样与量化
- 奈奎斯特条件 fs > 2B；混叠的成因与抗混叠滤波
- 量化步长 Δ、量化噪声功率与 SNR ≈ 6.02N + 1.76 dB
- 过采样与噪声整形的收益

### B7 DFT/FFT 与实用谱分析
- DFT 是有限长信号的频率采样；FFT 让大规模谱分析可行
- 窗函数、频谱泄漏、频率分辨率 Δf = fs/N
- 音频/生物信号的真实分析流程

### B8 随机信号与噪声
- 信号是随机过程的一次实现：均值、方差、自相关、功率谱
- 白噪声、1/f 噪声、热噪声 kTB 的物理来源
- 匹配滤波与信噪比提升：线性系统对付噪声的最优方式

### B9 估计与回归
- 最小二乘解 â = (XᵀX)⁻¹Xᵀy（18.06 的正规方程）
- 基函数选择 = 特征工程；过拟合与正则化（岭/Lasso）
- 从传感器数据到预测模型的标准工作流

### B10 特征分析与 PCA
- 协方差矩阵对角化得到不相关的主方向
- 去相关、降维与异常检测的同一套工具
- 传感器融合：把冗余测量投影到信号子空间

### B11 状态空间与矩阵指数
- ẋ = Ax + Bu；解 x(t) = e^{At}x(0) + ∫e^{A(t−τ)}Bu(τ)dτ
- 特征值决定稳定性与模态；可控/可观测性的秩判据
- 与 18.06 L14、18.330 ODE 求解的闭环

### B12 反馈与控制
- 闭环传递函数与灵敏度：反馈牺牲增益换取鲁棒性
- PID 三项的物理意义与整定；稳定性判据（Nyquist 直觉）
- 案例：平衡倒立摆/电机调速（EE120 lab6 的前置）

### B13 机电类比与阻抗
- 阻抗 Z(s) 的普适性：机械、流体、热、电的统一语言
- 力-电压 / 力-电流两套类比与功率共轭
- 能量存储—耗散—转换的系统观

### B14 生物与工程信号案例
- PPG/ECG 中的心率提取：滤波 + 峰值检测 + 统计
- 运动伪迹、基线漂移与自适应滤波
- 从"能算"到"能测得准"：真实数据的不完美是设计输入

### B15 综合设计
- 全链路项目：传感 → 调理 → ADC → 算法 → 显示/执行
- 误差预算表：每级的噪声增益与带宽贡献
- 工程判断：精度够用的前提下最小化成本与复杂度

### B16 复盘与路线图
- 16A/B 的知识地图：器件 → 电路 → 系统 → 信息
- 与 EE120（理论化）、EE106（控制）、EE141（器件）的衔接点
- 一句话总结：设计信息器件 = 在噪声与功耗的约束下榨取信息
