# etlcpp

https://www.etlcpp.com/

ETLCPP
ETLCPP是一个开源的C/C++数据抽取、转换和加载（ETL）工具库，支持复杂的数据处理流程，包含数据清洗、转换等功能。其代码结构清晰，支持通过CMake构建系统进行项目管理，并提供示例代码和测试用例。 ‌
TASKCTL
TASKCTL是国内首款C语言开源ETL调度系统，不依赖数据库或中间件，支持批量作业的独立调度。特点包括轻量化、高自由度配置，适合需要自定义流程的场景。 ‌
Informatica
虽然Informatica主要提供商业ETL工具，但其开源社区版（如IDQ）支持部分免费功能，可处理结构化数据。该工具在金融行业应用广泛，具备数据治理和合规性支持。 ‌
‌注意事项‌：
金融领域对数据安全和合规性要求较高，使用开源工具时需评估其安全性与合规性
