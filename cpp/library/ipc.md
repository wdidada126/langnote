# ipc

https://github.com/mutouyun/cpp-ipc

这个项目叫 cpp-ipc，是 C++ 校招简历中非常经典的加分项目，通过共享内存和无锁队列实现跨进程通信。

### 官方 GitHub 地址
* 官方仓库：[github.com/mutouyun/cpp-ipc](https://github.com/mutouyun/cpp-ipc)

### 核心特性
该项目核心优势在于高性能与低延迟，支撑了以下特性：
* 无锁设计：基于 lock-free 或轻量级 spin-lock 实现，减少了锁竞争的开销。
* 跨平台支持：支持 Linux、Windows 和 FreeBSD，涵盖了 x86、x64 及 ARM 架构。
* C++17 标准：推荐使用支持 C++17 的编译器（如 MSVC 2017、GCC 7 或 Clang 4）。
* 无额外依赖：除标准库 STL 外，无需引入其他第三方库。

### 简历加分点
简历上提到“吃透共享内存+无锁队列”，这恰好对应了项目中的核心机制。你可以从以下角度准备面试：
* 共享内存机制：在 Windows 上使用文件映射对象（file mapping object）实现跨进程内存共享。
* 同步原语：Windows 缺乏原生进程间条件变量，项目通过组合信号量和互斥体来实现更复杂的同步。

在社招面试中，经典加分项目往往不在于“数量多”，而在于技术深度和工程价值的体现。面试官主要考察候选人对底层原理的理解，以及解决实际问题的能力。

### 社招简历的经典加分项目类型

根据行业招聘需求，以下几类项目通常能获得较高认可：

*   基础组件类（深度优先）：例如线程池、内存池、无锁队列、日志库、MySQL连接池等。这类项目虽然规模不大，但能直接考察对并发、资源管理等底层原理的理解。面试官更关注你能否深入解释为什么这么设计，例如“任务队列为什么用条件变量”、“锁粒度如何控制”等细节。
*   网络与系统类（性能导向）：例如高性能网络库、HTTP服务器、Reactor模式实现等。这类项目考察对IO多路复用（如epoll）、线程模型、高性能架构的掌握。如果你能提供量化的数据（如QPS提升、延迟降低），会更有说服力。
*   存储与引擎类（高阶价值）：例如KV存储引擎（参考LevelDB）、RPC框架、简易消息队列等。这类项目能体现对数据结构、磁盘IO、分布式系统的综合理解。如果你能阐述清楚核心模块的设计取舍，往往能打动面试官。
*   特定领域与优化类：例如推理加速（TensorRT/ONNXRuntime）、协程化RPC、用户态TCP/IP协议栈等。这类项目在特定岗位（如AI Infra、基础架构）中非常稀缺，能体现你的差异化价值。

### 如何让项目在社招中脱颖而出？

在明确项目方向后，更重要的是通过项目展示你的工程思维：

*   运用STAR法则组织描述：在简历和面试中，用“情境-任务-行动-结果”的结构来讲述。例如，先说明项目背景和遇到的挑战，再讲你具体的技术方案，最后用数据（如内存占用降低50%、吞吐量提升）量化成果。
*   深挖技术细节与决策依据：面试官会追问“为什么用epoll而不是select”、“为什么用无锁队列而不是互斥锁”等问题。你需要准备好每个设计决策背后的技术考量，以及方案选型的优劣对比。
*   体现工程化与问题解决能力：准备讲一个自己实际解决的“难点问题”。例如，你是如何通过压测和日志分析，定位到性能瓶颈（如锁竞争），并通过调整方案最终优化解决的。这能证明你有真正的实战经验。

建议你选择1-2个最熟悉、能深入聊透的项目，把它们做精做深，远比在简历上罗列多个浅尝辄止的项目更有效。
