# scons

https://www.scons.org/

Scons是一个开源软件构建工具，它是对经典的Make实用程序的改进和跨平台替代，具有类似于autoconf/automake的集成功能和编译器缓存，例如ccache。简而言之，Scons是一种更容易、更可靠且更快的软件构建方式。你可以在SCons的官网上找到其最新版本，当前生产版本为4.6.0。同时，官网还提供了各种版本的文档，包括一般性说明、特定版本的手册和用户指南等。值得注意的是，所有Scons软件（包括Scons本身、测试和支持工具）都将与Python 3.6+一起编写并运行。

brew install scons
