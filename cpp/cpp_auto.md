# cpp_auto
类型推导是 C++ 中一项非常有用的功能，它允许编译器自动推断变量的类型，而不需要显式指定。这不仅简化了代码，还提高了代码的灵活性和可读性。C++ 类型推导主要通过 `auto` 和 `decltype` 关键字实现。

### 类型推导的作用

1. 简化代码：当变量的初始化表达式的类型冗长或复杂时，使用 `auto` 可以避免重复书写类型名。
   
   ```cpp
   std::map<int, std::string> myMap = getMap();
   for (auto it = myMap.begin(); it != myMap.end(); ++it) {
       // ...
   }
   ```

2. 提高灵活性：在编写模板函数或使用泛型编程时，类型推导可以显著减少需要手动指定类型的场景。
3. 支持现代C++特性：如范围for循环、lambda表达式等现代C++特性的有效使用通常依赖于类型推导。
4. 减少错误：减少了由于手动指定类型可能引发的错误，例如拼写错误或不匹配的类型声明。

### 进入标准的时间

- `auto` 关键字: 从 C++11 标准开始引入。它允许编译器根据变量初始化表达式自动推断变量的类型。

- `decltype` 关键字: 同样是从 C++11 开始提供的，用于获取表达式的类型而不实际计算表达式的值。这对于模板编程特别有用，因为它允许你基于其他表达式的类型来声明类型。

- C++14: 对 `auto` 进行了扩展，允许其用于函数返回类型推导，并且支持更复杂的类型推导场景。
- C++17: 引入了结构化绑定（Structured Bindings），它结合 `auto` 提供了一种新的方式来解构元组、数组和结构体到独立的变量中。
- C++20: 增加了对概念（Concepts）的支持，进一步增强了模板编程中的类型推导能力，使得模板约束更加明确和易于理解。

### 示例

#### 使用 `auto`

```cpp
auto i = 10; // i is of type int
auto d = 10.5; // d is of type double
auto str = "Hello"; // str is of type const char*
```

#### 使用 `decltype`

```cpp
int x = 3;
decltype(x) y = x; // y is also an int and initialized to 3
```
