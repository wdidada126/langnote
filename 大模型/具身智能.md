# 具身智能（Embodied AI）

> 整理日期：2026-09-27

## 一、这是什么

具身智能 = 让 AI 拥有「身体」（传感器 + 执行器），在物理或仿真环境中**感知 → 认知 → 行动**形成闭环。

它和纯语言模型的根本区别：智能不只是「会想、会说」，还要「能做、能改环境」。
与大模型的关系：VLA（Vision-Language-Action，视觉-语言-动作）把 VLM（视觉-语言模型）当作「大脑」，输出动作 token，是当前大模型走向具身的关键路径。

## 二、核心子方向（知识地图）

- **VLA / VLM**：视觉-语言-动作模型，机器人 / 具身最热方向
- **仿真与数据基础设施**：音视频数据、遥操作示教、仿真器（训练与评测的底座）
- **具身认知**：脑体隐喻、人机联合智能体（人作大脑、机器群作身体）
- **人形 / 工业机器人落地**：从实验室到产线的工程化
- **基准、数据集与评测**：cross-embodiment（跨本体）、操作基准

## 四、2026 视角（🔧）

- VLA 是当前机器人 / 具身最热门方向，但**真机示教数据 + 仿真基础设施**是核心瓶颈，相关人才稀缺。
- 开源动手首选 **OpenVLA**（`github.com/openvla/openvla`，7,074★ 实测）；综述官方索引仓库仅 20★（文献列表，非实现）。
- 收敛趋势：VLA / VLM / agentic AI 三者走向**社会化对齐、自适应、通用具身智能体**。
- 🔧 **本仓库缺口**：尚无「仿真器 / 数据集（Isaac Sim、Habitat、RLBench）」与「人形机器人（Figure、Unitree、宇树）」的专门笔记，待补；人形机器人量产进展（2025–2026）建议单独成篇。
