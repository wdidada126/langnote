win11 powershell 20260201.md  20260202.md 20260203.md 全部改成 20200201.md 2020的
在Windows 11的PowerShell中，你可以使用以下命令将文件名中的`2026`替换为`2020`。以下是具体代码：

```powershell
Get-ChildItem -Path . -Filter "*2026*.md" | ForEach-Object {
    $newName = $_.Name -replace "2026", "2020"
    Rename-Item -Path $_.FullName -NewName $newName
}
```

### 代码解释
1. `Get-ChildItem -Path . -Filter "*2026*.md"`：此命令用于获取当前目录（`.`）下所有文件名包含`2026`且扩展名为`.md`的文件。
2. `ForEach-Object`：针对获取到的每个文件执行后续操作。
3. `$newName = $_.Name -replace "2026", "2020"`：把文件名中的`2026`替换成`2020`，并将新文件名存于`$newName`变量中。
4. `Rename-Item -Path $_.FullName -NewName $newName`：将文件重命名为新的文件名。

### 使用方法
1. 打开PowerShell，把当前目录切换到包含这些文件的目录。你可以使用`Set-Location`命令来切换，例如：
```powershell
Set-Location -Path "C:\Your\Directory\Path"
```
2. 把上述代码复制到PowerShell中并回车执行，这样就能完成文件名的替换。
