在C++中，模板类的实现通常放在头文件中，而不是单独的源文件中。这是因为模板类的实例化需要在编译时完成，而编译器需要看到模板的完整定义才能正确生成代码。以下是关于模板类在头文件中实现的一些要点和示例。

为什么模板类的实现需要放在头文件中？

模板类的代码生成依赖于具体的模板参数。当使用模板类时，编译器需要根据传入的模板参数（如类型、值等）来生成具体的代码。如果模板类的实现放在源文件中，编译器在编译源文件时无法知道所有可能的模板实例化情况，因此无法生成完整的代码。而将模板类的实现放在头文件中，可以确保编译器在处理任何使用模板类的地方时都能看到完整的定义。

示例：模板类的定义和实现

以下是一个简单的模板类示例，展示如何在头文件中定义和实现模板类。

文件：`MyTemplateClass.h`


```cpp
#ifndef MY_TEMPLATE_CLASS_H
#define MY_TEMPLATE_CLASS_H

// 模板类的定义
template <typename T>
class MyTemplateClass {
public:
    // 构造函数
    MyTemplateClass(T value);

    // 获取值
    T getValue() const;

    // 设置值
    void setValue(T value);

private:
    T value_; // 成员变量
};

// 模板类的实现
template <typename T>
MyTemplateClass<T>::MyTemplateClass(T value) : value_(value) {}

template <typename T>
T MyTemplateClass<T>::getValue() const {
    return value_;
}

template <typename T>
void MyTemplateClass<T>::setValue(T value) {
    value_ = value;
}

#endif // MY_TEMPLATE_CLASS_H
```

使用模板类

在其他文件中包含头文件并使用模板类时，编译器会根据具体的模板参数生成相应的代码。

文件：`main.cpp`

```cpp
#include "MyTemplateClass.h"
#include <iostream>

int main() {
    // 使用模板类
    MyTemplateClass<int> intObj(42); // 实例化为int类型
    MyTemplateClass<double> doubleObj(3.14); // 实例化为double类型

    // 使用模板类的方法
    std::cout << "Int value: " << intObj.getValue() << std::endl;
    std::cout << "Double value: " << doubleObj.getValue() << std::endl;

    return 0;
}
```

编译和运行

由于模板类的实现放在头文件中，编译时只需要编译使用模板类的文件即可。例如，对于上述代码，可以使用以下命令编译和运行：

```bash
g++ -o main main.cpp
./main
```

注意事项
1. 头文件保护：确保头文件使用宏定义保护，避免重复包含。
2. 分离定义和实现：虽然模板类的实现通常放在头文件中，但为了保持代码的清晰性，可以将定义和实现分开。例如，可以在头文件中使用`class`定义，然后在头文件的后面或另一个头文件中实现。
3. 模板特化：如果需要对某些类型进行特殊处理，可以使用模板特化。特化也需要放在头文件中。
通过将模板类的实现放在头文件中，可以确保模板类在编译时能够正确实例化，同时保持代码的灵活性和可维护性。

介绍什么是虚函数，以及继承派生对应概念
空类大小是多少，加一个普通的成员函数怎么变化，加一个虚函数怎么变化

### 虚函数与继承派生概念

#### 1. 虚函数（Virtual Function）
- 定义：虚函数是C++中实现运行时多态（动态绑定）的关键机制。通过在基类中使用`virtual`关键字声明函数，允许派生类重写（override）该函数，实现不同的行为。
- 核心作用：  
  - 当通过基类指针或引用调用虚函数时，实际执行的是派生类重写的版本。  
  - 例如：
    ```cpp
    class Animal {
    public:
        virtual void speak() { cout << "Animal sound" << endl; }
    };

    class Dog : public Animal {
    public:
        void speak() override { cout << "Woof!" << endl; } // 重写基类虚函数
    };

    Animal* animal = new Dog();
    animal->speak(); // 输出 "Woof!"，而非基类实现
    ```

- 底层原理：  
  - 虚函数通过虚函数表（vtable）实现。每个包含虚函数的类都有一个虚函数表，存储该类虚函数的地址。  
  - 类的实例会包含一个虚函数指针（vptr），指向对应的虚函数表。调用虚函数时，通过`vptr`查表确定实际调用的函数。

---

#### 2. 继承与派生（Inheritance and Derived Classes）
- 继承：派生类（子类）可以继承基类（父类）的成员（属性和方法），并可以添加新成员或重写基类方法。
- 关键概念：  
  - 多态：基类指针/引用指向派生类对象时，通过虚函数调用派生类实现（如上述例子）。  
  - 纯虚函数与抽象类：若基类中虚函数声明为`virtual void func() = 0;`，则基类为抽象类，不能实例化，必须由派生类实现该函数。

---

### 空类的大小及变化

#### 1. 空类的大小
- 空类：没有成员变量、虚函数和虚继承的类。  
  ```cpp
  class Empty {};
  ```
- 大小：`sizeof(Empty) == 1`字节。  
  - 原因：C++要求每个对象必须有唯一地址。编译器插入1字节占位符，确保不同空类实例在内存中占据不同位置。

---

#### 2. 添加普通成员函数后的变化
- 添加普通成员函数：  
  ```cpp
  class EmptyWithFunc {
  public:
      void func() {} // 普通成员函数
  };
  ```
- 大小：`sizeof(EmptyWithFunc) == 1`字节（与空类相同）。  
  - 原因：成员函数的代码存储在代码区（全局内存），不占用对象实例的内存空间。

---

#### 3. 添加虚函数后的变化
- 添加虚函数：  
  ```cpp
  class EmptyWithVirtualFunc {
  public:
      virtual void func() {} // 虚函数
  };
  ```
- 大小：  
  - 32位系统：`sizeof(EmptyWithVirtualFunc) == 4`字节。  
  - 64位系统：`sizeof(EmptyWithVirtualFunc) == 8`字节。  
- 原因：  
  - 虚函数会触发编译器为类生成虚函数表（vtable），并在每个实例中添加一个虚函数指针（vptr）指向该表。  
  - `vptr`的大小由系统架构决定（32位4字节，64位8字节）。

---

### 总结对比
| 类类型               | 大小（32位系统） | 大小（64位系统） | 原因                          |
|----------------------|------------------|------------------|-------------------------------|
| 空类                 | 1字节            | 1字节            | 占位符保证地址唯一性          |
| 空类 + 普通成员函数  | 1字节            | 1字节            | 函数代码不占用实例内存        |
| 空类 + 虚函数        | 4字节            | 8字节            | 虚函数指针（vptr）的存储开销  |

### 关键结论
- 虚函数是运行时多态的基石，通过虚函数表和指针实现动态绑定。  
- 普通函数不影响对象大小，虚函数因引入`vptr`会增加对象内存开销。  
- 空类的最小大小为1字节，这是C++对象模型的直接结果。
