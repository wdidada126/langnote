### 虚函数与继承派生概念

#### 1. 虚函数（Virtual Function）
- 定义：虚函数是C++中实现运行时多态（动态绑定）的关键机制。通过在基类中使用`virtual`关键字声明函数，允许派生类重写（override）该函数，实现不同的行为。
- 核心作用：  
  - 当通过基类指针或引用调用虚函数时，实际执行的是派生类重写的版本。  
  - 例如：
    ```cpp
    class Animal {
    public:
        virtual void speak() { cout << "Animal sound" << endl; }
    };

    class Dog : public Animal {
    public:
        void speak() override { cout << "Woof!" << endl; } // 重写基类虚函数
    };

    Animal* animal = new Dog();
    animal->speak(); // 输出 "Woof!"，而非基类实现
    ```

- 底层原理：  
  - 虚函数通过虚函数表（vtable）实现。每个包含虚函数的类都有一个虚函数表，存储该类虚函数的地址。  
  - 类的实例会包含一个虚函数指针（vptr），指向对应的虚函数表。调用虚函数时，通过`vptr`查表确定实际调用的函数。

---

#### 2. 继承与派生（Inheritance and Derived Classes）
- 继承：派生类（子类）可以继承基类（父类）的成员（属性和方法），并可以添加新成员或重写基类方法。
- 关键概念：  
  - 多态：基类指针/引用指向派生类对象时，通过虚函数调用派生类实现（如上述例子）。  
  - 纯虚函数与抽象类：若基类中虚函数声明为`virtual void func() = 0;`，则基类为抽象类，不能实例化，必须由派生类实现该函数。

---

### 空类的大小及变化

#### 1. 空类的大小
- 空类：没有成员变量、虚函数和虚继承的类。  
  ```cpp
  class Empty {};
  ```
- 大小：`sizeof(Empty) == 1`字节。  
  - 原因：C++要求每个对象必须有唯一地址。编译器插入1字节占位符，确保不同空类实例在内存中占据不同位置。

---

#### 2. 添加普通成员函数后的变化
- 添加普通成员函数：  
  ```cpp
  class EmptyWithFunc {
  public:
      void func() {} // 普通成员函数
  };
  ```
- 大小：`sizeof(EmptyWithFunc) == 1`字节（与空类相同）。  
  - 原因：成员函数的代码存储在代码区（全局内存），不占用对象实例的内存空间。

---

#### 3. 添加虚函数后的变化
- 添加虚函数：  
  ```cpp
  class EmptyWithVirtualFunc {
  public:
      virtual void func() {} // 虚函数
  };
  ```
- 大小：  
  - 32位系统：`sizeof(EmptyWithVirtualFunc) == 4`字节。  
  - 64位系统：`sizeof(EmptyWithVirtualFunc) == 8`字节。  
- 原因：  
  - 虚函数会触发编译器为类生成虚函数表（vtable），并在每个实例中添加一个虚函数指针（vptr）指向该表。  
  - `vptr`的大小由系统架构决定（32位4字节，64位8字节）。

---

### 总结对比
| 类类型               | 大小（32位系统） | 大小（64位系统） | 原因                          |
|----------------------|------------------|------------------|-------------------------------|
| 空类                 | 1字节            | 1字节            | 占位符保证地址唯一性          |
| 空类 + 普通成员函数  | 1字节            | 1字节            | 函数代码不占用实例内存        |
| 空类 + 虚函数        | 4字节            | 8字节            | 虚函数指针（vptr）的存储开销  |

### 关键结论
- 虚函数是运行时多态的基石，通过虚函数表和指针实现动态绑定。  
- 普通函数不影响对象大小，虚函数因引入`vptr`会增加对象内存开销。  
- 空类的最小大小为1字节，这是C++对象模型的直接结果。
