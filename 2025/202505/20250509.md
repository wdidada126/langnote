要查看 Git 仓库中某个文件夹的更新记录，你可以使用 `git log` 命令并指定路径。以下是具体步骤和一些常用的命令选项：

### 查看文件夹的提交历史
要查看特定文件夹下的所有更改记录，可以使用以下命令：
```bash
git log -- <path/to/directory>
```

例如，如果你想要查看 `src` 文件夹的更新记录，可以运行：
```bash
git log -- src/
```
### 显示每次提交的简略信息
如果你不关心完整的提交信息，只想看到简略的日志信息，可以添加 `--oneline` 参数：
```bash
git log --oneline -- src/
```
### 查看文件改动详情
如果你想查看每个提交具体改了什么内容，可以加上 `-p` 参数来显示每次提交的补丁信息：
```bash
git log -p -- src/
```
### 统计每个提交影响的文件数量和行数
使用 `--stat` 参数可以看到每次提交影响了多少个文件以及增加了多少行、删除了多少行：
```bash
git log --stat -- src/
```
### 按作者过滤
如果想查看某一个作者在这个文件夹上的提交记录，可以加上 `--author` 参数：
```bash
git log --author="Author Name" -- src/
```
### 查看某个时间段内的提交
你还可以通过 `--since` 和 `--until` 来限制查询的时间范围：
```bash
git log --since="2 weeks ago" --until="1 week ago" -- src/
```
