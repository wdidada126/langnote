 如何配置并启动三台redis，如何测试启动是否成功，是否需要配置集群主从节点？


以下将详细介绍如何配置并启动三台 Redis 节点组成的集群，测试启动是否成功，以及是否需要配置集群主从节点。

### 1. 配置并启动三台 Redis 节点

#### 步骤 1：准备 Redis 配置文件
在每台机器上，为每个 Redis 实例创建配置文件。例如，在 `10.82.5.97` 机器上，创建两个配置文件 `redis6379.conf` 和 `redis6479.conf`，内容如下：

redis6379.conf
```plaintext
port 6379
cluster-enabled yes
cluster-config-file nodes-6379.conf
cluster-node-timeout 5000
appendonly yes
requirepass RedisP@ssW0rd
masterauth RedisP@ssW0rd
```

redis6479.conf
```plaintext
port 6479
cluster-enabled yes
cluster-config-file nodes-6479.conf
cluster-node-timeout 5000
appendonly yes
requirepass RedisP@ssW0rd
masterauth RedisP@ssW0rd
```

解释：
- `port`：指定 Redis 实例监听的端口。
- `cluster-enabled yes`：开启 Redis 集群模式。
- `cluster-config-file`：指定集群配置文件的名称。
- `cluster-node-timeout`：集群节点超时时间。
- `appendonly yes`：开启 AOF 持久化。
- `requirepass` 和 `masterauth`：设置访问密码。

在 `10.82.5.98` 和 `10.82.5.99` 机器上也做同样的操作，分别创建两个配置文件。

#### 步骤 2：启动 Redis 实例
在每台机器上，使用对应的配置文件启动 Redis 实例。例如，在 `10.82.5.97` 机器上执行以下命令：
```bash
redis-server redis6379.conf
redis-server redis6479.conf
```
同样，在 `10.82.5.98` 和 `10.82.5.99` 机器上执行相同的启动命令。

#### 步骤 3：创建集群
使用 `redis-cli` 工具创建 Redis 集群。在任意一台机器上执行以下命令：
```bash
redis-cli --cluster create 10.82.5.97:6379 10.82.5.97:6479 10.82.5.98:6379 10.82.5.98:6479 10.82.5.99:6379 10.82.5.99:6479 --cluster-replicas 1 -a RedisP@ssW0rd
```
`--cluster-replicas 1` 表示为每个主节点分配一个从节点。

### 2. 测试启动是否成功

#### 使用 `redis-cli` 连接测试
在任意一台机器上，使用 `redis-cli` 连接到集群中的一个节点，例如：
```bash
redis-cli -c -h 10.82.5.97 -p 6379 -a RedisP@ssW0rd
```
`-c` 表示以集群模式连接。连接成功后，执行 `cluster info` 命令查看集群信息，执行 `cluster nodes` 命令查看集群节点信息。

#### 方法二：Java 代码测试
在 Spring 工程中，使用 `Lettuce` 或 `Jedis` 客户端进行测试。以下是使用 `Lettuce` 的示例代码：

```java
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisClusterConfiguration;
import org.springframework.data.redis.connection.RedisPassword;
import org.springframework.data.redis.connection.lettuce.LettuceConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

import java.util.Arrays;
import java.util.List;

@Configuration
public class RedisConfig {

    @Value("${redis.cluster.node1.host}")
    private String node1Host;
    @Value("${redis.cluster.node1.port}")
    private int node1Port;
    @Value("${redis.cluster.node2.host}")
    private String node2Host;
    @Value("${redis.cluster.node2.port}")
    private int node2Port;
    @Value("${redis.cluster.node3.host}")
    private String node3Host;
    @Value("${redis.cluster.node3.port}")
    private int node3Port;
    @Value("${redis.cluster.node4.host}")
    private String node4Host;
    @Value("${redis.cluster.node4.port}")
    private int node4Port;
    @Value("${redis.cluster.node5.host}")
    private String node5Host;
    @Value("${redis.cluster.node5.port}")
    private int node5Port;
    @Value("${redis.cluster.node6.host}")   
    private String node6Host;
    @Value("${redis.cluster.node6.port}")
    private int node6Port;

    @Value("${redis.cluster.password}")
    private String password;

    @Bean
    public LettuceConnectionFactory redisConnectionFactory() {
        List<String> nodes = Arrays.asList(
                node1Host + ":" + node1Port,
                node2Host + ":" + node2Port,
                node3Host + ":" + node3Port,
                node4Host + ":" + node4Port,
                node5Host + ":" + node5Port,
                node6Host + ":" + node6Port
        );
        RedisClusterConfiguration clusterConfig = new RedisClusterConfiguration(nodes);
        clusterConfig.setPassword(RedisPassword.of(password));
        return new LettuceConnectionFactory(clusterConfig);
    }

    @Bean
    public RedisTemplate<String, Object> redisTemplate() {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(redisConnectionFactory());
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
        return template;
    }
}
```

在测试类中使用 `RedisTemplate` 进行操作：

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.stereotype.Component;

@Component
public class RedisTest {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    public void testRedisCluster() {
        redisTemplate.opsForValue().set("testKey", "testValue");
        Object value = redisTemplate.opsForValue().get("testKey");
        System.out.println("Value from Redis: " + value);
    }
}
```

### 3. 是否需要配置集群主从节点
在创建集群时，使用 `--cluster-replicas 1` 参数已经自动配置了主从节点。Redis 集群会自动将 6 个节点划分为 3 个主节点和 3 个从节点，每个主节点对应一个从节点。当主节点出现故障时，从节点会自动提升为主节点，保证集群的高可用性。

通过以上步骤，你可以成功配置并启动 Redis 集群，测试集群是否正常工作，并且已经自动配置了主从节点。
