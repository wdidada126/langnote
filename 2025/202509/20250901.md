# 20250901

根据您提供的信息和当前日期（2025年9月1日），关于 Isaac Lab 和 Isaac Sim 的开源情况，您的理解不完全准确。实际情况如下：

### 1. Isaac Lab

*   状态：是开源的。
*   开源时间：Isaac Lab 自其发布之初就采用了开源模式。
*   定位：它是一个基于 NVIDIA Isaac Sim 构建的机器人强化学习（Reinforcement Learning）框架。
*   功能：提供了一系列用于训练和部署机器人 AI 的工具、环境和算法，特别侧重于利用物理精确的仿真来加速机器人的开发。
*   开源地址：通常在 GitHub 上可以找到其开源代码库。

### 2. Isaac Sim

*   状态：不是在2025年6月才开源的。
*   实际情况：NVIDIA Isaac Sim 的核心部分（即 `omni.isaac.core` 等基础模块）在更早的时间（大约2023年）就已经以“源代码可用”（Source Available）的形式向开发者开放，但并非完全的开源（Open Source）。
*   2025年6月的关键事件：这个时间点更可能与 Isaac Sim 2025.1 或 2025.2 版本的发布有关。NVIDIA 在 2025 年初宣布了 Isaac Sim 将采用 NVIDIA 开发者软件许可证 (NVIDIA Developer Software License)，这使得开发者可以免费用于开发和非生产用途，并且可以访问更多源代码。
*   关键区别：
    *   开源 (Open Source)：通常指遵循如 MIT、Apache 2.0 等公认的开源许可证，允许自由使用、修改和分发，包括商业用途。
    *   源代码可用/开发者免费 (Source Available / Free for Developers)：NVIDIA 对 Isaac Sim 采取的模式。它允许开发者免费使用并查看大部分源代码，便于学习、研究和开发，但其许可证（NVIDIA Developer Software License）对生产环境的商业部署有更严格的限制和要求，通常需要购买专门的生产许可证。

### 总结

*   Isaac Lab 是一个开源的机器人强化学习框架。
*   Isaac Sim 并非在2025年6月“刚刚开源”。它在2025年经历了一次重要的许可模式更新，变得更加开放和对开发者友好（免费用于开发，提供源代码），但其许可模式仍属于“源代码可用”而非完全的“开源”。这一变化极大地降低了开发者使用这个强大仿真平台的门槛，促进了机器人技术的发展。
