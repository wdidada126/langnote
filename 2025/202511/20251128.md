Soot 是 Java 静态程序分析领域中使用最广泛的框架之一。

### 关于 SootUp (推荐的新项目)
值得注意的是，Soot 团队在 2022 年底发布了其继任者：
* SootUp:
    $$\text{[https://soot-oss.github.io/SootUp/](https://soot-oss.github.io/SootUp/)}$$

SootUp 是 Soot 的一个完全重写版本，拥有更模块化、更易于维护和使用的架构。
> 我的建议： 如果您是开始一个新的程序分析项目，维护团队强烈推荐您查看和使用 SootUp，尽管它目前可能还不具备 Soot 的全部历史功能。如果您正在维护一个基于旧版 Soot 的项目，则应继续使用原版 Soot。

### Soot 提供的四种主要 IR
Soot 能够将 Java 字节码转换为四种不同的中间表示，以满足不同的分析需求：

1.  Baf: 接近字节码，但进行了简化。
2.  Jimple: 3-地址代码形式，类型化，适用于优化。
3.  Shimple: SSA (Static Single Assignment) 形式的 Jimple，最适合数据流分析。
4.  Grimp: 表达式聚合形式的 Jimple，更接近源代码结构，适用于反编译和代码检查。
