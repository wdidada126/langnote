问题：如何不通过源码编译，在Mac或Linux上安装QuantLibXL (QLXL)。
遗憾的是，对于 QuantLibXL (QLXL) 这个特定的产品（它是 QuantLib 库的 Excel 插件），没有针对 Mac 或 Linux 的现成、预编译的二进制安装包。
### 核心事实：QuantLibXL与Excel
QuantLibXL 是一个 XLL 文件（Excel Add-in），它的主要目标是让 QuantLib 的功能在 Microsoft Excel 中使用。
  * Linux 上通常没有官方的 Microsoft Excel 客户端（只有 Web 版本，不支持 XLL）。
  * macOS 上的 Microsoft Excel 客户端在插件支持方面与 Windows 版本有所不同。
因此，QuantLibXL 的主要支持平台和二进制版本一直都是 Windows。

### 推荐的替代方案（不从源码构建）
如果您希望在 Mac/Linux 上使用 QuantLib 的功能，但不希望从源码构建，您应该考虑使用 QuantLib 的其他语言绑定，特别是 Python，它们有成熟的预编译包：

#### 方案一：使用 QuantLib Python 绑定 (推荐)
这是在 Mac 和 Linux 上使用 QuantLib 功能的最简单方法，因为它有预编译的二进制包。
1.  安装 Python 版本 QuantLib：
    ```bash
    # 确保您安装了 pip
    pip install QuantLib
    ```
2.  使用： 在 Python 环境中导入和使用 QuantLib 的功能。

#### 方案二：使用 Homebrew (仅限 Mac) 或 Linux 包管理器
这不是 QuantLibXL（Excel 插件），而是 QuantLib C++ 库 本身。如果您想编译自己的 C++ 代码并链接到 QuantLib，这是一个方便的起点。

  * 在 Mac 上 (使用 Homebrew)：

    ```bash
    brew install quantlib
    ```

* *安装后，您仍然需要配置您的项目 (例如 CMake 或 Ninja) 来找到这些头文件和库文件。*

  * 在 Linux 上 (例如 Ubuntu/Debian)：

    ```bash
    sudo apt update
    sudo apt install libquantlib-dev
    ```

* *同样，安装后需要配置您的构建系统。*

#### 方案三：使用 QuantLib C\# NuGet 包

如果您使用 C\#，QuantLib 有一个 NuGet 包，理论上在 Windows 和 macOS 上都应该可以工作。

```bash
dotnet add package QuantLib
```
### 总结
如果您最初的目的是在 Excel 中使用 QuantLib 的功能：

| 平台 | QuantLibXL 二进制安装包 | 解决方案 |
| :--- | :--- | :--- |
| Windows | 有（通常在 SourceForge 上可下载） | 推荐使用 QuantLibXL 二进制包。 |
| Mac/Linux | 无 | 没有直接的替代品。您需要将您的工作流程转移到 Python 等环境中。 |

如果您只是想在 C++/Python 代码中使用 QuantLib 功能，请选择方案一或方案二的预编译包进行安装。
