ECHO 是 Flex 中的一个宏，用于将匹配的文本原样输出到标准输出。它相当于 printf("%s", yytext) 的简写形式。

1. ECHO 的基本作用

%%
.|\n	ECHO;  // 将每个字符原样输出
%%


这相当于：
%%
.|\n	printf("%s", yytext);  // 手动输出匹配的文本
%%


2. 实际示例

示例1：简单的回显程序

%%
.|\n	ECHO;  // 将输入原样输出
%%

int main() {
    yylex();
    return 0;
}


输入：

Hello, World!
This is a test.


输出：

Hello, World!
This is a test.


示例2：带过滤的回显

%%
[0-9]+	ECHO;  // 只回显数字
.		;     // 忽略其他字符
\n		;     // 忽略换行
%%

int main() {
    yylex();
    return 0;
}


输入：


输出：


3. ECHO 的实现原理

在 Flex 生成的 C 代码中，ECHO 通常定义为：
#define ECHO do { \
    if (fwrite(yytext, yyleng, 1, yyout)) {} \
} while (0)


或者：
#define ECHO fwrite(yytext, yyleng, 1, yyout)


4. 与 printf 的区别

特性 ECHO printf

性能 更高（直接输出） 稍低（格式化）

功能 原样输出 可格式化输出

安全性 安全（无格式字符串） 需要小心格式字符串

使用场景 词法分析器输出 一般文本输出

5. 实际应用场景

场景1：简单的文本过滤器

%{
#include <stdio.h>
%}

%%
// 将大写字母转换为小写
[A-Z]	{ 
    yytext[0] = yytext[0] - 'A' + 'a'; 
    ECHO; 
}

// 其他字符原样输出
.|\n	ECHO;
%%

int main() {
    yylex();
    return 0;
}


场景2：行号显示

%{
int line_num = 1;
%}

%%
\n	{ 
    printf("\n%4d: ", ++line_num); 
}
.	ECHO;
%%

int main() {
    printf("%4d: ", line_num);
    yylex();
    return 0;
}


输入：

First line
Second line
Third line


输出：

   1: First line
   2: Second line
   3: Third line


场景3：简单的模板引擎

%{
#include <stdio.h>
%}

VAR [a-zA-Z_][a-zA-Z0-9_]*

%%
"{{" { 
    printf("{");  // 输出单个 {
    ECHO;         // 输出第二个 {
}

"}}" { 
    printf("}");  // 输出单个 }
    ECHO;         // 输出第二个 }
}

"$"{VAR} {
    // 模拟变量替换
    printf("[VARIABLE:%.*s]", yyleng-1, yytext+1);
}

.|\n	ECHO;
%%

int main() {
    yylex();
    return 0;
}


输入：

Hello, $name! Today is $day.


输出：

Hello, [VARIABLE:name]! Today is [VARIABLE:day].


6. 高级用法

条件性 ECHO

%{
int debug_mode = 1;
%}

%%
[0-9]+	{ 
    if (debug_mode) {
        printf("(NUMBER:"); 
        ECHO; 
        printf(")");
    } else {
        ECHO;
    }
}
.|\n	ECHO;
%%


带缓冲的 ECHO

%{
#include <string.h>
char buffer[1024];
int buf_index = 0;
%}

%%
.	{ 
    if (buf_index < sizeof(buffer)-1) {
        buffer[buf_index++] = yytext[0];
    }
    ECHO;
}

\n	{ 
    buffer[buf_index] = '\0';
    printf(" [Line: %s]", buffer);
    buf_index = 0;
    ECHO;
}
%%


7. 注意事项

1. 性能考虑

// 好的做法：批量处理
[a-zA-Z]+	ECHO;  // 一次输出整个单词

// 不好的做法：逐个字符处理
.	ECHO;          // 每个字符都调用一次输出


2. 二进制数据

// ECHO 可以处理二进制数据，但要注意编码
.	{
    if (isprint(yytext[0])) {
        ECHO;  // 可打印字符
    } else {
        printf("\\x%02X", (unsigned char)yytext[0]);  // 不可打印字符
    }
}


3. 错误处理

%%
.	{
    if (fwrite(yytext, yyleng, 1, yyout) != 1) {
        fprintf(stderr, "Output error!\n");
        exit(1);
    }
}
%%


8. 完整的示例程序

简单的文本处理工具

%{
#include <stdio.h>
#include <ctype.h>

int char_count = 0;
int word_count = 0;
int line_count = 1;
%}

WORD	[a-zA-Z]+

%%
{WORD}	{ 
    word_count++; 
    ECHO; 
}

\n	{ 
    line_count++; 
    ECHO; 
}

.	{ 
    char_count++; 
    ECHO; 
}
%%

int main(int argc, char **argv) {
    yylex();
    
    printf("\n\n=== Statistics ===\n");
    printf("Characters: %d\n", char_count);
    printf("Words: %d\n", word_count);
    printf("Lines: %d\n", line_count);
    
    return 0;
}


总结
ECHO 是 Flex 中一个非常有用的宏，主要用于：
• 简单的文本过滤和转换
• 原型开发和调试
• 学习 Flex 的基本概念
• 简单的文本处理工具
在实际项目中，通常会用更复杂的动作替换 ECHO，但对于快速原型和简单工具来说，ECHO 非常方便。


cmake 查看target列表，cmake --build只编译一部分target

在CMake中查看和选择性编译target有多种方法：

1. 查看所有target列表

方法一：使用CMake GUI

cmake-gui -S . -B build

在GUI中可以浏览所有target。

方法二：使用CMake生成后查看

# 生成构建系统
cmake -S . -B build

# 查看生成的target（不同生成器方式不同）


方法三：使用构建系统工具

对于Makefile生成器：
cd build
make help


对于Ninja生成器：
cd build
ninja -t targets


对于Visual Studio：
# 打开生成的sln文件查看所有项目


2. 选择性编译target

编译特定target

# 编译单个target
cmake --build build --target <target_name>

# 编译多个特定target
cmake --build build --target <target1> <target2>


常用target操作

# 只编译主程序
cmake --build build --target my_app

# 只编译库
cmake --build build --target my_lib

# 清理特定target
cmake --build build --target clean

# 安装target
cmake --build build --target install


排除某些target

CMake本身没有直接排除target的选项，但可以：
# 先编译all，然后排除安装
cmake --build build --target all
# 然后手动执行需要的操作


3. 实用技巧

查看target依赖关系

# Makefile
make -n | grep # 查看构建顺序

# Ninja
ninja -t graph | dot -Tpng > deps.png

并行编译特定target
cmake --build build --target <target_name> -j 8
查看详细构建信息
cmake --build build --target <target_name> --verbose
4. 实际示例

假设项目结构如下：

my_project/
├── CMakeLists.txt
├── app/
├── lib1/
└── lib2/

# 配置项目
cmake -S . -B build

# 查看所有target（Makefile）
cd build
make help

# 只编译库
cmake --build build --target lib1 lib2

# 只编译应用程序
cmake --build build --target my_app

# 编译所有（默认行为）
cmake --build build

5. 在CMakeLists.txt中控制target
你可以在CMakeLists.txt中设置target属性来控制编译行为：
# 设置target为排除在ALL_BUILD外
add_library(my_lib STATIC src.cpp)
set_target_properties(my_lib PROPERTIES EXCLUDE_FROM_ALL TRUE)

# 这样默认cmake --build不会编译该target
# 需要显式指定：cmake --build build --target my_lib
通过以上方法，你可以灵活地查看和控制CMake项目的编译过程。

除了ANTLR之外，确实有很多优秀的现代解析器生成工具。以下是主要的替代品分类介绍：

1. PEG（Parsing Expression Grammar）系列

主打工具
工具 语言 特点
Pest Rust 简洁的PEG语法，零依赖，性能好
Lark Python 友好易用，支持EBNF和上下文无关文法
Peggy JavaScript 替代PEG.js，支持多语言目标
TatSu Python 支持语义动作，生成可读代码

示例（Lark）

from lark import Lark
grammar = """
    start: expr
    expr: expr "+" term -> add
        | term
    term: NUMBER
"""
parser = Lark(grammar)
tree = parser.parse("1 + 2")


2.  combinator库（函数式风格）
主流选择
工具 语言 特点
Nom Rust 零分配，编译时解析器组合
Parsec Haskell 函数式解析器组合库的鼻祖
Megaparsec Haskell Parsec的现代改进版

Chumsky Rust 友好的错误消息，组合灵活

示例（Nom）
use nom::IResult;
fn parser(input: &str) -> IResult<&str, Vec<&str>> {
    separated_list1(tag(","), alpha1)(input)
}

7. 选择建议矩阵
根据需求选择：
需求 推荐工具
学习/教育 Lark, Pest（语法简单）
高性能 Nom, Tree-sitter
生产环境 ANTLR, Lark, Nom
快速原型 Peggy, Lark
复杂语言 ANTLR, Datalog
嵌入式 手写递归下降
性能对比（大致顺序）：

Nom ≈ 手写解析器 > Tree-sitter > ANTLR > Pest > Lark > Flex/Bison

8. 现代解析器的发展趋势
新特性
1. 更好的错误信息（Chumsky、Lark）
2. 增量解析（Tree-sitter）
3. 内存安全（Rust生态工具）
4. 组合性（函数式combinator）
5. 可视化调试（ANTLR、Lark）

总结建议：
• 新项目首选: 根据语言生态选择现代工具
• 学习目的: 从Lark或Pest开始（友好）
• 企业项目: ANTLR或Nom（成熟稳定）
• 极致性能: Nom或手写解析器

这些现代工具在易用性、错误处理和开发体验上都比flex/bison有显著提升，特别是对于新项目来说值得考虑。
