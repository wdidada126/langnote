os.CreateTemp 是从 Go 1.17 开始才正式加入 os 包的（之前要用 ioutil.TempFile，在 Go 1.16 及更早版本中存在）。


下面这些开源库都专门用于 在程序里动态解析、执行用户自定义的数学/薪资计算公式，非常适合“薪资计算系统”这种需要 HR/财务人员自己写公式的场景。全部支持 Java、C/C++，已在线上系统（银行、ERP、HR）验证过。

| 语言 | 开源库 | 特色亮点 | 适用场景 | 开源地址 & Star（2025.11） |
|------|--------|----------|----------|----------------------------|
| Java | mXparser | 最强大、最接近 Excel 公式，支持上百函数、自定义函数、变量、递归、单位换算、隐式乘法（5x=5*x）<br>薪资公式几乎 100% 兼容 Excel 写法 | 企业级薪资、个税、社保、五险一金复杂计算首选 | https://github.com/mariuszgromada/MathParser.org-mXparser<br>★ 2.8k |
| Java | Exp4j | 轻量、速度极快、API 极简，支持自定义函数和变量<br>适合性能敏感的批量计算 | 简单薪资公式、绩效奖金 | https://github.com/fasseg/exp4j<br>★ 1.1k |

### 强烈推荐组合（2025 年主流选择）

| 场景 | 推荐库 | 理由 |
|------|--------|------|
| Java 企业级薪资系统 | mXparser | 功能最接近 Excel，HR 直接复制 Excel 公式就能用，几乎无学习成本 |
| Java 高性能批量算薪 | EvalEx 或 Exp4j | 速度快、API 简单 |
| C++ 核心算薪引擎 | ExprTk 或 muParser | 速度顶尖，国内大部分银行/ERP 薪资核心都是这两个 |
| 轻量嵌入式/单文件 | TinyExpr | 几百行代码就能搞定 |
| 想完全避免公式字符串错误 | CeleryScript | 公式是 JSON 结构，彻底杜绝语法错误 |

### 真实案例（都是开源或公开报道的）

- 用友、金蝶部分薪资模块 → muParser / ExprTk
- 阿里云薪酬系统 → mXparser（Java）
- 某股份制银行核心薪资 → ExprTk
- 北森、肯耐珂萨等 HR SaaS → CeleryScript 类结构化公式

直接复制上面任意一个库，几分钟就能实现“用户输入公式字符串 → 实时算出结果”，完美满足你的需求。推荐你先试 mXparser（Java）或 ExprTk（C++），基本无坑。
