你遇到的错误信息：

```
[ERROR] Make sure to run from Native Tools Command Prompt.
FAILED
```

出现在你尝试运行 Telegram Desktop 的构建脚本 `win.bat` 时，说明你 没有在正确的命令行环境中运行该脚本。



## 错误原因

这个脚本依赖于 Visual Studio 的 Native Tools Command Prompt（原生工具命令提示），因为：

- 它需要使用微软的编译器（MSVC）
- 需要设置好环境变量（如 `PATH`, `INCLUDE`, `LIB` 等）
- 这些环境变量只会在 VS 的开发人员命令提示符 中自动配置



## 解决方案：使用 Visual Studio 的开发人员命令提示符

### 步骤如下：

### 方法一：通过开始菜单启动

1. 打开「开始菜单」
2. 搜索：
   ```
   x64 Native Tools Command Prompt for VS 2022
   ```
   或者你安装的是其他版本的 VS（如 VS 2019 / VS 2023），选择对应的版本。
3. 右键 → “以管理员身份运行”（可选）

> 如果你找不到它，请确认你已经安装了 Visual Studio 的 C++ 开发组件。



### 方法二：从 PowerShell 启动开发环境命令行

如果你希望继续使用 PowerShell，可以手动加载 VS 的环境变量：

#### 示例（适用于 VS 2022）：

```powershell
call "C:\Program Files\Microsoft Visual Studio\2022\Enterprise\VC\Auxiliary\Build\vcvars64.bat"
```

替换路径为你实际安装的 Visual Studio 版本，比如：

| Visual Studio 版本 | 路径 |
|--||
| VS 2022 Community   | `"C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"` |
| VS 2022 Professional| `"C:\Program Files\Microsoft Visual Studio\2022\Professional\VC\Auxiliary\Build\vcvars64.bat"` |
| VS 2019             | `"C:\Program Files (x86)\Microsoft Visual Studio\2019\Community\VC\Auxiliary\Build\vcvars64.bat"` |

然后运行你的脚本：

```powershell
.\tdesktop\Telegram\build\prepare\win.bat
```



## 补充说明

- `win.bat` 是 Telegram 的构建准备脚本，用于下载依赖、配置项目等。
- 它会调用 `ninja`, `cl.exe`, `link.exe` 等 MSVC 工具链，所以必须在正确的环境中运行。
- 如果你是在 WSL 或普通 PowerShell 中运行，这些工具不在 `PATH` 中，就会报错。



## 总结解决步骤

| 步骤 | 描述 |
|||
| 1    | 打开 x64 Native Tools Command Prompt for VS |
| 2    | 或者在 PowerShell 中手动加载 `vcvars64.bat` |
| 3    | 切换到 Telegram 源码目录 |
| 4    | 再次运行脚本：`.\build\prepare\win.bat` |



## 示例完整流程（PowerShell + VS 2022）

```powershell
# Step 1: 加载 MSVC 环境变量
call "C:\Program Files\Microsoft Visual Studio\2022\Enterprise\VC\Auxiliary\Build\vcvars64.bat"

# Step 2: 进入 Telegram 源码目录
cd \path\to\Telegram

# Step 3: 执行构建准备脚本
.\build\prepare\win.bat
```


在 Ubuntu 系统上安装 [Poetry](https://python-poetry.org/)（Python 依赖管理和打包工具）有多种方式。下面是最推荐的几种方法，适用于 Ubuntu 20.04、22.04、24.04 等主流版本。


## 方法一：官方推荐安装方式（使用 `install-poetry.py` 脚本）

这是官方推荐的方式，安全、独立、不会污染系统 Python 环境。

### 步骤如下：

```bash
# 下载安装脚本
curl -sSL https://install.python-poetry.org | python3 -
```

> 这会将 Poetry 安装到你的 `$HOME/.local/bin` 目录下。

### 添加路径到环境变量（如果未自动添加）

编辑你的 shell 配置文件（如 `~/.bashrc` 或 `~/.zshrc`）并加入以下内容：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

然后应用更改：

```bash
source ~/.bashrc   # 或 source ~/.zshrc
```

### 验证安装

```bash
poetry --version
```

输出示例：

```
Poetry (version 1.8.3)
```



## 方法二：使用 `pipx` 安装（推荐用于隔离环境）

`pipx` 是一个专门用于安装和运行 Python 应用程序的工具，它会在隔离环境中安装应用程序，避免依赖冲突。

### 安装步骤：

```bash
# 安装 pipx（如果还没有）
sudo apt update
sudo apt install python3-pip -y
python3 -m pip install --user pipx
python3 -m pipx ensurepath
```

```bash
# 使用 pipx 安装 poetry
pipx install poetry
```

### 验证安装

```bash
poetry --version
```



## 方法三：使用 `snap` 安装（简单但不推荐）

```bash
sudo snap install poetry --classic
```

⚠️ 注意：Snap 版本有时会滞后于最新版，且与虚拟环境交互可能存在问题，不建议生产使用。



## 常见问题解决

### ❌ 报错：`command not found: poetry`

请确认你已执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
source ~/.bashrc
```

或者重新登录终端。



## 示例：创建一个新项目

```bash
poetry new myproject
cd myproject
poetry install
```
