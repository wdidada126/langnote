libfilezilla 编译安装了，/usr/local include和lib目录下，sudo apt-get install libfilezilla-dev -y了，现在想使用apt-get安装的头文件和库文件，如何操作，Ubuntu

你已经：

- 编译安装了 `libfilezilla` 到 `/usr/local/include/` 和 `/usr/local/lib/`
- 同时也通过 `sudo apt-get install libfilezilla-dev` 安装了系统版本的开发包

现在你想 优先使用 apt-get 安装的头文件和库文件（即系统自带的 `/usr/include/libfilezilla/` 和 `/usr/lib/x86_64-linux-gnu/libfilezilla.so`），而不是编译安装的 `/usr/local/` 下的版本。

---

## 目标：让编译器和链接器优先使用 apt-get 安装的版本

### 1. 确认 apt-get 安装路径存在

```bash
ls /usr/include/libfilezilla/
ls /usr/lib/x86_64-linux-gnu/libfilezilla*
```

你应该看到类似如下内容：

```
/usr/include/libfilezilla/logger.hpp
/usr/include/libfilezilla/thread.hpp
...
/usr/lib/x86_64-linux-gnu/libfilezilla.a
/usr/lib/x86_64-linux-gnu/libfilezilla.so
```

---

## 解决方案一：清理 `/usr/local` 中的 libfilezilla 文件（推荐）

如果你确定要 完全使用 apt-get 的版本，建议先删除 `/usr/local` 中的旧文件：

```bash
sudo rm -rf /usr/local/include/libfilezilla
sudo rm -f /usr/local/lib/libfilezilla.*
sudo ldconfig
```

这样确保不会发生头文件或库文件冲突。

---

## 解决方案二：在 CMake 或编译时指定使用系统路径

如果你暂时不想删除 `/usr/local` 中的内容，可以通过构建命令强制使用系统目录下的版本。

### 方法 1：使用 `pkg-config`（推荐） 实际情况，搞不定

libfilezilla 提供了 `pkg-config` 支持，可以自动获取正确的头文件和库路径。

#### 示例 CMakeLists.txt：

```cmake
cmake_minimum_required(VERSION 3.14)
project(my_project)

find_package(PkgConfig REQUIRED)
pkg_check_modules(LIBFZ REQUIRED IMPORTED_TARGET libfilezilla)

add_executable(myapp main.cpp)
target_link_libraries(myapp PRIVATE PkgConfig::LIBFZ)
```

这个方法会自动使用 apt-get 安装的版本。

---

### 方法 2：手动指定 include 和 link 路径（适用于 Makefile 或 g++ 命令行）

```bash
g++ main.cpp -o myapp \
    -I/usr/include/libfilezilla \
    -L/usr/lib/x86_64-linux-gnu -lfilezilla
```

这样会明确使用 apt-get 安装的头文件和库。

---

## 如何验证是否使用的是 apt-get 安装的版本？

你可以运行以下命令查看动态库路径：

```bash
ldd myapp | grep libfilezilla
```

输出应为：

```
libfilezilla.so.0 => /usr/lib/x86_64-linux-gnu/libfilezilla.so.0 (0x...)
```

而不是指向 `/usr/local/lib/`。

---

## 额外建议：如何知道当前使用的版本？

你可以编写一个简单的程序打印 libfilezilla 的版本信息：

```cpp
#include <libfilezilla/version.hpp>
#include <iostream>

int main() {
    std::cout << "libfilezilla version: "
              << FZ_VERSION_MAJOR << "."
              << FZ_VERSION_MINOR << "."
              << FZ_VERSION_PATCH << std::endl;
    return 0;
}
```

编译运行后可以看到实际使用的版本号。
