在 C++ 中，`virtual void pureVirtualFunction() = 0;` 和 `virtual void pureVirtualFunction();` 虽然都涉及虚函数，但它们有着显著的区别，下面从定义、功能、使用场景等方面为你详细分析。

### 1. 纯虚函数（`virtual void pureVirtualFunction() = 0;`）
#### 定义
当在基类中声明一个虚函数时，在函数声明的末尾加上 `= 0`，这个函数就被定义为纯虚函数。包含纯虚函数的类被称为抽象类。示例代码如下：
```cpp
class Base {
public:
    virtual void pureVirtualFunction() = 0;
};
```

#### 功能
- 定义接口：纯虚函数为派生类定义了一个必须实现的接口。基类通过纯虚函数规定了派生类需要实现的功能，但不提供具体的实现代码。
- 强制实现：任何继承自抽象类的派生类都必须实现该纯虚函数，否则派生类也会成为抽象类，无法实例化对象。

#### 使用场景
适用于需要为一组相关的类定义统一接口的情况，比如图形类层次结构中，基类 `Shape` 可以定义一个纯虚函数 `area()` 来计算面积，所有具体的图形类（如 `Circle`、`Rectangle` 等）都必须实现这个函数。示例代码如下：
```cpp
#include <iostream>

class Shape {
public:
    virtual double area() = 0;
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() override {
        return 3.14 * radius * radius;
    }
};

int main() {
    // Shape s; // 错误：不能实例化抽象类
    Circle c(5.0);
    std::cout << "Circle area: " << c.area() << std::endl;
    return 0;
}
```

### 2. 普通虚函数（`virtual void pureVirtualFunction();`）
#### 定义
在基类中使用 `virtual` 关键字声明的函数就是普通虚函数，基类可以为该函数提供默认的实现。示例代码如下：
```cpp
class Base {
public:
    virtual void virtualFunction() {
        std::cout << "Base::virtualFunction()" << std::endl;
    }
};
```

#### 功能
- 实现多态：普通虚函数允许在基类指针或引用调用该函数时，根据实际指向的对象类型调用相应派生类的函数实现，从而实现运行时多态。
- 提供默认实现：基类可以为虚函数提供一个默认的实现，派生类可以选择重写该函数以提供自己的实现，也可以不重写而使用基类的默认实现。

#### 使用场景
适用于基类已经有一个通用的实现，但派生类可能需要根据自身特点进行修改的情况。例如，基类 `Animal` 有一个虚函数 `makeSound()`，不同的派生类（如 `Dog`、`Cat` 等）可以重写这个函数来发出不同的声音。示例代码如下：
```cpp
#include <iostream>
class Animal {
public:
    virtual void makeSound() {
        std::cout << "Some generic animal sound." << std::endl;
    }
};

class Dog : public Animal {
public:
    void makeSound() override {
        std::cout << "Woof!" << std::endl;
    }
};

int main() {
    Animal* animal = new Dog();
    animal->makeSound(); // 输出 "Woof!"
    delete animal;
    return 0;
}
```

### 总结
- 纯虚函数用于定义接口，强制派生类实现该函数，包含纯虚函数的类是抽象类，不能实例化对象。
- 普通虚函数用于实现运行时多态，基类可以提供默认实现，派生类可以选择重写该函数。
