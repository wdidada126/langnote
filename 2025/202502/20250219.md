# 一、netsh 是什么
netsh 是 Windows 系统自带的网络配置命令行工具
全称：Network Shell 网络命令行解释器

作用：
不用图形界面，纯命令行配置、查看、诊断、管理 Windows 所有网络组件：
- 无线网络 WiFi
- 网卡 IP / 子网 / 网关 / DNS
- 防火墙规则
- 端口转发
- 路由表
- 热点承载网络（你用的 hostednetwork）
- 重置网络、WLAN 配置等

# 二、哪个操作系统能用
仅 Windows 全系支持：
- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11
- Windows Server 2008~2022

Linux / macOS 没有 netsh 命令，完全不通用。

# 三、你这两条命令逐句解释
```cmd
netsh wlan set hostednetwork mode=allow ssid=dada-wins10 key=5Edidada
```
- `netsh wlan` 进入无线网络配置上下文
- `set hostednetwork mode=allow` 开启系统承载网络（虚拟热点）功能
- `ssid=dada-wins10` 热点名称
- `key=5Edidada` 热点WiFi密码

```cmd
netsh wlan start hostednetwork
```
启动这个 Windows 虚拟热点，手机/其他设备可以连这个 WiFi 上网。

# 四、补充常用 netsh 命令
```cmd
# 停止虚拟热点
netsh wlan stop hostednetwork

# 查看已保存WiFi密码
netsh wlan show profiles
netsh wlan show profile name=热点名 key=clear

# 重置网络（解决网络异常神器）
netsh winsock reset
netsh int ip reset
```

# 五、一句话总结
netsh 是 Windows 专属网络配置命令行工具，可以命令行管理 WiFi、IP、防火墙、虚拟热点；
你那两句就是 Win10/Win11 用系统自带功能开手机热点 的经典命令。
