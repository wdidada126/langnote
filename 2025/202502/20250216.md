mybatis oracle xml，报错 ###Cause:java.sql.sQLSyntaxErrorException:ORA-00923:未找到要求的 FROM关键宁 如何修改

从你给出的错误信息 `ORA-00923: 未找到要求的 FROM 关键字` 来看，这通常是 SQL 语句的语法存在问题，很可能是在 SQL 拼接或者关键字使用方面出了差错。下面为你详细分析并给出修改建议：

### 问题分析
1. `UPDATE` 和 `INSERT` 部分引用问题：在 `UPDATE` 和 `INSERT` 语句里，使用 `item` 对象时直接引用即可，无需再用 `#{}` 进行参数占位，因为在 `USING` 子句中已经将参数处理好了。
2. `GROUP_SORT` 未正确处理：原代码中 `SELECT` 子句里是 `#{index} AS index`，而 `UPDATE` 和 `INSERT` 部分使用的是 `GROUP_SORT`，这里应该统一，并且 `index` 作为列名不太合适，建议改为 `GROUP_SORT`。
3. `UNION` 关键字大小写问题：在 SQL 中，`UNION` 作为关键字，建议使用大写，避免一些潜在的大小写敏感问题。

### 修改后的代码
```xml
<insert id="insertUpdateMenuClassifyList" parameterType="map">
    MERGE INTO ${schema.inte}.ENT_ETP_MENU_CLASSIFY_TD A
    USING (
        <foreach collection="LIST" item="item" index="index" separator="UNION">
            SELECT
                #{item.GROUP_ID} AS GROUP_ID,
                #{item.GROUP_NAME} AS GROUP_NAME,
                #{index} AS GROUP_SORT,
                #{item.IS_DELETE} AS IS_DELETE,
                #{ETP_ID} AS ETP_ID,
                #{CREATE_TIME} AS CREATE_TIME,
                #{LAST_MODI_TIME} AS LAST_MODI_TIME
            FROM DUAL
        </foreach>
    ) item
    ON (
        A.ETP_ID = item.ETP_ID
        AND A.GROUP_ID = item.GROUP_ID
    )
    WHEN MATCHED THEN
        UPDATE SET
            A.GROUP_NAME = item.GROUP_NAME,
            A.GROUP_SORT = item.GROUP_SORT,
            A.IS_DELETE = item.IS_DELETE,
            A.LAST_MODI_TIME = item.LAST_MODI_TIME
    WHEN NOT MATCHED THEN
        INSERT (
            GROUP_ID,
            GROUP_NAME,
            GROUP_SORT,
            IS_DELETE,
            ETP_ID,
            CREATE_TIME,
            LAST_MODI_TIME
        ) VALUES (
            item.GROUP_ID,
            item.GROUP_NAME,
            item.GROUP_SORT,
            item.IS_DELETE,
            item.ETP_ID,
            item.CREATE_TIME,
            item.LAST_MODI_TIME
        )
</insert>
```

### 代码解释
- `foreach` 标签：该标签会遍历传入的 `LIST` 集合，为集合中的每个元素生成一个 `SELECT` 语句，这些 `SELECT` 语句通过 `UNION` 进行合并，从而构建出一个临时表 `item`。
- `MERGE INTO` 语句：这是 Oracle 用于实现插入或更新操作的语句。
  - `USING` 子句：借助 `foreach` 标签生成的临时表 `item` 来和目标表 `A` 进行匹配。
  - `ON` 子句：定义匹配条件，当目标表和临时表中的 `ETP_ID` 和 `GROUP_ID` 都相同时，认为匹配成功。
  - `WHEN MATCHED THEN`：若匹配成功，则执行 `UPDATE` 操作，更新目标表中的相关字段。
  - `WHEN NOT MATCHED THEN`：若匹配失败，则执行 `INSERT` 操作，向目标表中插入新记录。

### 注意事项
- 参数验证：在 Java 代码中调用该 SQL 语句时，要确保传入的参数合法，避免出现空指针异常等问题。
- 异常处理：添加异常处理逻辑，在出现数据库操作异常时能够进行相应的处理，比如回滚事务等。

powershell 遍历子文件夹下面的.flw文件

# 定义要遍历的根文件夹路径
$rootFolder = "D:\work\yitong\codes\mmc-platform\src\main\resources\flow"

# 遍历根文件夹下的所有子文件夹
Get-ChildItem -Path $rootFolder -Directory | ForEach-Object {
    $subFolder = $_.Name
    # 遍历子文件夹下的所有 .flw 文件
    Get-ChildItem -Path $_.FullName -Filter "*.flw" | ForEach-Object {
        $flwFile = $_.BaseName
        # 生成 curl 命令行
        $curlCommand = "curl -X POST http://127.0.0.1:9001/$subFolder/$flwFile.do"
        # 输出 curl 命令行
        Write-Output $curlCommand
    }
}
