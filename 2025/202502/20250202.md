## voip
以下是一些流行的开源VoIP 库及其对应的编程语言和特点：
### 1. C/C++
- PJSIP  
  - 特点：全面的SIP协议栈，支持音视频编解码（如 Opus、G.711）、NAT 穿透（STUN/TURN/ICE）等。  
  - 应用场景：企业通信系统、VoIP客户端/服务器。  
  - 链接：[PJProject](https://www.pjsip.org/)
- OpenH323  
  - 特点：基于 H.323 标准的协议栈，支持多方通话和视频会议。  
  - 应用场景：传统 VoIP 解决方案、视频会议系统。  
  - 链接：[GitHub](https://github.com/OpenH323/openh323)
- Mumble  
  - 特点：低延迟、高质量语音通信软件，常用于游戏语音。  
  - 应用场景：实时语音聊天、游戏内通信。  
  - 链接：[GitHub](https://github.com/mumble-voip/mumble)
### 2. Go
- Pion WebRTC  
  - 特点：纯 Go 实现的 WebRTC 库，支持浏览器与服务器通信。  
  - 应用场景：WebRTC 视频通话、实时流媒体。  
  - 链接：[GitHub](https://github.com/pion/webrtc)
### 3. JavaScript/TypeScript
- SIP.js  
  - 特点：轻量级 SIP 协议库，适合浏览器端 VoIP 应用。  
  - 应用场景：Web 电话、浏览器间通话。  
  - 链接：[GitHub](https://github.com/onsip/sip.js)
- MiroTalk SFU  
  - 特点：基于 WebRTC 的可扩展视频会议服务器，支持高并发。  
  - 应用场景：实时视频会议、在线教育。  
  - 链接：[GitHub](https://github.com/mirotalk/mirotalk-sfu)
### 4. Rust
- webrtc-rs  
  - 特点：纯 Rust 实现的 WebRTC 库，注重安全性和性能。  
  - 应用场景：高性能实时通信、P2P 应用。  
  - 链接：[GitHub](https://github.com/webrtc-rs/webrtc)
### 5. Erlang
- Ejabberd  
  - 特点：支持 XMPP/SIP 的高并发通信服务器，适合大规模部署。  
  - 应用场景：企业即时通讯、VoIP 云服务。  
  - 链接：[GitHub](https://github.com/processone/ejabberd)
### 6. C#
- Sipsorcery  
  - 特点：.NET 平台的 VoIP 库，支持 SIP 和 WebRTC。  
  - 应用场景：Windows 桌面或服务器端通信应用。  
  - 链接：[GitHub](https://github.com/sipsorcery/sipsorcery)
### 7. Python
- PJSIP 的 Python 绑定  
  - 特点：通过绑定使用 PJSIP 的功能，简化 Python 开发。  
  - 应用场景：快速原型开发、脚本化 VoIP 工具。  
  - 链接：[pjsip-python](https://github.com/pjsip/pjproject/tree/master/pjsip-apps/src/python)
### 8. Java/Kotlin
- Jitsi  
  - 特点：跨平台的视频会议软件，支持 WebRTC 和 SIP。  
  - 应用场景：开源视频会议解决方案、企业协作。  
  - 链接：[GitHub](https://github.com/jitsi/jitsi)
- Linphone-Android  
  - 特点：Android 平台的 SIP 软电话，支持音视频通话。  
  - 应用场景：移动 VoIP 应用开发。  
  - 链接：[GitLab](https://gitlab.linphone.org/BC/public/linphone-android)
### 9. 其他语言
- FreeSWITCH（C）：开源电信框架，支持 SIP、WebRTC，适合高并发场景。  
- Asterisk（C）：PBX 系统，常用于企业电话交换。  
- Kamailio（C）：高性能 SIP 服务器，适合大规模 VoIP 部署。
### 选择建议
- WebRTC 优先：Go 的 Pion 或 Rust 的 webrtc-rs。  
- 高性能服务器：Erlang 的 Ejabberd 或 C 的 FreeSWITCH。  
- 浏览器端开发：JavaScript 的 SIP.js 或 MiroTalk SFU。  
- 跨平台客户端：C++ 的 PJSIP 或 Java 的 Jitsi。  

根据项目需求（如性能、平台、生态）选择合适的库。
