编译obs stuido需要设置



配置项目（不指定构建类型）：
```bash
cmake -S . -B build
```

编译 Debug 版本：
```bash
cmake --build build --config Debug
```

这里 --config Debug 明确编译 Debug 版本。
安装 Debug 版本：
```bash
cmake --install build --config Debug
```

通过 --config Debug 选项，确保安装的是 Debug 版本的文件。
