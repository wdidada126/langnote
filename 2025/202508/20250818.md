N3656 是一个 C++ 标准提案文档的编号，而它出现在 `isocpp.org` 这个网站上。我们来深入解释：

##  问题解析：`N3656` 是什么？和 `P-number` 有什么关系？`make_unique` 提案设置了什么？

###  1. N3656 是什么？

- `N3656` 是 C++ 标准委员会（WG21） 使用的 文档编号（Document Number）。
- 前缀 `N` 表示这是一个 WG21 的“工作文件”（National Body Comment / Working Paper）。
- 所有提交给 C++ 标准委员会的提案、修订、技术报告等，都会被分配一个 `N` 开头的编号。
- `N3656` 就是 `std::make_unique` 这个功能的正式提案文档之一。

> 📌 N3656 = `make_unique` (Revision 1)` by Stephan T. Lavavej

- 作者：Stephan T. Lavavej（STL），当时在微软，C++ 标准库的重要贡献者。
- 日期：2013年4月18日
- 内容：提议在 C++ 标准库中添加 `std::make_unique<T>(...)` 工厂函数，用于安全地创建 `std::unique_ptr<T>`。

---

###  2. N-number vs P-number：有什么区别？

| 类型 | 含义 | 说明 |
|------|------|------|
| N-number | National Body / Working Paper | 早期提交给委员会的草案，编号由秘书处分配，如 `N3656` |
| P-number | Project Paper | 现代 C++ 提案的标准编号系统，由 WG21 推行，如 `P0254R2` |

>  演变过程：
> - 早年（2013年左右）：使用 `N-number`（如 N3656）
> - 2014年后：逐步过渡到 `P-number` 系统（更规范、可追溯）
> - 现在：新提案都用 `P-number`，旧的 `N-number` 文档仍可查

所以：
- `N3656` 是 `make_unique` 的 早期提案版本
- 后来它被整合进标准，最终以 P0009R0 等形式继续演进

---

###  3. `make_unique` 提案“设置”了什么？（即：它引入了什么功能？）

`N3656` 提案的核心是：

> 为 `std::unique_ptr` 添加一个工厂函数 `make_unique`，用于更安全、更方便地创建智能指针。

#### 📌 原有问题（C++11 初期）：
```cpp
// 容易出错：
std::unique_ptr<Foo> p(new Foo(42));

// 如果 new 失败，可能内存泄漏（虽然 unique_ptr 会处理，但表达式复杂时有问题）
// 而且不支持数组
```

####  `make_unique` 解决方案：
```cpp
#include <memory>

// ✅ 推荐方式
auto p = std::make_unique<Foo>(42);

// 支持数组（C++14 起）
auto arr = std::make_unique<int[]>(10);
```

####  提案设置（引入）了以下特性：

| 特性 | 说明 |
|------|------|
| ✅ 类型推导 | 自动推导 `T`，无需重复写类型 |
| ✅ 异常安全 | 避免“new 表达式”在复杂调用中的求值顺序问题 |
| ✅ 完美转发 | 支持任意参数构造对象 |
| ✅ 支持数组 | `make_unique<T[]>` 和 `make_unique<T[N]`（后者有限制） |
| ✅ 避免重复 new | 更简洁、更现代的 C++ 风格 |

---

###  4. `make_unique` 最终被纳入哪个标准？

- C++14 ✅
- 虽然 C++11 引入了 `unique_ptr`，但 `make_unique` 是在 C++14 中正式加入标准库的。
- `N3656` 在 2013年4月的 Bristol 会议上被采纳，成为 C++14 的一部分。

> ⚠️ 你看到的网页标题：
> ```
> New adopted paper: N3656, make_unique (Revision 1) -- Stephan T. Lavavej
> Note: This paper was adopted into draft C++14 on Saturday at the Bristol UK ISO C++ meeting.
> ```
> 说明：N3656 被正式采纳进入 C++14 草案。

---

###  5. 为什么 `isocpp.org` 会发布这个博客？

- `isocpp.org` 是 ISO C++ 委员会官方博客。
- 它会发布：
  - 新采纳的提案（如 N3656）
  - 会议纪要
  - C++ 标准进展
  - 教程和最佳实践
- 所以 `N3656` 被采纳后，他们发博客宣布：“这个功能要进标准了！”

---

###  6. `make_unique` 的限制（如评论中问的 `T[N]`）

提案中提到：
- `make_unique<T[N]>(...)` 是 不允许的（即已知大小的数组类型）
- 原因：语义模糊，且无法初始化数组元素（C++ 不支持对数组类型调用构造函数）

但支持：
- `make_unique<T[]>(n)`：创建长度为 `n` 的数组（运行时大小）

### 📌 现代 C++ 推荐用法：
```cpp
#include <memory>

// ✅ 好
auto p = std::make_unique<Foo>(1, 2, 3);
auto arr = std::make_unique<int[]>(100);

// ❌ 避免
std::unique_ptr<Foo> p(new Foo(1, 2, 3));
```
