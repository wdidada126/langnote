`PTHREAD_MUTEX_INITIALIZER` 是 POSIX 线程（pthread）库中用于静态初始化互斥锁（mutex） 的一个宏。它提供了一种简单、安全且高效的方式来初始化 `pthread_mutex_t` 类型的互斥锁变量，特别适用于在全局作用域或静态变量中声明的互斥锁。


###  1. 基本定义与用途

```cpp
#include <pthread.h>

pthread_mutex_t my_mutex = PTHREAD_MUTEX_INITIALIZER;
```

- 作用：将 `my_mutex` 初始化为一个默认属性的互斥锁（即“快速互斥锁”，normal/fast mutex）。
- 使用场景：适用于不需要自定义属性（如递归锁、错误检查锁等）的互斥锁。
- 初始化时机：在程序启动时、进入 `main()` 之前就完成初始化，属于静态初始化。


###  2. 与 `pthread_mutex_init()` 的对比

| 特性 | `PTHREAD_MUTEX_INITIALIZER` | `pthread_mutex_init()` |
|------|------------------------------|-------------------------|
| 初始化方式 | 静态初始化（编译时/加载时） | 动态初始化（运行时） |
| 适用变量 | 全局或静态变量 | 任意 `pthread_mutex_t` 变量（包括堆上分配） |
| 属性 | 固定为默认属性（`PTHREAD_MUTEX_DEFAULT`） | 可通过 `pthread_mutexattr_t` 自定义属性 |
| 错误检查 | 无（宏展开为常量） | 返回错误码（如 `ENOMEM`, `EAGAIN`） |
| 是否需要销毁 | 通常不需要调用 `pthread_mutex_destroy()` | 必须配对使用 `pthread_mutex_destroy()` |

>  注意：使用 `PTHREAD_MUTEX_INITIALIZER` 初始化的互斥锁，不应再调用 `pthread_mutex_destroy()`，否则行为未定义。


### 3. 默认属性（`PTHREAD_MUTEX_DEFAULT`）

`PTHREAD_MUTEX_INITIALIZER` 实际上创建的是一个 `PTHREAD_MUTEX_DEFAULT` 类型的互斥锁。其行为取决于实现，但在大多数系统（如 Linux）上：

- 表现为 快速互斥锁（`PTHREAD_MUTEX_NORMAL`）
  - 不检测死锁
  - 同一线程重复加锁会导致死锁
  - 不检查解锁者是否为加锁者

> 示例：  
> 线程 A 加锁 → 线程 A 再次加锁 → 死锁（程序挂起）


###  4. 其他互斥锁类型（需 `pthread_mutex_init` 配合属性）

| 类型 | 描述 |
|------|------|
| `PTHREAD_MUTEX_NORMAL` | 快速锁，不检查错误，重复加锁导致死锁 |
| `PTHREAD_MUTEX_ERRORCHECK` | 错误检查锁，重复加锁返回 `EDEADLK` |
| `PTHREAD_MUTEX_RECURSIVE` | 递归锁，同一线程可多次加锁，需等量解锁 |
| `PTHREAD_MUTEX_DEFAULT` | 默认类型，Linux 上通常为 `NORMAL` |

```cpp
// 想要递归锁？必须用 pthread_mutex_init
pthread_mutex_t recursive_mutex;
pthread_mutexattr_t attr;
pthread_mutexattr_init(&attr);
pthread_mutexattr_settype(&attr, PTHREAD_MUTEX_RECURSIVE);
pthread_mutex_init(&recursive_mutex, &attr);
```

###  5. 使用建议

 使用 `PTHREAD_MUTEX_INITIALIZER` 当：
- 互斥锁是全局或静态变量
- 使用默认属性即可
- 希望代码简洁、高效

❌ 使用 `pthread_mutex_init` 当：
- 互斥锁在堆上分配（`new` 或 `malloc`）
- 需要自定义属性（如递归锁）
- 需要在运行时动态创建互斥锁


###  6. 示例代码

```cpp
#include <pthread.h>
#include <iostream>

// 静态初始化互斥锁
pthread_mutex_t counter_mutex = PTHREAD_MUTEX_INITIALIZER;
int shared_counter = 0;

void* thread_func(void* arg) {
    for (int i = 0; i < 1000; ++i) {
        pthread_mutex_lock(&counter_mutex);
        ++shared_counter;
        pthread_mutex_unlock(&counter_mutex);
    }
    return nullptr;
}

int main() {
    pthread_t t1, t2;
    pthread_create(&t1, nullptr, thread_func, nullptr);
    pthread_create(&t2, nullptr, thread_func, nullptr);
    pthread_join(t1, nullptr);
    pthread_join(t2, nullptr);
    std::cout << "Final counter: " << shared_counter << std::endl;
    // 注意：不要对 PTHREAD_MUTEX_INITIALIZER 初始化的锁调用 destroy
    return 0;
}
```


###  7. 注意事项

1. 不要销毁：使用 `PTHREAD_MUTEX_INITIALIZER` 初始化的锁，不能调用 `pthread_mutex_destroy()`。
2. 线程安全：静态初始化是线程安全的，无需额外同步。
3. C++ 全局构造：在 C++ 中，如果互斥锁是类的静态成员或命名空间作用域变量，使用此宏是最佳实践。


###  总结

`PTHREAD_MUTEX_INITIALIZER` 是一个宏，用于静态初始化具有默认属性的互斥锁。它简洁、高效，适用于大多数基本的线程同步场景。对于更复杂的锁行为（如递归锁），应使用 `pthread_mutex_init()` 配合属性对象。
