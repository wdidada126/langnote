# 20250121

WiFi Calling 是一种允许用户通过WiFi网络进行语音通话和短信发送的技术，无需依赖传统蜂窝网络。以下是其作用：
### 1. 覆盖增强
- 信号差时：在蜂窝信号弱的地方（如地下室、偏远地区），WiFi Calling 能提供稳定的通话和短信服务。
### 2. 节省费用
- 国际漫游：在国外使用WiFi Calling，通常按国内资费计费，避免高额漫游费用。
### 3. 通话质量提升

### 4. 无缝切换
- 网络切换：支持在WiFi和蜂窝网络之间自动切换，保持通话不间断。

### 5. 无需额外应用
- 内置功能：直接使用手机自带拨号和短信应用，无需下载其他软件。

### 6. 紧急呼叫
- 紧急情况：即使没有蜂窝信号，WiFi Calling 也能拨打紧急电话。

### 使用条件
- 设备支持：需手机支持WiFi Calling功能。
- 运营商支持：需运营商开通此服务。
- WiFi网络：需连接稳定的WiFi网络。

### 总结
WiFi Calling 在信号弱或国际漫游时非常实用，能提升通话质量并节省费用，但需要设备和运营商的支持。
