`FindOpenSSL.cmake` 是 CMake 自带的一个模块文件，用于查找和配置 OpenSSL 库。其具体位置取决于操作系统以及 CMake 的安装方式。CMake 将这些模块文件存储在其模块路径下的 `Modules` 文件夹中。以下是根据不同的操作系统找到 `FindOpenSSL.cmake` 文件位置的方法：

### 查找 `FindOpenSSL.cmake` 路径

#### 方法一：使用 `cmake --find-package` 或者 `cmake-path` 命令

你可以通过以下命令来获取 `FindOpenSSL.cmake` 文件的路径：

```bash
cmake --help-module-path
```

这将输出 CMake 模块的搜索路径。通常 `FindOpenSSL.cmake` 会位于其中一个目录下的 `Modules` 文件夹中。

或者更直接地：

```bash
echo "$(cmake -E system_information | grep 'CMAKE_MODULE_PATH' -A1 | tail -n 1)"
```

不过请注意，上述命令可能需要较新版本的 CMake 支持。

#### 方法二：手动查找

在大多数情况下，`FindOpenSSL.cmake` 文件可以在如下路径中找到：

- Linux (Ubuntu 等):
  ```
  /usr/share/cmake-x.y/Modules/FindOpenSSL.cmake
  ```
  其中 `x.y` 是你的 CMake 版本号。例如，在 Ubuntu 上如果你安装了 CMake 3.28，那么路径可能是：
  ```
  /usr/share/cmake-3.28/Modules/FindOpenSSL.cmake
  ```

- macOS:
  如果你是通过 Homebrew 安装的 CMake，那么路径通常是：
  ```
  /usr/local/Cellar/cmake/x.y.z/share/cmake/Modules/FindOpenSSL.cmake
  ```
  其中 `x.y.z` 是具体的 CMake 版本号。例如：
  ```
  /usr/local/Cellar/cmake/3.28.0/share/cmake/Modules/FindOpenSSL.cmake
  ```

- Windows:
  如果你通过安装包安装了 CMake，那么默认路径可能是：
  ```
  C:\Program Files\CMake\share\cmake-x.y\Modules\FindOpenSSL.cmake
  ```
  或者对于某些特定安装情况：
  ```
  C:\Program Files (x86)\CMake\share\cmake-x.y\Modules\FindOpenSSL.cmake
  ```

### 快速定位

为了快速定位 `FindOpenSSL.cmake` 文件的位置，可以使用以下命令（适用于 Unix-like 系统如 Linux 和 macOS）：

```bash
find $(cmake --system-information | grep 'CMAKE_ROOT' -m 1 | cut -d'=' -f2) -name FindOpenSSL.cmake
```

这个命令首先获取 CMake 的根目录，然后在该目录下搜索 `FindOpenSSL.cmake` 文件。

在 Windows 上，你可以使用类似的思路，但可能需要借助 PowerShell 或者 CMD 命令进行搜索，比如：

```powershell
Get-ChildItem -Path (cmake -E system_information | Select-String 'CMAKE_ROOT' | ForEach-Object { $_.ToString().Split('=')[1].Trim() }) -Filter FindOpenSSL.cmake -Recurse
```

请确保替换相应的 CMake 版本号和路径格式以匹配你的系统环境。这样可以帮助你准确定位到 `FindOpenSSL.cmake` 文件所在的位置。
