CMake 自带了许多标准模块，这些模块可以帮助开发者更方便地查找库、处理编译选项、管理安装过程等。`FindPackageHandleStandardArgs.cmake` 是其中之一，用于标准化处理 `find_package()` 的查找逻辑。

### 常见的 CMake 标准模块

以下是一些常用的 CMake 标准模块：

1. `FindPackageHandleStandardArgs`
   - 用于帮助编写自定义的 `FindXXX.cmake` 模块时，提供一致的处理逻辑。
   
2. `FindBoost`
   - 用于查找 Boost 库及其组件。
   
3. `FindCUDA`
   - 支持 CUDA 编程模型，可以找到 NVIDIA CUDA 工具包。
   
4. `FindGit`
   - 查找 Git 版本控制系统。
   
5. `FindOpenMP`
   - 查找 OpenMP 并行编程支持。
   
6. `FindPython`
   - 查找 Python 解释器和开发环境（包括 Python3）。
   
7. `FindQt4`, `FindQt5`, `FindQt6`
   - 分别用于查找 Qt 4, Qt 5 和 Qt 6 开发环境。
   
8. `FindThreads`
   - 查找线程库支持，如 pthreads。
   
9. `UseSWIG`
   - 支持 SWIG（Simplified Wrapper and Interface Generator），用于生成语言绑定。
   
10. `FindZLIB`
    - 查找 ZLIB 压缩库。
    
11. `CheckFunctionExists`
    - 检查特定函数是否存在于链接库中。
    
12. `CheckIncludeFile`
    - 检查指定的头文件是否存在并可包含。
    
13. `CheckSymbolExists`
    - 检查给定符号（函数或变量）在编译环境中是否存在。
    
14. `InstallRequiredSystemLibraries`
    - 安装系统所需的共享库。

正确查看 CMake 模块路径的方法
你可以使用以下方式来查看 CMake 的模块搜索路径，尤其是包含 FindOpenSSL.cmake 的位置：

 方法一：使用 cmake -E system_information
cmake -E system_information | grep CMAKE_ROOT
输出示例：

CMAKE_ROOT:INTERNAL=/usr/share/cmake-3.28
然后在这个目录下查找模块路径：

find /usr/share/cmake-3.28 -name FindOpenSSL.cmake
或者在 macOS 上：

find /Applications/CMake.app/Contents/share/cmake-3.28 -name FindOpenSSL.cmake
 方法二：使用 CMake 脚本临时打印模块路径
创建一个临时 CMakeLists.txt 文件，内容如下：

Cmake
message(STATUS "CMAKE_ROOT: ${CMAKE_ROOT}")
message(STATUS "CMAKE_MODULE_PATH (默认为空): ${CMAKE_MODULE_PATH}")
message(STATUS "标准模块路径: ${CMAKE_ROOT}/Modules")
运行它：

cmake .
输出示例：


-- CMAKE_ROOT: /usr/share/cmake-3.28
-- CMAKE_MODULE_PATH (默认为空): 
-- 标准模块路径: /usr/share/cmake-3.28/Modules
然后去这个目录找文件：

Bash

ls /usr/share/cmake-3.28/Modules/FindOpenSSL.cmake
 各平台默认路径总结
平台	默认模块路径 示例
Ubuntu	/usr/share/cmake-<version>/Modules/FindOpenSSL.cmake
macOS (Homebrew)	/usr/local/Cellar/cmake/<version>/share/cmake/Modules/FindOpenSSL.cmake
macOS (官方安装包)	/Applications/CMake.app/Contents/share/cmake-<version>/Modules/FindOpenSSL.cmake
Windows	C:\Program Files\CMake\share\cmake-<version>\Modules\FindOpenSSL.cmake
 查看是否加载了自定义模块路径
如果你在项目中设置了：

Cmake

set(CMAKE_MODULE_PATH ${PROJECT_SOURCE_DIR}/cmake ${CMAKE_MODULE_PATH})
那么 CMake 会优先从你的项目目录下的 cmake/ 文件夹中查找模块文件（比如你自己写的 FindOpenSSL.cmake）。
