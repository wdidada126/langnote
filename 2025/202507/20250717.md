shared_ptr与weak_ptr结合使用解决循环引用问题 给出讲解和可执行的main函数源代码

在 C++ 中，`std::shared_ptr` 是一种智能指针，它通过引用计数来管理对象的生命周期。当最后一个 `shared_ptr` 被销毁时，所管理的对象也会被删除。

然而，在某些情况下（如树形结构或观察者模式中），两个或多个对象之间互相持有 `shared_ptr`，就会导致循环引用（circular reference），从而造成内存泄漏 —— 因为它们的引用计数永远不为零，对象无法释放。


##  解决方案：使用 `std::weak_ptr`

`std::weak_ptr` 是一种对 `shared_ptr` 所管理对象的“弱引用”，它不会增加引用计数。你可以通过调用 `.lock()` 来获得一个临时的 `shared_ptr`，如果原始对象已经被释放，则返回 `nullptr`。

这样就可以打破循环引用链。



##  示例场景

我们创建两个类：

- `Parent`
- `Child`

其中：
- `Parent` 持有 `Child` 的 `shared_ptr`
- `Child` 持有 `Parent` 的 `weak_ptr`

这样就避免了循环引用。


## 可执行源代码

```cpp
#include <iostream>
#include <memory>

class Parent;

class Child {
public:
    std::weak_ptr<Parent> parent;  // 使用 weak_ptr 避免循环引用

    ~Child() {
        std::cout << "Child destroyed" << std::endl;
    }
};

class Parent {
public:
    std::shared_ptr<Child> child;  // 正常使用 shared_ptr

    ~Parent() {
        std::cout << "Parent destroyed" << std::endl;
    }
};

int main() {
    {
        std::shared_ptr<Parent> parent = std::make_shared<Parent>();
        std::shared_ptr<Child> child = std::make_shared<Child>();

        parent->child = child;           // Parent 拥有 Child
        child->parent = parent;          // Child 弱引用 Parent

        // 在作用域内，parent 和 child 都存在
    } // 离开作用域后，parent 和 child 的引用计数都归零

    std::cout << "End of program." << std::endl;
    return 0;
}
```

## 输出结果（示例）

```
Parent destroyed
Child destroyed
End of program.
```

说明：
- `Parent` 和 `Child` 都成功析构。
- 没有发生内存泄漏。

##  总结

| 类型 | 特点 | 使用建议 |
|------|------|----------|
| `std::shared_ptr` | 带引用计数，共享所有权 | 当你需要共享资源所有权时使用 |
| `std::weak_ptr` | 不影响引用计数，仅观察对象 | 用于打破循环引用、缓存、监听器等 |


非常好！我们来扩展一个更复杂的例子：在 观察者模式（Observer Pattern） 中使用 `shared_ptr` 和 `weak_ptr`，以解决循环引用问题。

## 场景描述：观察者模式中的循环引用

在观察者模式中，通常有两类对象：

- Subject（被观察者）：维护一组 `Observer`。
- Observer（观察者）：持有对 `Subject` 的引用以便订阅更新。

如果 `Observer` 用 `shared_ptr` 持有 `Subject`，而 `Subject` 也用 `shared_ptr` 持有 `Observer`，就会形成循环引用。



## 使用 `weak_ptr` 打破循环引用

我们通过一个简单的例子实现：

- `Stock`：被观察的股票
- `Investor`：观察者，当股票价格变化时收到通知
- `Investor` 持有对 `Stock` 的 `weak_ptr` 避免循环引用


## 可执行完整代码

```cpp
#include <iostream>
#include <memory>
#include <vector>
#include <string>

// 前向声明
class Investor;

// Subject
class Stock {
public:
    std::string symbol;
    double price;

    std::vector<std::shared_ptr<Investor>> observers;

    Stock(const std::string& symbol, double price)
        : symbol(symbol), price(price) {}

    void attach(const std::shared_ptr<Investor>& investor) {
        observers.push_back(investor);
    }

    void set_price(double new_price) {
        price = new_price;
        notify();
    }

    void notify();

    ~Stock() {
        std::cout << "Stock " << symbol << " destroyed" << std::endl;
    }
};

// Observer
class Investor {
public:
    std::string name;
    std::weak_ptr<Stock> stock;  // 使用 weak_ptr 避免循环引用

    Investor(const std::string& name) : name(name) {}

    void update() {
        if (auto s = stock.lock()) {
            std::cout << name << ": Stock " << s->symbol
                      << " price changed to " << s->price << std::endl;
        } else {
            std::cout << name << ": Stock has been destroyed." << std::endl;
        }
    }

    ~Investor() {
        std::cout << "Investor " << name << " destroyed" << std::endl;
    }
};

// 实现 notify 函数（在 Investor 定义后）
void Stock::notify() {
    for (const auto& observer : observers) {
        observer->update();
    }
}

int main() {
    {
        auto stock = std::make_shared<Stock>("AAPL", 150.0);
        auto investor1 = std::make_shared<Investor>("Alice");
        auto investor2 = std::make_shared<Investor>("Bob");

        investor1->stock = stock;
        investor2->stock = stock;

        stock->attach(investor1);
        stock->attach(investor2);

        stock->set_price(155.0);  // 触发通知
    } // 离开作用域，stock 和 investor1/2 都应被释放

    std::cout << "End of program." << std::endl;
    return 0;
}
```

## 输出示例

```
Alice: Stock AAPL price changed to 155
Bob: Stock AAPL price changed to 155
Stock AAPL destroyed
Investor Alice destroyed
Investor Bob destroyed
End of program.
```

说明：
- `Investor` 持有 `Stock` 的 `weak_ptr`
- `Stock` 持有 `Investor` 的 `shared_ptr`
- 两者没有形成循环引用，生命周期正常释放

## 循环引用问题演示（不使用 `weak_ptr`）

如果你把 `Investor` 中的 `std::weak_ptr<Stock>` 改成 `std::shared_ptr<Stock>`：

```cpp
std::shared_ptr<Stock> stock;
```

输出会变成：

```
Alice: Stock AAPL price changed to 155
Bob: Stock AAPL price changed to 155
End of program.
```

你会发现析构函数没有执行，内存泄漏了！

## 封装为模板类（可选进阶）

如果你希望将观察者模式封装为通用模板类，可以这样做：

```cpp
template<typename Observer>
class Subject {
public:
    using ObserverPtr = std::shared_ptr<Observer>;

    void attach(const ObserverPtr& observer) {
        observers.push_back(observer);
    }

    void notify() {
        for (const auto& observer : observers) {
            observer->update(static_cast<Subject*>(this));
        }
    }

private:
    std::vector<ObserverPtr> observers;
};

class Investor;

class Stock : public Subject<Investor> {
public:
    std::string symbol;
    double price;

    Stock(const std::string& symbol, double price)
        : symbol(symbol), price(price) {}

    void set_price(double new_price) {
        price = new_price;
        notify();
    }
};

class Investor {
public:
    std::string name;
    std::weak_ptr<Stock> stock;

    Investor(const std::string& name) : name(name) {}

    void update(Stock* stock) {
        if (auto s = stock->shared_from_this()) {
            std::cout << name << ": Stock " << s->symbol
                      << " price changed to " << s->price << std::endl;
        }
    }
};
```

这个模板类可以适用于任何 `Subject-Observer` 对应关系，提高复用性。

## 总结

| 问题 | 解法 |
|------|------|
| `shared_ptr` 循环引用 | 使用 `weak_ptr` 打破循环 |
| 观察者模式中对象互相引用 | `Observer` 使用 `weak_ptr` 持有 `Subject` |
| 提高复用性 | 使用模板封装 `Subject` 类 |

## Java语言就业岗位

### 1. 服务端开发
关于服务端开发，Java是我们选择最多的语言。客观而言，Java语言在当前的互联网时代占据了主导地位。当我们谈论到程序员时，默认他们就是使用Java进行网页开发的。目前丰富的网络设备和互联网应用，几乎都是由Java构建的。因此，Java在市场上有巨大的需求。
首先，让我们看看Java能做什么。Java主要用于Web开发，即创建网站，如电商、银行和证券网站，这些只是其中的一部分。在中国，我们接触到的几乎所有应用、服务，如外卖、直播、购物和聊天，超过80%的业务都是用Java编写的。除了一些性能要求极高的服务，如搜索引擎和即时通讯等可能不是用Java编写的，几乎所有你能接触到的产品都是用Java编写的。
电商领域的例子包括京东，它最初使用C#，但后来转向Java，因为淘宝证明了Java的强大能力。淘宝在第一次双11活动后取得了巨大成功，京东认为自己的C#技术可能不够好，于是转向了Java。拼多多的创始人来自淘宝，因此他继承了之前的技术优势，并选择使用Java。现在的公司不再只使用一种语言，他们可能会根据业务需求选择不同的语言。例如，订单处理、支付和购物车可能使用Java，而对于性能要求更高的功能，如视频播放和搜索排序，可能会选择其他高性能的语言，如C++。业务占据内存较多，则可能使用Go。因此，目前大多数电商网站绝大部分都是用Java编写的。只有少数需要高性能的部分会使用其他语言。
如果未来你的同学想要从事服务端开发，Java无疑是一个值得首先考虑的语言。Java之所以成为服务端开发的主导语言，原因在于它的设计优良。Java在C++的基础上改进，去除了许多被认为是“反人类”的特性，例如复杂的指针操作和内存管理问题。Java通过垃圾回收机制解决了内存泄露和重复释放的问题，尽管这样做在某些极端情况下可能会牺牲一些性能。
然而，对于当前的服务器行业来说，这种极端情况并不常见。因此，Java仍然是一个非常适合服务端开发的语言，它的普及和强大功能使其成为许多开发者的首选。Java的跨平台特性和丰富的生态系统也为其在服务端开发中的主导地位提供了支持。总的来说，Java提供了一个平衡了易用性、功能性和性能的开发环境，这使得它在服务端开发领域中非常受欢迎。

## C++语言就业岗位

C++以其性能优越而著称，尤其在需要高性能计算的领域中。虽然C++的学习曲线相对陡峭，但它在多个细分领域中都有广泛的应用。C++的就业方向非常广泛，从早期的网站开发到现在的人工智能和智能驾驶等新兴技术领域，C++都有一席之地。

在新兴行业初期，C++常常是首选语言，因为它提供了较高的性能和灵活性。随着行业的成熟和技术的发展，可能会转向使用Java或其他更易于维护的语言。C++的特点在于它几乎可以用于任何方向的开发，就业方向杂，但这也意味着它在某些领域可能不是最佳选择。

### 8. 分布式系统

分布式系统，即云计算、分布式存储和分布式数据库，曾在前年非常热门。然而，现在这个方向已经不再像之前那么火爆了。

这些技术确实非常先进，但可能并没有太多直接盈利的机会。因此，虽然这些领域仍然受到关注，但不再像之前那样热门。

主要是过去几年中，在线教育行业蓬勃发展，尤其是网课。这导致了两个相关领域的火爆。第一个是音视频技术，因为网课需要音视频对话，所以音视频技术变得非常重要。另一个是数据流量管理，因为大量的网课内容产生了海量的数据流量。这就需要强大的云计算平台来支持这些数据处理需求。

总之，尽管分布式系统、云计算、分布式存储和分布式数据库仍然具有重要性，但目前的需求量可能没有之前那么火热。如果你的实验室专注于这些领域，那么你可能会有更多机会深入研究和应用这些技术。

### 9. 推广搜

各位同学，如果你对自己有自信，精通C++和Python，那么我鼓励你勇敢地追求推广搜这个领域，多参与相关实习，冲刺大厂例如阿里巴巴。推广系统和广告系统是目前最赚钱的方向之一，而且从长远来看，这个领域的前景一直都很好。

推荐系统和广告系统需要高度的专业知识。首先，你需要深入了解算法，掌握每个模型的基本特点，并能合理地调整参数和设计策略。其次，你需要丰富的工程经验，因为这些算法需要部署到实际的机器上。你要确保你的广告算法能够提高付费率，这就需要你将算法部署到设备上并运行。你需要熟练掌握Python来跑模型和C++来部署模型，两者缺一不可。

虽然门槛较高，但推广系统和广告系统是许多互联网公司核心部门的重要领域，比如字节跳动、小红书和拼多多。这个方向的工资水平肯定是非常高的。
