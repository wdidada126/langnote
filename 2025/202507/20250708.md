你原来的 SQL 是：

```sql
DROP TABLE IF EXISTS `app_market_dev`.`ETP_BILL_DATA_TD`;
```

这条语句会 彻底删除表结构和数据，不可恢复。

## 现在你想改成：清空表数据，但保留表结构

### 正确写法是使用：

### 方法一：`TRUNCATE`（推荐）

```sql
TRUNCATE TABLE `app_market_dev`.`ETP_BILL_DATA_TD`;
```

- 快速清空整个表的数据
- 不可回滚（自动提交）
- 重置自增列（如果有的话）
- 比 `DELETE` 更快更高效

### 方法二：`DELETE FROM`（适合需要条件删除）

```sql
DELETE FROM `app_market_dev`.`ETP_BILL_DATA_TD`;
```

- 可配合 `WHERE` 使用，如只删某部分数据
- 支持事务、可以回滚
- 性能较低（因为记录日志）

##  总结对比

| 操作 | 是否删除结构 | 是否清空数据 | 是否可回滚 | 自增列重置 | 性能 |
|------|----------------|--------------|-------------|---------------|-------|
| `TRUNCATE` | ❌ 否 | ✅ 是 | ❌ 否 | ✅ 是 | ⚡ 快 |
| `DELETE`   | ❌ 否 | ✅ 是 | ✅ 是 | ❌ 否（需手动处理） | ⏱️ 较慢 |

### 推荐用法（适用于你的需求）：

```sql
TRUNCATE TABLE `app_market_dev`.`ETP_BILL_DATA_TD`;
```

安全地清空数据，不改变表结构。
