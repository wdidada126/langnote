你提到的 CMake 输出日志中出现了以下内容：

```
-- Detecting CXX compiler ABI info
-- Detecting CXX compiler ABI info - done
-- Check for working CXX compiler: /usr/bin/c++ - skipped
-- Detecting CXX compile features
-- Detecting CXX compile features - done
```

这是 CMake 在配置项目时，对你的 C++ 编译器进行的一些基本探测和检查。下面我们来详细解释：

---

##  一、`CXX compiler ABI info` 是什么？

###  含义：
- `CXX` 表示 **C++ 编译器（C++ compiler）**
- `ABI` 是 **Application Binary Interface** 的缩写，中文是 **应用程序二进制接口**

###  它检测的是：
CMake 会尝试编译并运行一个小程序，以确定你的 C++ 编译器使用的 **ABI 版本** 和 **是否支持某些特性（如异常、RTTI）**。

#### ABI 包括的内容有：
- 函数调用约定（Calling conventions）
- 类型信息（Type information layout）
- 异常处理机制（Exception handling）
- RTTI（Run-Time Type Information）布局
- 名称改编规则（Name mangling）

###  为什么重要？
- 如果两个库/程序使用了不同 ABI 的编译器构建（例如 g++9 vs g++11），可能会导致链接失败或运行时崩溃。
- 某些 Linux 发行版（如 Ubuntu）在 g++7 到 g++9 之间切换默认 ABI 版本，会导致兼容性问题。


##  二、`CXX compile features` 是什么？

###  含义：
这是 CMake 探测你的 C++ 编译器支持哪些语言特性的过程。

###  它检测的是：
CMake 会尝试编译一些测试代码片段，以确认编译器是否支持特定的 C++ 标准特性，比如：

- C++11、C++14、C++17、C++20 等标准
- 特定语言特性，如：
  - `cxx_constexpr`
  - `cxx_lambda_init_captures`
  - `cxx_generic_lambdas`
  - `cxx_thread_local`
  - `cxx_variable_templates`
  - `cxx_aggregate_default_initializers`
  - 等等

###  为什么重要？
- 这些信息用于生成正确的编译标志（如 `-std=c++17`）
- 可以让 CMake 自动选择适合当前编译器的代码路径
- 避免在不支持某些特性的编译器上编译失败

---

## 📌 示例：这些信息是如何探测出来的？

你可以通过查看 CMake 生成的文件 `CMakeFiles/CMakeOutput.log` 或 `CMakeError.log` 查看具体的探测过程。

例如：

```bash
cat CMakeFiles/CMakeOutput.log
```

你会看到类似这样的内容：

```
Compiling the CXX compiler identification source file "CMakeCXXCompilerId.cpp" succeeded.
Compiler:
/usr/bin/c++
Build flags:
Id flags:

The output was:
...
```

这说明 CMake 正在尝试编译一个小的测试程序，来判断编译器的能力。

---

## 🛠️ 三、如何影响 CMake 构建行为？

这些探测结果会被保存在缓存变量中，供后续的构建使用：

| 变量名 | 含义 |
|--------|------|
| `CMAKE_CXX_COMPILER_ID` | 编译器类型（GNU、Clang、MSVC 等） |
| `CMAKE_CXX_COMPILER_VERSION` | 编译器版本号 |
| `CMAKE_CXX_ABI_COMPILED` | 是否成功探测到 ABI |
| `CMAKE_CXX_COMPILE_FEATURES` | 支持的 C++ 特性列表 |

你可以在 `CMakeLists.txt` 中使用这些信息做条件判断，例如：

```cmake
if (CMAKE_CXX_COMPILER_ID STREQUAL "GNU")
    if (CMAKE_CXX_COMPILER_VERSION VERSION_GREATER_EQUAL "11.0")
        add_compile_options(-std=c++20)
    else()
        add_compile_options(-std=c++17)
    endif()
endif()
```
