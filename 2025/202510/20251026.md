错误原因  
```
no template named 'function'
```

这个错误出现在 macOS + Clang 环境下（从 `1 error generated.` 可判断是 Clang），因为你在使用 `std::function` 时 忘记包含 `<functional>` 头文件，并且 没有使用 `std::` 命名空间前缀。

此外，`function` 是 C++11 引入的模板，CMake 默认可能没有启用 C++11（尤其是旧的默认生成器）。

### 修复方案（两步）

#### 1. 在 `thompson.cpp` 中加入头文件和命名空间

```cpp
// thompson.cpp
#include <functional>   // 必须添加
#include <memory>
#include <vector>
// ... 其他头文件

using std::function;  // 或者使用 std::function
// 或者：using namespace std; （不推荐在头文件中）

// 正确写法：
function<void(shared_ptr<State>)> dfs = [&](shared_ptr<State> s) {
    // ...
};
```

或者更安全的写法（推荐）：

```cpp
std::function<void(std::shared_ptr<State>)> dfs = [&](std::shared_ptr<State> s) {
    // ...
};
```

#### 2. 在 `CMakeLists.txt` 中强制启用 C++11（或更高）

```cmake
# CMakeLists.txt
cmake_minimum_required(VERSION 3.14)
project(thompson LANGUAGES CXX)

# 强制启用…
set(CMAKE_CXX_STANDARD 11)        # 或者 14, 17
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)     # 禁用编译器扩展（如 -std=gnu++11）

add_executable(thompson
    src/thompson.cpp
    # 其他源文件
)

target_link_libraries(thompson PRIVATE re2::re2)
```

> 关键：`set(CMAKE_CXX_STANDARD 11)` 必须在 `add_executable` 之前！

### 完整修复示例

#### `src/thompson.cpp`（关键部分）

```cpp
#include <functional>
#include <memory>
#include <vector>
#include <iostream>

using std::function;
using std::shared_ptr;

void buildNFA() {
    function<void(shared_ptr<State>)> dfs = [&](shared_ptr<State> s) {
        // 你的 DFS 逻辑
        std::cout << "Visiting state\n";
    };

    // ...
}
```

#### `CMakeLists.txt`

```cmake
cmake_minimum_required(VERSION 3.14)
project(thompson LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

find_package(re2 REQUIRED)

add_executable(thompson src/thompson.cpp)
target_link_libraries(thompson PRIVATE re2::re2)
```

### GitHub Actions 验证（可选增强）

确保你的 `.github/workflows/cmake.yml` 中 所有平台都使用 C++11：

```yaml
- name: Configure CMake
  run: >
    cmake -B ${{ steps.strings.outputs.build-output-dir }}
    -DCMAKE_CXX_STANDARD=11
    -DCMAKE_BUILD_TYPE=${{ matrix.build_type }}
    -S ${{ github.workspace }}
```

### 总结：你只需要做这两件事

| 步骤 | 操作 |
|------|------|
| 1 | 在 `.cpp` 文件顶部添加 `#include <functional>` |
| 2 | 在 `CMakeLists.txt` 中设置 `set(CMAKE_CXX_STANDARD 11)` |

修复后，所有平台（包括 macOS + Clang）都会通过编译。
