# 20251020
error: use of undeclared identifier 'time_of_day'
    auto tod = time_of_day{now - today};
             ^
根本原因

time_of_day 不是 C++20 标准的一部分，它是一个GCC libstdc++内部的实现细节，不可移植。

    在某些 GCC 版本中（如 13.1），std::chrono 的内部实现中存在 time_of_day 这个别名，用于构造 hh_mm_ss。
    但在 Clang（使用 libc++）或较新/较旧的 GCC 中，它不存在。
    因此，当您在 GitHub Actions 上使用 Clang 时，time_of_day 未定义，编译失败。
