实际 YAML 配置示例
1. 基础配置（推荐：Temurin）
yamlname: Java CI with JDK 25
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4
    
    - name: Set up JDK 25
      uses: actions/setup-java@v4
      with:
        java-version: '25'           # 直接指定 25
        distribution: 'temurin'      # 或 oracle, zulu, corretto
        
    - name: Validate JDK version
      run: java -version            # 输出: openjdk version "25"
    
    - name: Build with Maven
      run: mvn -B package --file pom.xml
2. 多版本矩阵测试
yamlstrategy:
  matrix:
    java-version: [21, 25]        # JDK 21 + JDK 25
    distribution: [temurin, zulu]

steps:
- uses: actions/setup-java@v4
  with:
    java-version: ${{ matrix.java-version }}
    distribution: ${{ matrix.distribution }}
3. GraalVM 25（Native Image 支持）
yaml- name: Set up GraalVM JDK 25
  uses: actions/setup-java@v4
  with:
    java-version: 25
    distribution: 'graalvm'
    components: 'native-image'    # 支持 AOT 编译

常见问题与解决方案
Q1: 为什么之前配置 java-version: 25 报错？
A: 使用了旧版 actions/setup-java@v3 或 v4.3.x。必须升级到 v4.4.0+。
yaml# ❌ 错误（旧版本）
- uses: actions/setup-java@v4   # v4.3.x 不支持 JDK 25
  with:
    java-version: 25

#  正确
- uses: actions/setup-java@v4   # v4.4.0+
  with:
    java-version: 25
Q2: 支持哪些新特性？
yaml# JDK 25 新特性自动可用
- java-version: 25              # Preview: Primitive types in patterns
- java-version: 25              # Preview: Vector API (第 8 孵化)
- java-version: 25              # Stable: Module import declarations
Q3: Native Image 支持？
yaml- uses: actions/setup-java@v4
  with:
    java-version: 25
    distribution: 'graalvm'
    components: 'native-image'
- run: native-image --no-fallback -o myapp .
