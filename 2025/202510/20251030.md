为什么所有的教科书中都不赞成手写自底向上的语法分析器？

因为 bottom-up parser 的可读性极差，根本无法手写。实际上 bottom-up parser 是一个不该在实际工程中应用的纯学术的东西。最初被提出的时候，人们认为它的优点主要是 recognition strength 比较强。LR(1) parser 的 recognition strength 就可以超过 k 为任意值的 LL(k) parser[1]。而且 LL(k) parser generator 的运算复杂度是 O(|T| ^ k)，所以当时人们认为其自动化生成算法不可能被工程应用。一度公认 LL(k) 只能手写实现，而且 k 只能实际为一。不过后来 Terence Parr，ANTLR 的作者，开发了 LL&#39;(k) parser，把复杂度降低到 O(|T| x k)。LL'(k) 的 strength 小于 LL(k) 但大于 LL(k-1)。这就抵消了 LR 算法的两个重要优势：自动生成和 recognition strength。如此一来，LL 一族虽然不能从理论上完全取代 LR，但是考虑到其代码可读性，已经完全消除了 LR 的工程必要性。接下来还有几个实际问题也抵消了 bottom-up parser 的必要性：目前流行的 LR parser generator 是 LALR，其 parsing strength 弱于 LR(1)。所以还不能和任意 LL(k) 相比。把 LL(k) 语法改写为 LR(1) 是非常反直观的做法。Bottom-up parser 的优势建立在严格的数学基础上，要求语言必须是 context-free 语法。实际中严格的 context-free 语法很少。可读性极好的 LL parser 可以任意加入 ad-hoc trick 来分析 context-sensitive 语法，乃至于使用回溯来分析 undetermined 语法。而 bottom-up parser 就无能为力了。实际中设计语言可以尽量向 LL(1) 靠拢。注意这一条并不和上一条矛盾。一个语言可以是 99% 的  LL(1) 语法加上几个 undetermined 语法的特例。这时用 bottom-up parser 是最尴尬的，parsing strength 在 99% 的情况下白白浪费（之所以说是浪费是因为这种 strength 是以 readability 为代价的），在 1% 的特例中还非常难于处理。@vczh 的看法可能来自一些误解。我的观点不是 LL 多么牛逼。而是：LL'(k) 的发明说明 LL 没有人们原本想像的那么弱。LL 经常用 recursive-descend 实现。而这种实现是最容易加入 ad-hoc trick 的方式。@vczh 举的例子基本上都是 LL 在纯理论方面比 LR 弱的例子。这恰恰是我已经说明过的问题。比如 @vczh 说道：「再说了，语言设计成 LL(1) 的话，整个语法憋手蹩脚，你会发现根本没有一个流行的语言是这么做的」。我不能同意。写一个纯粹的 LL(1) 语法当然很反直观，但是 99% 的 LL(1) 语法加上个别特例是非常常见的。Lua 语言就是几乎 LL(1) 语法。参考^Knuth, D. from pulp import *

# 示例1：简单的生产计划问题
def production_planning_example():
    """
    生产计划问题：
    公司生产两种产品A和B，每个产品需要不同的资源
    目标：最大化利润
    """
    # 创建问题实例（最大化问题）
    prob = LpProblem("Production_Planning", LpMaximize)
    
    # 定义决策变量（产品A和B的生产数量）
    x1 = LpVariable("Product_A", 0, None, LpInteger)  # 产品A，非负整数
    x2 = LpVariable("Product_B", 0, None, LpInteger)  # 产品B，非负整数
    
    # 目标函数：最大化利润
    # 产品A利润30元/个，产品B利润20元/个
    prob += 30*x1 + 20*x2, "Total_Profit"
    
    # 约束条件
    prob += 2*x1 + 1*x2 <= 100, "Labor_Hours"      # 劳动力约束：100小时
    prob += 1*x1 + 3*x2 <= 120, "Material_Units"   # 材料约束：120单位
    prob += x1 + x2 <= 80, "Machine_Hours"         # 机器时间约束：80小时
    
    # 求解问题
    prob.solve()
    
    # 输出结果
    print("=" * 50)
    print("生产计划优化结果")
    print("=" * 50)
    print(f"求解状态: {LpStatus[prob.status]}")
    print(f"最大利润: {value(prob.objective)} 元")
    print(f"产品A生产数量: {x1.varValue} 个")
    print(f"产品B生产数量: {x2.varValue} 个")
    
    # 打印约束条件的使用情况
    print("\n资源使用情况:")
    for name, constraint in prob.constraints.items():
        print(f"{name}: 使用 {constraint.value()} / 限制 {constraint.constant}")

# 运行示例
production_planning_example()

def transportation_problem():
    """
    运输问题：
    从多个仓库运输货物到多个商店，最小化运输成本
    """
    # 仓库供应量（吨）
    warehouses = ['W1', 'W2', 'W3']
    supply = {'W1': 300, 'W2': 400, 'W3': 500}
    
    # 商店需求量（吨）
    stores = ['S1', 'S2', 'S3', 'S4']
    demand = {'S1': 200, 'S2': 300, 'S3': 250, 'S4': 350}
    
    # 运输成本（元/吨）
    costs = {
        'W1': {'S1': 2, 'S2': 3, 'S3': 4, 'S4': 5},
        'W2': {'S1': 3, 'S2': 2, 'S3': 5, 'S4': 4},
        'W3': {'S1': 4, 'S2': 5, 'S3': 2, 'S3': 3, 'S4': 2}
    }
    
    # 创建问题
    prob = LpProblem("Transportation_Problem", LpMinimize)
    
    # 创建决策变量（从仓库i到商店j的运输量）
    routes = [(w, s) for w in warehouses for s in stores]
    vars = LpVariable.dicts("Route", (warehouses, stores), 0, None, LpInteger)
    
    # 目标函数：最小化总运输成本
    prob += lpSum([vars[w][s] * costs[w][s] for (w, s) in routes]), "Total_Transportation_Cost"
    
    # 约束条件1：每个仓库的供应量限制
    for w in warehouses:
        prob += lpSum([vars[w][s] for s in stores]) <= supply[w], f"Supply_{w}"
    
    # 约束条件2：每个商店的需求量必须满足
    for s in stores:
        prob += lpSum([vars[w][s] for w in warehouses]) >= demand[s], f"Demand_{s}"
    
    # 求解
    prob.solve()
    
    # 输出结果
    print("\n" + "=" * 50)
    print("运输问题优化结果")
    print("=" * 50)
    print(f"求解状态: {LpStatus[prob.status]}")
    print(f"最小运输成本: {value(prob.objective)} 元")
    
    print("\n最优运输方案:")
    for w in warehouses:
        for s in stores:
            if vars[w][s].varValue > 0:
                print(f"从仓库 {w} 到商店 {s}: {vars[w][s].varValue} 吨")

# 运行运输问题
transportation_problem()

def portfolio_optimization():
    """
    投资组合优化：
    在给定风险水平下最大化收益，或在给定收益水平下最小化风险
    """
    # 投资产品数据
    stocks = ['Stock_A', 'Stock_B', 'Stock_C', 'Stock_D']
    
    # 预期收益率
    expected_returns = {'Stock_A': 0.12, 'Stock_B': 0.08, 'Stock_C': 0.15, 'Stock_D': 0.10}
    
    # 风险（标准差）
    risks = {'Stock_A': 0.20, 'Stock_B': 0.10, 'Stock_C': 0.25, 'Stock_D': 0.15}
    
    # 创建问题：最大化收益，风险不超过20%
    prob = LpProblem("Portfolio_Optimization", LpMaximize)
    
    # 决策变量：每个股票的投资比例
    allocations = LpVariable.dicts("Allocation", stocks, 0, 1)
    
    # 目标函数：最大化预期收益
    prob += lpSum([allocations[s] * expected_returns[s] for s in stocks]), "Total_Return"
    
    # 约束条件
    prob += lpSum([allocations[s] for s in stocks]) == 1, "Total_Allocation"  # 总投资比例=100%
    prob += lpSum([allocations[s] * risks[s] for s in stocks]) <= 0.20, "Risk_Constraint"  # 风险约束
    
    # 可选：单个股票投资比例不超过40%
    for s in stocks:
        prob += allocations[s] <= 0.4, f"Max_Allocation_{s}"
    
    # 求解
    prob.solve()
    
    # 输出结果
    print("\n" + "=" * 50)
    print("投资组合优化结果")
    print("=" * 50)
    print(f"求解状态: {LpStatus[prob.status]}")
    print(f"预期收益率: {value(prob.objective)*100:.2f}%")
    print(f"组合风险: {sum(allocations[s].varValue * risks[s] for s in stocks)*100:.2f}%")
    
    print("\n最优投资组合:")
    total_allocation = 0
    for s in stocks:
        allocation_pct = allocations[s].varValue * 100
        if allocation_pct > 0.01:  # 只显示投资比例大于0.01%的股票
            print(f"{s}: {allocation_pct:.2f}%")
            total_allocation += allocation_pct
    
    print(f"总投资比例: {total_allocation:.2f}%")

# 运行投资组合优化
portfolio_optimization()

    }
    
    # 客户需求
    demands = {'C1': 100, 'C2': 150, 'C3': 200, 'C4': 120, 'C5': 180}
    
    # 设施容量
    capacities = {'F1': 400, 'F2': 350, 'F3': 500, 'F4': 300}
    
    # 创建问题
    prob = LpProblem("Facility_Location", LpMinimize)
    
    # 决策变量
    # 是否建立设施（0-1变量）
    build = LpVariable.dicts("Build", facilities, 0, 1, LpBinary)
    
    # 从设施到客户的运输量
    ship = LpVariable.dicts("Ship", (facilities, customers), 0, None, LpInteger)
    
    # 目标函数：最小化总成本（固定成本 + 运输成本）
    prob += lpSum([build[f] * fixed_costs[f] for f in facilities]) + \
            lpSum([ship[f][c] * transport_costs[f][c] for f in facilities for c in customers]), "Total_Cost"
    
    # 约束条件
    # 每个客户的需求必须满足
    for c in customers:
        prob += lpSum([ship[f][c] for f in facilities]) == demands[c], f"Demand_{c}"
    
    # 设施容量约束
    for f in facilities:
        prob += lpSum([ship[f][c] for c in customers]) <= build[f] * capacities[f], f"Capacity_{f}"
    
    # 每个客户只能由一个设施服务（可选约束）
    for c in customers:
        prob += lpSum([(ship[f][c] > 0) for f in facilities]) <= 1, f"Single_Source_{c}"
    
    # 求解
    prob.solve()
    
    # 输出结果
    print("\n" + "=" * 50)
    print("设施选址问题优化结果")

import numpy as np
import pandas as pd
from scipy.optimize import minimize
import pulp
from typing import Dict, Tuple

class PortfolioOptimizer:
    def __init__(self):
        self.risk_free_rate = 0.02  # 无风险利率
        
    def optimize_portfolio(self, returns: pd.DataFrame, 
                          objective: str, max_risk: float, min_return: float) -> Tuple[np.ndarray, Dict]:
        """投资组合优化主函数"""
        # 计算预期收益和协方差矩阵
        expected_returns = returns.mean()
        cov_matrix = returns.cov()
        
        n_assets = len(expected_returns)
        
        if objective == "最大夏普比率":
            weights = self.maximize_sharpe(expected_returns, cov_matrix, max_risk, min_return)
        elif objective == "最小方差":
            weights = self.minimize_variance(cov_matrix, max_risk, min_return)
        elif objective == "最大收益":
            weights = self.maximize_return(expected_returns, cov_matrix, max_risk)
        else:  # 风险平价
            weights = self.risk_parity(cov_matrix, max_risk)
        
        # 计算绩效指标
        results = self.calculate_performance(weights, expected_returns, cov_matrix, returns)
        
        return weights, results
    
    def maximize_sharpe(self, expected_returns, cov_matrix, max_risk, min_return):
        """最大化夏普比率"""
        n = len(expected_returns)
        
        # 使用PuLP求解
        prob = pulp.LpProblem("Maximize_Sharpe_Ratio", pulp.LpMaximize)
        
        # 变量
        weights = [pulp.LpVariable(f'w_{i}', 0, 1) for i in range(n)]
        
        # 目标函数：最大化夏普比率
        expected_return = pulp.lpSum([weights[i] * expected_returns[i] for i in range(n)])
        variance = pulp.lpSum([weights[i] * weights[j] * cov_matrix.iloc[i,j] 
                             for i in range(n) for j in range(n)])
        
        # 约束条件
        prob += pulp.lpSum(weights) == 1, "预算约束"
        prob += variance <= max_risk 2, "风险约束"
        prob += expected_return >= min_return, "收益约束"
        
        # 求解
        prob.solve()
        
        return np.array([w.varValue for w in weights])
    
    def risk_parity(self, cov_matrix, max_risk):
        """风险平价模型"""
        n = len(cov_matrix)
        
        # 使用scipy优化
        def objective(weights):
            portfolio_risk = np.sqrt(weights @ cov_matrix @ weights)
            risk_contributions = weights * (cov_matrix @ weights) / portfolio_risk
            # 最小化风险贡献的差异
            return np.sum((risk_contributions - portfolio_risk/n) 2)
        
        constraints = [
            {'type': 'eq', 'fun': lambda x: np.sum(x) - 1},  # 权重和为1
            {'type': 'ineq', 'fun': lambda x: max_risk - np.sqrt(x @ cov_matrix @ x)}  # 风险上限
        ]
        
        bounds = [(0, 1) for _ in range(n)]
        x0 = np.ones(n) / n  # 等权重初始值
        
        result = minimize(objective, x0, method='SLSQP', 
                         bounds=bounds, constraints=constraints)
        
        return result.x

    def calculate_performance(self, weights, expected_returns, cov_matrix, returns):
        """计算投资组合绩效"""
        portfolio_return = weights @ expected_returns
        portfolio_volatility = np.sqrt(weights @ cov_matrix @ weights)
        sharpe_ratio = (portfolio_return - self.risk_free_rate) / portfolio_volatility
        
        # 计算最大回撤
        portfolio_returns = returns @ weights
        cumulative_returns = (1 + portfolio_returns).cumprod()
        running_max = cumulative_returns.expanding().max()
        drawdown = (cumulative_returns - running_max) / running_max
        max_drawdown = drawdown.min()
        
        return {
            'expected_return': portfolio_return,
            'volatility': portfolio_volatility,
            'sharpe_ratio': sharpe_ratio,
            'max_drawdown': max_drawdown
        }

class RealTimePortfolioOptimizer:
    """实时投资组合优化器"""
    
    def __init__(self):
        self.current_weights = None
        self.market_data = {}
        
    async def connect_market_data(self):
        """连接实时市场数据"""
        async with websockets.connect("wss://api.example.com/market-data") as websocket:
            async for message in websocket:
                data = json.loads(message)
                self.update_market_data(data)
                await self.rebalance_portfolio()
    
    def update_market_data(self, data):
        """更新市场数据"""
        for symbol, price in data.items():
            self.market_data[symbol] = price
    
    async def rebalance_portfolio(self):
        """实时再平衡"""
        if len(self.market_data) < 10:  # 确保有足够的数据
            return
            
        # 基于最新数据重新优化
        returns = self.calculate_recent_returns()
        new_weights = self.optimize_weights(returns)
        
        # 检查是否需要调仓
        if self.needs_rebalance(new_weights):
            await self.execute_trades(new_weights)
    
    def optimize_weights(self, returns):
        """优化权重"""
        # 使用在线优化算法
        from cvxpy import Problem, Minimize, quad_form
        import cvxpy as cp
        
        n = returns.shape[1]
        w = cp.Variable(n)
        mu = returns.mean().values
        Sigma = returns.cov().values
        
        # 在线投资组合选择
        objective = Minimize(quad_form(w, Sigma) - mu.T @ w)
        constraints = [cp.sum(w) == 1, w >= 0]
        prob = Problem(objective, constraints)
        prob.solve()
        
        return w.value

        self.assertAlmostEqual(np.sum(weights), 1.0, places=6)
        self.assertTrue(all(0 <= w <= 1 for w in weights))
        self.assertGreater(results['sharpe_ratio'], 0)
    
    def test_risk_parity(self):
        weights, results = self.optimizer.optimize_portfolio(
            self.returns, "风险平价", 0.2, 0.03
        )
        
        # 验证风险贡献相对均衡
        risk_contributions = self.calculate_risk_contributions(weights, self.returns.cov())
        std_dev = np.std(risk_contributions)
        self.assertLess(std_dev, 0.1)  # 风险贡献应该相对均衡

    unittest.main()

### 投资标的内部收益率（IRR）计算的开源库推荐

内部收益率（Internal Rate of Return, IRR）是评估投资项目盈利能力的常用指标，它表示使项目净现值（NPV）等于零的折现率。在投资分析中，常用于比较不同投资标的（如股票、基金、项目）的回报率。以下重点介绍Python开源库中用于IRR计算的工具，这些库免费开源、易集成，且在金融数据处理中广泛应用。

#### 1.  numpy-financial（推荐首选） 
   -  描述 ：这是NumPy的金融扩展库，专门用于金融计算，包括IRR、NPV、XIRR（考虑不规则现金流的时间加权IRR）等函数。原NumPy中的`irr()`函数已于1.20版本弃用，转而推荐此库。它高效、稳定，适合定期现金流的投资分析。
   -  安装 ：`pip install numpy-financial`
   -  示例代码 （假设初始投资1000元，后续4年现金流入分别为200、300、400、500元）：
     ```python
     import numpy_financial as npf

     cashflows = [-1000, 200, 300, 400, 500]  # 负值为初始投资，正值为流入
     irr_value = npf.irr(cashflows)
     print(f"内部收益率 (IRR): {irr_value:.2%}")  # 输出示例: 内部收益率 (IRR): 8.00%
     ```
   -  优势 ：支持XIRR（`npf.xirr()`），适用于不规则日期的投资标的；计算速度快，精度高。
   -  GitHub ：https://github.com/numpy/numpy-financial

#### 2.  NumPy（基础库，兼容旧版本） 
   -  描述 ：NumPy是Python科学计算核心库，其`irr()`函数可直接计算定期现金流的IRR。但在新版本中已弃用，建议迁移到numpy-financial。
   -  安装 ：`pip install numpy`
   -  示例代码 ：
     ```python
     import numpy as np

     cashflows = [-1000, 200, 300, 400, 500]
     irr_value = np.irr(cashflows)
     print(f"内部收益率 (IRR): {irr_value:.2%}")
     ```
   -  优势 ：无需额外安装，适合简单定期现金流；但不支持不规则时间序列。
   -  注意 ：如果使用NumPy 1.20+，会收到警告，推荐升级到numpy-financial。

#### 3.  PyXIRR（针对不规则现金流） 
   -  描述 ：专为计算XIRR设计的轻量级库，适用于投资中日期不均匀的现金流（如分批投资或赎回）。它使用迭代算法求解NPV=0的利率。
   -  安装 ：`pip install pyxirr`
   -  示例代码 （假设现金流带有日期）：
     ```python
     from pyxirr import xirr
     from datetime import date

     transactions = [
         (-1000, date(2025, 1, 1)),  # 初始投资
         (200, date(2025, 12, 31)),  # 第一年流入
         (300, date(2026, 12, 31)),
         (400, date(2027, 12, 31)),
         (500, date(2028, 12, 31))
     ]
     irr_value = xirr(transactions)
     print(f"XIRR: {irr_value:.2%}")
     ```
   -  优势 ：精确处理时间加权，适合复杂投资标的如基金定投。
   -  GitHub ：https://github.com/brettkromkamp/pyxirr

#### 其他选项
-  SciPy ：使用`scipy.optimize.newton`手动求解NPV方程，适合自定义场景，但需编写NPV函数。安装：`pip install scipy`。
-  statsmodels  或  PuLP ：更侧重统计/优化，可间接计算IRR，但不如上述库直接。

#### 使用建议
-  定期现金流 ：优先numpy-financial的`irr()`。
-  不规则现金流 ：用`xirr()`或PyXIRR。
-  验证 ：IRR计算依赖现金流准确性（初始投资为负，后续为正）。如果IRR < 资金成本（如银行利率），项目可能不值得投资。
-  工具环境 ：这些库可在Jupyter Notebook或VS Code中轻松测试。如果需要更高级的金融回测，可结合Pandas处理数据。

```java
import org.apache.commons.math3.analysis.solvers.LaguerreSolver;
import org.apache.commons.math3.analysis.polynomials.PolynomialFunction;
import org.apache.commons.math3.analysis.solvers.UnivariateSolver;

public class IRRDemo {
    public static double irr(double[] cashflows) {
        // 构造多项式： Σ cashflow[i] * x^(n-i)
        int n = cashflows.length;
        double[] coeffs = new double[n];
        for (int i = 0; i < n; i++) {
            coeffs[n - 1 - i] = cashflows[i];
        }
        PolynomialFunction poly = new PolynomialFunction(coeffs);

        // 使用 Laguerre 求根（NPV=0 的根）
        UnivariateSolver solver = new LaguerreSolver();
        double guess = 0.1;                 // 初始猜测 10%
        double root = solver.solve(1000, x -> poly.value(1.0 / (1 + x)), -0.999, 10.0, guess);
        return root;                        // 根即为 IRR
    }

    public static void main(String[] args) {
        double[] cf = {-1000, 200, 300, 400, 500};
        double irr = irr(cf);
        System.out.printf("IRR = %.2f%%\n", irr * 100);
    }
}
```

#### 1.2 XIRR（不规则现金流）——手写实现（兼容 Java 8+）

```java
import java.time.LocalDate;
import java.util.Arrays;
import java.util.List;

public class XIRR {
    public static double xirr(List<Transaction> transactions) {
        // 排序确保时间递增
        transactions.sort((a, b) -> a.date.compareTo(b.date));

        // 目标函数：NPV(r) = Σ cash / (1+r)^days
        class NPV {
            double eval(double r) {
                double total = 0.0;
                LocalDate first = transactions.get(0).date;
                for (Transaction t : transactions) {
                    double days = java.time.temporal.ChronoUnit.DAYS.between(first, t.date);
                    total += t.amount / Math.pow(1 + r, days / 365.0);
                }
                return total;
            }
        }
        NPV npv = new NPV();

        // Newton-Raphson 迭代
        double r = 0.1;                 // 初始猜测
        double eps = 1e-9;
        int maxIter = 100;
        for (int i = 0; i < maxIter; i++) {
            double f = npv.eval(r);
            double df = derivative(npv, r);
            double rNew = r - f / df;
            if (Math.abs(rNew - r) < eps) return rNew;
            r = rNew;
        }
        throw new RuntimeException("XIRR 未收敛");
    }

    private static double derivative(NPV npv, double r) {
        double h = 1e-8;
        return (npv.eval(r + h) - npv.eval(r - h)) / (2 * h);
    }

    public static class Transaction {
        double amount;
        LocalDate date;
        public Transaction(double amount, LocalDate date) {
            this.amount = amount; this.date = date;
        }
    }

    public static void main(String[] args) {
        List<Transaction> tx = Arrays.asList(
            new Transaction(-1000, LocalDate.of(2025,1,1)),
            new Transaction(200,  LocalDate.of(2025,12,31)),
            new Transaction(300,  LocalDate.of(2026,12,31)),
            new Transaction(400,  LocalDate.of(2027,12,31)),
            new Transaction(500,  LocalDate.of(2028,12,31))
        );
        double xirr = xirr(tx);
        System.out.printf("XIRR = %.2f%%\n", xirr * 100);
    }
}
```

> 优点： 无需第三方库 ，只用 Java 标准库；适用于任意不规则日期。

#### 2.3 手写 Newton-Raphson（纯 C++）

```cpp
#include <vector>
#include <cmath>
#include <iostream>

double irr(const std::vector<double>& cash) {
    auto npv = [&](double r) {
        double sum = 0.0;
        for (size_t i = 0; i < cash.size(); ++i)
            sum += cash[i] / std::pow(1 + r, i);
        return sum;
    };
    auto deriv = [&](double r) {
        double sum = 0.0;
        for (size_t i = 1; i < cash.size(); ++i)
            sum -= i * cash[i] / std::pow(1 + r, i + 1);
        return sum;
    };

    double r = 0.1;
    for (int i = 0; i < 100; ++i) {
        double f = npv(r);
        double df = deriv(r);
        if (std::abs(df) < 1e-12) break;
        double r_new = r - f / df;
        if (std::abs(r_new - r) < 1e-9) return r_new;
        r = r_new;
    }
    return r;
}

int main() {
    std::vector<double> cf = {-1000, 200, 300, 400, 500};
    std::cout << "IRR = " << irr(cf)*100 << "%\n";
}
```

#### 1.  MATLAB （适用于工程数学，Symbolic Math Toolbox 支持符号计算）
MATLAB 是数值和符号计算的首选工具，内置线性代数函数（如`inv`、`lu`），并通过Symbolic Toolbox 处理微积分。

-  高等数学示例 ：求 f(x) = sin(x)^2 的导数，并计算 ∫从0到π的积分。
  ```matlab

  f = sin(x)^2;  % 定义函数
  df = diff(f);  % 求导数
  integral_f = int(f, 0, pi);  % 求定积分
  disp('导数:'); disp(df);
  disp('积分值:'); disp(double(integral_f));  % 输出数值
  ```
  输出：导数 cos(2*x)，积分值 1.5708（π/2）。

-  线性代数示例 ：求解 A x = b，其中 A = [1 2; 3 4]，b = [5; 11]。
  ```matlab
  A = [1 2; 3 4];  % 定义矩阵 A
  b = [5; 11];     % 定义向量 b

  disp('解 x:'); disp(x);
  ```
  输出：x = [1; 2]。

-  概率论示例 ：计算正态分布 N(0,1) 下 P(X < 1.96)（95%置信水平）。

  ```matlab
  mu = 0; sigma = 1; z = 1.96;  % 参数

  disp('P(X < 1.96):'); disp(prob);
  ```

### 2. 求函数极值（导数）

 题目 ：求 f(x) = x³ - 3x 在 [-2, 2] 的极值点和极值。

 Python + SymPy（推荐） ：
```python
from sympy import *
x = symbols('x')
f = x 3 - 3*x

# 求导
df = diff(f, x)
critical_points = solve(df, x)  # 解 f' = 0
print("极值点:", critical_points)

# 二阶导数判断
d2f = diff(df, x)
for p in critical_points:
    if d2f.subs(x, p) > 0:
        print(f"x={p}: 极小值, f={f.subs(x,p)}")
    else:
        print(f"x={p}: 极大值, f={f.subs(x,p)}")
```
 输出 ：
```
极值点: [-1, 1]
x=-1: 极小值, f=2
x=1: 极大值, f=-2
```
 验证 ：图像凹凸性正确，答案无误。

### 5. 解析几何（圆与直线）

 题目 ：求直线 y = x + 1 与圆 x² + y² = 4 的交点。

 Python + SymPy ：
```python
from sympy import *
x, y = symbols('x y')
eq1 = y - x - 1
eq2 = x 2 + y 2 - 4
sols = solve([eq1, eq2], [x, y])
print(sols)
```
 输出 ：
```
[(-√3/2 - 1/2, √3/2 - 1/2), (√3/2 - 1/2, √3/2 + 1/2)]
```
 验证 ：代入圆方程都等于4， 正确 。

### 6. 概率统计（正态分布）

 题目 ：身高 ~ N(170, 8²)，求 P(165 < X < 180)。

 Python + SciPy ：
```python
from scipy.stats import norm
prob = norm.cdf(180, 170, 8) - norm.cdf(165, 170, 8)
print(f"概率 = {prob:.4f}")
```
 输出 ：`概率 = 0.7887`  
 验证 ：标准正态表查 Z=1.25 → 0.8944，Z=-0.625 → 0.266，差值 ≈ 0.788， 正确 。

```python
from .sub.b import hello   # . 表示当前包

def main():
```

## Ⅱ. 把项目打包成 `.whl`

### 1. 推荐使用 `pyproject.toml`（PEP 517/518）

```toml
# pyproject.toml
[build-system]
requires = ["setuptools>=61", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "my-pkg"
version = "0.1.0"
description = "示例项目：a.py 调用 b.py"
authors = [{name = "Your Name", email = "you@example.com"}]
license = {text = "MIT"}
readme = "README.md"
requires-python = ">=3.8"
classifiers = [
    "Programming Language :: Python :: 3",
    "License :: OSI Approved :: MIT License",
]

# 声明包的根目录是 src/
[tool.setuptools.packages.find]
where = ["src"]

# 或者手动列出（不推荐）
# [tool.setuptools]
# packages = ["my_pkg"]
```

```bash
pip install --upgrade build setuptools wheel
```

```bash
# 在项目根目录（my_project/）执行
```

#### 1. 视频推荐系统：核心算法原理
抖音推荐系统的目标是 拟合用户对内容的满意度函数 ，通过神经网络实时预测用户行为（如点赞、完播、分享），并平衡多目标（如用户体验、内容多样性）。系统不依赖传统“打标签”模式，而是基于行为数据和多模态分析（CV+ NLP）实现高效推荐。

##### 关键流程与算法
-  内容上传后处理 ：
  -  初筛审核 ：机器审核（基于深度学习模型检测标题、画面、音频），结合人工复核。使用CNN（卷积神经网络）提取视觉特征，BERT-like模型处理文本/语音。
  -  内容理解 ：多模态嵌入（Embedding），将视频分解为关键词、物体、情感等特征。公式：内容向量 = f(视觉 + 文本 + 音频)，f为Transformer编码器。

-  推荐排序 ：
  -  核心公式 ：推荐优先级 = Σ (用户行为概率 × 行为价值权重)。例如，完播率权重0.4、点赞率0.3、分享率0.3。
  -  模型架构 ：
    -  Wide & Deep模型 ：Wide部分处理低阶特征（e.g., 用户年龄+内容类别），Deep部分用DNN学习高阶交互。公式：P(行为) = σ(Wide(x) + Deep(x))，σ为Sigmoid激活。
    -  协同过滤 + 内容-based ：结合用户历史行为矩阵（User-Item Matrix）和内容相似度（Cosine Similarity）。
    -  多目标优化 ：使用REINFORCE强化学习，平衡“兴趣匹配”和“信息茧房”问题（e.g., 注入10%多样性内容）。
  -  实时反馈 ：每15分钟一轮A/B测试，调整模型参数。冷启动问题通过探索-利用（Epsilon-Greedy）策略解决。

-  底层技术栈 ：
  - 数据：Hudi湖仓（处理TB级日志），Flink实时流。
  - 训练：MegaScale架构，支持万卡GPU训练LLM增强推荐（HLLM分层大模型）。

#### 2. 广告上传展示系统：核心算法原理
广告系统嵌入推荐生态中，上传后需通过审核、竞价、投放，实现精准展示。核心是 oCPC/oCPM竞价 与推荐融合，确保广告不打扰用户体验（e.g., 广告占比<20%）。

##### 关键流程与算法
-  上传与审核 ：
  -  自动审核 ：类似视频初筛，使用OCR+ NLP检测违规（e.g., 虚假宣传）。模型：YOLO物体检测 + RoBERTa文本分类。
  -  创意优化 ：AI生成变体（e.g., A/B测试标题/封面），基于历史CTR预估。

-  展示与投放 ：
  -  竞价机制 ：实时拍卖（GSP算法），出价 = 基础价 × 质量分（Quality Score）。质量分 = eCTR（预计点击率） × 相关性。
    - 公式：排名 = 出价 × (历史CTR / 预期CTR偏差)。
  -  推荐融合 ：广告作为“特殊内容”注入推荐流，使用 联合排序模型 （Dual-Tower：用户塔 + 广告塔）。预测P(点击) = Dot(User_Embedding, Ad_Embedding)。
  -  人群定向 ：Lookalike建模（相似用户扩展），结合地理、行为标签。算法：Graph Neural Network (GNN) 传播兴趣图谱。
  -  反作弊 ：异常检测（Isolation Forest），过滤刷量/无效点击。

-  底层技术栈 ：
  - 平台：火山引擎“灵驹”（ByteAir），开放版推荐服务，支持企业定制。
  - 优化：深度强化学习（DRL），动态调整广告曝光率。

## 完整代码（PyTorch）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from collections import OrderedDict

class WideDeep(nn.Module):
    """
    Wide & Deep 模型（PyTorch 实现）
    适用于 CTR 预测（如抖音视频/广告点击）
    """
    def __init__(self, 
                 wide_feature_dim,           # Wide 部分输入维度（one-hot 总维度）
                 embedding_dims,             # 每个类别特征的 embedding 维度列表
                 deep_layer_sizes=[256, 128, 64],  # Deep DNN 层结构
                 dropout_rate=0.1):
        super(WideDeep, self).__init__()
        
        # ------------------- Wide Part -------------------
        self.wide_linear = nn.Linear(wide_feature_dim, 1, bias=True)
        
        # ------------------- Deep Part -------------------
        # 存储每个字段的 Embedding 层
        self.embeddings = nn.ModuleList()
        total_embedding_dim = 0
        for emb_dim in embedding_dims:
            # 假设每个字段的词汇表大小未知，先用 emb_dim 占位
            # 实际使用时需传入 field_dict: {field: vocab_size}
            embedding = nn.Embedding(num_embeddings=100000, embedding_dim=emb_dim, padding_idx=0)
            self.embeddings.append(embedding)
            total_embedding_dim += emb_dim
        
        # Deep DNN
        deep_input_dim = total_embedding_dim
        deep_layers = []
        for i, size in enumerate(deep_layer_sizes):
            deep_layers.append(nn.Linear(deep_input_dim, size))
            deep_layers.append(nn.BatchNorm1d(size))
            deep_layers.append(nn.ReLU())
            deep_layers.append(nn.Dropout(dropout_rate))
            deep_input_dim = size
        deep_layers.append(nn.Linear(deep_input_dim, 1))
        
        self.deep_net = nn.Sequential(*deep_layers)
        
    def forward(self, wide_inputs, deep_categorical_inputs):
        """
        wide_inputs:          [batch_size, wide_feature_dim]  float tensor
        deep_categorical_inputs: List[Tensor], 每个 shape=[batch_size]
        """
        # Wide
        wide_out = self.wide_linear(wide_inputs)  # [B, 1]
        
        # Deep: Embedding + Concat
        embedded = []
        for i, emb_layer in enumerate(self.embeddings):
            x = deep_categorical_inputs[i].unsqueeze(1)  # [B] -> [B,1]
            emb = emb_layer(x).squeeze(1)               # [B, emb_dim]
            embedded.append(emb)
        deep_input = torch.cat([F.relu(emb) for emb in embedded], dim=1)  # [B, total_emb_dim]
        
        deep_out = self.deep_net(deep_input)  # [B, 1]
        
        # 联合输出
        output = wide_out + deep_out
        return torch.sigmoid(output.squeeze(1))  # [B]
```

## 训练示例（模拟抖音 CTR 数据）

```python
# train_example.py
import torch
from torch.utils.data import Dataset, DataLoader
import numpy as np
from wide_deep_pytorch import WideDeep

# 1. 模拟数据集
class CTRDataset(Dataset):
    def __init__(self, num_samples=10000):
        self.num_samples = num_samples
        
        # Wide 特征：手动构造交叉特征（如 user_age * video_category）
        self.wide_features = np.random.randint(0, 2, size=(num_samples, 100)).astype(np.float32)
        
        # Deep 类别特征：3个字段（user_id, video_id, category_id）
        self.user_ids = np.random.randint(0, 10000, size=num_samples)
        self.video_ids = np.random.randint(0, 50000, size=num_samples)
        self.categories = np.random.randint(0, 20, size=num_samples)
        
        # 标签：模拟点击行为（非线性 + 线性）
        linear_part = self.wide_features[:, :10].sum(axis=1)
        nonlinear_part = np.sin(self.user_ids * 0.0001) + np.log1p(self.video_ids)
        self.labels = (linear_part + nonlinear_part > 5).astype(np.float32) + \
                      np.random.normal(0, 0.1, num_samples)
        self.labels = (self.labels > 0.5).astype(np.float32)
    
    def __len__(self): return self.num_samples
    def __getitem__(self, idx):
        return (
            torch.tensor(self.wide_features[idx]),
            [torch.tensor(self.user_ids[idx]), 
             torch.tensor(self.video_ids[idx]), 
             torch.tensor(self.categories[idx])],
            torch.tensor(self.labels[idx])
        )

# 2. 初始化模型
model = WideDeep(
    wide_feature_dim=100,
    embedding_dims=[16, 32, 8],   # user:16, video:32, category:8
    deep_layer_sizes=[128, 64, 32]
)

# 3. 训练
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.BCELoss()

dataset = CTRDataset(10000)
dataloader = DataLoader(dataset, batch_size=256, shuffle=True)

model.train()
for epoch in range(5):
    total_loss = 0
    for wide_x, deep_x_list, y in dataloader:
        wide_x = wide_x.to(device)
        deep_x_list = [x.to(device) for x in deep_x_list]
        y = y.to(device)
        
        pred = model(wide_x, deep_x_list)
        loss = criterion(pred, y)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    print(f"Epoch {epoch+1}, Loss: {total_loss/len(dataloader):.4f}")
```

```
import java.security.*;
import java.util.Base64;
import java.util.Arrays;
import java.util.StringJoiner;

/ 
 * 银企直联签名工具类
 */
public class BankSignUtil {
    
    / 
     * 生成签名原文字符串
     * @param businessParams 业务参数对象
     * @return 签名原文字符串
     */
    public static String generateSignDataStr(BusinessParams params) {
        // 按规范要求的格式拼接签名原文
        StringJoiner signDataStr = new StringJoiner("|");
        
        // 添加需要签名的业务字段（根据具体交易确定）
        signDataStr.add(params.getSerialNo());          // 流水号
        signDataStr.add(params.getPayAccountName());    // 付款账户名称
        signDataStr.add(params.getRecAccount());        // 收款账号
        signDataStr.add(params.getPayUse());           // 用途
        signDataStr.add(params.getTranAmt());          // 交易金额
        
        return signDataStr.toString();
    }
    
    / 
     * 使用UKEY进行数字签名
     * @param signDataStr 签名原文
     * @param keyStorePath UKEY证书路径
     * @param keyStorePassword 证书密码
     * @return Base64编码的签名结果
     */
    public static String generateSignData(String signDataStr, String keyStorePath, 
                                         String keyStorePassword) throws Exception {
        try {
            // 加载UKEY证书
            KeyStore keyStore = KeyStore.getInstance("PKCS12");
            try (FileInputStream fis = new FileInputStream(keyStorePath)) {
                keyStore.load(fis, keyStorePassword.toCharArray());
            }
            
            // 获取私钥
            String alias = keyStore.aliases().nextElement();
            PrivateKey privateKey = (PrivateKey) keyStore.getKey(alias, keyStorePassword.toCharArray());
            
            // 获取证书链（可选，用于验证）
            Certificate[] certChain = keyStore.getCertificateChain(alias);
            
            // 使用SHA256withRSA进行签名
            Signature signature = Signature.getInstance("SHA256withRSA");
            signature.initSign(privateKey);
            signature.update(signDataStr.getBytes("UTF-8"));
            
            // 生成签名
            byte[] digitalSignature = signature.sign();
            
            // Base64编码
            return Base64.getEncoder().encodeToString(digitalSignature);
            
        } catch (Exception e) {
            throw new RuntimeException("数字签名生成失败: " + e.getMessage(), e);
        }
    }
    
    / 
     * 验证签名（银行端使用）
     * @param signDataStr 签名原文
     * @param signData Base64编码的签名数据
     * @param publicKey 公钥
     * @return 验证是否通过
     */
    public static boolean verifySignature(String signDataStr, String signData, 
                                        PublicKey publicKey) throws Exception {
        try {
            Signature signature = Signature.getInstance("SHA256withRSA");
            signature.initVerify(publicKey);
            signature.update(signDataStr.getBytes("UTF-8"));
            
            byte[] signatureBytes = Base64.getDecoder().decode(signData);
            return signature.verify(signatureBytes);
            
        } catch (Exception e) {
            throw new RuntimeException("签名验证失败: " + e.getMessage(), e);
        }
    }
}
```

```
/ 
 * XML报文构建类

public class BankMessageBuilder {
    
    / 
     * 构建完整的请求报文（包含签名）
     */
    public static String buildRequestMessage(String bsnCode, String cstNo, 
                                           BusinessParams params, 
                                           String ukeyPath, String ukeyPassword) throws Exception {
        
        // 1. 生成签名原文
        String signDataStr = BankSignUtil.generateSignDataStr(params);
        
        // 2. 生成数字签名
        String signData = BankSignUtil.generateSignData(signDataStr, ukeyPath, ukeyPassword);
        
        // 3. 构建XML报文
        return buildXMLMessage(bsnCode, cstNo, params, signDataStr, signData);
    }
    
    / 
     * 构建XML报文内容
     */
    private static String buildXMLMessage(String bsnCode, String cstNo, 
                                        BusinessParams params, String signDataStr, String signData) throws Exception {
        try {
            DocumentBuilderFactory docFactory = DocumentBuilderFactory.newInstance();
            DocumentBuilder docBuilder = docFactory.newDocumentBuilder();
            
            // 创建文档
            Document doc = docBuilder.newDocument();
            
            // 根元素 QLBankData
            Element rootElement = doc.createElement("QLBankData");
            doc.appendChild(rootElement);
            
            // opReq 元素
            Element opReqElement = doc.createElement("opReq");
            rootElement.appendChild(opReqElement);
            
            // 添加基本字段
            addTextElement(doc, opReqElement, "bsnCode", bsnCode);
            addTextElement(doc, opReqElement, "cstNo", cstNo);
            addTextElement(doc, opReqElement, "reqTime", getCurrentTime());
            addTextElement(doc, opReqElement, "reqMac", getMacAddress());
            
            // ReqParam 元素
            Element reqParamElement = doc.createElement("ReqParam");
            opReqElement.appendChild(reqParamElement);
            
            // 添加业务参数
            addTextElement(doc, reqParamElement, "serialNo", params.getSerialNo());
            addTextElement(doc, reqParamElement, "payAccount", params.getPayAccount());
            addTextElement(doc, reqParamElement, "currencyType", params.getCurrencyType());
            addTextElement(doc, reqParamElement, "payAccountName", params.getPayAccountName());
            addTextElement(doc, reqParamElement, "recAccount", params.getRecAccount());
            addTextElement(doc, reqParamElement, "recAccountName", params.getRecAccountName());
            addTextElement(doc, reqParamElement, "tranAmt", params.getTranAmt());
            addTextElement(doc, reqParamElement, "payUse", params.getPayUse());
            addTextElement(doc, reqParamElement, "remark", params.getRemark());
            addTextElement(doc, reqParamElement, "branchId", params.getBranchId());
            addTextElement(doc, reqParamElement, "groupId", params.getGroupId());
            addTextElement(doc, reqParamElement, "transferType", params.getTransferType());
            
            // 添加签名数据
            addTextElement(doc, reqParamElement, "signDataStr", signDataStr);
            addTextElement(doc, reqParamElement, "signData", signData);
            
            // 转换为XML字符串
            return documentToString(doc);
            
        } catch (Exception e) {
            throw new RuntimeException("XML报文构建失败: " + e.getMessage(), e);
        }
    }
    
    private static void addTextElement(Document doc, Element parent, String tagName, String textContent) {
        Element element = doc.createElement(tagName);
        if (textContent != null) {
            element.setTextContent(textContent);
        }
        parent.appendChild(element);
    }
    
    private static String documentToString(Document doc) throws Exception {
        TransformerFactory transformerFactory = TransformerFactory.newInstance();
        Transformer transformer = transformerFactory.newTransformer();
        transformer.setOutputProperty(javax.xml.transform.OutputKeys.ENCODING, "UTF-8");
        transformer.setOutputProperty(javax.xml.transform.OutputKeys.INDENT, "yes");
        
        StringWriter writer = new StringWriter();
        transformer.transform(new DOMSource(doc), new StreamResult(writer));
        
        // 添加XML声明
        return "<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n" + writer.toString();
    }
```

运筹学（Operations Research, OR）是一门 应用数学 学科，其核心是使用数学模型和方法来解决实际中的优化问题。因此，它对大学阶段的数学知识有较高的要求。

以下是运筹学中 最常用和最重要的大学数学知识 ：

### I. 核心基础数学知识

#### 1. 线性代数（Linear Algebra）
这是运筹学，尤其是 线性规划 的 基石 。
*  应用：  用于构建和求解线性规划问题（如单纯形法）。
*  关键知识点： 
    * 矩阵（Matrix）及其运算（乘法、逆、转置）。
    * 向量空间、基、秩。
    * 线性方程组的求解（高斯消元法）。
    * 特征值和特征向量（在某些高级应用中会用到）。

#### 2. 微积分（Calculus）
微积分，特别是 多元微积分 ，是 非线性规划 和 优化理论 的基础。
*  应用：  用于求解目标函数和约束条件是连续函数的优化问题。
*  关键知识点： 
    * 导数和偏导数：用于寻找函数的极值点。
    * 梯度（Gradient）、黑塞矩阵（Hessian Matrix）：用于非线性规划的迭代算法（如牛顿法、梯度下降法）。
    * 拉格朗日乘数法（Lagrange Multipliers）：用于带等式约束的优化问题。

### II. 运筹学专属数学分支

#### 3. 概率论与数理统计（Probability and Mathematical Statistics）
这是运筹学中 随机模型 的基础。
*  应用： 
    *  排队论（Queueing Theory） ：分析系统的等待时间和性能。
    *  库存论（Inventory Theory） ：处理需求不确定的库存问题。
    *  模拟（Simulation） ：进行随机抽样和结果分析。
    *  决策分析 ：在不确定性下做出决策。
*  关键知识点： 
    * 随机变量、概率分布（如泊松分布、指数分布、正态分布）。
    * 期望、方差。
    * 马尔可夫链（Markov Chains）：排队论和动态规划中的重要工具。

#### 4. 离散数学（Discrete Mathematics）
虽然不总是作为一个独立的必修课，但其概念渗透在运筹学中。
*  应用： 
    *  图论（Graph Theory） ：用于网络流问题、最短路径问题、最小生成树问题等（如交通、物流、项目管理）。
    *  组合数学（Combinatorics） ：用于某些整数规划和组合优化问题。

### III. 其他重要辅助数学知识

#### 5. 数值分析（Numerical Analysis）
*  应用：  实际中许多复杂的优化模型无法解析求解，需要使用数值方法（如迭代法）来近似求解。
*  关键知识点：  迭代法、收敛性分析、数值稳定性。

#### 6. 集合论与逻辑（Set Theory and Logic）
*  应用：  用于严谨地定义优化模型中的变量、约束和可行域。
