# 20251018
一证五卡
“一证五卡”是中国大陆电信运营商为了落实电话用户实名制、有效防范和打击电信网络诈骗而设置的一项限制性规定。

### “一证五卡”的核心定义

“一证五卡”是指：
1.  一证： 指同一个有效身份证件（主要指居民身份证，通常也将户口簿合并校验）。
2.  五卡： 指在同一家基础电信企业（即中国移动、中国联通、中国电信三家中的任意一家）的全国范围内，办理的移动电话卡（含手机卡和无线上网卡/eSIM卡）数量累计达到 5 张（或以上）。

### 政策内容与限制
根据相关规定（主要依据六部委发布的《关于防范和打击电信网络诈骗犯罪的通告》等文件）：
* 限制内容： 如果同一用户在同一家基础电信企业名下已经办理了 5 张（或以上）有效使用的移动电话卡，该电信企业就不得再为其开办新的移动电话卡业务。
* 目的： 主要目的是遏制一些不法分子利用他人身份信息或虚假信息，大量注册电话卡进行电信网络诈骗、发送垃圾短信等违法行为。
* 适用范围： 该限制适用于所有基础电信企业（移动、联通、电信）以及移动通信转售企业（虚拟运营商）。
* 计算方式： 5 张卡的数量是跨系统、跨省在全国范围内累计计算的。

例如： 如果您在中国移动名下已经有 5 张手机卡，您将无法在中国移动的任何营业厅或线上渠道再办理第 6 张移动卡，但您仍可以在中国联通或中国电信名下分别办理新的电话卡（前提是这两家运营商名下的卡数未超限）。

### 在 Rust 和 JavaScript 中直接访问 MySQL 数据库
MySQL 是一种流行的关系型数据库，在 Rust 和 JavaScript（通常指 Node.js 环境）中都可以通过官方或社区驱动直接访问。Rust 使用 Crate（如 `mysql` crate），提供纯 Rust 实现，支持异步/同步查询；JavaScript 使用 npm 包（如 `mysql` 或 `mysql2`），支持 Promise 和连接池。以下是详细步骤、示例代码及注意事项。示例基于最新版本（2025 年 10 月数据），假设您有 MySQL 服务器运行（e.g., localhost:3306，用户 root，密码 password，数据库 test）。

#### 1. Rust 中访问 MySQL
Rust 的推荐库是 mysql crate（版本 26.0.1），一个纯 Rust MySQL 客户端，支持连接、查询、事务及类型转换。无需外部依赖，兼容 Tokio for async。

##### 步骤
1. 添加依赖：在 `Cargo.toml` 中添加：
   ```
   [dependencies]
   mysql = "26.0.1"
   ```
   运行 `cargo build` 安装。

2. 示例代码（简单查询和插入）：
   ```rust
   use mysql::prelude::*;
   use mysql::{Opts, Pool};

   fn main() -> Result<(), mysql::Error> {
       // 步骤 1: 创建连接选项
       let opts = Opts::new()
           .ip_or_hostname("127.0.0.1")
           .tcp_port(3306)
           .user(Some("root"))
           .pass(Some("password"))
           .db_name(Some("test"));

       // 步骤 2: 创建连接池（推荐用于生产）
       let pool = Pool::new(opts)?;

       // 步骤 3: 执行查询（插入示例）
       let mut conn = pool.get_conn()?;
       conn.exec_drop(
           "CREATE TABLE IF NOT EXISTS users (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(255))",
           (),
       )?;

       // 插入数据
       let stmt = conn.prep_drop("INSERT INTO users (name) VALUES (:name)")?;
       stmt.execute((":name", "Alice"))?;
       stmt.execute((":name", "Bob"))?;

       // 步骤 4: 查询数据
       let users: Vec<(u32, String)> = conn
           .query_map("SELECT id, name FROM users", |id: u32, name: String| (id, name))?;

       println!("Users: {:?}", users);  // 输出: [(1, "Alice"), (2, "Bob")]

       Ok(())
   }
   ```
   - 运行：`cargo run`。输出用户列表。
   - 说明：使用 `prep_drop` 准备语句防 SQL 注入；`query_map` 自动映射结果到 Rust 类型。

3. 高级功能：
   - 异步：添加 `tokio` 依赖，使用 `mysql_async` crate。
   - 事务：`conn.start_transaction()`。
   - 文档：https://docs.rs/mysql/latest/mysql/ 

##### 注意事项
- 性能：连接池（Pool）推荐用于多线程；默认支持 SSL。
- 错误处理：使用 `?` 操作符处理 `mysql::Error`。
- 兼容：支持 MySQL 5.7+；若需 ORM，使用 Diesel crate（`diesel = { version = "2.0", features = ["mysql"] }`）。

#### 2. JavaScript (Node.js) 中访问 MySQL
Node.js 的推荐驱动是 mysql (v2.18.1) 或 mysql2 (v3.11.3)，mysql2 支持 Promise/async-await，更现代。两者均为纯 JS，无需编译。

##### 步骤
1. 安装：在项目目录运行：
   ```
   npm install mysql2  # 或 mysql
   ```

2. 示例代码（简单查询和插入，使用 mysql2）：
   ```javascript
   const mysql = require('mysql2/promise');  // Promise 支持

   async function main() {
       // 步骤 1: 创建连接配置
       const connection = await mysql.createConnection({
           host: 'localhost',
           port: 3306,
           user: 'root',
           password: 'password',
           database: 'test'
       });

       // 步骤 2: 执行查询（插入示例）
       await connection.execute(
           'CREATE TABLE IF NOT EXISTS users (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(255))'
       );

       // 插入数据
       await connection.execute('INSERT INTO users (name) VALUES (?)', ['Alice']);
       await connection.execute('INSERT INTO users (name) VALUES (?)', ['Bob']);

       // 步骤 3: 查询数据
       const [rows] = await connection.execute('SELECT id, name FROM users');
       console.log('Users:', rows);  // 输出: [ { id: 1, name: 'Alice' }, { id: 2, name: 'Bob' } ]

       // 关闭连接
       await connection.end();
   }

   main().catch(console.error);
   ```
   - 运行：`node app.js`（保存为 app.js）。输出用户列表。
   - 说明：`execute` 自动转义参数防注入；`[rows]` 是结果数组。

3. 高级功能：
   - 连接池：`mysql.createPool()` for 多连接。
   - 事务：`connection.beginTransaction()`。
   - 文档：https://www.npmjs.com/package/mysql2  或 https://dev.mysql.com/doc/connector-nodejs/ 

##### 注意事项
- 性能：mysql2 比 mysql 更快，支持二进制协议。
- 错误处理：使用 try-catch for async。
- 兼容：支持 MySQL 5.6+；浏览器端需 WebSQL（已弃用），推荐 Node.js。

#### 总结与推荐
- Rust：适合高性能应用，使用 `mysql` crate 简单高效。
- JS：Node.js 环境首选 `mysql2`，易集成 Express 等框架。
- 通用建议：始终使用参数化查询防 SQL 注入；测试连接前确保 MySQL 服务运行（e.g., `docker run -p 3306:3306 -e MYSQL_ROOT_PASSWORD=password mysql:8`）。
- 资源：Rust 示例基于 [crates.io](https://crates.io/crates/mysql) ；JS 示例基于 [npm](https://www.npmjs.com/package/mysql) 。
