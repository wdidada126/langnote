### 如何找到更多成员的个人信息：
1.  C++ 官方网站：
    * 访问 isocpp.org 上的“The Committee”页面，可以找到核心官员和各个子工作组 (Study Group, SG) 主席的名单。
2.  C++ 标准提案 (Papers)：
    * 查阅 open-std.org/jtc1/sc22/wg21/docs/papers/ 上的 C++ 标准提案文档。每篇提案的作者通常就是委员会中积极贡献的成员。
3.  技术会议演讲：
    * 许多核心成员是 CppCon, Meeting C++ 等大型 C++ 会议的常客和主讲人，通过搜索他们的演讲视频，可以找到他们最新的工作和公司信息。
4.  LinkedIn/Twitter (X)：
    * 大多数成员在 LinkedIn 上有详细的职业档案，有些活跃的贡献者也会在 Twitter (X) 或 Mastodon 上讨论 C++ 的最新进展。

重要提示： 委员会成员的身份主要取决于他们所代表的国家机构或公司的任命，并且可能会随时间变化。要获取完整的、官方的、最新的成员名单，通常需要联系各国家标准机构（例如美国的 INCITS PL22.16 或英国的 BSI C++ Committee）。

IntelliJ IDEA 对 JDK 的支持非常广泛和灵活。它支持所有主要的 JDK 发行版，因为这些发行版都基于开源的 OpenJDK 项目。
在 IntelliJ IDEA 中，你可以通过以下两种方式使用 JDK：

### 1. IDE 运行环境 (Boot JDK)

IntelliJ IDEA本身是使用Java编写的应用程序，它依赖一个Java运行时环境（JRE/JDK）来运行。
* JetBrains Runtime (JBR)： 默认情况下，IntelliJ IDEA会捆绑并使用JetBrains Runtime来运行。JBR是一个基于OpenJDK的分支，包含了JetBrains为优化IDE 性能、字体渲染和稳定性的特定改进。
* 要求： 最新版本的 IntelliJ IDEA 通常要求使用Java 17或更高版本的JDK/JRE来启动 IDE。

### 2. 项目开发环境 (Project SDK)

这是你用来编译和运行 Java 项目的 JDK。IntelliJ IDEA 几乎支持所有基于 OpenJDK 的发行版，并推荐使用这些版本。

通过 IDE 内建的下载功能，你可以直接选择并下载以下主流的 JDK 发行版：

| 发行版名称 (Distribution Name) | 供应商 (Vendor) | 备注 (Notes) |
| :--- | :--- | :--- |
| Oracle OpenJDK | Oracle | Oracle 官方提供的 OpenJDK 版本。 |
| Adoptium (Eclipse Temurin) | Eclipse 基金会 | 非常流行的、由社区驱动的 OpenJDK 版本，是 AdoptOpenJDK 的继任者。 |
| Amazon Corretto | Amazon | 亚马逊为内部使用并公开提供的、符合 OpenJDK 标准的、有长期支持的版本。 |
| Azul Zulu | Azul | Azul 公司提供的 OpenJDK 版本，有免费和商业支持版本。 |
| BellSoft Liberica JDK | BellSoft | 提供标准版和包含 JavaFX 的完整版，通常被 Spring 官方推荐。 |
| Oracle GraalVM / GraalVM Community | Oracle/社区 | 专注于高性能、即时编译 (JIT) 和原生映像 (Native Image) 功能的 JDK。 |
| IBM Semeru Runtime | IBM | IBM 提供的基于 Eclipse OpenJ9 的高性能 OpenJDK 运行时。 |
| SapMachine | SAP | SAP 提供的 OpenJDK 发行版。 |

简而言之：
只要是符合Java SE标准的JDK，无论是LTS（长期支持版，如 Java 8, 11, 17, 21）还是最新的非LTS版本（如 Java 25），IntelliJ IDEA 都能支持并允许你将其配置为项目的SDK。如果你不确定选择哪个，Adoptium (Eclipse Temurin)和Amazon Corretto 是社区中最常用且推荐的免费、开源且长期支持的选择。
