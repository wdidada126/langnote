ifnull函数处理null
IFNULL 函数是 MySQL 中用于处理 NULL 值的常用函数。它的核心作用是：如果第一个参数不为 NULL，则返回第一个参数的值；如果第一个参数为 NULL，则返回第二个参数的值。

其基本语法如下：
IFNULL(expr1, expr2)


用法示例

下面通过一些具体的例子来说明 IFNULL 函数的用法和场景。

场景描述 SQL 示例 返回值说明

第一个参数非 NULL SELECT IFNULL(1, 0); 返回第一个参数 1

第一个参数为 NULL SELECT IFNULL(NULL, 10); 返回第二个参数 10

参数为字符串 SELECT IFNULL(NULL, '替代值'); 返回字符串 '替代值'

参数为计算结果 SELECT IFNULL(1/0, '计算无效'); 因为 1/0 结果为 NULL，所以返回 '计算无效'

实际应用场景

一个典型的应用场景是处理联系人电话信息。假设有一张 contacts 表，其中有些人只有办公电话 (bizphone)，有些人只有家庭电话 (homephone)。我们可以使用 IFNULL 函数来确保总能获取到一个有效的联系电话。
SELECT 
    contactname, 
    IFNULL(bizphone, homephone) AS phone
FROM 
    contacts;

在这个查询中，如果 bizphone 不为 NULL，则显示 bizphone；如果 bizphone 为 NULL，则显示 homephone 的值作为备用。

相关函数比较

为了更好地处理空值，MySQL 还提供了其他几个相关函数，你可以根据具体需求选择使用：

函数 作用 示例

ISNULL(expr) 判断表达式是否为 NULL，是则返回 1，否则返回 0。 SELECT ISNULL(NULL); 返回 1

NULLIF(expr1, expr2) 比较两个表达式，如果相等则返回 NULL，否则返回第一个表达式。 SELECT NULLIF(1, 1); 返回 NULL<br>SELECT NULLIF(1, 2); 返回 1

COALESCE(expr1, expr2, ...) 返回参数列表中第一个非 NULL 的值。可以接受两个以上的参数，比 IFNULL 更灵活。 SELECT COALESCE(NULL, NULL, '第三个值'); 返回 '第三个值'

注意事项

在使用 IFNULL 函数时，有两点需要注意：
1.  避免在 WHERE 子句中滥用：例如 WHERE IFNULL(column, 'default') = 'some_value' 这类写法会使索引失效，降低查询性能。应优先使用 IS NULL 或 IS NOT NULL。
2.  返回值类型：IFNULL 函数的返回值类型由两个参数中更“通用”的类型决定，顺序通常是字符串（STRING）、实数（REAL）、整数（INTEGER）。例如，IFNULL(1, 'test') 返回的字段类型会是 CHAR。
