org.apache.commons.lang.mutable

Apache Commons Lang库的org.apache.commons.lang.mutable包包含一些可变的对象类，用于封装原始数据类型（如int，long等）的操作。这些类设计用于提供线程安全的环境，同时简化编程模型。以下是一些在org.apache.commons.lang.mutable包中常见的类：

MutableInt：一个可变的int值，提供了原子操作。
MutableLong：一个可变的long值，提供了原子操作。
MutableObject：一个可变的通用对象，提供了原子操作。
MutableBoolean：一个可变的boolean值，提供了原子操作。
MutableDouble：一个可变的double值，提供了原子操作。
MutableFloat：一个可变的float值，提供了原子操作。
MutableShort：一个可变的short值，提供了原子操作。
MutableByte：一个可变的byte值，提供了原子操作。
MutableCharacter：一个可变的char值，提供了原子操作。
这些类都实现了相应的接口，例如MutableInt实现了Int接口，这样它们就可以用在需要这些接口的地方。每个类都提供了一些方法来安全地修改封装的值，例如setValue()、increment()、decrement()等。

Apache Commons Lang的Maven坐标如下：

xml
<dependency>  
    <groupId>org.apache.commons</groupId>  
    <artifactId>commons-lang3</artifactId>  
    <version>3.12.0</version>  
</dependency>
请注意，这里的version（版本号）可能需要根据你的具体需求进行调整。在编写这个答案的时候，最新的版本是3.12.0。你可以在Maven中央仓库找到这个jar包。

不过需要注意的是，org.apache.commons.lang.mutable包是在commons-lang的2.x版本中，从3.x版本开始，该包被移除，相关的类都被移动到了其他的包中。例如，MutableInt类现在位于org.apache.commons.lang3.mutable包中。所以如果你需要使用commons-lang3，你需要调整你的代码以适应新的包结构。
