# 2019_year

2019 年的笔记主线很清楚，是一整年围绕工作适应、后端基础补强和工程实践扩展展开的学习过程。年初从入职与适应新环境开始，随后逐渐把重心放到 Java 后端常见的测试体系、Spring、Maven、配置中心、数据库以及工程化工具链上，笔记内容从零散的节奏记录，慢慢转为围绕具体技术点的持续积累。

从下半年开始，学习范围明显进一步展开，不再局限于 Java 生态，而是扩展到了算法题、MySQL、Hystrix、有限状态机、C++、编译原理、Go、Rust 以及实际项目中的构建与部署问题。整体看，2019 年更像是一个“夯实技术广度与工程基本功”的阶段：既在补基础，也在通过不同语言和工具链寻找更适合自己的技术路径。
