要将多个 SQL COUNT 统计语句合并成一个，可以使用 UNION ALL。以下是一个示例：

假设有两个表 table1 和 table2，我们想要统计这两个表中的记录数，可以这样写：

```sql
SELECT 'table1' AS table_name, COUNT(*) AS count FROM table1
UNION ALL
SELECT 'table2' AS table_name, COUNT(*) AS count FROM table2;
```

这个查询将返回一个结果集，其中包含两个字段：table_name（表名）和 count（记录数）。
