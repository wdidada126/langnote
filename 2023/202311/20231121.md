要将多个 SQL COUNT 统计语句合并成一个，可以使用 UNION ALL。以下是一个示例：

假设有两个表 table1 和 table2，我们想要统计这两个表中的记录数，可以这样写：

```sql
SELECT 'table1' AS table_name, COUNT(*) AS count FROM table1
UNION ALL
SELECT 'table2' AS table_name, COUNT(*) AS count FROM table2;
```

这个查询将返回一个结果集，其中包含两个字段：table_name（表名）和 count（记录数）。

如果你在UEFI模式下更换硬盘并重新安装Windows后发现Ubuntu引导区丢失，以下是恢复Ubuntu引导的步骤：
首先，你需要准备一个Ubuntu的安装镜像（.iso文件），最好和你安装Ubuntu的镜像版本相同。此外，你还需要一个U盘（注意不能是启动盘，否则不能启动U盘里的系统）。然后，在Windows环境下，双击.iso文件，把Ubuntu的文件全部复制到U盘里面去。这里需要通过Windows来复制，否则无法正常启动Ubuntu的安装程序。
接下来，将U盘插入电脑，并从U盘启动（一定要选“UEFI：你的U盘名”那个启动项）。然后进入Ubuntu试用模式。
在试用模式下，打开抽屉的gparted分区软件，查看自己的分区表。找到你的Ubuntu系统分区和EFI分区。
接下来，重启电脑并进入BIOS设置。在BIOS中，将引导选项设置为优先从Ubuntu系统分区启动。这样，当你下次开机时，电脑会先尝试从Ubuntu系统分区启动，从而进入Ubuntu系统。
最后，一旦能够进入Ubuntu系统，你就可以使用Grub命令来修复或添加Ubuntu的引导项。例如，你可以运行`sudo update-grub`命令来更新Grub引导菜单，或者运行`sudo grub-install /dev/sda`命令（其中/dev/sda是你的Ubuntu系统分区）来重新安装Grub到MBR或GPT磁盘分区。
