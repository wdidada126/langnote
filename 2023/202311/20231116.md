es查询，为什么比mysql快
ES索引多，json数据每个字段都索引了

Elasticsearch 默认情况下会对 JSON 数据中的每个字段进行索引。这意味着，如果你有一个包含多个字段的 JSON 文档，Elasticsearch 会为每个字段创建一个单独的倒排索引。

例如，假设你有以下 JSON 文档：

```json

{
  "name": "张三",
  "age": 30,
  "city": "北京"
}

```

在创建索引时，Elasticsearch 会为 `name`、`age` 和 `city` 这三个字段分别创建倒排索引。这有助于提高搜索性能，因为你可以针对特定字段执行更精确的查询。

然而，并非所有字段都需要被索引。有时，某些字段可能包含大量重复数据（例如枚举类型），或者不需要用于搜索目的。在这种情况下，你可以使用以下方法来避免对特定字段进行索引：

  1.  使用 `_source` 参数排除字段** ：在创建或更新文档时，可以使用 `_source` 参数来指定要包含在索引中的字段。例如：
```json

PUT /my_index/_doc/1?refresh=true
{
  "name": "张三",
  "age": 30,
  "city": "北京",
  "_source": ["name", "age"]
}

```

这将仅对 `name` 和 `age` 字段进行索引，而不会对 `city` 字段进行索引。请注意，这种方法需要为每个文档显式指定要包含的字段。

  2.  使用 `@field` 注解 ：在 Java 中，可以使用 `@Field` 注解来指定哪些字段应该被索引。例如：
```java

public class Person {
    @Field(include = false)
    private String city;
    // ...其他字段...
}

```

这将确保 `city` 字段不会被索引。请注意，这种方法需要在代码中显式指定要排除的字段。
