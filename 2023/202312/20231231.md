要在 Ubuntu 20.04 上通过命令行下载 OpenJDK 7 的 tar.gz 文件，你可以使用 `wget` 命令。以下是具体的步骤：
1. 打开终端（命令行界面）。
2. 使用 `wget` 命令下载 OpenJDK 7 的 tar.gz 文件。你可以选择从适当的源进行下载，例如 AdoptOpenJDK 或其他可信赖的来源。假设你要从 AdoptOpenJDK 下载，可以使用以下命令：
```bash
wget https://github.com/AdoptOpenJDK/openjdk7-binaries/releases/download/jdk7u80-b32/OpenJDK7U-jdk_x64_linux_7u80b32.tar.gz
```
这将从指定 URL 下载 OpenJDK 7 的 tar.gz 文件。
3. 下载完成后，你将在当前目录下看到一个名为 `OpenJDK7U-jdk_x64_linux_7u80b32.tar.gz` 的文件，这是 OpenJDK 7 的压缩包。
现在你已经成功通过命令行下载了 OpenJDK 7 的 tar.gz 文件。你可以继续使用其他命令解压和安装 OpenJDK 7，根据你的需要进行进一步的操作。
请注意，OpenJDK 7 已经过时，不再接收官方安全更新。如果可能，建议使用更新的 OpenJDK 版本，如 OpenJDK 8、11 或更高版本，以获取更好的安全性和功能支持。

Elasticsearch（简称ES）是一个分布式、可扩展、实时的搜索与数据分析引擎，不仅仅只是全文搜索，还支持结构化搜索、数据分析、复杂的语言处理、地理位置和对象间关联关系等。底层依赖Lucene，这是一个非常先进、高性能和全功能的搜索引擎库。
在ES的读写流程中，检索的Fetch阶段是一个关键步骤。由于ES分片机制的存在，插入的文档是不连续存放在同一个Shard分片上的。因此，当我们想要检索满足指定条件的文档时，必须在所有的分片上都进行检索后，再将结果归并后再排序才能得到最终满足条件的文档ID。在Fetch阶段，根据文档ID重新在各个分片上查询得到最终结果，再合并后返回出去。
ES有两种search_type：query_then_fetch（默认）和dfs_query_then_fetch。对于query_then_fetch，用户发起搜索请求到集群中的某个节点后，query会被发送到所有相关的shard分片上。每个shard分片独立执行query搜索文档并进行排序分页等，打分时使用的是分片本身的Local Term/Document频率。最后，分片的query结果（只有元数据，例如_id和_score）返回给请求节点。
