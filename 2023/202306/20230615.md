在 Java 8 中，跟时区无关的日期和时间类是 java.time.LocalDate、java.time.LocalTime 和 java.time.LocalDateTime。这些类提供了更加丰富和灵活的日期和时间操作，并且不依赖于特定的时区。
java.time.LocalDate 表示一个日期，只包含年、月和日，没有时、分、秒和时区信息。
java.time.LocalTime 表示一个时间，只包含时、分、秒，没有年、月、日和时区信息。
java.time.LocalDateTime 表示一个日期和时间，包含年、月、日、时、分、秒，但没有时区信息。
这些类可以根据需要进行日期和时间的处理，而无需关注时区的影响。

`java.util.Date` 类在存储日期和时间时不考虑时区信息，它代表的是一个特定的时间点，与时区无关。当你创建一个 `java.util.Date` 对象时，它会使用系统默认时区。
在使用 `java.util.Date` 进行日期和时间计算时，它会考虑系统默认时区。然而，`java.util.Date` 本身并不保存时区信息，因此无法直接获取或设置时区。
如果你需要在特定的时区中进行日期和时间操作，可以使用 `java.util.Calendar` 或更现代的 `java.time` API（在 Java 8 及更高版本中可用）。这些 API 提供了更丰富的日期和时间处理功能，并支持时区操作。
要注意的是，在进行日期和时间操作时，始终建议明确指定所使用的时区，以避免潜在的时区相关问题。
