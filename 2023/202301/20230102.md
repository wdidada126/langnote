要在Spring API中自定义线程池，可以使用ThreadPoolTaskExecutor类。以下是一个简单的示例：

首先，在Spring配置文件中定义一个ThreadPoolTaskExecutor bean：

```xml
<bean id="myThreadPoolTaskExecutor" class="org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor">  
    <property name="corePoolSize" value="5" />  
    <property name="maxPoolSize" value="10" />  
    <property name="queueCapacity" value="25" />  
</bean>
```
在上面的示例中，我们定义了一个名为myThreadPoolTaskExecutor的bean，并设置了以下属性：

corePoolSize：线程池的核心大小，即最小线程数。
maxPoolSize：线程池的最大大小。
queueCapacity：线程池队列的容量。
接下来，您可以在您的代码中使用myThreadPoolTaskExecutor bean来执行异步任务。例如，您可以在服务层中注入该bean，并使用它来执行长时间运行的任务：

```java
@Service  
public class MyService {  
    @Autowired  
    private ThreadPoolTaskExecutor myThreadPoolTaskExecutor;  
      
    public void doSomethingAsync() {  
        myThreadPoolTaskExecutor.execute(() -> {  
            // 执行长时间运行的任务  
        });  
    }  
}
```
在上面的示例中，我们注入了myThreadPoolTaskExecutor bean，并使用execute()方法来执行一个匿名函数，该函数包含长时间运行的任务。由于该任务是在线程池中执行的，因此它不会阻塞主线程。


在Java业务代码中，可以使用java.util.concurrent.ExecutorService接口和它的实现类来自定义线程池。以下是自定义线程池的一般步骤：

导入必要的类：

```java
import java.util.concurrent.ExecutorService;  
import java.util.concurrent.Executors;  
import java.util.concurrent.ThreadPoolExecutor;
```
创建一个线程池对象：

```java
// 创建一个固定大小的线程池，包含1个核心线程和2个最大线程  
ExecutorService executorService = Executors.newFixedThreadPool(2);
```
在上面的示例中，我们使用Executors.newFixedThreadPool()方法创建了一个固定大小的线程池，其中包含1个核心线程和2个最大线程。你也可以使用其他方法来创建不同类型的线程池，如newCachedThreadPool()、newSingleThreadExecutor()等。

提交任务到线程池：

```java
// 提交一个Runnable任务到线程池  
executorService.submit(() -> {  
    // 业务逻辑代码  
});
```
可以使用submit()方法将Runnable或Callable任务提交到线程池中进行执行。在上面的示例中，我们提交了一个Runnable任务。

关闭线程池：

```java
// 关闭线程池，平滑关闭，会等待正在执行的任务完成后再关闭  
executorService.shutdown();
```
在应用程序结束时或者不再需要使用线程池时，应该关闭线程池以释放资源。可以使用shutdown()方法来平滑关闭线程池，它会等待正在执行的任务完成后再关闭。如果你希望立即关闭线程池并取消所有未执行的任务，可以使用shutdownNow()方法。

这是一个简单的自定义线程池的示例。在实际应用中，你可能还需要根据业务需求和性能考虑来调整线程池的配置，如核心线程数、最大线程数、队列容量等。可以参考ThreadPoolExecutor类的文档和示例来了解更多关于线程池的配置和使用的细节。
