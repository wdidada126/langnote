在 Vue.js 中，`.vue` 文件通常用于编写单个组件。在一个 `.vue` 文件中，可以通过 `export default` 语法导出一个 Vue 组件对象。

`export default` 语法用于将组件定义导出为默认导出。这意味着在其他地方引入该组件时，可以使用任意名称来接收它，而不需要使用特定的名称。

在一个 `.vue` 文件中，`components` 属性用于注册和引入其他组件。通过将其他组件作为键值对添加到 `components` 属性中，可以在当前组件中使用这些组件，并在模板中使用它们。

以下是一个简单的示例，展示了一个 `.vue` 文件的基本结构，其中包含了 `export default` 和 `components` 的使用：

```vue
<template>
  <div>
    <!-- 模板内容 -->
    <ChildComponent />
  </div>
</template>

<script>
import ChildComponent from './ChildComponent.vue';

export default {
  components: {
    ChildComponent
  },
  // 组件的其他配置和逻辑
}
</script>

<style>
/* 样式规则 */
</style>
```

在上面的示例中，`ChildComponent` 是从 `./ChildComponent.vue` 文件中导入的另一个组件，然后通过 `components` 属性注册为当前组件的子组件。这样，就可以在当前组件的模板中使用 `<ChildComponent />` 标签来渲染子组件的内容。

通过这种方式，可以在一个 `.vue` 文件中组合多个组件，使代码更模块化和可维护。
