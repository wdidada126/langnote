```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Person("John", 30);

        ReflectivePropertyAccessor accessor = new ReflectivePropertyAccessor();
        String name = (String) accessor.getPropertyValue(person, "name");
        System.out.println("Name: " + name);

        accessor.setPropertyValue(person, "age", 31);
        System.out.println("Age: " + person.getAge());
    }
}
```

需要注意的是，使用 ReflectivePropertyAccessor 时，属性名大小写敏感。如果属性名写错了，会导致程序出错。
