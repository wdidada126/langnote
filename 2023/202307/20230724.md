统计Spring MVC接口的执行耗时,常用的开源方案包括:
1. Spring AOP + AspectJ:通过AOP切面在Controller方法执行前后计算时间,输出统计信息。
2. Spring Boot Actuator:提供built-in的HTTP请求监控,可以看到时间指标。
3. InspectorTap:注入Agent,可以拦截方法调用信息。
4. Uber JVM Profiler:通过JVM信息统计调用时间。
5. Micrometer:整合多种监控框架,提供计时器注解等功能。
6. Async-profiler:低开销的纯Java分析器。
7. Java Interactive Profiler:图形界面分析调用信息。
8. Greys:Java诊断工具,可以查看方法执行数据。
9. Arthas:在线诊断和监控工具。

推荐使用 Spring Boot Actuator,可以快速实现接口统计,也可以结合 AOP、Micrometer 等框架扩展监控功能。
但需要注意避免监控本身带来过大性能开销。
