```
	@Bean
	public MappingJackson2HttpMessageConverter mappingJackson2HttpMessageConverter() {
		MappingJackson2HttpMessageConverter jsonConverter = new MappingJackson2HttpMessageConverter();
		ObjectMapper objectMapper = new ObjectMapper();
		objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
		objectMapper.setPropertyNamingStrategy(PropertyNamingStrategy.SNAKE_CASE);
		jsonConverter.setObjectMapper(objectMapper);
		return jsonConverter;
	}
```

这两行代码都是用于配置Jackson库中ObjectMapper对象的行为的。
1. `objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);`
该行代码的作用是禁用Jackson库中的反序列化特性：当Java对象中有未知属性时，如果该特性被开启（默认开启），则会抛出异常；如果该特性被禁用，则会忽略未知属性而不会抛出异常。因此，通过该行代码，我们可以允许Java对象中存在未知属性而不导致反序列化失败。
2. `objectMapper.setPropertyNamingStrategy(PropertyNamingStrategy.SNAKE_CASE);`
该行代码的作用是设置Jackson库中的属性命名策略，用于控制Java对象属性名与JSON属性名之间的映射关系。在该行代码中，我们使用了SnakeCase策略，它将Java对象中的属性名转换为下划线分隔的形式，例如，Java对象中的属性名"firstName"会被转换为JSON中的属性名"first_name"。该策略通常用于将Java对象与采用下划线分隔命名规则的系统进行交互。
总的来说，这两行代码的作用是为Jackson库中的ObjectMapper对象配置反序列化特性和属性命名策略，从而控制Java对象的序列化和反序列化行为，以满足特定的需求。

    @NacosConfigListener(dataId = DATA_ID, groupId = GROUP_ID)
    public void changeLoggingLevel() {
        ch.qos.logback.classic.LoggerContext loggerContext = (ch.qos.logback.classic.LoggerContext) LoggerFactory.getILoggerFactory();
        loggerContext.getLogger("root").setLevel(ch.qos.logback.classic.Level.toLevel(rootLevel));
        loggerContext.getLogger("druid.sql.Statement").setLevel(ch.qos.logback.classic.Level.toLevel(druidSqlStatementLevel));
        log.info("change logging level to {}", rootLevel);
    }
