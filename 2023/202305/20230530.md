BeanPropertyRowMapper、ColumnMapRowMapper和SingleColumnRowMapper都是RowMapper的实现类。
它们的主要区别在于:
- BeanPropertyRowMapper:
将结果集的每一行映射为一个JavaBean对象。
利用BeanWrapper将结果集的列名自动匹配类的相应属性。
- ColumnMapRowMapper:
将结果集的每一行映射为一个Map。
Map的key为数据列名,value为数据值。
- SingleColumnRowMapper:
将结果集的每一行映射为一个单列的值。
使用指定的index (序号)或column name (列名)作为Map的唯一键值。
举个例子:
如果一个结果集如下:

| id | name | age |
| 1  | John | 20  |
- 使用BeanPropertyRowMapper,会映射为:
```java
User {
   id: 1,  
   name: "John",
   age: 20
}
```
- 使用ColumnMapRowMapper,会映射为:
```java
{
   "id": 1,  
   "name": "John", 
   "age": 20
}
```
- 使用SingleColumnRowMapper,映射age列,会得到:
```java
{
   "age":20  
}
```
总的来说:
- BeanPropertyRowMapper会将结果集映射为一个JavaBean对象
- ColumnMapRowMapper映射为一个Map
- SingleColumnRowMapper映射为一个包含单列值的Map
它们分别适用于需要整体映射JavaBean、部分映射Map或者只映射单个值的场景。
