BeanPropertyRowMapper、ColumnMapRowMapper和SingleColumnRowMapper都是RowMapper的实现类。
它们的主要区别在于:
- BeanPropertyRowMapper:
将结果集的每一行映射为一个JavaBean对象。
利用BeanWrapper将结果集的列名自动匹配类的相应属性。
- ColumnMapRowMapper:
将结果集的每一行映射为一个Map。
Map的key为数据列名,value为数据值。
- SingleColumnRowMapper:
将结果集的每一行映射为一个单列的值。
使用指定的index (序号)或column name (列名)作为Map的唯一键值。
举个例子:
如果一个结果集如下:

| id | name | age |
| 1  | John | 20  |
- 使用BeanPropertyRowMapper,会映射为:
```json
User {
   id: 1,  
   name: "John",
   age: 20
}
```
- 使用ColumnMapRowMapper,会映射为:
```json
{
   "id": 1,  
   "name": "John", 
   "age": 20
}
```
- 使用SingleColumnRowMapper,映射age列,会得到:
```json
{
   "age":20  
}
```
总的来说:
- BeanPropertyRowMapper会将结果集映射为一个JavaBean对象
- ColumnMapRowMapper映射为一个Map
- SingleColumnRowMapper映射为一个包含单列值的Map
它们分别适用于需要整体映射JavaBean、部分映射Map或者只映射单个值的场景。

spring-jdbc这个jar
org.springframework.jdbc.core.RowCountCallbackHandler
RowCountCallbackHandler是Spring Framework中的一个回调接口，用于处理SQL查询结果集的行数。
当使用JdbcTemplate执行SQL查询操作时，可以通过实现RowCountCallbackHandler接口来获取查询结果集的行数。该接口只有一个方法：processRow(int rowNum)，它会在每一行查询结果集返回时被调用，参数rowNum表示当前行的行号。
使用RowCountCallbackHandler可以在查询操作执行完成后，获取到查询结果集的行数，以便进行后续的处理。例如，可以将查询结果集的行数用于分页操作或者做一些统计工作等。
