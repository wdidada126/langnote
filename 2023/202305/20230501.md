java.util.EventListener 接口主要有以下几个作用:

1. 定义事件监听器的类型
事件监听器接口必须继承 EventListener 接口,以定义其类型。

例如:

```java
public interface ActionListener extends EventListener {
    // 实现方法
}
```

ActionListener 定义了一个 action 事件的监听器类型。

2. 将事件源和监听器解耦
事件源(Event Source)只需要知道监听器实现了 EventListener 接口,但并不需要知道具体是哪个实现类。
这就实现了事件源和事件监听器的解耦。
3. 在注册监听器时进行类型检查
当向事件源注册监听器时,事件源可以检查监听器是否实现 EventListener 接口,从而进行类型检查。
例如:

```java
button.addActionListener((ActionListener)listener);
```

这里检查 listener 是否是 ActionListener 类型。

4. 作为事件监听器的基类
所有事件监听器接口都继承自 EventListener,它实现了事件监听器的公共功能。
5. 作为事件监听器列表的类型
事件源可以使用 EventListener 类型表示其绑定的监听器列表。

例如:
```java
private EventListener[] listeners;
```

总的来说,EventListener 接口主要用于定义事件监听器类型、将事件源和监听器解耦,并作为注册监听器和表示监听器列表的基础类型。


```java
ServletContext servletContext = getServletContext();

// 获取所有监听器
Enumeration<EventListener> listenerEnum = servletContext.getListeners();
while (listenerEnum.hasMoreElements()) {
    EventListener listener = listenerEnum.nextElement();
    System.out.println("Listener: " + listener.getClass().getName());
}

// 获取所有过滤器
Enumeration<FilterRegistration> filterEnum = servletContext.getFilterRegistrations();
while (filterEnum.hasMoreElements()) {
    FilterRegistration filterRegistration = filterEnum.nextElement();
    System.out.println("Filter: " + filterRegistration.getClassName());
}
```

WebMvcConfigurer接口


在SpringMVC中，可以使用`InterceptorRegistry`来注册拦截器，并在Spring应用程序中打印生效的拦截器。以下是示例代码：

1. 创建一个拦截器类并实现HandlerInterceptor接口。例如：

```
public class MyInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler)
            throws Exception {
        System.out.println("MyInterceptor preHandle method called");
        return true;
    }

    @Override
    public void postHandle(HttpServletRequest request, HttpServletResponse response, Object handler,
            ModelAndView modelAndView) throws Exception {
        System.out.println("MyInterceptor postHandle method called");
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler,
            Exception ex) throws Exception {
        System.out.println("MyInterceptor afterCompletion method called");
    }

}
```

2. 在Spring MVC的配置文件中声明拦截器。例如：

```
@Configuration
public class AppConfig extends WebMvcConfigurerAdapter {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new MyInterceptor());
    }
}
```

3. 运行应用程序并查看控制台输出。您应该能够看到类似以下内容的输出：

```
MyInterceptor preHandle method called
MyInterceptor postHandle method called
MyInterceptor afterCompletion method called
```

这表明您的拦截器已经生效，并且在控制器方法执行之前、之后和完成之后都执行了相应的操作。通过`InterceptorRegistry`注册拦截器可以方便地管理和配置多个拦截器。如果您想要打印所有生效的拦截器，可以在`addInterceptors`方法中修改代码如下：

```
@Configuration
public class AppConfig extends WebMvcConfigurerAdapter {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new MyInterceptor());
        registry.addInterceptor(new AnotherInterceptor());

        for (HandlerInterceptor interceptor : registry.getInterceptors()) {
            System.out.println("Interceptor: " + interceptor.getClass().getSimpleName() + " is active");
        }
    }
}
```

这样，当您运行应用程序时，控制台将输出类似以下内容的消息：

```
Interceptor: MyInterceptor is active
Interceptor: AnotherInterceptor is active
```

这表明这两个拦截器都已激活并生效。
