springboot webmvc项目，spring容器中有ObjectMapper对象吗？

在 Spring Boot WebMvc 项目中，如果你使用了 `spring-boot-starter-web` 依赖，那么 Spring 容器中会自动配置 `MappingJackson2HttpMessageConverter`，并注入 `ObjectMapper` 对象。

`ObjectMapper` 是 Jackson 库中的核心类，它用于将 Java 对象序列化为 JSON 字符串或将 JSON 字符串反序列化为 Java 对象。在 Spring Boot WebMvc 项目中，`ObjectMapper` 是用于 `MappingJackson2HttpMessageConverter` 进行 JSON 序列化和反序列化的。

如果你需要在代码中使用 `ObjectMapper` 对象，可以直接在需要的地方将其注入进来，Spring Boot 会自动将 `ObjectMapper` 对象注入到容器中，你可以使用 `@Autowired` 注解将其注入到你的代码中，例如：

```java
@RestController
public class MyController {

    @Autowired
    private ObjectMapper objectMapper;

    @GetMapping("/test")
    public String test() throws JsonProcessingException {
        MyObject obj = new MyObject();
        obj.setFoo("foo");
        obj.setBar("bar");
        return objectMapper.writeValueAsString(obj);
    }
}
```

在上面的代码中，我们将 `ObjectMapper` 对象注入到 `MyController` 中，并在 `test` 方法中使用它将 `MyObject` 对象序列化为 JSON 字符串。

总之，如果你使用了 `spring-boot-starter-web` 依赖，那么 Spring Boot WebMvc 项目中会自动配置 `ObjectMapper` 对象，并将其注入到容器中，你可以在需要的地方直接使用 `@Autowired` 注解将其注入到代码中。
