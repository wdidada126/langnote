好的,我用中文给你一个 Spring Boot 整合 Dubbo 的配置示例:

```java
@SpringBootApplication
@EnableDubbo
public class DubboProviderDemoApplication {

  public static void main(String[] args) {
    SpringApplication.run(DubboProviderDemoApplication.class, args);  
  }

  @Bean
  public DemoService demoService() {
    return new DemoServiceImpl();
  }

}

@DubboService  
public class DemoServiceImpl implements DemoService {

  @Override
  public String sayHello(String name) {
    return "Hello " + name;
  } 

}
```

Dubbo 的配置放在`application.properties`文件中:

```
# Spring Boot应用配置  
spring.application.name=dubbo-provider-demo
server.port=9090

# Dubbo配置
dubbo.scan.base-packages=com.example.dubboproviderdemo  
dubbo.protocol.name=dubbo
dubbo.protocol.port=20880

dubbo.registry.address=N/A
```

这个配置了一个基本的Dubbo提供者,通过Dubbo在20880端口暴露`DemoService`服务。

客户端类似,只是使用`@DubboReference`引用远程服务,并不暴露服务端口。

在Spring Boot中使用Dubbo,需要在pom.xml中添加以下依赖:

<dependency>
    <groupId>org.apache.dubbo</groupId>
    <artifactId>dubbo-spring-boot-starter</artifactId>
    <version>2.7.3</version>
</dependency>

这个是Dubbo Spring Boot Starter的依赖,它会自动扫描@DubboService,@DubboReference注解并注册服务。

如果你需要使用Zookeeper作为注册中心,还需要添加:

<dependency>
    <groupId>org.apache.dubbo</groupId>
    <artifactId>dubbo-dependencies-zookeeper</artifactId>
    <version>2.7.3</version>
    <type>pom</type>
</dependency>

这会引入Zookeeper客户端相关的依赖。

另外,Dubbo还支持其他注册中心,如Nacos、Eureka等,如果要使用其他注册中心,需要将对应的依赖添加到pom.xml中。

最后,在Spring Boot 2.x中,需要额外添加:

<dependency>
  <groupId>org.apache.dubbo</groupId>
  <artifactId>dubbo</artifactId>
  <version>2.7.3</version> 
</dependency>

这是因为Spring Boot 2.x默认使用高版本的commons-codec,和Dubbo不兼容,需要显式指定dubbo依赖来解决冲突。

springmvc 内置thfrif protobuf支持吗？
在Spring MVC中，并没有内置对Thrift或Protobuf的直接支持。然而，您可以通过自定义配置来集成Thrift或Protobuf到Spring MVC应用程序中。

对于Thrift，您可以使用第三方库如"thrift-spring"来实现集成。"thrift-spring"提供了Thrift服务的Spring集成支持，包括Thrift服务的定义、处理器的注册和请求的处理。您可以将其添加到您的项目的Maven依赖中，然后根据文档进行配置和使用。

对于Protobuf，您可以使用"spring-protobuf"或"spring-boot-starter-protobuf"等第三方库来实现集成。这些库提供了与Protobuf相关的Spring集成支持，包括Protobuf消息的定义、编解码器的注册和请求的处理。您可以根据您的需求选择适当的库，并按照其文档进行配置和使用。

总之，虽然Spring MVC本身没有内置Thrift或Protobuf的支持，但可以通过使用第三方库来实现集成并在Spring MVC应用程序中使用它们。

对于"thrift-spring"库的Maven坐标，以下是一个示例：

```xml
<dependency>
    <groupId>org.apache.thrift</groupId>
    <artifactId>thrift-spring</artifactId>
    <version>0.13.0</version>
</dependency>
```

您可以将上述依赖项添加到您的项目的pom.xml文件中，以使用"thrift-spring"库。请注意，版本号可能会有所不同，您可以根据需要选择适当的版本号。

请确保您的项目配置了正确的Maven仓库，以便能够从中央仓库或其他相关仓库获取该库的依赖项。
