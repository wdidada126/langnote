Collections.unmodifiableList() 不可变集合到底用来干嘛的

Java 中的Collections.unmodifiableList() 方法可以用来创建一个不可变的List集合(无法对其进行添加、删除、修改操作)。不可变集合一般有以下几个使用场景:
1. 在创建集合后防止程序意外修改集合内容
将一个普通List使用unmodifiableList()包装后返回,可以防止接收方随意修改List中的内容。
2. 避免共享集合被修改
如果需要共享一个集合给多个调用方,可以返回unmodifiableList() version,避免集合内容被修改。
3. 作为方法返回值类型
方法返回一个集合时,通常只需要读取,不需要修改,所以返回unmodifiableList()更安全。
4. 类不可变设计
如果一个类需要存储集合属性,通常会定义为private final,同时使用unmodifiableList()包装,可以实现整个类的不可变设计。
5. 防御性编程
使用unmodifiableList()可以提高程序对修改集合的防御能力,发现问题更快。
6. 并发程序中防止共享集合被修改
在并发场景下,可以使用unmodifiableList()来避免共享集合被修改出现问题。
所以简单来说,unmodifiableList() 主要用于防御性编程,避免集合被意外修改,提高程序健壮性。它通常用在需要共享集合的场景中。
