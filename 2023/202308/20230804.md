如果你想要接收 `ApplicationEvent` 事件，可以实现 `ApplicationListener` 接口或者使用 `@EventListener` 注解来定义一个事件监听器。具体来说，你可以按照以下步骤进行操作：

1. 实现 `ApplicationListener` 接口来定义一个事件监听器。比如，如果你要监听 `MyEvent` 事件，你可以按照以下方式编写一个事件监听器：

   ```java
   public class MyEventListener implements ApplicationListener<MyEvent> {
       @Override
       public void onApplicationEvent(MyEvent event) {
           // 处理 MyEvent 事件
       }
   }
   ```

   这个代码中，我们定义了一个名为 `MyEventListener` 的类，它实现了 `ApplicationListener` 接口，并将泛型参数指定为 `MyEvent` 类型。在 `onApplicationEvent()` 方法中，我们可以处理 `MyEvent` 事件的逻辑。

2. 将事件监听器注册到 Spring 应用上下文中。可以在 Spring 配置文件中使用 `<bean>` 元素来注册监听器，也可以使用 `@Component` 注解将监听器声明为一个 Spring 组件。比如，如果你使用 `@Component` 注解将 `MyEventListener` 声明为一个组件，可以按照以下方式进行操作：

   ```java
   @Component
   public class MyEventListener implements ApplicationListener<MyEvent> {
       @Override
       public void onApplicationEvent(MyEvent event) {
           // 处理 MyEvent 事件
       }
   }
   ```

   这个代码中，我们使用 `@Component` 注解将 `MyEventListener` 声明为一个 Spring 组件。在 Spring 应用上下文启动时，Spring 会自动将 `MyEventListener` 注册为一个事件监听器。

3. 发布事件。可以使用 `ApplicationEventPublisher` 接口来发布事件。比如，如果你要发布一个名为 `MyEvent` 的事件，你可以按照以下方式进行操作：

   ```java
   @Autowired
   private ApplicationEventPublisher appEventPublisher;

   public void doSomething() {
       MyEvent event = new MyEvent(this, "some data");
       appEventPublisher.publishEvent(event);
   }
   ```

   这个代码中，我们注入了一个 `ApplicationEventPublisher` 对象，并使用它来发布一个 `MyEvent` 事件。在 `MyEventListener` 中实现的 `onApplicationEvent()` 方法会在事件被发布后自动被调用，从而完成事件的处理逻辑。

需要注意的是，`@EventListener` 注解可以替代 `ApplicationListener` 接口，用于定义一个事件监听器。使用 `@EventListener` 注解时，你只需要在方法上标注该注解，并将方法参数的数据类型指定为你要监听的事件类型即可。比如，如果你要监听 `MyEvent` 事件，你可以按照以下方式编写一个事件监听器：

```java
@Component
public class MyEventListener {
    @EventListener
    public void handleMyEvent(MyEvent event) {
        // 处理 MyEvent 事件
    }
}
```

这个代码中，我们使用 `@Component` 注解将 `MyEventListener` 声明为一个 Spring 组件，并在其中定义了一个名为 `handleMyEvent()` 的方法，它使用 `@EventListener` 注解来标注，表示该方法是一个事件监听器，并将方法参数的数据类型指定为 `MyEvent` 类型。在方法中，我们可以处理 `MyEvent` 事件的逻辑。
