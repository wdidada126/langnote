StandardEvaluationContext调用例子
org.springframework.context.expression.StandardBeanExpressionResolver#evaluate()

```java
			StandardEvaluationContext sec = this.evaluationCache.get(evalContext);
			if (sec == null) {
				sec = new StandardEvaluationContext(evalContext);
				sec.addPropertyAccessor(new BeanExpressionContextAccessor());
				sec.addPropertyAccessor(new BeanFactoryAccessor());
				sec.addPropertyAccessor(new MapAccessor());
				sec.addPropertyAccessor(new EnvironmentAccessor());
				sec.setBeanResolver(new BeanFactoryResolver(evalContext.getBeanFactory()));
				sec.setTypeLocator(new StandardTypeLocator(evalContext.getBeanFactory().getBeanClassLoader()));
				ConversionService conversionService = evalContext.getBeanFactory().getConversionService();
				if (conversionService != null) {
					sec.setTypeConverter(new StandardTypeConverter(conversionService));
				}
				customizeEvaluationContext(sec);
				this.evaluationCache.put(evalContext, sec);
			}
```

印花税是一种由政府对证券交易收取的税费，通常应用于股票交易、债券交易和其他金融资产的转让交易。这种税收的目的可以包括税收收入、市场监管、抑制过度频繁的交易等。
以下是一个举例说明证券行业中的印花税：
**假设情境：**
在一个国家的证券市场中，有一名投资者名为小明，他打算购买1000股某家公司的股票。每股股票的价格为10美元。该国的政府规定了印花税，该税率为0.1%。这意味着每次进行股票交易，交易金额的0.1%将作为印花税收取。

**交易过程：**
1. 小明决定购买1000股股票，每股价格为10美元。总交易金额 = 1000股 * 10美元/股 = 10,000美元。
2. 根据政府的印花税规定，交易金额的0.1%将被收取为印花税。因此，印花税 = 10,000美元 * 0.1% = 10美元。
3. 小明购买股票的实际支出为股票价格加上印花税，即10,000美元 + 10美元 = 10,010美元。
在这个例子中，小明购买股票时需要支付10,010美元，其中10美元是印花税。这部分印花税会被政府收取，作为股票交易的一部分费用。
请注意，印花税的税率和适用对象会因国家和地区而异。一些地方可能对股票买卖征收印花税，而另一些地方可能会对债券、期货等金融资产的交易征收印花税。此外，印花税的目的也可能会根据国家政策的不同而有所不同。
