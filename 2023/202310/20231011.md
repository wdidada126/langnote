在Java 8中，reduce()函数是Stream API的一部分，用于将Stream中的元素通过指定的操作（BinaryOperator<T>）进行累积。这个操作接受两个参数：一个当前元素和一个累积器，并返回一个新的累积值。

orElse()函数也是Stream API的一部分，用于提供一个默认值如果Stream为空。

这两个函数可以联合使用，例如在处理可能为空的Stream时提供一个默认值，或者在处理Stream之后提供一个最终的累积结果。

下面是一个例子：

```java
List<String> list = Arrays.asList("a", "b", "c");  
Optional<String> reduced = list.stream()  
    .reduce((s1, s2) -> s1 + s2)  
    .orElse("Default");  
System.out.println(reduced);  // 输出 "abc"  
  
List<String> emptyList = new ArrayList<>();  
Optional<String> reducedEmpty = emptyList.stream()  
    .reduce((s1, s2) -> s1 + s2)  
    .orElse("Default");  
System.out.println(reducedEmpty);  // 输出 "Default"
```
在这个例子中，reduce()函数把一个非空列表的元素通过字符串拼接进行累积，如果列表为空，orElse()函数会提供一个默认值"Default"。

CAll添加 A B之后，A B的值就变了？

根据您提供的信息，我认为您可能是在问关于Java中的List（列表）的操作。在Java中，List是一种集合类型，用于存储一组有序的元素。

如果您创建了两个List A和B，并且想要将它们添加到另一个List CAll中，那么CAll添加 A B之后，A B的值不会发生改变。这是因为List是可变的，您可以通过CAll修改A和B的值，但这不会影响原始的A和B列表。

下面是一个简单的示例代码来说明这个概念：

```java
import java.util.ArrayList;  
import java.util.List;  
  
public class ListExample {  
    public static void main(String[] args) {  
        // 创建两个列表 A 和 B  
        List<String> listA = new ArrayList<>();  
        listA.add("Apple");  
        listA.add("Banana");  
  
        List<String> listB = new ArrayList<>();  
        listB.add("Orange");  
        listB.add("Pear");  
  
        // 创建第三个列表 CAll  
        List<List<String>> listCAll = new ArrayList<>();  
  
        // 将 A 和 B 添加到 CAll 中  
        listCAll.add(listA);  
        listCAll.add(listB);  
  
        // 输出原始的 A 和 B 列表的值  
        System.out.println("List A: " + listA);  
        System.out.println("List B: " + listB);  
  
        // 修改 CAll 中 A 和 B 的值  
        listCAll.get(0).set(0, "Cherry"); // 修改 A 中的第一个元素  
        listCAll.get(1).set(0, "Pineapple"); // 修改 B 中的第一个元素  
  
        // 输出修改后的 A 和 B 列表的值，可以看到它们的值已经被修改了  
        System.out.println("List A after modifying CAll: " + listA);  
        System.out.println("List B after modifying CAll: " + listB);  
    }  
}
```
上述代码中，我们将列表A和B添加到了CAll中，并对CAll中A和B的值进行了修改。但是，修改后的值只影响CAll中的副本，原始的A和B列表的值并没有发生改变。这是因为Java中的List是对象引用类型，当您将列表添加到另一个列表中时，实际上只是将引用添加到列表中，而不是复制整个列表。因此，对引用的修改将影响原始列表。
