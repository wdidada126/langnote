# 20231011

在Java 8中，reduce()函数是Stream API的一部分，用于将Stream中的元素通过指定的操作（BinaryOperator<T>）进行累积。这个操作接受两个参数：一个当前元素和一个累积器，并返回一个新的累积值。

orElse()函数也是Stream API的一部分，用于提供一个默认值如果Stream为空。

这两个函数可以联合使用，例如在处理可能为空的Stream时提供一个默认值，或者在处理Stream之后提供一个最终的累积结果。

下面是一个例子：

```java
List<String> list = Arrays.asList("a", "b", "c");  
Optional<String> reduced = list.stream()  
    .reduce((s1, s2) -> s1 + s2)  
    .orElse("Default");  
System.out.println(reduced);  // 输出 "abc"  
  
List<String> emptyList = new ArrayList<>();  
Optional<String> reducedEmpty = emptyList.stream()  
    .reduce((s1, s2) -> s1 + s2)  
    .orElse("Default");  
System.out.println(reducedEmpty);  // 输出 "Default"
```
在这个例子中，reduce()函数把一个非空列表的元素通过字符串拼接进行累积，如果列表为空，orElse()函数会提供一个默认值"Default"。
