🔧 主要开源项目（与数据库内核相关）

1. [rosedb](https://github.com/rosedblabs/rosedb)
基于 Bitcask 模型的轻量级、高性能 KV 存储引擎（Go 语言）
⭐ 4.9k stars
特点：WAL + 内存索引 + 磁盘 SST 文件，适合学习存储引擎原理

2. [lotusdb](https://github.com/lotusdblabs/lotusdb)
高性能 KV 数据库，支持 LSM-tree 和 B+ tree 两种结构（Go）
⭐ 2.2k stars
定位为“最先进的 Go语言KV存储”

3. [wal](https://github.com/rosedblabs/wal)
通用的 Write-Ahead Log 实现，可用于 Bitcask 或 LSM 引擎

4. [Apache Cloudberry](https://github.com/apache/cloudberry)
参与贡献的 MPP 分布式数据库（类似 Greenplum）
C 语言为主，属于 Apache 孵化项目

这属于技术博主常见的知识变现模式，并非骗局。其开源项目质量较高，社区认可度好（合计超 8k stars），课程内容也基于真实代码。
