# 贾磊

贾磊博士的求学和工作经历非常精彩，是一位从学术研究到产业应用都取得卓越成就的科学家。
以下是小米集团副总裁、集团技术委员会主席 贾磊博士 的详细求学及职业履历：
一、 求学经历
贾磊博士的求学阶段主要在中国顶尖的科技大学完成，奠定了深厚的理论根基。
•   本科： 毕业于 中国科学技术大学（USTC） 无线电系（现为电子工程与信息科学系）。中科大以其坚实的数理基础培养而闻名。
•   博士： 在 中国科学院自动化研究所 模式识别与智能系统专业获得博士学位。中科院自动化所在国内人工智能和模式识别领域是顶尖的研究机构，这段经历为他日后在语音识别领域的深耕打下了核心基础。
二、 职业经理人经历（从学术界到产业界）
贾磊博士的职业路径清晰地展现了他将前沿学术研究转化为巨大商业价值的成功历程。
1.  微软美国总部研究员（2003-2009）
    ◦   博士毕业后，他加入了微软美国总部，担任研究员。在此期间，他成为了微软语音识别引擎的奠基人之一，负责核心算法的研发。这段经历让他在工业级的大型语音系统开发上积累了宝贵的经验。
2.  百度首席科学家（2009-2012）
    ◦   2009年，贾磊回国加入百度，担任百度首席科学家，并一手创建了百度的语音技术团队。
    ◦   他主持研发了百度第一代大规模商品化语音识别系统，为百度早期的语音业务奠定了技术基础。这是中国互联网公司早期在语音AI领域的重要突破。
3.  创业：KITT.AI 创始人兼CEO（2012-2017）
    ◦   2012年，贾磊离开百度，在美国西雅图创立了专注物联网语音交互的初创公司 KITT.AI。
    ◦   KITT.AI 开发了著名的唤醒词技术，其产品“Snowboy”是一个可以高精度、低功耗地在嵌入式设备上运行的自定义唤醒词检测引擎，在当时深受开发者社区欢迎，是著名的开源项目。
    ◦   关键转折： 2017年，KITT.AI被中国领先的AI公司科大讯飞收购，贾磊和团队一同加入科大讯飞。
4.  科大讯飞 AI研究院副院长、讯飞苏州研究院院长（2017-2019）
    ◦   在科大讯飞期间，他主要负责前沿技术的探索和研发，进一步深化了在智能语音和人工智能领域的研究。
5.  小米集团（2019年至今）—— 当前的职位
    ◦   2019年： 贾磊博士加入小米集团，担任集团副总裁、集团技术委员会主席。
    ◦   主要职责：
        ▪   领导小米集团技术战略规划：负责制定公司中长期的技术发展方向。
        ▪   构建技术研发体系：提升小米整体的技术研发能力和效率。
        ▪   打造开源技术生态：推动小米积极参与和贡献开源社区。
        ▪   强化知识产权布局：管理小米的专利等知识产权资产。
    ◦   在他的带领下，小米的技术委员会在推动包括语音技术、影像技术、充电技术、物联网平台等核心技术的突破和整合方面发挥了关键作用。特别是小米的小爱同学语音助手，其技术演进也离不开他的领导和影响。
总结
贾磊博士的履历是一条典型的 “顶尖学术背景 -> 跨国巨头核心研发 -> 回国引领巨头技术团队 -> 成功创业 -> 被收购后进入另一巨头 -> 最终成为大型科技集团的技术总指挥” 的路径。
他是一位横跨学术界、跨国公司、创业公司和大型互联网集团的复合型顶尖技术领袖，是中国智能语音技术产业化的重要推动者之一。
