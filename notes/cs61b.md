### 🎓 伯克利 CS61B（Data Structures）
- 定位：Java 入门 + 数据结构与算法 + 软件工程实践，北美经典硬核课，自学首选。
- 节奏：前半学期 Java 面向对象；后半学期数据结构与算法，全程强工程实践。
- 教材：Head First Java（第2版） + 课程官方在线笔记（免费）。
- 官网：https://datastructur.es/（最新学期）；推荐 SP21（有公开自动评测）：https://sp21.datastructur.es/。
- 代码仓库：https://github.com/Berkeley-CS61B。

### 课程大纲（精简）
#### 前半段：Java 面向对象（OOP）
- 环境配置：IntelliJ、Git、Maven/Gradle
- Java 基础：类/对象、方法、重载、构造器、this、static
- 面向对象：封装、继承、多态、接口、抽象类、内部类
- 异常处理、泛型、集合框架（List/Set/Map）、I/O、JUnit 测试

#### 后半段：数据结构与算法
- 基础结构：数组、链表（单向/双向/哨兵）、栈、队列
- 树：二叉树、BST、AVL、红黑树、B 树
- 哈希：哈希函数、链地址、开放寻址、扩容
- 排序：选择/插入/归并/快排/堆排、复杂度分析
- 图：DFS/BFS、最短路径（Dijkstra）、最小生成树
- 高级：动态规划、贪心、内存管理、性能调优

### 作业体系（小作业 + 大项目，全公开）
#### 小作业（Homework，短平快）
- HW0：环境配置 + 简单 Java 热身
- HW1：Java 基础语法与面向对象练习
- HW2：泛型 + 集合框架实战
- HW3：链表与递归
- HW4：树与哈希表
- HW5：排序算法实现与对比

#### 大项目（Project，工程化，重点）
- Project 0（NBody）：天体运动模拟，OOP 入门实战。
- Project 1（Deque）：双端队列，实现 ArrayDeque/LinkedListDeque，性能对比。
- Project 2（Gitlet）：简易版 Git，实现commit/branch/merge，深入文件I/O与哈希。
- Project 3（WordNet）：词网 + 最短祖先路径，图算法实战。
- Project 4（Kd-Tree）：二维范围搜索，空间划分树，性能优化。
- Project 5（BYOW）：2D 随机世界生成，面向对象设计 + 算法综合。
