这就是找到距离cap参数最近的2的次幂
static final int tableSizeFor(int cap) {
    int n = cap - 1;
    n |= n >>> 1;
    n |= n >>> 2;
    n |= n >>> 4;
    n |= n >>> 8;
    n |= n >>> 16;
    return (n < 0) ? 1 : (n >= MAXIMUM_CAPACITY) ? MAXIMUM_CAPACITY : n + 1;
}

“>> 右移,高位补符号位” 这里右移一位表示除2
“>>> 无符号右移,高位补0”； 与>>类似
“<< 左移” 左移一位表示乘2，二位就表示4，就是2的n次方

		System.out.println(8>> 2); //除法，如果右边因子大于1，结果变小，
		System.out.println(8<< 2); //乘法，左移位
