# 面试策略

https://github.com/kdn251/interviews/blob/master/README-zh-cn.md

关于面试，我的常见策略是问几个要点：
1. 关于这项技术的应用细节：即一个人如果声称掌握了这项技术，那么实践过程的一些经验是书上没有而却根本避不开的，问这些问题可以有效的识别简历造假。比如问Web框架可以问如何做重定向，问深度学习就问模型的存储格式优化。
2. 关于这项技术的缺点：只有用过一段时间某个技术，才能看到这个技术的缺点，虽然不至于信仰崩溃，但至少知道如何去解决这些缺点，扬长避短。
3. 关于这项技术的bug：将一个框架用出bug来是不太难的，能做到这一步就比较熟悉了。
4. 技术的领域知识：框架无关的问题，能够判断一个人基础知识的牢固程度，并判定在这个领域能走多远。
