# flume

Flume is a distributed, reliable, and available system for efficiently collecting, aggregating, and moving large amounts of log data from many different sources to a centralized data store.

Flume 是一个分布式、可靠且高可用的服务，用于有效地收集，聚合和移动大量日志数据。它具有基于流数据的简单灵活架构，良好的可靠性机制、故障转移和恢复机制，具有强大的容错性。
Flume 主要用于大数据处理中，用于收集、聚合和移动大量日志数据。它可以从各种数据源（如本地文件、实时日志、REST 消息、Avro、Syslog、Kafka 等）中收集数据，并将数据写入各种数据接收方（如 HDFS、HBase 等）。
