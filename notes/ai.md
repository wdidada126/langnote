### 一般读哪些论文来复现？（按学习阶段推荐，2025–2026视角）

大多数人不会从头复现所有论文，而是分阶段、有针对性地选，目标是从简单 → 经典 → 现代前沿。

1. 入门 / 打基础阶段（建议先复现这些，代码相对干净，论文也经典）
   - LeNet-5 (1998) 或 AlexNet (2012) → 卷积网络基础
   - ResNet (2015, Deep Residual Learning for Image Recognition)
   - Transformer (2017, Attention is All You Need) — 几乎所有现代大模型的起点
   - BERT (2018) 或 GPT-2 small (2019)
   - Vision Transformer (ViT, 2020)
   - Diffusion Models (DDPM, 2020)

   这些论文的官方/社区代码质量高，数据集标准（MNIST/CIFAR/ImageNet），复现周期短（几天到一周），能快速建立信心。

2. 中级 / 理解现代架构阶段（2023–2025 经典）
   - LLaMA / LLaMA-2 / LLaMA-3 系列（Meta）
   - Mistral / Mixtral（高效 MoE）
   - Qwen / DeepSeek 系列（尤其是 DeepSeek-V2/V3/R1，2025年开源社区最火的推理模型之一）
   - FlashAttention-2 (2023–2024)
   - LoRA / QLoRA（参数高效微调）
   - o1-like reasoning models 的相关工作（DeepSeek-R1, o1-mini 相关开源复现）

3. 高级 / 研究级复现（瞄准顶会，挑战大）
   - NeurIPS/ICML/ICLR 2025 的高引论文（如 Test-Time Compute / Reasoning 相关、Efficient LLM、Multimodal）
   - SAM 2 (Segment Anything 2, 2025)
   - 新一代 diffusion / VLA (Vision-Language-Action) 模型
   - 具身智能 / 机器人相关（如 OpenVLA, RT-X）

2025–2026 复现热度 Top 论文（社区 GitHub star 多、讨论活跃）：
- DeepSeek-R1 / DeepSeek-V3
- Qwen 系列后训练 / GSPO
- Llama-3 / Llama-4 相关开源实现
- o1-style 推理模型（过程奖励、自我一致性等）
- FlashAttention-3 / 新注意力变体
- SAM 2 / MobileSAM 等视觉分割

最常用的一站式组合（2026 年主流路径）：
1. 阅读论文 → 看 abstract / introduction / method / appendix（算法伪代码）
2. 去 arXiv 搜 "paper name github" 或 "paper name reproduce"
3. 找不到官方代码 → 用 HuggingFace 搜索模型名，或看 lucidrains / karpathy 是否有实现
4. 基础框架选 nanoGPT 或 Transformers + PEFT
5. 分布式 / 大规模 → verl / OpenRLHF / Megatron
6. 验证：先在小数据集（C4 subset / FineWeb-Edu small）上跑通，再上全量

- 遇到 bug 先搜 issue（GitHub + Reddit + HuggingFace forum）
- 2025–2026 年最火的复现主题：reasoning model post-training（DeepSeek-R1 风格的 GRPO / process reward）

在 数据库系统（DBMS） 领域，读论文并写代码复现（reproduce / implement）是深入理解内核机制、算法创新和工程权衡的最有效方式之一。相比 AI/ML 领域，DBMS 论文的代码复现难度通常更高（涉及并发、磁盘 I/O、崩溃恢复、分布式一致性等），但回报也很大：能真正搞懂一个模块，就相当于掌握了一个真实系统的子系统。

### 一般读哪些论文来复现？（按学习路径推荐，2025–2026视角）

大多数人不会复现所有论文，而是分阶段、有针对性地选，从经典 → 现代 → 前沿。以下是社区公认的“高性价比”复现列表（优先选择有开源代码或伪代码清晰的）。

#### 1. 入门 / 打基础阶段（强烈推荐先复现这些）
这些论文算法相对清晰，工程量适中，复现周期 1–4 周，能快速建立对 DBMS 核心的直觉。

- ARIES (1992) – Mohan et al.  
  几乎所有现代数据库的恢复基石（WAL、checkpoint、ARIES-style undo/redo）。  
  复现目标：实现简单 WAL + recovery。

- The R* Tree (1984) 或 R*-tree (1990)  
  经典空间索引，PostgreSQL 的 GiST基础。  
  复现：实现 R-tree 插入/查询/分裂。

- The Volcano Optimizer (1990s) 或 Cascades Framework (Graefe)  
  查询优化器的经典框架，许多现代优化器（如 DuckDB、TiDB）受其影响。  
  复现：简单 rule-based optimizer。

- Log-Structured Merge-Tree (LSM-Tree) (1996) – O'Neil et al.  
  LevelDB / RocksDB / Bigtable / Cassandra 基础。  
  复现：简单 LSM + compaction。

#### 2. 中级 / 现代经典阶段（2020年后高影响力）
这些论文代码往往有官方/社区实现，适合深入理解当前工业界热点。

- Umbra (2010s–2020s) 系列论文（Neumann & Kemper）  
  现代内存数据库代表，查询编译、 morsel-driven 并行。  
  复现：向量化执行引擎或 JIT 查询编译（参考 DuckDB 实现）。

- DuckDB 相关论文（Raasveldt & Mühleisen）  
  如 "DuckDB: An Embeddable Analytical Database" 或向量化执行系列。  
  复现：列式存储 + vectorized query execution。

- Redesigned Storage for Modern Main Memory DBMS (HyPer / Umbra 相关)  
  虚拟内存快照、fork-based OLAP。

- Balsa 或 NoisePage (CMU) 论文  
  学习型数据库（learned index / learned optimizer）。  
  复现：learned B-tree 或 learned cardinality estimation。

- TiDB / CockroachDB 相关论文  
  如 Spanner-inspired 分布式事务、Raft + Percolator。  
  复现：简单 Raft-based KV 或 MVCC。

#### 3. 高级 / 2024–2026 前沿热点（SIGMOD / VLDB / CIDR / OSDI）
这些论文复现难度大，但含金量高，常用于面试/研究。

- Learned Query Optimization (e.g. Bao, RTOS, Neo, etc.)
- Disaggregated Databases (e.g. PolarDB、Neon、Cloudberry）
- HTAP / Hybrid Row-Column Stores (e.g. TiFlash、SAP HANA 相关)
- Vector Databases 内部分区/索引（如 Milvus、Qdrant 论文）
- Persistent Memory DBMS (e.g. PMem KV stores, Pronto)

2025–2026 复现热度较高的（SIGMOD/VLDB 常被复现）：
- SQuaLity 测试套件（2025 SIGMOD）
- Andromeda（LLM 配置调试）
- CODDTest（logic bug 检测）
- Learned components in DuckDB / Umbra

最常用的一站式起步路径（2026 年主流）：
1. 先 fork bustub 或 huadb（根据你熟悉 C++）
2. 实现论文中感兴趣的模块（如加一个 learned index 到 buffer pool，或改成 fork-based snapshot）
3. 测试：用 JOB (Join Order Benchmark) 或 TPC-H/DS 测试查询性能
4. 验证：对比 baseline（原 bustub / huadb）的吞吐 / 延迟 / 正确性

小建议：
- 从 bustub Lab 3–5（锁、MVCC、查询执行）开始，几乎等于复现了很多 90 年代经典论文的现代版本。
- 遇到并发 bug 先用 thread sanitizer + valgrind 调试。
- 想测性能用 ycsb / benchbase / tpch-dbgen。
- 记录实验用 wandb 或 tensorboard（loss 换成 latency / throughput）。
- 2025–2026 年最火的复现方向：learned components（索引/优化/调度）+ disaggregated storage（计算存储分离）。

在操作系统（OS）领域，读论文并通过写代码复现是深入理解内核机制、并发、虚拟化、文件系统、调度等核心概念的最有效方式之一。相比 AI/ML，OS 论文的复现工程量通常更大（涉及底层汇编、硬件交互、并发 bug、崩溃恢复等），但一旦跑通，对系统级编程的理解会产生质的飞跃。

### 一般读哪些论文来复现？（分阶段推荐，2025–2026视角）

大多数学生/研究者不会从头复现所有论文，而是分阶段、有针对性地选，优先选择有清晰伪代码或已有开源实现可对比的经典/现代论文。

#### 1. 入门 / 打基础阶段（强烈推荐先复现这些，周期 2–8 周）
这些是教学经典，几乎所有 OS 课程都会涉及，复现后能快速建立对内核的整体认知。

- Xv6 相关（MIT 6.S081 / 6.828 核心）
  - xv6 本身就是对 Unix V6 的现代重写（RISC-V / x86 版）
  - 配套论文/书：xv6: a simple, Unix-like teaching operating system（免费 PDF，常年更新）
  - 复现目标：从零实现进程、trap、系统调用、页面表、文件系统、锁等（分 lab 逐步加）

- 经典论文（常被学生扩展 xv6 复现）
  - The Design and Implementation of the 4.4BSD Operating System（部分章节）
  - The Slab Allocator: An Object-Caching Kernel Memory Allocator (1994)
  - Exokernel: An Operating System Architecture for Application-level Resource Management (1995)
  - Lottery Scheduling: Flexible Proportional-Share Resource Management (1994)

#### 2. 中级 / 现代教学与工业经典阶段（2020年后高影响力）
这些论文算法/设计有清晰描述，很多有开源参考实现。

- 文件系统 / 存储
  - The Log-Structured File System (Rosenblum & Ousterhout, 1992) → LSM-Tree 基础
  - A Fast File System for UNIX (McKusick et al., 1984) → FFS / UFS
  - The Design of the UNIX Operating System (Bach) 中的 inode / buffer cache

- 虚拟内存 / 页面替换
  - The Working Set Model for Program Behavior (Denning, 1968)
  - Clock-Pro: An Effective Low-Overhead Replacement Algorithm (2004)

- 调度与并发
  - Completely Fair Scheduler (Linux CFS, 2007 相关论文)
  - CFS: Completely Fair Scheduler (2007, Ingo Molnar)

- 现代教学 OS 项目论文
  - Umbra / HyPer 系列（查询编译、morsel-driven parallelism）
  - DuckDB 相关论文（向量化执行、columnar storage）

#### 3. 高级 / 2024–2026 前沿热点（OSDI / SOSP / EuroSys / ASPLOS / HotOS）
这些难度大，但复现价值高，常用于研究生/面试/研究。

- Learned Systems：Learned Index Structures (Kraska et al., 2018) → 扩展到 OS 中的 learned page replacement / prefetcher
- Disaggregated / CXL Memory：Toleo / CXL-PIM 相关（ASPLOS 2025 多篇）
- Quantum OS：QNodeOS (Nature 2025) – 量子网络节点 OS 架构
- Guardrails / Learned OS Policies (HotOS 2025)
- Persistent Memory：PMem-aware file systems / allocators

最常用的一站式起步路径（2026 年主流）：
1. fork xv6-riscv（https://github.com/mit-pdos/xv6-riscv）
2. 先完整跑通所有 lab（MIT 6.S081 有公开 lab 文档）
3. 选一篇感兴趣的论文（如 CFS、Lottery Scheduling、LogFS），在 xv6 上实现对应模块
4. 测试：用 stress tests / custom benchmarks / QEMU 观察性能 / 正确性
5. 对比：与原 xv6 或 Linux 对应实现对比（e.g. strace、perf）

小建议：
- 先在 xv6 上实现 Lottery Scheduler 或 MLFQ（经典调度论文），工程量适中，容易看到效果
- 并发 bug 用 QEMU + gdb + thread sanitizer 调试
- 性能测试用 lmbench / sysbench / fio / 自写 workload
- 想测崩溃恢复，先实现简单 WAL（参考 ARIES 伪代码）
- 记录实验用 markdown + graphs（latency / throughput / fairness）
