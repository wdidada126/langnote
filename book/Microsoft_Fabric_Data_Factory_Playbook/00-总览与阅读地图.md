## 3. ADF → Fabric Data Factory 谱系梳理（头号辨析义务，有据转述）

- **产品谱系** ⚠️（据 compare 官方页 ✅ F2 与 ADF introduction ✅ A1 转述）：Fabric Data Factory
  不是新造引擎，而是 Azure Data Factory 的「SaaS 化重定位」——管道/活动/连接器/Copy 语义继承自
  ADF，但剥离了集成运行时（IR）自助管理面、SSIS 与映射数据流等 Azure 专属能力，改按 Fabric 容量
  （CU）计费、原生落 OneLake。迁移与并存双路径由官方 migrate-planning ✅ F10 /
  upgrade-planning ✅ F11 两页分别承接。
- **作者谱系（本书独有的一手证据）** ✅：作者 @@AUTHOR@@ 先于 2022 年在 Apress 出版
  《Introduction to Azure Data Factory》（Crossref 实抓：ISBN 9781484286111/9781484286128，
  publisher Apress，year 2022，作者姓寄存 `@@AUTHSUR@@`）；本书（Packt）为其同一作者从 **ADF**
  到 **Fabric Data Factory** 的续作——**作者个人书目线恰好踩在产品谱系线上**，这是本册区别于
  泛 Fabric 入门册（#218/#221）的最强定位信号：本册默认读者「懂 ADF 或需要 ETL 编排纵深」，
  而非从 Fabric 全景讲起。⚠️ 同姓同人判定基于封面署名 + Crossref 姓寄存双重合，未获出版社页
  作者 bio 一手（403），留人工终裁位。
- **与 Synapse 线的关系** ⚠️：Synapse Pipeline 是 ADF 的第三种承载（#217/#219 波内登记），
  Fabric DF 是第四种；本册不展开 Synapse 专用面（波内兄弟规则，只登记不链）。

## 6. 实测纪律与 🔧 类比实验总表（本机，非 Fabric 平台行为）

Fabric/Data Factory 为云 SaaS，**本机不可实测**（无租户、不起容器、零新装）：机制全部 ⚠️ 转述 +
✅ URL。ETL 概念用本机 **DuckDB 1.5.5（pip 已装）/ SQLite 3.45.3（python 内置）** 实测 🔧，
脚本与输出落盘 `D:\develops\tmp\dbwave_w9_fdfab\`（exp_out.txt，repo 零构建产物）：

| # | 实验 | 真实输出（实抓） | 类比对象 → 落点章 |
| --- | --- | --- | --- |
| E1 | CSV→表→`COPY ... PARTITION_BY` 分区 Parquet（Copy job 落地类比；含 glob×read 交叉连接计数虚高的自纠：6/3/3→修正 2/1/1） | 目录 `order_date=2024-01-05/…` 三分区，金额 200.50/45.25/300.00 | Copy Job 分区落地/Hive 式路径 → 03 章 |
| E2 | `ATTACH` 第二库 + 跨 catalog `CREATE TABLE AS SELECT`（OneLake 统一存储类比） | landing 库收到 amount>100 两行（Acme 120.5 / Gamma 300.0） | 跨数据移动/统一命名空间 → 06 章 |
| E3 | `MERGE INTO` 维表 upsert 两轮（增量装载水位线类比） | 首轮 3 行；次轮 Delta 插入、Acme 更新，4 行终态 | 增量 Copy/查找活动模式 → 07 章 |
| E4 | SQLite 库 `ATTACH (TYPE SQLITE)` 读取 + 过滤导出 Parquet（连接器类比） | click 2/buy 1；buy.parquet 450 字节 | 异构源连接器/副本直读 → 03 章 |
| E5 | `COPY (SELECT 聚合) TO CSV`（数据流转换类比） | 三行日聚合 CSV 实文 | 无代码转换/映射数据流 → 04 章 |

结论一律标注「**非 Fabric/Data Factory 平台行为**」；DuckDB 单机无编排、无 CU 计费，数字不可换算。
