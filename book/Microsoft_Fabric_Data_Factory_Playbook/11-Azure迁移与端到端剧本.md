## 11.2 迁移决策树（Playbook 的「一页裁决」⚠️ 编者综合 F2/F10/F11）

```
存量 ADF 资产
 ├─ 强依赖 SSIS IR / 自托管 IR 特殊网络形态？
 │    ├─ 是 → 留 ADF（F11 升级路线），FDF 只接新管道（双轨，01 章 1.5 判读）
 │    └─ 否 ↓
 ├─ 组织已购/将购 Fabric 容量，且数据目标形态 = OneLake/湖仓？
 │    ├─ 是 → 迁 FDF（F10 规划页流程），按 11.4 波次推进
 │    └─ 否 → 缓迁：新管道 FDF、存量冻结，季度复评
 └─ 依赖映射数据流等能力面？ → 查 ✅ F2 现行对比表定「可迁/改造迁/不迁」三档
```

- 语言翻译前置件：10.1 的「核时→CU」账单翻译表先做，否则财务评审无法立项 ⚠️。
- 双轨期纪律：命名前缀区分承载（`adf-`/`fdf-`）、同名活动差异查 F2 不查记忆（01 章 1.6
  反模式的制度化封堵）。

## 11.3 终章串联：一条「可靠增量管道」的完整剧本（全书十一课复习卷 ⚠️ 编者）

以 F8 教程骨架（copy 起步→转换→编排）为骨，串本册各章处方：

1. **谱系定位**（01）：确认对象语法族与差异表入口（F2）。
2. **管道骨架**（02）：参数签名 `windowStart/windowEnd` + 幂等三件套 + 失败边。
3. **接入评估**（03/06）：先问 shortcut（O2）再问 copy；显式列映射；分区落地（🔧E1 形态）。
4. **转换选型**（04/05）：四级地图（无代码/SQL/笔记本/作业定义）落 silver MERGE（🔧E3 语义）。
5. **增量机制**（07）：水位线六步 + 审计表（`ctrl.watermark`，含 run_id 列）。
6. **部署**（08）：合入前五项清单 + 提升后凭据重绑 + 影子参数测试。
7. **运维**（09）：三层告警接线（运行/数据/时效），五指标进周报。
8. **优化**（10）：关键路径归因 → 10.5 处方表开刀，三字段评审模板过审。

- 异构源接入一幕（03 章 🔧E4 的 SQLite ATTACH 类比）对应剧本第 3 步的连接器矩阵查询；
  统一命名空间一幕（06 章 🔧E2 的 ATTACH 跨库）对应「湖内移动降级为 SQL」的转换段——
  E1–E5 五组实验在此完成闭环回收（全部**非 Fabric 平台行为**，仅概念锚）。
