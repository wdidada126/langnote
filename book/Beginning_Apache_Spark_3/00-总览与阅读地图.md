# Beginning Apache Spark 3 — 总览与阅读地图（书目 #152·波8·精读重构）

> 定位一句话：这是 Apress「Beginning」个人自学入门线里的 Spark 3 册——一个人写的讲义体，三根柱子（DataFrame/Spark SQL、Structured Streaming、MLlib）一根不少、一根都不深，终点停在「ML 生命周期管理」。它回答的问题是「零基础的人如何在一周内把 Spark 的三套 API 都摸一遍」，而不是「生产集群怎么调优」。
>

## 五、🔧 本机实验清单（全部为 DuckDB/SQLite **概念类比**，非本书 Spark 引擎行为）

环境：Python 3.13.2 · DuckDB 1.5.5（Python 客户端）· SQLite 3.45.3（内置）。脚本与输出：`D:\develops\tmp\dbwave_w8_bspark3\`（repo 零产物）。Spark 本机**不可装**（沿用波6 #215 实测结论，本波不重试）→ Spark 侧一律转述 ⚠️ + spark.apache.org 官方文档（引用 URL 已逐条 curl 验证；其中 structured-streaming-programming-guide 路径本次 404，已按验证结果绕行，见各章）。

| 组 | 类比对象（本册章） | 实测要点 | 落点章文件 |
| --- | --- | --- | --- |
| E1 | Catalyst 物理算子树（Ch4） | DuckDB EXPLAIN 把 join+filter+agg 规划成 SEQ_SCAN→HASH_JOIN→HASH_GROUP_BY 算子树，20 万行×97 客户 join 聚合 9.7ms | `04` |
| E2 | UDF 是优化器黑箱（Ch4） | 同谓词原生表达式 14.0ms vs Python UDF 逐行 1468.7ms（200 万行，**约 105 倍**），且计划无下推收益 | `04` |
| E3 | 微批 trigger 重算模型（Ch6） | SQLite 每 2 万行为一个 trigger：全表重算 4.3→48.9ms 线性增长，增量只算新段恒定 2.8–7.6ms | `06` |
| E4 | shuffle 聚合代价（Ch5） | SQLite 对 20 万行无索引 group-by：Sorter 排序聚合 44.0ms；DuckDB 同数据哈希聚合 1.4ms（PERFECT_HASH_GROUP_BY） | `05` |
| E5 | 分区裁剪+谓词下推（Ch3） | 3 分区 parquet（Hive 目录 `part=0/1/2`）：`where part=1` 命中 10 万行/7.9ms；EXPLAIN 显示 File Filters (part=1) 且 Scanning Files: 1/3 | `03` |

红线声明：以上数字只证明「关系引擎对同类问题的机制长相」，**不可**外推为 Spark 数值；Spark 的 AQE/Catalyst/Tungsten 具体行为一律 ⚠️ 转述官方文档。

## 最新演进与工业实践

**从 Spark 3.2（本书写作时最新）到 2026**：

- Spark 主线：3.3（2022，pip 依赖分发、ANSI 默认）、3.4（2023，Variant 类型入 Iceberg 生态）、3.5（2023 尾，MLlib 宣布进入维护模式、Query Commerce…以官方 release notes 为准 ⚠️）；**4.0（2025，基于 Scala 2.13/3 双编译、Spark Connect GA、ANSI 默认全面化）**——官方源：https://spark.apache.org/news/（✅ curl 200）、4.0 API 文档 https://spark.apache.org/docs/4.0.0/api/python/index.html（✅ curl 200）。本册教的 3.2 时代 API 面在 4.0 下绝大部分仍有效；RDD 线、DStream 线按官方通告属逐步退场 ⚠️。
- Spark SQL 文档锚点（各章引用均已验证 200）：https://spark.apache.org/docs/latest/sql-programming-guide.html、https://spark.apache.org/docs/latest/sql-ref-functions-builtin.html。注意：https://spark.apache.org/docs/latest/structured-streaming-programming-guide/index.html 本次 curl 为 **404** ⚠️，流处理改以 https://spark.apache.org/docs/latest/streaming-programming-guide.html（✅ 200，DStream 旧册仍在线）+ latest 文档主页为锚。
- ML 线：MLlib 之外的行业重心已移向 MLflow（https://mlflow.org/docs/latest/ ✅ 200）与特征平台；Delta Lake 文档 https://docs.delta.io/latest/index.html（✅ 200）承接本册 Ch7/9 的「流式落地/模型化数据」话题。
- 入门册替代读物建议（2024–2026）：官方编程指南 + 盘上 [../Spark_The_Definitive_Guide/00-总览与阅读地图.md](../Spark_The_Definitive_Guide/00-总览与阅读地图.md)（Spark 3.x 权威面），本册价值在「最短路径建三支柱心智」，不在追版本。
