## 3.1 程序家族全景（管理员分工图）

| 类别 | 成员 | 一句话职责 |
| --- | --- | --- |
| 服务器 | mysqld / mysqld_safe | 守护进程本体；safe 包装器负责自动重拉（书时代仍讲，现由 systemd 替代 ⚠️） |
| 交互客户端 | mysql / mysqladmin | REPL 与"脚本化健康检查"（ping/status/flush-processlist） |
| 导出导入 | mysqldump / mysqlpump / mysqlimport / SELECT…OUTFILE / LOAD DATA | 逻辑备份与批量装载两族（详见 [05-数据库管理.md](05-数据库管理.md)） |
| 检查维护 | mysqlcheck（表检查）/ mysqlshow / mysqldelta ⚠️ | 对象级巡检 |
| 认证辅助 | mysql_config_editor（登录路径）/ mysql_ssl_rsa_setup | 免密连接与 TLS 证书自举 |
| 新栈 | MySQL Shell（mysqlsh，X DevAPI/JS/Python）/ MySQL Router / MySQL InnoDB Cluster 成员 | 8.0 引入的"现代三件套" |
| 日志侧 | 错误日志 / 慢查询日志 / general log / binlog 查看（mysqlbinlog） | 事后可追溯性的全部来源（联动 [15-故障排除.md](15-故障排除.md)） |

- 通用命令行约定：`--defaults-file/--defaults-extra-file`、`-h -P -u -p`、SSL 段参数；
  所有程序共读 option 文件（✅ option-files 页），`--help --verbose` 看生效值。
- ⚠️ 书中细节（如 mysql_convert_audit、mysql_upgrade_* 类旧工具名单）未逐一实证，登记为缺口，
  以手册 programs 列表为准。

## 3.2 客户端工具选型的任务映射

1. **每日备份**：mysqldump（`--single-transaction` 对 InnoDB 一致性快照；`--routines/--triggers` 显式开关）→ 5 章实操。
2. **备份也要并行**：mysqlpump 多线程导出（8.0 时代新品，书内作为 mysqldump 对照 ⚠️）。
3. **看结构**：mysqlshow / SHOW CREATE TABLE 优先于任何 GUI（复制/排障时以服务器为准，不信缓存）。
4. **免密自动化**：mysql_config_editor 写 `~/.mylogin.cnf` 登录路径； cron 脚本禁裸写 -p 明文（安全线联动 11 章）。
5. **事件回放**：mysqlbinlog 解析 binlog（`--read-from-remote-server` 远程拉取）——PITR 的时间机器（5/15 章复用）。

## 3.2a 高频命令速查（本章代码包的任务化重写，⚠️ 语法为手册通用形态）

```bash
# 服务与健康
mysqld --verbose --help | less          # 看 option 解析与生效路径
mysqladmin --login-path=admin ping status variables

# 备份/导出族（05 章展开一致性语义）
mysqldump --single-transaction --routines --triggers --all-databases > full.sql
mysqlpump --default-parallelism=4 --all-databases > pump.sql
mysqlimport --local --fields-terminated-by='\t' db tbl.csv
SELECT ... INTO OUTFILE '/safe/dir/x.tsv';   # FILE 权限+secure_file_priv（11 章）

# binlog 时间机器
mysqlbinlog --start-datetime='2026-09-27 10:00:00' \
            --stop-datetime='2026-09-27 10:15:00' binlog.000042 | mysql -u root -p

# 凭据与 TLS
mysql_config_editor set --login-path=admin --host=localhost --user=root -p
mysql_ssl_rsa_setup --datadir=/data/mysql   # 8.0.28+ 首启自动生成，旧书流程 ⚠️

# 结构速览
mysqlshow -i -u root -p            # 库表统计一览
mysql -e "SHOW CREATE TABLE t\G"   # 以服务器为准的结构真相
```

- 速查只列"任务→命令"映射；每个开关的边界语义放对应深读章（05 备份、08 复制、11 安全、15 排错）。

## 核心概念速览（中英对照）

- **mysqld** — 服务器守护进程：一个进程多线程模型（1 连接 1 线程 + 后台线程组）。
- **mysqladmin** — 管理客户端：ping/status/variables/processlist 的脚本化入口。
- **mysqldump** — 逻辑导出器：产 DDL+DML 文本流；一致性靠单事务快照（见 05 章 🔧）。
- **mysqlpump** — 并行导出器：8.0 新工具，多默认数据库线程导出 ⚠️。
- **mysqlbinlog** — 二进制日志阅读器：事件转文本、远程拉取、按时间点截取。
- **login path** — 登录路径：mysql_config_editor 存的混淆凭据组，避免命令行泄密。
- **SET PERSIST** — 持久化动态变量：写入 datadir/mysqld-auto.cnf，重启不丢。
- **general query log** — 常规日志：全语句流水，性能毒药，仅诊断短时开（⚠️）。
- **MySQL Shell** — mysqlsh：SQL/X DevAPI 多语言 shell，AdminAPI 驱动 InnoDB Cluster（10 章）。
- **option 加载顺序** — option-file order：决定"生效配置"的第一因，排错先问它（✅ option-files 页）。
- **--single-transaction** — 单事务导出：对 InnoDB 不锁表的一致性备份开关（5 章主题）。

## 最新演进与工业实践

- **工具线存活度 2026**（⚠️ 转述 + ✅ 手册版本页书目）：mysqldump/mysqlbinlog/mysqladmin 仍是标配；
  mysqlpump 长期未获投入，社区更多用 **MySQL Shell `util.dumpInstances()`（并行、直写对象存储）** 与
  **XtraBackup/其 8.0 后继（物理热备）** 接管备份工具位——本书"dump 双雄"叙事已被重写。
- **systemd 完全替代 mysqld_safe**；`Restart=`、`NotifyAccess` 与现代 unit 模板成为运维基线（⚠️）。
- **TLS 自举默认化**：8.0.28+/8.4 起首启自动生成证书，mysql_ssl_rsa_setup 的历史使命结束（⚠️ 演进见 [11-安全.md](11-安全.md)）。
- **云托管分流**：RDS/aurora 类托管实例限制 mysqld 启动参数与文件工具面（OUTFILE/LOAD DATA LOCAL 默认关），
  本书工具清单在云语境需按各服务"参数组/权限"重映射（⚠️）。
- **取证留痕**：✅ https://endoflife.date/mysql（200）给出 8.0/8.4/9.x 全部日期轴；本章被引 4 个镜像页
  （programs/mysqld/mysqlpump/option-files/server 组）均 2026-09-27 curl 200 实测。
