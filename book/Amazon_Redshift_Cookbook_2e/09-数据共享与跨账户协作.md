## 1. 本章定位（推定）

Redshift 的"出口"配方：**Datashare 把本仓 schema/表授权给别的集群/账户/Region，消费方以挂载外部数据库的方式直读**——零拷贝、按用量计费方付费、数据不出仓。再加两条延伸：AWS Data Exchange（商品化）与 AaaS（分析即服务的多租户形态）。

## 3. 深潜一：Datashare ≠ 拷贝 ≠ 联邦（三件套辨析，⚠️ 转述）

| 通道 | 数据移动 | 计算 | 新鲜度 | 适用 |
|---|---|---|---|---|
| Datashare | 零拷贝（同 Region 内元数据+授权平面） | 消费方集群算力读生产方存储 | 实时 | 组织内/受控伙伴共享 |
| UNLOAD+COPY | 全量/增量物理搬 | 各自 | 批 | 跨云/离线交割（→04 §5） |
| 联邦查询 | 不搬但拉行 | 生产库算力被借用 | 实时 | RDS 小表（→06） |
共享的账单翻转（消费方付查询、生产方付共享费+存储）与配额（并发共享对象数上限）是落地两痛点（⚠️ 数字不编，以官方配额页为准，入口 ✅ mgmt/welcome）。

## 4. 深潜二：共享与权限的合流（⚠️ 转述）

- 仓内 RBAC 与共享正交：先管好库内（→02），共享出口只授视图/脱敏层（→ TDG 08 的动态脱敏话题，✅ 盘上文件）；
- Serverless↔预置互通、跨 Region 限制（⚠️）；
- 与 Ch10 Lake Formation、Ch11 DataZone 的关系：Datashare=仓对仓的**点**，LF=湖权限的**面**，DataZone=目录与产品化的**集市**——三层各司其职（本章重构口径 ⚠️）。

## 5. 🔧 类比：挂载即"只读外部库"的抽象（本机真实跑过）

DuckDB 1.5.5 双库挂载实验（attach_demo.py，输出 attach_demo_out.txt，存 tmp/dbwave_w5_rscb/）——**非 Redshift 行为，方言已按 DuckDB 改写**：producer 库建 `orders_shared` 5 行（SUM=138.24）；consumer 库 `ATTACH '...producer.duckdb' AS prod (READ_ONLY)` 后：①`SELECT count(*), sum(amt) FROM prod.main.orders_shared` 读通返回 (5, 138.24)；②对 prod 内表 INSERT 被拒（InvalidInputError: Cannot execute statement of type "INSERT" on database "prod"）；③consumer 本库照常可写。——`CREATE DATABASE ... FROM DATASHARE` 的"挂载+只读+命名空间隔离"三特征全部在场（Redshift 真语义 ⚠️ 转述，不冒充实测）。

## 6. 常见坑与最佳实践（⚠️ 转述+✅ 锚）

1. 共享对象数配额先查后设计（百级 schema×千级表=触顶）（⚠️；✅ 配额总页入口 mgmt/welcome 同址 200）；
2. 消费端把 datashare 库当缓存层反复全表扫=生产方存储 IO 账单共享双方都疼——上 MV/汇总（→05/07）；
3. 撤权生效边界：消费方在跑查询不受撤，新查询拒——发布窗口要约定（⚠️）；
4. 跨账户排障第一坑=IAM 信任+RAM 关联漏配，SQL 侧错误信息误导（⚠️ 工程惯例）；
5. 共享数据的产品化（ADX/DataZone）引入合同与审计面——先治理框架后上架（→11）。

## 核心概念速览（中英对照）

- 数据共享 — datashare：仓对仓零拷贝授权共享原语
- 生产者/消费者 — producer/consumer：共享两端角色，账单翻转主体
- 挂载外部库 — CREATE DATABASE FROM DATASHARE：消费方直读姿势
- RAM 底座 — AWS Resource Access Manager：跨账户资源共享的底层服务
- 跨 Region 共享 — cross-Region datashare：带限制与拷贝语义的延伸（⚠️）
- AaaS — analytics as a service：一仓多租户的产品化共享
- ADX — AWS Data Exchange：datashare 商品化市场
- 共享配额 — datashare quotas：对象数/并发上限（数字以官方页为准）
- 只读语义 — read-only mount：消费端不可写承诺
- 脱敏层共享 — share via views/DDM：只出视图不出裸表
- 撤权窗口 — revoke semantics：在跑不受/新查即拒
- 三层权限观 — datashare/LF/DataZone：点/面/集市分工（本章重构）
