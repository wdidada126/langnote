# 10 · AI 时代的数据底座与演进展望

> 主题章（⚠️ 推定归属本书"前瞻"部分；亦为全系列 fabric 编线的收口）。本章双向讲：AI 如何补上 fabric 欠了五年的账（打标/归一/生成），以及 fabric 如何成为企业 AI 的数据前置件（检索/特征/评测/Agent）。截至 2026 的演进线以 ✅ 可证 URL + ⚠️ 转述标注；登记态兄弟目录义务见文末。

## 10.1 fabric 欠账清单与 AI 的补位

回看全书各章标注的 ⚠️ 软肋，AI 逐项补位（⚠️ 机制推定，效果均待 PoC）：

| 欠账 | 出处 | AI 补位 | 剩余风险 |
|---|---|---|---|
| 业务标签人工成本 | 3.6-2、9.5-1 | LLM 列级语义推断+词表对齐 | 幻觉标签污染图谱→置信度分级必配（3.6-4） |
| 实体归一长尾 | 3.1、9.5-1 | 嵌入相似+LLM 仲裁成对候选 | 高敏域仍需人审，A2 档为主 |
| 冷启动死循环 | 5.6 | schema 指纹+内容嵌入破冷 | 新域词表外概念仍盲区 |
| 管道手写 | 02.4 末行 | 自然语言→管道骨架（A2） | 生成质量依赖 9.4 类验收 |
| 冲突裁决停摆 | 9.5-3 | LLM 整理证据链供人裁决 | **不可全自动**（5.5 A3 上界论断维持） |

一句话：**AI 把 fabric 从"需要咨询公司养五年的元数据工程"降为"需要工程纪律维护的自动回路"**——这解释了 01.2 第三线索为何是决定性的，也解释了为何 2019 年概念只能叫 PPT。

## 10.2 企业 AI 的 fabric 前置：四类新消费者

```
RAG 检索     需要: 文档/表混合索引+权限过滤(8.2 标签直接复用)
特征工程     需要: 跨源组装+新鲜度 SLA(4.2 物化开关的 ML 版)
评测/微调集  需要: 可追溯快照+删除闭包(8.5 被遗忘权延伸)
Agent 工具面  需要: 语义发现 API+契约交付(6.4 L6 的机器消费者版)
```

要点（⚠️ 立场）：四类消费者的共同点是**都不与人商量、直接消费元数据平面**——目录第一次有了"机器用户"，元数据质量从体验问题升格为正确性问题（错标签→错检索→错答案，无人工兜底）。这是"AI 倒逼 fabric 做实"的最硬论证。

## 10.3 LLM 进治理回路的两条安全带

10.1 的自动打标与 05 章回路结合时（即"AI active metadata"），5.2 四元组加两条：
- **动作域封闭**：AI 只允许产生"候选事件"（tag_candidate/merge_candidate），晋级为事实需门限或人审（A1/A2 纪律，5.5）。
- **溯源随行**：每个 AI 生成元数据带 prompt/模型版本/证据指针，8.6-2 决议可证率扩展到元数据本身（"这条标签谁说的"成为审计问题）。

## 10.5 与同名平台的分岔预言

6.6 辨析的演化分支（⚠️ 推定，可证伪）：
- 若开放 catalog+主动元数据平面成为标准 → **fabric 范式赢语义层，平台产品赢运行时**：Microsoft Fabric 类一体化平台（盘上实链 [../Fundamentals_of_Microsoft_Fabric/00-总览与阅读地图.md](../Fundamentals_of_Microsoft_Fabric/00-总览与阅读地图.md)）吸收 fabric 术语作营销，独立 fabric 平台收缩为治理/目录组件。

两分支共同的不变量：**L3 元数据模型的开放度决定谁是宿主谁是租户**（9.2-3 退出成本条款的宏观版）。

## 10.7 给不同读者的最后一页话术

- 对 CDO：fabric 是唯一不需要推倒重建就能收敛数据成本的路线（01.2），但组织账（9.5-3）不付，平台钱就是白扔。
- 对平台工程：先接 5.2 护栏再谈自动化率；G3/G5 告诉你算得起，没告诉你错得起。
- 对数据工程师：你的新岗位描述里会多出"元数据回路运维"（L3 SLA+影子执行例行化）。
- 对算法团队：把 fabric 当你最干净的检索与特征地基用（10.2），别被它的治理话术劝退。
- 对 skeptic：接受本目录 01.5 的反论检验——若无主动回路与 AI 打标，fabric 不成立；这正是鉴别真伪的快刀。

## 10.8 用例解剖：权限过滤的检索问答

问："给我华东区上季度大客户收入榜单"。链路：Agent 解析→L4 词表对齐（"大客户"=domain 标签+分层口径）→L2 联邦取数→8.2 标签策略过滤行（提权者不可见区）→决议记录落 8.6 审计。
故障树演示：无 L4 则"大客户"三义并陈（金额/行业/等级）；无 8.2 标签锚定则权限过滤靠提示词——**提示词是请求不是策略**（⚠️ 本章最锋利的一句）；无 8.6-2 则整条链不可证，合规一票否决。
结论：10.2 四类机器消费者共用此故障树，差别只在出口形态（榜单/特征/评测样本/工具调用）。

## 10.9 特征平台与 fabric 的边界

特征平台（系列在盘 （特征库专题目录本库暂无，登记为后续编线对象））管"训练-服务 skew 与在线低延迟"；fabric 管"跨源组装与语义/权限"。合流点：特征定义作为一等 BusinessTerm 进 L4、特征物化点受 4.7 策略与 8.2 标签约束。反模式：特征平台自建平行词表=语义层的封建割据（03.5 冲突显式化的组织版）。
