## 6. 全书核心论点（主题地图版提炼）

1. **架构的钟摆回到"总纲"**：数仓→大数据→湖仓每一步都以"新存储"解决上一代问题，同时制造集成债；fabric 把解法从"再建一层存储"换成"**用元数据把既有层缝起来**"（01/02）。
2. **元数据是货币，知识图谱是账本**：技术/业务/运营元数据三本账进 graph，语义发现与自动集成才有地基（03）。
3. **访问逻辑化、搬运最小化**：统一语义层+虚拟化让"就近消费"替代"复制消费"，湖仓仍是物化底座（04/06）。
4. **主动元数据=架构的自动驾驶**：从"记录发生了什么"到"驱动该发生的事"（推荐、编排、策略下发），这是 fabric 区别于老 EAI/ESB 的地方（05/08）。
5. **与 mesh 不是竞争是正交**：fabric 供语义与自动化，mesh 供组织与产品化；成熟组织两者同用（07）。
6. **AI 是把 fabric 从 PPT 拉进生产的那只手**：LLM 让元数据打标/血缘推断/自然语言取数第一次划算（10）。
