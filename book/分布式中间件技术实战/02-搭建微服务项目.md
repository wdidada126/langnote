## 核心精讲

（以下为教学性梳理，代码均**教学示意，不参与构建**。）

### 2.1 Spring Boot 为什么是本书基座

- **核心思想**：约定优于配置（Convention over Configuration）+ 自动装配（Auto-configuration）。
  不用再手写一大堆 `web.xml`、Spring XML，引入 `spring-boot-starter-web` 就能直接跑一个 HTTP 服务。
- **起步依赖（starter）**：把一组相关依赖打包成一个「BOM 式」入口，例如
  `spring-boot-starter-data-redis`（第 3 章）、`spring-boot-starter-amqp`（第 5 章）。
- **自动配置**：Spring Boot 按 classpath 上已有的 jar 推断你要用什么，自动注入 `RedisTemplate`、
  `RabbitTemplate` 等 Bean（第 3、5 章会具体看到）。

```java
// 教学示意，不参与构建：本章 Hello World
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String hello() {
        return "Hello, 分布式中间件!";
    }
}

@SpringBootApplication   // = @Configuration + @EnableAutoConfiguration + @ComponentScan
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### 2.2 搭建规范与流程（教学示意）

- **分层规范**（书中强调的可复用骨架）：

```text
# 教学示意，不参与构建：推荐包结构
com.example.demo
 ├── controller   // 对外接口
 ├── service      // 业务逻辑
 ├── dao / mapper // 数据访问
 ├── config       // 中间件 Bean 配置（第 3/5/8 章在此扩展）
 ├── model / entity
 └── DemoApplication.java
```

- **流程**：Spring Initializr（或 IDE 向导）选依赖 → 生成 `pom.xml` → 写 `application.yml` →
  写启动类 → 写 Controller 验证。后续每章只需往 `config`/`service` 里加中间件相关代码。

### 2.3 总结

脚手架章不复杂，但**不能跳过**——第 3–9 章的所有 `@Autowired RedisTemplate`、
`@RabbitListener` 都依赖本章打好的 Spring 容器与自动配置基础。

## 版本演进

- **本书基于 Spring Boot 2.x（Java 8）**；到 2026 年主线已演进到 **Spring Boot 3.x（要求 Java 17+）**。
- **最大的破坏性变更是命名空间迁移**：`javax.persistence` / `javax.annotation` 等
  全部改为 `jakarta.persistence` / `jakarta.annotation`（Jakarta EE 9+）。
  本书代码若原样迁移到 Boot 3，需要改包名与部分依赖。
- **GraalVM 原生镜像（AOT）**：Boot 3 支持把 Spring 应用编译成原生可执行文件，启动毫秒级、内存更低；
  本书 2020 年尚未普及。
- **Java 基线**：Boot 2 支持 Java 8/11；Boot 3 最低 Java 17。本书示例若想 2026 年跑，建议升 Java 17。

## 常见误区与本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | 「Spring Boot 就是 Spring」 | Boot 是在 Spring 之上的**约定与自动配置层**，不是替代 Spring |
| 2 | 「starter 越多越好」 | 多余的 starter 会拖慢启动、引入无用自动配置；按需引入 |
| 3 | 「自动配置是黑魔法，不用懂」 | 排错时必须懂 `@ConditionalOnClass` 等条件装配，否则配置不生效时无从下手 |
| 4 | 「Hello World 跑通=环境 OK」 | 真正验证环境是跑通一个中间件连接（见第 3 章整合 Redis） |
| 5 | 🔧 本书锁定 Spring Boot 2.x / Java 8 | 2026 年应升 Boot 3 / Java 17；注意 `javax`→`jakarta` 改名 |
| 6 | 🔧 本书用本地裸装中间件 | 2026 年建议 Docker Compose 或云托管（见 00-实验工具链） |
| 7 | 🔧 本书未提 Actuator/可观测 | 生产环境健康检查、Metrics、Tracing 是 2026 必备，本书脚手架章未覆盖 |
