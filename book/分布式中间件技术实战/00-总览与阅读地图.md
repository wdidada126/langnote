## 本书没覆盖的缺口

> 以下缺口要在读本书时心里有数——它们不是本书的错（定位就是入门实战），但 2026 年做生产必须补。

1. **ZooKeeper 没有独立章节**。书脊与简介都宣传「统一协调管理中间件 ZooKeeper」，
   但真实目录里 ZooKeeper **只在第 7 章 7.4 作为「基于 ZooKeeper 实现分布式锁」的一种实现出现**，
   没有讲 ZK 的数据模型（znode）、Watcher 机制、ACL、集群与 ZAB、配置中心、命名服务、Master 选举等。
   想系统学 ZK，需另读 `book/ZooKeeper-分布式过程协同技术详解.md`。
2. **没有独立的「性能与高可用」章**。本书高可用多停留在「主从/集群概念」与单章项目优化，
   缺系统的容量规划、限流熔断、降级、可观测性（ tracing/metrics/logging ）专章。
3. **缺消息中间件的横向对比**。只讲 RabbitMQ，没有 Kafka / RocketMQ / Pulsar 的选型对照；
   2026 年「RabbitMQ vs Kafka」已是必答题。本仓库已有 `book/Kafka权威指南.md`、
   `book/RocketMQ技术内幕.md`、`book/ApachePulsar原理解析与应用.md` 可补。
4. **缺分布式事务专章**。第 7 章的锁与第 4 章抢红包涉及并发一致性，但没讲
   TCC / Saga / 消息表 / Seata 等分布式事务方案。
5. **Spring Boot 版本锁定在 2.x**。2026 年 Spring Boot 3 已切换 `javax` → `jakarta` 命名空间、
   要求 Java 17+、GraalVM 原生镜像；本书代码若原样迁移需改造包名与依赖。
6. **Windows 下跑 Redis / 中间件**的本地教学路径，到 2026 年已被 Docker Compose +
   云托管（阿里云/腾讯云/AWS 的托管 Redis、RabbitMQ、ZK）大幅替代；本地裸装仅适合学习。

## 实验工具链

- **JDK**：本书基于 Java 8；2026 年建议 Java 17（Spring Boot 3 最低要求）。
- **构建**：Maven（本书默认）；Gradle 亦可。
- **框架基座**：Spring Boot 2.x（本书）/ 3.x（2026 推荐，注意 `jakarta.*` 命名空间迁移）。
- **中间件本地部署**：Docker Compose 拉取 `redis` / `rabbitmq` / `zookeeper` 镜像（替代本书 Windows 裸装）；
  或直接使用云厂商托管实例。
- **压测**：Apache JMeter（本书第 4 章即用 JMeter 压抢红包）。
- **客户端**：Spring Data Redis（底层 Lettuce / Jedis）、Spring AMQP（RabbitMQ Java Client）、
  Curator（ZooKeeper）、Redisson。
