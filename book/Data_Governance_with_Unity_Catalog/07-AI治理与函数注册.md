## 2. UC Functions：函数注册与治理（§1）

Unity Catalog 支持将自定义函数注册为 **governed securables**，
使函数与表、视图一样受统一权限管理。

✅ 关键事实（docs.databricks.com/en/data-governance/unity-catalog）：
- 函数存储在 catalog.schema 下，与表同级
- 支持 SQL UDF、Python UDF、Pandas UDF
- 函数受 UC USAGE 特权控制——未授权用户无法调用
- 函数可标记分类标签（如 `data_classification`）

```sql
-- 注册 SQL 函数
CREATE FUNCTION analytics.finance.calculate_tax(
    amount DECIMAL(12,2), region STRING
) RETURNS DECIMAL(12,2)
RETURN CASE
    WHEN region = 'US' THEN amount * 0.08
    WHEN region = 'EU' THEN amount * 0.20
    ELSE amount * 0.10
END;

-- 注册 Python 函数
CREATE FUNCTION analytics.ml.normalize_text(text STRING)
RETURNS STRING
LANGUAGE PYTHON AS $$
    import re
    return re.sub(r'\s+', ' ', text.strip().lower())
$$;

-- 授予函数使用权限
GRANT USAGE ON FUNCTION analytics.finance.calculate_tax TO `analyst-group`;
```

⚠️ 转述：函数注册使 UC 成为"数据+代码"的统一治理平台——
不仅管数据（表/视图），还管计算逻辑（函数）。

## 3. 模型注册与治理（§2）

UC 将 ML 模型纳入治理体系，模型成为一等公民的 securable：

| 模型治理维度 | UC 实现 |
| --- | --- |
| 注册 | CREATE MODEL / MLflow 注册 |
| 版本管理 | 模型版本（v1, v2, ...） |
| 访问控制 | APPLY CATALOG / CREATE MODEL / USE MODEL |
| 血缘 | 训练数据 → 模型 → 推理结果 |
| 存储 | Volume（模型权重/配置） |

```sql
-- 查看已注册模型
SHOW MODELS IN analytics.ml;

-- 授予模型使用权限
GRANT USE MODEL ON MODEL analytics.ml.fraud_detector TO `ml-team`;

-- 模型血缘（自动追踪）
-- 训练数据: analytics.fraud.training_data → 模型: analytics.ml.fraud_detector
```

⚠️ 转述：模型治理的关键价值在于**可追溯性**——
当模型产生错误预测时，可回溯到训练数据和训练代码。

## 4. AI Gateway：LLM 调用的治理层（§3）

AI Gateway 是 Databricks 2025 年推出的 LLM 治理组件（✅ docs.databricks.com）。
核心能力：速率限制（按用户/组限制 LLM API 调用频率）、审计日志（记录每次 LLM
调用）、成本追踪（按团队追踪 LLM 使用成本）、模型路由（自动选择模型）、
安全过滤（拦截含敏感信息的 prompt）、缓存（相同 prompt 响应复用）。

✅ AI Gateway 与 UC 的集成：每个 LLM 端点注册为 UC 的 Endpoint securable，
访问需要 USE 特权，审计日志写入 UC 系统表。

## 5. AI 资产的访问控制（§4）

AI 资产的权限设计遵循 UC 的统一模型：Function → USAGE（按团队授予）、
Model → USE MODEL / CREATE MODEL（科学家 CREATE，业务 USE）、
Endpoint → USE（应用服务主体调用）、Volume → READ/WRITE（模型权重读写分离）。

⚠️ AI 治理的核心挑战是**速度与安全的平衡**——数据科学家需要快速实验，
但生产部署需要严格治理。UC 通过 catalog/schema 分层实现环境隔离。

## 5. 🔧 SQLite 模拟函数注册表（§4）

> ⚠️ **非本书引擎/平台行为**：以下演示用 Python sqlite3（3.45.3）模拟
> Unity Catalog 的函数注册与权限管理，仅做机制类比。

```python
import sqlite3

con = sqlite3.connect(":memory:")

# 模拟 UC 函数注册表
con.execute("""CREATE TABLE uc_functions (
    catalog TEXT, schema TEXT, func_name TEXT,
    language TEXT, owner TEXT)""")
con.execute("""CREATE TABLE uc_privileges (
    principal TEXT, object_name TEXT, privilege TEXT)""")
con.execute("""CREATE TABLE group_membership (
    user_email TEXT, group_name TEXT)""")

# 注册函数
con.execute("""INSERT INTO uc_functions VALUES
    ('analytics', 'finance', 'calculate_tax', 'SQL', 'alice@co.com'),
    ('analytics', 'ml', 'normalize_text', 'PYTHON', 'bob@co.com')""")

# 授予权限
con.execute("""INSERT INTO uc_privileges VALUES
    ('analyst-group', 'analytics.finance.calculate_tax', 'USAGE'),
    ('ml-team', 'analytics.ml.normalize_text', 'USAGE')""")
con.execute("""INSERT INTO group_membership VALUES
    ('alice@co.com', 'analyst-group'),
    ('carol@co.com', 'analyst-group')""")

# 查询：某用户可使用的函数
result = con.execute("""
    SELECT f.func_name, f.language, p.privilege
    FROM uc_functions f
    JOIN uc_privileges p ON
        f.catalog || '.' || f.schema || '.' || f.func_name = p.object_name
    JOIN group_membership g ON p.principal = g.group_name
    WHERE g.user_email = 'alice@co.com'
""").fetchall()
print(f"alice 可用函数: {result}")
# [('calculate_tax', 'SQL', 'USAGE')]

con.close()
```

## 最新演进与工业实践

- **2025 Q2**：AI Gateway 正式发布，支持 OpenAI / Anthropic / Cohere 等
  主流 LLM 提供商的统一治理入口。✅ docs.databricks.com AI Gateway 文档。
- **UC Functions 增强**：支持 Python 包依赖管理（函数级 pip 依赖声明），
  使函数注册更加自包含。⚠️ 转述自 Databricks 博客。
- **向量搜索集成**：UC 现支持注册向量索引（用于 RAG 场景），
  向量表作为 Volume 或 Table 的一种特殊形式受 UC 治理。
- **对标**：AWS SageMaker Model Registry + Bedrock Gateway 是 AWS 侧的
  对应方案；Azure ML Model Catalog + API Management 是 Azure 侧方案。
- **趋势**：AI 治理从"模型注册"扩展到"全链路治理"——数据→训练→部署→
  推理→监控的完整生命周期均需可追溯。
