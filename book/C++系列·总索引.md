## 分层阅读路线

1. 入门：《C++语言程序设计》（郑莉）→《C++ Primer》第 5 版（习题答案见 `cppprime.md`）→《C++语言程序设计》（阚道宏）
2. 现代 C++ 基础：《C++之旅（第 3 版）》→《C++ 语言导学（第 2 版）》→《C++ 实战》（吴咏炜）→《现代 C++ 教程》（GitHub 电子书）→《现代 C++ 语言核心特性解析》→《深入应用 C++11》
3. 进阶：Effective 系列（《Effective Modern C++》《More Effective C++》）→《深度探索 C++ 对象模型》→《C++ 标准库》→《C++ 新经典》系列（含对象模型/设计模式）→《C++ 模板元编程》
4. 专题：模板元编程（《C++20 模板元编程》《C++ 模板元编程实战》《深入实践 C++ 模板编程》）、性能（《提高 C++ 性能的编程技术》）、调试（《C++ 代码调试的艺术》《高效 C/C++ 调试》）、大规模工程（《大规模 C++ 程序设计》《C++ API 设计》）、服务器与库（《C++ 服务器开发精髓》《poco》《wxWidgets 跨平台程序开发》）、设计模式（《C++20 设计模式》《C++ 新经典：设计模式》）
5. 演化与视野：《C++ 语言的设计与演化》（D&E）→《在拥挤和变化的世界中茁壮成长：C++ 2006–2020》（HOPL-IV 论文中译）

## 易混淆条目辨析

- 阚道宏《C++语言程序设计》两个版次：`C++语言程序设计.md`（ISBN 9787302421047）与 `C++语言程序设计_阚道宏.md`（ISBN 9787302475620）为同作者不同版次，不是重复笔记，暂分立。
- 郑莉 与 阚道宏：`C++语言程序设计5.md` 是郑莉/董渊的第 5 版教材，与前两条同名不同书。
- 《C++之旅（第 3 版）》与《C++ 语言导学（第 2 版）》：同为 Stroustrup "A Tour of C++" 的中译，分属第 3 版（电子工业）与第 2 版（机械工业，王刚译），不是重复。
- 《C++语言的设计与演化》两个中文版：科学出版社 2012 与人民邮电出版社 2020 均为裘宗燕译，书目表中两版并列，引用时注意区分。
- 《C++新经典》系列：`C++新经典.md` 为主体卷；`C++新经典_设计模式.md` 为系列分卷，各自独立成册。
- 《深入应用C++11》与《C++实战》：前者偏 C++11 语言特性与开源工程案例（祁宇），后者为极客时间课程实体化（吴咏炜），内容不重叠。
- poco.md：正文是 VDM 出版社用维基百科内容拼凑的出版物，与 POCO 库官方文档不可等同，仅作线索保留。
