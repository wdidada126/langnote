## 章定位

全书最"系统编程"的一章：在 **1000 Genomes Project（BDG 试点）** 场景里，把 **BAM 比对文件**切成 RDD、抽取基因型字段、做群体统计与简单变异检测。它示范 Spark 的边界能力——**自定义分片输入格式**（对齐第 6 章 XML 切分手法）。样本文件 ✅ 仓库 README：`ftp://ftp.ncbi.nlm.nih.gov/1000genomes/ftp/phase3/data/HG00103/alignment/HG00103.mapped.ILLUMINA.bwa.GBR.low_coverage.20120522.bam`（phase3 冻结数据集；NCBI ftp 2026 年仍服务但建议走 https 镜像 ⚠️）。

## 10.1 生物背景速写（书给计算读者的最小集）

- DNA 读段（read）→ 参考基因组比对（BWA）→ SAM/BAM：每行=一段读段的定位+碱基+质量；BGZF=带块索引的 gzip，可 **按 64KB 块边界并行解压** ⚠️✅（htsjdk 文档线 https://samtools.github.io/hts-specs/SAMv1.pdf ⚠️ PDF 存在性未本机验证，标准公开文档）。
- 关键概念：位点（position）、碱基质量（BQ）、基因型似然（GL/AD）、SNP、杂合=两倍体两碱基不同 ⚠️。

## 10.2 自定义 BamFileRDD：本章技术核心

1. 切分策略：按 BGZF **块**（magic 字节 + CRC 校验定位块首）而非字节偏移切分区，每分区自带完整块流——"格式感知的 InputFormat"是通用模式（Parquet/ORC 同理）⚠️。
2. executor 端用 htsjdk `SAMFileReader` 逐块读记录（record iterator），**绝不**把整文件送 driver ⚠️。
3. 过滤与投影：只留比对成功（`!read.getReadUnmappedFlag()`）、目标染色体、高质量碱基；产出 RDD[(position, (base, qual))] 类结构 ⚠️。
4. 书中教训（2e 强调）⚠️：Java 序列化开销——htsjdk 对象重，map 里尽量**即刻投影成轻量元组**再进 shuffle；与 [../bigdata/05-Spark性能优化.md](../bigdata/05-Spark性能优化.md) 的序列化/内存段呼应。

## 10.3 位点统计与朴素变异检测

- 位点列联：按位置 group（`pairRDDOf(position → counts)` + `reduceByKey`）得每碱基深度/质量分布——先 `filter` 低质量碱基防假阳性 ⚠️。
- 杂合检测朴素贝叶斯：P(genotype|counts) ∝ 先验（群体等位频率）× 二项/多项似然（错误率→观测碱基概率）；书中手推三基因型（AA/AB/BB）后验 ⚠️。
- 群体扩展：多样本 BAM 联算等位频率（AD/GQ 汇总），演示"分布式 join 位点×样本"的矩阵式数据布局 ⚠️。
- 🔧 列联表语义类比（非 Spark）：以 SQLite 3.45.3 复核 `GROUP BY pos` 后 `SUM(CASE WHEN q>=20 THEN 1 ELSE 0 END)` 的深度统计写法（与 [02 章](02-用Scala和Spark进行数据分析.md) 🔧 的 FILTER 聚合同族：条件计数=分组聚合的 CASE 形态）；Spark 侧 `countWhen`/`sum(when(...))` 同语义 ⚠️。
- 精度纪律：深度直方图（30x 目标）、GC 偏倚——书中把"数据质量画像"置于算法之前 ⚠️。

## 逐节精读扩展（重构笔记）

1. **BAM 文件解剖**（书给的最小结构 ⚠️）：
   - 头：magic `BAM\1` + 文本头 + 参考序列/读段组元数据；
   - 体：BGZF 块序列，每块若干 `BAMRecord`（CIGAR、MAPQ、bin/pos、碱基+质量、tag）；
   - 尾：块偏移索引（bai）——**随机访问靠它，并行切分不靠它**（书中选择自研切分的原因：多文件多任务场景下索引维护成本大于收益）⚠️。
2. **BGZF 块切分算法**（本章最值得默写的 20 行 ⚠️✅ htsjdk 语义）：
   - 在任意偏移起解，`GZIP` 头 12 字节 + 压缩数据 + **8 字节额外区**（含 BC 块大小字段）；
   - 向前找下一个块首（magic 匹配）→ 得"从本偏移可解的第一个完整记录"；
   - 分区起点=文件长度/并行度的均匀网格 → 各分区跳到自己第一个合法块 → 读到下一分区起点之后的首条完整记录为止——"重叠读一条"规则防漏读 ⚠️。
3. **htsjdk 上 executor 的依赖打包**：jar-with-dependencies 进 `spark-submit --jars`；书演示 `SAMRecordIterator` 在 `mapPartitions` 的局部实例化（不可序列化对象的标准逃生门，与 [03 章 SAX 同法](03-音乐推荐与Audioscrobbler数据集.md)）⚠️。
4. **位点矩阵构造细节** ⚠️：
   - read 展开成 (chrom, pos, base, qual) 记录流（`flatMap` CIGAR 步进，M 前进/D 跳读）；
   - 丢弃 I/N/S 处理——书简化声明：indel 与剪接不在本章范围；
   - `reduceByKey` 得每 (pos,base) 计数 → 再聚成列联矩阵（每行=位点，四碱基计数）。
5. **质量分数三件套**：Phred Q=-10log₁₀P(错误)；MAPQ（比对质量）过滤假定位点；碱基质量参与似然——**错误率进贝叶斯公式**的方式书用一张小表讲透 ⚠️。
6. **杂合后验手推**（等位先验 1/4,1/2,1/4 的 HWE 起步）：P(数据|AB) ∝ 组合数 (n_A!n_B!/n!)·p^{n_A}(1-p)^{n_B}... 加错误率卷积——代码里是多项分布 × 测序混淆矩阵两因子 ⚠️。
7. **群体频率估计**：多样本 BAM 的 AD 汇总 → 每样本基因型后验→等位频率 p̂ 的 EM 一步法——书以此说明"分布式=同任务乘样本数"，BDG 的 2504 样本在当年要数小时 ⚠️✅ 数据源即 1000G phase3。
8. **🔧 条件计数复述（非 Spark）**：SQLite `SUM(CASE WHEN q>=20 THEN 1 ELSE 0 END)` 即"高质量碱基深度"的 SQL 形态——RDD `filter+count` 与 DF `sum(when())` 三写法同语义（[02 章 §2.3 🔧](02-用Scala和Spark进行数据分析.md) 的同族证据）。
9. **工程反思（书末自评 ⚠️）**：本章"自研 BamFileRDD"在 2019 已被 Hadoop-BAM/Cloudbio 库吸收；写它的理由是教学可见性，生产请直接用现成 InputFormat——诚实条款延续到 11 章。

## 本章自问自答

- **Q1：为什么不 `sc.textFile` 逐行读 SAM？** A：BGZF 解块成本与行解析量级相同，BAM 才是分发形态；且 SAM 文本 5~10 倍体积——读压缩二进制是生信第一纪律 ⚠️。
- **Q2：重叠读一条会不会重复计数？** A：不会——每分区"从自己起点、到邻居起点内首记录前"恰好覆盖全集一次；漏/重是切分代码唯二 bug 类型 ⚠️。
- **Q3：CIGAR 为什么难？** A：它编码 M/I/D/N/S 的行进规则，pos 推进必须按算子走；错一位=全 read 坐标漂移——本章代码最易翻车处 ⚠️。
- **Q4：MAPQ=0 的多映射读段？** A：过滤是默认立场（书用），mappability 图/期望最大化处理是进阶方案 ⚠️。
- **Q5：本章模式还能用在哪？** A：任何"带块压缩的二进制大文件"：CRAM、HTS、NetCDF、Parquet 前史记录格式——格式感知切分思想通用 ✅（同 [06 章 §6.1](06-潜在语义分析与维基百科.md)）。
- **Q6：现代复现最短路径？** A：GATK/Picard 读记录 + Spark DF 聚合（或直接 Hail），半天搭完——本章代码价值在"知道库里发生了什么" ⚠️。

## 书中写法 ↔ 现代写法速查（迁移表）

| 书中 | 现代 | 状态 |
|---|---|---|
| 自研 BGZF 切分 BamFileRDD | Hadoop-BAM/GATK 现成 InputFormat | 库化 ⚠️ |
| htsjdk executor 逐记录解析 | 仍是事实标准解析器 | ✅ 存活 |
| RDD (pos, base, qual) 流 | DF(chrom,pos,ref,alt,AD) + Parquet | 列存化 ⚠️ |
| 手写三基因型贝叶斯 | GATK HaplotypeCaller（组装+PairHMM） | 代际差 ⚠️ |
| `reduceByKey` 位点计数 | `groupBy(pos).agg(...)` DF | 迁移 ✅ |
| phase3 BAM 直下 | 云托管公开表/桶 | 入口换代 ⚠️ |
| 群体频率 EM 一步 | Hail `annotate_freq` | 库化 ✅ hail.is（已验 200） |

**BGZF 块结构默写卡**：gzip magic `1f 8b` + FEXTRA 子头（SI2="BC"，SDATA=块长−1）→ 压缩流 → CRC；任意偏移向后扫 magic、解 BC 自洽即锚定块首——"块自带长度字段"是并行随机读的物理前提 ⚠️✅（SAM/BAM 规范公开文档，§10.1 声明其 PDF 链接未本机验证）。

**质量值速记**：Q20=1% 错误率、Q30=0.1%；书中双门=碱基 Q≥20 且 MAPQ≥20 ⚠️。

**数量级体检法**：单样本（GBR）SNP 检出应在数百万级（⚠️ 教学量级记忆，以 1000G phase3 发布统计为准）——超出先查过滤线，再谈算法精度；"先对账后优化"贯穿本章。

## 核心概念速览（中英对照）

1. **BAM/SAM** — binary/sequence alignment map：读段比对的标准容器格式。
2. **BGZF** — blocked gzip：可随机并行解压的块式压缩。
3. **读段** — read：测序仪产出的短序列片段。
4. **比对** — alignment：read 到参考坐标的定位。
5. **碱基质量** — base quality (BQ)：每碱基错误概率的对数刻度。
6. **SNP** — single nucleotide polymorphism：单碱基多态位点。
7. **基因型似然** — genotype likelihood (GL/AD)：观测支持各基因型的计数/概率。
8. **杂合** — heterozygous：二倍体两等位不同。
9. **深度** — coverage/depth：位点被覆盖的平均次数。
10. **自定义分片** — custom partitioning：按格式边界切 RDD 分区的技艺。
11. **htsjdk** — htsjdk：Java 基因组格式解析库（executor 侧）。
12. **1000 Genomes** — 千人基因组计划：phase3 公共样本数据源。
