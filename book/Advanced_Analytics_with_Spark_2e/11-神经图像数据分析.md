## 章定位

收尾章＝**Python 阵营的 Spark**：用 **Thunder**（基于 PySpark 的神经影像分析库）对斑马鱼钙成像时间序列（体素×时间矩阵）做滤波、z-score、聚类找"响应同相位"的神经元。2e 把 1e 的 Scala 版重写为 PySpark+Thunder ⚠️（目录题名即含 PySpark ✅，sohu 公告实抓）。代码目录 `ch11-neuro` ✅；数据 ✅ 仓库 README：`github.com/thunder-project/thunder/tree/v0.4.1/python/thunder/utils/data/fish/tif-stack`（AFNI 格式 NII/TIF；GitHub API 实测 thunder 仓库仍在、未归档 ✅ `archived=false`，最后成式版本停在 0.4.x/2016 代 ⚠️）。

## 11.1 为什么是神经影像

- 数据形态：4D 阵列（x,y,z,时间），单样本可达数十 GB；"全脑体素级时间序列统计"=天然的行独立并行 ⚠️。
- 分析原语：按体素算均值/方差/滤波（空间平滑、高通去漂移）、时间相关、聚类/分类体素群——与基因组"位点独立"同构（对照 [10-基因数据分析.md](10-基因数据分析.md)）⚠️。
- Thunder 定位（书时代）：`ThunderContext`/`Series`/`Image` 三类 RDD 封装 + scikit/numpy 生态复用——"Python 科学栈 × Spark"的早期答案 ⚠️。

## 11.2 本章流水线（书叙述骨架）

1. 读 TIF 栈 → 体素时间序列 RDD（每元素=一维 numpy 数组）⚠️。
2. 预处理：`filter(highpass)` 去低频漂移、`standardize()` 全脑 z-score（按时间维）⚠️。
3. 降维选区：按能量/方差阈值裁掉背景体素，只留活跃区（数据驱动 ROI）⚠️。
4. 相似与聚类：时间序列相关矩阵抽样 + KMeans（MLlib）或 k-medoids；"同相位神经元群"解释 ⚠️。
5. 出图：把簇标签投回坐标，matplotlib 上色——Spark 只做计算，可视化回单机 ⚠️。
6. 🔧 类比实测（非 Spark）：体素 z-score=`(x-mean)/std` 与聚类前的标准化，用 DuckDB 在 5 点 1 维例子上验证 K-means 一轮 Lloyd 后中心迁移（[05 章 §5.2 🔧](05-K均值聚类网络异常检测.md) 同组数字：0 簇 μ=1.25、1 簇 μ=6.5）；"按值分组统计"（Spark `groupBy().agg(avg,stddev)`）在播放表实测含 NULL 组语义（[03 章 §3.1 🔧](03-音乐推荐与Audioscrobbler数据集.md)）。

## 逐节精读扩展（重构笔记）

1. **数据形态拆解**（斑马鱼全脑钙成像 ⚠️）：
   - 样本=~550×370×64(z)×T 的 4D 堆栈，单个体素的时间序列长度数百帧；
   - 格式：AFNI 的 +orig/BRIK 对（head+brick）或 TIF 栈——书选 TIF 栈简化；
   - 生物学信号：神经元激活→荧光升→"哪批体素同步亮"=功能连接雏形 ⚠️。
2. **Thunder 抽象层速记**（书时代 API ⚠️）：`td.Series(array)`=体素视图（每元素一维时间序列）、`td.Image(rdd)`=帧视图（每元素 3D 体）、`.to RDD` 桥回 Spark——双向视角切换是 Thunder 的设计灵魂（仓库 v0.4.1 文档已古 ⚠️，✅ GitHub API 探活 archived=false）。
3. **预处理算子的数学** ⚠️：
   - 高通：每序列减滑动均值/一阶差分——去呼吸与漂移伪低频；
   - z-score：(x−μ_脑)/σ_脑 全局标准化 → 跨样本可比；
   - 方差筛选：保留 top 方差体素（背景噪声方差≈1，激活区≫）——"降维=选演员" ⚠️。
4. **相关矩阵的规模陷阱**：V 个候选体素的 V×V 相关=O(V²d)；书给两条出路：抽样体素（几千）或先 KMeans 再算**簇间**相关——"聚类当降维器"的次序论 ⚠️。
5. **KMeans 在本章的角色**：对标准化后的时间序列分群（k=8~16 相位族），簇心曲线人肉核对（刺激锁定/自发/运动噪声）——评估仍是"看图说话"，神经影像的现实 ⚠️。
6. **numpy 在 executor 里** ⚠️：scipy.signal 滤波在 `mapPartitions` 内逐序列跑——Python 函数式负载走 Spark 的"每分区一次 import"模式（`reducer` 侧大对象避免）；2019 无 pandas UDF，这段手工优化正是后来 Arrow 批式接管的痛点 ⚠️。
7. **可视化回单机的分工论**（书立场 ⚠️）：Spark 只产 (x,y,z,cluster_id) 表；AFNI/surf 工具做脑投影上色——"分布式算、单机画"到 2026 仍成立（绘图瓶颈是显存不是 CPU 核数）。
8. **🔧 类比补充（非 Spark）**：体素 z-score = `SELECT (x-avg)/stddev OVER ...`——[08 章 🔧 D2](08-出租车轨迹时空分析.md) 的窗口聚合族；"方差 top-K 选体素"=`ROW_NUMBER() OVER (ORDER BY var DESC)`+过滤，实测语义与 Spark `row_number` 同构（DuckDB 原生支持，Spark 需窗口 API ⚠️）。

## 本章自问自答

- **Q1：Thunder 死了为什么还读？** A：读的是"科学数组 × RDD"接口设计（Series/Image 双向视图）——同类抽象后来在 xarray/Hail MatrixTable 复活 ⚠️。
- **Q2：为什么不用 GPU？** A：2019 语境无解；2026 现实：体素滤波是 elementwise——MONAI/cuDNN 路径更快，Spark 退居调度 ⚠️。
- **Q3：Spark 在这里比单机 numpy 强在哪？** A：只在样本批量处理（数百鱼×全脑堆栈）横规模；单样本全脑在 512GB 单机 numpy 可跑——书的诚实前提 ⚠️。
- **Q4：本章的"分布式程度"？** A：滤波/标准化=分区内，z-score 全局统计=一次 reduce，聚类=MLlib——教科书式的三板斧复用 ⚠️。
- **Q5：换成人类 fMRI 要改什么？** A：4D 不变但多 session 配准/空间归一化前置；体素数十万→千万级，方差筛选更关键 ⚠️。

## 书中写法 ↔ 现代写法速查（迁移表）

| 书中 | 现代 | 状态 |
|---|---|---|
| Thunder `td.Series/td.Image` | xarray/Zarr+Dask；或 pandas API on Spark | 抽象换代 ⚠️✅（pyspark.pandas 已验 200） |
| RDD[numpy] mapPartitions 逐序列滤波 | `applyInPandas` Arrow 批通道 | 序列化税消除 ✅ |
| 手工 reduce 求全脑 μ,σ | DF `describe()` / 窗口均值 | 迁移 ✅ |
| mllib KMeans（RDD 向量簇） | `spark.ml` KMeans；中小规模 sklearn 单机 | 视规模 ⚠️ |
| 相关矩阵抽样近似 | 同法存活；GPU 全矩阵为第二解 | 两代并行 ⚠️ |
| matplotlib 回单机出图 | 同左 + napari 生态 | 分工不变 ✅ |

**4D 搬运预算三档**（书量级转述 ⚠️）：单样本全脑堆栈→单机 numpy 可容；百样本批处理→Spark 横规模；千样本+多通道→先降采样（体素合并/时间分箱）再上集群——"先减维再分布式"是本域铁律。

**功能聚类实验五步**：①高通滤波；②top-5% 方差体素筛选；③k=12 KMeans；④簇心曲线人工命名（刺激锁定/运动相关/自发）；⑤留 20% 体素做外推验证——完整复刻本章 demo，且可平移到任何传感器阵列数据 ⚠️。

**写作史注脚**：本章为 2e 重构重点之一（目录题名即含 PySpark ✅ sohu 公告实抓）；2019→2026 的对照证明本书"Python 通道"押注正确——只是载体从 Thunder 换成了官方 pandas API ⚠️。

## 本章金句与误读提醒

1. 金句（书意转述 ⚠️）："这一章证明 Spark 能走出互联网数据，也证明它不该独自留下。"
2. 误读一：为了单样本上集群——单机 numpy 装得下的 4D 堆栈，上 Spark 只增延迟与序列化税；先算体积再谈架构 ⚠️。
3. 误读二：把 Thunder 当领域标准——领域标准始终是 FSL/AFNI/SPM；书用的是"Python 科学栈接入 Spark 的桥"，桥已拆、过河方法仍在 ⚠️。
4. 误读三：簇=神经元类型——k-means 给出的是同相位群，不是细胞分类学；命名靠人工审曲线 ⚠️。
5. 一个可带走的原则：体素级的"分组统计+全局标准化+抽样相似"三件套，在任何传感器阵列上同构复用——这才是本章的传家宝 ⚠️。

## 核心概念速览（中英对照）

1. **体素** — voxel：三维像素，影像最小单元。
2. **4D 阵列** — 4-D array：x,y,z,time 的钙成像数据形态。
3. **z-score 标准化** — standardization：全脑尺度归一，跨样本可比。
4. **高通滤波** — high-pass filter：去低频漂移/伪影。
5. **ROI** — region of interest：方差/能量驱动的活跃区裁剪。
6. **同相位聚类** — co-activated clustering：时间相关系数群分神经元。
7. **PySpark** — PySpark：Spark 的 Python API。
8. **Thunder** — Thunder：PySpark 上的神经影像库（书中工具，已停滞 ⚠️）。
9. **AFNI** — AFNI：神经影像分析软件生态（数据格式源）。
10. **mapPartitions** — mapPartitions：按分区批处理，摊薄 Python 序列化税。
11. **Series/Image 抽象** — Thunder 两类 RDD 封装（时间序列视图/空间视图）。
12. **可视化回单机** — client-side viz：Spark 出结果、matplotlib 出图。
