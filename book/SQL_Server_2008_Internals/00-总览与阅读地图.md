# 《Microsoft SQL Server 2008 Internals》目录版笔记——总览与阅读地图

> 本目录是基于公开资料（Library of Congress 书目记录、Crossref API、Microsoft Learn 官方文档、出版社/社区书目页）的**精读重构**，不是原书文本的复制或转抄。
> SQL Server 本机不可安装、不可实测：引擎机制一律「转述 + ⚠️」；通用机制（页/区/B+树/WAL/列存批处理/一致性审计）用本机 SQLite 3.45.3(python 内置) / SQLite CLI 3.50.6 / DuckDB 1.5.5 做 🔧 类比实验，**每一处都标注"非本书 SQL Server 引擎行为，仅通用机制演示"**。
> ⚠️ 特别说明：SQL Server 2008 的存储引擎行为（8KB 页、extent/区、VLF、锁层级、恢复模型）无法本机复现，本目录全部为权威二手转述 + ✅ Learn 文档为现代准绳；凡"实测"数字均来自 SQLite/DuckDB 的类比实验，不代表 SQL Server。

## 八、🔧 类比实验总表（本机真实跑过；全部标注"非本书 SQL Server 引擎行为"）
