# 概念专篇：大 O 记号与算法分析

> 跨章节核心概念（第 13、21 章）。本文把本书的"增长量级"直觉讲严谨，并给出常用复杂度速查与 Python 标准库对应。

## 一、大 O 是什么

大 O 描述输入规模 n 增长时，运行时间（或空间）的**渐进上界**，只看主导项、忽略常数：O(n²+3n+5)=O(n²)。它回答"数据翻倍，时间翻几倍"。

| 记号 | 含义 | 典型操作 |
|---|---|---|
| O(1) | 常数 | 字典查键、列表下标 |
| O(log n) | 对数 | 二分查找、`bisect`、堆插入 |
| O(n) | 线性 | 遍历列表、线性搜索 |
| O(n log n) | 线性对数 | `sorted`/Timsort、归并/堆排序 |
| O(n²) | 平方 | 双重循环、选择/冒泡排序 |
| O(2ⁿ) | 指数 | 裸斐波那契、子集枚举 |

## 二、本书相关案例

- **线性搜索**（无序列表）：O(n)。逐个比较。
- **二分搜索**（有序）：O(log n)。每次砍半，标准库 `bisect`。
- **选择排序**：O(n²)。嵌套循环。
- **归并排序**：O(n log n)。分治，见 [21-算法分析.md](../21-算法分析.md)。
- **哈希表（dict/set）**：平均 O(1)，最坏 O(n)（哈希碰撞恶化，🔧 Python 3.4+ 用 SipHash 随机化缓解）。

## 三、Python 标准库的复杂度保障

```python
import bisect, heapq

xs = [1, 3, 5, 7]
bisect.insort(xs, 4)          # O(n) 插入但定位 O(log n)
heapq.heappush(xs, 0)         # O(log n)
```

- `list.append`/`pop()`：均摊 O(1)；`list.insert(0, x)`：O(n)。
- `dict`/`set` 成员判断：平均 O(1)。
- `sorted`：O(n log n)，稳定。

## 四、空间复杂度

同一算法常可时间换空间。递归斐波那契空间 O(n)（调用栈），迭代 O(1)。归并排序需 O(n) 辅助空间。

## 五、版本演进

- 3.0+：Timsort 作为默认排序（稳定、对部分有序数据接近 O(n)）。
- 3.11（2022）：整体解释器提速，但**渐进复杂度不变**——优化常量不改变大 O。

## 六、经典文献

- Cormen 等《算法导论》（CLRS）：大 O 形式定义、归并/快速排序证明（🔧 以版次为准）。
- Knuth《计算机程序设计艺术》：算法分析的严格起点（🔧 以版次为准）。

## 七、常见误区

| 误区 | 正确 |
|---|---|
| "常数不重要" | 小 n 时常数主导；大 O 看趋势 |
| "sorted 很慢" | Timsort O(n log n)，手写多更慢 |
| 哈希表永远 O(1) | 平均 O(1)，最坏退化 |
