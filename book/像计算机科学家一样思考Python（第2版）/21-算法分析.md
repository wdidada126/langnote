## 核心精讲

教学示意，不参与构建：

```python
import bisect, random

xs = sorted(random.sample(range(1000), 50))
# 二分查找插入位置：O(log n)
idx = bisect.bisect_left(xs, 42)
print(idx, xs[idx] if idx < len(xs) else None)

# 归并排序（分治，O(n log n)）
def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    return merge(left, right)

def merge(p, q):
    out, i, j = [], 0, 0
    while i < len(p) and j < len(q):
        if p[i] <= q[j]:
            out.append(p[i]); i += 1
        else:
            out.append(q[j]); j += 1
    return out + p[i:] + q[j:]
```

## 版本演进

- 3.0+：内置 `sorted`/`list.sort` 用 Timsort（O(n log n)，稳定），不必手写排序。
- 3.10（2021）：`bisect` 模块稳定；`heapq` 提供堆操作（O(log n) 插入）。
- 字典/集合哈希见 [11-字典.md](11-字典.md)，平均 O(1)。
