## 核心精讲

教学示意，不参与构建：

```python
from pathlib import Path

p = Path("notes.txt")
p.write_text("line1\nline2\n", encoding="utf-8")   # 写（自动创建/覆盖）

# 逐行读（上下文管理器自动关文件）
with p.open(encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())

# 一次性读全部
text = p.read_text(encoding="utf-8")
print(text)
```

## 版本演进

- 3.0：`open` 文本模式返回 `str`（Unicode），二进制模式返回 `bytes`；编码概念核心化。
- 3.4（2014）：`pathlib` 引入（PEP 428），现代路径操作首选，替代 `os.path` 拼接。
- 3.6（2016）：`Path.read_text`/`write_text`/`read_bytes` 便捷方法。
- `with` 自 2.5（PEP 343）即有，但今天必用。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `open` 后手动 `close` | 异常时漏关 | `with open(...) as f:` |
| `os.path.join` 拼路径 | 跨平台丑 | `Path(...).joinpath(...)` |
| 不写 `encoding` | 平台默认编码坑 | `encoding="utf-8"` |
| `write` 不自动换行 | 易漏 `\n` | 显式加 `\n` 或 `print(..., file=f)` |
