## 核心精讲

教学示意，不参与构建：

```python
xs = [1, 2, 3]
xs.append(4)
xs.insert(0, 0)
print(xs)                     # [0, 1, 2, 3, 4]
last = xs.pop()
print(last, xs)               # 4 [0, 1, 2, 3]

# 别名：两个名字指向同一对象
a = [1, 2]
b = a                         # 别名，不是拷贝
b[0] = 99
print(a)                      # [99, 2]  ← a 也变了！

c = a.copy()                  # 浅拷贝
c[0] = 1
print(a, c)                   # [99, 2] [1, 2]
```

## 版本演进

- 3.0：`list` 是真正的对象，方法稳定；`range` 返回惰性序列。
- 3.9（2020）：`list` 合并/重复运算符 `|`、`*` 经 PEP 584 也适用于 `dict`，列表用 `+`/`*`。
- 3.10（2021）：`list[int]` 内置泛型注解（PEP 585），无需 `from typing import List`。

## 经典论文与原始文献

- PEP 585（2019）https://peps.python.org/pep-0585/ 内置泛型 `list[int]` 等。
- PEP 8（2001）https://peps.python.org/pep-0008/ 可变对象风格。

## 近年研究与工业界开源实践（2015–2026）

- 大数据用 `array`（定长同类型）、`numpy.ndarray`（数值）、`collections.deque`（双端队列，O(1) 头插）。
- 不可变序列用 `tuple`（见 [12-元组.md](12-元组.md)）表达"不应被改"的数据（🔧 非同行评审，惯用法）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `=` 当拷贝 | 共享对象 bug | `copy()`/`list(xs)` |
| 遍历中改列表长度 | 跳过元素 | 遍历副本或推导式 |
| 嵌套未提深拷贝 | 一层拷贝不够 | `copy.deepcopy` |
