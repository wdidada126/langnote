## 核心精讲

教学示意，不参与构建：

```python
def factorial(n):
    if n == 0:                 # 基线条件
        return 1
    return n * factorial(n - 1)

print(factorial(5))           # 120

def fib(n):
    if n <= 1:                 # 基线
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(10))                # 55（指数级重复计算，见下节修正）

# 取模判断奇偶
print(7 % 2 == 1)             # True
```

## 近年研究与工业界开源实践（2015–2026）

- `@cache` 记忆化把指数级斐波那契降到线性（🔧 非同行评审，社区惯用法）：

```python
from functools import cache

@cache
def fib(n):
    return n if n <= 1 else fib(n - 1) + fib(n - 2)
```

- 递归深度受 `sys.getrecursionlimit()` 限制（默认 1000），深递归用迭代或 `sys.setrecursionlimit`（谨慎）。

## 常见误区与本书需修正之处
