## 核心精讲

教学示意，不参与构建：

```python
class Point:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

    def __str__(self):                 # print 时调用
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(p)                              # (3, 4)
print(p.x, p.y)                       # 3 4
```

现代可用 `@dataclass` 省掉手写 `__init__`：

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int = 0
    y: int = 0
```

## 版本演进

- 3.7（2018）：`dataclasses`（PEP 557）大幅简化数据类。
- 3.6（2016）：`__init__` 等可用类型注解 `def __init__(self, x: int) -> None`。
- 3.10（2021）：`match` 可对对象做模式匹配（PEP 634），`dataclass` + `match` 配合好。

- `@dataclass(frozen=True)` 做不可变值对象；`pydantic` 做带校验的数据模型（🔧 非同行评审）。
- `attrs` 库是 `dataclasses` 前身/替代，功能更全（🔧 非同行评审）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 手写 `__init__`/`__str__` | 样板多 | `@dataclass` |
| `print` 对象显示内存地址 | 不友好 | 实现 `__str__`/`__repr__` |
| 运行时动态加属性 | 难追踪 | 用 `dataclass`/`slots` |
