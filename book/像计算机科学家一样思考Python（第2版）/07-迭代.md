## 核心精讲

教学示意，不参与构建：

```python
# 并行赋值（无需临时变量）
a, b = 1, 2
a, b = b, a
print(a, b)                  # 2 1

# 牛顿法求平方根
def sqrt_newton(x, eps=1e-10):
    guess = x / 2
    while abs(guess * guess - x) > eps:
        guess = (guess + x / guess) / 2
    return guess

print(sqrt_newton(2))        # 1.41421356...

# for + range
total = 0
for i in range(1, 5):
    total += i
print(total)                  # 10
```

## 版本演进

- 3.0：`range` 返回惰性对象（Python 2 的 `xrange` 行为），不再占内存。
- 3.10（2021）：`math.sqrt` 之外另有 `math.isqrt`（整数平方根，3.8+）。
- 3.11（2022）：循环提速明显（整体解释器提速约 25%）。
