## 核心精讲

教学示意，不参与构建：

```python
# 赋值：名字绑定到值（不是"盒子装值"）
n = 17
print(n, type(n))          # 17 <class 'int'>

# 表达式有值，语句没有
m = n + 1                  # 语句
print(n + 1)              # 表达式，输出 18

# 字符串拼接与重复
s = "abc"
print(s + "d")            # abcd
print(s * 3)              # abcabc

# 现代字符串格式化：f-string（3.6+）
name, age = "Ada", 36
print(f"{name} is {age} years old")

# 运算符优先级
print(2 + 3 * 4)          # 14
print((2 + 3) * 4)        # 20
```

## 版本演进

- 3.6（2016）：f-string（PEP 498）成为首选格式化方式，取代 `%` / `.format()`。
- 3.8（2019）：仅位置参数用 `/` 分隔（PEP 570），函数签名更精确。
- 3.10（2021）：更清晰的错误回溯，SyntaxError 直接指位置（新手友好）。

## 近年研究与工业界开源实践（2015–2026）

- `rich` / `f-string` 调试技巧：`print(f"{x=}")` 输出 `x=42`（3.8+ 的 `=` 自文档化，🔧 非同行评审，社区实践）。
- 类型注解普及：`age: int = 36`，但本章仍从动态类型起步（见 [03-函数.md](03-函数.md)）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `%s`/`str.format()` 拼接 | f-string 更清晰 | `f"{name}: {age}"` |
| 把变量当"容器"讲 | 易误解为别名问题 | 讲"名字→对象"绑定与 mutability |
| 未提 `:=` 海象 | 3.8+ 可在表达式内赋值 | 进阶时用 `while (c := f.read(1))` |
