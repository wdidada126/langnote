## 核心精讲

教学示意，不参与构建：

```python
# 条件表达式
sign = "pos" if x > 0 else "non-pos"

# 列表推导
squares = [n * n for n in range(5)]
print(squares)                 # [0, 1, 4, 9, 16]

# 生成器：惰性产出
def gen(n):
    for i in range(n):
        yield i * i
print(list(gen(5)))            # [0, 1, 4, 9, 16]

# 装饰器
def trace(func):
    def wrapper(*args, **kwargs):
        print("call", func.__name__, args)
        return func(*args, **kwargs)
    return wrapper

@trace
def add(a, b):
    return a + b
```

## 版本演进

- 3.0：列表推导不再泄漏循环变量；生成器表达式稳定。
- 3.3（2013）：`yield from`（PEP 380）委托子生成器。
- 3.8（2019）：海象 `:=`（PEP 572）；仅位置参数 `/`（PEP 570）。
- 3.10（2021）：结构模式匹配 `match`（PEP 634），替代复杂推导分支。
- 3.12（2023）：f-string 形式化（PEP 701）；类型参数语法（PEP 695）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 推导式嵌套过深 | 难读 | 拆成 `for` 或 `filter` |
| 未提海象 `:=` | 表达式内复用 | `while (c := f.read(1))` |
| 未提 `match` | 长 if/elif | `match x:`（3.10+） |
| `reduce` 手写 | 可读性差 | `functools.reduce` 或显式循环 |
