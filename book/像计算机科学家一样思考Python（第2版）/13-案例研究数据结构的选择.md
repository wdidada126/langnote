## 核心精讲

教学示意，不参与构建：

```python
from collections import Counter
import re

text = "apple banana apple cherry banana apple"
words = re.findall(r"\w+", text.lower())
counts = Counter(words)
print(counts.most_common(2))   # [('apple', 3), ('banana', 2)]

# 结构化记录：用 namedtuple/字典
records = [
    {"word": w, "n": n}
    for w, n in counts.items()
]
print(records)
```

## 版本演进

- 原书用 `shelve` 做持久化；今天更常用 `json`（人类可读）、`sqlite3`（查询）、`pickle`（仅可信数据）。
- 3.9（2020）：`zoneinfo` 等标准库完善；`shelve` 仍可用但不推荐新项目。
- 3.11（2022）：`sqlite3` 改进（返回行命名访问）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `shelve` 持久化 | 跨版本不兼容、不安全 | `json`/`sqlite3` |
| 手写频率排序 | 啰嗦 | `Counter.most_common` |
| 没区分"随机访问 vs 查键" | 选型错 | list 随机访问、dict 查键 |
