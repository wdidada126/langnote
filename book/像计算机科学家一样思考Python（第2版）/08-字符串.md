## 核心精讲

教学示意，不参与构建：

```python
s = "Python语言"
print(s[0])                  # P
print(s[-1])                 # 言
print(s[0:6])               # Python（左闭右开）
print(s[::2])               # Pto语（步长）

for ch in s:
    print(ch)

# 不可变：不能 s[0] = 'J'
t = "J" + s[1:]             # 新建字符串
print(t)                    # Jython语言

words = "a,b,c".split(",")
print(words)                # ['a', 'b', 'c']
print("-".join(words))      # a-b-c
```

## 版本演进

- 3.0：文本 `str` 是 Unicode（Python 2 的 `unicode`/`str` 区分已消除，🔧 若你见旧代码 `u"..."` 是 Python 2 写法）。
- 3.6（2016）：f-string（PEP 498）。
- 3.9（2020）：`str.removeprefix`/`removesuffix`（PEP 616），替代手写的 `if s.startswith(...)` 切片。
- 3.12（2023）：f-string 形式化（PEP 701），嵌套/多引号更自由。

## 近年研究与工业界开源实践（2015–2026）

- 文本处理用 `regex` 库（第三方）支持 Unicode 属性；标准库 `re` 够用（🔧 非同行评审）。
- 路径/文本区分：`pathlib.Path` 读文本自动按 UTF-8，见 [14-文件.md](14-文件.md)。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `%`/`.format()` | f-string 更直观 | `f"{s}"` |
| 手动 `s.startswith(x)` 后切片 | 易错 | `s.removeprefix(x)`（3.9+） |
| 忽略编码 | 默认 UTF-8 但文件需显式 | `open(..., encoding="utf-8")` |
