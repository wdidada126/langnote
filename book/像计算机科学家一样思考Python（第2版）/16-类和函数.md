## 核心精讲

教学示意，不参与构建：

```python
class Time:
    def __init__(self, hour=0, minute=0, second=0):
        self.hour = hour
        self.minute = minute
        self.second = second

    def __str__(self):
        return f"{self.hour:02d}:{self.minute:02d}:{self.second:02d}"

    def __add__(self, other):
        # 简化：秒数相加，返回新 Time（纯函数风格）
        s = self.to_seconds() + other.to_seconds()
        return Time(s // 3600, (s % 3600) // 60, s % 60)

    def to_seconds(self):
        return self.hour * 3600 + self.minute * 60 + self.second

print(Time(1, 2, 3) + Time(0, 0, 5))   # 01:02:08
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 手写 `__init__`/`__str__` | 样板 | `@dataclass` |
| 可变默认参数 `def f(t=Time())` | 共享 state | `t=None` 占位 |
| 混用纯函数/修改式无标注 | 调用者困惑 | 命名/文档区分 |
