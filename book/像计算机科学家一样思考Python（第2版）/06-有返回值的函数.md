## 核心精讲

教学示意，不参与构建：

```python
import math

def distance(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    return math.hypot(dx, dy)     # 欧氏距离（替代 sqrt(dx*dx+dy*dy)）

def is_between(x, y, z):
    return x <= y <= z            # 链式比较，Python 特色

def optional_args(n, base=2):
    return int(n, base)

print(distance(0, 0, 3, 4))       # 5.0
print(is_between(1, 2, 3))        # True
print(optional_args("101", 2))    # 5
```

增量开发（incremental development）是本章核心方法论：先写能跑的最小版，再逐步加功能、常打印中间值验证。今天可用 `pytest` 把它固化成测试（见 [20-调试.md](20-调试.md)）。

## 版本演进

- 3.8（2019）：仅位置参数 `/`、关键字仅参数 `*` 让签名更精确（PEP 570）。
- 3.10（2021）：`X | None` 联合返回类型（PEP 604）；`int | None` 替代 `Optional[int]`。

## 近年研究与工业界开源实践（2015–2026）

- `pytest` 把"增量开发的打印自查"升级为可回归断言（🔧 非同行评审，工业界标准）。
- `math.hypot` 支持 N 维（3.8+），比手写 `sqrt(sum(...))` 更稳健。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| `return` 多分支未强调 | 易漏基线 return | 确保每条路径有返回 |
| 用 `sqrt(dx**2+dy**2)` | 可 `math.hypot` | `math.hypot(dx, dy)` |
| 未提 `Optional` 返回 | 现代类型必备 | `def f() -> int | None:` |
