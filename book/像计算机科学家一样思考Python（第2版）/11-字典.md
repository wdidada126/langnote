# 第 11 章 字典（原书 pp.约143–158）

> 字典是哈希映射：键值对、`get`、遍历、作为计数器/累加器、备忘录。原书强调「字典无序」，本目录按 3.7+ 修正为保序。

## 本章地图

| 小节 | 内容 | 结论 |
|---|---|---|
| 11.1 字典即映射 | `key: value` | 键可哈希 |
| 11.2 操作 | `get`/`in`/`del` | O(1) 平均 |
| 11.3 遍历 | `keys`/`values`/`items` | 见下 |
| 11.4 计数器 | `hist[key] = hist.get(key,0)+1` | 可用 `Counter` |
| 11.5 备忘录 | 缓存递归结果 | 见 [05-条件与递归.md](05-条件与递归.md) |
| 11.6 全局变量 | `global` | 慎用 |

## 核心精讲

教学示意，不参与构建：

```python
# 计数器：手写为
hist = {}
for ch in "abracadabra":
    hist[ch] = hist.get(ch, 0) + 1
print(hist)                  # {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}

# 现代等价：collections.Counter
from collections import Counter
print(Counter("abracadabra"))

# 遍历
for k, v in hist.items():
    print(k, v)

# 备忘录缓存斐波那契
from functools import cache
@cache
def fib(n):
    return n if n <= 1 else fib(n - 1) + fib(n - 2)
```

## 版本演进

- 3.7（2018）：**字典保序成为语言规范**（原书反复强调"字典无序"，此结论自 3.7 起过时，🔧 旧代码仍兼容但语义已变）。
- 3.9（2020）：合并 `|`、更新 `|=`（PEP 584）；`dict` 合并更直观。
- 3.7+：`dict`/`set` 插入顺序保留，JSON 序列化顺序可预期。

## 近年研究与工业界开源实践（2015–2026）

- `collections.Counter`/`defaultdict` 替代手写计数/累加（🔧 非同行评审，惯用法）。
- `dataclasses`/`types.MappingProxyType` 做只读映射（3.3+/3.12）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| "字典顺序不确定" | 3.7+ 保序 | 可依赖插入顺序 |
| 手写 `get` 计数 | 啰嗦 | `Counter` / `defaultdict` |
| 未提 `defaultdict` | 易 KeyError | `defaultdict(int)` |
