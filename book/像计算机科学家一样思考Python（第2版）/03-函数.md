## 核心精讲

教学示意，不参与构建：

```python
def print_2x_plus_1(x):        # x 是形参，函数内为局部名
    print(2 * x + 1)

print_2x_plus_1(3)             # 7

def add(a, b):
    return a + b               # 有返回值

result = add(2, 3)
print(result)                  # 5

def no_return():
    pass
print(no_return())             # None
```

栈图（stack diagram）是本书招牌教学法：每次调用造一个「帧」，记录局部变量与指向调用者的链。递归章节 [05-条件与递归.md](05-条件与递归.md) 大量用到。

## 版本演进

- 3.0：`print`/`exec` 变函数，定义函数更一致。
- 3.5（2014）：类型注解 `def add(a: int, b: int) -> int`（PEP 484）。
- 3.8（2019）：仅位置参数 `/`（PEP 570）；关键字仅参数 `*`。
- 3.10（2021）：`X | Y` 联合类型（PEP 604）；3.12 类型参数语法（PEP 695）：

```python
def f[T](x: T) -> T:
    return x
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 参数"传值"讲得含糊 | Python 是"对象引用传递" | 区分可变/不可变对象 |
| 未提类型注解 | 现代大型项目必备 | `def add(a: int, b: int) -> int:` |
| 可变默认参数风险未强强调 | `def f(x=[])` 共享 | `x=None` 占位 |
