## 核心精讲

教学示意，不参与构建：

```python
# 用内建单词集替代外部 words.txt（不依赖文件）
WORDS = {"listen", "silent", "enlist", "python", "typhon", "racecar"}

def is_anagram(a, b):
    return sorted(a) == sorted(b)

def is_palindrome(s):
    s = s.lower()
    return s == s[::-1]

print(is_anagram("listen", "silent"))   # True
print(is_palindrome("racecar"))          # True

# 在集合中查找所有易位词（O(1) 成员判断）
target = sorted("listen")
matches = [w for w in WORDS if sorted(w) == target]
print(matches)                          # ['listen', 'silent', 'enlist']
```

## 版本演进

- 3.0：`set` 字面量 `{"a","b"}` 可用（Python 2.6+）；`str` 为 Unicode。
- 3.10（2021）：`match` 可表达更复杂的词形匹配（PEP 634）。
- 集合/字典用哈希，成员判断 O(1)，比列表线性扫描快得多。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 依赖外部 `words.txt` | 跨平台缺失 | 用 `set` 内建或读资源 |
| 列表线性查找易位词 | O(n·m log m) 慢 | 集合 + `sorted` 键 |
| 大小写未归一 | 误判 | 先 `.lower()` |
