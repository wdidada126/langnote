## 核心精讲

教学示意，不参与构建：

```python
# 第一个程序
print("Hello, World!")

# 算术
print(2 + 3)        # 5
print(7 / 2)        # 3.5（Python 3 真除法）
print(7 // 2)       # 3（整除，向下取整）
print(7 % 2)        # 1（取余）
print(2 ** 10)      # 1024（幂）

# 值与类型
print(type(42))     # <class 'int'>
print(type(3.14))   # <class 'float'>
print(type("hi"))   # <class 'str'>
```

## 版本演进

- 3.0（2008）：`print` 成为函数（原书已用 `print(x)`，正确）；真除法 `/` 默认返回 float（Python 2 的 `/` 对整数做整除，这是最大差异，🔧 若你见过 Python 2 代码需注意）。
- 3.6（2016）：f-string 取代 `%`/`.format()`（见 [02-变量表达式和语句.md](02-变量表达式和语句.md)）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 多数示例用 `%` 或 `.format()` 拼接 | f-string 更直观（3.6+） | 一律用 `f"{x}"` |
| 「字典/集合顺序不确定」 | 仅 Python <3.7；3.7+ dict 保序 | dict 保序已成规范 |
| 安装 swampy 跑图形 | 现代环境难装 | 图形用标准库 `turtle`（第 4 章） |
