## 核心精讲

教学示意，不参与构建：

```python
import turtle

def draw_square(t, length):
    """在 Turtle t 上画边长为 length 的正方形。"""
    for _ in range(4):
        t.forward(length)
        t.left(90)

def draw_polygon(t, n, length):
    """画正 n 边形。"""
    angle = 360 / n
    for _ in range(n):
        t.forward(length)
        t.left(angle)

def draw_circle(t, r):
    """用正多边形逼近圆。"""
    circumference = 2 * 3.14159 * r
    n = max(10, int(circumference / 3))
    draw_polygon(t, n, circumference / n)

bob = turtle.Turtle()
draw_circle(bob, 80)
turtle.done()
```

## 版本演进

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
