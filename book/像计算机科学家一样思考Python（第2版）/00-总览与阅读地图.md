## 四、Python 3.2 → 3.14 版本演进时间轴（本书相关）

- 3.6（2016）：f-string 引入（PEP 498）——原书用 `%` 与 `.format()`，今天一律换成 f-string。
- 3.7（2018）：`breakpoint()` 内置（PEP 553）；字典保序成语言规范（原书强调「字典无序」，需修正）。
- 3.8（2019）：海象运算符 `:=`（PEP 572）；仅位置参数 `/`（PEP 570）。
- 3.9（2020）：字典合并 `|`（PEP 584）；内置泛型 `list[int]`（PEP 585）。
- 3.10（2021）：结构模式匹配 `match`（PEP 634）；更清晰的错误回溯。
- 3.11（2022）：`ExceptionGroup`/`except*`（PEP 654）；提速约 25%；`tomllib`（PEP 680）。
- 3.12（2023）：f-string 语法形式化（PEP 701，任意表达式任意位置）；`type` 语句泛型（PEP 695）；`override`（PEP 698）。
- 3.13（2024）：自由线程构建（PEP 703，实验性）；移除一批「死电池」标准库（PEP 594）。
- 3.14（2025，开发线）：模板字符串 t-string（PEP 750，🔧 以官方为准）。

## 六、本书缺口（2026 视角）

- 不覆盖：类型注解与静态检查、虚拟环境/`pyproject.toml` 工程化、异步、`pathlib`、测试框架（仅讲手工调试）。
- 案例研究依赖 `swampy` 第三方包（第 4 章 TurtleWorld），该包自 Python 2 时代后维护停滞，现代直接用标准库 `turtle` 即可，见 [04-案例研究界面设计.md](04-案例研究界面设计.md)。
- 算法章节只讲大 O 直觉与二分/归并，未涉及现代数据结构库（`heapq`、`bisect`、`array`）。

## 七、工具链

- 运行：Python 3.12+；编辑器 VS Code 或任意。
- 第 4 章可选：`pip install swampy`（🔧 现代 Python 可能安装失败，建议改用 `turtle`）。
- 调试：`python -m pdb` 或 IDE 断点；第 20 章方法在今天仍适用。

- 每章七段式：本章地图 / 核心精讲 / 版本演进 / 经典论文与原始文献 / 近年研究与工业界开源实践 / 常见误区与本书需修正之处 / 与其他章·其他书的联系。
