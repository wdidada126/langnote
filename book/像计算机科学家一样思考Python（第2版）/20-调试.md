## 核心精讲

教学示意，不参与构建：

```python
import logging
logging.basicConfig(level=logging.DEBUG,
                    format="%(levelname)s %(message)s")

def divide(a, b):
    logging.debug("divide a=%s b=%s", a, b)
    return a / b

# 断点调试（3.7+ 内置 breakpoint()）
def buggy(xs):
    total = 0
    for x in xs:
        breakpoint()          # 进入 pdb，可查变量
        total += x
    return total
```

现代自文档化打印：`print(f"{x=}")` 输出 `x=42`（3.8+ 的 `=` 说明符）。

## 版本演进

- 3.7（2018）：内置 `breakpoint()`（PEP 553），取代 `import pdb; pdb.set_trace()`。
- 3.8（2019）：f-string 的 `=` 自文档化 `f"{x=}"`（PEP 572 海象同期）。
- 调试器增强：`python -m pdb`、`python -X dev` 开发模式（3.7+）。

- `pytest` 把"打印自查"升级为可回归断言；`assert` + 测试覆盖（🔧 非同行评审，工业界标准）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `print` 调试后留代码 | 污染生产 | 用 `logging` 或删除 |
| `pdb.set_trace()` | 冗余 | `breakpoint()` |
| 一次改多处 | 不知哪处生效 | 一次改一处、最小复现 |
