## 这本书在讲什么（一段话）

Spark 与 Iceberg 的关系是「计算引擎 × 表格式」：Spark 提供 DataFrame/SQL 与调度，Iceberg 提供
ACID、快照、隐藏分区与演化能力。这份 short report 的实用主线是：**如何把 connector 接上（catalog 配置），
怎么读写（含 MERGE INTO upsert），怎么用快照能力（时间旅行、元数据表），怎么享受演化与隐藏分区，
以及如何让表长期健康（维护过程）与进 Streams（流式读写）**。本目录把这 6 块各自展开成可操作的笔记。

## 一页速查表（各章结论浓缩）

```
接入   --packages iceberg-spark-runtime-3.5_2.12:x.y.z
       + spark.sql.extensions=...IcebergSparkSessionExtensions   ← 不开=没有 CALL/增强 MERGE/分支旅行
写     df.writeTo(t).append() / .overwritePartitions()；INSERT OVERWRITE 前先 dynamic 模式
改     UPDATE/DELETE/MERGE INTO（v2 表）；高频 upsert 选 merge-on-read
看     snapshots/history/files/partitions 元数据表 = 一切排障起点
旅行   VERSION AS OF <id> / TIMESTAMP AS OF '<ts>' / VERSION AS OF '<branch>'
演化   ADD/AFTER/RENAME/DROP + REPLACE PARTITION FIELD：全元数据、零回填
维护   rewrite_data_files → rewrite_manifests → expire_snapshots → remove_orphan_files（按此顺序排班）
流式   readStream option("streaming","true") 消费快照链；写侧 micro-batch append，每批一快照
```
