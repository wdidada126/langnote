## 一、定位

Manning 这本走「PyTorch 机制纵深」：从 Tensor 存储/视图、autograd 动态 tape，到 `nn.Module` 组装魔法、训练循环手工节拍，再到 CNN/RNN 两类核心网络、性能与多 GPU，末尾三类实战项目与生态巡礼。与库内 Raschka 那本（[../MachineLearningWithPyTorchAndScikitLearn.md](../MachineLearningWithPyTorchAndScikitLearn.md)，ML 全景 + PyTorch 实现）分工明确：**全景查 Raschka，机制读本书，API 现行口径最终以官方文档纠偏**。2020 年 API 截点（`Variable` 遗迹、早期 `DataLoader` 写法、`torch.cuda.amp` 新件）是本书最大折旧源。

## 三、读法

不线性读。第一遍吃透 01+02（机制层，折旧最慢）；03/04 按手头任务二选一先读；05 在训练变慢时才翻；06 收尾建生态地图。每章配「批判读法」栏：凡书中 API 写法与现行官方文档冲突，以官方为准并回写欠账。Transformer 时代（2020 书中仅露端倪）请跳 [../NaturalLanguageProcessingWithTransformers.md](../NaturalLanguageProcessingWithTransformers.md) 续命，本书不教。

## 四、🔧 实测口径

本机无 torch/tf/sklearn，**一律未实测、不装依赖**（用户纪律）。各章微实验位只写设计与预期结论：视图原地传播、梯度累加陷阱、BN 训推差异、DataLoader worker 流水线、DDP 梯度同步等，均需未来在带 torch 的环境复验后把 🔧 升 ✅ 或改判。代码可照抄书中骨架当练手模板，但运行时 API 需对照现行文档。
