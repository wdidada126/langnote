## 阅读路线

1. **工具双轨直读（书的骨架）**：`01` 地基 → `02`（VS/Windows 轨）与 `03`（gdb/Linux 轨）成对读，
   同一操作（断点、监视、调用栈、线程）在两套 UI 里各走一遍，形成「肌肉记忆映射表」。
2. **问题类型线（工程师查病线）**：`04` 死锁 → `06` 内存 → `08` 崩溃现场 → `09` 只在 Release 复现的鬼 bug；
   这四章是「症状 → 诊断路径」的查表式读法。
3. **原理纵深线**：`03` 会用断点 → `10` 断点底下是什么（INT3、DR 寄存器、ptrace/Win32 调试 API）→
   `11` 再往上一层（内核与驱动、WinDbg）。`07` 远程调试是 RSP 协议的应用，宜在 `10` 之后重读。
4. **Windows+MinGW 用户特供线**（本仓库用户环境）：`03`→`06`→`09`：本机 gdb 17.1 实测全部可在 Windows 复现，
   MSVC ASan 与 MinGW 无 libasan 的对照见 `06`。
5. **2026 视角速览线**：只读每章「最新演进与工业实践」小节，得到书后（2023→2026）工具链演化全景：
   Sanitizers 家族、rr/Time Travel Debugging、debuginfod、clang-tidy 前移、IDE 与 CLI 调试器分工。

## 本书定位与「2026 年视角」的对照读法

本书的骨架是**双调试器对照**（Visual C++ 调试器 + GDB），主线在 Linux 侧偏向 **GDB**，
并以「现场问题」组织后半部（死锁、动态库、内存、远程、转储、Release）。这个组织方式在 2026 年仍然成立，
但有四层必须补读（分散写入各章「最新演进与工业实践」节）：

1. **调试器不再只有 GDB**：LLDB（lldb/LLVM 单体仓库）已是 macOS 默认与 Linux 一线可选；
   Windows 侧 WinDbg（microsoft/windebug）+ Time Travel Debugging 已成为「回放式调试」工业标杆；
   VS 调试器与 MSVC 工具链深度耦合（PDB/编辑并继续/诊断附加）。
2. **内存类 bug 的主工具换代**：Valgrind 仍是 Linux 利器，但工业默认已移向编译器插桩的
   AddressSanitizer/UBSan/TSan/MSan（google/sanitizers，随 clang/gcc 分发）；
   Windows 侧 MSVC `/fsanitize=address` 自 VS2019 16.9 起可用——**本机已实测**（见 `06`）。
3. **符号与 debug info 生态**：DWARF 5 定稿、debuginfod（elfutils/dnf 项目）让「发行版二进制 + 服务器符号」
   成为 Linux 发行版标配；Windows 的 PDB 与 build-id 分离符号策略对照阅读（`08`、`09`）。
4. **调试前移**：clang-tidy / cppcheck / MSVC `/analyze` 把大量原书第 6/9 章的「运行时才抓到的 bug」
   挪到编译期；本仓库单文件笔记 [../cppprime.md](../cppprime.md) 的 C++ Core Guidelines 检查器条目与此直接衔接。

## 读完应该能回答的十个问题

1. 一条源码行断点从 `b foo.c:12` 到 CPU 停下来，中间经过哪四层（调试器/RSP 或 OS API/CPU/异常派发）？（`01`、`10`）
2. 软断点（INT3）与硬件断点（DR0–DR7）各自的数量限制、能否 watch 写入、对 Release 代码是否可用？（`03`、`10`）
3. 栈帧回溯凭什么能走通？`rbp` 链、DWARF `.eh_frame`/CFI、SEH 表三种 unwind 信息分别在哪个平台是主力？（`02`、`03`、`08`）
4. Linux 上进程死锁，gdb 里从 `info threads` 到「锁持有者链」的完整操作路径是什么？Windows 上同型问题用什么？（`04`、`11`）
5. 堆上写越界为什么常常「过很久才炸」？从症状反推是 heap 还是 stack 破坏的判据？（`06`）
6. core dump 不生成/被截断，依次查哪五个开关？Windows 的 WER/小程序转储对应机制是什么？（`08`）
7. Release 版「能调试」的最小构建改动是什么？`-g` 加到 `-O2` 上会看到哪些假象？（`09`）
8. gdbserver 与本机 gdb 之间跑的是什么协议？为什么断点命中有毫秒级延迟？（`07`）
9. 无源码的第三方 .dll/.so 崩溃，从转储/附加进程到定位的路线图？（`09`、`10`）
10. Sanitizer/rr/TTD 三类「时间机器」工具分别牺牲什么换到什么？（`06` 与各章演进节）
