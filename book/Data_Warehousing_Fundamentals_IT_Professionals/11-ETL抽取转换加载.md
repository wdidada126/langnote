## 2. 逐节精读（✅ 节题源自 Wiley 目录）

### 2.1 ETL Overview / Requirements and Steps（pp.282/284 ✅）

- 定义域 ⚠️：ETL = 把操作性数据变成"仓里可信信息"的全部工程；三大要求：可重复、可恢复（断点续跑）、
  可对账（行数/金额双向平衡）。
- 九步骨架（教材步骤序转述 ⚠️）：源清点→抽取→暂存落地→净化→标准化→一致性合并→业务规则转换→
  装载（含 SCD/聚合联动）→核验与例外处理；每步配日志入元数据（回收 08 文件流程域）。

### 2.2 Data Extraction（数据抽取，p.286 ✅）

教材抽取法典 ⚠️：
| 方法 | 机制 | 代价与判据 |
|---|---|---|
| 全量刷新 | 整表重搬 | 简单笨重；小维表首选 |
| 快照差分 | 两版本比对 | 需保留前像；无时间戳源的救星 |
| 时间戳/修改日期 | WHERE ts>水位 | 依赖源纪律；删不见 |
| 审计日志/触发器 | 源端变更记录 | 侵入源系统；运维敏感 |
| CDC/变更表 | 日志挖掘或变更队列 | 2010 属高端货；2026 成默认 |
- 🔧E4 实测类比（DuckDB ATTACH SQLite 源，非本书引擎）：源 1000 行、DW 存量 800 行，
  `EXCEPT ALL` 快照差分抽出增量 **200 行**（16.1ms）——"快照差分"一行 SQL 的最小复刻；
  删除检测仍靠全表比对（时间戳法的死穴同场演示）。

### 2.3 Data Transformation（数据转换，p.295 ✅）

- 转换分类 ⚠️：结构性（清洗/标准化/合并拆分/代理键生成）与经营性（单位换算/口径规则/派生指标/
  业务分层）；代理键发射器（sequence+自然键→代理键映射表）是本章与 09/10 文件的焊点。
- 教材工程戒律 ⚠️：规则必须外置成表/配置（可审计、可回放），反对"藏在脚本 if 里"。

### 2.4 Data Loading（数据装载，p.302 ✅）

- 装载模式 ⚠️：批量窗口（夜间/周末）、准实时微批（第 2 版新增主题 ✅ Wiley "New to This Edition"
  "实时信息交付"）、SCD 合并（T1 UPDATE/T2 INSERT 版本行）、聚合表联动刷新（回收 10 文件对账链）。
- 🔧E4b 实测（非本书引擎）：DuckDB `COPY ... TO 'orders.parquet'` 批量导出 9419B、回读 1000 行——
  高吞吐批量装载的文件侧形态；云仓 COPY 命令的祖先即此类"文件中转"。
- 失败恢复 ⚠️：装载幂等三件套=批次号、暂存可回放、目标可回滚（教材给原则，商用套件给按钮）。

### 2.5 Other Integration Approaches（其他集成方案，p.311 ✅）

- 兜底清单 ⚠️：联邦查询/数据复制/消息中间件/企业总线（ESB 年代语汇）；教材判词：**这些方案不消灭
  ETL，只是搬运它的责任**——口径整合总要在某处发生。

## 3. 关键概念辨析

- **ELT 逆转的条件** ⚠️：把转换后置进仓（现代 dbt 路线）成立的前提=仓侧算力便宜+暂存层消失；
  2010 教材的"仓外先洗"源于彼时算力昂贵——两朝皆对，成本函数变了。
- **抽取水位 vs 业务时间** ⚠️：迟到数据（late arrival）使"ts>水位"漏历史补录——教材以快照差分
  兜底，2026 以事件时间+窗口重算兜底，问题同源。
- 与 08 文件闭环：ETL 日志=技术元数据最大生产者；无装载日志的仓=无血缘的仓。

## 核心概念速览（中英对照）

| 英文 | 中文 | 一句话释义 |
|---|---|---|
| extract-transform-load (ETL) | 抽取-转换-装载 | 操作性数据进仓的全管道工程 |
| staging area | 暂存区 | 抽取落地与回放的工作区 |
| snapshot delta | 快照差分 | 两版全量比对求增量的抽取法 |
| change data capture (CDC) | 变更数据捕获 | 从日志/触发器取变更事件流 |
| watermark | 高水位线 | 增量抽取的时间/序列边界 |
| surrogate key generator | 代理键发射器 | 自然键→票号的映射构件 |
| externalized business rules | 业务规则外置化 | 规则入表不入码的戒律 |
| idempotent load | 幂等装载 | 重放不改变结果的装载设计 |
| ELT | 抽取-装载-转换 | 转换后置进仓的路线逆转 |
