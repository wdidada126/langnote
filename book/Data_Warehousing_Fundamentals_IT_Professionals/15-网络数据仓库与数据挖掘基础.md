## 2. 逐节精读：第 16 章（✅ 节题源自 Wiley 目录）

### 2.1 Web-Enabled Data Warehouse（Web 使能的仓库，p.408 ✅）

- 双向命题 ⚠️：方向一"仓库→Web"（BI 交付 Web 化：瘦客户端、门户嵌入、移动萌芽）；方向二
  "Web→仓库"（点击流/日志/会话数据入仓分析）——后者催生 **Webhouse** 专名：面向站点级并发与
  实时页面个性化的高吞吐查询变体。
- 点击流数据特性 ⚠️：海量、无模式偏好（session/page/referrer 粒度）、隐私敏感——装载与保留策略
  在 12/16 文件框架内加严。

### 2.2 Web-Based Information Delivery / OLAP and The Web（pp.414/420 ✅）

- 交付 Web 化三档 ⚠️：静态发布（HTML 报表推送）→ 交互门户（权限化仪表盘）→ 嵌入应用（分析进
  业务流程，回收 13 文件"嵌"通道）。
- OLAP on Web ⚠️：透视 UI 的服务器化（厚客户端退役）、会话立方缓存、并发降级策略（缓存命中换
  预聚合）——14 文件三特征的 HTTP 重述。

### 2.3 Building A Web-Enabled Data Warehouse（建设路线，p.421 ✅）

## 3. 逐节精读：第 17 章（✅ 节题源自 Wiley 目录）

### 3.1 What Is Data Mining?（数据挖掘是什么，p.430 ✅）

- 定义 ⚠️：从仓/集市数据中自动发现**非显然、可行动**模式的过程；与 OLAP 分工：OLAP 人导航假设，
  挖掘机搜索假设（13 文件形态谱的深浅两格）。
- 流程骨架 ⚠️（CRISP-DM 同构，教材以项目语汇重述）：业务问题→数据准备（抽样/规约/特征）→建模→
  评估→部署（回流成仓上的评分列/规则表——与 11 ETL 闭环）。

### 3.2 Major Data Mining Techniques（主要技术，p.439 ✅）

教材技术菜单 ⚠️（按"预测/分群/关联/异常"四桶组织笔记）：
| 桶 | 技术 | 仓库落点 |
|---|---|---|
| 预测 | 回归/决策树/（神经网络一笔带过） | 评分卡进维表，回收 T1 覆盖策略 |

## 4. 关键概念辨析

- **Webhouse vs 数据集市** ⚠️：前者是**交付侧性能形态**（高并发低延迟查询），后者是数据组织单位；
  混称导致采购错配——教材专段提醒。
- **挖掘吃仓库的哪口粮** ⚠️：抽样宽表（feature 表）——维度属性即特征，粒度即样本定义；星型质量
  直接决定挖掘上限（09/10 文件价值再证）。
- 点击流的**隐私时变性** ⚠️：2010 仅轻量提醒，2026 成决定性约束（同意管理/匿名化/边缘聚合）。

## 7. 行为分析指标卡（⚠️ 本册依 ch16 点击流节题域编制，教学示意）

| 指标 | 定义一句话 | 星型落位（回收 09/10） |
|---|---|---|
| 会话数 | 去重 session 计数 | 会话事实的行数 |
| 跳出率 | 单页会话占比 | 会话事实+页面计数派生列 |
| 漏斗转化 | 步序到达率比值 | 步骤维×时间维的不可加度量链 |
| 留存 | 同期群回访率 | 用户×日期快照事实 |
| 路径深度 | 会话内页均数 | 会话事实的不可加度量 |

- 度量可加性陷阱 ⚠️：跳出率/转化率沿维度**不可直接平均**——分子分母各自上卷再相除（09 文件可加性
  三标的实战位）。
- 挖掘侧注脚 ⚠️：3.2 四桶技术在行为域的当代形态=分群（同期群）+预测（流失概率）+异常（刷量检测）；
  模型回流两载体：评分列入维（T1/T2 决策）、规则表入管道（11 文件外置戒律）。
- 隐私三闸门 ⚠️：采集同意→存储窗口→出口匿名化——2010 一行提醒变 2026 工程三件套（回收 16 安全节）。

## 最新演进与工业实践

- **Webhouse 的归一** ⚠️：站点分析独立成产品域（GA4/Mixpanel/自研埋点仓），其查询形态（高并发
  漏斗/留存/路径）反哺云仓物化视图与增量计算设计——"双向命题"以两条产品线存续。
- **点击流→事件湖** ⚠️：埋点 schema-on-read 入湖、星型只在出口物化——16 章装载策略的 ELT 版重写；
  盘上湖仓册群对位（[../Data_Lakehouse_in_Action/00-总览与阅读地图.md](../Data_Lakehouse_in_Action/00-总览与阅读地图.md)）。
- **挖掘的 ML 工程化** ⚠️：3.2 四桶技术被 scikit-learn/AutoML/大模型吞并，"模型回流"演化为
  feature store+在线服务；教材"评分卡进维表"仍是批量特征的最简正确形态。
- **隐私合规接管方向盘** ⚠️：同意采集/匿名化/联邦统计成为 Web→仓 通道的前置闸——远超 2010 提醒
  的量级；对位治理册群（[../Understanding_Data_Governance/00-总览与阅读地图.md](../Understanding_Data_Governance/00-总览与阅读地图.md)，实名 ls ✅）。
