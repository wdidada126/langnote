# 02 数据仓库：基本构件（Datawarehouse: The Building Blocks）

> 原书：Data Warehousing Fundamentals for IT Professionals, 2nd Edition（Ponniah，Wiley 2010，ISBN 9780470462072）
> 第 2 章，pp.23–44 ✅（Crossref `...ch2` + Wiley 目录）。精读重构：节题/页码 ✅，论述转述 ⚠️；🔧 本机类比非本书示例引擎。

## 1. 章节定位

全书**术语与构件的立法章**：给出数据仓库的操作性定义（四特征）、区分仓库与集市、盘点架构类型与组件清单。
后文各章（架构 06、基础设施 07、元数据 08、ETL 11）都是本章构件表的展开。与 Inmon 册第 2 章
「数据仓库环境」互为教材层/原创层对照——概念同源，Ponniah 做了跨方法论中立化处理 ⚠️。

## 2. 逐节精读（✅ 节题源自 Wiley 目录）

### 2.1 Defining Features（定义性特征，p.24 ✅）

教材归纳的经典四特征（与 Inmon 1991 定义同源 ✅ 概念归属，转述 ⚠️）：

| 特征 | 英文 | 工程含义 | 反例（OLTP） |
|---|---|---|---|
| 面向主题 | subject-oriented | 按业务主题（客户/产品/销售）组织，而非按应用 | 按订单模块/账务模块切分 |
| 集成性 | integrated | 多源数据统一口径、编码、粒度后合并 | 各部门私有 schema |
| 非易失性 | non-volatile | 装载后只读不改，插入+定期清理 | 高频 UPDATE/DELETE |
| 时变性 | time-variant | 每个事实带时间上下文，历史版本保留 | 仅存当前值 |
- 教材补充的第五面：**不可变性中的"元数据驱动"**——构件清单里 metadata 从本章起就是一等公民 ✅（呼应 ch9）。

### 2.2 Data Warehouses and Data Marts（仓库与数据集市，p.29 ✅）

- 定义 ⚠️：data mart = 面向部门/主题域的仓库子集；两类集市：dependent（自 EDW 派生，Inmon 正统）与
  independent（直连源系统，Kimball 式起点）。
- 本书立场（教材中间路线）：集市是**交付加速器**而非架构分歧点——先列五维选型对照（范围/用户数/建设周期/
  成本/风险）⚠️，再指出独立集市失控即回退为"烟囱"（呼应 ch1 反面典型）。
- 第 2 版新增主题之一即 data marts 新进展 ✅（Wiley "New to This Edition" 实抓），指向 2010s 集市概念
  向"分析域小仓"的软化。

### 2.3 Architectural Types（架构类型，p.32 ✅）

- 三种经典拓扑 ✅ 节题存在于 ch2 与 ch7（两处呼应，ch7 展开技术架构）：
  1. **top-down（自顶向下）**：源→EDW→集市，Inmon CIF 路线；
  2. **bottom-up（自底向上）**：源→集市（总线约束）→逻辑上即仓库，Kimball 路线；
  3. **hybrid（混合）**：加中央集成层/枢纽（hub）缝合两线。
- 教材判词 ⚠️：三型无绝对优劣，**需求画像（用户广度×数据深度×预算节奏）决定选型**——该结论被 ch6
  "需求驱动"与 ch7"架构框架"两度回收，也是本册与两方法论单传教材的最大差异。

### 2.4 Overview of The Components（组件总览，p.34 ✅）

本章的"构件清单"（后续章文件对照索引）：

| 构件 ✅ | 职责一句话 | 本册展开文件 |
|---|---|---|
| source systems | 操作性数据与外部数据源 | 11（抽取） |
| extraction & data cleansing | 抓数、净化、标准化 | 11/12 |
| transformation & delivery | 业务规则加工、分发 | 11 |
| data store（warehouse & marts） | 分级存储：原子/当前/历史/归档 | 10/16 |
| metadata repository | 元数据仓库 | 08 |
| access & delivery tools | 查询/报表/OLAP/挖掘/门户 | 13/14/15 |
- ⚠️ 转述要点：教材强调存储分级（current detail / older detail / lightly summarized / archived）以平衡
  成本与响应——与 Inmon 册的粒度阶梯（其 ch4）对位阅读最佳。

### 2.5 Metadata in The Data Warehouse（仓库中的元数据，p.41 ✅）

- 三语打包 ✅ 节题：metadata 是"关于数据的数据"；**business metadata** 给用户看口径，**technical
  metadata** 给 ETL/DBA 看血缘；完整分类学与工具在 ch9（本册 08 文件）。
- 登记 🔧E7 概念类比预告：本机 DuckDB `information_schema`（3 列记录）与 SQLite `sqlite_master`（2 表记录）
  即"技术元数据的两个原生面"——仅演示"仓库自带元数据"这一事实，**非本书示例引擎**。

## 3. 关键概念辨析

- **仓库 vs 集市 vs "分析库"**：本章以范围/用户/数据源三轴划界 ⚠️；2010s 后云仓把该界线改写成
  "库/schema/warehouse 三级对象"，概念对位见盘上 Snowflake TDG 00（已验名）。
- **集成性 vs 一致性**：集成是建设动作，一致性（consistency，跨集市同名同义）是治理状态——Kimball 总线
  矩阵专治后者（对位 [../数据仓库工具箱3.md](../数据仓库工具箱3.md) 总线节）。
- 与 Inmon 册对位：[../Building_the_Data_Warehouse/02-数据仓库环境.md](../Building_the_Data_Warehouse/02-数据仓库环境.md)
  给四特征的原创论证；本文件是教材化的"测验就绪"版本。

## 核心概念速览（中英对照）

| 英文 | 中文 | 一句话释义 |
|---|---|---|
| subject-oriented | 面向主题 | 按业务主题而非应用组织数据 |
| integrated | 集成性 | 多源统一口径与编码后的合并态 |
| non-volatile | 非易失性 | 装载后只读、以插入维护 |
| time-variant | 时变性 | 历史版本随时间轴保留 |
| data mart | 数据集市 | 面向部门/主题域的仓库子集 |
| dependent / independent mart | 派生/独立集市 | 自 EDW 派生 vs 直连源系统 |
| top-down / bottom-up / hybrid | 自顶向下/自底向上/混合 | 三大架构路线 |
| metadata repository | 元数据仓库 | 存口径与血缘的中枢构件 |
| current / older detail | 当前/历史明细 | 存储分级层 |
| lightly summarized data | 轻汇总数据 | 原子与重度汇总之间的粒度带 |

## 最新演进与工业实践

- **四特征的 2026 体检** ⚠️ 泛述：面向主题被"数据域/数据产品"（mesh 语汇）继承；集成性改由
  schema-on-read + 契约测试保障；非易失性被 Delta/Iceberg 的 ACID UPDATE 软化（可改但仍时变）；
  时变性由"快照/时间旅行"原生实现——对位盘上 [../Delta_Lake_Definitive_Guide/00-总览与阅读地图.md](../Delta_Lake_Definitive_Guide/00-总览与阅读地图.md)（波 3 在盘，ls 验名 ✅）。
- **集市→域**：部门集市叙事让位于"分析域/feature store"；本书"集市失控回退烟囱"的警告在指标平台
  （semantic layer）运动中被重新引用 ⚠️。
- **组件清单的当代同构**：source→摄取（CDC/流）→中央表格式→catalog→BI/AI 消费——本书七构件表几乎
  逐项映射 2026 现代数据栈（Fivetran/dbt/Iceberg/Polaris 等），教学骨架仍有效；目录中枢对位
  [../The_Enterprise_Data_Catalog_2e/00-总览与阅读地图.md](../The_Enterprise_Data_Catalog_2e/00-总览与阅读地图.md)。
