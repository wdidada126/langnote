## 2. 逐节精读（✅ 节题源自 Wiley 目录）

### 2.1 Why Is Data Quality Critical?（质量为何致命，p.316 ✅）

- 教材论证链 ⚠️：数仓的存在理由=可信的统一口径 → 口径三要素（定义/来源/变换）任一污染即全盘失信；
  失信的终局是用户回退 Excel 私库（回收 ch1 烟囱病复发）。
- 成本不对称律 ⚠️：脏数据在源头修=分厘，在仓里修=元角，在决策后修=性命——本章引用顾问案例式
  论据（Ponniah 特色，BCS 书评同调 ✅）。

### 2.2 Data Quality Challenges（质量挑战，p.323 ✅）

典型病症清单 ⚠️：缺值/默认值冒充实值、编码漂移（同义异码）、异码同义、历史断档（源系统迁移）、
格式脏（空格/大小写/千分位）、重复自然键、跨源时钟错位、聚合口径偷换。
- 🔧E5 实测（SQLite，非本书引擎）：1000 行脏样本（5 类病×200）——重复组 5、空邮箱 200、负金额 200；
  `trim+lower+replace` 归一后**去重仅剩 5 个唯一模式**：一行 SQL 展示了"脏数据=少数模式×大量重复"
  的统计结构，剖析先行（profile-first）因此成立。

### 2.3 Data Quality Tools（质量工具，p.326 ✅）

教材工具分类 ⚠️：剖析器（画像：分布/空值率/基数）、清洗器（标准化/匹配合并）、校验器（规则拦截）、
监控器（趋势告警）、工作台（例外队列与人工裁决）。规则五件套：完整性/唯一性/一致性/时效性/准确性
（2026 语汇几乎原样，加"可发现性"）。

### 2.4 Data Quality Initiative（质量倡议/运动，p.328 ✅）

- 本章组织面 ⚠️：质量是**流程不是一次脚本**——倡议五步：基线剖析→立规则与阈值→源头修复工单制→
  装载期拦截与例外队列→趋势复盘入治理会。
- 责任结构：每规则须有 owner 与"修/绕/接受"裁决路径（回收 04 团队表数据owner 席位）。

### 2.5 Master Data Management（pp.335–336 ✅ 四小节）

- 教材 MDM 位：主数据=跨域共享的黄金记录（客户/产品/组织）；类别 ⚠️：注册式（单源权威）、
  合并式（多源拼金）、存储式（集中暂存分发）；与数仓关系：**仓库是 MDM 最大消费者兼体检仪**——
  多源比对天然暴露主数据分歧（回收 03 文件趋势 6、08 文件政策域）。

## 3. 关键概念辨析

- **质量维度 vs 质量规则** ⚠️：五维是度量语言，规则是可执行断言；"准确性"最难——需外部参照系，
  教材以"样例核对+来源权威分级"处理。
- **清洗 vs 转换** ⚠️：清洗修复"数据坏了"，转换执行"数据没错但形态不同"；混在一处则血缘失真——
  11 文件九步把两环节分开的理由在此回收。
- **例外队列=质量与交付的接缝** ⚠️：被拦行去哪（修/删/带旗放行）决定口径诚实度；教材反对静默丢弃。

## 7. 质量规则 SQL 模板五则（⚠️ 本册依 ch13 节题域+🔧E5 整理；本机 SQLite 语法示意，非本书示例）

1. 唯一键：`SELECT cust_id FROM dim GROUP BY cust_id HAVING COUNT(*)>1` 期望 0 行。
2. 非空率：`COUNT(*) - COUNT(email) AS 缺口` 对照阈值（剖析基线定标，回收 🔧E5 的 200 空邮箱）。
3. 域合法：`WHERE status NOT IN (合法值集)` 期望 0；合法值集来自业务元数据（08 文件）。
4. 金额符号：`WHERE amt<0` 计数与业务豁免清单对齐（🔧E5 演示负值 200 的暴露面）。
5. 新鲜度：`MAX(ts)` 距装载窗的滞后断言（时效维的可执行化）。

- 剖析先行律（本章核心方法论）⚠️：🔧E5 的"1000 行→5 个唯一脏模式"说明——规则应当从**模式**写起，
  不是从行数写起；先 GROUP BY 世界，再 IF 世界。
- 记分卡一句话 ⚠️：给管理层的汇报单位是"规则通过率趋势"，不是"修了多少条"——前者是质量，后者是劳动。


### 补充：质量规则落地四步清单（⚠️ 本册归纳）

1. 画像先行：先用 🔧E5 式频次画像找异常模式，再定规则，避免拍脑袋阈值。
2. 规则分级：阻断级（主键/非空）、告警级（域值/引用）、观察级（趋势漂移）三档，各档处置人不同。
3. 出处即参照：准确性校验必须绑定外部参照源（参考数据/账本），无参照的"准确"不可证。
4. 闭环回写：缺陷工单结论要回写元数据（08 章），否则质量台账只是日志坟场。
