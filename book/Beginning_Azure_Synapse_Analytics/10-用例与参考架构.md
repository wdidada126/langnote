## 10.3 用例族二：湖仓分析与探索（Serverless-first）

- 形态：管道/Spark 落 Bronze（Delta/Parquet）→ Serverless SQL 视图化 Silver → 热点物化进专用池
  Gold（02 章过渡三态的完整演出）；
- 入口工件 ✅：Serverless 快速上手 `quickstart-serverless-sql-pool`、湖文件查询
  `sql/query-parquet-files`、计量与历史 `sql/query-history-storage-analysis`（本册验 200 面）；
- 成本护栏叙事 ⚠️：按处理量计费+目录/分区设计（02 章 🔧E3 的裁剪机理就是省钱机理）。

## 10.4 用例族三：近实时分析与运营报表（Link 主线）

- 形态：Azure SQL DB/SQL Server 2022/Cosmos 经 Link 直达湖（09 章）→ Serverless/Spark 消费 →
  Power BI DirectQuery 或导入；新鲜度从 T+1 抬到分钟级；
- 流式补充位：管道事件触发 + Stream Analytics 联动（专用池集成文档 ✅
  `sql-data-warehouse/sql-data-warehouse-integrate-azure-stream-analytics`，本册验 200）处理
  高频事件流，Link 处理状态数据——两条新鲜度轴互补 ⚠️。

## 10.5 用例族四：ML 与高级分析

- 形态：仓特征（专用池）+ 湖样本（Delta）→ Spark 池训练（SynapseML）→ AML 注册/服务（06 章三段论）✅
  `machine-learning/what-is-machine-learning`；

## 10.7 选型决策树（全章收束 ⚠️ 推定）

1. 负载稳定且 BI 语义严格？→ 专用池为主（05 章）；否 → Serverless 先行；
2. 变换复杂/含 ML？→ Spark 面（06 章）；
3. 源是托管 OLTP/Cosmos 且求零作业？→ Link（09 章）；异源/需整形？→ 管道（07 章）；
4. 新鲜度 ≤ 分钟？→ Link/事件触发组合；T+1 足够？→ 批管道简案；
5. 预算敏感先问「扫描量 vs 预置时长」哪个可控（02 章账本）——两问皆不可控者，先治理负载再谈选型。

## 10.8 上线日检查清单（全书组件的验收投影 ⚠️ 推定组织）

1. **装载首窗**：Copy/PolyBase 基线吞吐达标；分布倾斜视图干净（05 §5.4 的 🔧E2 图景在真实键上复现核查）；
2. **统计与形状**：装载后 UPDATE STATISTICS 挂点生效；CCI 段压缩率进入监控面板（05 §5.7 🔧E5 教训）；
3. **新鲜度断言**：Link/管道的水位延迟指标有告警订阅（09 章；01 章 §1.6 度量兑现）；
4. **语义消费**：Power BI 数据集刷新链路通；Serverless 视图成本上限设防（02 章账本纪律）；
5. **横切就绪**：网络选型定版、RBAC 抽测、Git 发布演练、监控评审例会排期（08 章清单复用）；
6. **回滚预案**：影子表切换失败回退、管道重跑幂等窗口、Link 断点重同步路径写明（07/09 章）。
7. **成本快照**：首周导出四面计量（DWU/处理量/核心时/活动数）建立基线，对照 04 章 §4.6 账单映射；
8. **文档债清零**：所有内部 Runbook 引用链接跑一遍 HEAD 验真（本章取证方法的日常化，见
   [00](00-总览与阅读地图.md) §10 附录）。

- 六项对应六种「上线后第一周事故」的常见根因，7–8 两项补「钱与文档」两种慢性病；本清单是把
  04 章 §4.8 五问落成动作的版本（编者处方 ⚠️）。
