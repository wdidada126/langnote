## 三条阅读路线

1. **设计哲学线（最推荐，按顺序读）**：`01` → `02` → `12`。
   先懂"为什么长成这样"（目标与约束），再懂"按什么规则改"（设计规则与演化方法论），
   最后看这套方法论在 C++11/14/17/20/23 上的延续（HOPL-II→IV 接力）。
2. **机制深潜线（对应原书第二部分）**：`05` → `06` → `07` → `08` → `09` → `10`。
   每章都是一个完整的"问题空间→备选→取舍→后果"案例，也是最好的语言设计教材。
3. **应用与运行时线（对应原书第一/第三部分）**：`03` → `04` → `11`，再回 `12` 看并发的终局答案。

**最短路径**（只想带走"怎么设计一个会演化的语言"）：`02` + `08` + `09` + `12`。

## 本书定位与阅读姿势（为什么必须"配着读"）

- D&E 是 **C++ 设计史的第一手文献**：作者亲述每个机制的问题空间、备选方案与否决理由，
  这种"决策档案"在语言书里几乎独一份（另一份是同作者的 HOPL 系列论文）。
- **书写于 C++98 之前**（1994 年截稿，标准尚未冻结）：书中"展望"与 Part III 若干判断
  已被历史修正或绕开（如 RTTI 之争、异常规范的命运、GC 接口设想）。
  因此每一章的《最新演进与工业实践》一节都强制回答：**这个决策在 C++11 之后怎么样了**。
- 配套文献接力（DOI 均已用 `api.crossref.org` 实测，见各章末「参考」）：
  - HOPL-II：**A history of C++: 1979–1991**，Stroustrup，SIGPLAN Notices 28(3), 1993。
    D&E 正是这篇论文扩写而来（前言自述：应 HOPL-II 征稿之请，"这封约稿邮件是本书真正的起点"）。
  - HOPL-III：**Evolving a language in and for the real world: C++ 1991–2006**，2007（接 D&E 之后写）。
  - HOPL-IV：**Thriving in a crowded and changing world: C++ 2006–2020**，2020
    （库内即有中译全文：[../在拥挤和变化的世界中茁壮成长C++2006–2020.md](../在拥挤和变化的世界中茁壮成长C++2006–2020.md)）。
  - 库内没有 HOPL-II/III 的论文笔记目录（已 Glob `paper/` 确认），故各章引用外部 DOI，不做假互链。

## 读完应该能回答的十个问题

1. 为什么 C++ 拒绝"更安全的默认"（如默认 virtual、GC 默认开）？（`01`、`02`、`11`）
2. "不用者不付费"在 1994 年反对的是什么？在 concepts/modules 时代还剩多少？（`02`、`08`、`10`）
3. cfront 转译器约束如何塑造了 C++ 的布局与编译模型？（`05`）
4. 多重继承的虚基类布局为什么让 iostream 挣扎了十年？（`07`）
5. 模板为什么先要 `export` 再放弃？概念约束之争的终局是什么？（`08`、`12`）
6. 异常处理否决了哪些备选（返回码、自动 GC、异常规范），各自后果？（`09`）
7. 名字空间赢过 module 提案的关键论点是什么？（`10`）
8. D&E 的 GC 章预言错了什么、说对了什么？（`11`）
9. 静态对象构造次序问题在 C++11 里怎么被"顺带"解决的？（`11`）
10. 一条设计规则（如"保持对 C 的兼容"）如何被逐版本"有代价地"松动？（`02`、`12`）
