## 7.1 形态选择：预置集群 vs Serverless（✅ 两页）

- 锚页：`redshift/latest/mgmt/welcome.html` ✅、`redshift/latest/mgmt/serverless-whatis.html` ✅。
  ⚠️ 转述：预置=选节点类型/数量、RA3 换得本地热层+S3 托管存储层（存算解耦的仓内半程）；
  Serverless=以 RPU 计的工作组，自动弹性与伸缩，运维面（升级/重分布/vacuum）交还服务 ⚠️。
- 决策线 ⚠️（重构）：负载可预测且重 ⇒ 预置的稳态单价更优；脉冲/多团队共享 ⇒ Serverless
  的隔离与按秒账更优。13 章给算账模板。
- 历史包袱登记：2022 语境成书时 Serverless 尚新（GA 2021-12 ⚠️），书中仓位多半按 RA3 预置
  展开——重构章两形态并叙，避免时代错位。

## 7.2 仓的解剖学（一页速览，细节转 TDG）

分布键（DISTKEY：join 共置）、排序键（SORTKEY：zone-map 剪枝）、列式存储、
副本+托管 S3 层（RA3）——⚠️ 通识。对位：TDG 03（建模）/05（扩展调优）章主场；
本册只认领「**这些旋钮与湖侧分区键是同一枚硬币的两面**」这一架构句。

## 7.3 仓湖接缝的三世代（⚠️ 演进重构）

1. **Spectrum/直接挂 S3**（世代一）：仓 SQL 直读湖表（经 Glue Catalog）——联邦读在仓侧。
2. **COPY/UNLOAD 批量搬运**（世代二）：明确物化窗口，05/06 章恒等式在仓内复现。
3. **Zero-ETL 托管连线**（世代三，✅ `glue/latest/dg/glue-zero-etl.html` 302→200）：
   RDS/DynamoDB→Redshift 免管线直连 ⚠️——接缝从「你的代码」变「产品的 SLA」。
三代共存，**每代的运维税不同**——架构图上画哪代要配成本/可靠性两列账（13 章）。

## 7.4 并发与隔离（⚠️ 概念转述，不引未验证页）

预置时代的 WLM 队列/优先级，到 Serverless 时代的**工作组成员数隔离**：概念不变形，
旋钮变抽象。对位实验：🔧E6 之外可参波8 册
[../Tuning_the_Snowflake_Data_Cloud/06-虚拟仓库.md](../Tuning_the_Snowflake_Data_Cloud/06-虚拟仓库.md)
（✅ 在盘实名）——「算力池×并发配额」两平台同构 ⚠️。

## 7.5 🔧E6：SORTKEY 直觉的最小实验（**非 Redshift 行为**）

DuckDB 8M 行表，窄区间谓词（1/800 选择率）`BETWEEN 4,000,000 AND 4,010,000` 求和，3 次取优：
**有序 1.2ms vs hash 乱序 4.5ms（≈3.8×）**。三点移植：①有序=把谓词翻译成「少读块」；
②收益来自 min/max 块级剪枝而非算法奇迹；③排序是一次性写放大换长期读税的**交易**——
Redshift 的 vacuum/重分布就是在维护这笔交易（⚠️ 机制归属 Redshift 语义，非本实验观测）。
差异清单：本机无 DISTKEY/无网络 shuffle/无自动 vacuum——倍数不可外推。

## 7.6 仓层的典型反模式（⚠️ 重构清单）

- 「湖当备份仓当缓存」倒置：一切原始数据直灌仓表 ⇒ 存储单价税（13 章）。
- 仓内重 ETL：把 06 章清洗逻辑全写进存储过程式 SQL 任务 ⇒ 与湖侧口径分裂。
- 一仓通吃 BI+ETL+即席：无工作负载隔离 ⇒ 晚间的重刷拖死早间报表（对位 Cookbook
  08 并发扩展 ✅ 在盘实名）。
- 忽略 Spectrum 外表与内表的统计口径差异 ⇒ 同一指标两个数（05 章契约问题在仓侧显形）。

## 7.9 形态答辩六判据（⚠️ 重构，给 7.1 的可填版）

| 判据 | 偏预置 | 偏 Serverless |
| --- | --- | --- |
| 负载可预测性 | 稳定高频 | 脉冲/多租户 |
| 调优 appetite | 要碰内核参数/发行版 | 只要 SQL |
| 成本模型 | 能承诺时长换单价 | 要按秒与按成员 |
| 隔离需求 | 手工 WLM 队列可接受 | 工作组原生隔离更省 ⚠️ |
| 迁移资产 | 老集群+外部工具链 | 新起或重构 |
| 运维意愿 | 接受版本/重分布责任 | 全部交还服务 |

六格过半落哪列选哪列，**别用两列各自的甜区拼一张许愿单** ⚠️（重构句）。

4. 工作负载隔离做过压力对撞演练吗？（7.4；🔧E6 之外无更便宜的教具）
5. Serverless 形态下 vacuum/重分布「交还服务」的代价是什么可见性损失？
   （7.1 权衡题——黑盒度与运维自由度的守恒 ⚠️）

**一句话收束** ⚠️：仓层在湖仓时代的正确自我定位是「成品车间」：
进来的是被信任的银层，出去的是被承诺的口径——仓一旦开始自己收原料、自己定口径，
05/06/08 章的三条契约就同时失守 ⚠️（重构句）。
