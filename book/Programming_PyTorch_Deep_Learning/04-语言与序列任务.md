## 核心机制

### 文本管道：分词→词表→索引→嵌入

- 现代口径三步（✅ 定性）：文本切成 token、建 token→int 词表、`nn.Embedding(vocab, dim)` 把整数索引查成稠密向量（✅ API 事实）。Embedding 本质是可学习的查找表，反向时梯度只进被查行（✅ 机理）——对照 ../深度学习入门.md（✅ 在盘）无嵌入概念、字符直接 one-hot，两级差正是「分布式语义假设」的工程化。
- 2020 截点警示 ⚠️：当年教材多用自带小词表/`torchtext` 手工流水线；torchtext 此后大改并走向归档弃用（⚠️ 方向可信，逐条细节待 pytorch.org 公告复核），书例**不可照抄运行**——现行 tokenizer 实践走 Hugging Face 线（../NaturalLanguageProcessingWithTransformers.md，✅ 在盘）。
- 批处理的工程细节两枚（✅）：`nn.Embedding(padding_idx=0)` 让填充位零向量且不更新；配 `nn.utils.clip_grad_norm_` 抑制 RNN 梯度爆炸——短书例程常省掉这两拍 ⚠️，省了「也能收敛」但曲线抖，读数时别当成模型性质。

### RNN/LSTM：按时间步展开的共享权重

- `nn.LSTM(input, hidden)` 返回输出与 (h_n, c_n)（✅），`pack_padded_sequence` 处理变长批（✅）；对照 CNN：时间维共享权重换空间维共享权重（✅ 定性）。批维度 `batch_first=True` 让形状呈 (N, T, H) 与视觉档习惯对齐（✅），默认 (T, N, H) 是旧惯例雷点。
- 长程依赖困境的数学口径：连乘梯度的爆炸/消失（✅，d2l 与花书均有推导位：../DiveIntoDeepLearning.md、../DeepLearning.md，✅ 在盘）；LSTM 门控只是缓解非根治（✅ 定性）——Transformer 的自注意力正是冲这一痛点来的（✅），2026 视角下本书若停在 RNN 项目 ⚠️，该章只剩原理史价值。

### seq2seq 与注意力（若书含 NMT 项目 ⚠️ 推定）

- 编码器压状态、解码器逐步展开、注意力加权中间态（✅ 概念口径，d2l 有全实现）——注意：这是 2017–2020 教学线，非 2026 工程线；工程现行是预训练模型微调（../NaturalLanguageProcessingWithTransformers.md，✅ 在盘）。

1. 短书 NLP 项目常拿假数据/极小语料跑通演示 ⚠️——「能出 loss 下降曲线」≠「模型学到语言」，本节验收标准改为：是否讲清 padding/batch 对齐与嵌入冻结等真工程细节（未核 ⚠️）。
2. 2020 出版 = Transformer 前夜收尾期：若书有 GPT/BERT 章 ⚠️ 大概率为展望性闲笔，实操一律让位 HF 线（../NaturalLanguageProcessingWithTransformers.md）与从零实现线（../BuildALargeLanguageModelFromScratch.md，✅ 在盘）。
3. 词嵌入的「king−man+woman≈queen」类比在严肃教材已判为过度简化 ⚠️ 书若沿用需打折。
4. 不虚构引文页码；本节全部「书中位置」为 ⚠️ 推定，销账前不升 ✅。
5. 词表构建若走「`Counter`+截断」土路（2020 教材常见 ⚠️），与现行子词切分（BPE 等）有一代语义差——读时须声明「这是历史路线，非教学推荐」。

## 🔧 微实验（未实测：本机未装 torch，仅为设计）

- 实验 A：字符级 LSTM 续写小语料（数百行文本），观察 temperature 采样对输出的影响。
- 实验 B：同 batch 混 5/50 长句，跑 `pad_packed_sequence` 往返，实证 padding 不污染输出长度。
- 实验 C：训 3 epoch 后冻结 Embedding（`requires_grad=False`）续训，对比loss 曲线，实证嵌入即参数。
- 实验 D：同一模型分别以 `batch_first=True/False` 前向，比对输出张量形状，实证轴序换形不换算。

## 核心概念中英对照

- **词嵌入** — word embedding：整数 token 到稠密向量的可学习查找。
- **循环层** — recurrent layer (RNN)：时间步共享权重的序列变换。
- **门控单元** — LSTM/GRU：以门控缓解梯度连乘的循环变体。
- **填充与打包** — padding & packing：变长序列组批的配套工艺。
- **编解码架构** — seq2seq：编码状态+解码展开的翻译骨架。
- **注意力** — attention：对中间态按相关性加权的读取机制。
- **梯度裁剪** — gradient clipping：按范数上限缩放，RNN 训练常备。
