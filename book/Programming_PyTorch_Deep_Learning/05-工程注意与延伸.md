## 核心机制

### 存与取：state_dict 是唯一正统

- `model.state_dict()` 存参数字典、`load_state_dict` 取回（✅）——**不存整个对象**（pickle 全模型跨版本即碎，✅ 机理口径）。对照 Keras 的 SavedModel/权重+架构分离双文件制（../DeepLearningWithPython2e.md，✅ 在盘）：两家殊途同归到「架构是代码、权重是数据」这条铁律（✅ 定性）。
- 优化器状态同样可存（`optim.state_dict()`，✅）——续训与断点恢复的正解；2020 后 checkpoint 惯例已含 model/optim/epoch 三件组（✅ 官方教程口径）。

### 训练态 vs 评估态：一个布尔开关两套语义

- `model.train()`/`model.eval()` 切换 Dropout 与 BatchNorm 行为（✅ 事实：BN 用 running stats、Dropout 停掷骰）；评估期再包 `torch.no_grad()` 省显存提速（✅）。忘调 `.eval()` 是「训练 loss 漂亮、验证一塌糊涂」的头号元凶（✅ 机理）——对照 sklearn 无此坑因其无随机层（✅，见 ../MachineLearningWithPyTorchAndScikitLearn.md）。
- 配套小口径：`model.zero_grad(set_to_none=True)` 以 None 代零张量、省一次写（✅；默认值随版本变过 ⚠️ 用前查当前文档）——02 册五拍的第二拍在工程面另有这一维。

### 设备与性能：先量再调

- `.to(device)` 全链路搬运（模型+数据，✅）；本机无 GPU 🔧，一切「上卡加速」论断未实测。AMP 混合精度、`torch.compile`、分布式（DDP 起步）为 2020 后工程主线（✅ 方向）——其中 `torch.compile` 系 2020 书**不可能覆盖**的内容（✅ 年代事实），延伸一律走 pytorch.org 官方文档与教程线（../Python系列·总索引.md 补编节已钉「官方教程线=实操唯一现行口径」，✅ 在盘）。
- 可复现三件套：种子（`manual_seed`）、`DataLoader` worker 种子函数、确定性算法开关（✅ 口径；完全确定与性能有交换代价）。
- 归因工具位：`torch.profiler` 做算子级耗时、`tensorboard`/`SummaryWriter` 做曲线外置（✅ 官方配套存在）——短书几乎不写工具链 ⚠️，此位永远由文档线供给。

## 核心概念中英对照

- **状态字典** — state_dict：模型/优化器参数的纯张量映射，存盘正统。
- **评估模式** — eval mode：关闭 Dropout 随机性与 BN 批统计的开关态。
- **无梯度上下文** — no_grad：推理期免建图省显存。
- **混合精度** — AMP：FP16/BF16 换吞吐的精度工程。
- **分布式数据并行** — DDP：一份模型多卡各吃分桶数据。
- **可复现性** — reproducibility：种子+确定性开关的实验卫生。
- **检查点** — checkpoint：model/optim/epoch 打包的续训快照。
