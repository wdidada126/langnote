# 《TypeScript in 50 Lessons》课带 03 · 部Ⅲ 进阶类型

> 题注 ⚠️：课号与逐课原名以版权页为准（Manning 页本波 404 未破墙）；本档是按 TS 通行机制写的「课带地图」，不冒充书中原文。
> 证据三态：✅ = 本机 node v22.14.0 `--experimental-strip-types` 真跑（/tmp/t50/，2026-10-07）｜⚠️ = 通行机制归纳｜🔧 = 待实测位（无独立 tsc，类型层「算得对不对」不可本机实证，只能实证「运行时零痕迹」面）。

## 一、课带地图（部Ⅲ · 约 13 课位）

- 课位 Ⅲ-1 · 泛型函数与约束：`<T extends Shape>` 把「类型=集合」兑现成参数——T 是变量，extends 是它的花名范围。
- 课位 Ⅲ-2 · 泛型接口/类与默认类型参数：声明位置上同样开参；`<T = string>` 给调用方省样板。
- 课位 Ⅲ-3 · 变型注解 `in`/`out`：TS 4.7+ 显式标参数协/逆变位——文档化+让编译器代检，对照 Kotlin/Variance 一脉（本书 2022 覆盖与否 ⚠️）。
- 课位 Ⅲ-4 · 条件类型：`T extends U ? X : Y` 是类型层的 if——集合语言下即「T 是否 ⊆ U」的子集判定， distributing 语义对联合自动逐成员跑。
- 课位 Ⅲ-5 · `infer`：条件类型里「挖个坑接住被匹配的结构」——`extends (...args: infer A) => infer R` 是 ReturnType/Parameters 一族的本体。
- 课位 Ⅲ-6 · 分发与 never 陷阱：裸类型参数上的联合自动分发；`never` 进条件类型整体塌为 never——高级类型两大经典坑位。
- 课位 Ⅲ-7 · 映射类型：`[K in keyof T]: F<T[K]>` 是类型层的 for——Partial/Pick/Omit 全族由这一式生成。
- 课位 Ⅲ-8 · 修饰符读写：`+readonly`/`-readonly`、`?`/`-?` 增减号——Required 与 `+?` 组合把「全必填」一句话写完。
- 课位 Ⅲ-9 · 键重映射 `as`：`[K in keyof T as \`get${Capitalize<K>}\`]`——映射类型的 filter/map 出口，通向 getter 生成器类宏。
- 课位 Ⅲ-10 · 模板字面量类型：`` `a${B}` `` 在字符串类型上做正则式拆解与拼接；与 as 重映射合成「字符串类型编程」双件套。
- 课位 Ⅲ-11 · 变长元组与解构：`[...T, X]`、`readonly [...A, ...B]`——元组上的正则语言直觉，尾随 rest 只允许一个。
- 课位 Ⅲ-12 · 递归类型与深度：JSON 值类型、深 Readonly 自引用即成；实例化深度上限报错是类型层「栈溢出」形态（具体码待 tsc 实测 ⚠️）。
- 课位 Ⅲ-13 · 工具类型内幕收束：把 Ⅲ-5/7/9 合读，Partial/Pick/Omit/ReturnType 全数一页可重写——本 band 的「分发消息」课位在此回收（判别式分派=运行时的镜像，类型层用条件类型分派）。

## 二、本书特色处

- `infer`/分发消息课向（00 骨架钉的 Ⅲ 部代表课）：把条件类型从「炫技」拉回「结构解构」的定位——infer 是模式匹配的回车键，这个讲法与 Type_Level_TypeScript 的「类型=程序」观互补（一个偏算子一个偏集合）。
- 类型层编程的「渐进三件」：约束→条件→映射，本书按可写可跑的例程推进 ⚠️（体例推断），本 band 课序按同一路径重排。
- 集合观在 Ⅲ 部兑现（接课带 01 收束锚）：extends 判定=⊆、联合=∪、never=∅——Ⅰ 部立的直觉到这里全部开花。

## 三、🔧 实验

✅ 实测（node v22.14.0，`--experimental-strip-types`，本档 1 跑）：

- `generics.ts`：映射+条件+递归三件套注解的 `type Deep<T>` 与泛型 `const id = <T,>(x: T): T => x` 直跑成功（exit=0）；`v === w` 为 true、原型检查为 Object.prototype、`"Deep" in globalThis` 为 false——**类型层的图灵级计算在运行时零痕迹**：泛型 T 无任何留存（对照 Kotlin `reified` 的逃逸口、Java 桥方法的残影，见专题档四语言对照表），`id` 产物就是恒等函数本数。
- 边界确认：本跑同时证明 `<T,>` 尾逗语法、递归 type 别名纯擦除可跑——Ⅲ band 只有 `enum`（产码语法）会被 strip-only 拒收，见课带 01/04。

🔧 待测（需 tsc ⚠️）：`Extract/Exclude/ReturnType` 手写版 × `tsc --noEmit` 的正误样例集；递归深度报错形态实录——挂 04 diff 框架。

## 五、中英对照

| 中文 | 英文 | 一句定义 |
|---|---|---|
| 泛型 | generics | 以类型为参数的类型定义 |
| 约束 | constraint | `extends` 限定类型变量的取值范围 |
| 变型注解 | variance annotation | `in`/`out` 显式标参数协/逆变位 |
| 条件类型 | conditional type | 类型层 if：子集判定选支 |
| 推断位 | infer position | 条件类型中接住匹配结构的类型变量 |
| 分发 | distribution | 条件类型对联合逐成员自动计算 |
| 映射类型 | mapped type | `for` over keys：按键遍历再造形状 |
| 键重映射 | key remapping | `as` 子句改名/滤键 |
| 模板字面量类型 | template literal type | 字符串字面量上的拼接与拆解 |
| 变长元组类型 | variadic tuple types | `[...A, B]` 元组上的 rest 运算 |
| 递归类型 | recursive type | 自引用类型定义，受实例化深度上限约束 |
| 工具类型 | utility types | 官方预置映射/条件类型族（Partial 等） |
