## 一、课带地图（部Ⅰ · 约 12 课位）

- 课位 Ⅰ-1 · 工具箱与编译单元：tsconfig/tsc 在工具链的位置；「TS 程序先变 JS 再运行」是全书地基认知。
- 课位 Ⅰ-2 · 原始类型：string/number/boolean 三大件加 null/undefined/symbol/bigint——与 JS 运行时原始值一一对应，无装箱层。
- 课位 Ⅰ-3 · 字面量类型：`"a"`、`3` 本身即类型（一个成员都不多），判别联合与模板字面量型的整个后续生态由此长出。
- 课位 Ⅰ-4 · 数组与元组：`T[]` 是定形数组的类型化；元组 `[A, B]` 用字面量数钉死长度与位置——两者都是结构化类型的特例。
- 课位 Ⅰ-5 · 对象与匿名类型：`{ a: number }` 形状即类型，没有「先声明后使用」的名义义务。
- 课位 Ⅰ-6 · 类型推断：注解是期望不是断言——在声明处写类型、消费处放手，与 Java 声明心智反着来。
- 课位 Ⅰ-7 · 结构化类型：形状相同即可赋值，implements 不必要；本系列对 Java/C++ 名义类型最根本的对立公理（上游 axiom 见 Learning_TypeScript 档）。
- 课位 Ⅰ-8 · type 别名：给任意类型（联合/元组/函数签名皆可）起新名；别名自身不参与身份判定——结构化到底。
- 课位 Ⅰ-9 · interface：只能命名对象形状，但可声明合并与 extends；「逢对象类型先用 interface」是旧 advice，按需裁决。
- 课位 Ⅰ-10 · 联合类型：`A | B` 是集合不是「二选一」开关态；未收窄前只能调用两侧交集成员。
- 课位 Ⅰ-11 · 交叉类型：`A & B` 是集合交，叠形状常用（mixin 手法的地基）；函数交叉=重载的类型层表达（Ⅱ band 回收）。
- 课位 Ⅰ-12 · 类型=集合（部收束双锚）：可赋值即 `⊆` 判定，类型安全全是子集演算；Ⅲ band 条件类型整条长在这一直觉上。

- 「擦除」叙事开门即立：类型层产物编译后=普通 JS，运行时零痕迹——与本仓独立专题档同源（见下方互链），本波已把该专题的「enum 拒跑 ⚠️ 待补实测」销账为 ✅。

## 三、🔧 实验

✅ 实测（node v22.14.0，`--experimental-strip-types`，本档 3 跑）：

- `erase.ts`：`type/interface/satisfies/as const/泛型函数` 全数擦除直跑成功（exit=0）——部Ⅰ 纯擦除语法面可零编译循环复演。
- `nocheck.ts`：`const n: number = "oops"` 照常运行且 `typeof n === "string"`——删注解≠查类型，number 盒里装 string 无人报警（专题档实验 B 复证）。

## 五、中英对照

| 中文 | 英文 | 一句定义 |
|---|---|---|
| 原始类型 | primitive type | 与 JS 运行时原始值同构的六+二类型，无装箱 |
| 字面量类型 | literal type | 值本身即类型，集合里只住一个成员 |
| 元组 | tuple | 长度与逐位类型钉死的对象类型 |
| 类型推断 | type inference | 编译器由初值反推类型，注解可省 |
| 结构化类型 | structural typing | 可赋值性由形状而非名字决定 |
| 类型别名 | type alias | 给任意类型起新名，无独立身份 |
| 接口 | interface | 对象形状的命名，可声明合并 |
| 联合类型 | union type | 集合并；收窄前只用公共面 |
| 交叉类型 | intersection type | 集合交；函数交叉≈重载 |
| 判别联合 | discriminated union | 带字面量 tag 的联合，收窄主粮（Ⅱ band 登场） |
| 类型擦除 | type erasure | 编译期类型层全数剥除，产物裸 JS ✅实测 |
