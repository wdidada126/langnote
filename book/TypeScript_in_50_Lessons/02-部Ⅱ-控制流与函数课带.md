## 一、课带地图（部Ⅱ · 约 13 课位）

- 课位 Ⅱ-1 · 控制流分析（CFA）总起：TS 顺着 if/switch/循环的可达路径给变量「实时改类型」——收窄是流程敏感的全局性质，不是某个运算符的私活。
- 课位 Ⅱ-2 · typeof 收窄：`typeof x === "string"` 分支内 x 被剪到对应原始子集；对联合逐成员裁剪。
- 课位 Ⅱ-3 · 真值收窄：`if (x)` 剪掉 `undefined/null/""/0` 等假值 inhabitant——粗但常用，配合 `??` 更精确。
- 课位 Ⅱ-4 · in 运算符收窄：`"tag" in obj` 按属性存在性分派联合两侧，属性名是字符串字面量。
- 课位 Ⅱ-5 · instanceof 收窄：对类实例按原型链判定改型——注意这是**运行时真存在**的机制（原型链在），与纯类型层判定不同色。
- 课位 Ⅱ-6 · 判别联合收窄：tag 字面量 switch 分派；分派穷尽时 default 分支变量收窄为 `never`，可借「不可达处赋值必报错」技巧做穷尽性检查。
- 课位 Ⅱ-7 · 类型谓词：`x is Foo` 返回布尔的自定义收窄函数——把 CFA 能力扩展给用户代码，声明层游戏。
- 课位 Ⅱ-8 · 断言函数：`asserts x is Foo`——谎称即拦截的运行时 throw + 编译期收窄双写；擦除世界里它是最接近「运行时类型检查」的语法，检查本体还得自己写。
- 课位 Ⅱ-9 · 可选属性与可选链：`?:` 使属性类型自动并上 `undefined`（strictNullChecks 语境）；`?.`/`??` 是 JS 语法（运行时真在），TS 只是让类型跟上。
- 课位 Ⅱ-10 · unknown：类型层的「顶」——不可调用不可投影，只能先收窄再用；与 `any`（逃生舱）对偶。
- 课位 Ⅱ-11 · 函数类型与逆变直觉：`(a: A) => B` 形状可标注；参数按「接收更宽的实现可替换」方向兼容（strictFunctionTypes 语境）——与返回协变合成子集直觉。
- 课位 Ⅱ-12 · 可选/默认/剩余参数：`?`/`= 默认值`/`...rest: T[]`——调用签名层的形状描述，重载消减大半于此（对照 Kotlin 默认参数消灭重载的同一剧情）。
- 课位 Ⅱ-13 · 函数重载：`f(a: A): B; f(a: C): D` 声明多个签名，实现签名对调用方隐藏；交叉类型是重载的另一面（接 Ⅰ-11）。

## 二、本书特色处

- CFA 专课地位（00 骨架钉的「控制流分析专课」）：多数书把收窄散落在联合章里打零工，本书把流程敏感分析立成机制本体——本仓 Ⅱ band 依此以 CFA 开部。
- 判别联合「分发消息」课向（00 骨架记）：tag 分派 + never 穷尽检查的组合拳，是 Ⅲ band 条件类型/映射的运行时语义参照物。
- 函数交叉=重载的等价表达这一桥（⚠️ 通行机制，是否书中明说待销账）：把 Ⅰ-11 与 Ⅱ-13 缝成一条线，属本书「一课一机制、机制互收束」体例红利。

## 三、🔧 实验

✅ 实测（node v22.14.0，`--experimental-strip-types`，本档 1 跑）：

- `narrow.ts`：判别联合 `switch`-等价分派（`m.tag === "num" ? ...`）、`unknown` 注解、`as` 断言、`?.`/`??` 链全部直跑成功（exit=0，输出 `n=1 s=x number 43 optional chain fallback`）。运行时读解：**收窄在产物里就是普通属性比较**——tag 字段本来就是真数据，类型层只是学会了用它；`as` 不产生任何转换或检查（撒谎面复证）。

🔧 待测（需 tsc ⚠️）：同一 union 变量 × typeof/in/instanceof/谓词四种收窄写法的「编辑器报错位点矩阵」；never 穷尽检查的报错样例——方案挂课带 04 统一 diff 框架，同题实测档见 [../Learning_TypeScript/05-联合类型与收窄.md](../Learning_TypeScript/05-联合类型与收窄.md)（三路收窄 JS 等价物已 ✅ 实测）。

## 五、中英对照

| 中文 | 英文 | 一句定义 |
|---|---|---|
| 控制流分析 | control flow analysis (CFA) | 沿可达路径为变量动态收窄类型 |
| 收窄 | narrowing | 把变量类型剪到联合的更小成员 |
| typeof 收窄 | typeof narrowing | 按运行时类型标签裁剪原始类型 |
| in 收窄 | in-operator narrowing | 按属性名存在性分派联合 |
| 判别式 | discriminant | 联合成员共享的字面量 tag 字段 |
| 穷尽检查 | exhaustiveness check | default 分支 never 赋值报错兜漏派 |
| 类型谓词 | type predicate | `x is T` 形返回布尔的自定义收窄 |
| 断言函数 | assertion function | `asserts x is T`，throw 即拦 |
| 可选链 | optional chaining | `?.` JS 语法，运行时真在 |
| 空值合并 | nullish coalescing | `??` 只对 null/undefined 兜底 |

| 参数逆变 | parameter contravariance | 接收更宽参数的实现可替换 |
