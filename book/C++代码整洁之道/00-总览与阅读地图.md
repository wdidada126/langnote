## 三条阅读路线

1. **主线（01→13）**：熵与原则（01–03）→ 表述层整洁（04–05）→ 现代 C++ 机制（06–08）→ 抽象层（09–10）→
   过程层（11）→ 模式与惯用法（12–13）。第一次通读走这条；本书的独特价值在于它是**唯一把"清洁代码运动"
   与"C++11/14/17 机制"缝在一起的中文书**，主线读法能完整看到这条缝合线。
2. **资源与错误线（工程浓度最高）**：`06`（RAII/智能指针/Move/零法则）→ `07`（编译期计算/UB/Type-Rich）→
   `08`（异常六条 + C++23 `std::expected` 对位）→ `12`（Copy-and-Swap、PIMPL）→
   [../大规模C++程序设计/05-编译防火墙：隔离技术.md](../大规模C++程序设计/05-编译防火墙：隔离技术.md)——
   从"类怎么写不漏"一路走到"整个工程怎么不断编译"。
3. **过程与测试线（团队落地必读）**：`02`（十二条单元测试规则）→ `03`（原则）→ `11`（TDD 与罗马数字 Kata 全程九轮）→
   `12` 的依赖注入与测试替身节 → [../架构整洁之道/14-层次与边界Main及测试边界.md](../架构整洁之道/14-层次与边界Main及测试边界.md)。
   这条线是本书与 Martin 两书真正短兵相接的地方。

**最短路径**：只读 `06` + `08` + `12`——机制账本、错误处理账本、模式瘦身账本各一份，约 90 分钟。

## 辨析节：本书在书架上的确切位置

### 1. vs 《代码整洁之道》目录版（Robert C. Martin, *Clean Code*）

| 维度 | [../代码整洁之道/00-总览与阅读地图.md](../代码整洁之道/00-总览与阅读地图.md) | 本目录（Clean C++） |
| --- | --- | --- |
| 语言立场 | 语言无关（示例 Java/敏捷社区口径） | **C++17 专门化**：每个论断都落到 RAII、移动、`constexpr`、智能指针 |
| 最大分歧点 | "函数理想 0 参、超过 3 参需特殊辩护"（Martin 原话） | 本书 4.3.5 **照引此说并当场打折**：成员函数有隐式 `this`，"0 参"实为读改对象状态；判据应是"参数是否表达同一概念" |
| 注释观 | "注释是失败的替代品"（强命题） | 4.2 同样反对废话注释，但明确保留 5 类有用注释（Doxygen 契约、许可证头、变更历史、特例说明） |
| 是否讲现代机制 | 不讲（2008 年成书，无 move/无智能指针规范） | 第 5 章整章即为此而设——**两书互补而非重复** |

**读法建议**：Martin 的"应该是什么"配 Roth 的"C++ 里怎么落"。凡 Martin 口号式规则，本书几乎都给了 C++ 版本的可执行判据。

### 2. vs 《架构整洁之道》目录版（Robert C. Martin, *Clean Architecture*）

[../架构整洁之道/00-总览与阅读地图.md](../架构整洁之道/00-总览与阅读地图.md) 谈**组件、边界、依赖方向、UI/DB 无关性**；
本书 6.3.2–6.3.7 逐条复述 SOLID + ADP（同一套原则，C++ 落地示例不同：本书用 `Customer/Account` 头文件循环演示 ADP，
Martin 用插件架构演示 DIP）。**本书几乎不做架构层论述**——它止步于类与库；要往上走必须换书。

### 3. vs 《C++ 编程惯用法》目录版（SIGS 1993 论文集）

[../C++编程惯用法/00-总览与阅读地图.md](../C++编程惯用法/00-总览与阅读地图.md) 是 **C++98 之前的多作者文集**：handle/body、
动态异常规范、COW 引用计数。本书 9.3 的 PIMPL、5.1 的 RAII、5.7 的异常纪律正是那些惯用法的**标准化后世**。
两书对读=一份 1993 病历 + 一份 2017 复诊单。

### 4. vs 《C++ Core Guidelines 解析》目录版

[C++CoreGuidelines解析/00-总览与阅读地图.md](../C++CoreGuidelines解析/00-总览与阅读地图.md) 按 Stroustrup/Penslar 的
**规则编号体系**（P/N/RES/CP 与 `cppcoreguidelines-*`）组织；本书按**主题叙事**组织，无编号、不可机检。
差别即用途：写作时查规则编号用 CG 版，建立判断力用本书；本书的"最新演进与工业实践"节负责把书中主张映射到
clang-tidy/cppcheck 的可执行规则上（各章已就地给出映射表）。

### 5. vs Effective 系列与同波 C++ 书目

[../Effective_Modern_C++.md](../Effective_Modern_C++.md)（42 条条款，C++11/14 机制说明书）与本书第 5 章重叠最重，
但 Effective 系列是**条款+反例**的参考书体，本书是**熵→原则→表述→机制→抽象→过程→模式**的教材体；
[../C++API设计/00-总览与阅读地图.md](../C++API设计/00-总览与阅读地图.md) 则从 ABI/导出符号层面接管本书讲不到的对外接口问题。
