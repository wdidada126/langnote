## 一、问题清单（真实工程问题 → 通行解法梗概）

1. **「第三方库没类型，编辑器满屏 implicitly any。」** — 三岔路：先查 `@types/<lib>`（DefinitelyTyped）→ 无则手写 `declare module "lib" { … }` 环境声明渐进补型 → 应急 `// @ts-ignore`（下下策）/`ts-expect-error`（有断言语义：它修好了你会收到通知）。
2. **「想给别人的类型加方法/属性（给 Express req 挂 user）。」** — 声明合并（declaration merging）/模块增强：`declare module "express" { interface Request { user?: User } }`——**接口可开、type 别名不可开**是本食谱的第一分叉；越界改库型要写注释认领。
3. **「strict 全家桶到底开哪些？」** — 通行起点 `"strict": true`（打包 noImplicitAny 等核心项）；进阶单独评估 `exactOptionalPropertyTypes`/`noUncheckedIndexedAccess`/`useUnknownInCatchVariables`——2e 时代口径「strict 全量」⚠️ 条号待 Effective 2e Ⅵ 部销账。
4. **「d.ts 和 types 字段、@types 包谁优先？」** — 解析序（通行版）：`package.json` 的 `types`/`typings` → 同目录 `index.d.ts` → `@types` 兜底；发布侧自带型（bundled）优先于 DefinitelyTyped ⚠️ 精确规则随版本演进，以 TS handbook 复核。
5. **「哪些 TS 语法不是『纯擦除』，工具链迁移会踩？」** — **产码语法三件套：`enum`、参数属性（`constructor(private x)`）、`namespace`**（外加装饰器 emit 面）——违背「类型全删」公理，strip-only 管线一律拒收。🔧 实验 E1/E2 本机实测 ✅：node v22.14 `--experimental-strip-types` 对 enum 报 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` exit=1；参数属性+namespace 同报双拒 exit=1。**本条即专题档四节戒律 4『strip-types 拒跑 enum 即界碑 ⚠️ 待补实测』的销账实测** ✅。
6. **「全局脚本（无 import 的 .ts）和新建模块互相污染 window。」** — `export {}` 一行改模块身份；全局增强走 `declare global`。混编事故位：`allowJs`+无 check 目录的隐性豁免 ⚠️。
7. **「CI 里类型门禁怎么装？」** — `tsc --noEmit` 独立跑（产物零改变=纯检查），与构建解耦；专题档戒律 1「CI 无 tsc=裸奔」的工程化落点。本机无独立 tsc ⚠️（00 档口径：装 `npm i -D typescript` 后销账——**禁 npm install 期间本条只记解型不记断言**）。

## 三、🔧 最小复现（node v22.14.0 `--experimental-strip-types`）

E1 · `enm.ts`（产码语法·界碑）：

```ts
enum Color { Red, Green }
console.log(Color.Red);
```

实测：`SyntaxError [ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX]: TypeScript enum is not supported in strip-only mode`，**exit=1** ✅。

E2 · `ppns.ts`（产码语法·双拒）：

```ts
class C { constructor(private readonly x: number) {} get v() { return this.x; } }
namespace NS { export const y = 1; }
console.log(new C(1).v, NS.y);
```

实测：同型错误**两条并发**（parameter property + namespace declaration），exit=1 ✅——
「纯擦除带」与「产码混合带」的分界不靠记忆背，靠管线拒收日志（专题档戒律 4 的『迁移脚本兼容地雷位』实证）。
对照 ✅：1–5 带全部样例在 strip-only 下 exit=0——纯类型层语法跨这条线无痛，产码语法跨线即死。

## 五、中英对照

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 声明文件 | declaration file (.d.ts) | 类型侧车，无实现 |
| 环境模块声明 | ambient module declaration | `declare module "x"` 补第三方型 |
| 声明合并 | declaration merging | interface 可开、type 别名不可 |
| 模块增强 | module augmentation | 越界给库类型加成员，要认领 |

| 产码语法 | emit-generating syntax | enum/参数属性/namespace，违纯擦除 |
