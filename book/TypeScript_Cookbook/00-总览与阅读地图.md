# 《TypeScript Cookbook》——总览与阅读地图

> 目标书：*TypeScript Cookbook: Real-World Type-Level Programming*（题名强匹配数据集 ✅，ISBN 9781098136659 / 1098136659 O'Reilly 2024），**作者第三方称 Stefan Baumgartner ⚠️**（本波检索结果未带作者字段，不写死）。
> 注意：存在同名/近名食谱书（如 Packt 系）——销账时先定版权页，防串号。

## 一、定位

问题驱动食谱线：Recipe（问题→解→讨论）体例，与 Kotlin Cookbook 同构。本书特色在副标题——**面向类型级编程的真实问题**（把体操当工程工具而非杂技），因此与 Type-Level TS 是「手册↔教材」关系。

## 二、骨架（⚠️ 章数/章名凭第三方简介与记忆，以版权页为准）

| 章带 | 主题方向 | 本仓用法 |
|---|---|---|
| 类型操作基础 | 收窄、守卫、工具类型再造 | 当 Effective 条目反例弹药库 |
| 函数与泛型 | 高阶泛型、参数推断技巧 | `infer` 用法目录 |
| 对象与映射 | 映射类型、键重排、深只读 | ↔ C++20 类型变换Trait 对照 |
| 判别与状态机 | 判别联合建模、穷尽处理 | 前端状态/事件总线食谱 |
| 类型级计算 | 条件链、模板字面量、递归类型 | 与 Type-Level TS 重叠带，食谱式速查 |
| 工程集成 | 声明文件、第三方库补型、模块边界 | @types 实战位 |

## 三、读法

工具书查章制：写 TS 撞到「这个形状怎么表达」→ 按主题带查 Recipe；每则采纳 Recipe 落一行「本仓裁决+可复演代码」到分章档。不做线性通读。

## 四、🔧 实测口径

每 Recipe 抄最小复现版，`tsc --noEmit` 验证成立/反例报错位点；纯类型实验可配 `// @ts-expect-error` 断言报错存在（该指令语义本身也值得入档：报错即测试）。本机独立 tsc 未装 ⚠️——装 `npm i -D typescript` 后销「未实测」。
