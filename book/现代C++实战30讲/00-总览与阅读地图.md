## 3. 本书（专栏）的方法论主线

| 主线 | 专栏的讲法 | 落到工程上的判据 |
| --- | --- | --- |
| **资源即对象** | 01、02：栈对象与 RAII，再手写智能指针 | 构造即获取、析构即释放；异常不该泄漏资源 |
| **移动优于拷贝** | 03、10：右值、移动构造、返回对象 | 大对象返回不必再「 outsourcing 出参」 |
| **把工作搬到编译期** | 12–15、18：模板、constexpr、SFINAE、可变模板 | 运行时零开销，错误提前到编译期 |
| **正确性优先于花活** | 06、20：异常、内存模型 | 先用 `seq_cst` 写对，再谈 `acquire/release` |
| **标准库优先于自造** | 04、05、13、24：容器、Boost、数字库 | 造轮子前先查标准库与 Boost |
| **工具链是生产力** | 21、25–27：编译、检查、测试、日志、HTTP | 自动化的格式化与 CI 检查比个人纪律更可靠 |

## 4. 三条主线的时间轴（C++11 → C++26）

| 年份 | 事件 |
| --- | --- |
| 2011 | **C++11**：右值引用、`auto`、智能指针、lambda、`constexpr`、`std::thread`/`std::future`、内存模型 |
| 2014 | **C++14**：泛型 lambda、`constexpr` 放宽、二进制字面量、变量模板 |
| 2017 | **C++17**：`std::optional`、`string_view`、fold expression、`if constexpr`、并行算法与执行策略、`inline` 变量 |
| 2020 | **C++20**：概念（Concepts）、Ranges、`std::jthread`/`stop_token`、协程、`std::format`、`std::span`、`atomic::wait/notify` |
| 2023 | **C++23**：`std::expected`、模块落地（`std` 模块）、`std::print`、`if consteval`、`std::move_only_function`、多维下标 |
| 2026 | **C++26 在路上**：反射、`std::hazard_pointer`/RCU、`std::execution` 并行算法补齐、SIMD 与「零开销抽象」进一步收敛 |

## 8. 阅读建议

1. **基础篇（01–09）建议原速过**，它们的写法直接决定你后续代码长什么样；尤其 01、02、03 三讲是全部现代 C++ 的地基。
2. **提高篇（10–20）建议动手改**：每讲的代码都在仓库里有对应文件，试着关掉优化改一遍，看 benchmark 的变化。
3. **实战篇（21–27）建议对照自己的项目**：你的构建系统、测试框架、日志库大概率与讲中不同，重点是**方法**而不是**库名**。
4. **未来篇（28–30）建议与编译器版本绑定阅读**：C++20 特性在 GCC 11+/Clang 15+/MSVC 19.33+ 上才有较完整支持，别在旧工具链上硬套。
5. 🔧 **2026 年的补读顺序**：讲 06+22 → 补 `std::expected`（C++23）；讲 15 → 补 C++23/26 的 `constexpr` 容器与 `if consteval`；讲 20 → 补 `atomic::wait/notify` 与 C++26 的 hazard pointer。
