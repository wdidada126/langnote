## 1.1 成书语境的"安装"：Oracle7/Oracle8 时代（⚠️）

本书 1999 年出版，覆盖 Oracle7 与 Oracle8 两代（封面与版权页文案 "covers Oracle7 and Oracle8"，✅ 封面图与 K10plus 书目记录目读实证）。这个语境的"安装"与今天的直觉完全不同：

| 维度 | Oracle7/8 时代（本书语境） | 今日（23ai/26ai） |
|---|---|---|
| 安装器 | 平台原生安装程序（脚本式引导，8.1.x 起才有图形化 OUI 雏形） | 统一 Oracle Universal Installer（runInstaller / zip+GUI） |
| 建库 | 手工跑 `cata.sql`/`catalog.sql`/`catproc.sql` 等字典脚本，或早期 DBCA | DBCA 模板化一键建库，或 `dbca -silent` |
| 参数 | 纯文本 `init<SID>.ora`（pfile），改后重启生效 | 默认 SPFILE（库内二进制参数）+ pfile 混合 |
| 实例识别 | ORACLE_SID + `oratab`（UNIX）/注册表（NT） | 同左，另有多租户 CDB/PDB 层 |

本书作为速查参考的价值恰在这里：它把"装完之后怎么把它开起来、关下去、进到什么状态"写成查表式清单——这是 1985 年起做 DBA 的 Kreines（出版社文案：自 1985 年做 Oracle 开发与管理、OCP 认证、两届 IOUG-A 会长）与 Laskey（11 年 DBA、OCP 7.3/8.0 双认证）的日常肌肉记忆。

## 1.2 启停四态与启动选项（⚠️ 文档转述）

实例生命周期三态 + 过渡态，自 Oracle7 定型、至今未变（这是本书少数"原样活到 2026"的知识）：

```
SHUTDOWN [NORMAL|IMMEDIATE|ABORT]
  └─ OPEN ── MOUNTED ── STARTED(NOMOUNT) ── 实例未起
STARTUP [NOMOUNT|MOUNT|OPEN] [READ ONLY] [RESTRICT]
```

- `STARTUP NOMOUNT`：只起实例（SGA+后台进程），读 pfile、不打开控制文件——建库与建控制文件场景；
- `MOUNT`：打开控制文件、不打开数据文件——重命名数据文件、切换归档模式、介质恢复场景；
- `OPEN`：按控制文件清单打开全部数据文件（允许部分文件失败进入 mounted 后单独 OFFLINE）；
- `RESTRICTED`：仅 `RESTRICTED SESSION` 权限者可连——迁移/升级窗口；
- SHUTDOWN 三档语义差：NORMAL 等全部会话自然退出、IMMEDIATE 回滚未提交事务后断开、ABORT 什么都不做留给 SMON 下次启动时恢复。ABORT 后的"冷启动=一次介质恢复演练"是 DBA 面试经典题（⚠️ 通说）。

## 1.3 安装后的第一批必做清单（⚠️ 按本书"任务清单"体裁重构）

本书文案自述"crammed full of quick-reference tables, task lists"（满是速查表与任务清单）。安装域的清单骨架（本目录依据公开 Oracle 文档自拟，不代表原书小节）：

1. 归档模式决策：`ARCHIVELOG` vs `NOARCHIVELOG`——决定 03 章备份能力的分水岭；`log_archive_start`/`log_archive_dest` 在 8.0 是安装后立即要设的参数；
2. 控制文件镜像：`control_files` 至少两份异盘——本书"防数据损失"单元的最低成本保险；
3. rollback 段规划：系统回滚段 + 按需 PUBLIC 回滚段（Oracle8 尚无 UNDO 表空间，8i 才有自动管理，⚠️）；
4. 口令文件：`orapw<SID>` + `GRANT SYSDBA`——远程 SYSDBA 认证的前提（与 [../Oracle_Security/02-认证机制与口令防线.md](../Oracle_Security/02-认证机制与口令防线.md) 同一对象，视角不同：那边讲安全面，这边讲安装步骤）；
5. 字典收尾验证：`SELECT * FROM dict` 能否查询、`SQL*Plus` 能否 `CONNECT / AS SYSDBA`。

## 1.5 安装后的目录地形（⚠️ 通说转述）

速查书的第一课是"东西在哪"。Oracle7/8 在 UNIX 上的家目录地形（NT 同构，路径换盘符）：

| 目录 | 内容 | DBA 日常频率 |
|---|---|---|
| `$ORACLE_HOME/dbs/` | `init<SID>.ora`、`orapw<SID>`、归档日志默认落点 | 高（07 章主场） |
| `$ORACLE_HOME/network/admin/` | `listener.ora`、`tnsnodes.ora`（04 章主场） | 高 |
| `$ORACLE_HOME/rdbms/lib/`、`bin/` | 可执行 `oracle`、`sqlplus`、`exp`/`imp`、`sqlldr`（08 章主场） | 中 |
| `$ORACLE_HOME/rdbms/admin/` | `catalog.sql`、`catproc.sql`、字典构建脚本群 | 装机一次 |
| `$ORACLE_HOME/plus/`、`sqlplus/demo/` | DEMO 建表脚本（BONUS/SALGRADE 等） | 学习期 |
| `$ORACLE_HOME/demo/startup/` | 示例建库脚本 `startor.sql` 一类 | 装机参考 |

环境变量三件套：`ORACLE_BASE`（根）、`ORACLE_HOME`（某版本产品树）、`ORACLE_SID`（默认实例）——多版本共存与"一台机器多个 SID"全靠这三个变量切换，这是 07 章"一个实例一个 pfile"的物理基础。

## 1.6 启动失败速查表（⚠️ 本目录自拟骨架）

本书体裁是"危机时刻能翻到那一页"（出版社文案：you need to do all this under pressure, while you face crisis after crisis）。启停域的高频故障-处置对（错误码为通说示例，非原书转录）：

| 症状 | 常见根因 | 处置 |
|---|---|---|
| `ORA-01078` failure in processing system parameters | `init<SID>.ora` 缺失/改名 | 核对 dbs 目录与 ORACLE_SID 拼写 |
| `ORA-00205` system parameter error, control file not found | `control_files` 所列路径有文件丢失 | NOMOUNT 后查 `v$controlfile`，用好的镜像替换坏位 |
| `ORA-01102` cannot mount database in EXCLUSIVE mode | 残留进程/锁文件 | 清 orphan 的 `sga` 锁与 PMON 进程 |
| `ORA-01033` ORACLE initialization or shutdown in progress | 正在 ABORT 恢复中 | 等 SMON，勿叠加操作 |
| `ORA-01034` ORACLE not available + `ORA-27101` | 实例没起或 SID 指错 | `ps -ef | grep ora_pmon` 验证 |
| 口令文件缺失导致远程 SYSDBA 被拒 | orapw 未建/`REMOTE_LOGIN_PASSWORDFILE=NONE` | 02/05 章交叉：建文件+设参数 |

## 核心概念速览（中英对照）

| 中文 | 英文 | 一句话 |
|---|---|---|
| 实例 | instance | SGA+后台进程的内存组织，启停操作的对象 |
| 启动三态 | NOMOUNT / MOUNT / OPEN | 不读控制文件 / 读而不开数据文件 / 全开 |
| 中止关闭 | SHUTDOWN ABORT | 不做清理，下次启动由 SMON 做实例恢复 |
| 受限会话 | RESTRICTED SESSION | 升级/迁移窗口的连接闸门 |
| 参数文件 | initialization parameter file (pfile) | 8.0 时代唯一形态，纯文本 init<SID>.ora |
| 口令文件 | password file (orapw) | 远程 SYSDBA 的库外凭据账本 |
| 回滚段 | rollback segment | UNDO 表空间之前的手工 undo 单元 |
| 归档模式 | ARCHIVELOG mode | 联机备份与时间点恢复的前提开关 |
| 环境变量三件套 | ORACLE_BASE / ORACLE_HOME / ORACLE_SID | 多版本多实例定位的坐标系 |
| 后台进程 | background process (PMON/SMON/DBWR/LGWR/ARCH) | 实例"活着"的判据，ps 查 PMON |
| 数据字典脚本 | catalog.sql / catproc.sql | 建库后把裸存储变成可查字典的仪式 |

## 最新演进与工业实践

- **安装器演进**（⚠️）：8.1.6（1999 末，恰在本书付梓后）Oracle Universal Installer 图形化统一各平台；9i 引入 DBCA；12c 起软件安装与建库彻底解耦（GI/RAC 先装网格基础设施再装 DB 家目录）；23ai/26ai 提供 zip 介质+`runInstaller -silent` 与镜像化交付。✅ 现行文档入口：https://docs.oracle.com/en/database/oracle/oracle-database/23/ （实抓 200，已重定向至 /26/ 首页——docs.oracle.com 默认版本已切到 26ai 家族，这本身是 2026 年的取证事实）。
- **启停语义的长寿**（⚠️）：NOMOUNT/MOUNT/OPEN 与 SHUTDOWN 三档在 23ai 文档中原文保留（✅ SQL*Plus/SQLcl 手册 https://docs.oracle.com/en/database/oracle/oracle-database/23/sqpug/ 经重定向实抓 200）；新增的是 `STARTUP FORCE`（=ABORT+STARTUP）与只读打开用于 Data Guard。
- **SPFILE 与参数在线化**（⚠️）：9i 引入 SPFILE 与 `ALTER SYSTEM ... SCOPE=MEMORY|SPFILE|BOTH`，本书"改 pfile 重启"的工作流被"多数参数在线可调"替代；pfile 退化为引导 SPFILE 的桥（`CREATE PFILE FROM SPFILE`）。
- **工业实践**（⚠️ 通说）：今天没有企业手工装 Oracle7/8；本章价值转为两类——①认证考试与面试仍考启停状态机；②遗留系统考古（金融/电信行业确有 9i/10g 存量，启停与口令文件流程三十年不变）。
- **类比锚点**（🔧，非本书引擎行为）：SQLite 打开一个不存在的路径即"建库"，无实例/会话分层——`sqlite3 /tmp/new.db "VACUUM"` 一行完成 Oracle 需要安装+建库+字典脚本三步的事；对照恰好说明 Oracle 启停状态机是为"多会话共享一个常驻实例"设计的，单机嵌入式语境没有这个问题。
- **快查书体裁的当代迁移**（⚠️ 观察）：本书的"task list + quick-reference table"形态今天活在 Ansible role、runbook 与云厂商 Operations Guide 里；读老速查书练的不是记参数，而是识别"检查单"这种知识压缩格式本身——本目录各章末尾的"核心概念速览"两列表即同一体裁的复刻。
