## 4.1 本书时代的连接栈：SQL*Net V2 → Oracle Net（⚠️）

1999 年的命名现场正处换代期：SQL*Net V2（Oracle7 时代定型的协议栈）在 Oracle8/8i 改称 Oracle Net，但文件与工具名残留旧称——本书速查表里你会同时看到两套词。分层模型：

```
应用/SQL*Plus
   │  连接串：username/password[@TNS别名] 或 //host:port/service
Oracle Net 客户端 (SQL*Net + name resolution)
   │  tnsnames.ora / Oracle Names / 目录
监听器 listener（服务器侧门房，TCP 1521 默认）
   │  listener.ora
服务器进程派生（专用服务器：每连接一 fork；MTS 共享服务器：Oracle8 新贵）
```

## 4.2 三张配置文件的语法面（⚠️）

**listener.ora**（服务器侧，`$ORACLE_HOME/network/admin/`）：

```
LISTENER =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = prod1)(PORT = 1521))
  )
SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC = (GLOBAL_DBNAME = oradb.world)(ORACLE_HOME = ...)(SID = oradb))
  )
```

- 静态注册（SID_LIST）=门房照本宣科，实例没起也告诉客户端"有这扇门"——8.0 之前唯一方式，本书主场景；
- 动态注册=PMON 向监听器报告服务（8i 起成熟），静态条目因此可删——时代分界记牢。

**tnsnames.ora**（客户端别名簿）：

```
ORADB.WORLD =
  (DESCRIPTION =
    (ADDRESS_LIST =
      (ADDRESS = (PROTOCOL = TCP)(HOST = prod1)(PORT = 1521))
      (ADDRESS = (PROTOCOL = TCP)(HOST = prod2)(PORT = 1521))   -- 8.0 起支持 FAILOVER 列表
    )
    (CONNECT_DATA = (SERVICE_NAME = oradb.world))
  )
```

**sqlnet.ora**（两端行为开关）：`NAMES.DIRECTORY_PATH=(TNSNAMES,ONAMES)` 解析顺序、`TRACE_LEVEL_SERVER`、`SQL.EXCLUDE=...`（NT 上限制可执行程序连库——安全与网络交界的老招，对照 [../Oracle_Security/06-网络监听与连接层安全.md](../Oracle_Security/06-网络监听与连接层安全.md)）。

## 4.3 命名解析四选一（⚠️）

| 方案 | 机制 | 本书时代评价 |
|---|---|---|
| 本地 tnsnames | 每机一份别名文件 | 默认答案；N 台机器 N 份同步噩梦 |
| Oracle Names Server | 专用名字服务器+区域复制 | 8.0 力推、短命；本书仍给整节速查 |
| 主机名方法 | `host:port/service` 直连（无需文件） | 简单场景一直活到今天 |
| 目录（LDAP） | 8i 起集成 Oracle Internet Directory | 成书时刻的"明天" |

Oracle Names 的速查表是全书"保质期最短"的部分——2000 年前后就被目录与 easy connect 淘汰，今天读它是纯网络考古。

## 4.4 监听器运维命令卡（⚠️）

```
lsnrctl status | start | stop | services        # services: 看动态注册到的实例
lsnrctl set password / change password          # 8i 监听器裸奔时代的止血带（安全线 06 章对象）
tnsping oradb.world                             # 只证明"门牌号解析得到+监听器应答"，不证明能登录
```

排错三段论（本书体裁的决策树）：`tnsping` 不通 → 网络/监听器层（端口、防火墙、HOST 解析）；tnsping 通而 `ORA-12514/ORA-12505`（服务/SID 未知）→ 注册面（静态 SID_LIST 缺条目或实例未起）；连上后 `ORA-01017` → 已穿过网络层，进 05 章认证域。**"错误码第一位数字定位层次"是本章最长寿的方法论。**

## 4.5 专用服务器 vs 共享服务器（MTS，⚠️）

Oracle8 的连接层大新闻：Multi-Threaded Server（后改名 Shared Server）。

- 专用（dedicated）：每会话 fork 一个服务器进程——内存随连接数线性涨，NT 上 fork 昂贵尤甚；
- MTS：调度器（dispatcher）进程池 + 共享服务器进程池，会话经虚拟电路排队复用——`MAX_SHARED_SERVERS`/`DISPATCHERS` 参数族；
- 本书速查价值：什么负载该 MTS（大量低活跃会话，OLTP 拨号盘后时代典型）、什么必须专用（批处理、并行查询、需要 ORA-DEBUG 的场景）；
- 时代注脚：连接池中间件（TPC 层）后来吃掉了 MTS 的主战场，但共享服务器架构仍在（⚠️ 23ai 文档中保留）。

## 4.6 外部命名与进程门（⚠️）

- 外部过程调用（`EXTPROC`）：PL/SQL 调 C 库经监听器派生独立进程——8i 时代著名攻击面（默认 EXTPROC0 可信），安全处置在 [../Oracle_Security/06-网络监听与连接层安全.md](../Oracle_Security/06-网络监听与连接层安全.md) 06 章；
- IPC（beq 协议）：同机连接绕过 TCP——`ps -ef | grep ora_pmon` 验证本地实例时的隐藏通道；
- 协议可插拔：TCP/IP、IPC、SSL（8i 起 ASO 选件）共用同一描述符语法。

## 核心概念速览（中英对照）

| 中文 | 英文 | 一句话 |
|---|---|---|
| 监听器 | listener | 服务器侧门房：接收连接并派生服务器进程 |
| 静态注册 | static registration (SID_LIST) | 照本宣科的门房账本，实例未起也应答 |
| 动态注册 | dynamic registration (PMON) | 实例活着才上报服务，8i 起主流 |
| 服务名 | service / GLOBAL_DBNAME | "能接哪种活"的逻辑名，区别于 SID |
| 系统标识符 | SID / instance_name | 一台机上具体实例的进程级名字 |
| 别名簿 | tnsnames.ora | 客户端本地连接描述符数据库 |
| 名字解析 | name resolution | 别名→描述符的查找路径（四选一） |
| 共享服务器 | Multi-Threaded Server (MTS) / Shared Server | 调度器+进程池复用，省会话内存 |
| 网络探活 | tnsping | 只测解析+监听应答，不测认证 |
| 外部过程 | EXTPROC | 监听器派生的 C 调用进程门（攻击面） |

## 最新演进与工业实践

- **easy connect 与目录兴衰**（⚠️）：Oracle Names 死、OID 边缘化、LDAP 式集中管理让位于 `//host:port/service` 直连与连接串内嵌（TNS 字符串），12c 起客户端可完全无文件运行；19c 的 `EZCONNECT` 语法是 4.3 表的终局。
- **监听器安全清算**（⚠️）：2005 年 TNS 监听器口令哈希爆破风暴（本书出版六年后）终结"监听器无口令"默认态；现代默认本地注册+`ADMIN_RESTRICTIONS`，Slammer 蠕虫（2003）打的正是 4.1 的连接栈协议解析层（⚠️ 通史转述）。
- **DRDA/ACFS 与多协议**（⚠️）：监听器今天还承载 XML DB HTTP、EM 控制台端口注册等"非数据库连接"——4.2 的描述符语法仍是统一入口。
- **23ai/26ai 文档现状**（✅/⚠️）：网络指南独立成册（Net Services Security/Administration），23ai 手册群入口实抓 200 的是安装/管理/调优等主干（见 01/02/07 章登记）；⚠️ 网络分册 slug 在 /26/ 重定向下未逐一验证，引用时以 https://docs.oracle.com/en/database/oracle/oracle-database/23/ 首页检索 "Net Services" 为准。
- **工业实践**（⚠️ 通说）：应用侧连接池（HikariCP/UCP）+ 数据库侧 DRCP（11g 线程池版"MTS 精神续作"）双层复用；监听器排错三段论仍是 OCI 工单第一屏标准动作——方法论零折旧。
