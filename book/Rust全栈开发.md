# Rust全栈开发

## 版本与 ISBN

- 原书名：*Rust Servers, Services, and Apps*
- 作者：Prabhu Eshwarla；译者：王志强、刘畅
- 中文版：《Rust全栈开发》，清华大学出版社（Web开发与设计丛书），2025-03
- ISBN：`978-7-302-68171-7`（276 页，CNY 98.00）

> 2026-09-22 由 202608 月度笔记（20260806 Rust 书单）整理。

## 笔记

- 定位：覆盖从前端到后端的 Rust 全栈技术，不依赖大型框架、从标准库写起，理解 Web 服务本质。
- 内容：TCP 服务器 → HTTP 服务器 → REST API → 数据持久化 → 部署，适合想搞清"框架之下发生了什么"的读者。
