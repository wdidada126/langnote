> Anthony Williams 著，吴天明译，人民邮电出版社 2021-11，ISBN 978-7-115-57355-1，393 页。
> 原书 *C++ Concurrency in Action, Second Edition*（Manning，2019，ISBN 978-1-6172-9565-0）。

**大纲式单文件在此**：`book/C++并发编程实战2.md`（含完整中译目录）。本目录是**深度重写版**，两者并存互链。

## 1. 元数据与作者背景

| 项 | 内容 |
| --- | --- |
| 作者 | Anthony Williams（英国标准协会 C++ 标准组成员；`just::thread Pro` 实现者；多个 C++ 并发提案作者） |
| 覆盖标准 | 以 **C++17** 为主干，**C++20** 补充（`jthread`、`stop_token`、原子 `wait/notify`、信号量、闩/卡） |

> 后者是**算法与理论**（线性一致性、共识数、通用构造），用 Java 伪码；
> 本书是**语言与工程**（C++ 标准库的正确用法、陷阱、调试），两者互补。建议先读本书建立 API 直觉，再读艺术版理解「为什么这样设计」。

## 3. 版本演进时间轴（本书 ⟶ 2026）

| 年份 | 事件 |
| --- | --- |
| 2011 | **C++11**：`<thread>` `<mutex>` `<atomic>` `<condition_variable>` `<future>`，内存模型（Boehm & Adve 奠基） |
| 2014 | **C++14**：`std::shared_timed_mutex`（读写锁）与一些小幅补充 |
| 2017 | **C++17**：并行算法 + 执行策略、`shared_mutex`、`scoped_lock`、O(1) `clamp` 等；本书的核心主干 |
| 2020 | **C++20**：`jthread`、`stop_token`、`atomic::wait/notify`、`latch/barrier/semaphore`、`atomic_ref` |
| 2023 | **C++23**：`std::expected`、`flat_map`；并发侧主要是修复和小补禽（`barrier::arrive` 系列完善） |
| 2026 | **C++26 在路上**：`std::hazard_pointer`/RCU、SIMD 与 `execution` 并行策略进一步整合（对应本书 Ch7 的内存回收痛点终于进入标准库） |

## 4. 本书刻意规避 / 未覆盖的缺口

- **协程与 executors**：C++20 协程没有 scheduler，直到三方库才开始补齐——本书第 8、9 章的线程模型与之不同近上门主要掉了。
- **形式化验证**：本书依靠样板代码与直观论证，不做形式化；想看形式化模型请看 RC11 / C++ 内存模型的形式化工作（见艺术版 Ch4）。
- **GPU / SIMD 数据并行**：第 10 章只谈 CPU 上的执行策略。
- **分布式并发**：本书范围是单机共享内存；分布式一致性请看 `book/数据库系统概念6/`。

## 6. 跨语言对照表

| C++（本书） | Java | Rust |
| --- | --- | --- |
| `std::thread` | `java.lang.Thread` | `std::thread` |
| `std::mutex` | `synchronized` / `ReentrantLock` | `Mutex`（`parking_lot`） |
| `std::condition_variable` | `wait/notify` / `Condition` | `Condvar` |
| `std::atomic<T>` + 6 序 | `VarHandle` + `AtomicXxx` | `AtomicXxx`（只有 SeqCst/AcqRel/Relaxed/Acquire/Release） |
| `std::future/promise` | `CompletableFuture` | `tokio::sync::oneshot` |
| `std::shared_mutex` | `ReadWriteLock` | `RwLock` |
| `jthread` + `stop_token` | Java 侧对应结构化并发（JEP 505） | Rust 作用域线程 + `CancellationToken` |
