# 第 11 章 其他并发工具

> 并发工具收尾：`ThreadLocal`（线程封闭/泄漏）、`ForkJoinPool`（工作窃取）、`CompletableFuture`、`CompletionService`、`ThreadLocalRandom`、`Phaser` 等。本书图解各自适用场景。详见之美 concepts、冰河卷2 12-13 章、精通2 7-9 章。

## 一、核心精讲

### 11.1 🔧 ThreadLocal
- 线程封闭（线程安全三策略之一）；弱引用 key + 强引用 value → 线程池泄漏（🔧 finally `remove()`；跨池用 `TransmittableThreadLocal`；JDK 21 `ScopedValue` 更安全，见之美专篇）。

### 11.2 ForkJoinPool
- 工作窃取 deque + 分治；`invokeAll` 让本线程也干活；阈值实测（🔧 纯 CPU；IO 用虚拟线程，见之美 concepts/ForkJoin）。

### 11.3 CompletableFuture / CompletionService
- 异步编排；`CompletionService` 按完成顺序消费结果（🔧 不传 `Executor` 会饿死 `commonPool`，见之美/冰河卷2 13 章）。

### 11.4 ThreadLocalRandom
- 每线程一份种子，无共享争用（🔧 别用 `Math.random`/共享 `Random`；JDK 17+ `Random` 默认 LXM 算法，见手册 10 章）。
