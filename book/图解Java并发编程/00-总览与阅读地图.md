# 《图解Java并发编程》（汪建）阅读地图

- 作者：汪建（笔名 seaboat），人民邮电出版社 2021-10，ISBN 978-7-115-56173-2，374 页（另有 388 页版本）
- 定位：「图例胜千言」——200+ 示意图 + 100+ 代码案例讲 Java 并发；**独门章：用 C++ 模拟实现 Java 线程**（其他并发书均无）。
- 作者的同类书：《图解数据结构与算法》《Tomcat内核设计剖析》。

## 同主题书籍分工

- 原理底层：方腾飞《艺术》、冷血《实现原理》、冰河卷1。
- 工具源码：冰河卷2、手册、线程与并发编程实践。
- **本书**：图解 + 案例最直观；第 12 章 C++ 模拟线程是独一无二的「造轮子」视角，与冷血《实现原理》的 Java 手写互补。

## 本书没覆盖的缺口

- 虚拟线程（JEP 444）、结构化并发（JEP 453/505）、VarHandle（JEP 471）、ScopedValue（JEP 506）—— 见《之美》。
