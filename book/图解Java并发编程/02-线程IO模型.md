# 第 2 章 线程 I/O 模型

> 阻塞 IO（BIO）、非阻塞 IO（NIO）、IO 多路复用（`select`/`poll`/`epoll`）。本书图解三种模型在「线程 vs 连接」上的差异。与尼恩《高并发核心编程》2-3 章（五种 IO 模型/零拷贝）互补。

## 一、核心精讲

### 2.1 🔧 三种模型对照
- **BIO**：每连接一线程，`read` 阻塞等数据（🔧 简单但连接多时线程爆炸，C10K 不可行）。
- **NIO**：`read` 立即返回，轮询查就绪（🔧 省线程但空轮询烧 CPU）。
- **IO 多路复用**：一个线程（Selector）监视多连接，就绪才处理（🔧 Netty/Redis/Nginx 基石，见尼恩 3-4 章）。

### 2.2 为何 Java NIO 不是真异步
- 多路复用是「就绪通知 + 用户自己读」，属同步 IO；真异步（AIO）是内核读完通知（🔧 Linux 上 `io_uring` 才接近）。
