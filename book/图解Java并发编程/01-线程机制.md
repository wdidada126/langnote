# 第 1 章 线程机制

> 线程基础：线程状态（NEW/RUNNABLE/BLOCKED/WAITING/TIMED_WAITING/TERMINATED）、调度、优先级、`yield`/`sleep`/`interrupt` 操作。本书图解状态流转。与黄文海 1 章、手册 1 章、冰河卷2 2 章互补。

## 一、核心精讲

### 1.1 🔧 状态流转
- `start`→RUNNABLE；等 `synchronized` 锁→BLOCKED；`wait`/`join`/`park`→WAITING；带超时→TIMED_WAITING；`run` 结束→TERMINATED（🔧 用 `jstack` 看状态定位卡点）。

### 1.2 yield / sleep / interrupt
- `yield` 提示让出（不可靠，OS 依赖）；`sleep` 阻塞不释放锁；`interrupt` 仅设标志，`sleep/wait/join` 抛 `InterruptedException` 并清标志（🔧 别吞，重设或上抛）。

### 1.3 优先级不移植
- 依赖 OS 调度器，不作正确性依据（🔧 实时性靠锁/自定义调度）。
