# 第 7 章 原子类

> JDK 原子类：`AtomicInteger/Long/Boolean`、`AtomicReference`、`AtomicStampedReference`（ABA）、字段更新器、数组原子类、`LongAdder`。本书图解 CAS 与各类原子操作。详见艺术 7 章、之美 concepts/CAS与原子操作/LongAdder、冰河卷2 11 章。

## 一、核心精讲

### 7.1 🔧 CAS 是基石
- `lock cmpxchg` 原子指令；失败自旋；ABA 用 `AtomicStampedReference` 戳版本（🔧 见《之美》CAS 专篇）。

### 7.2 累加器
- `LongAdder`：`base`+`Cell[]` 分段，高争用下吞吐远超 `AtomicLong`（🔧 `sum()` 非原子快照；见《之美》LongAdder 专篇）。

### 7.3 Unsafe → VarHandle
- JDK 21+ `Unsafe` 废弃（JEP 471/498）→ `VarHandle` 5 档语义（plain/opaque/acquire/release/volatile）（🔧 见《之美》CAS/volatile 专篇）。

## 二、版本演进 / 论文 / 前沿

- 论文：Herlihy Wait-Free（PODC'91）；Lea JSR 166；JEP 193/471。
