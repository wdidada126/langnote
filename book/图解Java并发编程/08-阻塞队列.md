# 第 8 章 阻塞队列

> 阻塞队列：`ArrayBlockingQueue`、`LinkedBlockingQueue`、`PriorityBlockingQueue`、`DelayQueue`、`SynchronousQueue`、`LinkedTransferQueue`、`LinkedBlockingDeque`。本书图解「生产者阻塞/消费者阻塞」两条件。详见深度解析 8 章、冰河卷2 7 章、之美 concepts/阻塞队列BlockingQueue.md。

## 一、核心精讲

### 8.1 🔧 两条件的阻塞语义
- `put` 在队满时阻塞（等 `notFull`）；`take` 在队空时阻塞（等 `notEmpty`）（🔧 `ArrayBlockingQueue` 单锁两条件；`LinkedBlockingQueue` 双锁分离 put/take 吞吐更好）。

### 8.2 无界陷阱
- `LinkedBlockingQueue` 默认 `Integer.MAX_VALUE`（🔧 务必显式容量；生产快于消费会 OOM）。

### 8.3 特殊实现
- `SynchronousQueue` 不存元素（手递手）；`DelayQueue` 到期才出；`LinkedTransferQueue` 支持 `transfer`（🔧 见冰河卷2 7 章、之美 concepts/阻塞队列）。
