## 8. 教学 FAQ（重构问答位，⚠️ 非原书）

- **问：交互式会话和生产调度差在哪？** 答：冷启动、并发会话数、CU 归因粒度三点不同；
  生产前用「调度视角重跑一遍」替代「最后一次交互成功」的侥幸（⚠️ 重构经验学）。
- **问：笔记本里的 SQL 算不算一等公民？** 答：能跑，但重 ETL 留在 Spark/仓两侧，
  笔记本 SQL 做探查与胶水（与 05 章 SQL 面矩阵呼应）。
- **问：开源 Spark 作业能直接搬吗？** 答：API 层多数平滑，差异在存储 URL 形态、凭据注入
  与内置连接器——搬迁验收看**读写路径与权限**而非语法树（⚠️ 转述）。
