# 05 C++ 新特性——11/14/17/20 版本全景与深潜篇

> 对应站点板块：`/docs/cpp-new-feature/`（23 篇，实抓 ✅）。它是 8 板块口径中"C++进阶教程
> （现代C++特性）"的实体之一，站点却单列板块——本目录顺势独立成章（映射声明见 [00 章](00-总览与阅读地图.md)）。
> 板块双层结构：**版本综述层**（cpp-11/14/17/20 四篇"完全指南" + 五个 *-feature 变体，内容有重复 ⚠️）+
> **深潜层**（modules/coroutines-concepts 三大特性、constexpr、智能指针、string_view、optional、
> 折叠表达式、左中右值、列表初始化、auto/decltype、C++20 同步原语、线程库、模板新特性、函数对象）。

## 核心概念速览（中英对照）

- **值类别判定树** — value categories：有身份+可移动 → lvalue/xvalue/prvalue 三分
- **统一初始化** — uniform initialization `{}`：一套花括号走天下，代价是 initializer_list 截胡构造
- **编译期计算谱系** — constexpr 演进：11 只能单 return → 14 放开语句 → 17 `if constexpr` → 20 虚函数/原子/new
- **类型推导双钥** — auto & decltype：一个看初始化值（丢引用丢 cv），一个看表达式本身（decltype 保血统）
- **智能指针三件套** — unique/weak/shared_ptr：独占→观测→共享的所有权三角（auto_ptr 是历史反面教材）
- **零拷贝视图** — string_view：指针+长度；站文自评"参考 gcc 源码手撸"，悬垂是其唯一死穴
- **可选值** — optional：把"可能没有"写进类型；与 `std::expected`（C++23）构成值语义错误处理两翼
- **折叠表达式** — fold expression：`(args + ...)` 四种折叠形态干掉递归样板
- **三大革命特性** — Modules / Coroutines / Concepts：站方钦点 C++20 的三张名片
- **无栈协程** — stackless coroutine：状态机放堆帧，co_await 挂起点即函数中间；promise_type 是定制协议
- **模块** — C++20 modules：`export module` 编译一次产出 BMI，文本 include 的 40 年补丁
- **概念约束** — concepts：`requires` 表达式即接口文档，SFINAE 天书报错的终结者
- **C++20 同步原语** — latch / barrier / semaphore：CountDownLatch 等 Java 熟面孔标准化
- **可停止线程** — jthread / stop_token：RAII 化的 thread + 协作式取消信号

## 动机：为什么需要"版本史"这个板块

站方动机是面试题库（"说说 C++11/14/17/20 各新增了什么"是必考题）。但四篇完全指南意外地
是全站**信息保真度最高**的内容：逐条列语言特性+库特性，每条给最小示例——相当于一部浓缩的
《The C++ Standards Committee 会议纪要》中文平行本。缺陷同样明显：**内容全部止步 C++20**，
23/26 缺席；综述层与深潜层互相重复（cpp-11 与 cpp-11-feature 两篇 ⚠️ 站方自己承认多版混发）。

## 机制：按主线重组 23 篇

### 主线一：对象怎么造出来（初始化与推导）

列表初始化篇讲 `{}` 的五种身份（聚合/initializer_list/explicit 构造收窄禁止…）与
两个著名坑：`vector<int> v{5}` 是一元素不是五容量、`auto x{5}` 是 int 不是 double（initializer_list 截胡）。
auto/decltype 篇给推导规则表：auto 按"模板实参推导+值类别"，`decltype((x))` 永远是引用——
站文用"`decltype(i)` vs `decltype((i))` 决定 `++` 合法性"收尾，这是理解 04 完美转发的先修。

### 主线二：对象怎么转移（值类别与移动时代）

左中右值篇的判定树（有身份？可移动？）是全板块理论支点；move/forward 机制细节在 [04 章](04-C++进阶-移动转发与泛型设施.md)。
智能指针篇：从 auto_ptr 的"拷贝即偷"讲起 → unique_ptr（删除拷贝、移动+删除器进类型）→
shared_ptr（控制块双计数、make_shared 合一分配）→ weak_ptr（破环、lock 提升）。
折叠表达式篇：`((args << ... << std::cout), ';')` 一行版 vs 递归终止函数四行版，
顺带把 `initializer_list` 绕路方案钉在耻辱柱上。

### 主线三：计算什么时候发生（constexpr 谱系）

constexpr 篇的区分很清醒："const 是运行时只读，constexpr 是编译期可求值"；
函数 constexpr 化=给编译器多一张牌。站文示例（编译期阶乘/斐波那契）+ "C++14 放宽为多语句、
C++17 if constexpr 终结标签分发、C++20 constexpr 虚函数/new"的演进注脚是后补的（本目录补 ⚠️ 站文止于 17 居多）。

### 主线四：接口怎么写（视图与约束）

string_view 篇实打实"手撸 gcc 版"（数据指针+长度、无保证 null 结尾警告都有），
optional 篇讲 `value_or` 与"引用成员难题的解法"。两篇共同铺垫"非拥有语义"：
**视图类型的通病=生命周期不由自己管**——悬垂陷阱在 07 章经验板块有二次消费。
模板新特性篇预告 concepts：C++17 之前用 static_assert+traits 手搓约束的痛。

### 主线五：程序怎么组织（三大革命特性深潜）

- `cpp-three-feature` 是三板合一的导览：Modules（编译防火墙的完全体）、
  Coroutines（异步 I/O 的零开销抽象）、Concepts（模板的参数校验）——站方观点"C++20=自 C++11 后最大版本"，
  与业界共识一致。
- `cpp-modules` 深潜篇是 MSVC 实战笔记：`export module mymodule; export int f();`
  分区/命名模块/BMI 产物；作者明说"GCC 支持少，MSVC 全面"——2026 年看：GCC 14/15 对
  named modules 仍属"实验性可用"（本目录补 ⚠️），该判断不过时。
- `cpp-twenty`（同步原语）：latch 一次性计数（站文先展示自己手搓 CountDownLatch 再换标准件）、
  barrier 多相位可循环（带 completion 回调）、counting_semaphore 资源配额。
- `cpp-thread-feature`：thread 家族增强——jthread 自动 join、stop_source/stop_token 协作取消、
  `std::thread::hardware_concurrency`。

## 最新演进与工业实践（站文止步 C++20，本节全量补位）

- **C++23 与本书相关的增量**：`std::expected<T,E>`（错误处理第二轨道）、`this auto& self`
  简化版（P0847R6 ✅ 04/05 通用）、`std::print`/`std::format`（P2093R14 ✅ 取代 printf 野心）、
  `make_shared<T[]>(n)`（P2674R5 ✅ 补智能指针板块空位）、`weak_ptr<T[]>`（P1132R7 ✅）、
  `std::mdspan`（多维视图，衔接 10 章 system64/对齐）、`ranges` 管道定型、`std::generator` 是 C++23
  协程的最大实际受益者（站文"用 cppcoro 库"的时代结束了）。
- **C++26 预告**：`std::at_exit`（P2589 ✅，ScopeGuard 进标准，03 章已提前实测其场景）、
  `std::execution`（P2300R10 ✅，sender/receiver 统一异步模型——协程板块的下一步棋）。
- **constexpr 到 C++20 的边界**（P0784R7 ✅ constexpr new、P0448R4 ✅ constexpr 分配器）：
  `std::vector` 在常量表达式里 new——编译期动态大小对象首次合法。
- **工业仓库对应物**：版本综述层≈[../modern-cpp-tutorial.md](../modern-cpp-tutorial.md) 的中文镜像
  （changkun 逐版本讲法同源，深度互补：那边的 `std::optional/expected` 与 constexpr 篇章更好）；
  abseil 的 `absl::string_view/optional` 是"没到 C++17 就用我"的过渡层（现已全量 alias 到 std）；
  fmt（P2093 的孵化器）；range-v3（concepts+ranges 的原型田）；GSL（`not_null/span` 语义参照）。
- **训练营属性→真实使用频率**：智能指针/string_view/optional=**每日**（现代 API 签名标配）；
  折叠表达式/concepts=**库作者每周、应用者偶尔读懂**；modules=**大型工程试点中、面试谈资**；
  协程=**网络/游戏服务器少数派但面试权重被高估**（与 06 章 async 陷阱连读）。

## 实测样例（已实测 g++ 15.2）

一站验证"站文 C++20 重心"与"C++23 现状"：三路比较（20）+ span CTAD（23）+ deducing this（23）：

```cpp
#include <compare>
#include <span>
#include <iostream>
struct Version { int major, minor; auto operator<=>(const Version&) const = default; }; // C++20
struct Widget {                                                  // C++23 deducing this
  auto& setVal(this auto& self, int v) { self.v = v; return self; }
  int v = 0;
};
int main(){
  std::cout << (Version{1,2} < Version{1,10}) << " ";   // 不写六个比较运算符
  int arr[5] = {1,2,3,4,5};
  std::span s = arr;                                     // 从 C 数组的推导指引（C++23 明确补齐）
  std::cout << s.size() << " ";
  Widget w; w.setVal(42);
  std::cout << w.v << "\n";
}
```

```
$ g++ -O2 -std=c++23 s05.cpp && ./s05
1 5 42
```

解读：三项特性在 g++ 15.2 -std=c++23 全绿。站文若今天重写这三段，
会用 `std::generator`（23）替代 cppcoro、用 `std::expected` 替代"返回 pair<bool,T>"的旧例——
这是 05 章与 2026 年现实的主要时差。
