### 辨析：勿与"Oracle Hacker's Handbook"混淆（作者谱系取证）

- 二手社区常把 Neil Heurtel、Tim Minto 列为本书作者——⚠️ 讹传。该二人是**姊妹书**
  *The Oracle Hacker's Handbook*（Litchfield/Heurtel/Minto，ISBN 9780470080221，Google Books 元数据 ✅）的合著者。
- 本书（2005）是**多引擎合订**：SQL Server、Oracle、MySQL、DB2、PostgreSQL、Sybase ASE、Informix 七系全覆盖；
  Oracle HH（2007）才是单引擎深潜。两书同为 Wiley/Sybex 系，Litchfield 主笔。

### 出版社归属取证（与波内 #35 SQL_Server_2008_Internals 同型）

本书**出版社是 Wiley/Sybex，不是 O'Reilly**。它出现在本 repo 的"O'Reilly 书目长名单"
（见 [数据库系列·新增书目补充（ISBN）.md](../数据库系列·新增书目补充（ISBN）.md) 第 51 行）仅因 O'Reilly 学习平台**藏书销售/平台收录**了
Wiley 电子版权威——归属链与 #35（Microsoft Press 书入 O'Reilly 书目）完全同型。
写笔记、引元数据时，出版社一栏必须以 Wiley/Sybex 为准。

## 核心概念速览（中英对照）

- **数据库攻防手册** — Database Hacker's Handbook：以攻击者视角系统覆盖多引擎的发现/利用/加固范式
- **出版社归属取证** — Publisher attribution forensics：辨析 Wiley/Sybex 原著与 O'Reilly 平台收录关系
- **攻击面** — Attack surface：监听端口、扩展存储过程、默认账户等可被触及的入口集合
- **叠加查询** — Stacked queries; 一条请求携带多条分号分隔语句，SQL Server/PG 类引擎尤险
- **定义者权限** — Definer's rights：Oracle PL/SQL 以所有者权限执行的授权模型及其注入温床
- **最小权限** — Least privilege：服务账户/角色/模块授权只给必需项的总原则
- **纵深防御** — Defense in depth：补丁+配置加固+网络隔离+审计的层叠策略
- **威胁建模** — Threat modeling：以数据价值与对手能力估计风险的方法论底座
- **精读重构** — Close-reading reconstruction：本目录性质声明，非原书文本复制
- **取证态标注** — Evidence tagging（✅/⚠️/🔧）：每级信息标注实抓/推定/实测三态

## 最新演进与工业实践

- 2007 年 Litchfield/Heurtel/Minto 将 Oracle 部分扩展为单引擎 *The Oracle Hacker's Handbook*
  （ISBN 9780470080221，Google Books 元数据 ✅ 本会话核到），本书 Oracle 章是其前身。
- 本书引擎基线之后的里程碑：SQL Server 2005 Surface Area Configuration→2017 起 xp_cmdshell 默认关闭；
  Oracle 12c 容器数据库与统一审计（2013）→23ai 数据库角色收紧；MySQL 5.7 移除匿名账户默认安装（2015）；
  PostgreSQL 10 起 scram-sha-256 逐步替代 md5（⚠️ 各条以厂商文档为准，本环境不具直连核链能力）。
- 工业实践：数据库入侵检测/审计产品（Imperva DBSecure 类、Opened、pgAudit 开源扩展）
  延续本书"监听器→协议→语句"三层检测思路；云数仓（Snowflake/BigQuery/Redshift）把"主机攻防"
  转译为"租户/凭证攻防"，参见 [00-总览与阅读地图.md](../Advanced_Snowflake/00-总览与阅读地图.md)。
- OWASP 仍列 Injection 于十大风险（2021 版第 A03）；参数化查询 + ORM 白名单仍是业界第一对策，
  与 [白帽子讲Web安全.md](../白帽子讲Web安全.md) 结论一致。
- 阅读本系列的安全线建议路径：[计算机安全导论.md](../计算机安全导论.md)（理论）→ 本书（引擎攻击面）→
