## 1. Ch6 DB2 UDB 体系结构（安全视角）

- **实例/数据库两级模型**：一个实例管理多库；实例属主（`db2inst1` 惯例）+
  `DB2ADMNS`/`DB2USERS` 组概念；Windows 服务形态下实例以高权服务账户运行——
  服务账户即主机提权跳板 ⚠️ 转述。
- **连接面**：DB2 默认经 DB2 TCP 端口（50000 起惯例）与 DRDA 协议服务；
  节点目录（db2nodes.cfg）与 `db2 connect to ... user ... using ...` 暴露认证交互。
- **管理服务器与 Java 存储过程**：10g 年代前后 DB2 支持外部 Java 例程，
  JVM 权限越界是出库通道 ⚠️ 转述。
- **命令行工具链**：`db2dart`（转储分析）、`db2look`（DDL 反出）、CLP 脚本——
  拿到主机后这些工具即是"库的情报与篡改全家桶"（与 Oracle 的 exp/imp 同型）。
- **权限模型**：SYSADM/SYSCTRL/SYSMAINT/DBA 实例与库级权威 + 对象权限 GRANT；
  SYSADM 默认映射到实例组，组成员≈库内 root——这是本章攻防的轴心。

## 2. Ch7–8 发现与攻击 DB2

- **发现**：端口扫描定位 50000+/历史 523 类端口、`db2pd`/快照监控函数
  在未加固主机上可被本地用户读取运行时配置 ⚠️ 转述。
- **认证攻击**：早期 DB2 口令以明文/弱混淆存于节点/实例配置面（版本相关 ⚠️），
  本地读取实例文件即可离线拿取全部 DB2 身份；OS 账户映射信任（Windows 域环境
  信任认证）意味着域控沦陷=DB2 沦陷。
- **语句层**：CLP 内联命令与动态语句拼接（应用经 CLI/ODBC 传 SQL）与通用
  SQL 注入同构；DB2 对叠加语句的限制依驱动/配置而异（⚠️ 书中语境未逐驱动核验，
  本目录不作行为断言，可类比 🔧 E1c 的 SQLite 驱动级拒叠）。
- **例程与外部点**：外部 C/Java UDF 以扩展 DLL/JAR 形式注入主机代码；
  高权账户可 `CREATE EXTERNAL`——对应 SQL Server xp_cmdshell、Oracle extproc
  的"第三方方言"（见 `05`/`02` 章）。
- **拒绝服务面**：锁升级/监视器内存膨胀（快照监控滥用）与日志盘填满
  是彼时 DB2 运维帖常见事故，也是书中"可用性也是安全"的注脚 ⚠️ 转述。

## 3. Ch9 保护 DB2

- 实例组最小化：`DB2ADMNS` 收窄、组≠个人；服务账户降权与独立。
- 认证加固：禁用 OS 信任映射（`CLNT_AUTH`/插件化）、强口令策略走 OS/插件。
- 授权审计：监控 `SYSIBM.SYSDBAUTH` 等目录表的权限变化；启用实例级审计
  （`DB2AUDIT`/审计例程）与 `db2audit` 提取。
- 例程策略：外部 UDF/SP 白名单化（`KEEPDIRTY`/`EXTPROC` 类配置随版本而异 ⚠️），
  原则上禁建。
- 补丁与指纹面：DB2 版本探测信息尽量收敛（banner/端口最小暴露），配合季度
  安全修订（IBM Security PTF 节奏 ⚠️ 制度名转述）。

## 4. 🔧 类比锚（SQLite，非本书 DB2 行为）

- **SYSADM 即 root** ↔ SQLite **文件权限即一切**：任何 OS 可读该文件的人
  拥有全库读写（🔧 E2b 平台注记），"库内无独立权威体系"的最小对照。
- **db2dart 脱机转储** ↔ 直接字节拷贝 + 页解析：SQLite 库文件为单文件，
  离线取证比 DB2 更容易（🔧 E3 明文抽取实验）。
- **快照监控函数暴露配置** ↔ `PRAGMA compile_options`/`PRAGMA database_list`
  全可读：嵌入式场景"监控即情报"面（🔧 E4b/E6d 输出可见）。

## 7. 发现→攻击→防御 三步清单（本章操作化）

发现（攻击者侧）：
1. TCP 扫描定位 50000+/配置端口，取实例名（`DB2DSTREAM`/服务名泄露 ⚠️）；
2. 尝试 `db2inst1`/`db2fenc1` 与弱口令组合（OS 层）；
3. 低权登录后读 `db2dsdriver`/节点配置，勾勒跨库联邦拓扑。

攻击（利用侧）：
1. OS 信任认证环境：域/本地凭证即库凭证（横向）；
2. SYSADM 组成员=库内 root：审计目录表找"组内闲账户"；
3. Java 存储过程/JVM 权限越界出库（版本相关 ⚠️）；
4. 本地实例文件读取口令面（早期版本形态 ⚠️）。

防御（蓝军侧）：
1. 实例组与个人账户一一对账，删闲置映射；
2. 认证改插件化（LDAP+TLS），禁隐式信任；
3. `db2audit` 常开：登录失败/权限变更/例程创建三类事件必告警；
4. 外部例程建审分离：默认禁，白名单双人批准；
5. 补丁：跟踪 IBM 安全公告季度节奏（⚠️ 制度名转述）。

## 核心概念速览（中英对照）

- **实例/数据库两级** — Instance/Database two-tier：DB2 权威分层，实例属主≈库 root
- **SYSADM** — System Administrator authority：实例级最高权威组
- **SYSCTRL/SYSMAINT** — System Control/Maintain：拆分的管理权威，最小化对象
- **DB2ADMNS/DB2USERS** — 组映射：OS 组到 DB2 权威的默认桥，信任面所在
- **DRDA** — Distributed Relational Database Architecture：DB2 分布式协议与端口面
- **db2dart** — Database Analysis and Runtime Tool：脱机转储分析，本地沦陷后的情报工具
- **外部例程** — External UDF/SP（C/Java）：扩展点出库通道，DB2 方言的 xp_cmdshell
- **快照监控** — Snapshot monitor：运行时配置可读面，DoS 与情报双重议题
- **db2audit** — DB2 audit facility：实例级审计提取机制
- **OS 信任映射** — Trusted OS authentication：域/本地账户直通库认证的加固拆除点
- **KEEPDIRTY/EXTPROC 类开关** — 外部例程配置：白名单化加固 ⚠️ 名称随版本
- **单库文件对照** — Single-file DBMS contrast：SQLite 权限=OS 文件的 🔧 类比

## 最新演进与工业实践

- 版本演进：DB2 9（2006）→10.5/11.1（2016 认证热点，波内 #76 主题）→11.5
  云混合形态；认证插件化（LDAP/Keyring）与 TLS 缺省化缓解了本章多数信任面 ⚠️ 概括。
- IBM 安全公告体系（PSIRT）与安全补丁滚动取代书中"手工关注"式建议；
  Db2 on Cloud 将监听/主机加固议题转为 IAM 议题（对照 [00-总览与阅读地图.md](../Advanced_Snowflake/00-总览与阅读地图.md)）。
- 工业现状：DB2 存量集中在银行/保险核心系统（国内大行常用），其攻防叙事
  已从"入侵库"转向"运行权限+审计合规"；可参考 [数据安全架构设计与实战.md](../数据安全架构设计与实战.md) 的落地方法。
- 开源近邻：DB2 专用开源攻击工具稀少（彼时至今），通用 DB 审计与
  SQL 注入检测工具同样适用；研究侧论文以存储引擎内部为多（[数据库系列·总索引.md](../数据库系列·总索引.md) 引擎线）。
