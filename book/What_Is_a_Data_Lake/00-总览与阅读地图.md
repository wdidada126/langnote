3. ✅ **Crossref ISBN 过滤**（api.crossref.org/works?filter=isbn:9781492088899）：**0 条**——
   与波6/7/8 先例一致：O'Reilly 不向 Crossref 寄存 ISBN，负结果符合预期，不作否证。
   注意 14920 号段虽为 Apress Crossref 寄存线，但本册封面为 O'Reilly REPORT 装帧，
   寄存线规则按**装帧体裁**而非号段适用，实测 0 条与判断一致。
4. ✅ **豆瓣 ISBN 页 404**：无中译记录 → 交波尾义务②登记。
