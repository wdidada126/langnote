## 核心机制

### v1：把检测化成一次回归（2015）

- S×S 网格，每格预测 B 个框 + 置信度 + 类别概率，端到端单网络一次前向 ⚠️（论文
  口径的通行复述；书内讲解深度待核）。设计动机锚：替代「区域提议→特征提取→分类」
  流水线的多次前向，把全图上下文塞进同一个卷积骨干 ⚠️。
- 对照经典 CV：滑窗级联（Viola–Jones ✅ 历史）是「局部窗口独立判决」，v1 起 YOLO
  系始终是「全图联合判决」——小目标弱是这个架构债的利息，v3 的多尺度头即还款 ⚠️。
- 缺陷谱（通行结论 ⚠️ 与书口径待对）：定位误差大（MSE 等权惩罚小框 IoU 不合理）、
  密集小物体召回差、置信度兼做「有物概率」与 IoU 导致校准糊。

### v2/v3：锚框聚类、多尺度与 Darknet 换代

- v2：维度聚类锚框、passthrough 细特征、训练分辨率多尺度 ⚠️（论文线口径）。
- v3：Darknet-53 + FPN 式三尺度头，每尺度独立预测 ⚠️；对照 Faster R-CNN 的 RPN
  （两阶段 ✅ 概念）——v3 用「网格先验 + 多尺度」近似了锚框提议的角色，省掉独立
  提议网络；这是「一阶段逼近两阶段精度」的关键拐点 ⚠️。
- 语言工程锚：v1→v3 的演进像一次库的大版本重构——对外 API（检测任务定义，见
  01 带）不变，内部表示层（框参数化、头部结构）两度换血；读谱系时抓住「哪些接口
  稳定、哪些实现滚动」就不会被参数细节淹没。

### 损失与训练配方（v1→v3 漂移线）

- 置信度权衡 λ_coord/λ_obj 手调 ⚠️ → v3 起二值交叉熵逐尺度独立 ⚠️：损失函数从
  「手工均衡回归/分类」走向「化归为多标签分类」，为 03 带 focal/IoU 系损失铺路 ⚠️。
- 分类头：v1/v3 用 sigmoid 多标签 ⚠️（非 softmax），书若写 softmax 即为讹误点，
  这是可预读的校验位。

## 批判读法（易错与存疑）

1. **「YOLO 一直最准」叙事**：v1 精度当年输 Fast R-CNN 线 ✅ 历史事实；书若倒着
   讲成功史，谱系带要倒序核对时间线 ⚠️。
2. **v2/v3 之间作者身份漂移**：v3 论文无「v2 增强全家桶」的消融承诺 ⚠️，书中
   归因表不可全信，逐条对论文消融表销账。
3. **Darknet-19/53 的残差差异**：d19 无残差、d53 有 ⚠️（通行口径）；书内架构图
   是否画对是鉴别「抄 README 还是读论文」的试纸。
4. 「本书讲到 v3 为止还是接 v4」⚠️ 未核——v4 是 BAG 工程拼盘而非新架构 ⚠️，
   若书把 v4 当大版本浓墨，权重自行下调。
5. 论文三连的 arXiv 编号在 paper/ 无档（find 实测为空）——本带所有「论文说」的
   转述目前都是二手 ⚠️，建档前勿引用本档做对外结论。

## 🔧 微实验位（未实测：本机未装 ultralytics/torch）

- 实验 A：v3 与 v1 权重重放同一张密集小目标图（COCO val 子集），分尺寸桶对比 AP，
  实证「多尺度头还债」叙事。

  先验值，验证「锚框是数据先验而非拍脑袋」。

## 核心概念中英对照

- **网格预测** — grid-based prediction：v1 立派根基，格子负责局部。
- **置信度** — objectness/confidence：框内含物 × IoU 的混合分数 ⚠️。
- **锚框聚类** — anchor clustering (v2)：IoU 距离 k-means 定先验尺寸。
- **多尺度头** — multi-scale prediction head：v3 三特征图分管大小目标。
- **特征金字塔** — FPN（概念对照）：自上而下融合，v3 借用其思想 ⚠️。
- **Darknet-53**：v3 骨干，53 层含残差 ⚠️ 通行口径。
