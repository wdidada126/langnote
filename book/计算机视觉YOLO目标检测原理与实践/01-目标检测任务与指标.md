## 核心机制

### 检测任务的形式化：分类之上加定位

- 输出 = 类别 + 归一化边界框 `(x_center, y_center, w, h)`（YOLO 参数化 ✅ 论文口径）；
  对比纯分类任务（花书第 6 章 MLP 头），检测多出的自由度是**连续回归 + 集合预测**：
  一张图可出 0..N 个框，需 NMS 或一对一分配去冗余 ⚠️（书内是否点破集合预测视角待定）。
- 经典 CV 对照锚：Viola–Jones 滑窗 + HOG/积分图 + 级联分类器（✅ 历史事实）——
  滑窗是「穷举候选 + 打分筛选」，两阶段 R-CNN 延续此思路；YOLO 的革命是把
  「找哪里」与「是什么」并成一个回归网络，候选生成整段消失 ⚠️（书表述待核）。
- 锚框（anchor）本质是把回归离散化为「先验形状 + 偏移量」⚠️；v8 起 anchor-free
  回潮的因果链在 03 带展开，本带先立「框参数化选择 = 召回/速度权衡」的判断坐标。

### 指标口径（✅ 通用学术定义，可直接校书）

- **IoU** = 交集面积 / 并集面积 ∈ [0,1]（✅）；匹配阈值常见 0.5（VOC）或
  0.5:0.05:0.95 十二档取均值（COCO AP@[.5:.95] ✅）——两口径数值差一个量级，
  书里「mAP 多少多少」不写口径即无效陈述，这是本带头号读法纪律。
- **P/R 曲线 → AP → mAP**：每个类别一条 PR 曲线取面积再平均（✅）；
  11-point 插值（VOC07）与全点插值（VOC10+/COCO ✅）结果不同，对照书稿要盯。
- 其他常配指标：FPS/延迟、参数量、FLOPs/GFLOPs（✅ 定义通用）——检测器选型是
  精度-速度 Pareto 前沿问题，单看 mAP 即误读。

### 数据集与基准生态

- 常见锚集：PASCAL VOC、COCO、Objects365 ⚠️（书内用哪个跑示例待核）；
  口径继承：在 VOC 上报 mAP@0.5、在 COCO 上报 AP@[.5:.95]，跨集比数即关公战秦琼。
- 工程语言锚：指标计算从「手写」到「库化」，对照 scikit-learn `average_precision`
  与 pycocotools 两套 AP 实现（✅ 存在性）——同为 AP，插值与类别聚合口径不同，
  复现书里数字前先确认计算器是谁。

## 批判读法（易错与存疑）

1. **mAP 不标口径**：见到「mAP 0.6」先问 @0.5 还是 @[.5:.95]、哪个数据集（✅ 口径纪律）。
2. **把 NMS 阈值当免费超参**：阈值松紧直接改召回-精度曲线形状，书若只给默认值不讲
   权衡即缺口 ⚠️。
3. **小目标/遮挡单列**：COCO 的 AP_s/AP_m/AP_l 分桶 ✅ 存在，若书只报总 mAP，
   对小样本场景的选型结论不可迁移。
4. **指标≠业务**：mAP 提升 0.3 点在漏检代价高的产线场景可能毫无意义 ⚠️（书是否有
   此层讨论待核，预设没有）。
5. 书是否覆盖 DetA/AssocA 之类跟踪复合指标 ⚠️ 不预设，跟踪线放 06 带处理。

## 核心概念中英对照

- **目标检测** — object detection：分类+定位+数量三合一。
- **边界框** — bounding box (bbox)：`(x_c, y_c, w, h)` YOLO 参数化。
- **交并比** — IoU：交集/并集，框匹配唯一标尺 ✅。
- **平均精度** — AP / mAP：PR 曲线下面积 / 类别均值，口径必须标注 ✅。
- **非极大值抑制** — NMS：按置信度贪心去重重叠框。
- **锚框** — anchor box：先验形状网格，v2 尺寸聚类起家的装置 ⚠️。
- **滑窗检测** — sliding-window detection：YOLO 之前的穷举候选范式 ✅ 历史口径。
