## 核心机制

### v5：从论文原型到产品管道（2020-06 起 ⚠️ 月份凭通行记忆）

- v5 的贡献不在新架构（相对 v3 是工程改良 ⚠️）：CIoU 损失、自适应锚框计算、
  CSP/PAN 式 neck 演进、AMP/EMA/scaled-YOLO 权重缩放家族 ⚠️（通行口径，书内取舍待核）。
- 定性：v5 是「把 YOLO 变成 pip install 就能跑的库」的一步——训练/验证/导出/跟踪
  四命令 CLI 化 ⚠️。读法上把 v5 章当**软件产品案例**而非算法论文案例。
- 语言工程锚：v5 的分层（models/datasets/utils + YAML 超参配置）对照 Python 生态
  「配置驱动」惯例，近似 Spring Boot 的 starter+yaml 心智模型 ⚠️（比喻锚，非书内容）；
  书若逐行讲源码则注意其随仓库滚动失效。

### v8：anchor-free + 解耦头（2023 ⚠️ 年份通行口径）

- 转向 anchor-free 的回归参数化（DFL 分布式框表示 ⚠️ 术语以论文为准）与
  一对一标签分配（TaskAlignedAssigner 类机制 ⚠️）——02 带「锚框=数据先验」的装置
  被整体拆换，动机是免掉锚框聚类/自适应对超参与数据的耦合 ⚠️。
- 多任务统一：v8 一套骨干同时出 detection/segmentation/pose ⚠️，为 06 带专题线埋线。
- 对照经典 CV：anchor-free 直接回归「到四边距离」的思路可回溯到 HOG 时代之前
  形状模型的「相对几何参数化」传统 ✅（概念谱系类比，非严格传承）。

### beyond：v9/v10/YOLO11 与命名漂移（⚠️ 本小节整体待 docs 销账）

- v10（一致性分配双头、去 NMS ⚠️）、v9（可编程梯度检查点 GELAN 线 ⚠️）、
  11 改名 YOLO11 ⚠️——这些是否进入 2026-04 印次正文、附录还是干脆没有，均未核实 ⚠️。
- 裁决重申：beyond 小节是本书**最先过期**的部分；读者应把这页当「2026-04 时点的
  生态快照」读，快照外的每个新版本走 docs/releases，不在书里找。

## 批判读法（易错与存疑）

1. **版本号≠论文**：v5/v8 主要载体是 GitHub 仓库而非 arXiv ⚠️（论文线只到 v4）；
   书中引文若给 v5/v8 配论文，查该引文真实性——本仓 paper/ 无档（实测）。
2. **「改进 YOLO」论文洪流污染**：v5 基线上嫁接注意力的魔改文献质量参差 ⚠️，
   书若引用此类做机制论据，降权处理。
3. **去 NMS 的代价叙事**：端到端分配省一次后处理，但小数据集上召回可能受损 ⚠️；
   书若有「更先进所以更好」单向叙事即为缺口。
4. **复现断代**：v5 老 commit 与 2026 版 ultralytics API 不兼容 ⚠️（默认模型名、
   参数改名），书中代码块按印次时点理解，照抄必炸。
5. v7/v6/其他社区分支（⚠️ 书是否提及）——不做覆盖假设，读到再登记。

## 核心概念中英对照

- **无锚框检测** — anchor-free detection：直接回归几何距离的范式。
- **标签分配** — label/assigner strategy：一对多（v5）↔ 一对一（v8）⚠️。
- **解耦头** — decoupled head：分类/回归分支分开 ⚠️（v8 线口径）。
- **PANet 式 neck** — path aggregation neck：双向多尺度融合的通行装置 ⚠️。
- **配置即接口** — config-driven API：YAML 超参文件承担版本兼容面 ⚠️ 类比。
- **发布快照** — release snapshot：书稿代码只对印次时点负责（本带读法关键词）。
