## 三、读法与时效裁决（本目录总纲）

- **书追不上 ultralytics release**——裁决写死：本书只当**原理与谱系地图**读；
  API 签名、模型名（v8→YOLO11 改名 ⚠️）、默认超参、CLI 用法一律以 Ultralytics
  官方 docs/仓库为现行口径，与 2026-04 印次冲突时**以 docs 为准**，书的工程章代码
  视同快照存档。谱系因果（为什么 anchor-free、为什么多尺度头）才是书的保值部分。
- 阅读路线：01（指标口径）→ 02/03（谱系两带，配合论文三连）→ 04/05（实践带，
  对照 docs 读）→ 06（选型收口）。有 DL 基础者可 02/03 先行。
- 前置锚：卷积/反传概念先查 [../深度学习_花书.md](../深度学习_花书.md) CV 章或
  [../深度学习入门.md](../深度学习入门.md)，本书默认读者已有之 ⚠️（假设未核）。
