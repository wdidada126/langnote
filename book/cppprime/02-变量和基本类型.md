## 核心概念速览（中英对照）

- **定义与声明** — definition vs declaration：定义分配存储并可能初始化；声明（extern）只给名字与类型
- **初始化非赋值** — initialization ≠ assignment：初始化创建时给初值；赋值擦除旧值换新值（单文件 chap2 第一句批注）
- **整型提升** — integral promotion：小整型进表达式先变 int
- **usual arithmetic conversions**：混合算术类型的统一转换阶梯
- **无符号回绕** — unsigned wraparound：`u-1` 当 u==0 得到模 2^N 的大数，定义行为
- **列表初始化** — list initialization（C++11）：`{}` 拒绝窄化转换，本书贯穿始终的新语法
- **字面值后缀** — literal suffix：`1024u`、`3.14F`、`10'000'000`（⚠️ 数字分隔符是 C++14，5版书里没有，别记串）
- **引用** — reference：必须初始化、不可改绑的别名
- **指针** — pointer：存地址的值；`nullptr`（C++11）取代 0/NULL
- **void\*** ：可指向任意对象地址但不参与隐式转换回具体类型
- **指向常量的指针 / 常量指针** — pointer to const / const pointer：底层/顶层 const 的两个方向
- **顶层 const** — top-level const：指针自身是常量；底层 const：所指对象是常量；拷贝时顶层可变、底层必须一致
- **constexpr / 常量表达式** — constant expression：编译期可求值；constexpr 变量必须是初始化器本身即常量的对象（5版2.4.4的严格口径）
- **类型别名** — type alias：`using pos = std::vector<int>::size_type;`，指针别名尤其回血
- **auto**：从初始化器推断类型，**丢掉引用与顶层const**（ decltype 保留）
- **decltype**：表达式类型的镜子，`decltype((x))` 是 `int&`——括号规则是全书第一个大坑
- **聚合/类内初始化器** — in-class initializer（C++11）：Sales_data 成员自带默认值
- **包含守卫** — include guard：`ifndef H / define H / endif`；单文件笔记第694行的批注即此

## 2.1 类型与转换：规则是阶梯，不是清单

**动机**：几乎所有"诡异 bug"追踪到源头都是本章规则——无符号减法、char 溢出、`-1 < 1u`。

**机制**：
- 算术类型按"精度/宽度"排序的转换阶梯：bool→char/short→int→unsigned→long→…；**优先级不是简单的大小**：同宽度时 unsigned 赢（int 转 unsigned 而非反向）。
- 初始化 vs 赋值的区别在列表初始化下变成**窄化即编译错**：`long x{3.14};` 直接拒绝（`long x = 3.14;` 只截断）。
- `auto_ptr` ⚠️ 本章不出现，但类型阶梯在 12.1 的 `auto_ptr` 陷阱里复发——那里会一并定性。

**权衡**：书的态度是"理解规则 + 避免混合符号性比较"；现代工具链的态度是"让编译器替你查"——`-Wall -Wextra -Wconversion` + clang-tidy `bugprone-*`。

**相邻概念对比**：`long` 与 `long long`（LP64/LLP64 平台差异，5版31页"long long 新特性"正是为 Windows 补的位）；`size_t` 与 `ptrdiff_t`——一个计数一个差值，混用回到符号地狱。

## 2.2-2.3 声明、作用域、引用与指针

- **声明与定义分离（2.2.2）**：头文件放 `extern` 声明，cpp 放定义；违反 ODR 的链接错误的根因在此。
- **作用域（2.2.4）**：名字查找"内层遮蔽外层"；函数内 `static` 局部变量生命周期跨越调用——`local static` 在 C++11 后自带线程安全初始化（第6章 6.1.1 正式讲）。
- **引用不是"更安全的指针"**：引用无自身语义（它不拥有地址），`int&` 必须绑定到左值，`const int&` 可绑右值——这是后面 13.6 右值引用的地基，本章先把"能绑临时量"的事实立起来。
- **指针是对象，引用不是**（本书原话级别区分）：可以改指针的指向，改不了引用的绑定。
- **理解复合声明（2.3.3）**：从名字出发先右后左；`int *(*p)[10]` 读成"指向 10 个 int* 的数组的指针"。别背语法，练 20 个例子。

## 2.4-2.5 const、别名与类型推断

- **const 的两种读法**：靠近 `*` 右侧修饰所指、左侧修饰指针自身；与 14.x `mutable`、20 章（无）呼应即可。
- **constexpr 与"常量表达式"**（2.4.4，C++11）：注意 5 版口径较严；C++14 放宽了 constexpr 函数体（见 05 文件），constexpr 变量本身 C++17 起才有 `inline constexpr`（头文件内定义常量对象不违反 ODR）。
- **auto 丢引用与顶层 const**（2.5.2）：`const int ci; auto b = ci;` b 是 `int`。想要引用写 `auto&`。这是 `std::vector<bool>` 代理对象咬人的前奏。
- **decltype 的括号规则**（2.5.3）：`decltype(x)` 看表达式种类——x 是左值表达式且带括号时得 `int&`。今天少踩，因为 CTAD/结构化绑定把类型书写量降下来了。
- **类型别名（2.5.1）**：`using` 优于 `typedef` 的唯一硬理由是模板：别名模板（16.1.2 再探）。

## 🔧 实测（已实测 g++ 15.2, -std=gnu++11）

`s02.cpp` 验证转换阶梯与列表初始化拒窄化：

```cpp
unsigned u = 0; --u;                 // 回绕：定义行为
long d = 3.14;                       // 旧式：静默截断
long ok{3};                          // 列表初始化：合法
char c = 300;                        // 窄化后果
printf("-1 < 1u ? %d", -1 < 1u);     // 符号混合比较
```

```
u = 4294967295            // unsigned回绕是定义行为
sizeof(long long)=8 sizeof(size_t)=8
d=3 ok=3 c=44
-1 < 1u 的结果 = 0 // 有符号转无符号后比较
```

编译器对 `char c = 300;` 给出 `-Woverflow` 警告（changes value from '300' to '44'）——证明"打开警告等于白送半个本章"。

## 2.6 自定义数据结构与头文件

Sales_data（bookNo/units_sold/revenue）从 struct 起步、带类内初始值、配三个"逻辑成员"非成员函数（`read/avg/add`）——这是 C++ 数据驱动的接口哲学：**能当友元的接口越少越好**。头文件三原则（2.6.3）：一次定义规则下的"头文件放声明、源文件放定义、用包含守卫"。

- **现代补位**：`#pragma once` 非标准但事实通用；真正的替代是 C++20 modules（P1103R3 "Merging Modules"，实测 200）——模块接口文件取代"头文件+守卫"这一 40 年范式，但采用率仍有限 ⚠️。

## 最新演进与工业实践（基线 C++11 → 现在）

- **`auto_ptr`（本书之外的旧遗产）**：C++11 废弃、**C++17 删除**。凡读到 `auto_ptr<T>` 直接等价改写为 `unique_ptr<T>`，其拷贝即转移的语义是本书 12.1.5 推荐 unique_ptr 的动机。
- **CTAD 类模板参数推断（C++17，[P0091R3](https://wg21.link/p0091r3) 实测200）**：`std::complex z{1.0, 2.0};` 不再写 `std::complex<double>`——本章"类型别名回血"主题的现代续集。
- **`inline constexpr`（C++17）**：头文件里定义常量对象的标准姿势，终结 `extern const` 声明+定义分离样板。
- **GSL（Guidelines Support Library）**：`gsl::narrow_cast<T>(v)` 显式承认窄化、`gsl::not_null<T*>` 表达"指针非空"约束——把本章"转换要自觉"落成可检查的类型。
- **clang-tidy**：`bugprone-narrowing-conversions`、`cppcoreguidelines-pro-type-*` 直接对位 2.1.2 类型转换陷阱。
- **abseil 对照**：`absl::string_view` 等"视图类型"的精神起点是本章"引用不是对象"的所有权观。

## 小节细目（按原书小节号速记）

- **2.1.1 算术类型（页30）**：bool/char/wchar_t/char16_t/char32_t（C++11 新增后两者）；short/int/long/long long；float/double/long double；"int 至少 16 位"式的下限承诺而非定死位宽。
- **2.1.2 类型转换（页32）**：带符号→无符号按模回绕；赋无符号/带符号值给无符号类型的两个方向各举数字例；`-1 < 1u` 反例（🔧 实测）。
- **2.1.3 字面值常量（页35）**：整型字面量的 u/l 后缀、八进制 0 前缀与十六进制 0x——`0144` 不是十进制这种阴间例子书中专设警示；字符与字符串字面量的转义序列表；字符串拼接规则（仅字面量间）。
- **2.2.1 变量定义（页38）**：初始化 vs 默认初始化的区别——内置类型默认初始化值是"垃圾"，类类型走默认构造；列表初始化 `{}`（C++11）全家桶。
- **2.2.2 声明和定义（页41）**：`extern`；"一次定义规则（ODR）"首次出现。
- **2.2.3 标识符（页42）**：下划线开头保留规则（双下划线/下划线+大写）。
- **2.2.4 名字的作用域（页43）**：作用域运算符 `::`；内层遮蔽；头文件中的 using 是灾难的预告。
- **2.3.1 引用（页45）**：引用即别名、必须初始化；`refVar = val` 改的是对象不是绑定。
- **2.3.2 指针（页47）**：指针是对象、可不初始化（危险）；`nullptr`（C++11）；void* 只能与 nullptr 比较不能解引用。
- **2.3.3 理解复合类型声明（页51）**：建议多行一声明；初始化符 `*p = nullptr` 与 `*p{nullptr}` 的视觉歧义警告。
- **2.4.1-2.4.3 const（页54-57）**：const 引用可绑非常量/右值/表达式结果（"临时量续命"）；指针两种 const；顶层/底层拷贝规则。
- **2.4.4 constexpr（页58）**：常量表达式的定义（编译期可求值的表达式）；constexpr 指针必须指向对象或为空 ⚠️ 细节以标准为准。
- **2.5.1-2.5.3 类型别名/auto/decltype（页60-63）**：见上文推断规则。
- **2.6.1-2.6.3 自定义数据结构与头文件（页64-68）**：Sales_data struct 版 + 类内初始值；头文件三要素与 `#ifndef` 守卫；"头文件不该放 using std::xxx"的工程铁律。
