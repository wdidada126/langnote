## 核心概念速览（中英对照）

- **输入输出流** — iostream：标准库用对象而非函数做 IO，`cin/cout` 是预定义流对象
- **流抽取运算符** — extraction operator `>>`：从 `istream` 读数据，返回左操作数故可级联
- **流插入运算符** — insertion operator `<<`：向 `ostream` 写数据，同样可级联
- **endl** — manipulator：换行**并刷新缓冲**；`"\n"` 只换行，高频输出时应选后者
- **命名空间限定** — namespace qualification：`std::` 前缀声明名字归属
- **main 的返回类型** — return code：返回 0 表示成功，非 0 含义由实现定义
- **头文件** — header：`#include <iostream>` 引入声明；不带 `.h` 的是标准头
- **注释三种** — comment：`//`、`/* */`（不能嵌套！Windows路径坑）、`;` 语句终止符
- **while / for 循环** — loop：1.4 用 ISBN 累加串起控制流
- **哨兵驱动输入** — sentinel-controlled input：`while (cin >> v)` 以流状态判断结束（EOF）
- **类 / 成员函数** — class / member function：1.5  Sales_item 的 `isbn()/qty()/avg()`，第一口 OOP
- **编译四流程** — compilation steps：预处理→编译→汇编→链接（5版1.1.1的模型）

## 1.1-1.4 机制与权衡：为什么从 `cout` 而不是 `printf` 讲起

**动机**：Lippman 想让第一行代码就体现"C++ 是带类型的对象世界"——`std::cout << sum << std::endl` 展示运算符重载、对象、命名空间三件事，这是 `printf("%d", sum)` 给不了的。

**机制**：
- `<<`/`>>` 是重载运算符而非格式串解释器：类型由编译器决定，运行时不再猜 `%d/%u/%lld`。
- 级联成立因为流运算符返回流对象自身；`endl` 是操纵符（manipulator）。
- 1.4.3 的"读取数量不定输入"是全书第一个惯用法：`while (cin >> v)`——流被隐式转换为状态检查（C++11 后走 `explicit operator bool`，见第14章"类型转换"呼应）。

**权衡**：书的例子把"每行一个数"当输入协议，真实 CLI 更多用命令行参数与文件重定向；1.1.1 讲的四步编译模型在今天的 `-j` 构建与 ccache 环境下只是心智模型。

**相邻概念对比**：`cout << x` vs `printf("%g", x)`——前者错了编译不过、后者错了自己找；`endl` vs `'\n'`——差一次 flush，循环里差别巨大。

## 1.5-1.6 类简介：书店程序的教学法

`Sales_item` 一上来就"用类"而非先讲 struct：`item1.isbn()` 让读者先当**用户**，第7章再当**作者**。书店循环 `while (cin >> trans && ++cnt <= 42)`（1.6 的 ISBN 计数版）把第1章所有零件拧成一个程序。这个"先接口后实现"的顺序是 Primer 与 Primer Plus 类书籍最大的教学法差异。

## 逐节精读札记（页码以单文件目录为准）

- **1.1.1 编译、运行程序（页3）**：四模型（预处理/编译/汇编/链接）。今天值得补一句：头文件展开发生在预处理期，这正是第16章"模板放头文件"、以及 C++20 modules 想根治的一切问题的源头。本书教学顺序里读者此刻还没有这个痛感，回头读 2.6.3 时再补。
- **1.2 初识输入输出（页5）**：`cin` 读空白分隔的值——ISBN 中间不能有空格是书的例子刻意选的。此处埋着后面第3章 string 读取语义（`>>` 遇空白停 vs `getline`）的对比伏笔。
- **1.3 注释（页8）**：`/* */` 不嵌套 → Windows 路径注释 `/* c:\programs\read */` 里的 `\r` 制表符经典坑（不同编译器行为不一，属于"不可依赖"的灰色区）。
- **1.4 控制流（页10）**：while 与 for 的第一个差别——for 把"初始化/条件/递增"收进头部，作用域更紧。书此时不说"为什么"，要到 3.5.1/6.1 才谈作用域；读第1章时应先记住形式。
- **1.4.3 数量不定输入（页13）**：`while (cin >> v)` 与"EOF 在 Windows 终端是 Ctrl+Z"这类实操知识，书放的是练习而非正文——新手常在这一步卡住，这里记一笔。
- **1.5 类简介（页17）**：`Sales_item` 的 `+` 与 `<<` 已是运算符重载的首次"使用"（定义在第14章）。术语表（页23）第一次出现 class、member、library 三件套。

## 易错点与辨析（第1章级）

1. **`cout << "a" << "b"` 不是字符串相加**：两次独立插入，与 `+` 拼接 `std::string` 是两回事（第3章展开）。
2. **`;` 是语句终止符不是分隔符**：`for(...);` 分号吃掉循环体的经典 bug 在第1章的 while 形式里就会出现。
3. **`return 0;` 可以省略**：main 特例——到达右花括号隐式返回 0，其他函数不可。书正文未强调，练习里撞到会困惑。
4. **头文件带不带 `.h`**：`<iostream>` 是标准写法，`<iostream.h>` 是 1998 年前的遗留物，本书教的是前者；读老代码遇到后者即知年代。

## 最新演进与工业实践（基线 C++11 → 现在）

- **`std::print`/`println`（C++23，[P2093R14](https://wg21.link/p2093r14) "Formatted output" 实测200）**：本章级别的 Hello World 在 2020s 的默认写法。libstdc++ 15 已实现；本机 MinGW 链接缺终端符号（win32 线程模型已知残缺 ⚠️），Linux/GCC 14+ 正常。
- **`std::format`（C++20）**：类型安全格式化，printf 的现代替身；fmtlib（[fmt](https://github.com/fmtlib/fmt)）是其工业前身。
- **范围 for（书中 3.x 才出现）**：第1章的累加循环今天一律 `for (int x : data) sum += x;`。
- **工业对照**：abseil 的 `absl::StrCat`/`absl::PrintF`、folly 的 `folly::format`（历史）/`F14` 无关但同属"替代 iostream 格式化"流派；大量服务代码直接上 spdlog（fmt 内核）而不是 `cout`。clang-tidy 无对应检查项，本知识点靠 code review。
- **定性标注**：1.2 强调的 `endl` 习惯在高频日志场景已被"显式 flush + `'\n'`"取代；书未提 `sync_with_stdio(false)`——IO 密集入门程序在现代编译器上仍可能因此慢一个数量级。

- **1.4 控制流（页10）**：1.4.1 while（累加 50·51 例子）；1.4.2 for（同一逻辑换写法，"for 头内变量作用域仅限循环"第一次出现）；1.4.3 while(cin>>v) 求和（EOF 语义）；1.4.4 if（成绩分级例子，`else if` 链）。
