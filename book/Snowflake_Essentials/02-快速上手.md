# 02 快速上手（Snowflake Quick Start）

> 原书章：Ch.2 "Snowflake Quick Start"（pp.11–24），DOI `10.1007/978-1-4842-7316-6_2` ✅（Crossref 章级寄存实证）。

## 阅读目标

1. 复述试用账户（Free Trial）从注册到第一条查询的完整链路。
2. 写通最小闭环：仓库→库→schema→表→插入→查询→销毁。
3. 理解试用期的计量方式（credits）与正式账户的差异。

## 1. 注册与首次登录

- 试用入口：官网表单注册（无需信用卡，成书口径 ⚠️；2026 现行为 **500 美元等值 credit、30 天试用期**，⚠️ 价目随官网调整，不写死，登记于 00 勘误精神下的"演进注"）。
- 选定云与区域（AWS/Azure/GCP × region）：试用账户区域一旦选定不可迁移（⚠️ 转述，✅ https://docs.snowflake.com/en/user-guide/intro-regions）。
- 登录 URL 形态：`https://<组织>-<账户>.<region>.snowflake.com`——账户标识进 URL 是 Snowflake 的多租户特征（⚠️）。
- 首登强制改密 + 可选 MFA；试用期默认以 `ACCOUNTADMIN` 单角色体验全部功能（⚠️ 转述；生产角色分离见第 7 章）。

## 2. 最小操作闭环（本书第 4–5 章界面之前的速览版）

```sql
-- 以下均为自拟教学示意 SQL（ANSI 风味，未在盘实测，⚠️ 语法以官方 SQL 引用为准）
CREATE WAREHOUSE QUICKSTART_WH
  WAREHOUSE_SIZE = 'XSMALL'
  AUTO_SUSPEND = 60 AUTO_RESUME = TRUE;

CREATE DATABASE DEMODB;
CREATE SCHEMA DEMODB.SALES;
CREATE TABLE DEMODB.SALES.ORDERS (
  id INT, amount DECIMAL(10,2), placed_at TIMESTAMP_LTZ
);
INSERT INTO DEMODB.SALES.ORDERS VALUES
  (1, 99.5, '2022-01-05 09:00:00'),
  (2, 12.0, '2022-01-06 11:30:00');

SELECT * FROM DEMODB.SALES.ORDERS WHERE amount > 50;

DROP WAREHOUSE QUICKSTART_WH;   -- 销毁即停止计费（⚠️ 秒级计量转述）
```

- 关键点一：**建表不需要集群决策**（无分布键/索引设计），对照传统 MPP 数仓的上手负担（⚠️）。
- 关键点二：查询必须"有仓库才跑得动"——DDL 元数据操作走托管的服务层、不消耗你的仓库 credits；DML/查询才拉起计算（⚠️ 转述，✅ https://docs.snowflake.com/en/user-guide/warehouses-overview）。
- 官方推荐的第一堂课是样例数据库 `SNOWFLAKE_SAMPLE_DATA`（TPC-H/TPC-DS 预置数据，从市场共享而来——Ch.14 的伏笔）（⚠️ 转述，✅ ui-snowsight-gs）。

## 3. 客户端选择：Web 界面 vs SnowSQL

| 客户端 | 成书时状态 | 现在（2026） | 适用 |
| --- | --- | --- | --- |
| Classic Console | 主界面 | **已退役**（文档 404 实证，见 04 章） | 仅历史资料 |
| Snowsight | "Preview App" | 唯一官方 Web 界面 | 交互分析/管理 |
| SnowSQL（CLI） | 在架 | 在架（脚本/装载 PUT/GET 依赖） | 批处理、文件上传 |
| 连接器/驱动 | ODBC/JDBC/Python | 增加 Connector/Python、Kafka Sink、dbt、Terraform 等 | 工程化 |

- 本书第 2 章教学载体大概率是 Web 界面 + 少量 SnowSQL（⚠️ 推定：未获样章；成书期试用引导以浏览器为默认）。

## 4. 试用期的计量与到期

- 试用消耗的是预付 credits：仓库运行秒数 × 尺寸系数、装载/查询类管道操作亦计量（⚠️ 转述，✅ https://docs.snowflake.com/en/user-guide/resource-monitors 见信用控制面）。
- 到期后账户进入只读/宽限期（⚠️ 具体天数随政策），转正式账户即换计费模式（预购年包或按月后付，⚠️）。
- 入门者最常见的第一笔"意外账单"：**仓库忘了挂起 + AUTO_SUSPEND 设太长**——所以第 10 章把 AUTO_SUSPEND 调优列为入门必修（⚠️ 社区共识转述）。

## 5. 章内易错与疑问

- **易错 1**：试用选错区域后想"搬家"——不可迁移，只能重注册（⚠️）。
- **易错 2**：把 `CREATE DATABASE` 当成需要仓库的活——不需要，但 `INSERT/SELECT` 需要；忘了 `USE WAREHOUSE` 会报"no warehouse available"（⚠️ 典型报错，转述）。
- **易错 3**：对象名大小写——不带引号符默认折叠为大写，带双引号则严格区分（⚠️ 转述，✅ https://docs.snowflake.com/en/sql-reference/identifiers-syntax 2022 后新增页）。
- **疑问**：为什么不先讲架构再上手？答：本书采用"先跑起来再懂"的教程式设计，第 3 章回头补架构；入门册的常见编排。

### FAQ

- **Q1 试用账号权限太大，学安全章还有效吗？** A：有效——试用是"上帝视角"，Ch.7 的角色链练习需自建第二角色模拟，本清单 D5 即为此。
- **Q2 报错 "No active warehouse selected" 第一反应该如何查？** A：`SHOW WARESHOPS` 心不在焉→先 `USE WAREHOUSE`，再查角色是否持有 USAGE（Ch.7 GRANT 链）。
- **Q3 为什么插入后立刻 SELECT 也要等仓库启动？** A：DML/查询都在计算层，SUSPENDED→RUNNING 有启动延迟——"冷启动"体验第一课（Ch.10 状态机）。
