## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 7.1 有限等概率：概率就是「有利结果数 / 总结果数」，分母来自第 6 章的计数。

from itertools import combinations

def uniform_prob(favorable, sample_space_size):
    """有限等概率空间：P(E) = |E| / |S|。"""
    assert len(favorable) <= sample_space_size
    return len(favorable) / sample_space_size

# 生日问题（7.1 的同类问题）：k 个人里至少两人生日相同的概率
def birthday_paradox(k, days=365):
    """至少两人生日相同的概率；「生日悖论」的直觉陷阱就在这里。"""
    same = 1.0
    for i in range(k):
        same *= (days - i) / days
    return 1 - same

for k in (10, 20, 23, 30, 50):
    print(k, round(birthday_paradox(k), 4))
# k = 23 时已超过 0.5 —— 与「直觉上要 100 多人」相反

# 抽样：无放回 vs 有放回（7.1 的核心区别）
def drawing_prob(kind, first_white, whites, total):
    """从瓮中取两球；有放回与无放回到处被混用。"""
    if kind == "with_replacement":
        return first_white * (first_white / total)
    return first_white * ((whites - 1) / (total - 1))
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 7.2 / 7.4：条件概率、独立性判定，以及期望与方差的直接计算。

def conditional_prob(p_a_and_b, p_b):
    """条件概率 P(A|B) = P(A ∩ B) / P(B)；P(B) = 0 时无定义。"""
    return p_a_and_b / p_b if p_b else None

def independent(p_a, p_b, p_a_and_b):
    """独立性的判定：P(A ∩ B) = P(A)·P(B)。注意与「互斥」区分。"""
    return abs(p_a_and_b - p_a * p_b) < 1e-12

def expected_value(samples, weights):
    """期望 E[X] = Σ x_i · p_i（离散随机变量的加权平均）。"""
    total = sum(weights)
    return sum(x * w for x, w in zip(samples, weights)) / total

def variance(samples, weights):
    """方差 Var(X) = Σ p_i · (x_i − E[X])²。"""
    mean = expected_value(samples, weights)
    return sum((x - mean) ** 2 * w for x, w in zip(samples, weights))

# 7.2 的经典陷阱：感冒检测
sens, spec, prevalence = 0.99, 0.95, 0.005   # 敏感度、特异度、患病率
p_pos = prevalence * sens + (1 - prevalence) * (1 - spec)
ppv = conditional_prob(prevalence * sens, p_pos)
print("阳性者真患病的比例（PPV）:", round(ppv, 4))
# 结果远低于直觉——这正是第 7.3 节贝叶斯定理要回答的问题
```

- **条件概率的三个易错点**：分母是「条件事件」不是原样本空间；`P(A|B) ≠ P(B|A)`（医学检测是最著名的例子）；独立与互斥不可混用——互斥必然不独立，独立必然不互斥（除非概率为 0）。
- **期望的线性性**是本章最有用的工具：`E[X + Y] = E[X] + E[Y]`，无论 X 与 Y 是否独立。这在算法分析里用来拆分「比较次数 = 交换次数 + 其他」时非常省心。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **把「至少一个是 A」当成 P(A)** | 事件「至少一个」是并事件 `A ∪ B`；写成 `P(A)` 会丢掉另一个事件 |
| 🔧 **混淆互斥与独立** | 互斥是指 `A ∩ B = ∅`（不能同时发生），独立是指 `P(A ∩ B) = P(A)P(B)`；互斥的两个事件必然不独立 |
| 🔧 **条件概率的分母写错** | `P(A|B)` 的分母是 `B` 的概率，不是 `A` 的；医学检测里把「阳性中患病的比例」写成敏感度，就是这一条错误 |
| **「生日悖论」当成悖论** | 它只是反直觉：23 人中至少同生日的概率已超 50%，因为比较对象是 253 对而非 23 对 |
| 🔧 **等概率假设被滥用** | 7.1 的 `|E| / |S|` 只在「样本空间等概率」时成立；掷一个两面体不一样重的骰子时该假设失效 |
| 🔧 **有放回与无放回混用** | 无放回抽样时每次概率会变；除非题目明确「抽出后放回」，否则必须按无放回计算（如抽签公平性问题） |
| **把期望当「一定会出现的值」** | 期望是加权平均，可以是「没有一个人会拿到的值」（如「家庭子女数」）；它也不保证是整数 |
| 🔧 **把「这是离散概率」当成「本章够用了」** | 本章全是有限样本空间，没有连续分布、没有密度函数、没有凸优化；做机器学习需要另外补概率论与最优化（本书的缺口，见 00 总览第 3 节） |
