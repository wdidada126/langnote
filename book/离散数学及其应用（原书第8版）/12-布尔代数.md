# 第 12 章 布尔代数

> **一句话**：布尔代数把「逻辑」变成「电路」——本章的四节正好是一条从函数到硬件的流水线：布尔函数 ⟶ 函数表示 ⟶ 逻辑门 ⟶ 电路极小化。

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 12.2：用真值表生成布尔函数的「最小项之和」表示（sum of minterms）。

from itertools import product

def truth_table(n, f):
    """n 元布尔函数的真值表（1 为真）。"""
    return [f(*bits) for bits in product([0, 1], repeat=n)]

def minterms(n, f):
    """最小项之和：列出使 f 为 1 的下标（下标即二进制位序）。"""
    rows = list(product([0, 1], repeat=n))
    idx = [i for i, bits in enumerate(rows) if f(*bits)]
    return idx

def from_minterms(n, idx):
    """从最小项集合还原布尔函数（先按位展开再合并同等价式）。"""
    rows = list(product([0, 1], repeat=n))
    selected = [rows[i] for i in idx]
    def f(*bits):
        return tuple(bits) in [tuple(s) for s in selected]
    return f

# 12.1 的不同函数计数：2^(2^n)
for n in range(1, 5):
    print(n, 2 ** (2 ** n))
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 12.3：半加器（两个半加器叠成全加器）与 4 选 1 多路复用器的逻辑建模。

def half_adder(a, b):
    """半加器：sum = a XOR b，carry = a AND b。"""
    return (a ^ b, a & b)

def full_adder(a, b, carry_in):
    """全加器：由两个半加器与一个或门组成。"""
    s1, c1 = half_adder(a, b)
    s2, c2 = half_adder(s1, carry_in)
    return (s2, c1 | c2)

def mux4(sel1, sel0, d0, d1, d2, d3):
    """4 选 1 多路复用器：选择线决定哪一路数据送到输出。"""
    if (sel1, sel0) == (0, 0):
        return d0
    if (sel1, sel0) == (0, 1):
        return d1
    if (sel1, sel0) == (1, 0):
        return d2
    return d3

# 12.3 的传播延迟：n 位行波进位加法器的关键路径是 O(n) 个全加器串联
def ripple_carry_add(a, b):
    """行波进位加法器（示意）：逐级进位，关键路径长度与位数成正比。"""
    result, carry = [], 0
    for i in range(max(len(a), len(b))):
        bit_a = a[i] if i < len(a) else 0
        bit_b = b[i] if i < len(b) else 0
        bit, carry = full_adder(bit_a, bit_b, carry)
        result.append(bit)
    return result, carry
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 12.4 K-map：两变量/三/四变量的「圈 1」化简可以完全手工化为表格判定。

def kmap_groups(n_vars, ones):
    """四变量 K-map 的相邻 pairs：把 16 个格子按格雷码顺序编号。"""
    # 四变量 K-map 的行用 00/01/11/10（格雷码），保证相邻行只差一位
    gray_rows = [0b00, 0b01, 0b11, 0b10]
    gray_cols = [0b00, 0b01, 0b11, 0b10]
    groups = []
    for r1 in range(4):
        for c1 in range(4):
            if (r1, c1) not in ones:
                continue
            # 与「上下左右」相邻且同为 1 的格子合并
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                r2, c2 = (r1 + dr) % 4, (c1 + dc) % 4
                if (r2, c2) in ones and (r2, c2) > (r1, c1):
                    groups.append({(r1, c1), (r2, c2)})
    return groups

# 无关项（don't care）可当 0 也可当 1，是 K-map 化简里最容易多圈一项的地方
def minimize_with_dont_care(ones, dont_cares):
    """把无关项视作可用格，参与合并但不要求最终为 1（教学示意）。"""
    return kmap_groups(4, set(ones) | set(dont_cares))
```

```cpp
// 目标：把 f(a,b,c) = Σm(1,3,5,7) 化简后再描述。

/*
  f(a,b,c) = Σm(1,3,5,7)
           = (a'b'c + a'bc + ab'c + abc)
           = c·(a'b' + a'b + ab' + ab)
           = c
  因此整个电路只需要一根线——这正是 K-map「圈成一片」的效果。
*/

module example(input a, b, c, output f);
    assign f = c;         // 化简后的最简与或式
endmodule

// 未化简写法（保留作为对照，门数明显更多）：
module example_unminimized(input a, b, c, output f);
    wire n_a, n_b, n_c, t1, t2, t3, t4;
    not (n_a, a), (n_b, b), (n_c, c);
    and (t1, n_a, n_b, c);
    and (t2, n_a, b, c);
    and (t3, a, n_b, c);
    and (t4, a, b, c);
    or  (f, t1, t2, t3, t4);
endmodule
```

**关于「可逆计算」的一点补充（外扩）**：经典逻辑门会丢弃信息（`AND`、`OR` 不可逆），但物理上信息不可随意销毁（Landauer 原理），于是产生了可逆门（如 Toffoli 门）与「 Bennett 可逆计算」。第 12 章只讨论不可逆的组合电路，可逆计算属于量子计算与低能耗计算的交叉领域，可用 `Qiskit/Qiskit`（≈**7.8k★**，实测）动手对照。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **把「电路」当成有记忆的** | 12.3 明确是**组合电路**（无反馈、无存储）；一旦出现反馈就是时序电路，分析方法完全不同（需状态机） |
| 🔧 **K-map 用自然二进制码排格** | K-map 的行列必须按**格雷码**顺序（00→01→11→10），否则「相邻」关系不成立，圈出来的项是错误的 |
| 🔧 **无关项（don't care）被当成果真为 0** | 无关项可以当 0、也可以当 1 参与合并；把它固定为 0 会少圈项，电路就不是最简 |
| **把 `f = Σm(1,3,5,7)` 当成已经最简** | 它的最简形式是 `c`；最小项之和只是**一种**规范形式，不是极小形式 |
| 🔧 **NAND 单独不是完备集这一说法记反** | `{NAND}` 与 `{NOR}` **各自都是**功能完备集；说「NAND 不完备」是错的 |
| **K-map 用在 5 变量以上** | `n ≥ 5` 时手工圈格几乎不可靠；应改用 Quine–McCluskey 或 EDA 工具 |
| 🔧 **把「布尔函数个数 = 2^(2^n)」当小数字** | `n = 4` 时已经 65536；`n = 5` 时 4.29×10⁹；任何「枚举所有布尔函数」的实现都会在 `n ≥ 5` 时爆炸 |
| **格 / 布尔代数的表示定理当成本章内容** | 12 章只有 4 节，不含偏序集上的格与分配格、也不含「有限布尔代数同构于幂集代数」；这部分是外扩小节的内容，见 00 总览的缺口表 |
| 🔧 **门电路传播延迟被忽略** | 组合电路的延迟按关键路径累加；行波进位加法器的进位链是 `O(n)`，超前进位（carry look-ahead）才把它压到 `O(log n)` |
