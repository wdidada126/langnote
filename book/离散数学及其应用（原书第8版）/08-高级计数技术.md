## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 8.2 线性递推：用特征方程法手算「兔子问题」与斐波那契的闭式（Binet 公式）。

def rabbit_pairs(n, a=1, b=1):
    """8.1 兔子问题：F(n) = F(n−1) + F(n−2)，初始 F(1) = F(2) = 1。"""
    if n == 1 or n == 2:
        return b
    return rabbit_pairs(n - 1, a, b) + rabbit_pairs(n - 2, a, b)

def fib_binet(n):
    """斐波那契闭式（Binet 公式），用于对照 8.2 的「特根」求解。"""
    phi = (1 + 5 ** 0.5) / 2
    psi = (1 - 5 ** 0.5) / 2
    return int(round((phi ** n - psi ** n) / (phi - psi)))

# 特征方程 r^2 = r + 1 的两个根就是 phi 与 psi；重根情形（如 r^2 = 2r − 1）
# 会得到 (c1 + c2·n)·r^n 形式，这是 8.2 中「重根必须补一个 n 的幂次」的原因。
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 8.3 分治递推：主定理的三类情形，用代码把「比较 f(n) 与 n^{log_b a}」写清楚。

import math

def master_theorem(a, b, f_exponent):
    """解 T(n) = a·T(n/b) + Θ(n^f)：比较 f 与 log_b(a)。

    返回 (类型, 复杂度上界)。注意主定理只在三种情形下给出答案，
    中间情形（f = log_b a）需要更细的分析（如归并排序的 Θ(n log n)）。
    """
    n_log_b_a = math.log(a, b)
    if f_exponent < n_log_b_a - 1e-9:
        return "case 1: a < b^f", f"Θ(n^{n_log_b_a})"
    if abs(f_exponent - n_log_b_a) < 1e-9:
        return "case 2: a = b^f", "Θ(n^f · log n)"
    return "case 3: a > b^f", f"Θ(n^{f_exponent})"

print(master_theorem(2, 2, 1))      # 归并排序 → case 2 → Θ(n log n)
print(master_theorem(3, 2, 1))      # Karatsuba → case 1 → Θ(n^1.585)
print(master_theorem(2, 2, 2))      # 某些快排变体 → case 3 → Θ(n^2)
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 8.5 / 8.6 容斥与错排：用「全部排列 − 至少一位固定」的路线数错排数。

from itertools import permutations

def derangement_count_small(n):
    """小规模错排数：容斥原理的直接展开 !n = Σ_{i=0}^{n} (−1)^i · C(n,i) · (n−i)!。"""
    total = 0
    for i in range(n + 1):
        choose = math_comb(n, i)
        total += ((-1) ** i) * choose * math_factorial(n - i)
    return total

def math_comb(n, k):
    return math_factorial(n) // (math_factorial(k) * math_factorial(n - k))

def math_factorial(x):
    r = 1
    for i in range(2, x + 1):
        r *= i
    return r

# 概率版本：!n / n! → 1/e ≈ 0.3679（错排数与 e 的关系）
print(derangement_count_small(4), derangement_count_small(5))
```

- **生成函数（8.4）的三个基本力量**：`(1 + x)^n` 是组合数；`1/(1 − x) = Σ x^k` 是自然数；`1/(1 − ax)` 是几何比。把递推关系 `a_n = …` 两边乘以 `x^n` 求和，就把递推变成代数方程，解出来再展开即得 `a_n` 的闭式。
- **容斥（8.5）**：`|A ∪ B| = |A| + |B| − |A ∩ B|`，三个集合时再加回三重交。错排数是它最著名的应用：`!n = Σ_{i=0}^{n} (−1)^i C(n,i) (n−i)!`。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **重根时漏掉 `n` 的幂次** | 特征方程有重根时，通解要乘 `n^k`；只用「不同根」的公式会给出错误通解 |
| 🔧 **主定理的中间情形硬套** | `f(n)` 与 `n^{log_b a}` 同阶时，主定理给的是 `Θ(n^f log n)`，但有些递推（如 `T(n) = 2T(n/2) + n log n`）不满足任何一条标准情形，必须另行分析 |
| 🔧 **生成函数当成「形式幂级数」之外的函数** | 生成函数的变量 x 没有数值意义，只关心系数；把它当实函数代入求值通常是没有意义的 |
| **递推关系的初始条件被省略** | 同一个递推式配不同初始条件给出完全不同的序列（斐波那契与卢卡斯序列同式不同初值） |
| 🔧 **容斥只写到两项就停** | 三个及以上集合要一直写到全部子集；漏最后一项会高估并集 |
| 🔧 **错排数当成 `(n−1)!`** | 错排数 `!n` 与 `(n−1)!` 不同（后者是圆排列数）；`!n ≈ n!/e`，差在舍入 |
| **把递推式的顺序写反** | `a_n` 依赖 `a_{n−1}` 是「向下递推」；若写成 `a_{n−1}` 依赖 `a_n`，得到的递推树会反向 |
| 🔧 **忽略递推成立的前提规模** | 递推关系往往只在 `n ≥ 某个阈值` 时有效；小 n 上不成立会让闭式解在边界处偏离 |
