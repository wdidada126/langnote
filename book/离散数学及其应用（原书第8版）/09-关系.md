# 第 9 章 关系

> **一句话**：关系是「一对对象之间是否有某种联系」的抽象；给关系加上不同性质（自反/对称/传递），就分别得到等价关系、偏序与函数——数据结构与数据库的骨架都从这里长出来。

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 9.1 关系及其性质 | 二元关系定义、定义域/值域、自反、对称、反对称、传递 | 四个性质决定关系的「形状」；它们与关系矩阵的特征一一对应 |
| 9.2 n 元关系及其应用 | n 元关系、数据库关系模型、关系代数 | n 元关系是数据库的数学原型 |
| 9.3 关系的表示 | 关系矩阵、关系图、关系运算（并、交、补、逆、复合） | `M_R` 的转置即 `R⁻¹`；`(M∘M)_ij = 1` 表示两步可达 |
| 9.4 关系的闭包 | 自反闭包、对称闭包、传递闭包、闭包的计算、Warshall 算法 | 传递闭包 = 图的传递可达性，可用 Floyd–Warshall 求 |
| 9.5 等价关系 | 等价关系、等价类、划分、商集、整数同余的例子 | 等价 ⟺ 划分（二者一一对应）；`a ≡ b (mod m)` 是经典例子 |
| 9.6 偏序 | 偏序、偏序集、哈斯图、极大元/极小元、 greatest/least element、拓扑排序 | 偏序集上的哈斯图是「去掉自环与传递边」的关系图；拓扑排序存在当且仅当是 DAG |

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 9.1 / 9.3：用邻接矩阵表示二元关系，并从中读出四个性质。

def relation_matrix(pairs, n):
    """把二元关系 R ⊆ {1..n} × {1..n} 转成 n×n 的 0/1 矩阵 M_R。"""
    M = [[0] * n for _ in range(n)]
    for i, j in pairs:
        M[i - 1][j - 1] = 1
    return M

def is_reflexive(M):
    return all(M[i][i] == 1 for i in range(len(M)))

def is_symmetric(M):
    n = len(M)
    return all(M[i][j] == M[j][i] for i in range(n) for j in range(n))

def is_antisymmetric(M):
    """反对称：i ≠ j 蕴含 ¬(M[i][j] ∧ M[j][i])（注意对角线允许为 1）。"""
    n = len(M)
    return all(not (M[i][j] and M[j][i]) for i in range(n) for j in range(n) if i != j)

def is_transitive(M):
    """传递：R∘R ⊆ R。用布尔矩阵乘法判断（见第 2.6 节）。"""
    n = len(M)
    return all(
        any(M[i][k] and M[k][j] for k in range(n)) <= bool(M[i][j])
        for i in range(n) for j in range(n)
    )

def compose(M, times):
    """关系的复合 M_R^n：M^n 表示「n 步可达」。"""
    R = [row[:] for row in M]
    for _ in range(times - 1):
        n = len(R)
        R = [[any(R[i][k] and M[k][j] for k in range(n)) for j in range(n)]
             for i in range(n)]
    return R
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 9.4 传递闭包：Floyd–Warshall（书中称 Warshall）一步完成，O(n^3)。

def transitive_closure(M):
    """Warshall 算法：逐点更新，把传递闭包算成布尔矩阵。"""
    n = len(M)
    T = [row[:] for row in M]
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if T[i][k] and T[k][j]:
                    T[i][j] = 1
    return T

# 9.5 等价类：用并查集（union-find）枚举等价类，O(α(n)) 近似常数
class UnionFind:
    """等价类的并查集实现（教学示意，不参与构建）。"""
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # 路径压缩
            x = self.parent[x]
        return x

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 9.6 拓扑排序：Kahn 算法（反复删除入度为 0 的顶点）。

def topological_sort(nodes, edges):
    """拓扑排序；若存在环则返回 None（此时偏序不存在线性扩展）。"""
    from collections import deque
    indeg = {v: 0 for v in nodes}
    adj = {v: [] for v in nodes}
    for a, b in edges:
        adj[a].append(b)
        indeg[b] += 1
    q = deque([v for v in nodes if indeg[v] == 0])
    order = []
    while q:
        v = q.popleft()
        order.append(v)
        for w in adj[v]:
            indeg[w] -= 1
            if indeg[w] == 0:
                q.append(w)
    return order if len(order) == len(nodes) else None
```

- **四个性质与关系矩阵的对应**（9.1 的核心表格）：

| 性质 | 矩阵条件 |
| --- | --- |
| 自反 | 对角线全为 1 |
| 对称 | `M = Mᵀ` |
| 反对称 | `i ≠ j` 时 `M_ij` 与 `M_ji` 不同时为 1 |
| 传递 | `M² ⊆ M`（布尔乘法） |

- **哈斯图（9.6）**：把偏序集的关系图去掉自环（自反边）与传递边后得到的图，就是哈斯图。拓扑排序是它的线性扩展。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **把「对称」和「反对称」当成互斥** | 二者可以同时成立（如「i = j」关系既对称又反对称）；也可以都不成立。反对称的定义里**对角线允许为 1** |
| 🔧 **传递闭包用「反复求交」手写** | 正确做法是直接 Warshall（本书 9.4）或 Floyd–Warshall；反复做关系复合是 `O(n⁴)` 以上的浪费 |
| 🔧 **等价关系与划分的对应被漏掉** | 等价关系唯一确定一个划分，反之亦然；只写「等价类」而不提划分，会错过 9.5 的核心结论 |
| **哈斯图当成关系图** | 哈斯图省掉了自环与传递边；用带自环的关系图去读「谁直接覆盖谁」是错的 |
| 🔧 **拓扑排序当成唯一** | 偏序集的线性扩展通常不唯一，Kahn 算法给出的只是其中之一；有环时返回 None 才是正确判定 |
| **把「逆关系」当成「逆函数」** | `R⁻¹` 只是把矩阵转置；若 `R` 不是函数，`R⁻¹` 不构成函数，也没有「定义域/值域互换」之外的语义 |
| 🔧 **n 元关系当成二元关系的特例** | 9.2 的 n 元关系有独立的选择（projection 等运算），不能只用二元关系推导 |
| 🔧 **反对称被写成「若 `M_ij=1` 则 `M_ji=0`」** | 正确表述是「若 `i ≠ j` 且 `M_ij = 1` 则 `M_ji = 0`」；加上 `i ≠ j` 才不会误伤对角线 |
