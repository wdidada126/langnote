# 第 4 章 数论和密码学

> **一句话**：整除与同余给出「整数上的代数」，而密码学是这套代数第一次真正改变世界的样子——RSA 的全部安全性都押在「大数分解很难、判断素数容易」这个非对称事实上。

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 4.1 整除性和模算术 | 整除、`a mod m`、`gcd`、模运算与同余、`m | (a−b) ⟺ a ≡ b (mod m)`、同余类与 `Z_m` | `gcd(a,b)·lcm(a,b) = |ab|`；`Z_m` 中只有与 m 互素的元有乘法逆 |
| 4.2 整数表示和算法 | 二进制/十六进制表示、二补数、位运算、模幂 `b^e mod m`、Sieve of Eratosthenes | 模幂用「平方-乘法」只需 `O(log e)` 次乘法；素数筛是 `O(n log log n)` |
| 4.3 素数和最大公约数 | 素数、合数、gcd/lcm、欧几里得算法、贝祖等式、`√n` 判定法 | 欧几里得算法复杂度 `O(log min(a,b))`；贝祖等式给出逆元的存在条件 |
| 4.4 求解同余方程 | 线性同余 `ax ≡ b (mod m)`、模逆元、中国剩余定理 (CRT) | `ax ≡ b` 有解 ⟺ `d = gcd(a,m)` 整除 b；解在模 `m/d` 下唯一 |
| 4.5 同余的应用 | 散列表（哈希）、伪随机数、SHA-256 概览、校验位（ISBN、UPC）、RSA 公钥 | 移位与模运算是哈希与校验位的设计主体；SHA-256 需 `gcd` 之外的位运算 |
| 4.6 密码学 | 替代密码、仿射密码、RSA、流密码、AES 概览、公钥与数字签名 | RSA 加解密是模幂；签名用私钥加密、公钥验证；安全性依赖分解困难性 |

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 4.2 / 4.3：欧几里得算法、扩展欧几里得（求模逆）、平方-乘法模幂。

def gcd(a, b):
    """欧几里得算法；复杂度 O(log min(a, b))。"""
    while b:
        a, b = b, a % b
    return abs(a)

def egcd(a, b):
    """扩展欧几里得：返回 (g, x, y) 使 a·x + b·y = g = gcd(a, b)。"""
    old_r, r = a, b
    old_s, s = 1, 0
    old_t, t = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t
    return old_r, old_s, old_t

def mod_inverse(a, m):
    """求 a 在模 m 下的逆元；当 gcd(a, m) ≠ 1 时不存在。"""
    g, x, _ = egcd(a, m)
    if g != 1:
        return None
    return x % m

def mod_pow(base, exp, mod):
    """平方-乘法：把 exp 的二进制位逐位扫一遍，只需 O(log exp) 次模乘。"""
    result = 1
    base %= mod
    while exp > 0:
        if exp & 1:
            result = (result * base) % mod
        base = (base * base) % mod
        exp >>= 1
    return result
```

**RSA 的四个步骤**（4.6 的骨架）：

1. 取两个大素数 `p, q`，令 `n = pq`，`φ(n) = (p−1)(q−1)`。
2. 选 `e` 使 `gcd(e, φ(n)) = 1`，且 `1 < e < φ(n)`。
3. 用扩展欧几里得求 `d`，使 `e·d ≡ 1 (mod φ(n))`。
4. 加密 `c = m^e mod n`，解密 `m = c^d mod n`。

正确性来自 Euler 定理：`m^(φ(n)+1) ≡ m (mod n)`，从而 `c^d = m^(ed) ≡ m (mod n)`（书上也用二项式定理推出 Fermat 小定理作为推论）。

```python
# 教学示意，不参与构建（不编译、不运行）
# 4.4 中国剩余定理：x ≡ a_i (mod m_i) 且 m_i 两两互素时，解在 M = Π m_i 下唯一。
# 实现即「用逆元逐步合并同余式」。

def crt(remainders, moduli):
    """合并同余式 x ≡ r_i (mod m_i)，要求 m_i 两两互素。"""
    x, cur_mod = 0, 1
    for r, m in zip(remainders, moduli):
        _, inv, _ = egcd(cur_mod, m)      # 借自上面的扩展欧几里得
        # 用「逐步提升模数」的方式合并
        lift = lambda k: r + m * k
        k0 = None
        for k in range(m):
            if lift(k) % cur_mod == x % cur_mod:
                k0 = k
                break
        if k0 is None:
            return None
        x = lift(k0)
        cur_mod *= m
    return x

# 4.5 的哈希与校验位：移位 + 模是散列表与 ISBN 校验的共同骨架
def linear_probe_hash(key, table_size):
    """散列表的线性探测：h(k) + i (mod m)，i = 0, 1, 2, …"""
    slot = key % table_size
    return slot
```

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **把 `a ≡ b (mod m)` 当成等式** | 同余是**关系**不是相等；`≡` 与 `=` 不可互换。可行的运算只有「同余类里的加、减、乘」，除法需要模逆元 |
| 🔧 **模幂写成「连乘 e 次」** | `b^e mod m` 若循环 e 次则 `O(e)`；正确用平方-乘法，只需 `O(log e)` 次模乘 |
| **RSA 里用 `φ(n) = n`** | 必须用 Euler 函数 `φ(n) = (p−1)(q−1)`；用 `n` 会让解密失败 |
| 🔧 **求逆元用试除法** | 应统一用扩展欧几里得（或 `pow(a, −1, m)`）；`a` 与 `m` 不互素时逆元根本不存在，必须先查 `gcd` |
| **CRT 要求模数两两互素** | 不互素时不能完全合并成单一模数下的解；本章 4.4 的结论只在互素前提下成立 |
| 🔧 **「分解很难所以 RSA 安全」被写成定理** | 安全性假设依赖具体困难问题的假设；没有证明表明 P ≠ NP，也没有证明分解是 NP 完全的（见第 13 章外扩） |
| **素性检验用试除法** | 4.3 的 `√n` 方法只适用于小整数；2048 位素数必须概率素性检验 |
| 🔧 **抄 RSA 参数直接上线** | 实际部署必须用 CSPRNG 生成 `p, q`，并对 `d` 做约束（如 FIPS 标准的限定）；书上的小参数是教学用的 |
