# 第 6 章 计数

> **一句话**：计数的做法是「把计数对象拆成正交的选择步骤」——乘法原理管「分步骤」，加法原理管「分类型」，剩下的全部工作就是判断该用哪一个。

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 6.1 计数的基础 | 乘积法则、和法则、修正原则（排除重复计数）、排列、组合 | 「先分类再分步」的分解顺序决定成败；集合的基数「要么加法要么乘法」 |
| 6.2 鸽巢原理 | 鸽巢原理（抽屉原理）、`⌈n/m⌉`、后缀与前缀、`n` 个球 `m` 个盒子 | 反证法最常用：假设每个盒子至多 `k` 个，则总数不足 |
| 6.3 排列与组合 | 排列 `P(n,r)`、组合 `C(n,r)`、`n!`、圆排列与环排列 | `P(n,r) = n!/(n−r)!`，`C(n,r) = n!/(r!(n−r)!)` |
| 6.4 二项式系数和恒等式 | 二项式定理、帕斯卡三角形、组合恒等式、Vandermonde 恒等式 | `(x+y)^n = Σ C(n,k) x^k y^(n−k)`；帕斯卡递推 `C(n,k) = C(n−1,k−1) + C(n−1,k)` |
| 6.5 排列与组合的推广 | 多重集的排列与组合、允许重复的排列、二项式系数系数的推广 | 多重集排列 `n!/(n1! n2! … nk!)`；「星与条」处理重复选择 |
| 6.6 生成排列和组合 | `next_permutation` 类算法、字典序全排列、组合枚举 | 全排列 `n!` 个，组合枚举用 `itertools.combinations` |

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 6.1 / 6.6：用 itertools 直接枚举排列与组合，验证乘法/加法原理的计数结果。

from itertools import permutations, combinations, product, combinations_with_replacement

n_items = ["A", "B", "C"]

# 乘法原理：三个位置各有 3 种选择 → 3^3 = 27 种
print(len(list(product(n_items, repeat=3))))          # 27

# 排列：从 3 个里选 2 个并排序 → P(3,2) = 6
print(len(list(permutations(n_items, 2))))            # 6

# 组合：从 3 个里选 2 个不考虑顺序 → C(3,2) = 3
print(len(list(combinations(n_items, 2))))            # 3

# 可重复组合（星与条）：C(n+r−1, r) = C(3+2−1, 2) = 4
print(len(list(combinations_with_replacement(n_items, 2))))   # 4

# 加法原理与排除重复计数：从 {1..100} 中选出两个不同的、其中一个为偶数的个数
# 错误做法 C(100,2) 会把「两个都是偶数」算成 n^2 而非排除重复；正确分两类：
same = lambda k: k * (k - 1) // 2          # 组合数 C(k,2)
odd_cnt, even_cnt = 50, 50
print(same(odd_cnt + even_cnt) - same(odd_cnt) - same(even_cnt))   # 排除重复
```

**二项式定理（6.4）**：`(x + y)^n = Σ_{k=0}^{n} C(n,k) · x^k · y^(n−k)`。它在本书里的三个作用：给出组合数的对称性与递推、给 Fermat 小定理一个证明（见 8 版新增习题）、以及在第 8.4 节生成函数里作为系数来源。

```python
# 教学示意，不参与构建（不编译、不运行）
# 6.2 鸽巢原理： proofs 用反证法；代码里则用「最少必有一个盒子装了多少」的形式化判定。

def pigeonhole(ball_cnt, box_cnt):
    """鸽巢原理：n 个球放入 m 个盒子，则至少有一个盒子含 ⌈n/m⌉ 个球。"""
    assert ball_cnt >= box_cnt, "鸽巢原理的前提：n ≥ m"
    return -(-ball_cnt // box_cnt)          # 即 ⌈n/m⌉

# 典型推论：n 个人的房间里至少有 2 人有相同的生日之类，用「每个盒子至多 k 个」反证
# 例：从 [1..100] 中选 51 个数，必有两个数互差是 2 的倍数（奇偶两个盒子）
print(pigeonhole(51, 2))                     # 26 → 必有一类至少有 26 个
```

- **「星与条」（6.5）**：从 `n` 个可重复元素中选 `r` 个的方案数是 `C(n + r − 1, r)`。推导方式是把它转成「从 n 类中选择并排成一行」的组合问题。
- **多重集排列**：`n` 个元素中各有 `n₁, n₂, …, n_k` 个相同，排列数为 `n! / (n₁! n₂! … n_k!)`。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **乘法原理与加法原理选错** | 判断标准：若一件事要**分几步**完成 → 乘法；若一件事**有几种互斥的类型** → 加法。写「或者」时先问是否互斥 |
| 🔧 **用 `n²` 当从 n 个元素中选两个的方案数** | 无序组合是 `C(n,2) = n(n−1)/2`；`n²` 是**有序**选择（即 `P(n,2)`），差别在于是否区分顺序 |
| 🔧 **鸽巢原理写成「至少有 n/m 个」** | 正确下界是 `⌈n/m⌉`（向上取整）；`n = 5, m = 2` 时是 3 而不是 2 |
| **求排列数时把可重复当不可重复** | 多重集排列要除以各重复度的阶乘 `n! / (n₁! n₂! …)`；若元素可重复选，则总数是 `n^r`，不是 `n!/(n−r)!` |
| 🔧 **二项式系数被当成「排列数」用** | `C(n,k)` 不含顺序；需要顺序时是 `P(n,k)`。二者在「选歌单」这类题里常被混用 |
| **组合恒等式只代入数字验证** | 恒等式要给出组合解释（双射）；数字吻合不等于正确 |
| 🔧 **枚举全排列当成可行的实现手段** | `n = 20` 时全排列已有 2.4×10¹⁸ 个；`itertools.permutations` 产出的是**枚举器**，真正先要回答的是「有多少个」，规模一大必须改用递推/生成函数 |
| **排除重复计数的修正原则被漏掉** | 分两类相加时若类别不互斥，必须减去交集（容斥思想，第 8.5 节正式化） |
