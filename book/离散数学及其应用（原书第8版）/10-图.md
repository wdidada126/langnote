# 第 10 章 图

> **一句话**：图把「对象 + 对象之间的联系」抽象成顶点与边；一旦有了它，最短路、连通性、着色、平面图就都成为同一套矩阵与遍历的语言。

## 本章地图

| --- | --- | --- |

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 10.2 / 10.3：图的邻接表与邻接矩阵两种表示，以及握手定理的检查。

class Graph:
    """无向图：邻接表表示，O(V + E) 空间（10.3）。"""
    def __init__(self, vertex_cnt):
        self.V = vertex_cnt
        self.adj = [[] for _ in range(vertex_cnt)]

    def add_edge(self, u, v):
        self.adj[u].append(v)
        self.adj[v].append(u)

    def degrees(self):
        return [len(row) for row in self.adj]

    def is_connected_bfs(self):
        """10.4：连通分量数量用一次 BFS 就能判定。"""
        seen = [False] * self.V
        start = 0
        stack = [start]
        seen[start] = True
        while stack:
            u = stack.pop()
            for w in self.adj[u]:
                if not seen[w]:
                    seen[w] = True
                    stack.append(w)
        return all(seen)

def to_adjacency_matrix(g):
    """10.3：邻接矩阵，O(V^2) 空间，适合稠密图。"""
    M = [[0] * g.V for _ in range(g.V)]
    for u in range(g.V):
        for v in g.adj[u]:
            M[u][v] = 1
    return M

# 握手定理（10.2）：Σ deg(v) = 2|E|
g = Graph(5)
for u, v in [(0, 1), (1, 2), (2, 3), (3, 4), (4, 0), (0, 2)]:
    g.add_edge(u, v)
print(sum(g.degrees()))     # 12 = 2 × 6 条边
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 10.6 Dijkstra：非负权单源最短路；用二叉堆把复杂度降到 O((V + E) log V)。

import heapq

def dijkstra(weights, src):
    """weight[u][v] 为 u→v 的边权（非负）；返回各点到 src 的最短距离。"""
    INF = float("inf")
    dist = {v: INF for v in weights}
    dist[src] = 0
    pq = [(0, src)]
    visited = set()

    while pq:
        d, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        for v, w in weights[u].items():
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

# Bellman–Ford：允许负权，可检测负环（10.6）
def bellman_ford(edges, n, src):
    """edges: [(u, v, w)]，允许负权；若返回 None 则表示存在负权环。"""
    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:
            return dist
    # 第 n 轮仍可松弛 → 存在负权环
    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            return None
    return dist
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 10.8 贪心着色：边上不同色；给出的是上界而非最优（四色定理保证平面图 ≤ 4）。

def greedy_coloring(n, edges):
    """朴素的「按顺序给点染色」算法；最坏情况用 V 种颜色。"""
    result = [-1] * n
    result[0] = 0
    for u in range(1, n):
        used = {result[v] for v in range(n) if (u, v) in edges or (v, u) in edges}
        i = 0
        while i in used:
            i += 1
        result[u] = i
    return result

# 10.7 欧拉公式的可检查形式：|V| − |E| + |R| = 2
def euler_formula_for_planar(vertices, edges, faces):
    """平面图满足 |V| − |E| + |F| = 2（10.7）。"""
    return vertices - edges + faces
```

**三种最短路的适用边界**（10.6 的表格）：

| 算法 | 权 | 复杂度 | 适用 |
| --- | --- | --- | --- |
| BFS（无权图） | 无 | `O(V + E)` | 边权全为 1 |
| Dijkstra | 非负 | `O((V + E) log V)` | 非负权，单源 |
| Bellman–Ford | 任意 | `O(VE)` | 允许负权、检测负环 |
| Floyd–Warshall | 非负 | `O(V³)` | 全源 |

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **路径 / 简单路径 / 迹 的混用** | 「walk」可重复顶点，「trail」不重复边，「path（简单路径）」不重复顶点；中文里常被一并译成「路径」。本书 10.5 的欧拉通路（边不重复）与简单回路（顶点不重复）严格区分，做题时必须分辨 |
| 🔧 **Dijkstra 用在含负权的图上** | Dijkstra 的前提是**所有边非负**；一旦出现负权就应改 Bellman–Ford。含负权环时二者都需额外处理 |
| **欧拉公式只记 `v − e + r = 2`** | 它只对**连通**平面图成立；非连通平面图是 `v − e + r = 1 + c`（c 为连通分量数） |
| 🔧 **把四色定理说成「未证明的猜想」** | 1976 年 Appel–Haken 给出第一个证明，其后 Robertson–Sanders–Seymour–Thomas 给出了可独立复核的证明；四色定理是**定理**，不是猜想。仍然开放的是更细的问题（如图着色的色性、图的上色数与列表着色猜想） |
| 🔧 **哈密顿回路与欧拉回路判据互换** | 欧拉回路看**度数**（奇度顶点 ≤ 2），哈密顿回路看**结构性条件**（Dirac/Ore 等充分条件），二者完全无关；哈密顿回路的存在性判定是 NP 完全 |
| **Kuratowski 定理里的两个图记错** | 不可平面的最小图是 `K_5` 与 `K_{3,3}`；`K_{3,4}` 之类不是判据 |
| 🔧 **同构判定当成多项式时间** | 一般图的同构问题无已知多项式算法；只有**平面树、 planar 图**等受限类有多项式算法 |
| **把「最短路」当成「唯一解」** | 平局（tie）时最优解通常不唯一；工程上必须定义 tie-breaking 才能复现结果 |
| 🔧 **P vs NP 在图论问题上的误用** | 「顶点覆盖是 NP 完全」不等于「求近似解很难」——它有 PTAS 与多种有效启发式；把 NP 完全当成「算不出来」是本章最常见的读者误解 |
