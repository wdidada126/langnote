# 《离散数学及其应用（原书第8版）》总览与阅读地图

> **一句话**：离散数学是计算机科学的语法——本书用「命题 ⟶ 证明 ⟶ 计数 ⟶ 关系 ⟶ 图与树 ⟶ 布尔代数 ⟶ 可计算性」这条主线，把 13 章内容组织成一套可以直接写进代码、也能写进论文的形式化语言。

> **大纲版在此**：`book/离散数学及其应用（原书第7版）.md`（只有短摘 + 中译本目录 + ISBN 线索）。**本目录是深度重写版**，与大纲版并存、互链，大纲版不作修改。
>
> 目录：`00-总览与阅读地图.md`（本文件）、`01` … `13` 共 13 个章节文件。

- **最小主线（1 个学期）**：1 → 2 → 5 → 6 → 9 → 10 → 11 → 12 → 13（证明、计数、关系、图、树、布尔、可计算性）。

- ** proofs 训练**：1.7 / 1.8 必须精读——这是全书其余 12 章的语言基础。

## 3. 本书没覆盖的缺口（2026 视角）

| 缺口 | 说明 | 建议补到哪里 |
| --- | --- | --- |
| **机器学习所需的概率与优化** | 第 7 章是**离散概率**（有限样本空间、组合概率），没有连续分布、没有凸优化、没有梯度/拉格朗日对偶。想做深度学习、强化学习、贝叶斯推断需另外补概率论与最优化 | 另选一本概率论/最优化教材；`book/深度学习_花书.md` 一类的读书笔记可作入口 |
| **现代密码学的后量子部分** | 第 4.6 节是经典 RSA / 对称加密 / 数字签名框架，不含格密码、LWE、NIST PQC 标准 | 见 `04-数论和密码学.md` 的「版本演进」小节与 NIST FIPS 203/204/205 |
| **P vs NP 与 NP 完全** | 第 8 版第 13 章止于图灵机 | 见 `13-计算模型.md` 的外扩小节 |
| **格的辩护与偏序代数** | 第 12 章只有 4 节（布尔函数、表示、逻辑门、极小化），**不含偏序集的格、分配格、互补、布尔代数的表示定理**；这部分在本书第 9.6 节偏序里只有铺垫 | 见 `12-布尔代数.md` 的外扩小节 |
| **AVL / B 树 / B+ 树 / 并查集的完整证明** | 第 11 章只讲树、遍历、生成树、最小生成树与树的应用（含 BST 与前缀码/Huffman），平衡树与并查集是工程 folklore | 见 `11-树.md` 的外扩小节；与 `book/数据结构.md`、`book/数据结构与算法分析java语言描述.md` 互补 |
| **自动机完整理论** | 第 13 章只涉及有限状态机与文法入门，不含泵引理的严格证明体系、正规式的 Myhill–Nerode 刻画、CFG 的歧义判定与 parser 构造 | 与 `book/自动机理论、语言和计算导论.md` 对照 |

## 6. 写作约定

每个章节文件固定八段结构：

1. `# 第 N 章 标题` + `> **一句话**：`
2. `## 本章地图`——表格：节 | 内容 | 结论
3. `## 核心精讲`——含 ```python / ```cpp 教学示意代码，统一注明「**教学示意，不参与构建**」；**不编译、不运行**
4. `## 版本演进`——第 6→7→8 版差异，以及 2020 年代在 AI / 密码学中的新发展
5. `## 经典论文与原始文献`——表格：论文 | 出处 | 贡献（只列可查证的真实文献）
6. `## 近年研究与工业界开源实践（2015–2026）`——趋势 + 表格：仓库 | star | 说明（star 为 `gh api` 实测）
7. `## 常见误区与本书需修正之处`——表格 ≥ 5 行，若干行以 🔧 开头
8. `## 与其他章 / 其他书的联系`
