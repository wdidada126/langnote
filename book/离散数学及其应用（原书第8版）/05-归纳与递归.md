# 第 5 章 归纳与递归

> **一句话**：数学归纳法把「无穷多个命题」压成两步，递归定义把「无穷多个对象」压成基例与两步——前者是证明的工具，后者是定义与实现的工具，两者同构。

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 5.1 数学归纳法 | 归纳法原理、基础步与归纳步、`n ≥ 0` 与 `n ≥ 1` 的差别、 sums、不等式的归纳证明 | 两步缺一不可；归纳假设必须是对**某个任意** k 成立，不是对特定值 |
| 5.2 强归纳法与良序性 | 强归纳（归纳假设含所有更小的 k）、良序原理、用良序性证明归纳法、「最小反例」法 | 数学归纳法与强归纳法在逻辑上等价；最小反例法是其变形 |
| 5.3 递归定义与结构归纳法 | 递归定义集合、结构与递归定义函数、结构归纳法、递归定义的子集均值、斐波那契、帕斯卡三角 | 结构归纳对「由构造得来的对象」（树、公式、表）同样有效，且比数学归纳更自然 |
| 5.4 递归算法 | 递归算法举例、递归与迭代的对照、分治、汉诺塔、斐波那契（记忆化）、归并排序 | 递归带来清晰性，代价是调用栈与重复子问题；记忆化把它变成多项式 |
| 5.5 程序正确性 | 循环不变式、终止性证明、部分正确性与完全正确性、`{pre} S {post}` | 循环不变式 + 终止性 = 完全正确性；这是归纳法在程序里的化身 |

## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 5.4 递归骨架：斐波那契的朴素递归 O(φ^n) 与记忆化 O(n)；汉诺塔的递归描述。

from functools import lru_cache

def fib_naive(n):
    """朴素递归：T(n) = T(n−1) + T(n−2) + O(1)，复杂度 O(φ^n)。"""
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fib_naive(n - 1) + fib_naive(n - 2)

def fib_memo(n, cache=None):
    """记忆化（自顶向下）：把重复子问题缓存，复杂度降到 O(n)。"""
    if cache is None:
        cache = {0: 0, 1: 1}
    if n not in cache:
        cache[n] = fib_memo(n - 1, cache) + fib_memo(n - 2, cache)
    return cache[n]

def fib_iter(n):
    """迭代（自底向上）：空间 O(1)，是第 5.1 节归纳构造的直接翻译。"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def hanoi(n, src, dst, aux):
    """汉诺塔：T(n) = 2T(n−1) + O(1)，解得 T(n) = 2^n − 1。"""
    if n == 1:
        return [(src, dst)]
    return hanoi(n - 1, src, aux, dst) + hanoi(1, aux, dst, src) + hanoi(n - 1, aux, dst, src)
```

**递归关系与解的对照表**（5.1 与 5.4 都会用到）：

| 递归式 | 解 | 典型来源 |
| --- | --- | --- |
| `T(n) = T(n−1) + c` | `T(n) = Θ(n)` | 线性扫描、求最大元 |
| `T(n) = T(n/2) + c` | `T(n) = Θ(log n)` | 二分查找 |
| `T(n) = 2T(n/2) + c` | `T(n) = Θ(n log n)` | 归并排序 |
| `T(n) = T(n−1) + O(1)`（斐波那契式） | `T(n) = Θ(φ^n)` | 朴素递归斐波那契 |
| `T(n) = 2T(n−1) + O(1)` | `T(n) = Θ(2^n)` | 汉诺塔 |

```python
# 教学示意，不参与构建（不编译、不运行）
# 5.3 结构归纳：对树做归纳，比「对整数 n 做归纳」更贴近结构本身。
# 这里演示一个通用的结构归纳证明框架（不是可运行的证明系统）。

class Node:
    """二叉树的构造子：叶 → 内部节点。"""
    def __init__(self, label, left=None, right=None):
        self.label, self.left, self.right = label, left, right

def size(t):
    """结构归纳：基例（叶 size = 1，label = 1），归纳步（size(node) = 1 + size(left) + size(right)）。"""
    if t.left is None and t.right is None:
        return 1, t.label            # 基例
    l_sz, l_sum = size(t.left) if t.left else (0, 0)
    r_sz, r_sum = size(t.right) if t.right else (0, 0)
    return 1 + l_sz + r_sz, t.label + l_sum + r_sum   # 归纳步

def structural_induction(base_cases, inductive_steps, objects):
    """把结构归纳拆成「基例」与「归纳步」两步的可检查写法（教学示意）。"""
    checked = set()
    for o in objects:
        if base_cases(o):
            checked.add(o)                     # 基例直接成立
        elif any(inductive_steps(i, o) for i in checked):
            checked.add(o)                     # 由已检查对象归纳得到
        else:
            return False                       # 既不是基例，也没被归纳覆盖
    return True
```

**循环不变式（5.5）的三段式**：初始化 establishing（循环第一次迭代前）→ 保持 preservation（每次迭代后仍成立）→ 终止 termination（循环退出时推出结论）。这与数学归纳的三行结构一一对应，`while` 循环的条件就是归纳假设。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **归纳步里假设「对任意 n 成立」** | 归纳假设只能是「对某个**任意给定的** k ≥ 1 成立」；若假设「对所有 n 成立」，就是在用待证结论 |
| 🔧 **基础步写「n = 1 成立」就跳到「n = k」** | 必须显式写出基础步的取值与证明；只写「易见 n = 1 时成立」而没验证，等于缺了一个基例 |
| **强归纳与数学归纳等价却被当成两种理论** | 二者在逻辑上可相互导出；用强归纳时要把「对某个选定的 k 成立」说清 |
| 🔧 **结构归纳的基例集合不完整** | 对递归定义的集合做结构归纳时，基例必须包含递归定义里的**所有**基例对象；漏一个基例，归纳链可能有洞 |
| **分治递推的解被记错** | `T(n) = 2T(n/2) + n` 是 `O(n log n)`，而 `T(n) = T(n/2) + n` 是 `O(n)`；分治递推必须由主定理或递归树推导，不能猜 |
| 🔧 **递归算法里的重复子问题被忽略** | 朴素斐波那契是 `O(φ^n)` 而非 `O(n)`；「递归 = 慢」的直觉只有在不加记忆化时成立 |
| 🔧 **循环不变式跳过终止性证明** | 5.5 要求「不变式 + 终止」才构成完全正确性；只看每次迭代后不变式成立，不能保证循环会结束 |
| **把归纳证明的「归纳步」写反方向** | 必须从 k 推 k+1；若写成「假设 k+1 成立推 k」，那是循环论证 |
