## 核心精讲

```python
# 教学示意，不参与构建（不编译、不运行）
# 2.1 集合 / 2.2 集合运算：用 Python 的 frozenset 直接对照定义。

from itertools import combinations, chain

def powerset(a):
    """2.1 幂集：返回 A 的所有子集（含空集与 A 自身）。|P(A)| = 2^|A|。"""
    a = list(a)
    return [set(c) for k in range(len(a) + 1) for c in combinations(a, k)]

def cartesian(a, b):
    """2.1 笛卡儿积 A × B。"""
    return [(x, y) for x in a for y in b]

def symmetric_difference(a, b):
    """2.2 对称差 (A − B) ∪ (B − A)。"""
    return a ^ b

def membership_table_check(universal, left_sets, right_sets):
    """2.2 集合恒等式的「元素法」验证：对每个元素 e，检查 e 是否同属于左右两侧。

    若对 universal 中每个 e 都有 (e 在左 当且仅当 e 在右)，则两侧集合相等。
    """
    def belongs(sets, e):
        return any(e in s for s in sets)
    return all(belongs(left_sets, e) == belongs(right_sets, e) for e in universal)

# 示例：验证 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A, B, C = {1, 2, 3, 4}, {3, 4, 5}, {4, 5, 6}
left = [A & (B | C)]
right = [(A & B), (A & C)]
U = sorted(A | B | C)
print(membership_table_check(U, left, right))
```

```python
# 教学示意，不参与构建（不编译、不运行）
# 2.3 函数：单射 / 满射 / 双射的直接判定，以及复合与求逆。

def is_injective(f, domain):
    """单射：f(x) = f(y) 蕴含 x = y。"""
    seen = {}
    for x in domain:
        y = f(x)
        if y in seen and seen[y] != x:
            return False
        seen[y] = x
    return True

def is_surjective(f, domain, codomain):
    """满射：陪域每个元素都有原像。"""
    image = {f(x) for x in domain}
    return codomain <= image

def is_bijective(f, domain, codomain):
    """双射：既是单射又是满射；此时反函数存在。"""
    return is_injective(f, domain) and is_surjective(f, domain, codomain)

def compose(g, f, domain):
    """复合 (g ∘ f)(x) = g(f(x))。注意「从右往左读」。"""
    return {x: g(f(x)) for x in domain}
```

2.3 节里最容易出错的是**复合的读法**：`(g ∘ f)(x)` 表示先 `f` 后 `g`。写成 `f(g(x))` 时，若 `f` 的定义域装不下 `g` 的值域，就会出错。

```python
# 教学示意，不参与构建（不编译、不运行）
# 2.4 序列与求和 / 2.6 矩阵：用递推定义生成序列，并做布尔矩阵乘法。

def geometric(a0, ratio, n):
    """几何序列 a0, a0·r, a0·r^2, …  （2.4）"""
    seq, cur = [], a0
    for _ in range(n):
        seq.append(cur)
        cur *= ratio
    return seq

def harmonic(n):
    """调和序列前 n 项；其和发散到 +∞（算法分析里最常用的一面）。"""
    return [sum(1.0 / k for k in range(1, i + 1)) for i in range(1, n + 1)]

def mat_mul(X, Y, mul=lambda a, b: a * b, plus=lambda a, b: a + b):
    """2.6 矩阵乘法 Z = X·Y，其中 Z[i][j] = Σ_k X[i][k]·Y[k][j]。

    把 (mul, plus) 换成 (and, or) 即得布尔矩阵乘法。
    """
    n, p, m = len(X), len(X[0]), len(Y[0])
    Z = [[plus(mul(X[i][k], Y[k][j]), 0) for j in range(m)] for i in range(n)]
    for i in range(n):
        for j in range(m):
            acc = mul(X[i][0], Y[0][j]) if m else 0
            for k in range(1, m):
                acc = plus(acc, mul(X[i][k], Y[k][j]))
            Z[i][j] = acc
    return Z

def bool_path_exists(adjacency, k):
    """邻接矩阵（布尔）自乘 k 次，得到「k 步可达」矩阵。"""
    n = len(adjacency)
    M = [[bool(adjacency[i][j]) for j in range(n)] for i in range(n)]
    for _ in range(k - 1):
        M = [[any(M[i][t] and M[t][j] for t in range(n)) for j in range(n)]
             for i in range(n)]
    return M
```

- **康托尔对角线法（2.5）**：假设 `ℝ` 中 `[0,1)` 区间中的实数可与 `ℕ` 一一列出 `r_1, r_2, …`，把它们的十进制展开按位排成矩阵，再沿对角线取一位、把第 k 位与第 k 位加一得到的新小数，必然与每个 `r_k` 在第 k 位不同，从而不在表中——矛盾。这一步「逐位构造一个不在列表中的对象」是全书反复出现的手法（第 4 章的 Cantor 集合、第 13 章的对角线论证同源）。
- **2.5 的常见陷阱**：`|A| ≤ |B|` 需要**单射**的存在性，而不是「A 的元素更少」的直觉；有限集上二者等价，但无穷集上完全可分。

## 常见误区与本书需修正之处

| 误区 / 需修正 | 说明 |
| --- | --- |
| 🔧 **把笛卡儿积的元素写成 `x, y` 而不是 `(x, y)`** | `A × B` 的元素是**有序对**；写成无括号形式会与「两个集合的交」混淆，也会让 `A × B ≠ B × A` 这条性质失效 |
| 🔧 **混淆 `∈` 与 `⊆`** | `∈` 是元素与集合的关系，`⊆` 是集合与集合的关系；幂集的求法里 `P(A)` 的元素是**集合**，`|P(A)| = 2^|A|` 在这里必须用集合计数 |
| 🔧 **复合函数的顺序写反** | `(g ∘ f)(x) = g(f(x))` 容易被误读成「先 g 后 f」；下标与括号必须一一对应 |
| **「A 比 B 少」不等于 `|A| < |B|`** | 没有单射时基数的大小无法直接比较；本节只在**有限集**上才允许把「元素更少」与「存在单射」混用 |
| 🔧 **调和级数求和当成有界** | `Σ 1/k` 发散；把 `1 + 1/2 + 1/3 + …` 当成 O(1) 或 O(log n) 的下界误用是算法分析里常见错误（它只有 O(log n) 的**上界**） |
| **布尔矩阵乘法当成普通算术** | `(A²)_ij = ∨_k (A_ik ∧ A_kj)`，与算术乘法不同；第 10.4 节的可达性要用布尔算术，不能用数值 |
| 🔧 **集合恒等式只用两个例子验证** | 2.2 的「元素法」要求对**任意元素**验证；取 2–3 个具体集合只能说明不相等，不能证明相等 |
| **对角线法被当成「列表法」** | 康托尔对角线不是「构造一个反例列表」，而是「用列表自身构造一个不在列表中的元素」 |
