## 三条阅读主线

1. **「少写样板」线（语言侧）**：`01` → `02` → `03` → `04` → `05` → `06`。
   C++17 的语言改动几乎全是「把已有的手写模式标准化」：解包（01）、收窄作用域（02）、去掉 ODR 补丁（03）、
   lambda 补齐（04）、省掉重复实参（05）、模板分发瘦身（06）。读完这条线，你就能把 C++11/14 的老代码
   改写成今天的默认写法。
2. **「值语义的错误与多态」线（库侧）**：`07` → `08` → `09` → `12`。
   optional（可能没有值）、variant（值在若干类型之一）、any（值在任意可拷贝类型）、string_view（值是一段别人的内存）
   是同一套「用类型表达存在性/种类/所有权」的思想在四个方向上的展开；`12` 的错误处理小件（`to_chars` 的 `errc`、
   `filesystem` 的 error_code 重载）是同一风格的延续。
3. **「把系统能力搬进标准库」线**：`10` → `11` → `12`。
   filesystem（跨平台路径与目录遍历）、并行算法（执行策略）、内存资源（PMR）与超对齐 new，
   都是原先靠 Boost/POSIX/厂商库解决的东西，C++17 第一次给出标准形状——也第一次暴露「标准只管接口、
   实现质量差很多」的问题（本目录用实测把它讲透，见 `10`/`11`）。

**最短实用路径**：`01` → `02` → `07` → `09` → `12`（约 4 小时），这四章覆盖日常代码 90% 的 C++17 收益。
**做库/写框架**再加 `05`、`06`、`08`。**做系统工具/跨平台**必读 `10`、`11`。

## 本书定位与「2026 年折扣率」

- **定位**：**特性级权威导览**。Josuttis 的写法是「一个特性一章：动机 → 最小可运行示例 → API 全表 → 陷阱」，
  适合已经有 C++11/14 基础的人**按特性查**，不适合当作第一本 C++ 书。它与作者自己的
  《C++ 标准库》（仓库有目录版 [../C++标准库/00-总览与阅读地图.md](../C++标准库/00-总览与阅读地图.md)）互补：
  后者讲「库怎么用」，本书讲「新版本改了什么」。
- **必须复核的结论（本书成书于 C++17 定稿期，2016–2022）**：
  1. **标准现状**：ISO/IEC 14882:2024（C++20 + 缺陷修复）已生效，C++23 已发布，**C++26 于 2026 年 3 月会议定稿**
     （⚠️ 依据 Herb Sutter 的会议报告 *C++26 is done!*, 2026-03-29；正式文本发布待确认）。
     本书每个特性都要问「后续标准是否补齐/改了口径」，答案统一放各章 `## 最新演进与工业实践`。
  2. **实现可用性**：书中「GCC 7/8 部分支持、MSVC 19.14」这类支持矩阵**已全部过时**。
     本目录用 **MinGW g++ 15.2（win32/x86_64/seh）** 重新实测，并给出「哪个 `-std=` 档位才生效」的实测表。
  3. **个别例子的现代改写**：例如书里 `Overloaded{f1, f2}` 式的访问器惯用法在 C++17 **无法不带额外推导指引而编译**
     （聚合 CTAD 缺失），本目录实测复现了这一点并给出两种写法（见 `05`/`08`）。
- **该读原书的地方**：`std::filesystem` 的完整 API 表、`<charconv>` 的格式细节、以及作者对每个特性的
  「何时该用/不该用」的议论。本目录不做逐字替代。

## 读完应该能回答的十个问题

1. 结构化绑定为什么不能用在含私有成员的类型上？它产生的是变量还是一个「名字别名」？（`01`）
2. `if (auto it = m.find(k); it != m.end())` 相比老写法除了省作用域还买到什么？（`02`）
3. `inline` 变量、聚合扩展、强制拷贝消除分别在消除哪种「样板或低效」？（`03`）
4. `[=]` 隐式捕获 `this` 为什么在 C++17 是坑、在 C++20 被弃用？`[*this]` 何时用？（`04`）
5. CTAD 为什么不能对聚合生效（C++17），`Overloaded` 惯用法要怎么补救？（`05`）
6. `if constexpr` 丢弃分支里可以放什么、不可以放什么？折叠表达式空包返回什么？（`06`）
7. `optional<T>` 与 `T*`、`expected<T,E>` 的语义边界在哪？`value()` 与 `operator*` 差在哪一步？（`07`）
8. `variant` 的 `visit` 如何分发、`any` 为什么装不下 `unique_ptr`、`byte` 为什么不能当数字用？（`08`）
9. `string_view` 什么时候必然悬垂？为什么编译器抓不到？（`09`）
10. `filesystem` 的路径在 Windows 上的编码/分隔符怎么处理？并行算法为什么可能一行都不并行？（`10`、`11`）
