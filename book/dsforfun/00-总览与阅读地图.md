**三处需要诚实说明的核实结果：**

1. **`mixu/distsys` 这个仓库不存在**。`gh api repos/mixu/distsys` 返回 404（Not Found）。
   本书的真实仓库是 **`mixu/distsysbook`**，实测 star = **2676**（2026-09）。
   本目录后续所有引用一律写 `mixu/distsysbook`。
2. **第 4、5 章的主题顺序与常见二手描述相反**。官方站原文写得很清楚：
   - **Ch4 = "Replication: preventing divergence"**（防止分歧 → 单副本/强一致，2PC 到 Paxos）；
   - **Ch5 = "Replication: accepting divergence"**（接受分歧 → 弱一致/最终一致，Dynamo、CRDT、CALM）。
   本目录按官方顺序编排，不采用「4 弱一致 / 5 强一致」的说法。
3. **官方站没有名为「A note on distributed systems」的附录**。
   官方目录页列出的附录是 **"Appendix: recommendations for further reading"**，
   章节页自身标题为 **"6. Further reading and appendix"**，内容是书单 + 开创性论文 + 系统论文清单。
   分布式领域确有同名名篇，但那是 **Waldo、Wyant、Wollrath、Kendall《A Note on Distributed Computing》
   （Sun Microsystems 技术报告 TR-94-29，1994）**，与本书无关，本目录只在第 06 篇作为对照文献提及，
   **不把它写成本书附录**。

## 阅读顺序建议

- **主线 A（按书读）**：01 → 02 → 03 → 04 → 05 → 06。
  作者的顺序就是「先立目标（1）、再拆模型与不可能（2）、补时间这根暗线（3）、
  再讲两条复制路线（4 强 / 5 弱）、最后给书单（6）」。
- **主线 B（按问题读）**：
  - 「CAP 到底在说什么」：02 → 04（CA 类：2PC）→ 05（AP 类：Dynamo）；
  - 「时钟和顺序怎么用」：03 → 05（向量时钟/CRDT）；
  - 「共识怎么落地」：02（共识定义与 FLP）→ 04（Paxos/Raft/ZAB）→ 仓库 Raft 专篇；
  - 「选型怎么答」：01（目标与代价）→ 04/05（两条路线）→ 06（替代读物）。
- **对照读**：本书每章末尾都列了 Further reading，那些就是作者自己给的延伸清单，
  本目录第 06 篇把它整理成「2013 年书单 → 2026 年该怎么替换」。

## 常见疑问 FAQ

- **问：这本书 2013 年写的，还值得读吗？**
  - 值得，但要带补丁读。它的**解释力**（把设计空间讲清楚）至今少见，
    但它的**事实面**（Raft 状态、CRDT 成熟度、NewSQL 实践）已过时，补丁写在各章第六、七段。
- **问：为什么第 4、5 章和很多中文笔记说的顺序不一样？**
  - 官方站就是「4 防止分歧（强一致）/ 5 接受分歧（弱一致）」；
    二手笔记常把顺序写反或合并成「复制」一章。本目录以官方站为准（见上文核实说明第 2 条）。
- **问：本书讲 Raft 吗？**
  - 讲，而且第 4 章用了相当篇幅（roles / epochs / duels / numbered proposals 都是 Raft 词汇），
    但写于 Raft 论文正式发表前后，未覆盖 Raft 之后的工程化事实（etcd、Multi-Raft、KRaft 等）。
    见 [04-复制-防止分歧与强一致.md](04-复制-防止分歧与强一致.md) 的版本演进段。
- **问：star 数为什么写 `mixu/distsysbook`？**
  - 因为 `mixu/distsys` 经 `gh api` 实测返回 404；真实仓库名是 `mixu/distsysbook`（star 2676）。
    所有 star 均为 2026-09 `gh api` 实测，查不到的一律写「star 未核验」。
- **问：要不要跑书里的代码？**
  - 本书正文基本是概念与伪代码，本目录所有代码均为**教学示意、不参与构建**，不运行任何程序。
