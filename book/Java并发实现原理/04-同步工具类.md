# 第 4 章 同步工具类（原书 pp.83-103）

> 手写 `CountDownLatch`/`CyclicBarrier`/`Semaphore`/`Exchanger`，逐个用 AQS 或锁+条件实现。与《艺术》8 章 + 《之美》10-线程同步器.md 互补——本书是"自己写一遍"，另两本是"读 JDK 源码"；本书对 CountDownLatch 与 CyclicBarrier 实现差异的澄清与《之美》一致。

## 一、本章地图

| 工具 | 手写实现 |
| --- | --- |
| `CountDownLatch` | AQS 共享：`state`=倒数，`countDown`→`releaseShared`，`await`→`acquireShared` 等 0 |
| `CyclicBarrier` | `ReentrantLock` + `Condition` + `generation`；N 个到齐放行，可循环 |
| `Semaphore` | AQS 共享：`state`=剩余许可，`acquire`→`releaseShared` 减，`release`→加 |
| `Exchanger` | 锁 + 单槽（slot），两线程汇合交换 |

## 二、核心精讲

### 2.1 手写 `CountDownLatch`
- `state` = 初始倒数；`countDown()` 调 `releaseShared(1)`（`state` CAS 减 1）。
- `await()` 调 `acquireSharedInterruptibly(1)`：当 `state!=0` 入 AQS 队列 park；`state` 归 0 时 `tryReleaseShared` 返回 true → 唤醒所有等待者（共享传播）。
- **一次性**：`state` 到 0 不再回；要循环用 `CyclicBarrier`。

### 2.2 手写 `CyclicBarrier`
- `ReentrantLock` + 一个 `Condition` + `count`/`parties`/`generation`。
- 每线程 `await()`：`lock` → `count--`；若 `count==0`：重置 `generation`、唤醒所有 `signalAll`、放行；否则 `condition.await()`。
- 可循环：一轮结束自动进入下一代；`reset()` 打破（抛 `BrokenBarrierException`）。
- **与 CountDownLatch 核心区别**（本书易混点，与《之美》10 章一致）：Latch 是"等 N 个事件"（事件与线程解耦，AQS 共享）；Barrier 是"N 个线程互相等齐"（锁+条件，线程对称）。

### 2.3 手写 `Semaphore`
- `state` = 剩余许可；`acquire()`：`tryAcquireShared` 看 `state>=0` 则 CAS 减，否则 park；`release()`：`state` CAS 加并唤醒。
- 公平/非公平：公平版 `tryAcquire` 先查队列前驱。
- **只限并发数**，不保证共享资源线程安全（被准入线程仍需自己加锁）。

### 2.4 手写 `Exchanger`
- 单槽 `slot` + 锁；线程 A 放数据进 slot 并等；线程 B 来取出并放自己的，双方各自返回对方数据。
- 仅成对（两线程）；多于两线程随机配对非预期。

## 三、版本演进

- **JDK 5**：四者随 J.U.C 引入（Lea AQS 论文）。
- **JDK 7**：`Phaser` 补充（更灵活的分代屏障，见《之美》10 章）。
- **JDK 21+**：`StructuredTaskScope` 提供作用域级"等所有完成/取首成"，替代手写 Latch/Barrier 编排。

## 六、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Latch 可重置" | 一次性；循环用 Barrier/Phaser |
| 2 | "Latch == Barrier" | 实现/语义不同（AQS 共享 vs 锁+条件），见《之美》10 章 |
| 3 | "Semaphore 保线程安全" | 只限并发数；共享资源仍需锁 |
| 4 | "Exchanger 多线程" | 仅成对 |
| 5 | "忘 countDown 只是慢" | 永久阻塞；try/finally 或虚拟线程作用域 |
| 6 | "新代码手写 Latch 编排" | 虚拟线程 + StructuredTaskScope 不易漏 |
