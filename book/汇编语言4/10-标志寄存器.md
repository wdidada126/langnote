# 第 11 章 标志寄存器

> **一句话**：标志寄存器让汇编第一次有了「条件」——`ZF/PF/SF/CF/OF` 分别回答「结果为零 / 低 8 位中 1 的个数为偶 / 结果为负 / 有借进位 / 有溢出」，而 `adc/sbb/cmp` 三条指令则把标志位从「观测结果」变成「 computation 的输入」。

---

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 11.1 ZF（零标志） | 本次结果是否为 0 | `mov` 不影响标志；`add/and/inc` 影响 `inc` 例外（结果为 0 时 ZF=1，但不破坏进位） |
| 11.2 PF（奇偶标志） | 结果低 8 位中 1 的个数是否为偶数 | 只看低 8 位；只用于偶数校验，不用于算术 |
| 11.3 SF（符号标志） | 结果是否为负（最高位是 1） | 只看结果，不看操作数 |
| 11.4 CF（进位/借位标志） | 有无进位/借位 | 无符号溢出的唯一依据 |
| 11.5 OF（溢出标志） | 有符号溢出 | 有符号溢出的唯一依据 |
| 11.6 `adc` 指令 | 带进位加法 | `ADC dst,src = dst = dst + src + CF`（**多倍精度加法**） |
| 11.7 `sbb` 指令 | 带借位减法 | `SBB dst,src = dst = dst - src - CF` |
| 11.8 `cmp` 指令 | 只比较不改写 | `cmp a,b` ≡ `sub a,b` 但不回写，用于后续条件转移 |
| 11.9 检测比较结果的条件转移 | `je/jne/jg/jl/ja/jb` 等 | 无符号用 `ja/jb`，有符号用 `jg/jl`，**混用是经典错误** |
| 11.10 DF 标志与串传送 | `cld/std` + `movsb/stosb` | DF=0 递增，DF=1 递减 |
| 11.11 `pushf` / `popf` | 保存/恢复标志 | 为「中断时保护现场」服务 |
| 11.12 标志寄存器在 Debug 中的表示 | Debug 的 NV/UP/EI/PL 位图 | 认识调试器里那串字母 |

## 核心精讲

### 1) 标志位全景（11.1–11.5）

```asm
; 教学示意，不参与构建
; 15…12 OF DF IF TF SF ZF AF PF CF
; 11…8  IF=1 允许可屏蔽中断；TF=1 单步；DF=0 串操作递增
; 7…4   SF ZF AF PF CF
; 3…0   CF PF AF ZF SF TF IF DF OF
```

| 标志 | 置位条件 | 典型用途 |
| --- | --- | --- |
| **ZF** | 结果为 0 | `je/jne`；字符串比较的终止条件 |
| **PF** | 结果低 8 位中 1 的个数为偶数 | 奇偶校验（如 UART） |
| **SF** | 结果最高位为 1（即「负」） | `js/jns` |
| **CF** | 结果超出目标位数（无符号） | `jc/jnc`；配合 `adc/sbb` 做多倍精度 |
| **OF** | 有符号溢出（如 127+1） | `jo/jno` |
| **DF** | `cld`(DF=0) / `std`(DF=1) | 串操作方向 |
| **IF** | `sti`(IF=1) / `cli`(IF=0) | 是否响应可屏蔽中断（Ch14/15） |
| **TF** | Debug 单步用 | 每执行一条产生 1 号中断 |

### 2) 哪些指令影响标志（关键表格）

| 指令类别 | 影响标志 |
| --- | --- |
| `mov`、`xchg`、`push`、`pop` | **不影响** |
| `add/adc/sub/sbb/cmp` | 全部影响（CF、OF、SF、ZF、AF、PF） |
| `and/or/xor/test` | 影响 ZF/SF/PF/OF=0，但 **CF=OF=0** |
| `mul/div`、`shl/shr` | 影响 CF/OF（与结果位数相关），SF/ZF 不定 |
| `inc/dec` | 影响 ZF/SF/OF/AF/PF，但 **不影响 CF** ← 经典坑 |

### 3) `adc` / `sbb`：多倍精度运算（11.6 / 11.7）

```asm
; 教学示意，不参与构建
; 32 位加法（8086 只有 16 位寄存器）：把两个 32 位数拆成高低 16 位
;  (DX:AX) = (DX:AX) + (CX:BX)
    mov ax, [si]        ; 被加数低 16 位
    mov dx, [si+2]      ; 被加数高 16 位
    add ax, bx          ; 低 16 位相加 → 若产生进位，CF=1
    adc dx, cx          ; 高 16 位带进位相加  ← 本章的核心技巧

; 减法
    sub ax, bx
    sbb dx, cx          ; 高 16 位带借位相减
```

> 这一技巧的适用范围远超 8086：**现代 CPU 上的 128/256 位大整数加法（如 RSA、 curvE 点乘）仍然用 `adc` 串起来。**

### 4) `cmp` 与条件转移（11.8 / 11.9）

```asm
; 教学示意，不参与构建
    mov ax, 5
    mov bx, 10
    cmp ax, bx          ; 只做 sub，不回写 → 标志位体现 (ax-bx)
    je  equal           ; ZF=1
    jbe less            ; 无符号：CF=1（5 < 10）← 用 jb/jbe
    ; 有符号判断要用 jl/jle（看 SF/OF），不要用 jb/ja
equal:
    mov ax, 4c00h
    int 21h
```

**条件转移速查**

| 条件 | 无符号（A < B 语义） | 有符号 |
| --- | --- | --- |
| 相等 | `je` (ZF=1) | `je` |
| 不等 | `jne` | `jne` |
| 小于 | `jb` (CF=1) | `jl` (SF≠OF) |
| 小于等于 | `jbe` | `jle` (ZF=1 或 SF≠OF) |
| 大于 | `ja` (CF=0 且 ZF=0) | `jg` (SF=OF 且 ZF=0) |
| 大于等于 | `jae` | `jge` |

### 5) 串传送与 `DF`（11.10）

```asm
; 教学示意，不参与构建
    cld                 ; DF = 0，串操作地址递增
    mov cx, 100
    rep movsb           ; 重复 100 次：ds:si → es:di，SI/DI 各 +1
    ; rep 依赖 CX 计数与 ZF/SF 的语义（rep 用 CX，不为 0 就重复）
```

> `movsb` 默认 `DS:SI` → `ES:DI`；`stosb` 存到 `ES:DI`。本书第 13、17 章读扇区与打印字符串时频繁用到。

## 版本演进

| 年份 | 事件 | 关联 |
| --- | --- | --- |
| 1978 | 8086 的标志寄存器与 `adc/sbb/jg/ja` | 本章主角 |
| 1985 | 80386：`ecx` 作串计数，32 位标志 | `rep movsd` 等扩展 |
| 1993 | Pentium：`cmovcc`（条件传送）加入 | 免去分支预测的代价 |
| 1996 | MMX 借用**同一批**标志位（FPU 状态） | 标志的「借用」传统延续 |
| 2003 | x86-64：`rflags`，`cmov` 全套 | 条件传送成为向量化/分支消解的基础 |
| 2013+ | AVX-512 的掩码寄存器提供「无分支」的另一条路 | 标志仍是主流控制手段 |
| 2026 | 常量时间代码要求「避免分支」，标志相关指令被重新审视 | 侧信道防护里 `cmov` 与掩码操作成为标准手段 |

> `adc/sbb` 这条思路在 40 年后的今天依然健壮，这几乎是 x86 CISC 里最成功的一个遗产。

## 常见误区与本书需修正之处

| # | 误区 / 待修正 | 说明 |
| --- | --- | --- |
| 1 | 🔧 「`inc ax` 之后标志位不变吗？」 | 恰恰相反：`inc` 影响 ZF/SF/OF/PF，**唯独不影响 CF**。做「加 1 是否进位」的判断时不能用 `inc`。 |
| 2 | 🔧 「`mov` 会改 ZF」 | 不会。`mov/push/pop/xchg` 都不影响任何标志位。「mov 之后 je 失效」通常是标志被中间指令覆盖了，不是 mov 的问题。 |
| 3 | 🔧 「`and ax, ax` 用来清零 ax 并影响标志」 | 可以，但语义上它是「测试 ax」；常见写法 `test ax,ax` 更清晰。注意 `and` 会**清掉 CF 与 OF**，这可能不是你想要的。 |
| 4 | 🔧 「有符号比较用 `ja/jb`，结果总对」 | 会错。`ja/jb` 看 CF（无符号），有符号溢出时判断会翻转。**用 `jg/jl/jge/jle`**。这是本书 11.9 的重点，也是面试常考题。 |
| 5 | 🔧 「`cmp` 之后无需恢复」 | `cmp` 不改变操作数，但会改变标志。若你在 `cmp` 与 `je` 之间插入了任何算术指令，标志就被覆盖了。 |
| 6 | 🔧 「`adc dx, cx` 是 16 位加法」 | 它是**带进位加法**：`dx = dx + cx + CF`，正是为了解决 16 位寄存器做 32 位加法的问题。缺了它就得手工判进位。 |
| 7 | 🔧 「PF 用来判断结果是否为偶数」 | PF 判断的是**低 8 位中 1 的个数**是否为偶数，与数值奇偶无关（数值奇偶看最低位）。名称上的「奇偶」指的是 1 的个数。 |
| 8 | 🔧 「本书的标志模型 = 现代 x86 的标志模型」 | 现代 x86 有 `rflags`，且 TF/IF 的语义在虚拟化与 CET 场景下更复杂。但 **ZF/CF/SF/OF 的定义 40 年没变过**。 |
