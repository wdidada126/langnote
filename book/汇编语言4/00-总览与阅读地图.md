# 《汇编语言（第 4 版）》总览与阅读地图

> **一句话**：王爽著，清华大学出版社 2020-01，ISBN 9787302539414，348 页；以 **8086/8088 实模式**为唯一教学模型，用「知识最小化分割 + 实验 + Debug 跟踪」的方式讲透 x86 实模式的寄存器、寻址、栈、中断机制，是中文世界流传最广的 x86 汇编入门书。

**大纲版在此**：`book/汇编语言4.md`（含原书 **完整中译目录，逐节页码齐全**，本目录是**深度重写版**）。两者并存、互链，不冲突。
此外 `book/汇编语言王爽.md` 存有 EMU8086 练习与 AT&T / Intel 语法对照摘录，与本目录互补。

| 实验 | 实验 1–17（每章末尾一个「实验」小节，是本册精髓） |

### 关于「第 4 版修订要点」的核实结论（重要）

网络与坊间常流传几种说法，逐一核实如下：

| 流传说法 | 核实结论 |
| --- | --- |
| 「第 4 版改用 80386 / 32 位为教学模型」 | **不实**。第 4 版正文仍以 **8086** 为教学 CPU（书前明确「本书采用以 8086CPU 为中央处理器的 PC 机来进行学习」）。80386 只在**附注 1** 与少量正文中作为「三种工作模式（实模式 / 保护模式 / 虚拟 8086 模式）」的背景出现，**没有**独立的保护模式章节。 |
| 「加入了 64 位扩展内容」 | **不成立**。全书没有 MMX / SSE / AVX / x86-64 的正文讲解，只在「版本演进」的口吻里提及。 |
| 「增加了内存寻址的系统讲解」 | 部分成立。第 2 章（物理地址、段地址 × 16 + 偏移）、第 3 章（DS 与 `[address]`）、第 7 章（7 种寻址方式）、第 8 章（数据位置与数据长度）确实构成本书最完整的**实模式内存寻址主线**，这是第 4 版最扎实的部分。 |
| 「相对第 3 版的修订」 | 主要是**章节重组**（原第 1 章拆成「基础知识 / 寄存器 / 寄存器(内存访问)」三章）、实验环节重写、语句表述与图示更新；核心指令集范围与第 3 版基本一致。 |

> 因此本目录的定位是：**把一本 16 位实模式的经典教材，用 x86-64 工程师的视角重新组织**，既讲清书里的原理，也标注书外必须补的现代知识。

## 4. 版本演进时间轴（8086 ⟶ 2026）

| 年份 | 事件 | 与本书的关系 |
| --- | --- | --- |
| 1978 | **8086** 发布；1979 年 8088 进入 IBM PC（1981），其总线结构成为后续 PC 的基本结构 | 本书唯一的教学 CPU |
| 1982 | **80286** 引入保护模式与 A20 地址线扩展，但兼容 8086 程序做得不好 | 附注 1 的背景 |
| 1985 | **80386** 引入 32 位寄存器、段描述符、页式管理、虚拟 8086 模式 | 附注 1 的背景；正文中段寄存器只讲 16 位形式 |
| 1989 | **80486**：集成 FPU / 分级 cache；**Pentium**（1993）超标量 + MMX（1996） | 本书未覆盖 SIMD |
| 1999 | **SSE** 引入单精度 SIMD 与 XMM 寄存器 | 本书未覆盖 |
| 2003 | **x86-64**（AMD64）发布：向后兼容 IA-32 的 64 位扩展；Intel 于 2004 年以 EM64T 跟进 | 本书未覆盖 |
| 2008 | **AVX**（VEX 编码，256 位） | 本书未覆盖 |
| 2013–2016 | **AVX2**（FMA、 Gather）→ **AVX-512**（ZMM、mask 寄存器，Skylake-SP / Cannon Lake） | 本书未覆盖 |
| 2015–2026 | x86-64 仍是**服务器与桌面绝对主导**（PC 端份额长期在九成以上）；移动与嵌入式端 **AArch64** 占比上升；**RISC-V** 在开源 ISA 上 growing，但生态距 x86/Arm 仍有量级差距 | 决定「学汇编的收益在哪里」 |

> **2026 年的现实判断**：x86-64 在服务器与桌面仍占主导；**SIMD 的战场已经从 SSE 迁移到 AVX2 / AVX-512**，手写汇编的收益绝大多数在「启动代码、热循环、加密原语、JIT 内核、内核路径」这几处。

## 5. 实验工具链

### 5.1 书中原配工具（16 位实模式路线）

| 工具 | 用途 | 现状 |
| --- | --- | --- |
| **MASM**（`masm.exe`）+ **LINK**（`link.exe`） | 书中默认编译器 / 连接器 | 仍是 DOS 时代的 16 位工具，需 DOSBox |
| **Debug**（`debug.exe`） | 书中默认调试器：`-r` 看寄存器、`-d` 看内存、`-u` 反汇编、`-e` 改内存、`-t`/`-p` 单步 | Windows 10/11 仍内置 `debug.exe`（64 位系统里是 32 位兼容版） |
| **DOSBox / PCem / VirtualBox + MS-DOS 6.22** | 运行 MASM 与 Debug 的 16 位环境 | DOSBox 是今天最实用的选择；PCem 可复现更真实的 80486 机器 |

### 5.2 现代替代（强烈推荐，本目录所有示例均按这套跑）

| 工具 | 说明 |
| --- | --- |
| **NASM + DOSBox** | `nasm hello.asm -o hello.com`；NASM 语法更干净、跨平台、开源，比 MASM 更适合自学者（`netwide-assembler/nasm`） |
| **YASM** | NASM 语法的分支，BSD 许可，被大量项目（甚至 LLVM）作为汇编器使用（`yasm/yasm`） |
| **NASM + QEMU（-kernel / -drive）** | 用 `qemu-system-i386` 直接跑 `bin` 格式裸机程序，比 DOSBox 更容易脚本化 |
| **objdump -d / objdump -D** | 反汇编，看机器码与指令的对应关系 |
| **gdb / lldb** | 条件断点、寄存器窗口（`info registers`）、内存（`x/16xb addr`） |
| **GCC/Clang `-S -masm=intel`** | 看编译器实际生成的 x86-64 汇编 |
| **Compiler Explorer（godbolt.org）** | 在线对比 C/C++/Rust/Go 到多种编译器输出的汇编，无需本地配置 |
| **Dogbolt（dogbolt.org）** | 在线多反编译器对比（Ghidra / angr / RetDec 等） |
| **defuse.ca/online-x86-assembler** | 在线 x86/x64 汇编 — 反汇编互转 |
| **Capstone / Keystone** | 反汇编 / 汇编引擎库，Radare2、Ghidra 的底层之一 |
| **Ghidra / x64dbg / IDA** | 静态反汇编与逆向分析 |

## 6. 跨语言对照：x86-64 寄存器与 System V ABI

> 本书教的是 **8086 的 16 位寄存器**；下表给出同一套概念在 **x86-64 System V ABI**（Linux）下的对应，是「从书里走出来」的落脚点。

| 8086（本书） | 32 位 IA-32 | 64 位 x86-64（System V） | System V ABI 角色 |
| --- | --- | --- | --- |
| —（无 RSP 语义） | — | **rax** | 返回值；`mul/div` 隐含被乘数 |
| — | — | **rbx** | 被调用者保存（callee-saved） |
| — | — | **rcx** | 第 4 个整数参数 |
| — | — | **rdx** | 第 3 个整数参数；`mul/div` 隐含高位 |
| — | — | **rsi** | 第 2 个整数参数 |
| — | — | **rdi** | 第 1 个整数参数 |
| — | — | **rbp** | 栈帧指针（可裸用，ABI 不强制） |
| **sp** | esp | **rsp** | 栈指针；**ABI 强制对齐到 16 字节（调用点）** |
| — | — | **r8** | 第 5 个参数 |
| — | — | **r9** | 第 6 个参数 |
| **ax / bx / cx / dx / si / di / bp / sp** | eax…esp | eax…esp 同名 32 位部分 **r8d…r15d** | 本书的 16 位通用寄存器只是 x86-64 的**低 16 位子集** |
| **ip** | eip | **rip** | 指令指针；**x86-64 代码可位置无关** |
| **cs/ds/ss/es** | cs/ds/ss/es/fs/gs | cs/ds/ss/es **fs/gs 仍存在** | 64 位模式**段基址被忽略**（fs/gs 例外，用于 TLS） |
| **flags**（ZF/PF/SF/CF/OF/DF/IF/TF） | eflags | **rflags** | 本书 Ch11 的全部内容；**TF/IF 语义仍在** |
| x87 **st(0)–st(7)** | 同 | **st(0)–st(7)** | x87 在 64 位模式仍在，但 SSE2 已成主流浮点 |
| — | — | **xmm0–xmm15** | 标量浮点 / SIMD；返回值常用 `xmm0` |
| — | — | **xmm16–xmm31** | AVX-512 扩展 |
| 无 | 无 | **zmm0–zmm31 / k0–k7** | AVX-512 的 512 位寄存器与掩码寄存器 |

**调用约定对照**

| 主题 | 本书（8086 实模式 / 自定约定） | System V AMD64（Linux/macOS） | Microsoft x64（Windows） |
| --- | --- | --- | --- |
| 参数传递 | 寄存器（AX/BX/CX/DX）或内存，作者自定 | `rdi, rsi, rdx, rcx, r8, r9`，更多参数走**栈** | `rcx, rdx, r8, r9`，更多参数走栈 |
| 返回值 | AX（甚至 DX:AX） | 整数 `rax`；浮点 `xmm0` | `rax`；浮点 `xmm0` |
| 保存现场 | 由程序员手工 push/pop | **rbx/rbp/r12–r15 被调用者保存**；其余调用者保存 | 同左，但 `rbx/rbp/r12–r15` + `rsp` 亦被调用者保存 |
| 栈帧 | `bp` 手工维护 | 帧指针可省略，靠 `rsp` 偏移访问 | 同左 |
| 栈对齐 | 无要求 | 调用点 **rsp 必须 16 字节对齐** | 调用点 **rsp 必须 16 字节对齐** |
| 红区（red zone） | 无 | 有（128 字节） | 无 |
| 系统调用 | `int 21h` / `int 13h` | `syscall`（`rax` = 号，`rdi/rsi/rdx…` 传参） | `syscall`（`rax`，状态码在 `rdx`） |
