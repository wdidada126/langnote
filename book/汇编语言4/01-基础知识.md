# 第 1 章 基础知识

> **一句话**：本章不写一条汇编指令，而是把「CPU 怎么读内存、内存怎么编号、地址总线 / 数据总线 / 控制总线各干什么」讲清楚——这是全书唯一的「硬件地图」，后面 16 章全在这张地图上走。

## 核心精讲

本章没有可执行代码，重点是把「地址」这件事掰开。

**1) 存储单元与编号**

```
1 bit = 一个二进制位
1 Byte (字节) = 8 bit        ← 存储器的最小可寻址单元
1 word (字)   = 2 Byte = 16 bit   ← 8086 的一个「字」
```

存储器的容量用「地址寄存器 + 译码器」实现：地址寄存器宽 20 位 ⇒ 可寻址 `2^20 = 1 MB`。

**2) 8086 的三总线（本书 1.8–1.10 的量化结论）**

```
地址总线  : 20 根  → 寻址能力 2^20 = 1,048,576 个单元 = 1 MB
数据总线  : 16 根  → 一次最多传 2 字节；1 个总线周期读/写 1 个字
控制总线  : 读写控制线（MEMR#/MEMW# 等）+ 中断请求等，宽度与实现相关
```

> 关键结论（贯穿全书）：**一段内存能不能被访问，取决于地址总线的宽度**；一段指令要读写多少数据，取决于**数据总线的宽度**。

**3) 内存地址空间 = 抽象层（1.11 / 1.15 的核心）**

真实机器里挂着 RAM、ROM、显卡显存、网卡寄存器……CPU 不区分它们，只按地址访问：

```
地址空间 (1 MB, 8086)
├─ 0x00000–0x9FFFF  常规内存 (RAM)
├─ 0xA0000–0xBFFFF  显卡图形显存区域
├─ 0xC0000–0xEFFFF  各类 ROM（显卡 BIOS 等）
└─ 0xF0000–0xFFFFF  ROM BIOS（F000:0000 开始，正好是 64 KB）
```

**4) 主板、接口卡与端口（为 Ch14 铺垫）**

接口卡（显卡、网卡、硬盘控制器）通过**端口**与 CPU 通信；端口在 x86 上与内存**独立编址**（`in`/`out`），这与内存映射 I/O 是两套机制。本书 Ch14 用 `in al, 70h` / `out 71h, al` 读写 CMOS RAM，正是这条线。

## 版本演进

| 年代 | 处理器 | 地址总线 | 数据总线 | 与本章的关系 |
| --- | --- | --- | --- | --- |
| 1974 | Intel 8080 | 16 根 | 8 根 | 64 KB 空间，8 位机 |
| 1978 | **8086** | **20 根** | 16 根 | 本书模型，1 MB 空间 |
| 1979 | 8088（IBM PC 用的就是它） | 20 根 | 8 根（外部） | 内核是 8086，省引脚 |
| 1982 | 80286 | 24 根（16 MB） | 16 根 | 引入保护模式，A20 门打开 |
| 1985 | 80386 | 32 根（4 GB） | 32 根 | 段页式、32 位，线性地址 = 物理地址（未开分页时） |
| 1993 | Pentium | 32 根 | 64 根（外总线） | 超标量 + 双流水 |
| 2003 | x86-64 (AMD64) | 40 根（理论） | 64 根 | 仍保留 20 位实模式兼容层 |
| 2020s | — | — | — | **地址总线早不是瓶颈**；瓶颈在延迟、带宽、乱序执行 |

> 本章的 1 MB 世界到 80386 就扩到 4 GB。今天写 x86-64 代码时，你几乎不需要自己算物理地址——分页与 MMU 接管了这件事。本书讲解的「物理地址 = 段地址×16 + 偏移」在 64 位模式下**已退出历史舞台**（64 位模式段基址被忽略）。

## 常见误区与本书需修正之处

| # | 误区 / 待修正 | 说明 |
| --- | --- | --- |
| 1 | 🔧 「8086 的 1 MB 地址空间就是今天 PC 的内存模型」 | 从 80286 的 A20 门、80386 的保护模式到 x86-64 的分页，地址形成方式早已换过三轮。今天跑的程序**不经过** `段×16+偏移`。 |
| 2 | 🔧 「 CPU 一次能从内存取 1 MB 里任意数据 」 | 要区分：地址总线宽（能寻址多少）≠ 数据总线宽（一次传多少）≠ cache line（64 B）大小。8086 是「16 位数据总线 + 20 位地址总线」的组合。 |
| 3 | 「ROM 一定是只读的」 | ROM 内容靠硬件写或固件更新；现代 X86 系统的 SPI Flash 里的 BIOS **可以被运行时更新甚至被 rootkit 改写**，安全上并不「只读」。 |
| 4 | 🔧 「内存地址空间统一编址，所以端口也是内存」 | x86 的端口是**独立地址空间**（`in/out`，64 KB 个端口），与内存映射 I/O 不同。本书 Ch14 正是用端口访问 CMOS。 |
| 5 | 「本章讲的就是今日 x86 编程的样子」 | 今日 x86-64 的线性地址、分页、cache、`retpoline`、IBRS 等全都与本章的极简模型不同。本章的价值在**建立直觉**，不在工程可直接照搬。 |
| 6 | 「汇编 = 直接操作所有硬件」 | 现代程序里访问硬件几乎都走操作系统（系统调用 / 驱动 / MMIO）。裸机硬件操作只在 bootloader、内核、固件、安全研究院里出现。 |
