## Paimon 一句话定位（贯穿全书的主轴）

```text
Paimon = 湖上的 LSM 树 + 显式 changelog 语义 + Flink 深度绑定
  为什么用 LSM：高频行级 upsert 在"仅追加"的湖文件上做不动（Delta/Iceberg 靠重写或 MOW 增量代价高，
               Hudi MOR 靠 log 追加），LSM 天然把"随机更新"变成"顺序追加 + 后台归并"。
  为什么需要 changelog：流计算下游要 -U/+U 才能正确聚合；湖只有"新快照"不够，必须把"更新前的旧值"也落盘。
  代价：compaction 是第二主语；写读两侧都要为合并付费。
```
