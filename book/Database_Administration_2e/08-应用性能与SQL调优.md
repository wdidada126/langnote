# 08 应用性能与 SQL 调优（Chapter 12: Application Performance，pp.373–408）

## 1. 为关系访问设计应用（Designing Applications for Relational Access，p.373）

- ✅ 章开篇即立场声明：应用性能的第一决定因素是**访问模式设计**，而非事后调 SQL ⚠️ 转述。
- 设计律（⚠️ 重构，与本书一贯口径一致）：
  1. 面向集合而非游标逐行——把业务动作写成尽量少的 SQL 语句；
  2. 把计算推向数据（存储过程/服务端聚合）以削减网络往返（往返账在第 21 章 Database Connectivity p.661 ✅ 回收）；
  3. 少 while 循环、少动态拼 SQL、少隐式转换（谓词可索引性，与第 4 章 p.150 索引策略互为镜像）⚠️ 推定。
- 本节与第 5 章 Application Design（p.185 ✅）构成「设计期规范 → 调优期审计」的闭环 ⚠️ 推定。

## 2. 关系优化（Relational Optimization，p.374）

本章主体（✅ 页 374–391，独占 17 页）。关系代数级优化技术清单（⚠️ 重构为通行名目，原书条目名以原文为准）：
- 谓词下推与早期选择（先筛再联）；
- 联结顺序与联结算法选择（嵌套/合并/哈希的适用面）；
- 用 EXISTS/IN/JOIN 改写子查询的语义与代价差异；
- UNION vs UNION ALL、DISTINCT 的排序代价；
- 聚合路径（先聚合后联 vs 先联后聚合）⚠️ 转述。
- 要点：本节教的是**人替优化器思考**的 2012 年手艺——优化器已能做大部分决策，但改写知识仍是审查生成 SQL 的眼力来源 ⚠️ 推定。
- 理论对照：关系代数与改写等价性见 [../SQL_and_Relational_Theory/00-总览与阅读地图.md](../SQL_and_Relational_Theory/00-总览与阅读地图.md)；
  声明式 SQL 思维的系统阐述在 [../SQL沉思录.md](../SQL沉思录.md)（Celko，存在已验证）。

## 5. 为效率而写与调 SQL（SQL Coding and Tuning for Efficiency，p.399）

- ✅ 本章收口（页 399–407，8 页编码规约）。规则族（⚠️ 重构为通行条款名目）：
  只取所需列、避免 SELECT *；WHERE 写法可索引（避免函数包裹列/隐式类型转换）；分页与 ORDER BY 的配合；
  事务内语句条数与锁持有时间最小化（回指第 5 章 p.205 ✅）；绑定变量替代字面量以提升共享命中率 ⚠️ 转述。

## 7A. 关系改写规则对照表（⚠️ 重构；左列对应 p.374 内容域，右列为通行改写手法名目）

| 病灶形态 | 改写方向 | 判定依据 |
| --- | --- | --- |
| 先联后筛（大中间集） | 谓词前置/下推，缩小参与联结的行 | 计划中基数估计在联结节点爆炸 |
| 逐行游标处理 | 集合化：UPDATE..WHERE EXISTS、MERGE 一类 | 语句数≈行数即反模式 |
| 相关子查询 | 脱相关改 JOIN/窗口函数（语义等价需证明） | 执行次数随外层行数线性 |
| DISTINCT 掩盖联结错误 | 修联结条件而非去重 | 结果集宽度/行数与业务不符 |
| UNION 当 UNION ALL 用 | 无去重需求即省排序 | 计划含多余排序/散列 |
| 函数包裹索引列 | 改写为区间谓词（SARGable） | 计划显示全表扫描 |
| OR 串联多列 | 拆 UNION ALL 或位图/合并扫描路径 | 索引不可用 ⚠️ 引擎差异大 |
| 深分页 OFFSET 巨值 | 键集（keyset）分页 | 跳过行成本随页数线性 ⚠️ 通用术语 |

- 纪律（⚠️ 转述）：每次改写附「等价性论证+对照计时」，否则只算碰运气——p.394 访问路径审查是改写的验收关 ✅。

## 7B. SQL 调优工单模板（⚠️ 重构，对应 p.394–407 流程）

1. 现场记录：原 SQL、原计划、指标（次数×耗时×资源）；
2. 分层排除：系统事件？结构缺索引/统计旧？才轮到 SQL 本身（第 10/11 章漏斗 ✅，见 [07-系统性能与数据库性能.md](07-系统性能与数据库性能.md)）；
3. 假设与试验：一次只改一因；在等数据量环境测；
4. 交付：新 SQL+新计划+计时对照+回滚件；
5. 固化：进代码/迁移脚本+补规则到审查清单（p.399 戒律 ✅）；
6. 复盘归档：写进元数据（第 22 章 ✅）与知识库（第 24 章 Share p.739 ✅）。

## 核心概念速览（中英对照）

| 术语 | English | 释义 |
| --- | --- | --- |
| 访问模式设计 | Access Pattern Design | 应用取数路径的总体设计，性能第一因 |
| 面向集合操作 | Set-based Processing | 以整批 SQL 替代逐行游标 |
| 谓词下推 | Predicate Pushdown | 尽早过滤以减少中间集大小 |
| 联结方法 | Join Method | 嵌套循环/合并/哈希三类实现 |
| 相关子查询 | Correlated Subquery | 逐外层行重执行的子查询，改写重点 ⚠️ 转述 |
| 访问路径审查 | Reviewing Access Paths | 以执行计划核对设计预期 |
| 计划回归 | Plan Regression | 同一 SQL 计划变差的现象 ⚠️ 通用术语 |
| 统计信息偏差 | Stale Statistics | 估行数失真引发选路错误 |
| 绑定变量 | Bind/Parameterized SQL | 字面量参数化以复用计划 ⚠️ 转述 |
| 可索引谓词 | SARGable Predicate | 不经函数/转换即可用索引的写法 ⚠️ 通用术语 |
| 网络往返 | Round Trip | 每条语句/每行的隐性代价来源 |
| 缓存一致性 | Cache Coherency（app vs DB） | 双层缓存的失效责任划分 ⚠️ 推定条目 |
