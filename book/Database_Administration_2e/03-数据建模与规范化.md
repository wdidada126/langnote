## 1. 数据建模概念（Data Modeling Concepts，p.108）与模型组件（p.113）

官方 TOC ✅：Concepts → Components → Discovering Entities, Attributes, and Relationships（p.124）构成「是什么→有什么→怎么发现」三段。

- 概念层（⚠️ 重构）：数据模型是业务结构的形式化陈述；模型的价值在于**可沟通、可校验、可再生成 DDL**，而非画图本身。
- 组件层 ✅ 小节存在：实体（entity）、属性（attribute）、关系（relationship）三大件，加上主键/外键语义与基数约束的讨论 ⚠️ 具体子项为重构。
- 发现法（p.124）：从业务名词抽实体、从动词抽关系、从访谈与单据抽属性 ⚠️ 转述。

与教材分工：ER 语义的严格定义在 [../数据库系统概念6/00-总览与阅读地图.md](../数据库系统概念6/00-总览与阅读地图.md) 第 6–7 章原理域；

## 3. 什么是规范化（What Is Normalization?，p.128）与范式（The Normal Forms，p.128）

- ✅ TOC 显示 Normalization 与 Normal Forms 同页起始：先给定义与动机（冗余、更新异常、插入/删除异常），再逐范式推进 ⚠️ 重构。
- 工程化讲法（⚠️ 重构，符合本书「到 5NF 为止的速览」惯例）：
  1NF 原子性 → 2NF 消部分依赖 → 3NF 消传递依赖 → BCNF 决定者皆候选键 → 4NF 消多值依赖 → 5NF 消连接依赖。
- 本书特色是把规范化的**辩护词写成运维账**：每个未消的依赖都会在备份窗口、重组织（p.365 ✅ Database Reorganization）、
  完整性实施（第 13 章）上产生复利利息 ⚠️ 推定。
- 关系理论的严格版本请转读：本 repo 的 [../SQL_and_Relational_Theory/00-总览与阅读地图.md](../SQL_and_Relational_Theory/00-总览与阅读地图.md)（Date）；

## 8. 范式速查表（⚠️ 重构为通行定义，供评审时快查；原书表述以 p.128–135 为准）

| 范式 | 消灭的对象 | 一句话判定 | 典型残留异常 |
| --- | --- | --- | --- |
| 1NF | 重复组/复合列 | 每列原子、无嵌套集合 | 更新需拆多值 |
| 2NF | 部分依赖 | 非键属性依赖**完整**候选键 | 键的一部分变了不用动它 |
| 3NF | 传递依赖 | 非键属性只直接依赖键 | 改一个非键要扫全表 |
| BCNF | 决定者非候选键 | 每个函数依赖左边都是超键 | 罕见的非对称依赖 |
| 4NF | 非键多值依赖 | 独立多值集各自成表 | 交叉复制爆炸 |
| 5NF | 连接依赖 | 无损分解到不能再分 | 三元约束被两两代替 |

- 评审用法（⚠️ 推定）：第 6 章设计评审的模型检查=自上而下核对「每残留一级，写一条理由」；无理由的残留即整改项 ⚠️ 方法论重构。

## 9. 规范化工程决策流（⚠️ 重构流程，对应 p.135 Normalization in Practice）

1. 逻辑模型规范化到 **3NF/BCNF 为默认档位**；
2. 列出已知高频查询 → 预判哪些跨表联结昂贵（数据量、频率两轴）；
3. 昂贵 ≠ 立即反规范：**先索引/统计/改写**（第 4 章 p.150、第 12 章 p.374 ✅ 的层位）；
4. 仍不达标才动结构：选择手法族（派生值/复制列/合并表/提取），每处登记**同步机制+责任人+校验查询**；
5. 反规范项进入第 22 章元数据账本与第 7 章变更影响清单 ✅（联动结构实抓）；
6. 定期复核：负载变了，反规范可能变成纯负债——本书流程线的闭环点之一 ⚠️ 推定。

## 核心概念速览（中英对照）

| 术语 | English | 释义 |
| --- | --- | --- |
| 实体/属性/关系 | Entity / Attribute / Relationship | 数据模型三大组件：名词、性质、联系 |
| 主键/外键 | Primary Key / Foreign Key | 唯一标识与跨表引用完整性载体 |
| 基数 | Cardinality | 关系两端的发生次数约束（1:1/1:N/M:N） |
| 部分依赖 | Partial Dependency | 非键属性依赖候选键的一部分（2NF 要消灭的） |
| 传递依赖 | Transitive Dependency | 非键属性经另一非键属性间接依赖主键（3NF 对象） |
| 多值依赖 | Multivalued Dependency | 属性组间独立多重取值关系（4NF 对象） |
| 连接依赖 | Join Dependency | 可无损分解至更小子集的依赖（5NF 对象） |
| 更新异常 | Update Anomaly | 冗余导致的多处同步修改风险 |
| 反规范化 | Denormalization | 以受控冗余换读取性能的结构决策（第 4 章主题） |
| 三层模型 | Conceptual/Logical/Physical Model | 业务→结构→落地的模型分层 |
| 域 | Domain | 属性取值的数据类型与约束的复用单元 ⚠️ 重构条目 |
