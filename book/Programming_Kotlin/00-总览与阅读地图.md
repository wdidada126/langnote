# 《Programming Kotlin》——总览与阅读地图

> 目标书：*Programming Kotlin*，Venkat Subramaniam，Packt，2018（⚠️ ISBN 待核验，不写死）。
> 用户粘贴的第三方结论评 ★★★★（综合进阶：JVM、DSL、异步）；官方书目页在列 ✅。

## 一、定位与时效裁决

Venkat 的短讲风格：语言哲学+JVM 生态+函数式/响应式概览。**2018 年出版是硬伤**：协程尚在 experimental 定名前夜、K2/值类/新 stdlib 全未发生——本仓裁决：**语言动机与 DSL 章照读，并发/响应式章只当历史语境，现代语义一律回 KiA2e + 官方文档**（✅ 判断依据为出版年份，非书中内容逐字）。

## 二、骨架（⚠️ 章名以版权页为准）

| 段 | 覆盖 | 读法 |
|---|---|---|
| 基础与惯用 | 类型/不可变/空安全叙事 | 老手快跑，捡表达 |
| 集合与函数式 | 高阶函数、惰性 | 与 Atomic 互补 |
| 模式 | 函数式/响应式概览 | 概念地图，不深挖 |
| DSL | 类型安全 builder DSL | **本书最强段 ⚠️ 评价性；与 KiA2e DSL 章对读** |
| 并发/虚拟线程前史 | 线程与 Future | 历史语境 ⚠️ |

## 三、🔧 实测口径

DSL 章逐例用 kotlinc 重敲并加 `@DslMarker` 违规负例（编译报错捕获）——衔接本仓 C++ DSL 对照档（无模板元也能做 fluent builder 的观察）。
