## 核心主题线索

- **SQL as transformation language** — dbt 将 SQL 提升为一等公民
- **Lineage & dependency (ref/source)** — 自动构建 DAG 血缘图
- **Materialization strategy** — table / view / incremental / ephemeral
- **Testing-driven development** — schema test + data test + unit test
- **Documentation as code** — schema.yml 驱动文档与 lineage 可视化
- **dbt Mesh** — 跨项目协作的分布式架构范式
- **Semantic Layer** — 从 BI 工具解耦指标定义

## 本书特色与写作风格

- **实战驱动**: 以 Jaffle Shop 等示例项目贯穿全书，每章可跟练
- **云仓库优先**: 示例覆盖 Snowflake / BigQuery / Databricks 等主流平台
- **渐进式深入**: 从基础概念到 Mesh/语义层，难度阶梯上升
- **配置导向**: 大量 `dbt_project.yml` / `schema.yml` 实际配置示例
- **社区最佳实践**: 融入 dbt Labs 官方推荐的建模与组织模式

## 前置知识

## 本书约定

- 代码示例默认使用 **Snowflake** 适配器，但逻辑通用于其他适配器
- `{{ ref() }}` / `{{ source() }}` 为 Jinja 语法，非 SQL 原生
- 所有 YAML 示例遵循 `config-version: 2` 标准
- 章节间存在依赖关系——建议按顺序阅读前 5 章
