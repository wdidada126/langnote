# 07 · 触发器、规则与分区（原书第 8–9 章合并）

## 1. 触发器四象限（Ch8 上半 ⚠️+✅）

- 时机 × 粒度：
  - `BEFORE`：可改 NEW/拦截（默认值、规范化、审计预填）；
  - `AFTER`：看得见最终态（联动汇总、外发通知）；
  - `INSTEAD OF`：只住视图上（可更新视图正解）；
  - 粒度 `FOR EACH ROW / STATEMENT` 两档。
- 事件族：INSERT/UPDATE/DELETE（TRUNCATE 自 PG 11 ⚠️）+ `UPDATE OF col` 列订阅 + `WHEN` 谓词条件——缩小触发面第一招 ⚠️。
- 绑定语法正字：`WITH EXECUTE FUNCTION fn()`（PG 10+，旧 `PROCEDURE` 措辞兼容 ⚠️）✅ https://www.postgresql.org/docs/current/sql-createtrigger.html 。
- 触发器函数=`RETURNS trigger` 的 PL 函数：`NEW/OLD` 记录变量+`TG_OP/TG_WHEN/TG_LEVEL` 环境（✅ https://www.postgresql.org/docs/current/plpgsql-trigger.html ）——直接复用 [06-服务端编程_PLPGSQL.md](06-服务端编程_PLPGSQL.md) 全套。
- 约束触发器（`Constraint Trigger`，可 DEFERRED）：FK 级自定义完整性 ⚠️+✅ sql-createtrigger 页。
- 语句级过渡表：`REFERENCING OLD TABLE AS .../NEW TABLE AS ...`（批量行集进触发器，替代逐行打点 ⚠️+✅）。

## 2. 规则系统：Rewritable，谨慎爱（Ch8 下半 ⚠️+✅）

- `CREATE RULE ... AS ON INSERT/UPDATE/DELETE TO tbl DO ALSO/DO INSTEAD (...)`：把语句**改写**成另一条语句——查询改写器而非行执行器 ✅ https://www.postgresql.org/docs/current/rules.html （200 已验）。
- 官方与本书同调 ⚠️：规则难推理（多规则合并次序、视图可更新性怪癖），**新代码一律触发器优先**。
- rule×8 的实证说明本章确有规则篇幅——按"历史机制+风险清单"读法处理 ⚠️。

## 3. 声明式分区（Ch9 主干 ⚠️+✅）

- 协议（✅ 代码逐行实证）：

```sql
CREATE TABLE part_tags (id bigint, tag_date date, level int)
    PARTITION BY RANGE (tag_date);                 -- 父表只立协议不放数据
CREATE TABLE part_tags_date_01_2023
    PARTITION OF part_tags FOR VALUES FROM ('2023-01-01') TO ('2023-02-01');
CREATE TABLE part_tags_default PARTITION OF part_tags DEFAULT;
```

- 三策略：RANGE（时间滚动）/LIST（枚举分流，代码 level 族 ✅）/HASH（均匀打散 ⚠️）；支持**子分区**层级（✅ ddl-partitioning）。
- 分区裁剪 `enable_partition_pruning`：规划期+执行期两级（PG 12 完备 ⚠️）✅ https://www.postgresql.org/docs/current/ddl-partitioning.html 。
- 约束/索引继承：父表定义级联到全部分区（PG 11 补完 ⚠️+✅ 同页）；FK 双向分区限制 ⚠️。
- 运维原语：`ATTACH/DETACH PARTITION`+DEFAULT 兜底重排=滚动窗口自动化素材（联动 Ch14-16 → [11-日志备份与监控.md](11-日志备份与监控.md)）。

## 4. 🔧 类比实测 A：`PARTITION BY` 在嵌入式引擎一律不可用（sq2a.out / duck.out 🔧）

```text
SQLite 3.50.6:  CREATE TABLE p(id INT, ts DATE) PARTITION BY RANGE (ts);
                Parse error near line 1: near "BY": syntax error
DuckDB 1.5.5:   同语句
                Parser Error: syntax error at or near "PARTITION"
```

- 两家把 `PARTITION BY` 只留给**窗口函数/COPY 分区输出**语境，无声明式表分区 ⚠️；
- 等价手段：手工分表（SQLite）/写分区 Parquet 数据集（DuckDB `COPY ... PARTITION_BY`，对位 [../DuckDB_in_Action/00-总览与阅读地图.md](../DuckDB_in_Action/00-总览与阅读地图.md)）；
- PG 的分区是规划器一等公民（裁剪直接进 EXPLAIN——对照 [10 号文件](10-查询调优索引与性能.md)）⚠️+✅ ddl-partitioning。**非 PostgreSQL 行为**：两条报错为本机否证实验本体。

## 5. 🔧 类比实测 B：触发器——SQLite 也有的"最小服务端钩子"（sq6.out 🔧）

```text
sqlite> CREATE TABLE posts(pk INTEGER PRIMARY KEY, title TEXT, cnt INTEGER DEFAULT 0);
sqlite> CREATE TABLE audit(ts TEXT, op TEXT, pk INTEGER);
sqlite> CREATE TRIGGER trg_ins AFTER INSERT ON posts FOR EACH ROW
        BEGIN INSERT INTO audit VALUES(datetime('now'),'I',NEW.pk); END;
sqlite> INSERT INTO posts(pk,title) VALUES (1,'Btree in PostgreSQL');
audit|2026-09-27 13:20:24|I|1        -- 行级 AFTER + NEW：与 PG 同构 ✅ 概念
```

- 未建 UPDATE 触发器 ⇒ UPDATE 后 audit 仍 1 行（🔧 语义自洽验证）；
- SQLite 有行级 AFTER/BEFORE（上验），但 **无语句级触发器**：`FOR EACH STATEMENT` → `near "STATEMENT": syntax error`（sq9.out 🔧）；亦无触发器函数对象（体内只有迷你 SQL 串）⚠️；
- DuckDB：**无触发器**——`CREATE TRIGGER ...` → `Parser Error: syntax error at or near "TRIGGER"`（sq9.out 🔧 实测）；
- 谱系结论：审计/汇总联动心智从 SQLite 平滑升级到 PG，但 PG 的语句级/过渡表/约束触发器/延迟执行是超集（**非 PostgreSQL 行为**）。

## 7. 本章自测（重构版；题目自拟 ⚠️）

1. **问**：BEFORE 与 AFTER 触发器各干什么？**答**：改 NEW/拦截 vs 看终态做联动。
2. **问**：可更新视图的机制？**答**：INSTEAD OF 触发器（规则为历史解法 ⚠️）。
3. **问**：DEFAULT 分区的用途与代价？**答**：兜底不收的行走它；代价=需定期 DETACH 重排 ⚠️。
4. **问**：分区裁剪开关与生效阶段？**答**：enable_partition_pruning；规划期+执行期（PG 12+ ⚠️）。
5. **问**：为什么 DuckDB 里没有本章对应物？**答**：单写者分析引擎不做行级自动化（🔧 否证）。

## 核心概念速览（中英对照）

1. **行级触发器** — FOR EACH ROW：逐行 NEW/OLD 钩子。
2. **语句级触发器** — FOR EACH STATEMENT：一次一触发。
3. **INSTEAD OF** — 视图替代动作触发器。
4. **WHEN 条件** — 触发谓词过滤：省开销。
5. **过渡表** — REFERENCING NEW/OLD TABLE：语句级批量行集。
6. **约束触发器** — constraint trigger：可延迟的完整性钩子。
7. **规则** — rewrite rule：DO INSTEAD/ALSO 查询改写，慎用 ⚠️。
8. **声明式分区** — declarative partitioning：RANGE/LIST/HASH 父协议。
9. **分区裁剪** — pruning：按约束排除分区的两级优化。
10. **DEFAULT 分区** — 兜底分区：滚动窗口素材。
11. **ATTACH/DETACH** — 分区热插拔原语。
12. **EXECUTE FUNCTION** — 触发器绑定正字（PG 10+ ⚠️）。
