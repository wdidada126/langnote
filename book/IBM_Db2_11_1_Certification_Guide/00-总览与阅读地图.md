## 七、实测纪律与 🔧 对照登记（全部为非 DB2 行为）

DB2 不可本机安装实测，本目录 DB2 语法/命令/参数一律 ⚠️ 转述（IBM 公开文档口径 + 社区笔记）。SQL 标准特性用 SQLite/DuckDB 做对照实测 ≥4 组（本机 Windows，Python 3.x 自带 sqlite3 3.45.3，duckdb 1.5.5，2026-10-01；脚本与输出在 `D:\develops\tmp\dbwave_w7_db2cert\`）。**所有结论只描述 SQLite/DuckDB，标非 DB2 行为**，仅作 DB2 语法谱的概念锚点：

| 组 | 对照实验（🔧 实测） | 结果 | 锚定的 DB2 考点 | 章 |
|---|---|---|---|---|
| A | DuckDB `OFFSET 2 ROWS FETCH FIRST 2 ROWS ONLY`；SQLite 同句 vs `LIMIT 2 OFFSET 2` | DuckDB 标准分页语法通过；SQLite 报 `near "OFFSET"` 语法错、仅认 LIMIT/OFFSET | FETCH FIRST 分页（Db2 属标准语法阵营 ⚠️ 转述） | 04 |
| B | DuckDB `MERGE INTO ... WHEN MATCHED/NOT MATCHED`；SQLite 同句 + `ON CONFLICT DO UPDATE` | DuckDB MERGE 通过（结果 (1,10),(2,20)）；SQLite 报 `near "MERGE"`，UPSERT VALUES 形式可用 | Db2 MERGE INTO（SQL:2003 ⚠️） | 04 |
| C | `GENERATED ALWAYS AS (a+b) STORED` | SQLite 通过（2+3=5）；DuckDB 报 "Can not create a STORED generated column" | Db2 生成列 VIRTUAL/STORED 双态 ⚠️ | 04 |
| D | `CREATE SEQUENCE` + `nextval` | DuckDB 通过（100→105）；SQLite 报 `near "SEQUENCE"` 语法错 | Db2 序列对象 vs IDENTITY ⚠️ | 04 |
| E | 递归 CTE + 标准 `CYCLE ... SET ... USING path` | 两家递归 CTE 均通过；CYCLE 子句两家均语法错 | Db2 支持 SQL:1999 循环保护 ⚠️ | 04 |
| F | `CREATE TABLE ... WITH SYSTEM VERSIONING` | 两家均语法错 | Db2 11.1 系统时段表 ⚠️ | 04 |
| G | SQLite WAL 库：`BEGIN EXCLUSIVE` 持锁时第二连接写入；未提交 UPDATE 期间读连接取快照 | 写入报 `database is locked`（busy_timeout=500ms 后）；读连接返回旧值快照 | Db2 锁等待/超时与隔离级直觉 ⚠️ | 07 |

## 八、易混淆点辨析

1. **Packt 认证册 vs IBM 官方红宝书**：本册是第三方应试指南（含 ⚠️ 重构成分），IBM 官方文档面在 ibm.com/docs（✅ 可达），两者术语粒度不同。
2. **Associate vs Administrator 两级**：Db2 11.1 时代认证分初级（Database Associate）与专家（Database Administrator）；本册对齐后者 ⚠️（页面仅题录级）。
3. **实例 vs 数据库**：与 #77 易混点第 1 条同题；11.1 未变，`db2start` 的仍是实例。
4. **FETCH FIRST vs LIMIT**：SQL 标准分页 Db2/PG/DuckDB 系与 SQLite/MySQL 系方言差异——见 🔧A，非高下之分，考试只考前者。
5. **IMPORT vs LOAD**：IMPORT 走 SQL 引擎、全约束全日志；LOAD 旁路引擎、非可恢复装载会置表空间 pending（⚠️ 转述，考点高频）。
6. **循环日志 vs 归档日志**：循环日志只能冷备、崩溃恢复不保证前滚；归档日志（LOGRETAIN/LOGARCHMETH1）才支持在线备份+前滚恢复（⚠️）。
7. **页锁 vs 行锁**：Db2 LUW 传统以页粒度加锁并做锁升级，非 InnoDB 行锁模型；SQLite 文件级锁仅作第三极类比（🔧G，非 DB2）。
8. **SMS 表空间**：11.1 时代新库不推荐/趋向淘汰 SMS，DMS+自动存储是主线（⚠️ 转述，代差注记见 03 章）。
9. **9.x 与 11.1 考纲**：#77 对齐 730/731/73x 老三线，本册对齐 11.1 新命名；同知识点考题命令输出样式已变，勿混背。
