# 01 · Db2 根基与体系结构（对齐考试域：Fundamentals ⚠️ 推定）

> 章名 ⚠️ 推定（本目录为考试域主题重构，非原书章名，见 00 降级声明）。DB2 不可本机实测，命令与行为一律 ⚠️ 转述自 IBM 11.1 公开文档与社区笔记。

## 一、章定位

本域回答"Db2 是什么、由哪几层构成"。认证考试在此域的考法：产品版本选型（哪个 edition 支持哪个特性）、实例/数据库两级关系、内存结构归属（实例级 vs 库级）、引擎进程/线程各自职责。它是 02（装什么）、03（建什么）、09（看什么）的前置词表。

## 二、多模产品家族与版本选型（⚠️ 转述）

1. Db2 11.1 = 关系引擎 + XML（pureXML 血统）+ JSON（BSON 存储，11.1 新）+ 时空等扩展的多模数据库；LUW 版跑 Linux/UNIX/Windows，与 z/OS 版是两条代码线（考试默认 LUW）。
2. 版本谱（选型高频考点）：Enterprise（全特性）、Advanced（企业特性减配）、Standard/Standard Edition Server、Personal（单机全功能体验）、Developer/Community（免费学习件，容量受限）、Express-C（更早的免费件，11.x 后由 Community Edition 接班 ⚠️ 年代推定）、Warehouse（数仓专用形态）、Connect（网关访问 z/OS 数据）。
3. 特性→版本反查是典型题型：如"分区表/数据分片、HADR、pureScale 分别要求哪个版本线"（⚠️ 具体门槛以 IBM 版本对比表为准，https://www.ibm.com/docs/en/db2 ）。
4. 免费件的合法用途：本目录全部 🔧 对照与练习题可在 Developer/Community Edition 上做；本机未装，属 ⚠️ 转述。

## 三、实例与数据库两级模型

- 安装产物（代码副本）→ 实例（instance：调度器进程 + 共享内存 + 端口）→ 数据库（库目录 + 表空间 + 日志）。一个实例可挂多库；实例间内存/端口互相隔离。
- 实例所有者（instance owner）与 SYSADM 组决定实例管理权；Windows 上实例表现为系统服务（⚠️ 与 #77 第 2 章同题，11.1 无概念变化）。
- 库级对象命名空间：schema（默认与授权 ID 同名）→ 表/视图/索引等；目录视图双面孔：SYSCAT（推荐查询面）与 SYSIBM（基面/兼容面）。
- SAMPLE 库与 db2sampl：考试示例输出常见底座（题面出现 EMPLOYEE/ORG 表多来自它 ⚠️ 转述）。

## 四、内存结构：实例共享内存 + 库控制列表（⚠️ 转述）

1. 实例级共享内存承载：库缓存（database cache）、缓冲池（可实例级共享池）、锁列表 LOCKLIST、锁句柄内存、排序堆 APPLHEAPSZ/排序共享 SHEAPTHRES、编目缓存等。
2. 库级配置参数（DB CFG）决定上述分配：bufferpool 大小与页尺寸（4/8/16/32KB）、LOCKLIST/MAXLOCKS、LOGFIELSIZ/LOGPRIMARY/LOGSECOND、DFTDECFLOAT? 等——03/07 章展开。
3. 自动内存治理：STMM（自调内存管理器）动态调缓冲池/锁/排序三类内存；SELF_TUNING_MEM=ON 是 11.1 默认倾向（⚠️）。
4. 内存不足表现与定位入口：SQL0289? 报资源不足类错误，用 db2pd -mem、GET SNAPSHOT FOR MEMORY POOL 观察（09 章工具谱）。

## 五、引擎进程/线程与后台职责（⚠️ 转述）

- 协调代理（agent/coordinator）：服务应用连接，执行 SQL；线程模型下由调度器/线程池托管（DB2_THR_LIST? 细节不背）。
- 后台必考名单：db2pfchr（页预取）、db2pclnr（页清除器）、db2logn（日志写）、db2lfr（日志回收）、db2ckpwd（口令校验）、db2agent? 等；记"名字前缀 + 职责"的配对题。
- 实例守护：db2sysc 是引擎主体进程（UNIX 上 `ps` 里看到它即实例在跑）；故障监控/恢复类进程负责连接期崩溃恢复（connect-time recovery，07/08 交界）。
- DPF（数据库分区特性）：多分区并行（db2nodes.cfg 定义分区），Enterprise 线特性；SMP 单分区是考试默认场景（⚠️）。

## 六、SQL 引擎处理链路速览

- 动态 SQL：准备（解析/绑定，产物进包缓存）→ 优化（访问计划）→ 执行；静态 SQL：precompile/bind 提前产出计划（#77 第 9 章纵深，11.1 概念未变 ⚠️）。
- 优化器输入=目录统计（RUNSTATS 产物，10 章）+ 配置（DFT？、优化级别）+ 工作区内存；输出=访问计划（IXSCAN/TABLESCAN/JOIN 方法，09 章）。
- 本域只建立"统计→计划→执行"因果链认知；题型多为"改了 X 后计划为何变"。

## 六点五、词根速记卡（命令/进程名解码）

Db2 对象名自带上文风格法，认词根可省一半死记：

- `db2 + 动词/名词`：db2icrt（create instance）、db2ilist（list instances）、db2iupdt（update instance）、db2sampl（sample）、db2dart（dart=页体检 ⚠️ 词源趣记）、db2pd（process dump 类现场工具 ⚠️）。
- `db2 + 角色名`：db2sysc（系统控制主体）、db2pfchr（prefetch reader）、db2pclnr（page cleaner）、db2logn（logger）、db2lfr（log file reclaim? ⚠️ 展开口径存疑）、db2ckpwd（check password）。
- 参数分层口诀：**DBM CFG=实例的事，DB CFG=库的事，db2set=引擎的脾气，OS 组=身份的门**（02/06/07 章反复用这句）。
- 目录双面孔：SYSCAT.* 查元数据首选，SYSIBM.* 底层表；`select tabschema,tabname from syscat.tables` 是探活之后的第二句肌肉记忆。
- 缩写词族：LUW（Linux/UNIX/Windows）、DPF（分区特性）、BLU（列组织引擎代号 ⚠️）、STMM（自调内存）、MQT（物化查询表）、FP（Fix Pack）。

## 六点七、自测题（本目录自编，非原书题 ⚠️）

**Q1** 一台机器三个实例，`db2 list active databases` 查不到刚启动的库，最先怀疑什么？
**答**：DB2INSTANCE 指向了别的实例——先 `db2 get instance` 确认路由（三/四节事故源，与 02 章配置双轨联动）。

**Q2** 判断正误："缓冲池是实例级唯一大内存，因此调一个库的缓冲池不影响同实例他库。"
**答**：错。实例共享内存承载多库（第四节结构），池本身按页尺寸建且可能共享/独立配置，参数联动与 STMM 接管都会跨库影响（⚠️ 转述口径，细节以 DB CFG 文档）。

**Q3** 配对：db2pfchr / db2pclnr / db2lfr 各职责一句话。
**答**：预取读页入池 / 清脏页回盘 / 回收重用日志文件（⚠️ 名字展开存疑处已标注，职责配对为社区共识口径）。

**Q4** 哪个版本选型题眼与免费件无关、纯企业特性？
**答**：DPF/HADR/pureScale 类高可用与扩展特性走 Enterprise/Advanced 线；Developer/Community 只作学习载体（第二节谱系；具体门槛回官方版本对比表 ⚠️）。

**Q5** "装了 11.1 却发现 CLPPlus 不存在/Control Center 消失"，一句话定性。
**答**：11.1 图形面换代事件（Control Center 退场 ⚠️），用 CLP/CLPPlus/Data Studio 组合替代（11 章工具谱），非安装失败。

## 六点八、本域场景表达三句话（面试/论述题可背）

1. 选型句："LUW 线按负载选 edition：事务密集走 Enterprise/Advanced 拿全特性，学习验证用免费件，数仓形态看 Warehouse——特性门槛以官方版本对比表为准。"
2. 架构句："Db2 的容量治理是两级三段：代码副本—实例—数据库；内存看实例共享段，行为看 DBM/DB 两本配置加注册表开关。"
3. 观测句："引擎的呼吸都在后台进程名里：读有 pfchr、写有 pclnr、日志有 logn/lfr、口令有 ckpwd——db2pd 一帧看清。"（⚠️ 转述拟人口径，命令以 09 章为准）

## 核心概念速览（中英对照）

- **实例** — Instance：承载引擎进程/内存/端口的服务容器，一实例多库
- **实例所有者** — Instance Owner：创建并启动实例的 OS 用户
- **SYSADM 组** — System Administrator Group：实例级管理权限的 OS 组
- **SYSCAT/SYSIBM** — Catalog Views/Tables：目录元数据的推荐查询面与基面
- **缓冲池** — Buffer Pool：页缓存，按页尺寸分池
- **STMM** — Self-Tuning Memory Manager：自动调配缓冲池/锁/排序内存
- **db2sysc** — Engine Process：LUW 引擎主体进程
- **协调代理** — Coordinator/Agent：服务连接执行 SQL 的工作单元
- **db2pfchr** — Page Cleaner/Prefetch 家族名：后台页预取进程（对照 db2pclnr 清除器）
- **DPF** — Database Partitioning Feature：多分区并行架构（企业线）
- **Community Edition** — 免费学习版：替代 Express-C 的入门件（⚠️ 年代推定）
- **多模数据** — Multimodel：关系+XML+JSON 同引擎存储
- **SAMPLE 库** — Sample Database：db2sampl 生成的教学演示库
