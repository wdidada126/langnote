# 11 · 连接编目与开发接口（对齐考试域：Connectivity & Tools ⚠️ 推定）

> 章名 ⚠️ 推定（主题重构，见 00 降级声明）。DB2 行为一律 ⚠️ 转述自 IBM 11.1 公开文档与社区笔记；本机不可装 DB2，无本章专属 🔧 组（连接参数方言对照沿用 04 章"方言阵营"心智）。

## 一、章定位

本域回答"应用怎么找到库"：目录（catalog）双本账（节点目录/数据库目录）、DCS 集中配置、客户端形态选型（Full vs Runtime vs Driver），以及驱动家族（CLI/JDBC/.NET/Python）与工具面（CLP/CLPPlus/Data Studio）。配对题密集区。

## 二、编目机制：两本目录账（⚠️ 转述）

- 节点目录（SQLHOSTS）：远端"节点"= host+port+协议 的抽象；`db2 catalog tcpip node n1 remote 10.0.0.5 server 60000`。
- 数据库目录：节点+真实库名→本地别名；`db2 catalog db demo as demo_s at node n1`。
- 双层目录体系：系统级（实例 sqllib 下）与本地（用户级，LOCAL?）——同名别名遮蔽规则是判断题眼。
- 未编目直连：DSN 串内嵌 HOST/PORT/PROTOCOL/DATABASE 可免编目（Runtime 驱动主用法）——"最少安装+最少配置"组合拳（与 02 章客户端形态联动）。
- 查账工具：`db2 list node directory` / `list database directory` [local/global]；删账 `uncatalog` 家族。

## 三、DCS 与认证联动（⚠️ 转述）

- DCS（Distributed Connection Service）：服务端集中下发连接配置（db2ns? 名称服务器/DCS 分实例级与 DB2 Community? 两态 ⚠️ 冷门）；客户端免逐库编目。
- 认证联动：DCS 配 SERVER 认证时客户端可不带本地账号（06 章回收）——"装了 client 却 SQL30082N? 认证失败"类排错题（错误号示意 ⚠️）。
- 选型题模板：应用机数量大、库多、变更频繁→DCS 或纯 DSN 直连；小规模→手工编目足够。

## 四、驱动与客户端家族（⚠️ 转述）

1. CLI：Db2 原生 C 接口（ODBC 超集），驱动库即 IBM Data Server Driver；db2cli.ini/IBM Data Server Driver 参数文件两代配置面 ⚠️。
2. ODBC：经 CLI 薄封装；DSN/无 DSN 两用法。
3. JDBC：db2jcc4（Type-4 纯 Java 直连）与旧 Type-2（需本地库）；连接串 `jdbc:db2://host:port/dbname:user=..:password=..:` 方言形态（属性链式冒号结尾是 Db2 特色语法 ⚠️ 细节）。
4. .NET：IBM.Data.DB2? 提供器（命名随版本 ⚠️）；Python：ibm_db（官方扩展包生态位 ⚠️ 版本）。
5. 嵌入式/预编译：EXEC SQL 静态路线（#77 第 9 章 PREP/BIND 纵深，11.1 概念未变 ⚠️）；动态路线=直接 PREPARE/EXECUTE。
6. 协议面：LUW 间/客户端-服务器走 DRDA over TCP；z/OS 数据经 Db2 Connect 网关授权（01 章版本位回收）。

## 五、工具面谱（11.1 时代快照，⚠️ 转述）

- CLP：管理命令全能壳（02 章三态用法回收）。
- CLPPlus：SQL*Plus 风格增强壳（脚本变量/格式化 ⚠️ 后续版本进入退场叙事）。
- Data Studio：Eclipse 系图形开发/调试件（对象浏览、SQL 构建）。
- Data Server Manager/控制台类 Web 件：监控+运维轻量面（命名与能力随 FP ⚠️）。
- Control Center：11.1 已移除 ⚠️——"哪个图形件不存在了"送分题。
- SAMPLE/db2sampl 与试验纪律：练连接域的标准底座（01 章）。

## 六、连接排错主线（例题库向）

1. SQL30061N?（库未找到）：别名→编目→真实库名三级核对（03 章建库名回收）。
2. SQL30081N?（认证被拒）：认证方式与凭证链核对（06 章）；先 `db2 connect to X user .. using ..` 最小化。
3. SQL30082N? 类账号问题：锁定/口令过期 OS 侧原因。
4. SQL30020N? 安全例程错：客户端版本与服务器安全级别错配（TLS/GSKit ⚠️）。
5. 连不上端口类：服务/db2start（02 章）、防火墙、svcname 注册三查。
6. "应用能连不能查系统目录"：权限面而非连接面——两域分界判断题。

## 八·五、自测题（本目录自编，非原书题 ⚠️）

**Q1** 排错主线：应用报"数据库别名未找到"类（SQL30061N 示意），给出三账核对顺序。
**答**：本地/系统数据库目录里别名存在吗（list database directory）→ 别名指向的真实库名在目标节点存在吗（list node directory + 服务器端确认）→ 连接串/DSN 用的到底是别名还是真名（第二节双账+第六节 1；顺序错=白重启）。

**Q2** 组合题：瘦客户端 + 免编目 + 免本地凭证 三个需求各对应哪两个设计点的组合？
**答**：Runtime/Driver 形态（02 章三形态）+ DSN 自包含串（第二节）+ DCS SERVER 认证代客（第三节）——三者常同题出（陷阱 5 的解药）。

**Q3** 判断："JDBC Type-4 驱动要求客户端装有本地 Db2 库文件。"
**答**：错。Type-4 纯 Java 直连 DRDA 端口，免本地库；Type-2 才依赖（第四节 3——"选 Type-4 的理由"配对口径）。

**Q4** 配对：CLP / CLPPlus / Data Studio / db2pd 各一句"最擅长"。
**答**：管理命令全能壳 / SQL 脚本增强壳（变量与格式化）/ 图形开发与对象浏览 / 无连接事故现场直读（09 章借将；第四节工具谱+第五节退场史合并记忆）。

**Q5** 场景：企业 200 个应用、30 个库、连接参数常变——给两方案并选一。
**答**：A=DCS 服务端集中下发（变更一处生效），B=部署系统统一脚本写目录账；规模与变更频率推 A 占优（第三节选型模板；合规环境再叠加 TLS/插件认证，06 章联动）。

## 八·七、本域场景表达两句话

1. 排错句："连不上先分'账、门、路'三查：目录账对不对（本节）、认证门开没开（06 章）、网络路通不通（02 章端口/服务）——四码归三域是本章的读题法。"
2. 设计句："客户端形态×配置载体×认证方式三维笛卡尔积里取最小格：Runtime+DSN+SERVER 是应用农场的答案，Full+本地编目+OS 认证是 DBA 工位的默认值。"

## 八·九、本域一句话索引（复述练习用）

- 两本账：节点目录（host/端口/协议）+ 数据库目录（真名→别名），系统级/本地两级。
- 三形态：Full（全能壳）/ Runtime（只驱动）/ 独立 Data Server Driver（分发面）。
- 三认证：CLIENT 自带凭证 / SERVER-DCS 代客 / 插件接企业目录（06 章）。
- 驱动谱：CLI=ODBC 超集；JDBC Type-4 免本地库；嵌入式走 PREP/BIND 静态路。
- 协议位：LUW 互访 DRDA over TCP；z 数据经 Connect 网关（01 章版本位）。
- 排错三查口诀：账（目录）、门（认证）、路（网络）——四码归三域。
- 退场史：Control Center 没了（11.1）；CLPPlus 后继收缩 ⚠️——图形面看 Data Studio/Web 控制台。

## 核心概念速览（中英对照）

- **节点目录** — Node Directory（SQLHOSTS）：host/协议/端口台账
- **数据库目录** — Database Directory：库名→本地别名映射
- **uncatalog** — 撤账命令族：删目录条目
- **DSN 直连** — 连接串自包含：免编目连库
- **DCS** — Distributed Connection Service：服务端集中连接配置
- **Full Client** — 全量客户端：含 CLP/编目工具
- **Runtime Client** — 运行时客户端：仅驱动库
- **Data Server Driver** — 独立分发的驱动族（CLI/ODBC/JDBC）
- **Type-4 JDBC** — 纯 Java 直连驱动（db2jcc4 代表）
- **DRDA** — 分布式关系数据库体系：LUW 线 SQL 协议
- **Db2 Connect** — z 数据网关授权形态
- **CLPPlus** — 增强命令行壳（11.1 时代仍在册 ⚠️）
- **Data Studio** — Eclipse 系图形开发件
- **静态 SQL** — Embedded/Precompile：提前绑定计划路线（#77 09 章纵深）

## 最新演进与工业实践

- 驱动整合：IBM Data Server Driver 统一 CLI/ODBC/JDBC 分发延续至今；.NET Core/Python 官方包在 2024–2026 的迭代由 IBM 开源仓库承接（✅ 示例仓库 https://github.com/IBM/db2-samples curl -sI 200 ；具体驱动仓库名请以 GitHub 检索为准 ⚠️）。
- 编目式微：云/容器环境里"系统目录账"被环境变量+连接串取代，DCS 存量集中在传统企业内网；概念仍是排错语言底座 ⚠️ 转述。
- 工具换代：Data Studio 主线由 Data Movement/Development 插件化叙事演进，浏览器控制台（DSM/Db2 托管服务控制台）承担日常面 ⚠️；CLPPlus 退场（11.5 后不再随装 ⚠️ 版本归属存疑）。
- 认证前移：TLS/证书与平台 SSO 成为连接第一关（06 章插件路线），传统"OS 口令直穿"在合规区绝迹。
- 面试串讲点：Db2 的"两本目录账"与 Oracle tnsnames、SQL Server 客户端别名、PG pg_hba+连接参数是同一问题的四种工程解，repo 内四册 00 互链可组一套题。
