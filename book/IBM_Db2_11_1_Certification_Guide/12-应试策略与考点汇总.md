## 四、自编自测题（非原书题 ⚠️ 答案随题，机制均为转述口径）

**T1** 新库需支持在线全备与时间点恢复，建库后必须先动哪个参数族？
A. LOCKLIST 扩容 B. LOGARCHMETH1/LOGRETAIN 归档化 C. AUTO_MAINT D. TRACKMOD
**答 B**。循环日志是根因锁死项；TRACKMOD 只关系增量备（03/08 章）。

**T2** LOAD 以 NONRECOVERABLE 完成后，USERSPACE1 的正确状态与补救是？
**答**：表空间进入备份挂起（pending），需立即对该表空间做一次备份解除恢复链断裂风险（05 章×08 章）。

**T3** 应用报 -911 类锁超时，持锁者长时间未提交。给出"现场取证→处置"两步命令形态。
**答**：`db2pd -db 库 -locks wait showlocks`（或 MON_GET_LOCKS）定位持锁应用（07 章）；确认后协调该事务提交/回滚，勿先调大 LOCKTIMEOUT（治标错项）。

**T4** 哪组分页写法在 Db2 与 PostgreSQL 中同形，而在 SQLite 中需改写？
**答**：`ORDER BY ... OFFSET n ROWS FETCH FIRST m ROWS ONLY`（🔧A 实测：DuckDB 通过、SQLite 语法错仅认 LIMIT/OFFSET；Db2 属标准阵营为 ⚠️ 转述）。

**T5** 判断"页锁太多导致表锁"现象的名称与三个联动参数。
**答**：锁升级（Escalation）；LOCKLIST/MAXLOCKS/（应用数或阈值类参数，AVG_APPLS ⚠️）联动（07 章）。

**T6** 大批 IMPORT 后报表 SQL 计划劣化，第一步动作？
**答**：RUNSTATS 重建统计（装载/导入清统计联动，05→10 章），而非立即建索引/重组。

**T7** SYSMAINT 与 DBADM 各能否 SELECT 业务表？（口径辨析）
**答**：维护/控制类实例权限不天然含数据读取；读数据需 DATAACCESS 或对象授权路径（06 章三级金字塔；具体组合以 11.1 文档核对 ⚠️）。

**T8** 认证题：客户端不含 CLP、只需连库跑应用，选哪形态？再走 DSN 直连还需要编目吗？
**答**：Runtime/驱动形态；自包含连接串可免编目（11 章×02 章）。
