## 二、核心精讲

### 11.1 复杂度类
- P：确定性图灵机多项式时间可解。
- NP：解可多项式验证；P ⊆ NP（是否相等即 P vs NP 千年难题）。
- NP 完全：在 NP 中且任一 NP 问题可多项式规约到它。

### 11.2 规约
证明 B 是 NP 完全：先证 B ∈ NP，再把一已知 NPC 问题 A 多项式规约到 B（见 [concepts/归约与NP完全性.md](concepts/归约与NP完全性.md)）。

### 11.3 典型 NPC 问题
SAT、3-SAT、顶点覆盖、团、哈密顿回路、旅行商（决策版）、子集和、划分等。

### 11.4 近似与启发式
- 顶点覆盖：贪心选最大度边得 2-近似。
- TSP：三角不等式下用 MST 得 2-近似；一般 TSP 无常数近似（除非 P=NP）。
- 局部搜索/模拟退火/遗传：工程启发式，不保证界。

## 五、近年研究与工业界前沿（2020–2026）

- 现代 SAT 求解器（`python-sat` / `pysat`）在工业实例上极快，远超本书 2014 年的手写回溯。
- 约束优化用 `ortools`（Google）直接建模；非同行评审但工业广泛。
- P vs NP 仍未解（2026 现状）；机器学习「神经组合优化」是活跃研究方向（同行评审论文逐年增多，但无突破性降复杂度结论）。

## 六、常见误区与本书需修正之处

- 🔧「NPC = 完全不能解」：错，是小输入/特殊结构可精确解，大输入才需近似；原书已澄清但易被误解。
- 原书的「启发式」示例偏教学；今天生产用 `ortools`/`pysat` 而非手搓退火。
- 🔧 注意 NPC 指「决策版」；优化版（如找最短 TSP  tour）通常更难，但可借决策版二分。

## 七、跨语言对照

- 规约思想是语言无关的；但 `ortools` 的建模 API 在 Python 比 C++ 更简洁，适合快速验证 NPC 近似方案。
