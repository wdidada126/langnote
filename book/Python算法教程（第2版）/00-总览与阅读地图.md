## 三、版本演进时间轴

| 版本 / 年份 | 与本书相关的变化 | 影响章节 |
|---|---|---|
| Python 3.3（原书基线，2012） | `functools.lru_cache`、`yield from`、`collections.ChainMap`；原书部分示例即基于此 | 全 |
| Python 3.8（2019） | `math.comb`/`math.perm` 取代手写组合数；`f-string=` 调试；海象运算符 `:=` | 03、08 |
| Python 3.9（2020） | `functools.cache`（无参 `lru_cache`）；`graphlib.TopologicalSorter` 内置拓扑排序；字典合并 `\|` | 05、08 |
| Python 3.10（2021） | 结构化模式匹配 `match`；`zip(*, strict=True)` | 05、09 |
| Python 3.11（2022） | CPython 提速约 25%（专用于帧/调用）；异常更轻 | 12 |
| Python 3.12（2023） | 每解释器 GIL（PEP 684）；`bisect` 新增 `key=`；更细异常组 | 12 |
| 🔴 Python 3.13–3.14（2024–2025） | **实验性 free-threading（无 GIL，PEP 703）**；`subprocess` 默认 `text=True` 弃用写法；CPython 持续提速 | 12（原书「加速」章节已严重过时） |

## 七、跨语言对照速查

| 概念 | Python 习惯 | C++ / Java 习惯 |
|---|---|---|
| 队列（BFS） | `collections.deque`（`popleft` O(1)） | `std::queue` / `ArrayDeque` |

## 八、本目录的写作约定

- 每章按六段式：一、本章地图；二、核心精讲（含可运行片段）；三、版本演进；四、经典论文与原始文献；五、近年研究与工业界前沿（2020–2026）；六、常见误区与本书需修正之处（含跨语言对照可选）。
- 代码以 Python 3.12 为准，关键处标注与原书 3.3 的差异；可运行片段 `main` 尽量自足。
- 不虚构文献：未核到的编号/年份标注 🔧 以官方文档为准。
- 诚实声明：原书基于 Python 3.3，部分性能建议（PyPy 版本、Cython、NumPy API）已大幅过时；第 12 章须整体按今天重读。
