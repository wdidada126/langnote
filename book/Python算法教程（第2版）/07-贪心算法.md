## 二、核心精讲

### 7.2 活动选择（贪心证明范式）
按结束时间排序、每次选不冲突且最早结束的，可证最优。

### 7.3 Huffman 编码（用 `heapq` 最小堆）
```python
# 教学示意，不参与构建
import heapq
from typing import Dict, Tuple

def huffman(freqs: Dict[str, int]) -> int:
    heap = [[w, ch] for ch, w in freqs.items()]   # 用负权可改最大堆；此处只需取最小
    heapq.heapify(heap)
    total = 0
    while len(heap) > 1:
        lo = heapq.heappop(heap)
        hi = heapq.heappop(heap)
        merged = [lo[0] + hi[0], lo[1] + hi[1]]
        total += merged[0]
        heapq.heappush(heap, merged)
    return total   # 返回编码总比特数
```

### 7.4 最小生成树
- Kruskal：边按权排序 + 并查集（Union-Find）判环。
- Prim：`heapq` 维护「割边最小堆」。

## 六、常见误区与本书需修正之处

- 🔧「贪心一定快且对」：仅当满足贪心选择性质 + 最优子结构时才保证最优；否则只是启发式（如一般旅行商问题用贪心会很差，见 [11-困难问题与近似.md](11-困难问题与近似.md)）。
- 原书未强调 `heapq` 只支持最小堆、且元素需可比较（用 `[权重, 计数器, 节点]` 避免节点不可比时报错）。

## 七、跨语言对照

- C++ `std::priority_queue` 默认最大堆，与 Python `heapq` 默认最小堆相反，写 MST/最短路时符号要当心。
