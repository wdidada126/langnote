## 二、核心精讲

### 6.2 归并排序
```python
# 教学示意，不参与构建
from typing import List

def mergesort(xs: List[int]) -> List[int]:
    if len(xs) <= 1:
        return xs
    mid = len(xs) // 2
    left = mergesort(xs[:mid])
    right = mergesort(xs[mid:])
    out: List[int] = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:]); out.extend(right[j:])
    return out
```

### 6.3 快速排序
原书用列表推导写 `quicksort`；生产用 `random` 选基准避免最坏 O(n^2)，或直接使用内置 `sorted()`（Timsort）。

### 6.4 二分
`bisect` 模块；3.10+ 支持 `bisect.bisect_left(a, x, key=...)`（3.12 起 `key=` 参数），注意 `key=` 是 3.12 新增。

## 三、版本演进

- 🔴 Python 3.12 起 `bisect` 支持 `key=` 参数，按投影二分更方便。
- 原书 `quicksort` 列表推导版会产生大量拷贝；今天大数据用 `sorted()`（Timsort，O(n log n) 且对部分有序极快）。

## 六、常见误区与本书需修正之处

- 🔧 原书「自己写 quicksort 练习」可以，但生产**不要**替代 `sorted()`；Timsort 在真实数据上通常更快且稳定。
- 🔧 递归版 mergesort/quicksort 在超大数组上会 `RecursionError`，需用迭代或提高递归限制（见 [04-归纳递归与规约.md](04-归纳递归与规约.md)）。

## 七、跨语言对照

- C++ `std::sort` 是 introsort（快排+堆排+插排混合）；Java `Arrays.sort` 对对象用 Timsort、对基本类型用双轴快排——与 Python `sorted` 的 Timsort 思路相近。
