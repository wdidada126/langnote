# 概念专篇：渐近记号与复杂度分析

> 跨章节概念，出现在 [02-基础.md](../02-基础.md) 与 [03-计数基础.md](../03-计数基础.md)。本文把「如何描述算法快慢」系统讲透。

## 一、记号定义

- `O(g)` 渐近上界：`f ≤ c·g` 对足够大 n。
- `Ω(g)` 渐近下界：`f ≥ c·g`。
- `Θ(g)` 紧界：同时 O 与 Ω。
- `o(g)`/`ω(g)`：严格小于/大于（极限比值为 0 / ∞）。

## 二、常见复杂度速查（Python 语境）

| 操作 | 复杂度 | 备注 |
|---|---|---|
| `list.append` / `list.pop()` | 均摊 O(1) | `pop(0)` 是 O(n) |
| `dict`/`set` 查找、插入 | 均摊 O(1) | 3.7+ 保序（PEP 520） |
| `deque.popleft` | O(1) | BFS 队列必备 |
| `heapq.heappush/pop` | O(log n) | 最小堆 |
| `bisect` 插入 | O(log n) + O(n) 移动 | 3.12+ 支持 `key=` |
| `sorted` / `list.sort` | O(n log n) | Timsort，稳定 |

## 三、版本演进

- 原书（3.3）未提 `dict` 保序、`bisect` 的 `key=`（3.12）、`graphlib`（3.9）。今天这些都已落地，分析时应纳入。

## 五、近年研究与工业界前沿（2020–2026）

- 工业界更关注「均摊 vs 实际」与缓存友好性；`pytest-benchmark`/`hyperfine` 做经验对比（非同行评审）。

## 六、工业界实现与跨语言对照

- C++ `std::vector`、`std::unordered_map` 与 Python 列表/字典复杂度同阶，但缓存局部性不同导致常数差异，分析时勿只看大 O。
