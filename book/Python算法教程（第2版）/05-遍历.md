## 二、核心精讲

### 5.1 邻接表表示
用 `dict[str, list[str]]` 存图最自然：

```python
# 教学示意，不参与构建
from collections import deque

def bfs(graph: dict[str, list[str]], start: str) -> list[str]:
    seen = {start}
    q: deque[str] = deque([start])
    order: list[str] = []
    while q:
        u = q.popleft()          # deque.popleft 是 O(1)，list.pop(0) 是 O(n)
        order.append(u)
        for v in graph.get(u, []):
            if v not in seen:
                seen.add(v)
                q.append(v)
    return order

def dfs(graph: dict[str, list[str]], start: str) -> list[str]:
    seen = set()
    order: list[str] = []
    stack = [start]
    while stack:
        u = stack.pop()
        if u in seen:
            continue
        seen.add(u)
        order.append(u)
        for v in reversed(graph.get(u, [])):
            if v not in seen:
                stack.append(v)
    return order
```

### 5.2 DFS 与 5.3 BFS
DFS 用栈（或递归）、BFS 用 `deque`。BFS 天然给出无权图单源最短路（第 9 章加权情形用 Dijkstra）。

### 5.4 拓扑排序
可用 DFS 后序反转；3.9+ 有内置 `graphlib.TopologicalSorter`：

```python
# 教学示意，不参与构建
from graphlib import TopologicalSorter

ts = TopologicalSorter()
ts.add(2, 1); ts.add(3, 1); ts.add(3, 2)
print(list(ts.static_order()))   # [1, 2, 3]
```

## 三、版本演进

- 🔴 Python 3.9 新增 `graphlib.TopologicalSorter`，原书手写的拓扑排序可替换为标准库，且支持「动态添加边、分批 yield」。
- BFS 队列务必 `collections.deque`（`popleft` O(1)），原书已强调；今天仍成立。

## 六、常见误区与本书需修正之处

- 🔧 原书用 `list` 当队列写 BFS 会退化为 O(n^2)；今天必须用 `deque`。
- 🔧 递归 DFS 在大数据图上会 `RecursionError`（见 [04-归纳递归与规约.md](04-归纳递归与规约.md)），生产用显式栈或 `networkx` 的迭代实现。
- 原书未提 `graphlib`，今天拓扑排序优先标准库。

## 七、跨语言对照

- Java `ArrayDeque`、C++ `std::queue` 与 `deque` 等价；语义一致，仅 API 名不同。
