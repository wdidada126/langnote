# 附录 图术语与习题提示（原书 pp. 267–287，英文 2e；中文版页次以实体书为准 🔧）

## 一、图论术语表（速查）

| 术语 | 含义 |
|---|---|
| 有向图 / 无向图 | 边是否带方向 |
| 邻接 / 关联 | 顶点相邻、边连接顶点 |
| 度（degree） | 关联边数；有向图分入度/出度 |
| 路径 / 简单路径 | 顶点序列；无重复顶点为简单 |
| 环 / 回路 | 起点=终点的路径 |
| 连通 / 强连通 | 无向可达 / 有向互相可达 |
| 树 / 森林 | 无环连通 / 多棵树的并集 |
| 生成树 / 最小生成树 | 含全部顶点的树 / 边权最小者 |
| 二分图 | 顶点可分两集、边只跨集 |
| 割 / 割集 | 删除后增连通分量数的边集 |
| 拓扑序 | 有向无环图的线性序，前驱在前 |

## 三、版本演进

- 原书术语表用纯文字；今天可配 `networkx` 的 `DiGraph`/`Graph` 对象即时验证（如 `G.is_connected()`）。

## 四、经典论文与原始文献

- 术语体系见 Bondy, J. A., Murty, U. S. R. *Graph Theory*, Springer, 2008（标准图论教材）。

## 五、近年研究与工业界前沿（2020–2026）

- 图学习（GNN）把传统图算法扩展到表示学习，属研究前沿（同行评审论文众多）；工业落地见 `pytorch-geometric` / `dgl`（非本书范围）。

## 六、常见误区与本书需修正之处

- 🔧 原书「有向图默认邻接表」即可；今天大稀疏图用 `scipy.sparse` 邻接矩阵更高效，稠密小图用 `networkx`。

## 七、跨语言对照

- 与 C++ 竞赛图模板相比，Python 版更短但常数大；教学与中小规模首选 Python。
