## 二、核心精讲

### 3.1 常用求和
- 等差：`Σ_{i=1}^{n} i = n(n+1)/2 = Θ(n^2)`。
- 等比：`Σ_{i=0}^{n} r^i = (r^{n+1}-1)/(r-1)`；当 `r<1` 时收敛到常数。
- 调和数：`H_n = Σ 1/i = ln n + γ + o(1) = Θ(log n)`。

### 3.2 排列组合（按 3.8+ 校准）
原书手写阶乘与组合数。今天直接用标准库：

```python
# 教学示意，不参与构建
import math

n, k = 10, 3
perm = math.perm(n, k)      # P(n,k)
comb = math.comb(n, k)      # C(n,k)，3.8+ 内置，无需自己写
print(perm, comb)
```

### 3.3 递归式展开
归并排序 `T(n) = 2T(n/2) + Θ(n)` 展开得到 `Θ(n log n)`；这是第 6 章的主角。

### 3.4 主定理
对 `T(n) = a·T(n/b) + f(n)`：比较 `f(n)` 与 `n^{log_b a}` 三档得出解。第 6 章分治、第 5 章遍历都靠它。

## 六、常见误区与本书需修正之处

- 🔧 原书手写的 `choose(n,k)` 在 `n` 大时易溢出或慢；今天一律 `math.comb`。
- 原书对「主定理不适用时的 Akra–Bazzi 法」着墨少；遇到非均衡分治（如 Karatsuba）需 Akra–Bazzi，建议补 [`具体数学`](../具体数学/00-总览与阅读地图.md)。

## 七、跨语言对照

- C++ 标准库无 `comb`/`perm`，需 `<numeric>` 手写或 Boost；Python 3.8+ 在此处更省心。
