## 二、核心精讲

### 10.2 Edmonds-Karp（BFS 找增广路）
```python
# 教学示意，不参与构建
from collections import deque, defaultdict
from typing import Dict, List

def edmonds_karp(cap: Dict[str, Dict[str, int]], s: str, t: str) -> int:
    flow = 0
    while True:
        # BFS 找一条增广路
        parent = {s: None}
        q = deque([s])
        while q:
            u = q.popleft()
            if u == t: break
            for v, w in cap.get(u, {}).items():
                if w > 0 and v not in parent:
                    parent[v] = u; q.append(v)
        if t not in parent:
            break
        # 沿路求瓶颈
        path = []
        v = t
        while v is not None:
            path.append(v); v = parent[v]
        path.reverse()
        bot = min(cap[path[i]][path[i+1]] for i in range(len(path)-1))
        for i in range(len(path)-1):
            u, v = path[i], path[i+1]
            cap[u][v] -= bot
            cap.setdefault(v, defaultdict(int))[u] += bot
        flow += bot
    return flow
```

### 10.3 最大流最小割
最大流值 = 最小割容量（核心定理，证明见 CLRS 26 章）。

### 10.4 二分匹配
建超级源/汇，边容 1，跑最大流即得最大匹配。

## 五、近年研究与工业界前沿（2020–2026）

- 工业级：直接用 `networkx.maximum_flow` / `max_flow`；超大图用 `igraph`。
- 推送-重标号（Push-Relabel）在稠密图上比 Edmonds-Karp 更快，属现代实现常识（非同行评审，算法教材共识）。

## 六、常见误区与本书需修正之处

- 🔧 原书残量网络用「反向边 +容量」实现；写错反向边更新会遗漏可撤销流量——务必 `cap[v][u] += bot`。
- Edmonds-Karp 是 BFS（最短路）增广；若用 DFS 退化为 Ford-Fulkerson 最坏 O(E·|f*|)，务必 BFS。

## 七、跨语言对照

- C++ 竞赛常用静态邻接表 + `vector` 存边与反向边（成对下标）；Python 用字典更直观但常数更大。
