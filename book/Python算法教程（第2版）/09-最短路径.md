## 二、核心精讲

### 9.1 Dijkstra（用 `heapq`）
```python
# 教学示意，不参与构建
import heapq
from typing import Dict, List

def dijkstra(graph: Dict[str, List[tuple[str, float]]], start: str) -> Dict[str, float]:
    dist = {start: 0.0}
    pq = [(0.0, start)]          # (距离, 节点)，heapq 最小堆
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float("inf")):
            continue
        for v, w in graph.get(u, []):
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

### 9.2 Bellman-Ford
支持负权边，检测负环；O(VE)。

### 9.3 Floyd-Warshall
全源最短路，O(V^3)，用邻接矩阵。

### 9.4 A*
`f = g + h`，启发式 `h` 可采纳则最优；常用于地图/网格寻路。

## 六、常见误区与本书需修正之处

- 🔧 原书 Dijkstra 用「已访问集合」提前退出；现代写法用 `if d > dist: continue` 惰性删除，更稳（重复入堆不漏解）。
- 🔧 Dijkstra 不能处理负权边——有负权必须用 Bellman-Ford；原书强调但易被忽略。
- `heapq` 只最小堆，最短路天然契合；最大生成树才需取负。

## 七、跨语言对照

- Java `PriorityQueue`、C++ `std::priority_queue` 默认最大堆，写 Dijkstra 要反转比较器——与 Python `heapq` 相反。
