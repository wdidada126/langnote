## 精读补写（系统整理，2026-09-23）

### 主线脉络（虎书 = Appel《Modern Compiler Implementation》）
一条自底向上的编译器主线：**词法分析**（正则 → NFA（Thompson 构造）→ DFA（子集构造）→ 最小化（Hopcroft/Myhill-Nerode））→ **语法分析**（递归下降/LL、LR(0)/SLR/LALR(1)/LR(1)，虎书强调用生成器与冲突消解）→ **语义分析**（符号表、类型检查、作用域与记录类型、函数式语言的类型推断）→ **中间表示**（树形 IR、三地址码、SSA）→ **数据流分析**（可达定义、活跃变量、可用表达式、常量传播；格上的不动点迭代，Kildall 1973）→ **循环优化**（支配关系、自然循环、循环不变量外提、归纳变量、强度削弱）→ **寄存器分配**（图着色 Chaitin 1982 / Briggs 乐观着色；线性扫描用于 JIT）→ **运行时系统**（栈帧、调用约定、堆管理、分代 GC）。

### 经典论文与原始文献根基
- Aho & Ullman《Principles of Compiler Design》(1977)、Aho/Sethi/Ullman《Compilers: Principles, Techniques, and Tools》(1986)——"龙书"，LR 与优化的系统化表述。
- Knuth《On the Translation of Languages from Left to Right》(Information and Control, 1965)——LR(k) 文法与移进-归约。
- DeRemer & Pennello《Efficient Computation of LALR(1) Look-Ahead Sets》(TOPLAS 1982)——yacc/bison 的 LALR 实用化。
- Kildall《A Unified Approach to Global Program Optimization》(POPL 1973)——数据流分析的格理论框架。
- Cytron, Ferrante 等《Efficiently Computing Static Single Assignment Form》(TOPLAS 1991)——**SSA 是现代优化器的地基**（LLVM IR 即 SSA）。
- Chaitin《Register Allocation via Graph Coloring》(1982)；Briggs《Improvements to Graph Coloring Register Allocation》(1992)。
- Muchnick《Advanced Compiler Design and Implementation》(1997)——优化细节的百科书。
- Appel 关于 GC 的工作："Simple Generational Garbage Collection and Fast Allocation"(Software P&E 1989)。

### 最新研究与产业进展
- **LLVM/MLIR**：LLVM IR + SSA 已成事实标准；**MLIR**（Lattner 等，2019，多层 IR dialect）把"编译"推广到 AI 加速器与领域专用编译，是当下最活跃的方向。
- **自动调度/自动向量化**：Halide（Adams 等，SIGGRAPH 2019 自动调度）、TVM/Ansor（Zheng 等，OSDI 2020）——用搜索+代价模型替代手写优化策略。
- **ML for Compilers**：Facebook CompilerGym（2021）、Google MLGO（2022，用 RL 做内联与寄存器分配决策，已进 LLVM）；"机器学习替代启发式"是当前论文热点（MLGO、AutoPhase、 LLVM-RL）。
- **多面体编译**（polyhedral model / PLuTo / Polly）用于循环变换与自动并行；**JIT 与 WASM**（Graal、Wasmtime、WASI）推动轻量沙箱执行。
- 中文实践对照：读虎书第 19 章循环优化时，可对照 LLVM `LoopPass`/`ScalarEvolution` 与 GCC 的 `tree-ssa-loop`。

### 常见误区 / 纠错
- 虎书按 **C / ML / Java 三种描述版本**出版，中文版多为 C 描述版；笔记引用章节时须注明版本，否则章节号错位。
- "SSA 只是一种表示"是保守说法——现代优化（GVN、SCCP、循环优化）都建立在 SSA 之上，虎书写于 SSA 普及之前，实践应结合 LLVM/GCC 的 SSA 管线理解。
- "图着色一定最优"不成立：图着色是 NP-hard，实际用启发式（Chaitin-Briggs）或线性扫描（JIT 场景权衡编译时间）。
