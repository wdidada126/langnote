# 《Programming TypeScript》——总览与阅读地图

> 目标书：*Programming TypeScript*，Boris Cherny（Facebook/Stripe，ts-morph 作者——谱系佐证 ⚠️ 以版权页为准），O'Reilly，2020，ISBN ⚠️9781492052187（凭记忆，未破墙）。
> 第三方书目表配对成立 ✅；本书 2020 年写作，覆盖 TS 4.x 前语义——模板字面量类型等 4.1+ 机制**不在书内**，读时按总索引概念清单补位。

## 一、定位

主干书：**类型系统作为一门小语言来讲**（类型运算符、类型层级 `any/unknown/never`、对象/函数/泛型的组合代数）。对 C++ 模板背景读者，这是全目录里「类型级思维」迁移成本最低的一本——它的类型代数章与 `C++20模板元编程/` 同构。

## 二、骨架（⚠️ 部名/章名凭记忆，以版权页为准）

| 部 | 主题带 | 本仓高价值点 |
|---|---|---|
| Ⅰ Getting Started | 类型注解基础、类型检查器工作位置 | 「类型只在编译期存在」首次点破——擦除专题书内锚点 |
| Ⅱ Type Systems | **类型运算符/类型层级/结构化类型** | 全书精华：any→unknown→never 层级、交叉=∩、联合=∪ 的集合代数 |
| Ⅲ Objects and Interfaces | 对象类型、接口、泛型约束 | 结构子类型判定流程 ↔ Java 名义子类型对照档 |
| Ⅳ Functions | 重载、条件式返回、`this` | 函数类型双向协变/逆变规则（strictFunctionTypes 实测位） |
| Ⅴ Combinations | 联合/交叉/异构数组/映射 | 分发式条件类型前夜——接 Type-Level TS |
| Ⅵ Appendix | 类型检查器内部、编译器配置 | 实现线跳板：接 TypeScript_Compiler_Notes/官方源码 |

## 三、读法

Ⅱ 部慢读并全集合抄类型代数表；Ⅰ/Ⅲ 快速过（Learning TS 已覆盖）；Ⅴ 部读完立即转 [../Type_Level_TypeScript/00-总览与阅读地图.md](../Type_Level_TypeScript/00-总览与阅读地图.md)。附录「类型检查器内部」是本仓实现线的第一块砖。

## 四、🔧 实测口径

- 类型层级实验：`unknown` 窄化链、`never` 穷尽检查（switch exhaustiveness）——`tsc --noEmit` 断言报错文本；本机 strip-types 只可跑不可报错 ⚠️。
- 协变/逆变反例：方法语法 vs 属性语法双关参数赋值，配对写「预期报错/实际报错」表。
