# 《Programming TypeScript》章笔记 02 · 类型系统的代数

> 对照骨架部号：**Ⅱ Type Systems**——00 总览裁定全书精华、慢读位（⚠️ 章名凭记忆）。
> 本书 2020 年写作：`unknown`（3.0）、`never` 穷尽惯用法在书内；模板字面量类型（4.1）、`satisfies`（4.9）等**超书范围**。

## 核心机制（本档重头：类型=集合的全代数表）

**公理**：类型是「值的集合」，subtype = 子集，`A extends B` 读作 `A ⊆ B`。全部运算可在这一模型内重演：

- **层级三极**：`any` = 顶且**带逃逸**的顶（既是超集又允许任意成员进出，不健全）；`unknown` = 真·健全顶（`∀T: T ⊆ unknown`，进来容易出去难——使用前必须窄化）；`never` = 空集⊥（`∀T: never ⊆ T`，任何函数的返回都可细分为 never）。链条 `never ⊂ T ⊂ unknown`，`any` 与链条平行脱钩。
- **联合 = ∪（并集）**：`A | B` 的成员属于 A 或 B；窄化 = 与某子集求交的过程（类型守卫是「集合过滤器」）。判别联合把并集做成**运行时可辨认的不交并**——tag 字段是擦除世界里自己编码的类型信息（专题戒律 3）。
- **交叉 = ∩（交集）**：`A & B` 对属性逐条取交，对象交叉 = 属性合并；`number & string` 是空集（字面量层可判），这暴露纯集模型的极限——检查器对原始类型交叉不做结构求解 ⚠️（书中口径，报错面需 tsc）。
- **字面量类型 = 单点集**：`1`、`"a"`、`true`；`1 | 2 | 3` 是有限集——枚举的集合论正身。
- **分配律**：`Array<A|B>` ≠ `Array<A>|Array<B>`（函数位置不分配），而对象/交叉对联合的分配成立——05 章映射类型的入口。

**C++ 对照（跨域主表）**：

| TS 集合代数 | C++20 对偶 | 机制差异一句话 |
|---|---|---|
| `A extends B`（子类型谓词） | concept 满足集 `{T: C<T>}` | TS 谓词内建于赋值规则；C++ 谓词要自己具名（[../C++20模板元编程/06-概念和约束.md](../C++20模板元编程/06-概念和约束.md)） |
| `keyof T` / 类型查询 | type trait（`is_enum_v` 等） | 同为「对类型求值的编译期函数」（05 章对偶） |
| `unknown` 必窄化 | `void*`/`std::any` 必显式还原 | 都是健全顶：进得去出不来，还原错了 C++ 是 UB、TS 是运行时炸 |
| `never`（空集返回） | ill-formed/`static_assert(false)` | TS 用可达性分析、C++ 用实例化失败表达「不可能」 |
| `any` | **无对偶** | C++ 类型层没有顶类型；最近似是绕过类型的模板文本替换——这正是两族语言的断裂点 |
| 联合 `A|B` | `std::variant<A,B>` | variant 是**值的带标签和**（运行时留存判别）；TS 联合擦除后标签必须手写进数据 |

## 批判读法

- 书中把 `any` 译作「escape hatch」而非「类型系统缺陷清单」——反读法：每见 `any` 记一笔「此处集合代数断裂」，全书读完即得个人版不健全点账本（配对 Effective 2e 规范线）。
- 「类型=集合」叙事掩盖了两个 flag 依赖：`strictNullChecks` 关时 `null/undefined ∈ 一切类型`（集合论全盘变形）；`strictFunctionTypes` 改的是箭头参数位置的子集定义（04 章主场）。**先固定 strict 全开再读本章代数表**，否则抄下来的表在默认配置下不成立。
- 交叉的「∩」直觉对函数出错：`(A=>C) & (A=>B)` 的交集语义检查器并不按集合求交处理重载候选——见 04 章。

## 🔧 微实验

实验 1 ✅（`/tmp/tsexp/e3_algebra.ts`，exit=0）：∪ 的运行时投影=tag 分派 + `never` 穷尽位的 throw 替身；`as` 撒谎对机器无效：

```ts
type Shape = { kind: "circle"; r: number } | { kind: "square"; s: number };
const area = (x: Shape): number => { switch (x.kind) {
  case "circle": return Math.PI * x.r ** 2;
  case "square": return x.s ** 2;
  default: throw new Error("unreachable"); } };  // never 位的运行时代码
const n = "7" as unknown as number;
console.log((n as any) + 1, typeof n);
```

实测输出：`area circle: 3.1416` / `area square: 9` / **`n+1 = 71`** `typeof = string`——断言链不转换值，集合代数对运行时零干预。

实验 2 ✅（`/tmp/tsexp/e4_unknown.ts`，exit=0）：`unknown` 的「出来必窄化」在运行时只剩手写守卫：`typeof x === "number"` / `Array.isArray(x)` 逐一放行，输出 `num 42 | arr len 3 | other string`——守卫函数是检查器词汇表在 JS 里的**唯一合法移民**。

不可实测位 ⚠️：`number & string` 空集报错、穷尽检查缺分支报错——均为检查器面，本机无 tsc，不得引为实测。
