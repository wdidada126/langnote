# 《Programming TypeScript》章笔记 05 · 组合类型与映射类型

> 对照骨架部号：**Ⅴ Combinations**（⚠️ 章名凭记忆；00 总览判带：联合/交叉/异构数组/映射，「分发式条件类型前夜」）。
> 书 2020 年止：键重排 `as` 子句（4.1）、模板字面量类型（4.1）、`satisfies`（4.9）**全部超书范围**——本档涉及处只给方位注记，不代书立说。

## 核心机制

- **组合阶梯**：联合（∪）× 交叉（∩）× 元组 × 映射，四级搭起「类型级程序」的语法层。判别联合在 02/03 已铺；本章新增的关键形状：
  - **异构数组与元组**：`[string, number]` 是**有限积**（位置即键），`Array<string|number>` 是无限和——`T[0]` 索引访问取回分量，等于对积做投影函数。
  - **索引访问 `T[K]`**：类型层的下标运算，`keyof`+`T[K]` 合成「枚举成员再取值」——02 章 trait 对偶的最实用组合拳。
  - **映射类型** `{ [K in keyof T]: F<T[K]> }`：**对类型的每个键做一次 foreach**，`K in keyof T` 是类型级循环变量。标准库五件套 `Partial/Pick/Record/Omit/Readonly` 全部由它拼出（`Omit = Pick<T, Exclude<keyof T, K>>`——库编码而非语言原语，注意层级）。
  - **同态（homomorphic）性**：形如 `[K in keyof T]` 的映射**继承原键的可选/readonly 修饰符**——这是 TS 映射类型区别于朴素「类型变换」的独有约定；C++ 无对偶（trait 变换要自己逐层重加 cv 限定），读时把这条当「编译器帮你做了 ref-qualifier 传播」。
- **分发式条件类型**：`T extends U ? X : Y` 遇裸联合自动按成员分发（`F<A|B> = F<A>|F<B>`）——书中讲到边界即止，纵深全部让位给 Type-Level TS（00 总览裁定的「立即转档」点）。
- **C++ TMP 对照总表**：

| TS 本章机制 | C++20 对偶 | 差集裁定 |
|---|---|---|
| 映射类型 foreach | `std::tuple` 上的 trait 变换/`index_sequence` 展开 | 同构；TS 语法原生化，C++ 靠库花招 |
| `keyof T` 枚举键 | 无（静态反射缺位，P2996 在路上） | **TS 领先位**，反直觉，如实登记 |
| 条件类型+分发 | `if constexpr` / 特化+重载决议 | 分发≈参数包展开的语义版（03 章对偶） |
| `infer` 模式提取 | 特化偏序匹配抽实参（`Extract<T,U>` 手搓） | Type-Level 主场，书内只露哨 |
| 元组类型 | `std::tuple` | TS 元组可变长操作（concat/spread）多 |

## 批判读法

- 「映射类型强」的另一面是**它纯在类型层**：`Partial<T>` 不生成新对象、不删属性、不造代理——一切形状变换若要在运行时成立，必须**另写一份值层函数**与之配对（✅ 实验）。这是全书对 C++ 读者最反直觉处：TMP 的 trait 变换「生成」了真实类型实体，TS 的映射只「描述」了一个检查器口径。
- 书内 `Omit` 讲法（若出现）依赖 3.5+ 库定义——版本考古位：以书内实际给的库源码片段为准，勿以现 lib 回灌 ⚠️。
- 组合爆炸警告（书内/社区共识 ⚠️ 混标）：联合×交叉×映射嵌套后错误信息不可读，等价于 C++ 模板错误墙；工程上「先 Probe 后体操」。

## 🔧 微实验

实验 ✅（`/tmp/tsexp/e7_mapped.ts`，node v22.14.0 `--experimental-strip-types`，exit=0）：映射类型=检查器口径的形状重描述，运行时对象**同一性不变**；真删属性必须手写值层变换：

```ts
type Full = { a: number; b: string };
const v: Full = { a: 1, b: "x" };
const p: Partial<Full> = v;
const q = v as Pick<Full, "a">;           // as：不删属性、不复制
console.log(p === v, q === v, Object.keys(q));
const actualPick = <T extends object>(o: T, k: string): object => {
  const out: Record<string, unknown> = {};
  for (const key of Object.keys(o)) if (key === k) out[key] = (o as any)[key];
  return out; };
console.log(JSON.stringify(actualPick(v, "a")));
```

实测输出：`true true [ 'a', 'b' ]` / `{"a":1}`——`Pick` 后的 `q` 仍带 `b`（`as` 撒谎面），手写函数才给出真子集对象。「类型层 foreach ≠ 值层 foreach」一屏证毕。

不可实测位 ⚠️：同态修饰符继承、分发律的报错/推断面均为检查器现象，无 tsc 不引为实测。
