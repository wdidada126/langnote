# 《Programming TypeScript》章笔记 04 · 函数与协变逆变

> 对照骨架部号：**Ⅳ Functions**（⚠️ 章名凭记忆；重载/条件式返回/`this` 主题带见 00 总览）。
> 书 2020 年止：`strictFunctionTypes`（2.6 起入 strict 家族）在书内；**variance 标注 `in`/`out`（4.7）超书范围**，涉及处只作方位注记。

## 核心机制（本档重头：双关 vs 逆变的机制分岔）

- **子类型规则的形状**：`(A) => B` 对参数**逆变**、对返回**协变**。直觉证明：需要 `f: (Dog) => void` 时，喂 `(Animal) => void` 安全（它吃得更宽），喂 `(Cat) => void` 危险（Dog 进来它咬不住）。返回侧对偶：产出更窄者可替换产出更宽者。
- **TS 的历史伤疤与现行规则**：默认（`strictFunctionTypes` 关）参数按**双变（bivariant）**放行——为 OO 回调人体工学让的不健全路；strict 开启后，**函数类型写法**的参数转真逆变，**但方法写法永远双变**。
- **方法语法 vs 属性语法：同物异名在运行时、同名异物在检查器**。机制差异要钉死：JS 层 `m(x: T): void {}` 与 `m = (x: T): void => {}` 擦除后同形（✅ 见实验）；差异**纯住在检查器对 AST 记号的判决里**——assignability 关系处理签名时携带「此符号是 method 还是 property」的标志位，method 标志位把参数 variance 切回双变。豁免动机是 DOM 事件面（`addEventListener` 族）与旧 lib.d.ts 的兼容雪崩，不是类型学理由。
- **重载**：候选按**书写顺序**择优（首个匹配胜出），不是最特定优先——与 C++ 重载决议「最匹配优先」机制相反，跨域读者第一大坑。交叉类型伪装重载 `((A)=>R & (B)=>R)` 书中出现但已被官方口径弃用 ⚠️。
- 条件式返回（`T extends X ? R1 : R2`）在函数签名为 05 章分发式条件类型埋线；`this` 形参（`void function(this: W)`）是给「检查器想象调用对象」用的匿名约束，运行时同样零痕迹。
- **C++ 对照定位**：C++ 函数指针/模板参数是**不变（invariant）**的——`void(*)(Animal)` 不能替 `void(*)(Dog)`，因为 C++ 无子类型关系可谈；「逆变」在 C++ 侧显形为概念约束下的替换规则（写 `C(auto)` 收紧约束=逆变方向的替换许可）。TS 数组协变不健全（`Dog[] → Animal[]` 塞 Cat 无险）对应 C++ 模板不变恰是安全解。

## 批判读法

- 本章最值钱的一句不是任何定义，而是**「方法/属性双规则」这一事实本身**：它证明 TS 子类型表不是一张纯语义表，而是背着向后兼容包袱的判例法。读法：凡遇 variance 结论，先问「strict 开没开、写成 method 还是 property」，三问齐了才落子集关系。
- 书中「bivariance 是妥协」的调子偏轻描淡写——反读账本：方法豁免至今是 `tsc --strict` 下最大的静默不健全面之一（EventEmitter 系回调炸单来源），Effective 2e 有对应规范条目配对读。
- 重载顺序规则拿反例自测：先写宽签名再写窄签名，检查器会「选中错的却全绿」——这是纯检查器现象，运行时无从察觉（分发已手写）。

## 🔧 微实验

实验 ✅（`/tmp/tsexp/e6_fn.ts`，node v22.14.0 `--experimental-strip-types`，exit=0）：两种语法擦除后**在 JS 层不可区分**，variance 差异只能是检查器内部记号：

```ts
class Holder { m(x: string, y?: number): void {} }
const prop = { m: function (x: string, y?: number): void {} };
console.log(Holder.prototype.m.length, prop.m.length);
console.log(Holder.prototype.m.toString().replace(/\s+/g," "));
console.log(prop.m.toString().replace(/\s+/g," "));
```

实测输出：`2 2` / `m(x , y ) {}` / `function (x , y ) {}`——只剩函数体外壳词不同，注解全灭；`fn.length` 数到可选参数为止（无默认值即计数，默认值起截断——JS 原生规则，类型无关）。

不可实测位 ⚠️：「方法语法逆变反例全绿 / 属性语法反例报错」的配对报错表是检查器面，本机无 tsc，只登记为预期（专题口径：配对写预期报错/实际报错表，待补）。
