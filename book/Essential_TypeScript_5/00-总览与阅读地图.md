# 《Essential TypeScript 5》——总览与阅读地图

> 目标书：*Essential TypeScript*（"5" 对应 TS 5.x 覆盖版次），Adam Freeman（Pro/Apress 系高产作者 ✅ 谱系公认；本版次序与首印年份 ⚠️），Apress，约 2023–2024，ISBN ⚠️待核验。
> 佐证：高校图书馆藏有 "Essential TypeScript" 各版 MARC 记录 ✅（存在性直证）；具体版次对位（Essential TypeScript 4 → 5 的编号口径）待购书页销账 ⚠️。

## 一、定位

**大而全参考书位**：Freeman 体例=长例程渐进重构贯穿全书（同一 ASP.NET/示例工程反复加类型），厚度大、覆盖面全。本仓不线性读，定位为「机制细节仓库」：主线书遇到讲不清的开关/边角语法来回查本章档。第三方书单把它排进阶路线属重量错配 ⚠️——采纳为参考书而非主干。

## 二、骨架（⚠️ 部名凭 Freeman 惯例与记忆，以版权页为准）

| 部 | 主题带 | 本仓查表场景 |
|---|---|---|
| Ⅰ JS 底座与工具链 | ES6+ 回顾、编译器/打包器环境 | 环境配置速查（本仓已 node 直跑，价值低） |
| Ⅱ 类型系统全项 | 基础类型→泛型→高级类型逐个长例程 | 某机制「最完整写法」来这查 |
| Ⅲ 应用集成 | 类、装饰器、模块、Angular/React/Vue 集成 | 框架集成带（本仓画像后端为主，Angular 章低优先） |
| Ⅳ Node 与服务端 | Node.js + TS、Express 例程 | 与用户后端线接口位 |
| Ⅴ 配置与部署 | tsconfig 全项字典、构建流 | **tsconfig 字典章=本系列最全单点** ⚠️ |

## 三、读法

Ⅴ 部 tsconfig 章先建「开关→报错形态」表（配 🔧 实测）；其余按需查。装饰器章注意语义版本断裂：实验装饰器 vs 标准 Stage-3 装饰器两制并存 ⚠️ 书中覆盖到哪版以目录销账。

## 四、🔧 实测口径

tsconfig 字典逐项：固定样例集 × 单开关开/关 → 记录报错增量（`tsc --noEmit` 依赖安装 ⚠️）；Node 服务端部例程可用 `--experimental-strip-types` 面跑通部分 ✅（纯擦除语法内）。
