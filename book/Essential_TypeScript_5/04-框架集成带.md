## 三、🔧 微实验（本波真跑 4 条 + 设计 2 条）

1. `elide.ts`（strip）→ `import-type-elided: true unused-value-import-still-loaded: function` ✅ —— `import type` 是**纯语法擦除**（连模块存在性都不查），未使用的**值** import 仍在运行时被加载：接线纪律全靠编译期，运行时零保护（专题档公理的框架侧现形）。
2. `json.ts`（strip 与 `--experimental-transform-types`）→ `attr-import: 42 readfile: 42` ✅ —— 无 bundler、无 `resolveJsonModule` 时，JSON 导入用 import attribute 或 `readFileSync` 双路皆通。
3. `shim.ts`（strip）→ `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX ... import equals declaration is not supported in strip-only mode` ✅ —— CJS 互操作老写法在本仓运行面被禁，接线一律 `import`/`export`。
4. `fw/vue.mts` → `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'vue'` ✅ —— 框架包不可解；本带例程的「跑通」上限是 `node:*` 内置模块（见 `srv.mts`，归 ./05-Node服务端与tsconfig全项字典.md）。
5. 设计（需真 tsc + 依赖，本波关闭 ⚠️）：装 React 后 `FC<Props>` 与手写 `(p: Props) => JSX.Element` 的产物 diff；装 Vue 3 后 SFC 宏（`defineProps<T>`）编译产物阅读。
6. 设计（零依赖可行 ✅ 待第 3 波）：纯 `.ts` 化的「mini 中间件链」泛型类（`mw.ts` 已跑通：`chain: {"body":"HI!"}`、私有字段运行时可见性另查）作为框架接线不可用时的**替身实验台**。
