## 核心机制

### 运算符 = 命名约定的静态派发

- `a + b` 转调 `a.plus(b)`，成员或扩展函数均可充当实现，须 `operator` 修饰（✅）。对照 C++：真运算符重载还能碰 `operator new`/用户字面量——Kotlin 集合小得多：无赋值运算符重载、无自定义优先级（✅）。对照 Java：零对位（String `+` 是语言特例），所以区间/解构这套"普通函数重定义语法"在 Java 全部降级成方法调用。
- 约定簿：`a[i]`→`get/set`、`x in y`→`contains`、`a..b`→`rangeTo`、`!x`→`not()`、解构→`componentN()`（✅）；注意 **componentN 不要求 operator**（✅ 官方口径）。
- `for (x in xs)` 走 `iterator()` 约定而非 Iterable 接口（✅）——自定义 `operator fun iterator()` 任意类型进 for；`by` 惰性序列、`.use{}` 同族（✅）。JS 对照：`for...of` 认 Symbol.iterator 协议——两家都是"语法位背后挂一个众所周知的函数名"，Kotlin"约定优于关键字"路线与 JS 最相像的一处。

### invoke、infix 与优先级账本

- `operator fun invoke(...)` 让对象可调用：`myRouter("path")`（✅）；函数类型值即 invoke 契约实现。C++ functor/operator() 直系对位；Java 无（Function.apply 要点名）。DSL 地基见 [08 册](08-DSL构建.md)。
- `infix fun` 三约束：标注 infix、单参数、无默认值（✅）。优先级表焊死在语言里（✅）：elvis 与 `||/&&` 同层、具名 infix 调用低于比较——`"a" + "b" to 1` 是标准库 `to` 的经典括号省略陷阱；C++ 可自定义运算符但优先级不可改，两家都拒绝把优先级交给库作者。
- 相等契约：`==` 调 equals、`===` 引用相等（✅，01 册重申）；`Comparable` 喂 `< >` 约定（✅）。

### 语言细节杂项

- try/catch/finally 皆表达式，try 块尾表达式即返回值、finally 不参与（✅）；try-with-resources 对位 `.use{}` 扩展（✅，异常抑制语义同 JVM）。
- `@JvmName` 平台名补丁：`val isSuccess` 与成员 `isSuccess()` 访问器撞名、仅返回类型不同的重载 JVM 签名冲突，两类"编译过、链接炸"靠它解（✅）。
- `typealias` 不建新类型、不参与方差（✅）；TS 的 type 别名同为纯别名且擦除后零残留——"别名不是类型"两家同律。

## 批判读法（易错与存疑）

1. **运算符不是接口**：`plus` 是约定名不是 Plus 接口（✅），"可加性"无法作泛型上界传递（`T + T` 在 `T:Num` 写不出）；C++ concepts 可约束表达式合法——Kotlin 操作符约定在泛型语境是哑的（reified 特例存在理由之一，[06 册](06-泛型.md)）。
2. **扩展运算符静态派发**：给 String 加 plus 不改成员集，接收者静态类型定胜负（✅，02 册扩展陷阱同型）。
3. **同名不同约定**：`map["k"]=v` 走两参 `setValue`，委托属性走 (thisRef, prop, value) 三参 `setValue`（✅）——抄代码先认签名。
4. **中缀滥用**：中缀适合 DSL/集合代数不适合业务动词；`user follows topic` 读顺但可搜索性差——书中立场核对点 ⚠️。
5. **`+=` 复刻 03 册陷阱**：assign 走 plus 再赋值，只读 List 循环累加即 O(n²)（✅）。
6. 2e 是否并入 1.9-2.x 新糖（data builder、context parameters，✅ 存在性按版本口径 ⚠️ 收录未核）⚠️。

## 核心概念中英对照

- **约定** — convention：函数名（plus/get/componentN）触发语法位。
- **运算符重载** — operator overloading：`operator` 标注的命名函数。
- **中缀函数** — infix function：单参数无默认值的中缀调用糖。
- **可调用对象** — invoke convention：`obj()` 转 `obj.invoke()`。
- **迭代器约定** — iterator convention：for-in 走 `iterator()`。
- **平台改名** — @JvmName：JVM 签名层重定向，规避链接冲突。
- **类型别名** — typealias：不建新类型的命名重定向。
