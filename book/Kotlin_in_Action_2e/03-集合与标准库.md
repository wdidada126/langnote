## 核心机制

### 只读 ≠ 不可变：接口层二元划分

- Kotlin 把 `List/Set/Map`（只读视图）与 `MutableList/MutableSet/MutableMap` 拆成同层级两组接口，Mutable 继承只读（✅）。
- 对照 Java：JDK 只有一个 `java.util.List`；`Collections.unmodifiableList` 是防御视图（原集合被改照样穿透，✅），Java 9 `List.of` 才真不可变且拒 null（✅）。Kotlin `listOf` 的"只读"**只是编译期契约**，运行时可能就是个 ArrayList，类型层拿不到 mutate 入口而已（✅）。
- TS 对照：`Object.freeze` 浅冻结是运行时事实；Kotlin 只读是类型层事实、运行时零强制——两家在"不可变由谁担保"上分居光谱两端。
- 互操作红线（✅）：Kotlin `List<T>` 编译后即 `java.util.List<T>`，无包装层；传引用给 Java 后对方 `add`，"只读"即破。`toList()/toMutableList()` 各重载复制语义需按版本核实，不是一句"总是拷贝"。

### 构造、转换与拷贝

- 工厂 `listOf/setOf/mapOf/pairOf`；`arrayOf(1,2)` 是装箱 `Array<Int>`，`intArrayOf` 才是原生 int[]（✅）——`Array<IntArray>` 与 `int[][]` 的维度错位是 Java 老兵头号坑（✅）。
- `+`/`plus` 生成新集合（复制语义，✅）；循环里对只读 List 反复 `+=` 是 O(n²) 复制陷阱（✅），对照 C++ `push_back` 均摊 O(1)：Kotlin 的函数式加法没有自动 fusion 兜底。

### Sequence：惰性迭代一等公民

- `Iterable` 集合操作每步生成中间集合（✅ eager）；`asSequence()` 切单遍惰性（✅）。对照 Java Stream：同惰性但绑 Spliterator/close/并行池；Sequence 本质是 Iterator 生产器函数（✅），且可多次消费（每次重跑 producer），Stream 终端后即耗竭（✅ JDK 口径）。C++ 对位 ranges view 管道（../C++20模板元编程/09-范围库.md）。
- 无限源：`generateSequence(seed){...}` + `take/first` 短路（✅），对位 `Stream.iterate`。

### 标准库操作词汇表（Java 无糖位的高频件）

- `mapNotNull`（过滤+解包一步）、`groupBy`、`associateBy/associateWith`、`partition`、`zip/unzip`、`chunked/windowed`（✅）。
- 选择器排序 `sortedBy { it.age }` 顶掉 `Comparator.comparing(Person::getAge)` 脚手架，`thenBy` 链式组合（✅）。
- 聚合 `sumOf{}`、`maxByOrNull`（空集返回 null 而非抛异常——可空类型把 `Optional.orElseThrow` 的抉择前移进类型，✅）。

## 批判读法（易错与存疑）

1. **"只读"当"不可变"讲**：读集合章要盯它是否点破 List≠Immutable（1e 明言视图，✅ 记忆）；含糊带过即教材缺口。
2. **Sequence 不是免费午餐**：小集合上迭代器构造/装箱开销常输给直接 for 循环，书中基准结论凭记忆 ⚠️ 需复验。
3. **重放语义漂移**：同一 Sequence 多次消费会重跑副作用，Iterable 版只跑一遍；两边输出不一致不是 bug 是设计。
4. **`to` 不是关键字**：`mapOf("a" to 1)` 的 to 是 infix 构造 Pair；`"a" to "b" to 1` 省括号即错（✅）。
5. **null 键值规则照单全收**：mutableMapOf 背后混进 ConcurrentHashMap 时 put null 直接 NPE（✅ JDK 行为），`MutableMap<K, V?>` 声明给不了运行时保证。
6. 2e 集合章是否新增并发集合/新标准库小节 ⚠️ 未核。

## 核心概念中英对照

- **只读视图** — read-only view (`List`)：编译期契约，非运行时不可变。
- **可变集合** — mutable collection (`MutableList`)：同层级可写接口。
- **序列** — `Sequence<T>`：单遍惰性迭代管道，对 eager Iterable。
- **中间操作** — intermediate operation：filter/map 类惰性步骤。
- **选择器排序** — sort by selector：`sortedBy` 以 key 函数代 Comparator。
- **配对中缀** — `to`：infix 造 Pair，`mapOf("k" to v)` 地基。
- **装箱数组** — `Array<T>`：泛型位装箱；`IntArray` 才是原生 int[]。
