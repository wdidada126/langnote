# 《Kotlin in Action, 2nd Edition》——总览与阅读地图

> 目标书：*Kotlin in Action, Second Edition*，Manning，2024，约 560 页，ISBN **9781617299605**（✅ 用户提供并载于 Manning 官方书页）。
> 作者署名线：Sebastian Aigner、Dmitry Jemerov 等（⚠️ 完整名单以版权页为准；**第三方 AI 结论所称"含 Roman Elizarov"未获证实，不写死**）。
> 第一版（2017，ISBN 9781617293290 ✅）无现代协程内容，降级为参考书。
> 本目录 = 全书骨架 + 面向 Java/C++ 工程师的阅读路线；分章档 01–NN 待第 2 波展开。

## 一、为什么它是主线第一优先

- 作者是 Kotlin 语言设计/核心开发者一侧的人（Jemerov：JetBrains，Kotlin 早期负责人线 ✅），语法解释直抵设计动机，不是 API 复述。
- 2e 相对 1e 的增量恰是本画像最需要的：**Coroutines、Structured Concurrency、Flow、Flow operators、错误处理与测试**（✅ 用户提供的 Manning 页结论）。
- 官方推荐书目页在列 ✅。

## 二、结构（部—章骨架，⚠️ 章号/章名以版权目录为准，本表凭官方 TOC 记忆整理）

| 部 | 覆盖 | 对应本仓读法 |
|---|---|---|
| Ⅰ Kotlin 基础 | what/why、词法、类型与变量、控制流、函数、lambda、集合与标准库 | Java 工程师可 1.5x 快跑；重点记 null 安全与智能转换差异 |
| Ⅱ 面向对象与惯用法 | 类、属性与委托、data/sealed/枚举、运算符、泛型、注解 DSL | **泛型方差 ↔ C++ 模板无协变**、`in/out` 对照 Java `? extends`；scope functions 集中营 |
| Ⅲ 高级主题与并发 | 互操作、DSL、反射、**协程四章+（14–18：Coroutine/Structured Concurrency/Flow/operators/错误与测试，✅ 用户提供的章节范围）** | 本系列的协程主教材；C++20 co_await 对照位 |

## 三、互操作章的必读坑（Ⅲ 部）

nullability 注解映射、platform types、`@JvmStatic/@JvmOverloads`、可变参数/数组映射、函数类型 ↔ SAM、集合与不可变视图、`suspend` 对 Java 不可见（kotlinx-coroutines-jdk8 Future 桥 ⚠️ 具体模块名以书中为准）。Spring/JPA/Jackson 场景的坑在 `Spring系列·总索引.md` 路线处续。

## 四、协程阅读路线（与官方文档并读）

```
Thread/Executor → suspend → CoroutineContext/Dispatcher/Scope/Job
→ Structured Concurrency → Channel → Flow(cold/State/Shared)
```
书中模型 + `kotlinx.coroutines` 源码 + Elizarov 官方 guide（⚠️ 篇名不写死）三角对读。

## 五、🔧 实测环境（本仓口径）

- JDK + IntelliJ/gradle Kotlin DSL；`kotlinc` REPL 快验（Windows，衔接 `notes/mingw.md` 同级的 PATH 习惯）。
- 每章微实验原则：单文件 main + 断言输出；协程实验用 `runBlocking`/`delay` 打印调度线程名，验证 Dispatcher 语义——第 2 波分章时逐章落 `NN-章名.md` 附实验。
