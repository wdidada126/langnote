## 核心机制

### data 类：编译器代劳的样板

- `data class User(val name: String, val age: Int)` 合成 equals/hashCode/toString/copy/componentN 五件套（✅），**仅主构造器属性**参与相等判定，body 里的 var 不算（✅）。Java record（JDK16）全字段参与、无 copy、不可 var（✅）——边界差是迁移面试级细节；C++ 聚合体+`=default` 凑不出 copy 与解构。
- `copy()` 是**浅拷贝**（✅）：嵌套引用共享；data 属性可声明 `var`（✅ 合法但毁值语义）——语言给语法不给纪律。
- `componentN` 解锁解构 `val (name, age) = user`（✅）。TS 对照：JS 解构 `{a,b}=obj` 按属性名结构操作，Kotlin 解构按位置的协议调用，改名安全与否的判据完全不同。
- 禁区（✅）：不能 abstract/open/inner；主构造至少一个参数。

### sealed / value：代数并与零成本壳

- `sealed class/interface` 限定直接子类集合（✅）→ when 穷尽免 else（✅，衔接 [01 册](01-语言基础与结构.md)）。类型层"有限并"：TS 判别联合 `{kind:"a"}|{kind:"b"}` 结构同解，但 TS 擦除后运行时只剩普通对象（见 ../TypeScript系列·Runtime_vs_Type_System专题.md），Kotlin sealed 在 JVM 留类结构。C++ 对位 `std::variant`+`std::visit`：穷尽同强制，声明分散、无语言级 when。
- `@JvmInline value class`（✅ 1.5 转正）：单属性零包装（泛型位/可空位退化装箱），`@JvmName` 收拾 mangled 签名。C++ strong typedef 惯用法的第一等公民化；Java Value Types（JEP 方案）未落地，Kotlin 先行。

### 委托：把协议实现外包

- 属性委托 `var x by Delegates.observable/lazy/Map`（✅）：访问转调 `getValue/setValue` **约定**（operator 函数，见 [07 册](07-运算符重载与语言细节.md)）；`by lazy` 默认线程安全（✅ LazyThreadSafetyMode）。Java 要 AspectJ 或手写监听器；C++ 靠 CRTP 代理——皆非语言内建。
- 接口委托 `class Derived(b: Base) : Base by b`（✅）：编译器生成全部转发方法，GoF 装饰器的语法糖位；只转**接口声明的成员**，实现类自有成员不暴露（✅）。
- Map 委托（✅）支撑动态字段薄封装（JSON）；扩展属性无 backing field 所以带状态必须走委托（[02 册](02-函数与Lambda.md) 易错点 5 兑现）。

## 批判读法（易错与存疑）

1. **data ≠ 值语义全对**：集合字段走 List.equals 逐元素（✅），可变字段改后哈希桶漂移照旧（✅ JVM 契约）；书中若讲成"自动正确"要打折。
2. **copy 浅坑**：忘了 `tags = old.tags.toMutableList()` 两实例共享同一 MutableList（✅），与 record 的 with 同病。
3. **componentN 顺序耦合**：解构按位置，属性重排即静默错值（✅）；往主构造加参数破坏构造签名（✅）。
4. **sealed 穷尽的代价**：新增子类令下游 when 编译失败——升级即破坏性变更，与 Java sealed+pattern matching 同一权衡（✅）。
5. **lazy 循环初始化**：`by lazy` 体内互引兄弟 lazy 属性成环时栈溢出而非编译错（✅ 机理，未实测）。
6. 2e 对 value class/data builder（1.9 实验，✅ 版本线 ⚠️ 细则）收录深度未核。

## 核心概念中英对照

- **数据类** — data class：合成五件套的浅语义值载体。
- **复制** — `copy()`：浅拷贝命名参数变异构造。
- **解构声明** — destructuring：`val (a,b) =` 走 componentN。
- **密封类** — sealed hierarchy：穷尽并类型，when 免 else。
- **值类** — value class（`@JvmInline`）：单属性零包装壳。
- **属性委托** — property delegation：`by` 转调 getValue/setValue。
- **接口委托** — interface delegation：`by` 生成转发，装饰器糖。
- **惰性属性** — `by lazy`：线程安全一次性初始化。
