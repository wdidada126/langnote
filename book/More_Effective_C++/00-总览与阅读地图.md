## 三条阅读主线

1. **资源与生命周期线（本书的真正脊柱）**：`01`(Item 1 引用) → `02`(Item 8 new/delete) →
   `03`(Item 9–11 RAII 全链) → `05`(Item 28 智能指针) → `07`(智能指针收编史)。
   读完能回答："一个资源从取得到归还，语言给了哪几层护栏，各层在哪一年塌过/加高过。"
2. **多态与分派线**：`01`(Item 3 数组多态) → `04`(Item 24 机制价签) →
   `05`(Item 25/31 虚构造与双分派) → `08`(CRTP/variant/Visitor 的谱系终局)。
3. **旧书读法示范线（元阅读）**：`03`(Item 14 异常规格之死) → `07`(三态判定表) →
   `02`(nothrow/new handler 现状)。凡遇到与今天直觉冲突的条款，先去 07 查命运再回原章读论证。

**最短路径**（有《Effective Modern C++》基础者）：直接读 `07` 全表，按"存活"条目回跳原章。

## 本书的历史定位：1996，C++98 前夜

成书时标准化（WG21 的 C++98 工程）已进行七年而未定稿：书中 `std::auto_ptr`、
异常规格、new handler 都是**对草案的写作**而非对成品的总结——这解释了它独特的双面性：
一半条款（RAII、转型纪律、数组多态禁令）越过 30 年仍是公理，另一半机制（Item 14 全文、
Item 28 的 auto_ptr 形态、Item 8 的 handler 建议）整建制进了语言的"停尸房"。
它也是三本书时间轴的中继：EC++(1991 前身/1997) → **MEC++(1996)** → EMC++(2014)，
读 MEC++ 的最佳姿势是左手 07 补编的"命运表"、右手
[../Effective_Modern_C++.md](../Effective_Modern_C++.md)。
语言演化全图见 [../C++语言的设计与演化.md](../C++语言的设计与演化.md)（D&E 止于 1994，
恰是本书的起跑线）与 HOPL-IV 论文中译（[../在拥挤和变化的世界中茁壮成长C++2006–2020.md](../在拥挤和变化的世界中茁壮成长C++2006–2020.md)）。
