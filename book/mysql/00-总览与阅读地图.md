- **主线（结构派，原书第 4–9 章）**：04 → 03 → 05 → 06 → 07 → 08 → 11 → 09 → 10。
  从「一条记录怎么落盘」走到「表/库的文件长什么样」，再回到内存结构。

  建议按「`EXPLAIN` → trace → 成本 → 统计 → 规则」的顺序读：先看结论，再看为什么。
