# 01 · Product Overview（Ch1 · PART ONE 开篇）

> 章名 ✅ InformIT 出版社页实抓；章内小节与全部技术叙述为 ⚠️ 转述重构（依 DB2 9 公开文档/社区笔记），DB2 不可本机实测。

## 一、章定位

本章是全书的"产品地图"：DB2 9 在 IBM 数据平台中的位置、LUW 家族版本划分、9.x 相对 8.x 的关键增量（XML、自动存储、监控增强），以及 730/731/733 认证路径。作者 Baklarz/Zikopoulos 均 IBM 研究院背景，本章带明显"官方视角"营销色，阅读时剥离。

## 二、DB2 9 时代坐标（⚠️ 转述）

- DB2 9.1 "Viper"（2005）：pureXML 原生 XML 存储、自动存储、实例级监控增强——本书主体语境。
- DB2 9.5 "Nacht van het Rijnland/NLVR"（2007）：扩展优化器（X.OPT）、工作负载管理、XML 索引与标注分解增强——与本书出版日期（2007-11）同步，作者按 9.5 口径更新"第六版"。
- 产品命名纪律：官方标 DB2，2017 后标 Db2；本目录按原书口径写 DB2，演进节写 Db2。

## 三、LUW 版本家族（⚠️ 转述，命名随版次漂移）

| 版本 | 面向 | 关键限制/特性 |
|---|---|---|
| Express-C | 免费开发/小型生产 | 内存/CPU 封顶 |
| Express | 入门商用 | 容量限制 |
| Personal | 单机开发 | 可连远端库 |
| Workgroup | 中小部门服务器 | 连接数受限 |
| Enterprise Server (ESE) | 全功能 | DPF 分区、HADR、Infinite Data |
| Enterprise Web 2.0 / Information Server Warehouse (EEE) | 9.5 时代打包 | XML 全功能+数件（⚠️ 命名细节存疑） |

## 四、9 的卖点清单（本章论述主线）

1. **pureXML**：不是 CLOB 伪装，独立存储引擎+XQuery——为第 08 章埋线。
2. **自动存储**：建库路径声明后容器自动创建/扩展——为第 11 章埋线。
3. **监控与自调**：STMM、事件监控器增强、WLM（9.5）——第 14 章。
4. **安全分权**：SECADM/LBAC 把 SYSADM 权力切开——第 04 章。
5. **高可用**：HADR、备份增量/在线——第 13 章。
6. **开发面**：CLI/JDBC/.NET 驱动矩阵与静态/动态双轨 SQL——第 03/09/15 章。

## 五、与其他引擎概念对照（读法提示）

- 与 Oracle 对照：DB2 家族版次近似 Oracle Standard/Enterprise 分层，但 DB2 把分区（DPF）留在 ESE 以上——参见 [../Cost_Based_Oracle_Fundamentals/00-总览与阅读地图.md](../Cost_Based_Oracle_Fundamentals/00-总览与阅读地图.md) 的许可分层讨论。
- 与 SQL Server 对照：DB2 "实例≈SQL Server 实例"但 DB2 实例不含 Agent 服务模型差异——参见 [../SQL_Server_2012_Internals/00-总览与阅读地图.md](../SQL_Server_2012_Internals/00-总览与阅读地图.md)。

## 八、DB2 9 之前的谱系（本章开场叙事拆解，⚠️ 转述）

1. DB2 起源：1983 年 OS/2、VM、VMS 平台的关系产品，名字即"Database 2"。
2. DB2 UDB 5/6/7（90 年代末）：Universal Database 口号期，开始统一多平台代码线。
3. DB2 UDB 8 / 8.2：LUW 命名固化（Linux, UNIX, and Windows 与 z/OS 分家）；HADR 雏形出现在 8.2 FP 期（⚠️ 确切版次存疑）。
4. DB2 9.1（2005）：去"UDB"改标 DB2，pureXML 与自动存储双主打。
5. DB2 9.5（2007）：本书"第六版"对应的更新版次；X.OPT、WLM、纯 Java 驱动增强。
6. 命名学读法：原书标题中"6th Edition"是本书自身版次，不是 DB2 版本——新手易混。

## 九、本章出现过的管理命令首瞥（示意，非实测）

以下仅建立"命令感"，语义细节以后章为准（全部 ⚠️ 转述，本机不可跑 DB2）：

```text
db2level                      # 看实例/产品版本与补丁
db2ilist                      # 列出本机所有实例
db2 list active databases     # 当前已启动数据库
db2 "CONNECT TO sample USER ... "
db2 "SELECT * FROM SYSIBM.SYSDUMMY1"
db2stop / db2start            # 实例生命周期对
db2sampl                      # 生成 SAMPLE 演示库
```

- 对照第 16 文件：附录 B 的 DB2DEMO 安装即这类演示资产的部署。
- 与兄弟引擎对照：`db2sampl` ≈ MySQL 的 sample 数据库导入脚本；`SYSIBM.SYSDUMMY1` ≈ Oracle 的 DUAL（`../Cost_Based_Oracle_Fundamentals/00-总览与阅读地图.md`）。

## 核心概念速览（中英对照）

- **DB2 LUW** — Linux, UNIX, and Windows edition：跨平台统一代码线的 DB2
- **Viper / NLVR** — 9.1/9.5 代号：两个里程碑版次（⚠️ 代号轶事级）
- **pureXML** — Native XML Storage：二进制 XML 树存储引擎
- **Automatic Storage** — 自动存储：路径托管的表空间容器自动管理
- **STMM** — Self-Tuning Memory Manager：内存自治调优框架
- **WLM** — Workload Management：9.5 起的工作负载资源治理
- **DPF** — Database Partitioning Feature：ESE 独占的共享 nothing 分区
- **HADR** — High Availability Disaster Recovery：日志传送备库
- **Express-C** — 免费版：容量受限的社区/小产用途
- **731** — DBA 认证考试号（DB2 9 时代）：本册备考锚点
- **DRDA** — 分布式关系数据库协议：LUW 网络层根基
- **CLI** — Call Level Interface：DB2 原生 C API（ODBC 超集）

## 最新演进与工业实践

- 版本线推进：9.x → 10.5（BLU 列组织）→ 11.1/11.5 → Db2 12（12.1.5 GA，主打内嵌 AI 向量能力；✅ 公告页 curl 200：https://www.ibm.com/cn-zh/new/announcements/ibm-db2-12-1-5-now-available-bringing-ai-to-where-your-mission-critical-data-already-lives）。
- SKU 大洗牌：Express/Personal 等已淡出，现行文档主干 https://www.ibm.com/docs/en/db2 ✅ 200；fix pack 索引 ✅ https://www.ibm.com/support/pages/download-db2-fix-packs-version-db2-linux-unix-and-windows 。
- pureXML 到 2024–2026：仍在产品线但社区热度远低于 PostgreSQL JSONB/Snowflake 半结构化；XML 相关认证考域退役（⚠️ 转述）。
- 工业面：DB2 存量集中于银行/保险/政府 LUW 大机外迁与延续系统；新项目选 Db2 多伴随 Cloud Pak for Data（⚠️ 未逐项验链）。
- 本册价值再定位：不是"最新 DB2 指南"，而是"关系引擎 DBA 纵深教材"——恢复、锁、表空间的机理层与 MySQL/PG 同源互通（对照 [../Understanding_MySQL_Internals/00-总览与阅读地图.md](../Understanding_MySQL_Internals/00-总览与阅读地图.md)）。
