# 11 · Data Storage Management（Ch11 · PART THREE 开篇：空间与内存的地基）

> 章名 ✅ InformIT 出版社页实抓；正文 ⚠️ 转述重构，命令示意非实测。

## 一、章定位

管理部第一章：从"表空间-容器-盘区-页"的空间层级到缓冲池/预取/清理器的内存与 I/O 机制。自动存储（9.1）是本章新旧世界的分界线：DBA 从手工 DMS 容器规划转向路径池治理，但性能敏感场景仍回 DMS——原书以对比表展开，读时抓住"自由度 vs 托管度"主轴。

## 二、空间层级（⚠️ 转述）

1. 层级：数据库 → 表空间（page size 4/8/16/32K）→ 容器（文件/裸设备/路径池自动切片）→ 盘区（extent）→ 页。
2. 一个对象只住一种页大小的表空间；页大小建库/建空间即定（02/05 章红线）。
3. 数据页类型：行数据页/XML XDA 页/索引页/LOB 页——分表空间落位决定并发 I/O 争用面（05 章三 IN 的深化）。
4. 临时表空间：排序/哈希连接/GTT 归宿；`NOT LOGGED` 属性；多 TEMP 竞争是分析负载第一监控项。
5. 数据副本（DB2 9 引入）：容器级多副本写（`COPY1/COPY2` + `COPYNO`）应对坏盘（06 章 LOAD COPY 子句同源 ⚠️ 细节保守）。

## 三、SMS/DMS/自动存储对比（原书表格重构，⚠️）

| 维度 | SMS | DMS | 自动存储 |
|---|---|---|---|
| 容器粒度 | 目录+FS 文件 | 显式文件/裸设备 | 路径池自动建容器 |
| 扩展 | 随 FS | 手工 ADD/RESIZE | 自动（空间不足告警） |
| extent/prefetch | 引擎代管 | DBA 直控 | 托管默认+可覆盖 |
| 条带 | 借 FS | 多容器交替盘区 | 路径跨盘即条带 |
| 典型场景 | 快速起步 | 数件/大 I/O | OLTP 主流（9 起默认） |
| 裸设备 | 否 | 是 | 否 |

- 迁移语法面：`db2 "ALTER TABLESPACE ... MANAGED BY AUTOMATIC STORAGE"` 类转换受对象形态限制（⚠️ 保守）。

## 四、缓冲池与 I/O 机制（⚠️ 转述）

1. 多缓冲池：`CREATE BUFFERPOOL bp16k IMMEDIATE SIZE 4000 PAGESIZE 16`；表空间绑池，热池分治。
2. `IBMDDEFAULTBP` 兜底池与 `dft_extents`/`num_pool` 系参数（⚠️ 参数面以现行核）。
3. 预取器（prefetchers）：顺序读批量拉页；`DB2PARALLELIOSL/NUM_IOSERVERS` 开关（注册表面，02 章双轨呼应）。
4. 页面清理器（page cleaners）：脏页异步落盘；`DB2_BATCHSTORE` 批量存储权衡（⚠️）。
5. STMM（9.1）：缓冲池/排序/包缓存内存自治（`AUTO_MEMTUNE`），DBA 留"设界"职责——本章把自治叙事引入 14 章调优。

## 五、容量治理工作流（原书 DBA 视角）

```text
db2 "get snapshot for tablespaces on demo"        # 使用率/容器满
db2 "select ts_name, ... from syscat.tablespaces" # 目录面（05 章表）
db2 "ALTER TABLESPACE tsd ADD (FILE '/d3/x' 2G)"  # DMS 扩容器
db2 "QUIESCE TABLESPACE ... FOR LOAD"             # 装载/维护窗口锁静（LOAD/13 章接口）
db2pd -db demo -tablespaces
```

- 阈值文化：容器 80% 告警、TEMP 池独立盘、日志与数据分盘（13 章前置）。
- DPF 一角：ESE 的分区库 `db2nodes.cfg` 与多节点表空间并行扩展——原书一节概览，深读推 Redbooks（⚠️）。

## 六、易错雷点（例题库精华）

1. 页大小选错：4K 库装宽行表 → 行溢出（LRECORDS），只能重建。
2. 自动存储路径盘满：`SQL0670N` 且无告警提前量——池内留第二路径是纪律。
3. 多 TEMP 表空间但页大小单一 → 大排序溢出到磁盘风暴（→14 章 sortheap）。
4. DMS 裸设备权限属主错位（实例用户）——实例迁移必检。
5. 副本容器与备份混淆：COPY1 是**实时镜像写**，不是备份（13 章辨析题）。
6. 删容器前未移动数据/离线表空间——`SQL2106N` 类违例（⚠️ 码保守）。

## 八、空间巡检 SOP（把本章变周课表，⚠️ 重构）

1. 日：容器/路径池用量 Top10（阈值 80% 告警，第五节）。
2. 日：TEMP 表空间高水位与溢出计数（快照 sort overflows，14 章接口）。
3. 周：`db2dart`/表空间状态位扫非正常态（`db2pd -tablespaces` 状态列）。
4. 周：缓冲池命中率与预取效率趋势（第四节机制的读数面）。
5. 月：页大小-对象适配审计（宽表住 4K 池复查，雷点 1）。
6. 月：容器条带度与跨盘均衡（自动存储路径池分布，第三节表）。
7. 季：增长模型重估（容量规划从表→库→实例三级外推）。
8. 变更季：新增表空间/缓冲池评审走 04 章授权与 13 章备份策略联动。

## 核心概念速览（中英对照）

- **tablespace** — 表空间：对象与容器的中间逻辑层
- **container** — 容器：表空间的物理落盘单元
- **extent** — 盘区：跨容器轮写的分配单元
- **automatic storage** — 自动存储：路径池托管容器体系
- **bufferpool** — 缓冲池：按页大小分治的内存缓存
- **prefetcher** — 预取器：顺序批量拉页的 I/O 代理
- **page cleaner** — 页面清理器：脏页异步落盘
- **STMM** — 自调内存管理器：池/堆/缓存自治
- **temporary table space** — 临时表空间：排序/物化归宿
- **database copy** — 数据副本：容器级实时镜像写（⚠️ 非备份）
- **QUIESCE** — 静默：为维护冻结表空间写入
- **row overflow (LREC)** — 行溢出：超页宽记录的外溢
- **db2nodes.cfg** — 节点拓扑文件：DPF 分区地图

- 现状：Db2 11.5/12 中 SMS 进入退役叙事、自动存储为默认正解；**系统管理的临时空间自动扩展、通用表空间（universal，自动存储型 DMS）**成空间治理新词汇（⚠️ 转述；入口 ✅ https://www.ibm.com/docs/en/db2 ）。
