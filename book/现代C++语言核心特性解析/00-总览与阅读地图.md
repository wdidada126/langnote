## 两条阅读路线

**路线 A · 按标准年代（本书目录自带年代的自然顺序）**
- C++11 主力：`01`(long long/原生字符串) → `03`(auto/decltype) → `04`(右值引用) → `05`(lambda) → `06`(列表初始化) → `07`(=default/=delete) → `08`(枚举/联合) → `09`(范围for) → `11`(noexcept) → `13`(alignas/属性) → `15`(变参模板) → `16`(SFINAE)。
- C++14 增量：`03`(返回类型推导/别名模板) → `05`(泛型 lambda) → `10`(constexpr 函数放宽) → `16`(变量模板)。
- C++17 增量：`06`(聚合嵌套/指定初始化前夜) → `09`(初始化语句 if/switch、结构化绑定) → `11`(强制求值顺序) → `02`(inline 变量) → `13`(__has_include) → `16`(CTAD/折叠表达式归 15)。
- C++20 增量：`01`(char8_t) → `10`(consteval/constinit/若 constexpr 虚) → `12`(三向比较) → `13`([[no_unique_address]]/__VA_OPT__) → `14`(协程) → `16`(概念和约束) → `02`(模块，34.12)。

**路线 B · 按主题**
1. 类型记法与推导：`03` ↔ `16`（CTAD 是推导规则的类模板延伸）。
2. 值类别与资源转移：`04` → `05`（lambda 闭包靠移动/完美转发进捕获）→ `07`（特殊成员函数的移动生成规则）→ `11`（noexcept 决定移动是否被容器采用）。
3. 初始化与对象布局：`06` → `08`（联合活跃成员）→ `12`（launder/伪析构/对象生命周期）→ `13`（对齐）。
4. 抽象与复用机制：`15` → `16` → `14`（协程=可以暂停的函数这一"控制流抽象"）。
5. 工程接口卫生：`01` → `02` → `09` → `10` → `13`（命名空间/语句糖/断言/属性是 API 表面的四件套）。

## 读完应该能回答的十个问题

1. `wchar_t` 为什么不能保证跨平台？char8_t 相对 u8 字符串字面量的类型变化解决什么？（`01`，Windows 下 sizeof(wchar_t)=2 实测）
2. `decltype(auto)` 返回 `(局部变量加括号)` 与不加括号的值类别差异是什么？漏了会返回悬垂引用吗？（`03`，实测）
3. `std::move` 到底移动了什么？为什么 `decltype((i))` 永远是左值引用？（`04`，实测）
4. lambda 在编译器内部是什么？捕获变量去了哪里？（`05`，`__closure->__base` dump 取证）
5. NSDMI 之后聚合为什么在 C++14/C++17/C++20 三次被"平反"？（`06`）
6. 用户声明析构函数会怎样静默抑制移动构造？后果在 vector 增长上如何放大？（`07`+`11`，实测 15 copies vs 15 moves）
7. `=delete` 相比 private 未定义构造好在哪？（`07`）
8. 强枚举 `enum class : unsigned char` 的 sizeof/隐式转换规则？（`08`，实测 sizeof=1）
9. 只写 `operator<=>=default` 编译器合成了哪六个运算符？（`12`，实测 !=/>= 生成）
10. SFINAE 与 concepts 在同机 g++ 15.2 上的诊断差异到底差在哪几行？（`16`，完整报错实测对比）
