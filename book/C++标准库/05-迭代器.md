## 核心概念速览（中英对照）

- **迭代器类别** — Iterator Category：input / output / forward / bidirectional / random_access 五级能力格（C++20 增 contiguous）。
- **单向 vs 多趟** — Single-pass vs Multi-pass：input 迭代器读过即弃，forward 起「同一迭代器可回头再读」。
- **推进** — advance(it, n)：按类别自动选 `++` 循环还是 `+=`；写泛型代码的距离原语。
- **距离** — distance(beg, end)：forward 走 O(n) 数，随机访问走 O(1) 减。
- **反向适配器** — reverse_iterator：`base()` 总指向「逻辑元素的下一个」，off-by-one 事故高发点。
- **安插适配器** — insert/back_/front_inserter：忽略目标区间、只向容器追加的输出通道。
- **串流适配器** — istream_/ostream_iterator：把「输入流上的 T 序列 / 输出到流」伪装成区间。
- **搬移适配器** — move_iterator：`operator*` 返回 `T&&`，让拷贝语义的算法执行搬移。
- **迭代器萃取** — iterator_traits：泛型函数取 `value_type/difference_type/iterator_category` 的统一孔。
- **哨兵** — Sentinel（C++20 概念，本书无 ⚠️）：end 侧不必与 begin 同类型的推广，`istream_iterator` 的正名。

## 动机：迭代器是把「遍历」从「容器」里抽走的尝试

没有迭代器的世界：每个容器自带 find/sort 接口（MFC 时代），算法无法跨容器复用。
迭代器把「如何走位与读写」抽象成一套**协议**（外加 traits 在编译期披露等级），
算法只依赖协议等级——这是 03 站「正交分解」的执行层。代价是：协议靠纪律维持（失效即 UB）、
C++98 手写迭代器类型样板极重（traits + 多个 typedef），这也是 9.6 读起来劝退的原因。

## 机制

### 1. 类别的继承语义与「谁能喂谁」

```text
random_access ⊂ bidirectional ⊂ forward ⊂ input / output
每级追加工具：BiDi 加 --；RA 加 +n/ -=/ < 比较 / it[n]。
Forward 的本质：可拷贝 + 多次遍历同一区间结果一致（算法可存「第二把游标」的前提）。
```

算法签名旁的「要求 InputIterator」等注释（11 章各算法）就是在声明最低等级。
🔧 已实测 g++ 15.2：用 `iterator_traits` 探测 `vector<int>::iterator` → `random_access_iterator_tag`：

```cpp
template <class I> constexpr const char* cat() {
  using C = typename std::iterator_traits<I>::iterator_category;
  if constexpr (std::is_same_v<C, std::random_access_iterator_tag>) return "RA";
  /* ... BiDi / Fwd 分支略 */
}
static_assert(std::string_view(cat<std::vector<int>::iterator>()) == "RA");
```

### 2. 辅助函数（9.3）与「别乱用 distance」

- `advance/next/prev`：`next(it)` 非破坏地 lookahead——写成对遍历（`i, j=next(i)`）的标准姿势。
- `distance(beg,end)` 对 forward 是 O(n)：**循环不变式里放 distance 是最常见的隐性 O(n²)**。
- `iter_swap(i,j)`：交换两迭代器指向的元素；list 上 O(1)（换节点内容仍要拷贝，真结构交换用 `splice`）。

### 3. 四大适配器逐个看（9.4）

- **reverse 与 base() 的换算全图**：

```text
正向:  a     b     c     d     end
逆向:                          ▲ rbegin —— 逻辑上指向 d
规则1: rit.base() 是 rit 逻辑位置「右边那位」的正向坐标；rbegin.base() == end
规则2: 删除 rit 当前指向的元素:  c.erase(std::next(rit).base())   // 不是 erase(rit.base())
规则3: 反向世界里的 lower_bound(>) 等价正向 upper_bound —— reverse 适配器真正被低估的礼物
```
- **insert 族**：`back_inserter(c)`→`push_back`、`front_inserter(c)`→`push_front`（deque/list）、
  `inserter(c, pos)`→`insert(pos,v)`。算法输出目标从「预分配区间」变成「无限长的洞」，
  `copy` 不再要求目标够长——但容器本身要能长（array 不行）。
- **stream**：`istream_iterator<T> it(cin)` 读一个 T，`{}` 是 end 哨兵；
  `copy(istream_iter, {}, ostream_iter)` 一行管道。注意：其 traits 甚至声明为双向可比（按值/EOF 比较），
  但语义上只该当单向用——别回头重读、别存第二把游标。
- **move**：`std::move(v1.begin(), v1.end(), std::make_move_iterator(v2.begin()))`——
  对象带昂贵拷贝（如 `vector<string>`）时是免费午餐；对 trivially copyable 类型纯装饰。

### 4. traits 与自定义迭代器（9.5–9.6）

C++11 起**不再要求**继承 `std::iterator`（该基类 C++17 弃用、C++20 移除 ⚠️ 移除版次未细核，弃用为 C++17 确定），
只需提供 5 个 typedef：`iterator_category/value_type/difference_type/pointer/reference`。
纯输出迭代器（如 `ostream_iterator`）不需要 `value_type`——`iterator_traits` 对 `T*` 与标准输出适配器已做适配。
写迭代器的高频坑：`operator++(int)` 后置形态返回旧值；`value_type` 要去引用去 cv。

## 权衡

- **迭代器对 vs 容器引用**：迭代器对可指子区间、可跨实现，但两端可错配（UB）；
  传 `container&` 安全但失去子区间与原生数组。C++20 的 `subrange`/`span` 是对「安全版迭代器对」的补课。
- **适配器 vs 手写循环**：`transform(..., back_inserter(out))` 一行 vs 声明+reserve+push 五行；
  前者对「目标容量未知」优雅，后者对「知道要多大」更快（少一层插入协议开销）。
- **end 是位置不是元素**：所有「区间右端」类比较（`it == c.end()`、`rit.base()`）都在讨论位置；
  把 end 当「最后一个元素」是初学者迭代器事故的第一成因。

## 相邻概念对比

- **指针就是迭代器**：`T*` 天然满足 RA；9.6 证明自定义迭代器「不用继承任何东西」，指针是其极限样本。
- **move_iterator vs 直接 std::move 元素**：前者批量、协议兼容 copy/transform；后者逐个、需要循环手写。
- **C++98 traits 孔 vs C++20 concepts 孔**：`iterator_traits<I>::iterator_category` 是运行期不可验证的标签；
  C++20 `std::bidirectional_iterator<I>` 是真概念且可 `requires` 表达（P0896R4/P0898R3，均已核）。

## 最新演进与工业实践

- **C++11**：`cbegin/cend`（容器配套）、`next/prev` 新增、`std::iterator` 被「仅 typedef」取代的开始。
- **C++17**：`data(ptr)` 非成员（配合 `span` 前夜）；`std::iterator` 弃用。
- **C++20**（迭代器十年最大重造，P0896R4 已核）：
  - 概念家族：`input_or_output_iterator → bidirectional_iterator → random_access_iterator → contiguous_iterator`，
    外加 `sentinel_to` / `sized_sentinel_for`（end 可异类、可 O(1) 求距）。
  - `std::ranges::iterator_t/range_value_t/...` 取代手写 traits 萃取；`borrowed_iterator_t` 标记
    「这里存迭代器不会悬垂」（解决返回局部容器迭代器的历史 UB 类别）。
  - `std::ssize` **未**进入 C++20（提案未获通过 ⚠️ 编号未核），日常可用 GSL 的 `gsl::ssize` 或自定义 `ranges::distance` 包装。
- **C++23**：`std::counted_iterator`/`std::basic_subrange`（把「还剩多少」编码进游标类型，P0433 家族 ⚠️ 号未核）；
  `iterator_range`/`subrange` 的 `contains`。
- **工业实践**：
  - 新代码里「裸迭代器对」正在让位：范围 API（`std::span<T>` 参数、`ranges::` 算法）是
    [cppreference](https://en.cppreference.com/w/cpp/iterator) 与 libc++/libstdc++ 文档的默认推荐位。
  - 手写迭代器只剩「自定义容器/流式数据结构」场景，此时参照
    [libcxx 的迭代器测试](https://github.com/llvm/llvm-project/tree/main/libcxx) 里对概念的验证集。
  - 面试常考「`list::erase(rit.base())` 为什么差一位」——机制即上文 reverse 一节，属协议税。
