# 第 7 站 · STL 算法：动词大全（原书第 11 章）

> 11.5 非更易型、11.6 更易型、11.7 移除型、11.8 变序型、11.9 排序、11.10 已序区间、11.11 数值算法。
> 注意：**执行策略（parallel/seq）是 C++17 增补，本章（原书第 11 章）没有**，只在演进节交代。

## 核心概念速览（中英对照）

- **非更易型算法** — Nonmodifying Algorithm：count/find/search/equal/mismatch —— 只读不写。
- **更易型算法** — Modifying Algorithm：copy/transform/replace/fill/generate —— 写元素但不改容器结构。
- **移除型算法** — Removing Algorithm：remove/remove_if/unique —— 「逻辑删除」：搬前部 + 回新尾，**不缩容器**。
- **变序型算法** — Mutating/Reordering Algorithm：reverse/rotate/random_shuffle/partition 族。
- **排序网络** — Sorting Family：sort/stable_sort/partial_sort/nth_element/is_sorted。
- **堆算法** — Heap Algorithm：make_heap/push_heap/pop_heap/sort_heap —— priority_queue 的公开底座。
- **已序区间算法** — Sorted-Range Algorithm：binary_search/lower_/upper_bound/merge/set_* —— 前提有序且**同准则**。
- **数值算法** — Numeric Algorithm：<numeric> 的 accumulate/inner_product/partial_sum/adjacent_difference。
- **区间参数** — Range Parameter：一切算法吃 `[beg,end)`（第 5 站的协议在动词侧的投影）。
- **投影** — Projection（C++20 概念，本书无 ⚠️）：`ranges::find(v, 42, &P::age)` 先映射再比较。

## 动机：动词表为什么值得单独一章

容器是名词，算法是动词。STL 的算法库是「按语义动词分类 + 按迭代器等级定价」的函数目录：
找（find 族）、数（count 族）、比（equal/lexicographical_compare）、搬（copy/move/transform）、
删（remove/unique）、序（sort/partition/reverse/rotate）、堆（heap 族）、算（numeric 族）。
把它背下来 ≈ 拥有「不写循环」的能力——书中反复示范：能用算法处，循环是 bug 温床
（边界、失效、类型三坑在第 4 站已述）。

## 机制：分类精讲（每族挑书中重点）

### 1. 非更易型（11.5）

- `count/count_if` 线性数数；`find/find_if` 返回迭代器或 `end`；**C++23 前没有 find_if 的 bool 版**，
  用 `any_of`（11.5.5 检验族：any_of/all_of/none_of）替代。
- `search` 子序列查找（默认朴素 O(N*S) 上界，11.5.3）；`find_first_of` 「多选一」。
- `adjacent_find` 找**相邻重复**——检测「是否意外有序/去重前置检查」的探针。
- `mismatch/equal/lexicographical_compare`：两个区间并行走；string 的 `<` 就是字典序比较的教科书样本。

### 2. 更易型与输出目标协议（11.6）

copy/transform/replace_copy/fill/generate/generate_n：注意**输出端三类姿势**——
预分配区间（要够长）、`back_inserter`（随便长）、`ostream_iterator`（流）。
`transform` 单源=映射、双源=_zipwith_（`transform(a,b,out,plus<>{})`，06 站预定义件的会师点）。

### 3. 移除族与 erase-remove（11.7，全书高频题）

`remove/remove_if` 把保留元素依次搬向前部并返回新逻辑尾，**尾部残留旧值**（不销毁、不缩 size）。
真删除 = 配容器 `erase`：

```cpp
v.erase(std::remove_if(v.begin(), v.end(), pred), v.end());     // vector
l.remove_if(pred);                                              // list：成员一步到位（6.7.3 规则）
// 关联容器没有 remove_if：用 extract(pred)（C++17，本书无 ⚠️）或 while (auto i = s.find(k)) s.erase(i);
// C++20 起 std::erase_if(s, pred) 对关联/无序/字符串全家可用（P1209R0，已核）
```

`unique` 只去**相邻**重复：先 `sort` 再 `unique` 再 erase 三连（11.7.2 的标准仪式）。

### 4. 变序族（11.8）

- `reverse`（BiDi）/`rotate`（把 [mid,end) 转到前面，**改变逻辑起点**，partition 算法的支点）。
- `random_shuffle`（C++11 弃用、C++17 移除）→ `shuffle(urng)`（11.8.4，配 `<random>`，见第 10 站）。
- `partition` 三件套：`partition`（重排，不保序）/`stable_partition`（保序，可能分配临时内存/抛 bad_alloc）/
  `is_partitioned`（11.8.6 划分为两子区间）。
- `prev_permutation/next_permutation`（11.8.3）：字典序全排列枚举器——组合爆炸的优雅迭代器。

### 5. 排序族（11.9）

| 算法 | 稳定 | 成本 | 用途判据 |
| --- | --- | --- | --- |
| sort | ❌（introsort） | O(n log n) 保证 | 默认 |
| stable_sort | ✅ | O(n log n)，内存不足 O(n log²n)？⚠️ 各版表述有差 | 需要保留等值相对序 |
| partial_sort | ❌ | O(n log m) | 「前 m 名」精确 |
| partial_sort_copy | — | 同上 | 目标更小/源不可改 |
| nth_element | ❌ | **平均 O(n)** | 第 n 名就位 + 左 ≤ 右 ≥（中位数/分位数） |
| is_sorted / sort_heap | — | O(n) / O(n log n) | 堆转有序 |

11.9.3「根据第 n 个元素排序」即 nth_element 一节，书中强调：只要「分堆」不要「排序」时它是复杂度冠军。

### 6. 堆与已序区间（11.10、11.9.4）

- heap 族维护「最大堆不变式」：`push_heap` 假设 [first,last-1) 已是堆；`sort_heap` 反复 pop 得**升序**。
- `lower_bound/upper_bound/equal_range` 在已序区间上二分（log n）——**配 map 使用是常见误用**
  （成员 `map::lower_bound` O(log n)，对 vector 用区间版才叫二分；两者同名不同物）。
- `merge`（两个已序区间归并）+ 集合运算 `set_union/intersection/difference/symmetric_difference`：
  **都要求输入按同一准则已排序**，否则结果无定义（不报错！）。

### 7. 数值族（11.11、<numeric>）

`accumulate`（左折叠；注意初始值类型决定溢出——`accumulate(v.begin(),v.end(),0.0)` 给 vector<int> 求浮点和）、
`inner_product`（点积；也是「相邻差异之和」的泛化底座）、
`partial_sum/adjacent_difference`（前缀和 ↔ 差分互逆，11.11.2）。

🔧 已实测 g++ 15.2（`-std=gnu++23`）：`std::reduce`（C++17，无序折叠可并行）对 1..1000 求和 = 500500，
`std::execution::par` 形态一并通过：

```cpp
std::vector<int> v(1000); std::iota(v.begin(), v.end(), 1);
auto s = std::reduce(std::execution::par, v.begin(), v.end(), 0LL);  // 500500
std::ranges::sort(v);                                                // C++20 容器版排序
```

## 权衡

- **算法 vs 手写循环**：算法给出复杂度承诺 + 迭代器协议复用；循环灵活但要自备边界与失效纪律。
  经验：能用现成动词就动词；动词要串三步（filter+map+dedup）时可考虑 ranges 管道（演进节）。
- **成员函数 vs 算法**（6.7.3 在此复述）：能改容器结构的（list::remove、set::erase、extract）用成员；
  跨容器通用的用算法。
- **stable 版的税**：`stable_sort/stable_partition` 可能分配临时内存且可能抛 `bad_alloc`——
  内存敏感场景用不稳定版 + 显式索引排序。

## 相邻概念对比

- **`sort` vs `set` 有序性**：需要「随时有序」→ 容器；「终态有序、构建期高频追加」→ vector+sort 快数倍（04 站选型矩阵）。
- **`nth_element` vs `partial_sort`**：分位数 vs Top-K；前者 O(n)，后者 O(n log k)。
- **`find_if` vs `binary_search` 族**：线性 vs 对数；配 05 站的 `lower_bound` 可写泛型「有序容器查找」。

## 最新演进与工业实践

- **C++17 执行策略（本书无 ⚠️）**：算法首参加 `std::execution::par / par_unseq / seq`（P0024R2，提案存在已核）；
  `reduce/exclusive_scan/inclusive_scan/transform_reduce` 同期入列（scan 族把「前缀和」升级为可并行结合运算）。
  实测注：g++ 15.2 下 `par` 版 reduce 结果正确（本机 MinGW 无需额外链接即可通过 ⚠️ 未验证是否真并行，
  GCC ≥12 的并行后端官方文档记为依赖 Intel TBB，生产启用前先查所用工具链）。
- **C++20**：`std::ranges` 算法全家桶（P0896R4，已核）——动词不变，但签名从迭代器对换成「range + 投影」：
  `ranges::sort(v, std::less<>{}, &P::age)`；`contains` 等小组合子进视图。
- **C++23**：`ranges::zip`（P2609R3，已核）把「双区间手工并走」标准化；
  `std::generator`（P2502R2，已核）让你用协程**写出**惰性区间喂给 ranges（🔧 实测 `ints(4)` 求和 = 6）。
- **C++26**：统一并行执行框架 `std::execution`（P2300R3，已核）意在替换执行策略的碎片化——sender/receiver 模型。
- **工业实践**：
  - OneAPI TBB / PSTL、[libc++ 的 <execution> 实现状态](https://github.com/llvm/llvm-project/tree/main/libcxx)、
    libstdc++ 的并行算法文档（[gcc-mirror/gcc](https://github.com/gcc-mirror/gcc)）决定你开不开得起 par。
  - 数据并行热点在数值/图形库（Eigen、xtensor、numpy C++ 绑定）由**向量化循环**接管；
    STL 算法层负责「非热路径的清晰表达」。
  - 查任何动词：[cppreference Algorithm library](https://en.cppreference.com/w/cpp/algorithm)。
