## 核心概念速览（中英对照）

- **所有权谱系** — ownership：独占（unique_ptr）→共享（shared_ptr）→借用（T&/T*）
- **make_unique/make_shared** — 工厂函数：异常安全+一次分配（shared_ptr 控制块合并）
- **自定义删除器** — custom deleter：智能指针托管文件句柄/连接池的出口
- **循环引用与 weak_ptr** — reference cycle / weak_ptr：共享图的断环刀
- **span** — span：`{ptr,count}` 的安全借用窗，C++20 预告位（§13.3）
- **array / bitset** — array / bitset：定长栈上容器与位压缩向量
- **pair / tuple** — pair / tuple：二件套与"编译期变长记录"，`get<I>`/结构化绑定消费
- **variant** — variant：类型安全的 tagged union，`visit/holds_alternative/get`
- **optional** — optional：值可能缺席的显式表达，替身"指针可空惯用法"
- **any** — any：运行期任意类型盒子，type_id 探测——擦除的代价是堆与转换
- **allocator（薄讲）** — allocator：§13.6 只承认其存在并建议"库外别碰"
- **chrono** — chrono：时长/时刻/时钟三词表，字面值 `100ms` 需 using
- **function** — std::function：类型擦除的调用槽，捕获型策略的存放处
- **type traits** — type traits：`is_same/enable_if/decay` 的编译期谓词库（§13.9）
- **复数与随机数引擎** — complex / random：`valarray` 的 SIMD 未兑现史与
  播种+分布分离的随机数管线（§14.4–14.5）

## 动机：两章是"库侧语言"与"语言侧库"

第 13 章回收全书欠账：第 4 章"delete 谁来"→ unique_ptr；第 2 章"tagged union 手搓"→ variant；
第 3 章"错误值返回"→ optional；第 1 章"数组不带长度"→ span/array。
**Stroustrup 把 utility 组件写成语言设施的续集**，这是导学区别于百科手册的写法。
第 14 章数值则低调得多——一节的数学函数、一节的随机数、半节坦承
`valarray` "从未被 SIMD 编译器善待"的历史失败（§14.6 的悼词语气是原书风格）。

## 机制：四件必会

1. **移动出厂**（§13.2）：`unique_ptr` 不可拷贝、只能移动——所有权规则被编码进类型系统；
   传 `unique_ptr` 参数=接管，返回=移交。shared_ptr 的拷贝是原子引用计数，
   "共享便宜、探测循环贵"。
2. **variant 的封闭分派**（§13.5.1）：`visit(overloaded{...})` 要求覆盖全部备选类型，
   漏一个编译即拒——与第 4 章 dynamic_cast 链"漏一个运行才发现"形成教学对位。
3. **traits 的语法位**（§13.9）：`iterator_traits` 展示"用类型查询类型"的范式；
   `enable_if` 是 concepts 之前的约束土法——2nd 版诚实地教它，第 3 版几乎删了它。
4. **随机数三段式**（§14.5）：引擎（`mt19937`）+分布（`uniform_real_distribution`）+
   播种（`random_device`）分层——rand() 的诅咒（低位烂、全局态）到此终结。

🔧 实测（g++ 15.2）：`optional/variant/any/string_view` 组合用例 **c++17 即三档全绿**
（第 13 章主体=C++17 存量）；`std::span` c++17 拒、**c++20 通**——印证 §13.3 的
"C++20 预告"角标；`std::bit_cast` 的编译期用法（`static_assert(bit_cast<...})`）
同档 fail/OK/OK——**constexpr 之箭射穿了 utility 章节**：P0784R7
（[wg21.link/p0784](https://wg21.link/p0784) 实测可跳转，本次核实标题
"More constexpr containers"）与 P2280R4（constexpr 传 const&，
[wg21.link/p2280](https://wg21.link/p2280) 实测可跳转）。

## 课堂问答（自读后对答案）

1. **问：** 形参收 `unique_ptr<T>` 和收 `T&`/`T*`，分别向调用者宣告什么？
   **答：** `unique_ptr<T>` 形参=**请交出所有权**（调用方须 `std::move`，之后手里的指针为空）；
   `T&`=借用且保证非空；`T*`=借用且允许为空。签名即合同，编译器执行——这是第 2 章"类型是
   最小防御单位"在 API 上的兑现。
2. **问：** `variant` 漏了一个分支会怎样？和 `dynamic_cast` 链漏一个分支差在哪？
   **答：** `visit` 的过载集漏分支直接**编译失败**（`Overloaded` 惯用法要求覆盖全集）；
   `dynamic_cast` 链漏分支=悄悄落到最后一条 else，**运行时**才变错误——封闭集合交给类型系统，
   开放集合才交给层次。
3. **问：** `optional<T>` 与 `T*`（可空）表达"可能没有值"，为什么前者更好？
   **答：** optional 拥有值（值语义，可放在栈上/容器里），`T*` 是借用且逼调用者追问"指向的谁、
   活着吗"；optional 把"可能空"编码进类型而不捎带生命周期歧义——第 3 章错误处理光谱的成员。
4. **问：** 随机数为什么反对 `rand()`？三段式各管什么？
   **答：** `rand()` 全局态不可复现、低位质量差、范围手动取模进一步歪斜。三段式：
   引擎管**随机源**（`mt19937` 状态机），分布管**形状**（均匀/正态），`random_device` 管**播种**
   ——三者正交才能既换分布又留可复现种子。

## 权衡：借用、共享与擦除的三难

span/引用=借用（要管生命周期）、智能指针=所有权（要管图结构）、any/function=擦除
（要付堆+间接税）。§13.4 的 array/tuple 是"编译期已知尺寸"的零代价区，
§13.5 三件套是"封闭选择"的零代价区——**能用零代价形态就别上税**，
这条与第 4 章"具体优先于抽象"同构。数值章的对应权衡：`complex<double>` 表达式
可能被模板内联打平，`valarray` 靠向量化许诺翻身未遂——**性能靠抽象设计不靠语法糖**。

## 最新演进与工业实践

- **第 3 版（C++20）改了什么**：本章被**拆成两章**——"指针和容器"独立为 3e 第 15 章
  （unique/shared/span/array/bitset/pair/tuple/variant/optional/any 全部去"C++20 预告"
  转正），"实用工具"（3e 第 16 章）新增**日历与时区**（`sys_days`/`zoned_time`）、
  `source_location`、**位操作 `<bit>`**、"退出程序"小节；`enable_if` 让位于概念话语。
- **C++23/26 又推进了什么**：`std::expected`（C++23 的"会带错误信息的 optional"，
  其单子链 P2505R5《Monadic Functions for std::expected》
  [wg21.link/p2505](https://wg21.link/p2505) 实测可跳转，标题本次核实）；
  `std::out_ptr`（C++23 智能指针接 C API，⚠️ 未核提案号）；mdspan（C++23，多维视图，
  ⚠️ 其提案号本会话未核实成功，不给号）。**实测（g++ 15.2）**：
  `std::expected<int,int>` c++17/20 拒、**c++23 通过**——optional→expected 的
  演进线在编译器上看得见。
- **实现史**：`<bit>`/`bit_cast` GCC 10 起（`has_single_bit/midpoint` 实测 20 通过；
  注意 `midpoint` 在 `<numeric>` 不在 `<bit>`——本会话踩过并直证的头文件边界）。
