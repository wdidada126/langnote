# 05 部署与配置

> 本章覆盖 Polaris 的部署实操：Docker Compose 最小链路、配置项、存储后端选择。
> ⚠️ 本目录不实际搭建环境——所有配置描述转述官方文档并标 ⚠️。

## 5.1 部署模式概览

### 5.1.1 三种部署模式

| 模式 | 适用场景 | 复杂度 |
| --- | --- | --- |
| Docker Compose（单机） | 开发/测试/学习 | 低 |
| Kubernetes（Helm） | 生产环境 | 中-高 |
| 托管服务（Snowflake/TABULAR） | 免运维 | 最低 |

> ⚠️ 本目录聚焦 Docker Compose 模式——这是理解架构的最小链路。

## 5.2 Docker Compose 部署

### 5.2.1 最小架构组件

```text
┌─────────────────────────────────────────┐
│  docker-compose.yml                     │
│  ┌───────────┐  ┌───────────────────┐  │
│  │  Polaris  │  │  元数据存储        │  │
│  │  Server   │←→│  (PostgreSQL/     │  │
│  │  :8181    │  │   H2/内存)        │  │
│  └───────────┘  └───────────────────┘  │
│       │                                 │
│       ↓                                 │
│  ┌───────────┐                         │
│  │  MinIO    │  (本地 S3 兼容存储)      │
│  │  :9000    │                         │
│  └───────────┘                         │
└─────────────────────────────────────────┘
```

### 5.2.2 docker-compose.yml 关键配置

> ⚠️ 以下为官方文档转述的配置结构，非实际运行验证。

```yaml
services:
  polaris:
    image: apache/polaris:latest    # ⚠️ 镜像名以官方文档为准
    ports:
      - "8181:8181"
    environment:
      - POLARIS_PERSISTENCE_TYPE=jdbc      # 元数据存储类型
      - POLARIS_JDBC_URL=jdbc:postgresql://db:5432/polaris
      - POLARIS_JDBC_USER=polaris
      - POLARIS_JDBC_PASSWORD=polaris
    depends_on:
      - db
      - minio

  db:
    image: postgres:16
    environment:
      - POSTGRES_DB=polaris
      - POSTGRES_USER=polaris
      - POSTGRES_PASSWORD=polaris

  minio:
    image: minio/minio:latest
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      - MINIO_ROOT_USER=minio
      - MINIO_ROOT_PASSWORD=minio123
```

## 5.3 核心配置项

### 5.3.1 服务配置

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `server.port` | HTTP 端口 | 8181 |
| `server.admin.port` | 管理端口 | 8182 |

### 5.3.2 持久化配置

| 配置项 | 说明 | 选项 |
| --- | --- | --- |
| `persistence.type` | 元数据存储类型 | `memory` / `jdbc` |
| `jdbc.url` | JDBC 连接 URL | PostgreSQL/H2 |

> 🔧 类比：Polaris 的元数据存储配置类似 SQLite 的 `PRAGMA journal_mode`——内存模式 = 临时表（重启丢失），JDBC 模式 = 持久化文件。⚠️ 非本书引擎行为。

### 5.3.3 存储凭证配置

| 配置项 | 说明 |
| --- | --- |
| `storage.credential.type` | 凭证类型（`sts` / `static`） |
| `storage.s3.region` | S3 区域 |
| `storage.s3.endpoint` | S3 端点（MinIO 需配置） |
| `storage.gcs.project-id` | GCS 项目 ID |
| `storage.adls.account` | ADLS 存储账户 |

## 5.4 Catalog 创建实操

### 5.4.1 创建 Catalog（REST API）

```bash
# ⚠️ 文档转述，未实际执行
curl -X POST http://localhost:8181/api/management/v1/catalogs \
  -H "Content-Type: application/json" \
  -d '{
    "catalog": {
      "name": "my_catalog",
      "type": "INTERNAL",
      "properties": {
        "default-base-location": "s3://warehouse/my_catalog"
      },
      "storageConfigInfo": {
        "storageType": "S3",
        "allowedLocations": ["s3://warehouse/my_catalog"]
      }
    }
  }'
```

### 5.4.2 Catalog 类型

| 类型 | 说明 |
| --- | --- |
| `INTERNAL` | Polaris 自身管理的 Catalog |
| `EXTERNAL` | 联邦的外部 Catalog（见 08 章） |

### 5.4.3 存储位置限制

Polaris 通过 `allowedLocations` 限制 Catalog 可以写入的存储路径——
这是安全模型的一部分，防止 Catalog 越权访问其他存储位置。

## 5.5 元数据存储后端选择

| 后端 | 适用场景 | 生产推荐 |
| --- | --- | --- |
| 内存（memory） | 测试/演示 | ❌ 不推荐 |
| H2（嵌入式） | 单机开发 | ❌ 不推荐 |
| PostgreSQL | 生产环境 | ✅ 推荐 |

> 🔧 类比：选择元数据存储后端类似 SQLite vs PostgreSQL——单机开发 vs 多客户端并发生产。⚠️ 非本书引擎行为。

## 5.6 与引擎连接的配置

创建 Catalog 后，引擎通过以下配置连接：

```properties
# Spark 配置示例（⚠️ 文档转述）
spark.sql.catalog.polaris.type=rest
spark.sql.catalog.polaris.uri=http://localhost:8181/api/catalog
spark.sql.catalog.polaris.warehouse=my_catalog
spark.sql.catalog.polaris.credential=<client_id>:<client_secret>
```

详见 07 章各引擎的完整配置。

## 5.7 本章小结

- Docker Compose 最小链路：Polaris Server + 元数据存储 + 对象存储。
- 元数据存储推荐 PostgreSQL；内存模式仅用于测试。
- Catalog 创建通过 Management API，需指定存储类型和允许位置。
- 引擎通过 REST 端点 + OAuth2 凭证连接 Polaris。
