# 07 连接引擎

> Polaris 的价值在于"一个 Catalog，多引擎共享"。
> 本章覆盖 Spark、Flink、Trino、Doris 等引擎接入 Polaris 的配置与行为差异。

## 7.1 多引擎接入的设计哲学

### 7.1.1 为什么需要多引擎

现代数据平台中，不同引擎承担不同职责：

| 引擎 | 主要职责 |
| --- | --- |
| Spark | 批处理 ETL、大规模数据转换 |
| Flink | 流式摄入、实时处理 |
| Trino | 交互式查询、联邦查询 |
| Doris/StarRocks | OLAP 分析、BI 报表 |

如果每个引擎维护自己的 Catalog 元数据，就会产生 **元数据孤岛**——
Spark 创建的表，Trino 看不到。Polaris 通过 REST 标准接口解决此问题。

### 7.1.2 统一 Catalog 的好处

```text
Spark ──┐
Flink ──┤
Trino ──┼── Polaris REST API ── 同一组 Iceberg 表
Doris ──┤
```

- ✅ 元数据一致性：所有引擎看到同一份表定义。
- ✅ 配置简化：只需维护一个 Catalog URL。
- ✅ 权限统一：RBAC 在 Catalog 层集中管理。

## 7.2 Spark 接入

### 7.2.1 配置

```properties
# ⚠️ 文档转述，未实际验证
spark.sql.catalog.polaris=org.apache.iceberg.spark.SparkCatalog
spark.sql.catalog.polaris.type=rest
spark.sql.catalog.polaris.uri=http://polaris:8181/api/catalog
spark.sql.catalog.polaris.warehouse=my_catalog
spark.sql.catalog.polaris.credential=<client_id>:<client_secret>
spark.sql.catalog.polaris.scope=PRINCIPAL_ROLE:ALL
spark.sql.defaultCatalog=polaris
```

### 7.2.2 基本操作

```sql
-- 创建命名空间
CREATE NAMESPACE polaris.analytics;

-- 创建表
CREATE TABLE polaris.analytics.events (
    event_id BIGINT,
    event_type STRING,
    created_at TIMESTAMP
) USING iceberg
PARTITIONED BY (days(created_at));

-- 写入数据
INSERT INTO polaris.analytics.events VALUES
    (1, 'click', '2025-01-01 10:00:00'),
    (2, 'view',  '2025-01-01 11:00:00');

-- 查询
SELECT * FROM polaris.analytics.events;

-- 时间旅行
SELECT * FROM polaris.analytics.events VERSION AS OF 1;
```

## 7.3 Flink 接入

### 7.3.1 配置

```properties
# ⚠️ 文档转述，未实际验证
catalog.type=rest
catalog.uri=http://polaris:8181/api/catalog
catalog.warehouse=my_catalog
catalog.credential=<client_id>:<client_secret>
catalog.scope=PRINCIPAL_ROLE:ALL
```

### 7.3.2 Flink SQL 操作

```sql
-- 注册 Catalog
CREATE CATALOG polaris WITH (
    'type' = 'iceberg',
    'catalog-type' = 'rest',
    'uri' = 'http://polaris:8181/api/catalog',
    'warehouse' = 'my_catalog',
    'credential' = '<client_id>:<client_secret>'
);

-- 创建命名空间
CREATE DATABASE polaris.streaming_db;

-- 创建表
CREATE TABLE polaris.streaming_db.events (
    event_id BIGINT,
    event_type STRING,
    event_time TIMESTAMP(3),
    WATERMARK FOR event_time AS event_time - INTERVAL '5' SECOND
) WITH (
    'connector' = 'iceberg',
    'format' = 'parquet'
);
```

### 7.3.3 Flink 特有行为

| 特性 | 说明 |
| --- | --- |
| 流式写入 | Flink 支持 Iceberg 表的流式写入（changelog 模式） |
| Watermark | Flink 的 watermark 机制在 Iceberg 表上正常工作 |
| Checkpoint | Flink checkpoint 与 Iceberg 快照的协调 |

> 与 [Apache_Paimon_Streaming_Lakehouse/](../Apache_Paimon_Streaming_Lakehouse/) 的对照：
> Paimon 原生为流式设计，Flink + Paimon 的流式体验更紧密；
> Flink + Iceberg（via Polaris）的流式能力在持续完善中。

## 7.4 Trino 接入

### 7.4.1 配置

```properties
# catalog/iceberg.properties ⚠️ 文档转述
connector.name=iceberg
iceberg.catalog.type=rest
iceberg.rest-catalog.uri=http://polaris:8181/api/catalog
iceberg.rest-catalog.warehouse=my_catalog
iceberg.rest-catalog.access-token=<token>
```

### 7.4.2 Trino 查询示例

```sql
SHOW SCHEMAS FROM iceberg;
SELECT * FROM iceberg.analytics.events LIMIT 100;
SELECT * FROM iceberg.analytics."events$snapshots";
SELECT * FROM iceberg.analytics.events
FOR TIMESTAMP AS OF TIMESTAMP '2025-01-01 00:00:00';
```

### 7.4.3 Trino 特有行为

| 特性 | 说明 |
| --- | --- |
| 联邦查询 | Trino 可同时查询 Polaris 和其他数据源 |
| 系统表 | `$snapshots`、`$manifests`、`$files` 等系统表 |
| 物化视图 | Trino 的物化视图与 Iceberg 的交互 |

## 7.5 Doris / StarRocks 接入

Doris/StarRocks 通过 Iceberg REST catalog connector 接入 Polaris，配置方式类似 Trino。
⚠️ 对 Iceberg REST catalog 的支持仍在迭代中，部分高级特性（视图、时间旅行）的支持程度因版本而异。
建议查阅对应版本的官方文档确认兼容性。

## 7.6 引擎间行为差异总结

| 行为 | Spark | Flink | Trino | Doris |
| --- | --- | --- | --- | --- |
| 建表 | ✅ | ✅ | ⚠️ 有限 | ⚠️ 有限 |
| 流式写入 | ❌ | ✅ | ❌ | ❌ |
| 时间旅行 | ✅ | ⚠️ | ✅ | ⚠️ |
| 系统表 | ✅ | ⚠️ | ✅ | ⚠️ |

> ⚠️ 以上为基于公开文档的推断，具体行为以各引擎+Polaris 版本实测为准。

## 核心概念速览（中英对照）

- **多引擎** — Multi-Engine：多个计算引擎共享同一 Catalog。
- **流式写入** — Streaming Write：Flink 特有的 Iceberg 写入模式。
- **行为差异** — Behavioral Differences：各引擎对 Iceberg 特性的支持程度不同。

## 最新演进与工业实践

- **2025**：Spark/Flink/Trino 均已原生支持 REST catalog ✅。
- **工业趋势**：Spark 做 ETL + Flink 做实时摄入 + Trino 做即席查询，全部通过 Polaris 共享元数据。
- **⚠️**：Doris/StarRocks 的 Iceberg REST catalog 支持仍在快速迭代中。
- **参考**：引擎配置以各引擎官方文档 + Polaris 官方文档为准。
