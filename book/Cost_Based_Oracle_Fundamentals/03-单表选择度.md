# 03 · Single Table Selectivity（单表选择度）

> 原书第 3 章 ⚠️ 精读重构：章题 ✅ 实抓（Springer/Crossref），小节自拟；估算规则为文档/社区转述，一律 ⚠️，无法在 Oracle 实测。

## 本章定位

选择度（selectivity）是 0–1 的小数：**谓词通过行的比例估计**。基数（cardinality）= 基表行数 × 各谓词选择度的组合。本章把"单表上每种谓词怎么估"逐类过一遍——这是全书所有连接/路径成本公式的上游输入，也是 06（组合）、07（直方图）、10（连接基数）三章的地基。跨引擎的同类规则在 [../数据库查询优化器的艺术.md](../数据库查询优化器的艺术.md) 与 [../PostgreSQL技术内幕_查询优化深度探索.md](../PostgreSQL技术内幕_查询优化深度探索.md) 有通用化讲法，可对照阅读。

## 3.1 估算的原料：列统计 ⚠️ 文档转述

`DBMS_STATS` 落在数据字典（`USER_TAB_COL_STATISTICS` 等视图，视图名按 ⚠️ 文档转述）的量：

| 统计量 | 英文 | 用途 |
|---|---|---|
| 行数 | num_rows | 基数计算的底数 |
| 不同值数 | num_distinct (NDV) | 等值选择度分母 |
| 密度 | density | 无直方图区间的范围/不等式兜底 |
| 空值数 | num_null | `IS NULL` 谓词 |
| 最小/最大值 | low_value / high_value | 范围谓词锚点 |
| 平均长度 | avg_row_len | 块折算与表成本 |

- 直方图存在时 density/区间规则整体改写 → [07-直方图.md](07-直方图.md)。

## 3.2 谓词类型 × 估算规则总表 ⚠️ 文档转述

| 谓词 | 估算式（无直方图） |
|---|---|
| `col = const` | 1 / NDV |
| `col > const` | (high − const) / (high − low) 线性内插 |
| `col BETWEEN a AND b` | (b − a) / (high − low) |
| `col != const` | 1 − 1/NDV（若含 NULL 再修正） |
| `col IS NULL` | num_null / num_rows |
| `col IN (v1..vn)` | n × 1/NDV |
| `col LIKE 'abc%'` | 前缀长度与字符集假设的启发式（各版本细节不一 ⚠️） |
| 函数包裹列 `f(col)=c` | 无直方图时退化为默认常量（历史上 5% 一类规则 ⚠️），函数索引/虚拟列可救 |
| 隐式类型转换 | 等同函数包裹，谓词"失明"——改写案例集高频条目，参 [../Oracle查询优化改写技巧与案例.md](../Oracle查询优化改写技巧与案例.md) |

- Lewis 强调的读法：10053 trace 里每条谓词旁边就印着 sel 值，**规则表背下来 = 能默写优化器在想什么**（方法见 [14-10053跟踪文件.md](14-10053跟踪文件.md)）。

## 3.3 范围谓词与索引的关系 ⚠️ 文档转述

- 有直方图的高度平衡桶给出"区间内值数"的粗粒度刻度；无直方图时密度值（density）承担不等式估算——9i 与 10g 对 density 的用法有差异（本书时代坑 ⚠️）。
- "范围谓词的索引有效部分"引 out **有效选择度（effective index selectivity）**：复合索引只有前导连续列上的谓词参与索引区间定价，其余靠回表过滤 → 见 [04-B树索引基础访问.md](04-B树索引基础访问.md)。

## 3.4 估算错误的传导 ⚠️ 文档转述

- 单表 sel 错 10 倍，到 4 表连接里基数可错 3–4 个数量级（连接处的级联机制 → [10-连接基数估算.md](10-连接基数估算.md)）。
- 典型"选择度撒谎"场景（社区共识 ⚠️）：数据倾斜但无直方图；ETL 后统计过期；绑定变量使范围谓词按共享游标初值估；列相关（如 city 与 zip）被当独立事件连乘（→ [06-选择度组合难题.md](06-选择度组合难题.md)）。
- 学术印证：基数估计误差是计划质量第一杀手——Leis 2015（✅ DOI：https://doi.org/10.14778/2850583.2850594 ）。

## 3.5 实践清单（精读重构）⚠️ 文档转述

1. 慢 SQL 先看"估算行数 vs 实际行数"（`GATHER_PLAN_STATISTICS` + `DBMS_XPLAN DISPLAY_CURSOR`，操作层步骤见 [../Oracle12c数据库应用与开发/07-SQL性能诊断与调优实践.md](../Oracle12c数据库应用与开发/07-SQL性能诊断与调优实践.md)）。
2. 偏差大 → 查该列统计五件套（NDV/密度/直方图/NULL/边界值）。
3. 谓词是否被函数/隐式转换包裹。
4. 是否绑定变量偷走了选择性（peeking 与 ACS → 07 章演进节）。
5. 修复优先级：补统计 > 补直方图 > 虚拟列/函数索引 > hint（最后手段）。

## 3.6 一次手算走查（示意数字，非实测 ⚠️）

表 T：`num_rows=500000`；列 C1（NDV=10000, low=1, high=100000）、C2（NDV=50, 有频率直方图）。
谓词：`C1 BETWEEN 20000 AND 30000 AND C2 = 'ACTIVE' AND C3 IS NOT NULL (num_null=50000)`。

1. `C1` 范围：(30000−20000)/(100000−1) ≈ 0.1000 → 底数 50 万 ⇒ 估 5 万。
2. `C2` 等值：查直方图 repeat_count（→ 07 章）设 0.30 ⇒ 估 1.5 万。
3. `C3 IS NOT NULL`：1 − 0.1 = 0.9 ⇒ 估 1.35 万。
4. 连乘组合（06 章将追问这个假设）⇒ 最终基数 13500。
5. 对照 `DBMS_XPLAN` 的 EST 行：逐层对上，说明本章规则已内化；对不上先查 3.4 四场景。

## 3.7 谓词规范化检查清单（改写前置）

- [ ] 列裸奔：谓词两侧无函数包裹（`trunc(dt)=...` → 区间改写，案例见 [../Oracle查询优化改写技巧与案例.md](../Oracle查询优化改写技巧与案例.md)）。
- [ ] 类型对齐：字符列存数字/数字列绑字符串，杜绝隐式转换。
- [ ] 字面量与绑定分家：倾斜+范围谓词列评估 peeking 风险（3.4/6.4）。
- [ ] NULL 语义显式化：`col != 'X'` 漏 NULL 是逻辑错+估算错双重。
- [ ] LIKE 前缀化：`'%x%'` 无索引可用且 sel 走默认，先问能不能改成层级编码。
- [ ] IN 列表长度：超长列表触发 9.2 的展开/迭代定价分岔（→ [09-查询变换.md](09-查询变换.md)）。
- [ ] 冗余谓词：传递闭包会自己推导，人不要替它乘两遍（6.1 呼应）。

## 核心概念速览（中英对照）

- **选择度** — selectivity：谓词通过行的比例估计，0–1 小数。
- **基数** — cardinality：行源输出行数 = 底数 × 选择度组合。
- **不同值数** — num_distinct（NDV）：等值选择度的分母。
- **密度** — density：无直方图时不等式/区间估算的兜底刻度。
- **边界值** — low_value/high_value：范围谓词线性内插的两锚。
- **空值数** — num_null：IS NULL 谓词的选择度来源。
- **线性内插假设** — linear interpolation：假定值在区间均匀分布，倾斜数据下失真核心。
- **有效选择度** — effective (index) selectivity：复合索引前导连续列实际可用的选择度。
- **函数暴露** — exposure to function：列被函数包裹后优化器改用默认启发式。
- **隐式转换** — implicit type conversion：类型不匹配致谓词按函数包裹处理。
- **统计视图** — USER_TAB_COL_STATISTICS：列统计的字典出口（视图名 ⚠️ 转述）。
- **谓词追踪** — predicate trace：10053 中逐条打印谓词与 sel 值的段落。

## 最新演进与工业实践

- **SQL Plan Directives 与扩展统计（12c+，文档转述 ⚠️）**：优化器自动"点名"需要统计的列组合，`DBMS_STATS.CREATE_EXTENDED_STATS` 支持列组/表达式/交互组统计，缓解本书时代的单列独立假设局限。
- **自适应游标共享（ACS，11g+ ⚠️）**：同一游标按绑定值区间生成子游标，弥补范围谓词 peeking 一次定终身的问题；配套 `V$SQL_CS_STATISTICS` 一类观测视图（名称 ⚠️ 转述）。
- **默认直方图策略收紧（11g+ ⚠️）**：`METHOD_OPT` 默认 AUTO 只给"被用作谓词且有倾斜"的列建直方图，列使用追踪（`column_usage`）自动判定——3.4 的"无直方图倾斜"场景显著减少，但 ETL 过期统计问题不变。
- **统计自动化（19c/23ai ⚠️）**：自动统计收集作业按对象修改率（stale_percent 阈值可调）触发；23ai 的统计相关增强见官方性能管理指南目录（✅ 可达：https://docs.oracle.com/en/database/oracle/oracle-database/23/tgdba/index.html ）。
- **研究线**：单列选择度估算的通用化即 Selinger 框架的 `SEL-EST` 模块（✅ DOI：https://doi.org/10.1145/50202.50214 ）；现代学习式估计器（如 Neo/Kang 等综述所涵盖，未逐一核 DOI ⚠️ 不给链接）尝试用采样/贝叶斯网络替换均匀性假设；中文系统对照可读 [../数据库查询优化器的艺术.md](../数据库查询优化器的艺术.md)。
