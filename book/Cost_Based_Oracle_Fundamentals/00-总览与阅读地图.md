## 三、本书在数据库系列中的定位

本书是**数据库"成本优化器"流派在单一商用引擎（Oracle）上的最细颗粒度标本**：不是 SQL 调优技巧汇编，而是"反推 Oracle CBO 内部成本模型→统计信息→选择度/基数→访问路径代价"的白盒解剖。 repo 系列中与之构成四层分工：

1. **理论层**：`[../../db/db.md](../../db/db.md)` 的 RBO/CBO 对照与 System R/Selinger 成本优化器论文线（本书即 Selinger 1988 一系在 Oracle 中的工程实现细部）。
2. **通用优化器层（中文原创）**：`[../数据库查询优化器的艺术.md](../数据库查询优化器的艺术.md)`（李海翔，据在盘总索引；任务单注"焦振中"与在盘索引署名不符，以实证为准）——跨引擎优化器原理，与本书"只解剖 Oracle"互补；`[../PostgreSQL技术内幕_查询优化深度探索.md](../PostgreSQL技术内幕_查询优化深度探索.md)`——PG 侧同题对照（代价模型、选择度估算可逐点映射）。
3. **Oracle 使用/体系层（在盘）**：`[../Oracle12c数据库应用与开发/00-总览与阅读地图.md](../Oracle12c数据库应用与开发/00-总览与阅读地图.md)` 及其 [06-SQL执行计划与CBO.md](../Oracle12c数据库应用与开发/06-SQL执行计划与CBO.md)、[07-SQL性能诊断与调优实践.md](../Oracle12c数据库应用与开发/07-SQL性能诊断与调优实践.md)——12c 时代的操作视角，本书的"为什么"接它们的"怎么做"；另有 `[../Oracle查询优化改写技巧与案例.md](../Oracle查询优化改写技巧与案例.md)`（Appleton 系改写案例，⚠️ 待核验）与 `[../数据库高效优化.md](../数据库高效优化.md)`（架构/规范/技巧三合一）。

## 五、全书主线论点（精读重构）

1. **成本是模型不是现实**：优化器在"块访问计数 + 简化 I/O 假设"的沙盘上推演，统计信息是沙盘的刻度；沙盘错则全盘错（前言主旨 ✅ Springer 简介）。
2. **修一类问题而非一条 SQL**：调模型（系统统计、MBRC、伪数据/统计操纵）与造真统计（采样、直方图、聚簇因子校正），一次生效覆盖整个问题域。
3. **10053 是听诊器**：优化器把每一步估算写进 trace（约 2005–2006 年 9i/10g 时代语境），读得懂 trace 才能证伪任何"我觉得优化器傻了"的判断（14 章方法论）。
4. **时代局限**：本书锚定 9i/10g CBO。11g 的 SPM、12c 的自适应计划与默认直方图收紧、19c/23ai 的自动化（自动索引、优化器补丁）改变了诸多操作细节——各章"最新演进"节逐一标注 ⚠️ 官方文档转述。
