# 《Effective TypeScript, 2nd Edition》——总览与阅读地图

> 目标书：*Effective TypeScript: 83 Specific Ways to Improve Your TypeScript*（第二版），Dan Vanderkam（2e 全作者名录 ⚠️ 是否增补合著者以版权页为准），O'Reilly，约 2024，ISBN ⚠️待核验。
> 条目数 ✅：1e 中文版《精进TypeScript代码的62个实践方法》ISBN 9787519859381；2e 中文版书名即《…83个实践方法（第二版）》——62→83 双源直证。

## 一、定位

工程规范线主教材，条目式（Item XX）体例与 Effective Java / Effective Kotlin 完全同构——本仓三本 "Effective" 系可横向比对同一 Item 在多语言下的裁决差异（如可变性、类型断言 ≈ 强转的告诫位）。专治「JS 习惯写 TS」。

## 二、骨架（⚠️ 部名/条目号以版权页为准；1e 六部结构为参照）

| 部 | 主题带 | 本仓高价值条目方向 |
|---|---|---|
| Ⅰ 类型基础 | number/`any`/`unknown`/`never` | `any` 三罪状（关检查/传染性/假断言）——strict 家族选型条目 |
| Ⅱ 类型宽窄 | 推断、字面量类型、类型保护 | **narrowing 规范**：判别式优先、`in`/`instanceof`/谓词函数选型 |
| Ⅲ 对象与接口 | 结构类型、类型子类型关系 | 可选属性 `?` = `undefined` 联合的陷阱条 |
| Ⅳ 函数 | 重载、`this`、参数协变逆变 | 优先交叉而非重载 |
| Ⅴ 类型别名/映射 | 别名哲学、映射类型初步 | 别名≠新类型（对照 nominal 语言）条 |
| Ⅵ 项目与工程 | tsconfig、声明、工具链 | **2e 新增带**：strict 全量时代配置、模板字面量/infer 条目 ⚠️ 具体增补分布待目录销账 |

## 三、读法

不线性读。写 TS 遇风格争议→查对应 Item；每 Item 分章档落「本仓裁决」+ 与 Effective Java/Kotlin 同题条目互链一行。2e 相对 1e 的增删条目清单是第 2 波销账重点 ⚠️。

## 四、🔧 实测口径

Item 级成对反例（坏味道版/修正版），`tsc --noEmit --strict` 对比诊断文本；无独立 tsc 时以 `node --experimental-strip-types` 验证「运行时零保护」面（已实测 ✅ 基线见总索引）。
