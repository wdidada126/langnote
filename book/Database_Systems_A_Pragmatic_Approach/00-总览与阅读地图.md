## 3 成书风格与受众（✅ Springer About/章摘要逐字锚点）

- **课堂教材+自学线双栖**：About 原文 "a classroom textbook for use by students who are learning about relational databases, and the professors who teach them"；"based on lecture notes that have been tested and proven over several years"；作者标榜 "brevity, comprehensive coverage, and relevance" 与 "combining and balancing theory with practice"。
- **先修假设**（ch1 摘要原文）："you have covered several fundamental topics in programming, data structures, user interface, and software engineering"——本书不补数据结构课，只在附录复习（ch27/28）与需求收集（ch29）。
- **贯穿示例=college database**（ch8 摘要原文 "The partial college database, introduced in the previous chapter (figures 7-1 and 7-2)"）：大学场景（学生/课程/教师/院系类关系）是全书代数/演算/SQL 例题库——本笔记各章例题沿用此域。
- **时代指纹**：SQL 教学实现基于 Oracle 10g（ch11 摘要原文 "The main SQL definition statements in an Oracle 10G environment"）、前端专章 Delphi（ch20 "the second front-end system that we will consider - Delphi"，⚠️ 第一前端何物摘要未露）、商用概览四连 Oracle/DB2/SQL Server/MySQL——2014 年"企业三巨头+开源新贵"版图，无 PostgreSQL 专章。
- **考核导向**：ch26 整章 sample exercises/examinations/case studies（页 415–446 共 32 页），自学线标配。

## 4 🔧 实测清单（红线②：仅 SQLite/DuckDB，非本书引擎行为）

> **非本书引擎行为声明**：本书 SQL 主线为 Oracle 10g 方言，概览章为 Oracle/DB2/SQL Server/MySQL（均不可在本工作区实测→标 ⚠️ 转述+官方演进 URL）。以下全部实验用 **python 内置 sqlite3（SQLite 3.45.3）** 与 **pip 已装 duckdb 1.5.5**（零新装、未起任何服务）做**同题概念类比**，结果只说明 SQLite/DuckDB 行为，不能外推到本书讨论的任何引擎。原始输出落盘 `dbwave_w10_dbspa/out_all.txt、e12.txt、e3456b.txt、e4b.txt、e78.txt、e8b.txt、e6c.txt、e6d.txt、e6e.txt`。

| 组 | 主题 | 关键读数 | 用于成书文件 |
|---|---|---|---|
| E1 | SQLite DDL/约束 | FK 默认关（`PRAGMA foreign_keys`→0）孤儿行入库；开后 `IntegrityError:FOREIGN KEY constraint failed`；CHECK/UNIQUE 各报错；`ON CONFLICT DO UPDATE` upsert→999.0；弱类型 `typeof`→('text','text')，亲和性 '42'→integer | 02/03/07 |

| E3 | 双引擎 DML | CTE 均值比较、SQLite `RETURNING`、**SQLite 也支持 UPDATE…FROM**（3.33+）、事务回滚保 90.0、DuckDB rank() 窗口 | 08 |
| E4 | 索引 | SQLite EQP `SCAN emp`→`SEARCH … USING INDEX (did=? AND salary>?)`；ANALYZE→sqlite_stat1 `3 2 1`；30 万行点查 8.636ms→0.032ms=**267.4×**；**DuckDB 1.5.5 竟接受 `CREATE INDEX`**（1M 行 1.29ms 带索引 vs 1.65ms 行组跳扫）——旧版"不支持"口径已过时 | 06/11/17 |
| E5 | 视图 | SQLite 一切视图不可直写（`cannot modify v1 because it is a view`），**INSTEAD OF 触发器**开写入→(7,)；DuckDB 视图 INSERT→CatalogException `v2 is not an table`；`sqlite_master` 存 CREATE VIEW 原文 | 09/10 |
| E6 | 系统目录 | SQLite `sqlite_master`+`PRAGMA table_info/index_list/writable_schema`；DuckDB `duckdb_tables()/duckdb_views()/duckdb_columns(is_nullable)/duckdb_functions()`=2948 个函数 | 10 |

| E8 | 复杂对象/联邦/哈希 | SQLite `json_extract` 取嵌套 city='CD'（JSON 即 text）；DuckDB STRUCT 嵌套查询 ('a',2)、map['k2']=2；双引擎 **ATTACH 跨库 JOIN** 同出 (left,right)；2 万次点查 哈希表 3.7ms vs 有序数组二分 18.8ms=**5.0×**；md5('student-1001') 前 8 位十六进制 %97→桶 43 | 13/14/17 |
