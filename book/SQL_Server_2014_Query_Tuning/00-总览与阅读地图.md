## 5. 🔧 本机类比实验总表（SQLite 3.45.3 / DuckDB 1.5.5；**一律非本书引擎行为**）

| 组 | 实验 | 关键数字 | 所在章 |
|---|---|---|---|
| G1 | 50 万行 orders 表：无索引 SCAN 21.1ms vs COVERING INDEX SEARCH 0.2ms | ≈124× | 05 |

## 9. 术语与缩写速查（本目录通用）

- **CE / 基数估计** — Cardinality Estimation：优化器行数猜测系统；2014 兼容级 120 换代。
- **QO** — Query Optimizer：查询优化器；SQL Server 系基于成本规则混合搜索。
- **CCB** — Common Criteria Buffer：优化器内部公共判据子树缓存。
- **SARGable** — Search ARGument able：谓词可走索引查找的写法性质。
- **DMV** — Dynamic Management View：动态管理视图，如 sys.dm_exec_query_stats。
- **DTA** — Database Engine Tuning Advisor：引擎调优顾问（工作负载→索引/分区建议）。
- **Hekaton / 内存 OLTP** — In-Memory OLTP：2014 增强的本机内存引擎。
- **CCI** — Clustered Columnstore Index：2014 可更新的聚集列存储。
- **BPE** — Buffer Pool Extension：缓冲区池扩展（SSD 二级缓存；⚠️ 文档旧链已 404，见 §7）。
- **RSTI** — Read Committed Snapshot Isolation：基于行版本化的读已提交。
- **PSU/CU** — 累积更新单元；2014 支持止于 2024-07（✅ lifecycle 页）。
- **估算/实际计划** — Estimated/Actual Execution Plan：前者编译期猜测，后者运行期实录。
