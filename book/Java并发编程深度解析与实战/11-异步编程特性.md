# 第 11 章 Java 并发编程中的异步编程特性

> 异步编程：`Future`/`Callable`、`CompletableFuture`、回调、与虚拟线程的关系。本书重「异步为何存在 + 与同步写法对照」。详见《之美》concepts/CompletableFuture与异步编排.md、高并发核心编程 concepts/CompletableFuture异步回调.md。

## 一、核心精讲

### 2.1 🔧 异步解决「线程阻塞」
- 同步 IO 时线程空等；异步把「等」让出，结果就绪再回调（🔧 提升吞吐但引入回调嵌套/错误传播难）。

### 2.2 CompletableFuture 编排
- `supplyAsync`/`thenApply`/`thenCompose`/`thenCombine`/`allOf`（🔧 不传 `Executor` 用 `ForkJoinPool.commonPool`，阻塞任务会饿死全局池；传自定义池）。

### 2.3 虚拟线程让异步「退场」
- JDK 21 虚拟线程：「每请求一虚拟线程 + 同步写法」，IO 时自动卸载 carrier，既简单又高吞吐（🔧 大量 `CompletableFuture` 回调链可改写为顺序虚拟线程代码；但跨服务异步/响应式仍保留）。
