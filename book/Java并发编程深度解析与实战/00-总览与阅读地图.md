# 《Java并发编程深度解析与实战》阅读地图

- 主题：JDK 并发「原理揭秘」向——线程/synchronized/volatile/JUC 锁/条件等待/并发工具/阻塞队列/安全集合/线程池/异步，重**源码级原理**（与方腾飞《艺术》重叠度高，本书更偏「逐行揭秘 + 实战踩坑」）。
- 定位：在《艺术》（底层汇编）与《之美》（concepts 横切）之间，补「原理+实战」一层。

## 同主题书籍分工

- **方腾飞《艺术》**：volatile 汇编、synchronized 三级、AQS 源码 —— 最底层。
- **《之美》concepts**：AQS/JMM/volatile/CAS/阻塞队列/CompletableFuture 横切专论 —— 查字典。
- **冷血《实现原理》**：JDK 源码「手写实现」 —— 从零造。
- **本书**：原理揭秘 + 实战踩坑，介于二者之间。

## 本书没覆盖的缺口

- 虚拟线程（JEP 444）、结构化并发（JEP 453/505）、ScopedValue（JEP 506）—— 见《之美》。
- VarHandle 取代 Unsafe（JEP 471/498）。
