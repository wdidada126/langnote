# 第 8 章 深度剖析阻塞队列的设计原理及实现

> 阻塞队列族的设计：接口（`BlockingQueue`）、`ArrayBlockingQueue`（单锁+条件）、`LinkedBlockingQueue`（双锁+/无界陷阱）、`SynchronousQueue`（手递手）、`PriorityBlockingQueue`、`DelayQueue`、`LinkedTransferQueue`（dual data structure）。本书重「为什么需要阻塞队列 + 各实现锁策略」。详见方腾飞《艺术》6 章、手册 7 章、之美 concepts/阻塞队列BlockingQueue.md。

## 一、核心精讲

### 2.1 🔧 `LinkedBlockingQueue` 无界陷阱
- 默认构造 `Integer.MAX_VALUE` 容量（🔧 生产快于消费时无限堆积 OOM；务必 `new LinkedBlockingQueue(cap)` 显式容量）。

### 2.2 `SynchronousQueue`
- 不存元素，生产者直接交给消费者（手递手），`offer` 无消费者立即失败（🔧 `Executors.newCachedThreadPool` 用它；高吞吐小任务友好，但任务无缓冲）。

### 2.3 `LinkedTransferQueue` 双数据结构
- Scherer-Lea-Scott（PPoPP'06）dual data structure：节点既是数据也是请求，匹配即传递（🔧 `transfer`/`tryTransfer` 比 SynchronousQueue 更通用）。
