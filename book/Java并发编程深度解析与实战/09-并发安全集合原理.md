# 第 9 章 深度解读并发安全集合的原理及源码

> 并发集合源码：`ConcurrentHashMap`（JDK8 桶级锁 + 红黑树）、`CopyOnWriteArrayList`（COW）、`ConcurrentSkipListMap`（跳表）、`ConcurrentLinkedQueue`（MS 无锁）。本书重「源码级为什么线程安全」。详见方腾飞《艺术》6 章、手册 7 章、之美 concepts/JMM与并发集合。

## 一、核心精讲

### 2.1 🔧 `ConcurrentHashMap` 桶级锁
- JDK 8 弃分段锁，初始化/写用 `synchronized` 锁单桶 + `CAS` 拿头节点；`sizeCtl` 控初始化/扩容（🔧 扩容时多线程协助迁移，读不阻塞；`get` 无锁）。

### 2.2 `CopyOnWriteArrayList`
- 写时复制整个数组，读持旧数组引用无锁（🔧 读多写少；写频繁/OOM；迭代器弱一致不抛 `ConcurrentModificationException`）。

### 2.3 `ConcurrentSkipListMap`
- 无锁跳表（CAS 多层索引），有序且高并发（🔧 替代 `Collections.synchronizedSortedMap`；但占用更高）。
