# 第 7 章 深度探索并发编程不得不知的工具

> 并发排障工具链：线程 dump（`jstack`）、`jconsole`/`jvisualvm`、JOL（对象布局）、`jcstress`（并发压测）、`async-profiler`（火焰图）、Arthas（运行时诊断）、`java.util.concurrent.atomic` 辅助。本书补「原理→实战」的排障闭环。详见黄文海 10 章、Goetz concepts/并发测试方法论、手册 9 章。

## 一、核心精讲

### 2.1 🔧 死锁定位
- `jstack <pid>` 搜 `deadlock` / `BLOCKED` 环（🔧 或 Arthas `thread -b` 直接给阻塞线程；生产首选 Arthas 不重启）。

### 2.2 内存布局与伪共享
- JOL 看对象头/对齐填充（🔧 `@Contended` 填 128B 缓存行隔离伪共享，见《之美》concepts/伪共享FalseSharing；JVM `-XX:-RestrictContended` 开启）。

### 2.3 并发压测
- `jcstress` 验证内存模型/线性化（🔧 DCL 不加 volatile 会被 jcstress 抓出半初始化；替代单测）。
