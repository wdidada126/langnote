## 本书在数据库系列中的定位

- **一句话**：系列里第一本完全以「嵌入式分析引擎（analytics-in-the-process）」为主角的实操书——把 DuckDB 当作"分析界的 SQLite"，从 CLI、方言 SQL、文件直查一路写到 Python 生态、云（MotherDuck）与管道（dlt/dbt/Dagster）。
- 与仓库既有笔记的分工（互链目标均已验证存在）：
  - [../Database_Internals/00-总览与阅读地图.md](../Database_Internals/00-总览与阅读地图.md)：讲存储引擎/分布式内核**原理**；本书几乎不碰内核推导（第 10 章查询计划是浅接触）。DuckDB 的向量化/块格式细节转介 [../数据库系统内幕.md](../数据库系统内幕.md) 与 C-Store/Vector 论文线 [../../db/db.md](../../db/db.md)。
  - [../大数据SQL优化.md](../大数据SQL优化.md)：MPP 数仓口径的 SQL 优化；本书第 10 章是**单机进程内**口径，两本互为"同题异构"对照。
  - [../The_Data_Lakehouse/00-总览与阅读地图.md](../The_Data_Lakehouse/00-总览与阅读地图.md)：湖仓**架构学**（Inmon）；本书第 5/10 章是湖仓**工程现场**（Parquet 直查）。DuckLake 一节见本目录 05/11 两文件。
  - 开放表格式对照：[../Delta_Lake_Definitive_Guide/00-总览与阅读地图.md](../Delta_Lake_Definitive_Guide/00-总览与阅读地图.md)、[../Apache_Iceberg活用入門/00-总览与阅读地图.md](../Apache_Iceberg活用入門/00-总览与阅读地图.md)——DuckLake 与它们同代竞品，读法互参。

## 🔧 实测环境总声明

本机 Windows 11（16 核 / 内存上限 25 GiB）、Python 3.13.2、`pip install duckdb` 即得 **DuckDB 1.5.5**（2026-07-22 发版）；pandas 3.0.2、polars 1.44.2、pyarrow 已装。全书各章的 🔧 数据均出自本目录工程在 `D:\develops\tmp\dbwave_duckdb\` 的临时脚本（repo 零产物），方法可复述、数字可复跑（具体机器会有差异，以量级为准）。CLI（独立二进制）本机未安装，涉及处标 ⚠️。
