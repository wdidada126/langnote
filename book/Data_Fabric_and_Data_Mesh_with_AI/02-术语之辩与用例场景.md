## 3. 深读笔记

**3.1 "术语章值不值 26 页"的读法。
** 短视者跳过，行家知道：fabric 类术语的**定义战争**才是落地事故的头号来源（POC 各说各话）。
判断一本书术语章质量的试金石是它是否给出**可伪证的定义**——即"一个系统缺了 X 就不算 fabric"。
✅ 外部参照：IBM 词条给出的"抽象/统一访问/元数据驱动/建议自动化"四件套（ibm.com/think/topics/data-fabric，2026-09-27 复测 200）即是这种可验定义；
⚠️ 推定本书 ch2 以能力清单方式收口，因为 ch5 标题就是"Key Capabilities"。

**3.2 mesh 一词在本书的转义风险。
** #201 原著四原则（域所有权/数据即产品/自助平台/联邦治理，见 [../Data_Mesh/00-总览与阅读地图.md](../Data_Mesh/00-总览与阅读地图.md)）是强承诺定义；
本书 ch2 在合流语境下引用 mesh 时容易弱化为"域分数据+中心化平台"的温和版——读者应区分**mesh-as-architecture**（原教）与 **mesh-as-vocabulary**（本书借词）。
这是三线合流册的结构性代价：每个词都要过一遍"谁的 mesh"。
⚠️ 本目录对作者的这一读法为解释性重构而非指控。

**3.3 用例光谱作为选型工具。** ch3 的工程价值在"先对号再选型"。
可操作化（⚠️ 重构）：每类用例打三列分——语义集中度需求、组织分权度需求、数据可移动性约束（合规/成本）。
前两列差值大→选对应极；
第三列硬约束→直接排除需物化搬运的一极。
**用例打分矩阵**比任何厂商成熟度模型都诚实，因为它把"我们是谁"放在"它有什么"之前。

**3.4 🔧G1：数据产品即 schema 的最小可运行类比**（DuckDB 1.5.5，本机跑测；
**非本书引擎/平台行为**）。
把 mesh 的"数据产品"降维成可运行的对象：一个域=一个 schema，一个产品=一张表+注册表一行元数据（FQN/owner/SLA/版本）。
实测：`sales.orders`(20 万行)/`logistics.shipments`(5 万行)/`iot.readings`(30 万行) 三产品共 55 万行，注册表 3 条；
产品注册表驱动跨产品 join（orders⋈shipments, amount>300）命中 20000 行，含建数全程 44.3ms。
读数：① owner/SLA 只是注册表列，**没有引擎强制**——正如 mesh 的"产品契约"多数平台只记账不执法；
② 跨 schema join 无摩擦，恰演示"平台层自助"是域自治不崩的前提（ch3 用例打分第三列在单机上永远绿灯，真实约束在合规网络里）。

## 4. 边界与易混点

- **fabric ≠ 产品 Microsoft Fabric**（00 §4 防混表）；
  本书 ch16 讨论厂商供给时两词并置，翻译引用需加限定语。
- **fabric ≠ 老 EAI/ESB**：ch2 必须划的界——主动元数据回路（发现→建议→执行）是否存在是新旧分水岭（对读 #210 05 章）。
- **mesh ≠ 每个域一套数仓**：无产品化契约的域拆分只是把数仓复制 N 份（#201 06 章的"旧架构换皮"批评适用）。
- **用例 ≠ 能力**：ch3 的场景清单不能直接当 ch5 的采购核对单，中间隔着"场景→能力→特性"的映射层，⚠️ 本书可能未显式给出，本目录笔记在 03 章文件里补做。

## 核心概念速览（中英对照）

| 中文 | 英文 | 一句话 |

| 领域所有权 | domain ownership | mesh 第一原则：产生数据的团队对数据负责 |

| 织点 | fabric node/connection | 被主动元数据登记并可被自动连接的源/目标 |

## 最新演进与工业实践

- **2024→2026 词义战报**：① "data product" 已进入 Iceberg/Polaris/Unity 三家目录规范的产品建模议程（catalog 从管表到管产品，✅ 各官方文档站点）；
② Fabric 产品阵营与 fabric 范式阵营在 2024 后达成危险的词汇合流——Gartner 类报告用词需逐处消歧；
③ mesh 原教（#201）与工程简化版分野明朗：学界审稿人开始要求 mesh 论文给出"产品契约的可验证定义"。
- **工业实践**：跨域数据产品在强监管行业以"数据交换协议+合同化 SLA"落地（欧洲医疗/金融的数据空间 Gaia-X/IDSA 系，✅ idsa-hq.com 框架文档）；
国内数据空间试点与"数据要素×"行动提供同构的中文语料——术语立宪在国际上正从"两词之争"转向"契约语法之争"。
- **选型工法**：先跑 3.3 的打分矩阵再约厂商演示；
  演示脚本里塞一个 ch3 光谱外用例（如实时风控特征）测其声明能力的边界带——比看功能清单有效一个量级。
