## 3. 深读笔记

**3.1 "删了什么"检验。** 本章标题用 Relevant 一词自我设限——只讲**相关**概念。
对 fabric/mesh 读者，最相关的三个 ML 事实其实不是算法而是：① **评估瓶颈=标注瓶颈**（监督学习的税单，直接解释为何 ch13 智能编目以"预打标+人抽检"为人机协议）；
② **数据质量决定收益上限**（garbage-in 定理，DCAI 范式的通俗面，✅ Crossref 10.1145/3711118）；
③ **模型的遗忘与漂移**（没有持续数据供给模型即腐烂，→ch9 反馈环）。
⚠️ 推定本书以 ML 术语清单方式覆盖 ①② 而弱化 ③——2023 年"LLM 时代的数据回流"议题尚未定型，这是本书的时间胶囊属性。

**3.2 嵌入（embedding）是两线的枢纽概念。
** 对线 B（AI for data）：表和列的语义嵌入让"发现相似数据集"成为最近邻检索，织点匹配从规则走向向量空间；
对线 C（data for AI）：语料的嵌入索引即 RAG 底座。
一个概念同时服务两条线，正是三线合流册需要专设 ML 章的深层理由。
✅ 延伸取证：向量检索工程在盘上已有专册 [../Vector_Databases/00-总览与阅读地图.md](../Vector_Databases/00-总览与阅读地图.md)，本章读到嵌入即跳转对读，不必在本书内求全。

**3.3 评估素养被多数同类书低估。
** ch8 实体解析的效果口径（precision/recall 之辨）完全立基本章的混淆矩阵教学。
工程上最痛的悖论：ER 的 ground truth 本身要靠 ER——**评估的递归**。
⚠️ 本书作为咨询系著作是否会直面该悖论存疑；
本目录立场：必须直面，否则读者会在真实项目里把"匹配率 95%"读成质量达标（05 文件 🔧G4 用本机数据演示 precision 假象）。

**3.4 时代断代：2023 年中的 ML 章。
** 成书时点恰在 ChatGPT 冲击波第一浪（2022-11）与 GPT-4 普及（2023-03）之间，章内 DL 部分最可能止步于 Transformer/预训练范式，而无（或在后记补）指令微调、少样本、检索增强。
读法：把本章当"古典 ML 素养"必修，把 GenAI 增量放到各章「最新演进」节补课（本目录已如此处理）。

**3.5 与盘上读物的替换关系。

## 4. 边界与易混点

- **ML ≠ AI ≠ DL 的日常混用**：本书章题并列 ML and DL，书名却只写 AI——三层词的用场差异（营销层 AI/工程层 ML/实现层 DL）值得在第一遍就钉死。
- **"模型"一词双关**：数据模型（data model）与 ML 模型在 ch6–9 高频相邻，笔记转写必须加限定词——本书翻译版（若出）在此必埋雷。
- **监督学习≠有标签的数据库**：K1 元数据"打标"是标签供给问题（半监督/弱监督），与教科书监督学习有偏差，ch13 展开。
- **概念章不产生选型结论**：任何"因为用了深度学习所以架构更好"的论证都不合法——能力必须回到 K 域记分（03 文件 2.2）。

## 核心概念速览（中英对照）

| 中文 | 英文 | 一句话 |
|---|---|---|
| 监督/无监督学习 | supervised / unsupervised learning | 有无标签两种学习体制，决定打标税的轻重 |
| 自监督学习 | self-supervised learning | 从数据自身构造监督信号，GenAI 时代的标签解放路径 |
| 嵌入 | embedding | 把列/表/文档映射为向量，两线（AI for data / data for AI）的枢纽 |
| 特征工程 | feature engineering | 把原始属性变成模型可食原料，ER 相似度之根 |
| 混淆矩阵 | confusion matrix | precision/recall 的记账底稿 |
| F1 值 | F1 score | 精确率与召回率的调和平均，单指标神话的来源与终结 |
| 预训练语言模型 | pretrained language model | 通用语义表征的廉价供给者，ch13 的前提 |
| 检索增强生成 | retrieval-augmented generation (RAG) | 以外部语料约束生成，语料组织即架构问题 |
| 标注瓶颈 | labeling bottleneck | 监督学习的税单，人机协议设计的出发点 |
| 概念漂移 | concept drift | 输入分布随时间偏移，目录与模型的共同腐烂引擎 |
