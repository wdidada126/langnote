## 版本与 ISBN

- 原名：*The Quick Python Book, 4th Edition*（Naomi Ceder 等）
- 英文 4e ISBN：9781633436336；出版社：Manning（2025）
- 定位：面向「有其他语言经验者」的紧凑 Python 入门到中级，强调标准库与现代实践。

## 版本演进（覆盖 3.13）

- 4e 相对 3e 更新至 Python 3.13，新增 AI 编码工具（Copilot、Colab）相关内容与交互式 notebook。
- 本笔记按 3.12–3.14 校准：PEP 695 类型参数、free-threading、异常组等。
- 🔧 各章具体页码以实体书/官方目录为准（本目录用「原书 pp. 第 N 章」标注）。
