# 概念专篇 · 数据文件处理流水线

> 跨章参考：把[第20章 Basic file wrangling](../20-Basic file wrangling.md)、[第21章 Processing data files](../21-Processing data files.md)、[第23章 Saving data](../23-Saving data.md) 串成一条可复用流水线。

## 典型流水线

```
读取(路径) → 解析(CSV/JSON) → 清洗(缺失/类型) → 转换(聚合) → 写出(持久化)
```

## 关键决策

| 环节 | 推荐 | 避免 |
|---|---|---|
| 读路径 | `pathlib.Path` | 字符串拼 |
| 解析 CSV | `csv.DictReader`/`pandas` | 手搓 split |
| 解析 JSON | `json`（`ensure_ascii=False`） | 信任外部 pickle |
| 清洗 | `pandas`/`polars` | 循环改 list |
| 持久化 | SQLite/JSON | 外部 pickle |

## 健壮性

- 先收集文件列表再操作，避免遍历中改结构导致遗漏。
- `try/except` 包裹单文件，避免一个坏文件中断整批（见[第14章 Exceptions](../14-Exceptions.md)）。
- 重要文件删除用 `send2trash` 进回收站。

## 版本演进

- `tomllib`（PEP 680，3.11）读配置；`zoneinfo`（PEP 615）时区。
- `polars` 惰性执行适合大文件；NumPy 2.0 移除旧别名。
