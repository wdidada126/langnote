## 核心精讲

```
# 教学示意，不参与构建
def add(a: int, b: int = 0) -> int:
    return a + b
print(add(3), add(3, 4))
# 高阶
def apply(f, x):
    return f(x)
```

- 参数默认值在定义时求值一次（勿用可变默认）。
- 函数是一等对象，可作参数/返回值。
- 类型标注（PEP 484）提升可读性。
