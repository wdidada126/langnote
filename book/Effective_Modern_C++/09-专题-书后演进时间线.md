## 核心概念速览（中英对照）

- **类模板实参推导** — CTAD (class template argument deduction)：C++17 起声明对象可不写模板实参。
- **编译期分支** — `if constexpr`：C++17 起按常量条件裁掉整条分支，标签分派的主要继任者。
- **保证的拷贝消除** — guaranteed copy elision：C++17 prvalue 直接在目标存储上初始化。
- **视图类型** — `std::string_view` / `std::span`：按值的只读序列句柄，重写了「传参成本」章节。
- **概念** — concepts：C++20 的约束语法，万能引用重载难题的官方解。
- **可连接/可取消线程** — `std::jthread` / `std::stop_token`：C++20 对 Item 37 的收编。
- **协程** — coroutines：C++20 `co_await/co_yield/co_return`，任务化编程的语言层兑现。
- **发送者/接收者** — senders/receivers（`std::execution`）：P2300 的异步执行模型，C++26 库组件。
- **推导 this** — deducing this：C++23（P0847R7）成员函数按调用对象类别取 `this`。
- **仅移动函数包装器** — `std::move_only_function`：C++23（P2387R3），`std::function` 的移动-only 兄弟。

## 时间线：标准侧发生了什么

```text
2014  本书出版（O'Reilly，9781491903995，✅豆瓣「更多版本」核实）
2017  C++17：CTAD｜if constexpr｜string_view｜optional/variant｜内联变量｜filesystem
      ｜保证拷贝消除｜**求值序修订**（make_* 异常安全论据被语言吸收）｜[[maybe_unused]]｜try_emplace
2020  C++20：concepts｜ranges｜coroutines｜jthread/stop_token｜atomic::wait/notify
      ｜latch/barrier/semaphore｜span｜source_location｜constinit｜三向比较｜模板 lambda/
      unevaluated lambda｜[=, *this]（隐式捕 this 弃用）｜atomic<shared_ptr>｜move-only call wrapper 酝酿
2023  C++23：deducing this（P0847R7 ✅核实）｜move_only_function（P2387R3 ✅核实存在）
      ｜expected｜to_underlying｜out_ptr/inout_ptr｜static_assert 可省消息
2026  C++26（编制中）：std::execution（P2300R10 ✅核实存在，cppreference 登记为 C++26 组件，
      ⚠️ 收录会次未核）｜contracts 多轮反复（P2388R4「Minimum Contract Support」✅核实存在——
      注意：它是**契约检查**提案，与「参数推导」无关，见勘误节）
```

**勘误（写作过程中被核实推翻的假设，留档以示诚实）**：

1. 「P2388 是参数推导相关提案」——❌ 经查 P2388R4 是契约检查（Minimum Contract Support），
   与参数推导无关；本目录不引用其支撑任何推导结论。
2. 「P0292R2 的标题是『Tag Dispatching is Out, If-constexpr is In』」——❌ 该口号出自
   VC++ 团队博客（Billy O'Neal，2015）⚠️ 原 URL 本次未检索到；P0292R2 实为
   Jens Maurer 的 constexpr if 语法文档。两处已在 [03 章](03-转向现代C++.md) 分列。
3. 「make 函数的异常安全论据」——🔶 C++17 求值序修订后失效一半；[04 章](04-智能指针.md) 已注明版本分界。
4. 未能核实项（全文一律 ⚠️ 不展开）：O'Reilly 官方英文章名逐字、P2300 收录会次、
   SC22 德国 volatile 意见书文档编号、`make_unique` 缺席 C++11 的会议过程细节。

## 读完本篇应该带走的一句话

**这本书的条款会过时，它的账本不会**：每一次语言「善意更新」（CTAD、jthread、
try_emplace）都在偿还 2014 年留下的某张欠条，而记账方法——动机→机制→权衡→相邻概念——
就是本书 42 条教的那件事。
