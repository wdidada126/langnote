# 精通Rust

## 版本与 ISBN

- 原书名：*Mastering Rust, Second Edition*（Packt）
- 作者：Rahul Sharma、Vesa Kaihlavirta；译者：邓世超
- 中文版：《精通Rust（第2版）》，人民邮电出版社，2021-01
- ISBN：`978-7-115-55254-9`（472 页，CNY 139）

> 2026-09-22 由 202608 月度笔记（20260806 Rust 书单）整理。

## 笔记

- 定位：从基础语法到高级主题（类型系统、并发模型、宏、FFI、网络编程、HTTP、数据库、WebAssembly、GTK+、GDB 调试）。
- 适合已有 C/C++/Python 基础、想系统进阶 Rust 的中级程序员。
