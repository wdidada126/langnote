# 第 6 章 形式化关系查询语言

> 三种形式化查询语言：**关系代数**（过程式）、**元组关系演算**（TRC，声明式）、**域关系演算**（DRC）；**关系代数与 SQL 的对应关系**、表达能力等价性、安全性（safe expression）。

## 一、核心精讲

### 6.1 🔧 三类语言
- **关系代数**：过程式，给运算序列（σ/π/⋈/∪/−/×/ρ/÷）；**元组关系演算**：`{t | P(t)}`，声明「要什么」；**域关系演算**：`{<x,y> | P(x,y)}`（🔧 后两者声明式，是 SQL 的理论源头；SQL 基本等价于关系代数+聚合扩展）。

### 6.2 等价性
- Codd 定理：关系代数、安全的 TRC、安全的 DRC **表达能力等价**（🔧 任何 SQL 查询都能转成关系代数表达式，这是查询优化的基础，见第 13 章）。

### 6.3 除运算（division）
- 「对所有…」类查询（如「选了所有课程的学生」）（🔧 SQL 无直接对应，常用 `NOT EXISTS` 双重否定实现）。

## 二、版本演进 / 论文 / 前沿

- 论文：Codd（CACM 1970）；Codd 关系完备性（1972）；Ullman《Principles of Database and Knowledge-Base Systems》。
- 工业界：查询优化器内部就是关系代数重写（🔧 理解本章有助于读懂执行计划 `EXPLAIN`）。
