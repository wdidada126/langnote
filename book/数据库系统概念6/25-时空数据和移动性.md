# 第 25 章 时空数据和移动性

> **本章地图**：**空间数据**（几何对象：点/线/面；栅格）→ **空间查询**（包含、相交、距离、**最近邻 NN**、**范围查询**）→ **空间索引**（**R-树**及其变体 R\*-树、四叉树、网格文件、k-d 树、四叉/希尔伯特曲线降维）→ **时间数据**（**有效时间 / 事务时间**、时态数据库、SQL:2011 的 `PERIOD` 与 `SYSTEM_TIME`）→ **移动对象数据库**（轨迹、位置更新策略、预测查询）→ **移动性与断连操作**（移动数据库、缓存失效与广播、位置相关服务）→ 现代：**PostGIS / GeoMesa / H3 / S2 与手机信令/网约车轨迹**。

## 二、核心精讲

### 25.1 空间数据模型
- **几何类型**：`POINT`、`LINESTRING`、`POLYGON`（含 hole）、`MULTI*`、`GEOMETRYCOLLECTION`；**栅格（raster）**（影像/DEM）。
- **坐标参考系 SRID**：WGS84（4326，经纬度）、Web Mercator（3857）、高斯-克吕格/CGCS2000（中国）；**投影与距离单位**是空间计算最常见的错误来源（用 4326 直接算 `ST_Distance` 得到的是"度"，不是米）。
- **标准**：OGC **Simple Feature Access (SFA)**、WKT/WKB 表示；SQL/MM Spatial；**GeoJSON**（RFC 7946）。

### 25.2 空间查询与谓词
- 拓扑关系（DE-9IM 模型）：`ST_Contains / Within / Intersects / Touches / Crosses / Overlaps / Disjoint`。
- 度量：`ST_Distance`、`ST_Buffer`、`ST_Area`、`ST_Length`。
- **最近邻（kNN）**与 **空间连接（spatial join）**：`ST_DWithin` + 索引；kNN 用 **best-first 遍历 R-树**（Hjaltason & Samet, 1995）或 `ORDER BY geom <-> point` 的 **KNN 索引算子**（PostgreSQL `<->`）。
- 🔧 现代扩展：**路网距离**（pgRouting，A*/Dijkstra）而非欧氏距离；**多边形内点判定**用射线法；**射线/瓦片金字塔**用于大规模可视化。

### 25.3 空间索引
| 索引 | 思想 | 评价 |
| --- | --- | --- |
| **网格文件（grid file / 均匀网格）** | 空间切成等大单元 | 简单，数据分布不均时退化 |
| **四叉树（quadtree）** | 递归四分 | 适合栅格与点数据 |
| **k-d 树** | 逐维二分 | 点数据，动态更新退化 |
| **R-树**（Guttman, SIGMOD 1984） | 层级 **MBR（最小外接矩形）** 分组 | **事实标准**，PostGIS/Oracle/MySQL 均用 |
| **R\*-树**（1990） | 优化插入的覆盖/重叠/周长 | R-树的主流改进版 |
| **空间填充曲线**（Z 序 / **Hilbert**） | 二维→一维降序，复用 B 树 | 分布式系统（GeoMesa、HBase、S2）首选 |

- 🔧 工程要点：R-树的 MBR 重叠导致多路径搜索；**Hilbert 曲线**在保持局部性的同时可直接用 B+ 树，是**分布式空间索引**（GeoMesa 的 Z3/XZ3、Google S2、Uber H3）的基础。
- 🔧 **H3**（Uber, 2018）用六边形全球网格做聚合与可视化，是网约车/外卖行业的实际标准之一。

### 25.4 时间数据与时态数据库
- **有效时间（valid time）**：事实在现实中为真的时间段；**事务时间（transaction time）**：该事实在数据库中被记录的时间段。**双时态（bitemporal）**同时支持两者。
- **SQL:2011** 引入：`PERIOD`、`AS OF SYSTEM TIME`、`FOR SYSTEM_TIME`、`SYSTEM_VERSIONING`（**系统版本表 / temporal table**）。落地：SQL Server 2016 temporal tables、MariaDB/MySQL 的系统版本表、Oracle Flashback。
- 🔧 现代等价物：**CDC + 快照表 + 事件溯源（Event Sourcing）**；**湖仓的 time travel**（Iceberg/Delta 的 `VERSION AS OF` / `TIMESTAMP AS OF`）本质上就是事务时间维度。

### 25.5 移动对象数据库
- **轨迹（trajectory）**：随时间变化的位置序列；建模方式：**MOST 模型**（位置 = 时间的函数 + 运动向量）、**离散采样 + 插值**。
- **位置更新策略**：距离/时间/速度阈值触发更新（dead reckoning），平衡精度与通信量。
- **查询类型**：**范围查询**（某时段在某区域内）、**最近邻**（离我最近的出租车）、**预测查询**（t 分钟后它在哪）、**轨迹相似度**（DTW、LCSS、EDR）。
- 🔧 工业形态：网约车/物流的 **轨迹压缩（Douglas-Peucker）与地图匹配（map matching, HMM）**；存储和查询常落在 **时序数据库 + 空间索引**（ClickHouse + 网格索引、TDengine、或专门的 **MobilityDB**（PostgreSQL 扩展，SIGMOD 2020 论文））。

### 25.6 移动数据库与断连操作
- **移动计算约束**：电池、带宽、频繁断连、位置变化。
- **数据广播（data broadcast / 广播磁盘）**：服务器周期性广播热点数据，客户端被动收听（可扩展到无限客户端）。
- **缓存失效**：断连后缓存可能过期 → 广播**失效报告（IR）**、**时间戳策略（TS）**、**签名（signature）**方案（Barbara & Imielinski, SIGMOD 1994）。
- **复制与同步**：弱一致副本 + 冲突解决；现代形态是 **local-first / CRDT**（Automerge、Yjs）与移动端离线同步（CouchDB/PouchDB 的同步协议）。
- 🔧 本章的「移动数据库」在 2020 年代的实际载体是 **移动端本地数据库（SQLite/Realm/WCDB）+ 增量同步**，而非专用移动数据库系统。

## 四、近年研究与工业界开源实践

- **近年研究**：**轨迹表示学习**（t2vec, AAAI 2018；TrajBERT 系列）与轨迹相似度学习；**路网匹配与时空预测的深度学习**（ST-ResNet、Graph WaveNet、DCRNN）；**大规模空间连接**（*Hadoop-GIS / SpatialHadoop*, ICDE 2015；*Simba*）；**时空数据的压缩与列存**（Parquet + 空间分区（GeoParquet））。
- **工业界开源**（star 数 2026-09 实测）：
  - `postgis/postgis`（≈2.2k★）：PostgreSQL 的空间扩展，**本章最好的实践靶场**（R-树 GiST 索引、`ST_DWithin`、KNN `<->`、栅格与拓扑）。
  - `locationtech/geomesa`、`geo` 生态；`uber/h3`（≈6.6k★）与 `google/s2geometry`（≈2.7k★）：分布式空间索引库。
  - `pgRouting/pgrouting`：路网分析（Dijkstra/A\*/TSP）。
  - `clickhouse/clickhouse`（≈50.1k★）：大规模点/轨迹的分析（GeoHash 索引、`geo` 函数）。
  - `duckdb/duckdb`（≈41.7k★）+ `duckdb/duckdb_spatial`：GeoParquet 时代的轻量空间分析。
  - `MobilityDB/MobilityDB`（≈0.6k★）：PostgreSQL 上的移动对象数据库，直接对应本章 25.5 的理论。

## 五、常见误区与本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "经纬度可以直接算米" | SRID 4326 是角度单位；需 `geography` 类型或投影转换 |
| 2 | "空间索引就是 B 树加两列(lat, lng)" | 二维无法用单一 B 树有效索引；需 **R-树 GiST / SP-GiST** 或空间填充曲线 |
| 3 | "最近邻先按距离排序再取 1 条" | 全表扫描；应用 **KNN 索引算子**（`<->`）或 R-树 best-first 遍历 |
| 4 | "时态数据加个 updated_at 就是双时态" | 有效时间 ≠ 事务时间；双时态需两套时间维（SQL:2011） |
| 5 | 🔧 本书视角 | 移动数据库部分（广播、断连同步）已转化为 **local-first/CRDT 与移动端同步**；空间部分应补 **H3/S2、GeoParquet、轨迹学习** |
