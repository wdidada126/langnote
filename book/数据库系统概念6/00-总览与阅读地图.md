# 《数据库系统概念》（第6版）阅读地图

- 原书名：*Database System Concepts*（6th ed），Abraham Silberschatz / Henry F. Korth / S. Sudarshan；中文版《数据库系统概念（第6版）》，豆瓣 10548379；官网 db-book.com
- 定位：数据库领域的「百科全书式教材」，覆盖**关系模型 → SQL → 设计 → 存储/查询 → 事务 → 体系结构 → 数仓/检索 → 特殊模型 → 案例（PostgreSQL/Oracle/DB2）**。与并发系列互补：本书第 15 章「并发控制」是数据库侧的并发（两阶段锁/时间戳/MVCC），与 Java 并发（AQS/内存模型）是不同层面但思路相通。

## 阅读路径建议

- **必读主线**：2-5（模型与 SQL）→ 7-8（设计/范式）→ 10-13（存储/索引/查询优化）→ 14-16（事务/并发/恢复）。
- **按需**：17-19（体系/并行/分布式）、20-21（数仓/检索）、22-23（对象/XML）、27-29（具体数据库案例）。
- **与并发系列交叉**：Ch15 并发控制的**两阶段锁（2PL）**、**时间戳排序**、**MVCC（快照隔离）** 与 Java 并发的锁/无锁/内存模型对照阅读效果最好。

## 本书没覆盖的缺口（2026 视角）

- NewSQL/HTAP（TiDB、CockroachDB）、云原生数据库（Aurora、PolarDB）、存算分离。
- 向量数据库与 AI 检索（pgvector、Milvus）——第 21 章信息检索的现代延伸。
- 向量化/编译执行（Velox、DuckDB）、湖仓一体（Iceberg/Delta/Hudi）、确定性事务（Calvin/Aria）。
