本书以 **Snowflake / BigQuery / Redshift** 为主要目标引擎。为帮助本地学习，每章提供 ≥ 4 组 DuckDB/SQLite 类比：

| # | dbt 概念 | DuckDB 类比 | SQLite 类比 | 标注 |
|---|---------|-------------|-------------|------|
| 1 | `ref()` 依赖 | `CREATE VIEW ... AS SELECT` 链式引用 | 同：VIEW 链 | 🔧 非本书引擎行为 |
| 2 | 物化 = table | `CREATE TABLE AS SELECT` | 同：CTAS | 🔧 非本书引擎行为 |
| 3 | 物化 = view | `CREATE VIEW` | 同：VIEW | 🔧 非本书引擎行为 |
| 4 | `source()` | 外部表 / `read_csv_auto()` | `.import` + 表 | 🔧 非本书引擎行为 |
| 5 | incremental | `INSERT OR IGNORE` + 去重 CTE | `INSERT OR IGNORE` | 🔧 非本书引擎行为 |
| 6 | `test` (not_null) | `COUNT(*) WHERE col IS NULL` 手动校验 | `CHECK` 约束 | 🔧 非本书引擎行为 |

## 核心概念速览（全书关键词云）

- **Analytics Engineering**: 软件工程实践应用于数据建模
- **ELT**: Extract-Load-Transform，区别于传统 ETL
- **dbt**: data build tool，SQL-first 变换框架
- **ref()**: dbt 模型间依赖引用机制
- **Materialization**: 物化策略（view / table / incremental / ephemeral）
- **Schema Test**: 基于 YAML 声明式数据质量测试
- **DAG**: 有向无环图，dbt 自动构建的依赖图
- **Semantic Layer**: 语义层，dbt metrics / dbt Semantic Layer
- **Data Mesh**: 去中心化数据架构（参见 #201）
- **Modern Data Stack**: Snowflake/BigQuery + dbt + reverse ETL
