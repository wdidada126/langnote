## 14.1 Definitions（定义，p.529）

- **Join Trees（529）**：连接图/树；left-deep 与 bushy；连接序搜索空间（n! 级与 `_optimizer_max_permutations` 上限——回扣 Ch12 慢解析）。
- **Types of Joins（534）**：内/左/右/全外/交叉/自然；实现算子层 NLJ、MERGE、HASH、CROSS、（PX 下 BROADCAST）与 SEMI/ANTI 变体；**FILTER 算子=相关子查询式连接，每父行执行，常为计划第一坏味**。
- **Restrictions vs Join Conditions（537）**：ANSI 化时代关键辨析——**外连接表上的过滤谓词放 WHERE 会退化外连接（Ch6 变换）并阻断分区裁剪（Ch13）**；`(+)` 旧语法 vs ON/USING 的合法位置；作者给"谓词归属"判定表。

## 14.2 Nested Loops Joins（p.538）

- Concept（538）：驱动行源 × 被驱动行源重复访问；成本≈驱动基数×内表单次访问；看 Starts。
- Two-Table（539）：内表索引列序/覆盖决定每行成本。
- Four-Table（541）：**连接序在 NLJ 下的杠杆效应**（LEADING hint 试验法，回扣 Ch10 Outline）。
- **Buffer Cache Prefetches（542）**：11g 的 NLJ 预取（`_nlj_batching_enabled`）把随机单块读批化为多块读——**"NLJ 一定随机 IO 慢"的现代修正**；观察位：计划不变但 `db file sequential read` 计数形态改变（⚠️ 转述）。

## 14.3 Merge Joins（p.544）

- Concept（544）：双排序后线性归并；两侧本就有序时排序消除复用。
- Two-Table（545）/ Four-Table（548）：排序来源（索引有序 vs SORT ORDER BY 成本前置）。
- **Work Areas（549）**：内存排序 vs 临时段落盘；one-pass/two-pass 退化；`V$SQL_WORKAREA*` 与 PGA 分摊（回扣 Ch9 PGA 节）；取证法=看 MEMOPTIMAL/ONEPASS 计数判工作区饥饿（⚠️ 转述）。

## 14.4 Hash Joins（p.555）

- Concept（555）：小侧建哈希表、大侧探测；ALL_ROWS 下批量等值连接的默认王。
- Two-Table（556）/ Four-Table（557）：**build/probe 侧选择由估算行数决定——基数错→侧反→灾难**（回扣 Ch2/Ch8）；hash 连接链（cascade）。
- Work Areas（559）：`V$SQL_WORKAREA_ACTIVE`、自动 PGA 分摊、落盘分区数。
- Index Joins（560）：HJ 与索引路径组合形态（与 13.3 INDEX JOIN 呼应）。

## 14.5 Outer Joins（p.561）

- 算子支持矩阵：HJ/MJ 支持外连接（NULL 补齐规则），NLJ 全支持；`FILTER` 作为外连接替代的劣化；ANTI（NOT EXISTS）原生算子化（11g+）。

## 14.6 Choosing the Join Method（选择判据，p.562）

- First-Rows（562）：小驱动集+索引内表→NLJ（首行快）。
- All-Rows（562）：大集合等值→HJ/MJ。**方法选择首先是优化模式的函数**。
- Supported Join Methods（562）：谓词形态约束——非等值连接只能 NLJ/FILTER（BETWEEN 连接、不等值连接的可行域）。
- Parallel Joins（563）：BROADCAST/PARTITION-WISE/分布策略与倾斜（Ch15 并行接口）。

## 14.7 Partition-wise Joins（p.563）

- 前提：两表同分区方案（同键同粒度）+ 连接条件含分区键。
- **Full（563）** vs **Partial（566）**：一方无对齐分区时以全局/本地索引补齐消除。
- 收益：各对各区独立 HJ、可并行、工作区需求骤降。
- 失效检查清单：分区键类型一致、无函数包裹、并行 DML 限制（⚠️ 转述）。

## 14.8 Star Transformation（p.568）

- 链路：事实表位图索引（含 join key）→ 维度过滤 → 位图 AND/EQUAL_MINUS → `BITMAP CONVERSION TO ROWIDS` 回事实表。
- `STAR_TRANSFORMATION` hint 与启用参数；子查询 STAR 形态。
- 与物化视图（Ch15）分工：**能建 MV 就别靠变换硬算**。

## 易混点与补记

- NLJ 的 prefetch（11g 默认）把"驱动行×回表"折叠成批量读：老手册"NLJ 必单块读"已过时（⚠️ 转述）。
- sort-merge 的内存工作区（work area）溢出走临时表空间，PGA 目标设定直接改写它的成本曲线。
- hash join 在 12c 已支持布隆过滤与分区裁剪联动，"hybrid hash"不再是手工双路。
- 分区连接（partition-wise join）要求键与粒度严格对齐，差一列就退化成普通连接。
- 星形转换由事实表上多个外键位图索引触发，维表过滤先行的计划形态认得出就省半天工。

## 核心概念速览（中英对照）

- **连接树** — Join Tree：连接序与形状（left-deep/bushy）
- **FILTER 算子** — 相关子查询式连接（每父行执行）
- **半/反连接** — Semi/Anti Join：IN/NOT EXISTS 的原生算子
- **限制条件 vs 连接条件** — Restrictions vs Join Conditions：谓词归属
- **NLJ 预取** — Buffer Cache Prefetches（NLJ batching）
- **归并连接** — Merge Join：排序换线性合并
- **哈希连接** — Hash Join：build/probe 两阶段
- **工作区** — Work Area：排序/哈希内存配额（one-pass 退化）
- **分区连接** — Partition-wise Join（full/partial）
- **广播** — Broadcast（PX）：小表全复制分发
- **星型变换** — Star Transformation：位图代数重构
- **BITMAP CONVERSION TO ROWIDS** — 位图回表算子
