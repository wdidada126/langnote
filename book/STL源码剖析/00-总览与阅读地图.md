## 全书结构：六大部件 × 八章目录

侯捷在书首把 STL 拆为**六大部件**（这是理解全书骨架的关键；网传「六分法」若作
Containers / Algorithms / Allocators / Functors / Subiterators / Space management，
那是 **SGI 官方文档的模块分类**，不是本书章目录——本目录以核实到的书结构为准）：

```text
STL 六大部件（本书观点）          原书八章目录（已核实于既有笔记）
─────────────────────           ──────────────────────────────
容器 Containers          ←──────→ 第4章 序列式容器 / 第5章 关联式容器
算法 Algorithms          ←──────→ 第6章 算法
迭代器 Iterators         ←──────→ 第3章 迭代器概念与 traits 编程技法
仿函数 Functors          ←──────→ 第7章 仿函数（函数对象）
适配器 Adapters          ←──────→ 第8章 配接器
空间配置器 Allocators     ←──────→ 第2章 空间配置器
                                 第1章 STL概论与版本简介（总纲）
```

**本目录 6 个文件如何覆盖 8 章**：01↔第 1 章；02↔第 2 章；03↔第 3 章；04↔第 4 章；
05↔第 5 章；06 把**第 6、7、8 章合并**为一篇（算法、仿函数、配接器三者本来就是同一条
「以函数对象驱动算法」的流水线，拆开讲解反而割裂）；07 为**专题补编**（不冒充原书章节）。
auto_ptr 与 temporary_buffer（SGI 文档的 Space management 模块）在本目录落在 06
（tempbuf 服务于 sort/merge 的暂存）与 07（现代演化对照），并在此处声明来源差异：⚠️ 原书对
这两者的确切归章未逐页核实。

## 三条阅读主线

1. **内存线（本书最硬的部分）**：`02` → `04` → `05`。两级配置器如何喂饱每个容器；
   vector 的「整块重分配 + 元素搬移」与 deque 的「分块 + map 索引」是两种对立的成长策略；
   hash 表的 resize 则是「配置 + 重新链接」。看懂这条线，容器就只是内存布局题。
2. **类型萃取线**：`03` → `06`。traits 机制是全书的语法底座——迭代器分类器、
   `iterator_traits` 三层回退、functor 的 typedef 约定、`select1st/select2nd` 取值萃取，
   全是同一招：用类型信息在编译期分派。现代视角请对照
   [../C++模板元编程.md](../C++模板元编程.md) 与 C++20 concepts。
3. **组件装配线**：`01` → `06`。容器存数据、迭代器定位、算法搬运、仿函数定制策略、
   适配器缝合——六大部件如何在 `sort(v.begin(), v.end(), greater<int>())` 一行里会师。

**最短路径**：只关心面试/工程速效 → `02` + `04` + `05`；想理解泛型编程思想 → `03` + `06`。

## 本书定位与现代视角

本书是**C++98 时代的源码解剖学**：它剖析的不是 ISO C++ 标准库，而是 SGI STL 这一份实现
（经 gcc 2.91 与 STLport 深刻影响过 libstdc++）。今天读它有三个价值与一个代价：

- 价值一：两级配置器、free-list、红黑树、链式 hash 这些**机制本身没有过时**，
  它们是 glibc malloc arena、jemalloc/mimalloc 分级缓存、absl::flat_hash_map 的祖先形态；
- 价值二：traits 是理解整个模板库生态（`<type_traits>`、iterator traits、allocator_traits）的钥匙；
- 价值三：它是极少数「带着你逐行看一份真实标准库实现」的中文书；
- 代价：书中 API 与容器家族（hash_map、slist、rope、auto_ptr、ptr_fun/bind1st、mem_fun）
  有一半已被标准淘汰或替换。**每章末尾的「最新演进与工业实践」就是补这笔账的**，
  现代 std::allocator 接口收缩、C++17 pmr、abseil、ranges 等都在那里对照实测（g++ 15.2）。

## 读完应该能回答的十个问题

1. 为什么 SGI 要把「64KB 以下」交给自管的 16 条 free-list，而不是全甩给 malloc？（`02`）
2. `round_up` 到 8 的倍数、chunk 申请量 `2×size×nobjs + heap_size>>4`，各自防住什么坏情况？（`02`）
3. 给定一个裸 `T*` 指针，`iterator_traits` 凭什么还能萃取出它的 `value_type`？（`03`）
4. vector 扩容为什么是「翻倍」而不是「+1」？deque 为什么能两头插还不搬元素？（`04`）
5. map 的 `operator[]` 和 insert 返回的 `pair<iterator,bool>` 各暴露了红黑树的什么能力？（`05`）
6. hash 表为什么用质数桶数？bucket 之间如何借 `slist` 完成整体搬迁？（`05`）
7. `accumulate` 的初值类型为什么决定了累加结果类型？这和 traits 有什么关系？（`03`、`06`）
8. `mem_fun` 到底把 `p->f()` 变成了什么签名？为什么需要 ref 版和 ptr 版两套？（`06`）
9. `get_temporary_buffer` 分配不到足够的内存时，`stable_sort` 会发生什么？（`06`）
10. 今天你要给一个高频分配的服务选内存方案：`std::allocator`、pmr、jemalloc，各在什么位置？（`07`）
