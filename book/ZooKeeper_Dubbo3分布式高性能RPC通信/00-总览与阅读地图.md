## 版本演进时间轴

- **2010** ZooKeeper 论文（USENIX ATC 2010）发表，ZAB 协议定型；ZK 成为 Hadoop 生态的协调服务事实标准。
- **2011–2012** 阿里巴巴开源 Dubbo（Dubbo 2.x），基于 ZK 做注册中心，默认 Dubbo 私有 RPC 协议。
- **2014** Dubbo 停更一段时间；同期 Spring Cloud（基于 HTTP/REST + Eureka/Consul）兴起。
- **2017–2018** 阿里巴巴重启 Dubbo，贡献回 Apache；Dubbo 成为 Apache 顶级项目（2019 毕业）。
- **2019** Dubbo 2.7 引入元数据中心、配置中心，开始去 ZK 强耦合。
- **2020–2021** Dubbo 3.0 发布：引入 **Triple 协议**（基于 gRPC/HTTP2，支持流式、跨语言、Protobuf）、
  **应用级服务发现（应用级注册模型）**、Proxyless 服务网格、统一路由规则。
- **2022-10** 本书出版，但内容仍停留在「ZK 注册中心 + Dubbo 2.x 风格 RPC + Nacos」视角，
  **未覆盖 Triple、应用级服务发现、云原生治理**——这就是「书名 Dubbo 3、内容 2.x」的时间错位。
- **2023–2026** Dubbo 3 持续演进：Triple 成为默认推荐协议，Spring Cloud Alibaba 整合成熟，
  Dubbo + Kubernetes + 服务网格（Proxyless）成为云原生主流组合。

- **ZooKeeper**：本书基于 3.x；下载、zoo.cfg、单机/集群部署（见 02、03）。
- **Curator**：Netflix/Apache 的 ZK Java 客户端封装（见 04）。

- **Nacos**：作为 ZK 的替代注册中心（见 07.11–07.14）。
- **JDK 8+ / Maven**：本书示例基于传统 Spring XML/注解配置。

## 跨语言对照

- **ZooKeeper**：服务端是 JVM，但客户端协议多语言（C、Python、Go 等官方/社区绑定）。
- **Dubbo 2.x 私有协议**：强 Java 绑定，跨语言弱（hessian 序列化亦偏 Java）。
- **Dubbo 3 Triple 协议**：基于 HTTP/2 + Protobuf，**跨语言**（兼容 gRPC 的 proto 契约），
  这是 Dubbo 3 相对本书内容最大的跨语言进步——本书完全未触及。
- **对照 gRPC**：`grpc/grpc-java`（12072★，2026-09 实测）是 Triple 的协议近亲；
  理解 Triple 必须先理解 gRPC 的四种方法类型（Unary / Server Streaming / Client Streaming / Bidirectional）。
