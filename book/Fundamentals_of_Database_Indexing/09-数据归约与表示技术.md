# 09 · 数据归约与表示技术（Part VI — Dimensionality Reduction & Data Representation）

> 对应原书 Part VI「Data Reduction Techniques」分部标题页（p.175）与两章：Dimensionality Reduction Techniques（pp.177–200）、Data Representation Techniques（pp.201–213）。✅ 章名/页码取自 Crossref；两章主题同为"把高维拉回可索引低维"，本目录合并为一文件（合并口径见 [00-总览与阅读地图.md](00-总览与阅读地图.md) §2）。这是全书"应对维数灾难"的正面答卷：**与其在高维硬剪，不如先把数据降到低维再索引。**

## 1. 归约 vs 表示：先分清楚

| 维度 | 目标 | 手段 | 结果 |
|---|---|---|---|
| **降维（dimensionality reduction）** | 减少坐标个数 | PCA/SVD、子空间、聚合 | 更低维的等价/近似点 |
| **数据表示（representation）** | 从原始对象造出可比较的特征 | 直方图、矩、词袋、签名、嵌入 | 把非结构化对象变向量 |

表示是"从无到有造坐标"，降维是"从多到少减坐标"；检索流水线常是"先表示、后降维、再索引（06/08）"。

## 2. 主成分分析 PCA（降维的旗舰）

给定点集 X（n×d，列中心化），PCA 找一组正交方向（主成分）使投影方差最大：

- 计算协方差 `C = XᵀX/(n−1)`，取前 k 个最大特征向量 `V_k`（k×d）。
- 降维映射：`x → V_kᵀ x`，d→k 维。
- **核心性质**：`V_k` 给出的是"k 维子空间中对 X 的**最小平方重构误差**"（Eckart–Young 定理），即 PCA 是最优线性降维。⚠️ 标准结论转述。

对检索的意义：若数据内在维度低（§07.4），前几个主成分就保住了绝大部分距离信息，在 k 维（k≪d）上建 R*-tree/子空间索引，重新获得可剪枝性。

## 3. SVD：PCA 的计算实现

对 X 做奇异值分解 `X = U Σ Vᵀ`，取前 k 个奇异值对应分量 `X_k = U_k Σ_k V_kᵀ` 即 rank-k 最优逼近。

- 与 PCA 等价（对中心化数据，右奇异向量=主成分）。
- 文本场景的 **LSA（潜在语义分析）** 就是对词-文档矩阵做截断 SVD，把"词表维（上万）"降到"语义维（百级）"，是本书表示+降维的合体应用。⚠️ 转述。

## 4. 非线性/其他降维（点到）

- **MDS / 等距映射（Isomap）**：保距/保流形几何，适合非线性低维流形。
- **随机投影（Johnson–Lindenstrauss）**：用随机矩阵把 d 维降到 `O(log n / ε²)` 维，**近似保两两距离**——是 LSH 类近似的理论基石，工程实现极简。⚠️ 转述（JL 引理）。
- **k-匿名/离散化/抽样**：偏统计的"归约"，本书在数据归约语境亦及（非检索主线）。

## 5. 数据表示技术（把对象变成可索引向量）

- **直方图 / 矩（moments）**：图像颜色直方图、灰度共生矩阵；低维、可 L1/L2 比较，是经典 CBIR 表示。
- **小波 / 傅里叶系数**：抓主频能量，用前若干系数代表信号。
- **词袋 / TF-IDF**：文本→高维稀疏向量，配合 §3 LSA 降维。
- **签名类（MinHash/SimHash）**：集合/文档→定长短码，配海明距离（05 章）做近似去重/相似。
- 现代：深度**嵌入（embedding）**——本书时代尚未普及，2026 已是默认表示层（见"最新演进"）。⚠️

## 6. 🔧 实测：截断 SVD/主成分对"内在维度"的显形（非本书引擎行为）

"降维能否恢复距离区分度"可用 Python/NumPy（DuckDB 不内建向量检索）在合成低秩数据上直接验证——这也是 §07 距离集中实验的正向对照。

🔧 实测（NumPy，seed=42；构造内在维度=3 的 200 维数据：真实信号 3 维随机，经随机投影矩阵 A(3×200) 升到 200 维，n=800，查询点 q 亦随机）：
- **表观 200 维**：`d(q,NN)/d(q,FN) = 0.2465`。
- **截断 SVD 降到 3 维**（保留前 3 主成分、q 同投影）：比值降到 **0.0384**（NN 更显著小于 FN，区分度大幅恢复，约 6.4×）。
- **前 3 主成分解释方差 = 1.0000**（因数据严格 rank-3）；非零奇异值个数恰为 **3**——即表观 200 维、内在维度仅 3 被 PCA 精确认出。
→ 实证 §2/§07.4：内在维度低的表观高维数据，降回内在维后**距离比值骤降、重新有信息量**，剪枝/索引随之可行；"奇异值非零个数 = 内在维度"是 §4 判据的直接演示。脚本 `D:\develops\tmp\dbwave_w5_fdbidx`（临时件）。**非本书引擎行为**（NumPy 合成数据，仅演示降维几何效应，与 §07 的 iid 高维实验形成正/负对照）。

## 8. 常见误区（⚠️）

- "PCA 万能"：它是**线性**最优，非线性流形（人脸姿态）需 Isomap/自编码；且 PCA 保方差 ≠ 保判别（分类要 LDA）。
- "降维一定保距"：PCA 保重构误差、JL 随机投影近似保距，一般 PCA 不严格保 kNN 序，需回原维验证或用保距型降维。
- "表示与索引无关"：表示决定坐标分布，直接决定包围盒紧不紧、重叠大不大（连 §06）。坏表示 = 再好索引也白搭。

## 5.5 PCA 的五步手算流程（把 §2 变成可操作）

给定 n×d 数据矩阵 X（行=样本）：

1. **中心化**：每维减均值，`X ← X − mean(X, axis=0)`（PCA 只处理协方差，不含均值偏移）。
2. **求协方差** `C = XᵀX/(n−1)`（d×d），或对大 d 直接对 X 做 SVD 绕开 d² 矩阵。
3. **特征分解 / SVD**：取 C 的最大 k 个特征向量，或 SVD 右奇异向量前 k。
4. **投影**：`Z = X · V_k`（n×k），数据降到 k 维。
5. **解释方差比** `λᵢ/Σλ`：决定 k 取多大（如"累计 95%"）；🔧 §6 正是看这条比值=1.0000 判内在维=3。

工程提示：d 很大时不建 `d×d` 协方差（内存爆炸），走 SVD / 随机 SVD / 增量 PCA；样本多且流式用 incremental PCA。⚠️ 标准实践转述。

## 5.6 降维家族对照：PCA / LDA / Kernel PCA / t-SNE（何时用哪个）

| 方法 | 目标 | 线性? | 保什么 | 检索适配 |
|---|---|---|---|---|
| PCA | 最大方差/最小重构误差 | 线性 | 全局方差/近似距离 | ✅ 保距度好，可索引 |
| LDA | 最大类间/类内比 | 线性 | 判别方向 | 分类友好，非纯检索 |
| Kernel PCA | 非线性流形上的 PCA | 非线性 | 核空间方差 | 需回原空间验证 |
| t-SNE / UMAP | 保局部邻域、可视化 | 非线性 | 局部结构 | ❌ 全局距离失真，不宜做检索索引 |

关键坑：**t-SNE/UMAP 为可视化设计，两点远近不携带可检索的距离语义**，拿来建 ANN 索引会崩；检索用 PCA/JL 保距型降维。⚠️ 实践提醒（本书时代 UMAP 尚未普及，属 2026 补充）。

## 5.7 检索流水线：表示 → 降维 → 索引（09/08 缝合）

把全书收进一条可落地流水线（⚠️ 综合梳理）：

1. **表示（§5）**：对象→高维原始向量（直方图/TF-IDF/嵌入）；决定"距离是否有语义"。
2. **预处理（05 §5.7）**：归一化/标准化；决定"哪个维主导距离"。
3. **降维（§2/§4）**：PCA/JL/PQ 把表观高维拉向内在低维；决定"剪枝是否还有效"（连 §07）。
4. **索引（06/08）**：在降维后的空间建 R*-tree/子空间过滤（精确）或 IVF/HNSW/LSH（近似）。
5. **回验/召回控制**：近似或降维后按需回全维精算，监控 recall@k。

本书的六 Part 恰好被这条线一次串起——这也解释了为何把"表示/降维"（09）放最后：它是前面一切"结构能否在高维成立"的前提阀门。

## 核心概念速览（中英对照）

- **降维** — Dimensionality reduction：减少特征坐标个数，恢复可索引性。
- **数据表示** — Data representation：从原始对象构造可比较的特征向量。
- **主成分分析（PCA）** — 找最大方差正交方向的最优线性降维。
- **SVD / 截断 SVD** — 奇异值分解；rank-k 逼近 = Eckart–Young 最优。
- **Eckart–Young 定理** — 截断 SVD 给出最小平方重构误差的降维。
- **潜在语义分析（LSA）** — 对词-文档矩阵截断 SVD 的文本降维。
- **随机投影 / JL 引理** — 近似保两两距离的低维线性映射，LSH 理论基。
- **直方图/矩** — 图像等对象的基础低维表示。
- **MinHash/SimHash** — 集合→定长短码，配海明距离做相似/去重。
- **数据归约** — Data reduction：以更少/更概括的数据表示维持查询结果可信度的总称。
- **解释方差比** — Explained variance ratio：某主成分占据总方差的比例，定 k 的依据。
- **增量/随机 PCA** — Incremental/Randomized PCA：大数据下绕开 d² 协方差的可扩展降维。
- **乘积量化（PQ）** — Product Quantization：分段码本压缩向量，IVF-PQ 的降维/压缩内核。
- **内在维度** — Intrinsic dimension：数据真实占据的低维，降维收益之源（🔧 §6 由奇异值个数认定）。

## 最新演进与工业实践

- **嵌入成为默认表示层**：文本/图像/音频经深度模型映为稠密向量（word2vec 以降，至 2026 的多模态大模型嵌入），是 §5"表示"的现代形态；向量检索=在其上跑 ANN。⚠️ 趋势判断（访问 2026-09）。
- **降维 + 量化进主流向量索引**：乘积量化（PQ）本质是有监督的分段降维/压缩，IVF-PQ 即 §2/§4 降维思想的工程放大。⚠️ 转述。
- **Matryoshka 表示**：一个嵌入可截前若干维当低维用，与 PCA"前 k 主成分"同构，把"降维"内建进训练目标。⚠️ 转述。
