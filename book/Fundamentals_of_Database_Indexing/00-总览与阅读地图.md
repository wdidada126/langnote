## 3. 本书在数据库系列中的定位

这是一本**结构导向**（structure-centric）的索引/检索理论书：先立"数据库查询 = 相似检索查询"的抽象，再按 **低维（哈希/内存树/磁盘层次树）→ 距离度量 → 高维（维数灾难下的高维索引）** 的维度阶梯组织索引结构，落点在相似检索（nearest/farthest/range）。它不绑定某个 DBMS，与 repo 内**引擎绑定**的索引册互补：MySQL/SQL Server 册讲"这个引擎怎么建索引用索引"，本书讲"索引结构本身为何长这样、代价从哪来"。

## 6.6 全书核心论点（精读提炼）

1. **一切查询皆可视为空间检索**：把记录映射到某特征空间，选择查询（selection）、范围查询（range）、最近邻（nearest neighbor / similarity）在同一几何框架下讨论——这是本书区别于"工程索引手册"的理论底色。
2. **维度是索引难度的第一变量**：0 维（哈希）→ 1 维序（树）→ 中低维空间（R 树/包围盒）→ 高维（维数灾难）。索引结构沿维度阶梯逐层失效，"越升维越要放弃最坏保证、转向近似"。
3. **代价来自磁盘/内存访问次数，不是 CPU 比较**：结构好坏用 page touch / I/O 计（详见 10 附录、04 章 🔧）。
4. **剪枝的本质是"用一个可计算的界排除一整块"**：距离下界（min-dist）、包围盒 min/max（zone-map 之几何一般化）是同一思想的两种投影。

## 6.7 相似检索坐标系（帮助定位各章）

```
                 精确匹配 equality ─────────► 相似/最近邻 NN/range
   低维 1D          哈希(02)·B+树(04)          区间树·度量树(06)
   中维 2–10D        —                          R-tree/包围盒(06)·GM-tree
   高维 >10D         —                          维数灾难(07)→近似/降维(08·09)
```
