## 1. 附录 A — 内存与磁盘访问：全书代价单位来源

正文评价索引一律"访问多少次"，其单位就在 A：

- **磁盘**：以**页/块（block，4–16KB）** 为 I/O 单位，一次读含 seek + rotational latency + transfer；故"少访问几页"远比"少几次比较"重要。→ 04 章 B+树大扇出的动机。
- **内存**：以**字/缓存行（cache line 64B）** 为单位，随机指针追逐触发 cache miss；→ 03 章内存结构劣于哈希直达的根因。
- **代价记法**：点查 I/O = 树高；范围 I/O = 树高 + 命中跨的页数；构建/分裂付额外页写（写放大）。
- 本附录把 01 章"三把代价尺"里的第 1、2 条（跳跃次数、被访问对象数）落成可算式。⚠️ 概念梳理。

## 2. 附录 B — 包围盒距离：06 章剪枝公式的出处

给出点 q 到轴对齐盒 `B=[lo,hi]` 的两个界（06 章直接引用）：

- **最小距离 min-dist**（盒内/外统一式）：
  ```
  min-dist(q,B) = sqrt( Σᵢ max(0, loᵢ−qᵢ, qᵢ−hiᵢ)² )
  ```
  即"q 在各轴上向盒靠拢后的最近角点"距离；`q∈B` 时为 0。→ branch-and-bound 用它给子树定优先级、超阈剪枝。
- **最大距离 max-dist**：`sqrt( Σᵢ max((qᵢ−loᵢ)², (qᵢ−hiᵢ)²) )`。用于 kNN 里"已找到 k 个且当前候选下界 ≥ 已知第 k 近上界"时的**安全终止/剪枝**。
- 球/盒交叠判定、盒到盒距离亦属本节，是 R*-tree 重叠度量的几何基础。⚠️ 公式为标准结论转述。

## 3. 附录 C — 向量与矩阵：PCA/SVD 的线性代数地基

- 内积、范数（`‖x‖`）、正交/标准正交基：距离函数（05）与投影（09）的语言。
- 特征值/特征向量、对称半正定矩阵：PCA 求主成分 = 求协方差矩阵最大特征向量。
- SVD `X=UΣVᵀ` 与 rank-k 逼近、Eckart–Young：09 章降维最优性的证明工具。
- 矩阵求迹（trace）、方差分解：解释"主成分解释方差比"（🔧 §6 用到）。⚠️ 概念梳理。

## 4. 附录 D — 概率与统计：距离集中与选择性的依据

- 期望/方差、独立和的集中不等式（切比雪夫/Hoeffding 一类）：07 章"距离集中"的数学来源——高维两点距离是 d 个独立分量贡献之和，均值集中、方差相对均值→0。
- 均匀分布体积论证：07 章"体积塌缩到角"的计算。
- 选择性估计（range 命中比例）：优化器"走索引 vs 全扫"判断的统计基础，连 04/§6.6。⚠️ 概念转述。

## 4.5 min-dist 手算一例（附录 B 公式落地）

盒 `B=[lo,hi]=([2,5],[3,7])`（2D，x∈[2,5]、y∈[3,7]），查询 `q=(4,9)`：

- x 轴：`q=4` 落在 `[2,5]` 内 → 贡献 `max(0,2−4,4−5)=0`；
- y 轴：`q=9` 在 `[3,7]` 外 → 贡献 `max(0,3−9,9−7)=2`；
- `min-dist = sqrt(0² + 2²) = 2`；
- `max-dist`：各轴取"到 lo 或 hi 较远者"，x=`max(|4−2|,|4−5|)=2`、y=`max(|9−3|,|9−7|)=6` → `sqrt(4+36)=√40≈6.32`。

于是任何落在 B 子树里的点到 q 的距离必 ≥ 2。若当前 kNN 第 k 近 `d_k < 2` → 整棵子树安全剪去（06 章 §6.5 步骤 2 的一次具体展开）。⚠️ 标准几何算例。

## 4.6 磁盘代价一例（附录 A 的 I/O 账）

承接 04 章 §6.5：f≈1000、每页 256 叶记录、内存根常驻，则亿级行表点查最坏 I/O = 2（磁盘内节点 + 叶）；范围命中 K 行、跨 `⌈K/256⌉` 叶 → I/O = 2 + ⌈K/256⌉。反之无索引全扫 = 表总页数。→ "选择率决定走索引还是全扫"的定量临界，正是附录 D 选择性 × 附录 A 页数的联合应用。⚠️ 算例梳理。

## 8. 常见误区（⚠️）

- "附录可跳过"：跳过 A 会误用"比较次数"评估磁盘索引；跳过 B 会不懂 R 树为何要 min-dist；跳过 D 会以为 07 的灾难是玄学而非概率。
- "max-dist 无用"：它在 kNN 的**剪枝与终止判定**中提供"整块不可能更优"的可靠上界，是正确性护栏。
- "min-dist 只能到盒"：同法可推广到多边形/凸包，本书限于轴对齐盒（工程性价比最高）。

## 核心概念速览（中英对照）

- **块/页 I/O** — Block/page I/O：磁盘以块为最小读写单位，索引代价的基本尺度。
- **cache miss** — 缓存未命中：内存结构中随机指针追逐的主要隐性代价。
- **写放大** — Write amplification：分裂/合并导致的超数据量的额外页写（连 04）。
- **min-dist** — 点到包围盒的最小距离：branch-and-bound 剪枝的下界。
- **max-dist** — 点到包围盒的最大距离：kNN 安全终止/剪枝的上界。
- **Eckart–Young 定理** — 截断 SVD 是最优 rank-k 逼近（连 09）。
- **特征分解/协方差矩阵** — PCA 求主成分的线性代数实现。
- **距离集中不等式** — 高维距离方差相对均值塌缩的概率论证（连 07）。
- **选择性（selectivity）** — 谓词命中比例，决定走索引还是全扫。
- **书目（Bibliography）** — 原书 1990s–2000s 相似检索/空间索引经典文献清单（仅登记）。
- **delta 法** — Delta method：由 `D²` 的矩近似 `D=√(D²)` 的均值/方差的工具（连附录 D/07）。
- **累计解释方差** — Cumulative explained variance：选降维目标维数 k 的经验准则。
- **工作集** — Working set：一次查询实际触达的页/缓存行集合，决定 A 的代价。

## 最新演进与工业实践

- **代价模型仍是查询优化器内核**：现代优化器的 I/O 代价（页读）+ CPU 代价 + 选择性的三段式，正是附录 A/D 的产品化；只是列存/SIMD 时代又加了"带宽与向量化"项。⚠️ 转述。
- **zone-map / data-skipping 是 min/max 包围的当代化**：附录 B 的 1 维退化在 Parquet/ORC 行组、云仓 min/max data-skipping 中大规模服役，🔧 G4 为其本机实证（非本书引擎）。✅
- **向量索引的线性代数依赖变重**：HNSW/PQ 对范数、内积、特征分解的依赖使附录 C 在 2026 更显基础地位；量化（PQ）本质是分块的最优码本（K-means）+ 矩阵运算。⚠️ 趋势。
