# 05 · 距离与距离函数（Part IV — Distances: Distance Functions）

> 对应原书 Part IV「Distances」分部标题页（p.93）与章 Distance Functions（pp.95–109）。✅ 章名/页码取自 Crossref。前三章（哈希、内存树、B 树）都在"键可全序比较"的 1 维世界。一旦进入相似检索，"全序"不复存在，取而代之的是**距离（distance）**——本章为 Part V/V 的高维索引打地基：定义度量空间、枚举可用距离函数、说明"什么结构需要什么距离性质"。

## 1. 为什么"相似"必须先定义"距离"

相似检索的判据是"离查询点 q 最近的点"。"最近"必须先有一个 `d(p,q)` 的数值，且它要满足**度量（metric）公理**，否则后文一切"剪枝"都不成立：

1. 非负 & 同一性：`d(p,q) ≥ 0`，`d(p,q)=0 ⟺ p=q`。
2. 对称：`d(p,q)=d(q,p)`。
3. 三角不等式：`d(p,r) ≤ d(p,q)+d(q,r)`。

**三角不等式是命门**：Part IV/V 的所有索引（vantage-point、R 树）都靠它做"由已知距离推未知距离的下界"来剪枝。距离一旦不满足三角不等式，剪枝会**漏掉**真正的近邻（假阴），检索不再正确。

## 2. 常用距离族（⚠️ 精读梳理）

设两向量为 x,y：

- **Minkowski / L_p 距离**：`d = (Σ|xᵢ−yᵢ|^p)^(1/p)`。p=1 曼哈顿、p=2 欧氏、p→∞ 切比雪夫。是**数值/几何**特征的主距离，均满足度量公理。
- **平方欧氏 `Σ(xᵢ−yᵢ)²`**：省去开方，比较大小不变，工程首选（少一次 sqrt）。⚠️ 注意：平方后仍是"序保持"，但**不再是度量**（破坏三角不等式），故只能用于"排序比较"，不能直接喂给依赖三角不等式的剪枝结构。
- **编辑距离 / Levenshtein**：字符串增删改步数，度量。服务拼写纠错、DNA 序列。
- **海明距离 Hamming**：等长符号串不同位数，度量。服务签名/哈希相似（SimHash 生态）。
- **余弦距离 / 夹角**：`1 − cos(x,y)`，看方向不看长度，文本向量常用；**它是否度量取决于归一化**（对单位向量成立）。
- **KL 散度 / 马氏距离**：概率分布间的"距离"，**KL 不对称、不满足三角不等式**，非度量；马氏距离是度量。⚠️ 二者常被误当欧氏同类使用。

## 3. 距离决定可用结构（本章承启）

一个核心因果链，串起后三章：

```
满足三角不等式 ──► 可用"距离下界"剪枝 ──► vantage-point / metric 树（06）成立
可用轴对齐包围盒 ──► min-dist/max-dist 到盒 ──► R 树 / GM-tree（06/08）成立
高维 L_p ──► 距离集中 ──► 剪枝失效 ──► 必须降维/近似（07/08/09）
```

所以本章不只要"给一堆距离公式"，更要说清：**每种索引结构都隐含对距离的要求**（可计算下界？轴对齐？）。这也是本书把"距离"与"结构"分章却同部的原因。

## 4. 非向量数据的"表示→距离"（接 Part VI）

图像、文本、音频没有天然数值坐标，须先做**特征提取**（直方图、词袋、嵌入）把对象映成向量，再套上面的距离。"用什么表示 + 用什么距离"共同决定相似检索效果——这正是 Part VI「Data Representation Techniques」（09 章）回收的主题。⚠️ 本章只给距离侧，表示侧留 09。

## 5. 高维下"距离本身"变味（预告 Part V）

本章末尾的伏笔：当维度 d 增大，各点两两距离趋于相等（**距离集中，concentration of distances**），于是"最近邻"与"次近邻"距离差→0，用距离做判据的检索在语义上失去区分力。这不是结构问题，是**距离函数在高维的性质问题**——07 章正式展开"维数灾难"。⚠️ 概念转述。

## 5.5 三角不等式到底"怎么剪枝"（形式化一次）

度量树（06）的核心手法：选一个"枢轴（vantage point）"v，预算所有点到 v 的距离。查询 (q, r=半径) 时：

- 对候选子树里一点 p，已知 `d(p,v)` 与 `d(q,v)`。
- 由三角不等式：`d(p,q) ≥ |d(p,v) − d(q,v)|`（反向三角不等式）。
- 若这个**下界**已 > r，则 p（乃至以其为枢轴的整块子树）可被安全排除，且**绝不会漏掉真正的近邻**（正确性来自公理，不来自运气）。

这正是 01 章代价尺第 3 条"靠可计算下界剪枝"的兑现。反证 §2 的警告：平方欧氏不满足三角不等式 → 下界不成立 → 剪枝会假阴 → 所以 metric 树必须用真度量。

## 5.6 距离—数据类型—是否度量 对照表（⚠️ 汇总）

| 数据/场景 | 常用距离 | 是否度量 | 备注 |
|---|---|---|---|
| 数值/几何向量 | L2 / L1 / L∞ | ✅ | Minkowski 族 |
| 比较排序（工程） | 平方欧氏 | ❌(保序) | 只可排序不可剪枝 |
| 文本词袋/归一化向量 | 余弦 | ✅(单位化) | 未归一化则非度量 |
| 字符串/序列 | 编辑距离 | ✅ | 纠错、DNA |
| 定长签名/哈希 | 海明 | ✅ | SimHash 生态 |
| 概率分布 | KL 散度 | ❌ | 不对称、无三角 |
| 相关结构数据 | 马氏距离 | ✅ | 考虑协方差 |

## 6. 🔧 实测：距离不可直接建索引时的后果（非本书引擎行为）

SQLite/DuckDB 只把 B+树/ART 建在"可全序比较的标量列"上，无法直接为"向量间距离"建序索引——这恰好演示"距离 ≠ 序"：一旦检索判据是距离而非大小，常规索引就退化为全表计算。

🔧 演示（SQLite 3.45.3，内存表，10000 点 (x,y)，做最近邻 `ORDER BY (x-qx)²+(y-qy)² LIMIT 1`）：
- 该查询无法命中任何 B+树（判据是"平方欧氏到 q"，随 q 变化），执行计划为 `SCAN` 全部 10000 行 + 临时排序。
- 单次最近邻 ≈ 全表距离计算；重复检索成本线性于 N。→ 印证 05/01 章："相似检索 ≠ 范围检索，序结构帮不上忙"，必须用专门的度量/空间结构（06/08）或降维近似。

🔧 对照（DuckDB 1.5.5）：对二维坐标 `WHERE x BETWEEN ... AND y BETWEEN ...` 这类**轴对齐范围**可借列式 min/max（zone-map，见 06 章 G4）剪枝，但纯 kNN `ORDER BY 距离` 仍走全量。→ 说明"轴对齐包围盒可剪、任意距离需专门结构"这一本章关键区分。数字方法学同 04 章（墙钟毫秒、`:memory:`、非本书引擎）。

## 7. 常见误区（⚠️）

- "距离 = 欧氏"：不同数据类型有各自良构距离；用错距离（如对词频向量用编辑距离）语义即废。
- "平方欧氏也是度量、可用于剪枝"：破坏三角不等式，只可用于比较排序，不可用于依赖下界的 metric 树（见 §2）。
- "余弦/欧氏谁更好"：余弦看方向、欧氏含模长；文本嵌入常归一化后二者单调等价，未归一化则结论不同。
- "非度量也能做相似检索"：能，但失去剪枝正确性保证，只能全量算或转近似——本书结构层依赖度量性。

## 5.7 距离前的预处理：归一化与标准化（决定成败的隐藏步骤）

同一批数据，是否归一化会让"哪个是最近邻"的答案完全不同——这是相似检索最常见的隐性 bug：

- **量纲标准化（z-score）**：各维减均值除标准差，避免"收入（万级）淹没年龄（十级）"使 L2 退化为单维距离。
- **向量归一化（单位化）**：`x/‖x‖` 后，余弦 = 内积 = (2−2cos)/2 的 L2，三者单调等价；未归一化则 L2 含模长、余弦只看方向，结论分叉（§2 已提示）。
- **降相关（白化）**：对强相关维做去相关（马氏距离即"用协方差逆度量的标准化欧氏"），使各维贡献独立。
- **离散/符号维**：分类特征不能直接做数值减法，需 one-hot 或专用子串距离（编辑/Hamming），否则"距离"语义假。

结论：距离函数不是"选一个公式"就完事，**表示（09）+ 预处理 + 距离**三件套共同决定检索是否合理。本书正文把重心放在距离与结构上，此处补足工程侧常被忽略的预处理一环。⚠️ 转述补充。

## 5.8 选距离的决策树（本章收口）

```
数据有轴对齐数值坐标?         ──是──► L2/L1(Minkowski)；需去量纲先标准化(§5.7)
      │否
高维稠密嵌入、只看方向?        ──是──► 余弦(单位化后=内积)
      │否
字符串/定长签名?              ──是──► 编辑距离 / 海明距离(度量,可剪枝)
      │否
概率分布?                    ──是──► KL(注意非度量,只能全算或近似)
      │否
拿不准 / 需保证剪枝正确?      ──► 回到"必须满足三角不等式"这条硬线(§5.5)
```

## 核心概念速览（中英对照）

- **度量空间** — Metric space： equipped with 满足三公理的距离的集合。
- **三角不等式** — Triangle inequality：`d(p,r)≤d(p,q)+d(q,r)`，一切距离剪枝的正确性来源。
- **Minkowski / L_p 距离** — 参数化距离族：p=1/2/∞ 对应曼哈顿/欧氏/切比雪夫。
- **平方欧氏距离** — Squared Euclidean：序保持但非度量，仅供比较排序。
- **编辑距离** — Levenshtein distance：字符串变换步数，度量。
- **海明距离** — Hamming distance：等长串不同位计数，度量。
- **余弦距离** — Cosine distance：方向差异，需单位化才成度量。
- **KL 散度** — Kullback–Leibler divergence：非对称、非度量的分布"距离"。
- **距离集中** — Concentration of distances：高维下两两距离趋同，相似检索失去区分力。
- **轴对齐** — Axis-aligned：与坐标轴平行的包围关系，使 min-dist/max-dist 可计算。
- **归一化** — Normalization：向量单位化，使余弦与欧氏单调等价。
- **标准化（z-score）** — Standardization：逐维去均值除方差，消除量纲主导。
- **马氏距离** — Mahalanobis distance：以协方差逆加权的标准化欧氏，去维相关。

## 最新演进与工业实践

- **嵌入时代 = "表示决定距离"的实践回潮**：现代向量检索把对象统一投到稠密嵌入空间，主流用**内积 / 余弦（归一化后即点积）**作相似判据，本书的距离分类学在此得到工业印证。⚠️ 趋势判断。
- **metric 学习（learned distance）**：从数据学一个满足（或近似满足）三角不等式的距离，是相似检索研究的长期方向。⚠️ 转述。
- **向量库的度量选项**：主流向量索引普遍暴露 L2/IP/cosine 三类度量供选择，本质就是本章距离族的工程封装；选错度量导致召回崩塌，与本书警告一致。⚠️ 转述（具体产品以各自文档为准）。
