# 01 · 数据库查询与相似检索导论（Part I — Basics: Database Queries）

> 对应原书 Part I「Basics」分部标题页（p.1）与其下章 Database Queries（pp.3–11）。✅ 章名/页码取自 Crossref 官方寄存；正文为精读重构。本章是全书立题：把"数据库查询"从 SQL 语法里抽出来，重述为**对象空间上的检索问题**，并引出贯穿全书的"相似检索（similarity search）"母题。

## 1. 本章要解决什么

传统数据库教科书按关系代数定义查询：`σ`（选择）、`π`（投影）、`⋈`（连接）。本书第一步就换一个视角——

- 每条记录被表示为某**特征空间（feature space）**中的一点（一个对象、一个向量、一段文本的签名）。
- 一次"查询"就是"在这个空间里，按某种条件把满足的对象找出来"。
- 于是选择查询、范围查询、Top-k、最近邻，全部落到同一抽象：**给定查询对象 q 与判据，返回空间中与之"匹配"的对象集合**。

这个统一不是修辞，它决定了后文为什么"索引结构"和"距离函数"可以放在一本书里讲：一旦查询=空间检索，索引=空间划分，两者就是几何问题的两面。

## 2. 三类检索的层级（⚠️ 精读梳理）

| 检索类型 | 判据 | 典型查询 | 对应结构（后文章） |
|---|---|---|---|
| **精确匹配（exact / equality）** | key 相等 | `WHERE k = c` | 哈希（02） |
| **范围检索（range / partial match）** | 属性落入区间 | `WHERE a BETWEEN x AND y` | B+树/区间树（03、04） |
| **相似检索（similarity / NN）** | 与 q 的"距离"最小/在阈内 | 最近邻 kNN、范围 NN | 度量树/R 树（05–08） |

精确匹配是相似检索在"离散符号空间 + 0/1 距离"下的退化特例。本书把这三类排成"维度递增"的阶梯：exact 无需几何（0 维），range 用 1 维序，similarity 要真正的度量空间。

## 3. 为什么要"抽象掉 SQL"

- 工程手册（如姊妹册 [../数据库索引设计与优化.md](../数据库索引设计与优化.md)）以"给定 workload → 选索引列"为主线，其语言始终是 SQL 谓词。
- 本书刻意不绑 SQL：因为高维相似检索（图像、文本、向量）根本没有"列"的概念，只有"对象间距离"。过早绑定 SQL 会让 Part V–VI 无处落笔。
- 代价：读者须自行把几何结论翻译回某引擎（MySQL/PG）的 DDL——这正是与 [../Understanding_MySQL_Internals/09-解析器与优化器.md](../Understanding_MySQL_Internals/09-解析器与优化器.md) 分工的原因：本书给"为什么"，那册给"这个引擎怎么做"。

## 4. 检索的代价视角（贯穿全书的评价尺）

本书评价任一索引结构，只用一把尺：**"回答一类查询，需要访问多少次存储（内存字 / 磁盘页）"**，而非"代码是否好看"。据此有三条贯穿性原则：

1. **点查看"跳跃次数"**：哈希期望 1 次、B+树约 `log_f N` 次、无索引线性 N 次。
2. **范围/近邻看"被访问对象数 + 被排除对象数之比"**：好结构能把大量不可能命中的区域"一整块剪掉"，代价仅与结果规模相关而非全库。
3. **剪枝靠"可计算的界"**：只要能为"一整块区域"廉价算出到查询点的距离下界，就能排除它（Part IV/V 的技术内核）。

这三把尺会在 04（B+树 I/O）、06（距离下界剪枝）、07（高维下界退化为常数）反复出现——先在此立好。

## 5. 全书结构预告（维度阶梯）

本章之后，本书按"维度"而非"引擎特性"推进：

1. **Part II 低维**：哈希（0 维，只支持 exact）、内存序结构（1 维，支持 range）、磁盘层次树（1 维 + I/O 代价）。
2. **Part III 磁盘**：把 1 维序结构放进"页"的现实，得到 B 树家族。
3. **Part IV 度量**：一旦要处理"相似"，必须先定义"距离"——于是插入距离函数与度量空间公理。
4. **Part V 高维**：距离定义好后，发现高维下所有基于"包围/剪枝"的结构集体失效（维数灾难）。
5. **Part VI 归约**：应对高维的唯一务实出路——降维与表示。

这条"维度是唯一自变量"的叙事线，是本书区别于按索引类型平铺的同类书（如 [../Physical_Database_Design/02-索引基础技术.md](../Physical_Database_Design/02-索引基础技术.md) 的分类式讲法）的最大特征。

## 6. 术语起点：对象、特征、空间

- **对象（object）**：被索引的实体（一条记录、一张图、一段语音）。
- **特征（feature / attribute / dimension）**：对象在某坐标上的取值；对象→特征映射称为**特征提取/表示**（Part VI 专章）。
- **空间（space）**：所有可能特征向量构成的集合；索引结构本质是对该空间的**划分（partition）**或**覆盖（covering）**。

本章给的是词汇表；下一章（哈希）开始第一层"0 维空间"的索引构造。

## 7. 🔧 直觉校准（非本书引擎行为）

本书本章无数值结论（纯定义）。为让"查询=空间检索、判据决定结构"可感，用 SQLite 演示"同一份数据、不同判据走不同访问方式"：

- `SELECT ... WHERE k=?`（精确匹配）→ 命中 B+树路径（可类比哈希直达）。
- `SELECT ... WHERE k BETWEEN a AND b`（范围）→ 需要序结构。
- `ORDER BY distance_to_q LIMIT 10`（kNN 近似）→ 若 distance 随 q 变化，无索引可用，退化为全表计算。

🔧 实测（SQLite 3.45.3，2M 行内存表，墙钟毫秒）：等值点查 `WHERE k=1234567` 无索引需扫全表（×200 ≈ 22149ms），建 B+树后 ×200 仅 ≈ 1.2ms（`SEARCH t USING INDEX (k=?)`）；范围 `k BETWEEN 1000 AND 60000` 索引命中 ≈ 130.6ms、无索引全扫 ≈ 6058.7ms。这印证"判据类型决定所需结构"——exact 只要可随机定位即可极快，range/NN 则要求空间有序或专门度量结构。完整数字与计划登记于 [00-总览与阅读地图.md](00-总览与阅读地图.md) §7（G1/G2），均**非本书引擎行为**。

## 8. 常见误区（⚠️）

- 误以为"索引=加速一切查询"：哈希索引对 range 完全无用，B+树对高维 kNN 急剧退化——本章的"判据→结构"映射正是为破除这一误念。
- 误把相似检索当"模糊查询"：本书的 similarity 有严格度量公理（Part IV），不是 LIKE 通配。
- 误以为降维可省：Part V 会证明高维不降维则"索引比全扫还慢"，这是本书最反直觉也最重要的结论，值得在读 Part V 前先在脑中标记。
- 误以为"越抽象越没用"：恰是抽象让同一套几何语言能同时解释 B+树、R 树与向量索引；工程手册反而做不到跨结构统一。

## 8.5 相似检索的四种查询形态（本章给全定义域）

把"相似"落到具体查询，本书后续要服务的形态有：

- **kNN（k 近邻）**：返回距 q 最近的 k 个对象——最常用，Top-k 推荐/检索即此。
- **范围 NN（range search）**：返回 `d(q,x) ≤ r` 的全部对象——地理"附近 3km"、阈值召回。
- **最远点对（farthest / diameter）**：找距离最大的一对——异常检测、数据划分定心；高维下与 NN 一样因距离集中而变难。
- **连续/增量 NN**：q 随时间微动，要求索引支持"上一次结果局部更新"——流式场景，本书仅点到。

这四态共用同一距离与剪枝 machinery（Part IV–VI），差别只在终止条件与队列维护。把"查询"抽象成"空间 + 判据"后，它们从四种 SQL 直觉变成了同一算法的四个参数化，这正是 §1 抽象的收益。

## 核心概念速览（中英对照）

- **相似检索** — Similarity search：以"与查询对象的距离"为判据的检索，是本书主问题。
- **精确匹配** — Exact / equality match：键值完全相等的检索，相似检索的离散退化特例。
- **范围查询** — Range query：属性落入给定区间的检索，需要空间有序。
- **Top-k / kNN** — k-Nearest Neighbors：返回距离最近的 k 个对象。
- **特征空间** — Feature space：对象经特征映射后构成的向量集合，索引即对其划分。
- **维度阶梯** — Dimensionality ladder：本书按维度递增组织索引结构的主叙事线。
- **判据决定结构** — Predicate determines structure：等值/范围/相似各需不同的索引几何。
- **划分与覆盖** — Partition vs covering：索引构造的两大流派（哈希=划分，R 树=覆盖）。
- **可计算距离下界** — Computable distance lower bound：一整块区域被剪枝的前提。
- **度量公理** — Metric axioms：距离须满足非负/对称/三角不等式（Part IV 展开）。
- **退化特例** — Degenerate special case：低维/离散问题是高维连续问题的边界情形。
- **kNN** — k-Nearest Neighbors：返回距 q 最近的 k 个对象。
- **范围 NN** — Range search：返回距 q 不超过半径 r 的全部对象。
- **最远点对 / 直径** — Farthest pair / diameter：距离最大的一对，异常检测与定心用。
