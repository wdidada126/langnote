# 《应用密码学：协议、算法与 C 源程序》总览与阅读地图

> **一句话**：这本书把「密码学当作一件可以动手做的工程」来讲——**你不仅能学到算法，还能学到怎么把算法拼成真正能用的协议**，而它 1996 年的安全判断在今天有相当一部分被彻底推翻。

## 2. 关于本目录与「大纲版」的关系

- **本目录是深度重写版**，按原书 25 章重组为 16 个主题文件 + 1 个 `concepts/` 专篇，每个文件含：本章地图 ⟶ 核心精讲（教学示意代码）⟶ 版本演进 ⟶ 经典论文 ⟶ 工业界开源实践（star 为 `gh api` 实测）⟶ 常见误区与需修正之处 ⟶ 与其他章/书的联系。
- **大纲式单文件在此**：`book/应用密码学.md`（含完整中译目录的清单式大纲）。
  > 查重结果（2026-09-25）：`book/` 下用 `grep -ril "应用密码学\|Schneier"` 与 ripgrep 双向检索，**未发现既有单文件大纲**，故本目录为首次建立。按仓库的一贯约定，一旦存在同名大纲文件，本文件第 2 节须替换为上面那两行互链说明，本目录文件一律**不删除、不修改**该大纲。
- **不编造章节**：所有小节编号（如 12.4、19.3、24.5）均取自 Wiley 第 2 版与中译本真实目录。原书**没有**独立的「密码分析」「后量子」「侧信道」章，这些内容以 `concepts/密码分析与侧信道.md` 专篇和相应章节的「版本演进 / 常见误区」小节补齐。

## 4. 版本演进时间轴（1996 成书 ⟶ 2026）

| 年份 | 事件 | 对本书的冲击 |
| --- | --- | --- |
| 1994 | 原书第 1 版（Wiley） | 成书基础 |
| **1996** | **原书第 2 版**（含源码附录） | 本书的「当前时刻」：3DES 已经面世、AES 尚未公开、SHA-1 刚发布不久 |
| 1997–09 | NIST 公开征集 **AES** 候选算法 | 本书第 12–15 章的全部分组密码都**不是** AES |
| 2000–10 | Rijndael 中选，2001-11 发布 **FIPS 197** | 🔧 **本书对分组密码走向的判断完全落空**：1996 年热议的「DES 后继」不是书中任何候选，而是五年竞赛后的 Rijndael；DES 挑战赛失败后 3DES 又撑了十几年 |
| 2001 | **9·11 后出口管制放松**（第 25.14 节的政策前提终结） | Ch25 的「政治」部分基本作废 |
| 2002 | Vaudenay 的 **CBC 填充预言机**（Ch9.3 的 CBC 埋下雷） | 直接演化为 2011 Lucky13、2014 POODLE |
| 2004 | **Wang 等破出 MD5 碰撞**（ePrint 2004/268） | Ch18 把 MD5 当作「已破但可用」的叙述彻底失效 |
| 2005 | **Wang、Yin、Liu 破出完整 SHA-1 碰撞**（Crypto'05） | Ch18.7 的 SHA 从「安全」变成「128 位强度已崩」 |
| 2006 | **NIST 撤销 SHA-1**（2010 年底前退役） | 见 FIPS 180-4 |
| 2008 | **Debian 的 OpenSSL PRNG 缺陷**（CVE-2006-3619 / CVE-2008-0166） | Ch2.8 / Ch16 的「随机性」章节一击即中：熵被砍到极弱，全球密钥可复现 |
| 2008 | **成熟流密码竞赛 eSTREAM 结束**；**Keccak 入选 SHA-3** | RC4 的黄金时代在 2008–2015 间被 eSTREAM 与 ChaCha20 取代 |
| **2013** | **Heartbleed**（CVE-2014-0160，2014 春曝光） | Ch2.6/Ch16 的 PRNG 与密钥材料问题再次被证实；OpenSSL 源码质量被质疑 |
| 2013–2017 | 2008 年那个 64 字节 SHA-1 碰撞块被公开实现成可复现攻击，2017 年 SHAttered 让 SHA-1 证书正式退役 | 见 12 章「版本演进」 |
| 2014 | **RC4 在 RFC 7465 中被 TLS 全面禁止** | 🔧 本书唯一单章讲解的流密码（Ch17.1「RC4」）被判死刑 |
| 2015 | **SHA-3 成标准（FIPS 202）**；**CNSA 1.0** 公布；Let's Encrypt 上线 | Ch18.13「如何选择哈希」的答案变成了 SHA-2 还是 SHA-3 |
| 2016 | SWEET32：64 位分组密码的生日型碰撞 | Ch12–15 的 64 位 DES/3DES/Blowfish 首次暴露实用化弱点 |
| 2018 | **TLS 1.3（RFC 8446）** | Ch16 里被拿来当实例的协议形态基本退出历史 |
| 2019 | 中国大陆《密码法》实施 | 合规层面替代了 Ch25 的美国出口管制叙事 |
| 2022 | **FIPS 203/204/205 草案发布**（RSA 与 ECC 退出 NSA 套件） | Ch19 的「公钥密码不会被动摇」被限定为「经典计算机上」 |
| **2024-08-13** | **NIST 正式发布 FIPS 203（ML-KEM）、FIPS 204（ML-DSA）、FIPS 205（SLH-DSA）** | 后量子时代开始；本书 Ch13/Ch14 的「数学难题长期有效」需要加限定语 |
| 2025–2026 | ML-KEM 在 TLS 与 PKI 中规模部署；CNSA 2.0 迁移推进 | 本书 Ch7「密钥长度」的换算口径需要按新算法重算 |

> **最重要的一条订正**：AES 于 1997 年才**征集**、2001 年才**成为标准**——本书成书于 1996 年，书中对「下一代分组密码将是什么」的推测与最终结果完全相反。**AES 不是 1996 年的答案，而是 1996 年之后长达五年的竞赛产物。** 因此本目录在 10 章明确指出：要理解今天的对称加密，必须以 FIPS 197（2001）为终点重读 Ch12–15。

## 5. 本书没覆盖的缺口（2026 视角）

| 缺口 | 说明 | 补到哪里 |
| --- | --- | --- |
| **后量子密码** | 全书建立在「因子分解与离散对数在经典计算机上不可解」之上，没有格、编码、多变量、哈希签名的一行内容 | 13 章「版本演进」、`concepts/密码分析与侧信道.md` |
| **侧信道攻防的工程化** | 只在 12.4 顺带提到定时/线性密码分析，没有功耗分析、故障注入、电磁侧信道的系统方法论 | `concepts/密码分析与侧信道.md` |
| **形式化协议验证** | Ch3.4 只做「形式化分析」的**介绍**，没有 ProVerif、Tamarin、TLA+ 这类工具的落地 | 03 章「常见误区」 |
| **TLS 1.3 的具体设计** | 全书只在 Ch24 讲 SSLv3/TLS1.0-1.2 的实例；TLS 1.3 删掉了 RSA 密钥传输、CBC、RC4、静态 DH，本书完全没有 | 16 章 + `concepts/` |
| **现代密钥派生与 AEAD** | 本书没有 HKDF（RFC 5869）、没有 AEAD 一体化的思路，Ch9 的「模式」是「裸块密码 + 手工拼 MAC」 | 08 章、12 章 |
| **现代「密码工程学」** | Rogaway 的《谁怕模式化加密？》一类结论（2000 年前后成文，中译本未收）：加密必须自带可验证完整性 | 08 章「常见误区」 |

### ⚠ 关于本书附带的 C 源代码

原书附录 A 的源码取自 *Dr. Dobb's Journal* 连载，作者本人在第 2 版前言与后来的博文中都承认：**其中的实现存在已知缺陷**（典型问题：PRNG 质量不足、错误检查不完整、侧信道不防御、未做常量时间比较）。因此：

- **这些代码只能当「算法的可读注释」**，不能直接复制进生产；
- 现代替代：`libsodium`（`crypto_stream`/`crypto_box`）、OpenSSL `EVP_*`、`cryptography`、`Bouncy Castle`；
- 想看「正确的实现长什么样」，`C2SP/wycheproof` 与 `PQClean/PQClean` 是最好的两份对照物。

## 7. 写作约定

- 每个章节文件首行为 `# 第 N 章 标题`，紧接 `> **一句话**：…`；
- 随后固定六个一级小节：本章地图 / 核心精讲 / 版本演进 / 经典论文与原始文献 / 近年研究与工业界开源实践（2015–2026）/ 常见误区与本书需修正之处 / 与其他章与我书的联系；
