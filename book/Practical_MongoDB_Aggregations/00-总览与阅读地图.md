## 十三、最容易混淆的十组词（开读前的消歧卡）

| 混淆对 | 一句话消歧 |
|---|---|
| $lookup vs JOIN | 都是关联，但 $lookup 把右表结果**装进数组字段**（可 preserve），SQL 是行乘积；详见 04 |
| $unwind vs UNNEST | 拆数组：语义同族，但 $unwind 的 includeArrayIndex/preserveNullAndEmptyArrays 两个开关决定行数去向（03） |
| $bucket vs $bucketAuto | 显式边界分箱 vs 自动等频分箱（后者近 NTILE，近而非等——05） |
| $facet vs GROUPING SETS | 多路输出桶 vs 多组集并表输出，行数形状不同（05） |
| $setWindowFields vs SQL OVER | 前者"分区+排序"内联在管道里，frame 语法是子集而非全集（06） |
| $group 两阶段 vs 分布式聚合 | 分片上 $group 拆 partial/final 两刀，SQL 侧对应 exchange 算子，不可直觉类比（07） |
| 16MB 文档限制 vs allowDiskUse | 前者管单文档输出，后者管管道溢盘，是两个独立天花板（07） |
| $expr vs WHERE 表达式 | $expr 让 find 借用聚合表达式语言；SQL 侧无此"方言夹层"（07） |
| $merge vs INSERT ON CONFLICT | 都是 upsert，但 $merge 按 whenMatched 分支且跑在管道末端（08） |
| Paul Done vs Michael Lynch | 同名两书，一人顾问一人在职厂商员工；引用带人名（第一节勘误 1） |
