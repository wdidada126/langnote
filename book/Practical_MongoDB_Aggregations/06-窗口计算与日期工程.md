# 06 窗口计算与日期工程——$setWindowFields/$dateTrunc/$dateToString

> 第 3 波 · #127《Practical MongoDB Aggregations》(Paul Done, Packt, 2024) 精读重构 · 章 6/8。
> 红线与取证口径同 [01-管道骨架与过滤排序.md](01-管道骨架与过滤排序.md)。

## 1. 本章主题

$setWindowFields（5.0）让 Mongo 一次性补上 SQL 攒了二十年的窗口函数家底；日期族（$dateTrunc/$dateToString/$dateAdd…，5.0+ 成建制）则把"时间桶"从手搓 $substr 时代解放。本章 🔧 的重头戏：窗口运行和的两引擎同值、以及一个**计划外发现**——跨年边界上 SQLite 与 DuckDB 相差 94 行的日期族分歧（时区/历法细节的真实教训）。

取证：✅ https://www.mongodb.com/docs/manual/reference/operator/aggregation/setwindowfields/ （301 解析实验）、✅ https://www.sqlite.org/windowfunctions.html 、✅ https://duckdb.org/docs/sql/aggregates 。

## 2. 精读

### 2.1 $setWindowFields：分区+排序+frame，一个阶段全包

- 结构：`output:{k:{operator, windowConfigs:[{partitionBy, sortBy, window:{documents/range…}}]}}`——**一条阶段可挂多套窗口配置**，SQL 一条 SELECT 也可挂多个 OVER()，对位自然。
- 算子族：$sum/$avg/$rank/$denseRank/$documentNumber/$shift/$derivative/$integral…（分析/排行/位移全覆盖）；rank 平局语义与 SQL rank()/dense_rank()/row_number() 三件套对位（$min/$max 的 push 变体另议）。
- frame 是子集不是全集：documents/range 两类，边界 UNBOUNDED/CURRENT/N 表达式；**没有 SQL 的 GROUPS 模式、没有 EXCLUDE** ⚠️（PG 18 才有 GROUPS/EXCLUDE；Mongo 8.x 未跟进）——复杂移动平均移植回管道时要手改。
- 与 $group 的本质区别：窗口**不压行**（每行带新增字段流出），$group 压行——SQL 同律（OVER vs GROUP BY）；02 章 "$first 不确定"的正解在此。
- 5.0 之前的史前史 ⚠️：$sort+$group+$push 手搓、或 MapReduce；TDG 3e 基线（2.4）连 $group 都才两岁（对位 [../MongoDB_The_Definitive_Guide_3e/04-聚合框架.md](../MongoDB_The_Definitive_Guide_3e/04-聚合框架.md)）。

### 2.2 日期族：时间桶的语法化

- $dateTrunc（5.3+）= 语义完整的时间桶：`{date, unit, binSize, timezone, startOfWeek, startOfMonth}`——**timezone 参数原生内置**；SQL 侧 `date_trunc('day', ts)` 无时区参数（PG/SQLite/DuckDB 皆然，要靠 AT TIME ZONE 另拼）。
- $dateToString/$dateFromParts/$dateAdd/$dateDiff：格式化与历法算术全套，对位 strftime/日期修饰符（SQLite ✅ https://www.sqlite.org/lang_datefunc.html 未单测则 ⚠️ 域惯例）与 DuckDB 的 date_trunc/epoch 族。
- Mongo 内部一律 **UTC 毫秒**存储——"时区是显示层的事"这条纪律与两演示引擎的亲和性差异，正是本章 94 行分歧的成因预演。

## 3. MQL⇄SQL 对照表（本章族）

| 管道 | SQLite 🔧 | DuckDB 🔧 | 备注 |
|---|---|---|---|
| $setWindowFields + $sum OVER 运行和 | `SUM(x) OVER (PARTITION BY c ORDER BY t ROWS UNBOUNDED PRECEDING)` | 同左 | Q8：8,117.32 同值 |
| rank() 平局头名计数 | `rank() OVER … =1` | 同左 | Q8-3：28,003 行 |
| $shift{direction:-1} | `lead(x) OVER …` | `lead(x)` | 方向词对位前后移 |
| $density/$stdDevPop OVER | STDDEV 缺失 ❌ | `stddev_pop OVER` ✅ | 引擎能力差 |
| $dateTrunc{unit:'year'} | `strftime('%Y',ts,'unixepoch')` | `year(to_timestamp(ts))` | Q12：分歧组 ↓ |
| $dateToString fmt | `strftime` 直通 | `strftime` 亦存 ✅ | 格式化三家同族 |
| timezone 参数 | ❌（需改 modifier） | AT TIME ZONE 子句 | Mongo 原生领先 |
| startOfWeek | 手工 (wday+n)%7 | 手工/dow 扩展 | 三家皆弱 |

## 4. 🔧 实测组（复现语义，非 mongod 行为）

- **Q8-1 运行和**：A 订单、客户 c0001 按 ts 累销，末行=**8,117.32**（SQLite 62.4ms / DuckDB 18.6ms，同值 ✅）——$setWindowFields 的 `window:{docs:[UNBOUNDED,CURRENT]}` ⇄ ROWS UNBOUNDED PRECEDING 一一译。
- **Q8-3 rank 平局**：全体 A 拆平行里 qty 组内第一（rank=1）共 **28,003** 行（SQLite 904.3ms）：管道 $rank 同款语义、同款"每分区多行并列"；01 章"取组内最大值文档"之坑在此给出正规解。
- **Q12 日期分歧（计划外，如实登记）**：按"年"分桶计数——SQLite `2023:100,296 / 2024:99,704` vs DuckDB `2023:100,202 / 2024:99,798`，**94 行跨年边界分歧**（177.3/35.7ms）。复跑不变（seed 固定）。本环境未能把 94 行逐条追到具体秒值 ⚠️，但两侧对 unix 秒→日历年的换算细节（DuckDB `to_timestamp` 的 tz 语境/闰秒历法 vs SQLite 纯 UTC 除法）互有出入是已知型别。**教训入纪律**：日期分桶跨引擎验证必须做"边界样本日"专项（本册补记为未来 Q12b），$dateTrunc 的 timezone 参数在此不是可选项。
- **Q13 日粒度桶+阈值**：单日 A 订单 distinct 客户 >170 的天数=**2**（SQLite 236.4ms / DuckDB 49.4ms，一致 ✅）；阈值 3000 时两侧同为 0（前轮实测）——HAVING 语义在时间桶上同德，且再次演示"空结果 vs 空流"的 Q3 教训（$group 空输入不出文档，SQL 聚合恒出一行）。

## 5. 常见误区

1. **忘 sortBy 就用运行和**：$setWindowFields 无 sortBy 时 frame 无定义（官方注记 ⚠️）；SQL 侧 `SUM() OVER (PARTITION BY c)` 不排序却是合法的"组内总和重复"——**方言强制性不同**，移植方向不同坑不同。
2. **range 窗口拿字段当时间轴**：Mongo range 边界表达式有类型苛求（date/number），`between:'unbounded preceding' and 0` 之类要写成表达式对象 ⚠️；SQL 的 RANGE INTERVAL 语法糖在 SQLite/DuckDB 支持面又各不相同——本章 94 行分歧正是"日期数值化"的代价。
3. **$dateTrunc 的 binSize 与 unit 错配**：binSize:7+unit:'day' 是"七天桶"非周对齐，周对齐要 startOfWeek:1——SQL 手搓 `(julianday/7)` 时同样一坑（本册对照表标弱）。
4. **窗口算子当 $group 优化**：$setWindowFields 不压行，20 万行输出照旧进下游——"用窗口替代 $group 省内存"是反的（内存账见 07）。
5. **$shift 当 LAG 用忽略默认值**：direction 越界输出 undefined 字段（可给 default）；SQL lead/lag 给 NULL——下游 `{$ne:undefined}` 与 `IS NOT NULL` 不互译。

## 7. 本章一句话

**$setWindowFields 补完了管道"不压行的聚合"这块 SQL 早已习以为常的拼图；而 94 行的跨年分歧提醒：日期是聚合工程里唯一"看起来最不容易出错、实际最容易出错"的类型。**

## 7.5 frame 术语互译卡（逐词对位）

| $setWindowFields | SQL OVER | 备注 |
|---|---|---|
| documents:[UNBOUNDED_PRECEDING, CURRENT] | ROWS UNBOUNDED PRECEDING AND CURRENT ROW | Q8 运行和 🔧 同值 |
| documents:[n, m] | ROWS BETWEEN n PRECEDING AND m FOLLOWING | 一一译 |
| range:[UNBOUNDED, 0]（按 sortBy 值） | RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW | Mongo 的 range 以 sortBy 表达式定距；DuckDB 支持 RANGE，SQLite 3.45 亦支持基本 RANGE ⚠️ 子集 |
| 无 GROUPS 模式 | GROUPS n..m | SQL:2011 特性，Mongo 未跟进 ⚠️；PG18 线互见波内 #52/#64 |
| 无 EXCLUDE CURRENT ROW | EXCLUDE … | 同上，手改=减当前值 |
| sortBy 强制性 | 非强制（无 ORDER BY 亦合法） | 05 节误区 1 的方言差 |

## 7.6 94 行跨年分歧的复现与排除程序（🔧 实录方法）

1. 复现：`demo.py` 重跑（seed=42），Q12 两行数字稳定重现（SQLite 100,296/99,704 vs DuckDB 100,202/99,798）。
2. 定位面：对 ts 取 2023-12-31T23:59:5xZ 邻域样本逐条两函数对比（本册未展开，登记为未来 Q12b 专项 ⚠️）。
3. 已知嫌疑人：epoch→日历换算的库实现差异（SQLite 纯整数除法+UTC 查表；DuckDB timestamp_tz/日历函数族走自身历法）；闰秒不参与 epoch 但参与个别历法库 ⚠️。
4. 纪律输出：凡"日期桶跨引擎对账"，**边界 ±1 天必须专测**——本册把 $dateTrunc 的 timezone 参数从"可选项"升格为"默认项"。

## 7.7 日期族互译小抄（高频五件）

| MQL | SQLite | DuckDB |
|---|---|---|
| $dateTrunc{unit:'month'} | `strftime('%Y-%m',ts,'unixepoch')` | `date_trunc('month', to_timestamp(ts))` |
| $dateToString{'%Y-%m-%d'} | `strftime('%Y-%m-%d',…)` ✅ | `strftime(…)`（复用 printf 风格 ✅ https://duckdb.org/docs/sql/aggregates 域内） |
| $dateAdd{unit:'day',amount:7} | `date(ts,'+7 days','unixepoch')` 心智 | `to_timestamp(ts)+INTERVAL 7 DAY` |
| $dayOfWeek（周日=1） | `(strftime('%w',…)+1)` | `extract(dow)+1`（起点方言 ⚠️） |
| $dateDiff{unit:'week'} | `(a-b)/604800` 手搓 | `date_diff('week',a,b)` |

## 核心概念速览（中英对照）

1. **$setWindowFields** — setWindowFields stage：不压行的分区窗口计算，5.0 引入。
2. **窗口配置** — windowConfigs：一阶段多套 partitionBy/sortBy/frame 的并列定义。
3. **frame** — window frame：documents/range 两型边界，UNBOUNDED/CURRENT/N 表达；无 GROUPS/EXCLUDE。
4. **运行和** — running total：docs UNBOUNDED→CURRENT 的 $sum，Q8=8,117.32。
5. **$rank/$denseRank/$documentNumber** — 排行三件套：对位 SQL rank/dense_rank/row_number，平局语义同。
6. **$shift** — shift operator：分区内前后移，对位 lead/lag，越界给 default。
7. **$dateTrunc** — date truncation：unit/binSize/timezone/startOfWeek 的时间桶原语。
8. **时间桶** — time bucket：日期截断后分组计数的通称，时序降采样的 SQL 同义词。
9. **UTC 毫秒存储** — internal UTC：Mongo 日期一律 UTC 存、显示层转时区。
10. **边界样本日** — boundary sampling（本册纪律）：跨引擎日期验证必须专测年/月/日界（94 行分歧教训）。
11. **窗口不压行** — windows keep rows：与 $group 的本质分界，20 万行照旧流下游。
12. **空结果 vs 空流** — zero-row vs no-doc：聚合恒出一行 vs $group 空输入无输出（Q13 双态实证）。
13. **RANGE 类型苛求** — typed range bounds：Mongo range 边界对 date/number 的强类型纪律。
