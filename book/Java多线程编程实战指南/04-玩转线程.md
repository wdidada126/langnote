## 二、核心精讲

### 2.1 DCL 单例
- `private static volatile Singleton instance;` + 双重 `if` + `synchronized` 块；`volatile` 阻断"构造重排到引用赋值前"。
- 现代直接 `static final` 或延迟占位类（JVM 保证线程安全）。

### 2.2 生产者-消费者
- 用 `ArrayBlockingQueue`（**指定容量**！）或 `LinkedBlockingQueue`（🔧 默认无界 OOM）。
- 背压：队列满时生产者阻塞，避免 OOM。

### 2.3 线程未捕获异常
- 线程 `run()` 抛未捕获异常 → 默认打印到 `System.err` 然后线程死；业务错误被吞。
- 用 `Thread.setDefaultUncaughtExceptionHandler` 或线程池 `afterExecute` 统一处理（见第 8 章）。
