# 第 8 章 线程管理（原书 pp.310-332）

> 线程的"生命周期治理"：关闭、异常处理、池化、监控。与《艺术》9 章（线程池源码）互补，本书重"管理实践 + 线上治理"。

| 主题 | 关键 |

## 二、核心精讲

### 2.1 优雅关闭（与《实战》7 章 / 之美中断专篇一致）
- 应用关闭：`shutdown()`（温和）或 `shutdownNow()`（尝试 interrupt 运行任务）+ `awaitTermination(timeout)`。
- 任务内响应中断：catch `InterruptedException` 后重抛或 reInterrupt（勿吞）。

### 2.2 未捕获异常
- 线程级异常不向上传播；用 `setDefaultUncaughtExceptionHandler` 统一记录。
- 线程池：`afterExecute(r, t)` 钩子捕获 `Future` 内异常（🔧 否则 `submit` 的异常被吞到 `get()` 才抛）。

### 2.3 线程池管理
- 参数：`core`/`max`/队列/空闲超时/拒绝策略（Abort/Discard/DiscardOldest/CallerRuns）。
- 监控：`getActiveCount()`/`getCompletedTaskCount()`/`getQueue().size()` 接监控系统。
- 🔧 快捷池（Fixed/Single/Cached）有 OOM/无限线程风险；生产用自定义 `ThreadPoolExecutor`。

## 三、版本演进

- **JDK 21**：`Executors.newVirtualThreadPerTaskExecutor()` + `StructuredTaskScope` → IO 密集不再需手动管理平台线程池（关闭变作用域级）。

## 六、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "submit 异常自动抛" | 吞到 get()；用 afterExecute |
| 2 | "忘了 shutdown 没事" | 非 daemon 阻止 JVM 退出 |
| 3 | "快捷池放心用" | Fixed/Single 无界 OOM；Cached 无限线程 |
