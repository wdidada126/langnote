## 二、核心精讲

### 2.1 调校原则（先量后改）
- 不靠猜：用 JMH 微基准（避开 GC/动态编译/死代码消除五陷阱，见《实战》12 章）。
- 看全局：Amdahl 定律（串行长 `F` 决定天花板，见《实战》11 章 + 之美 Amdahl 专篇）。

### 2.2 减少锁竞争四法（与《艺术》9 章一致）
1. 减小临界区（快进快出）。
2. 减小锁粒度（拆多把锁）。
3. 锁分段（如 JDK 8 前 CHM）。
4. 无锁化（CAS / 无锁结构 / `LongAdder`）。

### 2.3 伪共享（与《之美》伪共享专篇一致）
- 多个热点字段在同一缓存行 → 核间乒乓失效该缓存行 → 吞吐暴跌。
- 解法：JDK 8 `@Contended`（需 `-XX:-RestrictContended` 或模块开放）/ `LongAdder` 分段 / JOL 看布局。

### 2.4 线程池调优
- `N_threads ≈ N_cpu * U * (1 + W/C)`（W=等待时间，C=计算时间）；但**必须压测**（见《艺术》9 章）。
- 避免无界队列（OOM）/ 无限线程（Cached）。

### 2.5 工具链
- **async-profiler** `-e lock` 量化锁竞争；`-e cpu` 看切换；`-e alloc` 看分配。
- **JFR**：生产低开销看锁等待/阻塞/GC。
- **JOL**：看对象头/对齐/伪共享。

## 三、版本演进

- **JDK 8**：`@Contended`/`LongAdder`。**JDK 9**：JFR 开源。**JDK 21**：虚拟线程改"线程贵"假设 → 许多 IO 调优不再需要。
