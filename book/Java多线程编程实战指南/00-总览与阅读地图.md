> 作者：黄文海。本书独特定位：**以"多线程编程的目标与代价"为主线**——不是讲 API，而是讲"为什么要并发、并发带来什么故障、怎么在设计与调试层面系统性保障安全与性能"。相比 Goetz《实战》偏"原则与陷阱"、方腾飞《艺术》偏"底层"、冷血偏"手写"，**本书偏"工程方法论 + 活故障 + 调校"**，且第 11 章"硬件基础与 JMM"、第 12 章"性能调校"是补强项。

## 三、版本演进时间轴

- **JDK 5 (2004)**：J.U.C 引入，本书 API 基线。
- **JDK 7/8**：本书写作基线（ForkJoin、CompletableFuture 已可用）。
- **JDK 9+**：`VarHandle`（JEP 193）取代 `Unsafe`；JFR 开源。
- **JDK 21-25**：虚拟线程（JEP 444）/ 结构化并发（JEP 453/505）/ ScopedValue（JEP 506）——本书"线程管理/异步/活性故障"章节的现代改写。

## 五、本书没覆盖的缺口

1. 虚拟线程/结构化并发（JDK 21+）——"线程管理/异步"章节的现代替代。
2. `VarHandle` 5 档语义（JDK 9+）——仍 `Unsafe` 视角。
3. `LongAdder`/伪共享 `@Contended`（JDK 8）——性能调校章未展开。
4. 现代并发测试工具 jcstress/Coyote（见《实战》12 章 + 之美测试方法论专篇）。
