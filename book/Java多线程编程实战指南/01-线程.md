# 第 1 章 走近Java世界中的线程（原书 pp.2-30）

> 线程入门：什么是线程/进程、Java 线程模型（1:1 内核线程）、创建方式（Thread/Runnable/Callable/线程池）、生命周期。与《艺术》4 章互补，本书重"概念与代价"。

| 主题 | 关键 |

## 二、核心精讲

### 2.1 进程与线程
- 进程：资源（内存/文件句柄）分配单位；线程：CPU 调度单位。
- 单进程多线程：共享堆 + 方法区，各有独立栈 → 通信廉价（共享变量）但需同步防竞态。

### 2.2 Java 线程是 1:1 模型
- 每个 Java 线程映射一个 OS 内核线程（HotSpot 通过 `pthread`/OS 线程）。
- 代价：创建/切换涉及内核，贵 → 线程池复用（见第 8 章 / 《艺术》9 章）。
- 🔧 JDK 21 虚拟线程：M:N 调度（多虚拟线程复用到少量平台线程），创建成本接近 0，"一请求一线程"重获可行（JEP 444）。

### 2.3 创建方式与取舍
- `Runnable` 优于 `Thread` 继承（更灵活、可复用、可进线程池）。
- `Callable` 有返回值/抛受检异常，配 `Future`/`FutureTask`。
- 生产：**一律用线程池 / 虚拟线程**，避免 `new Thread().start()` 失控（见第 8 章）。

### 2.4 生命周期（6 态，与《艺术》4 章一致）
- `BLOCKED` 仅指 `synchronized` 竞争；`ReentrantLock` 等待是 `WAITING`/`TIMED_WAITING`（AQS 队列 park）。

## 三、版本演进

- **JDK 1.0**：1:1 线程（早期有过绿线程短暂历史）。
- **JDK 5**：`Callable`/`Future`/线程池。
- **JDK 21**：虚拟线程（M:N），1:1 模型不再是"唯一昂贵选项"。

## 六、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Java 线程很便宜随便建" | 1:1 映射内核线程，贵；用池/虚拟线程 |
| 2 | "继承 Thread 方便" | 用 Runnable/Callable，灵活可复用 |
| 3 | "直接 new Thread 跑任务" | 失控；用线程池/虚拟线程执行器 |
| 4 | "守护线程能做清理" | 不阻止 JVM 退出，清理未必完成 |
| 5 | "BLOCKED 含所有等待" | 仅 synchronized；ReentrantLock 等待是 WAITING |
