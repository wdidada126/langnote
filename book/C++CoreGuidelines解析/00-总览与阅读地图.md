## 本笔记与原指南的关系声明

1. **本书是解析，不是译本**：格林的书不逐字翻译 Guidelines（原指南亦以"引用规则编号"
   方式被使用，MIT 式授权，master 文件头实测声明）；本书的增量是按章组织的讲解、示例与
   工具落地。因此本笔记不冒充原指南逐字条文，所有"原文"引述均标注 current master 实测。
2. **快照漂移是常态**：本书依据 2023-07 前后的指南快照；本笔记以 2026-09 抓取的 master 为
   编号口径（一级标题 32 个、编号规则 448 条、In.sec 主要节 16 + 支撑节 13，均实测），
   差异处逐章 ⚠️ 标注（已知：Con 组条数收缩、SL 前缀曾摇摆 Std./SL、A 节含 `???` 占位）。
3. **规则数逐前缀实测清单**（grep 448 条标题所得）：P 13、I 20、F 38、C 97、Enum 8、R 22、
   ES 64、Per 18、CP 31、E 21、Con 5、T 54、CPL 3、SF 16、SL 约 20（含子前缀）、
   A 3、NR 7、Pro 13（Type.1–8/Bounds.1–4/Lifetime.1）、GSL 无编号规则（6 个设施子节）、
   NL 21、FAQ 21。

## 阅读路线

1. **顺读书序**：01 → 21，每文件独立成课，跨章引用已织入"相邻概念对比"。
2. **安全主线（推荐老项目接手者）**：07 资源 → 19 规格 → 20 GSL → 21 施行/契约——
   "消灭一类错误"的完整闭环：规则(R) → 成建制执法(profile) → 设施(GSL) → 运行期兜底
   (🔧 `_GLIBCXX_ASSERTIONS` 实测见 19)。
3. **接口评审线（API 设计者）**：03 接口 → 04 函数 → 05 类 → 13 模板 → 11 错误处理；
   配套外部深读 [../C++API设计/](../C++API设计/00-总览与阅读地图.md)。
4. **C 转 C++ 线**：14 C 风格 → 08 表达式语句 → 06 枚举 → 16 标准库 → 19 规格
   （每章 🔧 段都有"旧写法编译/运行现场"）。
5. **并发线**：10 并发 → 09 性能 → 12 常量（数据竞争=可变性×共享，12 章命题）→
   [../C++并发编程实战2/](../C++并发编程实战2/00-总览与阅读地图.md)。
