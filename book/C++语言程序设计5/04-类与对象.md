## 1 动机

本章把"数据 + 操作"焊成**类**这个类型系统一等公民。教材考试在"构造析构调用次序"，
真问题在**值语义的四个特例行**（默认构造/复制构造/复制赋值/析构）——它们是对象生命周期账本的
四栏，谁手写错了栏，第 6 章的指针成员就来引爆。

## 2 机制

### 2.1 构造/析构是编译期织入的协议

- 构造顺序：基类→成员（**按声明顺序**，与初始化列表书写顺序无关——考试点，机制解释：
  成员按声明布局分配，析构需要对称逆序，初始化列表只管初值不管次序）→自身函数体。
- 构造体内赋值 vs 初始化列表：对类类型成员，进入函数体前默认构造已经跑过一遍，
  体内"赋值"是第二次操作；无 const/引用成员时才能不写列表。
- 析构 = 成员逆序自动销毁 + 你的函数体（体先跑、成员后死——常见误解）。
- 编译器生成复制构造的条件与代价：按成员复制；对裸指针成员这恰恰是**最危险的正确语法**。

### 2.2 值语义与隐式转换的接缝

单参构造不带 `explicit` = 自动获得 `MyString s = "abc"` 的隐式转换通道（教材 4.9.2 点到了）。
现代纪律反过来：`explicit` 是默认姿势，只有"真的想要转换"才裸奔——`std::string` 的构造即如此设计。
复制省略（RVO/copy elision）：按值返回时编译器可在目标地址就地构造，**即使没写移动构造也可能不发生拷贝**
（C++17 起纯右值返回场景为强制省略）；"写了移动构造才快"是半真相。

### 2.3 对象布局的第一瞥

无虚函数的类：`sizeof` = 成员之和 + 对齐填充（位域 4.9.1 是对这条布局的手工干预）。
成员函数不占对象空间——它是带隐藏 `this` 参数的普通函数（mangling，衔接 03 章 §2.1）。
含虚函数后多出 vptr——那是 [08-多态性.md](08-多态性.md) 的账，此处知道"对象=数据成员+对齐"即可。

### 2.4 union 的真机制与真陷阱

union 所有成员共享起始地址、`sizeof` 取最大成员、**非平凡类型成员需要手工-placement 构造/析构**
（教材 4.6.2 点到"有对象成员受限"）。它的现代形态是"判别式联合"= union + tag + 手动/自动生命周期，
即 `std::variant` 的原料（§最新演进）。

## 3 权衡

- **组合 vs 继承**：教材 4.4 立组合，7.8.1 再对比。默认姿势：**组合优先**——继承带来
  名字掩蔽、二义、脆弱基类三件套（07 章实测 sizeof 虚继承税）。
- **手写四件套 vs 零法则**：每个含资源类都手写=高出错率；成员皆为 RAII 类型=四件套全自动
  （§5 实测 Stock 案例）。工业共识 **Rule of Zero → 五法则（含移动）→ 特例才三/五法则**。
- **委托构造 vs 私有 init()**：委托一次到位但构造顺序推理变难；二者都比复制粘贴强。
- **位域的便携性幻觉**：位域布局（从低/高字节填充）由实现定义——网络协议头请用移位显式拼装。

## 4 相邻概念对比

| 对比项 | 差异点 | 备注 |
| --- | --- | --- |
| 复制构造 vs 复制赋值 | 造新的 vs 改旧的（需先释放旧资源） | 参数都要 `const T&` |
| 移动构造 vs 复制构造 | 资源窃取（O(1)）vs 内容克隆 | 移动后对象须可析构（置空） |
| `=default` vs 不写 | 语义同但 `=default` 抢回"抑制点" | 写了析构则默认移动被抑制 |
| struct vs class | 仅默认访问级不同 | 教材 4.6.1 的历史包袱口径 |
| enum vs enum class | 是否泄漏到作用域、是否有隐式整转 | `enum class Color: uint8_t` 现代默认 |
| 前向声明 vs include | 指针/引用成员只需声明 | 组合类头文件解耦的起点（05 章） |

## 最新演进与工业实践

1. **三/五法则 → 零法则**：🔧 实测（ch04_old/new）：C++98 深拷贝 Str 约 20 行样板；换成
   `std::string + std::vector` 成员的 Stock，**删光**五件套，拷贝/移动/析构全自动且正确
   （实测输出 `b=AAA@2.5 c=AAA@2.5`）。条款化出处：
   [../Effective_Modern_C++/05-右值移动完美转发.md](../Effective_Modern_C++/05-右值移动完美转发.md)（Item 17 特殊成员函数的现代表述）。
2. **`=default/=delete` 的战术用法**：禁拷贝只留移动（`Stock(const Stock&)=delete;`）、
   禁堆（`operator new`=delete）、禁隐式转换——教材 4.3.7 已讲到 default/delete，演进在用法宽度。
3. **聚合初始化的翻身**：C++14 嵌套 `{}`、C++17 继承也聚合、C++20 指定初始化
   `Point{.x=1,.y=2}`（声明序校验）——教材的 `Date d; d.day=...` 三段式在现代写法里是一行。
4. **union → `std::variant`（C++17）**：带类型检查、异常安全的判别式联合；`std::any`（可持有型）、
   `std::optional`（可缺值）是它的两个特例。深挖：
   [../C++标准库/04-容器.md](../C++标准库/04-容器.md)（variant/optional 节）。
5. **委托/继承构造的补全**：`using Base::Base;`（C++11 继承构造）教材未提，派生类样板因此再减一层。
6. **教学设计对照**：本教材把四件套放第 4 章、移动构造也进第 4 章（4.3.6）——这比多数 2010 年代
   欧美教材激进，属"经典 OO 外壳 + C++11 内核"的混血编排；配套的现代动机（为什么要移动）
   在 [../现代C++实战30讲/03-右值与移动及返回对象.md](../现代C++实战30讲/03-右值与移动及返回对象.md) 补讲。
7. **cppreference 口径**：每个特殊成员函数的"隐式声明/定义/被抑制条件"表是本章考点的完全体，
   考试深度之上以它为准（教材 4.3 相当于其 1/5 篇幅）。

### 🔧 教材写法 vs 现代写法双编译实测（本机 MinGW g++ 15.2.0）

```text
ch04_old.cpp  -std=gnu++98 ✅：裸指针成员 Str，手写深拷贝三件套。
              实测输出 ctor / copy-ctor(deep) / b = hello / dtor / dtor
              （析构两行：栈对象逆序——先 b 后 a，声明序的镜像）
ch04_new.cpp  -std=gnu++23 ✅：零法则 Stock（string+vector 成员，无五件套），
              拷贝 b、移动 c 均隐式生成且正确：b=AAA@2.5 c=AAA@2.5
```

对照结论：样板行数从 ~20 → 0，出错面从"每个指针成员"→"成员本身是 RAII"。
老式四件套仍要会读——考古 + 面试双料刚需。
