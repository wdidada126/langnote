## 1 动机

模板是 C++ 泛型轴的第一原理：**复制代码的权力交给编译器，用编译期实例化换运行期类型安全**。
教材的编排小心思在第 9 章的"群体数据"实践：先学模板语法，立刻手写 Array/LinkedList/Stack/Queue
四个容器——不是为了用它们，是为了在第 10 章看见 STL 时知道**每一层抽象在替谁负重**
（节点析构、异常安全、迭代器失效——06 章的账全部到期）。

## 2 机制

### 2.1 隐式实例化与"定义进头文件"

98 标准的 `export` 模板（编译器分别编译实例） commercially 失败后，
主流模型只剩**隐式实例化**：使用点生成代码 → 编译器必须看见定义 → 模板体放头文件。
这解释 9.1 的"为什么模板都写在 .h"——不是语法怪癖，是 20 年编译模型投票的结果（设计史：
[../C++语言的设计与演化/08-模板：泛型的前史.md](../C++语言的设计与演化/08-模板：泛型的前史.md)）。
实例化时机/两阶段查找的完整机制在
[../C++编程惯用法/07-模板的高级用法.md](../C++编程惯用法/07-模板的高级用法.md)（该章 11 号样本实测过无约束 vs concepts 的报错落点差异）。

### 2.2 决议：名字找重载，重载赢了再说特化

`template<> int maxOf<int>(int,int)` 全特化存在时，调用 `maxOf(a,b)` 仍先看**重载集**：
普通函数 > 更专用的模板匹配 > 特化不参与"选模板"这步。9.5.2 的特化用例（为指针类型减一层间接）
的正确姿势是**重载**而非偏特化（函数模板无偏特化——语言缝死的老坑，CLRS 级讨论见链接节）。

### 2.3 手写容器四件套在教什么

数组类：拷贝三件套 + 深浅复制（06 章）+ 越界检查（`operator[]` 返回引用使 `a[i]=x` 可查）；
链表类：`Node*` 头的生命周期全账——**每个 new 找它的 delete 路径**，异常路径一断即漏（12 章伏笔）；
栈/队列：容器适配器概念的肉身上课版——同一链表可套两种接出口。
教材 9.2 的代码是"能跑的教学版"，工业版差距=异常安全+移动语义+分配器，三样各值一章。

### 2.4 教学排序算法的机制注脚

三排序全 O(n²) 但常数与性质不同：插入排序**稳定**、近乎有序时 O(n)；选择排序交换最少；
冒泡（教材"交换排序"）可早退。折半查找的事故在**边界**：`low <= high` 与 `mid = low + (high-low)/2`
（防溢出写法）——`bsearch` 至今有 CVE 级历史（JSL 的著名 bug 注脚，见"最新演进"）。

## 3 权衡

- **模板 vs 虚函数**（承 08 章）：类型封闭、性能敏感 → 模板；类型开放、运行时未知 → 虚。
  判据一句话：**"调用点知道类型吗？"**
- **代码膨胀**：每个 `<T>` 实例一份代码——现代对策是把公共体下沉到非模板基函数（侯捷版：
  [../STL源码剖析/01-STL概论与版本简介.md](../STL源码剖析/01-STL概论与版本简介.md) 的瘦身例）。
- **NTTP 的窄门**：float 作模板参数 20 年不许（C++20 才开）；字符串参数要 linkage 对象——
  教材 `Array<T,int N>` 只走了最平坦的一条路。
- **手写 vs 用 STL**：9.2 的练习价值在机制理解，**生产环境永远用 STL**——教材 9.4 的银行账户
  改进即示范"换掉手写容器"的迁移路径。

## 4 相邻概念对比

| 对比项 | 差异点 | 备注 |
| --- | --- | --- |
| 函数模板 vs 函数重载 | 生成一族函数 vs 手写一族函数 | 决议时普通重载优先（§2.2） |
| 全特化 vs 偏特化 vs 重载 | 类可全/偏；函数只能重载 | "函数无偏特化"是语言事实 |
| `Array<T,N>` vs `vector<T>` | 编译期容量零开销 vs 运行期容量可成长 | 栈上小缓冲 vs 堆上动态 |
| 模板参数 `class T` vs `typename T` | 模板语境同义 | 嵌套依赖名必须 typename（07 惯用法章） |
| 排序三兄弟 vs `std::sort` | 教学 O(n²) vs introsort O(n log n) + 小区间插排 | 工业答案在第 10 章 |

## 最新演进与工业实践

1. **可变参数模板：从递归展开到折叠表达式**。🔧 实测（ch09_old/new）：C++11 递归版
   `sum(first, rest...)` 两个重载 4 行 + 终止条件；C++17 一行 `(vs + ... + 0)`。
   `std::make_unique`/`emplace_back` 的完美转发身位见
   [../Effective_Modern_C++/05-右值移动完美转发.md](../Effective_Modern_C++/05-右值移动完美转发.md)；
   手写一遍：[../现代C++实战30讲/10-可变模板tuple与类型擦除.md](../现代C++实战30讲/10-可变模板tuple与类型擦除.md)。
2. **模板约束：SFINAE → concepts（C++20）**。教材 9.5.3 的 TMP 简介（编译期阶乘一类）
   现代教学位已被 **concepts + 编译期计算** 替换（`consteval`/`constinit`，C++20）。
   🔧 实测（ch09_new）：`template<std::integral T> T gcd(...)` 约束即文档即检查；
   违例报错从"模板黑话墙"变"约束不满足"一行。深挖：
   [../C++模板元编程/02-Traits与类型操纵.md](../C++模板元编程/02-Traits与类型操纵.md)、
   [../C++20模板元编程.md](../C++20模板元编程.md)（同题的现代重讲）。
3. **`Array<T,N>` 的官方后代**：`std::array`（C++11）+ `std::span`（C++20，06 章实测）——
   手写数组类退役为练习册物种。
4. **教学容器的现代审视**：手写单链表在 2020 年代面试与教学中存活，理由=最便宜的
   指针+生命周期综合实验；现代加固姿势是 `unique_ptr` 节点（自动析构链，异常安全白拿）。
5. **binary search 的官方化**：`std::lower_bound/upper_bound/binary_search`（C++11 起配迭代器）——
   手写折半的边界事故，标准版以"区间 `[first,last)` 半开"统一口径绕开。
6. **模块（C++20）与"定义进头文件"**：`export template` 借尸还魂式复活——模块可分离编译模板。
   普及度仍低 ⚠️ 本目录未实测；方向性阅读：
   [../现代C++实战30讲/16-未来篇Concepts-Ranges-协程.md](../现代C++实战30讲/16-未来篇Concepts-Ranges-协程.md)。

### 🔧 教材写法 vs 现代写法双编译实测（本机 MinGW g++ 15.2.0）

```text
ch09_old.cpp  -std=gnu++11 ✅：maxOf 函数模板 + C++11 递归展开可变参 → maxOf=7, sum=15
ch09_new.cpp  -std=gnu++23 ✅：折叠表达式 sum=15；std::integral 约束 gcd(12,18)=6；
              std::semiregular 约束的 Box 模板 → Box=7
```

同一求和：递归终止重载消失、报错友好度上升、约束写进签名——这就是本章的"现代对照"最小样本。
