## 本目录约定

- 🔧 = 自写代码示例；"实测"为本机 **MinGW g++ 15.2.0**（`-std=gnu++98/11/23 -Wall`）编译/运行/nm 第一手
  结果，样本全在仓库外 `D:\develops\tmp\cppsnippets_zhengli\`，仓库内不留任何 .cpp/.exe。
  实测清单：01 补码/bit_cast（含 `<print>` 链接缺符号事故 + `{:032b}` 非法格式串）；02 宏双求值
  `-Wsequence-point` 现场；03 默认参×重载二义编译错误 + lambda 捕获；04 三件套 vs 零法则输出序；
  05 静态成员两代定义法；06 sizeof 退化 20vs8 + strcpy 溢出警告（运行"侥幸正常"）+ span/string_view；
  07 菱形二义错误 + 虚基类 sizeof 税表 + 接口组合；08 override 静默失败 vs 编译拦截 + deducing this；
  09 递归可变参 vs 折叠/concepts；10 迭代器手工过滤 vs ranges 管道（含 `<algorithm>` 漏include 报错实录）；
  11 iomanip+抛 int vs format+expected。
- ⚠️ = 未核实项：页码逐页复核、2021 印次、cpp-5th 仓库逐文件、Google 禁异常措辞、C++26 细节、
  阚道宏目录版落盘。原书正文引句一律不伪造——各章所引"教材讲了什么"以目录条目与单文件笔记为据。
- 诚实声明：教材本身未发现 `iostream.h`/`void main` 类化石（第 5 版语言层是干净的）；
  滞后在**口径**不在语法错误，上表 #1–#12 即完整清单。
- 本目录只在 `book/C++语言程序设计5/` 新建文件 + 仓库外临时目录；未做任何 git 操作。
