## 精读补写（系统整理，2026-09-23）

### 版本与 ISBN
- 笔记所指为 **Sedgewick & Wayne《算法（第 4 版）》Java 描述版**，中文版人民邮电出版社，2012-10，**ISBN `978-7-115-29380-0`**（豆瓣 https://book.douban.com/subject/19952400/ ）。
- 英文原版 *Algorithms, 4th Edition*（Addison-Wesley, 2011，ISBN `0-321-57351-X`）。作者 Robert Sedgewick 是 Knuth 的博士生、普林斯顿教授，Kevin Wayne 为其长期合作者；配套 Princeton Algorithms 公开课程与 `algs4` 库。
- **与《算法导论》的关系**（笔记已点出）：本书给**可直接运行、带测试与可视化的 Java 实现**，强调"科学方法"（提出假设 → 写程序验证 → 用 DoublingRatio 等实验测量）；《算法导论》走**伪代码 + 数学证明**路线。二者是"工程实现"与"理论分析"的互补，而非替代。

### 主线脉络（第 4 版六大部分）
**基础**：编程模型、数据抽象、**背包-队列-栈**、算法分析（大 O、增长数量级、倍率实验）、**Union-Find（并查集）**。
**排序**：初级排序（选择/插入/希尔）、**归并排序**（自顶向下/自底向上）、**快速排序**（切分、三向切分）、**优先队列与堆排序**、应用（稳定性、排序的应用与归约）。
**查找**：符号表 API、无序/有序链表查找、二分查找、**二叉查找树**、**平衡查找树（2-3 树 → 红黑树）**、**散列表**（拉链/线性探测）、应用（集合、字典、索引、稀疏向量与矩阵）。
**图**：无向图与有向图的表示、DFS/BFS、**最小生成树**（Prim/Kruskal）、**最短路径**（Dijkstra/Bellman-Ford/无环加权）。
**字符串**：字符串排序（LSD/MSD 基数排序、三向快排）、**Trie（R-way / TST）**、子串查找（**KMP / Boyer-Moore / Rabin-Karp**）、正则表达式、数据压缩（Huffman、LZW）。
**高级**：B 树、后缀数组与字符串处理、最大流（Ford-Fulkerson）、**问题归约与不可判定性**（把 NP 完全与停机问题作为收尾）。

### 经典论文与原始文献根基
- **Knuth**《计算机程序设计艺术》卷 3《排序与查找》(1973)——Sedgewick 的师承来源，也是本书大量分析方法的出处。
- **Guibas & Sedgewick《A Dichromatic Framework for Balanced Trees》**(FOCS 1978)——红黑树的"二色框架"，本书第 3 章红黑树讲解的理论根基（作者本人成果）。
- **Pugh《Skip Lists》**(CACM 1990)；**Bayer & McCreight** B 树 (1972)——跳跃表与 B 树章节。
- **字符串匹配三剑客**：Knuth-Morris-Pratt (1977)、Boyer & Moore (1977)、Karp & Rabin (1987)。
- **Huffman (1952)** 与 **Welch 的 LZW (1984)**——压缩章节；**Ford & Fulkerson** 网络流 (1956/1962)。
- **Tarjan** 的并查集与摊销分析 (1975)；**Fredman & Tarjan** 斐波那契堆 (JACM 1987)——最短路径与 MST 的理论最优界。
- **Cook-Levin (1971/1973)** 与 **Karp (1972)** NP 完全——最后一章"归约与不可判定性"的依据。

### 最新研究与产业进展
- **算法工程（Algorithm Engineering）**：Sanders、Mehlhorn 等倡导的"理论 + 实现 + 实验"方法论正与本书一脉相承；现代研究强调在真实数据与缓存层次上验证（如 STXXL、TLX、k-way 归并排序的 SIMD 实现）。
- **亚线性/流式算法与 sketches**：**Count-Min Sketch**(Cormode & Muthukrishnan, 2005)、**HyperLogLog**(Flajolet 等, 2007；Google HLL++ 2013)——大数据基数与频率估计；**t-digest**(Dunning, 2019) 近似分位数。这些是本书"查找/统计"议题的现代表达。
- **并行与异构算法**：GPU 排序/图算法（Thrust/CUB、Gunrock）、NUMA 感知与向量化排序（SIMD 排序已用于 ClickHouse/Arrow/DuckDB）。
- **学习增强算法（Algorithms with Predictions）**：MIT 2018 年起的新方向——用机器学习预测替代最坏情况假设，在缓存（Belady 的替代）、调度、数据结构（学习化索引）上取得突破，是当下算法研究最活跃的分支之一。
- **随机化与高维**：Johnson-Lindenstrauss、局部敏感哈希（LSH）支撑向量检索，与 AI 时代的 ANN（HNSW、IVF-PQ、DiskANN）直接相连。

### 常见误区 / 纠错
- **书中的 Java 实现 ≠ 当前 JDK 的实现**：`Arrays.sort` 对基本类型自 JDK 7 起使用 **Dual-Pivot Quicksort**（Yaroslavskiy 等），对对象数组自 JDK 7/8 起使用 **TimSort**（归并 + 插入的混合，Python/Rust 也采用）。若笔记把书中快排/归并直接当作 JDK 现状，需修正。
- **"算法复杂度低就一定快"不成立**：常数因子、缓存命中率、分支预测在真实机器上常主导性能；本书强调的"倍率实验"正是为了量化这一点。
- **红黑树与 2-3 树的等价性**是本书理解平衡树的关键视角（左倾红黑树 LLRB），阅读时不要把它与 CLRS 的"黑高"表述混为一谈——二者等价但记号不同。
