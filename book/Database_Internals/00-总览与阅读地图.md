## 书籍定位

- **一句话**：这是一本「把数据库内核摊开给你看」的书——上半程造一台单机存储引擎（B 树与 LSM 双路线 + 事务/恢复），
  下半程把它撒到不可靠网络上（失败检测 → 复制一致性 → 分布式事务 → 共识）。
- **口径**：介于教科书与源码导读之间——比 CMU 15-445 更「论文综述」，比 DDIA 更「内核实现」；
  几乎每节都点名真实系统（InnoDB、LMDB、WiredTiger、LevelDB/RocksDB、Bitcask、Cassandra、Spanner、etcd）与原始论文。
- **不做什么**：不讲 SQL 语法、不讲分布式查询处理/优化器（这是它与 DDIA、数据库系统概念的主要差异）。

## 阅读路线建议

- **主线 A（按书）**：01 → 02 → 03 → 04 → 05 → 06 → 07（Part I 收官），再 08 → 09 → 10 → 11。
  作者明确说 Part II 可独立读，但 Part I 内部是严格递进的（02 依赖磁盘模型，04 依赖 03 的页格式，05 依赖 04 的页语义）。
- **主线 B（按问题）**：
  - 「为什么我的写入慢」：02 → 04 → 07（三种放大三角）→ 05（组提交）；
  - 「快照隔离怎么做」：05 → 10（Percolator）→ 11；
  - 「从单机到分布式」：05（WAL）→ 08 → 10（2PC）→ 11（共识 = 可复制状态机）；
  - 「选型 B 树还是 LSM」：01 → 04/06（原地更新系）vs 07（延迟整理系），最后回 07 的 RUM 表结算。
- **对照读**：每章末「与其他章/其他书的联系」列了跳读点；建议开读任一章前先看 15-445 对应讲次（文件内有标注）。
