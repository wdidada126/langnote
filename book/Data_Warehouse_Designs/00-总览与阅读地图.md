## 4. 本书骨架：一种「按 ROI 反推设计」的模式方法

- **双案例结构**：Part I（2–7 章）购物篮分析（Market Basket Analysis, MBA）、Part II（8–13 章）
  时间变异（Time Variance）——各按「概念 → ROI 机制 → 难点 → 解法定义 → 架构/库表 → ETL」六步展开，
  第 14/15 章合流（时变数仓上做 MBA）。这个**六步模式本身**是书题 "Designs" 的复数含义：
  设计不是从表结构出发，而是从「业务要什么 ROI → 什么查询形态 → 什么库表形态 → 怎么喂数」反推。
- **第 1 章总纲**：Data Warehouse ROI——先论证「数仓为什么值得建、什么时候回本」，把设计决策
  挂到投资回报上 ⚠️（章题 ✅，论证细节重构）。
- **体裁**：案例驱动的**设计模式册**（非方法论总纲、非教材）——与盘上三本设计册各居一角，见 §5。
