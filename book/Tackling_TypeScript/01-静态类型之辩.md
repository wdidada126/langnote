## 一、核心机制：静态类型价值四论点 × TS 擦除裁决

面向 Java/C++/Kotlin 读者的根本落差：三兄弟语言里「类型有运行时残留」是免费资产（Java checkcast/反射、Kotlin reified、C++ 单态化成机器码 ✅ 专题四语言对照表），**TS 的类型是纯编译期话语**（一句话公理 ✅）。因此 Rauschmayer 必须把「编译期价值」单独卖出去——每条论点都要问：擦除之后，它到底兑现在哪一层？

| # | 价值论点 | 通用论证（⚠️ 凭记忆归纳其式） | 擦除裁决：TS 实际兑现程度 |
|---|---|---|---|
| 1 | **捕获错误种类** | 类型捕获的是整类而非个案的错误：属性名手误、漏分支、参数形状错——测试只枚举写得出的用例，类型是「不变式的编译期证明」（00 档引文位 ⚠️） | **有条件兑现：只在 tsc 跑的那一刻**。专题实验 B ✅：`const n: number = "not a number"` 被 node strip-types 直跑、exit=0——**删注解≠查类型**；捕获面=结构形状类，数值边界/外部数据非 null 不在内。CI 无 `tsc --noEmit` 即归零（专题戒律 1 ⚠️） |
| 2 | **文档性** | 类型是机器校验的文档：hover 即签名，永不过期（对照 Javadoc 可腐烂） | **足额兑现但全在编辑/编译层**。专题实验 A ✅：`type/interface/implements` 运行时零痕迹——反射读不到任何东西；文档价值本就不需要运行时，此论点是四者中唯一不因擦除打折的 |
| 3 | **重构安全网** | 改签名→全项目红波浪线，调用图由编译器托底；动态语言重构靠测试覆盖率赌 | **部分兑现：网眼=撒谎面**。断言不产生转换也不产生检查（专题戒律 2）；本会话实测 ✅：`42 as unknown as string` 一路放行至运行时 `toUpperCase` 崩、`JSON.parse→any→number` 注解照样放行后 `toFixed` 崩——**安全网拦得住「改动」，拦不住「谎言」** |
| 4 | **意图表达** | `readonly`、字面量类型、判别联合把「我希望数据长什么样」写进代码 | **兑现于读者契约层，零强制**。本会话实测 ✅：TS `private` 字段运行时 `Object.keys` 照在、`as any` 直读；JS `#` 才是唯一硬墙——意图=礼貌约定，不是墙（类设计条目重灾区，专题实验 A 同判） |

裁决总表：**四论点全部真实，但全部只在编译期生效**——静态类型的价值在 TS 里被改写成一条工程纪律（让 tsc 常驻），而非语言自带的运行时财产。

给 JVM/C++ 读者的三条校准句：
- 把「编译器保证」在 TS 里一律读作「**我+我的工具链**保证」——保证的主体从语言移到了人。
- 把「编译通过」读作「**我写的类型是假的也没人知道**」——soundness 的对照系是 tsc 输出，不是 JVM 校验器。
- 把「运行时类型信息」的预算读作零——凡需要在运行时问「这是什么类型」，都得自己把答案编码进数据（判别标签、schema 值，专题戒律 3 ⚠️）。

`any` 的批判（00 档标 ✅ 此段含该主题）：any =「退出类型系统」的官方出口 ⚠️ 凭记忆归纳——它不是「动态类型的值」而是「编译器闭嘴」；对比无等价物：Java `Object` 仍强制向下转型检查、Kotlin `Any` 是真超类型。本会话实测 any 传染链 ✅：单个 any 入口（JSON.parse）即可把谎言一路运输进 `number` 注解。

## 二、批判读法
- 四论点预设「工具链常在线」——这是从静态语言**移植**来的纪律，不是 JS 生态的自然属性；对 JS 老手，本书的论战价值恰在此（⚠️ 推测定位）。
- 捕获面（#1）要按集合读：TS 拦得住的是「形状错」——属性名拼错、参数少给、判别联合漏分支；拦不住的是「值域错」——越界数字、非法字符串、外部 JSON 的任何违约。Java 读者习惯了 javac+JVM 双层，须把本段每句话自动补上「且仅编译期」后缀。
- 对 Java/C++ 者最强卖点是 #3 重构网与 #2 文档，而非 #1 捕获——TS 捕获面比 javac 窄（无标称类型护体）；Kotlin 读者则反过来：#1/#4 你在 Kotlin 里是**带运行时兜底**兑现的，落差须时刻校准。
- 「类型=运行时不变式的编译期证明」若确为此段表述（00 档 ⚠️ 引文位），其 TS 读法要补半句：**证明成立时运行时并不复查证明**——这正是本系列专题档的存在理由；读 Ⅰ 段时把每条论点拿去对照专题实验 A/B，即得「成书版论述 × 本机版裁决」双线读法。
- 布道书的通病照单检查：论点带立场溢价（对动态语言的代价着墨少 ⚠️ 印象口径，Ⅴ 段反例集恰是自我平衡的补救，两合读方平）。

## 三、🔧 微实验（本会话 node v22.14 --experimental-strip-types 真跑；类型报错面需 tsc，不可测已标 ⚠️）
- `aslie.ts` ✅：`const s = 42 as unknown as string` → `s.length` 为 undefined、`s.toUpperCase()` TypeError——断言零转换零检查，崩点在运行时。
- `any_json.ts` ✅：`JSON.parse` 返回 any → 赋给 `number` 注解变量 → `toFixed` 崩、`typeof n === "string"`——any 传染的运行时裸奔面实锤。
- `priv.ts` ✅：`private secret` 在 `Object.keys` 中照在、`as any` 读出 42；`#hard` 不可见——private≠墙。
- 引用专题档 ✅：实验 B「删注解≠查类型」、实验 A「type/interface 零痕迹」。
- 🔧 待补：同一三例在 `tsc --strict` 下的报错矩阵（本仓无独立 tsc、禁 npm install，专题档第五节 ⚠️）。
