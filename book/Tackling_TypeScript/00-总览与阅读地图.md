# 《Tackling TypeScript》——总览与阅读地图

> 目标书：*Tackling TypeScript: Up and Running with Static Types*，Dr. Axel Rauschmayer（Exploring JS / Exploring ES 作者 ✅ 谱系公认），2021 自出版（印刷版渠道与 ISBN ⚠️；免费在线全文按其站点惯例可读，具体 URL 本波未直证 ⚠️）。
> 第三方书目表配对成立 ✅；本书是其 "Exploring" 线的 TS 卷。

## 一、定位

**静态类型思维布道书**：前半不讲 TS 语法细节，讲「为什么静态类型、类型系统能/不能做什么」——恰好是本系列「Runtime vs Type System」专题的成书版论述位。Rauschmayer 写法短章节+高频示例，对 Java/C++ 者的增量在「结构类型+渐进式」两条公理的哲学阐述。

## 二、骨架（⚠️ 章名凭记忆与站体例，以版权页/在线目录为准）

| 段 | 主题带 | 本仓高价值点 |
|---|---|---|
| Ⅰ 静态类型之辩 | 类型目的、动态vs静态、`any` 的批判 | 「类型=运行时不变式的编译期证明」表述——擦除专题引文位 |
| Ⅱ 类型基础 | 原始类型、对象、数组、函数 | 与 Learning TS 重叠带，速过 |
| Ⅲ 进阶类型 | 联合、交叉、字面量、泛型、收窄 | 判别联合建模章 |
| Ⅳ 工程 | tsconfig、JS 迁移策略、类型获取（@types） | 渐进迁移论 ↔ Java_to_Kotlin 迁移论对照 |
| Ⅴ 常见疑难 | `this`、类字段初始化、结构化陷阱 | 「为什么 TS 不报错」反例集——擦除代价案例库 |

## 三、读法

Ⅰ 段全书最值，精读并摘录论点入专题档；Ⅱ–Ⅲ 对照 Programming TS 查缺；Ⅴ 段当 FAQ 速查。

## 四、🔧 实测口径

Ⅰ/Ⅴ 段论点逐条配反例：`const n: number = ("x" as any)` 链、strip-types 直跑错误类型值（已实测 ✅：运行时零保护实证）、`as` 断言骗过编译器后运行崩点——全部归入 Runtime vs Type System 专题档。
