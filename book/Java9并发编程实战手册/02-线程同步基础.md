# 第 2 章 线程同步基础（原书 pp.37-77）

> 同步基础配方：`synchronized`、`Lock`/`ReentrantLock`、`ReadWriteLock`、`Condition`、🔧 `StampedLock`（JDK 8）、`volatile`。菜谱式。与《艺术》5 章 + 《实战》13 章互补，本书重"选哪个锁的配方"。

## 一、本章地图

| 机制 | 配方场景 |
| --- | --- |
| `synchronized` | 默认互斥（JDK 6+ 快且不易漏锁） |
| `ReentrantLock` | 需定时/可中断/公平/多条件 |
| `ReentrantReadWriteLock` | 读多写少 |
| `StampedLock` 🔧 | 读极频繁（乐观读） |
| `volatile` | 状态标志/单写多读（非原子） |

## 二、核心精讲

- 选型：默认 `synchronized`；需高级特性用 `ReentrantLock`；读多写极少用 `StampedLock` 乐观读（🔧 JDK 8，非 AQS）。
- `volatile` 只可见+有序，非原子；复合操作用 `Atomic*`。
- 🔧 虚拟线程下 `synchronized` 会 pin 平台线程（JDK 24 起多数已解），高并发用 `ReentrantLock`/`StampedLock`。

## 三、版本演进 / 论文 / 前沿

- Doug Lea AQS (SCIENCE 2004)；JEP 374（偏向锁移除）；JDK 21 pin。开源 JDK 23.4k / JCTools 3.9k / Disruptor 18.5k。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Lock 更快用 Lock" | JDK 6+ synchronized 更快 |
