# 第 4 章 线程执行器（原书 pp.128-170）

> 执行器配方：`Executor`/`ExecutorService`/`ThreadPoolExecutor`、4 种快捷池、定时 `ScheduledThreadPoolExecutor`、`invokeAll`/`invokeAny`、`Future`。菜谱式。与《艺术》9-10 章 + 冷血 6 章互补，本书重"配置配方 + 定时任务"。

## 一、本章地图

| 主题 | 配方 |
| --- | --- |
| `ExecutorService` | `submit`/`shutdown`/`invokeAll`/`invokeAny` |
| `ThreadPoolExecutor` | 自定义 core/max/队列/拒绝 |
| 快捷池 | Fixed/Single/Cached/🔧 Scheduled（都有坑） |
| 定时 | `ScheduledThreadPoolExecutor`（`DelayedWorkQueue`，见《之美》09 章） |
| `Future` | `get`/取消 |

## 二、核心精讲

- 快捷池坑：Fixed/Single 无界队列 OOM；Cached 无限线程；🔧 生产用自定义 `ThreadPoolExecutor`。
- 拒绝策略：Abort/Discard/DiscardOldest/CallerRuns。
- 定时：`ScheduledThreadPoolExecutor` 用 `DelayedWorkQueue`（leader-follower，不出错不虚假唤醒，见《之美》09 章）；`period` 符号编码 3 语义、AtFixedRate 追赶/WithFixedDelay 不追赶。
- 🔧 现代：虚拟线程执行器 `Executors.newVirtualThreadPerTaskExecutor()` + `StructuredTaskScope`（IO 密集不再需手写池）。

## 三、版本演进 / 论文 / 前沿

- Doug Lea Executor；JDK 21 虚拟线程/结构化并发。开源 JDK 23.4k / Netflix concurrency-limits 1.4k / kotlinx 13.8k。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "快捷池放心用" | Fixed/Single OOM；Cached 无限线程 |
| 2 | "忘了 shutdown" | 阻止 JVM 退出 |
| 3 | "maxPoolSize 总生效" | 无界队列下形同虚设 |
| 4 | "新代码手写线程池" | IO 改虚拟线程 + 结构化并发 |
