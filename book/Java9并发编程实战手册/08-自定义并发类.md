# 第 8 章 自定义并发类（原书 pp.307-376）

> 定制 `ThreadPoolExecutor`、`ThreadFactory`、优先级 Executor、周期性任务、ForkJoin 自定义线程/任务、自定义 `Lock`、优先级传递队列、自定义原子对象、自定义流/异步流。本书是「扩展点配方大全」，与冷血《实现原理》的「手写实现」互补——本书教你**挂载 JDK 钩子**而非重写。

## 一、本章地图

| 主题 | 扩展点 |
| --- | --- |
| 定制线程池 | 继承 `ThreadPoolExecutor`，覆写 `beforeExecute/afterExecute/terminated` |
| 优先级 Executor | `PriorityBlockingQueue` + `Runnable` 带 `compareTo` |
| 自定义工厂 | `ThreadFactory`（命名/守护/异常） |
| ForkJoin 定制 | `ForkJoinWorkerThreadFactory` / 继承 `ForkJoinTask` |
| 自定义 Lock | 基于 `AbstractQueuedSynchronizer`（见《之美》AQS 专篇） |
| 自定义原子 | `AtomicReference` + CAS 循环 / `VarHandle` |
| 自定义流 | `Spliterator` / `Supplier<Stream>` / `SubmissionPublisher` |

## 二、核心精讲

### 2.1 🔧 钩子式监控
- `ThreadPoolExecutor.beforeExecute`/`afterExecute`：包一层记耗时、异常、MDC；`terminated` 做最终统计（🔧 生产级线程池监控标配，配合 Micrometer/Dropwizard metrics）。
- 拒绝策略 `RejectedExecutionHandler`：`AbortPolicy`(默认抛)/`CallerRunsPolicy`(调用者线程跑，天然背压)/`DiscardPolicy`/`DiscardOldestPolicy`（🔧 高并发下 `CallerRunsPolicy` 常优于直接抛）。

### 2.2 自定义 Lock 用 AQS
- 复用 `AbstractQueuedSynchronizer` 的 CLH 队列，只需实现 `tryAcquire`/`tryRelease`（独占）或 `tryAcquireShared`/`tryReleaseShared`（共享），其余排队/唤醒由 AQS 托管（🔧 见《之美》concepts/AQS抽象同步队列；冷血 3 章手写了一版 AQS 助理解）。

### 2.3 自定义原子对象
- 用 `AtomicReference` 包值对象 + CAS 循环（读-改-写），或 `VarHandle` 直接改字段 5 档语义（🔧 比 `synchronized` 读路径无锁；但要处理 ABA，用 `AtomicStampedReference`）。

## 三、版本演进 / 论文 / 前沿

- 论文：Lea AQS（SCIENCE'04）；Craig CLH（1993）/ MCS（IPPS'94）；Herlihy Wait-Free（PODC'91，自定义原子可参考）。
- 工业界：Netty 用 `ThreadPerTaskExecutor` + 自定义 `ThreadFactory`；Akka 自定义 ForkJoin 线程（pin 到 actor 调度）；Micrometer/Dropwizard `metrics` 库（stars 2026-09 核验：micrometer 4.8k / metrics 7.9k）。
- 开源 stars（2026-09）：JDK 23.4k / netty 34k / kotlinx 13.8k。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "自定义 Lock 自己写队列" | 继承 AQS，别重写 CLH |
| 2 | "CAS 循环不会失败" | 高争用下自旋烧 CPU；考虑退避/让权 |
| 3 | "默认 AbortPolicy 够用" | 高并发常改 CallerRuns 背压 |
| 4 | "自定义线程不命名" | 用 ThreadFactory 命名便于火焰图定位 |
| 5 | "原子对象字段可被 GC" | 注意 ABA；用带戳版本号 |
