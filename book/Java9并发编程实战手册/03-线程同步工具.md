# 第 3 章 线程同步工具（原书 pp.78-127）

> 同步工具配方：`Semaphore`、`CountDownLatch`(🔧 一次性)、`CyclicBarrier`(可循环)、`Phaser`(分代屏障)、`Exchanger`。菜谱式。与《艺术》8 章 + 《之美》10 章互补，本书补 **`Phaser` 实战**（JDK 7 引入，Goetz《实战》未覆盖）。

## 一、本章地图

| 工具 | 配方 |
| --- | --- |
| `Semaphore` | 限流/许可 |
| `CountDownLatch` | 等 N 个事件（一次性） |
| `CyclicBarrier` | 等 N 线程到齐（可循环） |
| `Phaser` | 分代/动态屏障（可注册/退出） |
| `Exchanger` | 两线程交换 |

## 二、核心精讲

- **Phaser（🔧 本书亮点）**：`CyclicBarrier` 的进化版——支持**动态注册/退出**参与方、`arrive()`/`awaitAdvance()` 分阶段；适合"任务数不固定的多阶段并行"（如遗传算法迭代、MapReduce 多轮）。Goetz《实战》成书时 Phaser 未出（JDK 7 才加），故《之美》10 章补了它（Habanero PPoPP 2008 论文）。
- Latch vs Barrier 实现差异：Latch 是 AQS 共享（事件解耦），Barrier 是 Lock+Condition（线程对称）——见《之美》10 章澄清。
- 🔧 现代：`StructuredTaskScope` 提供作用域级"等全部/取首成"（JEP 453/505）。

## 三、版本演进 / 论文 / 前沿

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Latch 可重置" | 一次性；循环用 Phaser/Barrier |
| 2 | "Latch==Barrier" | 实现/语义不同 |
| 3 | "Phaser 复杂没必要" | 动态/多阶段并行离不了 |
| 4 | "新代码手写 Latch" | 结构化并发作用域级 |
