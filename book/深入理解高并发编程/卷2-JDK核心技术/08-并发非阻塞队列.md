# 第 8 章 并发非阻塞队列

> `ConcurrentLinkedQueue`（Michael-Scott 无锁队列，两步 CAS、tail slack）、`ConcurrentLinkedDeque`（双向无锁）。本书源码级。详见《之美》concepts/Michael-Scott无锁队列.md、深度解析 9 章。

## 一、核心精讲

### 8.1 🔧 MS 队列
- 入队两步 CAS（先链 node.next，再移 tail）；**tail slack**（tail 可能落后于真尾，需 hop 修正）（🔧 见《之美》MS 队列专篇）。

### 8.2 JDK 的自链接优化
- `ConcurrentLinkedQueue` 出队时把节点 `next` 自链（lazySetNext）帮助 GC（🔧 见《之美》MS 专篇）。

### 8.3 无锁的内存回收难题
- 无锁队列无法简单 `free`：hazard pointer / epoch / interval-based / VBR（🔧 Java 靠 GC 天然解决，C++ 需专门方案，见《之美》MS 专篇）。

## 二、版本演进 / 论文 / 前沿

- 论文：Michael-Scott（PODC'96）；Treiber 栈（1986）；Herlihy Wait-Free（PODC'91）。
- 工业界：JCTools（3.9k，Mpsc/Mpmc 更快）、Disruptor（18.5k）、crossbeam（8.6k Rust）。
- 开源 stars（2026-09）：JDK 23.4k / JCTools 3.9k.

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "无锁一定更快" | 高争用/内存回收有代价 |
| 2 | "size() 便宜" | O(n) 非原子 |
| 3 | "C++ 无锁同 Java" | 需 hazard pointer 等 |
