# 第 2 章 线程的基本操作

> 创建线程（Thread/Runnable/Callable/池/虚拟线程）、`sleep`/`yield`/`join`/`interrupt`、线程状态、`ThreadGroup`。本书基础篇，与黄文海 1 章、手册 1 章互补。

## 一、核心精讲

### 2.1 🔧 创建与启动
- 实现 `Runnable`（推荐）或继承 `Thread`；必须 `start()` 才建真线程（🔧 调 `run()` 只是普通方法；一个 Thread 只能 start 一次）。

### 2.2 sleep/yield/join
- `sleep` 让出 CPU 不释放锁；`yield` 提示调度器（不可靠）；`join` 等目标结束（🔧 见《之美》10 章同步器；虚拟线程 `join(Duration)` 可超时）。

### 2.3 interrupt 协作
- 仅设标志；`sleep/wait/join` 抛 `InterruptedException` 并清标志（🔧 捕获后重设或上抛，别吞）。

### 2.4 ThreadGroup 过时
- 用 `Executor` + `ThreadFactory`/结构化并发替代（🔧 见线程与并发编程实践 4 章）。
