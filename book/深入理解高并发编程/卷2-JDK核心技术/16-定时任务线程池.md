# 第 16 章 定时任务线程池

> `ScheduledThreadPoolExecutor` vs `Timer`：初始化、`DelayedWorkQueue` 调度流程、`period` 三种语义（`schedule`/`AtFixedRate`/`WithFixedDelay`）、优雅关闭、`removeOnCancelPolicy`。本书线程池篇收尾。详见《之美》09 章（最细）。

## 一、核心精讲

### 16.1 🔧 vs Timer
- `Timer` 单线程：一任务异常拖垮全部；`ScheduledThreadPoolExecutor` 多线程 + 池化管理（🔧 现代一律用后者）。

### 16.2 DelayedWorkQueue + Leader-Follower
- 内部小根堆 + 单 `available` Condition；**Leader-Follower**：只有一个线程 timed wait 到最近到期时间，其余无限等（🔧 避免所有线程同时超时醒来，见《之美》09 章）。

### 16.3 period 三种语义
- `schedule`（一次）；`scheduleAtFixedRate`（固定频率，可能「追帧」连跑）；`scheduleWithFixedDelay`（上次完成后间隔）（🔧 `period` 正负号编码语义，见《之美》09 章）。

### 16.4 坑
- 周期任务抛异常 → **静默停止**后续执行（🔧 必须 try-catch 兜底）；`removeOnCancelPolicy` 默认 false → 取消任务仍留队列，可能泄漏（🔧 设 true）。

## 二、版本演进 / 论文 / 前沿

- 论文：Lea Executor 框架（JDK5）；Leader-Follower 模式（POSA）。
- 工业界：JDK `ScheduledThreadPoolExecutor`；Quartz（分布式调度）、XXL-Job（国产）。
- 开源 stars（2026-09）：JDK 23.4k / xxl-job 27k.

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Timer 够用" | 用 Scheduled 池 |
| 2 | "周期任务异常不影响" | 静默停止 |
| 3 | "取消任务自动移除" | 设 removeOnCancelPolicy |
| 4 | "AtFixedRate 不追帧" | 会追帧连跑 |
