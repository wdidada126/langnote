# 第 1 章 进程与线程的基本概述

> 进程 vs 线程、线程调度与上下文切换、进程/线程综合对比、查看进程与线程（`jps`/`jstack`/`ps`）。本书基础篇开篇，重「运行时观测」。

## 一、核心精讲

### 1.1 🔧 进程 vs 线程
- 进程是资源分配单位（独立地址空间），线程是 CPU 调度单位（共享进程资源）（🔧 线程切换比进程轻，但仍需上下文切换开销）。

### 1.2 上下文切换
- 保存/恢复寄存器、PC、栈（🔧 用 `vmstat cs`/`perf` 观测；线程数远超核数时切换反噬吞吐）。

### 1.3 观测命令
- `jps` 列 Java 进程、`jstack <pid>` 线程栈、`ps -eLf` 看内核线程（🔧 生产用 Arthas `thread` 更安全）。
