# 第 12 章 线程工具类

> `Thread` 类（状态/中断/`UncaughtExceptionHandler`/`ThreadFactory`）、`ThreadLocal`（泄漏/继承）、`Fork/Join` 框架（`ForkJoinPool`/`RecursiveTask`/工作窃取）。本书把「线程层工具」汇总。详见之美 concepts/ThreadLocal与内存泄漏/ForkJoin与工作窃取、线程与并发编程实践 4 章。

## 一、核心精讲

### 12.1 Thread
- 中断协作、命名（`ThreadFactory`）、未捕获异常处理（🔧 `submit` 异常吞到 `Future.get`，用 `afterExecute`；虚拟线程由作用域管）。

### 12.2 ThreadLocal
- 弱引用 key + 强引用 value → 线程池长生命线程泄漏（🔧 finally `remove()`；跨池用 `TransmittableThreadLocal`；JDK 21 `ScopedValue` 更安全，JEP 506）。

### 12.3 Fork/Join
- 工作窃取 deque（自己从头取，偷从尾）；分治阈值实测；`invokeAll` 让本线程也干活（🔧 见之美 concepts/ForkJoin与工作窃取、精通2 7 章；纯 CPU 用，IO 用虚拟线程）。
