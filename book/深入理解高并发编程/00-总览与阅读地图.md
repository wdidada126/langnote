## 阅读路径

1. **先原理后工具**：卷1 的 03/04/05（分工同步互斥 → 原子性/可见性/有序性）→ 卷2 的 02/11（线程操作、原子类）。
2. **锁主线贯穿**：卷1 `07-synchronized核心原理.md` → `08-AQS核心原理.md` → `09-Lock锁核心原理.md` → `11-死锁核心原理.md` → `12-锁优化.md`；卷2 `10-锁工具类.md` 是工具层对照。
3. **线程池主线**：卷1 `13-线程池核心原理.md` → `15-手动开发线程池实战.md`；卷2 `14-线程池总体结构.md` → `15-线程池核心流程.md` → `16-定时任务线程池.md`。
4. **架构收束**：卷1 `19-分布式锁架构.md`、`20-秒杀系统架构.md`（与 `book/Java高并发核心编程/` 的秒杀章、`book/软件架构设计/08-高并发问题.md` 互链）。

## 与其他书的分工（避免重复造轮子）

- 本书独有：死锁原理/锁优化专章、手写线程池、CAS 自旋锁与读写锁缓存实战、秒杀架构。
- 方腾飞《Java并发编程的艺术》→ 原理与 JMM 并重（`book/Java并发编程的艺术/`）。
- 葛一鸣《Java并发实现原理》→ JUC 源码更深（`book/Java并发实现原理/`）。
- 汪建《图解Java并发编程》→ 图解 + C++ 模拟线程（`book/图解Java并发编程/`）。

## 🔧 2026 年补充视角

- 卷1 写于 JDK 8/11 语境：虚拟线程（JEP 444，JDK 21 正式）、结构化并发（JEP 505）改变「线程池即并发」的前提，读线程池章时对照。
- 卷2 的同步集合章（03–08）：`ConcurrentHashMap` 的 Java 8 后实现已在各章覆盖，但 `ScopedValue`/`MemorySegment` 等新 API 未覆盖，需自行补充。
