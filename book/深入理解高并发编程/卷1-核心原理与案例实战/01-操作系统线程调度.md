# 第 1 章 操作系统线程调度

> 冯·诺依曼体系、CPU 架构（单核/多核/多 CPU）、用户级/内核级/混合级线程、Java 线程与 OS 线程映射。本书用大量图解讲「硬件→OS→JVM」链路。

## 一、核心精讲

### 1.1 🔧 三级线程模型
- 用户级线程（库调度，内核无感）、内核级线程（OS 调度，1:1）、混合级（M:N）（🔧 Java 传统平台线程是 **1:1** 内核线程；虚拟线程是 M:N 在 carrier 上调度，见 JEP 444）。

### 1.2 多核与上下文切换
- 多核并行；线程切换要存/恢上下文（寄存器/PC/栈），有开销（🔧 线程数远超核数时切换反噬吞吐；上下文切换次数用 `vmstat`/`perf` 观测）。

## 三、常见误区

| # | 误区 | 修正 |
