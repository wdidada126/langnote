# 第 4 章 并发编程的本质问题

> 计算机核心矛盾（CPU 速度 ≫ 内存 ≫ IO）、编译/OS/CPU 为性能做的优化引发的**原子性/可见性/有序性**三大问题，及对应解法（锁/原子类、volatile/锁、volatile/happens-before）。本书从「硬件矛盾」推导出三大特性，是理解并发的枢纽章。

## 一、核心精讲

### 4.1 🔧 核心矛盾→三特性
- CPU 与内存速度差 → 缓存/写缓冲 → **可见性**问题；编译/CPU 重排 → **有序性**问题；多核并行 + 复合操作 → **原子性**问题（🔧 详见《之美》concepts/JMM与happens-before、volatile与内存可见性）。

### 4.2 解决方案对照
- 原子性：锁 / `AtomicXxx`（CAS）；可见性：`volatile`/锁（使缓存失效）；有序性：`volatile`/acquire-release/`happens-before`（🔧 `synchronized` 同时保三性但重；`volatile` 仅可见+有序）。

## 二、版本演进 / 论文 / 前沿
