## 核心精讲

### 1. 握手协议（书中范式重述，教学示意）
```sql
-- 提供方（ACCOUNTADMIN，ch10.sql 实抓模式）
CREATE SHARE DEMO10_SHARE2;
GRANT USAGE ON DATABASE   DEMO10_DB       TO SHARE DEMO10_SHARE2;
GRANT USAGE ON SCHEMA     DEMO10_DB.PUBLIC TO SHARE DEMO10_SHARE2;
GRANT SELECT ON VIEW      DEMO10_DB.PUBLIC.V_SAFE TO SHARE DEMO10_SHARE2;  -- 常以安全视图暴露 ⚠️
GRANT USAGE ON SHARE      DEMO10_SHARE2 TO ACCOUNT  'AB12345.region.aws';   -- 或 TO READER ACCOUNT ...;

-- 消费方
CREATE DATABASE DEMO10_CONSUMED FROM SHARE 供应商账号.DEMO10_SHARE2;
SHOW GRANTS TO SHARE DEMO10_SHARE2;  SHOW NETWORK POLICIES;  -- 两侧审计
```
机制要点（转述 ⚠️，官方：https://docs.snowflake.com/en/user-guide/data-sharing-intro ✅200）：
- 共享对象是**只读引用**，元数据在提供方、数据在提供方存储；消费查询走消费方虚拟仓库 → 账单分离清晰。
- 消费者看到的是一个可 DROP 的镜像库名，不锁源数据版本（live share 持续可见新数据 ⚠️）。

### 2. 共享 vs 复制的经济学
| 维度 | Secure Data Sharing | 数据搬迁/复制 |
| --- | --- | --- |
| 延迟 | 即时（权限生效即查） | ETL 周期 |
| 新鲜度 | 实时 | 快照 |
| 成本 | 消费方算力 + 提供方少量元数据/存储 | 双份存储+管道维护 |
| 治理 | 可随时撤权、行级安全视图裁剪 | 副本失控风险 |
| 跨云/跨区 | 支持（对象经区域中继 ⚠️） | 自然可行但贵 |

### 3. 数据产品光谱（书中标题"Configuring"之外的工业视角 ⚠️）
1. **Direct Share**：给指定账户，最简。
2. **Private Listing**：定向"可发现的报价单"，含文档/样本，签协议即用。
3. **Marketplace Listing（公开）**：自助获取、可计费（per-query/订阅/试用）。
4. **Reader Account**：给无 Snowflake 账户的消费者开轻量账户（消费方算力自付 ⚠️）。
5. **Data Exchange / 实时共享（live shares）**：官方撮合 + 持续推送形态（书出版时为 preview ⚠️）。

### 4. 共享上的行级安全配方
- 安全视图 + 会话上下文函数（CURRENT_ROLE/CURRENT_ACCOUNT_NAME）按消费者过滤：
  `WHERE region IN (SELECT region FROM mapping WHERE account = CURRENT_ACCOUNT_NAME())`（教学示意）。
- Row Access Policy/Masking 与共享的组合语义升级是 8.x 后的事（第 5 章），书稿以安全视图为唯一 MAC 件 ⚠️。
官方口径：https://docs.snowflake.com/en/user-guide/views-secure ✅200。

### 5. 商业化与审计
- 提供方可为 Listing 设定价（货币化）；市场侧结算条款 ⚠️ 以官方为准。
- 审计：`SHOW OBJECT GRANTS IN SHARE`、`information_schema.share_usage_history`（消费者查询记录到提供方 ⚠️）、
  与第 9 章 Query History 组合定位"谁在烧我的共享"。

## 常见误区

| 误区 | 事实（转述 ⚠️） |
| --- | --- |
| "共享要拷数据" | 零拷贝；变的只是可见性 |
| "撤权立即全停" | 新查询立止；已在跑的查询/缓存语义以官方文档为准 ⚠️ |
| "能共享任何对象" | 白名单制；如 stage/流/任务不可共享 ⚠️ |
| "消费方数据会被改" | 只读；DML 无门 |
| "Marketplace=公开源码" | 上架可撤回、可按国别/行业定向可见 ⚠️ |

## 核心概念速览（中英对照）

1. **安全数据共享** — secure data sharing：跨账户零拷贝只读共享机制。
2. **共享（对象）** — share：打包可共享权限的具名容器。
3. **提供方/消费方** — provider / consumer：共享两端角色。
4. **上市（数据产品）** — listing：Marketplace 上可发现/可申请的共享商品。
5. **私有上市** — private listing：仅定向账户可见的报价单。
6. **读者账户** — reader account：为无账户消费者开的轻量账户。
7. **Data Exchange** — 官方数据产品撮合与交换网络。
8. **实时共享/快照共享** — live vs snapshot shares：持续可见 vs 固定版本 ⚠️。
9. **安全视图共享** — sharing via secure views：行级裁剪的默认姿势。
10. **FROM SHARE** — CREATE DATABASE … FROM SHARE：消费方挂载语法。
11. **共享使用历史** — share usage history：提供方审计消费行为的视图。
12. **变现** — monetization：按查询/订阅/试用计费的市场结算。
13. **共享授权握手** — GRANT USAGE … TO SHARE：提供方侧逐级放行的语法链。
14. **跨区域共享** — cross-region sharing：经区域中继实现，消费侧或有副本语义差异 ⚠️。
