## 核心精讲

### 1. SaaS 交付形态决定"入门即治理"
Snowflake 是运行在 AWS/Azure/GCP 之上的托管分析数据库（软件即服务）：用户不管硬件、不管安装升级、
不管备份调度——**换来的是从第一行 SQL 起就要理解"角色、仓库、信用额度"三个计费/权限实体**。
转述口径 ⚠️（https://docs.snowflake.com/en/user-guide/intro-key-concepts）。

### 2. 上下文四件套（本章最重要的心智模型）
```sql
-- 教学示意，非书中原文
USE ROLE SYSADMIN;              -- 我是谁（权限上下文）
USE WAREHOUSE COMPUTE_WH;       -- 用哪组算力（计费与执行上下文）
USE DATABASE DEMO_DB;           -- 默认库
USE SCHEMA PUBLIC;              -- 默认模式（对象名解析顺序：库.模式.名）
SELECT CURRENT_ROLE(), CURRENT_WAREHOUSE(), CURRENT_DATABASE(), CURRENT_SCHEMA();
```
未 `USE WAREHOUSE`（或仓库被挂起）时查询会排队并自动唤醒仓库（AUTO_RESUME），按秒计费 ⚠️
（https://docs.snowflake.com/en/user-guide/warehouses-overview）。

### 3. 预定义角色最小可用集
- `ACCOUNTADMIN`：账户级（共享、市场、参数）——练习中仅第 10 章才需要。
- `SYSADMIN`：绝大多数对象的创建者。
- `USERADMIN`：管用户与角色。
- `SECURITYADMIN`：治理面。
角色是可 GRANT 的"特权容器"，不是登录身份：用户→角色→对象的链式授权，详见 [05-访问控制.md](05-访问控制.md)。⚠️
（https://docs.snowflake.com/en/user-guide/security-access-control-overview）

### 4. 样本数据与"免费元数据仓库"
`SNOWFLAKE_SAMPLE_DATA`（TPC-H/TPC-DS 放大版）与 `SNOWFLAKE`（含 `INFORMATION_SCHEMA`、
`ACCOUNT_USAGE` 视图族）由 Snowflake 自身维护，查询它们用的是共享的小仓库，不消耗自建算力 ⚠️。
第 8/9 章的成本与性能视图全部长在这两套库上。

### 5. 本章的"坑清单"（书末 Knowledge Check 风格自拟）
1. 账户名拼错即冲突，云/区域不可改 → 命名前先想清合规地域。
2. 试用账户到期数据删除，学习周期要压进 30 天 ⚠️。
3. 忘记切仓库 → 所有练习都烧在 COMPUTE_WH 上，credit 消耗归因混乱。
4. 在 ACCOUNTADMIN 下建对象 → 后续 GRANT 链条与生产实践脱节（书刻意要求 SYSADMIN）。

## 常见误区

| 误区 | 事实（转述 ⚠️） |
| --- | --- |
| "试用账号功能阉割" | 功能同 Enterprise 试用口径，限制在期限与 credit；以官方条款为准 |
| "Snowsight 只是换皮 UI" | 它承载了工作表/仪表盘/数据市场/监控等控制面，Classic Console 仅存量运维 |
| "SQL 客户端先装驱动" | Web 端零安装；CLI（SnowSQL）与驱动是第二步 |
| "角色=用户" | 角色是权限载体，用户须 `GRANT ROLE` 后 `USE ROLE` 生效 |

## 核心概念速览（中英对照）

1. **账户** — Account：一个账户绑定单一云+单一区域，是计费与安全边界的最小单位。
2. **Snowsight** — Snowsight：官方 Web 控制台，工作表/仪表盘/共享/管理入口。
3. **试用信用** — trial credits：试用期赠送的算力额度（时长与额度以官方条款为准）。
4. **上下文** — context：当前 角色/仓库/库/模式 四元组，决定 SQL 的权限、算力与命名解析。
5. **预定义角色** — system-defined role：ACCOUNTADMIN/SYSADMIN/USERADMIN/SECURITYADMIN 等出厂角色。
6. **虚拟仓库** — virtual warehouse：按需启停的计算集群，本章只用到默认 COMPUTE_WH。
7. **多因子认证** — MFA：官方对所有人默认推荐的第一步安全配置。
8. **样本库** — SNOWFLAKE_SAMPLE_DATA：官方内置 TPC-H/TPC-DS 放大数据集。
9. **账户使用视图** — ACCOUNT_USAGE：SNOWFLAKE 库下的计费/查询历史视图族。
10. **Classic Console** — Classic Console：旧版控制台，逐步被 Snowsight 取代。
11. **工作表** — worksheet：Snowsight 内多语句 SQL 编辑与运行单元。
12. **数据共享入口** — Data Product Marketplace（原 Data Marketplace）：从 UI 直接请求第三方数据集。
