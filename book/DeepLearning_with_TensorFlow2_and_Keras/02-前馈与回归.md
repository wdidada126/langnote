## 核心机制

1. **密层即矩阵乘法加激活**：`Dense(units, activation='relu')` = `Wx+b` 后过非线性。
   Keras 一行 vs PyTorch 显式：

   ```python
   # Keras ✅（🔧 未实测：本机未装 tensorflow）
   model.add(Dense(64, activation='relu')); model.add(Dense(1))  # 回归头

   # PyTorch 对照：同一层的裸形状
   # self.lin = nn.Linear(64, 1)   # W 是 [1,64]，bias 是 [1]——参数形状可见
   ```
   Java/C++ 锚：花书/矩阵视角里前向就是仿射变换复合 ✅；DL4J 里同款是
   `DenseLayer(new Builder(64).layerActivation...)`（衔接 06 档，配置器模式更啰嗦）。
2. **回归 vs 分类的分岔在损失与输出层**：回归=线性输出头+MSE；二分类=sigmoid+1 输出
   +`binary_crossentropy`；多分类=softmax+n 输出+`sparse_categorical_crossentropy`。
   书中食谱按数据集换这一格 ⚠️，机制不变。对照 PyTorch：`F.mse_loss` /
   `nn.BCEWithLogitsLoss`（后者把 sigmoid 并入数值更稳 ✅——书中若裸写 sigmoid+
   BCE 值得以此改进）。
3. **过拟合三件套**：数据集小+模型大 → L2（`kernel_regularizer='l2'`）、Dropout
   （`Dropout(p)` 训练开、`predict` 自动关 ✅）、早停（`EarlyStopping` 回调）。
   Dropout 的「缩放近似集成」直觉见花书对应节（互链，页码不引 ⚠️ 不虚构）。

## 🔧 微实验位（未实测：本机未装 tensorflow）

1. 同一回归任务画「模型容量 × 训练/验证 loss」双曲线，亲眼确认过拟合剪刀差。
2. Dropout p ∈ {0, 0.2, 0.5} 消融；再验证 `model(x, training=False)` 时 dropout 失效。
3. sigmoid+`binary_crossentropy` 数值不稳负例：极端 logit 下与 `BCEWithLogits` 对照 🔧。

## 中英对照

| 英文 | 中文 | 一句注 |
| --- | --- | --- |
| feedforward network / MLP | 前馈网络/多层感知机 | 无环、单向 |
| dense (fully-connected) layer | 密层/全连接层 | 仿射+激活 |
| mean squared error (MSE) | 均方误差 | 回归默认损失 |
| cross-entropy | 交叉熵 | 分类默认损失 |
| L2 regularization / weight decay | L2 正则/权重衰减 | Keras 与 PyTorch 挂法不同 |
| dropout | 随机失活 | 训练期正则，推理期关闭 |
| early stopping | 早停 | 验证集触底即收手 |
| data leakage | 数据泄漏 | 玩具集上也易犯 |
