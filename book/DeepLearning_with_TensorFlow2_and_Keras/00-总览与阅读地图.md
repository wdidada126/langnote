# 《Deep Learning with TensorFlow 2 and Keras, 2e》——总览与阅读地图

> 目标书：*Deep Learning with TensorFlow 2 and Keras: Build and Train Advanced Neural
> Network Models with Keras, TensorFlow 2, and DeepLearning4J*，Apress，2e 2021 ⚠️。
> 作者凭记忆 Antonio Gulli 等，**未联网销账，以版权页为准**；ISBN ⚠️ 待核验（不写死）。
> 本档是「章节目录版」笔记的总入口；单文件速查版在 [../DeepLearningWithTensorFlow2AndKeras.md](../DeepLearningWithTensorFlow2AndKeras.md)。

## 一、定位与读法裁决

**食谱带**：一章一网络类型（MLP/CNN/RNN/GAN/自编码/RL 各占一章级别），Keras 高层 API
快速出图，**广度换深度**——每章给你「这个网络长什么样、能干什么」，不给「为什么收敛、
怎么推梯度」。这是本书的第一定性，也是它与 d2l/花书的分工线。

- 2026 时效裁决 🟡：网络类型的心智图仍可用；`tf.keras` v2 的 API 细节与 DL4J 支线已过时
  （Keras 3 多后端变局后，书中部分写法不再是现行口径——以 tensorflow.org/tutorials 为
  实操唯一现行口径 ✅ 判断依据为出版年份与生态事件，非书中内容逐字）。
- 反例代码少、调参叙事浅：凡「为什么」的问题，跳 [../DiveIntoDeepLearning.md](../DiveIntoDeepLearning.md) 补推导、
  [../深度学习_花书.md](../深度学习_花书.md) 补理论。
