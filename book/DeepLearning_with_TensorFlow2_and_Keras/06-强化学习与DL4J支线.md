## 核心机制

1. **RL 的最小闭环**：环境(state, reward) ↔ 智能体(action)。书中食谱推定为 DQN 级
   ⚠️（CartPole 一类玩具环境，具体环境名待对书销账）：把「值函数逼近」变成监督学习——
   用神经网络拟合 Q(s,a)，以贝尔曼目标 `r + γ·max Q(s′,·)` 自举回更。
   Keras/PyTorch 对照（经验回放+目标网络两构件框架无关）：

   ```python
   # Keras：Q 网络就是 02 档的 Dense 塔，输出维=动作数 ✅
   q_model = Sequential([Dense(64, input_shape=(4,), activation='relu'), Dense(2)])
   # loss 处需自定义（Huber + mask），fit 装不下逐样本 TD-error → train_step/手写循环

   # PyTorch 对照：同一逻辑，损失显式接线
   # loss = F.smooth_l1_loss(q_vals[actions], targets.detach())
   # loss.backward(); opt.step()
   ```
   「高层 API 装不下非常规损失」在 05(GAN) 与本章(RL) 复现两次——是 Keras 表达力
   边界的系统性证据，不是孤例。
2. **DL4J 支线 = JVM 生态旁支，2026 活跃度存疑 ⚠️**：DeepLearning4J 用 Java 写训练
   （ND4J 张量库 + SameDiff 自动微分），书中作为「非 Python 选项」出现 ⚠️ 篇幅待销账。
   它给的真实价值是**对照锚**：Keras `Dense(64)` ↔ DL4J
   `new DenseLayer.Builder().nIn(..).nOut(64).activation("relu").build()` 塞进
   `NeuralNetConfiguration`/`ComputationGraph` 的建造者模式——同一网络，三种生态
   （Keras 声明式 / PyTorch 命令式 / DL4J 配置器式）的 API 哲学切片。
3. **C++ 锚**：若真要生产级非 Python 训练，2026 现实答案是「Python 训练 + C++ 推理」
   （TFLite/ONNX Runtime 线 ✅），而非在 JVM 里从头训大模型——DL4J 支线按历史 curiosity
   读，🔴 不建议作主技能投资（判断依据为生态活跃度，⚠️ 未联网复核 DL4J 近况）。
