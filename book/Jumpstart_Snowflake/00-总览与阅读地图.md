## 3. 全书叙事线与阅读地图

本书是 Apress「Jumpstart」系的云分析入门：**第 1–3 章**建立云数仓认知并开出第一个虚拟仓库；
**第 4–6 章**构成完整装载叙事（批量 COPY → SnowSQL 工具面 → Snowpipe 连续装载）；
**第 7–8 章**转入管理与安全（角色/资源监视器/认证/RBAC）；**第 9–10 章**处理半结构化数据与
共享协作——正是书名「Modern Cloud Analytics」的两块差异化招牌；**第 11–13 章**给出方案级
设计、数据科学协作与迁移方法论；**第 14 章**以 Time Travel 收尾（本书时代最出圈的功能）。
建议首读路径 01→02→03→04→05→06 打通「开仓—装数」最小闭环，再按需跳转；已具云仓经验者可
从 09/10/14 切入。各章文末固定两节：核心概念速览（中英对照）与 2019→2026 最新演进。

### 3.1 分赛道导读

- **认知赛道（01–02）**：为什么上云 + 三层架构初看；配套动作=注册试用账号、看 Classic Console
  /Snowsight 前夜版 UI ⚠️。适合第一遍线性阅读。
- **数据管线赛道（03–06）**：仓库（算力面）→ 批量装载（COPY/Stage）→ SnowSQL（工具面）→
  Snowpipe（连续面）。本书 step-by-step 属性最浓的四章；🔧 实验 E1/E2/E3/E4 全部落此赛道。
- **治理赛道（07–08）**：Administration 与 Security 双章，2019 时点恰在 RBAC 成熟、动态脱敏
  刚出壳的交界——读时必须对照 08 章演进节，把"secure view 时代"升级到"策略时代"（2026）。
- **数据形态与协作赛道（09–10）**：VARIANT/FLATTEN 与零拷贝共享，是本书区别于传统数仓教材的
  招牌章；🔧 E5/E6/E7 中 E6/E7 落此。
- **架构与落地赛道（11–13）**：方案设计、数据科学协作、迁移方法论——2019 素材、2026 需大幅
  重锚（Snowpark/Cortex/SnowConvert 三条演进主线）。
- **特色能力（14）**：Time Travel 短章（pp.251–259，9 页 ✅），与 UNDROP/克隆/FailSafe 联动。

### 3.2 目标读者与前置

云分析决策者/新手上路者/从传统数仓迁移者；前置=基础 SQL 与对象存储常识 ⚠️。本书不含深度调优
（让位波8 #214）与对象级参考全表（让位波1 TDG #159），三册构成盘上「入门—参考—调优」阶梯。
