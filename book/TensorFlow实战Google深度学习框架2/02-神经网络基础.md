## 核心机制

### 从感知机到多层网络：前向传播

- 骨架（⚠️ 按书中线复述）：单神经元 `z = wx + b` 接激活；多层堆叠即 MLP，矩阵形式 `X·W + b` 逐层推进——书中用 MNIST 手写识别贯穿（⚠️ 数据集选择凭记忆）。
- 激活函数谱系：sigmoid/tanh/ReLU。1.x 写法 `tf.nn.relu(tf.matmul(x, W) + b)`（✅ TF 至今保留 `tf.nn.*` 这批原语——**本册唯一没死的 API 族**）；对照 PyTorch：`torch.relu(x @ W + b)`（✅）逐字同构，框架差异在容器不在数学。
- 输出层与 one-hot：分类任务末层接 softmax，与交叉熵配对——`softmax+交叉熵` 的数值稳定写法在 1.x 是 `tf.nn.softmax_cross_entropy_with_logits`（⚠️ 书中版本名凭记忆，TF2 改名带 `_v2` 且推荐 sparse 版/F.cross_entropy 直接吃 logits ✅）；书中反复叮嘱"不要自己先 softmax 再 log"是 ✅ 不过时的数值纪律。

### 损失、反向传播与"框架帮你微分"

- 损失函数两枚：均方误差（回归）、交叉熵（分类）；书中以"衡量预测与现实的差距"作引入 ⚠️ 措辞凭记忆。概念精确定义对位花书第 6 章（✅ 在盘：[../深度学习_花书.md](../深度学习_花书.md)）。
- 反向传播=链式法则在计算图上的自动装配（✅ 通用事实）；本书卖点是"TF 的 Optimizer 自动求梯度"，`tf.train.GradientDescentOptimizer(...).minimize(loss)`（**2026 已废**：TF2 用 `tf.GradientTape` 或 `keras.optimizers.*`；PyTorch 对位 `optimizer = torch.optim.SGD(...)`，`loss.backward()` 后 `optimizer.step()` ✅）。Java/C++ 概念锚：自动微分如**编译器做符号变换生成伴随代码**——你写正算、机器生成逆算，同 AST 改写思想；手推版见鱼书第 5 章（✅ 在盘目录）。
- 学习三件套（书中结构 ⚠️ 凭记忆）：前向算 loss → 反向算梯度 → 更新参数循环 mini-batch；这套循环在 TF2/PyTorch 里都缩成 5 行以内，1.x 需要 Session.run 驱动——读机制、弃样板。

### 高层封装的考古层：contrib.layers 与 estimator

- 书中后期例程转向 `tf.contrib.layers`（fully_connected 等快捷层 ⚠️ 例名凭记忆）与 **Estimator** 训练框架（`tf.estimator.DNNClassifier` 一类，**2026 已废**：estimator 已于 TF2 时代正式停止维护，Keras 为唯一官方高层线 ✅）。
- Estimator 的历史角色值得记一笔：model_fn(input_fn, params) 三段式=把"数据管道/模型/训练配置"分层的**早期 MLOps 抽象**，对位 Java 世界"框架接管生命周期"的容器思想（⚠️ 类比口径）——它死了，但"配置与模型分离"的诉求活在所有训练框架里。
- PyTorch 无 estimator 对位物：`nn.Module`+手写/库化 loop 一贯到底（✅）；这层哲学差异（框架托管 vs 用户主循环）是 2026 读 1.x 代码时最陌生的地方。

## 批判读法（易错与存疑）

1. **"实现神经网络=会写 1.x 五件套"**：placeholder/feed_dict/minimize/run 的肌肉记忆到 2026 全部作废；真资产是"层=仿射+激活、学习=损失梯度下降"这两句话，任何框架通用。
2. 书中把反向传播讲成"以损失为目标的优化过程"而不给手推（⚠️ 印象），与鱼书"每层一个类各管局部梯度"对照着读才不虚——黑盒 API 与白盒 numpy 是同一条腿的两种义肢。
3. `minimize()` 一行更新全部变量的**隐式变量收集**（靠集合机制）是魔法也是暗坑：训练时哪些变量被更新不显式（PyTorch 必须显式把参数交给 optimizer ✅ 对比）——初读容易漏掉"可训练/不可训练变量"的边界。
4. 存疑 ⚠️：本册是否已含 MNIST 完整准确率实验、以及是否引出 softmax 回归与逻辑回归的关系，待目录销账。

## 核心概念中英对照

- **前向传播** — forward propagation：输入逐层仿射+激活到输出。
- **损失函数** — loss function：预测与标签差距的标量度量。
- **交叉熵** — cross entropy：分类标配损失，吃 logits 最稳。
- **反向传播** — backpropagation：链式法则在图上的自动装配。
- **梯度下降** — gradient descent：沿负梯度更新参数（优化器家族见 03 册）。
- **mini-batch** — 小批量：一次取样若干条估梯度，平衡噪声与吞吐。
- **估计器** — Estimator：1.x 托管训练循环的高层容器（2026 已废）。
- **logits** — logits：softmax 之前的原始分数，数值稳定的损失入口。
