## 核心机制

### 为什么慢、并行切哪

- 动机三件套（书中叙事 ⚠️ 凭记忆）：数据量增、模型参数增、单机 GPU 显存/算力封顶——解法分两路：**模型并行**（图按设备切段，跨机传中间激活）与**数据并行**（每台机器一份完整图+不同数据切片，参数同步）。书中明说 TensorFlow 主要走数据并行路线 ⚠️ 待核。
- 同步 vs 异步更新：同步=等齐所有 worker 再聚合（稳、被最慢者拖死）；异步=各自算梯度直推参数服务器（快、陈旧梯度/收敛抖动）。这是 2018 分布式 ML 的中心辩论（✅ 史实），本书立场 ⚠️ 凭记忆倾向异步可行论。

### 参数服务器架构与 1.x 写法（全废区）

- **参数服务器（PS）**：worker 计算梯度、ps 节点存参数并聚合——经典"计算与存储分离"的 ML 特化版；概念锚：与 Java 世界早期 Hadoop 类分布式服务的"中心协调节点"同构（⚠️ 类比口径），gRPC 承担跨进程通信 ✅（TF 用 gRPC 是官方文档事实）。
- 1.x 集群三件套：`tf.train.Server(cluster_spec, job_name, task_index)`、`with tf.device('/job:ps/...')`、between-graph replication（每台机器各建一张同构图、变量钉在 ps 上）（**全部 2026 已废**：TF2 现行口径是 `tf.distribute.Strategy`——`MirroredStrategy`（单机多卡）/`MultiWorkerMirroredStrategy`（多机），PyTorch 对位 `torch.nn.parallel.DistributedDataParallel`（DDP，all-reduce 梯度同步）✅）。
- 书中"用 device 指定算子放置"的细粒度手工布图 ⚠️ 凭记忆——2026 视角这是**前 API 时代的显式编排**：思想活在"分区/放置/复制"三个动词里（今天叫 sharding/placement/replication，JAX 把它做成了语言 ✅），API 本身勿再触碰。
- 训练循环迁移点：1.x 每 worker 自开 Session 各自 feed（**已废**模式）；现代 Strategy/DDP 把"数据切片+梯度同步"封进运行时，用户代码与单机几乎同形 ✅——这一句就是"分布式 API 十年演化"的终点判词。
- 数据并行的隐藏工程量（✅ 通识，书中深度 ⚠️ 存疑）：输入流水线分片（input pipeline 切 shard）、checkpoint 只由 chief/rank0 落盘、评估去重——1.x 用 `tf.train.supervisor`/`ClusterSpec` 手工三件套（**2026 已废**），DDP/Strategy 全部代管。
- 单机多卡的中间档：`tf.train.replica_device_setter` 自动把变量轮询分给多个 ps ⚠️ 书中是否出现凭记忆（**2026 已废**）；对位现代是 `MirroredStrategy` 的变量镜像语义——"分片存"与"每卡一份"是两种一致性模型（类比 ✅：前者近主从复制、后者近全复制+读修复，C++ 分布式同学可从一致性谱迁移直觉 ⚠️ 类比口径）。

## 批判读法（易错与存疑）

1. **把 2018 章读成 2026 运维手册是最大误用**：TF-PS 手写集群今天几乎无生产用户；它的遗产是概念词汇表（ps/worker/同步异步/chunking）。实操请读 tf.distribute 或 torchrun+DDP（✅ 官方口径）。
2. 本章与主流行场景脱节：2026 大模型训练主战场是 **TPP/流水线并行+ZeRO/FSDP** 混合并行，超越书中"纯数据并行+PS"的视野 ⚠️ 评述——读时补一句"PS 范式在 LLM 时代让位于 all-reduce+FSDP"。
3. 书中若含 in-graph PS（`tf.train.ps_server` 一类 C++ 内部件 ⚠️ 记忆不确定）：**2026 已废**且无 TF2 对位物，仅作架构史阅读。
4. 同步/异步之辩后来被"大 batch+学习率 warmup+LARS"路线实质改写（✅ 通史口径）；本书给的是辩论一方，不是终局。
5. 章界存疑 ⚠️：分布式内容是否也散见于 RNN/CNN 实验的"加速"小节，待目录销账。

## 核心概念中英对照

- **数据并行** — data parallelism：完整模型多副本+数据切片。
- **模型并行** — model parallelism：模型分段放多设备。
- **参数服务器** — parameter server (PS)：worker 算梯度、ps 存聚合参数的架构。
- **同步/异步 SGD** — synchronous/asynchronous SGD：等齐聚合 vs 各推各的。
- **图复制** — between-graph replication：每机一张同构图、变量共享于 ps。
- **设备放置** — device placement：/job:/device: 字符串指定算子归属（1.x）。
- **All-Reduce** — 全规约：现代 DDP 梯度同步的核心集合操作。
- **环形All-Reduce** — ring all-reduce：带宽最优的去中心化梯度交换（NCCL 默认家族 ✅）。
- **陈旧梯度** — stale gradients：异步 SGD 中用旧参数算出的更新量。
- **分片** — sharding：参数/优化器态跨设备切存（FSDP/ZeRO 的动词）。
