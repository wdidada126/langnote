## 核心机制

### 学习率与优化器家族

- **学习率是"全局设定里最敏感的一根弦"**：书中用指数衰减建模学习率——1.x API `tf.train.exponential_decay(lr, step, decay_steps, decay_rate)`（**2026 已废**：TF2 走 `tf.keras.optimizers.schedules.ExponentialDecay`；PyTorch 对位 `torch.optim.lr_scheduler.*` ✅）。机制要点：衰减步数绑定**数据集大小×batch**（`decay_steps = 样本数/batch_size` 每 epoch 一坎）是本书讲得最透的一点（⚠️ 印象）。
- 优化器谱系（✅ 通用数学，框架无关）：SGD → Momentum（惯性）→ RMSProp/AdaGrad（自适应步长）→ Adam（两者合体+偏差校正）。1.x 写法 `tf.train.AdamOptimizer(learning_rate=...).minimize(loss)`（**2026 已废**：Adam 在 TF2 是 `keras.optimizers.Adam`、在 PyTorch 是 `torch.optim.Adam/AdamW` ✅；注意 TF2 后期 Adam 默认 eps 与论文口径的取舍战 ✅ 官方文档有注）。
- 书中"不同优化器在 MNIST 上收敛曲线对比"实验 ⚠️ 凭记忆；对照资源：d2l 有同题逐帧对比（✅ 在盘档 [../DiveIntoDeepLearning.md](../DiveIntoDeepLearning.md)），鱼书 6.1 亦给 SGD/Momentum/AdaGrad/Adam 全曲线（✅ 盘上目录实证）。
- 收敛判断：按**滑动平均的 loss** 看趋势而非单步抖动 ⚠️ 书中措辞；1.x 的 `tf.train.ExponentialMovingAverage`（**2026 已废**为独立训练件，EMA 思路活在 `keras.Model` 权重平滑/BN 统计里 ✅ 口径存疑 ⚠️）。

### 过拟合与正则化军备

- 诊断话术：train 降、validation 先降后升=过拟合拐点；欠拟合则两头都差。书中以损失曲线教"看监控仪表盘"（⚠️ 凭记忆）。
- **L2 正则化**：loss + λΣw²；1.x 藏在 `tf.get_variable(..., regularizer=tf.contrib.layers.l2_regularizer(λ))`（**2026 已废**双重死亡：contrib 2019 随 TF2 整体移除、regularizer 归 `keras.regularizers.l2`；PyTorch 对位 `optimizer=SGD(..., weight_decay=λ)` 或 AdamW 解耦权重衰减 ✅）。概念权威：花书第 7 章数值计算+正则化（✅ 在盘）。
- **Dropout**：训练期按概率随机丢激活、推理期还原尺度；书中强调它是"成本最低的强正则"（⚠️ 措辞）。1.x `tf.layers.dropout(x, rate=0.5, training=...)` 要手工传 training 标志（**2026 已废**：`keras.layers.Dropout` 训练/推理自动分相、PyTorch `nn.Dropout` 跟 `model.train()/eval()` ✅）——"训练态≠推理态"这条双层语义是全框架通用遗产。
- **BatchNormalization**：对每批做标准化+可学习 γ/β，缓解内部协变量移位、允许更大学习率（✅ 原论文口径；"ICM 解释已被质疑"是 2026 后语，书成于 2018 不会有）。1.x 用法 `tf.nn.batch_normalization` 手工接或 slim 层（⚠️ 书中收录深度存疑；TF2 走 `keras.layers.BatchNormalization` ✅）。

### 权重初始化：收敛的第一张多米诺

- 全零初始化会让各神经元梯度相同、对称性无法打破——书中以此劝退"设 0 省事"的直觉（✅ 通用事实；鱼书 6.2.1 同款论证，✅ 盘上目录实证）。
- 1.x 初始化器：`tf.glorot_uniform_initializer()`（Xavier，sigmoid/tanh 配）、`tf.variance_scaling_initializer()` 系（⚠️ 书中确切名凭记忆；**2026 已废**为 `keras.initializers.GlorotUniform`/PyTorch `nn.init.xavier_uniform_`、`kaiming_*` ✅ 对位）。
- 一句话账本：初始化与激活函数是**耦合决策**——tanh 配 Xavier、ReLU 配 He；本书把这条纪律讲清了没有 ⚠️ 待质检，读不到就去鱼书 6.2.3 补。

## 批判读法（易错与存疑）

1. **调参话术 vs 机制**：本书"学习率×0.9 逐步试、正则化系数 1e-4 起步"（⚠️ 典型建议凭记忆）在 2026 属经验玄学残篇——现行做法是 warmup+cosine/OneCycle 调度与自动扫参；读它记"为什么需要调度"即可。
2. **正则化全家桶≠更好**：L2+Dropout+BN 同上是负收益重灾区；书中是否给消融对比 ⚠️ 待质检。判据永远是验证集曲线，不是"书里都讲了就用上"。
3. `minimize()` 会把带 regularizer 的损失项**自动加进总损失**（靠 collection 隐式汇总）——初读极易以为 λ 项没生效（**2026 已废**机制；PyTorch 的 weight_decay 也只作用于 optimizer 收到的参数组 ✅ 显式对比）。
4. Dropout 推理期"缩放 vs 反向丢弃"两种实现等价但易写错——书中怎么交代 ⚠️ 存疑；今天直接用库层，无需重造。
5. BN 的 batch 维依赖：小 batch/序列末端/在线推理下的坑（滑动统计）**大概率超出成书范围** ⚠️——需要时读原论文与 d2l。

## 核心概念中英对照

- **学习率衰减** — learning rate decay：随步数缩步长，后期精修。
- **动量** — momentum：梯度指数滑动平均，冲过峡谷震荡。
- **自适应学习率** — adaptive learning rate：逐参数缩放步长（RMSProp/Adam）。
- **过拟合** — overfitting：训练好、验证崩的记忆化。
- **权重衰减/L2 正则化** — weight decay / L2 regularization：惩罚大权重。
- **随机失活** — dropout：训练期随机丢激活的集成近似。
- **批规范化** — BatchNormalization：层内输入标准化+仿射回。
