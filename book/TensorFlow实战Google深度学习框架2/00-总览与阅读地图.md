## 二、2026 时效裁决（头号义务）

- **定位**：本书作**中文概念地图**用——术语译名（计算图/会话/占位符/正则化/参数服务器）、机制叙事、学习路径编排仍是中文世界最顺的一版；**不作实操教材**。
- **API 判词**：`tf.Session`/`tf.placeholder`/`feed_dict`/`tf.contrib.*`/`tf.train.*Optimizer`/`Estimator` 一套在 TF2.e 系列已**2026 已废**（contrib 2019 随 TF2 移除、estimator 停维、Keras 3 多后端变局）。实操唯一现行口径 = tensorflow.org/tutorials（tf.keras）与 d2l 中文线。
- **读法**：每枚分章档在 1.x API 出现处均带「2026 已废」时效注 + PyTorch/官方文档线对照锚；读概念、弃代码。

## 五、阅读路径建议（2026 版）

1. 先读 00 → 01（计算图心智模型，这仍是理解 TF 遗产与 TorchScript/ONNX 的钥匙）；
2. 概念扫盲走 02→05，每节用鱼书或 d2l 同题章对读，防"框架术语=深度学习"的混淆；
3. 06（参数服务器）、07（DQN）按兴趣跳读——两者机制叙事价值高于代码价值；
4. 落任何工程代码前，一律回 tensorflow.org/tutorials 现行 API 重学，本书代码块**一行都不要照抄**。
