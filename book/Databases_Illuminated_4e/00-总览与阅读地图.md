## 五、🔧 实测环境与方法声明

- 环境：Windows，Python 3.13.2；`sqlite3` 模块内置 SQLite **3.45.3**；DuckDB Python 包 **1.5.5**。

## 核心概念速览（中英对照）

**说明**：本节速览为整册（00）层面的地图词，各章另有本章速览。

- **DBMS** — Database Management System：以模式统一管理数据、提供并发/恢复/安全机制的软件层
- **三级模式/数据独立性** — Three-Schema Architecture / Data Independence：外/概念/内三层隔离用户视角与存储细节
- **概念建模** — Conceptual Modeling：E-R/EER 在实现前捕捉业务结构
- **关系模型** — Relational Model：以关系（表）+ 键 + 完整性约束组织数据
- **SQL** — Structured Query Language：DDL/DML/DQL/DCL 四翼的声明式语言
- **规范化** — Normalization：用函数依赖消除冗余与更新异常
- **ACID** — Atomicity/Consistency/Isolation/Durability：事务的四类保证
- **隔离级别** — Isolation Levels：读未提交到可串行化的异常暴露谱
- **WAL** — Write-Ahead Logging：日志先于数据页落盘的恢复协议
- **分布式透明性** — Distribution Transparency：分片/复制对用户隐藏位置与副本
- **OLAP/数仓** — Online Analytical Processing / Data Warehouse：面向分析的多维聚合视图
- **NoSQL** — Not-Only SQL：放宽关系保证换取扩展性/灵活模式的族系
- **CAP** — Consistency/Availability/Partition tolerance：分区下三选二的权衡定理
- **精读重构** — Close-reading Reconstruction：基于公开资料的再述写作形态（本目录性质）
