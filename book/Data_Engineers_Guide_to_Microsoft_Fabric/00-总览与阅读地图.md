## 4. 「0642 → 实版 ISBN」取证结论（专节，供主代理登记名册）

1. **定性**：`0642572249151` = O'Reilly 平台内部产品号（非 ISBN），判定依据三条：前缀非 978/979
   （ISBN-13 定义级排除）；同段 #188/#190/#149 三连共用 `0642572xxxxxx`（波3 实锤）；URL slug
   `the-data-engineers` 为标题截断式（与 #190 同款）。✅ 可推广。
2. **实版印刷 ISBN：本环境全渠道查无**。17 路探测（§2）中"通道可用但零命中"的强负证据：
   Crossref×2、iTunes lookup、Amazon×4（作者路明确 No results）、豆瓣×3、oreilly.com.cn；
   "通道不可达"的环境性缺口：O'Reilly/Akamai 系、Google 系、archive.org、LoC、OpenLibrary。
3. **合理假说（⚠️ 未证实）**：本书或为数字优先/Early Access 形态新品（0642572 段属 2025–2026
   新产品段，波3 结论），印刷版可能尚不存在或极新未入各索引——"任务口径 2024"与此假说冲突，
   一并交人工终裁。
4. **登记建议**：名册 #191 行 ISBN 字段维持 `0642572249151（O'Reilly 产品号，印刷 ISBN 待人工
   终裁）`，勿回填任何未实证 978 号。
