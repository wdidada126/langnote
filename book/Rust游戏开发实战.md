# Rust游戏开发实战

## 版本与 ISBN

- 原书名：*Hands-on Rust: Effective Learning through 2D Game Development and Play*
- 作者：Herbert Wolverson；译者：米明恒
- 中文版：《Rust游戏开发实战》，人民邮电出版社（异步图书），2024-05
- ISBN：`978-7-115-62660-8`（298 页，CNY 99.80）

> 2026-09-22 由 202608 月度笔记（20260806 Rust 书单）整理。

## 笔记

- 定位：通过 2D 游戏开发实例学习 Rust，兼顾趣味性和知识性。
- 主线：先做 Flappy Bird 学基础 → 完整《地下城爬行者》Dungeon Crawler 项目 → Bevy 引擎用法 → 优化。
- 也介绍了适配 Unity、Unreal 等引擎的 Rust 技巧。
