# 05 三态建模与星型/雪花（⚠️ 主题重构章）

## 核心精讲

### 1. 三态的工作流与交接物

- 概念态：业务实体-关系极简图，**交接物=业务评审记录**（2002 语境为签字会议）⚠️。
- 逻辑态：业务过程×维度的**总线矩阵**+每过程的粒度声明，**交接物=矩阵表**（01 章学派分歧在此中立：两派都用某种矩阵）⚠️。
- 物理态：表/键/分区/聚合/索引决策（06 章接口），**交接物=DDL 与装载映射** ⚠️。
- 反模式：概念图直接跳 DDL——粒度未声明就建表，返工率最高的路径 ⚠️。

### 2. 粒度声明：先于一切实体

- 粒度=事实表每行代表的业务事件最小心智单位（"一行=一次订单行项目" vs "一行=一单"数字差一个量级）⚠️。
- 细粒度不可逆：先细后粗可聚合，先粗后细无中生有——**存疑时取更细** ⚠️ 2002 教材铁律。
- 粒度决定：可回答问题的上限、行数与存储（06 章容量公式输入）、维度冗余度 ⚠️。
- 盘上互校：[../Building_the_Data_Warehouse/04-数据仓库中的粒度.md](../Building_the_Data_Warehouse/04-数据仓库中的粒度.md) ✅（Inmon 的粒度章，维度/规范化双视角）。

### 3. 事实表三型

- **事务事实**（Transaction）：事件即行，只增不改——销量/通话单/日志 ⚠️。
- **周期快照**（Periodic Snapshot）：固定周期对存量成像——账户余额/库存水位；行数=实体数×周期数，规划须按此乘积 ⚠️。
- **累积快照**（Accumulating Snapshot）：一行贯穿多阶段流程（下单→发货→回款），阶段时间戳列被反复 UPDATE——非易失性的**受控例外**，需装载纪律保护 ⚠️。
- 半可加度量（余额类跨维可加、跨时间不可加）在快照表中最高频 ⚠️。

### 4. 星型 vs 雪花 vs 规范化的代价账

- 星型：维度反规范化为宽表——join 少、过滤直观、聚合扫描量大 ⚠️。
- 雪花：维度保持规范化——存储省、维护点唯一，但深层 join 链查询复杂 ⚠️。
- 2002 引擎约束（位图索引/聚合器视图时代）使星型默认胜出 ⚠️ 教材共识重构。
- 🔧 E1 实测（非本书引擎）：100k 行事实 × 三维度星型，SQLite 行存聚合 **107.3ms**，DuckDB 列存 ATTACH 直读同查询 **44.7ms（2.4 倍差）**，top1=(月5,'C2',819125.96)；两引擎**结果一致**（浮点求和顺序致末位差）✅ 本机跑过。
- E1 的双重教训：形态（星型）决定 join 拓扑，**引擎形态**（行存/列存）决定扫描代价——2002 用聚合表手工补偿，2026 引擎出厂自带（10 章）⚠️。

### 5. 一致性维度与总线矩阵

- 一致性维度=跨集市共享同一 SK 空间与属性口径的维度；是"集市可卷积"的唯一凭证 ⚠️。
- 总线矩阵（业务过程×维度）显式登记共享关系；矩阵中一列的维度被两个以上过程引用即触发一致性管控 ⚠️。
- 治理形态：维度发布流程（属性新增免审、口径改类必审）+ 版本登记入元数据（07 章）⚠️。
- 中译口径互读：[../数据仓库工具箱.md](../数据仓库工具箱.md)、[../数据仓库工具箱3.md](../数据仓库工具箱3.md) ✅（Kimball 总线矩阵原始出处之中文版）。

### 6. 三个高频专题

- **退化维度**（Degenerate）：单据号类"无属性维度"直接留在事实表——省 join 但注意与代理键主权（04 章）的边界 ⚠️。
- **垃圾维度**（Junk）：低基数标志位打包成单一维度，防事实表属性化蔓延 ⚠️。
- **桥接表**（Bridge）：多值关系（一个客户多个联系人/账户层次不定深）经桥接表+按因子分摊或上卷标记防重复计数——2002 最易做错的形态 ⚠️；盘上 DataVault 的 Bridge 章为其纵深 ✅ [../Data_Vault_2_0/06-高级建模PIT与Bridge.md](../Data_Vault_2_0/06-高级建模PIT与Bridge.md)。

### 7. 与第三流派：DataVault 的定位

- DataVault（2002 年前后兴起）以 Hub/Link/Satellite 优先集成与审计，把星型推给集市层——本册立场：仓库核心形态之争=**查询亲和 vs 演化/审计亲和** ⚠️。
- 盘上系统论述：[../Data_Vault_2_0/00-总览与阅读地图.md](../Data_Vault_2_0/00-总览与阅读地图.md) ✅ 与其附册分工辨析文件。

## 工程问答卡（⚠️ 重构口径，逐问一行）

- **问**：粒度问题怎么问业务 **答**：'这张表一行等于现实世界的一次什么'——一句话定生死。
- **问**：累积快照为何允许 UPDATE **答**：它是流程工单不是事实——非易失保护改判为'行数只增、列值按期填充'。
- **问**：星型与雪花谁先想 **答**：先粒度与一致性维度，形态是下游工程问题。
- **问**：中心层能用规范化吗 **答**：能——Inmon 中心规范化+维度集市是经典组合；混血不是异端。
- **问**：桥接表事故点 **答**：多值重复计数——因子分摊或上卷标记，二选一写进口径。
- **问**：垃圾维度解决什么 **答**：低基数标志位泛滥——防事实表属性化蔓延。
- **问**：退化维度别和什么混 **答**：别和代理键混——单据号保留在事实表，不建空维表。
- **问**：总线矩阵粒度 **答**：业务过程×维度；过程不是报表、维度不是字段。
- **问**：一致性维度变更控制 **答**：属性新增免审、口径改类必审、发布走登记（07 章）。
- **问**：DataVault 是什么的第三种 **答**：核心层形态的第三种解——集市层常仍回星型。
- **问**：E1 的 2.4 倍差影响建模吗 **答**：不影响逻辑，影响'形态补偿'（聚合表）密度——引擎形态属物理层（06）。
- **问**：两引擎末位浮点差说明什么 **答**：聚合对账应带容差——求和顺序是分布式常态而非 bug。
- **问**：集市扩张瓶颈在哪个维 **答**：一致性维度——它是矛盾汇合点，冻结先行再扩过程。
- **问**：三态交接要细到什么程度 **答**：能据此重建下季决策；模型是资产不是蓝图。
- **问**：本章重构最大风险 **答**：两派配比按 2002 战场重构，原书立场可能不同 ⚠️。

## 核心概念速览（中英对照）

- **三态建模** — Conceptual/Logical/Physical：逐级细化、各有签字交接物的建模工作流。
- **粒度** — Grain：事实表每行的最小心智单位；存疑取更细。
- **事务事实表** — Transaction Fact：事件即行、只增不改。
- **周期快照** — Periodic Snapshot：存量按周期成像，半可加度量主场。
- **累积快照** — Accumulating Snapshot：一行贯穿流程阶段，非易失性的受控例外。
- **星型模式** — Star Schema：事实居中、宽维度环绕的查询亲和形态。
- **雪花模式** — Snowflake Schema：维度规范化的存储/维护亲和形态。
- **总线矩阵** — Bus Matrix：业务过程×一致性维度的全局共享登记簿。
- **一致性维度** — Conformed Dimension：跨集市可卷积的共享维度资产。
- **桥接表** — Bridge Table：多值/层次关系的事实表伴航器，防重复计数。

## 最新演进与工业实践

- **列存使"形态之争"降级**：云仓/本地分析引擎默认列存+向量化，星型与雪花的物理代价差被引擎吸收（E1 的 2.4× 在 2026 引擎里只是索引/压缩策略差异）⚠️ 转述；DuckDB 官方文档列存形态 ✅ https://duckdb.org/docs/stable/ 。
- **表格式接管模式演进**：Iceberg 的 schema evolution/分区演进让"三态改图"从停机工程变成在线变更 ✅ https://iceberg.apache.org/docs/latest/ 。
- **建模对象扩展到半结构**：变体列、JSON、数组使"维度属性"形态多元化，但粒度与一致性维度两法则未变 ✅ 对位文档 https://docs.snowflake.com/en/user-guide/tables-scd （variant 与 SCD 同域）。
- **dbt 使总线矩阵成文**：YAML 模型+语义文档让矩阵从白板图变成可 diff 的仓库工件 ✅ https://docs.getdbt.com/docs/build/incremental-models 。
- **维度即服务**：一致性维度以共享模型/语义层下发（指标层产品），治理从"评审会"转为"目录订阅" ✅ https://docs.datahub.com/docs/introduction 。
- **第三流派进云**：DataVault 实现栈云仓化（哈希键+自动化生成），审计亲和论在强监管行业份额扩大 ⚠️ 转述（盘上 [../Data_Vault_2_0/00-总览与阅读地图.md](../Data_Vault_2_0/00-总览与阅读地图.md) 演进节互校）。
- **不变量**：粒度声明与一致性维度仍是任何形态（星/雪/ vault /宽表）的验收前置——2002→2026 从未失效 ⚠️。
