## 阅读顺序建议

- **主线 A（按书读，推荐）**：01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12。
  书本身是「概念（1–2）→ 数据（3）→ 共识（4）→ 事务（5）→ 时间（6）→ 案例（7）」，顺序读最省力。
- **主线 B（按问题读）**：
  - 「一致性到底有几层」：04 → 09（时间给序）→ 06/07（共识给全序）；
  - 「我要写一个分布式系统」：02（建模）→ 05（知道什么不可能）→ 06/07（选共识）→ 12（看别人怎么写）；
  - 「我要选一个分布式数据库」：03 → 04 → 08 → 11（Bigtable/Dynamo/Cassandra/Spanner 四条路线）；
  - 「面试向速通」：01（数字）→ 04（CAP/线性一致性）→ 06/07（Paxos/Raft）→ 05（2PC/Saga）。
- **对照读**：每读一章前先看该文件的「与其他章 / 其他书的联系」，
  特别是 04 与 van Steen Ch7、09 与 van Steen Ch6、11 与 分布式数据库入门进阶与实战 的对应小节。
