# 《Effective Kotlin: Best Practices》——总览与阅读地图

> 目标书：*Effective Kotlin*，Marcin Moskala（⚠️ 或存第二作者，以版权页为准，不写死），Packt，2022，ISBN ⚠️9781805125897（待核验）。
> 官方书目页未直接列名（列的是 kiA/Atomic 等 ✅），但社区口碑位「工程规范」第一，本仓采纳。

## 一、定位

KiA2e 教你 Kotlin「是什么」，Effective Kotlin 教你「怎么写才不露 Java 味」——**条目式（Item XX）最佳实践**，模仿 Effective Java 体例。对 Java 背景读者，这本书专治"用 Kotlin 语法写 Java 习惯"。

## 二、骨架（⚠️ 部名/条目号以版权页目录为准）

| 部 | 主题带 | 本仓高价值条目方向 |
|---|---|---|
| Ⅰ 语言基础 | 命名/局部变量/不可变 | `val` 优先、最小可见性 |
| Ⅱ 变量与表达式 | 空安全/智能转换 | 平台类型处理规范 |
| Ⅲ 类与对象 | data/sealed/value class、委托 | **value class(inline class) ↔ C++ 无此概念，重点档** |
| Ⅳ 函数与 Lambda | 高阶函数/内联 | `inline/noinline/crossinline` 语义条目（与 ABI 兴趣线接口） |
| Ⅴ 结构与设计 | DSL/类型系统/泛型方差 | 作用域函数选型规范 |
| Ⅵ 并发 | 协程实践条目 | 与 KiA2e 协程章对照读，**别只靠本书学协程**（Moskala 的协程条目受版本演化影响 ⚠️） |

## 三、读法

不线性读。写 Kotlin 代码遇到风格争议 → 查对应 Item；每 Item 落一条「本仓裁决」到分章档（第 2 波），与 Effective Java 老规矩同构——Java 人迁移成本最低的一本。

## 四、🔧 实测口径

Item 级微反例：写"坏味道版"与"修正版"成对 main，kotlinc 编译+运行对比诊断输出（尤其智能转换失效、平台类型 NPE 复现）。
