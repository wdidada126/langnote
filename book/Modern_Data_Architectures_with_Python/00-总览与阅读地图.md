## 核心概念速览（中英对照）

1. **现代数据架构** — Modern Data Architecture：湖仓存储 + 开放表格式 + 治理平面组合出的当代数据平台骨架。
2. **Lakehouse（湖仓）** — Lakehouse：对象存储之上以表格式提供 ACID 与时间旅行的架构形态。
3. **数据网格** — Data Mesh：以领域为所有权单元、数据即产品、联邦治理的 sociotechnical 架构范式。
4. **数据编织** — Data Fabric：以主动元数据与知识图谱驱动跨域自动化集成/治理的架构主张。
5. **ELT/ETL** — Extract-Load-Transform：装载后置到仓内变换（ELT）与装载前置变换（ETL）两种管道方向。
6. **水位线** — Watermark：以 max(updated_ts) 等标记切分「已摄取/待摄取」增量的游标。
7. **MERGE 幂等摄取** — Idempotent Upsert：按主键 MATCHED 更新/NOT MATCHED 插入的可重复执行装载。
8. **数据质量规则** — Data Quality Rules：空值率/唯一性/值域/引用完整性等以 SQL 表达的可断言检查。
9. **元数据指纹** — Schema Fingerprint：对列名+类型集合做哈希，比对即检出 schema 漂移。
10. **血缘边表** — Lineage Edges：以 (src, dst) 二元组为原子的依赖图存储。
11. **SQL 解析抽线** — Static SQL Parsing：用解析器（如 sqlglot）从 SQL 文本静态提取读写表。
12. **递归 CTE 追溯** — Recursive Query Ancestry：WITH RECURSIVE 沿边表逐级求上游闭包。
13. **域自治库** — Domain-autonomous Database：每域一个自包含存储，经 ATTACH/联邦视图跨域组装。
14. **OpenLineage** — OpenLineage：以 run/dataset/facet 事件表达血缘的开放规范（06 章对标）。
15. **数据产品契约** — Data Product Contract：域对外承诺的质量/SLO/文档面（08 章单机类比）。
