# 第 3 章 默认标签的解析

> `beans` 命名空间下的默认标签：`bean`、`import`、`alias`、`beans` 的解析流程（`DefaultBeanDefinitionDocumentReader` → `BeanDefinitionParserDelegate`）。本章讲「XML 元素如何变成 `BeanDefinition`」。

## 一、核心精讲

### 3.1 🔧 解析链
- `DefaultBeanDefinitionDocumentReader.parseBeanDefinitions` 区分**默认**与**自定义**命名空间（🔧 默认 = `http://www.springframework.org/schema/beans`；其余走第 4 章自定义解析）。

### 3.2 `<bean>` 解析要点
- 属性：`id`/`name`（别名）、`class`、`scope`、`lazy-init`、`init-method`/`destroy-method`、`factory-bean`/`factory-method`、`autowire`；子元素：`property`/`constructor-arg`/`lookup-method`/`replaced-method`/`qualifier`/`meta`（🔧 最终封装成 `GenericBeanDefinition`/`RootBeanDefinition`）。

### 3.3 `import`/`alias`
- `import` 递归加载其他 XML（路径解析含占位符）；`alias` 注册别名映射（🔧 别名在 `SimpleAliasRegistry` 里做**循环检测**，防止 A→B→A）。

## 二、版本演进 / 论文 / 前沿

- 文献：Spring Reference（XML 配置）；XML Schema 规范。
- 工业界：现代项目多用 Java Config（` @Configuration`/`@Bean`）与注解扫描，XML 已非主流（🔧 但源码解析链原理相通，理解 XML 有助于理解注解配置背后的 `BeanDefinition` 生成）。

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "XML 解析直接造对象" | 造 BeanDefinition |
| 2 | "alias 无环检测" | SimpleAliasRegistry 会查环 |
| 3 | "默认标签=所有标签" | 自定义走 NamespaceHandler |
