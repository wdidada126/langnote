# 第 1 章 Spring 整体架构与环境搭建

> Spring 5 模块划分（Core/Beans/Context/AOP/Data/Web）、源码环境搭建（Gradle 编译、JDK 8、仓库代理）。对应大纲里的编译踩坑记录。

## 一、核心精讲

### 1.1 🔧 模块分层
- `spring-core`（核心工具/资源）、`spring-beans`（`BeanFactory`/`BeanDefinition`）、`spring-context`（`ApplicationContext`/事件/国际化）、`spring-aop`、`spring-jdbc`/`orm`/`tx`、`spring-web`/`webmvc`（🔧 理解分层：Beans 是 IoC 内核，Context 在其上加「企业能力」）。

### 1.2 源码编译坑（大纲实录）
- `Could not determine java version from '11.0.4'` → 换回 **JDK 8** 的 `JAVA_HOME`（Spring 5.0.x 用 Gradle 4.x，不支持 JDK 11）。
- `Could not GET 'https://repo.spring.io/plugins-release'` → 配仓库/代理（🔧 `JAVA_HOME`、`<repositories>` 加 `spring-releases`、必要时 `http_proxy`）。
- `gradlew build -x test` 跳过测试加速（🔧 Spring Boot 编译更易失败，先编译 framework）。

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "用 JDK 11+ 编 Spring 5.0.x" | 需 JDK 8 |
| 2 | "仓库不可达就换镜像不管" | 加 spring-releases 仓库 |
| 3 | "Beans=Context" | Beans 是内核，Context 是企业扩展 |
