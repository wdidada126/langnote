# 第 12 章 远程服务

> Spring 远程调用支持：RMI（`RmiServiceExporter`/`RmiProxyFactoryBean`）、Hessian/Burlap（HTTP + 二进制）、HTTP invoker（Java 序列化 over HTTP）、JAX-WS/REST。本书讲 `RemoteExporter` + `RemoteInvocation` 的统一抽象。

## 一、核心精讲

### 12.1 🔧 统一抽象
- 导出端：`RemoteExporter` 把普通 bean 暴露成远程服务；调用端：`FactoryBean` 生成客户端代理（🔧 两端用 `RemoteInvocation`（方法名/参数类型/参数值）与 `RemoteInvocationResult` 交换，与具体协议解耦）。

### 12.2 各协议
- **RMI**：Java 原生，JDK 序列化，**同构 Java 环境**最快；**Hessian**：HTTP + 跨语言二进制（🔧 Caucho 出品，早期跨语言首选）；**HTTP invoker**：Spring 专有，Java 序列化 over HTTP（🔧 仅 Java↔Java，已不推荐）。

### 12.3 现代替代
- 上述技术**均已过时**（RMI 在 JDK 17 起部分废弃、序列化安全风险（反序列化 gadget））（🔧 现代用 gRPC/HTTP+JSON、Dubbo、Spring Cloud OpenFeign，见尼恩《高并发核心编程》7 章序列化）。

## 二、版本演进 / 论文 / 前沿

- 文献：Spring Reference（Remoting）；RMI 规范；Hessian 协议；gRPC（Google）。
- 工业界：gRPC（grpc-java 11k）、Dubbo（41k）、Spring Cloud OpenFeign；序列化改 Protobuf/JSON（🔧 反序列化漏洞警示，见尼恩 7 章）。
- 开源 stars（2026-09）：grpc-java 11k / dubbo 41k.
