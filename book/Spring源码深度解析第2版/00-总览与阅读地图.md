# 《Spring源码深度解析（第2版）》阅读地图

- 作者：郝佳；第2版 2019（Spring 5），豆瓣 30452948
- 定位：**Spring 框架源码逐行剖析**——从 IoC 容器 → bean 加载 → AOP → 数据访问 → MVC → 远程/消息 → Spring Boot 自动配置。与「并发系列」完全不同领域，是 Java 后端框架侧的核心书。
- 源码：`spring-framework-5.0.x`（`gradlew build -x test`；编译需注意 JDK 8 + 仓库可达，大纲记有 Maven/Gradle 代理与仓库坑）。

## 阅读路径建议

- 主线（IoC）：02 → 03/04 → 05 → 06（最核心，搞懂 `BeanDefinition` 生命周期 + 三级缓存）。
- 扩展（AOP/数据/MVC）：07 → 08-10 → 11。
- 收尾：12/13 按需；14 Spring Boot 是现代默认入口。

## 本书没覆盖的缺口（2026 视角）

- Spring Boot 3 / Spring Framework 6：Jakarta EE（`javax.*` → `jakarta.*`）、AOT/GraalVM Native（Spring Native）。
- 响应式栈 WebFlux（Reactor，见 `Java编程方法论_响应式Spring_Reactor3设计与实现.md`）。
- 虚拟线程：Spring Boot 3.2+ 支持 `spring.threads.virtual.enabled=true`（Tomcat 用虚拟线程处理请求）。
