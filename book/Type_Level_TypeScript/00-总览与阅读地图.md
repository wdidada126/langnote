# 《Type-Level TypeScript》——总览与阅读地图

> 目标书：*Type-Level TypeScript*，Gabriel Vergnaud（第三方书目表配对；本波检索未见官方出版页直证 ⚠️），独立出版/Leanpub 线 ⚠️，约 2023，ISBN 无或独立书号 ⚠️。
> 出版形态注记 ⚠️：疑似「书+配套练习站（typescript-exercises 系）」捆绑发行——同作者谱系，销账时确认。

## 一、定位

**类型体操教材位**：把 TS 类型系统当纯函数语言讲（条件类型、`infer`、递归类型、模板字面量类型、类型级列表编码）。本仓定位=**第二本「类型即程序」档**——与 `C++20模板元编程/` 双峰对照阅读，是 C++ 模板背景读者在 TS 侧最对胃的一本。

## 二、骨架（⚠️ 章名凭机制清单与简介记忆，以目录销账为准）

| 段 | 主题带 | ↔ C++ 对偶（本仓核心读法） |
|---|---|---|
| Ⅰ 类型级思维 | 类型=集合、函数=类型变换 | 模板=类型函数总纲位 |
| Ⅱ 条件与推断 | 条件类型、分发律、`infer` | 特化/SFINA ↔ 条件/`infer`；分发 ≈ 参数包展开 |
| Ⅲ 映射类型 | 键重排、修饰符增删、同态映射 | Trait 变换（`add_pointer` 系）对偶 |
| Ⅳ 字面量与模板 | 字符串字面量类型、模板字面量类型 | C++ 无对偶（`constexpr` 字符串时代差）——重点差集档 |
| Ⅴ 类型级编程 | 递归、列表/元组编码、类型解析器 | 与 `C++20模板元编程/` 递归实例化章互链；TS 递归深度限制 vs C++ 模板深度限制双表 |

## 三、读法

练习驱动：每章例必手写「体操解」再对书解；每章落一行「C++ 对偶/无对偶」裁定。目标产出=本仓 `TypeScript 类型体操 ↔ C++ TMP 对照表` 专题档（第 3 波候选）。

## 四、🔧 实测口径

体操题的「测试即类型」方案：`Expect<Equal<A,B>>` 断言惯用法（类型级相等判定）——需 `tsc` 报错面验证 ⚠️；运行面 strip-types 不适用（纯类型层）。递归深度上限、实例化爆炸案例各建一号（与 C++ `-ftemplate-depth` 对照）。
