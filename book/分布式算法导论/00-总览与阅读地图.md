# 《分布式算法导论》深度笔记——总览与阅读地图

> **阅读本书的第一原则**：这是一本 2000 年出版的理论教材（中译 2004），它教你的是**消息传递网络上的算法骨架与复杂度分析方法**，
> 而不是现代分布式系统的工程结论。书中所有「复杂度最优」都是在消息数/时间的渐近意义下说的；
> 现实系统还要面对容错、拜占庭行为、时钟误差工程化等问题。因此本目录**每一章都设「常见误区与本书需修正之处」**，
> 把 2000 年的结论校正到 2026 年的视角（Raft、Flink checkpoint、SDN、TrueTime/HLC 等）。

## 三、版本演进时间轴（算法视角，非软件版本）

> 本书不是软件书，此表按「书中算法 → 后续演化 → 今天的样子」组织，🔴 标出颠覆性变化。

| 时间 | 变化 | 影响 |
| --- | --- | --- |
| 1969 | 交替位协议（Bartlett–Scantlebury–Wilkinson）成为可靠链路层雏形 | Ch3 |
| 1978 | Lamport《Time, Clocks, and the Ordering of Events》奠定逻辑时钟与因果序 | Ch2 全书基石 |
| 1980–1983 | 环上选举、终止检测、生成树（GHS 1983）论文潮 | Ch6–8 |
| 🔴 1985 | Chandy–Lamport 快照（ACM TOCS）；Awerbuch 同步器（JACM） | Ch9–10、Ch12 |
| 1987–1990 | 信用终止检测（Mattern）、KKM 选举组合技术 | Ch7–8 |
| 🔴 1998–2001 | 拜占庭容错实用化（PBFT 1999）；Google GFS/MapReduce（2003–04）把「无故障教科书模型」抛在身后，工业界转向**容错优先的共识系统** | 全书定位变化：教科书算法成为共识/复制系统的底层积木 |
| 🔴 2013–2017 | Raft（USENIX ATC 2014）把「选举」变成每个工程师要懂的词；Flink 把 Chandy–Lamport 快照做成 checkpoint 工业标准 | Ch6、Ch7、Ch9 笔记的 2026 视角主线 |
| 2015–2026 | SDN 把路由控制面集中化；BGP/OSPF 仍是数据中心内网红；NTP→PTP/TrueTime/HLC 时间基础设施 | Ch3、Ch10 笔记的 2026 视角主线 |

最小验证范式（教学示意，不参与构建）：

```python
# 模拟一个异步点对点网络：每个进程收到消息才动一步
import heapq, itertools
clock = itertools.count()
class Net:
    def __init__(self): self.q = []            # (time, tie, to, msg)
    def send(self, to, msg): heapq.heappush(self.q, (next(clock), next(clock), to, msg))
    def deliver(self):
        _, _, to, msg = heapq.heappop(self.q)
        return to, msg
```
