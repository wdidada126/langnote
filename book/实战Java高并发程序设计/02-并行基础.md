## 二、核心精讲

### 2.1 线程安全三要素
- 原子性（`synchronized`/`Atomic*`）、可见性（`volatile`/锁）、有序性（happen-before，见《艺术》3 章）。

### 2.2 易错点
- `volatile` 非原子；`i++` 要用 `AtomicInteger`。
- `wait` 必须 `while` + 配 `synchronized`。
- `ThreadLocal` 在线程池下 value 强引用泄漏（remove / ScopedValue）。

### 2.3 🔧 现代
- 虚拟线程（JEP 444）+ 结构化并发（JEP 453/505）让"基础"层面多数手动管理变作用域级。
