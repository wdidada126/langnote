## 5. 本书在数据库系列中的定位（Spark 谱系分工表）

- **本书 = 2015 年 Spark 1.x/早期 API 的「问题→配方」横切面快照**：RDD 为主、Spark SQL 以 HiveContext/case class 为中心、MLlib 以 RDD 旧 API 为中心、DStream 先于 Structured Streaming。今天读它的价值是**理解旧配方到现代 API 的映射关系**，以及食谱体裁对「运维/接入/调优」三域的原始覆盖。
- 谱系对照：#215 [../Spark_The_Definitive_Guide/00-总览与阅读地图.md](../Spark_The_Definitive_Guide/00-总览与阅读地图.md)（3.x 权威全景）为**上行主参照**；[../Advanced_Analytics_with_Spark_2e/00-总览与阅读地图.md](../Advanced_Analytics_with_Spark_2e/00-总览与阅读地图.md)（同年代 O'Reilly 案例册，GraphX/ML 纵深更细）为**同期姊妹**；[../bigdata/00-总览与阅读地图.md](../bigdata/00-总览与阅读地图.md)（中文大数据系列）承担**中文语境概念底座**；[../Use_Iceberg_with_Spark/00-总览与阅读地图.md](../Use_Iceberg_with_Spark/00-总览与阅读地图.md) 展示**数据源章的湖仓现代化去向**。

## 8. 阅读方法声明与建议路径

1. **先新后旧**：先读 [../Spark_The_Definitive_Guide/00-总览与阅读地图.md](../Spark_The_Definitive_Guide/00-总览与阅读地图.md) 建立 3.x 坐标系，再回本目录看 1.x 食谱的「原始问法」。
2. **按域取用**：接入问题看 02，SQL 化看 03，流看 04，ML 看 05-07，调优看 08；01 仅作历史工具链考古。
3. **食谱体裁读法**：不线性通读；每题按「问题→配方骨架→2026 等价写法→坑」四步消化，各章文件即按此结构精读重构。
4. 本目录所有英文目录名与食谱题为官方电子版目录逐字转录；中文标题为本目录拟定，不构成对任何中译本的引用。
