# 《Java to Kotlin: A Refactoring Guidebook》——总览与阅读地图

> 目标书：*Java to Kotlin: A Refactoring Guidebook*，O'Reilly，2023（⚠️ 作者署名线含 Duncan DeVore，完整名单与 ISBN 待核验，不写死）。
> 用户粘贴的第三方结论评 ★★★★★ 并将它列入五本终裁清单；本仓采纳其定位，书目字段留 ⚠️。

## 一、定位（本画像专属的一本）

不讲 Kotlin 语法教科书，讲**如何把真实 Java 代码库逐步重构为 idiomatic Kotlin**：小步替换、每步可编译可测试、用 Kotlin 编译器/IDE 转换工具做起点再手工惯用化。对已有 Java/C++ 经验者，它解决的是"语法会了但写不出来/写出来不像 Kotlin"的核心病。

## 二、骨架（⚠️ 章名以版权页为准）

| 段 | 覆盖 | 关键转化 |
|---|---|---|
| 起步 | 混合模块策略、转换工具边界 | Java 互操作层→渐进切分 |
| 惯用化 | null→类型系统、getter→属性、Builder→默认参/data class、循环→集合操作、Checked 异常→Result/契约 | **Java idiom → Kotlin idiom 对照表的主产地** |
| 设计重构 | 继承→组合/接口默认实现、visitor→密封类+when、单例→object | sealed class 状态机化 |
| 并发迁移 | Thread/Executor→协程、Future→suspend | 与 KiA2e 协程章二选一做主读 |
| 测试与工具 | 转换后测试策略、Gradle/构建链调整 | 衔接 Spring Boot Kotlin |

## 三、读法与🔧实测

- 读本仓任一 Java 项目式样本（如 csdiy 课的 Java 作业，`courses/` 内 CS61B 线 ✅ 存在）做"逐章实操靶子"，每章交一份重构 commit 级笔记。
