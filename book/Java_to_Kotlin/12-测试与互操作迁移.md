## 机制：Java 原形 → Kotlin 翻法 → 重构步序

**Java 原形（JUnit4 测 06 档的 Builder）** 🔧：

```java
public class SearchQueryTest {
    @Test public void defaultsPageSize() {
        SearchQuery q = new SearchQuery.Builder().term("kotlin").build();
        assertEquals(20, q.getPageSize());
    }
    @Test(expected = IllegalStateException.class)
    public void blankTermRejected() {
        new SearchQuery.Builder().term("  ").build();
    }
}
```

**Kotlin 翻法（生产代码走完 06 档后，测试的两副面孔）** 🔧：

```kotlin
// 面孔 A——还没转的 Java 测试：生产已是 data class，
//   new SearchQuery("kotlin") 编译失败 → 边界决定：构造器加 @JvmOverloads，
//   或留薄 Builder 门面到 Java 调用清零（06 档步序⑤）。测试红 = "边界残量"信号。
// 面孔 B——转成 Kotlin 的同测试：
class SearchQueryTest {
    @Test fun `default page size`() {
        assertEquals(20, SearchQuery(term = "kotlin").pageSize)   // 属性直接读
    }
    @Test fun blankTermRejected() {
        assertThrows(IllegalArgumentException::class.java) {      // require 抛 IAE
            SearchQuery(term = "  ")
        }
    }
}
```

**重构步序**（迁移期测试策略，⚠️ 归纳）：① 转换**前**确认该文件被绿测试覆盖（测试是预言机，01 档循环的第 0 环）；② 转文件、惯用化，**保持 Java 测试原样**再编译再跑——行为不变性由旧预言机担保；③ 新测试一律 Kotlin（JUnit5 + `assertThrows`，或 `kotlin("test")` 断言）；④ 旧 Java 测试缓转、允许长期共存（混合构建在 01 档构建层已立）；⑤ 边界注解残量（`@JvmOverloads` 等）计数入仪表盘，随 Java 调用清零而删；⑥ 构建链：Gradle Kotlin DSL、`compileTestKotlin→compileJava` 顺序与主源码集同构（01 档实验 2 的测试版）。

## 老手易错点与批判读法（画像：Java/C++ 经验者）

- **别同时转产品和它的测试**：两处同变则红绿失义——"每步可编译可测试"（01 档主线）在测试侧的推论是**一次只动一侧**（⚠️ 归纳立场）。
- **data class 的 equals 会静默救活烂断言，也会埋掉实体 id 漂移**：`assertEquals(旧Bean, 新Bean)` 转 Kotlin 后可能因结构相等从"恰好过"变"永远过"——转前先补强断言（04 档实体判据）。
- **反引号测试名与 Java 工具链**：surefire 老版本对含空格方法名的报告兼容 ⚠️ 传闻级，混合构建升级时留意。
- **测试目录混编**：`src/test/java` 与 `src/test/kotlin` 并存的编译顺序、可见性（Kotlin 测试可读 Java 测试类）与主源码集同一套规则——01 档叶子模块策略先跑一遍再谈测试转换。
- **C++ 对照**：给"编译器视图变化"当预言机的正是测试——类似 C++ 迁移里 ABI 检查工具的角色；Kotlin 没有 ABI 差分器，测试绿 = 唯一哨兵，所以②步"旧测试原样跑"不可省略。
- **批判一句**：互操作注解族是**债的显式记账**，不是惯用化成果——`@JvmXxx` 数量应随迁移单调递减；某文件长期挂着多个注解就是"还没真转完"的仪表盘读数（🔧 实验 1 建立此读数）。

## 核心概念中英对照

| 中文 | 英文 | 一句话 |
|---|---|---|
| 预言机 | test oracle | 迁移期以旧测试担保行为不变 |

| 边界残量 | interop residue | 尚未清零的 Java 侧适配计数 |
