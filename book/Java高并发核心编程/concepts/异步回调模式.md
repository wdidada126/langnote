# 卷2·高并发核心模式之异步回调模式（尼恩）

> 卷2 第 9 章。异步回调：Callback 接口、Future/Promise、CompletableFuture、回调地狱与解救。与卷2 第 10 章（CompletableFuture 实战）连续，详见《之美》concepts/CompletableFuture与异步编排.md。

## 一、核心精讲

### 1.1 Callback 的局限
- 传入 `onSuccess/onFailure`，逻辑分散、错误难传播（🔧 「回调地狱」：嵌套回调可读性差、栈不连续）。

### 1.2 Future → CompletableFuture
- `Future.get()` 阻塞；`CompletableFuture` 支持 `thenApply/thenCompose/thenCombine` 链式 + 异常 `handle`（🔧 见之美 CompletableFuture 专篇完整 API 树）。

### 1.3 与虚拟线程
- 异步回调是为「避开线程阻塞」而生；JDK 21 虚拟线程让「同步写法 + 每请求一虚拟线程」重新简单（🔧 回调链可大量退场，但跨服务异步/响应式仍保留）。
