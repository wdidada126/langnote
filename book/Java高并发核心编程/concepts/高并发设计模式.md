# 卷2·高并发设计模式（尼恩）

> 卷2 第 8 章。并发/高并发设计模式：不变模式、线程封闭、策略模式、生产者-消费者、Future、保护暂停（Guarded Suspension）、两阶段终止、主仆（Master-Worker）、流水线、半同步半异步、反应器（Reactor）。详见葛一鸣《实战高并发程序设计》5 章（并行模式与算法）更全。

## 一、核心精讲

### 1.1 不变模式（Immutable）
- 字段 `final` + 不逸出，天然线程安全（🔧 见 Goetz《实战》3 章、黄文海 6 章、手册 11 章）。

### 1.2 生产者-消费者
- 阻塞队列解耦生产/消费速度（🔧 见之美 concepts/阻塞队列；Netty 写缓冲亦用）。

### 1.3 两阶段终止（Two-Phase Termination）
- 发中断/标志 → 任务在安全检查点优雅收尾（🔧 见黄文海 8 章、Goetz concepts/中断与取消策略）。

### 1.4 Master-Worker / 流水线
- 任务分解给多个 Worker 汇总（MapReduce 雏形）；流水线把处理分段并行（🔧 见葛一鸣 5 章、精通2 7-9 章）。

### 1.5 反应器（Reactor）
- 事件驱动，见本书卷1 第 4 章；半同步半异步分离 IO 与业务线程。

## 二、版本演进 / 论文 / 前沿

- 论文/文献：GoF 设计模式（1994）、Schmidt POSA（Reactor/半同步半异步，1996）、Doug Lea《Concurrent Programming in Java》。
- 工业界：Netty（Reactor）、Disruptor（流水线/环形）、Akka（Actor 替代多数模式）。
- 开源 stars（2026-09）：netty 34k / disruptor 18.5k / akka 13.3k.

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "模式套就安全" | 不变需真正不逸出 |
| 2 | "两阶段终止强杀" | 安全检查点优雅退 |
