## 二、核心精讲

### 2.1 🔧 五种 IO 模型对照
- **阻塞**：`recvfrom` 一直等；**非阻塞**：立即返 `EWOULDBLOCK`，轮询烧 CPU；**多路复用**：`select/poll/epoll` 等一组 fd；**信号驱动**：`SIGIO` 通知；**异步 AIO**：内核完成才通知（🔧 真正异步只有 AIO/`io_uring`，Java NIO.2 `AsynchronousSocketChannel` 在 Linux 早期用线程池模拟）。

### 2.2 零拷贝
- `sendfile`：数据从内核页缓存直接到网卡，省去内核↔用户拷贝（🔧 Kafka/Nginx/Netty `FileRegion` 用 `sendfile`，显著提升文件吞吐）；`mmap`：文件映射进用户空间免一次拷贝但仍有页表开销。

## 三、版本演进 / 论文 / 前沿

- 论文/文献：Kegel C10K；`epoll` (Linux 2.6)、`io_uring` (Linux 5.1，真正异步)；BSD `kqueue`。
- 工业界：Kafka（零拷贝+批量）、Netty `FileRegion`、`io_uring` (Rust tokio/glommio)。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "Java NIO 是异步" | 仅多路复用，非真异步 |
| 2 | "mmap 最省" | 文件传输用 sendfile |
| 3 | "AIO 都高效" | Linux AIO 早期是线程池模拟 |
| 4 | "频繁小包拷贝无所谓" | 高并发下拷贝是瓶颈 |
