## 二、核心精讲

### 2.1 🔧 单线程为何快
- 纯内存 + 非阻塞 IO（epoll）+ 单线程无锁（🔧 Redis 6 引入多 IO 线程处理网络读，但命令执行仍单线程；瓶颈在内存带宽/大 key，不在核数）。

### 2.2 缓存三坑
- **穿透**：查不存在 key→打库（🔧 布隆过滤器/缓存空值）。
- **击穿**：热点 key 过期瞬间海量打库（🔧 互斥重建/逻辑过期）。
- **雪崩**：大量 key 同时过期/Redis 挂（🔧 过期错峰 + 高可用 + 限流降级）。

### 2.3 大 key / 热 key
- 大 key（如巨型 Hash）阻塞单线程（🔧 拆分/分批）；热 key（🔧 本地缓存 + 多副本）。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |

| 1 | "Redis 多线程慢" | 网络多线程，执行单线程 |
