|---|---|---|---|

| E4 | 惰性执行/计划融合 | 02 | DuckDB 单计划融合 FILTER/HASH_GROUP_BY/TOP_N；SQLite 手工三步物化 6.8ms |

## 8. 精读单元要点速记（每章三行版）

- **01**：2.0 起 `SparkSession` 是唯一入口（SQLContext/HiveContext 退役）；RDD 仍是底层通货；窄依赖成 stage、宽依赖切 shuffle。
- **02**：DataFrame（带 schema 的分布式表）+ Dataset（类型化，Scala/Java 独有）在 2.0 合流；Catalyst+Tungsten 让 SQL 路径快过手写 RDD。
- **03**：Structured Streaming =「流是慢查询」；微批为主、事件时间+水位线管迟到、输出模式决定下游语义。
- **04**：ml（DataFrame-based）Pipeline 三件套 Transformer/Estimator/Stage 取代手写 RDD ML；KMeans/ANN 是本书代码仓实据。
- **05**：GraphX 把图当 RDD 属性挂载；2.x 的深度学习靠外接生态而非 Spark 本体——本册史料的诚实边界。
- **06**：调优三板斧=序列化/内存/shuffle；监控以 Spark UI+History Server 为核心；ALS 撑起推荐副题。
