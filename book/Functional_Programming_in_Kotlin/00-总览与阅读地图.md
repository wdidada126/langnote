# 《Functional Programming in Kotlin》——总览与阅读地图

> 目标书：*Functional Programming in Kotlin*，Apress，2021（⚠️ 作者署名线 Paolo Coletti/Kevin Jones 待核验，ISBN 不写死）。
> 用户粘贴的第三方结论列入五本终裁清单（函数式进阶位）；对位 Scala 界《FP in Scala》的 Kotlin 改写线（⚠️ 谱系说法待证）。

## 一、定位

类型驱动函数式风格：不可变数据、Option/Either/Validated、函数组合、typeclass 式参数多态（Kotlin 无 typeclass，用接口+扩展+高阶函数模拟 ⚠️ 归纳）。对 C++ 模板线读者：Kotlin 用「接口默认方法 + 扩展函数 + 高阶函数」表达 Scala typeclass 惯用法，表达力落差是本档观察重点。

## 二、骨架（⚠️ 章名以版权页为准）

| 段 | 覆盖 |
|---|---|
| 基础 | 引用透明、纯函数、不可变性 |
| 错误处理 | Option/Either/Validated → 衔接 Kotlin `Result` 与 sealed class 惯用法 |
| 组合子 | 函数组合、Currying、Memoization、Reader/State（⚠️ 是否覆盖 IO monad 待核验） |
| 类型类模拟 | Monoid/Functor/Monad 接口化实践 |
| 并行 | 并行求值——**读法裁决：并发部分不如 KiA2e 协程章现代，跳过 ⚠️ 判断** |

## 三、对读

- 《The Joy of Kotlin》（Saumont）同题更激进（Arrow 线前时代 ⚠️），两本择深；本仓先建此本（用户终裁清单在列），Joy 留第 2 波。
- Kotlin 官方惯用法以 `kotlin.Result`/sealed/`let-run-with` 为主，本书学院派类型体操**不与工程规范混背**（Effective Kotlin 裁决优先）。

## 四、🔧 实测口径

每章一个单文件示范：sealed ADT + when 穷尽、Either 链式、Memoization 用 by lazy——kotlinc 直跑；与 C++ `std::optional/variant` 对位表落分章档。
