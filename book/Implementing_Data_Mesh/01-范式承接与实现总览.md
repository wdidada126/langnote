## 1.1 为什么会有这本书：实现差距（implementation gap）

Dehghani 的 #201 给出了范式（paradigm）与逻辑架构，但它刻意不回答三个工程问题：**契约长什么样（语法与语义）、产品怎么被批量造出来、目录/市场用什么工件承载**。2022–2024 年工业界的普遍反馈正是"原则都对，工件没有"——本书（⚠️ 据副题与作者公开线推断的写作动机）填的就是这段：封面副题逐词都是工件名——**Data Contracts / Data Products / Data Mesh**，动词是 Design, Build, Implement。

| #201 原则 | 留下的空白 | 本书一侧的补法（⚠️ 主题级） |
|---|---|---|
| 领域所有权 | 切域判据多、落地判例少 | 以气候/地理空间域为贯穿案例（Broda 的 `osc-geo-h3grid-srv` 仓库实证其地理网格背景 ✅） |
| 数据即产品 | "产品"定义抽象 | 产品=可发现、可理解、可消费、可组合的交付物+伴随元数据（05 章展开） |
| 自助平台 | 平台组件语焉不详 | Backstage 编目、模板化生产（06 章展开，Broda `data-mesh-catalog` 仓库 ✅） |
| 联邦治理 | 政策如何变代码 | 契约即政策载体：校验规则、SLA 字段进 YAML（03/04/07 章展开） |

## 1.4 贯穿案例：气候/观测数据域（⚠️ 主题级重构）

本书叙事线围绕一个跨机构气候数据共享场景展开（⚠️ 据 Broda 地理空间网格仓库与 ODCS 样例的观测数据形状旁证；原书案例细节不可达）。笔记侧采用等价抽象：**观测站(station) → 观测值(observation) → 派生产品(derived product)**，其难点恰好是契约三要素的试金石：单位与量纲（语义）、缺测与异常值（质量）、跨机构时间戳对齐（兼容性）。本册 🔧 实验全部用这张形状跑。

## 1.5 🔧 类比实验组（SQLite/DuckDB 本机实测，**非本书平台行为**）

**🔧-A 域=独立库文件（域自治的最小物理类比）**：三域各建一个 SQLite 库文件（orders/climate/customers），主库不存业务表——`SELECT count(*) FROM main.sqlite_master` 实测 **0**（E1），所有权完全在域文件内。

```sql
ATTACH DATABASE 'domains/domain_climate.db' AS climate_dp;
SELECT o.order_id, u.region, c.temp_c
FROM orders_dp.orders o JOIN customers_dp.customers u ... 
     CROSS JOIN climate_dp.obs c;   -- 实测返回 ('o1','EU',21.3)
```

**🔧-B 消费面只读（产品接口不可回写）**：以 URI `file:...?mode=ro` 打开域库执行 INSERT，实测被拒：`attempt to write a readonly database`（E2）。

**🔧-C DuckDB 侧等价物**：`ATTACH DATABASE '...' AS orders_dp (READ_ONLY)` 后 INSERT 实测报 `Cannot execute statement of type "INSERT" on database "orders_dp"`（E5）——两种引擎都提供"挂载即边界"的自治类比。

**🔧-D 命名空间消歧（域内同名不互扰）**：`main.orders` 与 `orders_dp.orders` 同表名并存，限定名各取所需，实测 `[('local',)]` 与 `[('o1',),('o2',)]`（E11）——联邦寻址的基本性质。

## 1.9 本册对"实现"二字的裁剪

原书体量与覆盖面不可考 ⚠️，本册主动裁剪如下（声明式，防误期望）：不写云厂商产品名对照（留给 #202 与在盘厂商册）；不写流式引擎内部机制（[Streaming_Systems](../Streaming_Systems/00-总览与阅读地图.md) 已深）；不写表格式物理细节（湖仓诸册已深）；保留的是**跨引擎不变的工件层**：契约、目录条目、政策、路线图——这也正是"实现 Data Mesh"区别于"实现某个数据平台"的部分。若需要厂商组件级映射，本册不提供，请以 #202 与在盘厂商诸册为唯一入口。

## 1.10 三个常见误读（实现向册特有）

- **误读一："契约=dbt tests 换皮"**。区别在主权与合同性：tests 是生产者自检，契约是对消费者发布的可追责承诺（03/04 章整章差异由此展开）。
- **误读二："上了目录=有了网格"**。目录只是五件套之一件；无域写权限边界（02）与政策执行器（07）的目录=过期黄页。
- **误读三："mesh 反中台所以不建平台"**。#201 反对的是集中所有权不是集中供给，本册 06 章的三供给面恰是重平台——去中心化在拓扑不在物理。
- **误读四："前言作者=合著者"**。Scott Hirleman 仅作序（封面实证 ✅），正文所有权归 Perrin 与 Broda 二人——引用时勿把序言观点当作者观点。
- **误读五："有 ODCS 章节=本书讲某云产品"**。副题三词全是工件名不是产品名；厂商对照请去 #202 与在盘厂商册（1.9 裁剪声明）。
- **误读六："本册章号=原书章号"**。七章为主题重构口径（`00` §4），引用本册时写"Implementing_Data_Mesh/03"而非"原书第 3 章"。
