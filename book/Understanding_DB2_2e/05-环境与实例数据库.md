## 核心精讲

### 1. 环境三件套（⚠️ 转述）
`DB2INSTANCE`（当前默认实例）、实例 profile（UNIX 的 db2profile 经 `. profile` 注入 PATH/LD_LIBRARY_PATH；Windows 走服务与注册表）、注册表变量（db2set，含 GLOBAL/实例两级）。新手第一课就是"你在哪个实例里"——`db2 get instance` 与 `db2ilist` 是随身指南针。

### 2. 实例生命周期（⚠️ 转述）
db2icrt/db2idrop/db2ilist/db2start/db2stop；实例配置 dbm cfg（含最大连接、监控开关、故障恢复相关 SELF tunables 前代旋钮 ⚠️）。一个安装多实例共存时，端口表与服务名是规划重点（呼应 [03](03-安装DB2.md)）。

### 3. 数据库创建的关键决定（⚠️ 转述，多为不可逆项）
- **页大小**（4/8/16/32K）：定默认表空间的"物理基因"；
- **代码集/地域/排序规则**（CODESET/TERRITORY/COLLATE，UTF-8 以 codeset=unicode 表达，9.5 语境）；
- **默认缓冲池与表空间落位**（ON path / WITH n BUFFERPOOLS / PREFERRED 容器指向）；
- 是否分区库（DPF 语境，[02](02-DB2全景大图.md)）。
【警】建库时的"基因级"参数（页大小/代码集）不可改，只能建新库迁移——本章最贵的教训。

### 4. 数据库自述：目录与清单（⚠️ 转述）
- 目录表视图 SYSCAT/SYSIBM（附录 D 主题，[07](07-数据库对象.md) 展开）；
- 本地清单：`LIST DATABASE DIRECTORY`（DB2 自己的"编目账本"）vs OS 文件系统的真实落盘位置——**目录≠清单**，DROP DATABASE 后清单残留是经典新手坑；
- 活动监控：`LIST ACTIVE DATABASES` / `GET CONNECTION` 快照。

### 5. 连接的姿势（与 06 章分界）
本章只讲"本地实例内连库"：`CONNECT demo USER u USING p`；跨机网络编目与驱动栈全部推给 [06](06-客户端服务器连接配置.md)。CONNECT/DISCONNECT/TERMINATE 三兄弟的语义差（会话/连接/进程级退出）是 CLP 脚本高频考点。

### 6. 生命周期收口（⚠️ 转述）
QUIESCE（静默）、ACTIVATE/DEACTIVATE（预挂/释放）、DROP DATABASE（不可逆）与 RESTORE 覆盖（[13](13-备份与恢复.md)）构成库的"生老病死"；删除前查清单、查活动连接的肌肉记忆本章养成。

## 🔧 E6 类比实验：一个会话挂多库（SQLite ATTACH，**非 DB2 行为**）

方法（本机 Python sqlite3 3.45.3，2026-10-01 实跑，脚本在 `D:\develops\tmp\dbwave_w7_db2vis\`）：建 cat.db/sales.db/hr.db 三文件库各灌 5000 行，内存库会话逐一 `ATTACH '…' AS cat/sales/hr`。
- 结果：跨附库联合查询行数 `[(5000,), (5000,)]` ✅；`PRAGMA database_list` 返回 main+cat+sales+hr 四目（编号 0/2/3/4，编号 1 被临时库占用）✅。
- 对位：一次"实例会话"内多数据库并存、按 schema 限定跨库引用 ≈ DB2 实例托管多库的形态直觉；**差异**：SQLite 的 ATTACH 是会话级临时编目，没有 DB2 的目录表/清单/别名体系（那在 [06](06-客户端服务器连接配置.md) 章）。

## 常见误区

1. "删库=删目录行"——清单与目录两本账都要清（CLEAN/RESET CATALOG 语境 ⚠️）。
2. "页大小选 32K 更省"——省页数但放大随机 IO 与缓冲池浪费，8K/16K 折中是经验值（⚠️ 转述；对照 [08](08-存储模型.md) E2 实验的 4K vs 16K 页数账）。
3. "实例名就是服务名"——端口/服务名/实例名三个词，编目用哪个各不相同（06 章）。

## 核心概念速览（中英对照）

1. **DB2INSTANCE** — 环境变量: 指向当前默认实例。
2. **profile** — 实例环境脚本: db2profile/db2cli 注入路径。
3. **注册表变量** — Registry Variable（db2set）: 安装/实例级旋钮。
4. **dbm cfg / db cfg** — DBM/DB Configuration: 实例与数据库两级参数抽屉。
5. **CREATE DATABASE** — 建库: 页大小/代码集/缓冲池数的基因决定。
6. **CODESET/TERRITORY/COLLATE** — 编码三兄弟: 代码集/地域/排序规则。
7. **数据库清单** — Database Directory: 客户端可连库的本地账本。
8. **数据库目录** — Catalog（SYSDB*）: 库内自描述元数据。
9. **别名** — Database Alias: 连接串的本地可换名。
10. **CONNECT/TERMINATE** — 连接语义三兄弟: 断连接/断会话/退进程。
11. **QUIESCE** — 静默: 独占式冻结对象做维护。
12. **ACTIVATE** — 预激活: 让库提前常驻实例。
13. **LIST ACTIVE DATABASES** — 活动库列表: 谁在实例里醒着。

## 最新演进与工业实践

- **参数面存续**：CREATE DATABASE 的编码/页大小基因逻辑在 Db2 11.5 不变（⚠️ 转述；官方文档入口 https://www.ibm.com/docs/en/db2 curl 200 ✅）；11.x 增加了更多自动存储/自动内存的默认，减少"基因焦虑"（分界见 9.7，⚠️）。
- **UTF-8 一统**：现代建库口径近乎默认 Unicode——2008 年"codeset 选择题"的权重今日大幅下降（与 [09](09-SQL的力量.md) 字符集讨论联动）。
- **多租户对照**：Db2 主机/云形态的分区服务、其它引擎的 CDB/PDB（Oracle）与 AG（SQL Server）提供了"实例⊃库"的当代演进样本 → [../Pro_Oracle_23ai_Administration/00-总览与阅读地图.md](../Pro_Oracle_23ai_Administration/00-总览与阅读地图.md)（盘上已验名）。
- **云托管语境**：Db2 on Cloud 里用户不再亲手 db2icrt——"实例"被平台吞掉，但本章的清单/别名/编码三课仍以新面目出现（⚠️ 平台细节不贴深链）。
- **实验复现**：E6 的 SQLite ATTACH 脚本可在 D:\develops\tmp\dbwave_w7_db2vis\ 复跑（repo 零构建产物纪律）。
