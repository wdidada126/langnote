## 核心精讲

### 1. DB2 是什么（⚠️ 转述）
DB2 是 IBM 的关系数据库管理系统家族：同一 SQL 引擎内核，按平台分成 **z/OS 主机版、LUW 版（Linux/UNIX/Windows）、iSeries 版**等大支系；本册只讲 LUW。9.5 LUW 的定位是"企业级 RDBMS + 混合数据管理"：关系数据与 XML 原生共库（pureXML，本目录 [10](10-pureXML.md) 展开）。

### 2. 为什么"视觉学习"值得单独说
关系引擎的很多概念（实例/表空间/缓冲池/锁）没有可视形态，初学者抽象失败率高。本书的解法：
1. **每个概念先给一张截图或框图，再给术语**——先建立"它长什么样"，再回答"它是什么"；
2. 章首固定"Big Picture"栏，先把本章放进整体地图；
3. 章末复习题用同一组图反复回指。
本目录无法复制原图，按规范以"图描述"文字块保留每张图的位置/构成/含义——这是本工程的视觉向硬义务。

### 3. DB2 产品家族与版本形态（⚠️ 9.5 口径转述）
- 按功能档位分 Express C/Personal/Workgroup/Enterprise 等版次；**名称与档位随版本漂移，勿背死**（后续版本曾合并/更名多次）。
- 部署形态三档：Complete（全功能，含创建实例能力）/ **Runtime Client**（只连不建的瘦客户端）/ Data Server（介于两者）——安装章 [03](03-安装DB2.md) 的主线就是这三档。
- 企业档选装 **DPF（Database Partitioning Feature）**：多分区无共享并行，是"全景大图"章的伏笔（[02](02-DB2全景大图.md)）。

### 5. SQL 的一点历史感
DB2 家族在 SQL 标准演进史上贡献异常大：CTE/递归查询、MERGE、GROUPING SETS 等扩展多由 IBM 先落地后入标准（出处与年代细节放 [09](09-SQL的力量.md) 讲，此处只留印象）。读本书时请记住：**你在 DB2 里学的不少"日常语法"，历史第一现场就在这条产品线**。

### 6. 新手误区三则（⚠️ 社区笔记汇总）
1. "DB2 就是主机数据库"——错，LUW 支系自 2001 年起就是独立生态，本册全程 LUW。
2. "学了 DB2 9.5 界面就能用 2026 年的"——错，GUI 控制中心已退役，命令行与监控视图换了代际（见各章演进节）。
3. "视觉书=浅"——本书 987 页起索引的体量说明它的纵深：02/08/14/15 四章是正经内幕入门，不是科普。

### 7. DB2 强制你记住的层次观（⚠️ 转述，后续各章逐层放大）
- **安装（Installation）**：二进制+许可，一台机器可有多套安装。
- **实例（Instance）**：运行实体，拥有自己的配置与端口，管理多个数据库。
- **数据库（Database）**：一组表空间+目录+日志的集合，有唯一编目名/别名。
- **表空间（Tablespace）**：逻辑存储容器，分 SMS/DMS 两类，落到一个或多个**容器（Container）**。
- **缓冲池（Bufferpool）**：与表空间页大小匹配（或 NO）的内存缓存池。
- **页（Page）**：IO 与分配的最小单位，4/8/16/32KB 建库/建空间时选定，事后不可改。
- **行/键（Row/Key）**：数据与索引的最小逻辑单位，XML 文档则是另一套对象行（[10](10-pureXML.md)）。

## 核心概念速览（中英对照）

1. **DB2** — DB2: IBM 的关系数据库管理系统家族，本册聚焦 LUW 支系。
2. **LUW** — Linux, UNIX, and Windows: DB2 的非主机平台支系名称。
3. **pureXML** — pureXML: DB2 9 引入的 XML 原生存储与查询技术（未拍平关系建模）。
4. **DPF** — Database Partitioning Feature: 多分区无共享并行选装件（企业档语境）。
5. **视觉学习法** — Learning Visually: 先截图/框图后术语的教学法，本书招牌。
6. **Big Picture** — Big Picture: 原书章首鸟览栏，"先全景再细节"。
7. **标识符折叠** — Identifier Folding: 未加引号标识符的大小写规范化（⚠️ 附录 B 口径）。
8. **版次档位** — Edition Tiers: Express/Personal/Workgroup/Enterprise 的功能分档。
9. **实例** — Instance: DB2 在操作系统上的运行实体（一安装可多实例，05 章展开）。
10. **编目** — Cataloging: 把远端节点/数据库登记进本地客户端元数据（06 章展开）。
11. **数据服务器/客户机** — Data Server / Runtime Client: DB2 部署形态的两端。
12. **9.5 "NestPool"** — Version 9.5: 本册覆盖版本，XML/存储/并发的更新集。
13. **System R 血统** — System R Heritage: DB2 与 IBM 关系模型研究原型的师承（09 章语源）。
14. **混合数据管理** — Mixed Data Management: 关系+XML 共库的产品叙事，9 代主打。

## 最新演进与工业实践

- **版本线走到哪**：LUW 现行主线为 **Db2 11.5**（含持续更新与 Db2 Warehouse 形态）；官方文档入口 https://www.ibm.com/docs/en/db2 （curl 200 ✅，2026-10 实测）；本书 9.5 术语多数存续，控制中心类 GUI 已退役（见 [04](04-DB2工具集.md) 演进节）。
- **XML 一脉的现状**：pureXML 仍是 Db2 LUW 存续特性，XQuery 与关系 SQL 混查的叙事未变（⚠️ 转述，入口 URL 同上）。
- **云形态**：IBM 以 Db2 on Cloud / Db2 Warehouse on Cloud 交付托管形态；"DB2=主机老古董"的刻板印象在 2024–2026 已不成立（⚠️ 二手口径，产品深链本环境未取证不贴）。
