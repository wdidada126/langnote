## 核心精讲

### 1. 进程群：谁在干活（⚠️ 转述）
db2sysc 实例总机；**协调 agent** 一对一服务连接（线程池模型/专用 agent 模型可切 ⚠️）；后台班各司其职：预取器喂页、页清道夫扫地（脏页刷盘）、锁管家（死锁检测）、监视与清理类；agent 数随负载起落（maxagents 旋钮 ⚠️）。图 2-B 的"请求旅行"每一站都能在这张合影上指认执行人——两图对读是本章程式。

### 2. 平台差与统一抽象（⚠️ 转述）
UNIX/LINUX：进程/轻量线程混编；Windows：单进程多线程；DPF：每分区一套进程群+跨分区通信件（FCM 语境，[02](02-DB2全景大图.md)）。DB2 用同一"角色词汇表"抹平差异——读文档先认角色、再查平台落地。

### 3. 外围进程（⚠️ 转述）
DAS（GUI 管理服务的后台）、cmdserver（JDBC Type 2 通路）、围栏进程（外伸隔离，03/11 章联动）、db2wdog/db2ckpt（看门狗与检查点，9.x 时代 ⚠️ 名称口径）——"实例活着"=总机+公务员+外围三者齐。

### 4. 实例级共享集（⚠️ 转述）
实例启动申请一大块共享内存"总集"（ICM 语境 ⚠️ 术语），内含：实例堆/锁列表/目录缓存/FCM 缓冲等**共享组**；OS 键/句柄管理；容量估算从"集"开始——这是"实例内存参数"与"数据库内存参数"两层口径的由来（与 [05](05-环境与实例数据库.md) 两级抽屉呼应）。

### 5. 共享组：公共场地（⚠️ 转述）
缓冲池（与 [08](08-存储模型.md) 的 BP 同物，此处看"内存里的大小与命中率"）、锁列表（12 章的水位线本体）、目录缓存（SYSCAT 读加速）、排序共享件（SHARED_SORT 语境 ⚠️ 版本分界）；各组大小=db cfg 旋钮×页大小的算术。

### 6. 私有堆家族（⚠️ 转述）
每 agent 的"随身背包"：应用堆（APPLHEAPSZ，结果缓冲/会话状态）、排序堆（SORTHEAP，溢出到临时表空间续命 ⚠️）、语句/包缓存份额、LOB/程序堆（⚠️ 细分名以版本为准）。**排序溢盘**是性能事故常客：SORTHEAP 太小→临时空间 IO 放大（15 章回收此线）。

### 7. 容量规划方法（本章工程观）
先算共享集（BP×数+锁+目录…）再乘代理峰值（APPLHEAPSZ+SORTHEAP+常数）；留出 OS/其他实例余量；"自动内存"（9.7+ SELF_TUNING ⚠️）出现后手工账仍是排障底账。原书用截图展示 Health Center 内存告警位——工具换代、算术不朽。

## 🔧 类比说明（本章无等价实验）
SQLite/DuckDB 是"无进程群"的嵌入式/单进程形态：其页缓存（page_cache）、连接对象与 DuckDB 线程池可对位"BP/agent"，但无实例共享集与锁管家等服务器构造——差异>相似，**不硬凑实验**（纪律声明同 [10](10-pureXML.md)）；相关通用机制笔记 → [../DuckDB_in_Action/00-总览与阅读地图.md](../DuckDB_in_Action/00-总览与阅读地图.md)（线程/缓冲语境）、[../The_Definitive_Guide_to_SQLite_2e/00-总览与阅读地图.md](../The_Definitive_Guide_to_SQLite_2e/00-总览与阅读地图.md)（page cache/mmap）。

## 常见误区

1. "一个连接=一个进程"（UNIX 语境尤其）——现代以线程/线程池为主，看平台与配置。
2. "缓冲池越大越好"——私有堆与 OS 被挤的账单在高峰才爆（精讲 7）。
3. "内存参数都在 db cfg"——实例集/注册表/两级参数混编，先分抽屉（[05](05-环境与实例数据库.md)）。
4. "排序溢盘=配置错"——也可能是计划错（统计过期，12 章 E1 教训）。

## 核心概念速览（中英对照）

1. **db2sysc** — 实例总机: 常驻核心进程。
2. **协调 agent** — Coordination Agent: 代表连接的执事（线程/进程随平台）。
3. **预取器** — Prefetcher: 异步喂页的后台角色。
4. **页清道夫** — Page Cleaner: 异步扫地（脏页刷盘）。
5. **锁管理器** — Lock Manager: 锁列表管家+死锁检测。
6. **DAS/cmdserver** — 管理服务/JDBC 服务: 外围进程双常见。
7. **围栏进程** — Fenced Process: 外伸执行隔离（03/11 联动）。
8. **实例共享集** — Instance Shared Memory: 一实例一大集的总账。
9. **共享组** — Shared Set 成员: 缓冲池/锁列表/目录缓存等。
10. **私有堆** — Private Heaps: 每 agent 随身背包（APPLHEAPSZ/SORTHEAP）。
11. **排序溢盘** — Sort Overflow: 堆不够临时空间凑。
12. **目录缓存** — Catalog Cache: 元数据热区。
13. **FCM** — Federation/分区间通信缓冲（DPF 语境 ⚠️）。
14. **自调内存** — Self-Tuning Memory: 9.7+ 的自动档（版本分界）。
