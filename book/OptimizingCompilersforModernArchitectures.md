# Optimizing Compilers for Modern Architectures

## 版本与 ISBN

- 原书名：*Optimizing Compilers for Modern Architectures: A Dependence-based Approach*
- 作者：Randy Allen、Ken Kennedy（Rice 大学）
- 英文原版：Morgan Kaufmann，2001-10，ISBN `978-1-55860-286-1`（816 页）
- 中文版：《现代体系结构的优化编译器》，机械工业出版社（计算机科学丛书），ISBN `978-7-111-14122-8`（张兆庆、乔如良、冯晓兵等译）

> 2026-09-22 由 202609 月度笔记（编译器优化书单）整理。

## 笔记

- 编译器优化的权威参考，中科大等课程直接采用；核心工具是数据依赖（data dependence）分析。
- 覆盖：依赖分析、并行化、向量化、存储层次（cache）管理、指令调度等变换。
- 面向高性能计算（HPC）体系结构，Fortran 示例为主，但理论适用于 C 等多语言。
