## 四、基线对位总表（书中 3.6.x 世界 → 2026 现状 3.53.x；锚点均 ✅ changes.html/官方页原句，另注明者除外）

| 2010 设定 | 2026 现状 | 引入版本 |
| --- | --- | --- |
| 回滚日志是唯一并发物理层 | WAL：读写并发、自动 checkpoint 1000 页 | **3.7.0**（2010-07-21，与本书出版同年） |
| 备份=关库拷贝/ATTACH 花活 | 在线热备接口 `sqlite3_backup_*`（Python `Connection.backup` 🔧） | **3.6.11** "Added the hot-backup interface" |
| 无 UPSERT：OR REPLACE 仪式 | `ON CONFLICT DO UPDATE/NOTHING` | **3.24.0**（2018-06-04，lang_upsert.html 史栏） |
| DML 后二查取值 | RETURNING | **3.35.0** |
| 排名/累计手工活 | 窗口函数 | **3.25.0** |
| 无 CTE | 递归/普通 CTE | 3.8.3 ⚠️（通识，changelog 未直词） |
| ALTER 两动作 | RENAME/DROP COLUMN 等 | 3.25.0/3.35.0 ✅ 原句 |
| 宽松类型唯一态 | STRICT 表 / 生成列 | 3.37.0 / 3.31.0 ✅ 原句 |
| 无 JSON | JSON 内置（opt-in→opt-out） | 3.38.0 ✅ json1.html 原句 |
| FTS3 新玩具 | FTS4→FTS5 内置（🔧 module_list） | FTS5 **3.9.0** ✅ 原句；FTS4 3.7.x ✅ first-mention |
| 数学函数无 | `pow()/log()` 族（CPython 发行已开 🔧 E4） | 3.35.0 ✅（需编译旗标原句） |
| busy_timeout 手调 | `PRAGMA busy_timeout` 通用；unlock_notify 死锁解药（3.6.11 ✅ first-mention，与书同期） | — |
| 视图只读+INSTEAD OF | 仍只读+INSTEAD OF（🔧 E3）——**十年未变**的对照组 | — |
| UPDATE 无 LIMIT | 仍无（🔧 E3 报错复现）——方言坑未变 | — |
| REGEXP 无实现 | 仍需自注册 UDF（🔧 E7）——第二组"未变" | — |
| 3.5x 增量（2024–2026） | GEOPOLY/优化器连进、WASM 64-bit、`.mode` 翻新；stable=**3.53.4（2026-07-24）** | changes.html ✅ |
