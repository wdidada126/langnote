# 08 · Language Extensions（语言绑定）

> 原书第 8 章（Crossref 章题 ✅：`..._8` "Language Extensions"）。该章覆盖 PHP/Python/Perl/TCL/
> C#/Java 等绑定的时代群像（具体语言小节顺序 ⚠️ 推定）；本文件把 PHP 侧按 2010 语境转述、
> Python 侧全量实测。
> 🔧 环境：Python 3.13.2 内置 sqlite3 模块（pysqlite 血统，DB-API 2.0）。

## 1. 本章在 2010 年的语境

2010 年的绑定世界：PHP 的 sqlite3 扩展与 PDO_SQLITE 并存（书里两条线都给例）、Python 的
pysqlite 刚并入标准库不久（3.x 内置 ✅ 通识）、Ruby 的 sqlite3 gem、.NET 的 System.Data.SQLite
（Provider 形态）、Java 靠 JDBC 驱动第三方。书中反复处理三类"翻译损耗"：

1. **句柄与资源生命周期**：DB-API 游标 vs C stmt；连接不 close 导致锁滞留（🔧 E6 的 idle 事务
   即其孪生）。
2. **类型系统落差**：SQLite 动态存储类 ↔ 语言静态类型；PHP 里全变 string、Python 靠 adapter/
   converter 表（本章实测主角）。
3. **事务语义方言**：C 层 autocommit 与 DB-API "isolation_level" 的妥协史——pysqlite 自创的
   隐式 BEGIN 从此背了十几年包袱（🔧 E8 两代 API 并存现场）。

## 2. 精读要点（重构）

- **PHP 线 2010 的抉择**：类风格 `SQLite3` 扩展 vs PDO 抽象；书中倾向 PDO 以保多库可移植
  （⚠️ 倾向判断按书谱系推定）。今天 PHP 绑定仍在但存在感萎缩，SQLite 的 Web 面移交
  WASM/浏览器存储叙事（⚠️ 趋势）。
- **Python converter 协议**：`detect_types=PARSE_DECLTYPES` 按**声明类型子串**匹配回读
  （'TIMESTAMP'→datetime），不声明就是 str（🔧 E8 三态对照）。
- **文本工厂/字节观**：`text_factory` 决定 TEXT 回读 str/bytes——嵌入式本地化场景的老坑。
- URI 文件名（`file:...?mode=ro&cache=shared`）由 `sqlite3_open_v2` 血统而来，绑定层暴露后
  "只读连接"第一次成为零代码事务纪律（🔧 E8 实锤拒写）。

## 3. 🔧 实测（E8）：2026 Python 绑定的三代同堂

| 观察 | 数字/结果 |
| --- | --- |
| datetime 写入后的存储真相 | `typeof` 均为 **text**；值 `'2026-09-27 08:30:00'`/`'2026-01-01'`（默认 adapter 转 ISO 文本 ✅） |
| 默认回读 | `str`（converter 未开）——**写 datetime 读 string 的往返破口** |
| `detect_types=PARSE_DECLTYPES` 回读 | `datetime.datetime(2026, 9, 27, 8, 30)` ✅；该机制 3.12 起标 **deprecated**（FutureWarning 面 ⚠️ 本实验未截获告警，按文档口径标注） |
| `row_factory=sqlite3.Row` | `row["t"]` 键式取列 + 位置式兼容 ✅ |
| URI 只读 | `file:...?mode=ro` + `uri=True`：INSERT → `attempt to write a readonly database` ✅ |
| 新事务 API | `Connection.autocommit` 属性存在=True；设 `autocommit=True` 后 `in_transaction=False` ✅（3.12+ 的 PEP 式正名） |
| 旧事务 API | 默认 `isolation_level=''`（legacy 隐式 BEGIN 仍是出厂默认！）✅——迁移者必须显式二选一 |

## 5. 常见误区

1. 以为 `execute` 返回对象=连接状态：游标即语句影子，多语句要 `executescript`（🔧 04 章
   E4 首跑就踩：单 execute 多语句 `ProgrammingError: You can only execute one statement at a time`）。
2. 依赖 datetime 自动往返：`typeof=text` 决定了跨语言互读是字符串协议（🔧 E8）；2026 写法
   是显式 ISO 或 epoch 整数。
3. 忘 `commit`/不关游标 → 持 SHARED 卡别人提交（🔧 E6 两次失败实录——绑定层把 C 的锁协议
   藏起来，事故原样继承）。
4. 把 DB-API paramstyle（qmark/named）当 SQL 可移植性：占位符方言表（`?`/`:name`/$1/@1）
   书中那张矩阵在 2026 仍逐字可用。

## 8. 2010→2026 绑定迁移清单（给抱着旧代码的人）

1. 事务：`isolation_level=None` + 手写 BEGIN/COMMIT（或直接 `autocommit=True`）——别再信默认 `''`（🔧）。
2. 时间：删掉 datetime adapter 依赖，边界统一 ISO 字符串/epoch 整数（🔧 E8 text 真相）。
3. 取回值：`INSERT...RETURNING`（3.35+）替代 lastrowid 二段舞（🔧 E4）。
4. upsert：`ON CONFLICT DO UPDATE` 替代 OR REPLACE（🔧 E4 rowid 分叉）。
5. 错误处理：按 `sqlite_errorname` 枚举分支（3.11+ 🔧），字符串匹配全清退。
6. 备份：文件拷贝一律改 `Connection.backup`（E6）；WAL 场景无此不可（05 章）。
7. PHP 线（若维护旧库）：sqlite3 扩展与 PDO 双轨仍在 ⚠️，参数风格 `?` 与 SQLite 原生一致。
8. 线程：`check_same_thread=False` 只是放行，锁纪律仍归你（🔧 E6 线程炸点实录）。

## 9. 本章自检卡（一问一答）

1. Q：写 datetime 读出来是什么？ A：默认 str（🔧 typeof=text）。
2. Q：PARSE_DECLTYPES 的匹配规则？ A：声明类型**子串**命中 converter（列名后缀也参与 ⚠️ 文档向）。
3. Q：Row 比 tuple 多花什么？ A：列名映射便利，少量开销（⚠️ 未测性能）。
4. Q：URI 连接前缀何时必须？ A：`uri=True` 时 file: 协议生效（🔧 mode=ro 拒写）。
5. Q：autocommit=True 与 isolation_level=None 区别？ A：殊途同归 C 语义；前者是 3.12+ 正门。
6. Q：executescript 的提交副作用？ A：先 COMMIT 再逐句跑（旧版隐含 ⚠️）。
7. Q：游标忘关会怎样？ A：可能持锁卡全库提交（🔧 E6 教训）。
8. Q：qmark 与 named 能混用吗？ A：一次调用一种风格。
9. Q：备份能跨不同 SQLite 版本吗？ A：能（页级复制 + format 4 兼容 🔧 E1 DEFAULT_FILE_FORMAT=4）。
10. Q：绑定层能修引擎缺陷吗？ A：不能——参数风格/类型落差只是翻译，锁与崩溃语义原样继承。

## 核心概念速览（中英对照）

- **DB-API 2.0** — Python 数据库接口规范：connect/cursor/execute/commit 五件套。
- **adapter/converter** — 类型桥：写入转储、按声明类型回读（🔧 text 真相；3.12 弃用向 ⚠️）。
- **PARSE_DECLTYPES** — 声明类型探测旗标（🔧 datetime 复活开关）。
- **Row 工厂** — row_factory=sqlite3.Row：列名双模访问（🔧）。
- **legacy 隐式事务** — isolation_level=''：DML 前偷发 BEGIN 的历史包袱（🔧 默认仍在）。
- **autocommit 属性** — 3.12+ 新事务控制面（🔧 True/False/三态）。
- **URI 连接** — file:..?mode=ro：绑定透传的只读纪律（🔧 拒写实锤）。
- **paramstyle 矩阵** — qmark/named 等占位符方言表。
- **PDO_SQLITE** — 2010 PHP 线主角（⚠️ 转述）。
- **text_factory** — 字节/文本边界旋钮。
- **游标=语句影子** — cursor 生命周期映射 stmt finalize。
- **backup 直通** — 绑定层暴露在线备份（🔧 E6 0.125 s 12 KB）。
- **锁滞留** — 未关游标/未提交 = 隐形 SHARED（跨 02/06 章复现）。
- **薄封装变厚** — 绑定层十年演化：从 API 翻译到安全/备份/钩子的门面。

## 最新演进与工业实践

- Python 侧 2024–2026 的主线就是"两代事务 API 并跑"（🔧 E8 同框）：新代码建议
  `autocommit=None/True` 显式三态 + 手工 BEGIN；`detect_types` 路线则倒计时弃用 ⚠️。
- 生态位变化：应用层流行"不裸写绑定"——SQLAlchemy/Prisma/Drizzle/ORM 把 SQLite 当本地库，
  而**性能敏感路径回落到原生绑定 + 手工事务**正是本书当年教的姿势（⚠️ 趋势转述）。
- PHP/Perl/TCL 绑定维护中但示例价值 > 使用价值；本文件保留 2010 群像的动机是：绑定层的
  类型/事务/锁三大落差是**引擎无关**的迁移课程，换任何引擎都重演。
