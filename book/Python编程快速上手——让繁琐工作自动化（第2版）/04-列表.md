## 核心精讲

教学示意，不参与构建：

```python
a = [1, 2, 3]
b = a            # 共享同一对象
b[0] = 99
print(a[0])      # 99  （a 也被改）
c = a[:]         # 浅拷贝
c[0] = 0
print(a[0])      # 99  （a 不变）
```
