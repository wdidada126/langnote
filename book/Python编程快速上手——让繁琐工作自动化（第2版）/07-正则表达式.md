## 核心精讲

教学示意，不参与构建：

```python
import re
phone = re.compile(r"(\d{3})-(\d{3}-\d{4})")
m = phone.search("Call 415-555-1234 now")
if m:
    print(m.group(1), m.group(2))      # 415 555-1234

emails = re.findall(r"[\w.]+@[\w.]+", "a@x.com b@y.org")
print(emails)                           # ['a@x.com', 'b@y.org']
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 不用原始串 `r""` | 转义地狱 | 正则一律 `r"..."` |
| 贪婪匹配误判 | 默认贪婪 | 用 `*?` 非贪婪 |
| 复杂解析用正则 | 易错（如 HTML） | 用专用解析器（bs4/lxml） |
