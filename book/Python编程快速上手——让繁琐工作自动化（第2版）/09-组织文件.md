## 核心精讲

教学示意，不参与构建：

```python
import shutil
from pathlib import Path

shutil.copy("a.txt", "b.txt")
for f in Path(".").rglob("*.py"):          # 递归匹配
    print(f)

import zipfile
with zipfile.ZipFile("a.zip") as z:
    z.extractall("out")
```

## 版本演进

- 3.4 `pathlib` 提供 `rglob`/`glob` 替代 `os.walk`；3.5 `Path` 更完整。

## 近年研究与工业界开源实践（2015–2026）

- 危险批量操作前先 `shutil.copytree` 备份；用 `send2trash` 进回收站而非硬删。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| os.walk | 繁琐 | Path.rglob |
| 直接 os.unlink 批量 | 误删不可逆 | send2trash + 先备份 |
