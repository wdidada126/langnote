> 表达式、值、变量、数据类型入门。基线：原书 Python 3.8；本目录按 3.12+ 校验。

## 核心精讲

教学示意，不参与构建：

```python
>>> 2 + 2
4
>>> type("hi")
<class 'str'>
>>> spam = 42
>>> f"spam = {spam}"
'spam = 42'
>>> "ha" * 3
'hahaha'
```
