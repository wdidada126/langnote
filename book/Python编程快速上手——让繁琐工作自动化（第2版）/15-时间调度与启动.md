> `time`/`datetime`、定时、`subprocess` 启程序。基线：原书 Python 3.8；本目录按 3.12+ 校验。

| 小节 | 内容 | 结论 |

## 核心精讲

教学示意，不参与构建：

```python
import time, datetime, subprocess
start = time.time()
print(datetime.datetime.now().strftime("%Y-%m-%d %H:%M"))
print(datetime.date(2026, 1, 1) + datetime.timedelta(days=30))
subprocess.run(["ls", "-l"], check=True)    # 优于 os.system
```

## 近年研究与工业界开源实践（2015–2026）

- 生产定时用 cron/systemd timer/云 Scheduler，而非脚本内轮询。
- 时区一律 `zoneinfo`，勿手算偏移。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| os.system | 注入风险 | subprocess.run |
| 手写时区 | 错 | zoneinfo |
| 脚本内死循环 | 不稳 | 系统调度 |
