## 核心精讲

教学示意，不参与构建：

```python
def say_hi(name="there"):
    return f"Hi {name}"

def total(*nums):                 # 收集为元组
    return sum(nums)

print(say_hi("Bob"))              # Hi Bob
print(total(1, 2, 3))             # 6
```
