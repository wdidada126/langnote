## 核心精讲

教学示意，不参与构建（需 `pip install httpx beautifulsoup4`，遵守 robots.txt）：

```python
import httpx
from bs4 import BeautifulSoup

r = httpx.get("https://example.com", timeout=10, follow_redirects=True)
r.raise_for_status()
soup = BeautifulSoup(r.text, "html.parser")
for a in soup.select("a[href]"):
    print(a["href"])
```
