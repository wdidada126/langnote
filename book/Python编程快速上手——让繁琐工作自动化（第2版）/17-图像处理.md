## 核心精讲

教学示意，不参与构建（需 `pip install pillow`）：

```python
from PIL import Image, ImageDraw
img = Image.open("cat.png").convert("RGB")
small = img.resize((128, 128))
small.save("cat_small.png")

watermark = Image.open("wm.png")
img.paste(watermark, (10, 10), watermark)
img.save("cat_wm.png")
```
