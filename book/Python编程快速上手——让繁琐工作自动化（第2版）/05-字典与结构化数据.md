## 核心精讲

教学示意，不参与构建：

```python
inventory = {'apple': 3, 'pear': 5}
inventory['banana'] = 2
for k, v in inventory.items():
    print(k, v)
merged = inventory | {'peach': 1}   # PEP 584, 3.9+
```
