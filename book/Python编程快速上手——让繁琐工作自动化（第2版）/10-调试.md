## 核心精讲

教学示意，不参与构建：

```python
import logging
logging.basicConfig(level=logging.DEBUG,
                    filename="app.log",
                    format="%(asctime)s %(levelname)s %(message)s")
logging.debug("start")

def avg(nums):
    assert len(nums) > 0, "empty list"
    return sum(nums) / len(nums)
```
