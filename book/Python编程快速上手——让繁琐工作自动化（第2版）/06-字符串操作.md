## 核心精讲

教学示意，不参与构建：

```python
s = "  hello world  "
print(s.strip())                 # "hello world"
print(", ".join(["a", "b"]))     # "a, b"
print("a-b-c".split("-"))        # ['a','b','c']
print(f"{3.14159:.2f}")          # "3.14"
print(f"{name=}")                # 3.8+ debug 语法
```
