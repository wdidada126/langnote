## 核心精讲

教学示意，不参与构建：

```python
from pathlib import Path
p = Path("data.txt")
p.write_text("hello\n", encoding="utf-8")     # 现代写法
text = p.read_text(encoding="utf-8")
for line in p.open(encoding="utf-8"):         # 迭代器
    print(line.rstrip())
```

## 近年研究与工业界开源实践（2015–2026）

- `pathlib` 全套；配置用 TOML（3.11 `tomllib`）/JSON。
- `shelve`/`pickle` 反序列化有 RCE 风险，勿加载不可信数据。
