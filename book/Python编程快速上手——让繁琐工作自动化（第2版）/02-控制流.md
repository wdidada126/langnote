# 第 2 章 控制流（原书 pp.约31–约60）

> `if`/`while`/`for` + `break`/`continue` 控制程序走向。基线：原书 Python 3.8；本目录按 3.12+ 校验。

## 本章地图

| 小节 | 内容 | 结论 |
|---|---|---|
| 2.1 条件 | 比较/布尔/and/or/not | `and`/`or` 短路 |
| 2.2 代码块 | 缩进 | 一律 4 空格 |
| 2.3 if/elif/else | 分支 | 只进首个真分支 |
| 2.4 while | 条件循环 | 防死循环 |
| 2.5 for + range | 计数循环 | 左闭右开 |
| 2.6 break/continue | 控制跳转 | 少用，重写条件更清晰 |
| 2.7 import | 导模块 | 见 03 |

## 核心精讲

教学示意，不参与构建：

```python
name = input("name: ")
if name == "Alice":
    print("Hi Alice")
elif name == "":
    print("empty")
else:
    print("who?")

for i in range(5):
    if i == 3:
        continue
    print(i)
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| `if x == True` | 冗余 | `if x:` |
| `is` 比相等 | 仅 None/单例 | `is None` |
| while 搬运列表 | 慢 | 推导式/切片 |
