## 阅读顺序建议

- **主线 A（按书读）**：01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12。
  作者的组织逻辑是「先立理论边界与选型语言（1–2）→ 再逐个讲十种协议与算法（3–12）→ 最后用三个案例把它们穿起来（13–15）」。
- **主线 B（按问题读）**：
  - 「怎么在多个副本间达成一致」：02 → 03 → 05（Paxos / Raft / ZAB 三选一对照）；
  - 「怎么做分布式事务」：08 → [01](01-拜占庭将军问题与CAP-ACID-BASE.md) 的 ACID 段；
  - 「怎么做最终一致与弹性读写」：06 → 07 → 11；
  - 「怎么落地一个 Raft 系统」：03 → 12 → 11。
- **对照读**：本书是**实战科普口径**，理论边界（FLP、不可能三角的形式化）几乎不谈；
  想要严格化的读者建议把 [../分布式算法/03-FLP与不可能性.md](../分布式算法/03-FLP与不可能性.md) 与本目录 02/03 一起读。
