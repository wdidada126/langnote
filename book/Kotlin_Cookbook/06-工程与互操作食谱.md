## 问题清单（6 问）

1. Java 要用 Kotlin 默认参数：@JvmOverloads 管什么？
2. Java 看到 `FooKt`/`getFoo()`：类名与 JavaBean 表面怎么修整？
3. 平台类型：@Nullable/@NotNull 真能改变 Kotlin 编译判定吗？
4. value class 在 JVM 上 mangling：Java 签名长什么样、怎么喂 Java？
5. Gradle：jvmToolchain/freeCompilerArgs（-Xjsr305=strict 等）关键开关位？
6. 测试：JUnit5 与 kotlin.test 双轨怎么选，data class 断言怎么写？

## R1 · 默认参数的 Java 视图
`[✅ | ⚠️ 归属推定 | 🔧]`
```kotlin
class Search @JvmOverloads constructor(val q: String, val page: Int = 1, val size: Int = 20)
// Java: new Search("kotlin"); new Search("kotlin", 2); ——无 @JvmOverloads 只见全参 ✅
```
呼应 [01](01-基础与字符串集合.md) R1"缺省在调用侧展开"：默认值不生成重载 ✅，@JvmOverloads 才是 Java 可见补救（函数位同理）。

## R2 · JavaBean 表面与文件类名
`[✅ | ⚠️ | 🔧]`
```kotlin
@file:JvmName("Searches")      // Java 见 Searches 而非 SearchesKt ✅
class User(val name: String)   // Java 见 getName()：属性↔JavaBean 映射 ✅
// @JvmField 去访问器直出字段（与反射式序列化框架打交道位）✅
```
[02](02-面向对象与data-value类选型.md) R6 三件套（@JvmStatic/@JvmField/@JvmName）落到工程面；Gson/Jackson"字段不见/序列化失配"是高频坑 ⚠️（书中 recipe 待证）。

## R3 · 平台类型与空性注解
`[✅ | ⚠️ | 🔧]`
```kotlin
val g: String? = javaObj.greet()   // 无注解 → String! 平台类型：编译放行、运行 NPE ✅
// @NotNull（jetbrains-annotations）或 -Xjsr305=strict → 编译器收紧为 T/T? ✅（jspecify 迁移中 ⚠️）
```
注解→Kotlin 类型映射总表归 KiA2e 互操作章（主教材 ✅ 00 档第三节）；与 [01](01-基础与字符串集合.md) R4"is MutableList 区分不了"同源——运行期无语法，边界靠约定 ⚠️。

## R4 · value class 的 JVM 签名
`[✅ | ⚠️ | 🔧]`
```kotlin
@JvmInline value class Password(val raw: String)
fun login(p: Password) {}      // Java 见 mangled 名（login-<后缀>形态 ✅ 逐字 🔧）
// Password? 可空/泛型位 → 回退装箱 ✅；Java 侧直接消费基本不可行 ⚠️
```
[02](02-面向对象与data-value类选型.md) R4"零装箱"的代价在互操作面兑现：Kotlin 侧包一层普通 API 再给 Java 消费 ⚠️。

## R5 · Gradle 与编译开关
`[⚠️ 重灾区 | 🔧]`
```kotlin
// build.gradle.kts：plugins { kotlin("jvm") version … }——版本不写死 ⚠️
kotlin { jvmToolchain(17) }    // toolchain 官方推荐位 ✅（细节以版本为准 ⚠️）
// -Xjsr305=strict 影响 R3；-Xjvm-default 影响接口默认方法形态 ✅
```
Maven 线 `src/main/kotlin` 约定、KSP vs kapt 清单均不写死 ⚠️；书中提不提 Maven 未证（"Kousen 培训线惯用 Gradle"系转称 ⚠️）。

## R6 · 测试位
`[✅ | ⚠️ | 🔧]`
```kotlin
@Test fun `data class 按字段相等`() {                // 反引号名 ✅（JVM 允许，细节 🔧）
    assertEquals(User("a", "a@x"), User("a", "a@x"))  // equals 由 data 生成 ✅
    assertIterableEquals(listOf(1, 2), listOf(1, 2))  // kotlin.test 断言族 ✅
}
// suspend 测试去 [05](05-协程食谱.md) R6；kotest/mockk 生态位不写死 ⚠️
```
kotlin.test 是多平台子集：JVM-only 项目直用 JUnit5 少一层间接 ⚠️ 工程口诀（非书中引文）。

## 核心概念中英对照

| 中文 | 英文 | 一句话 |
