# 《Kotlin Cookbook》——总览与阅读地图

> 目标书：*Kotlin Cookbook*，Ken Kousen，O'Reilly，2022（⚠️ ISBN 凭记忆不写死）。
> 用户粘贴的第三方结论评 ★★★★（工程实践/问题解决方案）。

## 一、定位

Recipe 体（Problem/Solution/Discussion）：按主题查，不线性读。Kousen 是 Java 培训线作者（Effective Java 生态常客 ⚠️ 说法待证），故本书**天然带 Java 对照视角**——对画像读者比 Head First 线有用，与 Effective Kotlin 功能重叠区做仲裁：条目规范从 Effective，即查即用食谱从本书。

## 二、骨架（⚠️ 章节名以版权页为准）

| 章带 | 覆盖 | 高价值 Recipe 方向 |
|---|---|---|
| 基础 | 字符串/集合/控制流 | 解构、when 穷尽惯用法 |
| OOP | 类/接口/委托 | data vs value class 选型 |
| 函数与 Lambdas | 高阶/内联/局部 | 内联值语义 Recipe |
| 泛型 | 方差/通配符对照 | `in/out` ↔ Java `? super/? extends` 速查 |
| 空安全/异常 | platform types、Result | 互操作空判定坑 |
| IO/序列化/并发 | File、协程、并行流对照 | 协程 Recipe 以官方文档复核 ⚠️ |
| JVM 生态 | 与 Java/Maven/Gradle 混编 | 互操作配置速查（衔接 Spring 线） |

## 三、🔧 实测口径

按 Recipe 编号落可跑单文件（kotlinc main+断言），与 Effective_Kotlin 反例形成正反两套；互操作 Recipe 双语言工程（javac+kotlinc 混编顺序验证）。
