## R1 · 最小可跑形态
`[✅ | ⚠️ 归属推定 | 🔧]`
```kotlin
fun main() = runBlocking {                    // main→协程桥，教学入口 ✅（生产勿滥用 ⚠️）
    val job = launch(Dispatchers.Default) { println("in ${Thread.currentThread().name}") }
    job.join()                                // 不 join 则 main 退出、后台协程被取消 ✅
}
```
微实验口径沿用 KiA2e 00 档第五节：runBlocking+delay+线程名打印验证 Dispatcher 语义 🔧。

## R2 · Dispatcher 选型
`[✅ | ⚠️ | 🔧]`
- CPU 密集 → `Dispatchers.Default`；阻塞 IO → `Dispatchers.IO`（弹性池）；UI → `Dispatchers.Main`（仅 Android/Swing，纯 JVM 无 ✅）。
- 挂起函数内"跳池"唯一正解 `withContext(Dispatchers.IO) { jdbc.query() }` ✅；`Unconfined` 是坑位（栈溢出+上下文错位），至多以反例面目出现 ⚠️。

## R3 · 结构化并发
`[✅ | ⚠️ | 🔧]`
```kotlin
coroutineScope {                            // 父等全部子，返回即无孤儿 ✅
    val a = async { fetchA() }
    supervisorScope { launch { tickA() } }  // 子失败不连坐兄弟 ✅
    a.await()
}
```
GlobalScope=脱管泄漏（不属任何 scope、取消不传播、测试不可控）✅ 官方立场；两制（默认连坐 vs supervisor）裁决细节从 KiA2e Structured Concurrency 主线 ⚠️。

## R4 · 回调转 suspend
`[✅ | ⚠️ | 🔧]`
```kotlin
suspend fun awaitOnce(conn: Connection): Message = suspendCancellableCoroutine { cont ->
    val reg = conn.addListener { m -> cont.resume(m) }
    cont.invokeOnCancellation { conn.removeListener(reg) }  // 取消路径必清 ✅
}
```
现成桥：CompletableFuture `.await()`（kotlinx-coroutines-jdk8 ⚠️ 模块名不写死）；单向门：挂起函数对 Java 不可见 → 补救去 [06](06-工程与互操作食谱.md)。

## R5 · Flow 三件事
`[✅ | ⚠️ 归属存疑 | 🔧]`
```kotlin
fun ticks(): Flow<Int> = flow { repeat(10) { emit(it); delay(100) } }  // 冷：collect 才 emit ✅
    .flowOn(Dispatchers.Default)              // 只切上游 ✅
ticks().buffer(8).collect { render(it) }      // 背压算子族 buffer/conflate ⚠️
```
Flow=suspend+拉取语义，不是 Reactive Streams；与 Rx 互转和取消清单归 KiA2e Flow 主线，本档不越位 ⚠️。

## R6 · 测试与虚拟时间
`[✅ kotlinx-coroutines-test | ⚠️ | 🔧]`
```kotlin
@Test fun `delay 不真等`() = runTest {        // 1.6+ 位 ✅（旧 runBlockingTest 弃用 ⚠️）
    val d = async { delay(1_000); "done" }
    assertEquals(1_000L, currentTime); assertEquals("done", d.await())  // 虚拟快进不睡觉 ✅
}
```
`Standard/UnconfinedTestDispatcher` 选择清单版本漂移大 ⚠️ 以官方 test 文档为准；测试工程位与 [06](06-工程与互操作食谱.md) R6 合流。

## 核心概念中英对照

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 挂起函数 | suspend function | 挂起不占线程，调度器接续 |
| 结构化并发 | structured concurrency | scope=Job 树生命周期，无孤儿 |
| 监督策略 | supervision | 子失败不连坐兄弟 |
| 协作式取消 | cooperative cancellation | Job 传播+检查点，非抢占 |
| 回调桥 | suspendCancellableCoroutine | 老 listener API 一次性包装 |
| 冷流 | cold flow (Flow) | collect 才产出；flowOn 切上游 |
| 虚拟时间 | virtual time | runTest 快进 delay |
