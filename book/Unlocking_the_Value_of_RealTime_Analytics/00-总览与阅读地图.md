## 2. 取证链声明（逐条标注）

本波取证网络环境受限（Google Books / OpenLibrary / Wayback / libgen / DuckDuckGo 均不可达，
oreilly.com 与 Amazon 仅 HEAD 可达）。实际动用的源与结果：

1. ✅ **封面 CDN 图像目读**（covers.oreilly.com/images/9781098134464/cat.gif，HTTP 200）：
   确认主/副标题、作者署名、O'Reilly REPORT 体裁角标。这是本书身份裁定的**决定性证据**。
2. ✅ **官方书页 HEAD 200**：URL 存在性确认；GET 403（Akamai），页面正文/目录/出版日期未获取。
3. ✅ **Crossref ISBN 过滤**（api.crossref.org/works?filter=isbn:9781098134464）：**0 条**——
   与波6/波7先例一致，O'Reilly 不向 Crossref 寄存 ISBN，负结果符合预期，不作否证。
4. ✅ **豆瓣 ISBN 页 404**：无中译记录（登记入波尾义务④中译反查结论：零命中）。
5. ⚠️ **Amazon**：/dp/9781098134464 与 /dp/1098134460 均 404/503，无书目记录（O'Reilly REPORT
   多为电子书专售，纸质 ASIN 常缺，不能据此否证存在性）。
6. ⚠️ **出版年**：仅能按 9781098134 号段（O'Reilly 2023 起启用）与名册"2023/24 短册?"上下文
   推定为 **2023–2024 区间**，精确到月不可得 → 全文一律写 ⚠️ 2023–2024。
7. ⚠️ **原书目录（TOC）**：官方页 GET 403、无公开样章镜像命中 → **原书章节标题不可实证**。
   本目录章结构为**精读重构**（依据：副题"架构实时数据基础设施"的叙事承诺、O'Reilly REPORT
   体裁惯例、RTA 主题域公开文献三角互证），逐章标 ⚠️ 推定。

## 6. 🔧 实测环境与五组实验总表

- 环境：Windows + Python（内置 sqlite3 库 3.45.3）+ DuckDB Python 1.5.5；脚本与输出存
  `D:\develops\tmp\dbwave_w8_uvrta\`（exps.py / e45.py），repo 零构建产物。
- **声明：SQLite/DuckDB 仅为"数据新鲜度/决策延迟"概念的类比实验床，非本书讨论的商业
  RTA 平台（如流式 OLAP/云仓）行为**；本书平台侧结论一律转述 + ⚠️。

| 组 | 实验 | 关键读数 | 所在章 |
