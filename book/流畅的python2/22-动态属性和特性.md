# 第 22 章 动态属性和特性（原书 pp.641–670）

## 核心精讲

### 22.2 `__getattr__`：动态访问 JSON 风格数据

```python
# 教学示意，不参与构建
class FrozenJSON:
    def __init__(self, mapping):
        self.__data = dict(mapping)
    def __getattr__(self, name):
        if hasattr(self.__data, name):
            return getattr(self.__data, name)
        return FrozenJSON.build(self.__data[name])   # 仅当属性缺失时触发
    @classmethod
    def build(cls, obj):
        return FrozenJSON(obj)

# fj.name 等价于 fj["name"]；不存在的属性才走 __getattr__
```

### 22.3 property 五步演进（关键一步）

```python
# 教学示意，不参与构建
class Vector2d:
    def __init__(self, x, y):
        self.__x = x
        self.__y = y
    @property
    def x(self):
        return self.__x              # 读：像属性一样访问
    @x.setter
    def x(self, value):
        self.__x = float(value)      # 写：可校验/转换

v = Vector2d(1, 2)
print(v.x)        # 1.0 —— 无需 v.x()
v.x = 3
```

### 22.1 现代补充：`cached_property`

```python
# 教学示意，不参与构建 —— Python 3.8+
import functools

class Dataset:
    @functools.cached_property
    def expensive(self):
        print("计算一次")
        return sum(range(10_000_000))
    # 首次访问后缓存到实例 __dict__，后续直接读
```

## 版本演进

- **PEP 412 / 🔧 `cached_property` 进标准库（3.8）**：`functools.cached_property` 是 22.3「自实现特性缓存」的现代替代——原书第五步手写缓存，如今直接用一个装饰器。
- **PEP 557 — `dataclasses`（3.7）**：`@dataclass` 自动生成 `__init__`/`__repr__`/`__eq__`，与本章「特性验证」配合见 [05-数据类构建器.md](05-数据类构建器.md)；`dataclasses.field` 的 `default_factory` 等价于「延迟计算属性」。
- **PEP 487 — `__set_name__`（3.6）**：描述符可自动拿到所属属性名，是 22.6「特性工厂」与 23 章描述符的底座。
- 3.12 `immortal objects`（PEP 683，🔧 以官方为准）：与本章关联弱，但 `__slots__`（`__set_name__`/特性在槽对象上的行为）在 free-threaded 下一致。
- 🔧 关于「`property` 与 3.14 t-string（PEP 750）的格式化联动」：t-string 提供「惰性格式化模板」，可替代部分 `__format__` 逻辑，以官方为准。

## 常见误区与本书需修正之处

| 原书说法 / 习惯 | 问题 | 2026 正确写法 |
| --- | --- | --- |
| 手写特性缓存（第五步） | 易错、重复 | 用 `functools.cached_property`（3.8+） |
| 用 `__getattr__` 兜底所有属性 | 会掩盖拼写错误，IDE 无法补全 | 仅对「动态数据」用 `__getattr__`，普通属性显式声明 |
| 把特性当「存储」 | 特性默认不存值，每次访问都计算 | 读特性要缓存或确认计算便宜；写特性才落 `__dict__` |
| `__getattr__` 与 `__getattribute__` 混用 | `__getattribute__` 拦截所有属性访问，易无限递归 | 一般只用 `__getattr__`（仅缺失时触发）；要拦截全部用 `__getattribute__` 并谨慎 |
| 忽略 `__set_name__` | 描述符/特性工厂拿不到名字要手传 | 3.6+ 用 `__set_name__` 自动拿属性名 |
| 🔧 `dataclass` 与特性的配合 | `@dataclass` 默认生成普通字段非特性 | 需要校验用 `@property`/`__post_init__` 或 pydantic |
