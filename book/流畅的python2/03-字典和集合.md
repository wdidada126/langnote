# 第 3 章 字典和集合（原书 pp.59–86）

> 一句话定位本章：把 dict / set 从「能用」讲到「为什么这么快」，以及货真价实的取舍（可哈希、`defaultdict`、`ChainMap`、不可变映射、视图运算）。
> 基线：原书 Python 3.10；本目录按 3.12+ 校验。

## 核心精讲

### 现代句法：推导式、`**` 拆包、`|` 合并

```python
# 教学示意，不参与构建
CODES = [('CN', 'China'), ('BR', 'Brazil'), ('JP', 'Japan'), ('US', 'United States')]
country = {code: name.upper() for code, name in CODES}
inverted = {name.upper(): code for code, name in CODES}   # 键值互换
print(country, inverted)

defaults = {'theme': 'light', 'lang': 'zh'}
user = {'lang': 'ja'}
print({**defaults, **user})        # 字面量拆包：键不必是 str
print(defaults | user)             # PEP 584（3.9+）：更直白，返回新 dict
d = dict(defaults)
d |= user                          # 就地版本：等价于 d.update(user) 后再赋回
print(d)
print(defaults.keys() & {'lang'})  # 视图做集合运算
```

`|` 与 `{**a, **b}` 的差别不在速度而在**语义**：

- `|` 是运算符，右操作数可以是**任意映射**（见下文 `MappingProxyType`、ChainMap 的实测）；
- `{**a, **b}` 要求右侧对象是 mapping 且键要能被字面量接收；
- `dict(**a, **b)` 要求所有键是合法标识符字符串，是最容易踩坑的一种。

### 模式匹配处理映射（3.3，第 2 版新增）

```python
# 教学示意，不参与构建
def handle(event):
    match event:
        case {'type': 'move', 'x': x, 'y': y}:
            return f'move to ({x}, {y})'
        case {'type': 'key', 'key': str() as k, 'modifiers': [*mods]} if mods:
            return f'key {k} with {mods}'
        case {'type': typ, **rest}:                 # 捕获其余字段，不要求匹配全部
            return f'unhandled {typ}: {sorted(rest)}'
        case _:
            return 'not a mapping event'


print(handle({'type': 'move', 'x': 1, 'y': 2}))
print(handle({'type': 'key', 'key': 'A', 'modifiers': ['ctrl']}))
print(handle({'type': 'ping', 'id': 7}))
print(handle(['not', 'a', 'dict']))
```

要点：**映射模式天生是部分匹配**，不需要像序列模式那样担心长度；键必须是字面量值，`case {k: v}` 这种写法不存在。

### 缺失键：`setdefault` / `defaultdict` / `__missing__`

```python
# 教学示意，不参与构建
from collections import defaultdict

occurrences = defaultdict(list)
for word in 'the quick brown fox jumps over the lazy dog'.split():
    occurrences[len(word)].append(word)
print(dict(occurrences))


class StrKeyDict(dict):                       # 演示 __missing__
    def __missing__(self, key):
        if isinstance(key, str):
            raise KeyError(key)
        return self[str(key)]

    def __contains__(self, key):
        return str(key) in self.keys()

    def get(self, key, default=None):
        try:
            return self[key]
        except KeyError:
            return default


kd = StrKeyDict([('1', 'one'), ('2', 'two')])
print(kd[1], kd.get('1'), kd.get(3, 'N/A'), 2 in kd)
```

三条边界必须记住（原书 3.5.3 也强调）：

1. `__missing__` 只被 `d[k]` 触发，`d.get(k)`、`k in d` 都不走它；
2. 标准库并未处处尊重它——`collections.Counter`、`shelve.Shelf` 各不相同，不要假设；
3. 一旦自定义 `__contains__`/`get`，请把三者一致性一次性写全。

### 不可变映射、视图与 dict 变体

```python
# 教学示意，不参与构建
from collections import ChainMap, Counter, OrderedDict
from types import MappingProxyType

source = {'a': 1}
ro = MappingProxyType(source)
try:
    ro['b'] = 2                      # TypeError: 只读
except TypeError as exc:
    print('TypeError:', exc)
source['a'] = 99
print(ro)                            # 跟着变 —— proxy 不是快照
print(ro | {'b': 2})                 # 3.13 实测：返回普通 dict

lookup = ChainMap({'user': 'guest'}, {'user': 'root', 'shell': '/bin/sh'})
print(lookup['user'], lookup.maps)
child = lookup.new_child({'user': 'admin'})
print(child['user'], dict(child))    # 环境栈/配置覆盖的经典写法

print(Counter('abracadabra').most_common(2))
print(Counter('aab') | Counter('bbc'))   # 多重集并集：取各键最大值，注意不是 dict 的「覆盖」
print(Counter('aab') + Counter('bbc'))

od = OrderedDict.fromkeys('abc')
od.move_to_end('a'); od.popitem(last=False)
print(od)                                # OrderedDict 今天剩下的独家价值就在这两个方法
```

`dict` 的代替品怎么选：

| 需求 | 用它 | 别用 |
| --- | --- | --- |
| 通用键值映射 | `dict` | 任何 abc 或旧式变体 |
| 缺键时自动建值 | `defaultdict` / 自定义 `__missing__` | `setdefault` 的长表达式 |
| 分层配置 / 作用域查询 | `ChainMap` | 手工 `dict(update(...))` 拷贝 |
| 计数 | `Counter` | 手写 `.get(k, 0) + 1` |
| 对外暴露只读视图 | `MappingProxyType` | 假装不可变的自定义类 |
| 需要按使用/插入做重排 | `OrderedDict`（`move_to_end`） | dict 手动重删+重插 |
| 持久化键值存储 | `shelve.Shelf` | pickle + dict 手写序列化 |

### 可哈希与 set

```python
# 教学示意，不参与构建
class Bad:
    def __eq__(self, other): return isinstance(other, Bad)

try:
    print(hash(Bad()))       # 定义了 __eq__ 却没 __hash__ → 不可哈希
except TypeError as exc:
    print('TypeError:', exc)

print(hash((1, 2, 'three')), hash(frozenset({1, 2})))
try:
    print(hash({1, 2}))      # set / list / dict 一律不可哈希
except TypeError as exc:
    print('TypeError:', exc)

words = set('the quick brown fox'.split())
print(words & set('the quick'.split()), words <= set('the quick brown fox jumps over'.split()))
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 年的正确写法 |
| --- | --- | --- |
| 3.6.1 把 `OrderedDict` 当作「保序 dict」的主力 | 3.7 起 dict 保序已写入语言规范 | `OrderedDict` 只在两种场景优于 `dict`：`move_to_end` / `popitem(last=False)` 重排，以及**需要相等比较考虑顺序**时。其余一律用 `dict` |
| 3.2.2 用 `dict(**a, **b)` 合并 | 要求键必须是合法标识符字符串 | 用 `a \| b`（PEP 584）或 `{**a, **b}` |
| 3.4.3 以 `setdefault` 为主 | 表达式长、每轮都构造默认值对象 | 「缺键则造 VALUE」优先 `collections.defaultdict(list/set/int)`；需要复杂逻辑才自定义 `__missing__` |
| 3.5 暗示 `__missing__` 是通用钩子 | 实现间不一致 | 只有 `d[k]` 会触发；`get`、`in`、`Counter` 不走它（3.5.3 已提示，但要记住是** setter 不一致**，别猜） |
| 3.7 只讲 `MappingProxyType` 只读 | 没点明它是**视图** | 底层 dict 改动会实时体现；需要不可变快照请用 `dict(...)` 复制 + proxy，或 `types.MappingProxyType(dict(d))` |
| 3.9 给出的具体内存/比率数字 | 数字随版本漂 | 结论（哈希表以空间换时间、扩容重散）保留，**具体 `sys.getsizeof` 数字一律实测** 🔧 |
| 3.12 视图集合运算 | 没提醒 `(key, value)` 参与运算时值必须可哈希 | `dict.items() & another` 要求 value 可哈希；只关心键就 `.keys()` 参与运算 |
| 🔧 3.11 提到「GIL 让某些操作天然线程安全」 | free-threading（PEP 703）下不再成立 | 不要依赖 GIL 做正确性；多线程共享 dict/set 用 `threading.Lock`，🔧 原子性边界以官方文档为准 |
| 全书仍见 `typing.Dict` / `typing.Set` | typing 已废弃这批别名 | PEP 585 起写 `dict[str, int]`、`set[int]` |
| 3.6.5 只说「子类应继承 UserDict」 | 未给更現代的选项 | 排序：① 组合（内含一个 dict）→ ② `collections.abc.MutableMapping` → ③ `UserDict`；继承内置 `dict` 是最后手段 |
