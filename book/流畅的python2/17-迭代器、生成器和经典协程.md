## 核心精讲

### 17.5.3 生成器函数：最常用写法

```python
# 教学示意，不参与构建
class Sentence:
    def __init__(self, text): self.words = text.split()
    def __iter__(self):
        for word in self.words:
            yield word            # yield 让 __iter__ 自动成为生成器

# 等价于手写迭代器，但代码量骤减
for w in Sentence("a b c"):
    print(w)
```

### 17.11 `yield from` 扁平化

```python
# 教学示意，不参与构建
def chain(*iters):
    for it in iters:
        yield from it            # 依次把 it 的每个元素产出（PEP 380）

print(list(chain("AB", [1, 2], range(3))))   # ['A', 'B', 1, 2, 0, 1, 2]
```

### 17.13 经典协程（仅作历史/理解 asyncio 来路）

```python
# 教学示意，不参与构建 —— 现代代码请用 async/await（见 21 章）
def averager():
    total = 0.0
    count = 0
    average = None
    while True:
        term = yield average          # .send(x) 注入 term，返回 average
        total += term
        count += 1
        average = total / count

coro = averager()
next(coro)                            # 预激
print(coro.send(10))                  # 10.0
print(coro.send(30))                  # 20.0
```

## 版本演进

- **PEP 380 — `yield from`（3.3）**：扁平化子生成器，本章 17.11 的基础，3.12+ 不变。
- **PEP 525 — Asynchronous Generators（3.6）**：`async def` + `yield` 产出异步生成器；第 2 版已补充，3.12+ 不变（见 [21-异步编程.md](21-异步编程.md) 17/21 交叉）。
- **PEP 479 — 生成器内 `StopIteration` 改为抛 `RuntimeError`（3.7）**：原书若提「生成器里抛 `StopIteration` 会停」，必须修正为：3.7 起会抛 `RuntimeError`，避免静默终止。
- **PEP 492 — `async`/`await`（3.5）**：原生协程取代 17.13 的经典协程，本章「经典协程」应明确标注「仅用于读懂旧代码与理解 asyncio 起源」。
- 3.10 `match` 可对可迭代对象做序列模式匹配，与本章迭代协议自然衔接（见 [18-with、match和else块.md](18-with、match和else块.md)）。
- 3.11 Faster CPython 对生成器帧有专门优化，生成器开销进一步降低（非同行评审，speed.python.org）。

## 常见误区与本书需修正之处

| 原书说法 / 习惯 | 问题 | 2026 正确写法 |
| --- | --- | --- |
| 把可迭代对象当迭代器 | 可迭代对象没 `__next__`，不能 `next()` | 区分：`Iterable` 有 `__iter__`；`Iterator` 还有 `__next__` |
| 在生成器里 `return` 值当产出 | 生成器 `return v` 只用于 `StopIteration.value`，不是产出 | 用 `yield` 产出；`return` 仅传值给 `asend`/`yield from` 调用方 |
| 经典协程当现代并发用 | 3.5+ 原生协程/asyncio 才是主流 | 经典协程只用于读旧代码；新代码用 `async`/`await` |
| 生成器内抛 `StopIteration` 想「提前结束」 | 3.7+ 改抛 `RuntimeError`，静默终止 bug 消失但行为变了 | 用 `return` 显式结束生成器 |
| 一次性 `list(generator)` 后再处理 | 大数据下内存爆炸 | 保持惰性，逐元素/逐块消费 |
