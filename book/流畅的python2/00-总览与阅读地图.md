## 七、跨语言对照速查（读本书时最常拿来对照的）

| Python（本书口径） | Java | C++ | 备注 |
| --- | --- | --- | --- |
| 数据模型 / 特殊方法 | 接口 + 约定（如 `Comparable`） | 运算符重载 | Python 用双下划线协议统一，且由解释器隐式调用 |
| 鸭子类型 | 接口必须显式 `implements` | 模板 / concepts | Python 在运行时按「有没有这个方法」判定 |
| 静态协议 `Protocol` | 接口 | concepts（C++20） | 结构类型，静态检查器可验证 |
| 抽象基类 `abc.ABC` | 抽象类 | 纯虚类 | 名义类型，需显式继承或 `register` |
| 描述符 `property` | getter/setter | 无直接对应 | 描述符是 `property`/方法/类方法/静态方法的共同底座 |
| 元类 `type` | 无（靠注解处理器） | 无（靠模板） | Python 中类是「元类的实例」 |
| 生成器 | `Stream` | 协程（C++20） | 生成器的 `.send()` 是经典协程的雏形 |
| `asyncio` | `CompletableFuture`/虚拟线程 | `std::execution`/asio | 事件循环 + 原生协程 |
| GIL / free-threading | 无 GIL，靠锁 | 无 GIL，靠 `std::mutex` | PEP 703 后才有无 GIL 构建 |

## 八、本目录的写作约定

1. **七段式固定结构**，每章都有，顺序不可改：
   `## 本章地图`（表格：节 / 内容 / 结论）→ `## 核心精讲`（代码块标「教学示意，不参与构建」）→ `## 版本演进` →
   `## 经典论文与原始文献` → `## 近年研究与工业界开源实践（2015–2026）` →
   `## 常见误区与本书需修正之处`（表格 + 🔧 标记）→ `## 与其他章 / 其他书的联系`。
2. **不虚构文献**。Python 生态知识主要来自 PEP 与官方文档，本目录统一以 **PEP 编号 + 标题 + 年份 + URL** 作为「原始文献」；
