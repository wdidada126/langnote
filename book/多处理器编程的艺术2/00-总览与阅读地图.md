# 《多处理器编程的艺术》（原书第 2 版）阅读地图

- 原书名：*The Art of Multiprocessor Programming*, **Second Edition**（2020-12，Morgan Kaufmann / Elsevier，ISBN `978-0-12-415950-1`，576 页；英文第 1 版 ISBN `978-0-12-397337-5`）
- 作者：Maurice Herlihy（Brown，2003 Dijkstra 奖 + 2004 Gödel 奖）、Nir Shavit（MIT / Tel-Aviv）、Victor Luchangco（Sun/Oracle Labs → Algorand）、Michael Spear（Lehigh）
- 中文版：《多处理器编程的艺术（原书第 2 版）》，机械工业出版社，2022-06（用户书单条目）
- 🔧 **去重说明**：`book/` 下另有 `多处理器编程的艺术.md`（298 行，**中文版修订版 = 英文 Revised First Edition**，金海/胡侃译，2013-05）。**那是第 1 版；本目录写的是第 2 版**。第 2 版作者增至 4 人，结构大改：新增 Ch4「共享内存基础」、Ch17「数据并行」、Ch19「乐观与手工内存管理」、Ch20「事务性编程」，原第 1 版的 Ch5「the relative power」被重排。两者并存，互相链接。

## 与并发系列的关系（各书总览已互链）

- **本书 = 算法与正确性的一面**；`Java并发编程之美/`、`Java并发编程实战/`(Goetz)、`Java并发实现原理/`(冷血)、`Java高并发核心编程/`(尼恩) = **Java 工程与 JDK 源码的一面**。建议顺序：**先用本书建立正确性定义（线性一致性、进展条件、内存模型）**，再回 JDK 看「为什么那样实现」。
- 本书 Ch2 的 **CLH / MCS 队列锁** → 就是 JUC `AQS` 与 `ReentrantLock` 的血脉。
- 本书 Ch9 Lazy list、Ch14 Lazy skiplist → 就是 `ConcurrentHashMap`（JDK 8 桶级）与 `ConcurrentSkipListMap`。
- 本书 Ch10 MS-queue → 就是 `ConcurrentLinkedQueue`；Ch11 Treiber 栈 → 就是各类并发 deque 的基础。
- 本书 Ch16 work-stealing → 就是 `ForkJoinPool`；Ch12 计数组合 → 就是 `LongAdder` 的理论原型（cell 分段）。
- 本书 Ch4/Ch5 的形式化是 **Java 内存模型（JSR-133）与 C++11 memory model** 的理论源头。

## 本书没覆盖的缺口（2026 视角）

- **语言 / 运行时**：Java 虚拟线程（JEP 444）、结构化并发（JEP 505）、ScopedValue（JEP 506）、C++20 `atomic_ref` / `jthread` / `atomic::wait`、Rust `Send/Sync` 所有权型并发。
- **弱内存模型的形式化**：x86-TSO（Sewell et al., CACM 2010）、ARMv8 公理模型（2017+）、Linux Kernel Memory Model（LKMM）、持久内存上的 fail-atomicity。
- **HTM 商业现实**：Intel TSX 在多数服务端 SKU 被微码禁用或删除；本书 Ch20 的 HTM 讨论需对照硬件可用性。
- **非阻塞内存回收的工程化**：folly `hazptr`、crossbeam `epoch`、以及 JVM 侧 GC 与显式回收混用的取舍（详见第 19 章）。
