## 核心概念速览（中英对照）

- **范围** — range：有 `begin()/end()` 的序列；C++20 概念树（`range/sized_range/common_range…`）定义身份。
- **视图** — view：惰性的 range 组合件，O(1) 构造、不持有元素（`views::filter/transform/join…`）。
- **管道** — pipeline：`|` 把视图串成数据流水线（`v | views::transform(f) | views::take(10)`）。
- **限定算法** — qualified algorithms：`std::ranges::sort(v, pred)` 直接吃容器，免传一对迭代器。
- **生成器** — generator（书中手写协程式）：`yield` 出一个惰性整数序列，第 14 章的"无限流"演示。
- **代理引用** — proxy reference：视图元素的引用可能是算出来的临时体（`transform_view` 值即此类）。
- **独占指针** — `unique_ptr<T,D>`：零开销 RAII 所有权（比裸 new/delete 只赚不赔）。
- **共享指针** — `shared_ptr<T>`：引用计数共享所有权；控制块另分配，`make_shared` 合一优化。
- **弱指针** — `weak_ptr`：破环工具，观察而不续命。
- **span** — `std::span<T>`：连续序列的非拥有视图（指针+长度成对），替代 `T*+size_t` 接口。
- **array / bitset** — 定长栈上数组 / 定长位向量：编译期尺寸的 C 数组替代与位操作容器。
- **pair / tuple** — 二元/多元值组：结构化绑定与 `get<>` 的两副面孔。
- **variant** — `std::variant<Ts...>`：带标签的类型安全 union，`visit/holds_alternative/get<>` 三开门。
- **optional** — `std::optional<T>`：值或"无值"，`has_value/value_or(value_type&&)`。
- **any** — `std::any`：类型擦除的任意值容器（小对象优化），`any_cast` 显式降级。

## 设计视角：动机 → 机制 → 权衡 → 相邻对比

**动机：为什么 pair-of-iterators 撑不住了？**（书之大意）算法+两迭代器的组合在**多输入**（set_operation）、
**惰性变换**（对每元素先 transform 再过滤）、**无限源**三场景下要么写出括号地狱要么写不出。
ranges 的答案：①容器直接作参数；②视图是"可组合的一等序列"——`views::filter` 不复制不计算，
只定义"按需读取规则"。Stroustrup 把这称为"把 STL 的第二乐章（泛型算法）写成可读的乐谱"。
管道 `|` 的语法价值被反复强调：数据流方向从左到右，与代码阅读方向一致（对比函数嵌套调用从内向外读）。
深读：[../现代C++实战30讲/16-未来篇Concepts-Ranges-协程.md](../现代C++实战30讲/16-未来篇Concepts-Ranges-协程.md)。

**机制：视图的三大契约与两大陷阱。** 契约：O(1) 拷贝/移动、可无限次重扫（若底层 range 允许）、
无副作用直到迭代。陷阱①**悬挂**：视图不拥有数据，`views::filter(...)` 的临时量存进变量后底层若亡则悬——
第 15 章 string_view 同款债务的"容器版"；陷阱②**代理引用**：`auto& x = *it` 对 transform 视图拿到的
可能是临时体引用，`auto` 才是安全默认（14.5 借概念系统讲"range 的值类型≠元素引用类型"）。

**机制：手写 generator 是教学，不是终态。** 14.3 用协程协议（promise_type/await 三件套）手搓一个
整数生成器——Stroustrup 用意是"让读者看清协程=可挂起函数的机械结构"。C++23 已提供现成的
`std::generator`（见最新节），生产代码不再手搓；但 2019-2022 间所有"awaitable 手写时代"的
理解成本，正是本章篇幅的由来。协程全景在 [10 章](10-并发.md) 18.6。

**机制：指针章=所有权语法的教科书。** 15.2 的取舍表（书之大意）：
单拥有者 `unique_ptr`（默认）→ 共享且**生命周期真重合**才 `shared_ptr`（控制块原子计数有并发成本）→
**不拥有只观察**：裸引用/`span`/迭代器。span 的定位是"数组接口的现代拼写"：
`void f(std::span<int> v)` 一参收编 C 数组/vector/子区间，且带 `subspan` 安全切片。
相邻对比：Rust `Box/Rc/&'a` 三件套靠借用检查器背书；C++ 的对应物靠**约定+静态分析**——
这是"同样分类学、不同执法力度"的最佳展示样本。

**机制：variant/optional/any 是"三种不确定"。** optional=有或无（单类型），
variant=多选一（封闭集合，编译期已知全名单），any=任一是（开放集合，运行期查类型）。
设计视角：C++ 坚持 variant 的 `visit` 要求穷尽性（漏分支在 C++20 可 static_assert 兜 ⚠️ 书口径为惯例），
而访问者模式（[../C++20设计模式/14-模板方法与访问者.md](../C++20设计模式/14-模板方法与访问者.md)）
在 variant 上从"手写 vtable 模拟"降格为"重载集 `overloaded{...}` + CTAD"——
第 2 版没机会展示的这条线，3 版把它放进 15.4 与第 8 章 concepts 连成闭环。

## 最新演进与工业实践（第 3 版止于 C++20，本节补 C++23/26）

- **`std::generator`（C++23，P2502R2 ✅wg21.link 302+索引相邻行实测）**：协程惰性等差数列进标准库，
  14.3 的手写教学版直接替换。🔧 本机实测（g++ 15.2 `-std=gnu++23`，输出 `0 1 1 2 3 5 8 13`）：

  ```cpp
  std::generator<int> fib(int n) {
    int a = 0, b = 1;
    for (int i = 0; i < n; ++i) { co_yield a; int t = a + b; a = b; b = t; }
  }
  ```
  ⚠️ 注意：该环境 `std::print` 链接失败（MinGW 运行时缺口，见 [00 章实测表](00-总览与阅读地图.md)），
  generator 本身编译运行无恙——两件事独立。
- **`std::mdspan`（C++23，P0009R18 ✅标题 "MDSPAN"）**：非拥有多维视图（`layout_right/extents/accessor`
  三参数化），数值/GPU/线性代数接口的"Fortran 子数组"正名。🔧 本机实测 ❌：MinGW libstdc++ 15 无 `<mdspan>` 头；
  libc++/MSVC STL 已实现——跨工具链选型时这是真实差异点。
- **`optional`/`expected` 组合子化（C++23，P2505R5 ✅）**：`and_then/or_else/transform` 让
  15.4 的 `value_or` 时代升级为链式；`flat_map` 的插入（见 [07 章](07-容器与算法.md)）补了有序哈希之外的第三档。
- **C++26 的"回收"话题：hazard pointers**：15 章结尾"裸指针何时合法"的开放伤口（锁-free 数据结构何时安全释放）
  正被标准化——Hoberock 论文族 P1121R2/R3（"Hazard Pointers: Proposed Interface…" ✅标题实测）→
  P2530R0-R3（"Why/…for C++26" ✅）→ 扩展 P3135/P3427（2024 ✅）；据媒体多源报道已入 C++26
  （⚠️ 本目录未核 ISO 最终文档，GCC 15 未实现）。工程对照：folly `HazPtrTS`、FCM 系是现行替代。
- **ranges 生态收编中**：range-v3 → std::ranges 迁移仍是各库进行时；视图新增
  `zip/adjacent/chunked/enumerate`（C++23 线）让 14.2 的示例库扩容（zip P2321R2 ✅，其余编号 ⚠️）。

## 常见误区

1. 存视图等于存数据：`auto v = vec | views::filter(...)` 捕获的是**临时量引用**——
  底层容器/临时对象亡则悬垂（先构造再取视图、或立刻消费）。
2. `shared_ptr` 到处传：函数参数需要所有权吗？不需要就 `T&`/`T*`（span 元素级则 `auto`）；
  计数原子递增在热路径是可见成本（15.2.1 明言）。
3. `variant` 当 `any` 用然后 `get<>` 猜类型：visit 穷尽才是正门；分支里出现 `holds_alternative` 链
  是"我在手写 tag switch"的坏味道。
4. `span` 成员化：它是视图不是容器；结构体存 span 等于存指针到别处——所有权错位第一来源。
5. optional 嵌套 optional 表达"两层未知"：语义爆炸（无值 vs 外层无值），设计域模型或用 variant。
6. 用 `any` 做扩展点再 `any_cast` 到处试探：那是运行期 RTTI 泥球——开放扩展用 virtual 接口
  （第 5 章），封闭集合用 variant（15.4.3 的定位）。
