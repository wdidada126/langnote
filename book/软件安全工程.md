# 软件安全工程

## 版本与 ISBN

- 原书名：*Software Security Engineering: A Guide for Project Managers*（SEI/CERT）
- 作者：Julia H. Allen、Sean Barnum、Robert J. Ellison、Gary McGraw、Nancy R. Mead
- 中文版：《软件安全工程》，机械工业出版社（华章程序员书库），2009-04
- ISBN：`978-7-111-26483-5`（222 页）
- 译者：郭超年、周之恒

> 2026-09-22 由 202609 月度笔记（20260922 TOCTOU/安全书单）整理。

## 笔记

- 从工程学视角讲如何在软件开发生命周期各阶段融入安全实践：安全需求、安全架构设计、安全编码与测试、系统集成、安全管理。
- 核心思想：软件安全不只是消灭漏洞和入侵检测，需要以攻击者视角思考，定义"足够好的"安全。
- 配套资源：美国国土安全部 Build Security In（BSI）网站。
