# 06 · 部署与服务

> 章名 ⚠️ 凭记忆推定带段，逐字目录待购电子版销账。对应 *Programming TensorFlow 2*（Packt·2021 ⚠️）交付带段：SavedModel 序列化 + TF Serving 起服务 + REST/gRPC 推理调用——单文件档口径「TFServing 部署雏形」。
> 时效注：书 API 截点 2021，**部署带段是全书贬值最快的一章**（单文件档红线：「部署章别当 2026 serving 指南」），一切以现行官方文档 Serving 篇为准。🔧 一律「未实测：本机未装 tensorflow」。

## 一、核心机制

### 1. SavedModel：TF 系的通用交换格式
- `model.save(path)`（TF2 默认即 SavedModel 目录格式：assets/ + variables/ + saved_model.pb ⚠️ 结构凭记忆）→ `tf.saved_model.load` / `tf.keras.models.load_model` 回读。
- 关键概念：**签名（signature）**——以命名函数（`serving_default`）声明输入张量规范，服务层按签名建请求 schema；`tf.function(input_signatures=...)` 可固化自定义签名 ⚠️ 参数写法版本敏感。
- PyTorch 对照（本档主锚）：SavedModel ≈ `torch.save(state_dict)` 与 `torch.export`/ExportedProgram 的**合身位**——但哲学不同：PyTorch 原生序列化只存权重（代码自持），TF 把「计算图+权重+签名」打包成**代码无关**产物，换 Python 侧重建推理器。这正是 TF 服务生态（TFX/TFServing）的地基，也解释了 Keras 3 时代 `.keras` 新格式（权重+配置、不带图）向 PyTorch 哲学**回摆** ⚠️ 归属推定。

### 2. TF Serving：gRPC/REST 双门面
- Docker 镜像 `tensorflow/serving` 挂载 `/models/<name>/<version>` 目录版本号布局；REST 端点 `POST /v1/models/<name>:predict`，gRPC 走 PredictService ⚠️ 路径形状凭通行记忆，不冒充书中原文。
- 批处理（batching）与多模型（model_config_list）是 TF Serving 相对「Flask 包 load_model」的两大真实增量 ⚠️ 书中覆盖深度待销账。

### 3. 客户端形态
- `predict()` 请求体：实例列表（或命名张量）→ 输出张量名到值的 JSON；书中若给 requests/grpcio 双样例，属「工程闭环」卖点带段 ⚠️ 推定。

## 二、批判读法
- **2021→2026 部署版图重写**：TF Serving 仍在维护但生态位收缩；LightRT/TF-TRT、ONNX Runtime 多框架服务、各云托管推理（SageMaker/Vertex 等）成主流选项 ⚠️ 未实测。书中 Docker 版号、镜像标签大概率已旧——**读概念（签名/版本目录/批处理），不读配置**。
- 「macOS 副题」在本章毒点最重：2021 Mac 上跑 TF Serving 的 Docker 路线（Docker Desktop x86/Rosetta 时代）与 2026 Apple Silicon 现状错位一档 ⚠️ 推定。
- `.h5`/`keras.engine` 反序列化兼容坑：Keras 3 加载 2.x 老模型有自定义对象/层注册变化——本章「存档即永生」暗示需按「格式代际」重读 ⚠️。
- 其他语言锚：SavedModel 版本目录 + 签名 ≈ 数据库迁移脚本目录 + 契约接口——「产物带 schema、服务按版本切流」的工程直觉同构。

## 三、🔧 微实验位（未实测：本机未装 tensorflow）
- E1：`model.save` 后查目录树（assets/variables/saved_model.pb），再用 `tf.saved_model.load` 取 `serving_default` 签名打印输入描述，坐实「签名=服务契约」。
- E2：同模型分别走 `keras.models.load_model` 与 `tf.saved_model.load`，对比能否继续 `fit`（推理器 vs 全模型语义差）。
- E3：（若 Docker 可用）挂载 models 目录起服务，REST 与 gRPC 各发一请求，对比延迟与批量参数效果。
