# 02 · tf.data 数据管道

> 章名 ⚠️ 凭记忆推定带段，逐字目录待购电子版销账。对应 *Programming TensorFlow 2*（Packt·2021 ⚠️）数据管道带段：`tf.data` 变换链 + TFRecord + 流水线化——单文件档「主线脉络」点名 `tf.data` 为本书工程化路径第一支柱。
> 时效注：书 API 截点 2021，对照现行官方文档（tensorflow.org/api_guide/python/datasets）；`tf.data` 核心概念十年稳，API 细节以现行文档为准。🔧 一律「未实测：本机未装 tensorflow」。

## 一、核心机制

### 1. Dataset 变换链：声明式流水
```python
ds = tf.data.TFRecordDataset(paths)             # 源：文件/内存/numpy/generator ⚠️ 凭通行口径
ds = ds.map(parse_fn, num_parallel_calls=tf.data.AUTOTUNE)
ds = ds.shuffle(buffer_size)
ds = ds.batch(B).prefetch(tf.data.AUTOTUNE)     # 预取=训练与取数重叠
```
- 心智模型：**Dataset 是惰性流水线描述，不是数据本身**；`AUTOTUNE` 把并行度交给运行时启发式。
- PyTorch 对照（本档头号锚）：`tf.data` ≈ `torch.utils.data.DataLoader`，但方向相反——DataLoader 是**拉取式**（`num_workers` 起进程池、迭代器按 index 取样本），`tf.data` 是**推送式流水线**（map/prefetch 在 TF 运行时内调度）。两个关键差：①PyTorch 自定义数据集写 `Dataset.__getitem__`（Python 任意 IO），TF 侧对位是 `tf.data.Dataset.from_generator`（跨语言边界、性能差一档 ⚠️）；②DataLoader 的 `pin_memory`/`prefetch_factor` 对位 `prefetch()` + `experimental_deterministic` 语义，参数名不可直译。

### 2. TFRecord：图时代的遗产格式
- 序列 protobuf 记录（`tf.io.TFRecordWriter` 写 / `tf.train.Example`+Feature 解析 ⚠️ 类名凭记忆）：单机顺序读大文件的「官方推荐姿势」，本书应有专节 ⚠️ 推定。
- 批判视角：TFRecord 解决的是「几万张小图片打开文件描述符慢」，2026 语境下 WebDataset/Parquet/直接内存映射都是竞品；**学概念（列式/记录式序列化）别学信仰** ⚠️。
- 其他语言锚：TFRecord ≈ 深度学习界的「二进制行格式」，工程直觉同 Kafka 的 segment log——顺序追加、批量顺序读、自带边界（长度前缀）。

### 3. 与模型层的接缝
- `model.fit(ds)` 直接吃 Dataset；验证集另建或 `split`。eager 下可对 Dataset 直接 `for x, y in ds` 调试——这是 TF2 相对 TF1（`iterator.get_next()` + session）的最大体感改善 ⚠️ 推定书中以此为卖点。

## 二、批判读法
- 本书管道章定位「会用」而非「调优」：prefetch 缓冲深度、`num_parallel_calls` 与 CPU 配额、shuffle buffer 内存代价三件事大概率一笔带过 ⚠️ 推定——2026 补 these 细节请去官方 performance guide。
- Estimator 时代的输入函数（`input_fn`）叙事若残留，属 1.x 惯性，纯 Keras 路线可跳 ⚠️。
- `tf.data` 之外书中是否讲 `keras.utils.sequence_encoding`/数据增强层（`tf.keras.layers.RandomFlip` 等 2021 前后新出）：⚠️ 记忆不明，目录销账时确认。

## 三、🔧 微实验位（未实测：本机未装 tensorflow）
- E1：同一批 numpy 数据，分别用 `from_tensor_slices(...).map(...).batch(...)` 与朴素 for 循环喂 `fit`，对比 epochs 墙钟时间，坐实 prefetch 收益。
- E2：写一对 TFRecord 读/解析函数，故意把 `parse_single_example` 的 dtype 写错，观察 eager 报错信息定位质量（对照 TF1 图时代「报错到 runtime 才炸」）。
- E3：`shuffle(buffer_size)` 设 1 与设全量，对比 batch 组成的可见差异，理解「近似洗牌」。

## 六、中英对照

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 数据集 | Dataset | 惰性流水线描述，非数据本体 |
| 映射变换 | map | 逐元素转换，可并行 |
| 预取 | prefetch | 取数与训练重叠 |
| 自动调优 | AUTOTUNE | 并行度交运行时启发式 |
| 打乱缓冲区 | shuffle buffer | 窗口内近似洗牌 |
| 记录文件 | TFRecord | protobuf 顺序记录格式 |
