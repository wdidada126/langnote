## 一、核心机制

### 1. Keras 循环层积木
- `SimpleRNN(units)` / `LSTM(units)` / `GRU(units)`，返回约定：`return_sequences=True` 出全序列 (B,T,H)，默认只出末态 (B,H)；`return_state` 另送 (h,c) ⚠️ 参数名凭通行口径。
- `Embedding(input_dim, output_dim)` = 可查表的稀疏→稠密映射，`mask_zero=True` 与 `tf.keras.layers.Masking`/`pad_sequence` 联动跳过填充位。
- PyTorch 对照（本档主锚）：`nn.LSTM` 显式返回 `(out, (h_n, c_n))` 元组、批量默认 `batch_first=False`（时间维在前）vs Keras 恒 (B,T)——**两条轴的默认顺序相反**，权重移植必转；PyTorch 变长用 `pack_padded_sequence`，Keras 用 mask 机制，语义对位但工程路径不同：**「填充位不参与隐态更新」这件事，两边各造了互不兼容的一套**。
- 其他语言锚：LSTM 门控（输入/遗忘/输出门）可读作「带可学习闸门的状态机」——与正则引擎/自动机的「状态转移」类比帮助建立形状直觉，但注意 LSTM 转移是连续可微的。

### 2. 典型训练形状
- 文本分类：向量化（`TextVectorization` 或 `Tokenizer`+`pad_sequences` ⚠️ 书中用哪套待销账）→ Embedding → BiLSTM → Dense。
- 双向：`Bidirectional(LSTM(units))` 前向+后向拼接，输出维 ×2。
- 时间序列回归：滑窗构造 (B, T, features) 三阶张量喂 SimpleRNN/LSTM——样本工程比模型本身更决定质量。

## 二、批判读法
- **生态变局（本档最重要一条）**：书 API 截点 2021，此后 NLP/序列建模被 Transformer 全面接位；本带段作「递归机制原理课」仍可读，作「2026 序列建模入门路径」已不合格——凡「LSTM 是当前最佳实践」暗示一律按 2021 共识打折 ⚠️。
- Keras 3 下 `SimpleRNN/LSTM/GRU` 多后端支持有坑（融合 kernel 与后端相关 ⚠️ 未实测），照抄前先查现行文档。
- 若书中 `tf.keras.preprocessing.text` 系 API：该模块在 TF2 后期被标注 legacy、官方推 `TextVectorization` 层——**书中预处理代码大概率正是被废弃面**，跳读改官方文档 ⚠️。
- seq2seq/注意力若存在，深度以「能跑」为限；原理纵深去 d2l 或花书 ⚠️ 归属推定。

## 六、中英对照

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 循环层 | RNN layer | 隐态沿时间步传递 |
| 门控单元 | LSTM / GRU cell | 遗忘/输入门控长程依赖 |
| 词嵌入 | Embedding | 稀疏 id 到稠密向量的查表 |
| 掩码 | masking (mask_zero) | 填充位不参与隐态更新 |
| 双向 | Bidirectional | 前向+后向状态拼接 |
| 返回序列 | return_sequences | 输出全序列而非末态 |
