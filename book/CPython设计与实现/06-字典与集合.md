## 核心精讲

**1. 紧凑字典（3.6+）**。`dict` 用「索引数组 + 条目数组」分离布局，迭代顺序即插入顺序，且更省内存。3.7 起插入保序成为**语言规范**（PEP 520）。

**2. resize**。负载因子超约 2/3 时整体搬迁到约 2 倍表；预建（`dict.fromkeys`、推导）减少搬迁。

**3. set**。`set`/`frozenset` 复用哈希表，元素本身即键（必须可哈希）。

```python
# 教学示意，不参与构建
d = {}
for i in range(10_000):
    d[i] = i          # 多次 resize
# 更优：d = dict.fromkeys(range(10_000))
```

## 常见误区与本书需修正之处

- 🔧 误：原书（3.10 基线）仍可能把 dict 顺序当「未定义」——3.7+ 已语言保证，必须修正。
- 误：用可变对象（list/dict）当键——`TypeError`（需可哈希）。
- 误：`dict.copy()` 浅拷贝，嵌套共享引用。
