## 核心精讲

**1. 目录结构（关键）**：`Include/`（公共头，如 `object.h`）、`Objects/`（内置对象 C 实现，listobject.c 等）、`Python/`（编译器、解释器主循环 `ceval.c`、字节码定义 `bytecodes.c`）、`Lib/`（标准库纯 Python）、`Modules/`（C 扩展模块）、`InternalDocs/`（3.12+ 内部设计文档）。

**2. 编译**：`./configure --with-pydebug && make -j$(nproc)`。debug 构建开启断言、关闭优化，便于 gdb 单步。

```python
# 教学示意，不参与构建（在 CPython 源码树里跑自定义解释器）
# ./python -m dis hello.py   # 看字节码
# gdb --args ./python hello.py
```

**3. 内部文档**：3.12+ 的 `InternalDocs/` 覆盖 compiler、execution、frames、generators、parser、string_interning 等，是读源码的最佳入口，比旧版零散注释系统。

## 版本演进

- 3.12 起新增 `InternalDocs/`，官方把内部设计文档从零散注释收敛为一套 Markdown。
- 字节码定义从手写 `opcode.h` 迁移到 `Python/bytecodes.c` + cases generator（3.11+），见第 11 章。

## 常见误区与本书需修正之处

- 🔧 误：原书（约 3.10 基线）的编译步骤未含 `InternalDocs`；2026 读源码应先看该目录。
- 误：以为「改一行 Python 标准库不用重编」——`Lib/` 是纯 Python，改了直接生效；改 `Objects/`/`Python/` 才需 `make`。
