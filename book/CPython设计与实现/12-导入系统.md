## 本章地图

| 节 | 内容 | 结论 |

| import 流程 | 查找→加载→执行 | 模块只执行一次 |
| sys.modules | 缓存 | 已导入直接返回 |

| 重载 | importlib.reload | 谨慎使用 |

## 核心精讲

**1. import 流程**。`import x` → 先在 `sys.modules` 查缓存（命中即返回）→ 否则走 `sys.meta_path` 上的查找器（finder）找 `x` 的规格（spec）→ 加载器（loader）读源码/字节码并执行 → 结果存入 `sys.modules` 与模块全局。模块体**只执行一次**，后续 import 取缓存。

**2. 查找器/加载器**。标准 `PathFinder` 沿 `sys.path` 找 `.py`/`.pyc`/包/命名空间包；可自定义 `MetaPathFinder`/`Loader` 实现插件式导入（如从 ZIP、网络）。

**3. 包与相对导入**。`package/__init__.py` 标记包；`from . import y` 相对导入基于 `__package__`；`__path__` 支持命名空间包（PEP 420，3.3）。

```python
# 教学示意，不参与构建
import sys
print("abc" in sys.modules)     # 已导入则为 True
import importlib
importlib.reload(sys.modules["some_mod"])   # 重新执行模块体
```

## 常见误区与本书需修正之处

- 🔧 误：原书（3.10 基线）对命名空间包/importlib 细节覆盖可能偏旧；应补 PEP 420/451。
- 误：以为「循环 import 一定报错」——只要不在模块顶层立即使用对方名字，循环导入可工作。
- 误：`importlib.reload` 会更新模块对象，但不更新已持有旧引用的地方，易出 bug。
