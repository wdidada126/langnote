## 核心精讲

教学示意，不参与构建：

```python
# 变量是「贴标签」，不是「装盒子」
message = "Hello, Python world!"
print(message)                      # Hello, Python world!

# 变量可重新绑定到任意类型
message = 42
print(message)                      # 42  （动态类型：名字不限定类型）

# 字符串：单/双引号等价，三引号多行
name = 'ada lovelace'
print(name.title())                # Ada Lovelace
print(name.upper(), name.lower())  # ADA LOVELACE ada lovelace

# f-string（PEP 498，3.6+）：可读性远胜 + 与 format()
first, last = "ada", "lovelace"
print(f"{first.title()} {last.title()}")   # ada lovelace

# 数字与类型转换
age = 23
print(f"You are {age} years old.")          # 自动在 f-string 内 str()
print(3 / 2)                                # 1.5  真除法
print(3 // 2)                               # 1    整除
print(2 ** 10)                              # 1024 幂
print(f"Age: {str(age)}")                   # 用 str() 显式转换
```

Python 之禅（PEP 20）是社区设计哲学，值得背下前几条：Beautiful is better than ugly / Explicit is better than implicit / Readability counts。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `+` 拼接大量字符串 | 循环中 O(n²) | 用 `join()` 或 f-string；批量用列表收集后 `"".join(parts)` |
| 变量「存储值」的比喻 | 易误解为盒子 | 变量是名字→对象的绑定（标签语义），`id()` 可证 |
| 缩进用 Tab | PEP 8 建议 4 空格 | 一律 4 空格，编辑器设「Tab 转空格」 |
| 注释越多越好 | 废话注释噪声大 | 注释「为什么」，不重复「做什么」 |
