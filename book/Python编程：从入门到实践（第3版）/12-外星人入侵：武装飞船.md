## 核心精讲

教学示意，不参与构建（需 `pip install pygame`，且本机有图形界面）：

```python
import sys
import pygame
from pygame.sprite import Group

pygame.init()
screen = pygame.display.set_mode((1200, 800))
clock = pygame.time.Clock()

running = True
while running:                       # 主循环
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

            ship_x += 5
    screen.fill((0, 0, 0))           # 重绘背景
    pygame.display.flip()            # 刷新
    clock.tick(60)                   # 限帧

pygame.quit()
sys.exit()
```

现代 `pygame` 是 `pygame-ce`（社区维护分支，🔧 以官方公告为准）；原书基于 1.9/2.0 API，事件常量、`font`、`surface` 用法基本一致。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `pygame` 1.9 | 旧版 | 用 `pygame-ce` 2.x |
| 全局变量存状态 | 难维护 | 用 `Settings`/`GameStats` 类封装 |
| 每帧重建对象 | 性能差 | Sprite/Group 复用 |
| 无帧率控制 | 速度随机器变 | 用 `clock.tick()` |
