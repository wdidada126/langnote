## 核心精讲

教学示意，不参与构建：

```python
def greet(name, greeting="Hello"):          # 默认值参数
    return f"{greeting}, {name}!"

print(greet("ada"))                         # Hello, ada!
print(greet("bob", greeting="Hi"))         # 关键字参数

def make_pizza(size, *toppings):            # *收集位置参数为元组
    return {"size": size, "toppings": list(toppings)}

def build_profile(**info):                  # **收集关键字为字典
    return info

# 可变参数的副作用：传入列表会被改
def add_item(items, x):
    items.append(x)
data = [1, 2]
add_item(data, 3)        # data 变成 [1,2,3]
add_item(data[:], 99)    # 传副本，data 不变
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 函数「修改列表」不提示 | 调用方易踩坑 | 文档注明副作用，或返回新对象 |
| 不写类型注解 | 大项目难维护 | 公共 API 加注解 + 跑 mypy |
| 默认参数是可变对象 | `def f(x=[])` 共享可变默认 | 用 `None` 占位：`def f(x=None): x = x or []` |
| 函数过长 | 难测难读 | 拆小、单一职责 |
