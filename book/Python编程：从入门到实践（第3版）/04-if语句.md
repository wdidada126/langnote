# 第 4 章 if 语句（原书 pp.69–83）

> 条件分支让程序「看情况办事」。基线：原书 Python 3.11；本目录按 3.12+ 校验。

## 本章地图

| 小节 | 内容 | 结论 |
|---|---|---|

## 核心精讲

教学示意，不参与构建：

```python
age = 19
print(age == 19)          # True
print(age >= 21 or age < 18)  # False

requested_toppings = ['mushrooms', 'onions']
if 'mushrooms' in requested_toppings:
    print("Adding mushrooms.")

# 多选一：只执行第一个为真的分支
score = 85
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'           # 命中这里，跳过下面
elif score >= 70:
    grade = 'C'
else:
    grade = 'F'

# 独立条件：用并列 if（都会判断）
if 'mushrooms' in requested_toppings:
    print("mushrooms")
if 'pepperoni' in requested_toppings:   # 独立判断
    print("pepperoni")

# 空容器为假
if requested_toppings:
    print("有配料")
```

## 版本演进

- 3.8 海象 `:=`（PEP 572）可在 `if` 内赋值并判断：`if (n := len(x)) > 5:`。
- 3.10 模式匹配 `match`（PEP 634）适合多分支等值判断，但本书阶段不强制。
- 比较链 `a < b < c` 一直是原生写法。

- 复杂业务规则用 `match` 或查表（dict 映射处理函数）替代长 `if/elif`。
- 布尔命名：`is_active`、`has_permission` 提升可读性。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| `if x == True:` | 冗余且对真值对象不通用 | 直接 `if x:` |
| `==` 与 `is` 混用 | `is` 只该用于 `None`/单例 | 比None一律 `is None`/`is not None` |
| `if list == []:` | 冗余 | `if not list:` |
| 长 elif 链 | 难维护 | 用 dict 分派或 `match` |
