## 核心精讲

教学示意，不参与构建（需 `pip install matplotlib pandas`，数据文件自备）：

```python
import csv
from pathlib import Path

with Path("death_valley_2021.csv").open(encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)
    highs = [int(row[4]) for row in reader if row[4]]   # 取高温列

# 现代写法：pandas 一行读
import pandas as pd
df = pd.read_csv("death_valley_2021.csv")
print(df["NAME"].head())
```

JSON 部分（人口数据）同 [09-文件和异常.md](09-文件和异常.md) 的 `json.load`。

## 版本演进

- 现代直接用 `pandas.read_csv` 替代手写 `csv` 循环（[../PythonForDataAnalysis3e.md](../PythonForDataAnalysis3e.md) 深讲）。
- `pathlib`（3.4）取代 `open("path")` 字符串拼接。
- 大数据用 `polars`（更快）替代 pandas 热点路径（🔧 以官网为准）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 手写 csv 解析 | 易错、慢 | 用 `pandas.read_csv` |
| 硬编码列索引 | 列一变就崩 | 用列名 `df["col"]` |
| 忽略编码 | 中文/其他语言乱码 | `encoding="utf-8"` |
