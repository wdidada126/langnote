## 核心精讲

教学示意，不参与构建（需 `pip install matplotlib`）：

```python
import matplotlib.pyplot as plt
import random

# 随机游走
x = y = 0
xs, ys = [x], [y]
for _ in range(1000):
    dx, dy = random.choice([-1, 1]), random.choice([-1, 1])
    x, y = x + dx, y + dy
    xs.append(x); ys.append(y)

plt.plot(xs, ys, linewidth=1)
plt.title("Random Walk", fontsize=14)
plt.show()

# 掷骰子统计
from collections import Counter
rolls = Counter(random.randint(1, 6) for _ in range(6000))
plt.bar(rolls.keys(), rolls.values())
plt.show()
```

## 版本演进

- `matplotlib` 3.x 持续更新；`plt.show()` 交互后端随环境变。
- 数值计算用 `numpy`（2.x）替代手写循环：`np.cumsum(np.random.choice([-1,1],1000))`。
- 现代替代：`plotly`（交互）、`seaborn`（统计美观）、`altair`（声明式）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 手算随机游走 | 慢 | 用 `numpy` 向量化 |
| `plt.show()` 做正式产出 | 不可批处理 | 用 `plt.savefig()` |
