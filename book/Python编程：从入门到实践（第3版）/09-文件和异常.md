## 核心精讲

教学示意，不参与构建：

```python
# 读：with 上下文管理器自动关闭
with open("pi_digits.txt", encoding="utf-8") as f:
    contents = f.read()
print(contents)

# 逐行
with open("data.txt", encoding="utf-8") as f:
    for line in f:                  # 文件是可迭代器
        print(line.rstrip())

# 写（会覆盖！）
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("hello\n")

# 异常
try:
    answer = 5 / 0
except ZeroDivisionError:
    print("不能除以 0")
else:
    print(answer)                  # 无异常才执行
finally:
    print("清理")                   # 总执行

# JSON：配置/数据交换
import json
data = {"name": "ada", "age": 23}
with open("cfg.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
with open("cfg.json", encoding="utf-8") as f:
    loaded = json.load(f)
```

## 版本演进

- 3.6 起 `open` 默认 `encoding` 取决于平台；🔧 「3.15 起 UTF-8 模式可能默认」属未定案，写文件务必显式 `encoding="utf-8"`。
- 3.4 `pathlib` 提供面向对象路径，取代 `os.path` 拼接：`Path("dir") / "file.txt"`。
- 3.6 `f-string` 让日志/格式化更清晰。
- 3.11 `ExceptionGroup`/`except*`（PEP 654）用于一次抛出多错。

## 近年研究与工业界开源实践（2015–2026）

- 路径一律用 `pathlib.Path`；大文件流式读取避免一次性 `read()`。
- 配置优先 `tomllib`（3.11，只读）或 `pydantic-settings`，JSON 仅用于数据交换。
- 敏感数据用 `secrets` 而非 `random`。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 不写 `encoding` | Windows 下 GBK 乱码 | 显式 `encoding="utf-8"` |
| 用 `os.path.join` 拼路径 | 字符串易错 | 用 `pathlib.Path` |
| `except:` 裸捕获 | 吞掉 SystemExit/KeyboardInterrupt | 捕获具体异常 |
| `pickle` 存配置 | 反序列化任意代码执行风险 | 用 JSON/TOML |
