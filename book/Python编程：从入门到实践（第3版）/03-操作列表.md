## 核心精讲

教学示意，不参与构建：

```python
# for 循环：迭代的是元素，不是索引
for bike in ['trek', 'cannondale', 'redline']:
    print(f"I would like to own a {bike.title()}.")

# 数值列表与 range（左闭右开）
squares = [value ** 2 for value in range(1, 11)]   # [1,4,...,100]
print(min(squares), max(squares), sum(squares))

# 列表推导：等价于「建空表→for→append」
doubles = [n * 2 for n in range(1, 6) if n % 2 == 0]  # [4, 8]

# 切片
nums = list(range(1, 21))
print(nums[:5])      # 前5
print(nums[-3:])     # 末3
copy = nums[:]       # 浅拷贝（独立对象）

# 元组：不可变，适合常量集合
dimensions = (200, 50)
print(dimensions[0])
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `for i in range(len(lst))` 遍历 | 反模式 | `for item in lst:`；要索引用 `enumerate()` |
| 切片拷贝当深拷贝 | 嵌套结构仍是浅拷贝 | 深拷贝用 `copy.deepcopy()` |
| 推导式塞过多逻辑 | 可读性差 | 复杂逻辑改回显式 `for` |
| 元组「不可变」 | 元组内可变元素仍可改 | 不可变指引用，不指内容 |
