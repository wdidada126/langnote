## 四、Python 3.5 → 3.14 版本演进时间轴（本书相关）

- 3.6（2016）：f-string 引入（PEP 498）——本书全程用 f-string，今天仍是首选格式化方式。
- 3.7（2018）：`breakpoint()` 内置（PEP 553）；字典保序成语言规范。
- 3.8（2019）：海象运算符 `:=`（PEP 572）；仅位置参数 `/`（PEP 570）。
- 3.9（2020）：字典合并 `|`（PEP 584）；内置泛型 `list[int]`（PEP 585）。
- 3.10（2021）：结构模式匹配 `match`（PEP 634）；更清晰的错误回溯。
- 3.11（2022）：`ExceptionGroup`/`except*`（PEP 654）；提速 ~25%；`tomllib`（PEP 680）。
- 3.12（2023）：f-string 语法形式化（PEP 701，任意表达式任意位置）；`type` 语句泛型（PEP 695）；`override`（PEP 698）。
- 3.13（2024）：自由线程构建（PEP 703，实验性）；移除一批「死电池」标准库（PEP 594）。
- 3.14（2025，开发线）：模板字符串 t-string（PEP 750，🔧 以官方为准）。
