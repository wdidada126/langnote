# 第 2 章 列表简介（原书 pp.28–48）

> 列表是 Python 最常用的「有序可变集合」。基线：原书 Python 3.11；本目录按 3.12+ 校验。

## 本章地图

| 小节 | 内容 | 结论 |
|---|---|---|
| 2.1 什么是列表 | 方括号、逗号分隔、索引从 0 | 异构允许，但同构更清晰 |
| 2.2 访问元素 | `bikes[0]`、负索引 `-1` | `-1` 取末项，避免 `len()-1` |

| 2.5 避免索引错误 | 空表/越界 | 出错时打印 `len()` 调试 |

## 核心精讲

教学示意，不参与构建：

```python
bikes = ['trek', 'cannondale', 'redline', 'specialized']
print(bikes[0])        # trek
print(bikes[-1])       # specialized  （负索引从末尾数）

bikes[0] = 'giant'     # 改元素
bikes.append('scott')  # 末尾追加
bikes.insert(1, 'bianchi')
print(bikes)

popped = bikes.pop()           # 默认弹末项
first = bikes.pop(0)           # 弹首项
bikes.remove('cannondale')     # 按值删第一个匹配

bikes.sort()                   # 原地升序（永久）
print(sorted(bikes, reverse=True))  # 返回新表，原表不变
bikes.reverse()                # 原地反转
print(len(bikes))
```

注意：字符串排序按 Unicode 码点；中文按拼音排序需 `locale` 或第三方库。

## 版本演进

- 3.7 起字典保序，但本章是列表，无影响。
- 3.9 起可用 `list[str]` 这类内置泛型注解（PEP 585），例如 `def f(x: list[int]) -> None`。
- 3.10 起 `bisect` 等标准库行为不变，但排序稳定性（Python 一直稳定）仍是 `sort` 的承诺。

## 近年研究与工业界开源实践（2015–2026）

- 大型有序集合用 `array`（同类型）或 `numpy.ndarray`（数值）更省内存更快。
- `sorted()` 的 `key=` 常配 `lambda` 或 `operator.itemgetter`；复杂排序用 `functools.cmp_to_key`（🔧 以官方为准）。

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 用 `del` 删已知位置 | 多数场景不需要保留值 | 要返回值用 `pop()`，仅删值用 `remove()` |
| `sort(reverse=True)` 做降序 | 无问题，但易忘「永久」 | 若需保留原序，用 `sorted()` |
| 把列表当栈/队列混用 | 列表头部插入 O(n) | 队列用 `collections.deque` |
| 循环里 `remove` | 边迭代边改大小会漏项 | 用列表推导或反向遍历/新建表 |
