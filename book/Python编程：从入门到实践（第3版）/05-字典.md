## 核心精讲

教学示意，不参与构建：

```python
alien = {'color': 'green', 'points': 5}
print(alien['color'])          # green
alien['x'] = 0                 # 新增键值
del alien['points']            # 删除

# 遍历
for key, value in alien.items():
    print(f"{key}: {value}")
for k in alien.keys():         # 等价于 for k in alien:
    print(k)

# 嵌套：列表里放字典（记录集合）
users = [
    {'name': 'ada', 'age': 23},
    {'name': 'bob', 'age': 30},
]
for u in users:
    print(f"{u['name'].title()} is {u['age']}.")

# 合并（PEP 584，3.9+）
base = {'a': 1}
merged = base | {'b': 2}       # {'a':1,'b':2}，不修改 base
```

## 常见误区与本书需修正之处

| 原书说法 | 问题 | 2026 正确写法 |
|---|---|---|
| 字典「无序」 | 3.7+ 已保序且进规范 | 可依赖插入序；但语义上仍按「键查找」建模 |
| `dict.keys()` 当集合改 | 视图非独立集合 | 要集合运算用 `set(d)` |
| `d['k']` 取值 | 键缺失抛 KeyError | 用 `d.get('k', default)` 或 `d.setdefault` |
| 嵌套裸字典表达记录 | 难维护、无校验 | 用 `dataclass`/`TypedDict` |
