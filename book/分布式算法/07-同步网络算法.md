# 第 07 章 同步网络算法（原书第 2–5、7 章，及第 6.1–6.2 节）

> **本章地图**：同步网络模型（第 2 章：轮结构、故障、复杂度度量）→ **同步环中的领导者选举**
> （第 3 章：不可能性、$O(n\log n)$ 算法、下界）→ 一般同步网络（第 4 章：选举、BFS、MST、
> 最大独立集）→ **链路故障下的共识：两军问题**（第 5 章）→ **进程停止故障下的 k-容错共识**

## 本章地图

原书 Part I 主体。同步模型（按轮推进、每轮消息必达）是全书最「友好」的实验室：
共识有解、门限干净、下界漂亮。本章覆盖第 2–5、7 章与第 6 章的停止故障部分；
第 6 章拜占庭部分独立成 08 章笔记。对称破缺（identical 进程无法选举）与
确定性门限（$f < n/2$）是贯穿全章的两条主轴。

## 核心精讲（教学示意，不参与构建）

### 7.1 同步网络模型（第 2 章）

- 执行按**轮**推进：每轮各进程收消息、改状态、发消息，下一轮开头送达；
- 故障：崩溃（某轮起停摆、消息不发）与拜占庭（任意行为，08 章）；
- 复杂度：轮数（时间）、总消息数、总位数；随机化建模为带概率转移的自动机（2.7 节）；
- **证明方法**（2.5 节）：不变式 + 归纳；「固定输入向量的所有执行」分析——
  同步性让「轮」成为数学归纳的天然单位，这是异步模型缺失的奢侈品。

### 7.2 环中领导者选举（第 3 章）

**不可能性**（3.2 节）：$n$ 个**完全相同**（identical、无 ID）的确定性进程在环上
无法选举——所有进程永远状态一致，破不了对称。结论：**ID/唯一名是对称破缺的最低要求**
（随机化可绕过，但只是概率意义）。

**比较型算法**（3.3–3.4 节，教学示意）：

- 基本算法（LCR）：ID 沿环单向传，比自己的大才转发；$O(n^2)$ 消息、$O(n)$ 轮；
- $O(n \log n)$ 消息算法（HS，Hirschberg–Sinclair）：**距离倍增**——
  第 $k$ 阶段 ID 向两个方向传播 $2^k$ 距离再折返比较，候选数每阶段减半，
  轮数 $O(n)$、消息 $O(n \log n)$。

**下界**（3.6–3.7 节）：比较型选举在环上需 $\Omega(n \log n)$ 消息——
HS 算法**恰好最优**。这是全书最干净的「算法-下界合龙」案例（非比较型另有下界，
详见 09 章笔记）。

### 7.3 一般同步网络（第 4 章）

- 领导者选举：洪泛最大 ID + 回声聚合，$O(|E|)$ 消息、$O(D)$ 轮；
- **BFS 树**：按轮扩散天然得到层结构（同步性省掉了异步版的层同步协议）；
- **MST**：同步化 GHS 思想，轮数 $O(n \log n)$；
- **最大独立集（MIS）**：Luby 算法（随机化，教学示意）：每轮各进程以概率 $1/(2d)$
  自荐，冲突邻居出局，期望 $O(\log n)$ 轮——随机化 + 同步 = 指数加速的范例。

### 7.4 链路故障与两军问题（第 5 章）

**协调攻击（两军问题）**：两支军队必须**同时**进攻才获胜，通信链路可能丢消息。
教学结论：

- 确定性下**不可能**：无论多少轮确认，最后一条消息的成功送达无法被发送方证实，
  归纳论证可延续到任意轮数——「最后一条消息永远悬而未决」；
- 随机化版本（5.2 节）：以概率 1 攻击成功、期望有限轮，可达「几乎确定」的协调。

工程对照：TCP 握手不能「保证双方都知道连接建立」是同一困境；分布式事务
commit 协议对协调者最后消息的依赖（2PC 的阻塞）是它的直接后代。

### 7.5 停止故障下的共识（第 6.1–6.2 节）★

$n$ 进程同步网络，至多 $f$ 个进程**崩溃**（停止故障），求共识三性质
（协定/有效性/终止，同 03 章定义）。教学核心结论：

- **算法**（教学示意，f 轮定理版）：每轮进程广播自己已知的提议集合，逐轮合并，
  取集合最小值当决定。$f+1$ 轮后，所有非故障进程的集合必然一致
  （崩溃进程最多拖慢信息一轮，所以 $f$ 个故障只需 $f+1$ 轮即可把「慢消息」暴露完）；
- **轮数下界**：$f+1$ 轮是精确下界（$f$ 轮不足）——同步模型里容错代价**精确可算**；
- 与异步的对照：同样 $f=1$，同步有解（本轮），异步无解（03 章 FLP）——
  **时间假设决定可解性**，这是全书最重要的对比实验。

### 7.6 共识变形（第 7 章）

- **k-协定**：同步下可解的故障容忍度比完全共识宽；异步下（与 FLP 同法）受限；
- **ε-近似协定**：数值型共识，异步随机化下可达（后面 03 章 🔧 与 Ben-Or 线相连）；
- **commit 问题**：数据库 2PC 的理论抽象——commit/abort 的决定必须全体一致，
  且 commit 要求全体都投 yes。第 6/7 章的轮数方法给出其容错边界。

### 7.7 停止故障共识算法（教学示意，$f+1$ 轮版）

```
// n 进程完全连接同步网络，至多 f 个崩溃；初值 v_i ∈ {0,1}
V_i := {v_i}                       // 进程 i 已知的提议值集合
for r = 1 .. f+1:
    broadcast 集合 V_i             // 每轮广播全部已知值
    收集所有到达消息中的集合，V_i := V_i ∪ (收到的所有值)
after f+1 轮：
    decide := min(V_i)             // 各非故障进程的 V_i 相同 → 协定
```

正确性直觉：崩溃进程最多在它死前的轮里「少转发」一轮信息，
$f$ 个崩溃最多造成 $f$ 轮的信息滞后，$f+1$ 轮把滞后全部暴露，
之后所有非故障进程的集合必然相等（严格证明见原书 6.2 节）。

### 7.8 环选举算法对比表

| 算法 | 消息复杂度 | 轮数 | 关键机制 |
| --- | --- | --- | --- |
| LCR（单向传值） | $O(n^2)$ | $O(n)$ | 大 ID 才转发 |
| Chang–Roberts 改进 | 平均改善（最坏 $O(n^2)$） | — | 非发起者提前截断 |
| HS（距离倍增） | $O(n \log n)$ | $O(n)$ | 第 $k$ 阶段双向传播 $2^k$ 距离 |
| 下界（比较型） | $\Omega(n \log n)$ | — | HS 恰好最优（09 章） |

## 版本演进

- 环选举：Le Lann 1977 首解、Chang–Roberts 改进、HS 1980（Hirschberg–Sinclair,
  Information Processing Letters）；下界：Burns 1980（$\Omega(n\log n)$，早期技术报告线）、
  最终由 Linial 1992 一线完善（细节条目存疑，以原书 3 章 notes 为准）；
- 同步共识轮数：Fischer–Lynch 1982（$f+1$ 轮精确性，STOC 会议线）、
  Dolev–Strong 1983（拜占庭消息复杂度，08 章）；
- MIS/图算法：Luby 1986、Alon–Babai–Itai 1986；CONGEST 下界体系（Linial 1992 起）
  把第 3/4 章的下界工程化为标准模型；
- 两军问题与「共同知识（common knowledge）」逻辑是同一时期的交汇线：
  协调攻击不可能的根因是**相互知识的层级无法封顶**
  （Halpern–Moses 一线，条目以原书 5 章 notes 为准，存疑不展开）。

## 近年研究与工业界开源实践（2015–2026）

- 🔧 **同步共识轮数的工程回声**：Raft 每次选举/提交 = 同步轮协议的现实投影——
  「一轮广播 + 多数确认」，$f+1$ 轮的容错代价体现为「最多容忍 $(n-1)/2$ 个故障仍能推进」，
  `etcd-io/raft`（2026-09 现查 1.1k★）、`hashicorp/raft`（现查 9.1k★）的任期推进
  即 $f+1$ 轮思想的连续化。
- 🔧 **$f < n/2$ 门限成为架构常识**：etcd 3/5/7 节点部署建议、Kafka KRaft quorum、
  CockroachDB/TiKV 的多数派写——门限公式 $(f+1) \times 2 - 1 \le n$ 是本章定理的
  运维翻译；跨地域部署的「两地三中心 5 副本」选型同样是门限算术。
- **MIS 与无线网络**：Wi-Fi/Sensor 网络的分布式调度持续使用 MIS 随机化变体；
  LoRa/蓝牙 mesh 的选主是 4 节 Luby 思想的低功耗版。
- **两军问题的现代形态**：跨 WAN 的最终一致写（Dynamo 风格）干脆放弃「同时协调」，
  用冲突调和替代同步协定——把不可能性转化为 API 设计选择。
- **门限算术的容灾落地**：两地三中心、跨城五副本、observer 只读节点不进 quorum——
  这些部署俗语背后都是 7.5 节「活人多于死人」的不等式；observer 的引入正是
  「参与共识」与「接收共识结果」两类角色的区分，对应本章「决定者 vs 学习者」的划分。
- **同步模型的教育价值**：TDDBench/教学项目几乎都从同步轮模型入手实现共识
  再逐步放宽假设——本章是动手实现 raft/paxos 前的正确热身；跳过同步模型
  直接读 raft，会把「随机超时」当成魔法而非部分同步假设的参数化。

## 常见误区与本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | 「有 ID 就能任意破对称」 | 只在**异步或同步 + 非对称位置**成立；同步 + identical 进程连位置对称都破不了（3.2 节，环上完全同构则不可能） |
| 2 | 「停止故障比拜占庭只是弱一点，算法差不多」 | 门限差一倍：停止故障容忍 $f < n/2$，拜占庭需 $n > 3f$（08 章）；轮数同样翻倍量级 |
| 3 | 「两军问题用更多次确认可以解决」 | 不可能对任意轮数成立（归纳论证）；工程上是**降级决策**（默认进攻/默认撤退）而非完美协调 |
| 4 | 「同步共识 $f+1$ 轮算法实际可用」 | 轮数最优但消息量 $O(n^2 f)$；工程共识走「领导者 + 日志」降复杂度，正确性借多数派而非全员广播 |
| 5 | 🔧 本书未覆盖 | **签名消息下的拜占庭**（Dolev–Strong 线，08 章 🔧 补充）、**异步图算法的 CONGEST 下界**、**共谋/自适应对手**模型；同步模型的工业对应物是「时间触发总线」（TTTech/时间敏感网络 TSN），属实时系统文献 |
| 6 | 🔧 现代视角 | 「同步轮」在数据中心内近似成立（微秒级延迟差），跨地域则退化为部分同步——同一协议在不同网络上应选 07 章或 10 章的解法，Spanner 用 TrueTime 硬买同步是后话（10 章） |
| 7 | 「随机化只解决性能问题」 | 3.2 节 identical 进程选举的不可能性被随机化**绕过**（以概率 1 破对称）——随机化改变可解性边界，不只优化常数 |
| 8 | 「同步 = 大家共用一个时钟」 | 同步模型只要求**轮的步调一致**（消息在轮界送达），进程无需真实时钟；把同步误解为时钟同步会低估其数学便利、高估其工程成本 |

## 本章速记卡

- 一句话：同步模型（按轮推进）是分布式算法的**理想实验室**——共识有解、下界精确。
- 对称破缺最低要求：唯一 ID；identical 进程的环选举不可能（随机化可绕）。
- 环选举：HS 算法 $O(n\log n)$ 消息，与比较型下界精确匹配。
- 停止故障共识：$f+1$ 轮精确；门限 $f<n/2$；两军问题（链路故障）不可能。
- 门限算术（$2f+1$、$3f+1$、$f+1$ 轮）是本章留给运维世界最常用的遗产。
