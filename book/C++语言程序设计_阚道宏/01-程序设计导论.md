## 核心概念速览（中英对照）

- **冯·诺依曼结构** — von Neumann architecture：程序与数据同存于存储器，CPU 取指-执行循环驱动一切
- **机器指令** — machine instruction：CPU 直接执行的二进制操作码，高级语言的最终归宿
- **程序副本** — program image：程序在磁盘上是文件、运行时装进内存的副本（本书贯穿后续章节的存储观）
- **程序设计/实现/测试/发布** — design / implementation / testing / deployment：§1.3 的四步开发流程
- **二进制数制** — binary numeral system：位、字节、补码与十六进制速记
- **数据类型** — data type：对比特序列的解读规则；`int`/`float`/`char` 是「同一存储的不同透镜」
- **数字化** — digitization：§1.4.3，数值/文本/图像/声音如何统一成二进制信息
- **编译与链接** — compilation and linking：源代码 → 目标码 → 可执行文件的流水线
- **集成开发环境** — IDE（Integrated Development Environment）：教材语境为 VC6，今天对应 VS/CLion/VS Code+工具链

## 动机：这一章在教材里的位置

阚书第 1 章不讲一行可运行的完整 C++，而是先把「计算机—程序—数据」三件套的世界观立起来，
这是它区别于多数入门教材的编排：**后续 2–4 章（数值计算/算法/数组与文字处理）全部建立在
「程序就是对二进制数据的分类处理」这一章的论断上**，C++ 只是执行这个论断的工具。
动机链：会算（2 章）→会控（3 章）→会存（4 章）→会拆（5–6 章结构化）→会归类（7–8 章 OOP）→会复用库（9–10 章）。

## 机制拆解（按已核实小节）

- **§1.1 硬件结构**：CPU/存储器/输入输出设备的总线连接；「程序功能=数据+算法」在此埋线。
  关键教学点：存储器按字节编址——这句直接决定 4 章字符编码、5 章存储原理的讲法。
- **§1.2 计算机程序**：源程序与目标程序、翻译（编译/解释）的区别。
- **§1.3 程序开发**：设计（流程图/伪码）→实现（编码）→测试（§1.3.3，教材口径为黑盒思路）→发布（§1.3.4）。
  「发布」单独列小节在入门教材里少见，体现作者工程背景（紫光国产化项目）的团队开发视角。
- **§1.4 信息分类与数据类型**：二进制数制→数据类型→信息数字化三级台阶；文本编码在此首次出现，
  为 4.5「中文处理」的 ANSI/Unicode 双轨埋线。
- **§1.5 C++语言简介**：从机器语言→汇编→高级语言→C→C++ 的演化叙事，定位 C++ 为「带类的 C + 抽象机制」。

## 权衡与相邻概念对比

- **自底向上（本书）vs 自顶向下（多数教材）**：先讲硬件与数字化，入门门槛更高但后续「编码/内存」章节几乎零障碍；
  先写 Hello World 的路线反馈快但内存模型普遍薄弱。两种没有绝对优劣，选教材=选叙事顺序。
- **数据类型 vs 位模式**：本教材反复强调「数据=比特+解释规则」，这与 C++ 标准 `object representation` 的口径一致；
  对比 Java 教材把类型系统交给虚拟机，C++ 阵营的教学传统必须尽早直面表示问题。
- **IDE（VC6 附录）vs 命令行**：VC6 时代「新建工程→Win32 Console」是操作主体；今天工具链换成
  CMake/编译器驱动，但「编译单元→目标文件→链接」的流水线概念完全同构——附录的教学价值在流水线，不在按钮位置。

## 最新演进与工业实践

**教材口径（2016/2017）→ 2026 现状**，逐点给三态编译实测（g++ 15.2；✅=通过 ❌=报错 ⚠️=通过但仅为 GCC 扩展）：

| 教学主题 | 当年写法 | 现代写法 | 实测结论 |
| --- | --- | --- | --- |
| 头文件与名字 | VC6 时代惯用 `#include <iostream.h>` + 无 `std::` | `#include <iostream>` + `std::cout` | 🔧 实测：现代 libstdc++ 中 `iostream.h` **在 c++98 与 c++23 下均不存在**（❌/❌）——该头是前标准化时代产物；教材正文（未能读到的部分除外 ⚠️）所依循的 `<iostream>`+`std::` 路线在两个标准下同样成立 |
| 主函数签名 | 旧教材常见 `void main()`（VC6 宽容） | `int main()` 返回退出码 | 🔧 实测：`void main()` 在 g++ 15.2 的 c++98/c++23 下**均报错**——从当年起 ISO 就不允许，现代编译器不再装看不见 |
| 二进制字面量 | `0x` 十六进制、`0` 八进制，二进制只能手写换算 | `0b1010`（C++14 起入标） | 🔧 实测：`0b1010` 在 c++98 下**也通过**（⚠️ GCC 向后扩展）——「编译器接受」≠「标准允许」，判年代要看 ISO/cppreference（C++14） |
| 数字分组 | `1000000` 数零 | `1'000'000` 撇号分隔（C++14） | 🔧 实测：c++98 ❌（撇号被解析成字符常量）、c++23 ✅ |
| 开发环境 | 附录 VC6（1998 年产品，教材 2016 仍在教） | VS 2022/VS Code+MinGW、CLion；在线编译器 Compiler Explorer | VC6 无 C++11 及以上支持是共识；本目录后续章的「教材写法」一律以 g++ `-std=gnu++98` 复现代口径 |

**现代教学运动的可核实产物**：ISO C++ 基金会站 [isocpp.org](https://isocpp.org)（FAQ 与「What is C++」文档，
CppCon 配套）与 [cppreference.com](https://cppreference.com)（标准文本的 wiki 镜像，编译器支持矩阵）是当下入门者
的「第二教材」；本书 1.4 的数制/编码内容在 cppreference「基础类型/数字字面量」页有权威现代版。
