# RustWeb开发

## 版本与 ISBN

- 原书名：*Rust Web Development*（Manning，2023）
- 作者：Bastian Gruber（前 Rust 官方异步工作组成员）
- 中文版：《Rust Web开发》，清华大学出版社（Web开发与设计丛书），2024-04
- ISBN：`978-7-302-65823-8`（344 页）
- 译者：赵永、邹松廷、卢贤泼

> 2026-09-22 由 202608 月度笔记（20260806 Rust 书单）整理。

## 笔记

- 定位：使用 Rust 构建服务端 Web 应用和微服务的实战指南，一本"工作手册"而非参考书。
- 技术栈：Tokio（异步运行时）+ Warp（Web 框架）+ Serde（序列化）+ Reqwest（HTTP 客户端）。
- 逐章迭代一个完整 Q&A 问答服务，覆盖 RESTful API、数据库集成、测试、追踪、Docker 部署。
