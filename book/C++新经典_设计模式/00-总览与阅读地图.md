## 阅读路线

1. **按原书直读（推荐首读）**：`01` → `02` → `03` → … → `14`，与原书 22 章一一对应（映射见上表）。
2. **三大类线（GoF 口径重切）**：创建型 `03`+`06`（单件）→ 结构型 `06`（装饰）`07`（外观）`08`（组合）
   `09`（享元）`10` `11`（桥接）→ 行为型 `02` `04` `05` `07`（命令）`08`（迭代器）`09`（状态）
   `11`（中介者）`12` `13`。适合已读过 GoF、想按类型横切对比的读者。
3. **游戏工程线（本书特色）**：`03`（刷怪/造装备）→ `05`（战斗事件）→ `06`（存档压缩）→ `07`（编辑器撤销）
   → `08`（场景树）→ `09`（AI 状态机 + 字形共享）→ `12`（存档点 + 审批流）→ `13`（脚本/技能解释器）。
   这条线回答：「一个游戏项目里，模式分别出现在哪块肌肉上」。
4. **2026 视角速览线**：只读各章「最新演进与工业实践」小节，横向得到「哪些模式已被现代 C++/引擎设施吸收、
   哪些仍要手写」的全景（variant+visit、concepts、协程、ECS、UE 反射、P2996 静态反射）。

## 姊妹卷辨析：《C++新经典》主体卷 vs 本书

「C++新经典」是王健伟的多卷系列（对象模型 / 模板与泛型编程 / Linux 通信架构 / 本书设计模式分卷）。
分工：**主体卷讲语言与对象模型本身**（虚表、构造语意、模板语法），**本书讲「用这些语言设施解决重复出现的
设计问题」**，且以游戏案例贯穿。对象模型是模式的「地基」（如 Visitor 的双分派成本由虚表机制决定），
本书则是地基之上的「房型」。`book/C++新经典/`（主体卷=《C++ 新经典：对象模型》目录版）已于 2026-09-27 落盘：[../C++新经典/00-总览与阅读地图.md](../C++新经典/00-总览与阅读地图.md)（本目录各章旧链保留单文件形态——单文件系合法共存笔记；注意其正文实混贴三册材料、登记 ISBN 对应对象模型卷，勘误见 [../C++系列·总索引.md](../C++系列·总索引.md) 收束记录第 3 条）。

## 读完应该能回答的十个问题

1. 为什么本书把简单工厂与工厂方法、抽象工厂放在同一章？三者的「决策推迟点」分别在哪？（`03`）
2. 模板方法「骨架在基类」与策略「整族算法可换」，什么场景必须先策略后模板？（`02`、`04`）
3. 观察者最大的工程坑是生命周期，weak_ptr 令牌/信号槽各解决到哪一层？（`05`）
4. 装饰器和 ranges view、单件和 `static` 局部变量，两组「语言吸收」例子各吃掉了模式的哪半边？（`06`）
5. 命令模式为什么是撤销/重做/宏/网络帧的公共底座？协程队列对它冲击在哪？（`07`）
6. 组合模式的透明式/安全式之辨，在 ECS 时代还重要吗？（`08`）
7. 状态模式：虚基类三件套、variant 状态机、转移表，成本曲线怎么 crossover？（`09`）
8. 代理与桥接都能「隔离实现」，分界线在哪？（`10`、`11`）
9. 备忘录在值语义语言里还需要 clone 吗？RAII 回滚和它谁更 C++？（`12`）
10. variant+visit 之后 GoF 双分派访问者还剩什么？反射（P2996/C++26）落地后注册样板会消失吗？（`13`、`14`）
