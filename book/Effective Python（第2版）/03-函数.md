# 第 3 章 函数（原书 pp.约 66–90）

> 条目 19–26。函数是最常用的抽象单元：返回值的粒度、异常 vs None、闭包变量作用域、参数列表设计、装饰器。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 19 | 不要把返回的多值拆分到三个以上变量 | 超过三个 → 返回专用结果对象/命名元组 |
| 20 | 遇到意外状况抛异常，不要返回 None | 返回 None 会被 `if result` 误判为真 |
| 21 | 了解闭包里如何使用外围变量 | 改写需 `nonlocal`；否则只捕获变量而非值 |
| 22 | 用可变长位置参数设计清晰参数表 | `*args` 收尾，仅用于同质序列 |
| 23 | 用关键字参数表示可选行为 | 可选参数用 `kwarg=value`，调用更可读 |
| 24 | 用 None+docstring 描述可变默认参数 | 可变默认（list/dict）必须用 None 占位 +  docstring 说明 |
| 25 | 用仅关键字/仅位置参数设计清晰列表 | 3.8 `/` 与 `*` 分隔，提升 API 稳定 |
| 26 | 用 functools.wraps 定义装饰器 | 保留原函数 `__name__`/`__doc__` |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 19：返回专用对象
from typing import NamedTuple
class RangeCount(NamedTuple):
    low: int
    high: int
    count: int
def count_range(it, low, high) -> RangeCount:
    ...

# 条目 20：异常而非 None
def careful_divide(a, b):
    if b == 0:
        raise ValueError("b must be nonzero")
    return a / b

# 条目 21：nonlocal
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

# 条目 24：可变默认参数陷阱
def bad(x, items=[]): ...      # 共享同一列表！
def good(x, items=None):
    items = [] if items is None else items

# 条目 25：仅位置/仅关键字
def func(pos_only, /, pos_or_kw, *, kw_only):
    ...

# 条目 26：装饰器
import functools
def trace(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(func.__name__, args)
        return func(*args, **kwargs)
    return wrapper
```

## 版本演进

- 3.8：仅位置参数 `/`（PEP 570），配合 `/` 与 `*` 可完全锁定签名（条目 25）。
- 3.0：print 变函数；3.5+ 类型注解常态化（条目 19 的 NamedTuple 更顺手）。
- 3.10：`X | Y` 联合类型注解（PEP 604），条目 19/24 的注解更简洁。

## 经典论文与原始文献

- PEP 570 — Python Positional-Only Parameters（条目 25）。
- PEP 604 — Allow writing union types as `X | Y`（条目 19/24 注解）。
- `functools.wraps` / `functools.partial` 文档（partial 在 [04-推导与生成.md](04-推导与生成.md) 条目 36 旁支）。
- `typing.NamedTuple` / `@dataclass`（条目 19 的现代替代，见 [05-类与接口.md](05-类与接口.md) 条目 51）。

## 近年研究与工业界开源实践（2015–2026）

- 装饰器广泛用于重试（`tenacity`）、缓存（`functools.cache`，3.9）、鉴权（FastAPI `Depends`）。
- 现代 API 设计普遍采用「仅关键字可选参数」减少误用（条目 25 的最佳实践）。
- `pydantic`/`dataclasses` 取代手写 NamedTuple 作返回对象（条目 19）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 可变默认参数「Bug」 | 条目 24 已讲清；🔧 静态分析（pylint W0102）可自动抓 |
| `nonlocal` 忘了写 | 闭包改写外层变量必须 `nonlocal`，否则新建局部变量 |
| 返回 None 表示失败 | 条目 20 强调应抛异常；否则调用方 `if not r` 会把 0/空串也当失败 |
| 装饰器丢了元数据 | 条目 26 强调 `@functools.wraps`；否则日志/测试按函数名路由会错 |
