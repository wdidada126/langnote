# 第 4 章 推导与生成（原书 pp.约 91–121）

> 条目 27–36。推导式与生成器是 Python 的标志性习惯用法：惰性求值、内存友好、可组合。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 27 | 用列表推导取代 map/filter | 可读性更好；多层循环仍优先循环 |
| 28 | 推导子表达式不要超过两个 | 超过两个控制流 → 抽成函数/普通循环 |
| 29 | 用赋值表达式消除推导重复 | `:=` 在推导里复用中间结果 |
| 30 | 让函数逐个生成值，别直接返回列表 | 返回生成器 `yield`，调用方决定要不要物化 |
| 31 | 谨慎地迭代函数收到的参数 | 参数可能是迭代器（一次性的），要先确认 |
| 32 | 用生成器表达式改写大数据列表推导 | `(x for x in big)` 省内存 |
| 33 | 用 yield from 串接生成器 | 委托子生成器，代码更平 |
| 34 | 不要用 send 给生成器注入数据 | 协程式 send 易错，改用 asyncio/Queue |
| 35 | 不要通过 throw 变换生成器状态 | 同上，`throw` 维护成本高 |
| 36 | 用 itertools 拼装迭代器 | `chain`/`islice`/`product` 等标准件 |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 27：列表推导 vs map
squares = [x*x for x in range(10)]            # 优于 list(map(...))

# 条目 29：:= 去重
seen = set()
uniq = [x for x in data if x not in seen and not seen.add(x)]
# 更清晰的写法（海象）
uniq = [x for x in data if (x not in seen) or seen.add(x) is None]  # 可读性仍一般
# 推荐：需要去重时直接用 dict/set 保序

# 条目 30：生成器函数
def gen_squares(n):
    for i in range(n):
        yield i*i                            # 惰性

# 条目 33：yield from
def combined(items):
    for it in items:
        yield from it                         # 委托

# 条目 36：itertools
import itertools
for combo in itertools.product("AB", range(2)):
    ...
```

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 推导里塞 3 层以上循环 | 条目 28 反对；改成显式 for 循环更易维护 |
| 把迭代器当列表重复用 | 条目 31：迭代器是一次性的，第二次遍历为空；需重复用先 `list()` 物化 |
| 用 `send`/`throw` 做协程 | 条目 34/35：现代用 asyncio（见 [07-并发与并行.md](07-并发与并行.md)）或 Queue |
| 生成器表达式末尾忘括号 | `(x for x in y)` 与 `[...]` 混用时优先级坑，必要时加括号 |
