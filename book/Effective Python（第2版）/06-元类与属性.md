# 第 6 章 元类与属性（原书 pp.约 153–190）

> 条目 44–51。属性访问控制的高阶手段：纯属性、`@property`、描述符、惰性属性、`__init_subclass__`、类装饰器 vs 元类。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 44 | 用纯属性与修饰器取代旧式 setter/getter | 直接 `self.x`，需要时再升级 |
| 45 | 用 @property 实现新访问逻辑，别急着重构 | 渐进式加校验/计算 |
| 46 | 用描述符复用 @property 逻辑 | 多个类共享同一验证 → 描述符类 |
| 47 | 用 `__getattr__`/`__getattribute__`/`__setattr__` 做惰性属性 | 延迟昂贵计算；注意递归陷阱 |
| 48 | 用 `__init_subclass__` 验证子类 | 子类定义即校验，比元类轻 |
| 49 | 用 `__init_subclass__` 记录子类 | 自动注册子类列表 |
| 50 | 用 `__set_name__` 给类属性加注解 | 描述符拿到自己的属性名 |
| 51 | 优先用类装饰器提供可组合扩充，不用元类 | 元类过重，类装饰器够用 |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 45：@property
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius
    @property
    def fahrenheit(self):
        return self._celsius * 9/5 + 32

# 条目 46：描述符
class Quantity:
    def __init__(self, name):
        self.name = name
    def __set__(self, instance, value):
        if value < 0:
            raise ValueError(f"{self.name} must be >= 0")
        instance.__dict__[self.name] = value

# 条目 47：惰性属性
class Lazy:
    def __getattr__(self, name):
        if name == "expensive":
            value = compute_expensive()
            setattr(self, name, value)
            return value
        raise AttributeError(name)

# 条目 48：__init_subclass__
class PluginBase:
    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        assert hasattr(cls, "run"), "must define run()"

# 条目 51：类装饰器
def logged(cls):
    cls._logged = True
    return cls
```

## 版本演进

- 3.6：`__set_name__`（PEP 487）让描述符拿到属性名（条目 50）。
- 3.6：`__init_subclass__`（PEP 487）成为元类的轻量替代（条目 48/49）。
- 3.7：`dataclasses` 内部即大量用描述符与 `__set_name__`（见 [05-类与接口.md](05-类与接口.md)）。

## 经典论文与原始文献

- PEP 487 — Simpler customisation of class creation（`__set_name__`/`__init_subclass__`，条目 48–50）。
- 官方「Descriptor HowTo Guide」（`docs.python.org/3/howto/descriptor.html`）——条目 46 必读。
- `functools.cached_property`（3.8）是条目 47 惰性属性的标准实现。

## 近年研究与工业界开源实践（2015–2026）

- `dataclasses` + `field`/`__post_init__` 取代手写描述符做校验（条目 46 现代版）。
- `pydantic`/`attrs` 把描述符与类装饰器封装成声明式模型，工业界标配。
- `@functools.cached_property`（3.8）是条目 47 惰性属性的官方答案。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 过早写 setter/getter | 条目 44：先纯属性，需要校验再加 `@property` |
| `__getattribute__` 里读属性触发无限递归 | 条目 47：需 `object.__getattribute__`/`__setattr__` 绕过自身 |
| 误用元类 | 条目 51：多数场景类装饰器或 `__init_subclass__` 就够了 |
| 描述符不实现 `__set_name__` | 条目 50：多实例共享描述符时拿不到属性名会出错 |
