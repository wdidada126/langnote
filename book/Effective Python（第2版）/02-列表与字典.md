# 第 2 章 列表与字典（原书 pp.约 37–65）

> 条目 11–18。Python 最常用的两个内置容器：切片的边界语义、排序 key、dict 顺序的演变、缺失键的三种处理手法。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 11 | 学会对序列做切片 | `a[start:stop:step]`，半开区间；负数与 None 边界 |
| 12 | 切片里不要同时指定起止与步进 | `a[::-1]` 反转可以，复杂步进易错 |
| 13 | 用 `*` 解包捕获多个元素 | `[first, *rest] = lst` 比切片更清晰 |
| 14 | 用 sort 的 key 表示复杂排序 | `key=` 返回可比较元组，避免 cmp 函数 |
| 15 | 不要过分依赖 dict 插入顺序 | ⚠️ 3.7+ 已保证插入顺序（PEP 520），本条需修正 |
| 16 | 用 get 处理缺失键 | `d.get(k, default)` 优于 `if k in d` |
| 17 | 用 defaultdict 处理内部状态缺失 | 计数/分组用 `defaultdict`，别用 setdefault |
| 18 | 用 `__missing__` 构造依赖键的默认值 | 自定义 dict 子类时覆写 `__missing__` |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 11/12：切片半开区间
nums = list(range(10))
assert nums[1:3] == [1, 2]          # stop 不含
assert nums[:3] == [0, 1, 2]
assert nums[::-1] == nums[::-1]     # 反转 OK

# 条目 14：key 返回元组
places = [("Japan", "Tokyo", 36), ("USA", "NYC", 8)]
places.sort(key=lambda p: (p[2], p[0]))   # 先人口后国名

# 条目 16/17：缺失键
counts = {}
for w in ["a", "b", "a"]:
    counts[w] = counts.get(w, 0) + 1

from collections import defaultdict
buckets = defaultdict(list)
for item in items:
    buckets[item.cat].append(item)

# 条目 18：__missing__
class AlwaysDict(dict):
    def __missing__(self, key):
        self[key] = 0
        return 0
```

## 版本演进

- 3.7：dict 插入顺序成为语言保证（PEP 520，原 CPython 3.6 实现细节）；`OrderedDict` 退居「需移动/相等语义不同」的 niche 场景。
- 3.7：`@functools.lru_cache` 等不变；3.9 新增 `dict`/`list` 合并运算符 `|`、`|=`（PEP 584），条目 16/17 可配合用。
- 3.12：dict 性能再优化（更紧凑的键共享）。

## 近年研究与工业界开源实践（2015–2026）

- 3.7+ 之后 `OrderedDict` 仅在需要「相等性按插入序」或 `move_to_end` 时用；日常顺序需求用普通 dict。
- PyPI `orjson` 等序列化库默认尊重 dict 顺序，JSON 配置可读性提升。
- 大数据场景用 `array`/`numpy` 结构化数组替代 list of dict，见 [08-稳定与性能.md](08-稳定与性能.md)。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 条目 15「不要过分依赖字典顺序」 | 🔧 3.7+ 起 dict 插入顺序已由语言保证（PEP 520），可放心依赖；仅在需「顺序参与相等比较」时用 `OrderedDict` |
| 以为切片会改原对象 | 切片返回新列表；原地改应用 `del a[i:j]` 或切片赋值 `a[i:j] = [...]` |
| `setdefault` 每次都构造默认对象 | 默认对象即使键存在也会被求值，浪费；用 `defaultdict` 或 `get` |
| `defaultdict` 误报 KeyError | 读不存在键会自动建空值，调试时难察觉；只读场景用普通 dict + `get` |
