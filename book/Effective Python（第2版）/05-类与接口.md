# 第 5 章 类与接口（原书 pp.约 122–152）

> 条目 37–43。何时该用类、如何用组合替代嵌套内置类型、接口应接受函数还是类、多态的三种实现、super 与 Mix-in。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 37 | 用组合类实现多层结构，别嵌套内置类型 | `dict` 套 `list` 套 `dict` 难维护 → 拆成小类 |
| 38 | 简单接口接受函数，而非类实例 | 单方法接口用 callable，更灵活 |
| 39 | 用 @classmethod 多态构造对象 | 工厂按子类分发，避免大量 `if` |
| 40 | 用 super 初始化超类 | MRO 正确；别硬编码父类名 |
| 41 | 用 Mix-in 类表示可组合功能 | 横切关注点（序列化/日志）抽成 Mix-in |
| 42 | 用 public 属性而非 private 表示受保护数据 | 单下划线约定即可，双下划线 name-mangling 坑多 |
| 43 | 自定义容器从 collections.abc 继承 | 只实现所需抽象方法，获全套 mixin 行为 |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 38：接受函数作接口
def download(build_request, parse_response):
    req = build_request()
    return parse_response(req)

# 条目 39：@classmethod 工厂
class InputData:
    def read(self): raise NotImplementedError
    @classmethod
    def from_file(cls, path):
        return _FileInputData(path)

# 条目 40：super
class Base: ...
class Child(Base):
    def __init__(self, x):
        super().__init__()
        self.x = x

# 条目 41：Mix-in
class ToDictMixin:
    def to_dict(self):
        return {k: v for k, v in vars(self).items()}

# 条目 43：collections.abc
from collections.abc import MutableMapping
class MyMap(MutableMapping):
    def __getitem__(self, k): ...
    def __setitem__(self, k, v): ...
    def __delitem__(self, k): ...
    def __iter__(self): ...
    def __len__(self): ...
```

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 双下划线私有属性 `__x` | 条目 42 不推荐：name-mangling 成 `_Class__x`，误用多；单下划线约定足矣 |
| 直接调父类 `__init__` | 条目 40 用 `super()`，多继承时 MRO 才不会错 |
| 过度设计接口 | 真单方法接口用 callable（条目 38），不必建类 |
| 自写容器不继承 abc | 条目 43：从 `collections.abc` 继承省去实现一堆 mixin 方法 |
