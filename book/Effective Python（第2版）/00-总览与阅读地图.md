> 整理日期：2026-10-02。基线 Python 3.7/3.8（原书 2e 写作时），本目录按 Python 3.12–3.14 校准，并在「常见误区与本书需修正之处」标注与 3e（2024）的差异。

## 一、这本书在讲什么

90 条「Specific Ways to Write Better Python」，沿用 Scott Meyers《Effective C++》的「场景化条目」写法：每条先给「该做 / 不该做」，再讲「为什么」。不是语法教程，是工程判断集。

- 作者：Brett Slatkin，Google 首席工程师（App Engine / Surveys / PubSubHubbub 共同作者）。
- 中文版：人民邮电出版社 ISBN 9787115562647；英文 2e Addison-Wesley ISBN 9780134853987。译者信息以版权页为准（🔧）。
- 篇幅：约 370–434 页（不同译本），90 条分 10 章。

## 三、与同类书的分工

- 《流畅的Python》= 语言模型（讲「Python 是什么」）；本书 = 规则集（讲「该怎么写」）。
- 《Python Cookbook》= 配方库（讲「怎么实现 X」）；本书 = 判断准则（讲「为什么选 A 不选 B」）。
- 阅读顺序建议：流畅的Python → Effective Python → Python Cookbook。

## 四、阅读层级

- 层级：核心主线（所有写 Python 的人都应读）。
- 状态：🟢 强烈推荐。2e 已纳入 typing 与现代并发；与《流畅的Python》互补。
