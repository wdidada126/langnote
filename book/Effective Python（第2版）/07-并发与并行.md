# 第 7 章 并发与并行（原书 pp.约 191–252）

> 条目 52–64。何时用 subprocess、线程、协程、进程；这是全书的难点，也是 3e 改动最大的区域之一。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 52 | 用 subprocess 管理子进程 | 调外部命令用 `subprocess.run`，别用 `os.system` |
| 53 | 线程做阻塞 I/O，别做并行计算 | GIL 下 CPU 密集用多进程 |
| 54 | 用 Lock 防数据竞争 | 共享状态加锁 |
| 55 | 用 Queue 协调线程工作 | 生产者/消费者用 `queue.Queue` |
| 56 | 判断什么场合必须并发 | 先确认瓶颈是 I/O 还是 CPU |
| 57 | 别每次 fan-out 都新建 Thread | 复用线程池 |
| 58 | 正确重构以便用 Queue 做并发 | 把任务封装成可入队单元 |
| 59 | 线程并发考虑 ThreadPoolExecutor | `concurrent.futures` 比手写 Thread 简洁 |
| 60 | 用协程实现高并发 I/O | `async`/`await` 单线程高并发 |
| 61 | 用 asyncio 改写线程 I/O | 旧线程代码迁移到协程 |
| 62 | 结合线程与协程迁移到 asyncio | `loop.run_in_executor` 桥接阻塞调用 |
| 63 | 保持 asyncio 事件循环畅通 | 不在协程里跑阻塞代码 |
| 64 | 用 concurrent.futures 做真正并行 | CPU 密集用 `ProcessPoolExecutor` |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 52：subprocess
import subprocess
result = subprocess.run(["ls", "-l"], capture_output=True, text=True, check=True)

# 条目 54/55：线程 + Queue
from threading import Thread, Lock
from queue import Queue
lock = Lock(); q = Queue()
def worker():
    while True:
        item = q.get()
        if item is None: break
        with lock: process(item)
        q.task_done()

# 条目 59/64：Executor
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor
with ThreadPoolExecutor(max_workers=8) as ex:
    results = list(ex.map(fetch, urls))
with ProcessPoolExecutor() as ex:           # CPU 密集
    results = list(ex.map(heavy, data))

# 条目 60：asyncio 协程
import asyncio
async def fetch_async(url):
    await asyncio.sleep(0)                  # 真实场景是 aiohttp 等
    return url
async def main():
    await asyncio.gather(*[fetch_async(u) for u in urls])

# 条目 63：桥接阻塞调用（3.9+ asyncio.to_thread）
async def bridge():
    await asyncio.to_thread(blocking_io)
```

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 线程能加速 CPU 密集任务 | 条目 53：GIL 下不能；用 `ProcessPoolExecutor`（🔧 3.13 free-threading 例外） |
| 协程里调阻塞函数 | 条目 63：会卡住整个事件循环；用 `asyncio.to_thread`（3.9+） |
| `os.system`/`popen` | 条目 52：用 `subprocess.run` 更安全可控 |
| 每次请求 new Thread | 条目 57：用线程池，避免线程爆炸 |
| 裸 asyncio 管理任务 | 🔧 3.12+ 用 `TaskGroup` 统一取消与异常传播 |
