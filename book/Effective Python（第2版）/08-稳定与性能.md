# 第 8 章 稳定与性能（原书 pp.约 253–299）

> 条目 65–74。异常处理的正确结构、资源管理与 with、时间/序列化/精度的坑、先做性能剖析再优化、 deque/bisect/heapq/memoryview 等高效容器。

## 本章地图

| 条 | 标题 | 结论 |
|---|---|---|
| 65 | 用 try/except/else/finally 各块 | else 跑「不抛异常才执行」，finally 保证清理 |
| 66 | 用 contextlib 与 with 复用 try/finally | `@contextmanager` 把清理逻辑变上下文 |
| 67 | 用 datetime 处理本地时间，别用 time | `time` 模块难处理时区/日期算术 |
| 68 | 用 copyreg 做可靠 pickle | 自定义类 pickle 需注册构造器 |
| 69 | 需要精确计算时用 decimal | 金融/货币别用 float |
| 70 | 先分析性能，再优化 | 用 cProfile/timeit，别凭直觉 |
| 71 | 用 deque 实现生产者-消费者队列 | 两端操作 O(1)，优于 list |
| 72 | 用 bisect 搜已排序序列 | 维护有序列表后二分插入/查找 |
| 73 | 用 heapq 做优先级队列 | 堆实现，O(log n) 入队 |
| 74 | 用 memoryview/bytearray 零拷贝处理 bytes | 大二进制避免复制 |

## 核心精讲

```python
# 教学示意，不参与构建
# 条目 65：try 结构
try:
    data = load()
except FileNotFoundError:
    log("missing")
else:
    process(data)            # 仅当无异常
finally:
    cleanup()

# 条目 66：contextmanager
from contextlib import contextmanager
@contextmanager
def open_db(path):
    db = connect(path)
    try:
        yield db
    finally:
        db.close()

# 条目 67：datetime
from datetime import datetime, timezone
now = datetime.now(timezone.utc)

# 条目 69：decimal
from decimal import Decimal, getcontext
getcontext().prec = 28
price = Decimal("19.99")

# 条目 71/72/73：高效容器
from collections import deque
from bisect import bisect_left
import heapq
dq = deque(maxlen=10); dq.append(1)
heap = []; heapq.heappush(heap, 5)

# 条目 74：memoryview
buf = memoryview(bytearray(b"hello"))
```

## 版本演进

- 3.9：`zoneinfo`（PEP 615）内置时区数据库，条目 67 不再依赖 `pytz`。
- 3.11：`datetime` 不可变对象可用 `replace`；性能提升。
- 3.12：`timeit`/`cProfile` 仍是剖析首选；`perf` 系统级剖析可配合。
- 3.13：`copyreg`/`pickle` 仍在，但 PEP 594 弃用了 `pickle` 的部分旧依赖（🔧 以文档为准）。

## 近年研究与工业界开源实践（2015–2026）

- `zoneinfo` 取代 `pytz`（条目 67 现代写法，`pytz` 的 LMT 怪异行为已过时）。
- 性能剖析：`py-spy`/`scalene`（2020+）做采样剖析，比 cProfile 更低开销。
- `orjson` 比 `pickle`/标准 `json` 更快且默认尊重 dict 顺序（条目 68/74 的序列化替代）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用 float 算钱 | 条目 69：二进制浮点不精确，货币用 `Decimal` 或整数分 |
| `time.time()` 做时区计算 | 条目 67：用 `datetime`+`zoneinfo`，别手算偏移 |
| 凭感觉优化 | 条目 70：先 cProfile，热点往往出乎意料 |
| list 当队列 `pop(0)` | 条目 71：`pop(0)` 是 O(n)，用 `deque` |
| pickle 直接序列化自定义类 | 条目 68：类定义变更后反序列化失败，用 `copyreg` 注册 |
