## 分层阅读路线

1. 教材地基（原理层，四选一主线）：《数据库系统概念》（Silberschatz，第 6 版已有目录版、第 7 版单文件）→ 或《数据库系统概论》（王珊，第 5/6 版）→ 或《数据库管理系统原理与设计》（Elmasri）→《数据库系统实现》（Ullman/Garcia-Molina）；国产新教材《数据库管理系统——从基本原理到系统构建》（李国良，2024）与 openGauss 系配套。
2. 内核与理论（源码级理解）：`book/Database_Internals/`（目录版，Petrov）与单文件《数据库系统内幕》同源 →《Readings in Database Systems》红宝书（`book/Readings_in_Database_Systems/`）→ 关系理论（`book/SQL_and_Relational_Theory/`）→ 事务三部曲（见"易混淆辨析"第 4 条）→ CMU 15-445 课程笔记（`数据库管理系统.md`）。
3. 引擎与运维（MySQL 线为主）：`book/mysql/`（《MySQL 是怎样运行的》目录版，索引/MVCC/EXPLAIN 必读）→《高性能MySQL》→《MySQL技术内幕：InnoDB存储引擎》→ 调优四书（千金良方/MySQL8查询性能优化/性能调优与架构设计/数据库高效优化）→ 运维三书（运维内参/DBA工作笔记/排错指南）→ 高可用。旁支：MariaDB、PostgreSQL 内核×3、openGauss×2、Oracle 体系结构+调优+管理。
4. NoSQL：Redis 五书+master-redis（先《Redis设计与实现》再《Redis深度历险》按趣味/深度取舍；Redis5设计与源码分析更新版次）。
5. 分布式数据库 → 数据仓库 → 数据湖仓：《分布式数据库入门进阶与实战》目录版（配合分布式系列索引的一致性书目）→ Kimball 维度建模（《数据仓库工具箱》第 3 版精读为主体）→《大数据之路》阿里数据中台 → 平台构建类 → 建模与治理（血缘/清洗/数据架构）→ 湖仓一体全家桶（`book/The_Data_Lakehouse/`、Delta/Hudi/Iceberg/Paimon 各目录版 + `db/db.md` 的 24 篇论文索引）。

📄 论文列表
数据库领域经典论文数量庞大，这里列出几篇具有里程碑意义的，作为起点：

关系模型与查询处理

“A Relational Model of Data for Large Shared Data Banks”（Codd, 1970）：关系模型的奠基之作，开创了现代数据库的理论基础。

“Efficiently Compiling Efficient Query Plans for Modern Hardware”（Neumann, VLDB 2011）：编译器式查询处理的开创性工作，获 2021 年 Test of Time Award，推动了从解释执行到编译执行的范式转变。

事务与恢复

“The Transaction Concept: Virtues and Limitations”（Jim Gray, VLDB 1981）：事务概念的经典阐述，奠定了事务处理的地位。

概率与不确定数据

“Efficient Query Evaluation on Probabilistic Databases”（Dalvi & Suciu, VLDB 2004）：概率数据库的奠基性工作，引入了可能世界语义和复杂度二分法。

排序与硬件意识

“AlphaSort: A RISC Machine Sort”（Nyberg 等, SIGMOD 1994）：展示了缓存意识编码的重要性，对查询处理策略产生了深远影响。

架构反思

“Database Systems: Achievements and Opportunities”（Lagunita Report, 1990）：对数据库系统研究方向的重要反思，提出了“改革”与“综合”的研究议程
