# 《The Joy of Kotlin》——总览与阅读地图

> 目标书：*The Joy of Kotlin*，Pierre-Yves Saumont，Manning，2019（⚠️ ISBN 凭记忆不写死，待核验）。
> 用户粘贴的第三方结论评 ★★★★（函数式线）；官方书目页在列 ✅。

## 一、定位

与《Functional Programming in Kotlin》同题不同路：Saumont 以**渐进重构叙事**（一段坏代码一路改到代数结构）讲 FP，含偏函数、Try/Either、惰性、尾递归(TRO)、直到 Monad 与 Lenses；工程妥协味比 Apress 本轻，理论步子更大。两本对读时：概念骨架取 FPIK，讲解手感取本书（⚠️ 本仓预设立场，读后裁决）。

## 二、骨架（⚠️ 章名以版权页为准）

| 部分 | 覆盖 | 老手注意 |
|---|---|---|
| Ⅰ 基础 | 函数/递归/集合操作/Option | 快跑 |
| Ⅱ 错误处理 | Either/Try/偏函数/组合 | **偏函数+Either 链是本仓最实用段** |
| Ⅲ 进阶 | TRO、Currying、Memoization、LIFO 结构、并行 | 并行段年代早（Future 线），**以 KiA2e 协程为准绳降权 ⚠️** |
| Ⅳ 类型类线 | Functor/Monad 接口化 | Kotlin 无 typeclass 的模拟天花板观察位 |

## 三、🔧 实测口径

每部分一个单文件演进链：同一问题从命令式改到 Either 组合，kotlinc 逐步编译留三个版本对照输出；Lenses 用 data class + `copy` 验证局限（不可变深改痛点 ↔ 官方 `kotlin.lenses` 草案 ⚠️ 状态待查）。
