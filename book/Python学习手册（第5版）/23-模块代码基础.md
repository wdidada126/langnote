## 核心精讲
`__name__ == "__main__"` 区分「直接运行」与「被导入」，是标准入口守卫。

```
教学示意，不参与构建
# mymod.py
def main():
    print("run")
if __name__ == "__main__":
    main()
```

- 3.4 `pathlib.Path` 取代 `os.path` 做路径拼装与读写（跨平台、链式）。
- 3.x 重载用 `importlib.reload(mod)`（2.x 的 `reload` 已移除）。

- `pathlib` 已成标准；`tomllib` 读 `pyproject.toml`/配置。
- `importlib.resources`（3.7）读取包内数据文件，替代 `__file__` 相对路径 hack。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 用 `os.path` 拼路径 | 优先 `pathlib.Path`，自动处理分隔符 |
| 顶层直接跑脚本代码 | 用 `if __name__ == "__main__":` 守卫，便于被导入复用 |
| 配置用 ini/json 随意 | 新项目优先 TOML（`tomllib`，3.11+，标准库） |
