## 核心精讲
`class` 定义类；`__init__` 构造实例；方法首参 `self` 是调用时的实例。`super()` 调用父类方法。

```
教学示意，不参与构建
class Animal:
    def speak(self):
        return "..."
class Dog(Animal):
    def speak(self):
        return "woof"
    def __init__(self, name):
        self.name = name
d = Dog("Rex")
print(d.speak(), d.name)
```

- 3.0+ 无参 `super()` 自动绑定（`super().__init__()`）。
- 3.7 `dataclass`：加 `@dataclass` 自动生成 `__init__`/`__repr__`/`__eq__`。
