## 核心精讲
Python 变量是「名字标签」而非「盒子」；赋值 `a = x` 让 `a` 引用 `x` 的对象。类型属于对象，不属于名字。

```
教学示意，不参与构建
a = [1, 2, 3]
b = a            # b 与 a 引用同一列表
b.append(4)
print(a)         # [1, 2, 3, 4] 被改动了！
a = 99
b = a
# 现在 a 与 b 都指向整数 99（整数不可变，无副作用）
```

- `is` 比较身份（同一对象），`==` 比较值。
- `id()` 查看对象标识；`del` 删除名字绑定。

## 版本演进

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 认为「变量有类型」 | 类型属于对象；名字只是引用 |
| 共享引用无害 | 对可变对象（list/dict/set）的就地修改会经多个名字暴露，注意拷贝 |
| 用 `is` 比较值 | 仅比较身份；值相等用 `==`（`小整数池` 属实现细节，勿依赖） |
