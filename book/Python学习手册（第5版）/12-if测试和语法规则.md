## 核心精讲
`if` 做真值测试；「假」集合：False/None/0/空容器/空字符串。3.10 新增 `match`/`case` 结构化模式匹配。

```
教学示意，不参与构建
x = 10
s = "big" if x > 5 else "small"     # 三元
match x:
    case 0:
        print("zero")
    case n if n > 0:                  # 守卫
        print("positive", n)
    case _:
        print("other")
```

- 真值可由对象定义 `__bool__`/`__len__` 自定义（见 [27-类代码基础](27-类代码基础.md)）。
- `match` 支持序列/映射/类/`*` 通配等多种模式（PEP 634）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 原书未含 `match` | 3.10+ 优先用 `match` 替代「if/elif 链 + isinstance」解析 |
| `if x:` 当 `if x is not None` | 二者语义不同：空串/0/空列表也视为假 |
| 用 `== True` | 直接 `if cond:`，勿与布尔常量比较 |
