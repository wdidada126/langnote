## 核心精讲
属性查找沿实例→类→基类（MRO）进行。三种方法：`实例方法`（self）、`@classmethod`（cls）、`@staticmethod`（无隐参）。

```
教学示意，不参与构建
class C:
    def inst(self): ...
    @classmethod
    def cls_m(cls): ...
    @staticmethod
    def st_m(): ...
    def __call__(self, x):
        return x * 2
c = C()
print(c(3))            # 6，实例可调用
```

- 单下划线 `_name` 约定「受保护」；双下划线 `__name` 触发 name mangling（`_C__name`，仅轻度混淆）。
- 实现 `__call__` 让实例像函数（结合闭包见 [17-作用域](17-作用域.md)）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 双下划线=私有强制 | Python 无真正私有；`__` 只是 name mangling，仍可访问 |
| 滥用 `@staticmethod` | 不需要类/实例状态时往往是模块级函数更合适 |
| MRO 靠猜 | 用 `Class.__mro__`/`help()` 查看确定顺序 |
