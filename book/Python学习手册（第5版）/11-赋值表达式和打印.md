## 核心精讲
3.x 中 `print` 是内置函数；赋值支持序列拆包与 3.8 的「海象」`:=` 在表达式内绑定。

```
教学示意，不参与构建
print("a", "b", sep="-", end="!\n")   # a-b!
# 序列拆包
first, *rest = [1, 2, 3, 4]            # first=1, rest=[2,3,4]
# 海象：在 while/推导里复用计算结果
while (line := f.readline()):
    print(line.rstrip())
```

- 3.8 `:=` 可在条件/推导中赋值并立即使用，避免重复调用。
- 3.10 `match` 也可做解构（见 [12-if测试和语法规则](12-if测试和语法规则.md)）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 2.x `print x` 语句写法 | 3.x 必须 `print(x)`，否则 `SyntaxError` |
| 海象滥用 | 仅在「计算一次、用多次」时提升可读性，否则反而难读 |
| `print` 当日志 | 生产代码用 `logging`，可分级与重定向 |
