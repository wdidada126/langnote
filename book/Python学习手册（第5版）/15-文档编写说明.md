## 核心精讲
文档字符串（docstring）是对象的首个语句字符串，被 `help()`、`pydoc`、Sphinx 读取；注释解释「为什么」而非「是什么」。

```
教学示意，不参与构建
def add(a: int, b: int) -> int:
    "返回 a 与 b 之和。"
    return a + b
print(add.__doc__)          # 返回 a 与 b 之和。
```

- PEP 257 约定：单行 docstring 用三引号一句；多行首句 summary、空行后详述。
- `doctest` 把 docstring 里的 `>>>` 示例当单元测试跑。

## 版本演进
- 3.5+ 类型注解写入签名（见 [16-函数基础](16-函数基础.md)），与 docstring 互补。
- 3.x `pydoc` 仍可用；现代项目多用 Sphinx + `autodoc`/`myst`。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 把注释当 docstring | docstring 给用户（API 含义），注释给维护者（实现理由） |
| docstring 重复签名 | 用类型注解表达参数类型，docstring 讲语义与边界 |
| 不写 docstring | 公共 API 必写；私有/明显函数可省 |
