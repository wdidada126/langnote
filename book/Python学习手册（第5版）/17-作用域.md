## 核心精讲
名称查找顺序 L-E-G-B：Local → Enclosing → Global → Built-in。嵌套函数形成闭包，捕获外层变量。

```
教学示意，不参与构建
def outer(n):
    def inner(x):
        return x + n        # 捕获外层 n（闭包）
    return inner
add5 = outer(5)
print(add5(10))             # 15
```

- `global x` 声明修改模块级变量；`nonlocal x` 修改外层（非 global）变量。
- 滥用 `global` 破坏封装，能用参数/返回值就别用全局状态。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 在函数中改全局不声明 | 会创建同名局部变量，值未变且易错；需 `global` 或改用类/返回值 |
| 循环变量被闭包捕获 | 延迟调用会拿到最终值；用默认参数 `f(i=i)` 或 `partial` 固定 |
| 作用域靠缩进 | 作用域按 `def`/`lambda`/`class`/`comprehension` 划分，非任意缩进 |
