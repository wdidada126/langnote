## 核心精讲
Python 一切皆对象，内置类型是「电池已备」：数字、字符串、列表、字典、元组、文件、集合、布尔、None。

```
教学示意，不参与构建
s = "python"
print(s[0], s[-1], s[1:4])   # p n yth
lst = [1, 2, 3]
lst.append(4)                 # 可变
t = (1, 2)                    # 不可变
```

- 通用序列协议：索引、切片、拼接、成员、`len()`、`for` 迭代，对字符串/列表/元组一致。
- 用 `dir(obj)`、`help(obj)` 探查类型方法与文档。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 原书强调「字典无序」 | 3.7+ 已保序，可放心依赖插入顺序 |
| 自定义类型总优于内置 | 优先内置类型与 `collections`/`dataclasses`，性能更好 |
| 切片产生副本的误用 | 列表切片是浅拷贝新列表，大对象注意开销 |
