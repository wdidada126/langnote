# 概念专篇：动态类型与共享引用

> 第 6 章延伸。解释 Python「名字—对象—引用」模型与由此产生的可变性陷阱。

## 核心模型
- 赋值 `a = x` 让名字 `a` **绑定**到对象 `x`；类型属于对象，不属于名字。
- 多个名字可绑定同一对象（共享引用）。`id()` 给出对象身份，`is` 比较身份。

```
教学示意，不参与构建
a = [1, 2]
b = a                 # 共享同一列表对象
a.append(3)
print(b)              # [1, 2, 3] 被改动（因为是可变对象）
```

## 可变 vs 不可变
- 不可变（int/str/tuple/bytes/frozenset）：`+=` 等会**新建对象**并让名字 rebind，不会经其他名字暴露。
- 可变（list/dict/set/bytearray/自定义实例）：就地修改会经所有共享名字可见。

## 常见陷阱
1. 默认参数用可变对象：`def f(x=[])` 多次调用共享同一列表（见 [18-参数](../18-参数.md)）。
2. 拷贝：浅拷贝只复制顶层引用；嵌套可变对象需 `copy.deepcopy`。
3. 函数返回内部可变结构：调用方意外修改影响原对象，必要时返回副本。

## 版本演进
- 基本语义自 2.x 稳定；3.x 删除 `long`/`unicode`，类型集合收敛。
- 静态类型注解（3.5+）不改变运行时引用语义，但让 IDE 更易发现共享误用。
