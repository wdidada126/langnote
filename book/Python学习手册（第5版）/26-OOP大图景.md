## 核心精讲
类把数据（属性）与操作（方法）捆绑；实例是类的具体对象。继承实现「是一个」关系，组合实现「有一个」。

```
教学示意，不参与构建
class Point:
    "二维点"
    def __init__(self, x, y):
        self.x, self.y = x, y
    def dist(self, other):
        return ((self.x-other.x)**2 + (self.y-other.y)**2) ** 0.5
p = Point(0, 0)
```

- 类也是对象（可赋值、传参、做工厂，见 [32-类的高级话题](32-类的高级话题.md)）。
- 「优先组合而非继承」是工程共识，避免脆弱的深层继承。

## 版本演进
- 3.x 所有类默认为新式类（2.x 需显式 `object`）。
- 3.6 `__init_subclass__`（PEP 487）、3.7 `dataclasses`（PEP 557）简化类定义。

## 近年研究与工业界开源实践（2015–2026）
- `dataclasses`（3.7）让数据类几乎零样板；`pydantic`/`attrs` 增强了校验与序列化。
- `mypy`/`pyright` 对类层次与 `Protocol`（结构化子类，3.8）支持成熟。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 一切皆用类 | 简单数据用 `dataclass`/`NamedTuple`，过程用函数，勿为 OOP 而 OOP |
| 深层继承树 | 用组合、`mixin`、`Protocol` 更稳 |
| 类需显式继承 object | 3.x 已默认新式类，无需写 `(object)` |
