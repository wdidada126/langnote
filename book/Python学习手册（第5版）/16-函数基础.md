## 核心精讲
`def` 创建函数对象并绑定名字；调用即执行；`return` 返回（无则 `None`）。函数是头等对象，可赋值、传参、返回。

```
教学示意，不参与构建
def greet(name):
    "返回问候语"
    return f"Hello, {name}"
shout = greet          # 函数也是对象
print(shout("world"))
```

- 函数是「可调用对象」，实现 `__call__` 的类实例也可被调用（见 [29-类代码细节](29-类代码细节.md)）。
- 3.0+ `print`/`len` 等均为函数；早期内置也可被重绑定（不推荐）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 注解会强制类型 | 运行时仍不检查；需类型检查器或 `pydantic`/`beartype` |
| 函数必 `return` | 无 return 返回 `None`，调用方勿误用 |
| 重绑定内置名 | 如 `list = [...]`，会遮蔽内置，极危险 |
