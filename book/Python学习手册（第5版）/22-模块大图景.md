## 核心精讲
模块 = 一个 `.py` 文件；`import mod` 执行该文件一次，结果缓存于 `sys.modules`，后续 import 直接复用。

```
教学示意，不参与构建
import math
print(math.sqrt(2))          # 模块属性访问
import os.path as p          # 别名
from collections import Counter   # 取属性进当前命名空间
```

- `import` 触发「执行模块体」；顶层代码副作用会在此刻发生，故模块顶层应少做重活。
- `from x import *` 易污染命名空间，不推荐（受 `__all__` 约束）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 循环 import 报错无解 | 推迟导入（函数内）、重构公共依赖、或用 `import mod` 后访问属性 |
| `from x import *` 随意 | 污染命名空间；显式 `from x import a, b` 或 `import x` |
| 模块顶层做重活 | 顶层放定义，重活放 `main()` 或 `if __name__ == "__main__":` |
