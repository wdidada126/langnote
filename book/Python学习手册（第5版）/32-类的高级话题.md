## 核心精讲
可子类化内置类型（如 `list`/`dict`）以扩展行为；现代更常用 `collections.UserDict` 等做安全扩展。

```
教学示意，不参与构建
from collections import UserList
class MyList(UserList):
    def sum(self):
        return sum(self.data)
```

- 3.6+ `__init_subclass__`（PEP 487）让基类在子类定义时收到钩子，常替代轻量元类。
- 属性/描述符/`__getattr__` 是「托管属性」核心（见 [38-托管属性](38-托管属性.md)）。

## 版本演进
- 3.6 `__init_subclass__`（PEP 487）替代大量元类用例。
- 3.7 `dataclasses` 简化数据类；3.10 `slots=True` 省内存。
- 3.x 删除旧式类，统一新式类模型。

## 近年研究与工业界开源实践（2015–2026）
- `attrs`/`pydantic` 用 `__init_subclass__`/`__set_name__` 实现声明式字段。
- 元类多用于框架（ORM、序列化），业务代码少用（见 [40-元类](40-元类.md)）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 直接子类化 dict 存数据 | 需要额外行为用 `UserDict`/`collections` 更安全；纯数据用 `dataclass` |
| 用元类做小事 | `__init_subclass__`/`dataclass` 通常足够，元类留给框架 |
| `super` 仅调父类 | 多继承下 `super()` 沿 MRO 协作，非「父类的父类」 |
