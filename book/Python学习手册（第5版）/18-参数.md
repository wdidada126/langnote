## 核心精讲
Python 参数传递是「对象引用传递」：形参接收实参对象的引用。可变对象会被函数内修改影响调用方。

```
教学示意，不参与构建
def f(a, b=1, *rest, c, **kw):    # b 默认；c 仅关键字；rest/kw 收集
    return (a, b, c, rest, kw)
def bad(x=[]):                    # 反例：可变默认在 def 时创建一次
    x.append(1); return x
```

- 3.8 `/` 标记仅位置参数；`*` 之后为仅关键字参数（PEP 570 / PEP 3102）。
- 可变默认值是经典坑：用 `None` 占位，函数体内初始化。

## 版本演进
- 3.0 仅关键字参数 `*`（`def f(*, k)`）。
- 3.8 仅位置参数 `/`（PEP 570）。
- 3.5+ 类型注解写在参数上（PEP 484）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 「Python 是值传递/引用传递」 | 准确说是「对象引用传递」，效果取决于对象可变性 |
| 用 `[]`/`{}` 作默认参数 | 多次调用共享同一对象，改用 `None` 初始化 |
| 关键字参数顺序随意 | 仅关键字参数须放 `*` 后，位置参数在前 |
