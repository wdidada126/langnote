## 核心精讲
元组 `()` 不可变、常用于「记录」与多返回值拆包；文件用 `open()` + `with` 自动关闭。

```
教学示意，不参与构建
point = (3, 4)
x, y = point                 # 拆包
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:           # 文件本身是可迭代器
        print(line.rstrip())
s = {1, 2, 2, 3}             # {1,2,3} 集合去重
```

- 集合：去重、成员判定、交并差（`& | -`）。
- 集合推导 `{x for x in ...}`（3.x）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 元组「完全不可变」 | 元组内若含可变元素（如列表），该元素内容可变 |
| 忘记指定文件编码 | 3.x 不指定可能按系统默认（非 UTF-8）解码报错，显式 `encoding="utf-8"` |
| `tuple` 当不可变列表滥用 | 元组语义是「记录」，大量同构数据用 `list` 更贴切 |
