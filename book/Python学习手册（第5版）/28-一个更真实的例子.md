## 核心精讲
本章用「记录/集合」类串起构造、方法、持久化与展示，体现类如何承载真实业务逻辑。

```
教学示意，不参与构建
import json
from dataclasses import dataclass, asdict

@dataclass
class Record:
    id: int
    name: str
    def to_json(self):
        return json.dumps(asdict(self), ensure_ascii=False)
    @classmethod
    def from_json(cls, s):
        return cls(**json.loads(s))
```

- 3.7 `dataclass` + `asdict` 让「类↔字典↔JSON」零样板（比原书 `pickle` 更安全可移植）。
- `__repr__` 给调试、`__str__` 给用户；都建议实现。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 用 `pickle` 做通用持久化 | `pickle` 不可信数据有安全风险且跨版本脆弱；优先 `json`/`dataclass` |
| 只写 `__str__` | 调试用 `__repr__` 同样重要，建议二者都给 |
| 用类承载无状态逻辑 | 无状态过程用函数/模块更轻 |
