## 核心精讲
`lambda` 写匿名单行函数；`functools.partial` 固定部分参数；`functools.lru_cache` 记忆化；`functools.reduce` 折叠（现多用 `sum`/`for`）。

```
教学示意，不参与构建
from functools import partial, lru_cache
double = lambda x: x * 2
add = lambda a, b: a + b
inc = partial(add, 1)
@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
```

- 3.9 `lru_cache` 有 `cache` 便捷版（无 maxsize）。
- 3.12 函数头部可用 `type T = ...` 泛型（PEP 695）。

## 版本演进

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 大量用 `lambda` | 复杂逻辑用 `def`；`lambda` 仅适合单行 |
| `reduce` 最优先 | 求和用 `sum`，累计用 `for`，`reduce` 可读性差 |
| 注解当约束 | 运行时仍不校验，需 `beartype`/`pydantic` |
