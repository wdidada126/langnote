## 核心精讲
优化前先基准测试。`timeit` 自动多次运行取最优，避免单次计时的噪声。

```
教学示意，不参与构建
import timeit
print(timeit.timeit("sum(range(1000))", number=10000))
# 更严谨：用 pytest-benchmark / perf 做统计分析
```

- 优先用 `cProfile` 找热点，而非微观优化。
- 复杂度比常数因子重要（见算法分析 [../像计算机科学家一样思考Python（第2版）/21-算法分析.md](../像计算机科学家一样思考Python（第2版）/21-算法分析.md)）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 凭直觉优化 | 先 `cProfile` 定位热点，再动手 |
| 单次 `time` 计时 | 用 `timeit`/`perf` 多轮统计，排除抖动 |
| 忽视算法复杂度 | 常数优化救不了 O(n²)，先改结构 |
