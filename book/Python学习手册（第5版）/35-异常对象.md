## 核心精讲
自定义异常应继承 `Exception`（而非 `BaseException`），并按领域建层次，便于调用方分组捕获。

```
教学示意，不参与构建
class AppError(Exception):
    pass
class ValidationError(AppError):
    def __init__(self, field, msg):
        self.field = field
        super().__init__(f"{field}: {msg}")
```

- 内置异常：如 `ValueError`/`KeyError`/`TypeError`/`OSError` 及其子类（如 `FileNotFoundError`）。
- 3.x 异常有 `__traceback__` 属性；3.11 `ExceptionGroup` 携带多个异常（见 [36-用异常来设计](36-用异常来设计.md)）。

## 版本演进

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 继承 `BaseException` | 自定义业务异常继承 `Exception`；`BaseException` 只给解释器级信号 |
| 抛宽泛 `Exception` | 抛具体子类，调用方可精准处理 |
| 异常不带上下文 | 把关键字段（如出错的 field/id）挂到异常实例上，便于诊断 |
