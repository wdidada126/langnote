## 核心精讲
列表 `[]` 与字典 `{}` 是日常最频繁的两种容器；二者皆可变、可嵌套、支持推导式。

```
教学示意，不参与构建
lst = [x*x for x in range(5)]            # [0,1,4,9,16]
d = {f"k{i}": i for i in range(3)}       # 3.7+ 保序
d["new"] = 9
print(list(d.items()))                   # [('k0',0),('k1',1),('k2',2),('new',9)]
import copy
deep = copy.deepcopy(lst)                # 嵌套结构用深拷贝
```

- 字典视图 `d.keys()` 等是动态的，反映实时变化。
- `list`/`dict` 拷贝：切片或 `list()` 为浅拷贝；嵌套用 `copy.deepcopy`。

## 版本演进
- 3.7 字典保序（PEP 520，🔧 3.6 为 CPython 实现细节，3.7 正式保证）。
- 3.9 `dict | dict`、`dict |= dict`（PEP 584）；3.10 `dict` 联合类型 `dict[str,int]`。
- 3.12 `dict` 更省内存、创建更快。

## 近年研究与工业界开源实践（2015–2026）
- `dataclasses`（PEP 557，3.7）作为「带方法的字典」替代；`typing.TypedDict`（3.8）给字典加类型。
- `collections.OrderedDict` 在需「重排顺序」语义时仍有用（普通 dict 不保证重排）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 原书「字典无序」 | 3.7+ 已保序，可依赖 |
| 用 `dict.keys()` 当列表 | 视图对象非列表，需 `list()` 转 |
| 浅拷贝即安全 | 含嵌套可变对象时浅拷贝会共享内层，必要时深拷贝 |
