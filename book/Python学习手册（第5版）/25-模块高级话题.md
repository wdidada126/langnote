## 核心精讲
运行时用 `importlib.import_module("pkg.mod")` 动态加载；插件架构常据此实现。

```
教学示意，不参与构建
import importlib
mod = importlib.import_module("json")
data = mod.loads('{"a": 1}')
```

- 3.12+ 打包用 `pyproject.toml`：构建后端（setuptools/hatchling）、依赖、入口点。
- 重载仅用于开发/热更新，生产慎用（状态不一致风险）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 仍用 `setup.py` 主导 | 新项目用 `pyproject.toml`；`setup.py` 已弃用式微 |
| 依赖锁文件等同于 requirements | 用 `uv.lock`/`poetry.lock` 锁定可复现环境 |
| `reload` 解决热更新 | 生产用进程管理器/容器重启，而非 `reload` |
