## 核心精讲
本章是「劝学」章，几乎没有需要上机跑的代码。要点是建立对 Python 定位的直觉：
- 解释执行 + 动态类型 + 自动内存管理，让开发者把精力放在问题而非仪式上。
- 「Python 是工程，不是艺术」——强调可读性、一致性、`import this` 的禅意。

```
教学示意，不参与构建
>>> import this
The Zen of Python, by Tim Peters
Beautiful is better than ugly.
Explicit is better than implicit.
...
```

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 原文强调 2.x/3.x「双线」并存 | 2026 年应直接学 3.x；2.7 已 EOL，无需再双线 |
| 「Python 慢所以只适合脚本」 | 解释器已大幅提速；瓶颈多在 I/O 与算法，且可用 C 扩展/PyPy 兜底 |
| 把脚本与系统编程对立 | 同一语言既能写一次性脚本也能写大型系统 |
