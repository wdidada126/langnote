## 核心精讲
可迭代对象实现 `__iter__`（返回迭代器），迭代器实现 `__next__`。推导式是「声明式循环」，生成器表达式 `(...)` 惰性求值。

```
教学示意，不参与构建
squares = [x*x for x in range(5)]          # 列表推导
evens = (x for x in range(10) if x % 2 == 0)  # 生成器表达式，惰性
grid = [[i*j for j in range(3)] for i in range(3)]  # 嵌套
# 海象在推导里复用
pos = [m.start() for line in ["ab","cab"] if (m := __import__("re").search("a", line))]
```

- 生成器表达式省内存，适合流式/大数据。
- 3.8 `:=` 可在推导的 `if`/表达式中绑定变量，避免重复计算。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 用列表推导处理超大文件 | 改生成器表达式或 `for` 流式，避免一次性占满内存 |
| 嵌套推导方向困惑 | 外层循环在前（`[... for i ... for j ...]`），建议拆开调试 |
| 推导里写复杂副作用 | 推导应是「纯变换」，有副作用用普通 `for` |
