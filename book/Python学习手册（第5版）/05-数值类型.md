## 核心精讲
数值类型：int（任意精度）、float、complex；3.x 已删除 2.x 的「长整型」区分，`int` 即任意精度。

```
教学示意，不参与构建
print(10 / 3)     # 3.333... 真除法（3.x）
print(10 // 3)    # 3 地板除
print(0b1010)     # 10
from decimal import Decimal
Decimal("0.1") + Decimal("0.2")   # 精确 0.3
```

- 链式比较：`1 < x < 10` 合法且高效。
- 位运算：`& | ^ ~ << >>`，用于标志位与掩码。

## 版本演进
- 3.x 统一 `int`/`long`，`/` 永远返回 float（2.x 的 `from __future__ import division` 已无意义）。
- 3.11 起整数→字符串、字符串→整数转换大幅加速。

## 近年研究与工业界开源实践（2015–2026）
- NumPy 的 `int64`/`float64` 仍是科学计算默认（注意与 Python 任意精度 `int` 区别）。
- 金融/计费优先 `decimal.Decimal` 或整数「分」避免浮点误差。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| `1/2 == 0`（2.x 地板除） | 3.x 中 `1/2 == 0.5`，要整数商用 `//` |
| `float` 可直接比较相等 | 浮点有误差，金融用 `Decimal` 或整数分 |
| 大整数溢出 | Python `int` 任意精度，不会溢出（仅受内存限制） |
