## 核心精讲
异常把「正常流程」与「错误处理」分离。推荐捕获具体异常，而非裸 `except:`。

```
教学示意，不参与构建
try:
    n = int(input("数："))
except ValueError as e:
    print("不是整数:", e)
else:
    print("得到", n)        # 无异常时执行
finally:
    print("无论如何都执行")
```

- `try/except/else/finally` 四段齐全；`else` 仅主逻辑无异常时跑。
- EAFP（easier to ask for forgiveness）风格优于 LBYL（look before you leap）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 裸 `except:` | 会吞掉 `KeyboardInterrupt`/`SystemExit`；用 `except Exception` 或更具体 |
| 用异常做流程控制 | 异常为「异常」而生，频繁路径用 `if`/返回值 |
| 捕 `BaseException` | 仅在需拦截退出信号时；常规业务捕 `Exception` 子类 |
