## 核心精讲
3.x 中 `str` 是 Unicode 文本，字节用 `bytes`；二者必须显式编解码，不能直接混用。

```
教学示意，不参与构建
name = "世界"
s = f"{name} 长度={len(name)}"     # f-string（3.6+）
b = s.encode("utf-8")              # str -> bytes
print(b.decode("utf-8"))           # bytes -> str
path = r"C:\new\test"              # raw，反斜杠不转义
```

- 常用方法：`split`/`join`/`strip`/`replace`/`upper`/`find`。
- 不可变：拼接大量字符串用 `list` + `join` 或 `io.StringIO` 更高效。

## 版本演进
- 3.6 引入 f-string（PEP 498）；3.12 允许 f-string 内复用同名引号、多行更自由；3.14 计划 t-string 模板字符串（PEP 750，🔧 以正式发行为准）。
- 3.x 删 2.x `unicode` 类型，`str` 即 Unicode。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 2.x `str`/`unicode` 双模型 | 3.x 只有 `str`(Unicode) 与 `bytes`，编解码显式 |
| 仍用 `%` 或 `.format` | 2026 首选 f-string，可读性最佳 |
| bytes 与 str 直接拼接 | 类型不同会 `TypeError`，需 encode/decode |
