## 核心精讲
四种运行方式：交互式 REPL、命令行 `python x.py`、`#!` 可执行脚本、IDE（IDLE/PyCharm/VSCode）。

```
教学示意，不参与构建
# Unix 风格可执行脚本
#!/usr/bin/env python3
print("hello")
# chmod +x x.py && ./x.py
```

- Windows 3.3+ 自带 `py` 启动器：`py -3.12`、`py -2` 选择版本；`#! python3` 被启动器识别。
- 交互式里 `_` 保存上一次表达式结果（3.x 仍可用）。

## 版本演进
- 3.3 引入 Windows `py` 启动器（原书已覆盖，但后续版本选择语法更稳）。
- 3.8 `py -0` 列出已安装解释器。

## 近年研究与工业界开源实践（2015–2026）
- `python -m venv` 虚拟环境成为标准实践；`uv`（Astral，2024）以 Rust 重写并加速依赖与解释器管理。
- `python -X importtime` 诊断导入耗时。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 依赖系统 `python` 指向 | 应显式 `python3` / `py -3`，避免 2/3 混淆 |
| IDLE 是唯一 IDE | 2026 主流为 VSCode + Python 插件、PyCharm |
| `input()` 陷阱 | 3.x `input` 返回 `str`（2.x `raw_input` 才等价），勿当数字用 |
