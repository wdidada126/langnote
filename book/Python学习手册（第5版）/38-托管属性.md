## 核心精讲
`property` 把方法当属性访问，隐藏「计算/校验」；描述符是更通用的「属性协议」（一个类实现 `__get__`/`__set__`）。

```
教学示意，不参与构建
class C:
    def __init__(self):
        self._x = 0
    @property
    def x(self):
        return self._x
    @x.setter
    def x(self, v):
        if v < 0:
            raise ValueError("需非负")
        self._x = v
```

- 3.8 `functools.cached_property` 缓存首次计算；3.9 `cache_property`（标准库）。
- 描述符常用于 ORM/校验框架（见 [concepts/描述符与属性管理.md](concepts/描述符与属性管理.md)）。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 手写 getter/setter 像 Java | Python 先用普通属性，需要逻辑再加 `@property` |
| 描述符 vs property 混淆 | `property` 是单属性便捷；描述符是类级可复用协议 |
| 忘记缓存昂贵属性 | 用 `@cached_property`，避免每次访问重算 |
