## 核心精讲
Python 用缩进定义代码块（冒号 + 缩进），而非大括号；一行一条语句，可用 `;` 分隔（不推荐）。

```
教学示意，不参与构建
a = b = c = 0          # 多目标赋值（共享同一不可变对象，安全）
x, y = y, x            # 元组拆包交换，无需临时变量
n += 1                 # 增强赋值
def f():
    "这是函数的文档字符串"
    return 1
print(f.__doc__)
```

- 增强赋值对可变对象会就地修改（见 [06-动态类型简介](06-动态类型简介.md)）。
- 文档字符串：`obj.__doc__`，被 `help()` 与 Sphinx 读取。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 用 `;` 写多语句 | 违反 PEP 8，降低可读性 |
| 缩进混用空格与 Tab | 必报错（PEP 8 要求 4 空格）；编辑器设「Tab 转空格」 |
| 文档字符串随意位置 | 必须是模块/函数/类/方法的**首个语句**才被 `__doc__` 捕获 |
