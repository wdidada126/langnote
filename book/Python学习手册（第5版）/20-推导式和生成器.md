## 核心精讲
含 `yield` 的函数是生成器：调用返回生成器对象，每次 `next()` 执行到下一个 `yield` 暂停并产出值。

```
教学示意，不参与构建
def count(n):
    i = 0
    while i < n:
        yield i
        i += 1
for v in count(3):
    print(v)                 # 0 1 2
# 3.3+ 委派
def chain(a, b):
    yield from a
    yield from b
```

- 3.3 `yield from` 把内层可迭代「委派」出去（PEP 380）。
- 生成器是单遍、惰性的，适合流式与无限序列。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 生成器可重复遍历 | 生成器是单遍；需重复用 `list()` 物化或重写函数 |
| `return` 在生成器报错 | 生成器 `return x` 以 `StopIteration(x)` 携带值（3.3+ 合法） |
| 用生成器做随机访问 | 不支持下标，需索引请用列表 |
