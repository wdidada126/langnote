## 核心精讲
附录偏「环境搭建与历史对照」：原书花了篇幅讲 2.7 与 3.3 的并存配置。2026 年的实践建议：
- 用官方安装包或 `uv` 装 3.12+，配虚拟环境（`python -m venv` 或 `uv venv`）。
- Windows 用 `py -3.12` 选择版本（见 [03-你应如何运行程序](03-你应如何运行程序.md)）。
- 2.x 已 EOL（2020-01-01），无需再维护双线。

## 版本演进
- 3.3 Windows 启动器 `py`（PEP 397，见 [03-你应如何运行程序](03-你应如何运行程序.md)）。
- 3.12 free-threading（PEP 703，实验）为近年重大方向。
- 3.13 `free-threading` 构建可单独启用；3.14 继续推进（🔧 以正式发行为准）。

## 经典论文与原始文献
- PEP 397 *Python launcher for Windows*（3.3）。
- PEP 703 *Making the Global Interpreter Lock Optional*（3.12+ 实验）。
- 官方 *Using Python*（安装/配置文档）；*What's New In Python 3.x* 各版说明。

## 近年研究与工业界开源实践（2015–2026）
- `uv`（Astral，2024）统一解释器安装/虚拟环境/依赖/构建。
- CPython 3.11+「Faster CPython」性能工程；3.12+ free-threading 实验开启多核友好时代。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 按原书配 2.x/3.x 双线 | 直接装 3.12+，2.x 已 EOL |
| 系统 Python 直接 `pip install` | 用虚拟环境，避免污染系统 |
| 忽视 GIL | 3.12+ free-threading 实验可绕开 GIL，但多数库尚未就绪，生产仍按 GIL 设计 |
