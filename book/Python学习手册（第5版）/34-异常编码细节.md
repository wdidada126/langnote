## 核心精讲
`try/finally` 保证清理（关文件、释放锁）；`with` 语句用上下文管理器自动清理，更安全。

```
教学示意，不参与构建
with open("data.txt", encoding="utf-8") as f:
    data = f.read()          # 退出时自动 close，即使异常
try:
    risky()
except ValueError:
    raise                     # 重抛当前异常，保留栈
```

- 3.3 起 `with` 可同时管多个（`with a, b:`）；对象实现 `__enter__`/`__exit__`。
- `raise ... from` 显式链接因果（3.0+），利于诊断。

## 版本演进
- 3.3 多上下文 `with a, b:`（PEP 405？实际为语法扩展）。
- 3.0 `raise New from old` 异常链；3.11 `ExceptionGroup` + `except*`（PEP 654）。
- 3.x `breakpoint()`（PEP 553，3.7）替代 `import pdb; pdb.set_trace()`。

## 常见误区与本书需修正之处
| 误区 | 修正 |
| --- | --- |
| 手动 `try/finally` 关文件 | 优先 `with`，避免漏关/异常路径遗漏 |
| `raise` 吞掉原栈 | 重抛用裸 `raise`；想保留因果用 `raise New from old` |
| `assert` 做参数校验 | `assert` 可被 `-O` 优化关闭；生产校验用显式 `if/raise` 或 `pydantic` |
