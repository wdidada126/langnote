# 《Java线程与并发编程实践》（Jeff Friesen）阅读地图

- 原书名：*Java Threads and the Concurrency Utilities*（2nd ed，2017），译者 鄢倩，人民邮电出版社，261 页
- 定位：「API 实战手册」型——按 JDK 线程 API 与 JUC 工具逐一套讲，重「能用 + 坑」，介于 Cookbook 与原理书之间。与所有其他并发书互补：本书最像「权威 API 用法参照」。

## 同主题书籍分工

- **原理**：方腾飞《艺术》、冷血《实现原理》、《之美》concepts。
- **实战/调优**：黄文海、葛一鸣、尼恩。
- **本书**：最全的「JUC API 逐一用法 + 陷阱」，作 API 字典。

## 本书没覆盖的缺口

- 虚拟线程（JEP 444）、结构化并发（JEP 453/505）、VarHandle（JEP 193/471）、ScopedValue（JEP 506）—— 见《之美》。
