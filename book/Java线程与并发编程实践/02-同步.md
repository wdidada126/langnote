# 第 2 章 同步

> `synchronized`（方法/块）、`volatile`、原子性/可见性/有序性。本书作为 API 用法基础章，与深度解析 2-3 章、艺术 2 章、之美 concepts/JMM与volatile 互补。

## 一、核心精讲

### 2.1 🔧 synchronized 两种写法
- 同步实例方法（锁 `this`）/ 同步静态方法（锁 `Class`）/ 同步块（锁指定对象）（🔧 锁对象要共享且不变；别锁 `String` 常量或 `Integer` 缓存对象，会意外共享）。

### 2.2 volatile 不保原子
- 仅可见+有序，`i++` 仍竞态（🔧 用 `AtomicInteger`；DCL 必须 volatile，见之美 concepts/volatile）。

### 2.3 锁升级
- JDK 6+ 偏向→轻量→重量（🔧 偏向锁 JDK15+ 移除，JEP 374；虚拟线程内 synchronized 会 pin，见之美 08 章）。

## 二、版本演进 / 论文 / 前沿

- 论文：JSR 133（Manson-Pugh-Adve POPL'05）、x86-TSO（Sewell CACM'10）。
- 工业界：JDK `synchronized`/`volatile`；JOL 观察锁状态。
