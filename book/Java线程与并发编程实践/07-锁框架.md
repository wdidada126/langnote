# 第 7 章 锁框架

> `AbstractQueuedSynchronizer`（AQS）、`ReentrantLock`、`ReentrantReadWriteLock`、`StampedLock`、`Lock`/`Condition`。本书 API 手册式，与深度解析 4 章、艺术 5 章、之美 06 章/concepts/AQS 互补。

## 一、核心精讲

### 2.1 🔧 AQS 是基石
- 三组件 `state`/`head`/`tail` + CLH 队列（🔧 见之美 concepts/AQS抽象同步队列.md 源码级；`ReentrantLock`/`Semaphore`/`Latch` 都建其上的）。

### 2.2 ReentrantLock vs synchronized
- 可中断/限时/公平/多 Condition；JDK6+ 低争用 synchronized 反超（🔧 见深度解析 4 章）。

### 2.3 StampedLock 乐观读
- `tryOptimisticRead` 非 AQS、不可重入（🔧 读多写少优于读写锁；见之美 06 章、高并发核心编程 concepts/JUC显式锁）。
