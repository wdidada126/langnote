# 第 8 章 额外的并发工具类

> 本书「工具大杂烩」：`AtomicXxx` 原子类、`ConcurrentHashMap`/`CopyOnWriteArrayList`/阻塞队列、`ForkJoinPool`/`RecursiveTask`、`CompletableFuture`、并发随机数。与艺术 6-7 章、冷血 5/7-8 章、之美 concepts 互补。

## 一、核心精讲

### 2.1 原子类
- `AtomicInteger`/`AtomicReference` + CAS；`LongAdder` 高并发分段计数（🔧 见之美 concepts/CAS与原子操作、LongAdder与分段累加）。

### 2.2 并发集合
- `ConcurrentHashMap`（JDK8+ 桶级锁）、`CopyOnWriteArrayList`（读多写少）、阻塞队列（🔧 见深度解析 8-9 章、之美 concepts/阻塞队列）。

### 2.3 ForkJoin / CompletableFuture
- 分治用 `ForkJoinPool`（工作窃取）；异步编排用 `CompletableFuture`（🔧 默认 `commonPool` 陷阱，见之美 concepts/CompletableFuture、精通2 7-9 章）。

### 2.4 并发随机数
- `ThreadLocalRandom` 替代 `Random`（🔧 见手册 10 章；JDK17+ `Random` 默认 LXM 算法）。
