# 第 3 章 等待和通知

> `Object.wait`/`notify`/`notifyAll`、`Condition.await`/`signal`/`signalAll`、`LockSupport.park`/`unpark`。本书 API 手册式讲解，与深度解析 5 章、黄文海 5 章、之美 10 章互补。

## 一、核心精讲

### 2.1 🔧 wait 三件套
- 必须在 `synchronized` 内；用 `while` 而非 `if`（防虚假唤醒）；`notifyAll` 优于 `notify`（🔧 见深度解析 5 章、之美 10 章）。

### 2.2 Condition 多等待集
- 一个 `Lock` 可建多 `Condition`，精准 `signal`（🔧 比 `Object.wait` 单等待集高效；AQS 条件队列实现）。

### 2.3 LockSupport
- 许可式 `park`/`unpark`，`unpark` 先调也不阻塞（🔧 AQS/线程池等待基础；虚拟线程 `park` 卸载 carrier）。
