# 第 4 章 额外的线程能力

> 本书独有 API 集合：`ThreadLocal`/`InheritableThreadLocal`、线程组 `ThreadGroup`、未捕获异常 `UncaughtExceptionHandler`、`Timer`/`TimerTask`。其中 `ThreadLocal` 内存泄漏是重点，详见《之美》concepts/ThreadLocal与内存泄漏.md。

## 一、核心精讲

### 2.1 🔧 ThreadLocal 内存泄漏
- `ThreadLocalMap` 的 key 是**弱引用**，线程池线程长期存活 → value 强引用不回收 → 泄漏（🔧 用完 `remove()` 在 finally；阿里规约强制；`InheritableThreadLocal` 在线程池下不继承（父子线程非池内新线程），见之美专篇）。

### 2.2 ThreadGroup / UncaughtExceptionHandler
- `ThreadGroup` 现已不推荐（🔧 用 `Executor` + `ThreadFactory`/结构化并发替代）；`UncaughtExceptionHandler` 统一捕获线程未捕获异常（`submit` 异常吞到 `Future.get`，用 `afterExecute`）。

### 2.3 Timer 已过时
- `Timer` 单线程，一任务异常拖垮全部（🔧 改用 `ScheduledThreadPoolExecutor`；虚拟线程下 `Timer` 更没必要）。

## 三、常见误区

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "ThreadLocal 不泄漏" | finally 里 remove |
| 2 | "Inheritable 池里继承" | 池化线程不继承，用 TTL |
