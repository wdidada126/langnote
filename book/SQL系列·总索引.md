# SQL 系列·总索引

> 本文件是 `book/` 根目录下 **SQL 系列大纲式单文件** 的总索引。这些笔记均为单文件形态，记录书目元数据、目录大纲与摘录代码。
>
> **两种笔记形态约定**：
> - ①「大纲单文件」——元数据（豆瓣链接/ISBN/出版年）+ 章节目录，个别附 PDF/随书代码存放位置；
> - ②「精读笔记」——在大纲之外还有 SQL 代码摘录、个人总结或跨年摘录聚合（2020–2026 日常笔记，2026-09-23 整理），如 `sql进阶教程.md`、`SQL数据分析.md`、`SQL沉思录.md`。
>
> 分层阅读路线按「入门 → 进阶 → 专家 → 优化与实战」组织。

## 分层阅读路线

- **第 0 层 · 入门**（零基础到会写查询）
  `SQL基础教程2.md` → `SQL必知必会5.md` → `SQL初学者指南2.md` → `SQL查询_从入门到实践4.md`
  语法打底：SELECT / 过滤 / 分组 / 连接 / 子查询。
  建议只精读其一作为主线（MICK《SQL基础教程》或 Forta《SQL必知必会》），其余作对照参考。
- **第 1 层 · 进阶**（从会写到写好）
  `sql进阶教程.md` → `SQL经典实例.md` → `SQL编程思想.md` → `SQL数据分析.md` / `SQL数据分析实战.md` / `对比Excel_轻松学习SQL数据分析.md`
  主题：CASE 表达式、自连接、HAVING、EXISTS、窗口函数、集合运算、SQL:2019 新特性与面试题解。
- **第 2 层 · 专家**（关系思维与工程素养）
  Celko：`SQL沉思录.md` → `SQL解惑.md`；再加 `SQL反模式.md` → `SQL语言艺术.md`
  主题：声明式/面向集合思维、辅助表与查找表设计、反模式识别、查询性能原则。
- **第 3 层 · 优化与实战**（面向生产环境）
  `SQL优化核心思想.md`（Oracle 系）→ `Effective_MySQL之SQL语句最优化.md` / `Effective MySQL之深入解析复制技术.md`（MySQL 系）→ `大数据SQL优化.md`（分布式/大数据引擎，RBO/CBO/倾斜治理）
  厂商专精：`OracleSQL高级编程.md`（Oracle）、`Microsoft_SQL_Server_2008技术内幕.md`（T-SQL）、`精通SQL_结构化查询语言详解.md`（跨 SQL Server/Oracle 的语句速查）。
- **可选补充**：`MySQL开发者SQL权威指南.md`（MySQL 方言全面教程，可作第 1 层的厚重参考）；`MySQL必知必会.md`（MySQL 视角极简入门，与 `SQL必知必会5.md` 二选一即可）。

## 维护约定

1. 本索引只收录 `book/` 根目录下的 **SQL 大纲单文件**；已建章节目录的书（如 `book/mysql/`、`book/数据库系统概念6/`）不在书目表内，仅在互链一节引用。
2. 书目表元数据著录顺序：笔记内已载信息优先；笔记缺失项经豆瓣/出版社官网核实后升级为 ✅；仍无法核实的字段一律写「待核验」，**不猜测、不补全**。
3. 新增 SQL 单文件时：先在书目表加一行（状态标 📄），再在「各单文件笔记内容速览」补一条，最后视情况更新阅读路线分层。
4. 待核验清单条目核实完成后，更新书目表状态标记并从清单中移除该条。
