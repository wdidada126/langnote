## 三、本书基线与 2026 现状的根本落差（勘误总纲）

本书成书于 **MongoDB 2.4（2013）**：MMapv1 内存映射引擎一统天下、配置服务器还是"三台独立 mongod"、主从复制有专节、MapReduce 与聚合框架并列、`mongo` 旧 shell 唯一入口、legacy 驱动世代、许可仍属 AGPL 语境。

到 2026（MongoDB 7.x/8.x + Atlas 时代），逐主题的换血对位（各章文件内有细化表）：

1. **存储引擎**：WiredTiger 3.0 引入 → 3.2 默认 → 4.2 弃用 MMapv1 → **6.0 移除**；本书第 19 章"日记+fsync+预热"心智整体退役。✅ https://www.mongodb.com/docs/manual/core/wiredtiger/
2. **一致性**：多文档 ACID 事务（4.0 副本集 / 4.2 分片）✅ https://www.mongodb.com/docs/manual/core/transactions/
3. **变更消费**：Change Streams（3.6+）取代尾随 oplog。✅ https://www.mongodb.com/docs/manual/changeStreams/
4. **查询/分析**：`$lookup/$facet/$unionWith/$setWindowFields/$merge`；MapReduce 已移除；Atlas `$search`/`$vectorSearch`。✅ https://www.mongodb.com/docs/atlas/atlas-vector-search/vector-search-stage/
5. **分片**：CSRS 强制、chunk 128MB、per-collection 分片（6.0）、zone/ranged sharding。✅ https://www.mongodb.com/docs/manual/release-notes/6.0/
6. **shell 与驱动**：mongosh 取代 mongo；驱动统一重写（PyMongo 4.x）。✅ https://www.mongodb.com/docs/mongodb-shell/ 、https://www.mongodb.com/docs/drivers/pymongo/
7. **平台**：Atlas 成事实主线；服务器二进制停发 Windows（5.0 起）。✅ https://www.mongodb.com/try/download/community （current 为 8.x 线）
8. **许可地震（2018）**：AGPL → **SSPL v1（2018-10-16，自 4.2）**，OSI 不认可；催生 API 兼容替代生态——AWS DocumentDB ✅ https://aws.amazon.com/documentdb/ 、开源 FerretDB（Apache-2.0，PostgreSQL 后端）✅ https://docs.ferretdb.io/ ；SSPL 原文 ✅ https://www.mongodb.com/licensing/server-side-public-license
