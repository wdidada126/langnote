## 精读笔记

### 1. 索引的心智模型（B-tree 时代）

- MMapv1 下索引是磁盘上的 B-tree（2.6 前无复合索引前缀压缩等细节），**索引常比数据先驻内存**——全书"工作集"叙事（21 章）的物理基础。
- 复合索引 = 有序键元组的 B-tree：**前缀可用、等值在前范围在后、排序方向需匹配**；`$in/$or` 的索引利用单列退化。
- 数组 → **多键索引（multikey）**：一元素一键；代价是含数组键的查询**不能覆盖（covered）**，必须回表校验。内嵌文档按点号路径索引，"内嵌文档匹配 + 数组"混合结构有跨元素误配陷阱（需 `$elemMatch`）。
- 基数（cardinality）决定索引收益；explain 字段（`indexOnly/cursor/multiKey/scanned/parsed`）是调优仪表盘。
- 何时不建索引：小集合、写多读少、索引比查询密——作者的"索引是双刃剑"论。

### 2. 特殊索引/集合清单（2013 前沿 → 2026 遗产）

- **唯一索引/稀疏索引/复合唯一**；`dropDups` 危险选项（后移除）。
- **TTL 索引**：单键日期、后台线程约每 60s 清理；分片集群 2.7/3.0 后支持——本书时代 TTL+分片尚未齐备。
- **固定集合 capped**：插入序环形文件 + 自然排序 + 循环游标，是 oplog 的实现，也是廉价"最新 N 条"日志表。
- **全文索引（2.4 新特性）**：`$text` 词干分词、权重、停用词、`textScore` 排序——功能孱弱但意义深远（见下文 Atlas Search 对位）。
- **2d 平面地理索引**：`$near/$within/$geoWithin`（书正处在 2d→2dsphere 过渡期，4.1 后球面成为主角）。
- **GridFS**：驱动规范，把大文件切成数据块（chunk，默认数百 KB）存 `fs.chunks`、元数据存 `fs.files`——本质是"用两集合模拟流式对象存储"。

## 2013 基线 → 2026 现状对位勘误

| 本书说法（2013） | 2026 现状 | 依据 |
|---|---|---|
| 索引构建阻塞写入（或 `background:true` 慢且碎） | 4.2+ **混合（hybrid）索引构建**：后台式不阻塞且默认化；旧 `background` 选项被忽略/移除 | ⚠️ 机制为官方文档长期事实 |
| 全文索引 `$text` 是文本搜索方案 | 服务器端 `$text` 仍保留但被**Atlas Search（Lucene 内核）/ `$search` 阶段**实质取代；多语言/模糊/拼写纠错全在 Atlas Search 侧 | ✅ https://www.mongodb.com/docs/manual/core/indexes/（索引总览页实抓）|
| 2d 平面索引 | **2dsphere（GeoJSON）** 为地理标准；2d 视为遗留 | ⚠️ |
| TTL 不支持分片集合 | 早已支持；并出现 **clustered collections（6.0 GA）** 让"按 `_id` 物理聚簇 + 自然序"部分取代 capped 场景 | ✅ https://www.mongodb.com/docs/manual/core/clustered-collections/（实抓）|
| 只有手工索引 | 新索引类型：**通配符索引 wildcard（6.2+）**、**隐藏索引**、**时序集合自动索引**、**向量索引（Atlas Vector Search，HNSW/IVF）** | ✅ https://www.mongodb.com/docs/atlas/atlas-vector-search/vector-search-overview/（实抓）|
| GridFS 用于大文件 | 规范仍在且被驱动统一实现，但工业实践多数迁对象存储（S3/OSS）+ 元数据在 Mongo；Atlas 本身即"存储计算分离"叙事 | ⚠️ |
| `hint()` 是调试手段 | `hint` 保留；新增 `$hint` 聚合内指定、**索引过滤器（4.2 query frameworks）**、Atlas Performance Advisor 自动建议 | ⚠️ |

## 核心概念速览（中英对照）

- **复合索引** — Compound Index：多键 B-tree，前缀匹配 + 排序方向敏感。
- **多键索引** — Multikey Index：数组逐元素入树；单文档可占多键。
- **索引基数** — Index Cardinality：不同键值比例，决定选择性。
- **覆盖查询** — Covered Query：仅扫索引不回表（`indexOnly`）。
- **explain** — 查询计划输出：`winningPlan/executionStats`（现代形态）。
- **hint** — 强制索引指定。
- **TTL 索引** — Time-To-Live Index：日期键后台过期删除。
- **固定集合** — Capped Collection：定容环形存储，插入序 = 自然序，oplog 之基。
- **全文索引** — Text Index（2.4）：分词 + 权重；2026 由 Atlas Search 接管。
- **2dsphere 索引** — 球面地理索引（GeoJSON）：取代书时代的 2d 平面。
- **GridFS** — 通用文件存储驱动规范：fs.files + fs.chunks。
- **通配符索引** — Wildcard Index（6.2+）：`field.$**` 自动为动态子键建索引。⚠️ 版本号推定
- **向量索引** — Vector Search Index（Atlas，HNSW/IVF）：embedding 近邻检索的存储层。✅ 官方 overview 页实抓
- **混合索引构建** — Hybrid Index Build（4.2+）：默认后台式、可中断恢复的建索引。
