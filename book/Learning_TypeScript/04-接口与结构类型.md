# 《Learning TypeScript》章笔记 04 · 接口与结构类型

> 对应 [00-总览与阅读地图.md](00-总览与阅读地图.md) 骨架 **Ⅱ 函数与对象段（后半）**——本书的**公理章**。
> ⚠️ 章名「接口与结构类型」为按书记忆的主题带命名（interface/object types 相关章），非逐字章名。
> 三态：**✅** = 本机实测（node v22.14 strip-types，脚本 `/tmp/lts_exp/exp04.ts`）；**⚠️** = 凭记忆；**🔧** = 未实测。

## 核心机制

- **结构类型（structural typing）是本书第一公理**：判「能不能赋」只看形状兼容，不看出身。
  ✅ 实测：`Duck` 与 `Robot` 都没有 `implements Quackable`，`(x: Quackable) => x.quack()`
  对两者照常工作（`quack / beep-quack`）——运行时本来就是 JS 属性查找，「结构兼容」在
  运行时的化身就是鸭子类型；类型层只是把这场动态邂逅提前到编译期裁决。
- **interface 零运行时痕迹**：✅ 实测：`new Duck()` 自身属性 `[]`、原型上只有
  `constructor/quack`，全局对象里搜不到任何 `Quackable` 注册——interface 连名字都不留。
  与专题档实验 A 的 `implements Named` 零痕迹结论互证 ✅。
- **interface vs type alias**：形状表达力大体等价；差异在声明合并（interface 同名自动
  合并 ⚠️）、`extends` 与交叉类型的报错体验、以及约定（公开对象契约偏 interface）。
  原书给的取舍准则偏温和，工程谱系（Effective TS）更锋利 ⚠️。
- **与名义类型系对照（思维切换主战场）**：Java/C++ 里两个字段全同的类是**不同**类型，
  转换需显式 cast/adaptor；Kotlin 亦然——两个成员一模一样的 interface，类不声明实现就
  互不可赋（名义系统）。TS 里它们**是同一类型**。名义↔结构这对轴，恰与 00 档点名的
  [../Java_to_Kotlin/](../Java_to_Kotlin/) 「翻 idiom」型切换同构：Java 老手请把 interface
  读作「属性检查清单」而非「血统证书」。
- **`implements` 是可选的自我声明**：不写它也满足结构兼容（✅ 实测）；写了只是让编译器
  在你漏方法时早报一处。它不产生任何运行时义务或包装。

## 批判读法

- 结构兼容在**函数参数位置**的双变/逆变细节远超入口书处理深度（`strictFunctionTypes`
  下参数逆变 ⚠️），此处读到的「形状相同即可赋值」要自觉降级为「属性协变为主的近似」。
- 声明合并是 TS 特有的「全局命名空间污染面」：库作者用它扩展 `window`，应用开发者常被
  它坑（同名 interface 悄悄合并）。原书作为特性讲，工程谱系作为风险讲，以后者为准。⚠️。
- 本章未展开「结构相等≠运行相等」：无 Kotlin data class 式 equals 生成，见专题档推论 5。⚠️。

## 🔧 微实验

- ✅ 已实测（exp04.ts，exit=0）：无 implements 的结构兼容调用、interface 全局零痕迹、
  类自身属性/原型清单确认。
- 🔧（未实测）名义性反例确认：两个形状全同的 `interface A/B` 互赋应**无错**（TS 非名义），

## 中英对照表

| 中文 | 英文 | 一句定义 |
| --- | --- | --- |
| 结构类型 | structural typing | 以形状兼容性定赋值关系，本书第一公理 ✅运行时即鸭调。 |
| 名义类型 | nominal typing | 以类型名/血统定关系，Java/C++/Kotlin 的默认世界观。 |
| 接口 | interface | 可起名的形状契约；声明合并、零运行时痕迹 ✅。 |
| 类型别名 | type alias | `type X = ...`；给任意形状起名的另一种登记。 |
| 实现声明 | implements clause | 可选的编译期自证，不产生运行时义务 ✅实测。 |
| 声明合并 | declaration merging | 同名 interface 自动并集，库扩展全局的类型面通道 ⚠️。 |
| 形状兼容 | assignability | 「左边能装右边」的判定关系，属性协变为主 ⚠️细节后置。 |
| 鸭子类型 | duck typing | 运行时属性查找定生死，结构类型的动态孪生 ✅。 |
