# 《Learning TypeScript》章笔记 05 · 联合类型与收窄

> 对应 [00-总览与阅读地图.md](00-总览与阅读地图.md) 骨架 **Ⅲ 联合与收窄段**——全书与 Kotlin 谱系对照密度最高的一章。
> ⚠️ 章名「联合类型与收窄」为按书记忆的主题带命名（union/narrowing 相关章），非逐字章名。
> 三态：**✅** = 本机实测（node v22.14 strip-types，脚本 `/tmp/lts_exp/exp05.ts`）；**⚠️** = 凭记忆；**🔧** = 未实测。

## 核心机制

- **联合=类型集合的并**，收窄=在控制流里把集合缩小到可操作子集。✅ 实测三连：
  `typeof` 收窄（`describe("abc")→"ABC"`）、判别字段收窄（`areaOf({kind:"circle",r:1})→3.1416`）、
  `in` 操作符收窄（`pick({inA:1})→"A"`）——全部照常运行，因为**收窄语句本身就是运行时 JS**；
  类型系统只是让编译器相信分支后的形状，不生成任何检查。
- **判别联合是「把类型信息编码进值里」的土法反射**：`kind: "circle"` 字段是程序员手动
  造出的运行时类型标签——专题档推论 3 的标准落地。擦除世界里想要 switch-on-type，
  只能自己造 tag。
- **撒谎没有守卫**：✅ 实测：`areaOf({ kind:"circle", s:5 } as unknown as Shape)` 返回
  `NaN` 而非崩溃——判别字段造假在编译期骗过检查器后，运行时静默地按假形状取属性、
  算出 NaN 继续活。**crash 位点与谎言位点分离**是 TS 排查事故的第一难。
- **与 Kotlin/C++ 三方对照（本章主轴）**：
  - Kotlin **智能转换**（smart cast，`if (x is Circle)` 后 x 自动变 Circle）与 TS 收窄形似
    神异：`is` 有运行时字节码（instanceof/checkcast 真执行），TS 的 typeof 分支是真 JS 但
    「收窄」这层编译器信任无对应运行时产物；Kotlin 智能转换对 `var`/可变性有失效条件，
    TS 收窄对闭包内重赋值同样失效（⚠️ 细节凭记忆）。
  - Kotlin **sealed class + when 穷尽** ↔ TS 判别联合 + `never` 兜底分支：TS 用
    `const x: never = shape` 手动实现穷尽检查，无 sealed 的出身约束，tag 靠自觉。⚠️。
  - C++20 `std::variant + std::visit`：穷尽是库级保证、访问错型抛 `bad_variant_access`
    ——运行时真墙；TS 对应物全程裸奔（见上 NaN 实测）。

## 批判读法

- 入口书收窄例子多为「好数据」路径，缺「脏数据从边界进来」一节——真实工程里联合的敌人
  是 JSON.parse 产物，需 zod 式 schema-first 补位（专题档推论 3），本书谱系后面书才展开。⚠️。
- `boolean` 函数返回真值收窄（type predicate `x is Foo`）在本章尾或后继章 ⚠️ 位置存疑，
  注意谓词函数本体也是「运行时只执行布尔逻辑、`is` 层零产物」。
- 判别联合的 tag 拼写漂移（"circle"/"Circle"）编译器管得住，但外部数据源的 tag 漂移
  编译器管不住——收窄的边界=你信任数据的边界。⚠️ 自建判词。

| 中文 | 英文 | 一句定义 |
| --- | --- | --- |
| 联合类型 | union type | `A \| B`：值落在成员类型集合之并，类型层概念 ✅无运行时产物。 |
| 判别联合 | discriminated union | 共享字面量 tag 的联合；手写的运行时类型标签。 |
| 收窄 | narrowing | 控制流内把联合缩小为子集；语句真跑，信任编译期 ✅实测。 |
| 类型守卫 | type guard | `typeof/in/instanceof/谓词函数` 四类收窄触发器。 |
| 类型谓词 | type predicate | `x is Foo` 签名；运行时只返回布尔，is 层零产物 ⚠️。 |
| 穷尽检查 | exhaustiveness checking | never 兜底逼 switch 全覆盖；仅编译期生效。 |
| 智能转换 | smart cast | Kotlin 对照物：is 检查后自动转型，且有运行时真身。 |
