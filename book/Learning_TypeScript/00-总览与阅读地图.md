# 《Learning TypeScript》——总览与阅读地图

> 目标书：*Learning TypeScript: Up and Running with Type-Safe JavaScript*，Josh Goldberg ✅（孔夫子中文版书目+O'Reilly 中文库页双源佐证；全作者名单是否有第二人 ⚠️），O'Reilly，2022（第二版存在与否 ⚠️），ISBN ⚠️待核验。
> 中文版存在：《学习 TypeScript》（O'Reilly 中文库页 979-8341-658196 线 ✅，译者安道）。

## 一、定位

本系列**入口书**：对 Java/C++ 背景者，它唯一的不可替代处是把「**结构类型**」这一与名义类型根本对立的公理，用 JS 动态语义讲透。后面所有书（尤其 Type-Level TS）默认你已内化这条公理。

## 二、骨架（⚠️ 章名/顺序凭记忆与中文藏书目录片段，以版权页为准）

| 段 | 主题带 | 本仓高价值点 |
|---|---|---|
| Ⅰ 基础 | 类型注解、原始类型、数组/对象字面量 | 注解=期望而非断言（与 Java 声明心智相反处第一条） |
| Ⅱ 函数与对象 | 签名、`this`、类、interface | **结构兼容判定**：形状相同即可赋值，无 implements 义务 |
| Ⅲ 联合与收窄 | union、narrowing、判别联合 | 判别联合 ↔ Kotlin sealed class / C++20 std::variant 三方对照 |
| Ⅳ 泛型与配置 | 泛型函数/类、tsconfig 关键项 | strict 家族开关逐项实测（🔧 主战场） |
| Ⅴ 工程 | 声明文件、模块、第三方类型 | @types 与 DefinitelyTyped 谱系 |

## 三、读法

线性读 Ⅰ–Ⅲ（结构类型公理必须一遍建牢），Ⅳ–Ⅴ 按需查。每章读毕在本仓分章档落一条「Java/Kotlin 对应物是什么、哪里不同」的对照裁定。

## 四、🔧 实测口径

- 本机基线已实测 ✅：`node --experimental-strip-types` 直跑（只删注解不检查）——入门期微实验可零编译循环跑通，见总索引「实测基线」。
- 收窄实验矩阵：同一 union 值配 typeof/in 判别/真值收窄 四种写法，观察编辑器报错位点差异（需 `tsc --noEmit` 或编辑器；本机独立 tsc 未装 ⚠️）。
