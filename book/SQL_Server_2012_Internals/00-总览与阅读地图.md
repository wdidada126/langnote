## 十、常见问答 FAQ

1. **问：名册给的 ISBN 为什么不用？** 答：四家权威书目源（Crossref/LoC/DNB/豆瓣 ISBN 页）对 9780735670174 均零结果，而 9780735658561 有 LoC 实例级 MARC 与豆瓣双源；按"勘误以权威书目为准"红线处理（第二节取证 1–9 步）。
2. **问：Ross Midgley 是谁？** 答：未出现在本书任何权威著录中，本目录不采信该名（第二节第 7 条）。作者团以 LoC 六人著录为准：Delaney/Randal/Cunningham/Nevarez/Kehayias/Beauchemin ✅。
3. **问：为什么 14 章只建 8 个章文件？** 答：第 1–2、3–4、8–9、10–12、13–14 各自同题相邻，合并后每文件主题内聚且达 120–200 行规格；映射表在第三节末列，逐章可对位回原书。
4. **问：盘上 2008 文件到底是不是这本书的前驱？** 答：不是——它是 Ben-Gan 的 T-SQL 语言卷（文件内豆瓣链与 TSQLFundamentals 源码包为证，#36 00 同结论）；本书真正的 2008 前驱（存储引擎卷）盘上无对位文件，详见第四节 4.1。
5. **问：为什么不装个 SQL Server 跑跑？** 答：共通规范明令 SQL Server 不可本机实测；本目录引擎机制全部 ⚠️ 转述 + ✅ Learn URL 准绳，🔧 只允许 SQLite/DuckDB 类比并逐处声明"非本书引擎行为"。
6. **问：各章作者归属可信度？** 答：LoC 不公布逐章分工，本目录仅给"推测 ⚠️"并写明推测依据（2005/2008 内幕卷谱系与著者公开写作线）；引用时请勿当作者口径。
7. **问：想读索引纵深接下来去哪？** 答：本册 05/06 → #36 的索引四章群（已在盘互链）→ 同波兄弟 #46《Expert Performance Indexing in SQL Server 2019》（登记于第十二节 A-3，波尾闭环后可读）。
8. **问：本册与 #36 观点冲突信谁？** 答：都以 ⚠️ 转述呈现，冲突时以 Microsoft Learn 官方文档为最终准绳（各章末节 URL 均 200 验过）。
