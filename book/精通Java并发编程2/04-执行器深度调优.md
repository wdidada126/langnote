## 二、核心精讲

### 2.1 🔧 监控钩子接 metrics
- `afterExecute` 记任务耗时/异常 + MDC；`terminated` 做汇总（🔧 接 Micrometer → Prometheus，生产线程池可观测标配）。

### 2.2 选型对照
- **执行器**：异构任务、需超时/取消/批量返回、IO 混合 → `ThreadPoolExecutor`。
- **ForkJoin**：纯 CPU、可递归分解、无 IO → `ForkJoinPool`（工作窃取）。
- **虚拟线程（JDK21+）**：IO 密集、每请求一线程、代码同步写法 → 取代手动池（🔧 但 `synchronized` 会 pin 平台线程，见之美 08 章）。
