## 二、核心精讲

### 2.1 🔧 拒绝 `Executors` 快捷工厂
- `newFixedThreadPool`/`newSingleThreadExecutor` 用**无界** `LinkedBlockingQueue` → 任务堆积 OOM；`newCachedThreadPool` 用 `SynchronousQueue` + `Integer.MAX_VALUE` 最大线程 → 海量线程耗尽资源（🔧 用 `ThreadPoolExecutor` 显式构造，设容量 + `CallerRunsPolicy`，见之美 08 章、手册 8 章）。

### 2.2 `invokeAny`
- 提交多个任务，**第一个成功返回的赢**，其余取消（🔧 适合「多源取最快」：多节点查同一数据取首达）。

## 三、版本演进 / 论文 / 前沿

- 论文：Lea《Executor 框架》并入 JDK 5（`java.util.concurrent`）；Schmidt Reactor 模式（POSA2'96）影响 NIO 线程模型。
- 工业界：Netty `EventLoopGroup`、Tomcat `NioEndpoint` 都是定制 `ThreadPoolExecutor` 思路。
- 开源 stars（2026-09）：JDK 23.4k / netty 34k / caffeine 17.9k。

## 四、常见误区 / 本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | "用 Executors 快捷工厂" | 显式 ThreadPoolExecutor 构造 |
| 2 | "Cached 池无限扩容" | 限 max + 有界队列 |
| 3 | "忘了 shutdown" | try-with-resources 或钩子关闭 |
| 4 | "invokeAll 抛异常即停" | 逐个 get 包异常 |
