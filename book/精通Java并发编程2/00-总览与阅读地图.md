# 《精通Java并发编程 第二版》阅读地图

- 原书名：*Mastering Concurrency Programming with Java — Second Edition*（Javier Fernández González，Packt 2017）
- 中文版：对应《Java9并发编程实战手册》作者的「精通」系列（侧重原理+调优，非菜谱）
- 定位：在《Java并发编程实战》(Goetz) 之后，补「执行器深度调优 / 并行流 MapReduce / JVM 多语言并发」三层

## 同主题书籍分工

- **Goetz《实战》**：原则与设计（线程安全、组合、取消）—— 本书的理论基座。
- **方腾飞《艺术》**：JVM/CPU 底层（volatile 汇编、锁升级、AQS 源码）。
- **冷血《实现原理》**：JDK 源码手写实现。
- **黄文海《多线程实战指南》**：工程方法论 + 活性故障 + 设计层保障。
- **葛一鸣《实战高并发程序设计》**：锁优化/并行模式/Akka/Jetty。
- **本书（精通2）**：执行器调优 + 并行流两种模型（MapReduce/MapCollect）+ **JVM 多语言并发**（独有）。
- **《之美》**：15 篇 concepts 横切专论，作字典查。

## 本书没覆盖的缺口

- 虚拟线程（JEP 444）、结构化并发（JEP 453/505）、ScopedValue（JEP 506）—— 均晚于 2017 版，见《之美》concepts。
- 响应式框架（Reactor/RxJava）仅概念提及，未深入。
