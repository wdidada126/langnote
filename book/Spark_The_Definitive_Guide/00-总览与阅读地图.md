## 本书定位与价值判断

✅ **Spark 生态的"圣经级"参考书**：由 Spark 核心创建者 Matei Zaharia 联笔，是理解 Spark 设计哲学与 API 演进的权威来源。

✅ **覆盖全栈工具集**：DataFrame/SQL/Dataset/RDD/MLlib/Structured Streaming/GraphX，一本书贯穿 Spark 全部子系统。

⚠️ **时效性注意**：本书基于 Spark 2.x（2018 年出版），Spark 已演进至 4.2.0（2026-07）。每章「最新演进」节补充 3.x→4.x 变更。

⚠️ **Scala 偏向**：示例以 Scala 为主，PySpark 为辅；R/Java 示例较少。Python 用户需自行适配。

## 最新演进与工业实践

**Spark 版本演进时间线（书后发展）：**

| 版本 | 时间 | 关键变更 |
|------|------|----------|
| 2.x (本书) | 2016-2020 | Dataset API, Structured Streaming, AQE 引入 |
| 3.0 | 2020-06 | AQE 正式 GA, Adaptive Spark, Unicode 支持 |
| 3.2 | 2021-12 | Dynamic Partition Pruning 默认开启 |
| 3.3 | 2022-06 | Spark Connect 引入（客户端-服务器架构） |
| 3.5 | 2023-09 | Photon 引擎集成, Python UDF 性能提升 |
| 4.0 | 2024-09 | Scala 2.13 only, R API 废弃, Spark Connect 增强 |
| 4.2.0 | 2026-07 | Java 25 支持, 持续性能优化 |

> 来源: spark.apache.org ✅

**工业现状（2026）：**
- Databricks 主推 Delta Lake + Unity Catalog 湖仓架构
- Spark + Iceberg/Hudi/Paimon 三足鼎立的表格式竞争
- Structured Streaming 在实时数仓中广泛应用
- Spark Connect 正在重塑客户端交互模式（→ 参见 [Data_Lakehouse_in_Action](../Data_Lakehouse_in_Action/00-总览与阅读地图.md) Ch 05）
