## Ch 6 核心：聚合操作

✅ **聚合是数据分析的核心操作**：Spark 的聚合机制比 SQL GROUP BY 更灵活。

### 基础聚合

```python
from pyspark.sql.functions import count, countDistinct, sum, avg, max, min

# 全局聚合 (无 GROUP BY)
df.select(count("*")).show()
df.select(countDistinct("department")).show()
df.select(avg("salary"), max("salary"), min("salary")).show()
df.select(approx_count_distinct("user_id")).show()  # 近似去重计数
```

⚠️ `approx_count_distinct` 用 HyperLogLog++ 算法，内存占用远小于精确计数，适合大数据集。

### GROUP BY 聚合

```python
# 基本 GROUP BY
df.groupBy("department").agg(
  count("*").alias("emp_count"),
  avg("salary").alias("avg_salary")
).show()

# 多列 GROUP BY
df.groupBy("department", "city").sum("salary").show()

# 聚合后过滤 (HAVING)
df.groupBy("department")
  .agg(count("*").alias("cnt"))
  .where(col("cnt") > 10)
  .show()
```

### 窗口函数 (Window Functions)

✅ **窗口函数在每行上访问与当前行相关的分组数据**，是 Spark SQL 的强大特性。

```python
from pyspark.sql.window import Window
from pyspark.sql.functions import rank, row_number, lag, lead

windowSpec = Window.partitionBy("department").orderBy(desc("salary"))
df.withColumn("rank", rank().over(windowSpec))
df.withColumn("row_num", row_number().over(windowSpec))
df.withColumn("prev_sal", lag("salary", 1).over(windowSpec))
df.withColumn("dept_avg", avg("salary").over(windowSpec))
```

⚠️ 窗口函数可能触发大量 Shuffle，需注意分区键选择。

### 分组集合操作

| 操作 | 说明 | 等价 SQL |
|------|------|----------|
| `rollup` | 层次聚合 (前缀) | `GROUP BY ROLLUP(...)` |
| `cube` | 全组合聚合 | `GROUP BY CUBE(...)` |
| `pivot` | 行转列 | `PIVOT(...)` |
| `groupingSets` | 自定义组合 | `GROUPING SETS(...)` |

```python
# Rollup: 产生 (dept), (dept, city), () 三级聚合
df.rollup("department", "city").sum("salary").show()

# Pivot: 行转列
df.groupBy("department")
  .pivot("gender", ["M", "F"])
  .avg("salary")
  .show()
```

## Ch 7 核心：复杂数据类型

### Array 类型

```python
from pyspark.sql.functions import split, explode, collect_list

df.select(split(col("name"), " ").alias("parts"))     # 字符串→数组
df.select(explode(col("parts")).alias("word"))         # 数组→多行
df.groupBy("dept").agg(collect_list("name"))           # 多行→数组
df.select(col("parts")[0], size(col("parts")), array_contains(col("parts"), "x"))
```

### Map 类型

```python
df.select(map_from_arrays(split("keys",","), split("values",",")).alias("m"))
df.select(col("m")["key1"])                            # 访问值
df.select(explode(col("m")))                           # Map→多行
```

### Struct 类型

```python
df.select(struct("name", "age", "salary").alias("info"))  # 创建
df.select(col("info.name"), col("info").getField("age"))   # 访问
df.select("info.*")                                        # 展开→多列
```

### JSON 数据处理

```python
from pyspark.sql.functions import from_json, to_json, get_json_object

df.select(from_json(col("json_str"), schema).alias("parsed"))  # 解析
df.select(to_json(struct("name", "age")))                       # 生成
df.select(get_json_object(col("json_str"), "$.name"))           # 快速提取
```

⚠️ JSON 处理性能较低；生产环境建议转为 Parquet/ORC 列式存储。

## 🔧 DuckDB / SQLite 类比

> 以下类比均为辅助理解，**非本书引擎行为**。

🔧 **类比 1：GROUP BY ≈ DuckDB/SQLite GROUP BY**
- 语义完全等价；DuckDB 有额外自动并行化优化 · ⚠️ 非本书引擎行为

🔧 **类比 2：窗口函数 ≈ DuckDB/SQLite Window**
- 三者都支持 `OVER(PARTITION BY ... ORDER BY ...)`；SQLite 3.25+ 支持
- Spark 分布式需 Shuffle；DuckDB/SQLite 单机无此开销 · ⚠️ 非本书引擎行为

🔧 **类比 3：explode(array) ≈ DuckDB UNNEST / SQLite json_each**
- 语义等价，都是将数组展开为多行 · ⚠️ 非本书引擎行为

🔧 **类比 4：JSON 处理 ≈ DuckDB json_extract / SQLite json_extract**
- `get_json_object(col,"$.name")` ≈ DuckDB/SQLite `json_extract(col,'$.name')`
- DuckDB `read_json_auto` 更强大（自动推断嵌套） · ⚠️ 非本书引擎行为

## 核心概念速览（中英对照）

| 中文 | English | 简述 |
|------|---------|------|
| 聚合 | Aggregation | 将多行数据汇总为单值 |
| 窗口函数 | Window Function | 在分区内跨行计算 |
| 分组 | Group By | 按键分组后聚合 |
| 上卷 | Rollup | 层次化聚合 (前缀组合) |
| 立方 | Cube | 全维度组合聚合 |
| 透视 | Pivot | 行转列操作 |
| 数组类型 | Array Type | 有序元素集合 |
| 映射类型 | Map Type | 键值对集合 |
| 结构类型 | Struct Type | 命名字段集合（嵌套行） |
| 展开 | Explode | 将数组/Map 展开为多行 |

## 最新演进与工业实践

**聚合与复杂类型的演进（书后发展）：**

| 演进 | 版本 | 影响 |
|------|------|------|
| AQE 动态优化聚合 | 3.0+ | 运行时检测数据倾斜并自动拆分倾斜分区 |
| 倾斜 Join 优化 | 3.0+ | `spark.sql.adaptive.skewJoin.enabled` 自动处理 |
| Variant 类型 | 4.0+ | 替代 JSON 字符串的半结构化数据类型 |
| 高阶函数 (Higher-Order Functions) | 2.4+ / 3.x 增强 | `transform`, `filter`, `exists`, `forall` 操作 Array |
| pandas UDF 聚合 | 3.0+ | Grouped Map / Grouped Agg 支持 Vectorized UDF |

> 来源: spark.apache.org ✅

**工业实践（2026）：**
- AQE 的倾斜 Join 自动处理大幅降低了手动调优需求
- Variant 类型（4.0+）正在替代 JSON 字符串处理半结构化数据
- DuckDB 的 `UNNEST` + `LIST` 操作与 Spark 的 `explode` + `collect_list` 形成有趣的对照
