## 本书在数据库系列中的定位

- **它是「MySQL 源码阅读地图」的祖先**：2007 年写的 4.1/5.0 内核导览。今天读它，价值在**机制的来龙去脉**（线程模型、handler 接口、优化器骨架、复制双线程），而**不在现状描述**——书中至少有一半机制已被 8.x 改掉（见下文勘误总表）。
- 与 repo 已验收目录版 [mysql/00-总览与阅读地图.md](../mysql/00-总览与阅读地图.md)（《MySQL 是怎样运行的》，5.7.22 基线）构成**上下游关系**：那本讲「今天的行为」，这本讲「当年为什么长这样」。每章文件尾部都设「与 mysql/ 目录的对位」小节。
- **同一本书的中文旧笔记**在 [../深入理解MySQL核心技术.md](../深入理解MySQL核心技术.md)（中国电力 2009 译本，repo 判词「讲的浅」）——本目录即在其基础上做目录版重写。
- 引擎侧深入交给 [../MySQL技术内幕_InnoDB存储引擎2.md](../MySQL技术内幕_InnoDB存储引擎2.md)；运维调优交给 [../高性能mysql.md](../高性能mysql.md)；教科书对照交给 [../数据库系统概念6/13-查询优化.md](../数据库系统概念6/13-查询优化.md) 等。
- 系列索引：[../数据库系列·总索引.md](../数据库系列·总索引.md)。

## 2007 → 2026 对位总表（本书重点：当年机制 vs MySQL 8.4/9.x）

| 主题 | 本书（4.1/5.0 口径，历史语境） | 今天（8.4 LTS / 9.x 创新版口径） | 两书口径差异（vs ../mysql/） |
| --- | --- | --- | --- |
| 连接模型 | one-thread-per-connection + 全局 mutex 分组 | 社区版仍一线程一连接；线程池仅企业版/Percona/MariaDB 有 | mysql/01 同口径；本书多了 5.0 全局变量分组动机 |
| 查询缓存 | 作为内核模块正式介绍（ch11 教引擎「使用查询高速缓存」） | **8.0 已整体删除**（5.7.20 起弃用）——书中该段全部作废 | mysql/ 目录直接按无 QC 讲 |
| 存储引擎接口 | handler/handlerton + 手写 ha_tina 引擎教程 | 接口大膨胀（分区、DD、组件框架），SE 以插件/组件注册；8.0 原子 DDL | mysql/01、10 从使用者视角；本书是唯一教「造引擎」的 |
| 表结构存储 | 每表一个 .frm 文件 + 引擎自有数据 | 8.0 事务性数据字典（InnoDB 内）+ SDI，**.frm 已消失**（8.0.16 起） | mysql/08 按 8.0 讲；书中 .frm 内容标「历史语境」 |
| 并发控制（Server 层） | THR_LOCK 表锁管理器；**尚无 MDL** | MDL 元数据锁（5.5 引入）+ 表锁弱化；InnoDB 行锁/间隙锁主导 | mysql/22 全按 InnoDB 行锁讲 |
| 优化器 | Selinger 式代价 + 5.0 子查询五策略；BNL 连接 | hash join（8.0.18+ 替代 BNL）、直方图统计（8.0）、EXPLAIN ANALYZE、CTE/窗口函数、优化器提示 | mysql/12–16 是现代口径；本书讲「原始骨架」 |
| 复制 | SBR 默认、双线程从库（IO+SQL）、基于文件+位置 | RBR 默认（5.7.7+）、GTID（5.6+）、并行复制 MTS→WRITESET 依赖追踪（8.0.26+）、组复制/InnoDB Cluster、binlog 压缩与加密 | mysql/X2 三日志协作是 5.7 口径；本书双线程从库段=历史语境 |
| 源码获取 | BitKeeper 树 + bk client | Git（2013 迁 GitHub）；4.1/5.0 树官方已不提供 | mysql/ 不以源码为轴 |
| 事务 | 存储引擎事务接口 + binlog 参与的早期两阶段 | 8.0 原子 DDL、内部 XA 成熟、组提交 | mysql/18–21 覆盖现代 redo/undo/MVCC |

> ⚠️ 勘误纪律：本目录凡转述书中 2007 年行为处一律标「历史语境」；凡 2024–2026 现状处给验证过的仓库/文档链接。
> 本环境无可运行的 MySQL 服务器实例，故本目录**不使用 🔧 实测标记**（与 mysql/ 目录不同），现状类结论给出处后标「转述」。

## 阅读地图（建议顺序）

1. **结构派主线**：01（架构史观）→ 02（源码树）→ 03（核心数据结构）——本书三大骨架章。
2. **机制派主线**：04（协议）→ 05（配置）→ 06（线程模型）→ 07（引擎接口）→ 08（锁）。
3. **SQL 派主线**：09（解析器/优化器）→ 10（各引擎）→ 11（事务）。
4. **分布式尾巴**：12（复制）。
5. 每章读完立刻翻对位：本目录文件内「与 mysql/ 对位」小节 → `../mysql/` 相应文件。

## 版本基线与工具声明

- 书中代码路径基于 4.1/5.0 源码树（`sql/`、`mysys/`、`storage/` 等，ch2 小节可证）；示例引擎 ha_tina、示例文件对照官方镜像仓库中的 `ha_csv-4.1.cc/ha_csv-5.1.cc`（✅ 实测存在于 dev2sec 仓库）。
- 本目录**不提供可运行环境**，所有代码片段为教学示意；英文原版 PDF 的下载链接（第三方镜像）不转载（版权原因），正文不复制原书段落。
- 网络取证缺口声明：O'Reilly 官方 TOC、archive.org、Google Books 对本环境不可达；目录正确性依赖中文版出版社引进目录（两处独立实抓）+ 社区旁证，可信度高但保留 ⚠️。
