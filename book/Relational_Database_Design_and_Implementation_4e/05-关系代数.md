## 一、精读札记（官方二级小节 ✅ 逐条）

- **The Relational Algebra and SQL Example Database: Rare Books** —— 一书两库并行：代数讲解与 SQL 章（Ch16–21）共用同一例库，教材一致性设计的典范。
- **The Sample Data** —— 珍本书域：出版商/书籍/藏书三级关系，含 1:N 与 M:N ⚠️（按后章连接用法推定）。
- **Making Vertical Subsets: Project** —— π：取列去重（注意：投影**自动消灭重复元组**——与 SQL SELECT  DISTINCT 缺省的差异是 Date 最爱开的炮口）。
- **Making Horizontal Subsets: Restrict** —— σ：谓词行过滤；三值逻辑下的真/假/未知（预告 Ch16 NULL 节）。
- **Choosing Columns and Rows: Restrict and Then Project** —— 复合：σ∘π 与 SQL 的 WHERE/SELECT 对应序。
- **Union** —— ∪：并兼容（union compatible）前置条件=同度同域。
- **Join** —— ⋈：θ连接→自然连接（按同名属性等值+去重列）；自然连接是代数与 SQL INNER JOIN 的分水岭。
- **Difference** —— −：R−S=在 R 不在 S；「差」是 NOT EXISTS 的集合论本体。
- **Intersect** —— ∩：可由两次差导出（代数封闭性的练习点）。

## 二、主题深读

### 2.1 代数是语义，SQL 是语法：三个违约点
1. **投影去重**：代数 π 产出关系（无重复）；SQL SELECT 产出多重集——DISTINCT 才是 π 的忠实翻译。🔧 E5（demos.txt，20000 行 emp）COUNT 语义差异演示：视图 v_a 定义含谓词、无 DISTINCT，聚合 5200 行——若按 π 语义重复列组会被消灭，SQL 不会。
2. **自然连接**：代数 ⋈ 按同名属性自动对齐；SQL 的 NATURAL JOIN 存在但工业弃用（列名演化即静默错连），等值 JOIN...ON 是 θ⋈+π 的手工展开——E1 五表模型 JOIN 链即证。
3. **除法定位**：本章 TOC 无「Division」小节 ✅——教材把除法留给 SQL 的 EXISTS 双重否定（Ch18 的 EXISTS 节 ⚠️ 对位推定），这个取舍与 DMD5e 显式讲除法（其关系代数章 ✅在册）形成对照。

### 2.2 与 Date 三部曲的正面对读
[../Relational_Theory_for_Computer_Professionals/04-关系运算符Ⅰ.md](../Relational_Theory_for_Computer_Professionals/04-关系运算符Ⅰ.md) 与 [05-关系运算符Ⅱ.md](../Relational_Theory_for_Computer_Professionals/05-关系运算符Ⅱ.md) 覆盖同一运算群但带 Tutorial D 记号与「四和（AND/OR/NOT/XOR 域上的关系布尔代数）」扩展；本书只用集合论基础群。对读收益：Harrington 讲「怎么用」，Date 讲「少了哪个运算就表达不了什么」（封闭性定理）。

### 2.3 运算序=优化问题的胚胎
σ∘π 可交换/可合并的代数性质是查询改写器（SQLite 查询平面化器、DuckDB 优化器）的合法变形清单。🔧 E5 计划对照（demos.txt）：`SCAN emp 1.65ms` → `SEARCH emp USING COVERING INDEX ix_emp (dept=? AND sal>?) 0.299ms`，谓词下推+覆盖索引=把 π 与 σ 在物理层融合的最直观工业注脚。

### 2.5 代数算子 → SQL 子句对照表（本册版）

| 代数 | 语义 | SQL 对应 | 纪律锚 |
|---|---|---|---|
| Project | 垂直截除重复 | SELECT 列清单 | DISTINCT 不自动（2.6） |
| Restrict | 水平筛选 | WHERE | 三值逻辑（11 §2.6） |
| Product | 笛卡尔积 | CROSS JOIN | 爆炸半径=两基数的积 |
| Join（θ/等值） | 二目装配 | JOIN…ON | FK 对齐（04 §2.3） |
| Union | 二目同型并 | UNION [ALL] | 列数/类型同构 |
| Difference | 二目排除 | EXCEPT（方言） | NULL 行陷阱 |
| Intersect | 二目同存 | INTERSECT（方言） | 同上 |

Ch6 的九个小节（✅ 小节清单：Project/Restrict/两者连用/Union/Join/Difference/Intersect）恰好铺满这张表——教材的章序就是算子的教学难度序。表外唯一缺角是除法：见 2.7。

### 2.6 bag vs set：SQL 对代数的「默认背叛」
代数论域是集合，SQL 的 FROM/UNION 默认是 bag——UNION 才去重回集合论域（⚠️ 通说措辞；本书 SQL 章按主流教学处理）。工程翻译：**DISTINCT 是税，不是美德**——出现意外重复行，第一假设是连接键没对齐（1:1 侧被当成 1:N，03 §2.1 中间表是结构防线），第二假设才是「数据真有重复」。🔧 E5 附注（非本书示范行为）：5200 行同查询 SCAN→SEARCH 的 6.1× 计划差（demos）提醒——代数等价 ≠ 执行等价，语义读本章、性能读 07。

### 2.7 除法与关系完备性的「留角」（⚠️ 评注）
Ch6 小节清单（✅ 全九节）不含 Division——「找买过全部 X 的客户」这类查询因此不能在代数章内闭环，教材的补偿路径是 Ch18 的 EXISTS/相关子查询双重否定（12 §2.3 已开）。本册合读法：「所有/全部」量词出现处，先写代数商式 R÷S，再写 SQL 的 NOT EXISTS…NOT EXISTS——两式互证即完备性自测。除法缺席是编排选择不是遗漏：商的教学成本高、SQL 实践者可绕。

### 2.8 算子覆盖自检（收束清单）
五动词一屏过：选（Restrict+NULL 分支）、投（Project+去重）、并（Union/bag 纪律）、连（θ/等值/外连在 12）、差（Difference/EXCEPT+NOT IN 陷阱的代数原型）。Rare Books 例库（✅ The Relational Algebra and SQL Example Database: Rare Books 节题）上每动词至少一题；🔧 单机 SQLite 十分钟全过（非本书示范行为，demos 环境同款）。
