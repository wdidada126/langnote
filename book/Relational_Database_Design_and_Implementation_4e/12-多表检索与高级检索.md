## 二、主题深读

### 2.1 NOT IN 的 NULL 陷阱：本章最值钱的一页纸
`WHERE id NOT IN (SELECT bad_id FROM blacklist)` 若 blacklist 含一个 NULL，**整个谓词永假**（每项比较出 UNKNOWN，OR 链含 UNKNOWN 无 TRUE）——反连接静默返空。修复三选一：`NOT EXISTS` 相关式 / 子查询加 `WHERE bad_id IS NOT NULL` / LEFT JOIN+IS NULL 反连接。🔧 该模式在两载体均可复现（demos.txt 未单列，本目录口径 ⚠️ 属 Ch16 三值逻辑推论，E6 的 AVG/SUM 差为其聚合面）。
### 2.2 🔧 方言矩阵（非本书示范行为）
本机 2026-10-02 语法面速查（可跑 demos.py 扩样）：

|---|---|---|
| FULL OUTER JOIN | ✅ 支持 | ✅ 支持 |
| EXCEPT/INTERSECT | ✅（3.8.3+） | ✅ |
| VALUES 表构造器 | ✅ `FROM (VALUES..)` 需别名技巧 | ✅ `FROM (VALUES..)` 原生 |

### 2.3 EXISTS 与除法：代数章还债
π_{a,b}(R) ⊆ S 的「全部买过」查询用双重 NOT EXISTS 表达——Ch6 未教除法，Ch18 用 EXISTS 还债；与 [../Relational_Theory_for_Computer_Professionals/00-总览与阅读地图.md](../Relational_Theory_for_Computer_Professionals/00-总览与阅读地图.md) 及 [../Databases_Illuminated_4e/00-总览与阅读地图.md](../Databases_Illuminated_4e/00-总览与阅读地图.md) 的对应章对读，三册同题深度排序：Date>RICARDO>Harrington。
### 2.4 子查询 vs 连接的选择律
书内立场「能连接尽量连接，存在性用子查询」；🔧 E5 计划面证据（demos.txt）：谓词可下推时优化器会把不相关子查询改写为连接/半连接——「写法选语义最清晰的，性能交给优化器；除非优化器不认（相关子查询退化循环）」，这是 Ch17 末节在列存引擎时代的修订版（DuckDB 对 EXISTS 的向量化半连接处理 ⚠️ 通说，盘上 ../DuckDB_in_Action 实测集在册 ✅ 可纵引）。

### 2.5 自连接与层级查询：本章通往递归的桥
Finding Multiple Rows in One Table: Joining a Table to Itself（✅ 节题）的两种正用：①同行异角比较（同事/同期/同域配对）；②表内 FK 的父子层级（经理→员工）。第二种在 2026 的延长线是递归 CTE 闭包查询（14 §2.2 主场）——本章给一次连接，14 给传递闭包，读者要认出它们是同一个想法的两层深度。外连接侧（Outer Joins ✅）的 2026 教义：**LEFT JOIN + 右侧 IS NULL = 反连接**，差集查询的方言主路（NOT IN 的 NULL 陷阱绕法，2.1 闭环）。

### 2.6 表达式三节（算术/字符串/日期时间，✅）的当代注记
Ch18 的三个表达式小节（✅）在 2026 的三点注记：**算术**——整数/小数/浮点三族的除法是精度事故重灾区，CAST 前置纪律交给 13 §2.5；**字符串**——排序规则（大小写/重音/尾空格）在多引擎时代是新方言面，🔧 E6 的 'new york ' 标本就是字符串谓词+数据质量两章的会师点（非本书示范行为）；**日期时间**——时区与夏令时是教材年代未竟的义务，2026 无时区 TIMESTAMP 上生产等于负债（⚠️ 综合判词）。CASE Expressions（✅）的后裔是查询内的小型函数式编程——它的教材定位（表达式不是语句块）至今正确。

### 2.7 Table Constructors 与 VALUES 的晋升（✅ 节题注记）
Table Constructors in Queries（✅）在 2016 是冷知识小节；2026 的 VALUES 已是四职常备件：内联测试夹具、反连接清单、批量行构造、递归 CTE 的种子行（14 §2.2 的 WITH … AS (VALUES …) 起手式）。一节十年冷转热——**为练习造数据的最短路径就是被教材埋没的那个语法**。🔧 载体注：本波 demos 各标本即多处以 VALUES/行构造起手（非本书示范行为）。
