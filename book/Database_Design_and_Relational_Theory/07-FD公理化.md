## 本章定位

给第 5 章"成立/蕴含"装上可计算的引擎：三条公理（Armstrong axioms）_sound_ 且 _complete_，
从此"这条依赖是否被那些依赖逼出来"是有限步内可判定的问题。全章是 05/06 两章算法的数学地基。

## 机制精讲

### 7.1 阿姆斯特朗公理（IRN）

对属性集 U 上的 FD（X,Y,Z ⊆ U， juxtaposition=并）：
- **自反 A1**：Y⊆X ⇒ X→Y（平凡依赖）；
- **增广 A2**：X→Y ⇒ XZ→YZ；
- **传递 A3**：X→Y, Y→Z ⇒ X→Z。

X 的**闭包** X⁺ = { A | X→A 可由公理推出 }；🔧 实测（demo D3）：
F={CT→I, I→C} 上 (CT)⁺={C,T,I}、(I)⁺={C,I}——超键判定一步到位。

**可靠性（soundness）**：三规则在关系语义下保持真；**完备性（completeness）**：凡语义蕴含
（5.1 的"成立"）皆可推出。作者在此只证可靠性方向、完备性给结论 ⚠️ 口径（证明需要"符号表构造"，
多数教材补全）。

### 7.2 附加规则（可派生）

- **并/加性 U**：X→Y, X→Z ⇒ X→YZ；
- **投影 P**：X→YZ ⇒ X→Y；
- **伪传递 PT**：X→Y, YZ→W ⇒ XZ→W；
- **复合 C**：X→Y, YZ→W ⇒ XZ→W∪(YZ−W)…（各书表述略异，本书取 ⚠️ 转述：由 PT+U 组合即得）。

🔧 穷举验证增广可靠性（本机 ✅ 思路）：在 3 元组小实例上枚举所有满足 X→Y 的状态，
逐一检查 XZ→YZ 亦成立——规则可靠性在有限模型上可**抽样检验**，但**证明**只能靠 5.1 的语义论证。

### 7.3 证明附加规则（样板）

示范风格（作者式的两栏证明）：证明 U：X→Y 与 X→Z。任取两元组 t1,t2 使 t1[X]=t2[X]；
由 X→Y 得 t1[Y]=t2[Y]，由 X→Z 得 t1[Z]=t2[Z]；两等式并置即 t1[YZ]=t2[YZ]。∎
——每步只是回到"满足"的定义（5.1），这正是"公理化不难、难在坚持回到语义"的教学点。

### 7.4 另一种闭包

**依赖集的闭包 F⁺**：F 语义蕴含的全部 FD。判分解是否保依赖（06 章）、求最小覆盖（6.5）
都是 F⁺ 的查询。实践用属性闭包算法迭代每条 FD 即可，无需显式展开 F⁺（指数大）。

> 与关系代数的呼应：闭包算子与投影-连接的"信息恢复"问题是同一枚硬币——09/10 章的 JD
> 公理化（更弱、不完备 ⚠️：JD 没有可靠的完备公理集，Rissanen 结果）会看到边界。

## 常见误区

- 「公理推出的依赖要看数据对不对」：公理是约束层的推导，与实例无关；实例只能证伪"成立"的前提。
- 「完备性=所有依赖都能列出来」：F⁺ 巨大，完备性只保证**判定**有限终止，不保证枚举便宜。
- 「 Armstrong 公理同样适用于 JD/MVD」：MVD 有增补的完备系统（Fagin ⚠️ 细节从略），
  JD 没有——这正是 5NF 理论更难算的原因（留神：别把本章引擎直接套到 09/10 章）。
- 「最小覆盖唯一」：不唯一；不同最小覆盖可能导向不同的保依赖分解片（06 章 6.2 例组的根因）。

## 属性闭包算法（🔧 伪码 + 本机已跑通）

```
输入：X, F
cl := X
repeat
    for each Y→Z ∈ F:  if Y ⊆ cl then cl := cl ∪ Z
until cl 不再变化
返回 cl          # X 为超键 ⇔ cl = U；F ⊨ X→Y ⇔ Y ⊆ cl
```

复杂度 O(|F|·|U|) 量级的不动点迭代——demo.py 的 `clo()` 即它的 12 行 Python 实现 ✅。
F⁺ 判定、最小覆盖去冗余、分解保依赖检查（06 章）、chase 的 FD 特例（11 章）全部是此一枚引擎的调用方。

## 三道推导练习（用公理而非直觉）

1. 证投影规则 P：X→YZ ⇒ X→Y。
   路线：A1 给 YZ→Y；A3 与 X→YZ 复合。∎（每步都回到"满足"定义，7.3 风格）
2. 证伪传递 PT：X→Y, YZ→W ⇒ XZ→W。
   路线：A2 于 X→Y 得 XZ→YZ；A1 得 YZ→YZ…接 A3 于 YZ→W。∎
3. 反例构造：在 U={A,B}、F={A→B} 上列出 F⁺ 的全部成员（3 条：A→B、A→AB?、AB→B/A→A…
   用闭包数：(A)+={A,B}，(B)+={B}，(AB)+={A,B}）——体会"公理可推出的恰是成立的"之双向含义。

## 核心概念速览（中英对照）

- **公理系统** — axiom system：生成全部成立依赖的推导规则集
- **阿姆斯特朗公理** — Armstrong's axioms：自反 A1、增广 A2、传递 A3
- **可靠性** — soundness：公理推出的必语义成立
- **完备性** — completeness：语义成立的必可推出
- **属性闭包** — attribute closure (X⁺)：X 能决定的全属性集；超键判据 X⁺=U
- **依赖集闭包** — closure of FD sets (F⁺)：F 蕴含的一切依赖
- **并规则** — union rule：X→Y, X→Z ⇒ X→YZ
- **投影规则** — projectivity rule：X→YZ ⇒ X→Y
- **伪传递规则** — pseudotransitivity：X→Y, YZ→W ⇒ XZ→W
- **最小覆盖** — minimal cover：F 的最简等价集（06 章综合算法输入）
- **蕴含判定** — implication testing：F ⊨ f?——闭包算法解之
- **有限模型检验** — finite countermodel（🔧）：小实例枚举可怀疑、不可证明
- **JD 无完备公理** — incompleteness for JDs：与 FD 的关键分野 ⚠️ Rissanen 结果转述
- **语义/语法对** — semantics vs syntax："成立"与"可推出"的同一性即完备性陈述
