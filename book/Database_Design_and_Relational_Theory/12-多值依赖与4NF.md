# 12 多值依赖和 4NF（MVDs and 4NF ✅，原书第 12 章）

> 🔧 分解等价与行数为本机 sqlite3 实测（demo.py D5）。

## 本章定位

4NF 处理的是 FD 与 5NF 之间的"中间冗余"：**独立多值事实**塞进一个 relvar。
MVD 恰是最简单的 JD（两元、对称），所以本章承上（10 章 JD 语言）启下（13 章剩余范式），
并顺手揭开 NULL 在依赖层的真面目（嵌入式依赖）。

## 机制精讲

### 12.1–12.2 介绍性例子与（非正式）MVD

谓词混形的经典例：`TSC{Teacher, Subject, City}`——"教师 t 教科目 s 且住在城市 c"？不：真实世界是
**两个独立事实**（t 教 s；t 住 c）硬挤一张表。非正式判据：固定 t 后，s 的集合与 c 的集合
**互不相关**（t 的每个科目 × t 的每个城市都在表里），记 `T →→ S`（补部即 C）。

🔧 实测（demo D5 ✅）：4 元组（t1×{db,ai}×{london,paris}）满足 T→→S；分解 TS{T,S}、TC{T,C}：
`TSC == TS |x| TC: True`；存储账：原表 4 行 vs 两片 2+2=4 行打平，但**增量**见真章——
t1 新增第 3 个城市时，TSC 要补 2 行（新城市×每科目）、TS/TC 各补 1 行；科目越多、乘法爆炸越狠。

### 12.3 正式定义

R 满足 `X →→ Y`（Z = R−X−Y）：对任意状态 r 中元组 t，存在 t1,t2 ∈ r 使
t1[X]=t2[X]=t[X]、t1[Y]=t[Y]、t2[Z]=t[Z]，且拼合元组 t1∪t2（在 X 上重合）∈ r。
- **补部定理**：X→→Y ⇒ X→→(R−XY)——MVD 天生对称，"独立"的双侧性就在定义里。
- **与 JD 的桥**（10 章兑现）：X→→Y ⇔ JD *{XY, X(R−XY)} 成立。故 4NF 是 JD 理论的两元特例，
  一切 5NF 工具（含 11 章 chase）退化可用且**完备公理化存在**（见 12.5）——比 JD 幸福。
- 与 FD 的包含：X→Y ⇒ X→→Y（函数依赖是"单值"的多值依赖）；4NF ⇒ BCNF。

### 12.4 第四范式

**R 是 4NF ⇔ 每个成立的非平凡 MVD 的决定因素都是超键。**
TSC：T→→S 非平凡、T 非超键 ⇒ 违 4NF ⇒ 分解 {TS,TC}——恰是 12.1 直觉的形式化盖章。
分解算法同希思形（MVD 直接给两片无损，且 4NF 分解**总保持** MVD ⚠️ 本书口径——4NF 无
第 6 章式的保持冲突，代价只是"可能停不到 BCNF+"）。

### 12.5 公理化

MVD+FD 的联合推理有**完备公理系统**（Fagin / Goguen-Thatcher-Lucena 等；📄 转述）：
Armstrong 三条 + MVD 增补（投影、传递、余因子/complementation、增广的对称版等约五条）。
🔧 演练：FD CT→I 与 MVD T→→S 混集下判蕴含，用 chase 或公理两路可达同结论（与 11 章呼应：
**MVD 世界 chase 完备**，JD 世界不完备）。

### 12.6 嵌入式依赖

把"对所有元组"改成"对所有**无 NULL**元组/在 NULL 忽略语义下"，得 **嵌入式 FD/MVD**（embedded
dependencies）。工场景观瞬间眼熟：SQL 表用 NULL 外键列模拟"多值"——一个可空属性存半个集合。
- 作者立场 ⚠️ 一贯口径：嵌入式依赖的存在不是"NULL 有理论席位"，而是坏设计的病理报告：
  4NF 的正解是把多值事实拆成独立 relvar（12.4 分解），NULL 随之失业。
- 呼应兄弟目录的查询侧病案：[../SQL_and_Relational_Theory/06-NULL与三值逻辑3VL.md](../SQL_and_Relational_Theory/06-NULL与三值逻辑3VL.md)、
  [../SQL_and_Relational_Theory/07-缺失值的真实语义-42与2与Placeholder.md](../SQL_and_Relational_Theory/07-缺失值的真实语义-42与2与Placeholder.md)。

## 常见误区

- 「多值=数组列」：MVD 是**约束**（独立性），数组/重复组是把约束**藏进表示**（1NF 违规，04 章）；
  两者方向相反：MVD 让你拆表，数组让你混表。
- 「MVD 是 FD 的推广所以 4NF 自动带 BCNF 的一切好」：包含关系对（4NF⇒BCNF），但"保持依赖"的
  安心感只对 MVD 集成立；混合集下 4NF 分解可能丢 FD 语义 ⚠️ 细节以 chase 复核为准。
- 「T→→S 里 t 的科目和城市有关也没关系」：有关就是 FD（T→SC 之类），MVD 判据正是"**不**相关"——
  独立性是约束内容不是背景假设。
- 「嵌入式依赖给 NULL 翻了案」：12.6 的定性相反；理论界为 NULL 修公理体系 ≈ 给病灶配语法。

## 本章自测

1. 语言题：把 TSC 的两个独立谓词写出来（"t 教 s" 与 "t 住 c"），再解释为什么挤一张表时
   它们变成"一个谓词的乘积外延"——这正是 12.3 补部定理所许可的形状。
2. 🔧 增量账复算：t1 的第 3 个城市在 TSC 里要补几行、TS+TC 里各几行？把科目数改成 m、
   城市数改成 n，写出两方案的行数公式并指出谁是乘法谁是加法。
3. 证明题（三行）：X→Y ⇒ X→→Y。（用 12.3 定义：拼合元组即原元组自身。）
4. 判定：R{S#,P#,QTY}，键 {S#,P#}，另有 S#→→P#？（提示：{S#,P#} 已是键 ⇒ 该 MVD 平凡？
   写出补部 R−SP={QTY} 后套用平凡定义。）
5. 立场题：12.6 为什么说"嵌入式依赖理论是 NULL 病理学而非 NULL 辩护词"？用 SQL 里
   可空外键列模拟多值的两个具体失效场景作答（唯一性约束失配、跨 NULL 的 join 语义漂移 ⚠️）。
6. 迁移题：自拟一张"教师-科目-城市"的变体表（如 订单-优惠码-收货电话），先声明你相信的
   FD/MVD，再按 12.4 出判决书：违例则给拆法并验行数账，不违则说明为何免拆。

## 核心概念速览（中英对照）

- **多值依赖** — multivalued dependency (MVD)：X→→Y；固定 X 后 Y 与补部无关
- **补部** — complement：Z = R−X−Y；补部定理 X→→Y ⇒ X→→Z
- **平凡 MVD** — trivial MVD：Y⊆X 或 XY=R
- **非正式判据** — independence reading：每 X 值的 Y 集与 Z 集独立
- **4NF** — 每个非平凡 MVD 的决定因素皆超键
- **MVD=两元 JD** — MVD as 2-way JD：*{XY, X∪(R−Y)}；4NF 是 JD 理论的特例
- **FD⊂MVD** — inclusion：X→Y 蕴含 X→→Y；4NF⇒BCNF
- **MVD 公理化** — axiomatization for FDs+MVDs：完备（与 JD 的不完备对照）
- **乘法爆炸** — cartesian blow-up：独立多值挤一表时行数的乘积增长（🔧 3 城市实测口径）
- **嵌入式依赖** — embedded dependency：忽略 NULL 元组后的弱化 FD/MVD
- **NULL 的病理报告** — NULL as symptom：作者对嵌入式依赖存在意义的定性
- **拆表方向** — decomposition direction：MVD 违例的处方永远是"一事实一 relvar"
- **TSC 例** — teacher-subject-city：本章的 S_P_J（独立双事实的标本）
- **保持性豁免** — preservation without conflict：4NF 分解总保 MVD ⚠️ 本书口径
- **独立双事实** — two independent facts：12.1 病例的诊断学名——一表两谓词，拆则各归一张
