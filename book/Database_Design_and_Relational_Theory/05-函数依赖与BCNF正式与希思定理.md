## 本章定位

把第 4 章的直觉升级为可对"所有合法状态"量化的定义，然后给出全书第一个分量定理——
**希思定理**：函数依赖保证无损分解。它是后面一切"放心拆表"的许可证。

## 机制精讲

### 5.1 初步定义（形式化底座）

设 R 为关系变量，r 为其某时刻取值（以下用同一字母）。对属性集子集 X：
- **投影**：r 在 X 上的值集（注意：关系语义 ⇒ 自动去重）。
- **r 满足 X→Y**：对 r 中任意两元组 t1,t2，若 t1[X]=t2[X] 则 t1[Y]=t2[Y]。
- **R 满足 X→Y**：R 的**每个可达状态**都满足之。——这一层量化就是"约束"与"巧合"的分界。
- FD **成立当且仅当**它被 FD 集逻辑蕴含（记 F ⊨ X→Y；公理化在 07 章）。

### 5.2 函数依赖（正式）

- 超键：X→ALL（全属性）且 R 满足之；候选键：极小超键。
- 派生性质（🔧 集合演算可自验）：自反、增广、传递三条公理即可生成全部成立依赖（Armstrong 完备性 → 07 章）。

### 5.3 Boyce/Codd 范式（正式）

**R 是 BCNF ⇔ 对 R 的每个成立的非平凡 FD X→Y，X 是超键。**

两条配套论断（作者反复使用的"同构三重唱"，正式版）：
1. BCNF ⇒ 无冗余（每个事实恰一处出现）⇒ 无相应更新异常；
2. 反之不绝对：BCNF 不排除**所有**异常——JD/MVD 造成的异常要到 4NF/5NF 才封顶（第 9–12 章）。
   因此"已到 BCNF"只是**在 FD 世界内**的健康证。

### 5.4 希思定理（Heath's Theorem）

**定理（本书口径的陈述 ⚠️ 措辞重构）**：设 X→Y 在 R 上成立，把 R 分解为
R1 = XY 与 R2 = X ∪ (R − Y)。则 {R1, R2} 是**无损连接**分解：对 R 的每个合法状态 r，
r = π_{R1}(r) ⋈ π_{R2}(r)。

- 直觉：X→Y 意味着"Y 的信息已经打包在 X 里"，把 Y 搬出去时，X 作为粘合键足以复原一切。
- 为什么重要（呼应官方问题清单 ✅）：它把"要不要拆"从玄学变成判定——**凡决定因素非超键的依赖，
  都提供一张无损分解的许可证**；反复应用即得 BCNF 分解算法（算法本体与"保持依赖"之困在 06 章）。
- 🔧 实测（SQLite，本机 ✅）：CTI{C,T,I}，FD 集 {CT→I, I→C}，按 I→C 分解为 R1{I,C}、R2{I,T}：
  `R1 |x| R2 还原 CTI（无损）: True`（自然连接重建后与原关系集相等）。
- 🔧 闭包验证（Python ✅）：(CT)+={C,T,I}（超键）、(I)+={I,C}（非超键 ⇒ I→C 是 BCNF 违例、
  也正是希思许可的分解方向）。

> 历史注 ⚠️：定理冠名 Heath（1971），一手文献本环境未核到（无 DOI），教材通道给 Bernstein 1976
> 的推广与综合算法（DOI:10.1145/320493.320489，api.crossref 200 ✅，见 06 章）。

## 常见误区

- 「实例上没看到重复元组 ⇒ relvar 满足该 FD」：5.1 的量化层又丢了；约束是关于意图的。
- 「无损分解 = 数据能拼回来就行」：还须对**所有合法状态**成立——否则今天无损、明天有损。
- 「BCNF 分解一定保持全部依赖」：这正是下一章的反例主题（🔧 D2 已见雏形：分解后的合法插入重建出 CT→I 违例）。
- 「希思定理只对 FD 有效」：对——JD 版的"无损"语言在 09/10 章重讲；两者的差别恰是 5NF 内容本身。

## BCNF 分解算法（希思定理的循环使用，🔧 伪码）

```
输入：R 与成立的 FD 集 F
D := {R}
while 某片 Ri ∈ D 存在非平凡 X→Y ∈ F⁺(在 Ri 上的投影) 且 X 非 Ri 超键:
    D := D − {Ri} + { XY, X ∪ (Ri − Y) }     # 希思许可证：无损
输出：D（BCNF + 无损；保持性另账——06 章）
```

三句批注：
1. 循环必终止：每步片数 +1、属性不增，界在 2^n；
2. "F 在 Ri 上的投影"是关键细节：分解后有些依赖**不再可见**，正是 6.1 冲突的机制面；
3. 分解顺序影响片数与保持性（06 章 6.2–6.4 例组），算法给的是存在性不是最优性。

## 核心概念速览（中英对照）

- **投影** — projection：关系在属性子集上的像；关系语义下自动去重
- **满足（实例级）** — satisfaction (by a relation)：当前值上 X 同则 Y 同
- **成立（约束级）** — holds (in a relvar)：所有可达状态均满足——约束的定义
- **逻辑蕴含** — logical implication：F ⊨ f：每个满足 F 的状态也满足 f
- **BCNF（正式）** — BCNF (formal)：每个成立的非平凡 FD 的决定因素皆超键
- **冗余 ⟺ 异常** — redundancy/anomaly equivalence：FD 世界内的"健康证"
- **分解** — decomposition：用一组投影替换原 relvar
- **无损连接** — lossless join：⋈π = 恒等；信息不因拆分而丢失
- **希思定理** — Heath's theorem：X→Y ⇒ {XY, X∪(R−Y)} 无损
- **分解许可证** — license to decompose：违例 BCNF 的依赖同时指明无损方向
- **粘合键** — join key：X 在两分解片中的复用角色
- **BCNF 分解算法** — BCNF decomposition：反复应用希思直至每片 BCNF（06 章谈代价）
- **闭包** — attribute closure：判定超键/蕴含的机器 (X)+
- **状态空间** — state space：约束量化的定义域

- **定理的当代教材化**：Silberschatz 等教材将同一定理表述为"无损连接测试"（⋈ 后属性集上的公共属性
  →某侧超键），与希思表述等价（对照 [../数据库系统概念6/00-总览与阅读地图.md](../数据库系统概念6/00-总览与阅读地图.md)）；
  本书的独特讲法是把定理当**设计动作**（发现违例依赖即可动手），不是事后检验。

  但证明只能走定理/闭包。遗留库逆向时建议双轨：实例试验 + 从业务语义提取 FD，再跑希思分解。
