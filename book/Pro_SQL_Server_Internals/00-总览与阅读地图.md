## 四、本书在数据库系列中的定位

- **谱系**：本书是 Korotkevitch"内核卷"谱系的开山之作（OLTP 视角、机制→设计决策的写法），
  作者自序里把它与 Kalen Delaney 等的《Microsoft SQL Server 2012 Internals》（开发者参考系列）做对照——本书刻意走"实用主义 + 开发/DBA 双读者"路线。
- **辨析（硬声明）**：本仓库中的 [../Microsoft_SQL_Server_2008技术内幕.md](../Microsoft_SQL_Server_2008技术内幕.md) 经豆瓣核实实为 Itzik Ben-Gan 的
  **T-SQL 语言基础分册**（《Microsoft SQL Server 2008 技术内幕：T-SQL 语言基础》，ISBN 9787121095931，见 [../SQL系列·总索引.md](../SQL系列·总索引.md)），
  讲查询语法与集合思维，**与本书（存储引擎/锁/日志内核）不同谱系、不同卷**，互为"语言层 ↔ 引擎层"互补，切勿混作"技术内幕系列"。
- **横向对照**：B-Tree/页存储可与 [../Database_Internals/00-总览与阅读地图.md](../Database_Internals/00-总览与阅读地图.md)、[../数据库系统内幕.md](../数据库系统内幕.md) 对照；
  InnoDB 页/索引机制对照 [../MySQL技术内幕_InnoDB存储引擎2.md](../MySQL技术内幕_InnoDB存储引擎2.md) 与 [../高性能mysql.md](../高性能mysql.md)；
  PG 内核对照 [../PostgreSQL数据库内核分析.md](../PostgreSQL数据库内核分析.md)；索引设计通论对照 [../数据库索引设计与优化.md](../数据库索引设计与优化.md)；
  事务/锁理论基线对照 [../事务处理概念与技术.md](../事务处理概念与技术.md) 与 [../数据库系统概念6.md](../数据库系统概念6.md)；
  ARIES 恢复算法与 Hekaton 论文线见 [../../db/ARIES.md](../../db/ARIES.md)、[../../db/Hekaton.md](../../db/Hekaton.md) 与 [../../db/db.md](../../db/db.md)。
- **系列入口**：[../数据库系列·总索引.md](../数据库系列·总索引.md)、[../SQL系列·总索引.md](../SQL系列·总索引.md)。

## 五、阅读地图

- **主线 A（存储与索引，全书地基）**：01 → 02 → 03 → 04 → 05。作者序言明确建议从 Part 1 起步，其余部分都建立在其上。
- **主线 B（并发三件套）**：12 → 13 → 16（行版本化、锁升级、日志）。对应官方 Part 3 + Part 6。
- **主线 C（查询生命周期与排障）**：14 → 15（优化器/计划缓存 → 等待统计/Extended Events）。
- **主线 D（新引擎，2012/2014 时代）**：17 → 18（Hekaton 与列存），并与 10（分区）、16（日志/HA）互引。
- **应用开发者线**：06 → 07 → 08 → 09 → 11（约束/触发器/视图函数/XML 与临时表/CLR/ORM 与数据访问层）。
