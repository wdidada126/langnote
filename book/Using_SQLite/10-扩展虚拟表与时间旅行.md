## 1. 扩展的两扇门：静态链接与动态加载

1. **SQL 函数扩展**（书中用 PHP/自定义函数示例）：`sqlite3_create_function()`
   注册标量/聚合函数，编译期静态链入——永远可用、无安全问题；
2. **加载扩展**（`loadable extension`）：运行期 `sqlite3_load_extension()` /
   SQL 里 `load_extension()`；需 `-DSQLITE_ENABLE_LOAD_EXTENSION` 编译，
   且 API 默认禁用（安全护栏：库文件不可信时加载 DLL/SO 等于任意代码执行）。

🔧 本机现状：CPython `enable_load_extension(True)` 调用本身成功（Python 3.5+ 暴露该 API），
compile_options 中未见 `SQLITE_ENABLE_LOAD_EXTENSION`——实际加载 `.dll` 是否放行
本会话未验证（无现成扩展二进制，⚠️ 记为未实测项）。
书中"自己写扩展要编 C"的门槛，在 2026 被**语言侧桥**大幅降低：
Python 3.13 `create_aggregate/function` 直接注册纯 Python 函数（官方文档 ✅）——
"扩展= C 专属"已过期。

## 2. 虚拟表：SQL 世界里的"存储引擎插件位"

虚拟表模块（[vtab.html](https://sqlite.org/vtab.html) ✅）让"一张表"由 C 代码实现
`xBestIndex/Next/Filter` 回调，把外部数据源或专用结构伪装成表。与 MySQL 的
storage engine handler 对照着读极有味（
[../Understanding_MySQL_Internals/07-存储引擎接口.md](../Understanding_MySQL_Internals/07-存储引擎接口.md)）：
同为"引擎内引擎"插槽，MySQL 按表空间接入，SQLite 按查询规划器 bestIndex 协商接入。

🔧 3.45.3 内置模块清单（`SELECT name FROM pragma_module_list`）：**11 项**——
`fts3/fts4/fts5/fts5vocab/fts4aux/fts3tokenize/rtree/rtree_i32/json_each/json_tree/pragma_module_list`
（亲验原样输出）——**同名的 eponymous 虚拟表**（`CREATE VIRTUAL TABLE` 可省、
直接 `SELECT * FROM json_each(...)`）是 3.8 之后普及度最高的一族。

书中"用虚拟表把 anything 变成 SQL 源"的思路，2026 的官方延续是 **CSV 扩展**
（[csv.html](https://sqlite.org/csv.html) ✅，CLI 内建）、社区延续是 db-duckdb 桥与
sqlite-vss 向量检索（⚠️ 三方仓库未核验，仅点名不引用数字）；
"单机把万物当表查"的当代最强代表则是 DuckDB（[#134 目录版已落盘](../DuckDB_Up_and_Running/00-总览与阅读地图.md)，波尾闭环；另可对读
[../DuckDB_in_Action/00-总览与阅读地图.md](../DuckDB_in_Action/00-总览与阅读地图.md)）。

## 3. 🔧 实测：FTS5 ——虚拟表主力用例（5 万文档）

方法：50,000 条文本（每 97 条埋一个唯一稀词 `unobtainium<i>`），双写：
普通表 `docs` + `CREATE VIRTUAL TABLE fts USING fts5(id UNINDEXED, body, tokenize='porter')`。

结果（Python 3.45.3）：

| 指标 | 数值 |
| --- | --- |
| FTS5 索引 5 万文档 | **0.32 s** |
| 稀词查询 `MATCH 'unobtainium388'` | **0.00065 s** |
| 同词 `LIKE '%unobtainium388%'` 全表扫 | 0.0095 s（**15× 慢**） |
| 语义差彩蛋 | LIKE 命中 **4** 行（子串匹配到 3880/388…）、FTS 命中 **1** 行（词元精确） |
| 短语查询 `MATCH '"small fast"'` | 0.0056 s（50,000 行匹配） |
| BM25 排序 | `bm25(fts)` 可 ORDER BY（🔧 top3 输出） |
| snippet() 高亮 | `SQLite is a small fast reliable <b>embedded</b> database...`（🔧 亲验） |
| 库体积 | 12,967,936 B（原文 + FTS 索引，索引约占一半，⚠️ 未精确拆分） |

书中（3.8 时代主推 FTS3/4）的倒排索引、`MATCH` 查询语法概念在 FTS5 全部成立；
FTS5 额外给了 UNINDEXED 列、外部内容表（content=，做"原文不存索引"的省空间模式）、
`PRAGMA optimize` 触发增量合并（官方 fts5.html ✅ 口径，本会话未做专项实验 ⚠️）。
搜索线互链：倒排思想的深论见 [../从Lucene到Elasticsearch.md](../从Lucene到Elasticsearch.md)；
ES 专书（TDG）的目录版归属见 [../数据库系列·总索引.md](../数据库系列·总索引.md)。

## 4. 🔧 实测：rtree ——空间虚拟表

`CREATE VIRTUAL TABLE rt USING rtree(id, minx, maxx, miny, maxy)`；插入矩形 (0,1)×(0,1)；
查询 `WHERE maxx>0.5 AND minx<0.5` → `[(1,)]`（🔧 亲验，3.45.3 内置 ENABLE_RTREE，
见 02 章 compile_options）。
书中"用 rtree 加速范围查询"的老话如今有了官方升级口径：3.24 起 rtree 支持
辅助列（✅ changes.html 2018-06-04 条目原文 "auxiliary columns in r-tree tables"）。

## 5. 时间旅行：书末玩笑与今天的正经对应物

Kreibich 末章以 "Time Traveling" 收束想象力（虚拟表可以接任何东西——包括把
历史/日志/任意数据源伪装成表来 SQL）。2026 该隐喻的**工程实体化**有三条：

1. **session/changeset 扩展**：官方 SQLite 自带变更记录与回放（
   [changes.html](https://sqlite.org/changes.html) 多年出现 session 修复条目 ✅；
   专页 session.html 本会话未抓 ⚠️）——行级"时间机器"；
2. **SQL 侧时点查询**：社区 MVCC/审计模式（如 mvSQLite）让 `SELECT AS OF`
   式查询成立（⚠️ 三方项目未经本会话核验，只作方向引用）；
3. **文件级**：`VACUUM INTO`/`.backup` + 快照 = 粗粒度但零依赖的 PITR
   （与 08 章备份实验衔接；
   [../Database_Reliability_Engineering/07-数据作为生产资料与备份恢复.md](../Database_Reliability_Engineering/07-数据作为生产资料与备份恢复.md)
   的恢复演练视角）。

数仓侧对读：Inmon/Kimball 线的"时点快照/SCD"正是把"时间旅行"做进建模
（[../数据仓库工具箱3.md](../数据仓库工具箱3.md)）——**同一隐喻，引擎层、
会话层、建模层三种实现**，这是本章在全系列里最有意思的定位。

## 6. 本章带走三条

1. 扩展谱系已从"C 重载 DLL"扩散为"SQL 函数注册（任意语言）+ 内置虚拟表 + 生态桥"；
   先盘点 `pragma_module_list`，再决定要不要引第三方扩展（🔧 方法本会话可复现）。
2. FTS5 对 `LIKE '%kw%'` 的胜利不只是 15×（🔧），更是**词元语义**的胜利：
   子串命中 ≠ 词命中——搜索功能验收要先问语义。
3. "时间旅行"从书中笑谈变成三层正经工程：session 扩展（引擎）、审计建模（数仓）、
   快照 PITR（运维），SQLite 三层全有零成本入口。

## 核心概念速览（中英对照）

- **虚拟表** — virtual table：C 模块实现的表接口（xFilter/xNext/xBestIndex 回调）
- **同名虚拟表** — eponymous virtual table：免 CREATE 直接查询的模块（json_each 等）
- **扩展函数** — application-defined function：sqlite3_create_function 注册的标量/聚合/窗口函数
- **加载扩展** — loadable extension：运行期 dlopen 的 DLL/SO；默认禁用需显式开启
- **FTS5** — 全文检索模块：倒排索引 + MATCH + bm25 + snippet + porter 分词
- **外部内容表** — content='' / content=tbl：FTS5 只存索引不存原文（或映射他表）的模式
- **UNINDEXED 列** — 非索引列：FTS5 中存而不倒排
- **rtree** — R 树虚拟表：多维范围（地理 bbox）加速
- **辅助列** — auxiliary columns：rtree 3.24+ 附带载荷列
- **sqlite_dbpage** — 页直通虚表：以表形态读写原始页（pragma schema 隐藏表，不在
  module_list 中；DBRE 撕裂页实验的取证工具）
- **session 扩展** — changeset 录制/回放：行级变更时间机器
- **CHANGESET/SEDAT** — 变更集对象：session 的序列化产物（⚠️ 细节未实测）
- **词元匹配** — token match：FTS 按分词命中，区别于子串 LIKE 的本质语义
