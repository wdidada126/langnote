## 三条阅读路线

1. **语法基座线（第Ⅰ部分）**：`01` → `02` → `03`。
   实例化/特化是所有元机制的发动机；变参 + 折叠是 C++20 泛型 API 的通货。
2. **元编程引擎线（第Ⅱ部分，全书心脏）**：`04` → `05` → `06`。
   依赖名与推导（04）→ traits/SFINAE 探测（05）→ concepts 把探测升格为接口（06）。
   **05 vs 06 的对照阅读是本书的最大卖点**：同一个"检测能力"问题的两代解法与诊断学差异。
3. **应用收束线（第Ⅲ部分）**：`07` → `08` → `09`。
   模式（07）是前六章技法的组合拳；08/09 把"范围"作为泛型设计的验收场景——
   自定义容器/迭代器/算法，再到 std::ranges 视图适配器。

**最短路径（已有 C++11/14 模板功底）**：`03` 折叠 → `05` 的 constexpr if/SFINAE → `06` 全章 → `09`。
