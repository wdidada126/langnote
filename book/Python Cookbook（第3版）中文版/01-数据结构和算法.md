## 核心精讲
- 1.1 解包：`first, *middle, last = seq`（Python 3 即支持，`*` 解包）。
- 1.3 `collections.deque` 保留最后 N 元素：定长 `deque(maxlen=n)`，O(1) 追加/弹出。
- 1.5 优先级队列：`heapq.heappush`/`heappop`，用 `(priority, index, item)` 元组规避比较。
- 1.6 `defaultdict(list)` 实现一键多值。
- 1.12 `Counter` 的 `most_common(n)` 取众数。
- 1.14 `sorted(rows, key=lambda r: r['age'])`；对象排序用 `operator.attrgetter`。
- 1.18 `namedtuple`：轻量不可变记录（Python 3.6+ 用 `typing.NamedTuple` 可加类型）。

```python
# 教学示意，不参与构建
from collections import deque, defaultdict, Counter, namedtuple
from heapq import nlargest

last3 = deque(maxlen=3)
d = defaultdict(list)
c = Counter("abracadabra")
Point = namedtuple("Point", ["x", "y"])
```

## 版本演进
- **3.7 PEP 520**：字典保证插入顺序。`dict` 本身就是有序的，1.7「字典排序」、1.8「字典运算」结论需修正——普通 `dict` 已保序，不必再转 `OrderedDict`（🔧 原书基于 3.3，那时仍是 3.6 之前）。
- **3.9 PEP 584**：`dict | dict` 合并、`dict |= update`，取代 1.20 的 `ChainMap` 或 `{**a, **b}` 写法。
- **3.7 PEP 557**：`@dataclass` 取代手写 `__init__`/`__repr__` 的数据类（原书用 `namedtuple` 或手动初始化），`frozen=True` 可得不可变记录。
- **3.8 PEP 589**：`TypedDict` 给字典加类型提示（取代部分 `namedtuple` 场景）。
- **3.10 PEP 634**：`match` 解构可替代某些解包/分支（非必须）。

## 近年研究与工业界（2015–2026）
- 大厂基础库（attrs、pydantic）将 `dataclass` 思想产品化，配置/数据建模几乎不再手写 `__init__`。
- `orjson`/`msgspec` 等高性能序列化库提供 `dataclass`/`NamedTuple` 原生支持。
- 不可变数据（`NamedTuple`/`dataclass(frozen=True)`）在并发与函数式风格中回潮。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 原书「dict 无序」推论（1.7/1.8 隐含） | 3.7+ 字典已保序，直接依赖即可 |
| 用 `{**a, **b}` 合并字典（1.20） | 改用 `a | b`（PEP 584，3.9+） |
| 手写 `__init__`/`__repr__` 数据类 | 用 `@dataclass`（PEP 557，3.7+） |
| `OrderedDict` 当作「有序字典」默认选择 | 普通 `dict` 已保序，`OrderedDict` 仅需在相等性/重排语义特殊时 |
| `heapq` 优先级用裸对象比较 | 元组 `(priority, index, item)` 避免无次序对象比较报错 |
