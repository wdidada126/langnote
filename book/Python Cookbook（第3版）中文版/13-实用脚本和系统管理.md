# 13 章 实用脚本和系统管理（原书 pp.约 695–751）

## 本章地图
| 节 | 内容 | 结论 |
|---|---|---|
| 13.1–13.2 | 重定向/管道输入、终止报错 | `fileinput`/`sys.exit` |
| 13.3–13.5 | 命令行选项、密码提示、终端大小 | `argparse`/`getpass`/`shutil.get_terminal_size` |
| 13.6–13.10 | 执行外部命令、复制移动、归档、查找、读配置 | `subprocess`/`shutil`/`configparser` |

## 核心精讲
- 13.3 命令行解析用 `argparse`（🔧 比手写 `sys.argv` 强）；现代也可 `click`/`typer`（第三方）。
- 13.6 执行外部命令优先 `subprocess.run(['ls', '-l'], capture_output=True, text=True)`（🔧 禁 `shell=True` 拼字符串，防注入）。
- 13.7 `shutil.copy`/`shutil.move`/`shutil.rmtree`（🔧 `rmtree` 危险，谨慎）。
- 13.8 `shutil.make_archive`/`unpack_archive` 处理归档。
- 13.10 `configparser` 读 INI；🔧 配置优先 TOML（`tomllib`，3.11）。

```python
# 教学示意，不参与构建
import subprocess, argparse, shutil
r = subprocess.run(["ls", "-l"], capture_output=True, text=True)
p = argparse.ArgumentParser(); p.add_argument("src")
```

## 版本演进
- **3.5 PEP 0479 / `subprocess.run`**：现代统一入口（13.6 升级，替代 `call`/`Popen` 散用法）。
- **3.7 `pathlib`**：路径操作（13.7/13.9）用 `Path` 取代 `os` 拼接。
- **3.11 PEP 0680 `tomllib`**：读 TOML 配置（13.10 取代 INI 更安全）。
- **3.12**：`subprocess` 默认 `text=True` 更顺；`argparse` 稳定。
- 🔧 `os.system` 已不推荐，全用 `subprocess`。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| `os.system`/反引号执行命令 | 用 `subprocess.run`（禁 `shell=True` 拼串） |
| 手写 `sys.argv` 解析 | 用 `argparse` 或 `click`/`typer` |
| 配置用 INI/JSON | 3.11+ 用 TOML（`tomllib`） |
| `shutil.rmtree` 直接删 | 危险，确认路径与回收机制 |
| 日志用 `print` | 用 `logging` 分级/结构化 |
