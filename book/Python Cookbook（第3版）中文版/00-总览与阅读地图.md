## 阅读层级与 2026 状态
- 层级：核心（进阶工具书，非教材）
- 状态：🟡 思想极佳、配方仍可复用，但标准库 API 举例需按 3.12+ 自行修正；建议当「解法手册」按需检索，不必通读

## 概念专篇（concepts/）
- [装饰器与元类](concepts/装饰器与元类.md)：第 7、9 章的交叉专题，覆盖 PEP 318 / PEP 3115 / PEP 614 / PEP 695
- [描述符与 property 属性](concepts/描述符与property属性.md)：第 8 章 descriptor 协议、`@property`、延迟属性、类型约束

## 主线脉络
- 以「配方（recipe）= 问题 → 代码 → 原理」三段式组织，覆盖数据结构、文本、数值、迭代、I/O、编码、函数、类、元编程、模块、网络、并发、系统管理、测试、C 扩展。
- 价值在「惯用法」：装饰器、生成器管道、描述符、元类、context manager、线程/进程并发。

- 进阶主线第三位（在 Effective Python 之后当解法手册使用）。
