## 核心精讲
- 3.1 `round(value, ndigits)`；注意 banker's rounding（偶数舍入）。
- 3.2 精确运算用 `decimal.Decimal('0.1') + Decimal('0.2')`，设 `getcontext().prec`。
- 3.7 `float('inf')`/`float('nan')`，用 `math.isnan` 判 NaN（不可 `==`）。
- 3.15 `datetime.strptime(text, '%Y-%m-%d')` 解析；3.16 时区用 `zoneinfo`（见下）。

```python
# 教学示意，不参与构建
from decimal import Decimal, getcontext
getcontext().prec = 4
from datetime import datetime, date
d = datetime.strptime("2026-10-02", "%Y-%m-%d")
```

## 版本演进
- **3.9 PEP 615**：`zoneinfo` 内置时区数据库，取代 3.16 的 `pytz`（原书推荐）。`ZoneInfo("Asia/Shanghai")`。
- **3.11**：`datetime` 增强（`fromisocalendar` 等已 3.8 加入；3.11 总体性能提升）。
- **3.9+ `math`/`statistics`**：更多统计函数；大数运算仍推荐 `numpy`（3.9 配方）。
- `fractions`/`decimal` 行为稳定；`dateutil` 仍是 `pytz` 之外常用补充（🔧 已非必需，优先 `zoneinfo`）。

## 经典论文与原始文献
- `decimal` 模块遵循 IBM 通用十进制算术规范（IEEE 754-2008 十进制）。
- PEP 0615 IANA 时区支持（`zoneinfo`，3.9）。
- 🔧 具体编号/年份以 https://peps.python.org/ 为准；`datetime` 设计见标准库文档。

## 近年研究与工业界（2015–2026）
- 时间序列库（pandas/Arrow/pendulum）成为数据工程标配；Arrow 简化时区/解析。
- `pytz` 进入维护模式，官方建议迁移 `zoneinfo`。
- 金融/科学计算默认 `numpy` + `decimal`（高精度）双轨。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 时区用 `pytz` | 3.9+ 用 `zoneinfo.ZoneInfo`（PEP 615） |
| `float('nan') == float('nan')` 判等 | 用 `math.isnan` |
| 二进制/十进制浮点混算 | 精确场景用 `decimal.Decimal` |
| 大整数打包手写 | 用 `int.to_bytes`/`int.from_bytes`（3.2+） |
| `round` 行为 | 银行家舍入（round-half-to-even），非四舍五入 |
