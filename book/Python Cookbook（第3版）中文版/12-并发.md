# 12 章 并发（原书 pp.约 649–695）

## 本章地图
| 节 | 内容 | 结论 |
|---|---|---|
| 12.1–12.7 | 线程启停、已启动、通信、加锁、防死锁、状态、线程池 | `threading`/`queue`/`concurrent.futures` |
| 12.8–12.9 | 并行编程、GIL 问题 | `multiprocessing` |
| 12.10–12.12 | Actor、发布订阅、生成器代替线程 | 消息模型 |

## 核心精讲
- 12.1 启线程：`t = threading.Thread(target=f); t.start(); t.join()`。
- 12.3 线程通信用 `queue.Queue`（不要用共享可变状态 + 锁硬抗）。
- 12.4 `with threading.Lock(): ...` 上下文管理加锁。
- 12.7 线程池：`with ThreadPoolExecutor(max_workers=n) as ex: ex.map(f, items)`（🔧 比手写线程池省心）。
- 12.8 CPU 密集用 `multiprocessing`（绕过 GIL）；IO 密集用线程/`asyncio`。

```python
# 教学示意，不参与构建
from concurrent.futures import ThreadPoolExecutor
import threading
def work(x): return x * 2
with ThreadPoolExecutor(max_workers=4) as ex:
    results = list(ex.map(work, range(10)))
```

## 版本演进
- **3.2 `concurrent.futures`**：`ThreadPoolExecutor`/`ProcessPoolExecutor` 是 12.7/12.8 现代写法。
- **3.4 `asyncio`**（PEP 3156）：协程/事件循环，IO 并发替代线程（12.12 生成器思路升级为 `async/await`）。
- **3.7 `asyncio` 稳定**：`async/await` 语法；`run()`。
- **3.9 `asyncio.to_thread`**：在线程跑同步函数（桥接线程与协程）。
- **3.11 `TaskGroup`**（PEP 654 异常组）：结构化并发，取代裸 `gather` 易漏错。
- **3.12 PEP 703（实验）**：free-threading（`--disable-gil` 构建），缓解 12.9 GIL 限制（🔧 实验性）。
- **3.13**：free-threading 仍实验；`asyncio` 持续增强。

## 经典论文与原始文献
- PEP 0315 `asyncio`（3.4 引入，3.7 稳定）；PEP 0654 异常组（3.11）。
- `threading`/`multiprocessing`/`queue`/`concurrent.futures` 标准库设计。
- PEP 0703 无 GIL 解释器（3.12+ 实验）。
- 🔧 具体编号/年份以 https://peps.python.org/ 为准。

## 近年研究与工业界（2015–2026）
- `asyncio`/`anyio` 成高并发 IO 标准；FastAPI 全异步。
- 结构化并发（`TaskGroup`/`trio`）兴起。
- free-threading（3.12+）探索 CPU 并行新路径，生态尚未全就绪。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 手写线程池 | 用 `concurrent.futures.ThreadPoolExecutor` |
| 多线程跑 CPU 密集 | 用 `multiprocessing` 或 3.12+ free-threading（实验） |
| 共享状态加锁硬抗 | 用 `queue.Queue` 通信 |
| 协程用 `yield from` 旧式 | 3.5+ `async/await` |
| `gather` 不处理异常 | 3.11+ `TaskGroup` 结构化并发 |
