## 核心精讲
- 4.3 `def frange(start, stop, step): while start < stop: yield start; start += step`。
- 4.4 迭代器协议：`__iter__` 返回 `self`，`__next__` 抛 `StopIteration`。
- 4.13 数据处理管道：`for item in (gen_a(gen_b(source))): ...`，惰性、省内存。
- 4.14 展开嵌套：`yield from` 递归展平（🔧 注意深度与安全）。
- 4.16 `for chunk in iter(lambda: f.read(8192), b''): ...` 代替 while 读块。

## 版本演进
- **3.3 PEP 0380**：`yield from` 已可用（原书 4.14 依赖它），但 3.3 即支持，本版无需改。
- **3.8 PEP 0572**：海象运算符 `:=` 在 4.16 这类「边算边判断」场景更紧凑。
- **3.10 PEP 618**：`zip(a, b, strict=True)` 防长度不匹配（数据管道对齐更安全）。
- **3.7 `math`/`itertools`**：`itertools` 稳定；无大改。
- 🔧 「数据管道」可结合 `asyncio` 做异步流（第 12 章）。

## 经典论文与原始文献

- PEP 0234 迭代器协议；`itertools` 设计（R. Hettinger）。
- PEP 0618 `zip(strict=)`（3.10）。
- 🔧 具体编号/年份以 https://peps.python.org/ 为准。

## 近年研究与工业界（2015–2026）
- 惰性管道在日志/ETL（如 `more-itertools`）中被广泛封装。
- `async generators`（3.6 PEP 0525）让 4.13 管道可异步化。
- 函数式风格（`toolz`/`itertools`）在数据处理回潮。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| `zip` 默认静默截断 | 3.10+ 用 `zip(..., strict=True)` |
| 用 while 读块 | 用 `iter(partial(f.read, n), b'')` 惰性迭代 |
| 手写排列组合 | 用 `itertools.permutations/combinations` |
| 生成器内复杂状态 | 用 `yield` + 实例属性，或 `itertools.tee`（🔧 注意内存） |
