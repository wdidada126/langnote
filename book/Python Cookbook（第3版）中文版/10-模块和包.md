# 10 章 模块和包（原书 pp.约 563–605）

## 本章地图
| 节 | 内容 | 结论 |
|---|---|---|
| 10.1–10.4 | 层级包、控制导入内容、相对导入、分割模块 | `__all__`、`from . import` |
| 10.5–10.8 | 命名空间包、重载、运行目录/压缩、读数据文件 | `importlib`/`pkgutil` |
| 10.9–10.12 | 加入 sys.path、字符串名导入、钩子远程加载、导入同时改 | `importlib.import_module` |
| 10.13–10.15 | 私有包、新环境、分发包 | `venv`/`pip`/`pyproject.toml` |

## 核心精讲
- 10.2 `__all__ = ['a', 'b']` 控制 `from pkg import *`。
- 10.3 相对导入：`from .sub import x`（包内用，脚本直接跑会 `ImportError`）。
- 10.6 `importlib.reload(mod)`（🔧 仅调试，慎用）。
- 10.10 `mod = importlib.import_module('pkg.mod')` 按字符串导入。
- 10.15 现代打包用 `pyproject.toml`（PEP 518/517），取代 `setup.py`。

```python
# 教学示意，不参与构建
import importlib
mod = importlib.import_module("collections")
from pathlib import Path
data = (Path(__file__).parent / "data.txt").read_text()
```

## 版本演进
- **3.3 PEP 0420**：隐式命名空间包（10.5），无需 `__init__.py` 也能跨目录聚包。
- **3.4 PEP 0451**：`importlib` 导入系统钩子更完整（10.11 远程加载）。
- **3.7 PEP 0621 / 517/518**：`pyproject.toml` 成标准打包配置（10.15 升级）。
- **3.11 PEP 0680**：`tomllib` 读配置（包元数据常放 TOML）。
- **3.12**：导入系统性能提升；`venv` 仍是建环境首选。
- 🔧 `setup.py` 已弃用，改用 `pyproject.toml` + `build`/`pip`。

## 近年研究与工业界（2015–2026）
- `pyproject.toml` 全面取代 `setup.py`/`setup.cfg`（打包事实标准）。
- `importlib.metadata` 读取已安装包版本（取代 `pkg_resources`）。
- 命名空间包在大型单体/插件架构常用。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 用 `setup.py` 打包 | 改用 `pyproject.toml`（PEP 517/518） |
| 包必带 `__init__.py` | 3.3+ 命名空间包可无 `__init__` |
| 直接执行含相对导入的包模块 | 用 `-m` 运行（`python -m pkg.mod`） |
| `reload` 当热更新 | 仅调试，生产用进程重载/导入器 |
| `pkg_resources` 读元数据 | 3.8+ 用 `importlib.metadata` |
