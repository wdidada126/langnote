## 核心精讲
- 8.3 上下文管理：`class CM: def __enter__(self): ...; def __exit__(self, *e): ...`（或用 `@contextmanager`）。
- 8.4 `__slots__ = ('x', 'y')` 省内存但禁用动态属性。
- 8.6 `@property` 把方法变只读属性；`@x.setter` 控制写。
- 8.7 `super()` 调父类（3.x 无参即可）。
- 8.12 `class Shape(abc.ABC): @abstractmethod def area(self): ...`。
- 8.25 缓存实例：`_cache = {}; cls._cache[key] = obj`（或用 `functools.cache`）。

```python
# 教学示意，不参与构建
import abc
class Vec:
    __slots__ = ("x", "y")
    def __init__(self, x, y): self.x, self.y = x, y
class Shape(abc.ABC):
    @abc.abstractmethod
    def area(self): ...
```

## 版本演进
- **3.7 PEP 557**：`@dataclass` 取代 8.11 手写初始化、`__repr__`（自动生成）。
- **3.8 PEP 545/`cached_property`**：`functools.cached_property` 进标准库（8.10 延迟属性更简）。
- **3.9 PEP 591**：`@final` 标记不可覆盖（设计约束）。
- **3.10 PEP 604**：`X | Y` 类型联合；`@dataclass(slots=True)`（3.10）替代部分 `__slots__`。
- **3.12 PEP 695**：类级类型参数 `class C[T]: ...`。
- 🔧 `dataclass` 已成数据模型首选，原书多处手写可重写成 `@dataclass`。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 手写 `__init__`/`__repr__` | 3.7+ `@dataclass` 自动生成 |
| 用 `__dict__` 省内存技巧 | `@dataclass(slots=True)`（3.10）更干净 |
| 手写延迟属性 | 3.8+ `functools.cached_property` |
| 抽象基类手写元类 | 用 `abc.ABC` + `@abstractmethod` |
| 名称改写当「私有」 | Python 无真正私有，`_name` 约定即可 |
