## 核心精讲
- 6.2 `json.dumps(obj, ensure_ascii=False, indent=2)`（非 ASCII 保留原样）。
- 6.3 `import xml.etree.ElementTree as ET; tree = ET.parse('x.xml')`。
- 6.5 字典转 XML：递归构建 `ET.Element`，或 `xmltodict`（🔧 第三方）。
- 6.12 `struct.unpack('<i', data)` 解析二进制；可变长用循环 + `struct.calcsize`。
- 6.8 `sqlite3` 内置于标准库，轻量持久化首选。

```python
# 教学示意，不参与构建
import json, csv, struct
s = json.dumps({"a": 1}, ensure_ascii=False)
i = struct.unpack("<i", b"\x01\x00\x00\x00")[0]
```

## 版本演进
- **3.7 PEP 0563 / typing**：`TypedDict` 给 JSON 结构加类型（3.8）。
- **3.11**：`sqlite3` 默认 `autocommit` 行为调整、`cli` 增强；`tomllib` 内置（PEP 0680）解析 TOML —— 配置场景优于部分 JSON/INI。
- **3.9**：` zoneinfo` 等；`xml` 解析注意实体炸弹（🔧 安全）。
- 数据类（PEP 557，3.7）常作 CSV/JSON 行模型。
- 🔧 `xml.etree` 默认不防「实体扩展」攻击，外部输入用 `defusedxml`。

## 经典论文与原始文献
- RFC 8259 JSON；RFC 4180 CSV；`ElementTree` 设计（F. Lundh）。
- PEP 0680 `tomllib`（3.11）；PEP 0557 `dataclasses`（3.7）。
- 🔧 具体编号/年份以 https://peps.python.org/ 为准。

## 近年研究与工业界（2015–2026）
- `orjson`/`msgspec` 高性能 JSON（含 `dataclass` 支持）。
- `pydantic` 用 `TypedDict`/模型做 JSON 校验，Web 框架标配。
- 列式/大数据：Parquet、Arrow 取代 CSV 做分析存储。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| `json.dumps` 默认 `ensure_ascii=True` | 中文需 `ensure_ascii=False` |
| `xml.etree` 解析外部 XML | 用 `defusedxml` 防实体炸弹 |
| 配置用 JSON/INI | 3.11+ 用 `tomllib` 读 TOML |
| 手写二进制解析 | 用 `struct` + `dataclasses` 建模 |
| 关系库必装 MySQL | 轻量用内置 `sqlite3` |
