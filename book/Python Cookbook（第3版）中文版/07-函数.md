# 07 章 函数（原书 pp.约 363–425）

## 本章地图
| 节 | 内容 | 结论 |
|---|---|---|
| 7.1–7.5 | 任意参数、`*` 仅关键字、参数元信息、多返回值、默认参数 | `*args`/`**kwargs`/`*` 分隔 |
| 7.6–7.7 | 匿名函数、闭包捕获 | `lambda`、`x=x` 默认绑定 |
| 7.8–7.11 | 减少参数、单方法类转函数、带状态回调、内联回调 | `partial`、`functools` |
| 7.12 | 访问闭包变量 | `nonlocal` |

## 核心精讲
- 7.1 `def f(a, *args, **kwargs)`；7.2 `def f(a, *, b)` 强制关键字参数。
- 7.5 默认参数只求值一次（陷阱）：可变默认用 `None` + 函数内初始化。
- 7.7 `lambda` 捕获循环变量要用默认参数 `lambda x, i=i: ...`（否则全捕获末值）。
- 7.8 `functools.partial(sorted, key=...)` 减少参数。
- 7.12 改闭包变量用 `nonlocal x`。

```python
# 教学示意，不参与构建
from functools import partial
add = lambda x, y=0: x + y
greeters = [lambda x, i=i: f"hi {x}{i}" for i in range(3)]
```

## 版本演进
- **3.8 PEP 0570**：仅位置参数 `/`：`def f(a, /, b, *, c)`。
- **3.10 PEP 612**：`ParamSpec`/`Concatenate` 给高阶函数保留签名类型。
- **3.12 PEP 695**：`type T = ...` 类型别名、泛型 `def f[T]`（可在 def 头部声明独立类型形参，注解更清晰）。
- **3.11 PEP 0646**：`TypeVarTuple` 可变长泛型（高级）。
- `functools.cache`（3.9，取代 `lru_cache(maxsize=None)`）记忆化。

## 经典论文与原始文献
- PEP 3102 关键字仅参数（`*`）；PEP 0570 位置仅参数（`/`）。
- PEP 0612 `ParamSpec`；PEP 0695 类型参数语法（3.12）。
- `functools` 设计（R. Hettinger 等）。
- 🔧 具体编号/年份以 https://peps.python.org/ 为准。

## 近年研究与工业界（2015–2026）
- 类型化函数（`ParamSpec`/`TypeVarTuple`）让 `functools` 包装器类型安全。
- `functools.cache` 成默认记忆化；`cached_property`（3.8）进标准库。
- 函数式风格（`toolz`/`funcy`）用 `partial`/`compose` 组合。

## 常见误区与本书需修正之处
| 误区 | 修正 |
|---|---|
| 可变默认参数 `def f(x=[])` | 用 `x=None` 体内初始化，否则共享状态 |
| `lambda` 循环捕获 | 用默认参数 `i=i` 绑定 |
| 记忆化用 `lru_cache(maxsize=None)` | 3.9+ 用 `functools.cache` |
| 高阶函数丢类型 | 3.10+ `ParamSpec` 保留签名 |
| 位置/关键字混用 | 3.8 `/` 与 3.0 `*` 明确分隔 |
