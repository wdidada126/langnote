## 核心精讲

> 以下均为**教学示意，不参与构建**：本目录不搭建工程，片段可直接 `python x.py` 运行以验证结论。

### 1. 整除与浮点：Python 3 最容易踩的第一个坑

```python
# demo_ch1_numbers.py —— 教学示意，不参与构建
print(1 / 2)        # 0.5   真除法，结果永远是 float
print(1 // 2)       # 0     地板除（向下取整）
print(-1 // 2)      # -1    注意：地板除向负无穷取整，不是「截断」
print(1 % 2, -1 % 2)  # 1 1  取模结果与除数同号
print(2 ** 10)      # 1024  幂运算
print(0.1 + 0.2)    # 0.30000000000000004 —— 二进制浮点误差
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))  # 0.3 —— 十进制精确运算
```

- 原书用 `//` 强调「Python 2 的 `/` 行为变了」，2026 年只需记住：**要整除就写 `//`**。
- 浮点误差不是 bug，是 IEEE 754 的必然；涉及金额用 `decimal`，不要先转 `float`。

### 2. 变量是标签，不是盒子

```python
# demo_ch1_names.py —— 教学示意，不参与构建
a = [1, 2, 3]
b = a          # b 与 a 指向同一个列表对象，没有拷贝
b.append(4)
print(a)       # [1, 2, 3, 4] —— a 也被改了
print(a is b)  # True
c = a[:]       # 浅拷贝：新建一个列表
print(a is c)  # False
```

这一条贯穿全书：第 6 章「能修改参数吗」、第 2 章 `list * n` 的共享引用、第 4 章 `dict.copy` 都是同一件事的不同面。

### 3. 模块、复数与「回到未来」

```python
# demo_ch1_modules.py —— 教学示意，不参与构建
import math, cmath
from math import sqrt as square_root

print(square_root(9))               # 3.0
print(math.floor(3.7), math.ceil(3.2))  # 3 4
print(square_root(-1))             # ValueError: math domain error
print(cmath.sqrt(-1))              # 1j —— 复数域不报错
print((1 + 2j) * (3 - 4j))         # (11+2j)
```

原书 1.8 的「回到未来」指 `from __future__ import division`（Python 2 时代的兼容开关）。
**在 3.12+ 里这个导入已无意义**，所有 Python 3 默认就是真除法；保留它是纯历史包袱。

### 4. 一个可执行的完整脚本（含 shebang）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-   # 3.x 源文件默认 UTF-8，此行仅为兼容旧工具链
# hello.py —— 教学示意，不参与构建
"""读取姓名并打招呼，演示 input / 函数 / 注释 / 脚本入口。"""

def greet(name: str, excited: bool = False) -> str:
    """返回一句问候语；excited 为真时加感叹号。"""
    msg = f"Hello, {name}"          # 3.6+ f-string，见第 3 章
    return msg + "!" if excited else msg + "."


def main() -> None:
    name = input("What is your name? ").strip()
    print(greet(name, excited=True))
    print(f"repr 形式：{name!r}")   # repr 用于「面向程序员」的表示


if __name__ == "__main__":          # 只在直接运行本文件时执行
    main()
```

```bash
python hello.py            # 跨平台通用
chmod +x hello.py && ./hello.py   # Unix：shebang + 可执行位
```

### 5. 字符串、字节与编解码

```python
# demo_ch1_strings.py —— 教学示意，不参与构建
s = "Let's go!"            # 双引号包单引号，省掉转义
t = 'She said "hi".'       # 反之亦然
path = r"C:\new\table"     # 原始字符串：反斜杠不转义
long_text = """第一行
第二行"""                   # 三引号保留换行
print(str("hi"), repr("hi"))        # hi  'hi'   —— repr 带引号，面向调试
print(len("你好"), len("你好".encode("utf-8")))  # 2 6 —— 字符数 != 字节数

b = b"hello"               # bytes：不可变字节序列
print(b[0])                # 104（整数，不是 b'h'）
print("你好".encode("utf-8").decode("utf-8"))    # 你好
```

- `str` → `bytes` 用 `.encode(encoding)`；`bytes` → `str` 用 `.decode(encoding)`。
- 原书用 `1/2` 与 `str/repr` 的小例子反复对比，核心差异一句话：**`str` 给人看，`repr` 给机器看（且尽量可 `eval` 还原）**。

## 近年研究与工业界开源实践（2015–2026）

- **REPL 生态**：`ipython/ipython` 与 `prompt-toolkit` 的补全/高亮能力被 CPython 3.13 的 `_pyrepl` 吸收进标准 REPL；`ptpython`、`bpython` 仍是重度 REPL 用户的选项（均为活跃开源项目，非同行评审论文）。
- **终端交互库**：`Textualize/rich` 与 `Textualize/textual` 把 `repr`/着色/表格带进终端，本质上是「`repr` 面向人类」这条思路的工业化。
- **数值精度**：`numpy`、`pandas` 在工程上仍以 IEEE 754 float64 为主；金融与计费场景普遍改用 `decimal` 或整数分单位存储——这是原书未强调、但每个业务系统都会撞上的实践共识。
- **脚本分发**：`python -m zipapp`、`pipx`、`uv` 让「单个 `.py` 脚本」也能带上依赖分发，补上了原书 1.9 缺失的一环（原书只讲 shebang + chmod）。
- **教学研究侧**：入门教学研究长期讨论「变量是盒子还是标签」的隐喻（boxes vs labels），Python 社区的教学材料普遍采用标签/引用隐喻，与本章 1.4 的口径一致。🔧 具体实证研究本目录不引用，避免编造文献。

## 常见误区与本书需修正之处

| # | 原书说法 / 常见误解 | 问题 | 2026 正确写法 |
| --- | --- | --- | --- |
| 1 | 「`1/2` 得到 0」（沿用 Python 2 记忆） | Python 3 已改 | `1/2 == 0.5`；整除写 `1//2`；负数地板除向 −∞ |
| 2 | 🔧 原书 1.8 演示 `from __future__ import division` | Python 3 下无意义，且易误导初学者以为必须写 | 直接删掉；`__future__` 只在跨 2/3 或启用特定编译器特性时使用 |
| 3 | 「`input()` 返回数字」 | 永远返回 `str` | `int(input())` / `float(input())`，并用 `try/except` 兜住（见第 8 章） |
| 4 | 「`math.sqrt(-1)` 报错就是不支持复数」 | 只是 `math` 不支持 | 用 `cmath.sqrt(-1)` → `1j`，或直接写 `(-1) ** 0.5` |
| 5 | 「`round(2.5) == 3`」 | Python 3 用**银行家舍入**（四舍六入五取偶） | `round(2.5) == 2`、`round(1.5) == 2`；要传统四舍五入用 `decimal` |
| 6 | 「变量有类型」 | 类型属于对象 | `a = 1; a = "x"` 合法；`type(a)` 看的是对象 |
| 7 | 「`print` 是语句」 | Python 2 遗留 | 3.x 是函数：`print(a, b, sep=", ", end="")` |
| 8 | 🔧「shebang 写 `#!/usr/bin/env python`」 | 系统 `python` 可能指向 Python 2 或不存在 | 一律写 `#!/usr/bin/env python3` |
| 9 | 「`str` 和 `bytes` 差不多」 | 混用会在 3.x 抛 `TypeError` | 边界处显式 `encode()/decode()`；读写文件时用 `open(..., "rb")` 或指定 `encoding=` |
| 10 | 脚本直接写顶层代码 | 被 `import` 时会执行副作用 | 用 `if __name__ == "__main__":` 包住入口（原书 1.9 未强调） |
