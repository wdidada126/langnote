## 核心精讲

> 教学示意，不参与构建：以下片段全部跑在 `127.0.0.1` 的随机端口上，不联网、不留残余监听。

### 1. `socket`：两个套接字的故事

服务端有两类套接字：**监听套接字**（`bind` + `listen`）与**已连接套接字**（`accept` 返回）。数据收发只在后者上进行。

```python
import socket, threading

HOST, PORT = "127.0.0.1", 0            # 端口 0 = 让内核分配空闲端口


def serve(listener: socket.socket) -> None:
    conn, addr = listener.accept()
    with conn:
        data = conn.recv(1024)
        conn.sendall(b"echo:" + data)


listener = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
listener.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
listener.bind((HOST, PORT))
listener.listen(1)
host, port = listener.getsockname()

threading.Thread(target=serve, args=(listener,), daemon=True).start()
with socket.create_connection((host, port)) as client:
    client.sendall(b"ping")
    print("收到:", client.recv(1024))
listener.close()
```

类型提示下的 socket 编程关注三件事：`socket.socket | None`（`accept` 可能超时）、`bytes` 与 `str` 的分界（线上只有字节）、以及 `sendall` 与 `send` 的区别（`send` 可能只发一部分）。

### 2. `urllib`：`urllib2` 已经不在了

```python
from urllib import parse, request

url = "https://example.com/search?q=python&page=2"
parts = parse.urlparse(url)
print(parts.netloc, parse.parse_qs(parts.query))

req = request.Request(url, headers={"User-Agent": "langnote-demo"})
print(req.full_url, "|", req.get_header("User-agent"))
# 真正发起请求（需联网）：with request.urlopen(req, timeout=5) as r: print(r.status, r.read(100))
```

Python 2 的 `urllib2` 在 Python 3 已拆分并入 `urllib.request` / `urllib.response` / `urllib.error` / `urllib.parse`。**业务代码里更常用的是 `httpx`（同步 + 异步同 API）或 `requests`**：`pip install httpx`。

### 3. `socketserver`：把样板收进框架

```python
import socket, socketserver, threading


class EchoHandler(socketserver.StreamRequestHandler):
    def handle(self) -> None:                 # 每个连接跑一次
        data = self.rfile.readline()
        self.wfile.write(b"echo:" + data)


with socketserver.ThreadingTCPServer(("127.0.0.1", 0), EchoHandler) as server:
    host, port = server.server_address
    threading.Thread(target=server.serve_forever, daemon=True).start()
    with socket.create_connection((host, port)) as client:
        client.sendall(b"hi\n")
        print("收到:", client.recv(1024))
    server.shutdown()                          # 停止 serve_forever 循环
```

`ForkingTCPServer`（进程）只在 POSIX 上可用，Windows 用 `ThreadingTCPServer`；`daemon_threads = True` 可让主线程退出时不卡住。这类「一连接一线程」模型的上限在几千连接量级，更高并发要换异步。

### 4. `select`/`poll` → `selectors`

```python
import selectors, socket

sel = selectors.DefaultSelector()             # 自动选 epoll/kqueue/IOCP
a, b = socket.socketpair()
a.setblocking(False)
sel.register(a, selectors.EVENT_READ)
b.sendall(b"ping")
for key, mask in sel.select(timeout=1):       # 等待就绪
    print("可读:", key.fileobj.recv(1024))
sel.close(); a.close(); b.close()
```

`selectors` 是对 `select`/`poll`/`epoll`/`kqueue`/IOCP 的统一封装——**写新代码不要直接用 `select.select()`**。再往上就是事件循环（`asyncio`）帮你做注册、分派与超时。

### 5. `asyncio`：今天的默认答案

```python
import asyncio


async def handle(reader: asyncio.StreamReader, writer: asyncio.StreamWriter) -> None:
    data = await reader.read(100)
    writer.write(b"echo:" + data)
    await writer.drain()
    writer.close()


async def main() -> None:
    server = await asyncio.start_server(handle, "127.0.0.1", 0)
    port = server.sockets[0].getsockname()[1]
    reader, writer = await asyncio.open_connection("127.0.0.1", port)
    writer.write(b"ping")
    await writer.drain()
    print("收到:", await reader.read(100))
    writer.close()
    server.close()
    await server.wait_closed()


asyncio.run(main())
```

一个 `await` 挂起点 = 一次让出事件循环；**不要在协程里调用阻塞式的 `socket.recv` / `time.sleep`**，否则整个循环停摆（CPU 密集或无法异步的库用 `asyncio.to_thread`）。

### 6. Twisted：历史对照

> 教学示意，不参与构建：需先 `pip install twisted`，本节代码仅做语法校验。

```python
from twisted.internet import protocol, reactor


class Echo(protocol.Protocol):
    def dataReceived(self, data: bytes) -> None:
        self.transport.write(b"echo:" + data)


class EchoFactory(protocol.Factory):
    def buildProtocol(self, addr):
        return Echo()


if __name__ == "__main__":
    reactor.listenTCP(8000, EchoFactory())
    reactor.run()
```

Twisted 的贡献是把「反应器（reactor）」「协议（Protocol）」「延迟对象（Deferred）」这套词汇带进 Python 社区，`asyncio` 的设计明显受其影响；但它的回调风格、自己的协议栈与非 `async/await` 语法，在 3.5 之后被原生协程全面取代——**新项目不要再引入 Twisted**。

## 近年研究与工业界开源实践（2015–2026）

- **`asyncio` 生态分层**：底层事件循环（`asyncio`、`uvloop`）、中间层框架（`anyio`、`trio`，提供结构化并发与更好的取消语义）、上层应用（`aiohttp`、`httpx`、`FastAPI`/Starlette）。新代码建议建立在**中间层**之上。
- **`uvloop`**：用 libuv 替换默认事件循环，连接密集场景吞吐显著提升；代价是平台绑定与调试复杂度（工具文档，非同行评审）。
- **同步 API 的现代化**：`httpx` 同时提供同步与异步两套 API，解决了「同步库与异步库二选一」的历史痛点；`requests` 仍是最广泛使用的同步客户端。
- **C10K → C10M 的工程化**：生产部署通常把 Python 放在 ASGI 服务器（Uvicorn/Hypercorn/Gunicorn worker）与反向代理之后，Python 侧只处理业务逻辑，连接管理交给事件循环与内核。
- **可观测性与超时**：异步程序最典型的故障是「一个请求卡住整个循环」与「取消传播不完整」；`asyncio.timeout`、`TaskGroup`、`tryio` 的结构化并发是学界与工业界共同的应对方向。
- 以上均为**工业界实践或工具文档，非同行评审论文**。

## 常见误区与本书需修正之处

| # | 原书说法 / 常见误区 | 问题 | 2026 正确写法 |
| --- | --- | --- | --- |
| 1 | 🔧 `import urllib2` | Python 3 已无此模块 | `urllib.request` / `urllib.error` / `urllib.parse`；业务代码用 `httpx` |
| 2 | 🔧 `import SocketServer` | Python 3 模块名为全小写 `socketserver` | `import socketserver`，处理器继承 `StreamRequestHandler` |
| 3 | 🔧 用 Twisted 写新服务器 | 回调风格、`Deferred` 与 `async/await` 生态不兼容 | `asyncio` + `async/await`（PEP 3156 / PEP 492）；Twisted 仅作历史对照 |
| 4 | 🔧 直接用 `select.select()` / `poll()` | 平台差异大、需手工维护 fd 表 | `selectors.DefaultSelector()`，或直接上 `asyncio` |
| 5 | 在协程里调 `socket.recv` / `time.sleep` | 阻塞整个事件循环 | `await reader.read()` / `await asyncio.sleep()`；无法异步的用 `asyncio.to_thread` |
| 6 | 「异步一定更快」 | CPU 密集与低并发场景反而更慢、更复杂 | 先量测；I/O 密集才上异步 |
| 7 | 忽略 `SO_REUSEADDR` | 重启服务报「地址已占用」 | `setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)`（框架通常已做） |
| 8 | `send()` 一次发完 | 可能只发一部分 | `sendall()`，或循环处理返回值 |
| 9 | 以为 `recv(1024)` 就是「一条消息」 | TCP 是字节流，会粘包/拆包 | 自定义长度前缀或分隔符做**分帧** |
| 10 | 明文传输 | 抓包即可读 | TLS：`ssl` 模块 / `httpx(verify=True)` / 反向代理终结 |
| 11 | 无超时 | 一个慢连接耗尽资源 | 处处设 timeout：`socket.settimeout`、`asyncio.timeout` |
| 12 | 🔧 沿用 `asyncore`/`asynchat`（第 24 章） | 3.12 起已从标准库移除（PEP 594） | `asyncio` 重写；`telnetlib`（3.13 移除）改用 `paramiko`/`asyncssh` |
