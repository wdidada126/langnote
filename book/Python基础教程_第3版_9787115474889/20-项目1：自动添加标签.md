# 第 20 章 项目1：自动添加标签（原书 pp.315–331）

> 一句话定位：本章把「纯文本 → HTML」做成一套**可插拔的四件套架构**（处理程序 / 规则 / 过滤器 / 解析器）——代码不难，难的是让「新增一种语法」的成本降到「只加一个类」。基线：原书 Python 3.5；本目录按 3.12+ 校验。
> 对应英文章名：**Project 1: Instant Markup**。

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 20.1 问题描述 | 给纯文本自动加 HTML 标签：标题、段落、列表、强调、链接、邮件 | 输入是「人写的文本」，输出是「机器要的 HTML」 |
| 20.2 有用的工具 | `re`（过滤器）、生成器（切块）、`getattr`（分派） | 三件小工具撑起整套架构 |
| 20.3 准备工作 | `util.py`：`lines()` 末尾补空行、`blocks()` 按空行切块 | **先有块，才有规则** |
| 20.4 初次实现：找出文本块 | 用正则或空行把文本切成块 | 切块是「流式处理」的最小形态 |
| 20.4 添加一些标记 | `re.sub` 就地替换 `*x*` → `<em>x</em>` | 能用，但**判定与标签混在一起** |
| 20.5 处理程序 + 超类 | `Handler.callback(prefix, name)` 用 `getattr` 分派 | 新增标签 = 新增一个 `start_x/end_x` 方法 |
| 20.5 规则 + 规则的超类 | `Rule.condition()` 判定、`action()` 执行；返回 True 表示停止 | 规则链 = 责任链模式 |
| 20.5 过滤器 | `add_filter(pattern, name)` → `re.sub(pattern, handler.sub(name))` | 行内标记与块级规则解耦 |
| 20.5 解析器 / 整合 | `Parser.parse()`：先过滤，再按规则链处理每个块 | 完整可运行，见下文 |
| 20.6 进一步探索 | 支持表格、图片、嵌套列表；换成 Markdown / PDF 输出 | 换一个 Handler 即可换输出格式 |

## 核心精讲

> 以下均为**教学示意，不参与构建**；代码已在 Python 3.13 实机运行验证。

### 1. 四件套架构

| 角色 | 回答的问题 | 需求变化时改哪里 |
| --- | --- | --- |
| Handler | 「输出长什么样」 | 换 HTML → Markdown：只写一个新 Handler |
| Rule | 「这个块是什么」 | 加一种块类型：只加一个 Rule 类 |
| Filter | 「块内的行内标记」 | 加一种行内语法：只加一行 `add_filter` |
| Parser | 「按什么顺序跑」 | 几乎不改 |

编排顺序是**先行内过滤、后块级判定**：`Parser.parse()` 对每个块先跑完 `filters`，再沿 `rules` 走责任链。
本章真正的教学价值正在于此——把「新增需求」的成本从「改一遍代码」降到「加一个类」。

### 2. 初次实现（原书 20.4）：切块 + 正则替换

```python
# simple_markup.py —— 教学示意，不参与构建
import re

TEXT = """Welcome to *Instant Markup*

A paragraph with *emphasis* and a link http://example.com

A Heading
"""


def add_markup(text):
    out, first = [], True
    for block in re.split(r"\n{2,}", text.strip()):
        block = block.strip()
        em = re.sub(r"\*(.+?)\*", r"<em>\1</em>", block)
        em = re.sub(r"(https?://[\.a-zA-Z/]+)", r'<a href="\1">\1</a>', em)
        if "\n" not in block and len(block) <= 70 and not block.endswith(":"):
            out.append(f"<{'h1' if first else 'h2'}>{em}</{'h1' if first else 'h2'}>")
            first = False
        else:
            out.append(f"<p>{em}</p>")
    return "\n".join(out)


print(add_markup(TEXT))
```

能跑、结果也对，但三个问题：① 判定条件（`len <= 70`）散落在分支里；
② 输出标签硬编码，换输出格式要重写整个函数；③ 加一种语法要动 `if/elif` 链。**这正是再次实现要解决的。**

### 3. 再次实现：完整可运行代码（原书 20.5）

```python
# instant_markup.py —— 教学示意，不参与构建（已在 Python 3.13 验证）
import io
import re

# ---------- util：按空行把文本切成块 ----------
def lines(file):
    yield from file
    yield "\n"                    # 末尾补空行，保证最后一块也被输出

def blocks(file):
    block = []
    for line in lines(file):
        if line.strip():
            block.append(line)
        elif block:
            yield "".join(block).strip()
            block = []

# ---------- handlers：超类 + HTML 渲染器 ----------
class Handler:
    """按约定拼方法名并调用；方法不存在则跳过（约定优于配置）。"""
    def callback(self, prefix, name, *args):
        method = getattr(self, prefix + name, None)
        return method(*args) if callable(method) else None
    def start(self, name): return self.callback("start_", name)
    def end(self, name): return self.callback("end_", name)
    def sub(self, name):
        def substitution(match):
            result = self.callback("sub_", name, match)
            return match.group(0) if result is None else result
        return substitution

class HTMLRenderer(Handler):
    def start_document(self): print("<html><head><title>Document</title></head><body>")
    def end_document(self): print("</body></html>")
    def start_title(self): print("<h1>")
    def end_title(self): print("</h1>")
    def start_heading(self): print("<h2>")
    def end_heading(self): print("</h2>")
    def start_paragraph(self): print("<p>")
    def end_paragraph(self): print("</p>")
    def start_list(self): print("<ul>")
    def end_list(self): print("</ul>")
    def start_listitem(self): print("<li>")
    def end_listitem(self): print("</li>")
    def feed(self, name, text): print(text, end="")
    def sub_emphasis(self, m): return f"<em>{m.group(1)}</em>"
    def sub_url(self, m): return f'<a href="{m.group(1)}">{m.group(1)}</a>'
    def sub_mail(self, m): return f'<a href="mailto:{m.group(1)}">{m.group(1)}</a>'

# ---------- rules：条件 + 动作 ----------
class Rule:
    type = "paragraph"
    def condition(self, block): raise NotImplementedError
    def action(self, block, handler):
        handler.start(self.type); handler.feed(self.type, block); handler.end(self.type)
        return True               # True = 我已处理，停止后续规则
    def finish(self, handler): pass   # 收尾钩子（原书未实现，2026 年应补）

class HeadingRule(Rule):
    type = "heading"
    def condition(self, block):
        return "\n" not in block and len(block) <= 70 and block[-1] != ":"

class TitleRule(HeadingRule):
    type = "title"
    first = True
    def condition(self, block):
        if not self.first: return False
        self.first = False
        return super().condition(block)

class ListRule(Rule):
    """只管 <ul> 的开关，返回 False 把块交棒给后续规则。"""
    type = "list"
    inside = False
    def condition(self, block): return True
    def action(self, block, handler):
        if block.startswith("- "):
            if not self.inside:
                handler.start("list"); self.inside = True
            return False          # 交棒给 ListItemRule
        if self.inside:
            handler.end("list"); self.inside = False
        return False              # 交棒给 ParagraphRule
    def finish(self, handler):
        if self.inside:
            handler.end("list"); self.inside = False

class ListItemRule(Rule):
    type = "listitem"
    def condition(self, block): return block.startswith("- ")
    def action(self, block, handler):
        for line in block.splitlines():        # 一个块里可含多行 "- "
            if line.startswith("- "):
                handler.start("listitem")
                handler.feed("listitem", line[2:].strip())
                handler.end("listitem")
        return True

class ParagraphRule(Rule):
    """兜底规则，放在最后。"""
    type = "paragraph"
    def condition(self, block): return True

# ---------- parser：把过滤器与规则串起来 ----------
class Parser:
    def __init__(self, handler):
        self.handler = handler; self.rules = []; self.filters = []
    def add_rule(self, rule): self.rules.append(rule)
    def add_filter(self, pattern, name):
        def filt(block, handler): return re.sub(pattern, handler.sub(name), block)
        self.filters.append(filt)
    def parse(self, file):
        self.handler.start("document")
        for block in blocks(file):
            for filt in self.filters:          # 先行内替换
                block = filt(block, self.handler)
            for rule in self.rules:            # 后块级判定
                if rule.condition(block):
                    if rule.action(block, self.handler): break
        for rule in self.rules:                # 收尾：关闭未闭合的列表
            rule.finish(self.handler)
        self.handler.end("document")

class BasicTextParser(Parser):
    def __init__(self, handler):
        super().__init__(handler)
        for rule in (TitleRule(), HeadingRule(), ListRule(), ListItemRule(), ParagraphRule()):
            self.add_rule(rule)
        self.add_filter(r"\*(.+?)\*", "emphasis")
        self.add_filter(r"(https?://[\.a-zA-Z/]+)", "url")
        self.add_filter(r"([\.a-zA-Z]+@[\.a-zA-Z]+[a-zA-Z]+)", "mail")

SAMPLE = """Welcome to *Instant Markup*

A paragraph with *emphasis*, a link http://example.com and mail foo@bar.com

A Heading

- first item
- second item
"""

with io.StringIO(SAMPLE) as f:                 # 换成 open("input.txt") 即可处理文件
    BasicTextParser(HTMLRenderer()).parse(f)
```

实际输出（已验证，换行略有差异）：

```html
<html><head><title>Document</title></head><body>
<h1>Welcome to <em>Instant Markup</em></h1>
<p>A paragraph with <em>emphasis</em>, a link
   <a href="http://example.com">http://example.com</a> and mail
   <a href="mailto:foo@bar.com">foo@bar.com</a></p>
<h2>A Heading</h2>
<ul><li>first item</li><li>second item</li></ul>
</body></html>
```

**规则链的顺序即优先级**：`Title → Heading → List → ListItem → Paragraph`。
关键设计是 `ListRule` 返回 **False**（不阻断）交棒给 `ListItemRule`；
`finish()` 收尾钩子保证文档末尾的 `<ul>` 一定被关闭（原书未处理）。

### 4. 2026 年等价做法

**做法 A：直接用成熟的 Markdown 解析器**（生产首选，`pip install mistune` / `markdown-it-py` / `marko`）：

```python
# 教学示意，不参与构建
import mistune

print(mistune.html("# 标题\n\n- a\n- b\n\n*强调*"))     # 直接得到完整 HTML（自带转义）
```

**做法 B：保留本章架构，用 dataclass + `match` 改写分派**（3.10+）：

```python
# 教学示意，不参与构建（需要 Python 3.10+）
from dataclasses import dataclass, field


@dataclass(frozen=True)
class Block:
    kind: str                                    # heading / list / paragraph
    text: str
    lines: tuple[str, ...] = field(default_factory=tuple)


def classify(block: str) -> Block:
    lines = tuple(block.splitlines())
    match lines:
        case [only] if len(only) <= 70 and not only.endswith(":"):
            return Block("heading", only, lines)
        case [*rest] if rest and all(l.startswith("- ") for l in rest):
            return Block("list", block, lines)
        case _:
            return Block("paragraph", block, lines)


print(classify("A Heading").kind, classify("- a\n- b").kind, classify("x\ny").kind)
# heading list paragraph
```

`match` 把「结构判定」写成声明式，`dataclass` 让「块」成为可比较、可测试的值对象；
规则链仍保留——二者不是替代关系，而是**分派方式的升级**。

## 常见误区与本书需修正之处

| # | 原书说法 / 常见想法 | 问题 | 2026 正确写法（🔧 = 需修正） |
| --- | --- | --- | --- |
| 1 | 直接 `print` 用户文本 | 🔧 **未转义，存在 XSS**（原书未涉及） | 🔧 `html.escape(text)` 或用模板引擎自动转义 |
| 2 | 用 `len(block) <= 70` 判断标题 | 启发式必然误判：短段落会被当标题 | 保留设计但明确它是**启发式**；生产改用显式标记（`#`） |
| 3 | 切块时末尾不补空行 | 最后一个块丢失 | 保留 `yield "\n"`；或 `re.split(r"\n{2,}", text)` |
| 4 | 列表在文档结束时仍开着 | 输出缺 `</ul>`（原书未处理） | 🔧 加 `Rule.finish()` 收尾钩子 |
| 5 | 一个块里写多行 `- ` 项 | 原书会合成一个 `<li>` | 🔧 逐行产出 `<li>`（见 `ListItemRule.action`） |
| 6 | URL / 邮件正则过于简陋 | 漏数字、端口、查询串；误匹配 | 🔧 用更完整的模式，或先 `urllib.parse` 校验再渲染 |
| 7 | 「过滤先于规则」顺序无所谓 | 顺序错了会破坏块结构 | 保持「先行内、后块级」；块级规则不依赖行内结果 |
| 8 | Handler 直接 `print` | 无法测、无法重定向、无法换目标 | 🔧 Handler 持有 `io.StringIO` 或接收 `file=`，便于断言 |
| 9 | 🔧 原书未涉及 | 无测试、无类型注解 | 补：`classify()` 这类纯函数用 `pytest.mark.parametrize`；块用 dataclass |
| 10 | 用正则解析嵌套结构（表格、嵌套列表） | 正则无法处理任意嵌套 | 上解析器（mistune 插件）或手写递归下降 |
