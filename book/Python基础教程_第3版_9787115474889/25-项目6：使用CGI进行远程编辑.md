# 第 25 章 项目6：使用CGI进行远程编辑（原书 pp.379-386）

> 一句话定位本章：做一个「通过浏览器远程编辑服务器上文件」的最小系统——三个 CGI 脚本串起**表单 → 编辑器 → 保存**的闭环；它同时也是本书展示 HTTP 无状态特性最直观的一章。
> 基线：原书 Python 3.5；本目录按 3.12+ 校验。
> 对应英文章名：Project 6: Remote Editing with CGI

### 25.2 原书工具链的现状：CGI 已经退场

```python
# ❌ 历史对照：Python 3.13 上无法运行（cgi / cgitb 已按 PEP 594 移除）
import cgi
cgitb = None                                     # import cgitb; cgitb.enable()
form = cgi.FieldStorage()                        # 解析 application/x-www-form-urlencoded
filename = form.getvalue("filename")
print("Content-type: text/html\n")               # CGI 协议：先输出响应头
print(f"<h1>正在编辑 {filename}</h1>")
print("<form action='save.cgi' method='post'>")
print(f"<textarea name='text'>{open(filename).read()}</textarea>")
print(f"<input type='hidden' name='filename' value='{filename}'>")
print("</form>")
```

这段代码有四处今日必须否定的写法：**①** 手工输出 `Content-type` 头；**②** `filename` 未校验 → 路径穿越可读可写任意文件；**③** 文件内容直接插进 `textarea` → 内容里的 `</textarea>` 能闭合标签造成注入；**④** 完全没有鉴权与 CSRF 防护。

CGI 退场的原因也很直接：每请求 fork 一个进程、无连接复用、无法做长连接，性能与安全面都不划算。今天的标准是 **PEP 3333（WSGI）** 或 ASGI。

### 25.4 初次实现：单文件最小闭环（FastAPI 版）

```python
# editor_app.py —— 教学示意，不参与构建
# pip install fastapi uvicorn jinja2 python-multipart
# 运行：python editor_app.py  → http://127.0.0.1:8000/
from __future__ import annotations

import os
import secrets
from pathlib import Path

from fastapi import FastAPI, Form, HTTPException
from fastapi.responses import HTMLResponse, RedirectResponse
from jinja2 import Environment, select_autoescape

BASE = Path("docs").resolve()
BASE.mkdir(exist_ok=True)
MAX_BYTES = 512_000
TOKENS: set[str] = set()            # 演示用 CSRF token 池；生产应存服务端 session

app = FastAPI(title="远程编辑器")
env = Environment(autoescape=select_autoescape(["html"]), trim_blocks=True)

INDEX = """<!doctype html><meta charset="utf-8"><title>远程编辑器</title>
<h1>文档列表</h1>
<ul>{% for f in files %}<li>
  <a href="/edit/{{ f }}">{{ f }}</a></li>{% endfor %}</ul>
<form action="/edit" method="post">
  <input name="filename" placeholder="new.txt" required>
  <input type="hidden" name="token" value="{{ token }}">
  <button>新建 / 编辑</button></form>"""

EDIT = """<!doctype html><meta charset="utf-8"><title>编辑 {{ name }}</title>
<h1>编辑 {{ name }}</h1>
<form action="/save" method="post">
  <textarea name="text" rows="20" cols="80">{{ content }}</textarea><br>
  <input type="hidden" name="filename" value="{{ name }}">
  <input type="hidden" name="token" value="{{ token }}">
  <button>保存</button></form>"""

def safe_path(name: str) -> Path:
    """把用户给的文件名钉死在 BASE 之内——本章最重要的一行防御。"""
    path = (BASE / name).resolve()
    if not path.is_relative_to(BASE):        # Python 3.9+
        raise HTTPException(status_code=400, detail="文件名非法：拒绝路径穿越")
    return path

def new_token() -> str:
    token = secrets.token_urlsafe(32)        # 令牌用 secrets，不用 random
    TOKENS.add(token)
    return token

@app.get("/", response_class=HTMLResponse)
def index() -> str:
    files = sorted(p.name for p in BASE.glob("*.txt"))
    return env.from_string(INDEX).render(files=files, token=new_token())

@app.post("/edit", response_class=HTMLResponse)
def edit(filename: str = Form(...), token: str = Form("")) -> str:
    if token not in TOKENS:
        raise HTTPException(status_code=403, detail="CSRF 校验失败")
    TOKENS.discard(token)
    path = safe_path(filename)
    content = path.read_text(encoding="utf-8") if path.exists() else ""
    return env.from_string(EDIT).render(name=path.name, content=content, token=new_token())

@app.get("/edit/{name}", response_class=HTMLResponse)
def edit_get(name: str) -> str:
    path = safe_path(name)
    if not path.exists():
        raise HTTPException(status_code=404, detail="文件不存在")
    return env.from_string(EDIT).render(
        name=path.name, content=path.read_text(encoding="utf-8"), token=new_token()
    )

def atomic_write(path: Path, text: str) -> None:
    """先写临时文件再 os.replace：要么整份新内容，要么原样保留。"""
    tmp = path.with_name(f"{path.name}.{secrets.token_hex(4)}.tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, path)

@app.post("/save")
def save(filename: str = Form(...), text: str = Form(""), token: str = Form("")) -> RedirectResponse:
    if token not in TOKENS:
        raise HTTPException(status_code=403, detail="CSRF 校验失败，请重试")
    TOKENS.discard(token)
    path = safe_path(filename)
    if len(text.encode("utf-8")) > MAX_BYTES:
        raise HTTPException(status_code=413, detail="内容超出上限")
    atomic_write(path, text)
    return RedirectResponse(url=f"/edit/{path.name}", status_code=303)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

### 25.5 再次实现：拆成「文件名表单 / 编辑器 / 保存」三块

原书把 25.5 拆成四个子步骤，映射到上面的代码：

| 原书子步骤 | 对应实现 | 关键校验 |
| --- | --- | --- |
| 创建文件名表单 | `GET /` + `POST /edit` | 文件名走 `safe_path()`；空名、绝对路径、`..` 全拒绝 |
| 编辑器脚本 | `GET /edit/{name}` | 内容经 Jinja2 **自动转义**，即使文件里写了 `</textarea>` 也跑不出来 |
| 保存脚本 | `POST /save` | CSRF token + 内容大小上限 + 原子写 |
| 运行编辑器 | `uvicorn`/`python editor_app.py` | 只读本机 `127.0.0.1`，不暴露到 `0.0.0.0` |

注意原书的一个隐含缺陷：CGI 是无状态的，**文件名只能通过隐藏字段或 URL 在请求间传递**，而用户提交的值一律不可信。上面的写法把「校验」放在**服务端重新计算**的 `safe_path()` 里，而不是相信隐藏字段。

### 25.6 进一步探索：从「能编辑」到「可交付」

| 方向 | 做法 |
| --- | --- |
| 鉴权 | 登录态 + 每用户独立 `BASE` 目录；未登录只读 |
| 并发写 | 乐观锁（提交时带上读到的 mtime / 版本号），冲突返回 409 |
| 版本历史 | 每次保存写一份快照，或用 Git 做后端（`GitPython`） |
| 测试与部署 | `TestClient` + `pytest` 无需真起服务；部署用 ASGI 服务器 + 反向代理 HTTPS |

配套的单元测试示例（不需要真的监听端口）：

```python
# test_editor.py —— 教学示意，不参与构建
# pip install pytest httpx
import pytest
from fastapi import HTTPException
from fastapi.testclient import TestClient

import editor_app

def test_path_traversal_is_rejected():
    for bad in ("../../etc/passwd", "/etc/passwd", "sub/../../secrets.txt"):
        with pytest.raises(HTTPException):
            editor_app.safe_path(bad)

def test_roundtrip(tmp_path, monkeypatch):
    monkeypatch.setattr(editor_app, "BASE", tmp_path)
    client = TestClient(editor_app.app)
    token = client.get("/").text.split('name="token" value="')[1].split('"')[0]
    resp = client.post("/save", data={"filename": "a.txt", "text": "你好", "token": token})
    assert resp.status_code == 303
    assert (tmp_path / "a.txt").read_text(encoding="utf-8") == "你好"
```

### 2026 年等价做法

| 原书环节 | 原书做法 | 2026 年等价做法 |
| --- | --- | --- |
| 请求解析 | `cgi.FieldStorage()` | FastAPI 的 `Form(...)` / Pydantic 模型（自动校验类型与必填） |
| 错误展示 | `cgitb.enable()` | 结构化 `logging` + 框架的调试中间件；生产只返回通用错误页 |
| 响应输出 | 手工 `print("Content-type: ...")` | 框架负责序列化，`HTMLResponse` / `RedirectResponse` |
| 部署形态 | CGI（每请求起进程） | ASGI（`uvicorn`）或 WSGI（PEP 3333）；前面挂反向代理 |
| 安全 | 无 | 鉴权 + CSRF token + 路径白名单 + 内容大小上限 |

## 近年研究与工业界开源实践（2015–2026）

- **FastAPI**：以类型注解驱动校验，把「解析表单 + 校验 + 生成文档」合成一步；配套依赖 `python-multipart` 用于解析 `multipart/form-data`。
- **Flask / Django**：WSGI 侧的主流；Django 自带 CSRF 中间件、用户体系与 ORM，更适合「真要做个系统」而不是教学演示。
- **Uvicorn / Gunicorn**：ASGI 与 WSGI 的生产服务器；ASGI 同时覆盖 HTTP 与 WebSocket。
- **`httpx` + `TestClient`**：让 Web 接口测试不需要真起服务，`pytest` 里直接调用，是「测试金字塔」中层的主力。
- **反向代理与 HTTPS、安全工程实践**：对外服务应终止 TLS 于 Nginx/Caddy/云负载均衡；路径穿越、CSRF、未授权访问长期位居 Web 风险前列（OWASP Top Ten 为行业共识文档，非同行评审）。🔧 各项目版本号与 API 以官方文档为准。

## 常见误区与本书需修正之处

| # | 原书写法 / 常见误区 | 问题 | 2026 年正确写法 |
| --- | --- | --- | --- |
| 1 | 🔴 `import cgi` / `import cgitb` | **3.13 已移除（PEP 594）**，导入即失败 | FastAPI / Flask + ASGI / WSGI（PEP 3333） |
| 2 | 🔧 手工 `print("Content-type: text/html\n")` | 头与体混写，编码与状态码全靠手 | 框架序列化响应对象 |
| 3 | 🔧 `open(form.getvalue("filename"))` | 路径穿越：可读可写任意文件 | `Path.resolve()` + `is_relative_to()` 白名单 |
| 4 | 🔧 文件内容直接插进 `<textarea>` | 内容含 `</textarea>` 即标签注入 | Jinja2 autoescape 或 `html.escape` |
| 5 | 🔧 无 CSRF 防护 | 第三方站点可诱导提交保存请求 | 每表单一次性 token（`secrets.token_urlsafe`） |
| 6 | 🔧 无鉴权 | 任何人都能编辑服务器文件 | 登录态 + 每用户目录隔离 |
| 7 | 🔧 直接 `write_text` 覆盖 | 写一半崩溃 → 文件损坏 | 临时文件 + `os.replace()` 原子替换 |
| 8 | 🔧 用 `random` 生成 token | 可预测 | `secrets` 模块 |
| 9 | 相信隐藏字段里的文件名 | 客户端可任意篡改 | 服务端重新校验，隐藏字段只作提示 |
| 10 | 🔧 用 `cgitb` 在生产显示 traceback | 泄露路径与源码片段 | 生产只返回通用错误，详情进日志 |
