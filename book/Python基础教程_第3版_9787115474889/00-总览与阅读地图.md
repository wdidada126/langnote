## 七、跨语言对照速查（读本书时最常拿来对照的）

| Python | Java | C++ | 备注 |
| --- | --- | --- | --- |
| `list` | `ArrayList` | `std::vector` | Python 的 list 是对象引用的动态数组，不是值数组 |
| `tuple` | 无直接对应（`record` 近似） | `std::tuple` | 常作不可变键与多返回值 |
| `dict` | `HashMap` | `std::unordered_map` | 3.7 起语言层面保证插入序 |
| `set` | `HashSet` | `std::unordered_set` | 基于哈希表，元素必须可哈希 |
| 生成器 | `Stream`（惰性但不同机制） | 协程（C++20） | Python 生成器是协程的最小形态 |
| `with` | try-with-resources | RAII | 基于上下文管理器协议 `__enter__/__exit__` |
| 魔法方法 | 无（靠接口） | 运算符重载 | Python 用双下划线协议统一 |
| GIL / free-threading | 无 GIL，靠 `synchronized`/锁 | 无 GIL，靠 `std::mutex` | PEP 703 后才有无 GIL 构建 |
