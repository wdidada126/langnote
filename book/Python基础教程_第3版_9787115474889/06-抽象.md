## 核心精讲

> 以下均为**教学示意，不参与构建**：片段自足，可直接 `python x.py` 运行。

### 1. 文档、返回值与「不是函数的函数」

```python
# demo_ch6_doc.py —— 教学示意，不参与构建
def square(x: float) -> float:
    """返回 x 的平方。

    Args:
        x: 被平方的数。
    Returns:
        x ** 2
    """
    return x * x

print(square.__doc__.strip().splitlines()[0])   # 返回 x 的平方。
print(help(square) is None)                     # True（help 返回 None，打印到 stdout）

def no_return(x):
    print("side effect:", x)

print(no_return(1))        # side effect: 1 \n None —— 没有 return 即返回 None
```

### 2. 参数传递：名字绑定到对象，不是拷贝对象

```python
# demo_ch6_args.py —— 教学示意，不参与构建
def rebind(n):        # 不可变：重绑形参，影响不到实参
    n = n + 1
    return n

def mutate(lst):      # 可变：就地修改，实参「看得见」
    lst.append(99)

a, lst = 1, [1]
print(rebind(a), a)   # 2 1
mutate(lst)
print(lst)            # [1, 99]

def safe(lst=None):
    lst = [] if lst is None else list(lst)   # 先拷贝再改，避免副作用
    lst.append(0)
    return lst

print(safe(), safe([7]), safe([7]))          # [0] [7, 0] [7, 0]
```

### 3. 🔴 可变默认值：Python 最著名的陷阱

```python
# demo_ch6_default.py —— 教学示意，不参与构建
def bad(item, bucket=[]):        # ❌ 默认值在函数定义时求值一次，被所有调用共享
    bucket.append(item)
    return bucket

print(bad(1))                    # [1]
print(bad(2))                    # [1, 2] —— 意外地累积了！

def good(item, bucket=None):     # ✅ 惯用写法
    bucket = [] if bucket is None else bucket
    bucket.append(item)
    return bucket

print(good(1), good(2))          # [1] [2]
```

### 4. 收集参数、分配参数与仅位置参数

```python
# demo_ch6_star.py —— 教学示意，不参与构建
def f(a, *args, **kwargs):
    return a, args, kwargs

print(f(1, 2, 3, x=4, y=5))      # (1, (2, 3), {'x': 4, 'y': 5})

def g(a, /, b, *, c):            # 3.8+ PEP 570：/ 前仅位置，* 后仅关键字
    return a, b, c

print(g(1, 2, c=3))              # (1, 2, 3)
# g(a=1, b=2, c=3)               # ❌ TypeError：a 只接受位置实参

def log(prefix, *msgs, sep=" "):     # *args 后的参数自动成为「仅关键字」
    return prefix + sep.join(msgs)

print(log("[INFO]", "a", "b", sep="|"))   # [INFO]a|b

pair = (1, 2)
print(f(*pair, **{"x": 9}))      # 分配参数：(1, (2,), {'x': 9})

def adapter(*args, **kwargs):    # 典型用途：透传包装
    print("before")
    result = f(*args, **kwargs)
    print("after")
    return result
print(adapter(1, 2, k=3))
```

参数设计速查（2026 年版）：

| 位置 | 语法 | 含义 | 典型用途 |
| --- | --- | --- | --- |
| `def f(a, /)` | `/` 之前 | 仅位置：调用者不能写 `a=` | 保持重命名自由（如 `len(x)`、`dict.get`） |
| `def f(a, b=1)` | 中间 | 位置或关键字 | 常规参数 |
| `def f(*, c)` | `*` 之后 | 仅关键字 | 布尔开关、可选行为（强制显式） |
| `def f(**kw)` | 末尾 | 收集关键字 | 透传、配置字典 |

### 5. 作用域与递归

```python
# demo_ch6_scope.py —— 教学示意，不参与构建
x = 10
def read_global():
    return x                  # 读：无需声明
def write_global():
    global x                  # 写（重绑）：必须声明
    x = 20
print(read_global()); write_global(); print(x)   # 10 20

def outer():
    count = 0
    def inner():
        nonlocal count        # 3.x：修改嵌套作用域变量
        count += 1
        return count
    return inner()
print(outer(), outer())       # 1 1（每次调用重新创建闭包）

def fact(n: int) -> int:      # 递归：基线 + 递推
    return 1 if n <= 1 else n * fact(n - 1)
print(fact(5))                # 120

def power(x, n):              # 快速幂：O(log n)
    if n == 0:
        return 1
    half = power(x, n // 2)
    return half * half * (x if n % 2 else 1)
print(power(2, 10))           # 1024

import sys, bisect
print(sys.getrecursionlimit())          # 1000（默认）
seq = [1, 3, 5, 7, 9]
print(bisect.bisect_left(seq, 6))       # 3 —— 生产二分查找用 bisect
bisect.insort(seq, 6)
print(seq)                              # [1, 3, 5, 6, 7, 9]
```

递归的取舍：**递归赢在可读性，输在栈深（默认约 1000）与函数调用开销**。Python 没有尾调用优化，深度不确定的问题（图的深搜、长链表）应改写成显式栈或迭代。

## 近年研究与工业界开源实践（2015–2026）

- **类型检查工业化**：`mypy`、`pyright`、`ruff` 把类型注解从「可选注释」变成 CI 门禁；大型项目（`pandas`、`sqlalchemy`、各类 SDK）普遍全量注解。PEP 484（2014）十年后从「实验」变成「默认工程实践」。
- **签名内省生态**：`inspect.signature`、`typing.get_type_hints` 驱动了依赖注入（FastAPI）、CLI 生成（`typer`/`cyclopts`）、序列化（`pydantic`）三大类框架——它们的共同基础就是本章讲的参数种类。
- **装饰器与闭包**：`functools.lru_cache`、`functools.wraps`（PEP 318 引入装饰器语法）是「函数抽象」的工业化延伸；`functools.cache` 让记忆化递归（如斐波那契）变得一行搞定。
- **递归 vs 迭代**：CPython 无 TCO 是有意的设计决定（Guido 多次公开说明：保留完整栈回溯利于调试）；工程上深度不确定的递归仍改为显式栈。这是社区共识而非论文结论（非同行评审）。
- **研究侧**：「高阶函数与抽象代价」在编程语言研究中有大量工作（如闭包转换、函数内联）；CPython 3.11+ 的 specializing interpreter 正是这类优化的工程化落地。🔧 具体论文本目录不引用，避免编造。

## 常见误区与本书需修正之处

| # | 原书说法 / 常见误解 | 问题 | 2026 正确写法 |
| --- | --- | --- | --- |
| 1 | 🔧「`def f(x, lst=[])` 挺方便」 | 默认值只求值一次，跨调用共享 | `lst=None` + 函数内初始化 |
| 2 | 「传参就是传值/传引用二选一」 | Python 是**传对象引用**（call by object） | 记住：重绑形参不影响实参；就地修改会影响 |
| 3 | 「函数没有 `return` 就没返回值」 | 返回 `None` | 显式区分「返回值」与「副作用」两类函数 |
| 4 | 「想在函数里改全局变量直接赋值」 | 会被当成创建局部变量 | `global x`；嵌套作用域用 `nonlocal x` |
| 5 | 「`*args` 后面还能跟普通位置参数」 | `*args` 后的是**仅关键字**参数 | `def f(*args, sep=" ")`；要位置参数就放到 `*` 前 |
| 6 | 🔧「默认参数位置无所谓」 | 有默认值的参数必须排在无默认值之后 | `def f(a, b=1)` ✅；`def f(a=1, b)` ❌ 语法错误 |
| 7 | 「递归比循环快」 | Python 无尾调用优化，函数调用开销大 | 数值类递归用迭代/公式；深递归用显式栈 |
| 8 | 「二分查找自己写更好」 | 边界易错 | 用 `bisect.bisect_left/insort` |
| 9 | 🔧 原书未讲类型注解 | 2026 年公共 API 应带注解 | `def f(x: int, y: str = "") -> bool:` |
| 10 | 「`Optional[int]` 必须用 typing」 | 3.10 起可用 `\|` | `int \| None`（PEP 604） |
| 11 | 「docstring 只是注释」 | 可被 `help()`/`__doc__`/doctest/`Sphinx` 消费 | 写清 Args/Returns/Raises；测试见第 16 章 |
| 12 | 「`lambda` 能替代所有小函数」 | 只能写单个表达式，且无名（调试信息差） | 需要文档/多行/递归时用 `def` |
| 13 | 「`def f(x: list=[])` 之类写法规避不了」 | 同 #1 | 同上；另外**注解里不要写可变字面量** |
