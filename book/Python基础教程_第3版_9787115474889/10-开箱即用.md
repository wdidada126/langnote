## 核心精讲

> 教学示意，不参与构建：以下片段可直接粘贴进 REPL 或 `.py` 运行，除显式标注外只用标准库。

### 1. 模块与包：导入只发生一次

模块 = 一个 `.py` 文件 = 一个命名空间。**首次 `import` 会执行模块顶层代码**，之后只在 `sys.modules` 里取缓存，所以不要用 `import` 实现「重新加载」（要 `importlib.reload`）。

```python
import sys, math, os

print("搜索路径首项:", sys.path[0])
print("math 已加载:", "math" in sys.modules)
print("math.__doc__ 首行:", math.__doc__.splitlines()[0])
print("带下划线的名字:", [n for n in dir(math) if n.startswith("_")][:3])
print("math 是否声明 __all__:", hasattr(math, "__all__"))
print("math 源文件:", getattr(math, "__file__", "内置模块无 __file__"))
print("进程参数与环境:", sys.argv[:1], len(os.environ) > 0)
```

让模块可用的三条路：放进 `sys.path` 里的目录、设置 `PYTHONPATH`、或用 `.pth` 文件；**工程化的正解是 `pyproject.toml` + `pip install -e .`（可编辑安装）**，而不是手改 `sys.path`。双入口写法：

```python
def main():
    print("被当脚本运行时才执行")


if __name__ == "__main__":      # 被 import 时 __name__ 是模块名，不会执行
    main()
```

包是「含 `__init__.py` 的目录」（3.3+ 起命名空间包可无 `__init__.py`，但常规包仍建议保留）：

```text
myproj/
├── pyproject.toml
└── src/myproj/
    ├── __init__.py        # 可写 __all__ 控制 from myproj import *
    ├── cli.py             # 包内相对导入：from . import core
    └── core.py
```

包内用**相对导入**（`from . import core`），顶层脚本用绝对导入；混用是新手最常见的 `ImportError` 来源。

### 2. 探索模块

`dir(x)` 列名字 → `help(x)` 看文档字符串 → `x.__file__` 定位 → `inspect.getsource(x)` 读源码。公开 API 看 `__all__`（它决定 `from m import *` 导入什么），没写 `__all__` 时，**下划线开头的名字视为私有**。

```python
import inspect, collections

print([n for n in dir(collections) if not n.startswith("_")][:6])
print(inspect.getsource(collections.namedtuple).splitlines()[0])
```

### 3. `fileinput` 与 `pathlib`（替代 `os.path` 拼路径）

```python
import fileinput, pathlib, tempfile

tmp = pathlib.Path(tempfile.mkdtemp())
(tmp / "a.txt").write_text("第一行\n第二行\n", encoding="utf-8")
for line in fileinput.input(files=[str(tmp / "a.txt")], encoding="utf-8"):
    print(line.rstrip())
print("路径拼接:", tmp / "sub" / "a.txt")     # pathlib 取代 os.path.join
print("父目录/后缀:", (tmp / "a.txt").parent.name, (tmp / "a.txt").suffix)
```

`fileinput` 的价值是把多个文件（或 stdin）当作**一条行流**；2026 年更常见的写法是 `for p in pathlib.Path(dir).glob("*.txt"): for line in p.open(encoding="utf-8")`，或用 `argparse` + `fileinput` 做命令行过滤器。

### 4. 集合、堆、双端队列

```python
from collections import deque
import heapq

a, b = {1, 2, 3}, {3, 4}
print(a | b, a & b, a - b)                      # 集合是可变的；frozenset 可作 dict 键
h = []
for x in (5, 1, 3, 2):
    heapq.heappush(h, x)
print(heapq.heappop(h), heapq.nlargest(2, h))   # 1 [5, 3]：堆只保证 heappop 取最小
d = deque(range(3), maxlen=3)
d.appendleft(9)
print(d)                                        # deque([9, 0, 1], maxlen=3)：左端插入 O(1)
```

`set` 去重与成员判断、`heapq` 取 Top-N / 优先队列、`deque` 做队列与滑动窗口——**不要用 `list.pop(0)` 当队列**，那是 O(n)。

### 5. `time` vs `datetime`，`random` vs `secrets`

```python
import time, datetime, random, secrets

print("时间戳/单调钟:", round(time.time()), round(time.monotonic()))
print("UTC 时间:", datetime.datetime.now(datetime.UTC).isoformat(timespec="seconds"))
print("随机抽样:", random.sample(range(100), 3))     # 模拟、洗牌、抽样：可以
print("安全令牌:", secrets.token_urlsafe(16))        # 令牌/密码/会话 ID：必须用 secrets
```

`time` 面向「时刻与计时」（`time.time()` 受系统时钟调整影响，测间隔要用 `time.monotonic()` 或 `time.perf_counter()`）；`datetime` 面向「日历与运算」（`timedelta`、时区）。原书用 `time` 做的日期处理，今天几乎都该换成 `datetime` + `zoneinfo`。

`random` 是 **Mersenne Twister 伪随机**，可预测，**不能**生成令牌、密码、会话 ID——用 `secrets`（`token_urlsafe` / `token_hex` / `choice`）。

### 6. `shelve` / `json`：持久化与交换

```python
import json, shelve, pathlib, tempfile

data = {"name": "中文", "tags": ["a", "b"]}
print(json.dumps(data, ensure_ascii=False))
print(json.loads(json.dumps(data)) == data)

with shelve.open(str(pathlib.Path(tempfile.mkdtemp(), "shelf"))) as db:
    db["k"] = data                              # shelve 底层是 pickle
    print(db["k"])
```

`shelve` 用 `pickle` 序列化，**反序列化会执行任意代码**——只加载你自己写的文件，跨网络/跨信任边界的数据一律用 `json`（或 `tomllib`、`sqlite3`）。原书后续项目（第 26 章公告板）把 `shelve` 直接放在 CGI 后面，今天看是一条明确的安全红线。

### 7. `re`：预编译与 3.11 新语法

```python
import re

pat = re.compile(r"(?P<word>\w+)=(?P<val>\d+)")     # 复用就预编译：更快也更清晰
print(pat.search("x=42").groupdict())
print(re.sub(r"\s+", " ", "a   b"))
print(re.findall(r"\d+", "a1 b22"))
print(re.match(r"a*ab", "aaab"), re.match(r"(?>a*)ab", "aaab"))   # 3.11+ 原子组：禁止回溯
print(re.match(r"\d*+\w", "123a"))                                 # 3.11+ 占有量词
```

`re.match` 只从头匹配、`re.search` 扫全文、`re.fullmatch` 要求整体匹配；量词默认**贪婪**，加 `?` 变非贪婪。3.11 起支持**原子组 `(?>...)`** 与**占有量词 `*+` / `++` / `?+`**，用来显式禁止回溯、缓解灾难性回溯（本机 3.13 验证可用；🔧 细节以 `re` 官方文档为准）。

### 8. `sys.setrecursionlimit`：只是 Python 层的闸门

```python
import sys

print("默认递归上限:", sys.getrecursionlimit())
sys.setrecursionlimit(10_000)       # 提高的是 Python 帧计数上限，不是 C 栈大小
```

把它调得很大仍可能崩解释器：真正的 C 栈溢出由解释器另行防护，🔧 **具体阈值与行为以官方文档为准**（3.12 前后有相关改动）。深递归的治本之法是**改写成迭代或用显式栈**，第 9 章的 `queens` 就是「递归思路 + 生成器」的折中。

| 用途 | 原书/旧写法 | 2026 推荐 |

| 命令行参数 | `getopt`、`optparse` | `argparse`（`optparse` 已弃用）；复杂 CLI 用 `click`/`typer` |

| 版本 | 与本章相关的变化 |

| 3.12 | 🔴 `distutils` 从标准库移除（PEP 632，若仍可导入多半是 setuptools 的兼容垫片） |
| 3.13 | 🔴 PEP 594「死电池」大清理：`cgi`、`cgitb`、`telnetlib`、`crypt`、`uu`、`pipes`、`nntplib`、`aifc`、`audioop`、`chunk`、`imghdr`、`sndhdr`、`sunau`、`xdrlib`、`mailcap`、`nis`、`ossaudiodev`、`spwd`、`msilib`、`lib2to3` 全部移除（本机 3.13 实测均为 `ModuleNotFoundError`）；`asyncore`/`asynchat`/`smtpd` 亦已移除 |

## 近年研究与工业界开源实践（2015–2026）

- **PEP 594 的连锁反应**：标准库「瘦身」把生态推向 PyPI——`requests`/`httpx`、`dateutil`/`pendulum`、`pydantic` 等成为事实标准；代价是依赖治理（锁文件、SBOM、供应链审计）变成必备技能。
- **依赖与环境的工业化**：`uv`、`pip-tools`、`poetry`、`hatch` 把「装包」变成可复现流程；`pip-audit`/`osv-scanner` 做漏洞扫描，呼应本章「让模块可用」的现代形态。
- **`pathlib` 的普及**：主流项目已默认用 `Path` 而非字符串拼路径，`os.path` 退为兼容层；`fsspec`/`anyio.Path` 把它推广到远端文件系统。
- **安全默认值**：`secrets`、`hashlib.scrypt`/`argon2`、`json` 取代 `pickle` 做跨边界交换，已成为代码审计的固定检查项（OWASP/CWE 对不安全反序列化的归类可直接对照）。
- **可观测性**：`logging` + `structlog` + OpenTelemetry 是本章「日志」的现代落点，`print` 调试只应出现在临时脚本里。
- 以上均为**工业界实践或工具文档，非同行评审论文**。

## 常见误区与本书需修正之处

| # | 原书说法 / 常见误区 | 问题 | 2026 正确写法 |
| --- | --- | --- | --- |
| 1 | `random` 生成令牌 / 密码 / 会话 ID | Mersenne Twister 可预测，属安全缺陷 | `secrets.token_urlsafe()` / `secrets.token_hex()` / `secrets.choice()` |
| 2 | `shelve` / `pickle` 存外部传入的数据 | 反序列化可执行任意代码 | 跨信任边界用 `json`；必须 pickle 时校验来源并考虑 `hmac` 签名 |
| 3 | 用 `time` 做日期运算、`time.time()` 测间隔 | 前者缺日历语义，后者受系统时钟调整影响 | `datetime` + `timedelta` + `zoneinfo`；计时用 `time.monotonic()` / `perf_counter()` |
| 4 | `os.path.join` 手工拼路径 | 字符串路径易错、跨平台差 | `pathlib.Path`：`/` 运算符、`read_text(encoding=...)`、`glob` |
| 5 | 🔧 `re` 未提 3.11 的原子组与占有量词 | 灾难性回溯只能靠改写模式规避 | `(?>...)`、`a*+`；🔧 细节以 `re` 官方文档为准 |
| 6 | 反复用字面量调 `re.match(...)` | 模块级缓存虽在，但可读性差 | 复用前 `re.compile()`，并给模式命名 |
| 7 | 原书「其他模块」里的 `getopt`/`optparse` | 已被 `argparse` 取代，后者已弃用 | `argparse`；复杂 CLI 用 `click`/`typer` |
| 8 | 🔧 沿用 PEP 594 已移除的模块 | 3.13 起 `import` 直接失败 | `cgi`→WSGI/ASGI 框架；`telnetlib`→`paramiko`/`asyncssh`；`distutils`→`setuptools`/`hatchling` |
| 9 | `sys.setrecursionlimit(100000)` 解决深递归 | 只抬高 Python 帧上限，C 栈可能仍溢出 | 改写为迭代或显式栈；🔧 C 栈保护细节以官方文档为准 |
| 10 | 用 `import` 重新加载模块 | 第二次 `import` 命中 `sys.modules` 缓存 | `importlib.reload()`（仅调试用） |
| 11 | 在包里用绝对导入或改 `sys.path` 找模块 | 易出 `ImportError`、部署即失效 | 可编辑安装（`pip install -e .`）+ 包内相对导入 |
| 12 | `os.system` 调外部命令 | 无参数转义、易命令注入 | `subprocess.run([...], check=True)`，绝不用 `shell=True` 拼用户输入 |
