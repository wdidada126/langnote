# 10 配置与集群运维（原书第 7 章 ✅ 译系列锚点：「Cassandra 配置」）

## 10.1 题纲

1. `cassandra.yaml` 的结构化读法：身份/通信/存储/压实/缓存/提示与保留/安全七抽屉
2. 内存配方：堆（MAX_HEAP/NEWS）、堆外（mmap/index summary）、压实与读并发共享堆的博弈
3. 磁盘配方：commitlog 独盘、多 data 目录 JBOD、`index_interval`/`memtable_*` 的写读权衡
4. 写路径旋钮：`commitlog_sync`（periodic 10ms / group ⚠️ 版本点）、`memtable_cleanup_threshold`
5. 压实旋钮：`concurrent_compactors`、throughput、`compaction_large_partition_warning`
6. 保留窗口：`gc_grace_seconds`（默认 10 天 ⚠️）、hint 窗口、TTL 上限
7. 多 DC 配置：rackdc 属性文件、`auto_bootstrap` 陷阱（2.x 事故集 ⚠️）、跨 DC 时钟同步铁律
8. 滚动操作手册：滚动重启/升级（2.1→2.2 流程 ⚠️）、`nodetool drain` 的角色
9. 快照与备份：`nodetool snapshot` + hardlink 语义、`cassandra.in.sh` 时代的工法 ⚠️

## 10.2 高价值参数逐条（2.x 名 ⚠️）

| 参数 | 书中立场 | 备注 |
|---|---|---|
| `concurrent_reads/writes` | CPU 核数同级起步 | 压实并发挤占读线程是经典事故 |
| `memtable_allocation_type` | heap_buffers vs offheap_buffers（2.x 特色 ⚠️） | 堆外集合存储的试验田，3.x 体系重做 |
| `index_interval` | 64KB 默认，大分区调小费内存 | 读放大/内存的连续谱 |
| `key_cache_size_in_mb` | 非 0 即开 | 点查型工作负载先动这里 |
| `hinted_handoff_enabled` | 默认开；`max_window_in_seconds` 保守 | 过期 hint=静默丢失（08 章回环） |
| `auto_bootstrap` | 2.x 建议默认关 ⚠️ | "空节点以为自己是新加入"而偷全环数据的名场面 |
| `num_tokens` | 256 默认 | 上线后不可改（07 章） |
| `endpoint_snitch` | 上生产必改 | 滚动逐个改（02 章） |
| `phi_convict_threshold` | 8 默认，云环境调高 | 误判率与故障检测灵敏的滑杆 |
| `commitlog_sync_batch_window_in_ms` | group commit 窗口 | 延迟/吞吐的毫秒级谈判 |

注：表中 ⚠️=按 2.x 文档转述；参数在 3.x/4.x 大量改名或删除——迁移总账见 10.5 与演进节。

## 10.3 JVM 与 GC：书中时代的手艺（⚠️ 转述）

2.x 标配 CMS + 手工堆配方：`MAX_HEAP_SIZE`（"min(8G, ¼内存)"类经验 ⚠️）、
`HEAP_NEWSIZE`（young gen 与刷新风暴的关系）、`-XX:+UseParNewGC` 族、JNA/mmap 开关。
GC 日志阅读（`gc.log` 里 promotion failure/长 ST 与读超时的相关性）被书归入"每个 Cassandra
工程师的必修课"——该判断在 ZGC/G1 时代依然成立，工具换了（11 章）。

## 10.4 多 DC 与升级的运维剧本（⚠️）

- **DC 扩建剧本**：新 DC 先只加 1 个 `dc=...` 的低 RF 表试验，`ALTER KEYSPACE` 提 RF 触发
  流式复制（书中"逐步把 RF 拉到目标"的节奏）⚠️。
- **时钟纪律**：LWW 让时钟=裁决器（08 章），NTP 漂移会直接改写业务真相——书中把
  "跨 DC 时钟同步"列为不可妥协项 ⚠️。
- **滚动升级 2.1→2.2（书中剧本 ⚠️）**：`nodetool drain`→换包→改配置兼容→起；
  schema 变更后 `nodetool describecluster` 核对版本一致；sstable 格式升级用
  `nodetool upgradesstables` 收尾。**2.x 的"格式升级非即时"心智**（新书旧盘混跑窗口）
  是它与现代大版本升级的最大差异。
- **快照/备份**：`nodetool snapshot -cf 表名` 生成硬链接快照，配合 commitlog 归档
  （`commitlog_archiving.properties`，2.2 引入 ⚠️）做时点恢复；恢复=停库回灌目录+
  `sstableloader` 重放。当代工法的完整展开在 #89 册 [08-备份恢复与数据迁移](../Expert_Apache_Cassandra_Administration/08-备份恢复与数据迁移.md)。

## 10.5 配置→症状的反查表（排障入口，11 章互指）

- 读超时成片 → 压实限流过紧/key cache 关死/大分区（06 章漏斗）
- 写抖动规律性 → memtable 刷新风暴×压实并发不足×GC 三者同相位
- 修复后性能雪崩 → repair 并发+stream 线程挤占（07 章 streams 教训）
- 换机后数据"复活" → gc_grace 调小×未修复窗口（06 章警告的回声）
- 加节点反而变慢 → auto_bootstrap 误开/stream 失控（10.2 条目）

## 10.6 端口表与安全抽屉（书中 2.x 全景 ⚠️）

| 端口 | 用途 | 2.x 备注 |
|---|---|---|
| 7000 | 节点间 gossip/storage（SSL 版 7001） | 防火墙第一红线 |
| 7080–7081 | JMX（remote/local） | `cassandra-env.sh` 明文口令时代 ⚠️ |
| 9042 | CQL 原生协议 | 应用白名单只开它 |
| 9160 | thrift | 书内仍在；4.0 起永久关闭 ✅（NEWS） |

安全抽屉四件（配置名 ⚠️ 转述）：`authenticator=PasswordAuthenticator`（默认 AllowAll）、
`authorizer`/`role-management`（2.x 中期角色体系 ⚠️）、`client_encryption_options`
（服务端证书）、`server_encryption_options`（节点间可选互签）；书中判词：
"Cassandra 的安全是默认全开的门——先关角色再说性能"。RBAC 表权限粒度与
审计缺失（当时）是它被企业合规追问的两处软肋 ⚠️，2026 见演进节。

## 核心概念速览（中英对照）

- **cassandra.yaml** — 主配置：集群行为的声明式入口，七抽屉读法防迷路。
- **commitlog_sync** — 同步策略：periodic/group 两模式，毫秒级 durability 谈判。
- **drain** — nodetool drain：停客户端监听、冲 memtable 的优雅停机前戏。
- **upgradesstables** — 格式追平：把旧格式段重写为当前版格式的收尾动作。
- **auto_bootstrap** — 自动偷数据开关：2.x 著名事故源，恢复/换机场景必须关 ⚠️。
- **gc_grace_seconds** — GC 宽限：墓碑存活期=修复窗口保险。
- **index_interval** — 索引采样距：SSTable 稀疏索引粒度，内存换读放大。
- **phi_convict_threshold** — φ 定罪阈：故障探测灵敏度滑杆。
- **rackdc.properties** — DC/机架声明文件：NTS 的地理真相来源。
- **snapshot + hardlink** — 快照：几乎零成本的表时点副本，备份最小单元。
- **sstableloader** — 重灌工具：把 SSTable 当客户端写入重建拓扑。
- **concurrent_compactors** — 压实并行：CPU/IO 预算的分配阀。
- **client_encryption_options** — 客户端加密：9042 线 TLS 的证书抽屉。
- **guardrails（后代）** — 护栏：把本节"手调纪律"变集群级禁令的 4.x 机制 ✅。

## 最新演进与工业实践

（除注明外均本会话实抓 ✅）

- **参数体系换代**：5.0 新特性页明列 **"Liberating cassandra.yaml / Parameters' Names from
  Their Units"** 管理章（导航 ✅ 实抓于 latest/6.0 文档）——大量 2.x 参数改名/单位化/废弃；
  书内参数表整体作为"出身字典"保留。
- **GC 终局**：4.0 起 Java 11、5.0 起 **JDK 17**（✅ latest new 页），G1/ZGC 替 CMS；
  10.3 的堆配方手艺让位于"堆小+堆外"的现代取向（trie 结构，CEP-19/25 ✅ 链接取自官方页）。
- **压实自助**：UCS（CEP-26 ✅）让 `concurrent_compactors`/throughput 家族的重要性骤降；
  10.2 表中多数行转为历史。
- **备份现代化**：快照 + **对象存储快照/恢复自动化**（#89 册 08 章口径）与云厂商托管备份
  （IBM/DataStax 系 ⚠️ 转引 #89 册 00 生态行）；`commitlog_archiving` 之后 CDC 提供了
  更合身的"变更副本"路径（✅ https://cassandra.apache.org/doc/latest/cassandra/managing/operating/cdc.html ）。
- **工业实践**：配置漂移检测改走"虚表自证"（`SELECT * FROM system.settings` ⚠️ 版本点）+
  基础设施即代码；K8s operator 场景下 yaml 由模板渲染，10.5 反查表仍是诊断起点。
