## 核心概念速览（中英对照）

- **一维数组** — one-dimensional array（7.1）：同类型元素的连续存储 + 下标随机访问，长度编译期固定
- **数组退化** — array-to-pointer decay（7.1.4 机制层面）：数组传参实际传首元素指针，长度信息丢失
- **统计表征数** — statistical characterization（7.3）：均值/方差/标准差描述信号特征的术语族
- **选择排序** — selection sort（7.5.1）：每轮选最小值就位，O(n²)，教学首选的「能跑」排序
- **顺序/二分搜索** — sequential / binary search（7.5.2）：无序线性扫 vs 有序对半折
- **C 风格字符串** — C-style string（7.7）：`char[]` + `'\0'` 终止约定，`strlen/strcat/strcmp` 家族
- **string 类** — the string class（7.8）：`std::string` 值语义字符串，本章引入
- **vector 类** — the vector class（7.9）：`std::vector` 动态数组，本书用「容器三明治」（string/vector 会先用，第 9 章才讲它们的内存机制）

## 1. 动机：同型批量数据的第一个容器

语音采样、海浪高度、飓风风速——第 6 章之前的程序遇到「n 个同类数」只能复制粘贴变量名。数组一次性解决三件事：命名（`ws[i]`）、批量处理（循环套下标）、传递（传给统计/排序函数）。本章的应用密度是全书最高：飓风等级、语音信号、海啸预警、概率计算，四个案例把「数组+循环+函数」的组合拳打满。

## 2. 机制：数组的三副面孔与一条断层

**(a) 声明与初始化**：`double x[10];` / `double y[3] = {1,2,3};`——数组不能整体赋值、不能比较，这是它与「值类型」的第一道断层（直到 C++11 `std::array` / C++20 三路比较才修复）。

**(b) 函数参数的陷阱**（7.1.4）：`void f(double a[])` 里 `sizeof(a)` 是指针大小；所以本书所有数组函数都要**额外传长度 n**。「数组+长度」这个孪生参数对正是 C++20 `std::span` 要消灭的东西。

**(c) 排序与搜索的配对**（7.5）：选择排序 O(n²) 换来「原地、简单、比较次数可预期」；搜索侧给出关键权衡表——**无序→只能线性 O(n)；有序→二分 O(log n)，但要先付出排序成本**。7.5.3/7.5.4「无序列表 vs 有序列表」是数据结构「按访问模式选型」的第一课。

**(d) 字符串双轨制**（7.7–7.8）：C 风格字符串讲机制（`\0`、缓冲区溢出风险 `strcat`），随后 `std::string` 立即接管正确姿势；7.9 的 `vector` 同理。本书的教学策略是「先展示伤口，再递绷带」。

## 3. 权衡：为什么教学仍从裸数组开始

直接教 vector 更快，但会跳过三大底层直觉：连续内存、下标即指针算术（第 9 章回收）、长度是外置契约。裸数组的坑（越界无检查、退化丢长度、sizeof 谎话）恰好是 std::array/vector/span 动机的最佳广告。工程读者的正确读法：把 7.1 当「span 出现前的历史」，把 7.9 当真正的起点。

## 4. 🔧 自编译样例（已实测 g++ 15.2）

书式 C++98：手写选择排序 + 线性搜索 + C 字符串函数：

```cpp
// 编译：g++ -std=gnu++98 ch07_old.cpp
void selection_sort(double a[], int n);        // 每轮挑最小
int linear_search(double a[], int n, double key);
char buf[32] = "hurricane"; strcat(buf, "_watch");
```

实际输出：

```text
33 43 55 61 74 92 120 
search 120 -> index 6
hurricane_watch len=15 cmp=0
```

同一任务的 C++20 写法：`std::array` + `std::ranges::sort`（内省排序 O(n log n)）+ `lower_bound` 二分 + `std::string_view`：

```cpp
// 编译：g++ -std=gnu++20 ch07_modern.cpp
std::ranges::sort(ws);
auto it = std::ranges::lower_bound(ws, 120);      // 有序序列二分
std::string s = "hurricane" + "_watch"s;
std::string_view sv = s;
```

实际输出：

```text
33 43 55 61 74 92 120 
search 120 -> index 6
hurricane_watch len=15 eq=true
sum=45
```

对照要点：输出逐位一致，但复杂度从「排序 O(n²)+搜索 O(n)」变成「排序 O(n log n)+搜索 O(log n)」——数据上万时这就是能跑与不能跑的分界；且 `strcat` 的 `buf[32]` 越界风险在 string 版里根本不存在。

## 5. 最新演进与工业实践

- **容器的现代选型**：定长 `std::array`、变长 `std::vector`（工程默认值语义序列）、非拥有视图 `std::span`（函数参数统一入口，C++20）；`vector<bool>` 位压缩特化是著名怪胎（代理引用、无法取 `&v[i]`），面试与生产都要当心。
- **排序的工业事实**：libstdc++ `std::sort` 为 introsort（快排+堆排+插值混合，最坏 O(n log n)）、`std::stable_sort` 归并、小数组插入排序；并行排序用 C++17 并行算法 `std::sort(std::execution::par, b, e)`（libstdc++ 需链接 oneTBB）或 TBB `parallel_sort`。
- **搜索**：`std::binary_search/lower_bound/upper_bound/equal_range` 是有序区间四件套；无序高频查找直接上 `std::unordered_map`（哈希）——本书「无序列表线性扫」在现代只出现在 ≤16 元素的小表或 SIMD 扫描（abseil 的 flat_hash_map/SimdScan）。
- **统计与信号**：`std::accumulate`/`std::inner_product` 能一行算均值方差；语音/海浪信号的生产分析走 FFT——Eigen、KissFFT、FFTW、pocketfft（NumPy 默认），本书 7.4 只到「均值/方差表征」的深度。
- **字符串现代化**：`string_view`（非拥有、可作参数）、C++20 `starts_with/ends_with/contains`、格式化统一进 `std::format`；C 风格字符串今天只出现在与 C API 边界，配 `zstring`（GSL）表意。
- **经典文献**：Introsort 由 Musser（1997，Science of Computer Programming，DOI 未逐条核实故不附）提出；abseil 容器文档 https://abseil.io/about/design/dictionarykeyhandle 是哈希工程化的现代读物（在线核实，2026）。

## 6. 相邻概念对比与易错点

- **数组 vs vector**：越界行为都是 UB，但 vector 有 `at()` 检查版、可增长、可拷贝比较；数组只在「长度是类型一部分」时有残存价值。
- **方差公式的两pass/一pass**：`Σ(x-μ)²` 需先知道 μ；一 pass 的 `Σx² - nμ²` 教科书常见但数值不稳定（大均值小方差时灾难性抵消）——Welford 算法（1962 技术报告，无 DOI）才是单遍正解，本书未提，属必补知识。
- **strcmp 返回值**：负/零/正三态，别当 bool 用；`strcoll`/ locale 语义差异在生产中常见。

## 7. 案例深潜：工程挑战「海啸预警系统」（7.6）与 7.4 语音信号

**海啸预警的算法管线**（本章知识点的总装）：

```
浮标时序数据 → [统计] 均值/标准差(7.3) → 基线建模
             → [排序/搜索] 阈值判定(7.5) → 有序告警表
             → [查找] 历史相似事件(7.5.2) → 决策支持
```

值得注意的机制细节：(a) 告警判定「超过均值+kσ」把 7.3 与 7.5 缝在一起——σ 是噪声的货币单位，这条工程启发式本书点到、现代信号检测（STA/LTA 算法）把它做成行业标准；(b) 有序数据一次排序后多次二分——「一次代价换千次便宜」的缓存/摊销直觉在此建立。

**语音信号分析（7.4）**：定长采样帧 + 均值/方差/过零率——「统计表征数」名称里的「表征」二字就是 ML 时代 feature 一词的教材形态。7.10 概率计算则把随机数（6.5）×数组×循环三件武器并到一个蒙特卡洛案例里。
