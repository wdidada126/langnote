## 核心概念速览（中英对照）

- **while 循环** — while loop（4.2.1）：入口判断，可能零次执行
- **do/while 循环** — do/while loop（4.2.2）：出口判断，至少执行一次
- **for 循环** — for loop（4.2.3）：初始化/条件/增量三段式的计数循环
- **计数器控制循环** — counter-controlled loop（4.5.1）：循环次数事先已知
- **标志控制循环** — flag-controlled loop（4.5.2）：用 bool 哨兵变量决定继续与否
- **数据终止循环** — data-terminated / sentinel loop（4.5.3）：以特殊值或输入流失败为终止条件
- **break / continue** —（4.4）：提前跳出/跳到下次迭代，本书用阈值场景教 break
- **迭代不变式直觉** — loop invariant intuition（4.1 算法设计隐含）：循环正确性推理的萌芽

## 1. 动机：重复计算是工程计算的母语

数值方法（求根、积分、迭代法解方程）全部长在三条循环上。本章用 GPS 定位迭代（4.3）和气象气球体积增长（4.6）说明：循环不是「语法」，而是「把收敛过程搬进机器」的机制。同时 4.5 把「循环怎么终止」升级为方法论：计数、标志、数据终止——分别对应「次数已知」「结果已知」「输入耗尽」三种工程语义。

## 2. 机制：三种循环 + 三种终止语义

**(a) 结构差异**：`for( init; cond; inc )` 与 `while` 表达力等价（`for` 不过是 while 的三段式封装），`do/while` 是唯一「至少一次」的结构。C++17 起 `for` 的 init 语句可声明变量（`for (int i = 0; ...)`），本书时代很多编译器还要退回 `for_init` 老扩展。

**(b) 终止语义**：
- 计数器控制：边界 off-by-one 是主要 bug 类（`<=` vs `<`）。
- 标志控制：现代观点是反模式——标志散落导致循环出口不唯一，应改写为 `while (!done)` 的直接条件或 `break`。
- 数据终止：`while (cin >> x)` 是本书最值钱的一行惯用法（5 章文件读循环沿用）：流的 bool 转换即 good() 检查。

**(c) break/continue**：break 用于阈值触发（4.3 GPS 星数够了就停）；continue 用于「坏数据跳过」——工程数据清洗场景（第 5 章数据过滤器）会大量复用。

## 3. 权衡：循环写法的成本曲线

- 手写索引循环 vs 范围 for（C++11）：只要「遍历整个序列」，range-for 消除一类 off-by-one 且表达意图；需要索引时用 `views::iota`（C++20）或老实写 for。
- do/while 的现代地位：C++20 Ranges 的 `take_while`、协程循环等替代下，do/while 只剩「菜单重显」「至少重试一次」的窄场景；注意它的条件末尾分号是新手陷阱。
- 循环不变式的维护：本书 4.1 的伪代码方法在嵌套循环+多出口时迅速失控——这是第 6 章「函数化拆分」的动机。

## 4. 🔧 自编译样例（已实测 g++ 15.2）

书式 C++98：do/while（气球体积超 100 m³ 停止）+ for/break（阈值终止）+ 标志循环：

```cpp
// 编译：g++ -std=gnu++98 ch04_old.cpp
double r = 0.0, vol = 0.0;
do {
    r += 0.5;
    vol = 4.0 / 3.0 * PI * r * r * r;
    cout << "r=" << r << " V=" << vol << endl;
} while (vol < 100.0);
```

实际输出（节选）：

```text
r=0.500 V=0.524
r=1.000 V=4.189
r=1.500 V=14.137
r=2.000 V=33.510
r=2.500 V=65.450
r=3.000 V=113.097
sat-loop stopped at n=31 total=80544.904
flag loop ended k=3
```

同一问题的 C++20 写法：`std::views::iota` 生成无限序列 + `std::numbers::pi` + `std::accumulate`：

```cpp
// 编译：g++ -std=gnu++20 ch04_modern.cpp
for (int i : std::views::iota(1, 7)) {
    double r = 0.5 * i;
    double vol = 4.0/3.0 * std::numbers::pi * r*r*r;
    std::cout << std::format("r={:.1f} V={:.3f}\n", r, vol);
    if (vol >= 100.0) break;
}
```

实际输出（与 98 版逐行等价，格式更干净）：

```text
r=0.5 V=0.524
r=1.0 V=4.189
r=1.5 V=14.137
r=2.0 V=33.510
r=2.5 V=65.450
r=3.0 V=113.097
accumulate=15
```

## 5. 最新演进与工业实践

- **C++11 range-for**：`for (auto& x : data)` 是本书所有遍历样例的直接替代；C++20 range-for 可带初始化（`for (auto i = 0; int x : xs)`）。
- **C++20 Ranges**：`views::iota/take_while/transform` 把「循环」变成「序列管道」，声明式、可组合、可延迟求值——与 NumPy 的向量化写法在风格上收敛。
- **std::execution / TBB**：计数循环在生产里常直接并行化——`std::for_each(std::execution::par, ...)`（C++17 并行算法，MSVC/GCC libstdc++-12+/oneAPI TBB）或 Intel oneTBB `parallel_for`；气象/网格类应用（第 8 章地形数据的后代）几乎必然向量化+多线程。
- **OpenMP**：科研计算圈事实标准，`#pragma omp parallel for` 一行改造本书式循环；gcc 自带 `-fopenmp`。
- **rand 的终止条件质量**：4.5.2 标志循环常配 `rand()` 生成试验数据——现代实践统一改用 `<random>`（见 [06 章](06-使用函数进行模块化编程.md)的现代样例）。
- 经典文献线索：Dijkstra 论循环推导（*A Discipline of Programming*, 1976，书籍无 DOI）是 4.1「算法设计」的严肃版；本书止步于直觉，建议工程读者至少掌握「不变式+终止函数」两件套来审计任何 while 循环。

## 6. 相邻概念对比与易错点

- **do/while vs while**：「至少一次」的语义在 I/O 重试、交互式菜单场景才有价值；滥用 do/while 会让「循环体执行次数」推理复杂化。
- **`while (cin >> x)` vs `while (!cin.eof())`**：后者是教科书级错误——eofbit 只在读取失败**之后**置位，会多处理一次旧值（本书 5.2.3 正确选择了前者，值得强调；本笔记实测：ch05_old 中成功读到最后一条记录时 eof() 仍为 no，即 eofbit 滞后性的直接证据）。
- **float 累加的循环顺序敏感性**：`total += 20000.0/i` 从大到小累加与反向累加结果不同；工程循环累加大量浮点数时考虑 Kahan 补偿求和或 `std::reduce(std::execution::par_unseq, ...)` 的分段求和。

## 7. 案例深潜：工程挑战「数据收集」与 4.3 GPS、4.6 气象气球

**GPS（4.3）的机制**：卫星信号按仰角/信噪比排序接收，「收满 N 颗或信噪比达标即停」——本笔记 ch04 样例把它压缩成「累加超阈值 break」的骨架。教学核心是**提前终止的循环出口纪律**：break 点要能一句话说清终止条件。

**气象气球（4.6）**：半径每步 +0.5 m 求体积表——do/while 的正当场景（第一步就要输出）。实测输出给出完整表：r=0.5→V=0.524 直到 r=3.0→113.097 越阈值停止；顺便可验证「体积随 r³ 增长」的步长非线性——这就是「循环 + 公式」合成一张数据表的工程原型（MATLAB/NumPy 的 `linspace` 干同一件事）。

**数据收集（工挑）**：三章合一的枢纽案例——循环（4）+ 文件（5）+ 数组（7）的雏形。标准流程：`while (cin >> t >> p) { 合法性检查; 存数组/求和; }`，坏值 `continue` 丢弃并计数——5.4 数据过滤器就是它的文件版放大。
