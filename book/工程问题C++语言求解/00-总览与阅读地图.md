## 3. 阅读路线

- **快线（3–4 天）**：01 → 02 → 03 → 04 → 07 → 09。适合已有其他语言基础、目标是读懂工程遗留 C++ 代码的读者。
- **数值方法线（本书的隐藏金线）**：3.5 线性插值 → 5.6 线性建模 → 6.9 多项式根（增量搜索）→ 6.11 积分 → 7.3 统计表征 → 8.5 高斯消元 → 每节配「现代演进」小节，对照 Eigen/SciPy/GSL 的实现与误差控制。适合想做仿真/信号处理的读者。
- **数据结构线**：7.5 排序搜索 → 9.7 链表/栈/队列 → 9.8 STL → 10.4.3 BinaryTree → 转读 [../STL源码剖析/](../STL源码剖析/) 与 [../C++标准库/](../C++标准库/)。
- **OOP 进阶线**：2.3 类 → 6.7 类方法 → 10.2 数据抽象 → 10.5–10.7 → 转读 [../深度探索C++对象模型/](../深度探索C++对象模型/)。
- 各章固定结构：核心概念速览（中英对照）→ 正文（动机→机制→权衡）→ 🔧 实测样例（旧式 vs 现代式）→ 最新演进与工业实践 → 易错点 → 延伸阅读。

## 4. 语言基线与「现代读法」（2011/2014 → 2026）

本书代码基线是 **ANSI C++/C++98**（实测用 `-std=gnu++98` 全部可编译），没有它自己的 C++11 之后任何特性：无 `auto`、范围 for、智能指针、移动语义、`std::array/string_view/span/format`。因此：

1. **语法部分降级为史料**：第 2–9 章的「怎么写」照抄即过时，「为什么需要那种写法」仍成立——每章「最新演进」节已给出同题的现代解。
2. **方法论部分仍是资产**：五步法、数据组织选型、数值方法小专栏、每章工程挑战的问题分解，均不随标准版本贬值。
3. **现代补读三件套**：《C++ Primer 第 5 版》（语言全貌，本库对应 [../cppprime.md](../cppprime.md) 习题笔记）→ Effective Modern C++（[../Effective_Modern_C++.md](../Effective_Modern_C++.md)）→ 现代C++实战30讲（[../现代C++实战30讲/00-总览与阅读地图.md](../现代C++实战30讲/00-总览与阅读地图.md)）。
4. 工具链实测基线：MinGW-Builds **g++ 15.2**（x86_64-win32-seh）。注：该构建上 `std::print` 链接失败（运行时库缺 `std::__open_terminal` 符号），现代样例统一用 `std::cout << std::format(...)` 替代——见 05 章踩坑记录。

## 5. 辨析：是不是同一本书？跟谁比？

### 5.1 与 *C++ for Engineers and Scientists*（总索引误记之源）

同作者（Etter，后版合著 Ingber）、同出版社（Pearson/Addison-Wesley 系）、近名——极易混淆，但**是两本书**：

| 维度 | Engineering Problem Solving with C++（本书底本） | C++ for Engineers and Scientists |
|---|---|---|
| 本书中译目录证据 | 10 章制，第 10 章「高级主题」收口泛型/继承 | 未持有任何一手目录证据可比对 |
| 案例族 | 汽车性能、全球变化、GPS、气象气球、臭氧、海啸预警、地形导航、天气模式、AI/囚徒困境（全部经豆瓣目录核实） | 任务线索所称「声呐（sonar）case study」**未出现**在本书核实目录的任何章首工程挑战/应用问题中——这是「两本书」判定的有力旁证 |
| 中译 | 机工 2014，冯力/周凯，ISBN 9787111459071 | 中译情况 ⚠️ 未核实 |

### 5.2 与 C++ Primer（第 5 版）

- 体量与野心：Primer ~1000 页讲**语言与库的每一个构件**；本书 608 页只讲「够解工程题」的子集，类/模板/继承压到一章。
- 习题取向：Primer 练习面向语言机制；本书面向数值/数据应用（每章「解决应用问题」）。
- 本库无 `C++Primer中文第5版.md`（已 Glob 确认不存在），对应条目是 [../cppprime.md](../cppprime.md)（习题答案笔记）。
- 读序建议：本书先读（快速获得完整问题闭环），Primer 后读（把没讲透的补透）。

### 5.3 与 《现代C++实战30讲》（吴咏炜）

| | 本书 | 现代C++实战30讲 |
|---|---|---|
| 时代 | C++98 教学基线（2011/2014） | C++11/14/17/20 工程实践（2024 书版） |
| 深度轴 | 问题求解流程 + 初级数值方法 | 语言机制 + 库与工具链现代化 |
| 重叠区 | 第 9 章指针/第 10 章类机制 | 第 1–3 讲 RAII/智能指针/移动语义 |

两书正好互补成「旧新对照」：本笔记各章「最新演进」节承担的桥接工作，可直接与 [../现代C++实战30讲/01-堆栈与RAII.md](../现代C++实战30讲/01-堆栈与RAII.md) 等互跳。

### 5.4 与姊妹书《工程问题C语言求解》

同作者体系、同丛书、同「五步法」骨架，只是语言换成 C（本库另有其笔记线索见总索引书目表；注意其「原书第 4 版」中译 ISBN 9787111554417 与本书无关，OPAC 检索时勿混）。
