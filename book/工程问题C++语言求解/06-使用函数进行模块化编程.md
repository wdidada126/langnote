## 核心概念速览（中英对照）

- **模块化** — modularity（6.1）：把程序切成可独立理解/测试/复用的函数单元
- **函数原型** — function prototype（6.2.2）：声明签名先于定义，支持分离编译与前向引用
- **值传递** — pass by value（6.3.1）：形参是实参副本，函数内修改不影响调用方
- **引用传递** — pass by reference（6.3.2）：`T&` 形参绑定实参本体，可作输入输出参数
- **存储类型** — storage class（6.3.3）：`auto/static/extern`（本书时代无 thread_local/mutable 讨论）
- **作用域 / 生存期** — scope / lifetime（6.3.3）：名字可见性 vs 对象存在期，两维正交
- **公共接口 / 访问器 / 修改器** — public interface / accessor / mutator（6.7）：类的「读方法 getX / 写方法 setX」纪律
- **增量搜索法** — incremental search（6.9.2）：沿 x 步进找符号变化定位多项式根，中值定理的工程化
- **数值积分** — numerical integration（6.11）：矩形/梯形法求定积分，本书用循环+函数调用组织

## 1. 动机：从「一段脚本」到「可维护的求解器」

第 5 章结束时的程序已经是多屏长文。本章引入函数与类方法两个封装单位，同时把**参数传递语义**作为核心知识点——工程程序员最常见的正确性事故（以为改了其实没改、以为没改其实改了）全部出在 6.3。

## 2. 机制：签名的三个自由度

函数签名 = 返回类型 × 参数类型 × 传递方式。本章建立的规则表：

| 意图 | 本书写法 | 机制要点 |
|---|---|---|
| 只读入参（标量） | `T x` 值传递 | 拷贝便宜 |
| 只读入参（大对象） | `const T& x` | 零拷贝 + 编译期防误改 |
| 输出结果 | 返回值（首选）或 `T&` 出参 | 本书大量使用出参（如 stats 例），是 C++98 时代风格 |
| 类内状态访问 | `get_x()/set_x()` | 接口面受控（6.7.2/6.7.2） |

**随机数（6.5）**：`srand(seed); rand()%6+1` 讲整数序列；`(double)rand()/RAND_MAX*(hi-lo)+lo` 讲浮点序列。机制上 `rand()` 是 C 遗留，质量（低位周期、线性同余）与线程安全都不合格。

**数值方法支线（6.9/6.11）**：增量搜索找根依赖「连续函数区间端点异号必有根」（中值定理）；矩形/梯形积分把 4.2 的循环升级为「可收敛的算法」——引入步数 n 与误差的权衡直觉。

## 3. 权衡：出参 vs 返回值 vs 全局状态

- 本书统计函数用 `void stats(double mean, double& sd)` 双出参——C++98 没有 tuple 时合理。
- 现代首选**返回结构体/元组**：`auto [mean, sd] = stats(data);`（C++17 结构化绑定），移动语义让返回大对象不再贵（RVO/NRVO 在 11 后是标准保证的 copy elision）。
- `static` 局部变量：本书用来演示生存期；多线程下它变线程安全的 magic static（C++11），但也提醒你这行代码有隐藏状态。
- 全局变量 + extern：6.3.3 讲其存在，工程准则（C++ Core Guidelines ES.5）明确应避免。

## 4. 🔧 自编译样例（已实测 g++ 15.2）

书式 C++98：原型 + 出参统计 + 手写中点积分 + rand：

```cpp
// 编译：g++ -std=gnu++98 ch06_old.cpp
void stats(double a[], int n, double& mean, double& sd);   // 引用传出结果
double integrate_midpoint(double lo, double hi, int steps); // 被积函数硬编码 x^2
srand((unsigned)time(0));
```

实际输出：

```text
mean=2.9167 sd=0.8085
integrate x^2 on [0,1] ~ 0.3333 (exact 0.3333)
3 rolls: 4 1 4
```

（骰子行依赖时间种子，每次运行不同；统计与积分行是确定性的。现代版同理：`3 rolls: 1 6 3`——若把 `random_device` 换成固定 seed，两版才可逐位复现，这正是「可复现仿真」的要点。）

同一组函数的 C++20 写法：`concepts` 约束的 `std::span` 算法 + 函数对象参数 + 现代随机数引擎：

```cpp
// 编译：g++ -std=gnu++20 ch06_modern.cpp
template<std::floating_point T> T mean_of(std::span<const T> v);
template<std::invocable<double> F, std::floating_point T>
T integrate_midpoint(F&& f, T lo, T hi, int steps);   // 被积函数参数化
std::mt19937 rng{std::random_device{}()};
std::uniform_int_distribution<int> die(1, 6);
```

实际输出：

```text
mean=2.9167 sd=0.8085
integrate x^2 on [0,1] ~ 0.333333
3 rolls: 1 6 3
pi=3.1415926536
```

两版对照的三个升级点：(a) `span` 消灭「数组+长度」双参数对（ch7 还要用）；(b) 概念约束让「传错类型」在模板实例化第一行报错，而不是深埋在 stl 内部；(c) 积分函数从「只能算 x²」变成可注入任意可调用对象——复用度质变。

## 5. 最新演进与工业实践

- **传参的现代决策表**（EMC Item 41 + Core Guidelines F 系列）：小对象按值；只读大对象 `const T&` 或 `std::string_view`/`std::span`（C++17/20，语义优于 const 引用且能表达「非拥有+连续存储」）；需要保存就按值 + `std::move`（sink 参数）。
- **concepts（C++20）**：`std::floating_point`、`std::invocable` 等标准概念让数值算法的接口第一次可以**写进类型**；自定义数值算法（如本书的插值/求根）现代写法一律加约束，报错质量与文档价值双赢。
- **<random>（C++11）**：`seed_seq`、`uniform_real_distribution`、引擎可序列化——蒙特卡洛仿真（本书 6.6 仪器可靠性、ch10 囚徒困境的现代版）的可复现性靠它；`rand()` 在 MSVC 外的实现质量参差是共识，工程评审应直接禁用。
- **确定性测试**：现代数值库为求根/积分提供黄金值回归（golden test）；GoogleTest + 固定 seed 是本书「测试第 5 步」的工业落地。
- **生态**：SciPy `integrate.quad`（自适应 Gauss-Kronrod，碾压本书定步长矩形法）、根查找的 Brent 算法（ GSL `gsl_roots`、Boost.Numerics、`std` 暂无内置）、Eigen 提供 SVD/特征值——读本书数值小节时应同时知道工业级替代是什么、强在哪（自适应误差控制）。
- **头文件纪律**：6.3.3 的声明/定义分离今天对应「头文件只放声明 + include-what-you-use + 模块（C++20 modules）」的演进线，大规模工程视角见 [../大规模c++程序设计.md](../大规模c++程序设计.md) 所在系列。

## 6. 相邻概念对比与易错点

- **函数重载 vs 默认参数**：`f(int)` 与 `f(int,int)` 可互相屏蔽意图，重载决议的歧义坑多；现代倾向默认参数或两个语义清晰的不同名。
- **引用不是「安全指针」**：返回局部变量的引用、把临时量绑进非 const 引用（扩展生命周期陷阱）都会越界；C++ Core Guidelines RF 系列是本章的现代补丁。
- **增量搜索 vs Newton 法**：前者稳健（只需连续）但慢，后者快但需导数与好初值；工程实践用「先粗搜定位再精化」的两段策略——本书 6.9 只给了第一段。

## 7. 案例深潜：工程挑战「仿真」与 6.4/6.6/6.9/6.11 四连

- **6.4 重心（质心）**：`xc = Σ(mᵢxᵢ)/Σmᵢ`——第一次出现「对数组式数据的聚合函数」，函数签名天然是 `centroid(const double m[], const double x[], int n)`：三参数一对数组，正是 `span` 教学动机的原型。
- **6.5–6.6 仪器可靠性**：用随机数模拟仪器寿命/失效率，统计「多少次试验里系统在 T 小时内未失效」——**蒙特卡洛四要素**齐活：随机源、重复循环、计数判定、频率→概率。本书只给 `rand()` 版；本笔记 ch06_modern 给出 `mt19937 + uniform_int_distribution` 的等价替换，两版输出结构完全一致。
- **6.9 多项式求根（增量搜索）**：`for x: 步进; if f(x)*f(x-h) < 0 定位区间`——「函数抽象让算法可组合」的第一课：被搜索的 f 与搜索策略天然分离（书里仍是硬编码多项式，本笔记 ch06_modern 把它改成了可注入的函数对象）。
- **6.11 积分**：矩形/梯形 + 步数 n 可控——与 6.9 合成「数值方法=循环×函数调用」的总纲。

**仿真（工挑）** 的读法：它是 10.8 囚徒困境仿真的前身，也是全书「第 5 步测试」的终极形态——用概率方法验证确定性代码（对拍）的思想起点。
