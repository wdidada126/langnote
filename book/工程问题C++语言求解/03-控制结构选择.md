## 核心概念速览（中英对照）

- **结构化编程** — structured programming（3.2）：仅用顺序/选择/循环三种控制结构组织程序的理论（Bohm–Jacopini 定理为其根基）
- **条件表达式** — conditional expression（3.3）：关系与逻辑运算结果为 bool 的表达式
- **短路求值** — short-circuit evaluation：`&&`/`||` 左侧定局则右侧不求值（书中隐含于逻辑操作符节）
- **if/else 语句** — if/else statement（3.4.2）：二分支选择；悬挂 else 问题由「配对到最近未配对 if」规则解决
- **switch 语句** — switch statement（3.7）：整型值的离散分支；`break` 缺失导致贯穿（fall through）
- **线性插值** — linear interpolation（3.5）：两已知点间按直线估计函数值，全书第一个「数值方法」专栏
- **为自定义类型定义操作符** — overloading operators for user-defined types（3.9）：本书第一次触碰操作符重载（第 10.2.3 节再深入）

## 1. 动机：让程序「看情况办事」

第 2 章的程序是无分支的直线。工程数据一旦有阈值（风速等级、冰点、告警线），就必须引入选择。本章同时承担第二个任务：把**算法设计**（3.1 伪代码 → 流程图 → 代码）作为正式方法引入——这是全书方法论密度最高的一章。

## 2. 机制：三层递进

**(a) 条件表达式**：关系操作符产出 bool，逻辑操作符组合 bool。机制要点是求值顺序与短路：`s != 0 && t/s > 1` 里除零被左侧挡住——本书把它当防御式编程技巧讲。

**(b) if/else 结构**：嵌套与「悬挂 else」由语法规则（else 与最近的未配对 if 结合）而非缩进决定；C++ 特有的坑是 `if (x = 0)`（赋值误作比较），现代对策：`if (const auto v = f(); v)`（C++17 带初始化语句的 if）或「yoda condition」+ `-Wall` 的 `-Wparentheses`。

**(c) switch**：只接受整型/枚举条件；`case` 是标签不是块，忘 `break` 就贯穿。书中把 fall through 当作可选技巧讲——今天这属于事故源，**必须**用 `[[fallthrough]];` 显式声明（C++17），clang-tidy 有 `bugprone-implicit-widening-of-multiplication-result` 等姊妹检查管这类事。

**数值方法·线性插值（3.5）**：`y = y0 + (x-x0)*(y1-y0)/(x1-x0)`，用 3.6 海水冰点（盐度 0→0°C、35ppt→约 -1.91°C 的两点线性模型）落地。机制简单，但它是后续 5.6 线性建模、6.9 多项式求根、6.11 积分这条「数值方法支线」的第一级台阶。

## 3. 权衡：if 链 vs switch vs 表驱动

- 分支少且是区间判断：if/else 链（本书主流）。
- 分支多是离散整型值：switch 可读性最好，编译器还能生成跳转表。
- 分支会增长/需要数据配置：表驱动（数组/`std::map` 存阈值→等级），第 7 章飓风等级（7.2）其实就是把本章 if 链升级成表。工程上「阈值超过 3 个就该表化」是本书没讲透的经验。

## 4. 🔧 自编译样例（已实测 g++ 15.2）

书式 C++98：线性插值 + 一个**故意贯穿**的 switch（经典事故复现）：

```cpp
// 编译：g++ -std=gnu++98 ch03_old.cpp
switch (band) {
    case 0:  msg = "fresh";      break;
    case 1:  msg = "brackish";
    case 2:  msg = "marine";     break;   // band 1 意外得到 "marine"
    default: msg = "unknown";
}
```

实际输出（salinity=20 的冰点 -1.0914°C；band 1 被贯穿成 marine）：

```text
salinity=20.0000 freezing=-1.0914 C
band 1 => marine
```

同一算法的 C++20 写法：`[[fallthrough]]` 显式化 + 标准库直接提供插值与「防溢出中点」：

```cpp
// 编译：g++ -std=gnu++20 ch03_modern.cpp
case 1:  [[fallthrough]];                 // C++17：贯穿必须声明
case 2:  return "marine";
...
std::cout << std::format("std::lerp = {:.4f} C\n", std::lerp(0.0, -1.91, 20.0 / 35.0));
```

实际输出：

```text
salinity=20 freezing=-1.0914 C
band 1 => marine
midpoint(1.0, 3.0) = 2
std::lerp = -1.0914 C
```

要点：本书 3.5 的整个小节在 C++20 后可以用 `std::lerp(a, b, t)` 一行替代（`<cmath>`）；`std::midpoint` 则解决了 `(a+b)/2` 的加法溢出问题——数值素养正是本书「最新演进」层最好的注脚。

## 5. 最新演进与工业实践

- **语言面**：C++17 带初始化语句的 `if`、`[[fallthrough]]`、`if constexpr`（编译期分支，模板元编程基石，本书无对应）；C++20 `<=>` 三路比较把「关系操作符六件套」压缩成一个运算符（P0515，DOI 未经核实不附）；C++23 无新控制结构，但 `std::expected` 让「判断后走错误分支」成为类型系统一等公民。
- **工具面**：`-Wimplicit-fallthrough`（GCC 7+）默认在 `-Wall` 外可选开启；clang-tidy `bugprone-*` 系列覆盖悬挂 else、空分支等本章全部经典坑。
- **数值方法面**：线性插值的现代生产级替代是分段插值/样条——SciPy `interp1d/make_interp_spline`、Eigen 无内置插值但有 `Unsupported/Eigen/Splines`；量纲检查可用 LLVM 的 units 库或 `std::chrono` 式的强类型单位库（nholthaus/units）。
- **论文线索**：结构化编程的理论根基是 C. Bohm & G. Jacopini, *Flow Diagrams, Turing Machines and Languages with Only Two Formation Rules*, Communications of the ACM, 9(5), 1966（DOI 未经 ACM DL 核实，故不附）；Dijkstra 1968 年致 ACM 的信 *Go To Statement Considered Harmful* 是「少用 goto/多用车同构结构」叙事的出处（ACM Commun. 11(3), 1968，同样未附 DOI）。本书 3.2 正是这两条历史线的教材化产物。

## 6. 相邻概念对比与易错点

- **浮点比较**：`if (x1 == x0)`（本书 ch03 样例为教学故意使用）在生产代码里是错的，应用 `fabs(a-b) < eps`（绝对容差）或 `std::abs(a-b) <= eps*max(|a|,|b|)`（相对容差，即 `std::numbers::epsilon` 的正确姿势）。
- **bool 转换**：`if (ptr)` 合法且惯用；`if (x = 1)` 合法但错误——语言不救你，工具救你。
- **线性插值 vs 最近邻**：插值假设两点间物理量线性变化，对不连续现象（相变！恰是 3.6 海水冰点的物理背景）要在文档里写明模型边界。

## 7. 案例深潜：工程挑战「全球变化」与 3.6 海水的冰点

**海水冰点（3.6）的完整拆解**（五步法示范）：

1. 问题：已知盐度求冰点——物理模型是「盐度升高、冰点下降」的单调关系；
2. I/O：输入盐度 s（ppt），输出冰点 tf（°C）；
3. 公式：两点线性模型 `s=0→0°C, s=35→-1.91°C`，即 3.5 的插值公式特例；
4. 算法：`if (s < 0 || s > 40) 报告越界; else tf = lerp(...)`——选择语句承担**模型定义域守卫**，这是「控制结构服务数值方法」的第一个样本；
5. 测试：s=0、35 端点精确值 + s=20 手算 -1.0914 对照（即本笔记实测输出）。

**全球变化（工挑）**：把同一骨架换成 CO₂ 浓度—温度异常的观测数据表，插值→外推的诱惑正是要讨论的坑——线性模型在区间外无效（书 5.6 线性建模会再收一次这个话头）。

**3.9 为自定义类型定义操作符**：本章第一次让读者给类写 `==/+`，为 10.2 的 Pixel 与 5.1 的流层次理解做铺垫——读时别当旁支。
