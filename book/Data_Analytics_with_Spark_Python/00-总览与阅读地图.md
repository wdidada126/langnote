  E6 抽样误差 1.80% + 广播式 merge。**全部标注「非本书 Spark 引擎行为」**，仅作概念锚定。

   目标是把「RDD 心智模型」立起来——这是全书其余四章的地基。

3. **断面周（Ch7–Ch8 文件）**：07 只精读 Structured Streaming 半章（DStream 半章作技术史读），
   08 只精读 ML 半章（R 节作历史读）；结尾用 §4 谱系表决定下一本读 #215 TDG 还是流批三册。
4. 全程提示：本册出版于 2018 年，任何「动手命令/连接器坐标/版本参数」执行前先查现行官方文档，
   负结果渠道清单见 §2——这正是目录版笔记相较原书的增值面。

   每章文末两节（概念速览+演进）建议在读后各复述一遍再离开该文件。
6. 反向建议：若你只关心 2026 年可动手的技能，请优先读波6在盘的 #215 TDG 目录版，本册作为
