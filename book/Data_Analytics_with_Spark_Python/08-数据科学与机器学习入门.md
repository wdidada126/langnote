示意（Spark 2.x ⚠️ 未实测，本机 pyspark 不可装——沿用波6 结论）：

```python
from pyspark.ml import Pipeline
from pyspark.ml.feature import StringIndexer, VectorAssembler
from pyspark.ml.classification import LogisticRegression
pipe = Pipeline(stages=[
    StringIndexer(inputCol="category", outputCol="cat_idx"),
    VectorAssembler(inputCols=["cat_idx", "amount"], outputCol="features"),
    LogisticRegression(maxIter=20)])
model = pipe.fit(train_df)
```

## 核心概念速览（中英对照）

- **SparkR** — SparkR：R 语言到 Spark 集群的镜像接口包，DataFrame-only 的老双栈桥。
- **RStudio** — RStudio：R 的集成工作台，书中练习的宿主 IDE（p.257）。
- **MLlib** — MLlib：RDD-based 的 Spark 机器学习算法库（旧 API 线）。
- **Spark ML** — Spark ML：DataFrame-based 的 Pipeline 化 ML API（现行主线）。
- **管道** — Pipeline：Estimator 序列组成的可持久化训练-变换流水线。
- **估计器/变换器** — Estimator/Transformer：能产出模型的阶段 / 只做确定性变换的阶段。
- **协同过滤/ALS** — Collaborative Filtering / Alternating Least Squares：矩阵分解推荐法，p.267 练习主角。
- **LDA** — Latent Dirichlet Allocation：主题模型，MLlib 无监督代表元（TOC 语境 ⚠️ 推定）。
- **特征装配** — VectorAssembler：把多列拼成算法输入的特征向量步骤。
- **交叉验证** — Cross Validation：k 折重训选参的通用评估回路，Primer 节收尾概念。
- **Jupyter** — Jupyter Notebook：浏览器内核式工作台，PySpark 数据科学交付面。
- **Zeppelin** — Apache Zeppelin：多解释器协作笔记本，YARN 时代企业选项。
