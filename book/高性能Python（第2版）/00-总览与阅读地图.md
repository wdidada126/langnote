# 高性能 Python（第2版）· 深度章节笔记

> 整理日期：2026-10-02，由 `book/高性能Python（第2版）.md`（大纲速查版）深度展开。
> 原书：*High Performance Python, 2e*（Micha Gorelick, Ian Ozsvald），O'Reilly，2020，468 页。
> 中文版：《高性能Python（第2版）》，人民邮电出版社，ISBN 9787115585776。
> 本书为「性能」主线核心。所有示例代码与结论已按 **Python 3.12–3.14** 校准；原书基于 Python 3.7/3.8 生态，涉及 GIL、并发、工具链之处已在各章「常见误区」与「版本演进」中显式更新。

## 一、阅读地图（章节 → 主题 → 结论）

| 章 | 标题 | 主题 | 一句话结论 |
|---|---|---|---|
| 01 | 理解高性能 Python | 计算机基础 / VM 抽象 | 先理解「理想计算」与「Python 虚拟机」的差距，再谈优化 |
| 02 | 性能分析定位瓶颈 | profiling | 不测不优化；cProfile / line_profiler / py-spy 三件套 |
| 03 | 列表与元组 | 数据结构 | list 是动态数组、tuple 是静态数组，选对容器省内存 |
| 04 | 字典与集合 | 数据结构 | 哈希表 + 保序（PEP 520），理解 resize 与熵 |
| 05 | 迭代器与生成器 | 惰性计算 | 生成器避免一次性物化，省内存、提吞吐 |
| 06 | 矩阵与向量计算 | 数值计算 | 上 NumPy；向量化 + 原地操作 + numexpr |
| 07 | 编译到 C | AOT/JIT/FFI | Cython / Numba / mypyc / cffi，按场景选编译器 |
| 08 | 异步 I/O | 并发 | asyncio + TaskGroup（PEP 654），I/O 密集型利器 |
| 09 | multiprocessing 模块 | 并发 | CPU 密集型绕开 GIL，多进程 + 队列 |
| 10 | 集群与任务队列 | 分布式 | 本地多进程 → 集群（Celery / Dask / Ray） |
| 11 | 使用更少内存 | 内存 | __slots__、array、memoryview、稀疏结构 |
| 12 | 实战经验 | 综合 | 来自业界的 war stories 与工程纪律 |

## 二、版本演进时间轴（本书基线 → 2026 校准）

- 本书基线：Python 3.7/3.8（2020 出版）。
- 关键更新点（逐章落地）：
  - GIL / free-threading：PEP 703（no-GIL 构建）于 3.13 实验性（3.13t）、3.14 默认实验通道——见 [concepts/GIL与free-threading.md](concepts/GIL与free-threading.md)。
  - dict/set 插入保序：PEP 520（3.7 已保序，原书仍当「未定义」讲，需修正）。
  - 异步：`asyncio.TaskGroup` + `ExceptionGroup`（PEP 654，3.11）、`asyncio.Runner`、anyio 生态。
  - 编译：Numba 0.6x、mypyc（Mypy 自带 AOT）、Cython 3.x、PyPy 3.10+。
  - 工具链：除原书 py-spy / line_profiler / memory_profiler，新增 Scalene、viztracer、perfetto。

## 四、缺失补丁 / 已知需修正项（🔧）

- 原书第 9 章默认「多进程永远快于多线程」——在 free-threading（3.13t/3.14t）下该结论需重新审视，见 [concepts/GIL与free-threading.md](concepts/GIL与free-threading.md)。
- 原书第 7 章对 PyPy 的描述沿用旧版；2026 年 PyPy 已支持 3.10 语法，且仍带 GIL，须校正。
- 原书第 2 章工具链未含 Scalene / viztracer，已在 [concepts/性能剖析工具链.md](concepts/性能剖析工具链.md) 补充。

## 五、工具链速查
