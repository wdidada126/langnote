# 深入理解LLVM：代码生成

作者: 彭成寒 / 李灵 / 戴贤泽 / 王志磊 / 俞佳嘉
出版社: 机械工业出版社
出版年: 2024-9
页数: 432
定价: 109
装帧: 精装
ISBN: 9787111764151

这本书以LLVM 15为基线介绍后段代码生成的全过程。详细介绍了指令选择、指令调度、寄存器分配和后段由哈的部分内容。
在介绍指令选择时，介绍了Fast、DAG、Global相关的原理，还通过示例一步一步演示指令选择的过程。
在介绍指令调度时，介绍了LLVM中涉及到的近十种调度实现，并通过示例介绍。
在介绍寄存器分配时，介绍了basic、fast、greedy、pbqp四种分配算法，同时也通过示例演示寄存器分配的过程。
这本书是近些年来最详细、最准确的关于编译器原理和实现的图书。
