同库已登记 [../C++新经典_设计模式.md](../C++新经典_设计模式.md)（单文件；总索引核实：ISBN 9787302601982，

## 三条阅读主线

1. **一个对象的诞生线（空间）**：`02` → `05` → `06` → `08`。
   空类占 1 字节 → 数据成员绑定/对齐 → 继承把子对象拼进更大布局 → 构造把布局「激活」。
2. **一次虚调用的旅程（时间）**：`03` → `04` → `07`。
   vptr/vtable 取槽 → 多继承的偏移调整与第二 vptr → 静态/动态绑定分岔与 RTTI 兜底。
3. **编译期那一半（模板）**：`09`，再跳 `10` 看它与现代 C++（concepts/modules/CTAD）的接缝。

**最短路径**：`03` → `05` → `08`（面试与排障最高频的三块）。
**已读 Lippman 者**：直接 `10` 篇，按对照表挑本目录的增量读。

## 本书定位：为什么读、怎么读

本书是「用 Visual Studio 调试器看见 C++ 幕后」的中文教材：篇幅精瘦（约 250 页）、例子直白，
定位介于《C++ Primer》与 Lippman《深度探索 C++ 对象模型》之间——侯捷译 Lippman 用的是
旧 Itanium 语境与深术语，本书则用 MSVC x64 + 内存窗口把同一批机制「降门槛」讲一遍。
它的**滞后点**在：只覆盖 C++98/11 时代的对象模型口径，MSVC 视角为主，对 Itanium ABI（thunk、
vbase offset、weak symbol）与 C++17/20 的语言层变化（保证拷贝消除、[[no_unique_address]]、
concepts、extern template 工程实践）基本未展开——这正是本目录每章 `## 最新演进与工业实践`
的补位空间。教材→专著的跳转梯度统一收在 `10` 篇。

## 读完应该能回答的十个问题

1. 一个带虚函数的空派生类，`sizeof` 是多少？vptr 住在对象的哪个偏移？（02、03）
2. 为什么 `mov (%rax),%rax; call *%rdx` 两行指令就是「多态」的机器真相？（03）
3. 把 `Derived*` 转成第二基类 `S2*`，指针值发生了什么？为什么需要 thunk/调整？（04）
4. `struct A{char;int;char}` 为什么是 12 字节？重排声明序能省什么？（05）
5. 虚基类 B 在菱形里为什么「只有一个」？谁负责构造它？访问它为什么多一次间接？（06）
6. 构造期间虚调用为何「降格」到基类版本？ typeid(*this) 在构造里打印的是什么？（07、08）
7. `final`/整程序可见如何让 `call *%rdx` 变成 `mov $0x2a,%eax`？（03、07）
8. 全局对象、函数局部静态、栈对象三者的构造/析构时点与顺序？（08）
9. `extern template` 让 `nm` 输出从 `T` 变 `U`，它省掉了什么、赌上了什么？（09）
