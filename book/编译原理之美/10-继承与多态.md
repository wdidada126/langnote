# 第 10 章 继承和多态：面向对象运行期的动态特性（讲 13）

> **一句话**：继承解决「类型之间的复用」，多态解决「同一个名字在运行时该跳哪段代码」；后者把一部分决策从**编译期推迟到运行期**，这就是「运行期动态特性」的全部含义。

## 核心精讲

### 10.1 继承的形式

```java
// 教学示意：本课小语言的继承语法（不参与构建）
class Animal {
    string name;
    void speak() { print("..."); }
}
class Dog extends Animal {
    void speak() { print("wang"); }        // 覆写
    void fetch() { }                        // 扩展
}
```

三种复用关系的取舍：

| 关系 | 表达 | 适用 |
| --- | --- | --- |
| **继承（is-a）** | `Dog extends Animal` | 子类确实是父类的一种 |
| **组合（has-a）** | `Dog has Tail` | 用「包含」表达能力 |
| **委托（does-instead-of）** | `Dog delegates Speak` | 用「代理」表达行为 |

课程建议优先考虑组合，因为继承会把父类的实现细节泄漏到子类，是「面向对象设计」里最常被批评的一处。

### 10.2 类型兼容与子类型

```java
// 教学示意：里氏替换（不参与构建）
Animal a = new Dog();     // 允许：Dog 是 Animal 的子类型
a.speak();                // 运行时跳到 Dog.speak()
```

判定规则（本课程简化的版本）：

| 子类方法 | 与父类什么关系 |
| --- | --- |
| 参数与返回类型**完全相同** | **覆写（override）**——多态生效 |
| 参数**不同**（数量或类型） | **重载（overload）**——与父类无关 |
| 返回类型是父类返回类型的子类型 | 协变覆写（Rust/Java 支持） |

### 10.3 方法表（vtable）

```java
// 教学示意：每个类一张方法表（不参与构建）
class Animal {
    String[] vtable = { "Animal.speak" };          // 槽位 0
    // 字段：name
}
class Dog extends Animal {
    String[] vtable = { "Dog.speak", "Dog.fetch" }; // 槽位 0 覆写，槽位 1 是新增
    // 字段：name（继承自 Animal）+ 可能的自有字段
}
```

**关键约束**：子类的方法表**槽位顺序必须与父类一致**，这样运行期才能用「父类槽位号」统一查找。这也是单继承实现简单、多继承实现复杂的原因之一。

### 10.4 动态绑定的一次调用

```java
// 教学示意：一次虚调用展开成什么（不参与构建）
a.speak();
// 展开成：
Object obj = load(a);                     // 取对象
int slot = 0;                             // 编译期已知：speak 在槽位 0
MethodTable vt = load(obj.vtablePtr);     // 取虚表
Code instr = load(vt.entry[slot]);        // 一次间接跳转
push(obj);                                // this
jump instr;                               // 真正的跳转
```

**这六步就是「运行期动态特性」的全部代价**。课程标题里的「运行期」三个字，指的就是第 5 步与第 6 步。

### 10.5 覆写 vs 重载（务必分清）

| | 覆写 override | 重载 overload |
| --- | --- | --- |
| 发生位置 | 子类与父类之间 | 同一个作用域内 |
| 依据 | 运行时类型 | 编译期签名 |
| 多态生效 | **是** | 否（静态分派） |
| Java 例子 | `toString()` | `println(int)` / `println(String)` |

### 10.6 构造函数链

```java
// 教学示意：初始化顺序（不参与构建）
// Dog 的构造过程：
//   1. 分配内存，vtable 指针指向 Dog 的方法表
//   2. 调用 Animal 的构造函数
//   3. Animal 里给 name 赋默认值
//   4. 回到 Dog，执行 Dog 自己的字段初始化与构造体
// 结论：先父后子；且父类的构造体里若调用虚函数，调用的是「父类版本」而非子类版本
```

> 最后一句是 OO 设计里最著名的陷阱之一：**不要在构造函数里调用可被覆写的方法**。

### 10.7 抽象方法与接口

```java
class Abstractish {                  // 本课小语言没有接口，用抽象函数模拟
    void speak() { throw new UnsupportedOperationException("抽象"); }
}
```

| | 抽象类 | 接口 |
| --- | --- | --- |
| 有状态 | 可以有字段 | 通常只有契约 |
| 多继承 | 单继承 | 可实现多个 |
| 运行期表示 | 有虚表槽位 | 有虚表槽位（Java 8+ 有 default 方法） |

### 10.8 三种实现策略

| 策略 | 查找成本 | 典型语言 |
| --- | --- | --- |
| **虚表（vtable）** | 一次间接跳转 | Java、C++（单继承）、Swift |
| **类指针数组 + 哈希** | 哈希查找 | Python、Ruby |
| **消息发送** | 字符串查找，可覆盖 | Objective-C、Smalltalk、早期 Smalltalk 风格实现 |

### 10.9 多态的成本与优化

现代编译器对多态做了大量优化：

- **去虚化（devirtualization）**：如果一个变量的动态类型在程序里只有一个，编译器直接内联。
- **内联缓存（inline cache）**：JIT 记住上次调用的目标，命中就直接跳（讲 34）。
- **虚表 specialization**：Rust 的 trait object 与 C++ 的二次动态派发。

## 常见误区与本书需修正之处

| # | 误区 | 修正 |
| --- | --- | --- |
| 1 | 「多态就是晚绑定」 | 更准确的说法：**把「选哪个实现」这个决策从编译期推迟到运行期**；去虚化会把它又拉回编译期 |
| 2 | 「覆写和重载是一回事」 | 完全不同：覆写跨类、多态生效；重载同域、静态分派 |
| 3 | 「多继承更强大」 | 菱形问题让实现复杂十倍；Java/C#/Go 都选择绕开 |
| 4 | 「继承应该优先于组合」 | 经典观点恰恰相反（GoF）：**组合优先于继承** |
| 5 | 「构造函数里调用方法很安全」 | 父类构造体里调用覆写方法会调到未初始化的子类状态 |
| 6 | 🔧 本课程只讲虚表，未提 **原型与委托** | Self 的委托链、JS 的原型链是「无继承的多态」，2026 年值得补 |
| 7 | 🔧 未提 **Rust 的 trait / dyn Trait** | 这是「继承替代品」最现代的样本，且零成本抽象 |
| 8 | 🔧 未提 **去虚化与内联缓存** | 编译器的多态优化是「多态成本」这一节的直接答案 |
| 9 | 🔧 未提 **泛型多态与子类型多态的分野** | 泛型是编译期/运行期参数化（泛型擦除或单态化），子类型多态才是运行期查表 |
| 10 | 🔧 未提 **LLM 写 OO 代码的高频错误** | 继承表达组合关系、覆写时忘加 `@Override`、父类构造器调用虚函数 |
