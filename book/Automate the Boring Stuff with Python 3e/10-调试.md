## 核心精讲

```
# 教学示意，不参与构建
import logging
logging.basicConfig(level=logging.DEBUG,
                    format='%(asctime)s %(levelname)s %(message)s')
def div(a, b):
    assert b != 0, '除数不能为 0'
    logging.debug(f'div {a}/{b}')
    return a / b
```

- 回溯从下往上看：最后一行是异常类型与消息，往上追溯调用链。
- `assert cond, msg`：条件为假抛 `AssertionError`，用于捕捉「不该发生」的状态。
- `logging` 分 `DEBUG/INFO/WARNING/ERROR/CRITICAL`；生产用 `WARNING+`，调试开 `DEBUG`。
- `pdb`/`breakpoint()`（3.7 内置）单步执行、查看变量。

## 版本演进

- `breakpoint()`（PEP 553，3.7）替代 `import pdb; pdb.set_trace()`。
- `logging` 长期稳定；结构化日志 `structlog`（第三方）在云原生流行。
- 异常组 `ExceptionGroup`（PEP 654，3.11）支持一次抛出多错误。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用 `print` 满屏调试 | 用 `logging` 可分级开关，或 `breakpoint()` |
| `assert` 当参数校验 | `assert` 在 `-O` 优化下被移除，运行时校验用异常 |
| 忽视回溯信息 | 从下往上读，定位根源行 |
| 🔧 本书未提 `breakpoint()` | 3.7+ 直接用 `breakpoint()` |
