## 核心精讲

```
# 教学示意，不参与构建
import shutil
from pathlib import Path
src = Path('a.txt'); dst = Path('backup/a.txt')
shutil.copy(src, dst)                       # 复制
# 遍历
for f in Path('.').rglob('*.py'):
    print(f)
# 批量重命名
import re
for f in Path('.').glob('*.txt'):
    new = re.sub(r'spam', 'eggs', f.name)
    f.rename(f.with_name(new))
```

- `shutil.copy/move/copytree` 处理复制与移动；`os.rename/remove` 原子操作。
- `Path.rglob('*.py')` 递归匹配；`os.walk` 返回 (目录, 子目录, 文件)。
- `zipfile` 做压缩/解压，无需系统命令。

## 版本演进

- `pathlib`（PEP 428）统一路径操作；`Path.replace` 跨平台移动。
- `shutil` 长期稳定；`copytree` 的 `dirs_exist_ok` 参数（3.8）避免已存在报错。
- `os.walk` 仍可用，但 `Path.rglob` 更 Pythonic。

## 近年研究与工业界开源实践（2015–2026）

- `pathlib` 已成标准路径写法；`rsync`/`robocopy` 仍用于跨机同步。
- `send2trash` 把文件送回收站而非硬删，更安全。
- `rich`/`tqdm` 给批量操作加进度条。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| `os.rename` 目标已存在报错 | 用 `Path.replace` 或先判断；跨盘用 `shutil.move` |
| 硬删重要文件 | 用 `send2trash` 进回收站 |
| 遍历中改目录结构 | 先收集列表再操作，避免 `os.walk` 混乱 |
| 🔧 本书未提 `send2trash` | 自动化脚本删文件优先进回收站 |
