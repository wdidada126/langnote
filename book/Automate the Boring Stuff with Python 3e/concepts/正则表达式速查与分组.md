> 跨章参考：支撑[第07章 正则表达式](../07-正则表达式.md)及[第09章 组织文件](../09-组织文件.md)的批量重命名。

## 元字符速查

| 符号 | 含义 | 示例 |
|---|---|---|
| `.` | 任意字符（除换行） | `a.c` 匹配 `abc` |
| `\d` | 数字 `[0-9]` | `\d+` 多位数字 |
| `\w` | 单词字符 `[A-Za-z0-9_]` | `\w+` 标识符 |
| `\s` | 空白 | ` `/\t/\n |
| `^` | 行/串首 | `^foo` |
| `$` | 行/串尾 | `foo$` |
| `[]` | 字符类 | `[aeiou]`、`[0-9]` |
| `[^]` | 取反类 | `[^0-9]` 非数字 |
| `()` | 分组（捕获） | `(\d{4})-(\d{2})` |
| `(?:)` | 分组（不捕获） | 仅用于量词聚合 |
| `|` | 或 | `cat|dog` |

## 量词

| 量词 | 次数 | 贪心/非贪心 |
|---|---|---|
| `?` | 0 或 1 | `*?` `+?` `??` `{m,n}?` |
| `*` | 0 或多次 | 默认贪心 |
| `+` | 1 或多次 | 默认贪心 |
| `{m,n}` | m 到 n 次 | `{2,4}` |

## 分组与提取

```
# 教学示意，不参与构建
import re
m = re.search(r'(?P<y>\d{4})-(\d{2})-(\d{2})', '2024-10-02')
print(m.group('y'))          # 2024（命名组）
print(m.group(2))             # 10（位置组）
print(m.groups())             # ('2024', '10', '02')
```

- 命名组 `(?P<name>...)` 用 `m.group('name')` 取，可读性好。
- `re.findall` 遇分组时返回元组列表：`re.findall(r'(\d+)-(\d+)', '1-2 3-4')` → `[('1','2'),('3','4')]`。
- `re.sub(r'(\w+)', r'\1', s)` 用反向引用替换。

## 高级与版本

- `re.VERBOSE`（`re.X`）允许模式内注释与空白，长模式必备。
- 第三方 `regex` 库支持递归 `(?R)`、`\p{...}` Unicode 属性（中文文本友好）。
- 🔧 本书未覆盖回溯失控（catastrophic backtracking）——长文本复杂模式注意用原子组/限长。
