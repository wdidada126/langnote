## 版本演进（2e → 3e 已核实差异）

- 网页抓取（第11章）：3e 改用 `requests` 库替代 2e 的 `urllib`/`webbrowser` 组合，更贴近现代实践。
- PDF 处理（第13章）：3e 迁移到 `pypdf`（PyPDF2 已停止维护，官方建议迁移）。
- 正则、文件组织、调试、Excel、CSV/JSON、邮件、图像、GUI 自动化：结构基本一致，3e 主要做 API 现代化与示例更新。
- 🔧 其余 3e 微调（如新增小节、示例替换）以官方免费版目录为准，本笔记未逐字对照。

## 工具链与运行环境

- Python 3.12+（本书示例兼容 3.6+，本笔记按 3.12 校准）。
- 第三方库：`requests`、`openpyxl`、`pypdf`、`python-docx`、`imapclient`、`pyautogui`、`pillow`、`schedule`。
- 安装：`python -m pip install --upgrade requests openpyxl pypdf python-docx imapclient pyautogui pillow schedule`
