## 核心精讲

```
# 教学示意，不参与构建
import requests
from bs4 import BeautifulSoup
resp = requests.get('https://example.com', timeout=10)
resp.raise_for_status()                 # 非 200 抛异常
soup = BeautifulSoup(resp.text, 'html.parser')
for a in soup.select('a.external'):
    print(a.get('href'), a.get_text())
```

- 3e 用 `requests`：`resp.text` 自动解码、`resp.raise_for_status()` 检查状态码。
- `BeautifulSoup` 用 CSS 选择器 `select` 或 `find/find_all` 定位节点。
- 动态渲染（JS 生成内容）用 `selenium`/`playwright` 驱动真实浏览器。
- 遵守 `robots.txt` 与网站Terms，控制请求频率。

## 版本演进

- **3e 关键变化**：网页抓取改用 `requests` 替代 2e 的 `urllib.request` + `webbrowser`，API 更友好。
- `BeautifulSoup4` 稳定；解析器推荐 `lxml`/`html.parser`。
- `playwright`（微软）渐取代 `selenium` 成为首选动态爬取工具。

- `playwright` 支持异步、多浏览器，E2E 与抓取通用。
