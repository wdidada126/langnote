## 核心精讲

```
# 教学示意，不参与构建
import smtplib
from email.message import EmailMessage
msg = EmailMessage()
msg['Subject'] = '自动报告'
msg.set_content('任务完成')
msg['From'] = 'me@example.com'; msg['To'] = 'you@example.com'
with smtplib.SMTP('smtp.example.com', 587) as s:
    s.starttls(); s.login('me', 'app_password')
    s.send_message(msg)
```

- `smtplib.SMTP` 连服务器；`starttls()` 加密；用「应用专用密码」而非账号密码。
- `email.message.EmailMessage` 构造正文/附件/HTML。
- `imapclient` 收信：`select_folder`/`search`/`fetch`。
- `twilio` 发短信需注册账号与号码（按量计费）。

## 版本演进

- `email.message.EmailMessage`（3.6+）替代旧 `MIMEText` 写法，更直观。
- `smtplib`/`imaplib` 标准库稳定。
- 现代替代：事务邮件用 `sendgrid`/`resend` 等 API 服务。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用账号明文密码 | 用应用专用密码/环境变量 |
| 凭据硬编码在脚本 | 用 `.env`（python-dotenv） |
| 忽略 TLS | 始终 `starttls()` 或 465 SSL |
| 🔧 本书未提 `resend`/`yagmail` | 现代发送优先这些 |
