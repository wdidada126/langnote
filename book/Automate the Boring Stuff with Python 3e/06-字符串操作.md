## 核心精讲

```
# 教学示意，不参与构建
s = '  Hello, World!  \n'
print(s.strip())                  # 'Hello, World!'
print(s.lower())                  # '  hello, world!  '
print(s.split(','))               # ['  Hello', ' World!  \n']
parts = 'a-b-c'.split('-')        # ['a','b','c']
print('-'.join(parts))            # 'a-b-c'
```

- 转义：`\n` 换行、`\t` 制表、`\\` 反斜杠；原始串 `r'C:\new'` 不转义。
- `strip/chars` 去首尾空白或指定字符；`lstrip/rstrip` 单向。
- `split(sep)` 切分；`join` 合并（注意是字符串方法，不是列表方法）。
- `pyperclip.copy/paste` 操作系统剪贴板（第三方库）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 字符串不可变，试图修改字符 | 字符串方法都返回新串，需重新绑定 |
| 用 `+` 在循环里拼大字符串 | 用 `''.join(list)` |
| 漏用原始串处理 Windows 路径 | 路径用 `r'...'` 或 `pathlib` |
| 🔧 本书未提 `removeprefix/suffix` | 3.9+ 优先用之 |
