## 核心精讲

```
# 教学示意，不参与构建
def greet(name: str, loud: bool = False) -> str:
    msg = f'Hello, {name}'
    return msg.upper() if loud else msg

print(greet('Alice'))            # Hello, Alice
print(greet('Bob', loud=True))   # HELLO, BOB
```

- `def` 定义函数；`return` 返回结果，无 `return` 则隐式返回 `None`。
- 参数可设默认值；调用时可按位置或关键字传。
- 局部变量只在函数内可见；`global` 声明可改全局（尽量不用）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 可变默认参数 `def f(x=[])` | 默认值是共享对象，应用 `x=None` 然后 `x = x or []` |
| 用 `global` 改全局 | 优先返回新值或传参 |
| 函数副作用不清 | 纯函数更易测试；见 [`Python测试`](#) 相关书 |
| 🔧 本书未强调类型标注 | 入门即写 `name: str` 受益良多 |
