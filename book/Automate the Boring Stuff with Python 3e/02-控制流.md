## 核心精讲

```
# 教学示意，不参与构建
name = 'Alice'
if name == 'Alice':
    print('Hi, Alice')          # 缩进块
elif name == 'Bob':
    print('Hi, Bob')
else:
    print('Who are you?')

# while 循环
i = 0
while i < 5:
    print(i)
    i += 1

# for + range
for i in range(5):              # 0,1,2,3,4
    print(i)
```

- 布尔值是 `True`/`False`；比较与逻辑运算产生布尔值。
- 代码块靠**缩进**界定（惯例 4 空格），冒号 `:` 开启块。
- `range(n)` 生成 `0..n-1`；`range(a, b, step)` 可指定起止与步长。
- `break` 立即退出循环；`continue` 跳到下一轮。

## 版本演进

- 海象运算符 `:=`（PEP 572，3.8）可在表达式内赋值：`if (n := len(data)) > 10:`。
- 模式匹配 `match`/`case`（PEP 634，3.10）是 `if/elif` 链的现代替代，本书未覆盖。

## 近年研究与工业界开源实践（2015–2026）

- `match/case`（3.10+）在解析命令、状态机中大量替代 `if/elif`。
- `itertools` 提供 `count`/`cycle`/`repeat` 等无限/循环迭代器，替代手写 `while`。
- 类型守卫 `typing.TypeGuard`（3.10）让分支内的类型收窄更安全。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| `=` 与 `==` 混淆 | `=` 赋值、`==` 比较；本书已强调 |
| `while` 死循环 | 确保循环变量在推进，或用 `for` 更安全 |
| 用 `range(len(x))` 遍历 | 优先 `for item in x:`；需下标用 `enumerate(x)` |
| 🔧 本书未提 `match/case` | 多分支解析建议学 3.10+ 模式匹配 |
