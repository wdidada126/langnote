## 核心精讲

```
# 教学示意，不参与构建
from pathlib import Path
p = Path('data.txt')
text = p.read_text(encoding='utf-8')        # 一次读全
lines = text.splitlines()
p.write_text('\n'.join(lines), encoding='utf-8')
# 二进制
data = p.read_bytes()
```

- `open(path, mode, encoding=...)`；文本模式默认平台编码，务必显式指定 `utf-8`。
- `with open(...) as f:` 离开块自动 `close`，避免句柄泄漏。
- `Path.read_text/write_text/read_bytes/write_bytes`（pathlib）比裸 `open` 更简洁。

## 版本演进

- `pathlib`（PEP 428，3.4）提供面向对象的路径；3.6 起 `Path.read_text` 等方法可用，3.12 增强。
- `os.scandir`（3.5）比 `os.listdir` 高效；`Path.glob`/`rglob` 遍历目录。
- 旧书用 `shelve` 持久化字典，现代改用 `json`（可读、跨语言）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 不指定 `encoding` | Windows 默认 GBK 会乱码，始终 `encoding='utf-8'` |
| 用 `shelve` 存数据 | 用 `json`/`sqlite3`，可移植可调试 |
| 忘记 `close` | 用 `with` 语句 |
| 🔧 本书未强调 `pathlib` | 现代路径处理优先 `pathlib` |
