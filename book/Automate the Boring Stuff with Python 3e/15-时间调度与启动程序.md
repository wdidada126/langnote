## 核心精讲

```
# 教学示意，不参与构建
import time, schedule
from datetime import datetime
from zoneinfo import ZoneInfo
print(datetime.now(ZoneInfo('Asia/Shanghai')))
time.sleep(5)                      # 暂停 5 秒
def job():
    print('tick')
schedule.every(10).minutes.do(job)
while True:
    schedule.run_pending()
    time.sleep(1)
```

- `time.sleep(n)` 阻塞当前线程；循环里配合 `schedule.run_pending()` 做轻量定时。
- `datetime.now()` 返回 naive 时间；带时区用 `zoneinfo.ZoneInfo`（3.9）。
- `schedule` 第三方库，语法直观；生产可用系统 `cron`/`Task Scheduler`/`systemd`。

## 版本演进

- `zoneinfo`（PEP 615，3.9）替代 `pytz`，成为标准时区库（需系统 tzdata 或 `tzdata` 包）。
- `datetime` 长期稳定；`dateutil` 提供 `relativedelta` 等增强。
- 旧书用 `pytz` + `localize()`，现代用 `zoneinfo`。

## 近年研究与工业界开源实践（2015–2026）

- `APScheduler` 提供 cron 风格调度，比 `schedule` 更适合复杂任务。
- `Prefect`/`Dagster` 做带依赖的工作流编排（数据工程）。
- 容器化后定时任务多用 Kubernetes `CronJob`。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| naive 时间当本地时间 | 显式用 `zoneinfo` 带时区 |
| 用 `pytz` | 3.9+ 用标准 `zoneinfo` |
| `while True` 占满 CPU | 循环内 `sleep` 让出 |
| 🔧 本书未提 `APScheduler` | 复杂调度优先它 |
