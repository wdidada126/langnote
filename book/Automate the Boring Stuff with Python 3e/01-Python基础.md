## 核心精讲

```
# 教学示意，不参与构建
print('Hello, world!')          # 打印字符串
spam = 40                       # 变量绑定到整数对象
eggs = 'Hello'                  # 变量可绑任意对象
print(spam + 2)                 # 42
print(eggs + ', world!')        # Hello, world!
```

- 表达式是「值 + 运算符」的组合；Python 在交互式环境直接回显其结果。
- 整数除法 `/` 永远返回 `float`（`21 / 7 == 3.0`）；整除用 `//`；取模 `%`；乘方 `**`。
- 字符串可用单/双引号；多行用三引号。f-string（Python 3.6+）是最推荐的插值方式：`f'{name} 今年 {age} 岁'`。
- 变量是名字到对象的绑定，不是「盒子」；重新赋值只是把名字绑到新对象。

## 版本演进

- Python 3 中 `/` 对整数也返回 `float`（Python 2 的「整数除法」已移除）。
- f-string 自 3.6（PEP 498）引入；3.12 支持 f-string 内复用同名引号、多行更自由；3.14 计划引入 t-string（模板字符串，PEP 750，实验）。
- 本书示例兼容 3.6+，本笔记按 3.12 校准。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用 `+` 拼接大量字符串 | 大量拼接应用 `str.join()` 或 `io.StringIO`，`+` 在循环里反复拷贝 |
| 把变量当「盒子」理解 | Python 变量是名字绑定，多个名字可绑同一对象（别名） |
| 混用 `print` 调试 | 现代实践用 `logging` 或断点；见第10章 |
| 🔧 本书未提 f-string 的 3.12 新语法（嵌套引号） | 以官方文档 f-string 小节为准 |
