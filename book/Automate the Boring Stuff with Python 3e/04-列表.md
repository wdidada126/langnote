## 核心精讲

```
# 教学示意，不参与构建
spam = ['cat', 'dog', 'mouse']
print(spam[0])                  # cat
print(spam[-1])                 # mouse
spam.append('bird')             # 末尾追加
spam.sort()                     # 就地排序
# 列表推导式
squares = [x * x for x in range(5)]   # [0,1,4,9,16]
```

- 下标从 0 开始；负数从末尾倒数（`-1` 末项）。
- 切片 `[a:b:step]` 左闭右开；`[:]` 是浅拷贝。
- `list.sort()` 就地排序；`sorted(x)` 返回新列表。
- **引用**：`b = a` 只是别名，改 `b` 也改 `a`；要独立副本用 `a.copy()` 或 `list(a)`。

## 版本演进

- 字典合并运算符 `|`（PEP 584，3.9）虽属 dict，但「合并」语义在列表用 `+`/`*` 早已支持（`[1]+[2]`）。

- 类型标注：`list[int]`（PEP 585，3.9 起无需 `typing.List`）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| `b = a` 后改 `b` 不影响 `a` | 这是别名，两者同一对象；用 `a.copy()` |
| 遍历时删除元素 | 会跳过项；用列表推导式或倒序，或 `filter` |
| `sort()` 返回 `None` | 排序是就地操作，无返回值 |
| 🔧 本书未提 `list[str]` 标注 | 现代写法应标注元素类型 |
