## 核心精讲

```
# 教学示意，不参与构建
from PIL import Image, ImageDraw
img = Image.open('photo.png')
cropped = img.crop((0, 0, 100, 100))      # 左/上/右/下
small = img.resize((64, 64))
draw = ImageDraw.Draw(img)
draw.text((10, 10), 'watermark', fill='red')
img.save('marked.png')
```

- `pillow`(PIL) 是图像处理标准；`Image.open` 惰性加载，`save` 写盘。
- `crop(box)` 盒是 (左, 上, 右, 下)；`resize` 显式尺寸。
- `ImageDraw` 画文字/形状；`ImageFilter` 做模糊/锐化。
- `pyautogui.screenshot()` 截全屏或区域。

## 版本演进

- `pillow` 持续维护；`numpy` 数组互操作方便（`np.array(img)`）。
- `imageio`/`opencv-python`(cv2) 在高级视觉处理更强。
- `pyautogui` 截图依赖系统后端（Windows/macOS/Linux 各异）。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 忘记 `img.save` | `crop/resize` 返回新对象，需保存 |

| 截图坐标错 | `pyautogui` 用屏幕像素，注意缩放 |
