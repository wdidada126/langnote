## 核心精讲

```
# 教学示意，不参与构建
import re
text = '订单号 ORD-2024-12345，金额 ¥99.50'
m = re.search(r'ORD-\d{4}-(\d+)', text)
print(m.group(1))                # 12345（分组捕获）
# 替换
clean = re.sub(r'\D', '', 'ORD-2024-12345')   # '202412345'
# 可读模式
pattern = re.compile(r'''
    (?P<year>\d{4}) - (?P<num>\d+)
''', re.VERBOSE)
```

- `re.search` 返回首个匹配对象；`re.findall` 返回所有匹配串（或元组列表）。
- 分组 `()` 用 `m.group(n)` 或命名组 `m.group('name')` 提取。
- 量词：`?` 0/1 次、`*` 0+ 次、`+` 1+ 次、`{m,n}` 区间。
- `re.VERBOSE` 允许在模式里加注释与空白，提升可读性。
- 默认贪心；量词后加 `?` 变非贪心（如 `.*?`）。

## 版本演进

- 标准库 `re` 长期稳定；第三方 `regex` 支持递归/命名组更丰富。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 忘记用原始串 `r'...'` | 反斜杠会被 Python 先转义，模式出错 |
| 混淆 `match` 与 `search` | `match` 只从开头，`search` 扫全文 |
| 贪心 `.*` 吞掉过多 | 用 `.*?` 非贪心 |
| 🔧 本书未提 `regex` 库 | 中文/Unicode 高级匹配用 `regex` |
