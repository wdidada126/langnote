## 核心精讲

```
# 教学示意，不参与构建
birthdays = {'Alice': '1990-01-01', 'Bob': '1992-05-20'}
print(birthdays['Alice'])               # 1990-01-01
birthdays['Carol'] = '1995-11-11'       # 新增
print(birthdays.get('Dave', 'N/A'))      # N/A
# 嵌套结构
db = {'users': [{'name': 'Alice', 'age': 30}]}
```

- 键必须是不可变类型（字符串/数字/元组）；值任意。
- `d.get(k, default)` 避免 KeyError；`k in d` 检查键存在。
- `setdefault(k, default)`：键不存在时设默认值并返回。
- `collections.defaultdict` 访问缺失键自动调用工厂函数。

## 版本演进

- 字典**保证插入顺序**自 3.7 起（PEP 520，3.6 CPython 已实现但未保证）。
- 合并运算符 `|` 与更新 `|=`（PEP 584，3.9）：`d1 | d2`。
- 类型标注 `dict[str, int]`（PEP 585）。

## 近年研究与工业界开源实践（2015–2026）

- `pydantic`/`dataclasses`（PEP 557，3.7）取代手写字典做数据校验与建模。
- `orjson`/`msgspec` 提供极速 JSON 编解码，替代 `json`。
- `typing.TypedDict`（3.8）给字典加结构类型。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用 `d['k']` 访问可能缺失的键 | 用 `d.get(k)` 或 `defaultdict` |
| 认为 dict 无序 | 3.7+ 已保序 |
| 手写嵌套初始化易 KeyError | 用 `defaultdict`/`setdefault` |
| 🔧 本书未提 `TypedDict`/`dataclass` | 结构化数据优先用这些 |
