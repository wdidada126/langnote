## 2. 勘误与取证链（发射环境实抓，2026-09-27）

- 环境：**DuckDB 1.5.5（Python 客户端）**、**sqlite3 模块 3.45.3**；Windows 单机，
  脚本与原始输出存 `D:\develops\tmp\dbwave_w6_dlai\`（exp1/exp2/exp6/exp7.log），
  repo 零产物。**引擎不可装实测确认**：`import pyspark`/`import delta` 均
  ImportError、无 spark-submit——Spark/Delta/Synapse 运行行为全目录一律 ⚠️，零新装红线未破。
- 五组实验一览（全部标"非本书引擎/平台行为"）：
  ①02 §4 MVCC 可见性/写冲突四场景；②04 §5 分区裁剪 2M 行/1887 文件→**5 文件**、×2.9；
  ③04 §6 小文件税 200 files vs 1 file **×5.3**；④05 §4 布局依赖的行组裁剪
  有序 0.0040s vs 乱序 0.0111s **×2.8**（另前置：点查 0.0048s vs 全扫 0.0100s）；

  两张表 schema-id 间接层复现。
- **与已验收各册实验错位**：DLUR 用 sqlite 手写版本表（时间轴）、#148 用迷你清单演

  本目录五组落在**可见性/文件税/布局裁剪/演化读侧/结构间接层**五个未占用点，无复跑。
