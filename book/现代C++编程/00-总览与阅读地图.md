## 3. 阅读路线

- **零基础最短路径**（约 4 周）：`01 → 02 → 03 → 04 → 06`（语言核心）→ `08 → 09 → 10 → 12`（库与数据结构）→ `13`（并发）→ `14`（工程收尾）。
- **C 程序员路径**（对应原书「致 C 语言程序员」）：`01 → 02 → 08`，重点看「数组→`std::array`/`std::span`、malloc→RAII/智能指针、裸指针→引用/视图」三条替换线，其余按需。
- **应试/面试路径**：`04（模板/concepts）`、`02（移动语义）`、`08（智能指针）`、`13（并发）`四件套，每章的「核心概念速览 + 实测对照」即高频考点。
- **只读库与工程**（已会语言）：从 `07（测试）`起顺序读完 07–14。
- 每章末「练习拓展接点」对应原书「练习/拓展阅读」栏目结构（⚠️ 具体题面未随单文件笔记保存，不冒充原文）。
