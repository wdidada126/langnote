## 核心精讲

### 期望与方差的最小骨架

```python
from fractions import Fraction

def expectation(outcomes):
    """outcomes: [(取值, 概率)]；期望 = Σ x·Pr(x)"""
    return sum(Fraction(x) * Fraction(p) for x, p in outcomes)

def variance(outcomes):
    ex = expectation(outcomes)
    return expectation([(x**2, p) for x, p in outcomes]) - ex**2

# 抛硬币：n 次抛掷中正面朝上的次数 X ~ Binomial(n, 1/2)
def binom_pmf(n, k, p=Fraction(1, 2)):
    from math import comb
    return Fraction(comb(n, k)) * p**k * (1 - p)**(n - k)

# E[X] = n*p，Var[X] = n*p*(1-p)：这是本章最重要的两个式子
```

### 生日悖论与哈希冲突

```python
# 生日问题：至少一对人生日相同的概率
def birthday_prob(n, days=365):
    p = 1.0
    for k in range(n):
        p *= (days - k) / days
    return 1 - p

# 经典反直觉点：23 人就有 50% 概率；50 人已接近 97%
print(round(birthday_prob(23), 4), round(birthday_prob(50), 4))
```

### 随机走步与首次返回

```python
# 一维对称随机游走：在 0 与 N 之间，返回 0 的概率、首次通过时间
def return_prob(n):
    """简单对称随机游走在 n 步后回到原点的概率（示意）"""
    from math import comb
    return comb(n, n // 2) / 2**n if n % 2 == 0 else 0

# 反射原理：从 (0,0) 到 (n, k) 不穿过对角线的路径数 = binom(n, k) - binom(n, k-1)
# 这正是第 5 章「反射原理」在概率里的应用
def ballot_paths(n, k):
    from math import comb
    return comb(n, k) - (comb(n, k - 1) if k > 0 else 0)
```

### Fisher–Yates 洗牌与「Mountain Ranges」

```python
import random

# Fisher–Yates（Knuth shuffle）的正确实现：从后往前，与「当前位置之前」的随机位置交换
# 注意：常见错误写法（每次与任意位置交换）会导致分布不均——这是本章最经典的坑
def fisher_yates(a):
    a = list(a)
    for i in range(len(a) - 1, 0, -1):
        j = random.randrange(i)          # 注意是 [0, i)，不是 [0, n)
        a[i], a[j] = a[j], a[i]
    return a

# 「Mountain Ranges」思想实验：把一条随机游走的路径画出来，
# 统计「山」的形状（峰、谷、高度）与 Catalan 型对象的对应
def mountain_ranges(steps):
    up = down = 0
    profile = []
    for _ in range(steps):
        up, down = up + (1 if random.random() < 0.5 else -1), 0
        profile.append(up)
    return profile
```

> 本章的现代价值在于：**洗牌的均匀性、随机走步的通过时间，正是 2020 年代表征学习里「采样与遍历」的数学原型**——只不过具体数学里只有离散版本，连续版（扩散、SDE）与 MCMC 已在本书之外。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **Bertrand 悖论只出现在习题里，正文未展开** | §8.4 提到「概率取决于样本空间的选择」但不给完整三种解法；建议自己补一遍，这是理解「概率定义」最好的一课 |
| 🔧 **Fisher–Yates 的正确性在第 2 版中不是正文章节** | 洗牌的均匀分布证明在第 2 版里只有边注；修订版据称会把它升格为正式小节——**这也是判断「你读的是哪一版」的信号之一** |
| **方差公式 `E[X²] - (E[X])²` 被当成显然** | 它的正确性依赖「期望的线性性」，而线性性依赖样本空间有限；在无限样本空间中需要额外的技术条件 |
| 🔧 **「Mountain Ranges」思想实验缺失** | 这一节在第 2 版只以涂鸦/边注形式存在；修订版据称会正式加入，用它解释随机游走轮廓与 Catalan 结构的对应 |
| 🔧 **连续概率被完全跳过** | 本章叫「离散概率」不是随口说的；2020 年代 MCMC、变分推断、扩散模型全部需要连续版，本书读者必须自行补课 |
| **哈希一节缺少现代密码学视角** | §8.5 只算期望冲突数，未涉及抗碰撞哈希的安全模型；工业上「生日界」的正确用法见密码学文献而非本书 |
| 🔧 **随机走步在机器学习中的问题被本书忽略** | 2020 年代的关键问题是「**采样的梯度怎么走**」（gumbel-softmax、重参数化），本章只有离散的第一次通过时间，无法直接回答 |
| 🔧 **机辅实验可以做得比作者更彻底** | Knuth 鼓励「用机器算着玩」，但只做到「算几个值对一下」；2020 年代应做到「用 SymPy 把本章所有习题的闭式一次性验证」，把体力活全部外包 |
