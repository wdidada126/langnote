# 第 5 章 二项式系数（Binomial Coefficients）

> **一句话**：本章是全书技巧密度最高的一章——**一个 `binom(n,k)` 能同时用九种方法算出来，而这九种方法恰好是「具体数学」的全部手法**（组合解释、生成函数、递推、归纳、超几何变换、机械求和）。

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 从阶乘到 Pascal 三角

```python
import math

def binom(n, k):                      # Python 3.8+ 直接内建
    return math.comb(n, k) if 0 <= k <= n else 0

# Pascal 递推 + 边界条件，注意这里「边界」是 二项式系数定义的地基
def pascal(n):
    row = [1]
    for _ in range(n):
        row = [1] + [row[i] + row[i + 1] for i in range(len(row) - 1)] + [1]
    return row

# 吸收实验（§5.1）：反复用 binom(n,k)*k/j 消掉上下界，是全书最常用的「消元」动作
def absorption(n, k, j):
    return binom(n, k) * k / j
```

### 组合证明：把公式翻译成「选东西」

```python
# 例：Σ_{0<=k<=n} binom(n,k)^2 = binom(2n, n)
# 组合解释：从 2n 个里选 n 个 = 先选前 n 个里的 k 个，再选后 n 个里的 n-k 个
def identity_check(n):
    lhs = sum(binom(n, k) ** 2 for k in range(n + 1))
    rhs = binom(2 * n, n)
    return lhs, rhs, lhs == rhs
```

### 三项式系数（§5.3 的悬念）

```python
# n = i + j + k 时，把 n 个东西分成三组，大小为 i, j, k
def multinomial(n, parts):
    from math import factorial
    val = factorial(n)
    for p in parts:
        val //= factorial(p)
    return val

# 三项式系数用二项式系数表示（本章 5.3 的核心联系）
def trinomial(n, i, j):
    k = n - i - j
    if k < 0 or i < 0 or j < 0:
        return 0
    return multinomial(n, [i, j, k])
```

### 超几何形式与机械求和（第 2 版的重点）

```python
# C(n, k) = (-n)_k / k!，其中 (a)_k 是下降阶乘
def falling(a, k):
    p = 1
    for i in range(k):
        p *= (a - i)
    return p

def binom_hyper(n, k):
    if k < 0 or k > n:
        return 0
    return falling(-n, k) // math.factorial(k)

# 机械求和：把和式写成 Σ C(a+k, b) * C(c-k, d) * z^k 的形式后交给机器
def hyper_term(a, b, c, d, k, z):
    return binom_hyper(a + k, b) * binom_hyper(c - k, d) * z**k

# 注：真正走 Gosper/Zeilberger 的是符号计算库，这里只演示「化成超几何形式」这一步
print(sum(hyper_term(-2, 2, -2, 2, k, 1) for k in range(5)))
```

> §5.8「机械求和」是**第 2 版相对第 1 版最重要的新增内容之一**：它把第 2 章学到的有限微积分 repertoire，升级为「把任意和式化成超几何项、再交给算法决定闭式」的流水线。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **「吸收实验」不是名字，是一族手法** | 5.1 后反复出现的 absorption 指的是「用 `binom(n,k)` 与 `k/(n-k)` 之类的比消掉上下界」；初学者常误以为它是某个固定公式 |
| 🔧 **三项式系数在 §5.3 只给定义不给构造方法** | `n!/i!j!k!` 的分组解释需要自己补；中译本此处跳跃较大 |
| 🔧 **超几何变换的下标极易抄错** | 5.5–5.6 的 Pfaff、Saalschütz 变换对参数顺序极敏感；建议用 SymPy 逐个校验，别手抄 |
| **把 Pascal 三角的模 p 性质当成「巧合」** | §5.3 提到的模 p 循环现象有严格理论（Kummer 定理、Lucas 定理），但正文只点到为止，容易让人以为只是图案 |
| 🔧 **中译本习题（5.10–5.60）缺少过程性解答** | 这一章习题是全书最硬的部分之一（尤其是「三项式系数与超几何变换」那批），只给最终答案几乎无法自查 |
| **本章对「随机走步」只是一笔带过** | 二项式系数与随机走步的深层联系（Chung–Feller、反射原理）在第 8 章才用；修订版据称会把这块推得更深 |
| 🔧 **工具可以做得远比书彻底** | 书里「机械求和」是「教你用技巧」，而 2020 年代 Zeilberger 的 WZ 是「给你一个一定对的答案」。**值得追问的不是机器算没算对，而是机器为什么算得对**——这正是 §5.5 的意义所在 |
