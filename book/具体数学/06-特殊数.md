# 第 6 章 特殊数（Special Numbers）

> **一句话**：本章给数学里最著名的那几个「整数序列」做了一次**家谱整理**——Stirling 数、Eulerian 数、调和数、Bernoulli 数、Fibonacci、Catalan、Bell 全都在这几十页里露面，而它们真正的统一点在于：**除了一族是生成函数来的，其余全都与「把东西划分成若干块」有关**。

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### Stirling 数：把幂换成阶乘的桥梁

```python
# 第二类 Stirling 数 S(n, k)：把 n 个有标号元素划分成 k 个非空集合
def stirling2(n, k):
    if k > n or k == 0:
        return 0
    if k == 1 or n == k:
        return 1
    return k * stirling2(n - 1, k) + stirling2(n - 1, k - 1)

# 第一类无符号 Stirling 数 c(n, k)：n 个元素排成 k 个轮换
def stirling1(n, k):
    if k > n or k == 0:
        return 0
    if k == 1:
        return -(-1)**(n - 1) * 1  # 结构上等于 (n-1)! 的符号处理，示意用
    return stirling1(n - 1, k - 1) + (n - 1) * stirling1(n - 1, k)

# z^n = Σ_k S(n,k) z^(k)  （生成函数：第二类与上升阶乘的互逆）
print(sum(stirling2(4, k) for k in range(5)))
```

### Bernoulli 数与伯努利多项式

```python
from fractions import Fraction

# B_n 由生成函数 Σ B_n t^n/n! = t/(e^t - 1) 定义
# 递推式（Pascal 三角式）：Σ_k binom(n+1, k) B_k = 0，解出 B_n
def bernoulli(n):
    from math import comb
    B = [Fraction(1)]                      # B_0 = 1
    for m in range(1, n + 1):
        total = Fraction(0)
        for k in range(m):
            total += Fraction(comb(m + 1, k)) * B[k]
        B.append(-total / (m + 1))
    return B[n]                            # B_1 = -1/2，注意符号约定
```

> 咬住这一句：Bernoulli 数的全部意义在于**它是 `Σ k^p` 这类幂和的生成函数**——`Σ_{0<=k<n} k^p = (B_{p+1}(n) - B_{p+1}(0))/(p+1)`，第 2 章的「分部求和」在这里终于有了闭式出口。

### 调和数与 Euler–Maclaurin

```python
import math

def harmonic(n):
    return sum(Fraction(1, k) for k in range(1, n + 1))   # 必须高精度，float 会骗你

def harmonic_asymptotic(n):
    return math.log(n) + 0.5772156649015328 + 0.5 / n - 1 / (12 * n**2)

print(float(harmonic(1000)), harmonic_asymptotic(1000))
```

### Catalan 数：一个数字，上百种解释

```python
from math import comb

def catalan(n):
    return comb(2 * n, n) // (n + 1)

# 经典恒等式：所有解释都指向同一个数
def catalan_check(n):
    return (
        catalan(n) == comb(2 * n, n) - comb(2 * n, n + 1)      # 反射原理
        and catalan(n) == sum(catalan(i) * catalan(n - 1 - i) for i in range(n))  # 卷积递归
    )
```

### Bell 数与 Dobinski 公式

```python
# Bell 数 B_n：把 n 个有标号元素划分成任意多个非空块
def bell(n, rows=None):
    row = [1]
    for _ in range(n):
        row = [1] + [row[i] + row[i + 1] for i in range(len(row) - 1)] + [0]
    # 简化版（只算 B_n）：用 Stirling 数第二行求和
    return sum(stirling2(n, k) for k in range(n + 1))
```

> Catalan 与 Bell 的共同点是：**它们都不是「数列」，而是「一个组合类的计数函数」**。本书在这一章的暗线是——每一个特殊数背后都有一个可解释的组合结构，找到它就找到了生成函数。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **两类 Stirling 数的记号冲突严重** | 第一类有符号/无符号、第二类 `S(n,k)` vs `Stirling2`，中译本沿用英文版但读者常把两类混用；务必在动手前确认用的是哪一类 |
| 🔧 **Bernoulli 数的生成函数在 `t=0` 处要单独处理** | `z/(e^z - 1)` 在 `z=0` 有可去奇点，`B_1 = -1/2` 与 `B_1 = +1/2` 的约定在两本书里不一致，本章用的是前者 |
| **调和数的浮点计算会骗人** | `H_n` 发散极慢（~ln n），用 float 到第 10⁶ 项误差仍很小，但**反过来会让你误以为 `H_n` 有界**；用 `Fraction` 或 `mpmath` 才安全 |
| 🔧 **Catalan 数的「上百种解释」一节缺少动机汇总** | 6.9 直接抛出各种组合解释，读者难以看出它们其实是同一个递推；建议自己把每种解释都画一遍 |
| 🔧 **Bell 数的 Dobinski 公式只在参考书目里** | `B_n = (1/e) Σ_{k>=0} k^n / k!` 是很好的数值算法，但正文未给证明；需要时查 §6.9 的注释 |
| **Fibonacci 与黄金比例的幂次表达被当成玩具** | Binet 公式与「矩阵幂 + 快速幂」是线性递推的标准解法，正文一笔带过，但它在 2020 年代的并行/矩阵加速里是真家伙 |
| 🔧 **修订版可能重排本章** | 若把 Bernoulli 数与 Euler–Maclaurin 一节推得更靠前（与第 9 章渐近式合并），本章页码会变；看第 2 版时别以页码索引 |
| 🔧 **现代机器学习已部分替代「手工推导闭式」** | 本章大量技巧（求 `Σ` 的闭式）2020 年代由自动符号计算接管；**剩下值得人做的事是「选对生成函数」**，而这正是机器不擅长的部分 |
