# 附录：本书与 TAOCP 及相关教材的对照阅读地图

> **一句话**：读懂《具体数学》的关键在于认清它在 Knuth 著作谱系里的位置——**它是 TAOCP 第一卷「数学预备知识」的展开，而不是 TAOCP 的替代品**；搞清这一点，很多「为什么这本书这么写」的问题会自动消解。

> ⚠️ **本文件不是原书章节**，是原书前言「与 TAOCP 的关系」一节的展开整理。

---

## 本章地图

| 书 | 定位 | 与《具体数学》的关系 |
| --- | --- | --- |
| **TAOCP Vol. 1《基本算法》** | 算法圣经；含约 100 页 "Mathematical Preliminaries" | **前身**。具体数学是它的「展开版」，风格更闲适、单个主题更深 |
| **《具体数学》** | 上述内容的独立化与扩充 | 新增大量话题，并把最核心的想法**追溯到历史源头** |
| **TAOCP Vol. 2《半数值算法》** | 随机数、算术、多项式 | 与本书第 3 章（整数函数）、第 6 章（特殊数）、第 7 章（生成函数）互为注解 |
| **《程序构造》SICP** | 计算过程的构造 | 与本书互补：一个讲「怎么写」，一个讲「公式怎么变形」 |
| **离散数学（ Rosen 等）** | 计算机专业的入门离散数学 | 本书的**进阶版**：更少铺垫、更多技巧 |
| **《生成函数函数学》Generatingfunctionology** | 生成函数的专门方法论 | 本书第 7 章的现代版 |
| **《解析组合学》Analytic Combinatorics** | 生成函数的复分析升级 | 本书第 7、9 章的现代续集 |

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 一条对照阅读的线索

```python
# 同一个数学对象，在两本书里的「长相」与「用途」
topic_map = {
    "floor/ceil":        ("TAOCP Vol.1 第 1.2 节",            "具体数学 第 3 章"),
    "递推式求解":          ("TAOCP Vol.1 第 1.2.2 节",          "具体数学 第 1–2 章"),
    "有限微积分":          ("TAOCP Vol.1（Delta and Summation）", "具体数学 第 2.6 节"),
    "二项式系数":          ("TAOCP Vol.1 相关节",                "具体数学 第 5 章"),
    "Bernoulli 与渐近":    ("TAOCP Vol.1 附录/第 1.4 节",        "具体数学 第 6、9 章"),
    "随机数与洗牌":        ("TAOCP Vol.2 第 3.4 节",            "具体数学 第 8 章（修订版将补）"),
    "多项式与生成函数":      ("TAOCP Vol.2 第 4.x 节",            "具体数学 第 7 章"),
}

for k, (a, b) in topic_map.items():
    print(f"{k:16s}　{a}　⟷　{b}")
```

### 为什么 Knuth 要改名

```python
# 一句话版本：
#   "Concrete" = CON(tinuous) + (dis)CRETE
#   "A Foundation for Computer Science" → "Concrete Mathematics"
# 前者自认只是「计算机科学基础」之一部分且坦承自己只是 TAOCP 的预备；
# 后者强调这是「具体对象上的可控操作」，且把数学本身当成了主体而非附庸。
print("改名反映的是定位从「附属」到「独立」")
```

## 版本演进

| 年份 | 事件 |
| --- | --- |
| **1968–** | TAOCP 第一卷初版；其中的 "Mathematical Preliminaries" 是本书的直接源头 |
| **1970** | Knuth 在斯坦福开课，课程笔记逐步独立成书 |
| **1981** | TAOCP 第一卷再版；数学预备部分小幅增订 |
| **1988** | 《具体数学》第 1 版；与 TAOCP 的关系在前言中写明 |
| **1994** | 第 2 版；新增「机械求和」 |
| **1997** | TAOCP 第一卷第 3 版（ISBN 9780321635747）；与本书同步更新 |
| **2009** | Flajolet & Sedgewick《解析组合学》；本书第 7 章的现代续集 |
| **2013** | 中译本（人民邮电，ISBN 978-7-115-30810-8） |
| **2020s** | 修订版仍待出版；Knuth 持续发布 errata |

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **把本书当 TAOCP 的替代品** | 本书明确是 TAOCP 的**展开与基础**，不是替代；想学算法设计还得读 TAOCP |
| 🔧 **中译本前言对「改名原因」只是一句带过** | 前言里的双关（CONtinuous + disCRETE）中译保留了，但**为什么改名的动机过程未讲清**，本文件补上 |
| **两书的版本号容易混** | 英文第 2 版（1994）与 TAOCP 第一卷第 3 版（1997）相邻出版；**不要按页码交叉引用** |
| 🔧 **Vol. 2 与本书的关系在中文语境下被忽略** | 《半数值算法》里的洗牌与随机数，正是修订版要补进第 8 章的内容 |
| **与 Rosen 版离散数学的重叠部分被当成「重复劳动」** | 重叠是有意设计的：入门读者应先读离散数学，再进具体数学 |
| 🔧 **2020 年代的续作未在书里提及** | 解析组合学、概率编程等现代分支已是事实上的「具体数学续集」，本书未提示 |
