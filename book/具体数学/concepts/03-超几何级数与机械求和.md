# 专篇：超几何级数与机械求和

> **一句话**：第 2 章教你「怎么猜出闭式」，§5.8 教你「怎么把猜的过程交给机器」——**超几何级数是把「和式」这个黑箱变成「一个项 quotients 的比值序列」的通用语言**。

---

## 本章地图

| 概念 | 含义 | 用处 |
| --- | --- | --- |
| **超几何项** | 相邻项之比为 `r(k)` 的有理函数 | 判断一个和式是否「可机械化」 |
| **超几何级数** | `Σ_k C(a+k, b) C(c-k, d) z^k` 这类 | 本书所有经典恒等式的统一载体 |
| **Gosper 算法** | 判定不定和是否仍为超几何 | §5.8 的引擎 |
| **Zeilberger 算法（WZ）** | 自动证明超几何恒等式 | 从「验证」升级为「证明」 |
| **`,_pF_q`** | 广义超几何函数 | SymPy 与 `mpmath` 的内建对象 |
| **Pfaff / Saalschütz 变换** | 三项式与超几何之间的转换 | 简化和式的参数 |
| **`A = B`** | Petkovšek–Wilf–Zeilberger 的方法论 | 「两个和式相等」的机器判定 |

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

```python
from fractions import Fraction

# 超几何项：t(k+1)/t(k) 是有理函数
def hypergeometric_ratio(a, b, c, d, k, z):
    """返回 C(a+k,b) * C(c-k,d) * z^k 的相邻项比"""
    num = (a + k + 1) * (c - k - 1) * z
    den = (k + 1) * (b + k + 1)
    return Fraction(num, den)

# 阶乘幂与超几何符号的关系（第 5 章的桥）
def rising(x, n):
    p = 1
    for i in range(n):
        p *= (x + i)
    return p

def binom_as_hyper(n, k):
    # C(n, k) = (-n)_k / k!    —— 把二项式系数写成下降阶乘的 quotient
    return rising(-n, k) / rising(1, k)

# 「机械求和」的判定思路：先化成超几何项，再看 Gosper 是否给出闭式
def mechanical_sum(n):
    terms = [binom_as_hyper(n, k) for k in range(n + 1)]
    return sum(terms)
```

### WZ 方法的骨架

```python
# WZ 的核心：为待证恒等式构造一个「证书」F(n,k)，使得
#   F(n, k+1) - F(n, k) = G(n, k+1) - G(n, k)
# 两边求和后 telescoping，即得恒等式。机器负责找 G，人负责解释它为什么有意义。
def wz_certificate(F, n, k, depth):
    """示意结构：返回望远镜函数 G"""
    G = {}
    for i in range(depth):
        G[k + i] = F(n, k + i) * Fraction(1, (k + i + 1))
    return G
```

> 这一篇的真正结论是一句实践判断：**当一个和式能写成「相邻项比为有理函数」的形式时，你有很大概率能自动化求解；否则，「化成超几何形式」本身就是该问的第一个问题。**

| 阶段 | 演进要点 |
| --- | --- |
| **1812** | Gauss 研究 `_2F_1` 的收敛与变换 |
| **1993** | Zeilberger 的 WZ 方法；超几何自动证明的元年 |

| **2020s** | AI 辅助下，「构造 WZ 证书」这类苦活开始有自动化尝试；但**选定正确的超几何参数**仍靠人 |

## 近年研究与工业界开源实践（2015–2026）

**趋势**：机械求和在 2020 年代已经完全「后台化」——几乎没人再手写 Gosper，但它的成果渗透进每一个符号计算库与每一个算法复杂度的推导中。真正的活跃方向转向了**「非超几何」的和式**（如带对数项、带 `q`-级数、带椭圆函数的求和），这些 WZ 方法还驾驭不了。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **§5.8 认为「机械」指的是算法，不是「可靠」** | 机械求和给出的是**一个答案**，不是**一个证明**；WZ 才给出证明 |
| **超几何变换的参数顺序抄错即全盘皆错** | Pfaff / Saalschütz 变换对参数顺序极敏感；必须靠 SymPy 逐条校验 |
| 🔧 **「可机械化」的条件（相邻项比为有理函数）未点明** | §5.8 直接给结论；这一句是判断「这道题能不能交给机器」的唯一标准 |
| **WZ 证书的「为什么」无人解释** | 机器给出的 `G` 往往人看不懂；这是 2020 年代「可解释性」在形式化里的具体困难 |
| 🔧 **只对超几何有效，一旦出现 `log` / `sqrt` 就失效** | 书里未说明这一边界；2020 年代的数量级很大工作仍卡在这一限制上 |
