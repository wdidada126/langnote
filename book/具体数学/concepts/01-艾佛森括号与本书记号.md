# 专篇：艾佛森括号与本书记号体系

> **一句话**：这本书在数学史上真正的贡献之一，是**给了数学一套「代码化的记号」**——Iverson 括号让你把条件判断写进公式，`floor/ceil` 让取整变成可操纵的量，阶乘幂让「连续积」与幂函数长得一模一样。

---

## 本章地图

| 记号 | 本书写法 | 通常含义 | 备注 |
| --- | --- | --- | --- |
| **Iverson 括号** | `[P]` | 命题 P 取真为 1，否则为 0 |  Kenneth Iverson 1962，《A Programming Language》提出；由 Knuth 推广开来 |
| **下取整 / 上取整** | `[x]` / `/x/` | `floor(x)` / `ceil(x)` | 数学书常用 `⌊x⌋`/`⌈x⌉`，本书用方括号，中文排版时更易错 |
| **阶乘幂** | `x^(n)` / `x_n` | 上升 / 下降阶乘 | 与幂函数 `x^n` 形状相似，正是为了让 `Δ` 与 `d/dx` 同形 |
| **二项式系数** | `binom(n,k)` / `C(n,k)` | 同上 | 本书正文对二者交替使用 |
| **和式** | `Σ_{a<=k<b}` | 带完整边界的和 | 本书坚持写出上下界，是「可机读」的体现 |
| **Kronecker delta** | `[k=j]` | 相等为 1 否则 0 | 与 Iverson 括号同构 |
| **指示函数** | `1[P]` | 同 `[P]` | 概率论中的常见写法 |

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

```python
import math

# Iverson 括号：把「条件」塞进算术里
def iverson(pred):
    return 1 if pred else 0

# 例：用 Iverson 括号重写「不超过 x 的整数个数」
def count(x):
    return iverson(True) * math.floor(x) + iverson(x == int(x)) * 0

# 例：k 整除 n 的指示函数，可直接加进和式
def divisor_indicator(n, k):
    return iverson(n % k == 0)

# floor/ceil 的精确定义（不是四舍五入！注意负数）
for x in (-2.3, -0.1, 0.0, 0.5, 3.7):
    print(x, "->", math.floor(x), math.ceil(x))

# 上升阶乘：x^(n) = x(x+1)...(x+n-1)，与 x^n 视觉上极像，这正是本书的用意
def rising(x, n):
    p = 1
    for i in range(n):
        p *= (x + i)
    return p

# 关键恒等式：Δ x^(m) = m x^(m-1)，与 d/dx x^m = m x^(m-1) 完全一致
# 这解释了为什么本书要用阶乘幂：它让「离散微积分 = 连续微积分」
```

> 一个值得记住的判断标准：**当你发现自己写「当且仅当」却写不出一个公式时，缺的就是 Iverson 括号**——它把一个布尔值塞进数字堆里，从此「条件」变成了可以被加、乘、求期望的普通量。

## 版本演进

| 阶段 | 演进要点 |
| --- | --- |
| **1962** | Kenneth Iverson, *A Programming Language*：Iverson 括号与数组记号诞生 |
| **1970s** | Knuth 在斯坦福课上采用 Iverson 记号，逐渐取代传统 `⌊x⌋` |
| **1988 / 1994** | 具体数学第 1、2 版把这套记号系统化为全书的统一语言 |
| **1999** | Iverson 获图灵奖（2006），`APL` 的记号体系被主流数学界正视 |
| **2013** | 中译本引入这套记号；中文排版下 `[x]` 与 `[P]` 的区分更依赖上下文 |
| **2020s** | 记号本身已稳定；`numpy`/`sympy` 里的 `Boole`、`Piecewise` 是其程序化等价物 |

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **`[x]` 既是 floor 又是 Iverson 括号** | 这是本书最有名的「记号冲突」；必须靠上下文区分，遇到 `[n|m]`（整除指示）时尤其危险 |
| 🔧 **中文排版会把 `/x/` 误印成其他符号** | 部分印次把 ceil 的 `/x/` 印错；引用公式时对照英文版 errata |
| **把 `x^(n)` 读成 `x` 的 n 次幂** | 上升阶乘与幂函数在本书记号里只差一个位置；**读公式时先确认它出现在微积分（连续）还是有限微积分（离散）语境** |
| 🔧 **中译本未附完整符号表** | 英文版第 2 版有符号表，中译本把符号表散在前言里，检索不便；建议自制一份对照表 |
| **Iverson 括号在概率论中早已普及，在数学中仍不普及** | 2020 年代的做法是在概率教科书中全面使用 `[P]`；本书算是这一趋势的推动者之一 |
