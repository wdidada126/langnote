# 《具体数学》总览与阅读地图

> **一句话**：《具体数学》不是「数学课」，而是**把公式当程序操纵的技术**——它教的正是「如何可控地摆弄数学式子，从而把算法里的和式、递归、概率算到闭式」。

**中译本**：Ronald L. Graham、Donald E. Knuth、Oren Patashnik 著，**张明尧、张凡 译**，人民邮电出版社 2013-04（图灵计算机科学丛书），ISBN **978-7-115-30810-8**，XIII + 562 页，据英文版第 2 版（Addison-Wesley, 1994）译出。
**原书**：*Concrete Mathematics: A Foundation for Computer Science*, 2nd ed., Addison-Wesley, 1994（ISBN 0-201-55802-5，xiv + 657 页）。第 1 版 1988-09（ISBN 0-201-14236-8）。

**查重说明**：`book/` 下原有提到本书的地方只有 `book/books.md:108` 的一句话书评，**不存在独立的 `具体数学.md` 大纲单文件**，本次亦未创建（避免与将来的大纲版冲突）。按惯例：**本目录下的 `00-总览与阅读地图.md` 承担大纲功能**，若日后补上 `book/具体数学.md` 大纲版，请与本文件互链（本文件已预留互链说明于此）。

## 1. 元数据与作者背景

| 项 | 内容 |
| --- | --- |
| 作者 | Ronald L. Graham（数学与计算机科学，与 Erdős 合著论文约 1500 篇，Erdős 数 1）、Donald E. Knuth（图灵奖，TAOCP 作者）、Oren Patashnik（夫妇同为斯坦福计算数学教授） |
| 课程来源 | Knuth 自 **1970** 年在斯坦福开设的「具体数学」课程演化而来 |
| 直接前身 | TAOCP 第一卷《基本算法》中约 **100 页**的 "Mathematical Preliminaries"（数学预备知识）一节的**大幅展开** |
| 篇幅 | 英文版第 2 版 657 页；中译版 562 页；**500 余道习题，分六类，除研究性问题外全部给出解答** |
| 风格 | 非正式、常带幽默、**页边留有学生涂鸦**（mathematical graffiti）；沿用 Knuth 的「抓错赏金」传统 |
| 推广的记号 | **Iverson 括号** `[P]`、`floor/ceil`、`x` 的上升阶乘 `x^(n)` 与下降阶乘 `x_n`、`binomial(n,k)` |
| 排版 | 第 1 版是 Knuth 测试 **AMS Euler 字族**与 **Concrete Roman** 字体的试验场（见 Knuth, *Digital Typography* 第 18 章） |

> **「具体」(Concrete) 这个名字是一个梗**——它是 **CON**tinuous（连续）与 dis**CRETE**（离散）的融合体。Knuth 的解释是：它是对「抽象的数学」的反面补充，**Concrete = 可控地操作公式**。

## 3. 版本演进时间轴

| 年份 | 事件 |
| --- | --- |
| 1202 | Fibonacci，《算盘书》(*Liber Abaci*)，本书第 6 章 Fibonacci 数的源头 |
| 1665 | Pascal，《算术三角形》(*Traité du triangle arithmétique*)，第 5 章 Pascal 三角的源头 |
| 1970 | Knuth 在斯坦福开课，课程笔记是本书的直接前身 |
| **1988-09** | **第 1 版** *Concrete Mathematics*（Addison-Wesley，xiv + 625 页，ISBN 0-201-14236-8） |
| 1989 | Knuth, *Typesetting Concrete Mathematics*, **TUGboat 10**, 31–36 & 342 —— 该版是 AMS Euler 字体与 Concrete Roman 的试验场 |
| **1994-01** | **第 2 版**（xiv + 657 页，ISBN 0-201-55802-5）。**新增「机械求和」(Mechanical Summation) 一节**，参考文献与索引大幅扩充，几乎每页都有实质改进 |
| 1997 | TAOCP 第 1 卷第 3 版（ISBN 9780321635747）的 "Mathematical Preliminaries" 相应更新，与本书的前缀形成对照 |
| 2013-04 | **中译本**（人民邮电，ISBN 978-7-115-30810-8），据英文第 2 版译出 |
| 2020s | Knuth 持续发布 **errata**（已有多版勘误：1994、1998-01、2013 第 27 次印刷等）；Knuth 本人把本书定位为「**可以Machine-check 的教科书**」，他确认要出**修订版**，但截至 2026 年英文第 3 版仍未正式出版 |
| 2020s 趋势 | **机辅验证从「算对答案」升级为「证明恒等式」**：`A = B`、Zeilberger 的自动证明、`AlphaProof`/Lean 等助手的涌现；SymPy 的高超几何函数与 `Sum.doit()` 已能复现全书大量习题 |

> **改名这件事**：本书原本是 TAOCP 第一卷「数学预备知识」的扩充，Knuth 最初仍想沿用「计算机科学基础」这个名字。但 Knuth 认为「**Foundation for Computer Science**」暗示了「这是 CS 的全部基础」，而书的实质内容是「**具体**的计算对象上的数学」——于是和 Graham、Patashnik 一起把标题换成 *Concrete Mathematics*。这句「Concrete = CONtinuous + disCRETE」的双关，以及「本书是 TAOCP 的**预备**而非**基石**」这一定位，正是理解全书的钥匙。

## 4. 本书刻意规避 / 未覆盖的缺口

| 缺口 | 说明 |
| --- | --- |
| **生成函数与解析组合学的现代发展** | 第 7 章只讲形式幂级数与「domino 理论」；Steiner 的 **解析组合学（Analytic Combinatorics）**（Flajolet & Sedgewick, 2009）用复分析做奇点分析，本书完全没有 |
| **Petersen 图** | 第 4 章习题与第 9 章的一部分用到图论，但全书没有系统讲图论，**Petersen 图**只在习题里露面，不构成主题 |
| **现代 AI 中的注意力数学** | 2020 年代 Transformer 的注意力矩阵、温度缩放、softmax 的渐近，本书无一字提及——这是本书最大的时代缺口 |
| **机器学习里的采样与优化** | Metropolis-Hastings、MCMC、变分推断、随机梯度下降的收敛分析，本书第 8 章只覆盖**离散**概率，与今天的「概率编程」距离很远 |
| **连续概率与测度** | 第 8 章的「离散概率」，只讲离散概率；本书刻意回避测度论 |
| **计算复杂度理论** | 本书关心的是「怎么算出答案」，不是「什么时候算不出来」 |

## 6. 跨语言对照表

| 具体数学里的对象 | Python | SymPy | Wolfram 语言 |
| --- | --- | --- | --- |
| `floor(x)` / `ceil(x)` | `math.floor` / `math.ceil` | `floor(x)` / `ceil(x)` | `Floor[x]` / `Ceiling[x]` |
| `x` 的上升阶乘 `x^(n)` | 手乘 | `rf(x, n)` | `Pochhammer[x, n]` |
| `binom(n, k)` | `math.comb(n, k)`（3.8+） | ` binomial(n, k)` | `Binomial[n, k]` |
| Iverson 括号 `[P]` | `int(P)` | `Piecewise([(1, P), (0, True)])` | `Boole[P]` |
| `sum` 的封闭形式 | `sympy.Sum(...).doit()` | 同（SymPy 侧即 `Sum.doit`） | `Sum[f, {i, a, b}]` |
| Stirling 数（第二类） | 手算 / `sympy.stirling` | `sympy.stirling(n, k, kind=2)` | `StirlingS2[n, k]` |
| Bernoulli 数 | `mpmath.bernoulli(n)` | `sympy.bernoulli(n)` | `BernoulliB[n]` |
| 生成函数系数提取 | `[z^n] F(z)` → `sympy.series`/`Poly` | `sympy.series.Series` | `SeriesCoefficient` / `CoefficientList` |
| 模逆 / 中国剩余定理 | `pow(a, -1, m)`（3.8+） | `sympy.mod_inverse` | `PowerMod[a, -1, m]` |

## 7. 写作约定

每个章节文件固定包含七块内容：本章地图（表格）⟶ 核心精讲（含**教学示意、不编译不运行**的代码）⟶ 版本演进 ⟶ 经典论文与原始文献（表格）⟶ 近年研究与工业界开源实践（`gh api` 实测 star）⟶ 常见误区与本书需修正之处（≥5 行，含 🔧 行）⟶ 与其他章/其他书的联系。

> 与本书相邻笔记的分工：
> - `book/离散数学及其应用（原书第7版）.md` 是**面向计算机的入门离散数学**（集合、逻辑、图、布尔代数），具体数学是它的**进阶版**——更多技巧、更少铺垫，两者对照最有效。
> - `book/计算机科学中的数学.md` 覆盖计算机专业的数学课程全景，本书是其中「离散 + 算法分析」那一部分的深度化。
> - `book/计算机程序的构造和解释（原书第2版）/` 讲「如何让机器执行过程」，本书讲「如何让数学式子听话」——一个是计算，一个是公式操纵。
