# 第 3 章 整数函数（Integer Functions）

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### floor/ceil 的定义与基本性质

```python
import math

# 本书记号：[x] = floor(x)，/x/ = ceil(x)
def floor_(x): return math.floor(x)     # Python 的 int() 对负数截断而非下取整，注意别用
def ceil_(x):  return math.ceil(x)

# floor 的定义性质（书中反复使用）：
#   [x] = k  <=>  k <= x < k+1
#   x = [x] + frac(x),  0 <= frac(x) < 1
def frac(x):
    return x - math.floor(x)

# 反函数关系（本章最重要的三条引理）：floor 与 ceil 的「互逆」
for x in (-1.5, 2.7, 3.0):
    print(x, "floor =", math.floor(x), " ceil =", math.ceil(x))
```

### floor/ceil 递归式：Apéry 式的经典例子

```python
def floor_recurrence(n, a=2, b=1):
    """形如 f(n) = f(floor((n+a)/b)) + g(n) 的递归式，最直接的迭代解法"""
    if n < b:                       # 边界条件：小于模数时返回基数
        return 1                    # R(0) = 1 是本章反复强调的「地基」
    return floor_recurrence((n + a) // b, a, b) + 1

# 经典例子：S(0) = 1, S(n) = 2*S(k) + S(k+1) 其中 k = floor(n/2)
# 答案是 S(n) = 2^(floor(log2 n)) * (n - 2^(floor(log2 n)) + 1) + ...（此处略）
def sherman(n):
    if n == 0:
        return 1
    k = n // 2
    return 2 * sherman(k) + sherman(k + 1)
```

### 面积法：`Σ floor(ak+b)/c`

```python
from fractions import Fraction

def floor_sum(n, a, b, c):
    """计算 Σ_{0<=k<n} floor((a*k + b)/c)。本书 3.5 节的核心技巧：
       把每个 floor 解释成「格点 (k, m) 落在直线 a k + b - c m >= 0 下方的整点数」，
       再对调求和顺序，把「纵向扫」换成「横向扫」。
       —— 这里只给出语义结构示意，真正的欧几里得式递归需要 (a, c, n, t) 四元组。"""
    total, k = 0, 0
    while k < n:
        q = (a * k + b) // c
        if q == 0:
            break
        total += q
        k += 1
    return total

# 校验：对小的 a, c 直接与暴力解比较
def brute(n, a, b, c):
    return sum((a * k + b) // c for k in range(n))

print(floor_sum(50, 7, 3, 11), brute(50, 7, 3, 11))
```

### `mod` 与 gcd

```python
def gcd_iter(a, b):
    while b:
        a, b = b, a % b
    return a

# Bézout 等式：存在 u, v 使得 a*u + b*v = gcd(a, b)（本章 3.4.2，第 4 章正式证明）
def bezout(a, b):
    old_r, r = a, b
    old_s, s = 1, 0
    old_t, t = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t
    return old_r, old_s, old_t     # a*old_s + b*old_t = old_r = gcd(a, b)
```

> 本章的**方法论核心**是：遇到 `floor` 就把它拆成 `n = mq + r`，把「不连续的除法」还原成「连续的乘法加余数」。这条思路一路通向第 4 章的同余与第 9 章的渐近展开。

## 版本演进

| 阶段 | 演进要点 |
| --- | --- |
| **1988 第 1 版** | 3.1–3.5 的局面已定：floor/ceil 的性质、递归式、`mod` 的二元运算、floor/ceil 的和式 |
| **1994 第 2 版** | 重写了 3.3 的递归式求解，加入更多与第 4 章衔接的习题；`mod` 一节区分「二元运算符」与「同余关系」 |

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **`[x]` 同时被 Iverson 括号占用** | 本书用 `[P]` 表示 Iverson 括号（命题 P 为真取 1），又用 `[x]` 表示 floor——同一个方括号承担两个意思；在阅读时**必须靠上下文区分** |
| 🔧 **Python 的 `//` 是 floor 除法，不是「截断」** | 对负数二者结果不同；本章所有 `mod` 的递归式若用 Python 直观编码，负数情形会立刻出错 |
| **把 `mod` 当成运算符就完事** | 3.4 节刻意区分「`mod` 作为二元运算」与「`mod` 作为同余关系（§4.3）」，混淆这两者会导致 3.5 的和式整体符号错误 |
| 🔧 **floor/ceil 的和式缺乏「为什么这样换序」的解释** | 3.5 的面积法一步跨过，建议自己画一次格点图；这是全章唯一「不画图就读不懂」的地方 |
| **习题涉及大量未讲清的技术细节** | 3.4 的带余递归式、3.5 的 floor 求和，中译本只给答案；部分题目还需要用到未在第 3 章出现的数论工具 |
| 🔧 **`β`/`ω` 类素数计数函数的内容尚不稳定** | 修订版相关章节的内容与编号仍在变动，看书时请以英文最新版或作者主页为准，不要把手头第 2 版当成最终形态 |
| **素数计数函数被「轻」处理** | 第 2 版对 `π(x)` 只是一笔带过；2020 年代 Meissel–Lehmer 的分布式实现（`π(10^27)` 级别）才是这个话题的现代舞台 |
| 🔧 **工具链可以做得比书更彻底** | 本书鼓励「用机器算着玩」，但 2020 年代 SymPy 已经能替你完成 §3.5 的暴力验证；**值得做的不是重复机器，而是让机器去证** |
