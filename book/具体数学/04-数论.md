## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 欧几里得算法与 Bézout

```python
# 扩展欧几里得：顺手得到 Bézout 系数
def egcd(a, b):
    if b == 0:
        return (a, 1, 0)
    g, u, v = egcd(b, a % b)
    return (g, v, u - (a // b) * v)

# g = a*u + b*v，其中 u、v 就是 Bézout 系数
print(egcd(240, 46))     # (2, -9, 47)  因为 240*(-9) + 46*47 = 2
```

### 模逆与 RSA 骨架

```python
# 模逆存在当且仅当 gcd(a, m) = 1（本章 4.4 的核心结论）
def modinv(a, m):
    g, u, v = egcd(a, m)
    if g != 1:
        raise ValueError("模逆不存在：gcd(a, m) != 1")
    return u % m

# Euler 定理的验证：a^φ(m) ≡ 1 (mod m)，一旦 m 不是素数就特别容易「看起来成立」
print(pow(3, 6, 7), pow(3, 2, 7))     # φ(7) = 6，两者应相同
```

### 中国剩余定理的构造

```python
# 给定互模 m_1,...,m_r 的余数，还原 x（章末 4.6 的习题原型）
def crt(rems, mods):
    x, M = 0, 1
    for r, m in zip(rems, mods):
        M *= m
    for r, m in zip(rems, mods):
        Mi = M // m
        x += r * Mi * modinv(Mi, m)
    return x % M

print(crt([2, 3, 2], [5, 7, 11]))     # 对应的 x
```

> CRT 的现代解读：它说的是「**余数向量」与「整数」在同余意义下一一对应**——这正是 2020 年代分布式系统里「把状态拆成独立维度再 recombine」这一整套做法的数学原型。

### `φ`、`μ` 与 Euler 定理

```python
from math import gcd

def phi(n):                      # Euler's totient
    return sum(1 for k in range(1, n + 1) if gcd(k, n) == 1)

def mu(n):                       # Möbius function（§4.7）
    k, p = 0, 2
    m = n
    while p * p <= m:
        if m % p == 0:
            m //= p
            k += 1
            if m % p == 0:
                return 0
        p += 1 if p == 2 else 2
    return -1 if k % 2 else (1 if k else 1 if n == 1 else 0)

# Möbius 反转：g(n) = Σ_{d|n} f(d)  <=>  f(n) = Σ_{d|n} g(n/d) * mu(d)
def mobius_invert(f, g, divisors):
    return {n: sum(g[n // d] * mu(d) for d in divisors[n]) for n in divisors}
```

> 本章最后三节（`φ`、`μ`、Euler 定理）看似抽象，实际是**哈希函数分析、随机游走中的周期、以及符号计算中「如何把和式按整除关系重组」**的公共底座。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **「整除」定义只在正整数范围内成立** | 本书默认讨论正整数，但程序里出现负模数时会立刻翻车；`n | m` 的定义必须补上「允许负号」后再用到代码里 |
| 🔧 **Bézout 系数的符号与绝对值不唯一** | 4.3 只要求 `au + bv = gcd`，但 `(u, v)` 有无穷多组；写实现时必须固定规范（如取最小非负解），否则测试无法复现 |
| **把 Euler 定理当成费马小定理的推广就放心用** | 只有当 `gcd(a, m) = 1` 时 `a^φ(m) ≡ 1` 才成立；`m` 为合数时「看起来成立」的反例极多 |
| 🔧 **CRT 要求模数**两两互素**，正文对此强调不足** | 4.5 的前提是 `m_1,...,m_r` 互素；若用普通 CRT 处理不互素模数会静默给出错误答案，工程上必须用「合并式 CRT」显式检测 |
| **Romanian 排序的动机缺失** | §4.6 把「利用互素对的无比较排序」当练习抛出，但未解释它在历史上的动机（早期计算机没有比较指令的设计约束），直接读会不明所以 |
| 🔧 **修订版中 CRC / Nim 的位置尚不稳定** | 这两块（同余校验与组合博弈）据公开修订计划会从习题升格为正文章节，但正式版尚未出版；**看第 2 版时不要把它们的缺失当成第一章的疏漏**——它们本来就在「计划中的修订」里 |
| 🔧 **本章的工具已部分被工业库接管** | 2020 年代的 RSA/EC 实现（`openssl`、`cryptography`）直接吃掉本章的全部代码；学本章真正的收益是「**看懂别人的数论代码到底在干什么**」，而不是重写它 |
