## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 把「只给答案」变成「可自查」的流程

```python
# 第二步通常最容易卡住：中译本只给最终式子。
# 补救办法：自己再算前几项，与答案对上，再看答案的形式。
from fractions import Fraction
from math import comb

def self_check(n):
    """示例思路：任何「猜出的闭式」都先对前 5 个 n 做精确比对"""
    guesses = {
        "pascal_sum": lambda m: 2**m,                       # Σ_k binom(m,k)
        "square_sum": lambda m: (m - 1) * m * (2 * m - 1) // 6,  # Σ k^2
    }
    brute = {
        "pascal_sum": lambda m: sum(comb(m, k) for k in range(m + 1)),
        "square_sum": lambda m: sum(k * k for k in range(m)),
    }
    for name in guesses:
        ok = all(guesses[name](m) == brute[name](m) for m in range(1, 6))
        print(name, "对上" if ok else "对不上，去翻英文版")
```

### 常见「做不出来」的三类题

```python
# （1）需要构造性洞察：直接套公式没有用，得先想组合解释
# （2）需要跨章工具：第 4 章的题可能要用第 7 章的生成函数
# （3）需要机辅实验：先用小值表找模式，再回头猜
def brute_first(f, n):
    return [f(m) for m in range(n)]      # 先算出来，再看规律
```

## 版本演进

| 阶段 | 演进要点 |
| --- | --- |
| **1988 第 1 版** | 500 余道题按六类编排，除研究性问题外全部给解答 |
| **1994 第 2 版** | 习题数量与覆盖面扩充；errata 首次成体系发布 |
| **1998-01 / 2013-27th** | 多轮勘误；中文版沿用英文版印刷 |
| **2013 中译本** | 只翻译答案部分，过程被省略 |
| **2020s** | 大量习题被社区题解、视频讲解、AI 解答覆盖；**难题的「过程」不再稀缺，稀缺的是「能不能读懂别人的解法」** |
| **2026** | 英文第 3 版仍未面世；修订版据公开材料会增补习题与新增小节 |

## 近年研究与工业界开源实践（2015–2026）

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **中译本省略了全部解题过程** | 英文版附录 A 只给结论（研究性问题除外），中文版沿用；**做不出来的题必须自己补过程** |
| 🔧 **「六类习题」的编号与章号完全无关** | 一类习题会跨第 1、5、6 章；按章顺序读的人极易找不到同类题 |
| **研究性问题（research problems）无解答** | 附录 A 明确不给研究性问题解答，这是设计而非疏漏 |
| 🔧 **印刷错误需要自己核对 errata** | 尤其第 5 章超几何变换的下标与第 9 章余项符号，在不同印次间有过修正 |
| 🔧 **AI 解答不可用直接抄** | 2020 年代 AI 能给出答案，但**本书的答案是「结论」，过程仍需自己建立**；把 AI 当答案机，等于放弃本书 80% 的价值 |
| **习题难度分布不均** | 同一章里前 3 题是热身、后 3 题是竞赛题；**卡住超过半小时应换题**，别硬碰 |
