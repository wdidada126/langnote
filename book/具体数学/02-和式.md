# 第 2 章 和式（Sums）

> **一句话**：如果第 1 章是全书的总纲，那么第 2 章就是全书的技术核心——**把「递归式」翻译成「和式」，再用一整套操纵技巧把它压成闭式**，这是全书后面七章的全部语言。

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 扰动法：加一项再减一项

```python
from fractions import Fraction

def alpha(n): return n**2            # 要算 Σ_{0<=k<n} k^2

# 扰动法的思路：S(n) = S(n-1) + f(n)，两边同乘后再相减
# 对 Σ k^2 而言，扰动 (k+1)^3 - k^3 = 3k^2 + 3k + 1 是关键恒等式
def perturb_check(n):
    lhs = (n + 1)**3 - 0**3                 #  telescoping 后的两端
    rhs = 3 * sum(alpha(k) for k in range(n)) + 3 * sum(k for k in range(n)) + n
    return lhs, rhs, lhs == rhs

# Σ_{0<=k<n} k^2 = (n-1)n(2n-1)/6
def sum_of_squares(n):
    return (n - 1) * n * (2 * n - 1) // 6
```

### repertoire method：猜参数、解线性系统

> 这是第 2 章最有名、也最「不像数学」的技巧：先对一小族和式猜一个带未知系数的闭式，再用**已知的简单情形**把这些未知数解出来。

```python
from fractions import Fraction

# 要计算 K(n) = Σ_{0<=k<n} S_k(n)，其中 S_k(n) 是 k 的 k 次多项式
# repertoire 的做法：猜 K(n) = A(n)C + B(n)D + C'(n)E + ...，再代入简单情形解系数
def repertoire_demo(S_fn, cases):
    """
    S_fn: 给定的和式项；cases: [(n, 已知和式值)]，用来解出未知系数
    """
    unknowns = ["A", "B", "C"]
    rows = []
    for n, known in cases:
        # 每一行 = [基函数1(n), 基函数2(n), ..., 已知值]
        rows.append([Fraction(n**k) for k in range(len(unknowns))] + [Fraction(known)])
    # 只需真正做高斯消元；此处给出结构示意
    return rows

# 典型例子：算 Σ_{0<=k<n} S_k(n) 时，取 S_0=1, S_1=n, S_2=n(n-1)... 逐条解
```

### 有限微积分：`Δ` 与 `Σ` 的整套类比

```python
# 类比值：微积分里 ∫_a^b f' = f(b) - f(a)；有限微积分里 Σ_{a<=k<b} Δf(k) = f(b) - f(a)
def delta(f):
    return lambda k: f(k + 1) - f(k)

def telescoping(f, a, b):
    terms = [f(k) for k in range(a, b + 1)]
    # Σ Δf = f(b) - f(a)，这里只是把两端相加验证
    return sum(delta(f)(k) for k in range(a, b)), f(b) - f(a)

# 关键的「幂函数」：x^(m) = x(x+1)...(x+m-1)，满足 Δ x^(m) = m x^(m-1)
def rising_factorial(x, m):
    p = 1
    for i in range(m):
        p *= (x + i)
    return p

# 于是 Δ x^(m) / m = x^(m-1)，与 d/dx x^m = m x^(m-1) 完全一致
print(telescoping(lambda x: rising_factorial(x, 3), 0, 5))
```

> 记住这张对照表，第 2 章后面就全是微积分了，只不过把 `dx` 换成了 `1`：
> `d → Δ`、`∫ → Σ`、`x^m → x^(m)`、`e^x → 2^x`。

## 版本演进

| 阶段 | 演进要点 |
| --- | --- |
| **1988 第 1 版** | 扰动法与 telescoping 已在；但「机械求和」的思想未成型 |
| **1994 第 2 版（重大变化）** | **新增 2.5 节「机械求和」(Mechanical Summation)**——把 repertoire 与有限微积分做成「可执行的算法」，这是第 2 版相对第 1 版最重要的新增内容之一 |
| **1998 第 1 次 errata / 2013 第 27 印** | 与 TAOCP 第一卷同步修正多种印刷错误 |
| **2013 中译本** | 张明尧、张凡译本据第 2 版译出；「机械求和」一节完整保留 |
| **2020s–** | 「机械求和」在符号计算里已经从技巧变成**库**：SymPy 的 `Sum.doit()`、超几何级的 Gosper 算法、Zeilberger 的 WZ 方法都在做同一件事；Knuth 的修订版据透露会进一步强化这一节 |
| **2020s AI 趋势** | 2020 年代的大模型与自动形式化把「猜闭式」的体力活大量接走，但**「选哪种方法」仍然靠人**——repertoire 的核心思想至今未被自动化取代 |

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **`Σ` 的边界约定比通常数学书更「重」** | 本书坚持用 `Σ_{0≤k<n}` 这样的完整上下界，并强调「`_` 与 `^` 是记号的一部分」；读者若沿用其他书的省略写法，在本章的 telescoping 中极易错位一项 |
| 🔧 **repertoire method 的讲解节奏偏快** | 2.3 节直接抛出带三个未知数的一次方程组，对第一次接触的人不友好；建议先手算 `S_1`、`S_2` 两个特例再回头看 |
| 🔧 **习题极难且中译本只给答案** | 2.4–2.6 的习题（如 2.30、2.52）需要真正的构造性洞察，中译本答案页只给最终式子，建议对照英文版与社区题解 |
| **把「有限微积分」当成微积分的近似** | 恰好相反：`Σ` 是**精确**的离散运算，`∫` 是它连续化的近似；本书 2.6 节把方向说反了才不易错 |
| 🔧 **`x^(n)` 与 `x_n` 的上下标方向易混** | `x^(n)` 上升、`x_n` 下降；在 telescoping 里用错方向会得到「差一错误」，这是本章最常见的一类错题 |
| 🔧 **现代工具已能替代手工 repertoire** | 2020 年代 SymPy 能对大量 §2.5 的和式直接求闭式；「机械求和」在书里是技巧，在外面是**库函数**——学习方法本身的价值在于理解「为什么机器算得出来」 |
| **无穷和式的收敛被轻描淡写** | 2.7 节对收敛只是点到为止，2020 年代若把这套记号用于解析组合学的奇点分析，会立刻需要复分析补丁 |
