## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### `O` 是集合，不是常数

```python
# 记号：[f(n) <= O(g(n))] 表示「f 属于 g 的阶为至多 g 的集合」
# 三条最常用的运算法则：
#   O(f) + O(g) = O(max(f, g))
#   O(f) * O(g) = O(f*g)
#   O(f) + O(f) = O(f)
def o_of(g):
    return lambda n: g(n)          # 示意：O(g) 是一个「函数族」的标签

# 常见错误：把 O(g(n)) 当成一个数去做减法
#   O(n^2) - O(n)  ≠  O(n^2) 不成立；正确写法是 O(n^2) + O(n) = O(n^2)
```

### 从和式到积分

```python
import math

# 核心思想：Σ_{k=1}^{n} f(k) 与 ∫_1^n f(x) dx 的差，被 f 的导数控制
# 用矩形法/梯形法把和式与积分画在一起（示意数据）
def comparison(f, n, steps=1000):
    rect = sum(f(k) for k in range(1, n + 1))
    integral = sum(f(a + (b - a) * i / steps) * (b - a) / steps
                   for i in range(steps + 1) for a, b in [(1, n)])
    return rect, integral
```

### Euler–Maclaurin：把求和变成积分加 Bernoulli 修正

```python
from fractions import Fraction

# Σ_{a<=k<b} f(k) = ∫_a^b f(x)dx + (f(a)+f(b))/2
#                 + Σ_{j>=1} B_{2j}/(2j)! * (f^{(2j-1)}(b) - f^{(2j-1)}(a)) + R_m
# 其中 B_{2j} 是第 6 章的 Bernoulli 数——这是两章的枢纽

def bernoulli_numbers(upto):
    from math import comb
    B = [Fraction(1)]
    for m in range(1, upto + 1):
        total = sum(Fraction(comb(m + 1, k)) * B[k] for k in range(m))
        B.append(-total / (m + 1))
    return B

# 调和数的渐近：H_n = ln n + γ + 1/(2n) - 1/(12n^2) + O(1/n^4)
def harmonic_asy(n):
    return (math.log(n) + 0.5772156649015328
            + 1 / (2 * n) - 1 / (12 * n**2))

print(harmonic_asy(1000), float(sum(Fraction(1, k) for k in range(1, 1001))))
```

### 「两个技巧」的实际用法

```python
# 技巧一：用已知展开倒推。已知 H_n = ln n + γ + O(1/n)，求 Σ_{k=1}^n H_k 的展开
#   Σ_{k=1}^n H_k = n ln n + (γ - 1)n + O(log n)
# 技巧二：把余数写成积分（§9.4），用它证明余项的符号与阶
#   H_n - ln n - γ = O(1/n) 的严格证明靠一个单调性的积分比较
```

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **`O` 被当成常数用** | 本章反复强调 `O(g)` 是**函数集合**；把它当数字做减法（`O(n²) - O(n)`）是本节最典型的错误 |
| 🔧 **§9.4「两个技巧」的命名不统一** | 中译本把 §9.4 的小标题译法在不同印次有差异，指的是「用已知展开倒推」与「把余数写成积分」两招 |
| **Euler–Maclaurin 的余项是发散的，正文未强调** | 展开项 `B_{2j}/(2j)! f^{(2j-1)}` 在某一点后必然放大；这是数值实现中最关键的一点，纸面数学书常略去 |
| 🔧 **中译本 §9.5 的余数项符号约定与英文版略有出入** | 不同印次的勘误里对 `R_m` 的符号有过修正；引用公式时务必核对所用印次的 errata |
| 🔧 **习题（9.10–9.50）极难，且只给答案** | 特别是「用 Euler 求和公式展开 `d(n)`」那批，需要同时对第 4 章的除数函数有熟悉；建议准备重读第 4 章再来 |
| **常数被渐近分析系统性忽略** | 本书的 `O` 是量级符号；2020 年代的系统工程（缓存、分支预测、SIMD 宽度）里，**常数往往比量级更能决定成败** |
| 🔧 **修订版可能加入数值稳定性内容** | Euler–Maclaurin 余项的实用截断策略是修订版据称的补强方向之一；第 2 版在这块偏理论 |
| 🔧 **`O` 记号在 2020 年代需要补上并行度与硬件层级** | 现代复杂度讨论必然带上「内存层次」与「并行度」，而 §9.1 的层次表只到 `O(n!)` 级别 |
| 🔧 **机器可以替你算渐近展开** | SymPy 的 `asymptotic_expansion` 一行给出本章大部分公式；**机器负责「算」，人负责「判断该展开到几项」**——这才是第 9 章留给读者的东西 |
