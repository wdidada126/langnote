# 第 1 章 递归问题（Recurrent Problems）

> **一句话**：本章是全书的**总纲**——作者用三个「看起来毫不相关」的问题（河内塔、平面直线、约瑟夫）演示同一件事实：**只要问题具备递归结构，归纳法就能一次性给出答案**。

---

## 本章地图

| 节 | 内容 | 结论 |
| --- | --- | --- |
| 1.1 | 递归问题的性质 | 一个问题是「递归的」当且仅当它能拆成更小的同构子问题；**边界条件（boundary conditions）必须显式列出** |
| 1.2 | 河内塔（Tower of Hanoi） | 经典递推 `T(n) = 2T(n-1) + 1`；** movable 圆盘编号与最佳解序列可由位运算直接给出** |
| 1.3 | 平面上的直线 | n 条直线最多把平面分成 `L(n) = (n³ + 5n + 6)/6` 个区域；递推来自「第 n 条直线穿过已有 n-1 条交点」 |
| 1.4 | 约瑟夫问题（Josephus Problem） | 递推式 `J(n)` 的分段解；更一般的 `J(n,d)` 与 **Dawson 函数** |
| 1.5 | 归纳的诀窍 | 把归纳法从「验证」升级为「猜测 + 证明」；**用「最小反例」做反证**是本书反复强调的技巧 |
| 1.6 | 习题 | 六类习题中的第一类；本章习题是全书写得最狠的部分 |

## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 三个递推式的同构本质

```python
# 方法 1：直接按递推式算（书中 1.2 的起点）
def towers(n):
    return 2 * towers(n - 1) + 1 if n else 0

# 方法 2：闭式。注意 T(n) = 2^(n+1) - 1，这一眼看出是靠「1 = 2 - 1」的 telescoping
def towers_closed(n):
    return (1 << n + 1) - 1

# 平面直线数区域：a(n) = a(n-1) + n，边界 a(0) = 1
def regions(n):
    a, seq = 1, [1]
    for k in range(1, n + 1):
        a += k
        seq.append(a)
    return seq[-1], seq

# 约瑟夫（d = 2 的经典情形，仅当 n 为偶数时的递推）
def josephus_even(n):
    if n == 0:
        return 0
    if n % 2 == 0:
        return 2 * josephus_even(n // 2) - 1
    return 2 * josephus_even(n // 2) + 1
```

> 三个函数「长得不一样、背景完全不相干」，但**都是同一个动作**：把规模 n 的问题拆成规模 n-1（或 n/2）的同构子问题。这正是第 1 章想说的一切。

### 归纳不是「猜」，而是「把边界钉死」

```python
# 归纳证明的机器化骨架：先算小值，再猜闭式，再验证归纳步
def guess_and_prove(f, n):
    base = {0: f(0)}                       # 边界条件：归纳的「地基」
    for k in range(1, n + 1):
        base[k] = f(k)
    closed = lambda k: (k + 1) * k // 2 + 1   # 猜出来的闭式
    mismatches = [k for k in base if base[k] != closed(k)]
    return "边界全部对上" if not mismatches else mismatches

# 注意：这只负责「看」，不负责「证」——证的是归纳步 R(n) => R(n+1)
```

### 位运算视角的河内塔（书中 「moves 的编号」练习）

```python
# 圆盘 k 在最佳解中第 2^k 步（从 0 计数）移动。用奇偶决定方向：
def hanoi_moves(n, src=0, dst=2, via=1, out=None):
    if n == 0:
        return out
    hanoi_moves(n - 1, src, via, dst, out)
    out.append((n, src, dst))              # 圆盘 n 从 src 移到 dst
    hanoi_moves(n - 1, via, dst, src, out)
    return out

# 最小反例技巧：断言「不存在更小的反例」等价于检查前半段
assert hanoi_moves(3, out=[]) == [(3, 0, 2), (1, 0, 2), (2, 0, 1), (1, 2, 1), (3, 0, 2), (1, 0, 1), (2, 1, 2), (1, 1, 2)]
```

> 第 1 章的精髓在这一行注释里：**数学归纳法不是「证明术」，而是「构造术」**——你先承认「更小的都成立」，剩下的那一步往往会自动浮现出解法。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **「边界条件」被读者跳过，导致整章白读** | 1.1 明确要求显式写出 `R(0) = 1` 之类的边界，但很多读者直接从 `R(n)` 的递推看起；**没有边界就没有归纳**，后面所有闭式都无从证起 |
| 🔧 **习题（1.10–1.28）远难于正文，且解答不友好** | 中译本只给最终答案不给过程，Dawson 函数、带重复圆盘编号的河内塔变体尤其劝退；建议对照社区题解与英文版 errata 一起读 |
| **把归纳法当成「代入验证」** | 本章反复强调归纳是**构造性**的：归纳步给出的往往是算法，而不是一句「易证」 |
| 🔧 **记号 `x^(n)` 的含义反直觉** | 本书用 `x^(n)` 表示**上升阶乘** `x(x+1)...(x+n-1)`，而上标括号在其他数学书里常指 n 次幂；**看到 `^(n)` 先查符号表**（见 `concepts/01-艾佛森括号与本书记号.md`） |
| 🔧 **第 1 章被误当成「简单入门章」** | 事实上本章是全书写得最幽默、习题最难的一章；跳过它直接读第 2 章的人，在 repertoire method 处会集体卡死 |
| **河内塔的「最佳」缺少下界证明** | 正文给出 2^(n+1)-1 步的解，但**最优性**的证明需要「规模论证」；部分读者误以为作者已证最优 |
| 🔧 **修订版尚未成形，勘误散落** | 英文第 3 版至今未正式出版，errata 只在作者个人主页零散发布；本章若有印刷错误需自行核对最新版勘误 |
