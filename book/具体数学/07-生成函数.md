## 核心精讲

> **教学示意，不编译、不运行，也不参与构建。**

### 系数提取：本书的「探针」

```python
# 记号约定：F(z) = Σ_{n>=0} a_n z^n，[z^n] F(z) = a_n
# 三个最基本的探针动作：
#   [z^n] (1 + z)^N = binom(N, n)
#   [z^n] 1/(1 - z) = 1
#   [z^n] z^k * f(z) = [z^(n-k)] f(z)      （移位）
coeffs = lambda f, n: f.coeff_monomial(z, n)

# 用有理函数做「自动展开」（示意结构，SymPy 里用 series / Poly 完成）
def extract(f, n):
    return f.coeff(z, n)
```

### 卷积：把组合求和变成乘法

```python
# 找零问题（§7.1）：用 {1, 5, 10, 25} 凑 n 分，方案数
def change_ways(n):
    import numpy as np
    coins = [1, 5, 10, 25]
    dp = np.zeros(n + 1, dtype=np.int64)
    dp[0] = 1
    for c in coins:
        for amount in range(c, n + 1):
            dp[amount] += dp[amount - c]
    return dp[n]

# 这就是「生成函数乘积 = 卷积」的事实版本：
#   (Σ 1/(1 - z^c)) 的系数展开 = Σ_c 展开后的卷积系数
```

### 用生成函数解递归式

```python
from sympy import symbols, Function, solve, binomial, Sum, factorial

# R(n) = R(n-1) + n (n>=1), R(0) = 0  ⟷  R(z) = R(z)/z ... 的代数化过程示意
# 更实际的做法：直接交给符号计算库
def solve_recurrence(expr, n):
    return Sum(expr, (n, 0, None)).doit()

# Fibonacci 的 Binet 式：F(z) = z/(1 - z - z^2)，系数提取即得 Binet 公式
# [z^n] z/(1-z-z^2) = (1/sqrt(5)) * φ^n - (1/sqrt(5)) * ψ^n
```

### 指数生成函数与「标号结构」

```python
import math

# 普通生成函数处理「无序组合」，指数生成函数处理「有标号的结构」：
#   把 n 个标号元分成 k 个标号块，方案数 = binom(n, k) * c(k) （数据丢失，示意）
def egf_to_n_exponential(egf_coeffs, n):
    return egf_coeffs[n] * math.factorial(n)   # 从 EGF 系数还原计数
```

> 本章真正要记住的**只有一句话**：`A(z)B(z)` 的第 n 项系数 = 「先从 A 取 i、再从 B 取 n-i」的**所有配对之和**。其余全是这句话的翻译：拼图、找零、树计数、随机走步。

## 常见误区与本书需修正之处

| 问题 | 说明 |
| --- | --- |
| 🔧 **形式幂级数是否收敛，本书几乎不谈** | 本书把 `F(z)` 当**纯代数对象**用，这与 2020 年代解析组合学（复分析 + 收敛半径）的路线不同；看到 `1/(1-z)` 时务必分清你在用哪一套 |
| 🔧 **`[z^n]` 的用法在本章后段被大量省略** | §7.2 后作者常直接写「`A(z)` 的第 n 项系数是…」而不写出 `{z^n}`；初读极易漏掉这个记号 |
| **EGF 与 OGF 的选择是直觉活** | 「无序/组合 → OGF；有标号/结构 → EGF」；选错了会得到错误的闭式，而 **SymPy 无法替你选** |
| 🔧 **指数生成函数的「数据丢失」一句话带过** | §7.6 提到「信息丢失」但没说清是哪一步丢的；这是本章最需要自己补的一段 |
| 🔧 **Dirichlet 生成函数（7.7）与前面几节几乎脱节** | 它是第 4 章 `μ`/`φ` 的延续，但正文把它放在生成函数章末，读者容易误以为它是「新主题」 |
| **分拆数只当作例子** | 分拆数的渐近（Hardy–Ramanujan）是 2020 年代组合学最活跃的一支，本书仅一笔带过；修订版据称会补强 |
| 🔧 **现代工具链让本章的「技巧」价值下降** | 2020 年代 `sympy.Poly(z, n).series` 一行就能展开到任意项；**本章真正的训练价值在于「看出该用哪个生成函数」**，而不是展开本身 |
| **概率生成函数被推到下一章** | §7.5 与第 8 章的 PGF 之间有一条未点明的桥，建议读者主动补上（这也是修订版想补的方向之一） |
