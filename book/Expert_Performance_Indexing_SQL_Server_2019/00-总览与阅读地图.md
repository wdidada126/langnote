## 5. 🔧 类比实测纪律（本波全册适用）

- SQL Server **不可本机实测**：索引结构/统计信息/临时表等一律 ⚠️ 转述 + Microsoft Learn
  ✅ URL；禁止伪装实测。
- 概念类比只用 python sqlite3 3.45.3、CLI 3.50.6、DuckDB 1.5.5，且每处标注
  **「非本书引擎行为，仅结构语义类比」**。本册 ≥4 组类比，分布：
  1. ch1：EXPLAIN QUERY PLAN 全表 SCAN → CREATE INDEX 后 SEARCH（B+树定位语义）；
  2. ch2：dbstat 每对象页数（ix_cov 1128 页 vs ix_partial 1 页）+ 覆盖索引计划；
  3. ch3：ANALYZE 前后 sqlite_stat1（`200000 40 39 1`）与计划对比；
  4. ch7：SQLite FTS5 倒排索引 MATCH/snippet（对应全文索引语义）；
  5. ch9：REINDEX 计时 + 多索引写放大计时；
  6. ch12：TEMP 表 + temp 索引计划；
  7. ch14：DuckDB 无二级索引时 SEQ_SCAN+Filters 计划、列裁剪 Projections（对照 8 页布局）。
- 输出存 D:\develops\tmp\dbwave_w4_idx19\demo_out.txt，repo 内零构建产物。
