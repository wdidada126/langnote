## 三、主打背景：MySQL ⇄ MariaDB 分叉史与 2026 版本线现状

本书 2019 年立论的前提——"MariaDB 是可信的开源数据库解决方案"——完全建立在分叉史之上，故在 00 专设此节取证（✅=实抓，⚠️=转述）。

| 时间 | 事件 | 状态与出处 |
| --- | --- | --- |
| 1995–1996 | Monty（Michael Widenius）等创建 MySQL；3.20 起密码挑战-应答协议（"从不明文发送口令"，且早期哈希仅 32 位） | ✅ mariadb.org 官方博客 Sergei Golubchik《Who are you? The history of MySQL and MariaDB authentication protocols from 1997 to 2017》(2017-03-22) 实抓 |
| 2008-01 | MySQL AB 售予 Sun | ⚠️ 广闻事实；本次未取到 dev.mysql.com 一手存档页 |
| 2009-04 → 2010-02 | Oracle 宣布收购 Sun → 完成；社区担忧 GPL 库被控制，Monty 分支 MySQL 创 MariaDB（命名自其女 Maria） | ⚠️ 转述（mariadb.org/about 未载逐日期）；"made by the original developers of MySQL" 一句 ✅ 实抓 |
| 至今 | mariadb.org 官方自述："MariaDB Server is one of the most popular database servers in the world. It's made by the original developers of MySQL and guaranteed to stay open source… Originally designed as enhanced, **drop-in replacement for MySQL**"，GPLv2 许可 | ✅ mariadb.org/about 实抓（2026-09-27） |
| 反向取证 | **dev.mysql.com 的沉默**：curl 直连 403（Akamai 拦截）；浏览器态可得的 Refman 8.4 "What Is New in MySQL 8.4"（mysql-nutshell）实测**通篇零次提及 MariaDB**——Oracle 官方手册不设 MySQL vs MariaDB 对比页 | ✅ 实测结论（含"取证缺口"声明：403 页只作书目引用不作内容依据） |
| 兼容性官方口径 | MariaDB 官方兼容性页：`.frm` 与数据文件二进制兼容；**GTID 与 MySQL 5.6 不兼容**；"All MySQL connectors (PHP, Perl, Python, Java, .NET…) work unchanged with MariaDB"；**JSON 在 MariaDB 是 TEXT/BLOB 别名**、MySQL 8 为二进制类型；MariaDB 不支持 MySQL 5.7 X 协议；捆绑 Spider/Aria 等引擎而 MySQL 聚焦 InnoDB | ✅ mariadb.com/docs "MariaDB versus MySQL - Compatibility" 实抓（WebFetch，2026-09） |

### 2026 现状：10.x → 11.x → 12.x LTS 版本线（✅ mariadb.org/about 维护表实抓）

| 版本线 | GA | Community EOL | 定位 |
| --- | --- | --- | --- |
| 10.4 | 2019-06-18 | 2024-06-18 | 本书出版年基线，**已过保** |
| 10.5 / 10.6 | 2020-06 / 2021-07 | 2025-06 / **2026-07-06** | 10.6 即将出保——存量库升级窗口 |
| 10.11 | 2023-02-16 | 2028-02-16 | LTS 长线（三列同 2028：无延展差异） |
| **11.4** | 2024-05-29 | **2029-05-29** | LTS；Enterprise/Extended 至 2030/2033 |
| **11.8** | 2025-06-04 | 2028-06-04 | LTS；Extended 至 2033-10 |
| **12.x** | 12.3 GA **2026-05-28** | 12.3→2029-06-12 | 年度 LTS 节奏（mariadb.org："A new LTS is announced yearly"）+ 季度滚动发布，官方给出 2025–2031 GA 节奏图 |

结论（本册视角）：2019 年"迁到 MariaDB"的可行性论证今天已被 11.x/12.x LTS 线和 MariaDB 公司化运营背书，但**分叉 15 年后"兼容"只剩外壳**：GTID、JSON、认证插件、版本号语义均已各走各路——这正是本目录 🔧 类比节要拆开讲的事。

## 六、🔧 类比实验总表（全目录 4 组，本机真实跑过，均为**非 MariaDB 行为**）
