# 《Pro TypeScript》考古档 01 · TS 0.8 时代语境

> ⛔ 全档基于 2012 前代语境（*Pro TypeScript*，Fenton，Apress 2012，TS 0.8 前夜写成）。
> ⚠️ 凡 0.8 时代细节凭记忆，未破墙核对原书；以原书影印/版权页为准。本节每条独立标 ⚠️。
> 证据三态：✅=本机 node v22.14 `--experimental-strip-types` 实测｜⚠️=记忆/推断｜🔧=可复演实验位。

## 一、0.8 时代语境逐条（当年「有」或「无」）

| # | 语境点 | 2012 状况 | 置信 |
|---|---|---|---|
| 1 | 联合类型 | **无**。多类型入参靠 `any` + 运行时手工判断，或函数重载签名堆叠 | ⚠️ |
| 2 | 类型收窄 narrowing | **无机制**。`typeof` 判断写了也不改变后续检查（对照今日流式收窄） | ⚠️ |
| 3 | 字面量类型 | **无**。字符串/数字面量一律并入基元类型，判别联合无从谈起 | ⚠️ |
| 4 | 注解风格 | 尖括号断言 `<string>x` 为主流写法（`as` 并行存在但书里偏爱前者） | ⚠️ |
| 5 | 泛型 | 0.9 前刚落地雏形，**基本不做推断**，调用点常手动 `f<number>(x)` | ⚠️ |
| 6 | `class` | TS 自有糖（属性声明+构造赋值），ES2015 class 尚未普及，两者形状不同 | ⚠️ |
| 7 | 模块 | 只有 `module X {}` 关键字，`namespace` 别名是后话（1.5 ⚠️），内外双模块并存混沌期 | ⚠️ |
| 8 | strict 家族 | 无 `strictNullChecks`，`undefined`/`null` 可赋值给一切类型——空安全整体失守 | ⚠️ |
| 9 | 工具链 | tsc 是 .NET 二进制 + Visual Studio 集成，npm/命令行生态未成形；书Ⅰ部全数 ⛔ 失效 | ⚠️ |
| 10 | 新增关键字 | `any`/`class`/`module`/`enum` 是 TS 向 JS 世界新放的棋子，`interface` 惯例未定型 | ⚠️ |

## 二、书的论辩面（考古真正价值）

- 本书通篇为「JS 上规模需要静态超集」辩护：类型=**开发者协作契约**而非证明论工具——这是 Anders 设计动机时代的社区回声，与后来「类型层图灵完备」路线（4.x）已属两个物种。⚠️ 归纳
- 前 `interface` 惯例时代：命名/注解风格与今日相反的案例集中区，读Ⅱ部时逐章摘录「当年写法」即可，勿把 2012 惯例当 TS 正统（00 档第一节已警示）。
- Ⅳ部 jQuery/ASP.NET 栈：⛔ 按 00 档口径跳过，不入对照表。
- 「重载当类型设计」惯例：今日用联合或 options 对象处，2012 只能签名堆叠——书中重载出场密度本身就是联合缺席的负片。⚠️ 依 00 档骨架判读，未逐章核对
- 默认参数/`void` 姿势带强 C#/Java 余韵（Anders 系出身），`undefined` 语义当时尚未与 `null` 分层。⚠️

## 三、🔧 断层实测（✅ 2026-10 node v22.14，脚本位 `/tmp/tsexp/`）

1. ✅ **尖括号断言是硬断层**：`const s = <string>pick("x","y");` 在 `--experimental-strip-types` 下拒载，报 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX: The angle-bracket syntax for type assertions ... use 'as'`——2012 主流写法在今日纯擦除管线**直接跑不起来**（exit=1）。
2. ✅ **纯擦除等价物通过**：同一段 2012 风格代码（`any` 注解 + `as` 断言 + `<T>` 泛型注解）改写后 strip-types 跑通（exit=0）——0.8 的**类型层**缺席是语义差距，**擦除层**今昔等价：删掉注解后就是当年能跑的 JS。
3. ✅ `enum`：strip-only 拒载（exit=1），`--experimental-transform-types` 通过（exit=0）——0.8 时代即有的 `enum` 属「会产码」语法，是纯擦除边界的界碑（销了 Runtime_vs 专题第五节一条待补项）。
4. ✅ `namespace`：同上，strip-only 拒载、transform 通过——Ⅲ部「模块雏形」的产物同样越过擦除线。

结论：**语法平面的 2012→今断层只有一处（尖括号断言）+ 产码语法对擦除管线的抵触（enum/namespace）；其余差距全在类型平面**，即下一档年表的内容。⚠️ 判读
