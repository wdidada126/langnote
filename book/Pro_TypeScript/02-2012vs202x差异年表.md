# 《Pro TypeScript》考古档 02 · 2012 vs 202x 差异年表

> ⛔ 全档基于 2012 前代语境（*Pro TypeScript*，Fenton，Apress 2012，TS 0.8 前夜）；「2012 状况」列即本书读者当年的真实世界。
> ⚠️ 凡 0.8 时代细节凭记忆，以原书影印/版权页为准；**「引入大版本」列全部版本号均凭记忆未经破墙核对，逐行 ⚠️**。
> 证据三态：✅=本机 node v22.14 `--experimental-strip-types` 实测｜⚠️=记忆/推断｜🔧=可复演实验位。

## 一、0.8 语境锚点（速览，详见 01 档）

2012 年类型系统的全部家当：基元 + `any` + `void` + `interface` + 早期 `class`/`module`/`enum` + 不做推断的泛型雏形。没有下面年表里的任何一行。⚠️

## 二、差异年表：机制 → 2012 状况 → 今正解 → 引入大版本

| 机制 | 2012 状况（书中世界） | 今正解 | 引入大版本 ⚠️ |
|---|---|---|---|
| 泛型推断 | 泛型刚落地，调用点惯于手写 `f<number>(x)`；返回值推断弱 | 上下文推断 + 协变返回（`T[]` 形状保留），多数调用点省略类型实参 | 雏形 0.9 ⚠️；推断大改 1.6 ⚠️；this 型方法链 2.2 ⚠️ |
| 联合类型 | **无**。多形态入参 = `any` + 运行时手工判断或重载堆叠 | `A \| B` 一等公民，配判别联合成为状态建模默认姿势 | 1.4 ⚠️ |
| 收窄 narrowing | **无**。类型判断不改变后续检查流 | `typeof`/`in`/类型谓词 `x is T`/可判别 tag 自动流式收窄 | 随 1.4 起步、2.0 成型 ⚠️ |
| 字面量类型 | **无**。字面量并入基元类型 | `'ok' \| 'err'` 字符串/数字/布尔字面量 + `as const` | 1.8 ⚠️；`const` 断言 3.4 ⚠️ |
| 映射类型 | **无**。`Pick`/`Omit` 不存在，工具类型只能手写 | `{ [K in keyof T]: … }` + key remapping，工具类型族标准化 | 2.1 ⚠️；`as` 重映射 4.1 ⚠️ |
| 条件类型 / `infer` | **无**。类型层无「如果」 | `T extends U ? X : Y` + `infer` 解构，类型层可编程的分水岭 | 2.8 ⚠️；递归条件 4.1 ⚠️ |
| 模板字面量类型 | **无**（当年连字符串插值都还是 JS 侧新事） | `` `prefix${string}` `` 参与类型运算，路由/event 名建模 | 4.1 ⚠️ |
| strict 家族 | `null`/`undefined` 畅通无阻，`any` 静默吞错；无一键严格 | `strictNullChecks` 为最大单点事件，`--strict` 聚合开关成脚手架默认 | null 检查 2.0 ⚠️；`--strict` 聚合 2.3 ⚠️ |
| 装饰器 | **无**。元编程空白（书中Ⅳ部以手写包装函数凑合） | 先 stage-1 实验装饰器、后对齐 TC39 标准装饰器，两制并存需开关切换 | 实验 1.5 ⚠️；标准对齐 5.0 ⚠️ |
| `unknown` | **无**（`any` 是唯一顶类型） | `unknown` 真顶类型 + 必须收窄，`any` 降级为受控逃生口 | 3.0 ⚠️ |

⚠️ 注：版本行以 microsoft/TypeScript wiki 历史页为最终裁决；本表价值在「机制有无对照」，版本号仅作粗定位，引用勿当一手。
