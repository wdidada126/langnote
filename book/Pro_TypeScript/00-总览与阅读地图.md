# 《Pro TypeScript》——总览与阅读地图（⛔ 时效警戒档）

> 目标书：*Pro TypeScript: Application-Scale JavaScript Development*，Steve Fenton，Apress，**2012**，ISBN ⚠️9781430241942（凭记忆，未破墙）。
> ⛔ 本书基于 **TypeScript 0.8 前夜**的初代设计写作——泛型推断、联合类型、收窄、映射类型、字符串枚举等一切现代机制**均不存在**。第三方 AI 书单将其排入推荐序列属**过时书单污染**，本仓降为考古位，不进主线。

## 一、定位（考古价值三条）

1. **「TS 为何而生」的第一手切片**：书内为「给 JS 上规模」辩护静态超集的论辩，是 Anders Hejlsberg 设计动机时代的社区回声。
2. **演化对照面**：与 Essential TypeScript 5 并读，可列「0.8→5.x 新增机制年表」——本仓独有专题产出位。
3. **前 `interface` 惯例时代**：命名/注解风格与今日相反案例，提醒读者勿把 2012 惯例当 TS 正统 ⚠️。

## 二、骨架（⚠️ 章名凭记忆，以版权页为准；现代读者只需浏览前部）

| 章带 | 内容 | 处置 |
|---|---|---|
| Ⅰ 入门与工具 | 编译器命令行、VS 集成（2012 生态） | ⛔ 全失效，仅记史 |
| Ⅱ 类型基础 | 注解语法、interface 初形、类 | 对照读：找出「当年有今日无」的语义（如早期 `class` 糖差异） |
| Ⅲ 高级特性 | 早期泛型、模块雏形 | 与 Programming TS Ⅱ 部对照列年表 |
| Ⅳ jQuery/ASP.NET 实战 | 前框架时代栈 | ⛔ 跳过 |

## 三、读法

**只读 Ⅰ–Ⅲ 的「差异猎奇」模式**：每章列「2012 写法 → 202x 正解」对照行入分章档；Ⅳ 不读。全书投入 ≤ 6 小时，产出一枚年表档即回本。

## 四、🔧 实测口径

不适用（无可运行现代例程）。可选史实微实验：早期 `<T>` 注解形式在今日 `tsc` 下的报错形态，验证语法断层 ⚠️。
