# 深入Rust标准库

## 版本与 ISBN

- 书名：《深入Rust标准库：必备的Rust语言高级指南》
- 作者：任成珺、王晓娜、韩龙
- 出版社：电子工业出版社（博文视点），2024-04
- ISBN：`978-7-121-47586-3`（434 页，CNY 118）

> 2026-09-22 由 202608 月度笔记（20260806 Rust 书单）整理。

## 笔记

- 定位：源码级进阶必选，详细剖析 Rust 1.56 标准库源代码。
- 结构：CORE 库与 ALLOC 库（可写内核）→ STD 库（用户态）→ 异步编程浅析。
- 重点讲清所有权、生命周期在标准库中的真实实现，适合想写出高质量代码的中高级开发者。
