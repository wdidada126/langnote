## 笔记

### 第1章绪论

#### 1.2 面向对象的方法
- 面向对象的基本概念：对象、类、封装；四大特征：抽象、封装、继承、多态。
- 面向对象方法针对结构化程序设计「数据与操作分离、难以维护扩展」的不足，将数据与操作数据的方法封装成类。
- 面向对象的软件开发过程：分析 → 设计 → 编程 → 测试 → 维护。

#### 1.4 信息的表示与存储
- 进位计数制：二进制、八进制、十六进制；掌握按权展开、除基取余等转换方法。
- 存储单位：位（bit）、字节（Byte = 8 bit）、KB/MB/GB。
- 整数编码：原码、反码、补码；计算机中整数用补码存储，负数补码 = 原码按位取反再加 1，使加减法统一为加法运算。
- 实数：定点数（小数点位置固定）与浮点数（小数点位置浮动，可表示更大数值范围）。
- 非数值信息：字符用 ASCII 等编码表示。

#### 1.5 程序开发的基本概念
- 基本流程：源程序 →（编译）→ 目标程序（.obj）→（连接）→ 可执行程序。
- 完整程序过程：编辑、编译、连接、运行、调试。

### 第2章C++语言简单程序设计

#### 2.1 C++语言概述
- C++ 由 C 语言发展而来，在保持 C 的高效灵活的同时支持面向对象程序设计。
- 词法记号：关键字、标识符（字母/下划线开头，区分大小写）、字面量、运算符、分隔符。
- 最小程序框架：`#include <iostream>`、`main` 函数、用 `cout` 输出。

#### 2.2 基本数据类型和表达式
- 基本数据类型：`bool`、`char`、`int`/`short`/`long`、`float`/`double`；`sizeof` 得类型占字节数。
- 常量：整型、实型、字符（`'a'`）、字符串（`"abc"`）、布尔（`true`/`false`）；变量先定义后使用、定义时可初始化。
- 符号常量：用 `const`/`constexpr` 定义，有类型、受作用域限制，比 `#define` 更安全。
- 运算符：算术、赋值、自增/自减（注意前/后缀区别）、关系、逻辑（短路求值）、条件 `?:`、逗号、`sizeof`；注意优先级与结合性。

#### 2.3 数据的输入与输出
- I/O 流：`cin` + 提取符 `>>` 输入，`cout` + 插入符 `<<` 输出，可链式使用。
- 格式控制：`setw`（宽度）、`setprecision`（精度）、`fixed`（定点格式）等操纵符（需 `<iomanip>`）。

#### 2.4 算法的基本控制结构
- 选择：`if`/`if-else`；`switch`（需 `break`，否则会穿透）。
- 循环：`while`、`do-while`（至少执行一次）、`for`；`break` 结束循环、`continue` 跳过本次迭代剩余语句。
- 三种控制结构可任意嵌套，构成算法的基本控制流。

#### 2.5 类型别名与类型推断
- 类型别名：`typedef` 或 `using`（C++11）。
- `auto`：由初始化表达式推断类型；`decltype`：由表达式推断类型（不对表达式求值）。

### 第3章函数

#### 3.1 函数的参数传递
值传递是单向复制，形参改变不影响实参；引用传递形参是实参的别名，可直接修改实参（例 3_7 交换两数）。常引用（`const T&`）既避免复制又防止被修改，适合大对象传参。

#### 3.2 内联函数
`inline` 建议编译器在调用处展开函数体，省去调用开销。适合短小、调用频繁的函数；编译器可自行决定是否内联（递归、含循环/复杂分支的函数一般不内联）。

#### 3.5 函数重载
同一作用域内同名函数靠参数列表（个数或类型）区分，返回值类型不参与重载判断。注意默认实参与重载同时使用时可能产生二义性。

### 第4章类与对象

#### 4.3 构造函数和析构函数
- **默认构造**：无参或所有参数都有默认值的构造函数，定义数组、容器元素时会被调用。
- **复制构造**：`T(const T&)`，对象以值方式传参/返回、用对象初始化另一对象时调用。默认浅拷贝，含指针成员时需自定义深拷贝。
- **移动构造**：`T(T&&)`（C++11），接管临时对象资源，避免深拷贝，配合 `std::move` 使用。
- 构造与析构顺序：先构造的后析构（栈对象），成员按声明顺序构造（与初始化列表顺序无关）。

#### 4.4 类的组合
一个类的成员是另一个类的对象（has-a）。组合类构造函数通过初始化列表先构造内嵌对象，再执行自身函数体。

#### 4.8 综合实例
个人银行账户管理程序：将「账户」抽象为类，日期独立成 `Date` 类并组合进账户，体现封装与复用（对应项目 `Chapter4.cpp`、`account.cpp`）。

### 第5章数据的共享与保护
#### 5.2 静态生存期与静态成员
- **静态局部变量**：函数内 `static` 变量只在首次调用时初始化一次，之后调用保留上次的值，生存期持续到程序结束（Clock::showTime 用 `static int count` 记录调用次数）。
- **类的静态数据成员**：属于类而非某个对象，所有对象共享同一份；必须在类外定义并初始化：`int Clock::count = 0;`。
- **静态函数成员**：不依赖具体对象，用 `类名::函数名` 直接调用；静态成员函数没有 `this` 指针，不能直接访问非静态成员。

补充——对象初始化与拷贝构造：
`Clock myclock(globClock);` 用已有对象初始化新对象，调用复制构造函数 `Clock(const Clock&)`。未显式定义时编译器自动生成默认版本，逐成员浅拷贝：
- 简单内置类型成员（int 等）直接复制值，默认拷贝足够；
- 含指针成员且指向动态内存时，浅拷贝只复制地址，导致两个对象指向同一块内存（悬垂指针、重复释放），需自定义深拷贝。

#### 5.4 友元
- 友元函数：在类内用 `friend` 声明的外部函数，可访问该类的私有/保护成员，但破坏封装，应慎用。
- 友元类：`friend class B;` 使类 B 的所有成员函数都能访问本类的私有成员。

#### 5.5 共享数据的保护
- 常对象与常成员函数：`const` 修饰的对象只能调用常成员函数；常成员函数内不能修改对象状态（`mutable` 成员除外）。
- 常引用 `const T&` 传参：既避免复制开销，又防止函数内意外修改实参。

#### 5.6.2 外部变量与外部函数
- 多文件程序：跨文件共享的变量/函数用 `extern` 声明；仅当前文件使用的用 `static` 限制为内部链接。
- 匿名命名空间：`namespace { ... }` 内定义的变量和函数仅当前编译单元可见，是替代 `static` 的现代做法，避免向外部暴露内部实现（如书中隐藏计数变量的 `next()` 例）。

#### 5.6.4 编译预处理
- `#define PI 3.14` 定义宏常量；宏不做类型检查，C++ 中更推荐用 `const`（或 `constexpr`）定义常量。
- 其他预处理指令：`#include`（文件包含）、`#ifdef/#ifndef/#endif`（条件编译，常用于防止头文件重复包含）。


### 第6章数组、指针与字符串

#### 6.2 指针
- 数组名在多数场合退化为指向首元素的指针，但 `sizeof(数组名)` 得到整个数组大小。
- 指针运算以「所指向类型的大小」为步长：`p+1` 跳过的是 `sizeof(T)` 字节而非 1 字节。
- 二级指针/指针数组与二维数组传递时注意形参类型写法（对应 `6_20`/`6_21`/`6_22` 等）。

#### 6.3 动态内存分配
`new`/`delete` 与 `new[]`/`delete[]` 必须配对使用；泄漏常见于异常路径或提前 `return`。现代 C++ 优先用 `vector`/`unique_ptr` 管理。

#### 6.4 vector
`vector` 自动管理内存、支持动态扩容；扩容可能使迭代器/指针失效。预分配用 `reserve()`。

#### 6.5 深层复制与浅层复制
含指针成员的对象拷贝时，浅拷贝只复制指针导致两块内存被同一指针指向（重复释放/悬垂），需自定义拷贝构造/赋值运算符实现深拷贝。

#### 6.8 类型转换
- const_cast：去除 `const`/`volatile` 属性，用于调用只接受非 const 参数的旧接口；若对象本身为 const 仍修改，行为未定义。
- static_cast：编译期做类型转换（如 `int`↔`double`、`void*`↔具体类型指针）；reinterpret_cast：底层的重新解释（不相关类型指针互转）；dynamic_cast：运行时安全的向下转型（需多态类型）。

### 第7章类的继承

#### 7.2 访问控制
public 继承保持基类成员访问属性；protected 继承 public/protected 变 protected；private 继承全部变 private（实现继承，表达"用...实现"而非"是一个"）。

#### 7.3 类型兼容规则
派生类对象可赋给基类对象/指针/引用（切割后仅保留基类部分），反之不允许。这是运行时多态（基类指针指向派生类）的前提。

#### 7.4 构造与析构
派生类构造函数通过初始化列表先调用基类构造函数，再按声明顺序构造成员，最后执行自身函数体；析构顺序相反。

#### 7.5 虚基类
菱形继承（两条路径汇聚到同一基类）用 `virtual` 继承消除二义性与重复基类子对象；虚基类由最派生类负责初始化。

### 第8章多态性

#### 8.2 运算符重载
- 成员函数重载：左操作数是对象本身（如 `+` 二元写成单参）；非成员重载通常声明为友元。
- 流运算符 `<<`/`>>` 只能用非成员（友元）形式重载，因为左操作数是 `ostream`/`istream` 而非本类。
- 不可重载的运算符：`.`、`.*`、`::`、`?:`、`sizeof`。

#### 8.3 虚函数
- 基类中用 `virtual` 声明，派生类重写（建议加 `override`）后，通过基类指针/引用调用时按对象实际类型动态绑定。
- 含虚函数的类，析构函数必须声明为虚析构（`virtual ~T()`），否则经基类指针 delete 派生类对象会只析构基类部分导致泄漏。

#### 8.4 纯虚函数与抽象类
`= 0` 声明纯虚函数；含纯虚函数的类是抽象类，不能实例化，只能作为接口被派生（对应 `Chapter8.cpp` 形状/面积示例）。

### 第9章模板与群体数据

#### 9.1 函数模板与类模板
- 模板是泛型代码的蓝图，编译时按实参类型实例化；模板的定义必须对编译器可见（通常放头文件）。
- 非类型模板参数（如 `template<class T, int N>`）可指定常量，数组长度等场景常用（对应项目 `Array.h`）。

#### 9.2 线性群体
- 数组类：连续存储、随机访问 O(1)；链表：节点通过指针链接、插入删除 O(1) 但查找 O(n)（`LinkedList.h`、`Node.h`）。
- 栈（LIFO）/队列（FIFO）可用数组或链表实现，是典型适配器（`Queue.h`）。

#### 9.3 排序与查找
插入/选择/交换排序适合小规模；折半查找要求序列有序，O(log n)（`insertSort.h`、`selectSort.h`、`swapSort.h`、`orderSearch.h`）。

### 第10章泛型程序设计与C++语言标准模板库

#### 10.2 迭代器
- 迭代器是算法与容器之间的桥梁，行为类似指针。5 类：输入、输出、前向、双向、随机访问（后者包含前者全部能力）。
- 流迭代器：`istream_iterator`/`ostream_iterator` 把流当容器遍历（`mySort.cpp`）；插入迭代器 `back_inserter` 等在插入元素时自动扩容。

#### 10.4 顺序容器
- `vector` 连续存储、随机访问 O(1)、尾部增删摊还 O(1)；`deque` 双端高效；`list` 双向链表任意位置增删 O(1)；`forward_list` 单向。
- 适配器 `stack`/`queue`/`priority_queue` 基于底层容器包装出受限接口。

#### 10.5 关联容器
`set`/`map` 红黑树实现、有序、查找 O(log n)；`unordered_set`/`unordered_map` 哈希表实现、平均 O(1)；`multiset`/`multimap` 允许重复键。

#### 10.6 函数对象与 lambda
- 函数对象是重载了 `operator()` 的类对象，可携带状态（如 `std::less`、`std::greater`）。
- lambda：`[捕获](参数){函数体}`，编译器生成匿名函数对象；`std::bind`/占位符可绑定部分实参。

#### 10.7 算法
STL 算法基于迭代器工作，与容器解耦；`sort` 要求随机访问迭代器；善用 `std::accumulate`、`transform`、`copy` 等简化代码。

### 第11章流类库与输入输出

#### 11.2/11.3 输出流与输入流
- `<<`/`>>` 支持链式调用；`setw`、`setprecision`、`fixed` 等操纵符控制格式。
- 文件流：`ofstream`/`ifstream`/`fstream`，文本/二进制模式由 `ios::binary` 控制；`ostringstream`/`istringstream` 用于内存字符串解析与拼接。

#### 11.6 对象的串行化
Boost.Serialization 将对象状态持久化到文件（`Chapter11.cpp`、`IBAM.cpp`）：通过 `boost::archive::text_oarchive`/`binary_iarchive` 读写，类需实现 `serialize` 模板函数并注册派生类（`BOOST_CLASS_EXPORT`）。

### 第12章异常处理

#### 12.2 异常语法
`try`/`throw`/`catch`：`throw` 抛出对象沿调用栈向上寻找匹配的 `catch`；`catch(...)` 捕获所有；异常对象按类型匹配，一般按派生到基类的顺序排列 `catch` 块。

#### 12.3 构造与析构
栈展开过程中，已构造的局部对象会被正常析构；构造函数抛异常则对象未完全构造，仅已构造的成员被析构——故构造函数内要用 RAII 管理资源。

#### 12.4 标准异常
`std::exception` 是标准异常基类，常见派生：`bad_alloc`、`out_of_range`、`invalid_argument`、`runtime_error` 等；自定义异常建议继承 `std::exception` 并重写 `what()`。

#### 12.6
- 异常安全三级别：基本保证（不泄漏、状态有效）、强保证（失败回滚）、不抛保证（`noexcept`）。
- `noexcept` 声明函数不抛异常，利于移动语义优化与编译器检查；`noexcept` 函数若实际抛出会调用 `std::terminate`。
