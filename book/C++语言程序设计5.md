#### 5.2
方法体里面定义static
static int a = 10;

在C++中，通常我们不会在方法体（即成员函数）内部直接定义静态局部变量static int a = 10;，因为这样的语法是不允许的。静态局部变量通常是在函数体外部或函数体的最开始部分声明的，而不是在函数体的执行代码块中。

然而，你可以在函数体外部或函数体的开始部分声明静态局部变量，如下所示：

cpp
#include <iostream>  
  
class Clock {  
public:  
    void showTime() {  
        static int count = 0; // 静态局部变量，只在第一次调用函数时初始化  
        std::cout << "showTime called " << ++count << " times." << std::endl;  
    }  
};  
  
int main() {  
    Clock clk;  
    clk.showTime(); // 输出: showTime called 1 times.  
    clk.showTime(); // 输出: showTime called 2 times.  
    return 0;  
}
在这个例子中，count 是一个静态局部变量，它只在 showTime 函数的第一次调用时被初始化，之后每次调用都会保留其值。

但是，如果你确实需要在某个方法内部“定义”一个静态变量，并且希望它在整个程序中只被初始化一次，同时你又想把它放在函数体内（尽管这不是常规做法），你可能需要重新考虑你的设计。一个更常见的做法是将这个静态变量定义为类的静态成员变量，或者如果它确实只与某个函数相关，就按照上面的例子那样在函数体外或函数体的最开始部分声明它。

例如，作为类的静态成员变量：

cpp
#include <iostream>  
  
class Clock {  
private:  
    static int count; // 类的静态成员变量，需要在类外定义  
public:  
    static void showTime() {  
        std::cout << "showTime called " << ++count << " times." << std::endl;  
    }  
};  
  
int Clock::count = 0; // 在类外定义静态成员变量  
  
int main() {  
    Clock::showTime(); // 输出: showTime called 1 times.  
    Clock::showTime(); // 输出: showTime called 2 times.  
    return 0;  
}
在这个例子中，count 是 Clock 类的静态成员变量，它在整个程序中只被初始化一次，并且可以在类的所有对象之间共享。


Clock myclock(globClock)调用哪个构造函数
Clock(const Clock& other);
在C++中，如果你没有为类显式定义拷贝构造函数，编译器会为你自动生成一个默认的拷贝构造函数。这个默认的拷贝构造函数会逐成员地执行浅拷贝（shallow copy），即将源对象的每个成员的值复制到新对象中对应的成员。

对于 Clock 类来说，如果它没有显式定义拷贝构造函数，编译器就会生成一个默认的拷贝构造函数。这个默认的拷贝构造函数会执行以下操作：

如果 Clock 类有内置类型（如 int、float 等）或编译器管理的类型（如 std::string，它有自己的拷贝构造函数）的成员变量，那么这些成员变量会被直接复制它们的值。
如果 Clock 类有指针成员变量，并且这些指针指向动态分配的内存（如使用 new 分配的内存），那么默认的拷贝构造函数只会复制指针的值（即内存地址），而不是它所指向的内存内容。这可能导致两个对象指向同一块内存，从而引发悬垂指针、内存泄漏或双重释放等问题，这被称为浅拷贝问题。
如果 Clock 类包含其他类的对象作为成员，并且这些类也没有显式定义拷贝构造函数，那么这些成员对象也会使用它们各自的默认拷贝构造函数进行浅拷贝。
然而，在你的 Clock 类的情况下，如果它只包含表示时间的简单数据类型（如小时、分钟和秒），并且没有指针或动态分配的内存，那么默认的拷贝构造函数就足够了，因为它会正确地复制这些值。

如果你需要执行深拷贝（deep copy，即不仅复制值还复制指针所指向的内存内容），或者你需要在拷贝时执行一些特殊的操作（比如更新日志、重置状态等），那么你就需要为 Clock 类显式定义拷贝构造函数。

但请注意，在你的特定示例中，如果 Clock 类只用于表示时间，并且不包含任何需要特殊处理的成员（如指针或动态分配的内存），那么默认的拷贝构造函数应该就足够了。
