## 三、本书在数据库系列中的定位

**一句话：这是 Date 关系理论三部曲里最短、最纯「模型本体」的一本——它教你「关系数据库到底是什么」，而不是「怎么写 SQL」或「怎么设计库」。**

| 维度 | 本书 #12（Relational Theory for CP） | Date 第 1 本 [../SQL_and_Relational_Theory/00-总览与阅读地图.md](../SQL_and_Relational_Theory/00-总览与阅读地图.md) | [#8 Database_Design_and_Relational_Theory](../Database_Design_and_Relational_Theory/00-总览与阅读地图.md)（已落盘） | 实务书（[#23 Cost-Based Oracle](../Cost_Based_Oracle_Fundamentals/00-总览与阅读地图.md) / [#87 Using SQLite](../Using_SQLite/00-总览与阅读地图.md)） |
| --- | --- | --- | --- | --- |
| 回答的问题 | 关系模型的本体：关系/关系变量/算子/约束/模型公设 | 用 SQL 写出**正确**的查询：NULL、3VL、重复行、外连接陷阱 | 设计过程：谓词→码→约束→范式→分解的可操作流程 | 引擎怎么跑、怎么调、怎么运维 |
| 语言 | Tutorial D（第 10–14 章才拿 SQL 作对照） | SQL 为主，附 Tutorial Dees | SQL + Tutorial D 混用 | 厂商 SQL / 配置 / 工具链 |
| 深浅 | 理论最纯、篇幅最短（220 页含答案） | 中等，可执行 | 偏设计实操，范式最细 | 工程细节最深，理论最薄 |
| 事务/恢复 | 有（第 8 章，概念级 ACID/日志/锁） | 无专章 | 少量 | 主讲（各本各自的产品视角） |
| 阅读顺序建议 | **先读它**（1 天可通读，建立坐标系） | 再读它（写 SQL 时天天回来查） | 建模时读 | 落地时读 |

三部曲三角关系：#12 给「模型是什么」（本体论）→ #8 给「按模型怎么设计」（方法论）→ SQL_and_Relational_Theory 给「现实 SQL 里怎么不犯错」（工程修正）。三者互为补充，任一本都不自足。
