## 核心精讲

把音频特征（如左右声道映射成 X/Y、音量映射成亮度）通过串口实时发给 Arduino，由它驱动 X/Y 振镜偏转激光，画出随音乐舞动的光图。

```python
# 教学示意，不参与构建
import serial, numpy as np, sounddevice as sd

ser = serial.Serial("/dev/ttyACM0", 115200)

def callback(indata, frames, t, status):
    mono = indata[:, 0]
    x = int((mono.mean() + 1) * 512) % 1024     # 幅值→X
    y = int(np.abs(np.fft.rfft(mono)).mean() * 200) % 1024  # 能量→Y
    ser.write(f"{x},{y}\n".encode())

sd.Stream(callback=callback).start()            # 🔧 pyaudio 可换 sounddevice
```

> 要点：环形缓冲/回调必须低延迟；坐标量化到振镜量程；激光用 TTL 同步开关防拖尾。

## 版本演进

- 原书用 `pyaudio` 采集 + `pyserial` 下发；🔧 3.12+ 建议 `sounddevice` 替代 `pyaudio`。
- 振镜驱动逻辑在 Arduino 草图（C++），PC 只发目标坐标。
- 现代可做 FFT 频谱实时可视化，比单纯幅值更炫。

## 近年研究与工业界开源实践（2015–2026）

- 开源激光秀：`LaserFOX`、`Helios`（DAC 直接出 ILDA 帧），比串口振镜专业。
- 音频可视化库：`aubio`（节拍/频谱）、`librosa`（特征）。
- 注意：市售「激光灯」多已集成 DAC，DIY 仅作学习。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用 `pyaudio` 直接装 | 3.12+ 难装，🔧 换 `sounddevice` |
| 忽略延迟 | 回调阻塞会卡顿，须非阻塞+缓冲 |
| 激光直视 | ⚠️ 严禁直射人眼/镜面反射，遵等级规范 |
| 串口波特率太低 | 实时需 115200+，低频会拖影 |
