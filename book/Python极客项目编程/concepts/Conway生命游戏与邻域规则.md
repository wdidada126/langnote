# 概念专篇：Conway 生命游戏与邻域规则

> 跨章主题：第 03 章（生命游戏）的「邻域/边界」机制细究，关联 05 章（Boids 邻域）、11 章（3D 体素）。

## 为什么值得单列

生命游戏的「趣味」几乎全在**邻域定义与边界条件**上。同一套规则，边界策略不同会演化出完全不同的宇宙。把它讲清，03 章代码与后续模拟章节的「邻居查询」范式就统一了。

## 规则回顾

每个细胞看 8 邻域存活数 `n`：
- 存活且 `n∈{2,3}` → 存活；否则死亡。
- 死亡且 `n==3` → 出生。

## 边界条件三选一

| 策略 | 实现 | 效果 |
|---|---|---|
| 死边界 | 越界视为 0 | 边缘不断「流失」，图案塌缩 |
| 环形（toroidal） | 坐标取模 | 宇宙无缝，稳定结构可绕行 |
| 镜面 | 反射取邻 | 边缘似有「墙」 |

```python
# 教学示意，不参与构建
import numpy as np
def step_toroidal(grid):
    # np.roll 天然环形；一次表达 8 邻域求和
    nbrs = sum(np.roll(np.roll(grid, i, 0), j, 1)
               for i in (-1,0,1) for j in (-1,0,1) if (i,j)!=(0,0))
    return (nbrs==3) | (grid & (nbrs==2))
```

> `np.roll` 比手写取模更简洁，且自动处理环形；这是 numpy 向量化的标准技巧。

## 经典结构与可复现性

- 滑翔机（glider）、振荡器（blinker）、飞船等是「稳定结构」，可用种子复现——说明生命游戏不是纯随机混沌，而是**确定性的图灵完备计算模型**（Conway 证明可构造逻辑门/循环）。
- 因此实验务必固定随机种子，否则无法对比边界策略差异。
