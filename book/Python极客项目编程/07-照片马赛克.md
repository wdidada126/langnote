| 节 | 内容 | 结论 |

## 核心精讲

把目标图切成网格，每格选「平均颜色最接近的缩略图」贴上，远看即原图、近看是素材拼贴。

```python
# 教学示意，不参与构建
from PIL import Image
import numpy as np, os

def avg_color(im):
    return np.asarray(im.convert("RGB")).mean(axis=(0, 1))

def build_mosaic(target, tiles_dir, grid=(40, 40)):
    tgt = Image.open(target).convert("RGB").resize(grid)
    tw, th = 40, 40
    tiles = [(avg_color(Image.open(os.path.join(tiles_dir, f)).resize((tw, th))),
              Image.open(os.path.join(tiles_dir, f)).resize((tw, th)))
             for f in os.listdir(tiles_dir)]
    out = Image.new("RGB", (grid[0]*tw, grid[1]*th))
    for gy in range(grid[1]):
        for gx in range(grid[0]):
            c = avg_color(tgt.crop((gx, gy, gx+1, gy+1)))
            best = min(tiles, key=lambda t: np.linalg.norm(t[0]-c))
            out.paste(best[1], (gx*tw, gy*th))
    return out
```

> 要点：缩略图需统一尺寸才能直接 `paste`；匹配用平均色欧氏距离，KD-tree 可把 O(n) 降到对数级。

## 版本演进

- 原书用 Pillow + 朴素线性扫描；现代用 numpy 向量化或 `scipy.spatial.cKDTree` 加速匹配。
- 匹配可升级为「感知哈希 / 直方图交」更稳健。
- 输出可叠加原图低透明度，增强可辨识度（🔧 增强技巧）。

## 经典论文与原始文献

- 照片马赛克（photomosaic）由 Joseph Francis（1993）提出商业方法；属计算美学应用。
- 图像检索基础：颜色直方图、平均哈希（aHash）。
- 无专属 PEP；Pillow / numpy 文档为主。

## 近年研究与工业界开源实践（2015–2026）

- 社区工具：`photomosaic` 多个 PyPI 包、在线生成器。
- 深度学习时代：用 VGG 特征做「语义马赛克」（按内容而非仅颜色匹配）。
- 与 [06-ASCII艺术.md](06-ASCII艺术.md)、[08-立体图Autostereograms.md](08-立体图Autostereograms.md) 同为 Pillow 图像处理实践。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 缩略图尺寸不一 | 统一 `resize` 才能拼贴 |
| 仅线性扫描匹配 | 大素材库用 KD-tree / numpy |
| 只用平均色 | 复杂图用直方图/感知哈希更准 |
| 网格太粗失真 | 网格细 + 素材多才清晰 |
