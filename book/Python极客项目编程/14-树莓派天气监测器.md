## 核心精讲

树莓派接 DHT11/22 温湿度传感器，定时读值写入 SQLite，再用轻量 Web 框架或 matplotlib 出趋势图。

```python
# 教学示意，不参与构建
import sqlite3, time, datetime
import Adafruit_DHT as dht          # 🔧 现代用 adafruit-circuitpython-dht

def read_once(sensor=dht.DHT22, pin=4):
    hum, temp = dht.read_retry(sensor, pin)
    return temp, hum

def log(db="weather.db"):
    con = sqlite3.connect(db)
    con.execute("CREATE TABLE IF NOT EXISTS readings(ts TEXT, temp REAL, hum REAL)")
    while True:
        t, h = read_once()
        con.execute("INSERT VALUES (?,?,?)", (datetime.datetime.now().isoformat(), t, h))
        con.commit(); time.sleep(300)        # 每 5 分钟一条
```

> 要点：DHT 读取易失败需 `read_retry`；SQLite 单文件库适合边缘设备；展示层与采集解耦。

## 版本演进

- 原书用 `Adafruit_DHT`（已归档）；🔧 现代用 `adafruit-circuitpython-dht`（CircuitPython 栈）。
- Web 层原书用 `bottle`；现可选 `Flask`/`FastAPI`，或纯 `matplotlib` 离线出图。
- 时序数据量大可转 InfluxDB/TimescaleDB（🔧 进阶），但 SQLite 对小项目足够。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 用已归档 Adafruit_DHT | 🔧 换 `adafruit-circuitpython-dht` 或 `gpiozero` |
| DHT 读取不重试 | 传感器偶发失败，需 `read_retry`/异常兜底 |
| 采集与展示耦合 | 拆成采集进程 + 展示层，便于维护 |
| 忽略时区 | 存 UTC + 显示转本地，避免跨时区错乱 |
