> 深度重写版（章节目录），由 `book/Python极客项目编程.md` 大纲速查版展开。
> 原书：*Python Playground: Geeky Projects for the Curious Programmer*（Mahesh Venkitachalam，No Starch Press，2015，1e）。
> 中文版：《Python极客项目编程》，人民邮电出版社（🔧 中文版年份以版权页为准，约 2016）。

## 本书定位

一本「项目驱动」的 Python 进阶趣味书：用 numpy / matplotlib / Pillow / pygame / PyOpenGL / pyserial 等常见库，把代码变成可触摸的作品——生成艺术与音乐、模拟真实世界现象、操作硬件。全书 14 章 + 3 附录，分为五部分：热身、模拟生命、玩图像、进入 3D、黑客硬件。

> 本目录按 Python 3.12–3.14 校准：原书代码同时兼容 Python 2/3（2015），凡 `print` 语句、旧式除法、`wave` 音频写文件等，均按 3.x 与 PEP 594 口径修正并标注 🔧。

## 技术栈与依赖（2026 核对）

- 仍活跃：`numpy`、`matplotlib`、`Pillow`、`pygame`（3.x 支持）、`pyserial`。
- 需替换 / 注意（见各章「常见误区」）：
  - `wave` 音频写文件 → 3.13 起被 PEP 594 标记弃用，建议 `soundfile`+`libsndfile`。
  - `pyaudio` 在 3.12+ 安装困难 → 改用 `sounddevice` / `simpleaudio`。
  - `pyopengl` + GLUT 上下文在现代系统搭建繁琐 → 🔧 以官方示例为准。
  - `turtle` 仍在标准库但属教学模块，生产勿用。

## 维度演进（版本要点）

- 原书基线：Python 2 与 3 双兼容（2015）。
- 本书按 Python 3.12–3.14 修正：f-string 取代 `%`/`.format`；`print()` 函数；`/` 真除法；`wave` 弃用提示；类型注解可选补充。
