## 核心精讲

粒子系统用大量带状态的小点模拟烟、火、喷泉。现代做法把粒子数组放在 GPU，用顶点/几何着色器更新并 `gl_PointSize` 画成「面朝相机」的点精灵。

```python
# 教学示意，不参与构建
import numpy as np
from OpenGL.GL import *

# 每个粒子: [x,y,z, vx,vy,vz, life]
particles = np.zeros((N, 7), dtype=np.float32)
particles[:, 3:6] = np.random.randn(N, 3) * 0.01   # 初速
particles[:, 6] = np.random.rand(N)                # 寿命

# 每帧在着色器里: pos += vel*dt; life -= dt; 寿命耗尽则重置
# 片元里按 life 调 alpha 做淡出，glBlend 叠加
```

> 要点：透明粒子需 `glEnable(GL_BLEND)` + `glBlendFunc(SRC_ALPHA, ONE)`（加性混合出辉光）；billboarding 让点始终面向相机。

## 版本演进

- 原书用旧式 OpenGL 固定管线 + `glPointSize`；现代改为着色器驱动的 `gl_PointSize`/instancing。
- 点精灵（point sprite）在 Core Profile 中 `gl_PointCoord` 取点内 UV。
- 海量粒子（百万级）转 compute shader / `cupy` 离屏计算再回传。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 固定管线 `glBegin` | 用 VBO/着色器，Core Profile 无立即模式 |
| 透明不开启混合 | 必须 `glEnable(GL_BLEND)` 否则无叠加辉光 |
| 点大小不随距离 | billboarding 需按深度缩放 `gl_PointSize` |
| CPU 逐粒子更新 | 海量转 GPU/compute，否则卡顿 |
