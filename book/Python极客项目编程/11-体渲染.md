## 核心精讲

体渲染不画表面，而是沿每条视线「发射光线」，在 3D 纹理里逐点采样并用「传递函数」映射成颜色/不透明度，前向累加得到半透明体积图像。

```python
# 教学示意，不参与构建
import numpy as np
from OpenGL.GL import *

# volume: (D,H,W) uint8，CT/MRI 体素
volume = np.fromfile("ct.raw", dtype=np.uint8).reshape(128, 256, 256)
volume = np.ascontiguousarray(volume)          # C 连续才能上传
tex = glGenTextures(1)
glBindTexture(GL_TEXTURE_3D, tex)
glTexImage3D(GL_TEXTURE_3D, 0, GL_R8, 256, 256, 128, 0,
             GL_RED, GL_UNSIGNED_BYTE, volume)

# 片元着色器: for t in steps: pos += ray_dir*dt;
#   s = texture(tex3d, pos); (col, a) = transfer(s); acc.rgb += (1-acc.a)*a*col; acc.a += ...
```

> 要点：光线步数决定质量/性能权衡；传递函数把灰度/CT 值映射成「骨头亮、软组织透」的观感。

## 版本演进

- 原书用 PyOpenGL + GLSL 光线投射；现代也可用 `pyvista`/`vtk` 直接出体渲染，省力很多。
- 数据加载：原书读裸 `.raw`；实际常用 NIfTI（`.nii`）、DICOM，配 `nibabel`/`pydicom`。
- 光线步进可在片元着色器或 compute shader 完成。

## 经典论文与原始文献

- M. Levoy, *Display of Surfaces from Volume Data*（1988, IEEE CG&A）——光线投射体渲染经典。
- 传递函数/分类：Levoy 同年续作。医学影像格式见 NIfTI-1、DICOM 标准。
- 库：`VTK`、`pyvista`、`nibabel`、`pydicom`；无专属 PEP。

## 近年研究与工业界开源实践（2015–2026）

- 医学/科学可视化：`3D Slicer`、`ParaView`（VTK 内核）是工业标准。
- 深度学习：用神经网络直接「从投影重建体」（如 NeRF、3D Gaussian Splatting）成新热点。
- Python 侧 `kaolin`/`pytorch3d` 提供可微体渲染，接 ML 管线。

## 常见误区与本书需修正之处

| 误区 | 修正 |
|---|---|
| 裸 `.raw` 直接 reshape | 须确认维度/字节序，🔧 实际用 nibabel 读 NIfTI |
| 光线步数太小 | 出现分层伪影，需权衡步数/性能 |
| 传递函数随意 | 不当会全透或全糊，需调组织阈值 |
| 忽视内存 | 大体积（512³）显存吃紧，需分块 |
