## 一、2022 的定位：本地引擎的"云桥"版本

- SQL Server 2022（兼容级别 160）的官方叙事是把本地实例变成 Microsoft 云的数据底座：Azure Synapse Link（近实时分析出湖）、Purview 敏感度标签同步、Microsoft Entra ID 身份接入、Copilot/向量等 AI 接口预留 ⚠️ 转述；官方 What's new 总览 ✅ https://learn.microsoft.com/en-us/sql/sql-server/what-s-new-in-sql-server-2022
- 管理员要区分三个层面：**实例层**（引擎+Agent+配置）、**数据库层**（兼容级别、选项）、**外部面**（Azure 服务连接）。2022 的新特性多数落在这三层的"连接点"上 ⚠️。
- Inside Out 系体例传统 ⚠️：先给"任务全景"（要装什么、为谁服务、预算什么资源），再逐步实操截图——本目录按该体例组织。
- 与内核册分工：为什么缓冲池/计划缓存在新版这样表现，归 [../SQL_Server_2012_Internals/00-总览与阅读地图.md](../SQL_Server_2012_Internals/00-总览与阅读地图.md)（#56）与 [../Pro_SQL_Server_Internals/00-总览与阅读地图.md](../Pro_SQL_Server_Internals/00-总览与阅读地图.md)（#36）；本章只管"装出来、认清版"。

## 三、安装：介质、edition 与决策树

- 安装官方流程（setup 向导、介质+产品密钥、功能选择、实例命名、服务账户、SQL Server Agent 启动类型）✅ https://learn.microsoft.com/en-us/sql/database-engine/install-windows/install-sql-server
- edition 速判 ⚠️ 转述（以官方 editions 页为准）：Enterprise（全功能/无核数上限）、Standard（功能封顶+核 cap）、Express/Developer（学习与非生产）；管理员选型先看**许可预算**再看功能表。
- 目录规划是安装期最大的"一次做对"事项：系统库位置、用户库分离、tempdb 独立盘、日志与数据分卷；安装后改路径要靠配置+重启，代价远高 ⚠️。
- Linux 安装是一条平行线：仓库包 + mssql-conf + systemd 单元，容器版给 ephemeral 存储警告 ✅ https://learn.microsoft.com/en-us/sql/linux/sql-server-linux-setup
- 服务账户纪律：虚拟账户（NT SERVICE\…）默认够用；域账户仅在需要链接服务器 Windows 认证时引入 ⚠️ 转述。

## 四、升级：就地（in-place）与并行（side-by-side）

- 官方升级路径与兼容矩阵 ✅ https://learn.microsoft.com/en-us/sql/database-engine/install-windows/upgrade-sql-server：setup 程序可就地版本升级（保留实例与库），或新装实例后迁移库。
- **就地升级**：停机窗口 = 引擎切换+全部库恢复；老库兼容级别默认**不**自动跳 160，行为变更要主动改 ⚠️——这正是"升级完成≠迁移完成"的经典坑。
- **并行迁移**：备份还原/附加分离/DMA/复制路线任选；配合第 04 章的还原链与第 05 章的 AG 灰度切换，可把窗口压到一次业务低峰 ⚠️ 转述。
- 升级前检查清单 ⚠️（Inside Out 体例式整理，非原书条文）：DMA（Data Migration Assistant）兼容性报告、废弃功能扫描（如 `sp_lock` 直用、旧备份设备)、统计信息重建预算、Query Store 打开留档、备份全绿。
- 升级后体检：错误日志无红色、`sys.dm_os_wait_stats` 基线重采、计划缓存冷启动的性能曲线、兼容级别逐个库评估后再切 160（配合 09 章自动调优兜底）⚠️。

## 六、无人值守安装速查卡（⚠️ 示意模板，非原书条文；参数以官方 setup 文档 ✅ 安装 URL 为准）

```ini
; configuration.ini 骨架（setup.exe /ConfigurationFile=...）
[OPTIONS]
ACTION               = "Install"
INSTANCENAME         = "MSSQLSERVER"          ; 默认实例名策略要先定
FEATURES             = "SQLENGINE,REPL,FullText"
INSTALLSQLDATADIR    = "D:\SqlData"
SQLUSERDBDIR         = "D:\SqlData\UserDB"     ; 数据/日志/系统库分卷
SQLBACKUPDIR         = "E:\SqlBackup"
SQLTEMPDBDIR         = "T:\TempDB"             ; 安装期就把 tempdb 安顿好
SQLSVCACCOUNT        = "NT SERVICE\MSSQLSERVER"
AGTSVCACCOUNT        = "NT SERVICE\SQLSERVERAGENT"
AGTSVCSTARTUPTYPE    = "Automatic"             ; 管理册默认开作业服务
SQLCOLLATION         = "Chinese_PRC_CI_AS"     ; 装后难改，安装期决策
```

- 读法：每一行都是一个"装后改起来要命"的决策点——排序规则、分卷、Agent 启动类型是三大经典后悔药 ⚠️。
- 验证手段（装完后）：`SELECT @@version, SERVERPROPERTY('ProductLevel'), SERVERPROPERTY('Edition'), compatibility_level FROM sys.databases` ——确认 CU 级别、edition 与逐库兼容位 ⚠️（T-SQL 为社区通行写法，非本书实测）。

## 七、常见坑清单（Inside Out 体例的"坑边注"，⚠️ 转述整理）

1. **兼容级别错觉**：实例升到 2022 ≠ 数据库跑在 160；老库继续 130/140 行为，新特性（含 IQP 多数项）按库兼容级开关 ⚠️。
2. **Agent 没自启**：装完作业全停摆，属"配置正确系统失灵"第一名 ⚠️。
3. **Windows 组策略改服务账户**：SQL Server 服务账户不在 sysadmin 时，备份路径/链接服务器会神秘失败；官方解法是给账户"作为服务运行"等策略或加入 sysadmin ⚠️ 转述。
4. **防火墙与命名实例**：默认实例 1433 vs 命名实例 UDP 1434 浏览端口，远程连不上先看这两层 ⚠️。
5. **介质与密钥错位**：Evaluation 介质装成生产、密钥与 edition 不匹配导致功能降级 ⚠️。
6. **升级前没留退路**：就地升级不可回滚实例目录——升级前全备份+系统库备份（master/msdb）是唯一后悔药，衔接 [04-备份还原与恢复模型.md](04-备份还原与恢复模型.md) ⚠️。
7. **Linux 容器当持久存储**：容器内数据卷不是 HA 方案，生产走持久卷+AG on Linux ✅ https://learn.microsoft.com/en-us/sql/linux/sql-server-linux-availability-group-overview。

## 九、升级路线速查表（⚠️ 整理示意，官方矩阵以 upgrade 页 ✅ 为准）

| 路线 | 停机构成 | 回滚难度 | 适用 |
| --- | --- | --- | --- |
| 就地升级 | 介质替换+全库恢复期 | 高（不可逆，靠备份） | 单机/小场/预算紧 |
| 并行走者（还原式） | 末次日志+切换验证 | 低（旧实例原样在） | 中型/可安排双轨窗口 |
| AG 灰度 | 一次故障转移 | 低（旧副本可回切） | 已有 HA 拓扑的生产 |
| 云迁移（MI/IaaS） | 应用连接串切换 | 中（网络路径复杂） | 混合战略先行区 |

## 核心概念速览（中英对照）

- **兼容级别** — Compatibility Level：数据库行为版本开关，2022 为 160，升级不自动跳。
- **就地升级** — In-place Upgrade：setup 直接替换实例二进制，停机换简单。
- **并行迁移** — Side-by-side Migration：新实例+数据搬迁，停机靠切换策略压缩。
- **Edition** — 版本/许可证型：Enterprise/Standard/Express/Developer 的功能与核数封顶。
- **产品密钥** — Product Key：安装期激活介质，与 edition 绑定。
- **系统数据库** — System Databases：master/model/msdb/tempdb，安装即落盘的"四件套"。
- **虚拟服务账户** — Virtual Service Account：NT SERVICE\…，免域管理的默认身份。
- **DMA** — Data Migration Assistant：升级前兼容性与迁移评估官方工具。
- **累积更新** — Cumulative Update (CU)：月度小版本载体，Linux/Windows 同号推进。
- **Synapse Link** — Azure Synapse Link：2022 的近实时云分析出湖通道。
- **Entra ID 集成** — Microsoft Entra ID Integration：云身份进入实例认证面。
- **Ledger** — SQL Server Ledger：2022 的密码学防篡改审计表族。
- **IQP** — Intelligent Query Processing：自适应优化器特性族的版本增量。
