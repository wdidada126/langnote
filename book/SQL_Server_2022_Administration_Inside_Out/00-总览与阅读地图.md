| E1 journal_mode=wal 文件形态与读写并发 | WAL 追加日志、快照读 | `-shm` 32768B/`-wal` 12392B/主库 4096B；写事务未提交时读者仍见 200 行，提交后见 201 行 | 04 |
| E2 wal_checkpoint PASSIVE vs TRUNCATE | 检查点把 WAL 页刷回主库、日志截断 | 2000 插入后 wal=49472B；PASSIVE→(0,12,12) 文件不减；TRUNCATE→(0,0,0)、wal=0B；autocheckpoint 默认 1000 页 | 04 |

## 核心概念速览（中英对照）

- **管理内幕系列** — Inside Out（Microsoft Press 体例）：任务驱动、逐层展开的管理/开发深度教程范式。
- **兼容级别** — Compatibility Level (160)：数据库行为版本开关，升级后默认沿用旧级的"时间胶囊"。
- **恢复模型** — Recovery Model (FULL/SIMPLE/BULK_LOGGED)：事务日志链能否支撑时点还原的合同。
- **文件组** — Filegroup：逻辑存储容器，MDF/NDF 页分配的账本分组单位。
- **可用性组** — Always On Availability Group：以副本+日志硬复制换读取与故障转移的 HA 框架。
- **Ledger 可信账本** — SQL Server 2022 Ledger：密码学防篡改的双账本式表（SEQ/APPEND_ONLY）。
- **智能查询处理** — Intelligent Query Processing (IQP)：2019+ 逐版增强的自适应优化器特性族。
- **DMV 动态管理视图** — Dynamic Management Views：实例运行态的透视窗。
- **扩展事件** — Extended Events (XEvents)：低开销的定向事件捕获与排查框架。
- **查询存储** — Query Store：计划历史与强制回放的行车记录仪。
- **作业调度** — SQL Server Agent Job：值班表+警报的自动化原语。
- **tempdb** — tempdb：版本存储与工作表共用的耗材库，多文件缓解争用。
- **混合弹性** — Azure hybrid（Synapse Link/Purview/Entra ID）：2022 把本地实例接到云上分析与身份。
- **取证降级** — Evidence-downgrade：书目不可达时按主题重构并显式声明的编目纪律。

- **SQL Server 2022 → 2025 版本线**：2022（160）之后的 SQL Server 2025 已把**向量数据类型与 VECTOR_SEARCH** 带入 T-SQL，AI 检索成为管理员新日常 ✅ https://learn.microsoft.com/en-us/sql/relational-databases/vectors/vectors-sql-server；2025 新特性总览 ✅ https://learn.microsoft.com/en-us/sql/sql-server/what-s-new-in-sql-server-2025。
