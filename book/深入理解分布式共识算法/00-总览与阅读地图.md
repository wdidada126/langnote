## 三处必须诚实记录的核实结果

1. **任务描述里的「本书主线」与真实目录不一致（重要）**
   任务描述称本书主线为「Paxos / Raft / Zab / **Gossip / Pow / PoW-PoS** 等共识算法家族」，
   但**真实目录中没有任何 Gossip 章、也没有 PoW / PoS / 区块链共识章**。
   第 3 篇是「Paxos 变种算法集合」（Disk/Cheap/Generalized/Stoppable/Mencius/Vertical Paxos、Fast Paxos、EPaxos），
   第 4 篇是「番外——FLP 定理」只有一章。
   → 本目录**严格按真实 10 章建章**，不写 Gossip / PoW / PoS 章；
   PoW→PoS 的 2026 现状只在第 1 章「拜占庭故障」的 🔧 补丁里作为**书外补充**出现，并明确标注它是补充而非本书内容。

2. **第 1 章「拜占庭故障」的正文内容未能核实**
   大纲只给出「1.4.1 拜占庭的背景知识 / 1.4.2 拜占庭解决方案」，未给出正文。
   本目录不猜测它是否讲了 PBFT、比特币或 PoW；相关 2026 对比一律标注为**书外补充**。

3. **出版月存在两处口径**
   仓库大纲文件记 `2023-4`，任务描述记 `2023-05`。本目录以**大纲文件为准记 2023-04**，差异列入文末「疑问」。

## 常见疑问 FAQ

- **问：本书讲 Gossip / PoW / PoS 吗？**
  - 按真实目录**不讲**（无对应章）；本目录不建这些章。

  - 会，这正是第 3 章（2PC/3PC）最需要警惕的地方：2PC 是**原子提交**，不是共识；
  - 区分标准见 [03-2PC与3PC分布式事务.md](03-2PC与3PC分布式事务.md)。
- **问：要不要跑本书附带的源码（PhxPaxos / SOFAJRaft）？**

  - 真要跑请自行 clone 对应官方仓库（本目录不代跑、不执行任何 git 命令）。

- **问：star 数是怎么来的？**
