## 阅读顺序建议

- **主线 A（按书读）**：
  - 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09；
  - 原书结构是「先立概念（1–2）、再讲机制（3–5）、后讲算法与保障（6–8）、最后安全收尾（9）」，顺序读最省力。
- **主线 B（按问题读）**：
  - 「一致性到底有几层」：07 → 06（时钟与序）→ 08（共识与提交）；
  - 「RPC/消息怎么选」：04 → 02（中间件组织）；
  - 「etcd/ZooKeeper 为什么这样设计」：06（选举/互斥）→ 08（提交/恢复）→ 05（命名/znode 对照）；
  - 「上安全」：09 可独立最后读（原书官方 PPT 也不含 Ch9）。
- **对照读**：
  - 本书算法级内容较浅（本科教材定位），共识推导看 `book/深入理解分布式共识算法.md`；
  - 工程口径看 `book/分布式数据库入门进阶与实战/`；
  - 学院派精讲看 `book/2020-10_DistSys_lectures/`；
  - DDIA 口径看单文件 `Design Data-intensive Applications.md`（章节目录建设中）。

## 常见疑问 FAQ

- **问：这本书和 DDIA 读哪个先？**
  - 有数据库背景：先 DDIA 再本书，本书补命名/体系结构/安全的盲区；
  - 零基础：先本书（更平缓、免费、有 PPT），再读 DDIA 的工程取舍。
- **问：本书讲共识吗？**
  - 讲概念与动机（Ch6 选举/Ch8 提交），**不深推 Paxos/Raft**；
  - 深度推导请配 `book/深入理解分布式共识算法.md` 与 Raft 论文（USENIX ATC 2014）。
- **问：3rd ed 的 Python 示例要跑吗？**
  - 不必须；本目录所有代码均为教学示意、不参与构建；
  - 想跑请从官方页下载源码并自装 Redis 包（本目录不代跑）。
- **问：为什么每章有「🔧 本书需 2026 补丁」？**
  - 书成书于 2017，QUIC/Raft/CRDT/零信任/TrueTime 等关键实践均在其后；
  - 这些补丁写在对应章的「常见误区」与「近年实践」两段，读时勿跳。
- **问：章节目录与单文件 `book/分布式系统.md` 什么关系？**
  - 无内容继承关系——那其实是 Coulouris CDK5 的笔记（见上文核实说明）；
  - 两处互链但互不修改。
