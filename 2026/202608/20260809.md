## 通用核心（贯穿所有 Lab）

| 类型 | 资源 | 说明 |
|---|---|---|
| 教材 | 《数据库系统概念》（Database System Concepts，Silberschatz/Korth/Sudarshan） | 覆盖面最全：SQL、存储、索引、事务、恢复、并发控制 |
| 教材 | 《数据库系统实现》（Database Systems: The Complete Book，Garcia-Molina/Ullman/Widom） | 偏实现：存储、查询执行、优化、事务，与 lab 契合度最高 |
| 教材 | 《数据库管理系统原理》（Database Management Systems，Ramakrishnan/Gehrke） | 查询处理和优化讲得好，适合 Lab4/5 |
| 小册子 | *Architecture of a Database System*（Hellerstein/Stonebraker/Hamilton） | 数据库系统全架构导论，必读 |
| 论文选集 | *Readings in Database Systems*（"Red Book"，Hellerstein 主编） | 经典论文合集，可当索引 |
| 书 | *Designing Data-Intensive Applications*（Martin Kleppmann） | 存储/索引/事务/一致性，现代视角 |
| 书 | *Database Internals*（Alex Petrov） | 存储引擎 + 分布式实现细节，偏 Lab1 |
| 书 | 《数据库系统内核》（Database System Concepts 中译本配套） | — |

## Lab0：SQL 解析 / 绑定 / 表达式

- 教材：《编译原理》（龙书，Aho et al.）——词法/语法/语义分析
- 教材：*Parsing Techniques – A Practical Guide*（Grune/Jacobs）——解析器大全
- 小册子：*Crafting Interpreters*（Nystrom，在线免费）——表达式求值/绑定思路
- 手册：flex / bison 官方手册，或 ANTLR 参考书

## Lab1：存储引擎（页式存储 / LRU 缓冲池 / Catalog / DML）

- 论文：*The Five-Minute Rule for Trading Memory for Disk Accesses*（Gray/Graefe）及十周年续篇——页大小与缓存取舍
- 论文：*Ubiquitous B-Tree*（Graefe）——B+ 树权威综述；配套 *Modern B+Tree Techniques in Database Systems*（Graefe）
- 论文：*Self-Adjusting Binary Search Trees*（Sleator/Tarjan，splay 树）——缓存替换理论根源
- 论文：*The LRU-K Page Replacement Algorithm*（O'Neil et al.）；*ARC: A Self-Tuning, Low Overhead Replacement Cache*（Megiddo/Modha，FAST'03）
- 在线书：*The Internals of PostgreSQL*（PostgreSQL 内部机制）——堆表/缓冲池/目录实现范例

## Lab2：事务与 WAL / ARIES 崩溃恢复

- 书：*Transaction Processing: Concepts and Techniques*（Jim Gray/Reuter）——事务处理"圣经"：WAL、2PL、恢复协议全部源头
- 论文：*ARIES: A Transaction Recovery Method Supporting Fine-Granularity Locking and Partial Rollbacks Using Write-Ahead Logging*（Mohan et al., ACM TODS 1992）——本项目 Lab2 直接对应的论文
- 论文：*The Transaction Concept: Virtues and Limitations*（Gray, VLDB 1981）——事务概念与 Halloween Problem 出处
- 书：*Concurrency Control and Recovery in Database Systems*（Bernstein/Hadzilacos/Goodman）

## Lab3：并发控制（MVCC / 2PL / MV2PL / RR、RC / 写倾斜）

- 论文：*Notes on Database Operating Systems*（Gray, 1978）——2PL 原始出处
- 论文：*A Critique of ANSI SQL Isolation Levels*（Berenson/Bernstein/Gray/Melton/O'Neil/O'Neil, SIGMOD 1995）——RR/RC 定义与**写倾斜**的正式定义
- 论文：*Multiversion Concurrency Control – Theory and Algorithms*（Bernstein/Goodman, TODS 1983）——MVCC 理论基础
- 论文：*On Optimistic Methods for Concurrency Control*（Kung/Robinson, TODS 1981）——OCC 对比
- 博士论文：*Isolation Semantics for Database Systems*（Atul Adya, 1999）——隔离级别形式化
- 论文：*An Empirical Evaluation of In-Memory Multi-Version Concurrency Control*（VLDB 2017）——MVCC 变体横向评测（TiKV/InnoDB 参与）
- 论文：*Serializable Snapshot Isolation*（Cahill/Röhm/Fekete, VLDB 2009）——SSI，PostgreSQL 采用，可对照理解 MV2PL 差异
- 论文：*Efficient Locking for Concurrent Operations on B-Trees*（Lehman/Yao）——锁粒度进阶

## Lab4：执行算子（LIMIT / ORDER BY / NLJ / Merge Join）

- 论文：*Query Evaluation Techniques for Large Databases*（Graefe, ACM Computing Surveys 1993）——**执行算子最经典综述**，排序/连接全覆盖
- 论文：*Volcano – An Extensible and Parallel Query Evaluation System*（Graefe, TKDE 1994）——火山模型迭代器
- 论文：*Access Path Selection in a Relational Database Management System*（Selinger et al., 1979）——System R，连接与访问路径选择
- 书：Knuth《计算机程序设计艺术》第 3 卷——外部排序/归并理论
- 在线：CMU 15-445 *Database Systems*（Andy Pavlo）课程 Slides（BusTub 实验）——与各 lab 一一对应

## Lab5：优化器（谓词下推 / join order / 统计 / EXPLAIN）

- 论文：*Access Path Selection in a Relational Database Management System*（Selinger et al., 1979）——动态规划 join order 鼻祖
- 论文：*The Volcano Optimizer Generator*（Graefe/McKenna）——成本模型与搜索框架
- 论文：*Improved Histograms for Selectivity Estimation of Range Predicates*（Poosala et al., SIGMOD 1996）——直方图统计，对应 ANALYZE
- 书：《数据库查询优化器的艺术》（李海翔）——国内讲优化器最系统的书，直指 Lab5
- 书：《PostgreSQL 技术内幕：查询优化深度探索》（张树杰）——谓词下推、join 顺序、成本估算工程实现
- 论文：*On the Propagation of Errors in the Size of Join Results*（Ioannidis）——估算误差分析
