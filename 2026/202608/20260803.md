pgrust 开发者与项目完整说明
 
你的表述准确：pgrust 核心发起者、主开发者是 Michael Malis（GitHub 用户名 malisper），项目为双人副业项目，另一位协作开发者是 Jason Seibel。
 
一、Michael Malis 背景
 
1. 从业履历：曾在 Heap 负责运维PB 级 PostgreSQL 生产集群，深耕 PG 内核多年，长期撰写 PostgreSQL 底层原理技术博客；后创办 YC 孵化企业 Freshpaint 并担任 CEO，拥有大规模数据库实战经验，绝非新手试水项目。
2. 项目初衷：原生 PostgreSQL 基于 C 编写，内存隐患多、内核改造门槛极高；他希望用 Rust 内存安全特性完整复刻 PG，同时借助 AI 大幅缩短重写周期。
 
二、pgrust 项目核心信息（区分同名小工具）
 
社区近期爆红的 malisper/pgrust（数据库完整重写项目），和普通 Rust 写 PG 扩展的同名工具并非同一事物：
 
1. 开发周期：2026 年 4 月启动，仅耗时两个月完成核心开发，依靠多 AI Agent 并行编码（Codex、Claude 等）生成百万行 Rust 代码。
2. 核心里程碑：完美对标 PostgreSQL 18.3，100% 通过 PG 官方 46066 条回归测试+事务隔离测试；磁盘文件完全原生兼容，可直接挂载原有 PG18.3 数据目录启动运行。
3. 架构改动：将 PG 多进程模型改为 Rust 线程模型，规避 fork 开销；基准测试下事务性能较原版 PG 提升约 50%，分析型查询提速最高 300 倍。
4. 当前状态（v0.1）：实验性版本，不建议生产使用，暂不兼容绝大多数 PG 第三方扩展，仍在持续完善生态。
 
三、开发模式特点
 
Michael 主导整体架构、子系统拆分与测试规则；搭建调度工具管理十余个并行 AI 编码代理，AI 负责翻译 C 源码、编写 Rust 实现，人工把控逻辑正确性与整体工程规范，提交记录中 Michael 个人提交 6200+ 次，为绝对核心负责人。
