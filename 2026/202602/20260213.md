一、PL/SQL 是什么？
PL/SQL = Procedural Language extensions to SQL
• 核心：在 SQL 的基础上添加了 过程化编程 特性
• 定位：Oracle 数据库的原生编程语言
• 执行环境：在数据库服务器端执行，而非客户端

二、PL/SQL 的扩展能力

1. 基本结构扩展（超越纯 SQL）
-- 纯 SQL 只能执行单条语句
SELECT * FROM employees;

-- PL/SQL 支持编程结构
DECLARE
    v_salary NUMBER;
BEGIN
    -- 过程化控制
    FOR emp_rec IN (SELECT * FROM employees) LOOP
        -- 条件判断
        IF emp_rec.salary > 10000 THEN
            v_salary := emp_rec.salary * 1.1;
            -- 更新操作
            UPDATE employees 
            SET salary = v_salary
            WHERE employee_id = emp_rec.employee_id;
        END IF;
    END LOOP;
    
    -- 事务控制
    COMMIT;
    
    -- 异常处理
    EXCEPTION
        WHEN OTHERS THEN
            ROLLBACK;
            RAISE;
END;
/

CREATE OR REPLACE FUNCTION calculate_bonus(
    p_salary NUMBER,
    p_performance_rating NUMBER
) RETURN NUMBER
IS
    v_bonus NUMBER;
BEGIN
    IF p_performance_rating >= 4 THEN
        v_bonus := p_salary * 0.3;

CREATE OR REPLACE PROCEDURE transfer_funds(
    p_from_account NUMBER,
    p_to_account NUMBER,
    p_amount NUMBER
)
IS
    v_balance NUMBER;
BEGIN
    -- 1. 检查余额
    SELECT balance INTO v_balance
    FROM accounts
    WHERE account_id = p_from_account
    FOR UPDATE;  -- 加锁防止并发
    
    IF v_balance < p_amount THEN
        RAISE_APPLICATION_ERROR(-20001, '余额不足');
    END IF;
    
    -- 2. 扣款
    UPDATE accounts
    SET balance = balance - p_amount
    WHERE account_id = p_from_account;
    
    -- 3. 存款
    UPDATE accounts
    SET balance = balance + p_amount
    WHERE account_id = p_to_account;
    
    -- 4. 记录流水
    INSERT INTO transactions VALUES(
        seq_transaction.NEXTVAL,
        p_from_account,
        p_to_account,
        p_amount,
        SYSDATE
    );
    
    COMMIT;
    
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END transfer_funds;

CREATE OR REPLACE PROCEDURE batch_update_salaries
IS
    TYPE emp_id_table IS TABLE OF NUMBER;
    TYPE salary_table IS TABLE OF NUMBER;
    
    v_emp_ids emp_id_table;
    v_salaries salary_table;
    
    CURSOR c_employees IS
        SELECT employee_id, salary
        FROM employees
        WHERE department_id = 50;
BEGIN
    -- 批量采集数据
    OPEN c_employees;
    FETCH c_employees BULK COLLECT INTO v_emp_ids, v_salaries;
    CLOSE c_employees;
    
    -- 批量处理
    FOR i IN 1..v_emp_ids.COUNT LOOP
        v_salaries(i) := v_salaries(i) * 1.05; -- 涨薪5%
    END LOOP;
    
    -- 批量更新（性能优化）
    FORALL i IN 1..v_emp_ids.COUNT
        UPDATE employees
        SET salary = v_salaries(i)
        WHERE employee_id = v_emp_ids(i);
    
    COMMIT;
    
    DBMS_OUTPUT.PUT_LINE('更新了 ' || SQL%ROWCOUNT || ' 条记录');
END batch_update_salaries;

你指的是 Java 8 中的大根堆（最大堆）和小根堆（最小堆），这是两种常见的优先队列（Priority Queue） 实现方式。在 Java 中，通过 PriorityQueue 类提供这两种堆的实现。

一、概念解析

1. 堆（Heap）是什么？
• 一种特殊的完全二叉树
• 满足堆性质：每个节点的值都 ≥（或 ≤）其子节点的值
• 不是内存中的堆（Heap），这是数据结构概念

2. 大根堆 vs 小根堆
特性 大根堆（最大堆） 小根堆（最小堆）
定义 父节点值 ≥ 子节点值 父节点值 ≤ 子节点值
根节点 最大值 最小值
Java 默认 需要自定义比较器 默认实现（自然顺序）

典型应用 获取前 K 个最大值 获取前 K 个最小值、Dijkstra 算法

二、Java 8 中的实现
1. 默认：小根堆（最小堆）

// 默认是小根堆（自然顺序）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

minHeap.offer(5);
minHeap.offer(2);
minHeap.offer(8);
minHeap.offer(1);

System.out.println(minHeap.poll()); // 1（最小）
System.out.println(minHeap.poll()); // 2
System.out.println(minHeap.poll()); // 5
System.out.println(minHeap.poll()); // 8

场景1：获取 Top K 元素

// 获取数组中最大的 K 个元素（使用小根堆）
public List<Integer> topKMax(int[] nums, int k) {
    // 大小为 K 的小根堆
    PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);
    
    for (int num : nums) {
        if (minHeap.size() < k) {
            minHeap.offer(num);
        } else if (num > minHeap.peek()) {
            minHeap.poll();      // 移除最小的
            minHeap.offer(num);  // 插入更大的
        }
    }
    
    return new ArrayList<>(minHeap);
}

// 获取数组中最小的 K 个元素（使用大根堆）
public List<Integer> topKMin(int[] nums, int k) {
    // 大小为 K 的大根堆
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>(k, (a, b) -> b - a);
    
    for (int num : nums) {
        if (maxHeap.size() < k) {
            maxHeap.offer(num);
        } else if (num < maxHeap.peek()) {
            maxHeap.poll();      // 移除最大的
            maxHeap.offer(num);  // 插入更小的
        }
    }
    
    return new ArrayList<>(maxHeap);
}


场景2：数据流的中位数

class MedianFinder {
    // 大根堆：存储较小的一半（堆顶是最大值）
    private PriorityQueue<Integer> maxHeap;
    // 小根堆：存储较大的一半（堆顶是最小值）
    private PriorityQueue<Integer> minHeap;
    
    public MedianFinder() {
        maxHeap = new PriorityQueue<>((a, b) -> b - a);
        minHeap = new PriorityQueue<>();
    }
    
    public void addNum(int num) {
        // 保持两个堆平衡
        maxHeap.offer(num);
        minHeap.offer(maxHeap.poll());
        
        // 保持 maxHeap 大小 >= minHeap 大小
        if (maxHeap.size() < minHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }
    
    public double findMedian() {
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.peek();
        } else {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
    }
}

场景4：合并 K 个有序链表

public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    
    // 使用小根堆，按节点值排序
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>(
        Comparator.comparingInt(node -> node.val)
    );
    
    // 将每个链表的头节点加入堆
    for (ListNode node : lists) {
        if (node != null) {
            minHeap.offer(node);
        }
    }
    
    ListNode dummy = new ListNode(0);
    ListNode current = dummy;
    
    while (!minHeap.isEmpty()) {
        ListNode minNode = minHeap.poll();
        current.next = minNode;
        current = current.next;
        
        if (minNode.next != null) {
            minHeap.offer(minNode.next);
        }
    }
    
    return dummy.next;
}


六、内部实现原理

Java 8 的 PriorityQueue 是基于二叉堆的数组实现：
// 近似源码结构
public class PriorityQueue<E> extends AbstractQueue<E> {
    private transient Object[] queue;  // 存储元素的数组
    private int size;                  // 元素个数
    private final Comparator<? super E> comparator;
    
    // 堆化操作（以大根堆为例）
    private void siftUp(int k, E x) {
        while (k > 0) {
            int parent = (k - 1) >>> 1;  // 父节点索引
            Object e = queue[parent];
            if (comparator.compare(x, (E) e) <= 0) // 比较
                break;
            queue[k] = e;
            k = parent;
        }
        queue[k] = x;
    }
    
    private void siftDown(int k, E x) {
        int half = size >>> 1;
        while (k < half) {
            int child = (k << 1) + 1;  // 左子节点
            Object c = queue[child];
            int right = child + 1;
            if (right < size && 
                comparator.compare((E) c, (E) queue[right]) < 0)
                c = queue[child = right];
            if (comparator.compare(x, (E) c) >= 0)
                break;
            queue[k] = c;
            k = child;
        }
        queue[k] = x;
    }
}


数组表示的完全二叉树：
• 索引 i 的父节点：(i-1)/2
• 索引 i 的左子节点：2*i+1
• 索引 i 的右子节点：2*i+2

七、注意事项

1. 线程不安全：PriorityQueue 不是线程安全的，多线程环境下使用 PriorityBlockingQueue
2. 不允许 null：不能插入 null 元素
3. 迭代顺序：迭代器不保证按优先级顺序遍历，只有 poll() 才保证顺序
4. 性能特点：
   • 插入/删除：O(log n)
   • 获取堆顶：O(1)
   • 查找元素：O(n)

5. 空间复杂度：底层是动态数组，会自动扩容

八、完整示例

import java.util.*;

public class HeapExample {
    public static void main(String[] args) {
        // 1. 小根堆示例
        System.out.println("=== 小根堆（默认）===");
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        int[] nums = {3, 1, 4, 1, 5, 9, 2, 6};
        for (int num : nums) minHeap.offer(num);
        
        while (!minHeap.isEmpty()) {
            System.out.print(minHeap.poll() + " ");  // 1 1 2 3 4 5 6 9
        }
        System.out.println();
        
        // 2. 大根堆示例
        System.out.println("\n=== 大根堆（自定义比较器）===");
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int num : nums) maxHeap.offer(num);
        
        while (!maxHeap.isEmpty()) {
            System.out.print(maxHeap.poll() + " ");  // 9 6 5 4 3 2 1 1
        }
        System.out.println();
        
        // 3. Top K 问题
        System.out.println("\n=== Top 3 最大值 ===");
        List<Integer> top3 = topKMax(nums, 3);
        System.out.println(top3);  // [5, 6, 9]
    }
    
    public static List<Integer> topKMax(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);
        for (int num : nums) {
            if (minHeap.size() < k) {
                minHeap.offer(num);
            } else if (num > minHeap.peek()) {
                minHeap.poll();
                minHeap.offer(num);
            }
        }
        return new ArrayList<>(minHeap);
    }
}

总结
• 小根堆（最小堆）：Java 默认，父节点 ≤ 子节点，堆顶是最小值
• 大根堆（最大堆）：需要自定义 Comparator，父节点 ≥ 子节点，堆顶是最大值
• 应用场景：Top K 问题、中位数、任务调度、Dijkstra 算法、合并有序序列等
• 核心操作：offer() 和 poll() 是 O(log n)，peek() 是 O(1)
• 实现原理：基于数组的完全二叉树，通过堆化（siftUp/siftDown）维护堆性质

掌握堆数据结构对于解决算法问题和性能优化至关重要，是面试和实际开发中的高频考点。
