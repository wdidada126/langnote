这些库（如 jsoncpp、uuid、zlib、openssl、c-ares、brotli、mariadb、sqlite3、hiredis、yaml-cpp、gtest）绝大多数在 Chocolatey 的社区仓库（community.chocolatey.org）没有直接提供独立的开发库包（即提供 .lib / .h 的那种）。
Chocolatey 主要适合安装可执行程序或工具，而C/C++ 静态/动态链接库通常不放在 Chocolatey 里，而是推荐用以下方式安装：

### 推荐解决方案（最常用、最干净的方式）
用 vcpkg（Microsoft 官方的 C++ 库管理器）来安装这些库，几乎全部都有。
1. 先安装 vcpkg（如果还没装）：

   ```powershell
   git clone https://github.com/microsoft/vcpkg.git
   cd vcpkg
   .\bootstrap-vcpkg.bat
   ```

   （建议放在 C:\vcpkg 或 D:\dev\vcpkg 这种固定位置）

2. 一次性安装你需要的库（64 位为例）：
   ```powershell
   .\vcpkg install ^
     jsoncpp:x64-windows ^
     zlib:x64-windows ^
     openssl:x64-windows ^
     c-ares:x64-windows ^
     brotli:x64-windows ^
     mariadb-connector-cpp:x64-windows ^
     sqlite3:x64-windows ^
     hiredis:x64-windows ^
     yaml-cpp:x64-windows ^
     gtest:x64-windows
   ```

   - uuid：Windows 上一般用系统自带的 rpcrt4.lib（UuidCreate），不需要额外安装。如果你要跨平台 uuid 库，可以用 `libuuid` 但 vcpkg 没有标准版，通常自己写或用 boost.uuid。
   - mariadb → 用 `mariadb-connector-cpp`（C++ 连接器），或 `libmariadb`（C 接口）。

3. 集成到 Visual Studio（只需执行一次）：
   ```powershell
   .\vcpkg integrate install
   ```

   之后新建 VS 项目，vcpkg 安装的库会自动被找到（include + lib 路径）。

4. 如果你只想要 32 位，改成 `:x86-windows`；静态链接加 `:x64-windows-static` 等。
### 当前 Chocolatey 能直接装的只有少数几个
- openssl → `choco install openssl`
- mariadb → `choco install mariadb`（但这是服务器，不是 client 开发库）
- sqlite → `choco install sqlite`（主要是 sqlite3.exe，不是开发用的 .lib/.h）

其他如 jsoncpp、yaml-cpp、gtest、hiredis、c-ares、brotli 在 community repo 基本都没有。
### 其他替代方案
- Conan（另一个包管理器）：也支持绝大部分上述库，但 Windows 上 vcpkg 更流行。
- 自己 build：从 GitHub 下载源码，用 cmake + VS 编译（最麻烦）。
- MSYS2 / mingw：`pacman -S mingw-w64-x86_64-jsoncpp` 等，但和原生 MSVC 不太兼容。

### 总结建议
直接放弃用 Chocolatey 装这些开发库 → 改用 vcpkg 是目前 Windows 上 C++ 开发者最主流、最省心的做法。
