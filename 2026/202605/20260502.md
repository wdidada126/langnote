Xcode OC/Swift 纯命令行：打包+真机部署+查看日志
 
核心前提（关键）
 
1. 不用付费开发者账号、不用证书、不用越狱
2. 仅限：开发调试包（Debug），不能打 AppStore/企业正式包
3. 设备：iPhone 开启「开发者模式」，电脑信任设备
4. 工具：Mac自带xcodebuild  +  idevicedebug  系列开源工具
 
一、前置环境安装（无账号必装）
1. 安装 iOS 真机调试命令行工具
 
bash
  
brew install libimobiledevice ideviceinstaller idevicedebug
 
 
作用：
- 免证书、免开发者账号
- 命令行安装 IPA、运行 App、抓取真机日志
 
2. 安装 Xcode 命令行工具
 
bash
  
xcode-select --install


3. 手机必须操作
设置 → 隐私与安全性 → 开启 开发者模式
数据线连接 Mac，点击「信任此电脑」
 

二、纯命令行：编译打包（Debug 免证书）
1. 进入项目目录（含  .xcodeproj  /  .xcworkspace ）
 
普通 xcodeproj 项目
 
bash
  
# 编译打出 Debug 包（免签名、开发调试用）
xcodebuild \
-project 你的项目名.xcodeproj \
-scheme 你的Scheme名 \
-configuration Debug \
-sdk iphoneos \
CODE_SIGN_IDENTITY="" \
CODE_SIGNING_REQUIRED=NO \
CODE_SIGNING_ALLOWED=NO
 
若是 CocoaPods 项目（用 xcworkspace）
 
bash
  
xcodebuild \
-workspace 你的项目名.xcworkspace \
-scheme 你的Scheme名 \
-configuration Debug \
-sdk iphoneos \
CODE_SIGN_IDENTITY="" \
CODE_SIGNING_REQUIRED=NO \
CODE_SIGNING_ALLOWED=NO
 
 
参数解释（免账号核心）：
-  CODE_SIGN_IDENTITY=""  清空签名
- 关闭强制签名、关闭证书校验
- 只编译无签名 Debug 包，用于真机调试

 
三、命令行：安装 App 到 iPhone 真机
 
1. 查看已连接真机设备

bash
  
idevice_id -l

2. 安装编译好的 App 目录/IPA

bash
  
# 安装.app 到真机
ideviceinstaller -i 编译产物路径/xxx.app


3. 卸载 App
 
bash
  
ideviceinstaller -U 你的BundleID

 
四、命令行：真机启动 App（对标 Xcode Run）
 
bash
  
# 直接拉起运行手机上的 App
idevicedebug run 你的BundleID

效果：
等同于 Xcode 点击 Run → 安装 + 启动 App
 
五、命令行：查看 iPhone 实时日志（对标 Xcode Console）

1. 实时全量日志
 
bash
  
idevicesyslog

2. 只筛选自己 App 日志

bash
  
idevicesyslog | grep 你的BundleID

3. 清空日志、只看新输出

bash
  
idevicesyslog | grep -iE "Error|Warning|你的类名"

六、精简全套一键流程（日常直接用）
 
1. 编译（免签名）
2. 安装真机
3. 启动 App
4. 实时看日志
 
bash
  
# 1. 编译
xcodebuild -workspace xxx.xcworkspace -scheme xxx -configuration Debug sdk=iphoneos CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO

# 2. 安装
ideviceinstaller -i build/Debug-iphoneos/xxx.app

# 3. 运行
idevicedebug run com.xxx.bundleid

# 4. 新开终端看日志
idevicesyslog
 

七、关键限制（必须清楚）
1. 可以：
- 纯命令行编译、打包、真机安装、运行、看日志
- 无付费苹果开发者账号、无证书、无描述文件
- OC / Swift 全支持
 
2. 不可以：
- 打 Release 正式包、上架 AppStore
- 脱离数据线无线调试
- 推送、后台刷新、iCloud 等特权能力（需要证书）

编译打包 Command+B xcodebuild 无签名编译 
Run部署真机 点击Run ideviceinstaller + idevicedebug 
控制台日志 Xcode Console idevicesyslog 
核心底层 Xcode 封装命令 xcodebuild + libimobiledevice 开源工具
