这是 Kotlin 的主构造函数（Primary Constructor）语法，同时也是 Spring Boot 中常见的构造函数依赖注入写法。

你的代码：

```
@RestController
class GoodsFrontController(private val items: ItemService) {
}
```

## 1. `()` 是什么？

Kotlin 允许直接在类名后面的 `()` 中声明构造函数参数。

```
class GoodsFrontController(private val items: ItemService)
```

拆开来看：

| 代码                     | 含义        |
| ---------------------- | --------- |
| `class`                | 定义类       |
| `GoodsFrontController` | 类名        |
| `(...)`                | 主构造函数参数列表 |
| `private`              | 私有访问修饰符   |
| `val`                  | 声明只读成员属性  |
| `items`                | 属性名称      |
| `ItemService`          | 属性类型      |

特别注意：

`private val items: ItemService` 不只是构造函数参数，还会自动成为类的成员属性。

## 2. 相当于 Java 的什么代码？

Kotlin：

```
@RestController
class GoodsFrontController(
    private val items: ItemService
) {
    @GetMapping("/goods")
    fun list() = items.list()
}
```

相当于 Java：

```
@RestController
public class GoodsFrontController {

    private final ItemService items;

    public GoodsFrontController(ItemService items) {
        this.items = items;
    }

    @GetMapping("/goods")
    public Object list() {
        return items.list();
    }
}
```

Kotlin 自动帮你生成了构造函数以及属性初始化逻辑。

## 3. 为什么不需要 `@Autowired`？

因为 Spring Boot 支持构造函数依赖注入。

```
@RestController
class GoodsFrontController(
    private val items: ItemService
)
```

Spring 会：

1. 创建 `GoodsFrontController` 对象。
2. 查找 Spring 容器中的 `ItemService` Bean。
3. 通过构造函数传入 `ItemService`。
4. 将它赋值给 `items` 属性。

对于只有一个构造函数的 Spring Bean，不需要写 `@Autowired`。

## 4. Kotlin 的三种写法有什么区别？

```
// 写法一：普通构造函数参数
class A(name: String)

// 写法二：只读成员属性
class B(val name: String)

// 写法三：可修改成员属性
class C(var name: String)
```

| 写法                         | 是否自动成为成员属性 | 是否可以重新赋值 |
| -------------------------- | ---------- | -------- |
| `name: String`             | 否          | 不适用      |
| `val name: String`         | 是          | 否        |
| `var name: String`         | 是          | 是        |
| `private val name: String` | 是，且为私有属性   | 否        |

例如：

```
class User(val name: String, var age: Int)

fun main() {
    val user = User("Tom", 20)

    println(user.name)
    println(user.age)

    user.age = 21

    // user.name = "Jack" // 编译错误
}
```

## 5. Kotlin 还支持普通构造函数吗？

支持。可以使用 `constructor` 关键字：

```
class GoodsFrontController constructor(
    private val items: ItemService
) {
}
```

这和你的原始代码等价。主构造函数没有注解或可见性修饰符时，`constructor` 可以省略。

另外，Kotlin 也支持次构造函数：

```
class User {
    var name: String

    constructor(name: String) {
        this.name = name
    }
}
```

总结：

你看到的：

```
class GoodsFrontController(private val items: ItemService)
```

可以理解为 Java 中：

```
private final ItemService items;

public GoodsFrontController(ItemService items) {
    this.items = items;
}
```

这是 Kotlin 相比 Java 一个非常重要的语法简化，尤其在 Spring Boot、Controller、Service、Repository 中使用非常频繁。
