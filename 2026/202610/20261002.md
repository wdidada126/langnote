# 哪些老书需要警惕？

可以用三个等级，而不是简单删除旧书：

🟢 继续读：核心思想和现代 Python 基本一致。

🟡 选择性读：思想仍然重要，但不要照抄环境、框架版本和 API。

🔴 不建议作为主教材：Python 2、旧 Django/Flask、旧 TensorFlow、旧 packaging 等内容占主体。

例如 Python Cookbook 3e 虽然出版时间已经很早，但仍然非常适合研究 Python idiom；相反，一本 2018 年的 Django/数据科学框架操作书可能已经严重过时。判断技术书寿命，不能只看出版年份。
