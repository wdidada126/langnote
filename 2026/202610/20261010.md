# 2. Rust 方向：Apache Arrow DataFusion（最像现代 Spark SQL）

Apache Arrow DataFusion

这是目前最重要的方向。


定位：

> Rust 写的查询执行引擎。


类似 Spark SQL：

Spark:

```
SQL
 |
Catalyst Optimizer
 |
Physical Plan
 |
Executor
```

DataFusion:

```
SQL
 |
Optimizer
 |
Physical Plan
 |
Rust Executor
```


代码：

Rust：

```rust
let df =
ctx.sql(
"SELECT * FROM users"
)
.await?;
```


支持：

- SQL
- DataFrame API
- Query optimizer
- Vectorized execution

+

+

例如：

Spark：

```

```

[Int32 Array]

# 10. Kafka vs Spark 重写难度

一个重要区别：

## Kafka

核心：

```
消息协议
日志存储
复制
网络
```

所以：

Redpanda：

```
重新实现协议
```

比较容易切入。


---

## Spark

核心：

```
计算模型
+
优化器
+
执行引擎
+
生态
+
机器学习
+
SQL
+
Streaming
```

更复杂。


所以没有：

```
RustSpark
```

这种完全替代。


而是拆：

```
Spark SQL
      |
      +--> DataFusion
      |
      +--> Velox


Spark Streaming
      |
      +--> Flink
      |
      +--> RisingWave


Spark Compute
      |
      +--> Ray
      |
      +--> Dask
```
