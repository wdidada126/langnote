The Rust Shift: Why Reliability Now Matters More Than Ever
Rust并非诞生于大公司战略或学术实验室，而是源于Graydon Hoare对系统编程语言不安全性的长期不满。2006年一次电梯因软件崩溃停运的经历，促使他开始构想一种既能保持C/C++级性能、又能在无垃圾回收器前提下保障内存安全的新语言。Rust早期经历多年反复迭代，核心突破是“所有权”与“借用检查器”：在编译期强制数据访问规则，从根源上避免数据竞争、空指针类错误和大量未定义行为。Mozilla于2009年正式支持Rust，并在2015年发布1.0时承诺向后兼容，为企业级落地奠定基础。Rust以“零成本抽象”为设计原则，通过类型系统、模式匹配、trait、Option/Result等机制，把更多错误前移到编译期，在安全与性能之间打破传统二选一。随着生态成熟，Dropbox、Cloudflare、Microsoft等公司在关键系统中采用Rust，Servo与Firefox Quantum进一步证明其大规模实践价值。2020年Rust Foundation成立，确保项目不依赖单一企业。如今，Rust不仅广泛用于系统组件，也扩展到命令行工具、WebAssembly、嵌入式与游戏开发，并推动业界重新审视“性能必须以安全为代价”的旧共识。Rust的真正意义在于：通过语言设计与社区治理，证明我们能够构建更可靠、更安全且不牺牲性能的软件。

Appel 在你提到的上下文中（那个 Git repo 的 README），指的就是 Andrew W. Appel 这个人。

他是一位著名的计算机科学家，主要成就和知名度都集中在编译原理（Compilers）领域。

### 简单介绍 Andrew W. Appel
- 身份：普林斯顿大学（Princeton University）计算机系教授（Eugene Higgins Professor），从 1986 年起就在那里任教，曾担任系主任（2009–2015）。
- 教育背景：普林斯顿本科 + 卡内基梅隆大学（CMU）博士（1985 年）。
- 研究方向：编程语言、编译器、软件验证、计算机安全、类型系统等。他是函数式编程和编译优化方面的专家。

### 他最出名的作品
他写了一系列经典的《Modern Compiler Implementation》教材（也叫 “Appel 的编译书” 或 “Tiger 编译器书”），这套书在编译原理学习中地位很高，常和“龙书”（Aho 的 Compilers: Principles, Techniques, and Tools）并列为两大入门/进阶圣经。

这套书有多个语言版本（同一个内容，用不同实现语言写）：
- Modern Compiler Implementation in ML（最经典版，用 Standard ML 语言实现，1998 年出版）
- Modern Compiler Implementation in Java（你那个 repo 就是在跟着这个 Java 版做的）
- Modern Compiler Implementation in C（C 语言版，也很受欢迎）

书里用一个叫 Tiger 的简化编程语言（类似 Algol/Pascal 的小型语言，有嵌套函数、数组、记录等）作为教学示例，从头实现一个完整的编译器，包括：
- 词法分析（Lexical analysis）
- 语法分析（Parsing）
- 抽象语法树（AST）
- 语义分析（类型检查、符号表）
- 中间表示（IR）
- 寄存器分配（graph-coloring 算法，很经典）
- 代码生成（目标是 MIPS 汇编，用 SPIM 模拟器跑）

### 为什么很多人提到 “Appel” 就知道是编译？
- 这套书实用性强：不光讲理论，还让你真正实现一个编译器（从零到能跑 Tiger 程序）。
- 社区里无数人跟着书敲代码、开源 repo（像你看到的那个 jeffweiss 的 GitHub 就是典型例子）。
- 相比龙书（更偏理论、厚重），Appel 的书更“动手”、代码干净、现代（强调函数式风格、模块化）。

一句话总结：  
Appel = Andrew W. Appel，普林斯顿教授，编译原理教材大神，他的《Modern Compiler Implementation》系列书是学编译器实现绕不过去的经典（尤其是 Java/ML/C 版）。

如果你在看那个 repo，就是在跟着他的 Java 版 书一步步实现 MiniJava/Tiger 编译器～
