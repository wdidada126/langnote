1：基于 Cookie 的会话保持
简单的来说 Nginx 会根据用户的 Cookie 路由到同一台 Upstream 服务器上，好处很多。
比如某些应用依赖服务器，没有做到无状态，那这个功能就很贴心，相当于根据用户身份确保路由的服务器是同一台。
再举个简单的例子，你将用户的数据根据Hash算法缓存到服务器上了，有了Cookie路由避免了缓存失效问题。
再比如 WebSocket 连接需要尽量和一台服务器保持连接。
也就是说 Nginx 完善了 HTTP 七层功能，过去也有基于 IP 的路由方法，但考虑到 NAT、移动网络等复杂的网络情况，显然Cookie路由方法更稳定。

# 1. pull 之前：不能直接改官方镜像里的源
`docker pull ubuntu` 下载的是官方原版镜像，里面自带的是 Ubuntu 官方国外源。
你无法在下载前修改镜像内部文件。

正确做法：
先pull，再进容器改源（最常用、最稳）

# 2. pull 之后：进入容器，直接改源（最推荐）
这是99%的人用的方法。

## 步骤（复制就能用）
### ① 运行一个临时 Ubuntu 容器
```bash
docker run -it --rm ubuntu
```

### ② 备份原来的源（可选但推荐）
```bash
cp /etc/apt/sources.list /etc/apt/sources.list.bak
```

### ③ 替换成国内镜像源（以阿里云为例）
直接复制执行：
```bash
cat > /etc/apt/sources.list << EOF
deb http://mirrors.aliyun.com/ubuntu/ noble main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ noble-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ noble-security main restricted universe multiverse
EOF
```

### ④ 更新缓存
```bash
apt update
```
速度立刻起飞！

# 3. 进阶：构建自己的镜像（一劳永逸）
如果你希望 每次新建容器都自动用国内源，可以做一个自定义镜像：

### 新建 `Dockerfile`
```dockerfile
FROM ubuntu:latest

# 替换阿里云源
RUN sed -i 's@archive.ubuntu.com@mirrors.aliyun.com@g' /etc/apt/sources.list
```

### 构建
```bash
docker build -t ubuntu-cn .
```

以后直接用：
```bash
docker run -it ubuntu-cn
```
自带国内源，不用每次改！

# 4. 最快最省事的方法（一行命令直接换源）
进入 Ubuntu 容器后，直接运行这一行：
```bash
sed -i 's/archive.ubuntu.com/mirrors.aliyun.com/g' /etc/apt/sources.list && apt update
```
1 秒换源，直接能用

# 你要构建 `Dockerfile.dev` 👇
## 正确命令（直接复制运行）
```bash
docker build -f Dockerfile.dev -t ubuntu-dev-flex:24.04 .
```

## 命令解释（一看就懂）
- `docker build`：构建镜像
- `-f Dockerfile.dev`：指定使用 Dockerfile.dev 这个文件
  （不加 `-f` 默认只找 `Dockerfile`，找不到你的自定义文件）
- `-t ubuntu-dev-flex:24.04`：给镜像起名字
- `.`：指定当前目录（必须写）

# 你的 Dockerfile.dev 可以这样写（自带 flex）
```dockerfile
FROM ubuntu-dev:24.04

RUN apt update && \
    apt install -y flex && \
    apt clean && \
    rm -rf /var/lib/apt/lists/*
```

# 构建完进入方式
```bash
docker run -it --rm ubuntu-dev-flex:24.04 /bin/bash
```

## 超级总结
构建自定义 Dockerfile 必须加 `-f`
```bash
docker build -f 你的Dockerfile名字 -t 镜像名:标签 .
```
