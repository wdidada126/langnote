我教你最简单、最稳、10秒保存镜像的方法！
你现在已经装好了 gcc、gdb、cmake、flex，不要退出容器，直接跟着我做

# 一步保存成镜像（永久保存软件）
## 1. 先不要退出当前容器
你现在还是在这里：
```
[root@1b0604de4424 /]#
```

## 2. 在电脑上新开一个终端窗口
输入这个命令，看你的容器ID：
```bash
docker ps
```

你会看到：
```
CONTAINER ID   IMAGE      COMMAND
1b0604de4424    centos:7   "/bin/bash"
```
把前面这个 ID 复制下来，比如：`1b0604de4424`

## 3. 执行保存命令（直接复制）
把 `你的容器ID` 换成你刚才看到的：
```bash
docker commit 你的容器ID centos7-dev:latest
```

### 例子（你照着改）：
```bash
docker commit 1b0604de4424 centos7-dev:latest
```

# ✅ 保存成功！现在你有了新镜像
## 这个镜像里 永久自带：
✅ gcc

✅ flex

# 以后直接用这个新镜像（再也不用重装）
```bash
docker run -it --rm centos7-dev:latest /bin/bash
```
