### 最快上手建议（推荐路径）
1. 先克隆官方最简单的（5 分钟上手）：
   ```bash
   git clone https://github.com/pybind/python_example
   cd python_example
   pip install .
   ```
   然后在 Python 里：
   ```python
   import python_example
   print(python_example.add(3, 4))   # 输出 7
   ```

2. 想用 CMake 的（大多数生产项目用这个）：
   ```bash
   git clone https://github.com/pybind/cmake_example
   cd cmake_example
   mkdir build && cd build
   cmake .. -DPYBIND11_INSTALL=ON
   make install
   ```
   （或直接 pip install . 如果有 pyproject.toml）

3. 想看多种写法：
   直接去 https://github.com/tdegeus/pybind11_examples ，里面有 10+ 个独立小例子，clone 后随便进一个文件夹看 README。

4. 配套官方文档（强烈建议同时看）：
   - https://pybind11.readthedocs.io/en/stable/basics.html （从这里开始，讲得最清楚）
   - 文档里也直接指向上面两个官方 example 仓库。

这些仓库代码都很干净，基本都是 2024–2026 年还能正常构建的。如果你遇到编译问题（比如 Python 版本、CMake 找不到 pybind11），可以先用 conda 环境：
```bash
conda create -n pybind python=3.11
conda activate pybind
conda install -c conda-forge pybind11 cmake
```
