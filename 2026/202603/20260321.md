在 WSL 环境下加速安装 Rust，核心是同时配置 rustup（工具链安装）与 cargo（依赖下载）的国内镜像，以下是一步到位的标准方案。

### 一、临时生效（当前终端，快速试错）
在当前 WSL 终端中执行以下命令，设置临时镜像环境变量：
```bash
# 字节跳动 rsproxy（稳定推荐）
export RUSTUP_DIST_SERVER="https://rsproxy.cn"
export RUSTUP_UPDATE_ROOT="https://rsproxy.cn/rustup"
```
随后直接执行安装命令：
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
✅ 提示：此方式仅当前终端有效，关闭终端后失效，适合快速验证。

### 二、永久生效（一劳永逸，推荐）
#### 1. 配置 rustup 镜像（工具链下载加速）
编辑 shell 配置文件（根据终端类型选择）：
- Bash：`vim ~/.bashrc`
- Zsh：`vim ~/.zshrc`

在文件末尾添加以下内容（任选一个镜像源，推荐 rsproxy）：
```bash
# 字节跳动 rsproxy（稳定、速度快）
export RUSTUP_DIST_SERVER="https://rsproxy.cn"
export RUSTUP_UPDATE_ROOT="https://rsproxy.cn/rustup"

# 备选：中科大源
# export RUSTUP_DIST_SERVER="https://mirrors.ustc.edu.cn/rust-static"
# export RUSTUP_UPDATE_ROOT="https://mirrors.ustc.edu.cn/rust-static/rustup"

# 备选：上海交大源
# export RUSTUP_DIST_SERVER="https://mirrors.sjtug.sjtu.edu.cn/rust-static"
# export RUSTUP_UPDATE_ROOT="https://mirrors.sjtug.sjtu.edu.cn/rust-static/rustup"
```

保存并生效配置：
```bash
# Bash 执行
source ~/.bashrc

# Zsh 执行
source ~/.zshrc
```

#### 2. 配置 cargo 镜像（依赖包下载加速）
创建/编辑 cargo 配置文件：
```bash
mkdir -p ~/.cargo
vim ~/.cargo/config
```

写入以下内容（推荐稀疏索引，cargo ≥1.68 版本支持，速度更快）：
```toml
[source.crates-io]
replace-with = "rsproxy-sparse"  # 替换为 rsproxy 稀疏索引

# 字节跳动 rsproxy 稀疏索引（推荐）
[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"

# 备选：中科大源
# replace-with = "ustc"
# [source.ustc]
# registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
```

### 三、验证安装与配置
1. 重启终端，执行安装命令：
    ```bash
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
    ```
2. 安装完成后，验证工具链与镜像配置：
    ```bash
    # 查看 rust 版本
    rustc --version
    # 查看 cargo 版本
    cargo --version
    # 测试下载依赖（会从国内镜像拉取，速度快）
    cargo new hello_rust && cd hello_rust
    cargo build
    ```

### 四、常见问题与优化
- 下载仍慢：检查环境变量是否生效（`echo $RUSTUP_DIST_SERVER`），确保没有拼写错误；可切换镜像源尝试。
- WSL 网络问题：确保 WSL 与 Windows 网络互通，可在 Windows 防火墙允许 WSL 网络访问。
- cargo build 卡顿：删除缓存文件（`rm -rf ~/.cargo/.package-cache`），重新执行构建。

### 五、镜像源对比
| 镜像源       | 地址                                 | 特点                     |
|--------------|--------------------------------------|--------------------------|
| 字节跳动 rsproxy | `https://rsproxy.cn`                 | 速度快、稳定、维护活跃   |
| 中科大       | `https://mirrors.ustc.edu.cn`        | 老牌镜像、可靠性高       |
| 上海交大     | `https://mirrors.sjtug.sjtu.edu.cn`  | 高校镜像、带宽充足       |
