国际通用的代码行数统计标准主要有以下几种：

1. 主要统计标准
物理行数 (Physical Lines)
• 统计文件中的所有行，包括空行和注释
• 最简单直接的统计方式
• 工具示例：wc -l
逻辑行数 (Logical Lines)
• 统计实际执行的代码行
• 排除空行、注释、仅包含大括号的行
• 更能反映实际代码量
非空行数 (Non-blank Lines)
• 统计所有非空行，包括注释
• 排除空行，保留注释

2. 行业常用工具

# Unix/Linux 工具
wc -l *.java                 # 物理行数统计
grep -c '.' *.java          # 非空行数
grep -v '^$' *.java | wc -l # 非空行数

# 专业工具
cloc                          # 最流行的多语言统计工具
scc                           # 快速准确的代码统计器
tokei                         # Rust编写的快速统计工具

3. CLOC 工具（推荐）
# 安装
brew install cloc           # macOS
apt-get install cloc        # Ubuntu
choco install cloc          # Windows (Chocolatey)

# 使用
cloc .                      # 统计当前目录
cloc --by-file .            # 按文件显示
cloc --include-lang=Java .  # 只统计Java
cloc --exclude-dir=vendor . # 排除目录

4. Maven/Gradle 插件

Maven:
<plugin>
    <groupId>org.codehaus.mojo</groupId>
    <artifactId>cloc-maven-plugin</artifactId>
    <version>2.9.0</version>
</plugin>

mvn cloc:count

Gradle:
plugins {
    id 'com.github.ben-manes.codenarc' version 'x.x.x'
}

6. 各语言统计差异
• Java/C++: 通常统计 .java/.cpp/.h 文件
• Web项目: HTML/CSS/JS/TypeScript 分开统计
• 配置文件: 通常单独统计 XML/YAML/Properties
• 测试代码: 建议与生产代码分开统计

7. 最佳实践

1. 一致性: 在团队中使用统一的统计标准
2. 排除项: 忽略生成代码、依赖库、构建产物
3. 自动化: 集成到CI/CD流水线中
4. 趋势分析: 定期统计跟踪代码增长趋势

推荐使用 CLOC 工具，它是最广泛接受的开源行数统计标准，支持200多种编程语言。
