在 AI 编程助手（如 Cursor、Windsurf、Codeium 等）中，用于定义助手行为、技能和上下文的配置文件通常被称为 .cursorrules 或 prompts 文件。这些文件用于定制 AI 在特定项目或目录中的行为。

以下是这类文件通常包含的内容：

1. 核心配置文件：.cursorrules

这是最主流的配置文件，通常放置在项目根目录或特定子目录下。它包含以下内容：

*   角色定义 (Role Definition)：告诉 AI 它在这个项目中的身份。
    ◦   例如：You are a senior backend engineer specializing in Go and microservices.

*   项目上下文 (Project Context)：提供项目背景、架构说明、技术栈。
    ◦   例如：This is a microservice project using Go, gRPC, and PostgreSQL. The code follows Clean Architecture.

*   编码规范 (Coding Standards)：定义代码风格、命名约定、文件组织规则。
    *   例如：Use snake_case for variables, write comprehensive unit tests, and avoid global variables.
*   特定指令 (Specific Instructions)：针对特定任务或文件的特殊要求。
    ◦   例如：When modifying the database schema, always write corresponding migration files.

*   依赖和导入规则 (Dependencies & Imports)：指定常用的库和导入语句。
    ◦   例如：Always import 'react' when writing React components.

2. 技能文件 (Skill Files)

技能文件通常指 .md 文件，用于存储可重用的代码片段、函数模板或复杂逻辑。它们通常被 .cursorrules 文件引用。

*   内容：
    ◦   函数模板：常用的函数结构（如 CRUD 操作、错误处理）。

    *   算法实现：特定算法的代码示例。
    ◦   配置模板：如 Dockerfile、CI/CD 配置的模板。

*   用法：在 .cursorrules 中通过路径引用，例如：Refer to the file './skills/database.md' for database operations.

3. 提示词文件 (Prompt Files)

这些是包含特定任务指令的文本文件，通常以 .txt 或 .md 结尾。

*   内容：
    ◦   重构指令：如何重构特定代码块。

    ◦   代码生成指令：生成特定类型代码的详细要求。

    *   调试指令：如何分析并修复错误。

4. 示例结构

一个典型的项目结构可能如下：

my-project/
├── .cursorrules          # 主配置文件
├── prompts/
│   ├── refactor.txt      # 重构提示词
│   └── generate-api.txt  # API 生成提示词
└── skills/
    ├── database.md       # 数据库操作技能
    └── auth.md          # 认证逻辑技能


5. 总结

•   .cursorrules：全局行为定义，告诉 AI 如何在这个项目中工作。

•   技能文件：可重用的代码模板，提供具体的实现细节。

•   提示词文件：特定任务的指令，用于执行具体的操作。

如果你在使用特定的 IDE 或工具，建议查看其官方文档以获取确切的文件命名和格式要求。

•   内容：深入剖析 CUDA 性能优化技巧，包括内存层级、原子操作、流与事件等。中文版为《CUDA C编程权威指南》。

3. 实战书籍：《Learn CUDA Programming》

•   内容：涵盖图像处理、数值模拟和神经网络等实战主题，同时提供 C++ 和 Python 版本代码，适合边学边练。

三、 核心概念速览

CUDA 编程模型的核心在于理解线程层次和内存层次：
•   线程层次：线程 (Thread) → 线程块 (Block) → 网格 (Grid)。通过 threadIdx 和 blockIdx 等内置变量来唯一标识线程。[citation:available:2]
*   内存层次：从快到慢依次为寄存器 (Registers)、共享内存 (Shared Memory)、全局内存 (Global Memory)。合理利用共享内存是性能优化的关键。[citation:available:2]
*   执行模型：GPU 以 Warp（32个线程为一组）为单位执行指令，遵循 SIMT（单指令多线程）模型。[citation:available:2]

四、 学习路径建议
1.  入门阶段：先玩 GPU-Puzzles，建立直观感受；然后阅读《CUDA by Example》或官方入门指南。
2.  进阶阶段：研读 cuda-samples 官方源码，结合《Professional CUDA C Programming》学习优化技巧。
3.  实战阶段：参考 LeetCUDA 项目，动手实现矩阵乘法、注意力机制等核心算法，并学习使用 Nsight 工具进行性能分析。
