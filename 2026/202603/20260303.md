根据 Rust 编程语言的官方定义，&str 和 String 确实是两种不同的字符串类型，它们在内内存表示、所有权和生命周期方面有本质区别。

&str 详解

&str 是一个字符串切片（string slice），它是一个引用类型。它的核心特征是：

1. 内存布局

// 在内存中，&str 由两部分组成：
let s: &str = "hello";
// 内存表示：
//   +-----+-----+
//   | ptr | len |
//   +-----+-----+
//      |     |
//      v     v
//   指向实际 字符串长度
//   数据的指针


2. 核心特性

• 不可变引用：默认情况下，&str 是不可变的引用

• 不拥有数据：它只是借用（borrow）了数据

• 编译时已知大小：固定大小（两个机器字：指针 + 长度）

• 栈上分配：切片本身存储在栈上

• 生命周期：有明确的生命周期，通常与源数据绑定

3. 常见来源

// 1. 字符串字面量
let s1: &str = "hello";  // 存储在只读内存区

// 2. 从 String 借用
let string = String::from("world");
let s2: &str = &string;  // 借用 String 的内容

// 3. 字符串切片
let s3: &str = &string[0..3];  // "wor"

// 4. 函数参数
fn print_str(s: &str) {  // 接受 &str
    println!("{}", s);
}


&str vs String 对比

特性 &str String

所有权 无所有权（借用） 拥有所有权

内存位置 栈上（指针+长度） 堆上（数据）

可变性 默认不可变 可变（需 mut）

大小 编译时固定（2个机器字） 运行时可变

性能 零成本抽象，无分配 需要堆分配

典型用途 函数参数、只读视图 需要修改或构建字符串

实际使用示例

fn main() {
    // String：堆分配的，可变的
    let mut s1 = String::from("Hello");
    s1.push_str(", world!");
    
    // &str：字符串的视图/引用
    let s2: &str = "I'm a string literal";
    
    // 从 String 创建 &str
    let slice: &str = &s1[0..5];  // "Hello"
    
    // 函数通常接受 &str 参数（更通用）
    print_length(&s1);  // String 自动解引用为 &str
    print_length(s2);
    
    // 比较操作
    if s1 == "Hello, world!" {  // String 可以和 &str 比较
        println!("They are equal!");
    }
}

fn print_length(s: &str) {
    println!("Length of '{}' is {}", s, s.len());
}


关键设计哲学

Rust 这样设计是为了：

1. 零成本抽象：&str 不涉及堆分配，性能接近 C 的字符指针
2. 安全性：通过生命周期确保不会出现悬垂引用
3. 灵活性：&str 可以引用任何字符串数据（字面量、String、子串等）
4. 效率：避免不必要的拷贝，特别是作为函数参数时

总结

&str 是 Rust 中字符串的只读视图，它：
• 是一个胖指针（包含数据指针和长度）

• 用于高效地传递和访问字符串数据而不取得所有权

• 是处理字符串的首选参数类型（函数应优先使用 &str 而非 String）

• 体现了 Rust 的借用检查和生命周期系统

这种设计使得 Rust 能在保证内存安全的同时，提供接近 C 语言级别的字符串处理性能。
