1. 网站是做什么的？

Code Synthesis 主要提供 C++ 领域的“代码生成”和“构建系统”工具，核心产品包括：
•   build2：一个现代化的 C++ 构建工具链，集成了构建系统、包管理器和项目依赖管理，旨在替代传统的 Make 或 CMake，提供更一致和高效的开发体验 。

•   ODB：一个开源的 C++ ORM（对象关系映射）框架。它通过一个编译器将 C++ 类定义直接映射到数据库表，让你可以用 C++ 对象直接操作数据库，而无需手写繁琐的 SQL 代码 。

•   XSD：用于处理 XML Schema 和数据的 C++ 工具。

# 或者查看包描述信息
dpkg -I your_package_name.deb
