开源正则解析器/引擎非常多，按语言、用途、性能、安全特性分类如下，覆盖主流场景与底层实现。

## 一、工业级、高性能、安全优先（生产推荐）
### 1. RE2 (Google, C++)
- 定位：安全、无回溯、线性时间、线程安全的正则引擎
- 核心：基于 Thompson NFA → DFA，无 ReDoS 风险
- 语法：兼容大部分 PCRE/Perl 风格（不支持回溯/后向引用）
- 用途：高吞吐、安全敏感场景（日志、搜索、API 网关）
- 语言绑定：C++、Go、Python、Java、Rust 等
- 仓库：https://github.com/google/re2

### 2. PCRE2 (C)
- 定位：最通用、兼容 Perl 语法的正则库（行业标准）
- 核心：支持回溯、后向引用、零宽断言、递归、Unicode
- 版本：PCRE2（10.x）替代旧版 PCRE（8.x）
- 用途：Apache、Nginx、PHP、Postfix、Nmap 等底层依赖
- 仓库：https://github.com/PhilipHazel/pcre2

### 3. Rust regex crate (Rust)
- 定位：Rust 标准生态，安全、零拷贝、高性能、无 ReDoS
- 核心：多引擎（PikeVM、Lazy DFA、OnePass）、SIMD 加速
- 语法：兼容 Perl/PCRE 常用子集，不支持回溯/后向引用
- 用途：Rust 项目、命令行工具、解析器、日志处理
- 仓库：https://github.com/rust-lang/regex

### 4. coregex (Go)
- 定位：Go 标准库 regexp 的 drop-in 高性能替代
- 核心：多引擎、SIMD 预过滤、反向搜索，号称 3–3000x 加速
- 特性：无回溯、O(n) 保证、无 ReDoS
- 仓库：https://github.com/coregx/coregex

## 二、语言原生/专用解析器（生成 AST、用于工具链）
### 1. regexpp (TypeScript/JS)
- 定位：ECMAScript 正则专用解析器，生成 AST
- 功能：解析、验证、遍历、修改 JS 正则 AST
- 用途：ESLint、Prettier、代码转换、IDE 插件
- 仓库：https://github.com/mysticatea/regexpp

### 2. tree-sitter-regex (C/多语言)
- 定位：基于 Tree-sitter 的增量正则语法解析器
- 支持：PCRE2、POSIX、JavaScript 语法
- 用途：编辑器高亮、语法检查、代码导航、重构
- 仓库：https://github.com/tree-sitter/tree-sitter-regex

### 3. oak-regex (Rust)
- 定位：高性能、增量解析、结构化输出
- 特性：错误恢复、适合 IDE/语言服务器场景
- 仓库：https://github.com/oak-lang/oak-regex

### 4. Regulex (JS)
- 定位：正则解析 + 可视化工具（浏览器/Node.js）
- 功能：生成正则语法图、错误定位、调试
- 用途：在线正则调试、教学、文档
- 仓库：https://github.com/CJDoobey/Regulex

## 三、教学/轻量/实验性解析器（学习用）
### 1. regex-parser (Haskell)
- 定位：函数式风格正则解析器，含解析、匹配、打印
- 仓库：https://github.com/gterrono/regex-parser

### 2. regexp-parser (JS)
- 定位：极简 JS 正则解析器，支持基础语法
- 仓库：https://github.com/springuper/regexp-parser

### 3. dregex (Java)
- 定位：Java DFA 正则引擎，支持集合运算、线性时间
- 仓库：https://github.com/marianobarrios/dregex

## 五、快速上手示例
### 1. Rust regex（最稳）
```rust
use regex::Regex;

fn main() {
    let re = Regex::new(r"(\w+)@(\w+)\.com").unwrap();
    let text = "user@example.com";
    if let Some(caps) = re.captures(text) {
        println!("User: {}", &caps[1]);
        println!("Domain: {}", &caps[2]);
    }
}
```

### 2. RE2 (C++)
```cpp
#include <re2/re2.h>
using namespace re2;

int main() {
    RE2 re(R"((\w+)@(\w+)\.com)");
    std::string text = "user@example.com";
    std::string user, domain;
    if (RE2::FullMatch(text, re, &user, &domain)) {
        // ...
    }
    return 0;
}
```

### 3. regexpp（解析 AST）
```typescript
import { parse } from 'regexpp';
const ast = parse('/a(b+)c/');
// 遍历 AST 结构
```

## 六、关键选型建议
- 安全优先（防 ReDoS）：选 RE2、Rust regex、coregex
- 功能最全（Perl 兼容）：选 PCRE2
- Rust 生态：直接用 regex crate
- JS/TS 工具链：用 regexpp
- 编辑器/IDE：用 tree-sitter-regex
- 学习原理：看 RE2、Rust regex、dregex 源码
