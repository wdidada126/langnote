打开 PowerShell 或 命令提示符（建议以管理员身份运行），输入以下命令：

wsl --terminate Ubuntu-22.04

# 停止 Ubuntu 18.04
wsl --terminate Ubuntu-18.04


3. 卸载（注销）发行版

使用 wsl --unregister 命令删除发行版。注意：此操作会永久删除该发行版内的所有文件和数据，请务必提前备份重要文件。
# 卸载 Ubuntu 22.04
wsl --unregister Ubuntu-22.04

# 卸载 Ubuntu 18.04
wsl --unregister Ubuntu-18.04


4. 验证卸载结果

再次执行查看命令，确认列表中已没有对应的发行版：

2. 取消勾选 适用于 Linux 的 Windows 子系统 和 虚拟机平台。
3. 点击“确定”并重启电脑。

# 一、汇编编程里的 内存对齐（Memory Alignment）
## 一句话解释
数据要按它自身大小，放在“能被整除”的内存地址上，这就是内存对齐。

## 为什么要对齐？
- CPU 读取对齐数据：一次读完，超快
- CPU 读取未对齐数据：要读多次、拼接，慢 + 可能崩溃
- macOS / iOS 强制要求栈对齐 16字节

## 简单例子
```
1字节 char  → 放任意地址
2字节 short → 放偶数地址
4字节 int   → 放 4 的倍数地址
8字节 long  → 放 8 的倍数地址
```

## 汇编里最重要的规则
macOS 调用函数前，栈指针 rsp 必须是 16 的倍数！
不满足就直接崩溃。

# 二、寄存器（Register）是什么？
## 一句话
寄存器是 CPU 上的“超级高速临时变量”，比内存快 100~1000 倍。

汇编编程就是在操作寄存器。

## macOS（x86_64）常用寄存器（必须记住）
### 通用寄存器
```
rax, rbx, rcx, rdx
rsi, rdi, rbp, rsp
r8, r9, r10 ~ r15
```

### 专用
- `rsp`：栈指针（stack pointer）
- `rbp`：栈基址
- `rip`：指令指针（下一条执行的指令）

### 函数调用传参顺序（x86_64 macOS / Linux）
```
rdi → 第1参数
rsi → 第2参数
rdx → 第3参数
rcx → 第4参数
r8  → 第5参数
r9  → 第6参数
```
再多参数才用栈。

# 三、macOS 12.7 如何查看寄存器？（最实用）
你不需要任何复杂工具，系统自带就能看。

## 方法1：看 CPU 支持哪些寄存器（最直接）
终端输入：
```bash
sysctl -a | grep cpu
```

查看指令集：
```bash
sysctl machdep.cpu.features
```

看到 `sse` `avx` 等，说明支持向量寄存器。

## 方法2：运行程序时，查看当前寄存器值（调试）
```bash
lldb 你的程序
run
# 断住后输入
register read
```

会输出所有寄存器：
```
rax = 0x0000000100000000
rbx = 0x0000000000000000
...
```

## 方法3：查看系统架构（确认是 x86_64 寄存器）
```bash
uname -m
```
输出：
```
x86_64
```
说明你用的是 x86_64 寄存器集（就是上面那套）。

# 视频最核心：YUV420 转 RGB（色彩转换）汇编优化
这是视频渲染、美颜、滤镜、屏幕共享必须用的函数，C 语言根本跑不动实时 1080p。

下面这段是 x86_64 + AVX2 汇编（你 mac 上能直接跑）。

# 真实工业级汇编代码（WebRTC 风格）
```nasm
; WebRTC / FFmpeg 真实使用：YUV420 转 RGB24  AVX2 优化汇编
; 一次处理 16 个像素（C语言的8倍速度）
section .text
global yuv420_to_rgb_avx2

yuv420_to_rgb_avx2:
    ; 输入：rdi=Y, rsi=U, rdx=V, rcx=RGB输出
    ; 寄存器：ymm0~ymm15 AVX2 向量寄存器（256位，一次处理32字节）

    vmovups ymm0, [rdi]    ; 加载 32字节 Y 数据
    vmovups ymm1, [rsi]    ; 加载 16字节 U 数据
    vmovups ymm2, [rdx]    ; 加载 16字节 V 数据

    ; 色彩转换公式（视频会议标准 BT.601）
    ; R = Y + 1.403 * (V - 128)
    ; G = Y - 0.344 * (U - 128) - 0.714 * (V - 128)
    ; B = Y + 1.773 * (U - 128)

    vbroadcasti128 ymm3, ymm1 ; U 扩展到 256位
    vbroadcasti128 ymm4, ymm2 ; V 扩展到 256位

    vpbroadcastb ymm5, [rip + const_128]   ; 减去128（UV偏移）
    vpsubb  ymm3, ymm5                     ; U -= 128
    vpsubb  ymm4, ymm5                     ; V -= 128

    ; 计算 RGB（SIMD 并行计算 16 个像素）
    vpmaddubsw ymm6, ymm3, [rip + coeff_b] ; B 系数
    vpmaddubsw ymm7, ymm4, [rip + coeff_r] ; R 系数
    vpmaddubsw ymm8, ymm3, [rip + coeff_g1]
    vpmaddubsw ymm9, ymm4, [rip + coeff_g2]

    ; 结果打包、限幅、写入内存
    vpackuswb ymm6, ymm6, ymm6
    vpackuswb ymm7, ymm7, ymm7
    vpackuswb ymm8, ymm8, ymm9

    vmovups [rcx], ymm7      ; 写 R
    vmovups [rcx+32], ymm8   ; 写 G
    vmovups [rcx+64], ymm6   ; 写 B

    vzeroupper       ; AVX2 退出必须清空高位
    ret

; 视频转换系数（WebRTC 官方固定值）
section .rodata
const_128:   times 32 db 128
coeff_r:     times 16 dw 1403
coeff_g1:    times 16 dw -344
coeff_g2:    times 16 dw -714
coeff_b:     times 16 dw 1773
```
