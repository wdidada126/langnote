在 Windows 11 上卸载 Ubuntu 18.04 和 22.04（WSL2 环境），最直接的方法是使用 wsl --unregister 命令。以下是详细的操作步骤：

1. 查看已安装的发行版

首先，你需要确认系统中具体安装了哪些 Ubuntu 版本，以及它们的准确名称。

打开 PowerShell 或 命令提示符（建议以管理员身份运行），输入以下命令：
wsl --list --verbose

执行后，你会看到类似下面的列表，确认 Ubuntu-18.04 和 Ubuntu-22.04 是否存在：

NAME            STATE      VERSION
Ubuntu-22.04    Running    2
Ubuntu-18.04    Stopped    2


2. 停止正在运行的发行版（可选）

如果目标发行版的状态是 Running，建议先停止它，以确保数据安全。
# 停止 Ubuntu 22.04
wsl --terminate Ubuntu-22.04

# 停止 Ubuntu 18.04
wsl --terminate Ubuntu-18.04


3. 卸载（注销）发行版

使用 wsl --unregister 命令删除发行版。注意：此操作会永久删除该发行版内的所有文件和数据，请务必提前备份重要文件。
# 卸载 Ubuntu 22.04
wsl --unregister Ubuntu-22.04

# 卸载 Ubuntu 18.04
wsl --unregister Ubuntu-18.04


4. 验证卸载结果

再次执行查看命令，确认列表中已没有对应的发行版：
wsl --list --verbose


5. 清理残留文件（可选）

如果通过 Microsoft Store 安装过，或者想彻底清理磁盘空间，可以手动删除残留文件夹：
1. 打开文件资源管理器，在地址栏输入 %LOCALAPPDATA%\Packages 并回车。
2. 删除以下文件夹（如果存在）：
    ◦ CanonicalGroupLimited.Ubuntu18.04LTS_*

    ◦ CanonicalGroupLimited.Ubuntu22.04LTS_*

6. 关闭 WSL 功能（可选）

如果你不打算再使用任何 WSL 环境，可以彻底关闭该功能：
1. 按 Win + R，输入 optionalfeatures 打开“启用或关闭 Windows 功能”。
2. 取消勾选 适用于 Linux 的 Windows 子系统 和 虚拟机平台。
3. 点击“确定”并重启电脑。

总结：核心操作就是使用 wsl --unregister 命令，它会自动删除虚拟硬盘文件（.vhdx），释放磁盘空间。
