你这条命令写了一半，`cp` 的语法是 `cp [选项] 源文件 目标文件`。如果目标是目录，并且你想覆盖目录里同名的文件，有两种写法：

### 写法一：直接指定完整的目标文件路径（推荐）
这样最明确，不会产生歧义：
```bash
cp /mnt/c/Users/wdidada/.codex/auth.json "$HOME/.codex/auth.json"
```
注意 `$HOME/.codex/` 后面要加上 `auth.json`，否则 `cp` 会认为你要把源文件复制成名为 `.codex` 的文件（如果 `.codex` 是目录，则行为不同）。

### 写法二：保留目录写法，让 cp 自动使用源文件名
如果 `$HOME/.codex/` 确实是个已存在的目录，可以这样写：
```bash
cp /mnt/c/Users/wdidada/.codex/auth.json "$HOME/.codex/"
```
末尾的 `/` 明确告诉 `cp` 这是目录，它会把 `auth.json` 复制进去，如果已存在同名文件就会直接覆盖。

### 关于“覆盖”的注意事项
- 默认情况下，`cp` 会直接覆盖目标文件，**不会有任何提示**（除非你的 shell 配置了 `alias cp='cp -i'`）。
- 如果你希望**强制覆盖且不报错**，可以加 `-f`：
  ```bash
  cp -f /mnt/c/Users/wdidada/.codex/auth.json "$HOME/.codex/auth.json"
  ```
- 如果希望**覆盖前有提示**，加 `-i`：
  ```bash
  cp -i /mnt/c/Users/wdidada/.codex/auth.json "$HOME/.codex/auth.json"
  ```

### 如果 `$HOME/.codex/` 目录还不存在
先创建目录再复制：
```bash
mkdir -p "$HOME/.codex"
cp /mnt/c/Users/wdidada/.codex/auth.json "$HOME/.codex/auth.json"
```
