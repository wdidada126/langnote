在 Oracle 数据库中，“空”和 NULL 是同一个概念，可以认为完全等价。
但需要注意几个关键点，否则容易踩坑：
· 写法：判断“是否为空”必须用 IS NULL 或 IS NOT NULL，不能用 = NULL 或 != NULL，因为 NULL 参与任何比较运算结果都是“未知”（Unknown），不会返回 true 或 false。
· 函数处理：大部分函数遇到 NULL 会返回 NULL，比如 'A' || NULL 结果是 NULL。如果需要将空值转为默认值，用 NVL() 或 COALESCE()。
· 索引与统计：NULL 值不会被 B-tree 索引记录（复合索引例外），且 COUNT(列名) 会忽略 NULL 行，但 COUNT(*) 会统计所有行。
· 空字符串的特殊性：Oracle 中 ''（空字符串）会被自动当作 NULL 处理，这与 SQL Server、MySQL 等数据库不同，是个常见大坑。比如 WHERE 列 = '' 查不到任何数据，必须用 IS NULL。
