## 各语言对象相等性判断总览

| 语言 | 机制 | 语法 | 哈希支持 |
|------|------|------|--------|
| **Java** | `equals()` + `hashCode()` | `obj1.equals(obj2)` | 方法重写 |
| **C** | 字段比较 / `memcmp` | `point_eq(a, b)` | 无 |
| **C++** | `operator==` | `a == b` | `std::hash<T>` |
| **Rust** | `PartialEq` trait | `a == b` | `Hash` trait |
| **Go** | `==` / 接口 | `a == b` / `reflect.DeepEqual` | 无标准化 |
| **Python** | `__eq__` | `a == b` | `__hash__` |
| **C#** | `Equals()` / `==` | `a.Equals(b)` | `GetHashCode()` |

## 详细对比

### 1. **C** — 手动比较

```c
#include <string.h>

struct Person {
    int id;
    char name[50];
    float salary;
};

// 方法1: 字段逐个比较（推荐）
int person_equal(struct Person a, struct Person b) {
    return a.id == b.id && 
           strcmp(a.name, b.name) == 0 && 
           a.salary == b.salary;
}

// 方法2: memcmp（注意内存对齐风险）
int person_equal_fast(struct Person a, struct Person b) {
    return memcmp(&a, &b, sizeof(struct Person)) == 0;
}
```

**无哈希**：C 没有集合类，通常需要自己实现哈希表。

---

### 2. **C++** — 重载运算符

```cpp
class Person {
    int id;
    std::string name;
    float salary;
    
public:
    // 重载 ==
    bool operator==(const Person& other) const {
        return id == other.id && 
               name == other.name && 
               salary == other.salary;
    }
    
    // 重载 !=
    bool operator!=(const Person& other) const {
        return !(*this == other);
    }
};

// 使用
Person p1{1, "Alice", 5000.0};
Person p2{1, "Alice", 5000.0};
if (p1 == p2) { /* 相等 */ }

// 哈希支持（用于 std::unordered_map / std::unordered_set）
namespace std {
    template <>
    struct hash<Person> {
        size_t operator()(const Person& p) const {
            return hash<int>()(p.id) ^ (hash<string>()(p.name) << 1);
        }
    };
}

std::unordered_set<Person> persons;
```

### 3. **Rust** — Trait 实现

```rust
#[derive(PartialEq, Eq, Hash)]
struct Person {
    id: i32,
    name: String,
    salary: f32,
}

// 或手动实现
impl PartialEq for Person {
    fn eq(&self, other: &Self) -> bool {
        self.id == other.id && 
        self.name == other.name && 
        (self.salary - other.salary).abs() < f32::EPSILON
    }
}

impl Eq for Person {}  // 若无浮点数，可实现 Eq（严格相等）

impl std::hash::Hash for Person {
    fn hash<H: std::hash::Hasher>(&self, state: &mut H) {
        self.id.hash(state);
        self.name.hash(state);
        self.salary.to_bits().hash(state);
    }
}

// 使用
let p1 = Person { id: 1, name: "Alice".to_string(), salary: 5000.0 };
let p2 = Person { id: 1, name: "Alice".to_string(), salary: 5000.0 };
assert!(p1 == p2);

// 用于 HashSet / HashMap
let mut set = std::collections::HashSet::new();
set.insert(p1);
```

**关键点**：
- `PartialEq`：可比较（允许 NaN 不等于自身）
- `Eq`：严格相等（自反性）
- `Hash`：必须与 `Eq` 一致

### 4. **Go** — 直接相等 / 深比较

```go
type Person struct {
    ID     int
    Name   string
    Salary float32
}

// 直接 == 比较（仅当所有字段可比较）
p1 := Person{1, "Alice", 5000.0}
p2 := Person{1, "Alice", 5000.0}
fmt.Println(p1 == p2)  // true

// 含 slice/map 无法用 ==，需要手写或用 reflect.DeepEqual
type PersonWithList struct {
    ID    int
    Names []string  // slice 不可比
}

a := PersonWithList{1, []string{"Alice"}}
b := PersonWithList{1, []string{"Alice"}}
// a == b  // 编译错误！

// 解决：手写比较函数
func (p PersonWithList) Equal(other PersonWithList) bool {
    if p.ID != other.ID {
        return false
    }
    if len(p.Names) != len(other.Names) {
        return false
    }
    for i, v := range p.Names {
        if v != other.Names[i] {
            return false
        }
    }
    return true
}

// 或用 reflect.DeepEqual（性能较低）
fmt.Println(reflect.DeepEqual(a, b))  // true
```

**Go 没有标准化的哈希接口**，`map` 只支持内置类型 key。

### 5. **Python** — 魔术方法

```python
class Person:
    def __init__(self, id, name, salary):
        self.id = id
        self.name = name
        self.salary = salary
    
    # 定义相等性
    def __eq__(self, other):
        if not isinstance(other, Person):
            return False
        return (self.id == other.id and 
                self.name == other.name and 
                abs(self.salary - other.salary) < 0.01)
    
    # 定义不等
    def __ne__(self, other):
        return not self.__eq__(other)
    
    # 定义哈希（用于 set / dict key）
    def __hash__(self):
        return hash((self.id, self.name))

# 使用
p1 = Person(1, "Alice", 5000.0)
p2 = Person(1, "Alice", 5000.0)
print(p1 == p2)  # True

# 用于集合
persons_set = {p1, p2}  # 使用 __hash__
persons_dict = {p1: "data"}
```

**注意**：
- 若定义了 `__eq__`，默认 `__hash__` 会变为 `None`（不可哈希）
- 需要显式定义 `__hash__` 才能用于 `set`/`dict` key

### 6. **C#** — Equals 和 GetHashCode

```csharp
public class Person {
    public int Id { get; set; }
    public string Name { get; set; }
    public float Salary { get; set; }
    
    // 重写 Equals
    public override bool Equals(object obj) {
        if (!(obj is Person other)) {
            return false;
        }
        return Id == other.Id && 
               Name == other.Name && 
               Math.Abs(Salary - other.Salary) < 0.01f;
    }
    
    // 必须同时重写 GetHashCode
    public override int GetHashCode() {
        unchecked {
            int hash = 17;
            hash = hash * 31 + Id.GetHashCode();
            hash = hash * 31 + (Name?.GetHashCode() ?? 0);
            hash = hash * 31 + Salary.GetHashCode();
            return hash;
        }
    }
    
    // 可选：重载 == 和 !=
    public static bool operator ==(Person a, Person b) {
        if (ReferenceEquals(a, b)) return true;
        if (a is null || b is null) return false;
        return a.Equals(b);
    }
    
    public static bool operator !=(Person a, Person b) {
        return !(a == b);
    }
}

// C# 7.3+ record 语法（自动实现）
public record PersonRecord(int Id, string Name, float Salary);

var p1 = new PersonRecord(1, "Alice", 5000);
var p2 = new PersonRecord(1, "Alice", 5000);
Console.WriteLine(p1 == p2);  // true

// 用于集合
var persons = new HashSet<Person>();
persons.Add(new Person { Id = 1, Name = "Alice" });
```

**C# record** 类型（.NET 5+）自动生成 `Equals` 和 `GetHashCode`。

## 与 Java 的关键差异

| 特性 | Java | 其他语言 |
|------|------|--------|
| **相等性方法** | `equals()` | 各自特定语法 |
| **哈希** | `hashCode()` | Python `__hash__`/C# `GetHashCode()`/Rust `Hash`/C++ `std::hash` |
| **默认行为** | 引用相等 | C/Go 无对象；Rust/Python 需显式实现 |
| **集合支持** | 标准化 | C/Go 无标准；Python/C#/Rust 各有方式 |
