总结：个人版的 Codeup 代码检测任务不支持自动触发（提交触发/合并请求触发），这是版本限制。如果需要 git push 自动扫描，需要通过 Flow 流水线的代码扫描步骤来实现。

不同分支合并到默认master时，有个节点可以ai code review

流水线yml
sources:
  my_repo:
    type: gitSample
    name: C++示例代码源
    endpoint: https://atomgit.com/flow-example/gcc-helloworld.git
    branch: master
stages:
  gcc_build_stage:
    name: "构建"
    jobs:
      dot_net_core_build_job:
        name: "GCC 构建"
        runsOn:
          group: private/<your-build-group-uuid>
          container: build-steps-public-registry.cn-beijing.cr.aliyuncs.com/build-steps/v2_gcc:10.2
        steps:
          command_step:
            name: "执行命令"
            step: Command
            with:
              run: |
                gcc --version
                make
