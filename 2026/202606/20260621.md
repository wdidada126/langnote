豆瓣（douban.com）作为国内早期大规模用Python开发的标杆网站，其技术栈以Python为核心，搭配了一批经典开源库与自研组件。下面按Web 服务、数据库、数据处理、中间件、自研工具分类，给你一份清晰、可对照的清单。
 
一、Web 框架与 HTTP 服务（早期+演进）
 
- Quixote（早期核心）- 豆瓣初创时用的 Python Web 框架，轻量、性能稳定。
- Django（后期部分业务）- 部分新业务/后台用 Django，配合自研组件混合开发。
- Twisted（后台异步/搜索/爬虫服务）- 异步网络框架，早期用于站内搜索引擎、消息队列、异步任务。
- Flask（内部工具/轻接口）- 内部系统、小服务常用。
 
二、数据库驱动 & ORM
 
- MySQLdb（pymysql 前身）- Python 连接 MySQL 的底层驱动（早期）。
- SQLAlchemy- ORM 框架，用于业务层数据库操作、事务、模型定义。
- BeansDB（豆瓣自研分布式 KV）- 非关系型存储，用于海量小文件/元数据（图片、短评、计数等）。
- Redis- 缓存、会话、计数器、热门榜单、消息队列。
 
三、数据处理 & 分析
 
- DPark（豆瓣自研分布式计算）- Python 版 Spark，用于日志分析、用户行为、推荐算法、榜单计算。
- NumPy / Pandas- 数据清洗、统计、评分/热度计算。
- cElementTree- XML/HTML 解析（早期爬虫、数据抽取）。
- PIL / Pillow- 图片处理（封面裁剪、缩略图、水印）。
 
四、中间件 & 工具库
 
- Jinja2 / Mako- 模板引擎（页面渲染）。
- PyJWT- 登录态、API 鉴权（后期）。
- python-dotenv / pydantic-settings- 配置管理（现代架构）。
- Gunicorn / uWSGI- WSGI 服务器（生产部署）。
- Celery- 异步任务队列（邮件、通知、数据同步）。
 
五、爬虫 & 数据采集（站内爬虫）
 
- Requests- HTTP 请求（站内抓取、外部数据同步）。
- BeautifulSoup / lxml- HTML 解析、数据抽取。
- Scrapy（后期爬虫系统）- 大规模分布式爬虫框架。
 
六、简单总结（一句话版）
 
豆瓣 Python 栈 = Quixote/Django + MySQL/SQLAlchemy + BeansDB + Redis + DPark + Twisted + PIL
 
- 早期：Quixote + Twisted + MySQLdb + PIL
- 后期：Django/SQLAlchemy + Redis + BeansDB + DPark + 微服务化
