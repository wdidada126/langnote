Codex CC (Claude Code + Codex) 可以在 IDEA 里用，但不是官方插件，而是靠 CC GUI 插件实现。
 
一、是什么
 
CC GUI（Claude Code GUI）：IDEA 插件，内置 Claude Code + OpenAI Codex 双引擎。
 
- 直接在 IDE 右侧面板对话
- 支持 @file、截图、代码 diff、历史记录
- 能切换用 Claude 或 Codex
- 解决你之前 Codex 403 问题（可换 Claude 线路）
 
二、安装（IDEA 2024+/2025+）
 
1. Settings → Plugins → Marketplace
2. 搜索 CC GUI（或 Claude Code GUI）
3. 安装 → 重启 IDE
 
三、配置 Codex（解决 403）
 
1. 右侧点开 CC GUI → 点 设置 ⚙️
2. 供应商管理 → 添加 → 选 OpenAI Codex
3. 填入 API Key（sk-...）
4. 关键：- 自定义域名： https://api.fe80.cn/v1 （国内反代，无 403） 
- 或切回 Claude Code（更稳）
 
四、使用
 
- 右侧面板直接发指令
- 右键代码 → 发送到 CC GUI
- 用  /codex:review  让 Codex 审查代码
- 用  /codex:rescue  让 Codex 修复问题
 
五、替代方案（更稳）
 
- JetBrains AI Assistant（内置 Codex） - Settings → Tools → AI Assistant → 登录 ChatGPT
- 支持国内反代，不会 403
- 豆包 MarsCode（纯国内，无地区限制）
