二叉树 vs 非二叉树 的区别、结构、典型应用场景，一次性讲透。
 
一、先一句话分清
 
- 二叉树：每个节点 最多 2 个子节点
- 非二叉树：每个节点 可以有 ≥3 个子节点（也叫多路树 / 多叉树）
 
 
 
二、二叉树（最常用）
 
典型结构
 
- 普通二叉树
- 二叉搜索树 BST
- 平衡二叉树 AVL
- 红黑树
- 完全二叉树（堆）
- 哈夫曼树
- 二叉线索树
 
核心特点
 
- 结构简单，代码好写
- 适合内存中高速操作
- 查找/插入/删除：平均 O(log n)
- 遍历：前/中/后/层序，标准模板一套通用
 
应用场景（高频）
 
1. 红黑树- Java： TreeMap / TreeSet 、HashMap 冲突转红黑树
- C++： std::map 、 std::set 
- 用途：有序映射、有序集合、范围查找
2. 堆（完全二叉树）- Java： PriorityQueue 
- 用途：优先级调度、TOP-K、堆排序、贪心算法
3. 二叉搜索树 BST- 模拟有序符号表
- 教材教学、算法基础
4. 哈夫曼树- 数据压缩（哈夫曼编码）
5. 表达式树- 编译器表达式求值、语法树
6. 二叉线索树- 无递归遍历，节省栈空间
 
 
 
三、非二叉树（多叉树 / 多路树）
 
典型结构
 
- B 树 / B+ 树 / B* 树
- Trie 字典树（前缀树）
- 2-3 树、2-3-4 树
- 多路搜索树
- 普通多叉树（文件夹结构）
 
核心特点
 
- 一个节点能存很多关键字 + 很多子节点
- 树高极低，适合磁盘 / 外部存储
- 减少 IO 次数，数据库/文件系统御用
 
应用场景（高频）
 
1. B+ 树- MySQL InnoDB 索引
- 文件系统索引
- 用途：磁盘存储、范围查询、海量数据索引
2. B 树- 文件系统（如 NTFS、Ext4）
- NoSQL 存储引擎
3. Trie 树（字典树）- 搜索引擎自动补全
- 词库检索、IP 路由最长前缀匹配

4. 普通多叉树- 文件目录结构（文件夹套文件夹）
- XML/HTML DOM 树
- 组织机构树、菜单树
- 抽象语法树 AST（多叉）
5. 2-3 树 / 2-3-4 树- 教学用，理解平衡原理
- 红黑树的原型
 
 
 
四、最强对比：什么时候用二叉？什么时候用非二叉？
 
用 二叉树 的场景
 
- 数据在内存里
- 需要高效动态插入、删除、查找
- 代码简单、通用、好实现
- 有序结构但不涉及磁盘 IO
→ 语言标准库几乎全是二叉树（红黑树 / 堆）
 
用 非二叉树 的场景
 
- 数据在磁盘 / SSD
- 数据量极大，不能全放内存
- 要减少 IO 次数
- 需要范围查询
- 前缀检索、路由匹配、目录结构
→ 数据库、文件系统、路由表、搜索引擎索引 都用非二叉

广域网下一跳选择：核心算法与开源实现
 
广域网下一跳选择的核心是控制平面选路规则与数据平面转发决策的协同，主流方案涵盖标准路由协议（BGP/OSPF）、内核多路径调度（ECMP）及覆盖网络创新算法，以下分模块梳理关键知识点与开源实现。
 
一、核心概念与决策逻辑
 
1. 下一跳的两层含义
 
- 控制平面：BGP/NEXT_HOP属性（RFC 4271），传递路由可达性的逻辑指针，需通过IGP迭代到直连邻居。
- 数据平面：FIB表项中的「下一跳IP+出接口」，直接指导数据包转发。
 
2. 选路核心指标
 
- IGP度量：OSPF的Cost（参考带宽/接口速率）、RIP的跳数。
- BGP策略属性：Local Preference（AS内优先级）、AS Path（防环+长度）、MED（多出口区分）、Weight（厂商本地优先级）。
- 多路径特性：等价多路径（ECMP）、加权多路径（WCMP）、基于流的哈希分发。
 
二、主流选路算法与开源实现
 
1. 边界网关协议（BGP）——广域网核心
 
（1）选路规则（按优先级排序）
 
1. 过滤不可达下一跳；
2. 最高Weight（厂商私有）；
3. 最高Local Preference；
4. 本地始发路由（network/aggregate）；
5. 最短AS Path；
6. 最低Origin（IGP<EGP<Incomplete）；
7. 最低MED（同AS内比较）；
8. eBGP优于iBGP；
9. 下一跳IGP Metric最小；
10. 最小RouterID/Originator ID。
 
（2）开源实现
 
- FRRouting（FRR）：C语言，Quagga继任者，全功能BGP/OSPF/ISIS，工业级标准 。- 核心源码： bgp_nexthop.c （下一跳缓存与选择）、 bgp_attr.c （属性处理） 。
- 地址：https://github.com/FRRouting/frr。
- GoBGP：Go语言，高性能云原生BGP栈，支持gRPC/OpenConfig，适合IXP/数据中心。- 核心能力：策略框架、多协议族、路由反射器。
- 地址：https://github.com/osrg/gobgp。
- OpenBGPD：OpenBSD项目，轻量安全，适合Unix路由场景。- 地址：https://github.com/openbgpd-portable。
 
2. 内部网关协议（IGP）——AS内选路
 
（1）OSPF（开放最短路径优先）
 
- 算法：链路状态+Dijkstra SPF，构建以自身为根的最短路径树。
- 核心机制：Hello报文邻居发现、LSA洪泛同步LSDB、区域分层（骨干Area 0）。
- 开源实现：- FRRouting/ospfd：C语言，完整实现OSPFv2/v3，内核路由表同步。
- OpenOSPFD：OpenBSD项目，安全精简版OSPF。
- 地址：https://github.com/FRRouting/frr/tree/master/ospfd。
 
（2）RIP（路由信息协议）
 
- 算法：距离矢量，基于跳数的Bellman-Ford，最大跳数15。
- 局限：收敛慢、不适合大规模网络。
- 开源实现：FRRouting/ripd。
 
3. 内核多路径调度——ECMP/WCMP
 
（1）核心算法
 
- ECMP：等价多路径，基于流哈希分发（源IP+目的IP+协议+端口）。
- WCMP：加权多路径，按权重分配流量（适配不同链路带宽）。
- Linux内核实现：- 核心函数： fib_select_multipath （net/ipv4/fib_semantics.c）。
- 配置： echo 1 > /proc/sys/net/ipv4/fib_multipath_hash_policy （L4感知哈希）。
- 源码：https://github.com/torvalds/linux/blob/master/net/ipv4/nexthop.c。
 
4. 创新覆盖网络算法
 
（1）Yggdrasil
 
- 核心思想：全局生成树+度量空间贪婪路由，无需全局路由表。
- 下一跳选择：按度量空间距离选最近邻居，支持NAT穿透 。
- 实现：Go语言用户态路由，适合去中心化Mesh网络。
- 地址：https://github.com/yggdrasil-network/yggdrasil-go。
 
三、关键技术细节
 
1. 下一跳迭代（Nexthop Resolution）
 
- 过程：将BGP NEXT_HOP（非直连）迭代为IGP可达的直连下一跳。
- 场景：BGP路由反射、跨AS转发、MPLS VPN 。
 
2. 多路径负载均衡
 
- 流哈希： hash(src_ip, dst_ip, proto, sport, dport) % num_paths ，保证同连接路径一致。
- eBPF扩展：自定义哈希策略（如基于RTT、丢包率）。
 
3. 防环机制
 
- BGP：AS Path记录途经AS，包含自身AS则丢弃。
- OSPF：区域内LSA泛洪、区域间边界过滤。

五、学习与实践建议

完全二叉树（堆）概念解析
 
一、完全二叉树
 
1. 定义
 
除最后一层外，其余每层节点都达到最大个数；
最后一层的节点都连续靠左排列，右边可以空缺。
 
2. 核心特点
 
- 是满二叉树的子集，结构非常规整
- 适合用数组顺序存储，不浪费空间
- 节点编号连续，可通过下标快速计算父子关系
 
3. 下标规律（从 0 开始）
 
- 父节点下标： i 
- 左孩子： 2*i + 1 
- 右孩子： 2*i + 2 
- 子节点下标  j  的父节点： (j-1) // 2 
 
 
 
二、堆（Heap）
 
1. 定义
 
堆是满足堆性质的完全二叉树，分为两种：
 
2. 大顶堆（最大堆）
 
- 任意父节点 ≥ 子节点
- 堆顶（根节点）是最大值
 
3. 小顶堆（最小堆）
 
- 任意父节点 ≤ 子节点
- 堆顶（根节点）是最小值
 
4. 堆的关键特性
 
- 只保证堆顶最值，不保证整体有序
- 插入、删除最值时间复杂度：O(log n)
- 常用于：优先队列、堆排序、TopK 问题
 
 
 
三、一句话总结
 
完全二叉树是结构，堆是在完全二叉树基础上增加了大小顺序约束的特殊完全二叉树。

Trie 树（字典树 / 前缀树）核心概念
 
1. 基本定义
 
Trie 树是一种多叉树形结构，专门用于处理字符串前缀匹配、快速查找问题，也叫字典树、前缀树。
 
本质：把多个字符串按公共前缀合并存储，共用前缀节点，节省空间并加速查询。
 
2. 核心结构
 
- 根节点为空，不存字符
- 每个节点包含：- 若干子节点指针/数组（对应字符）
- 标记位：标识是否是某个字符串的结尾
- 一条从根到某节点的路径，代表一个字符串
 
3. 关键特点
 
- 公共前缀只存一次，空间效率高
- 查找、插入时间复杂度 O(L)，L 为字符串长度
- 与哈希表相比：天然支持前缀查询、按字典序遍历
- 缺点：字符集大时（如中文）空间开销较大
 
4. 典型用途
 
- 字符串快速查找（是否存在）
- 前缀匹配（输入提示、自动补全）
- 词频统计、前缀计数
- 最长公共前缀
- 敏感词过滤
 
5. 一句话记忆
 
Trie 树 = 按前缀分层存储字符串的树，路径即单词，前缀共享，查询极快。

二叉搜索树 & 红黑树 概念解析
 
一、二叉搜索树 BST
 
1. 定义
 
一棵二叉树，满足对任意节点：
 
- 左子树所有节点值 < 该节点值
- 右子树所有节点值 > 该节点值
- 左右子树也都是二叉搜索树
 
2. 性质
 
- 中序遍历结果：严格递增有序序列
- 理想情况下查找/插入/删除：O(log n)
- 最坏情况（退化成链表）：O(n)
 
3. 缺点
 
容易不平衡，比如依次插入有序序列，树会变成一条链，效率急剧下降。
 
 
 
二、红黑树
 
1. 定位
 
红黑树是一种自平衡的二叉搜索树，通过颜色规则 + 旋转，保证树大致平衡。
 
2. 五大核心规则（必背）
 
1. 每个节点是红色或黑色
2. 根节点一定是黑色
3. 所有叶子节点（NIL 空节点）都是黑色
4. 如果一个节点是红色，则它的两个子节点都是黑色（不能有连续红节点）
5. 从任意节点到其每个叶子节点的所有路径，包含相同数量的黑色节点
 
3. 平衡保证
 
最长路径 ≤ 2 × 最短路径
查找/插入/删除稳定 O(log n)，不会退化成链表。
 
4. 核心操作
 
- 变色：调整节点红/黑
- 左旋 / 右旋：保持 BST 性质，恢复红黑规则
 
5. 典型应用

一、二叉搜索树 BST
 
1. 定义
 
一棵二叉树，满足对任意节点：
 
- 左子树所有节点值 < 该节点值
- 右子树所有节点值 > 该节点值
- 左右子树也都是二叉搜索树
 
2. 性质
 
- 中序遍历结果：严格递增有序序列
- 理想情况下查找/插入/删除：O(log n)
- 最坏情况（退化成链表）：O(n)
 
3. 缺点
 
容易不平衡，比如依次插入有序序列，树会变成一条链，效率急剧下降。
 
 
 
二、红黑树
 
1. 定位
 
红黑树是一种自平衡的二叉搜索树，通过颜色规则 + 旋转，保证树大致平衡。
 
2. 五大核心规则（必背）
 
1. 每个节点是红色或黑色
2. 根节点一定是黑色
3. 所有叶子节点（NIL 空节点）都是黑色
4. 如果一个节点是红色，则它的两个子节点都是黑色（不能有连续红节点）
5. 从任意节点到其每个叶子节点的所有路径，包含相同数量的黑色节点
 
3. 平衡保证
 
最长路径 ≤ 2 × 最短路径
查找/插入/删除稳定 O(log n)，不会退化成链表。
 
4. 核心操作
 
- 变色：调整节点红/黑
- 左旋 / 右旋：保持 BST 性质，恢复红黑规则
 
5. 典型应用
 
- Java： TreeMap 、 TreeSet 
- C++： std::map 、 std::set 
- Linux 内核：进程调度、虚拟内存管理
 
 
 
三、一句话总结
 
- BST：有序但可能不平衡，效率不稳定
- 红黑树：带颜色约束的自平衡 BST，保证稳定 O(log n)

二叉线索树（线索二叉树）概念解析
 
一、核心定义
 
线索二叉树（Threaded Binary Tree）：利用普通二叉链表中的空指针域，存放节点在某种遍历次序下的前驱 / 后继指针（称为“线索”），并增加标志位区分“孩子指针”和“线索指针”的优化二叉树。
 
二、为什么需要线索树
 
- 普通二叉链表：n 个节点有 2n 个指针，仅 n−1 个有效，浪费 n+1 个空指针 。
- 普通二叉树找前驱/后继：需重新遍历 / 栈/递归，效率低（O(n)）。
- 线索树：空指针变线索，直接 O(1) 找前驱/后继，遍历不用栈/递归。
 
三、节点结构（必记）
 
在普通二叉树节点基础上，增加两个标志位：
 
plaintext
  
data      // 数据域
lchild    // 左指针（孩子/前驱）
ltag      // 左标志：0=左孩子，1=前驱线索
rchild    // 右指针（孩子/后继）
rtag      // 右标志：0=右孩子，1=后继线索
 
 
- ltag=0：lchild 指向左孩子
- ltag=1：lchild 指向前驱节点
- rtag=0：rchild 指向右孩子
- rtag=1：rchild 指向后继节点
 
四、三种线索类型
 
按遍历顺序分为三种：
 
1. 中序线索二叉树（最常用）
2. 前序线索二叉树
3. 后序线索二叉树
 
五、核心特性
 
- 空间高效：复用空指针，不额外占用大量空间。
- 遍历高效：非递归、无栈线性遍历，O(n) 时间 。
- 快速定位：任意节点可 O(1) 找前驱/后继。
- 缺点：插入/删除复杂，需重新线索化。
 
六、一句话总结
 
线索二叉树 = 把空指针改成前驱/后继线索 + 标志位，实现无栈高效遍历、快速查前驱后继。
