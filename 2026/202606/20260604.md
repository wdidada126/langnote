一、为什么国外云服务器能用（你之前 403 的原因）
 
- Claude Code / Anthropic API 支持绝大多数海外国家/地区
- 你之前报错  Country not supported ：- 是 本地电脑（中国大陆 IP） 直接访问被拦截
- 海外云服务器（美/欧/日/新等）IP 完全不在黑名单
 
二、海外 VPS 运行 Claude Code CLI（步骤）
 
1. 选服务器（推荐）

- 系统：Ubuntu 22.04 / 24.04（最稳）
- 配置：2核4G、SSD 20G+（够用）
- 地区：美国、新加坡、德国、英国 等（都支持）
 
2. 安装（海外直装，无限制）

bash
  
# 1. 安装 Node.js 18+
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash
sudo apt install -y nodejs

# 2. 全局安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 3. 验证
claude --version
 
 
3. 登录 / 配置 API Key（海外直接过）
 
bash
  
# 方式1：命令行登录（浏览器授权，最稳）
claude auth login

# 方式2：环境变量（推荐服务器）
export ANTHROPIC_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxx"
echo 'export ANTHROPIC_API_KEY="sk-xxx"' >> ~/.bashrc
source ~/.bashrc

1. 本地 **SSH 登录** 海外服务器
2. 直接运行 `claude`
3. 完全 **不会 403、不会地区限制**

- ❌ 本地（中国大陆 IP）：**403 地区不支持**
