开源审批流项目列表（支持提交信息+多角色审批）
 
本清单聚焦支持业务信息提交、多角色权限审批、流程流转管控的开源工作流/审批流项目，覆盖企业级成熟引擎、轻量国产框架、低代码快速搭建平台，均满足提交人发起、多角色逐级/并行审批的核心需求，可直接二次开发或部署使用。
 
一、企业级成熟审批流引擎
 
1. Flowable
 
- 开源地址：GitHub（flowable/flowable）
- 核心技术：Java，支持SpringBoot快速集成
- 核心功能1. 完整支持业务表单提交，可自定义提交字段、附件、流程关联信息；
2. 精细化多角色审批：支持指定角色、部门、岗位审批，实现会签、或签、逐级审批、条件分支审批；
3. 流程管控：审批通过/驳回/退回/转办/加签/减签，流程进度实时追踪；
4. 适配OA、财务、人事、采购等全场景审批，企业级稳定性强。
- 适用场景：中大型企业复杂审批流程、后端集成开发
 
2. Camunda
 
- 开源地址：GitHub（camunda/camunda-bpm-platform）
- 核心技术：Java，支持微服务、分布式部署
- 核心功能1. 自定义审批提交表单，支持业务数据持久化与关联查询；
2. 角色/用户组权限管控，精准分配审批权限，支持多级审批、并行审批、条件跳转；
3. 可视化流程设计器，无需编码即可配置审批节点；
4. 支持审批日志、任务提醒、流程超时管控。
- 适用场景：大型企业、微服务架构下的复杂审批业务
 
3. Activiti
 
- 开源地址：GitHub（Activiti/Activiti）
- 核心技术：Java，经典开源工作流引擎
- 核心功能1. 标准化业务提交流程，支持各类审批单据信息录入与提交；
2. 基于角色的任务分配，实现发起人→部门审批→管理层审批等多级角色流转；
3. 支持流程模板配置，快速复用请假、报销、采购等常规审批流程；
4. 生态完善，文档齐全，二次开发成本低。
- 适用场景：传统企业OA系统、常规审批流程快速开发
 
二、轻量国产审批流框架
 
1. ESFlow
 
- 开源地址：Gitee/GitHub
- 核心技术：Java+Vue3，前后端分离
- 核心功能1. 轻量化设计，数据库表结构极简，部署快速；
2. 支持角色/人员/部门多维度审批人配置，满足中国式审批逻辑；
3. 审批提交：自定义提交表单，支持申请信息编辑、撤回；
4. 特色功能：审批退回、任意节点跳转、前加签、后加签。
- 适用场景：中小企业轻量化审批、快速搭建内部审批系统
 
2. Warm-Flow
 
- 开源地址：Gitee
- 核心技术：Java，无第三方依赖
- 核心功能1. 极简集成，支持SpringBoot/单体项目快速接入；
2. 支持角色、用户、部门三种审批指派模式，实现串行、并行、会签审批；
3. 提交信息完整留存，审批记录可追溯；
4. 支持审批驳回、撤销、转办、终止，适配国内审批习惯。
- 适用场景：中小型项目、嵌入式审批模块开发
 
3. 飞龙工作流（FlowLong）
 
- 开源地址：Gitee
- 核心技术：Java+Vue，仿钉钉审批模式
- 核心功能1. 可视化流程设计，拖拽配置审批节点与角色权限；
2. 支持顺序会签、并行会签、或签、票签等多角色审批模式；
3. 标准化提交页面，支持各类审批申请信息录入与上传；
4. 流程跟踪、审批通知、单据打印全功能覆盖。
- 适用场景：快速搭建类钉钉审批、中小企业通用审批系统
 
三、低代码审批流搭建平台
 
1. AgileBPM
 
- 开源地址：Gitee/GitHub
- 核心技术：基于Activiti7深度优化，低代码开发
- 核心功能1. 零代码表单设计，快速配置审批提交页面，自定义字段、布局；
2. 角色权限可视化配置，自动匹配部门负责人、管理层等审批角色；
3. 一键发布审批流程，支持请假、采购、合同等多场景模板；
4. 支持审批进度查看、消息推送、数据统计。
- 适用场景：无代码/低代码快速搭建审批系统、企业通用OA
 
2. Lowflow-Design
 
- 开源地址：GitHub
- 核心技术：Vue3+TypeScript，纯前端流程设计器
- 核心功能1. 轻量化流程设计，快速配置审批节点、角色、抄送人；
2. 支持指定角色、部门、上级领导等审批人规则；
3. 适配各类提交表单，无缝对接后端业务系统；
4. 界面简洁，上手门槛低，支持二次开发。
- 适用场景：前端快速搭建审批页面、轻量审批流程定制

五、选型建议
 
1. 大型企业复杂业务：优先选择Flowable、Camunda，功能全面、稳定性强，适配多系统集成；
2. 中小企业快速落地：优先选择ESFlow、Warm-Flow，轻量化、部署快，贴合国内审批习惯；
3. 无代码快速搭建：优先选择AgileBPM，无需专业开发，直接配置审批流程与提交表单。
