# 一句话结论
`__xxx__` 格式的方法，叫「特殊方法 / 魔法方法」，是 Python 内置规定好的。

- 不是你随便发明的
- 是 Python 解释器自己会去调用的方法
- 你写类时实现它，就是为了让你的对象能用 Python 原生语法

# 举几个最常见的（全是内置）
```python
__init__      # 初始化对象
__len__       # 对应 len(obj)
__getitem__   # 对应 obj[key]、迭代
__setitem__
__str__       # 对应 str(obj)、print(obj)
__repr__      # 对应 repr(obj)
__eq__        # 对应 ==
__lt__        # 对应 <
__add__       # 对应 +
__call__      # 让对象能像函数一样调用 obj()
```

# 它们是“内置”的两层意思
## 1. 名字是 Python 官方规定的
你不能自己乱造：
- `__my_length__` 就不是内置，`len()` 不会认它
- 只有 `__len__` 才会被 `len()` 识别

## 2. Python 解释器会自动调用
你不用自己写：
```python
obj.__len__()
```
你只需要写：
```python
len(obj)
```
Python 会自动去找 `obj.__len__()` 执行。

# 最经典例子（Fluent Python 扑克牌）
```python
class Deck:
    def __init__(self):
        self.cards = [...]

    def __len__(self):
        return len(self.cards)  # 实现内置方法

deck = Deck()
print(len(deck))  # Python 自动调用 __len__
```

# 超级总结
`__xxx__` 方法 = Python 内置的接口协议
- 你实现它
- Python 就用标准语法（len / for / print / == / []）支持你的对象

这就是 Python 面向对象设计的核心机制。
