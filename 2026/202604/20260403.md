Python里做情感分析（Sentiment Analysis） 有非常成熟的库，按 易用性、语言（英文/中文）、精度、场景 分成几类。下面是最主流、最常用的几个：

## 一、英文情感分析（最常用）

### 1. VADER (含在 NLTK 中)
适合：社交媒体、短文本、评论、带表情/俚语/缩写的英文
特点：
- 专门为 社交媒体、网络文本 优化
- 能识别：表情 😊、感叹号、大写、重复字母（soooo good）、俚语、否定
- 输出：pos/neg/neu/compound4个分数
- 轻量、无需训练、超快

安装 & 使用
```bash
pip install nltk
```

```python
import nltk
nltk.download('vader_lexicon')

from nltk.sentiment import SentimentIntensityAnalyzer
sia = SentimentIntensityAnalyzer()

text = "Wow, this movie is AMAZING!!! I love it so much 😍"
print(sia.polarity_scores(text))
# 输出: {'pos': 0.754, 'neg': 0.0, 'neu': 0.246, 'compound': 0.938}
```

### 2. TextBlob
适合：英文简单分析、快速原型、教学
特点：
- 极简 API，一行出结果
- 返回 polarity (-1~1) 和 subjectivity (0~1)
- 缺点：不懂讽刺、复杂语境、精度一般

```bash
pip install textblob
```

```python
from textblob import TextBlob
text = "This is the worst product ever."
blob = TextBlob(text)
print(blob.sentiment)
# 输出: Sentiment(polarity=-1.0, subjectivity=1.0)
```

### 3. spaCy（工业级）
适合：大规模、高性能、自定义 pipeline
特点：
- 本身不带情感模型，但可加插件：`spacytextblob` 或自己训练
- 速度快、稳定、适合生产

```bash
pip install spacy spacytextblob
python -m spacy download en_core_web_sm
```

```python
import spacy
nlp = spacy.load("en_core_web_sm")
nlp.add_pipe("spacytextblob")

doc = nlp("The service was slow but the food was great.")
print(doc._.blob.polarity)
```

## 二、中文情感分析库

### 1. SnowNLP（最简单中文）
适合：中文快速测试、小项目
特点：
- 自带分词、情感、摘要、关键词
- 情感分数 0~1（越接近1越正面）
- 缺点：准确率一般，对新词/网络语弱

```bash
pip install snownlp
```

```python
from snownlp import SnowNLP
text = "这部手机质量太差了，经常死机。"
s = SnowNLP(text)
print(s.sentiments)  # 输出接近0 → 负面
```

### 2. Baidu Senta / LTP（百度开源）
适合：中文高精度、工业级
- LTP：哈工大出品，中文NLP最强之一
- Senta：百度情感分析专用，F1≈0.92

```bash
pip install pyltp
# 需下载模型文件
```

### 3. 百度/阿里/腾讯 API（线上服务）
适合不想自己搭模型、直接调用：
- 百度智能云情感分析
- 阿里云 NLP
- 腾讯云情感分析

## 三、最高精度：深度学习（BERT类）
Hugging Face Transformers（目前最强）
适合：高准确率、复杂语义、长文本、生产环境

```bash
pip install transformers torch
```

英文（DistilBERT）：
```python
from transformers import pipeline
classifier = pipeline("sentiment-analysis")
# model = "distilbert-base-uncased-finetuned-sst-2-english"
print(classifier("I don't like waiting but this was worth it!"))
# 输出: [{'label': 'POSITIVE', 'score': 0.999}]
```

中文（bert-base-chinese 或中文情感模型）：
```python
classifier = pipeline("sentiment-analysis", model="uer/roberta-base-finetuned-dianping-chinese")
print(classifier("这家店的服务态度很差，味道一般"))
```

## 四、库对比（快速选型）

| 库 | 语言 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|---|
| VADER | 英文 | 快、表情/俚语、免训练 | 中文弱 | 推特、评论、短文本 |
| TextBlob | 英文 | 极简API | 精度低、不懂讽刺 | 教学、原型 |
| SnowNLP | 中文 | 简单、全功能 | 精度一般 | 小项目、快速验证 |
| spaCy | 多语 | 工业级、快 | 需插件/训练 | 大规模生产 |
| Transformers | 多语 | 精度最高 | 慢、耗资源 | 正式项目、高要求 |

## 五、你该选哪个？
- 英文短文本/社交媒体 → VADER
- 英文快速demo → TextBlob
- 中文简单用用 → SnowNLP
- 中文/英文正式项目、要准 → Transformers (BERT)
