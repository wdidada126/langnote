Camunda工作流开发实战——Spring Boot+BPMN+DMN

针对 Camunda 审批流 学习，以下是国内最实用、最权威的中文 + 英文书籍清单，并按入门、实战、原理、架构分级推荐，适合面试与系统开发。

## 一、中文首选（国内开发者必看）
### 1. 《Camunda 工作流开发实战 —— Spring Boot + BPMN + DMN》
作者：李贵俊
出版社：清华大学出版社（2021）

核心内容：
- BPMN 2.0 全元素精讲（任务、网关、事件、子流程）
- Camunda 7 核心 API、流程部署、用户任务、表单设计
- Spring Boot 整合 Camunda（最主流企业开发方案）
- DMN 决策表、外部任务、异常处理、集群部署
- 完整审批流案例（保险理赔、运维流程）

适合：
- Java/Spring Boot 开发者
- 从零学 审批流、OA、工单、风控流程
- 面试准备（国内最常用 Camunda 教材）

优点：中文、接地气、代码可直接运行、覆盖审批流全场景

## 二、英文权威（创始人/官方出品）
### 2. Real-Life BPMN (4th Edition)
作者：Jakob Freund、Bernd Rücker（Camunda 联合创始人）

核心内容：
- BPMN 建模思想 + 实战模式（审批流、会签、加签、驳回、跳转）
- 避免反模式（流程设计常见坑）
- 与微服务架构结合

适合：
- 架构师、产品经理、流程设计师
- 想把 BPMN 真正落地到复杂审批 的人

优点：全球 BPMN 圣经，Camunda 官方思想源头

### 3. Practical Process Automation (O’Reilly)
作者：Bernd Rücker（Camunda CTO）

核心内容：
- 流程自动化架构、分布式事务、Saga、补偿
- 审批流与微服务协同、可靠事件驱动、重试、幂等
- 高可用、可观测、性能调优

适合：
- 中高级开发者、架构师
- 做 大规模审批系统、金融/政企核心流程

优点：Camunda 架构与最佳实践权威著作

### 4. Camunda BPM 7: A Practical Guide（官方指南）
作者：Camunda 官方团队

核心内容：
- 完整 API、任务分配、表单、历史数据、监控
- 集群、高可用、性能调优、生产运维
- REST API、外部任务、DMN

适合：
- 开发、运维、测试
- 生产环境落地必备

### 3. 架构/面试（高频考点）
- 书籍：Practical Process Automation
- 重点：
  - 分布式审批、可靠事件、重试、幂等、补偿
  - 高可用集群、性能优化、数据隔离、权限
