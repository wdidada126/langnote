# 二、字符串类型入参：工业级完整校验项（你要的全套）
字符串必须校验 5大类：
1. 是否允许为null
2. 是否允许空串`""`、空白串`"   "`
3. 最小长度、最大长度
4. 正则表达式格式（手机号、身份证、邮箱、编号）
5. 是否允许前后空格（工业规范：默认自动trim）

对应注解：
```java
@NotNull    // 不能为null
@NotBlank   // 不能为null && 不能是空串 && 不能纯空格（字符串必用）
@NotEmpty   // 不能null、不能空集合/数组（字符串不推荐）
@Size(min=,max=) // 长度限制
@Pattern(regexp="") // 正则
```

字符串标准写法示例：
```java
@Data
public class UserReq {
    // 非空、非空白、长度2~30、自动trim
    @NotBlank(message = "用户名不能为空")
    @Size(min = 2, max = 30, message = "用户名长度2~30位")
    private String username;

    // 手机号正则
    @NotBlank(message = "手机号不能为空")
    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式错误")
    private String phone;

    // 允许为null，但不为空串，长度限制
    @Size(max = 200, message = "备注最大200字符")
    private String remark;
}
```

# 三、数字类型入参：工业级必须校验全部6个维度（重点！你问的核心）
Integer / Long / BigDecimal / Double 全部适用
很多开发只判非空，工业级必须校验下面6项：

## 数字完整校验项（面试+开发标准答案）
1. 是否允许为null（必填/非必填）
   `@NotNull` 必填数字
2. 数值最小值限制（不能负数、不能0、不能小于下限）
   `@Min` / `@DecimalMin`
3. 数值最大值限制（不能超上限、额度、金额上限）
   `@Max` / `@DecimalMax`
4. 是否允许0（金额、数量、状态码单独判断）
5. 小数精度/小数点位数（BigDecimal金额必校验，防止恶意传超长小数）
6. 枚举范围校验（状态码只能是0/1/2，不能传任意数字）

> 注意：数字不能用@NotBlank！@NotBlank只用于字符串！
> Integer/Long 用 `@NotNull`
> BigDecimal 金额用 `@NotNull + @DecimalMin + 精度校验`

## 数字标准注解对应
```java
// Integer/Long 整数
@NotNull(message = "年龄不能为空")
@Min(value = 18, message = "年龄不能小于18")
@Max(value = 120, message = "年龄不能大于120")
private Integer age;

// 状态码：只能0/1/2
@NotNull(message = "状态不能为空")
private Integer status;

// BigDecimal 金额（银行/支付项目最强工业规范）
@NotNull(message = "金额不能为空")
@DecimalMin(value = "0.01", inclusive = false, message = "金额必须大于0")
@DecimalMax(value = "99999999.99", message = "金额超出上限")
private BigDecimal amount;
```

## 额外工业级强制校验：BigDecimal小数点位数
Spring校验默认不校验小数位，必须手动自定义校验注解
防止前端传：`0.0000001`、`123.123456` 非法精度

自定义注解 `@BigDecimalScale` 限制最多2位小数（金融项目标配）

# 五、全局统一异常处理器（校验不通过直接返回规范JSON）
工业项目必须全局处理，不能抛白页、不能抛500、不能抛堆栈
```java
@RestControllerAdvice
public class ValidExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> validError(MethodArgumentNotValidException e) {
        BindingResult result = e.getBindingResult();
        String msg = result.getFieldErrors().stream()
                .map(FieldError::getDefaultMessage)
                .collect(Collectors.joining("；"));
        // 返回统一业务错误码
        return Result.fail(400, "参数校验失败：" + msg);
    }
}
```

## 3. Map链式校验器（核心工具，工业级通用）
支持：
- 必填非空校验（null/空串/纯空格）
- 字符串长度 min/max
- 字符串正则
- 数字Integer/Long非空、最小值、最大值
- BigDecimal金额非空、大于0、小数位数限制、范围
- 自动类型转换、自动trim字符串
```java
import java.math.BigDecimal;
import java.util.Map;
import java.util.regex.Pattern;

public class MapParamValidator {

    private final Map<String, Object> paramMap;

    private MapParamValidator(Map<String, Object> paramMap) {
        this.paramMap = paramMap;
    }

    public static MapParamValidator of(Map<String, Object> paramMap) {
        return new MapParamValidator(paramMap);
    }

    // ====================== 字符串校验 ======================
    // 必填：不能null、不能""、不能纯空格
    public MapParamValidator requireStr(String key, String msg) {
        Object val = paramMap.get(key);
        if (val == null) throw new ParamValidException(msg);
        String str = val.toString().trim();
        if (str.isEmpty()) throw new ParamValidException(msg);
        return this;
    }

    // 长度限制
    public MapParamValidator strLength(String key, int min, int max, String msg) {
        String str = paramMap.get(key).toString().trim();
        if (str.length() < min || str.length() > max) throw new ParamValidException(msg);
        return this;
    }

    // 正则校验
    public MapParamValidator strPattern(String key, String regex, String msg) {
        String str = paramMap.get(key).toString().trim();
        if (!Pattern.matches(regex, str)) throw new ParamValidException(msg);
        return this;
    }

    // 可选字符串：不为null时校验长度
    public MapParamValidator optStrLength(String key, int max, String msg) {
        Object val = paramMap.get(key);
        if (val == null) return this;
        String str = val.toString().trim();
        if (str.length() > max) throw new ParamValidException(msg);
        return this;
    }

    // ====================== 整数数字校验 Integer/Long ======================
    // 必填数字非空
    public MapParamValidator requireInt(String key, String msg) {
        Object val = paramMap.get(key);
        if (val == null) throw new ParamValidException(msg);
        return this;
    }

    // 数值范围 min <= val <= max
    public MapParamValidator intRange(String key, long min, long max, String msg) {
        long val = Long.parseLong(paramMap.get(key).toString());
        if (val < min || val > max) throw new ParamValidException(msg);
        return this;
    }

    // ====================== BigDecimal金额校验（银行专用工业级） ======================
    // 必填金额非空
    public MapParamValidator requireDecimal(String key, String msg) {
        Object val = paramMap.get(key);
        if (val == null) throw new ParamValidException(msg);
        return this;
    }

    // 金额必须 > 0
    public MapParamValidator decimalGtZero(String key, String msg) {
        BigDecimal val = new BigDecimal(paramMap.get(key).toString());
        if (val.compareTo(BigDecimal.ZERO) <= 0) throw new ParamValidException(msg);
        return this;
    }

    // 金额范围
    public MapParamValidator decimalRange(String key, String min, String max, String msg) {
        BigDecimal val = new BigDecimal(paramMap.get(key).toString());
        BigDecimal minVal = new BigDecimal(min);
        BigDecimal maxVal = new BigDecimal(max);
        if (val.compareTo(minVal) < 0 || val.compareTo(maxVal) > 0) throw new ParamValidException(msg);
        return this;
    }

    // 强制校验小数位数（金融必校验：最多2位小数）
    public MapParamValidator decimalScale2(String key, String msg) {
        BigDecimal val = new BigDecimal(paramMap.get(key).toString());
        if (val.scale() > 2) throw new ParamValidException(msg);
        return this;
    }
}
```

## 4. Controller 使用示例（完全对应你银行集团转账接口 Map入参）
入参直接 `Map<String,Object>`，一行链式校验，极其干净
```java
@PostMapping("/tran/group")
public Result<?> tranGroup(@RequestBody Map<String, Object> param) {

    // ========== 工业级Map参数一键校验（复制即用）==========
    MapParamValidator.of(param)
            // 字符串：必填、长度、正则
            .requireStr("custNo", "客户号不能为空")
            .strLength("custNo", 10, 30, "客户号长度10~30位")

            .requireStr("payAcctNo", "付款账号不能为空")
            .strLength("payAcctNo", 1, 32, "付款账号长度1~32位")

            .optStrLength("tranUse", 300, "转账用途最大300字符")

            // 数字整数：必填、范围（funcNo 0~5）

            .decimalScale2("tranAmt", "转账金额最多2位小数");

    // ========== 走到这里全部校验通过 ==========
    // 后续业务逻辑...
    return Result.success();
```

## 链式校验 Map（你要的写法）
```java
import org.valiktor.Validator;
import java.math.BigDecimal;
import java.util.Map;

Validator.validate(param)
    .validate("custNo", String::class)
        .isNotBlank()
        .hasSizeBetween(10, 30)
        .matches("^C\\d+$")

    .validate("payAcctNo", String::class)
        .isNotBlank()
        .hasSizeMax(32)

    .validate("funcNo", Integer::class)
        .isNotNull()
        .isBetween(0, 5)

    .validate("tranAmt", BigDecimal::class)
        .isNotNull()
        .isGreaterThan(BigDecimal.ZERO)
        .hasScaleLessThanOrEqualTo(2);
```
