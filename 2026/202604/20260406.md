# Floyd-Warshall 算法（多源最短路径）
## 极简核心理解
- 一维随机变量：1个数
- 二维随机变量：2个数
- Floyd：用二维数组（矩阵）算任意两点间最短路径
- 作用：给你一张图，算出所有点到所有点的最短距离

# 1. 你问的：各语言 / 工具 有没有现成库/内置函数？
我直接给你最准确、最实用的答案（不绕弯）

## Python（最常用）
### 有现成库！
1. `networkx`（最标准图论库）
   ```python
   import networkx as nx
   dist = nx.floyd_warshall(G)  # 直接算所有点最短路径
   ```
2. `scipy.sparse.csgraph`（科学计算）
   ```python
   from scipy.sparse.csgraph import floyd_warshall
   dist_matrix = floyd_warshall(adj_matrix)
   ```

## C / C++
### 没有官方内置库
但你可以直接复制模板代码（10行核心）
C++ 常用图论库：
- Boost Graph Library (BGL)
  ```cpp
  #include <boost/graph/floyd_warshall.hpp>
  ```

## Fortran
### 无内置，但有数值库支持
- Fortran 图形/图论库很少
- 一般自己写 Floyd 三重循环

## Octave（重点！你问的）
### Octave 有内置函数！
函数名：
```matlab
floydwarshall
```
直接调用：
```matlab
[D, P] = floydwarshall(adj_matrix);
```
- D = 距离矩阵
- P = 前驱矩阵（用于找路径）

Octave 是所有语言里最方便的！

# 1. 一维 vs 二维随机变量
- 一维随机变量 X：只描述一个随机结果
  比如：身高、成绩、抛硬币结果

- 二维随机变量 (X, Y)：同时描述两个随机结果
  比如：
  - 一个人的身高 X 和 体重 Y
  - 一个学生的数学成绩 X 和 英语成绩 Y
  - 靶子上点的横坐标 X 和 纵坐标 Y

一句话：
一维是一条线上的随机，二维是平面上的随机。

# 2. 二维也分两类
## （1）离散型二维随机变量
用联合分布律表示：
$$P(X=x_i,\ Y=y_j)=p_{ij}$$

就像一个表格：
X\Y | y₁ y₂ y₃
----|---------
x₁  | p₁₁ p₁₂ p₁₃
x₂  | p₂₁ p₂₂ p₂₃

## （2）连续型二维随机变量
用联合概率密度 f(x,y) 表示
概率 = 平面区域上的二重积分
$$P((X,Y)\in D)=\iint_D f(x,y)dxdy$$

最常见的：
- 二维均匀分布（平面某个区域内随机点）
- 二维正态分布（最重要）

# 3. 二维里必学的几个概念
- 联合分布：一起看 X 和 Y
- 边缘分布：只看 X，或只看 Y
- 条件分布：已知 X 时，Y 怎么分布
- 独立性：X 和 Y 互不影响
- 协方差 Cov(X,Y)、相关系数 ρ
  用来衡量 X 和 Y 有没有线性关系

# 4. 最简单总结
- 一维：一个随机数
- 二维：一对随机数 (X,Y)
- 三维、四维……统称多维随机变量
