# `android:usesCleartextTraffic="true"` 到底是干嘛的？
一句话总结：
允许你的 Android App 明文访问 HTTP 接口，而不是只能用 HTTPS。


## 详细解释
Android 9（API 28）及以上版本，默认禁止明文网络请求。
也就是：
- ✅ HTTPS（加密）：可以正常访问
- ❌ HTTP（明文）：直接报错、无法连接

加上这句：
```xml
android:usesCleartextTraffic="true"
```
就等于告诉系统：
我允许这个 App 访问不安全的 HTTP 接口，不要拦截！

---

## 你什么时候需要加它？
最常见场景：
1. 本地开发调试（后端是 `http://localhost`、`http://192.168.x.x`）
2. 对接老接口，服务器只支持 HTTP，暂时没升级 HTTPS
3. Flutter / React Native 开发时，接口请求失败、报网络错误

不加的话，你会遇到：
- 请求失败
- 超时
- 报错：`Cleartext HTTP traffic to xxx not permitted`

---

## 放在哪里？
在 `AndroidManifest.xml` 的 `<application>` 标签里：
```xml
<application
    android:usesCleartextTraffic="true"
    ...>
```

---

## 重要安全提醒（必须知道）
- 开发环境可以用
- 正式上线绝对不要用！
- HTTP 是明文传输，账号密码、数据都可能被窃取
- 上线必须改用 HTTPS

---

### 总结
- 作用：允许 Android App 访问 HTTP 明文接口
- 默认：Android 9+ 禁止 HTTP
- 场景：开发调试、对接老 HTTP 接口
- 安全：上线必须关闭，改用 HTTPS

计算金额的运算时，金额不一定是精确的，做过金额操作的都知道
整数和浮点数在计算机内部存储的方式是不同的，整数运算永远是精确的（除法难道也是精确的？是的！），而浮点数运算则可能会有四舍五入的误差。

Java 金额四则运算，不能用double（运算结果有误差），要用BidDecimal，python rust go js/ts dart c# c/c++用基础数据类型还是啥api去处理

我给你最清晰、最标准、最权威的答案：
所有语言处理【金额/货币/高精度计算】，绝对不能用浮点型（float/double）
必须用 十进制高精度类型 / 货币专用类型

我直接给你每一种语言的标准答案，一次性讲全！

# 一、Java（你问的起点）
## 必须用：BigDecimal
```java
BigDecimal a = new BigDecimal("10.01");
BigDecimal b = new BigDecimal("20.02");
BigDecimal sum = a.add(b);       // 加
BigDecimal sub = a.subtract(b);  // 减
BigDecimal mul = a.multiply(b);  // 乘
BigDecimal div = a.divide(b, 2, RoundingMode.HALF_UP); // 除
```
禁止：double、float

# 二、Python
## 用：decimal.Decimal
```python
from decimal import Decimal
a = Decimal("10.01")
b = Decimal("20.02")
print(a + b)
```
禁止：float

# 三、Go
## 用：github.com/shopspring/decimal 或 math/big
```go
import "github.com/shopspring/decimal"

a := decimal.NewFromString("10.01")
b := decimal.NewFromString("20.02")
sum := a.Add(b)
```
禁止：float64

# 四、Rust
## 用：rust_decimal
```rust
use rust_decimal::Decimal;

let a = Decimal::from_str("10.01").unwrap();
let b = Decimal::from_str("20.02").unwrap();
let sum = a + b;
```
禁止：f64

# 五、JavaScript / TypeScript
## 用：decimal.js 或 big.js
```ts
import { Decimal } from 'decimal.js'
let a = new Decimal("10.01")
let b = new Decimal("20.02")
let sum = a.plus(b)
```
禁止：number（有精度丢失）

# 六、Dart（Flutter）
## 用：decimal
```dart
import 'package:decimal/decimal.dart';

var a = Decimal.parse('10.01');
var b = Decimal.parse('20.02');
var sum = a + b;
```
禁止：double

# 七、C#
## 官方自带：decimal（货币专用）
```csharp
decimal a = 10.01m;
decimal b = 20.02m;
decimal sum = a + b;
```
C# 专门给金额设计了 `decimal` 类型

# 八、C / C++
## 用：GMP 库 或 自定义十进制库
```cpp
// 示例用GMP
mpf_class a("10.01");
mpf_class b("20.02");
mpf_class sum = a + b;
```
禁止：double

# 终极总结（所有语言统一规则）
## 1. 金额/货币/财务计算
永远不要用：float / double / f64 / number
这些是二进制浮点，一定会丢精度！

## 2. 所有语言正确方案
- Java：BigDecimal
- Python：decimal
- Go：shopspring/decimal
- Rust：rust_decimal
- JS/TS：decimal.js
- Dart：decimal
- C#：decimal
- C/C++：GMP

## 3. 统一原则
必须用 十进制高精度类型 ！
