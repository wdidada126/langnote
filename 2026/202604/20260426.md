<dependencyManagement>

            <artifactId>pig-common-bom</artifactId>
            <version>3.9.2</version>  <!-- 换成最新 tag 版本 -->

            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>

    <dependency>
        <groupId>com.pig4cloud</groupId>
        <artifactId>pig-common-seata</artifactId>
    </dependency>
    <!-- 日志 + 追踪 -->
    <dependency>
        <groupId>com.pig4cloud</groupId>
        <artifactId>pig-common-log</artifactId>
    </dependency>

    <dependency>
        <groupId>com.pig4cloud</groupId>
        <artifactId>pig-common-oss</artifactId>
    </dependency>

</dependencies>

### 1.1 最接近“银行/支付公司内部多模块Jar”的开源项目（直接可用）

#### 1）Spring Cloud Alibaba（阿里系，工业级事实标准）
- 地址：https://github.com/alibaba/spring-cloud-alibaba
- 定位：阿里内部微服务底座开源版，和翼支付/阿里系公司内部jar体系同源。
- 内置能力：
  - 服务注册/配置：Nacos
  - 限流熔断：Sentinel
  - 分布式事务：Seata
  - 链路追踪：SkyWalking/Zipkin
  - 消息：RocketMQ
- 模块划分（和企业内部jar完全一致）：
  ```
  spring-cloud-alibaba
  ├── spring-cloud-alibaba-common       // 通用工具、异常、常量
  ├── spring-cloud-alibaba-nacos         // 注册配置
  ├── spring-cloud-alibaba-sentinel      // 限流熔断
  ├── spring-cloud-alibaba-seata         // 分布式事务
  ├── spring-cloud-alibaba-rocketmq      // 消息
  └── spring-cloud-alibaba-starter       // 一站式starter
  ```

- 地址：https://github.com/sofastack/sofa-boot
- 定位：蚂蚁内部金融级底座开源，和北京银行/屹通支付体系技术同源。
- 特点：类隔离、日志隔离、金融级稳定性、内置分布式事务/分库分表。
- 模块：sofa-common、sofa-db、sofa-tx、sofa-trace、sofa-starter。

#### 3）Dromara Lamp-Cloud（国产最强企业级多模块，5.7k星）

- 定位：完全模仿银行/政务系统内部jar，开箱即用的多模块企业底座。
- 内置：日志追踪、Seata分布式事务、ShardingSphere分库分表、多租户、统一异常、代码生成。

## 二、企业级内部Jar的标准模块划分（直接照搬）
你要做的“公司私有jar”，必须按下面5个核心模块+1个聚合模块，所有大厂（屹通/翼支付/银行）都这么分：

```
xxx-platform（聚合父工程）
├── xxx-common-core        // 【必选】通用层：工具类、常量、枚举、统一异常、上下文、结果封装
├── xxx-common-db          // 【必选】数据层：MyBatis-Plus、分页、分库分表(ShardingSphere)、数据库加密
├── xxx-common-trace       // 【必选】观测层：日志追踪、MDC、SkyWalking/Zipkin、日志格式化
├── xxx-common-transaction // 【必选】分布式事务：Seata AT/TCC、本地事务封装
├── xxx-common-security    // 【可选】安全层：认证、授权、防重、加密
└── xxx-starter             // 【必选】一站式starter：依赖聚合、自动配置、默认参数
```

### 2.1 每个模块对应开源实现（直接引入）
#### ✅ xxx-common-core（通用工具）
- Hutool（国产瑞士军刀）：https://github.com/dromara/hutool
- Apache Commons：lang3、collections、io
- 统一异常/结果：直接复制Lamp-Common-Core的`R<T>`、`BaseException`。

#### ✅ xxx-common-db（数据库+分库分表）
- MyBatis-Plus（CRUD神器）：https://github.com/baomidou/mybatis-plus
- ShardingSphere（分库分表）：https://shardingsphere.apache.org/
- Druid（连接池+监控）：https://github.com/alibaba/druid

#### ✅ xxx-common-trace（日志追踪）
- SkyWalking Agent+SDK：https://skywalking.apache.org/
- SLF4J+Logback（日志标准）
- MDC链路上下文：直接复制Spring Cloud Alibaba的`TraceContext`。

#### ✅ xxx-common-transaction（分布式事务）
- Seata（阿里开源，工业级）：https://github.com/seata/seata
  - AT模式：零侵入，适合80%场景
  - TCC：高一致性场景

#### ✅ xxx-starter（一站式依赖）
- 聚合所有common模块，自动配置默认参数（如Nacos地址、日志级别、Seata模式）。

## 三、可直接复制的Maven父pom.xml（企业级）
```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.yourcompany</groupId>
    <artifactId>xxx-platform</artifactId>
    <version>2.0.0</version>
    <name>xxx企业级微服务底座</name>
    <packaging>pom</packaging>
    <modules>
        <module>xxx-common-core</module>
        <module>xxx-common-db</module>
        <module>xxx-common-trace</module>
        <module>xxx-common-transaction</module>
        <module>xxx-starter</module>
    </modules>

    <!-- 统一版本管理 -->
    <properties>
        <spring-boot.version>3.2.5</spring-boot.version>
        <spring-cloud.version>2023.0.0</spring-cloud.version>
        <spring-cloud-alibaba.version>2023.0.1.2</spring-cloud-alibaba.version>
        <mybatis-plus.version>3.5.15</mybatis-plus.version>
        <shardingsphere.version>5.5.2</shardingsphere.version>
        <seata.version>1.7.1</seata.version>
        <hutool.version>5.8.28</hutool.version>
        <skywalking.version>9.4.0</skywalking.version>
    </properties>

    <!-- 统一依赖管理 -->
    <dependencyManagement>
        <dependencies>
            <!-- Spring Boot -->
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-dependencies</artifactId>
                <version>${spring-boot.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            <!-- Spring Cloud -->
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-dependencies</artifactId>
                <version>${spring-cloud.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            <!-- Spring Cloud Alibaba -->
            <dependency>
                <groupId>com.alibaba.cloud</groupId>
                <artifactId>spring-cloud-alibaba-dependencies</artifactId>
                <version>${spring-cloud-alibaba.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            <!-- 内部模块 -->
            <dependency>
                <groupId>com.yourcompany</groupId>
                <artifactId>xxx-common-core</artifactId>
                <version>${project.version}</version>
            </dependency>
            <dependency>
                <groupId>com.yourcompany</groupId>
                <artifactId>xxx-common-db</artifactId>
                <version>${project.version}</version>
            </dependency>
            <!-- 其他common模块同理 -->
        </dependencies>
    </dependencyManagement>
</project>
```


## 四、和“上海屹通/翼支付/北京银行”内部Jar的对比（工业级）

## 一、ES 内置分词器（全部开源，随 ES 一起发布）

### 1. Standard（标准分词器）
- 是否开源：是（ES 内核）
- 源码地址：https://github.com/elastic/elasticsearch  
  包路径：`org.elasticsearch.index.analysis.StandardTokenizer`
- 特色：
  - ES 默认分词器，按 Unicode 词边界切分
  - 自动小写、过滤大部分标点
  - 中文会单字拆分，不适合中文检索
- 首次推出：2010 年（ES 0.16+）
- 兼容版本：全版本（0.16 ~ 8.x）

### 2. Simple
- 是否开源：是
- 源码地址：同 Standard
- 特色：
  - 按非字母切分，只保留字母并小写
  - 数字/符号直接丢弃
- 首次推出：2010 年
- 兼容版本：全版本

### 3. Whitespace
- 是否开源：是
- 源码地址：同 Standard
- 特色：
  - 仅按空格切分，保留大小写和符号
  - 适合代码、大小写敏感场景
- 首次推出：2010 年
- 兼容版本：全版本

### 4. Keyword
- 是否开源：是
- 源码地址：同 Standard
- 特色：
  - 不分词，整段文本作为一个 term
  - 用于精准匹配、枚举值
- 首次推出：2010 年
- 兼容版本：全版本

### 5. Pattern（正则分词器）
- 是否开源：是
- 源码地址：同 Standard
- 特色：
  - 用正则切分/提取词（默认 `\W+`）
  - 可灵活适配邮箱、URL、日志格式
- 首次推出：2010 年
- 兼容版本：全版本

### 6. Language（语言分词器，如 english）
- 是否开源：是
- 源码地址：同 Standard
- 特色：
  - 30+ 种语言专属规则（英文、法语、德语等）
  - 含词干提取 + 停用词过滤
  - 例：`running → run`，`the/a` 被过滤
- 首次推出：2010 年
- 兼容版本：全版本

### 7. ICU（国际化分词器，插件）
- 是否开源：是
- 源码地址：https://github.com/elastic/elasticsearch/tree/main/plugins/analysis-icu
- 特色：
  - 基于 ICU 库，强 Unicode 支持
  - 中日韩（CJK）切分优于 standard
  - 支持简繁体转换、归一化
- 首次推出：2013 年（ES 1.0+）
- 兼容版本：1.x ~ 8.x

## 二、第三方中文分词器（主流）

### 1. IK Analyzer（最常用）
- 是否开源：是（Apache 2.0）
- 源码地址：https://github.com/medcl/elasticsearch-analysis-ik
- 特色：
  - 双模式：`ik_smart`（智能粗分）/ `ik_max_word`（最细粒度）
  - 支持自定义词典、热更新
  - 中英混合、数字、URL 处理友好
- 首次推出：
  - IK 本体：2006-12（v1.0）
  - ES 插件：2012 年（ES 0.90+）
- 兼容版本：0.90.x ~ 8.x（版本严格对齐）

### 2. Jieba（结巴）
- 是否开源：是（MIT）
- 源码地址：https://github.com/sing1ee/elasticsearch-jieba-plugin
- 特色：
  - Python 结巴分词的 Java/ES 移植
  - 新词识别强、支持词性标注
  - 支持繁体、自定义词典
- 首次推出：2017-06（ES 插件）
- 兼容版本：5.x ~ 8.x（社区适配）

### 3. HanLP（汉语言处理包）
- 是否开源：是（Apache 2.0）
- 源码地址：https://github.com/AnyListen/elasticsearch-analysis-hanlp
- 特色：
  - 基于 HanLP，NLP 能力最强（分词、词性、实体、句法）
  - 内置多模型：标准、精确、极速
  - 支持远程词典热更
- 首次推出：2016 年（ES 2.x+）
- 兼容版本：5.x ~ 8.x

### 4. THULAC（清华分词）
- 是否开源：是（MIT）
- 源码地址：https://github.com/microbun/elasticsearch-thulac-plugin
- 特色：
  - 清华自然语言处理实验室出品
  - 分词+词性标注一体化
  - 速度快、准确率高
- 首次推出：2017 年（ES 5.x+）
- 兼容版本：5.x ~ 7.x（8.x 适配较少）
