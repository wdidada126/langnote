VS Code 设置 HTTP/HTTPS 代理（解决 Codex/Claude 403、插件下载），下面是最稳 3 种方法（Windows/macOS 通用）。
 
一、图形界面设置（最简单）
 
1. 打开 VS Code → 左下角 设置 ⚙️ → Settings
2. 搜索框输入：proxy
3. HTTP: Proxy 填入：plaintext
  
http://127.0.0.1:7890
 
 
（替换成你的代理地址+端口）
4. 把 HTTP: Proxy Strict SSL 设为 false（必选，防证书报错）
 
二、settings.json（推荐，稳定）
 
1. 快捷键：Ctrl+,（Win）/Cmd+,（Mac）
2. 点右上角 {}（Open Settings (JSON)）
3. 加入（覆盖原有 proxy 项）：
 
json
  
"http.proxy": "http://127.0.0.1:7890",
"https.proxy": "http://127.0.0.1:7890",
"http.proxyStrictSSL": false,
"http.proxyAuthorization": null
 
 
4. 保存 → 重启 VS Code
 
三、命令行临时代理（测试用）
 
关闭 VS Code，终端运行：
 
bash
  
# Win / Mac / Linux
code --proxy-server="http://127.0.0.1:7890"
 
 
只对本次启动生效。
 
四、带账号密码的代理
 
json
  
"http.proxy": "http://user:password@127.0.0.1:7890",
"https.proxy": "http://user:password@127.0.0.1:7890"
 
 
五、常见坑（必看）
 
- 地址必须带 http:// 前缀
- 用 127.0.0.1，别用 localhost（部分版本解析失败）
- 改完一定要重启 VS Code
- 仍不行：检查系统代理、防火墙、代理软件是否运行
 
六、配合 Codex/Claude
 
设置后再在 VS Code 装 Copilot / Claude Dev / CC GUI，就不会 403 了。

  对 Codex 的 skill 机制来说，项目内的 codex/skill.md 和 .codex/skill.md 不是标准位置。标准是：

  ~/.codex/skills/<skill-name>/SKILL.md

  或者系统内置的：

  ~/.codex/skills/.system/<skill-name>/SKILL.md

  也就是 SKILL.md 必须放在 skills/<skill-name>/ 目录下，Codex 才会把它当成一个 skill。

  所以如果你是想给“当前项目”做一个可用的 Codex skill，正确做法一般是：

  ~/.codex/skills/my-project-skill/SKILL.md

  如果你只是想在仓库里放一份给人看的说明文档，那么放 codex/skill.md 或 .codex/skill.md 都可以，但它不会自动被 Codex 识别成 skill。
