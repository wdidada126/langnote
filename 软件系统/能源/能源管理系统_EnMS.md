# 能源管理系统（EnMS）

EnMS 管理园区/工厂/楼宇的能耗计量、能效基线、需量、分布式能源、储能、充电和需求响应。它生成优化建议与受约束控制计划，不替代电网调度或现场保护系统。

## 数据流

```text
表计/设备/分布式电源 -> EnMS 采集能耗与状态
  -> 基线、预测、优化和告警
  -> 经授权网关/人工确认执行负荷或储能策略
  -> 计量系统确认实际量 -> 账单/市场/碳管理结算与分析
```

能耗读数和设备状态来自计量/现场系统；优化计划由 EnMS 负责；账单和市场结算以确认计量及规则为准。

## 验收重点

1. 表计映射、倍率、时区、缺失数据、基线版本和预测偏差。
2. 需求响应、储能充放、负荷控制的授权边界、失败回退和安全约束。
3. 能耗、费用、碳排和绿电属性口径分离且可对账。
