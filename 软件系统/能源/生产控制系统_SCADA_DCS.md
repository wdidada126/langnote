# 能源生产控制系统（SCADA/DCS）

能源生产 SCADA/DCS 管理油气田、管道、炼化、矿山、风光储场站等现场采集、过程控制、告警和联锁。它属于 OT 安全关键系统，普通数据平台或优化算法不能绕过现场保护和工艺许可直接控制设备。

## 数据流

```text
传感器/PLC/RTU -> SCADA/DCS -> 工业实时库和告警
  -> 生产运营/调度使用质量受控数据
  -> 授权控制或作业指令 -> 现场执行/联锁 -> 回读和操作审计
```

实时变量、联锁和操作事实归现场/控制系统；生产日报与经营量由生产运营确认；分析平台仅消费副本。

## 验收重点

1. 时标、质量码、坏点、通信中断、报警风暴与联锁测试。
2. 控制指令权限、双人复核、工艺边界、人工接管和回退。
3. OT/IT 分区、远程运维审计和配置变更测试。
