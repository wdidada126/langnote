# 能源资产与检维修系统（EAM）

EAM（Enterprise Asset Management）管理能源资产台账、位置、缺陷、巡检、保养、检维修、备件和作业许可。它将设备全生命周期与安全生产连接，不应由财务固定资产或普通工单系统替代。

## 数据流

```text
设计/GIS/采购建立资产与层级 -> EAM 维护台账和维护策略
  -> SCADA/巡检/人员上报缺陷 -> 工单与作业许可
  -> 备件/WMS 出库、现场执行、验收 -> 更新设备状态和维修历史
  -> 生产计划、财务、HSE 与数据平台消费受控结果
```

资产身份、维护策略、缺陷和工单状态由 EAM 负责；实时工况来自 OT；备件库存来自 WMS；财务价值来自 ERP。各系统通过资产编码和时间线关联。

## 验收重点

1. 资产层级、位置、变更、报废、替换和历史追溯。
2. 缺陷优先级、作业许可、停机窗口、备件可用性和复验闭环。
3. 维修完成不自动等于设备可投运，应由现场/调度状态确认。
