# 碳管理系统

碳管理系统收集活动数据，按组织/运营边界、排放因子和核算方法计算排放、配额、减排与披露指标。它是核算与证据管理系统，不应把能源账单金额或单一能耗读数直接等同于碳排放。

## 数据流

```text
生产、计量、采购、物流和财务系统提供活动数据
  -> 碳管理校验边界、数据质量和排放因子版本
  -> 计算排放/减排/配额 -> 审核与锁定核算期
  -> ESG 披露、内部决策或交易系统消费结果 -> 更正/重述留痕
```

活动数据仍由源系统负责；碳因子、方法、边界与核算版本由碳管理系统负责。核算更正应产生重述版本，不能覆盖历史披露证据。

## 验收重点

1. 组织边界、排放范围、因子来源、生效期和计算方法可审计。
2. 缺失/估算数据、数据更正、核算锁定、审批和披露版本管理。
3. 与能源、采购、财务数据的口径差异可解释，而非强行对齐数值。
