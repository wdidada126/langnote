# 能源软件系统

## 领域边界

能源软件覆盖煤炭、油气、电力、新能源、储能、热力、氢能和综合能源服务的产、供、储、销、用及碳管理。与电力系统相比，能源系统还要处理矿山/油气田/管网/炼化/新能源场站等资产生产过程、库存与物流、合同贸易和碳排放核算；“能源数据平台”不能替代各生产装置、计量和安全系统的原始责任。

## 核心系统地图

| 系统 | 应用场景 | 权威数据/责任 |
| --- | --- | --- |
| OT 生产控制 | 智能煤矿、油气田、管道、炼厂、风光场站、储能电站 | 设备工况、实时测量、联锁、告警和生产事件。 |
| SCADA/DCS/工业历史库 | 远程监控、过程控制、数据采集、趋势与告警 | 工艺变量、设备状态、操作记录与质量码。 |
| 生产运营 | 产量计划、作业、井/矿/场站管理、设备维护、质量检验 | 生产日报、作业票、产量/质量、停机和损失原因。 |
| 管网与调度 | 油气管网、水热管网、储能、综合能源调度 | 供需平衡、输配能力、压力/流量、库存和调度指令。 |
| 贸易与供应链 | 合同、提名、运输、仓储、交割、价格、风险敞口 | 合同、货权、库存、交付、定价与结算。 |
| 能源管理（EMS） | 园区/工厂能耗、需量、负荷、分布式能源、虚拟电厂 | 用能计量、能效基线、控制策略、需求响应与结算。 |
| 碳与 ESG | 排放因子、边界、活动数据、核算、配额、披露 | 排放活动数据、因子版本、核算方法、审计证据。 |
| 资产与项目 | EAM、GIS、工程、采购、备件、检维修、HSE | 资产、空间位置、工单、作业许可、事故与合规记录。 |

## 关键数据流

### 生产到经营

```text
现场设备/传感器/实验室产生实时工况、产量与质量数据
  -> SCADA/DCS/历史库校验质量码并沉淀时间序列
  -> 生产运营系统按班次/日结确认生产量、损耗和库存变化
  -> 贸易/供应链系统将合同、提名、运输和交割与确认量关联
  -> 结算/财务按合同条款、价格、计量和交付事实生成结算与凭证
  -> 数据平台/碳系统消费受控副本做分析、核算和披露
```

实时传感器值、交割计量值、生产报表量、库存账和财务结算量可能不同。每个口径都应记录测量位置、仪表/实验室、时间窗、质量状态、调整规则和审批人；不能由 BI 报表直接覆盖生产或结算事实。

### 分布式能源与综合能源

```text
分布式光伏/风电/储能/充电桩/负荷侧采集设备状态和计量
  -> 能源管理系统预测、优化和生成受约束的控制计划
  -> 经授权网关/现场控制执行并反馈状态
  -> 电力计量/市场/客户账单按确认量结算
  -> 碳管理按活动数据、因子和边界核算并保留证据链
```

优化算法只能在安全边界、设备约束、电网调度要求和用户授权内工作。能耗数据、碳数据、绿电/绿证或市场结算数据不应相互替代，必须注明口径与证据来源。

## 风险与验收

1. 将 OT 控制、生产运营、经营贸易和分析平台分层，禁止分析系统直接绕过控制边界下发生产指令。
2. 验证仪表失准、通信中断、补采、实验室修订、库存盘点、交割争议、合同变更和结算重算的版本与对账链。
3. 对油气/煤矿/化工等高危场景，作业许可、联锁、告警确认、应急处置和 HSE 记录应有独立可靠链路，不依赖普通办公流程。
4. 碳核算要保留组织/运营边界、活动数据来源、排放因子版本、计算方法、调整记录与审计材料。

国家能源局 2023 年意见覆盖智能电厂、新能源及储能并网、智能微网、虚拟电厂、智能煤矿、油气田、管道和炼厂等场景；2026 年进一步提出能源与人工智能双向赋能。参考：[能源数字化智能化意见](https://zfxxgk.nea.gov.cn/2023-03/28/c_1310707122.htm)、[人工智能与能源双向赋能行动方案](https://www.nea.gov.cn/20260508/4dae97ca01d348e4871bb8654be34b3a/c.html)。
