# POS 门店交易系统

POS 管理门店收银、促销、会员、票据、退款、交班和支付接入。它需要在网络不稳定时保障可控交易，并最终与 OMS、库存、支付和财务进行对账。

## 数据流

```text
商品/价格/促销/会员主数据 -> POS 本地缓存
  -> 扫码结算 -> 支付渠道返回交易状态
  -> POS 生成小票、库存扣减与会员积分事件
  -> 总部 OMS/WMS/财务汇总与对账 -> 差异补正
```

门店交易明细归 POS，支付回执归支付渠道，库存总账归库存系统。离线交易需有唯一流水、风险限额、补传顺序和冲突处理。

## 验收重点

1. 断网、离线收银、重复扫描、挂单、交班和设备故障。
2. 退款、撤销、优惠分摊、积分回滚和电子发票。
3. 门店日结与支付、库存、财务及总部订单的差异定位。
