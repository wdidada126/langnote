# 护理、手术麻醉与输血系统

## 定位

这类系统记录医疗服务的实际执行。EMR 中的医嘱表达“计划做什么”，护理、手术麻醉和输血系统记录“谁在何时如何完成、未完成或异常处理了什么”。因此它们是医疗安全、争议追溯和费用/耗材对账的重要事实来源。

## 子系统与数据流

| 子系统 | 主要功能 | 上游输入 | 下游/回写 |
| --- | --- | --- | --- |
| 护理信息系统（NIS） | 护理评估、体征、执行单、移动护理、交接班 | 患者/床位、护理医嘱、药品/检查任务 | 回写执行、拒绝、漏执行、体征与交接事实。 |
| 手术管理与麻醉 | 排台、术前评估、麻醉记录、术中事件、恢复室 | 手术申请、患者、检查结果、床位与人员 | 回写手术状态、麻醉记录、耗材植入、计价依据。 |
| 输血管理 | 申请、配血、发血、床旁核对、反应上报 | 输血医嘱、患者、血型/检验结果、血袋信息 | 回写发血/输注/退血、核对和不良反应。 |

```text
EMR 医嘱/手术申请 -> HIS 计价与资源信息
  -> 护理/手术/输血系统生成执行任务
  -> 扫描腕带、血袋、药品或耗材并记录执行
  -> 回写执行状态、时间、人员、批号/序列号与异常
  -> EMR 更新临床记录；PIS/SPD/HIS 更新消耗、库存和费用对账
```

## 控制与验收

1. 执行系统必须以患者唯一标识、就诊、医嘱/申请和任务 ID 关联，条码扫描是校验手段而不是唯一证据。
2. 验证转床、转科、交接班、临时医嘱、患者拒绝、设备离线、补录和撤销，确保不会把过期任务执行给错误患者。
3. 植入物、血袋、麻醉药和高警示药需要记录批号/序列号、操作者、双人核对、时间轴和异常处置。
4. “已收费”“已出库”“已执行”必须分别对账；手术取消或中止时，已使用耗材与可退耗材要有不同处理路径。
