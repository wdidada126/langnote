# 检验信息系统（LIS）

## 定位

LIS（Laboratory Information System）管理临床检验从申请到报告的检验专业工作流，包括标本、条码、仪器结果、质控、复核、报告和危急值。它与药企/器械企业的实验室 LIMS 缩写相近但责任不同：医院 LIS 服务患者诊疗和检验报告；研发/生产 LIMS 服务试验或生产质量。

## 功能大类

| 能力 | 小类 | 关键事实 |
| --- | --- | --- |
| 申请与采集 | 申请单、项目组合、采血/采样、条码、采集时间和人员 | 检验申请与标本不是同一对象；一个申请可对应多个标本。 |
| 标本流程 | 签收、拒收、分拣、离心、转运、留样、销毁 | 标本状态、拒收原因、交接链和位置。 |
| 检测与质控 | 仪器双向通信、结果接收、复测、室内质控、校准 | 原始结果、仪器/试剂批号、质控判定和复测关系。 |
| 审核与报告 | 自动审核、人工审核、报告发布、修订、打印 | 报告版本、审核人、发布时间和修订原因。 |
| 危急值与统计 | 危急值通知、确认、TAT、工作量、质控报表 | 通知对象、时间、确认人、升级处理和闭环证据。 |

## 数据流与状态回写

```text
EMR/HIS 创建检验申请、患者和就诊信息
  -> HIS/PIS 完成计价或按院内规则允许采集
  -> LIS 生成条码与采集任务
  -> 采集端记录标本、采集时间和采集人
  -> LIS 签收/拒收/分拣 -> 仪器或人工检测
  -> LIS 接收结果、质控和复测 -> 审核
  -> LIS 发布报告/危急值
  -> EMR 展示报告和趋势，HIS/运营系统取得完成状态
  -> 危急值通知临床并回写确认，不以“报告已发布”代替确认
```

患者、就诊和申请的权威来源通常是 HIS/EMR；标本、检测、审核与报告版本由 LIS 负责；收费与结算由 HIS/医保负责。接口消息必须携带患者标识、就诊标识、申请号、标本号、项目代码、时间和版本，不能用姓名加项目名匹配。

## 异常与验收

1. 申请取消、患者信息更正、标本拒收、条码重打、仪器离线补传和重复结果必须可区分且幂等。
2. 报告修订必须保留原报告、修订原因和临床已阅/危急值通知记录，不能原地覆盖。
3. 仪器接口应验证单位、参考区间、异常标识、项目映射、结果精度和时钟同步；接口“有数据”不等于医学语义正确。
4. 危急值需演练通知失败、无人确认、升级和交接班场景，统计闭环率而非只统计报告数。
