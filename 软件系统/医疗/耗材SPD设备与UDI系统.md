# 耗材 SPD、设备管理与 UDI 系统

## 定位

SPD（Supply, Processing and Distribution）在医院语境中通常指医用耗材供应、加工和配送协同能力；设备管理系统管理医疗设备的台账、维护、校准和生命周期；UDI 用于器械的唯一识别和追溯。三者共同支撑“物从哪里来、在何处、被谁使用、是否可追溯”，但不替代临床医嘱和病历。

## 数据流

```text
供应商/ERP 创建采购、合同、目录和到货信息
  -> SPD/WMS 入库、验收、批号效期/UDI、库存与配送
  -> 科室二级库领用或手术/护理扫码使用
  -> 手术麻醉/护理记录患者、用量、植入物和执行事实
  -> SPD 回写消耗、退库、盘点和召回范围
  -> HIS/收费/成本系统按可计费和实际消耗分别处理并对账
  -> 设备系统记录设备状态、维护/校准，RIS/LIS 等引用可用设备
```

UDI-DI 标识产品型号规格和包装，UDI-PI 标识批号、序列号、生产日期或失效日期等生产信息。医院系统应保存适用器械的标识与入库、领用、患者使用/植入、退货和召回关联；是否适用、哪些字段必须采集应按当期监管要求和产品类别实施。

## 子模块

| 模块 | 关键数据 | 控制点 |
| --- | --- | --- |
| 目录与采购 | 耗材编码、供应商、合同、价格、替代关系 | 与收费项目、医保目录和临床材料名称的映射版本。 |
| 库存与配送 | 库房、二级库、批号效期、UDI、出入库、盘点 | 账实一致、效期预警、冷链和调拨流水。 |
| 高值耗材 | 植入物、序列号、患者、手术、知情同意、结算 | 患者使用事实、收费、库存扣减和追溯不可互相替代。 |
| 设备管理 | 台账、位置、维护、计量、校准、工单、报废 | 设备状态影响检查排班和结果可信性，应有接口/人工确认机制。 |

## 风险与验收

1. 测试扫码失败、无条码、替代耗材、拆零、退货、召回、盘点差异和离线使用后的补录。
2. 对高值耗材验证“入库 -> 领用 -> 患者使用 -> 收费 -> 结算 -> 追溯”完整链路；不能仅以收费记录证明已使用。
3. 验证 UDI、批号、序列号、产品编码、收费编码之间的映射和版本，防止同名异物或规格混淆。
4. 设备维修/校准状态应影响可排班性或告警，避免故障设备仍接收检查任务。

参考：[国家药监局医疗器械唯一标识数据库](https://udi.nmpa.gov.cn/)。关联专题：[医疗软件系统](../医疗软件系统.md)。
