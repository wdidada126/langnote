# 影像信息系统（RIS/PACS）

## 定位

RIS（Radiology Information System）管理检查预约、登记、检查工作流和报告；PACS（Picture Archiving and Communication System）管理影像的接收、归档、传输、调阅和后处理。RIS 与 PACS 可由同一厂商产品提供，但数据边界不同：RIS 对检查业务状态和报告工作流负责，PACS 对影像对象、归档完整性和调阅负责。

## 核心数据流

```text
EMR/HIS 创建影像检查申请
  -> RIS 校验项目、预约资源、禁忌/准备事项 -> 预约或登记
  -> HIS 计价/医保状态回写
  -> RIS 将检查号、患者和检查上下文提供给设备工作列表
  -> 设备产生影像 -> PACS 接收、校验、归档
  -> RIS/PACS 工作站阅片、书写和审核报告
  -> RIS 发布报告，PACS 提供影像链接/调阅能力
  -> EMR 展示报告和影像；质控/运营系统消费完成、时效和剂量等数据
```

患者/就诊/申请由 HIS/EMR 维护，检查号与检查状态由 RIS 维护，影像和其归档校验由 PACS 维护，报告及其签署版本通常由 RIS 或报告系统维护。任何系统修改患者标识、撤销申请或更正检查信息，都要有受控的更正流程，不能直接改影像文件元数据掩盖历史。

## 功能与控制点

| 能力 | 小类 | 控制点 |
| --- | --- | --- |
| 检查工作流 | 预约、登记、叫号、技师执行、取消、补做 | 申请、检查和报告状态分别维护；取消后已采集影像的处置可追溯。 |
| 影像归档 | DICOM 接收、路由、缓存、长期归档、灾备 | 防止丢片、错片、重复片；校验可恢复性和跨院区调阅延迟。 |
| 阅片与报告 | 模板、语音、审核、修订、结构化报告 | 报告版本、签署人、修订原因和关键图像引用。 |
| 剂量与质控 | 设备参数、辐射剂量、质控、TAT | 数据来源、单位、患者/检查匹配和异常告警。 |

## 验收场景

1. 申请修改/撤销、患者合并或身份更正、急诊插队、重复检查和跨院区调阅。
2. 设备网络中断、PACS 存储故障、报告已发但影像不可调阅、影像已到但报告未审核。
3. 报告修订、关键发现/危急值通知、影像长期归档检索和容灾恢复。
4. 接口校验 DICOM 标识与 HIS/RIS 申请号的一致性，避免仅凭姓名、日期匹配。
