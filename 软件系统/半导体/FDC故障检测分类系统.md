# 半导体 FDC 故障检测与分类系统

FDC（Fault Detection and Classification）基于设备传感器和过程轨迹检测异常、分类故障模式并联动处置。它关注高频过程信号，与 SPC 的量测统计互补；模型结果是风险证据，不自动替代工程师诊断和设备安全逻辑。

## 数据流

```text
设备/EAP 流式过程数据 -> FDC 特征提取与规则/模型检测
  -> 异常分类、健康评分和告警 -> PAN/OCAP/QMS
  -> MES hold 受影响 lot，EAM 创建设备检修任务
  -> 工程师确认原因与处置 -> FDC 更新标签/模型与回溯范围
```

原始时序数据归设备/历史库，FDC 保存特征、检测版本和结果，MES 保存批次状态。模型或阈值变更必须可复现，不得只覆盖历史评分。

## 验收重点

1. 采样丢失、时钟偏移、设备/腔体映射、漂移和误报漏报评估。
2. 异常检测到批次范围、设备停机/恢复和维修工单的闭环。
3. 模型版本、训练数据、阈值、人审结论和再训练审批。
