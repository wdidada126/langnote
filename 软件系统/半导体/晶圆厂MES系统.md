# 晶圆厂 MES 系统

半导体 MES 管理晶圆批次（lot）、工艺路线、设备派工、工序过站、配方选择、在制品（WIP）和追溯，是晶圆厂制造执行的核心事实源。通用 MES 概念不足以描述晶圆批次、返工、分批合批、腔体和工艺配方等半导体约束。

## 数据流

```text
ERP/计划下达生产任务 -> MES 建立 lot、工艺路线和优先级
  -> MES 校验设备、配方、人员资格与物料 -> 派工/过站
  -> 设备 EAP 回传过程与状态 -> MES 更新 WIP/历史
  -> SPC/FDC/APC/QMS 消费过程数据并回写 hold/release 等受控结果
  -> YMS、计划、成本和交付系统消费确认生产事实
```

lot 状态、工艺履历和 WIP 归 MES；设备原始信号归设备/EAP；质量拦截由 QMS/OCAP 决定但必须通过 MES 执行。禁止下游系统直接改批次状态。

## 验收重点

1. 分批合批、返工、报废、hold/release、跨厂区转运和工艺路线变更。
2. 设备/配方/产品版本校验和离线设备补传，防止错机台、错腔体、错配方加工。
3. 批次到晶圆、工艺步骤、设备、腔体、配方和异常处置的完整追溯。
