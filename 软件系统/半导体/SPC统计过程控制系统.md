# 半导体 SPC 统计过程控制系统

SPC 管理测量数据、控制图、规格限、控制限、规则判异和异常通知，用于发现过程漂移。SPC 的报警不是自动判定产品失效；它需要和 MES 批次、设备、配方、量测与 OCAP 处置闭环关联。

## 数据流

```text
设备/量测系统产生测量值 -> SPC 按产品/工艺/设备/配方分组分析
  -> 触发规则判异与告警 -> PAN/OCAP/QMS 创建处置
  -> MES 对受影响 lot 执行 hold/release
  -> 处置结果和复测数据回写 SPC，形成持续改进证据
```

规格与控制规则、数据版本和判异结果归 SPC；lot 的实际状态仍由 MES 管理。不得用一次越界就直接修改良率或删除原始测量数据。

## 验收重点

1. 控制限版本、分组逻辑、缺失/异常测量、复测和仪器校准。
2. 告警去重、升级、受影响 lot 范围和 OCAP 闭环时限。
3. 原始数据、转换数据、控制图和处置结果可回放。
