# 半导体设备自动化系统（EAP）

EAP（Equipment Automation Program）连接 MES 与生产设备，处理设备状态、配方下载/校验、批次装载、过程数据和事件。它是设备通信与自动化执行边界，不拥有生产计划或质量放行规则。

## 数据流

```text
MES 下发 lot、步骤、配方和权限 -> EAP 校验设备状态/配方
  -> 设备执行并产生状态、事件和过程数据
  -> EAP 回传 MES、FDC/SPC/历史库
  -> 异常时 OCAP/PAN 触发 hold、通知或受控恢复
```

设备状态与原始过程数据由设备产生；EAP 负责规约/通信与命令审计；MES 是 lot 流转权威源。配方变更需由受控版本与设备实际回读确认。

## 验收重点

1. 通信中断、重复事件、设备离线、配方不一致、腔体切换和恢复重连。
2. 远程命令权限、联锁、超时、回执与人工接管。
3. 时钟同步、数据质量与设备事件同 MES 批次履历准确关联。
