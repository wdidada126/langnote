# 半导体软件系统

晶圆厂的核心链路是“计划 -> MES 批次流转 -> EAP 设备执行 -> SPC/FDC 质量监控 -> APC 受控优化 -> YMS 良率分析 -> QMS/OCAP 处置闭环”。每个系统独立维护自身事实，不能把分析平台或报警系统变成直接改生产状态的旁路。
