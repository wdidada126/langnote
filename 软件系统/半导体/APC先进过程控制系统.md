# 半导体 APC 先进过程控制系统

APC（Advanced Process Control）根据量测与过程反馈优化设备配方或工艺参数，常包含 run-to-run（R2R）控制。它直接影响制造过程，必须受设备安全范围、工艺批准版本和人工接管约束。

## 数据流

```text
MES/EAP 提供当前 lot、配方和过程上下文
  -> 量测/历史库提供反馈数据 -> APC 计算受约束参数建议
  -> 工艺规则/审批校验 -> EAP 下发参数或配方版本
  -> 设备执行与量测回传 -> APC 评估效果并保留计算版本
```

APC 保存控制模型、参数建议和执行证据；设备保留实际执行状态；MES 保留 lot 履历。任何自动调整都必须有上下限、适用产品/设备、回退和禁用开关。

## 验收重点

1. 模型失效、量测延迟、异常输入、设备切换和人工冻结/恢复。
2. 参数建议、审批、实际下发、执行回读和良率结果的可追溯性。
3. 仿真/影子模式验证后再受控上线，禁止直接用生产批次试错。
