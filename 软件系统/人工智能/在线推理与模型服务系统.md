# 在线推理与模型服务系统

在线推理系统负责模型部署、路由、弹性伸缩、限流、缓存、特征获取、响应和观测。它将已批准模型提供给业务应用，不应自行决定业务放款、支付、诊断或控制动作。

## 数据流

```text
MLOps 发布已批准模型制品 -> 推理服务加载/预热
  -> 业务应用携带经授权请求 -> 特征/知识服务提供上下文
  -> 推理服务返回版本化结果与置信/错误信息
  -> 应用规则和人工复核决定是否采取业务动作
  -> 延迟、错误、漂移和反馈回流监控/MLOps
```

推理服务保存调用与模型版本证据；业务系统保存最终决策和业务事实。模型成功返回不代表结果可靠或业务操作成功。

## 验收重点

1. 限流、超时、熔断、降级、模型热切换和回滚。
2. 多模型路由、特征时间点一致性、缓存失效和结果幂等。
3. 敏感请求日志脱敏、调用审计、成本配额和异常告警。
