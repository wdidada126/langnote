# 大模型应用与 RAG 系统

大模型应用与 RAG（检索增强生成）系统管理提示词、知识库、检索、上下文拼接、模型调用、输出约束和用户反馈。它应把生成结果视为候选内容，不应直接写入账务、病历、控制系统或高风险业务结论。

## 数据流

```text
经治理的文档/知识库 -> 分段、嵌入、索引与版本管理
  -> 用户请求经身份/权限/内容策略校验
  -> 检索授权范围内证据 -> 模型生成 -> 规则/人工复核
  -> 返回带来源/时效说明的结果，反馈进入评测与改进
```

知识来源、索引版本、提示词模板、模型版本和输出审计应可关联。RAG 降低幻觉但不保证正确性，检索到的内容也可能过期、无权或错误。

## 验收重点

1. 文档权限同步、删除/撤回、索引重建、引用准确性与敏感信息泄露。
2. 提示词注入、越权检索、工具调用越权、内容安全和拒答策略。
3. 高风险输出的人工确认、可解释来源和用户纠错闭环。
