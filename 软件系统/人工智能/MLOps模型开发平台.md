# MLOps 模型开发平台

MLOps 平台管理实验、训练、评测、模型注册、审批、部署和监控，使模型从研发到生产可复现、可审计、可回退。它不负责业务最终决策，业务规则和人工复核仍在应用系统中执行。

## 数据流

```text
数据/特征平台提供版本化数据 -> 训练与实验记录
  -> 离线评测、偏差/安全评估 -> 模型注册与审批
  -> 部署到推理服务 -> 线上指标、漂移和反馈监控
  -> 触发再训练、降级或回滚，保留全链路版本
```

模型代码、参数、数据版本、评测结果、审批和部署版本均需关联。不能以“最新模型”覆盖生产版本而无回退证据。

## 验收重点

1. 实验复现、资源配额、训练数据权限和制品签名。
2. 灰度、A/B、影子流量、漂移告警、自动/人工回滚。
3. 模型风险分级、审批责任和高风险场景的人类监督。
