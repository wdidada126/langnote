# 保险核心系统

保险核心系统管理产品、投保、核保、保单、批改、保费、理赔和再保。它与银行核心不同：核心事实是保单合同、保障责任、风险暴露和赔案，而非仅账户余额。

## 数据流

```text
渠道投保 -> 客户/KYC 与核保规则 -> 出单、保单和缴费计划
  -> 支付/银行回传保费结果 -> 保单生效
  -> 报案 -> 查勘/医疗或维修资料 -> 理算/审核 -> 赔付指令
  -> 支付系统执行赔款 -> 财务、再保、准备金和监管报送
```

保单责任、批改和理赔状态由保险核心负责；收付款状态由支付/银行系统负责；风险模型、外部资料和人工理赔结论应保留版本与来源。

## 验收重点

1. 保单撤销、批改、续期、保费失败、保单失效与恢复。
2. 重复报案、欺诈线索、理赔分案、拒赔申诉、赔款失败与重付。
3. 保单、收付、赔案、再保分摊和财务准备金的对账与审计。
