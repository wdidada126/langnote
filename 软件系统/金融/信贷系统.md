# 信贷系统

信贷系统覆盖申请、准入、授信、审批、合同、放款、还款、催收和资产分类。它管理信贷合同与风险决策，实际资金入账由 CBS 完成，征信、反欺诈和贷后模型也应保留独立证据。

## 数据流

```text
渠道申请 -> KYC/征信/反欺诈 -> 授信审批与额度
  -> 合同签署 -> 信贷发起放款 -> CBS 记账放款
  -> 还款计划/计息 -> CBS 扣款与回执 -> 信贷更新合同状态
  -> 贷后预警/催收/核销 -> 财务与监管报送
```

授信结论、额度和合同版本由信贷系统负责；贷款余额和资金流水以 CBS 为准；风险模型仅输出可复核的决策依据，不可覆盖人工审批和合同事实。

## 验收重点

1. 多申请并发、额度占用/释放、撤销、合同变更、提前还款和逾期转催收。
2. 征信/外部数据超时、异议、规则版本与人工复核留痕。
3. 合同、放款、还款、减免、核销与总账/监管口径的可追溯对账。
