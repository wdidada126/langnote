# 支付清算系统

支付清算系统接收支付指令、路由至行内或外部清算网络、处理回执、差错和对账。它不拥有银行核心账户余额，但应拥有支付业务状态机、原始指令和外部交互证据。

## 数据流

```text
渠道 -> 风控/限额 -> CBS 冻结或扣账
  -> 支付系统路由并发送指令 -> 外部清算/收款方回执
  -> 支付状态更新 -> CBS/总账/客户通知
  -> 渠道、清算、核心、总账和资金账户多边对账 -> 差错补正
```

已受理、已扣账、已发送、清算成功、结算成功、退款/冲正和对账完成必须分开。外部超时通常为未知状态，应查原流水而非无条件重发。

## 验收重点

1. 重复/乱序回执、跨日回执、部分退款、撤销和清算文件差异。
2. 业务 ID、幂等键、报文签名、金额币种、原始请求和回执的完整审计。
3. 灾备切换后不重扣、不漏单，并能重放未终态交易。
