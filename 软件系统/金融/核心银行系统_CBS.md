# 核心银行系统（CBS）

CBS（Core Banking System）管理账户、存贷款、计息、额度和明细账，是银行客户账户状态与行内账务事实的核心来源。渠道、支付、信贷和总账不能直接修改余额表，应通过受控交易和会计规则入账。

## 数据流

```text
渠道/支付/信贷提交幂等业务指令 -> CBS 校验账户、余额、额度和状态
  -> 记明细账/冻结或扣划 -> 生成会计事件
  -> 支付清算/贷款/通知系统消费结果
  -> 总账按会计规则生成凭证 -> 对账系统核对外部回执与账务
```

账户余额、可用余额、冻结、交易明细和账户状态由 CBS 负责；总账负责法定会计汇总，支付系统负责跨机构指令与回执。不得将“渠道受理成功”当作核心已入账。

## 验收重点

1. 并发扣款、重复报文、超时查询、冲正、日切和跨日计息。
2. 账户冻结、挂失、销户、限额与授权变更对所有渠道的即时生效。
3. 明细账、总账、外部清算回执和资金账户逐笔/日终对账。
