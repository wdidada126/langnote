# 证券交易与清算系统

证券系统覆盖开户、适当性、委托、成交、清算、交收、托管、登记、持仓和估值。委托、成交、清算和交收是不同市场阶段，不能将交易前端的“委托成功”视为资产最终可用。

## 数据流

```text
客户/渠道委托 -> 适当性、风控、资金证券校验 -> OMS/交易所撮合
  -> 成交回报 -> 清算系统计算应收应付与保证金
  -> 托管/登记/资金交收回执 -> 更新持仓和可用资金
  -> 估值、对账、风控、客户报表与监管报送
```

委托与成交由交易系统负责，清算金额与交收状态由清算托管链路负责，客户资产展示需基于已确认状态和市场规则。资金和证券交收需要保留参与方、批次、失败和补救记录。

## 验收重点

1. 撤单、部分成交、交易中断、清算失败、保证金不足和交收违约。
2. 持仓、可用、在途、冻结和估值口径的区分及日终重算。
3. 成交回报、清算文件、托管登记、资金交收与客户账单的逐笔对账。
