# 工商银行智慧托管系统

工商银行公开资料将智慧托管系统列为 ECOS 的重要组成。托管系统围绕资产保管、估值核算、清算交收、投资监督、信息披露和客户报告等托管责任建设；它与交易、登记结算、基金会计和投资管理系统协同，但不替代其原始交易或估值数据责任。

## 数据流

```text
投资管理/交易系统提交指令和成交
  -> 登记结算/清算链路确认资金与证券交收
  -> 托管系统记录资产保管、监督、估值核对与异常
  -> 基金会计/估值系统生成核算结果并与托管复核
  -> 客户报告、监管报送和对账输出受控结果
```

成交事实来自交易设施，交收事实来自清算登记托管机构，托管系统保存托管监督和核对证据。估值、会计与托管差异需要走核对和更正流程，不能直接覆盖。

## 验收重点

1. 资产、账户、组合、交易、交收、估值与会计期间的主键和时点一致性。
2. 失败交收、公司行动、估值差异、资金证券不一致和监管报告更正。
3. 客户隔离、授权、监督规则、异常升级和完整审计。
