# 工商银行司库与财资管理系统

工商银行公开介绍了“司库信息系统”“财资管理云”等产品能力，用于联动企业核心业务系统和财务系统，支持账户、结算、投融资等线上集中管理。它是企业客户资金管理与银行服务协同系统，不替代企业 ERP、银行核心账务或支付清算系统。

## 数据流

```text
企业 ERP/资金系统提交账户、支付、融资或资金归集指令
  -> 司库/财资平台校验授权、额度、审批和企业资金规则
  -> 银行核心/支付系统执行账户与支付交易
  -> 清算/结算回执返回 -> 司库更新企业头寸、对账和报表
  -> 企业 ERP/财务取得经确认的流水和对账结果
```

企业资金计划与审批归企业侧系统/司库平台，银行账户余额归核心系统，跨机构支付终态归支付清算链路。企业“提交成功”不代表银行已扣账或收款方已结算。

## 验收重点

1. 企业多法人、多账户、额度、授权矩阵、批量支付和审批替换。
2. 交易文件/API 幂等、失败重试、跨日回执、银企对账和差错补正。
3. 企业数据隔离、操作审计、密钥/证书、下载文件与 API 权限控制。
