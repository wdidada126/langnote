# 订单管理系统（OMS）

OMS 管理电商订单从创建、拆单、库存占用、支付、履约、售后到关闭的状态机。它不替代支付渠道、WMS 或财务系统，而是协调订单承诺与各专业系统回执。

## 数据流

```text
渠道创建订单 -> OMS 校验价格、促销、地址与库存占用
  -> 支付系统回传支付状态 -> OMS 下发 WMS/履约
  -> WMS 发货/取消回传 -> 物流跟踪 -> 客户签收
  -> 售后退款/退货 -> 支付、库存、财务分别处理并对账
```

订单状态由 OMS 管理，支付终态由支付系统管理，库存事实由 WMS 管理，物流事实由承运系统管理。支付成功不等于发货，签收不等于资金结算完成。

## 验收重点

1. 超卖、拆单、部分发货、取消、支付超时、重复回调和逆向退货。
2. 订单、支付、库存、运单、退款和财务流水逐笔对账。
3. 幂等键、状态迁移约束、补偿任务和人工异常处理。
