# 运输管理系统（TMS）

TMS 管理运力、线路、运单、调度、装卸、在途跟踪、签收、异常与运费结算。它与 WMS 的分界是：WMS 管仓内库存与出入库，TMS 管仓外运输与交付。

## 数据流

```text
OMS/WMS 创建出库与运输需求 -> TMS 配载、派车/承运商与运单
  -> 承运商/司机回传揽收、在途、异常、签收
  -> TMS 回写履约状态 -> OMS 通知客户
  -> 运费、计量、赔付与承运商账单 -> 财务对账结算
```

运输计划、运单和轨迹状态归 TMS；库存归 WMS；客户订单归 OMS；签收凭证和异常证据不能被单一物流状态文本替代。

## 验收重点

1. 拆单合单、改址、拒收、丢损、回单、逆向物流和时效异常。
2. 轨迹重复/乱序、离线补传、签收证据和承运商接口重试。
3. 运单、重量/体积、计费规则、赔付和财务结算对账。
