# 电信在线计费系统（OCS）

OCS（Online Charging System）在语音、数据、短信、物联网等使用事件发生时实时鉴权、额度预留、扣减与放行，主要服务预付费和实时信用控制。它不同于离线账单系统，不能以日终话单批处理替代实时额度控制。

## 数据流

```text
网络网元/业务平台发起使用请求 -> OCS 校验账户、套餐、余额和规则
  -> 预留/扣减额度并返回允许、限额或拒绝
  -> 网元上报使用结束/更新 -> OCS 最终结算使用量
  -> BSS/账务生成账单、充值、对账和客户服务记录
```

实时余额与额度状态归 OCS，客户产品/订购归 CRM/BSS，账单与应收归离线计费/账务系统。超时与重复请求必须通过会话 ID 和幂等机制处理。

## 验收重点

1. 会话中断、重复扣费、余额不足、套餐切换、漫游和多网元并发。
2. 预留、实际消耗、退款、充值和账单的逐笔对账。
3. 高并发限流、跨机房容灾与状态一致性。
