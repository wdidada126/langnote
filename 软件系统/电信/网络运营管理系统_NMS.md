# 电信网络运营管理系统（NMS）

NMS 管理网络设备、拓扑、性能、告警、配置、工单和故障恢复，服务 OSS 运维。它不直接拥有用户计费或客户合同，但网络故障与服务质量状态需要向客服、计费和运营系统提供受控信息。

## 数据流

```text
网元/探针上报遥测、告警和性能 -> NMS 关联拓扑与影响范围
  -> 生成告警/工单/变更任务 -> 现场或自动化处置
  -> 回读网络状态并关闭事件 -> 客服/运营消费已确认影响信息
```

设备配置和网络状态以网元/NMS 为准，客户影响以关联规则和确认状态为准。告警发生不等于客户已受影响，工单关闭不等于质量指标已恢复。

## 验收重点

1. 告警风暴、重复事件、拓扑变更、时钟同步和根因关联。
2. 变更审批、配置备份、回退、权限隔离和操作审计。
3. 网络故障到客户影响、赔付/减免和服务恢复的闭环。
