# 教务管理系统

教务系统管理培养方案、课程库、教学任务、排课、选课、学分和正式成绩发布。它是“教学规则与正式成绩流程”的权威系统，不应由排课工具或 LMS 直接替代。

## 数据流

```text
SIS 提供学生学籍、院系班级与培养层次
  -> 教务维护培养方案、课程、教师、教室和教学班
  -> 学生选课/退课 -> LMS 创建课程空间
  -> LMS/考试系统回传过程成绩和考试结果
  -> 教务审核、发布、复核正式成绩 -> SIS 归档学分与毕业资格
```

课程、教学班、选课资格、成绩发布版本归教务系统负责。LMS 暂存分、阅卷原始分与正式成绩应通过受控映射进入教务流程，不能覆盖已发布成绩。

## 验收重点

1. 排课冲突、容量控制、先修课、重修、跨校区和调停课的规则校验。
2. 选课高峰的幂等提交、候补队列、缴费/资格状态和可恢复性。
3. 成绩录入、复核、修改和归档的前后值、审批人与影响学生范围审计。
