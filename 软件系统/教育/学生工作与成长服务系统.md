# 学生工作与成长服务系统

学生工作系统管理资助、奖惩、宿舍、就业、心理、社团、辅导员工作和成长档案等服务。它服务学生发展与事务办理，敏感个人信息的访问边界通常比教务和 LMS 更严格。

## 数据流

```text
SIS 提供有效学籍、组织和基础身份
  -> 学工系统受理资助/宿舍/就业/心理等服务申请
  -> 审批、服务和干预记录由对应业务模块保存
  -> 仅向 SIS/教务/财务回传必要的资格或结果摘要
  -> 数据平台按授权提供统计，不直接暴露个案明细
```

学籍和班级以 SIS 为准；资助资格、宿舍分配、就业服务和个案服务记录由学工系统或其专业模块负责。心理、处分、资助等数据不得以“学生画像”名义向无关教师或第三方开放。

## 验收重点

1. 学籍异动后的服务资格、住宿、资助和权限回收。
2. 个案查看、导出、转交、结案和紧急干预的最小权限与完整审计。
3. 与财务、就业平台、宿舍门禁的接口只传必要字段并支持差异对账。
