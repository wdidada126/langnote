# 学生信息系统（SIS）

SIS（Student Information System）管理学生从录取、注册、学籍异动到毕业/学位的正式生命周期，是教育领域的学生主索引与学籍状态权威来源，不等同于 LMS 的学习过程记录。

## 数据流

```text
招生录取 -> SIS 建立学生、学籍、院系班级和培养层次
  -> 统一身份/校园服务开通账号与角色
  -> 教务、LMS、学工、宿舍、图书和财务消费受控学生副本
  -> 教务回传正式成绩/学分 -> SIS 支撑毕业、学位与档案归集
```

学生主档、学籍状态、行政组织和异动决定由 SIS 保存；课程活动、作业和考试明细由对应专业系统保存。学号、录取号、证件和统一身份必须有映射与合并/拆分审计。

## 验收重点

1. 录取撤销、报到注册、转学、转专业、休复学、留级、退学和毕业延期的状态机及历史留痕。
2. 同名学生、证件变更、重复录取和跨校区身份合并，禁止仅按姓名或手机号自动合并。
3. 下游同步延迟、重复消息和权限回收，确保学籍失效后不能继续访问不应拥有的服务。
