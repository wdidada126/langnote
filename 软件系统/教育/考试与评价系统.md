# 考试与评价系统

考试与评价系统管理题库、组卷、考试编排、身份核验、监考、阅卷、评分、复核和证书。它的核心是考试证据链与评分可追溯性，而不是只产生一个分数。

## 数据流

```text
教务提供课程、教学班、考试资格和成绩规则
  -> 考试系统生成场次、试卷/题库版本与准考信息
  -> 考生答卷、监考、异常和阅卷轨迹留存
  -> 评分/复核完成 -> 成绩结果回传教务审核发布
  -> SIS 只接收已发布的正式成绩或证书结果
```

题库、试卷版本、答卷、评分规则和复核结论由考试系统保存。在线监考、AI 判卷可提供风险提示，但异常认定和最终评分要有人工复核、申诉与审计路径。

## 验收重点

1. 题目泄露防护、试卷版本锁定、随机组卷可复现和阅卷权限隔离。
2. 考试中断、网络恢复、重复提交、缺考、违纪和成绩复核的状态与证据。
3. 成绩回传幂等、课程映射、教学班映射与成绩发布前后的版本控制。
