# 电力软件系统

## 领域边界

电力软件以安全稳定供电为第一约束，分为生产实时控制层、调度与市场层、配用电服务层、资产与经营层。SCADA/EMS/DMS 等系统直接或间接影响物理电网，和普通企业 IT 的一致性、发布和故障处理方式不同：实时遥测、遥信、遥控和保护闭锁必须优先考虑安全、时效、可验证性和人工接管，不能将云端分析结果直接作为未经校验的控制指令。

电力是能源系统的一部分；本文件聚焦发、输、变、配、用和电力市场，煤炭、油气、新能源场站经营、储能和碳管理的跨能源系统见[能源软件系统](能源软件系统.md)。

## 核心系统地图

| 系统 | 主要小类 | 权威数据/责任 |
| --- | --- | --- |
| 现场自动化 | 继电保护、RTU/IED、PLC、站控、采集终端 | 设备状态、测量值、保护动作和现场事件；以现场设备与规约时标为准。 |
| SCADA | 监视、数据采集、告警、遥控、历史库 | 遥信/遥测/遥控状态、告警确认和操作审计。 |
| EMS | 负荷预测、潮流、状态估计、AGC、经济调度、安全校核 | 调度模型、运行方式、计划与调度指令。 |
| DMS/OMS | 配网自动化、故障定位隔离恢复、停电管理、抢修 | 配网拓扑、设备状态、停电范围、工单和复电状态。 |
| AMI/计量与用电 | 智能电表、采集、抄表、费控、客户服务 | 表计读数、计量事件、计费周期和客户用电档案。 |
| 电力市场 | 交易申报、出清、合同、结算、偏差考核 | 交易申报、出清结果、计量数据、结算单和争议处理。 |
| 资产与工程 | EAM、GIS、项目、检修、物资、无人机巡检 | 资产台账、空间拓扑、缺陷、工单、检修记录和物资消耗。 |
| 数据与安全 | 生产数据平台、模型管理、网络安全、日志、灾备 | 数据目录、模型版本、访问控制、操作审计和恢复演练。 |

## 运行与经营数据流

### 调度实时闭环

```text
现场 IED/RTU/站控产生遥测、遥信、事件
  -> SCADA 采集、校验时标和质量码 -> 实时库/告警
  -> EMS 使用经校核的网络模型、负荷与机组状态进行分析
  -> 调度员审批/下达调度或 AGC 等受控指令
  -> 现场执行并回传状态 -> SCADA/EMS 复核结果和留存操作审计
```

分析、预测和数字孪生可以辅助决策，但现场控制需由授权边界、闭锁逻辑、调度规程和回执确认约束。任何控制指令都要区分“已下发”“已到站”“已执行”“状态已验证”，通信成功不代表电网状态已经改变。

### 计量、市场与结算

```text
AMI/关口计量采集原始表计与事件
  -> 计量系统校验、冻结、估抄/补抄和版本管理
  -> 市场系统消费经确认的计量、合同和出清结果
  -> 结算系统生成电费/市场结算/偏差考核单
  -> 营销、财务和客户服务完成账单、收款、对账与异议处理
```

原始计量、校核后的计量、市场结算量和客户账单量可能不同，必须说明口径、周期、版本和更正流程。不可用营销账单反推实时运行数据，也不能在报表层静默覆盖计量更正。

## 高风险边界与验收

1. 生产控制网与管理信息网分区隔离，跨区数据传递与远程运维须受控；生产系统补丁、模型和配置变更应经过仿真/测试、审批和回退方案。
2. 验证遥测质量码、时钟同步、通信中断、坏数据、重复事件、告警洪泛和人工接管，防止错误数据进入自动控制链路。
3. 验证 GIS 拓扑、DMS 开关状态、OMS 停电范围、现场工单之间的一致性，避免“图上已复电、现场未复电”。
4. 验证计量冻结、估抄补抄、结算重算、账单更正和财务对账的版本链；不要删除历史结算事实。

国家能源局将调度自动化、AGC 全生命周期质量管控和数字化转型作为新型电力系统相关能力；具体调度和市场规则以当期规程、地方/区域市场规则及企业制度为准。参考：[国家能源局相关说明](https://zfxxgk.nea.gov.cn/2023-08/16/c_1310762193.htm)、[新型电力系统发展蓝皮书](https://www.nea.gov.cn/download/xxdlxtfzlpsgk.pdf)。
