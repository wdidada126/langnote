# 充电运营系统

充电运营系统管理站点、桩枪、鉴权、充电会话、计量、订单、支付、结算、运维和负荷管理。它同时连接车辆、用户、配电和支付，必须区分设备状态、电量交付和资金结算。

## 数据流

```text
用户/车辆鉴权 -> 充电桩创建会话并上报状态/计量
  -> 运营系统生成订单、价格与优惠 -> 支付渠道处理付款
  -> 支付渠道回传付款状态 -> 充电结束确认电量
  -> 运营结算、站点对账、发票和财务凭证
  -> EnMS/电网侧消费负荷与需求响应数据
```

充电桩/表计是会话和电量事实源，运营系统负责订单与策略，支付系统负责收款状态。支付成功不代表电量已交付，充电中断/退款需按会话、计量和价格规则处理。

## 验收重点

1. 离线桩、断网补传、启动失败、异常停止、漫游、换枪和计量更正。
2. 会话、计量、订单、优惠、支付、退款、发票和站点结算逐笔对账。
3. 负荷控制、储能协同和需求响应命令的授权、回执与安全边界。
