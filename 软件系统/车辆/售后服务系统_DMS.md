# 车辆售后服务系统（DMS）

DMS（Dealer Management System）管理预约、维修、配件、质保、工时、索赔、召回和客户服务。它记录售后执行事实，并将质量问题反馈研发/制造；不能替代车端诊断、VIN 实装配置或财务收款系统。

## 数据流

```text
TSP/客户/经销商发起告警或预约 -> DMS 创建维修工单
  -> 查询 VIN 配置、质保和配件库存 -> 诊断/维修/换件
  -> 记录工时、配件批次、结果和客户确认
  -> 回写质保索赔/账单/召回完成状态 -> QMS/PLM 分析质量闭环
```

维修工单、配件使用和质保结果由 DMS 负责；车端故障码由车端/TSP 提供；配件库存由 WMS/ERP 提供。召回必须以 VIN 与实际配置范围为准。

## 验收重点

1. 预约取消、工单分派、配件缺货、返修、质保拒付和客户争议。
2. VIN、软件版本、故障码、零件批次、工时和维修结果追溯。
3. 召回通知、到店执行、未完成车辆清单与监管/质量报表对账。
