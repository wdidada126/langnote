# 车联网平台（TSP）

TSP（Telematics Service Platform）管理车辆身份、用户绑定、遥测接入、告警、远程服务和命令生命周期。它是云端车辆服务事实源，不是车端安全控制的替代者。

## 数据流

```text
制造/交付提供 VIN、配置、用户绑定 -> 车端安全通信接入 TSP
  -> TSP 校验身份并存储遥测/事件/诊断
  -> App/运营平台按授权查询或发起命令
  -> TSP 校验权限和车辆状态 -> 车端执行/拒绝 -> 回传最终状态与审计
```

车辆实际状态以车端回传为准；TSP 的命令状态须区分已发送、已接收、已执行和已验证。用户授权、车辆所有权变更和数据用途是独立状态。

## 验收重点

1. VIN 绑定/解绑、二手车过户、设备证书轮换和账号权限回收。
2. 消息重复、乱序、离线缓存、网络切换、数据保留和远程命令超时。
3. 数据分类分级、最小化访问、导出审计和安全事件处置。
