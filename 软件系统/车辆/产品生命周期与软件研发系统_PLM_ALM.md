# 产品生命周期与软件研发系统（PLM/ALM）

PLM/ALM 管理车型、BOM、配置、需求、软件架构、测试、缺陷和发布基线。它是研发定义与证据的权威系统，制造和车端运行系统只能消费已批准的配置，不应自行生成车型软件基线。

## 数据流

```text
需求/法规 -> ALM 需求、风险、测试与缺陷
  -> PLM 定义车型、零部件、软件 BOM 和配置基线
  -> 审批放行 -> MES/OTA 获取适配版本与工艺要求
  -> 制造、车端和售后回传质量问题 -> 研发变更与新基线
```

需求、配置、测试证据和放行基线归 PLM/ALM 管理；VIN 实装配置由制造系统记录；车辆实际软件版本由车端/TSP 回传确认。

## 验收重点

1. 需求到测试到发布的追踪、变更影响分析和版本冻结。
2. 车型/硬件/ECU/软件兼容矩阵与 OTA、MES 的一致性。
3. 缺陷、功能安全/网络安全证据和量产放行审批可审计。
