# 制造执行与质量系统（MES/QMS）

MES 管理生产订单、工艺、工位、刷写、装配和追溯；QMS 管理质量检验、缺陷、不合格、返工和 CAPA。它们以 VIN、零件批次和工位时间线记录制造事实。

## 数据流

```text
PLM 下发已批准 BOM/工艺/软件基线 -> MES 排产与执行
  -> 工位装配、刷写、测试记录 VIN 与零件序列号
  -> QMS 检验/缺陷/返工闭环 -> 放行
  -> 交付系统与 TSP 取得 VIN 实装配置 -> 售后/召回使用追溯数据
```

PLM 是设计基线，MES 是实际制造执行，QMS 是质量处置。设计版本不能覆盖已生产 VIN 的实装记录，返工后的最终配置要重新确认。

## 验收重点

1. VIN、零部件批次、软件刷写、工位、检验与返工全链路。
2. 工艺变更、缺件替代、离线工位补传和重复过站处理。
3. 缺陷到批次/VIN/召回范围的可追溯性和 CAPA 闭环。
