# 超网 sobs

IBPS（Interbank Payment System）

“超网”是中国银行业内部常用的一个术语，它是 “超级网银” 的简称。
全称是：网上支付跨行清算系统（又称 Super Online Banking System），由中国人民银行（央行）建设和运营。

###  一、什么是“超网”（超级网银）？

超网 是中国人民银行推出的一套 跨行支付与清算系统，旨在实现不同银行之间的快速、便捷、低成本的资金划转。

它于 2010 年 正式上线，是继大额支付系统（HVPS）、小额支付系统（BEPS）之后的重要支付基础设施。

###  二、“超网”的核心功能

| 功能 | 说明 |
|------|------|
| 跨行转账实时到账 | 支持在不同银行之间 7×24 小时实时到账，单笔限额一般为 100万元（具体以银行设置为准）。 |
| 统一账户管理 | 用户可通过一家银行的网银或手机银行，查询、管理在其他银行开立的账户（需授权）。 |
| 跨行代收代付 | 支持跨行自动扣款（如水电费、贷款还款）、批量代发工资等。 |
| 手机号转账 | 输入对方手机号即可完成跨行转账，无需输入卡号、开户行。 |

>  举例：你在工行手机银行里，可以直接向建行、农行的朋友转账，几秒钟到账，这就是“超网”在背后支撑。

### 三、“超网” vs 普通网银转账

| 对比项 | 普通网银转账（小额/大额） | 超网（超级网银） |
|--------|--------------------------|------------------|
| 到账速度 | 小额：实时；大额：工作日实时 | 7×24 小时实时 |
| 单笔限额 | 大额：无上限（工作日）；小额：100万 | 一般100万元以内 |
| 服务时间 | 大额：工作日 8:30–17:15；小额：7×24 | 7×24 小时全年无休 |
| 使用场景 | 大额资金划拨 | 日常跨行转账、实时支付 |
| 清算系统 | 大额/小额支付系统 | 网上支付跨行清算系统 |

### 四、银行内部如何使用“超网”？

在银行内部系统中，“超网”通常表现为：

- 支付清算平台 的一个通道
- 柜面或网银系统中的 “跨行实时转账” 功能
- 手机银行中的 “一键转账”、“手机号转账”
- 自动代扣协议签约（如第三方支付绑定银行卡）

银行系统会根据交易金额、时间等自动选择走“超网”还是“小额”或“大额”系统。

### 五、常见别名

- 超级网银
- 超网
- 网上支付跨行清算系统
- IBPS（Interbank Payment System）

### 六、总结

> “超网” = 央行建设的、支持7×24小时跨行实时转账的支付系统  
> 它让老百姓和企业可以 随时随地、快速安全地进行跨行转账，是现代数字支付的重要基石。


如果你是在银行做开发、运维、运营或风控，“超网”是必须了解的核心支付系统之一。需要关注其：
- 交易限额
- 对账文件（如 `NPC` 清算文件）
- 异常处理（如冲正、超时）
- 与银联、网联的区别
