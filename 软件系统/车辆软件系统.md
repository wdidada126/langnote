# 车辆软件系统

## 领域边界

车辆软件覆盖整车研发、供应链与制造、车辆电子电气架构、车联网、智能驾驶、售后服务、金融保险和充电/换电运营。它既是制造业软件，又包含高实时性的车端软件与安全关键系统。必须区分：车端实时控制、云端远程服务、研发配置、生产追溯和售后经营的数据所有权与安全级别。

车联网和 OTA 不是单纯 App 功能。它们涉及车辆身份、软件配置、远程命令、车辆运行数据、版本兼容、安全验证、用户授权和可回退发布。对智能网联汽车，网络安全、数据安全、软件升级和自动驾驶数据记录已有专门标准与监管要求，实施应按车型、功能和法规版本评估。

## 核心系统地图

| 系统 | 主要小类 | 权威数据/责任 |
| --- | --- | --- |
| 产品研发 | PLM、需求/架构、ALM、仿真、测试、配置/BOM、软件物料清单 | 车型配置、零部件版本、软件需求、测试证据与放行基线。 |
| 制造与质量 | ERP、MES、QMS、WMS、设备、工艺、追溯 | 生产订单、VIN、工位、零件批次、质量缺陷与返工记录。 |
| 车端软件 | ECU、域控制器、BMS、座舱、网关、诊断、日志 | 车辆实际软件版本、标定、故障码、运行状态和安全控制。 |
| 车联网平台（TSP） | 车辆身份、远程状态、告警、指令、围栏、数据接入 | 车辆数字身份、在线状态、遥测消息、命令生命周期和用户绑定。 |
| OTA 与软件运维 | 软件包、分批发布、兼容性校验、下载、安装、回滚、证据 | 发布策略、车辆适配清单、签名、安装结果和失败原因。 |
| 智能驾驶与数据闭环 | 传感器数据、标注、训练、仿真、评测、模型发布 | 数据授权、脱敏、场景、模型版本、评测和车端部署基线。 |
| 售后与客户 | DMS、预约、维修工单、配件、质保、召回、CRM | 车辆/车主关系、维修事实、配件批次、质保责任和召回执行。 |
| 充换电与能源服务 | 充电桩、站点、订单、计量、支付、结算、负荷管理 | 桩/枪状态、充电会话、计量、订单、结算和故障工单。 |

## 车辆全生命周期数据流

```text
PLM/ALM 定义车型、软件与零部件配置基线
  -> ERP/MES 按 VIN 生产并记录工位、零件批次、软件刷写和质量结果
  -> 交付系统绑定 VIN、车主、服务权益和初始配置
  -> TSP 接收车端遥测、告警、诊断与远程服务请求
  -> OTA 按已批准的软件基线、车辆兼容性和发布策略下发升级
  -> 车辆验证、安装、回滚或失败回执 -> TSP/售后形成可追溯记录
  -> 售后 DMS 处理维修、配件、质保和召回，并反馈质量/研发闭环
```

VIN、零部件序列号、ECU/软件版本、车主授权和维修记录需可关联，但权限不同。车辆制造配置是生产事实，车端实际版本是运行事实，云端“计划升级”不是已安装事实；售后工单也不能替代车端诊断数据。

## 车联网、远程命令与 OTA

```text
车端采集状态/事件 -> 安全通信 -> TSP 接入、鉴权、校验、存储
  -> 用户 App/运营平台查询经授权的车辆数据
  -> 远程命令或 OTA 请求经身份、权限、车辆状态和安全策略校验
  -> 车端接收并确认 -> 执行/拒绝/超时/回滚 -> 回传最终状态和审计证据
```

命令“云端已发送”“车辆已接收”“车辆已执行”“车辆状态已验证”必须独立记录。对门锁、动力、充电、驾驶辅助等安全相关能力，远程命令应有严格前置条件、速率限制、审计、失效策略与人工应急处置，不能以 App 接口成功判断车辆已经安全执行。

## 数据、质量与验收

1. 车辆/用户数据按目的最小化收集，建立数据分类分级、授权、保留、共享、出境和删除/匿名化流程；运营分析与训练数据不可越权复用。
2. OTA 验收包括软件签名、完整性、车型/硬件/电量/网络/驻车等前置条件、灰度策略、失败回滚、断点续传、版本兼容和事故追溯。
3. 建立从质量缺陷到 VIN、批次、软件版本、维修、召回和客户通知的链路；召回范围应基于可验证配置事实，而不是营销车型名称。
4. 充电业务分别对齐桩状态、充电会话、计量值、订单、支付、优惠、结算与电网/站点负荷数据；支付成功不代表电量已交付。
5. 智驾数据闭环记录场景来源、脱敏方式、标注版本、训练数据集、模型评测、车端版本和安全监控，避免模型版本不可追溯。

工信部发布的 GB 44495-2024、GB 44496-2024、GB 44497-2024 分别涉及整车信息安全、软件升级和自动驾驶数据记录，并自 2026 年 1 月 1 日起实施；车联网服务还应落实数据分类分级、应用安全和安全事件处置等要求。参考：[三项强制性国家标准说明](https://wap.miit.gov.cn/xwdt/gxdt/sjdt/art/2024/art_9fa0f052fe7d4a4683e366eb1afff952.html)、[车联网网络与数据安全通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2021/art_ba43080de41242e4ab6d6d5fa3218ff9.html)。
