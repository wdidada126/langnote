# DMS/OMS 配电与停电管理系统

DMS 管理配电网拓扑、自动化、故障定位隔离恢复；OMS 管理停电事件、客户影响范围、抢修和复电。二者必须与 GIS、SCADA、现场作业和客户服务同步，不能只在图上修改开关状态。

## 数据流

```text
GIS 提供资产与拓扑 -> SCADA 提供开关与告警
  -> DMS 分析故障和恢复方案 -> 调度/现场执行
  -> OMS 计算停电范围、生成抢修工单与客户通知
  -> 现场回传作业/复电 -> SCADA/DMS/OMS 交叉核验并关闭事件
```

GIS 负责资产空间与设计拓扑，SCADA 负责实时状态，OMS 负责客户影响和工单状态。三个系统需保存来源和时效，避免逻辑拓扑、现场状态和客户停电范围互相覆盖。

## 验收重点

1. 故障隔离、转供、计划停电、抢修延期、误报和复电确认。
2. 开关状态、拓扑模型、停电客户清单与现场工单的一致性核对。
3. 客户通知只在受控停电状态后发送，并支持纠正/追加通知。
