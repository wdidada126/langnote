# 电力 SCADA 系统

SCADA 负责电网/场站的监视与数据采集，处理遥测、遥信、告警和受控遥控。它是生产实时系统，数据质量码、时钟、操作权限和回执比普通 IT 接口吞吐更重要。

## 数据流

```text
IED/RTU/站控 -> SCADA 采集遥测遥信与事件 -> 实时库/告警
  -> EMS/DMS/调度员消费经校验数据
  -> 授权操作生成遥控指令 -> 现场执行/拒绝 -> SCADA 回读状态并审计
```

现场设备是状态事实源；SCADA 记录采集、质量和操作事实；EMS/DMS 不能把预测结果直接当成现场状态。

## 验收重点

1. 时钟同步、质量码、坏数据、通信中断、告警洪泛和事件重放。
2. 指令下发、到站、执行、状态验证分阶段审计，支持人工接管。
3. 生产控制网隔离、最小权限、配置变更审批与回退演练。
