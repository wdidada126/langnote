# 电力市场交易与结算系统

电力市场系统管理注册、申报、出清、合同、计量、偏差和结算。它以市场规则和经确认的计量为依据，不拥有调度现场控制状态，也不应改写 AMI 原始计量。

## 数据流

```text
市场主体注册/合同 -> 交易申报 -> 出清与结果发布
  -> 调度执行与 AMI/关口计量形成实际量
  -> 计量校验/冻结 -> 市场结算与偏差考核
  -> 财务、支付、客户账单对账 -> 异议与重算处理
```

申报、出清、计量、结算单和付款状态分别有版本。出清结果不是实际发用电量，计量确认不是资金到账，结算重算需保留原结算单与规则版本。

## 验收重点

1. 申报撤回/修改、规则切换、出清重跑、计量更正和结算重算。
2. 合同、出清、计量、偏差、结算与财务凭证逐层对账。
3. 市场主体权限、报价保密、审计与争议证据归档。
