# AMI 智能计量系统

AMI（Advanced Metering Infrastructure）管理智能电表、采集终端、抄表、事件、费控和计量数据处理。它面向客户计量与结算，不能把实时 SCADA 测量或营销账单直接替代为关口计量事实。

## 数据流

```text
电表/终端 -> AMI 采集读数与事件 -> 计量校验、冻结、估抄/补抄
  -> 营销/电力市场消费确认计量 -> 账单或市场结算
  -> 支付/财务回传收款与对账 -> 客服处理异议和更正
```

原始读数、冻结量、估抄补抄、结算量和账单量分别留存。计量更正要带规则、版本、审批和影响账期，不能静默更新历史账单。

## 验收重点

1. 表计离线、时钟偏差、通信补传、换表、倍率变更和异常用电事件。
2. 计量冻结、结算重算、账单更正、退费及客户异议的可追溯链。
3. 表计身份、客户户号、计量点和资产 GIS 映射一致性。
