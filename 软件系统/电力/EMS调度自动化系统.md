# EMS 调度自动化系统

EMS（Energy Management System）用于电网调度，包含状态估计、潮流、安全校核、负荷预测、机组计划和 AGC 等。它的输出是受规程约束的调度决策或建议，不是无条件自动控制。

## 数据流

```text
SCADA/实时库提供质量受控的量测与设备状态
  -> EMS 使用网络模型、机组/负荷计划进行分析
  -> 调度员审批或自动控制策略下达指令
  -> SCADA 回传现场执行结果 -> EMS 重新校核并留存运行方式
```

网络模型、运行方式和计算版本由 EMS 管理；量测原始事实来自 SCADA；市场计划与实际执行差异需通过市场/结算系统处理。

## 验收重点

1. 模型版本、拓扑变更、状态估计坏数据、预测偏差和降级运行。
2. AGC/控制策略的权限、边界、人工接管、回执与事故追溯。
3. 仿真环境与生产环境隔离，禁止未经验证的模型/算法直接影响控制。
